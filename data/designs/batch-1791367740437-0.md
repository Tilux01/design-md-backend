# UI/UX Specification: Dark Green Aesthetic Collage Feed

A high-fidelity implementation guide for creating a mood-board style social/media feed with an organic, scrapbook-inspired dark green aesthetic.

---

## 1. Global Layout & Theme

- **Background Color:** Deep Forest Green (`#1b3b22` or similar rich dark green texture).
- **Layout Structure:** Single-column vertical scrolling feed (`overflow-y: auto`).
- **Composition Style:** Scattered collage/scrapbook layout with irregular margins, overlapping elements, and subtle drop shadows on media items to create depth.

---

## 2. Typography & Text Styles

- **User Handles & Timestamps:**
  - Font Family: Sans-serif (clean, minimalist).
  - Size: 12px - 14px.
  - Color: Muted white / light sage green (`#d1e7dd`).
- **Body Text / Captions:**
  - Font Family: Sans-serif.
  - Size: 14px.
  - Color: Off-white (`#f8f9fa`).

---

## 3. Component Specifications

### A. Ambient Background Elements (Collage Accents)
- **Stickers / Graphics:**
  - Small illustrative icons (e.g., stylized shapes, plant leaves, abstract objects) scattered randomly near the top and side borders.
  - Positioning: Absolute positioning (`position: absolute`) anchored relative to the viewport/container.
- **Floating Orbs / Circles:**
  - Soft glowing circular elements (off-white/cream colored) positioned across the corners to mimic photo corners or decorative pins.

---

### B. Feed Item (Post Block)

Each post consists of a header, a primary media frame, and interactive indicators.

#### 1. Post Header
- **Layout:** Flex row (`display: flex; align-items: center;`).
- **Avatar:**
  - Shape: Circular (`border-radius: 50%`).
  - Size: ~32px x 32px.
- **Metadata:**
  - Username on the left.
  - Timestamp (e.g., "1 hr ago") aligned to the right or below.

#### 2. Media Container (Polaroid/Card Style)
- **Border / Frame:**
  - Thick white or cream border simulating instant film or a matted photograph (`border: 6px solid #fdfbf7`).
  - Subtle drop shadow (`box-shadow: 0 8px 24px rgba(0,0,0,0.3)`).
- **Media Type A (Portrait Photography):**
  - Aspect Ratio: Varies (approx. 4:3 or 16:9 landscape/portrait mix).
  - Content: High-fashion or portrait photography with warm, muted tones.
- **Media Type B (Multi-person shot):**
  - Same framed Polaroid aesthetic, placed further down the feed flow with slight asymmetry.

#### 3. Interaction / Action Bar
- **Icons:** Minimalist white icons (Heart/Like, Comment, Share) positioned below or subtly overlaid on the bottom edge of the media frame.

---

## 4. CSS Blueprint (Core Variables)

```css
