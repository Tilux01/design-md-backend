# Design Specification: Umbrella World Landing Page

This document outlines the exact specifications for cloning the "Umbrella World" e-commerce landing page shown in the media. 

---

## 1. Global Layout & Viewport

*   **Display Mode:** Fullscreen, responsive web layout (no device frames, mockup shadows, or background padding).
*   **Aspect Ratio:** Fluid/Responsive (desktop view depicted).
*   **Grid System:** Asymmetric layout featuring a left-aligned text hero section and a right-aligned product showcase.

---

## 2. Color Palette

*   **Deep Charcoal / Navy (Background):** `#2A3442` (Primary canvas background with subtle wave overlays).
*   **Darker Wave Overlay:** `#202834` (Used for background depth layers).
*   **Vibrant Orange (Accent):** `#FF6600` (Used for CTA buttons, the umbrella asset, and user profile accent).
*   **Pure White (Text/Icons):** `#FFFFFF` (Primary headlines, menu items, and line icons).
*   **Muted Gray (Secondary Text):** `#A0AAB2` (Navigation links, footer elements, and price tag background text).

---

## 3. Typography

### Primary Font Families
*   **Heading / Script Font (for "exclusive"):** *Pacifico* or *Great Vibes* (Fallback: `cursive`, `sans-serif`).
*   **Sans-Serif Bold (for "umbrella"):** *Montserrat* or *Poppins* (Font weight: **900 Black**, Fallback: `sans-serif`).
*   **Sans-Serif Regular (for UI/Navigation):** *Inter* or *Roboto* (Font weights: **400 Regular**, **500 Medium**, Fallback: `sans-serif`).

### Typography Hierarchy
1.  **Logo ("Umbrella World"):** 
    *   Style: Italicized serif/script.
    *   Size: `16px`, White.
2.  **Navigation Links ("umbrellas", "accessories", "special"):** 
    *   Style: Sans-serif, lowercase.
    *   Size: `13px`, Color: `#A0AAB2`, Hover: `#FFFFFF`.
3.  **Hero Script ("exclusive"):** 
    *   Style: Cursive script, lowercase.
    *   Size: `48px`, Color: `#FFFFFF`.
4.  **Hero Bold Headline ("umbrella"):** 
    *   Style: Heavy, ultra-bold sans-serif (`font-weight: 900`), lowercase.
    *   Size: `110px`, Letter-spacing: tight (`-2px`), Color: `#FFFFFF`.
5.  **Button ("shop now"):** 
    *   Style: Sans-serif, uppercase.
    *   Size: `12px`, Letter-spacing: `1px`, Color: `#FFFFFF`.

---

## 4. UI Components & Elements

### A. Navigation Bar (Header)
*   **Left:** Logo text *"Umbrella World"*.
*   **Center:** Menu links (`umbrellas`, `accessories`, `special`) + Search Icon (`🔍`).
*   **Right:** 
    *   Shopping Bag Icon (`🛍️`).
    *   User Profile Icon inside an Orange square container (`#FF6600`) with rounded corners (`border-radius: 6px`).

### B. Hero Section (Left Content)
*   **Text Block:** Positioned centrally-left.
    *   Line 1: *"exclusive"* (Script font).
    *   Line 2: *"umbrella"* (Massive bold font, partially overlaps with the product image).
*   **Call to Action (CTA):** 
    *   Text: *"shop now"*
    *   Background: `#FF6600` (Vibrant Orange).
    *   Padding: `12px 28px`.
    *   Border-radius: `4px` (subtle rounding).
    *   Shadow: Soft drop shadow matching the orange hue.

### C. Product Showcase (Right Content)
*   **Main Asset:** High-detail 3D render of an open bright orange umbrella (`#FF6600`), angled dynamically from top-right to bottom-center. The handle extends toward the bottom-left.
*   **Price Badge:** 
    *   Shape: Perfect circle, white background (`#FFFFFF`).
    *   Text inside: Small uppercase *"from"* (`9px`, `#777`), large bold `"$25"` (`16px`, `#000`).
    *   Position: Floating near the top right canopy of the umbrella.

### D. Footer Area
*   **Left:** Scroll indicator with mouse icon + *"scroll down"* text (`12px`, `#A0AAB2`).
*   **Right:** Social media icon links (`f`, `📸`, `🐦`, and a share/network icon) aligned horizontally in white outline style.

---

## 5. Animation & Interaction Specifications

*   **Page Load Animations (Entrance):**
    *   *Hero Text ("exclusive" & "umbrella"):* Fade in with a slight upward translation (`transform: translateY(20px)` to `0`) over `0.8s` with an ease-out cubic-bezier curve.
    *   *Umbrella Image:* Slides in smoothly from the right with a subtle scale effect (`scale(0.95)` to `scale(1.0)`) over `1.0s`.
    *   *Price Badge:* Scales up with a slight bounce effect after the umbrella settles (`delay: 0.8s`).
*   **Hover States:**
    *   *Nav Links:* Color transition from `#A0AAB2` to `#FFFFFF` (`transition: color 0.2s ease`).
    *   *CTA Button ("shop now"):* Slight elevation (translateY `-2px`) and brightness increase on hover.
    *   *Social Icons:* Opacity shift from `0.7` to `1.0`.
*   **Scroll Behavior:**
    *   Smooth scrolling enabled (`scroll-behavior: smooth`).
    *   Parallax effect on background waves and foreground umbrella when scrolling down.
