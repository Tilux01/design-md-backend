# Design Specification: Broqqoli Multibrand Store

## 1. Global Styles & Reset

- **Color Palette:**
  - Dark Theme Background: `#111111` (Very dark gray/black)
  - Light Theme Background: `#f4f4f4` (Off-white)
  - Primary Text / Brand Elements (Dark): `#ffffff` (White)
  - Primary Text (Light): `#111111` (Black)
  - Secondary / Muted Text: `#888888` (Medium gray)
  - Accent / Price Elements: `#111111` (Black on light), `#ffffff` (White on dark)

- **Typography:**
  - Font Family: Sans-serif, geometric, grotesk style (e.g., Inter, Helvetica Neue, or Roboto Mono for numbers/subtext).
  - Brand Title ("BROQQOLI"): Bold, uppercase, large scale. The letter 'Q' features a distinct zero-slash symbol (`Ø`).
  - Body / Subtext: Lightweight, uppercase/normal mixed tracking.

- **Layout Structure:**
  - Full-width sections spanning 100% viewport width.
  - Generous whitespace and padding.
  - Multi-column editorial grid (Header, Sidebar navigation, Center showcase, Footer utility).
