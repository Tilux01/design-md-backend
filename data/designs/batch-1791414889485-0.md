# Design Specification: Mobile Dashboard UI

## 1. Overview & Layout
* **Target Viewport**: Full-screen mobile (`393px × 852px`, standard iOS safe areas).
* **Layout Structure**: Vertical flex column (`flex-direction: column`) with `padding: 0 20px 24px 20px`.
* **Background**: Light neutral `#F5F5F7`.

---

## 2. Color Palette

| Token | Hex Value | Usage |
|---|---|---|
| `bg-main` | `#F4F5F7` | App background |
| `card-white` | `#FFFFFF` | Primary greeting card |
| `card-yellow` | `#FDE68A` | Alert/action banner |
| `card-cyan` | `#BAF3E6` | Highlights/stats card |
| `dock-bg` | `#111111` | Floating bottom navigation |
| `dock-indicator` | `#FFFFFF` | Active switch handle |
| `text-primary` | `#0F172A` | Headlines and heavy emphasis |
| `text-secondary` | `#64748B` | Subheads, small labels |

---

## 3. Typography

* **Primary Font**: `Cabinet Grotesk` or `Plus Jakarta Sans` (Geometric, high-contrast display sans).
* **Secondary Font**: `Inter` (UI elements, badges, small metrics).
* **Fallback Stack**: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.

### Font Scales
* **Hero Headline**: `32px` / Line-height: `1.15` / Weight: `800` (Extrabold).
* **Sub-labels / Tagline**: `13px` / Line-height: `1.4` / Weight: `500` (Medium).
* **Card Titles**: `18px` / Line-height: `1.2` / Weight: `700` (Bold).
* **Metadata / Badges**: `11px` / Line-height: `1.2` / Weight: `600` (Semibold), uppercase tracking: `+0.5px`.

---

## 4. Component Specifications

### 4.1 Top App Bar
* **Height**: `48px`
* **Elements**:
  * Left: User avatar (`36px` circle, border `1px solid rgba(0,0,0,0.05)`).
  * Right: Notification bell icon button (`36px` circular hit area).

### 4.2 Hero Section (Top Card)
* **Background**: `#FFFFFF`
* **Radius**: `24px`
* **Padding**: `24px 20px`
* **Content**:
  * Pre-title: "Weekly" (small secondary label).
  * Headline: `"Hello 👋 Daniel! / & your mutual / score is above / average"`
  * Bottom Metadata Row: Border-top `1px solid #F1F5F9`, `padding-top: 12px`, 3-column micro-metrics (`7 friends`, `Together 120h`, `+8%`).

### 4.3 Middle Banner (Yellow Card)
* **Background**: `#FDE68A`
* **Border Radius**: `16px`
* **Height**: `52px`
* **Padding**: `0 16px`
* **Layout**: Inline flex, horizontal alignment with text on the left and chevron/action icon on the right.

### 4.4 Feature Section (Cyan Card)
* **Background**: `#BAF3E6`
* **Border Radius**: `24px`
* **Padding**: `20px`
* **Elements**:
  * Top-right pill button: Solid `#111111`, white micro-text (`12px`), `padding: 6px 14px`, border-radius `999px`.
  * Left content: Stat tags and bold category descriptor.

### 4.5 Floating Bottom Dock
* **Position**: Floating fixed, bottom `24px`, horizontal center.
* **Dimensions**: Height `56px`, Width `200px`.
* **Background**: `#111111`
* **Corner Radius**: `999px` (Capsule shape).
* **Contents**:
  * 3 segmented icon sections with center oval toggle (`#FFFFFF` background, `36px × 24px` dimension).

---

## 5. Motion & Interaction

* **Card Entrance**: Staggered fade slide-up (`translateY(16px)` to `0`, `cubic-bezier(0.16, 1, 0.3, 1)`, duration `450ms`).
* **Dock Toggle**: Smooth slide translation for the white pill indicator (`spring(mass: 1, stiffness: 200, damping: 20)`).
* **Button Feedback**: Active tap scaling `scale(0.97)` on cards and interactive pills.
