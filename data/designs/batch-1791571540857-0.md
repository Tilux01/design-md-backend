# UI/UX Specification: Doctor Appointment Booking Mobile App

## 1. Global Layout & Structure
- **Target Platform:** iOS (Designed for iPhone with Dynamic Island and home indicator).
- **Layout Approach:** Full-screen responsive mobile view with a split background design (teal gradient top half, clean white bottom half).
- **Container Structure:** 
  - **Header Section:** Dark teal-to-white gradient background covering approximately the top 45% of the screen. Features a back button (`<`), profile image, doctor details, quick action icons, and favorite icon.
  - **Content Body Section:** White rounded container overlapping the gradient header, containing stats, month selector, horizontal date scroller, time slot grid, and a bottom sticky CTA button.

---

## 2. Color Palette
- **Primary / Brand Teal:** `#116979` (Used for buttons, selected states, and header background gradient start).
- **Dark Teal / Navy:** `#0c4a55` (Used for darker text headers, selected time pill outlines, and status bar elements).
- **Teal Gradient Base:** A linear gradient shifting from a vibrant teal (`#1B8090`) to a muted teal (`#0E5A68`).
- **Surface White:** `#FFFFFF` (Main background for the lower content area).
- **Light Gray Surfaces:** `#F0F4F5` (Used for unselected pills, icon backgrounds, and stat cards).
- **Muted Text / Secondary:** `#6E8085` (Used for secondary labels, unselected dates, and metadata).
- **Rating Gold:** `#F5A623` (Used for the star rating icon).

---

## 3. Typography & Fonts
*Note: If specific custom fonts are unavailable, use the system default sans-serif font stack (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`).*

- **Header / Doctor Name:**
  - Font Weight: Bold (`700`)
  - Size: `24px`
  - Color: `#FFFFFF`
- **Section Titles ("Select Date", "Select Time"):**
  - Font Weight: Semi-Bold (`600`)
  - Size: `16px`
  - Color: `#333333`
- **Body & Metadata (Specialty, Stats):**
  - Font Weight: Regular / Medium (`400` - `500`)
  - Size: `13px` - `14px`
  - Color: `#6E8085` (White variant for header metadata: `#E0E6E8`)
- **Interactive Elements (Months, Times, CTA Button):**
  - Font Weight: Medium (`500`)
  - Size: `14px` - `16px`

---

## 4. Component-by-Component Breakdown

### A. Status Bar & Navigation Bar
- **Time:** `9:41` (Bold, white, top left).
- **System Icons:** Cellular signal, Wi-Fi, and Battery indicators (White, top right).
- **Back Button:** Circular button with a left chevron (`<`) on the top-left of the image container.
- **Favorite Icon:** Circular button with a heart outline (`♡`) on the top-right of the image container.

### B. Doctor Profile Section
- **Doctor Image:** 
  - A professional portrait of a female neurologist with long brown hair, wearing a white medical coat and a stethoscope around her neck. She has a warm, welcoming smile and is centered within a circular masked container overlapping the header gradient.
- **Doctor Name:** "Tracey Clifford" (`24px`, Bold, White).
- **Specialty & Rating:**
  - Text: "Neurologist"
  - Rating: Star icon (`#F5A623`) followed by "4.8" (`14px`, White/Light Gray).
- **Quick Action Buttons:** Three circular icon buttons aligned horizontally:
  1. Chat/Message icon (White background, dark teal icon).
  2. Phone/Call icon.
  3. Video Call icon.

### C. Statistics Bar
- Three horizontal stat cards arranged in a light gray rounded background container (`#F4F7F8`):
  1. **Experience:** Clock icon inside a circle + `8 years` / `Experience`.
  2. **Patients:** Group/People icon inside a circle + `2.7K+` / `Patients`.
  3. **Reviews:** Star icon inside a circle + `4.8` / `Reviews`.
- *Styling:* Centered text alignment, small subtle icons, font size `12px` for labels and `14px` for values.

### D. Date Selection Section
- **Section Title:** "Select Date" (`16px`, Semi-Bold).
- **Month Horizontal Picker:**
  - Pill-shaped buttons with rounded corners.
  - Months listed: `October`, `November` (Selected: Light teal fill `#D8EDF2`, dark text), `December`, `January`, `February`.
- **Date Horizontal Scroller:**
  - Displays dates for the active month (e.g., Sun 2, Mon 3, Tue 4, **Wed 5** (Selected), Thu 6, Fri 7, Sat 8).
  - **Selected State (Wed 5):** Pill card with dark teal background (`#116979`), white text, and a small dot indicator below the card.
  - **Unselected States:** Light gray background (`#F4F7F8`) with muted dark gray text for the day number and day name.

### E. Time Selection Section
- **Section Title:** "Select Time" (`16px`, Semi-Bold).
- **Time Slots:** Grid/horizontal layout of time pill buttons with clock icons:
  1. **10:30 AM** (Selected state: Outlined with primary teal border, teal text).
  2. **11:00 AM** (Unselected state: Light gray background, dark gray text).
  3. **12:00 PM** (Unselected state).
  4. **01:00 PM** (Unselected state).

### F. Call to Action (CTA) Button
- **Button Text:** "Book Appointment - $15/hr"
- **Styling:** 
  - Full-width pill-shaped button.
  - Background Color: `#116979` (Primary Teal).
  - Text Color: `#FFFFFF` (White).
  - Font Weight: Semi-Bold (`600`).
  - Font Size: `16px`.
  - Padding: Generous vertical padding (`16px`).
  - Position: Fixed or anchored to the bottom of the content view, just above the iOS home indicator bar.
