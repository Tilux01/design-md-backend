# Design Specification: E-Commerce Storefront

This document outlines the precise specifications for recreating the provided e-commerce storefront. The layout is optimized for full-screen display, utilizing a clean, minimalist aesthetic with a monochromatic palette accented by high-contrast product imagery.

---

## 1. Global Styles & Variables

*   **Color Palette:**
    *   Primary Background: Pure White (`#FFFFFF`)
    *   Primary Text / Borders: Deep Black (`#000000`)
    *   Secondary Text / Subtitles: Muted Gray (`#666666` or `#767676`)
    *   Button Backgrounds: Deep Black (`#000000`) with White Text (`#FFFFFF`)
*   **Typography:**
    *   Font Family: Sans-serif (system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif)
    *   Weights: Regular (400), Medium (500), Bold (700)
*   **Spacing & Grid:**
    *   Container Max-Width: ~1280px (centered)
    *   Standard Gap / Padding: 24px - 32px between grid items.

---

## 2. Layout Structure & Components

### A. Product Grid 1 (Top Section)
*   **Layout:** 4-column CSS Grid.
*   **Card Structure:**
    *   **Image Container:** Light gray background (`#F4F4F4`), square aspect ratio, centered product image.
    *   **Badges/Icons:** 
        *   Top-right: Favorite/Heart icon (outline).
        *   Top-left (optional): "Limited" tag (small rounded dark pill, white text).
    *   **Product Details:**
        *   Product Title: Regular weight, ~14px, dark gray/black.
        *   Price: Bold weight, ~14px, black.
        *   Add-to-Cart Action: Shopping bag icon inside a circular border, positioned bottom-right of the text block.

## 3. Responsive Behavior Guidelines
*   **Desktop (>1024px):** 4-column product grids, 2-column promo banner, multi-column mosaic grid for collections.
*   **Tablet (768px - 1023px):** 2-column product grids, stacked promo banner (image stacked above text), adjusted mosaic grid.
*   **Mobile (<768px):** Single-column product lists, stacked layout for all sections, full-width buttons.
