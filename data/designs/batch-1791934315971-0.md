# Design Specification: Minimalist Portfolio Landing Page

## 1. Color Palette

*   **Primary Background:** `#F6F6F6` (Off-white with subtle fine-grained film noise overlay).
*   **Primary Text & Accents:** `#111111` (Deep soft black).
*   **Secondary Text & Borders:** `#717171` (Mid-tone neutral gray).
*   **Card Fill:** `#E8E8E8` (Light neutral gray base for image loading).

---

## 2. Typography & Fallbacks

*   **Display Hero Font ("less."):**
    *   *Font:* Recoleta (Black) or Playfair Display (900/Black).
    *   *Fallbacks:* `Didot`, `Bodoni MT`, `serif`.
    *   *Specs:* `font-size: clamp(8rem, 18vw, 22rem)`, `line-height: 0.8`, `letter-spacing: -0.04em`, `font-weight: 900`.
*   **Title/Serif Accents ("Kobe Bryant", "Untitled Res"):**
    *   *Font:* Editorial New, Freight Display, or Cormorant Garamond.
    *   *Fallbacks:* `Georgia`, `serif`.
    *   *Specs:* `font-size: 1.25rem`, `font-weight: 400`, `letter-spacing: -0.01em`.
*   **UI & Navigation (Sans-Serif):**
    *   *Font:* Inter, Neue Haas Grotesk, or Helvetica Neue.
    *   *Fallbacks:* `system-ui`, `-apple-system`, `sans-serif`.
    *   *Specs:*
        *   Logo ("neil"): `font-weight: 800`, `font-size: 1.15rem`, `letter-spacing: -0.03em`.
        *   Nav links ("Print Shop", etc.): `font-size: 0.75rem`, `font-weight: 500`.
        *   Tags ("PORTRAIT", "EDITORIAL"): `font-size: 0.65rem`, `text-transform: uppercase`, `letter-spacing: 0.08em`.
        *   Rotated Label ("Categories +"): `font-size: 0.8rem`, `letter-spacing: 0.02em`.

---

## 3. Global Layout (100vw, 100vh)

*   **Container:** Full-screen viewport, `overflow: hidden`, edge padding: `2.5rem 3rem`.
*   **Noise Texture:** Fullscreen fixed layer, opacity `0.035`, blend mode `multiply`.

---

## 4. UI Structure & Components

### 4.1 Header (Top Bar)
*   **Position:** Fixed/Absolute across full width, top: `2.5rem`, horizontal padding matching viewport.
*   **Left:** Brand title `"neil"`.
*   **Center:** Inline flex container with horizontal gap `2rem`: `"Print Shop"`, `"Commercials"`, `"Covers"`.
*   **Right:** Custom hamburger button (two horizontal lines: width `22px`, thickness `1.5px`, vertical gap `5px`).

### 4.2 Left Vertical Anchor
*   **Position:** Absolute, left `3rem`, top `40%`.
*   **Transform:** Rotated `-90deg` (`transform-origin: left bottom`).
*   **Content:** Text `"Categories +"`.

### 4.3 Bottom-Left Hero Element
*   **Position:** Absolute, bottom `1.5rem`, left `3rem`.
*   **Content:** Text `"less."`.
*   **Alignment:** Baseline sits directly aligned with the bottom margin.

### 4.4 Carousel Slider Controller ("Slide")
*   **Position:** Center-left, vertically centered (`top: 50%`, `left: 48%`).
*   **Visual:** Circle border (`48px` diameter, `1px` thin stroke `#111`), containing centered text `"Slide"` (size: `0.7rem`).
*   **Details:** Partial progress arc or stroke on the upper right quadrant of the circle.

### 4.5 Portfolio Carousel (Right Column)
*   **Position:** Absolute, top `25%`, right `0`, flex row display, gap `2rem`.
*   **Layout:** Horizontal rail overflowing past the right edge of the screen.

---
