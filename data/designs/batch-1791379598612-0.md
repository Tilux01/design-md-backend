# Visual Design Specification & Implementation Blueprint

---

## 1. Global Layout & Viewport Setup

* **Viewport Strategy:** Full-screen immersive layout (`100vw` × `100vh`), centered container mimicking a desktop display card, or true full-screen responsive banner.
* **Canvas Dimensions (Design Reference):** Scaled within a 1440px-wide viewport grid.
* **Overflow Rules:** `overflow: hidden;` applied to prevent structural scrollbars during floating asset loops.
* **Z-Index Layers:**
  * Background layer: `z-index: 0`
  * Typography & UI Controls: `z-index: 10`
  * Floating Product Can & Blueberries: `z-index: 20`
  * Foreground overlapping elements (partially visible lower-right container): `z-index: 15`

---

## 2. Color Palette & Gradients

| Token | Hex Value | RGBA Equivalent | Usage Context |
| :--- | :--- | :--- | :--- |
| **Primary Background** | `#F8A5D3` | `rgba(248, 165, 211, 1)` | Base viewport canvas, dominant gradient field |
| **Deep Magenta Accent** | `#C73874` | `rgba(199, 56, 116, 1)` | Drop shadows, base grounding platform |
| **Electric Cyan** | `#1C8FE3` | `rgba(28, 143, 227, 1)` | Primary can body metallic blue base |
| **Rich Purple** | `#522165` | `rgba(82, 33, 101, 1)` | Can rims, vertical Japanese branding text, shadow tones |
| **Pure White** | `#FFFFFF` | `rgba(255, 255, 255, 1)` | Vertical kanji text, UI arrows, descriptive body copy |
| **Soft Pink Glow** | `#FBCFE8` | `rgba(251, 207, 232, 0.6)` | Ambient lighting behind the can and UI buttons |

### Background Gradient Specification
```css
background: radial-gradient(circle at 60% 40%, #FFB6E1 0%, #F582BE 55%, #E05698 100%);
```

---

## 3. Typography System

### Primary Japanese Typography (Left Vertical Title)
* **Text String:** `ソ ー ダ` (So-da)
* **Font Family:** `"Zen Maru Gothic"`, `"Hiragino Sans"`, `"Meiryo"`, `sans-serif`
* **Font Weight:** `700` (Bold)
* **Font Size:** `clamp(3.5rem, 6vw, 6.5rem)`
* **Line Height:** `1.1`
* **Letter Spacing:** `0.2em`
* **Writing Mode:** Vertical text layout (`writing-mode: vertical-rl;`)
* **Color:** Pure White (`#FFFFFF`)
* **Styling Detail:** Accompanied by a horizontal separator bar below/next to the characters (`width: 4rem; height: 3px; background: #FFFFFF;`).

### Secondary Can Branding Typography (Vertical Script)
* **Text String:** `ぶどう` (Budō - Grape)
* **Font Family:** `"Yuji Boku"`, `"Klee One"`, `"Sawarabi Mincho"`, serif
* **Font Weight:** `700`
* **Writing Mode:** Vertical text layout aligned along the front panel of the soda can.
* **Color:** Deep Indigo / Purple (`#3B1443`) with subtle outer glow.

### Body & Micro-Copy Typography (Lower Right Description)
* **Text String:** *"refreshing beverages Carbonated water, also known as soda, is water that contains carbonic acid (H2CO3), which, being unstable, easily decomposes into water and carbon dioxide (CO2), which comes out in the form of bubbles when the drink is depressurized."*
* **Font Family:** `"Inter"`, `"Helvetica Neue"`, `sans-serif`
* **Font Weight:** `300` (Light) / `400` (Regular)
* **Font Size:** `0.7rem` (11px equivalent)
* **Line Height:** `1.4`
* **Color:** `rgba(255, 255, 255, 0.85)`
* **Text Alignment:** Left-aligned within a max-width of `220px`.

---

## 4. UI Elements & Interactive Components

### Carousel Navigation Arrows (Left & Right)
* **Container:** Circular button shape (`border-radius: 50%`)
* **Dimensions:** `48px` × `48px`
* **Background Color:** `#FFFFFF`
* **Box Shadow:** `0 8px 24px rgba(120, 20, 60, 0.2)`
* **Icon:** Minimalist chevron `<` and `>` in `#C73874`, `18px` stroke width `2px`.
* **State (Hover):** Scale up to `1.08`, background shifts to `#FFF5FA`, cursor pointer.
* **Positioning:** Vertically centered on the banner; left arrow offset `8%` from the left edge, right arrow offset `8%` from the right edge.

---

## 5. Composition & Asset Positioning

### Central Product (Grape Soda Can)
* **Positioning:** Absolute/Flex centered, tilted slightly at an approximate `12-degree angle` (`transform: rotate(12deg)`).
* **Effects:**
  * **Water Droplets:** Overlay macro-droplet specular highlights across the cylindrical body.
  * **Base Platform Shadow:** Soft radial gradient ellipse (`#3A0E2B` at `40%` opacity) beneath the can base.
* **Anime Character Integration:** Rendered directly onto the front face of the can featuring a silver-haired anime girl with striking red eyes and a dark uniform jacket.

### Floating Blueberries
* **Distribution:** 7 distinct whole blueberries orbiting the central can.
* **Physics / Styling:** Each blueberry features realistic light refraction, water beads, and soft drop shadows underneath.
* **Depths:** Varying scales (`scale(0.7)` to `scale(1.2)`) to create depth-of-field separation.

---

## 6. Animation & Motion Specification

### 1. Floating Float / Idle Animation (Can & Blueberries)
* **Effect:** Gentle, organic floating oscillation simulating a weightless underwater or carbonated suspension effect.
* **CSS Keyframes:**
```css
@keyframes floatAnimation {
  0% {
    transform: translateY(0px) rotate(12deg);
  }
  50% {
    transform: translateY(-12px) rotate(14deg);
  }
  100% {
    transform: translateY(0px) rotate(12deg);
  }
}

.soda-can-wrapper {
  animation: floatAnimation 6s ease-in-out infinite;
}
```

### 2. Orbital Blueberry Drift
* **Effect:** Subtle asynchronous drift for individual blueberries to create dynamic liveliness.
```css
@keyframes berryDrift {
  0% { transform: translate(0, 0) scale(1); }
  50% { transform: translate(6px, -10px) scale(1.03); }
  100% { transform: translate(0, 0) scale(1); }
}

.blueberry-item {
  animation: berryDrift 4.5s ease-in-out infinite alternate;
}
```

### 3. UI Hover Micro-Interactions
* **Transition Property:** `all 0.3s cubic-bezier(0.4, 0, 0.2, 1)`
* **Active Press State:** `transform: scale(0.95);`
