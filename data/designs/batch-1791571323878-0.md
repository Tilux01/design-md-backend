# UI/UX Specification & Design System: Radiyal Employee Dashboard

## 1. Global Layout & Structure

*   **View Type:** Full-screen web application dashboard.
*   **Grid Framework:** Modular card-based layout utilizing clean white surface containers on a soft, light gray background.
*   **Spacing Strategy:** Generous padding (approx. 24px to 32px gaps) with soft corner radii (border-radius: 16px to 24px) for modern glassmorphism/neumorphism-inspired dashboard cards.
*   **Background Color:** `#F8F9FC` (Very light cool gray).
*   **Card Background:** `#FFFFFF` (Pure white with subtle drop shadows: `0px 4px 24px rgba(0, 0, 0, 0.04)`).

---

## 2. Typography & Font Stack

*   **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif.
*   **Fallback Strategy:** If `Inter` fails to load, the browser defaults to native sans-serif system fonts.
*   **Font Hierarchy:**
    *   **Page Title / Brand (`radiyal`):** 18px, Bold (700), Letter-spacing: -0.02em.
    *   **Section Headers (e.g., "Top Performer", "Progress"):** 16px, Semi-Bold (600), Color: `#1A1D1F`.
    *   **Primary Metrics (e.g., `18%`, `6.1 h`):** 24px–28px, Bold (700), Color: `#1A1D1F`.
    *   **Body Text & Labels (e.g., "Product Manager", "Employee"):** 12px–14px, Regular (400) / Medium (500), Color: `#6F767E`.
    *   **Microcopy / Captions (e.g., Time slots, Dates):** 11px, Regular (400), Color: `#9A9FA5`.

---

## 3. Color Palette

*   **Neutral Dark (Text/Icons):** `#1A1D1F`
*   **Neutral Gray (Secondary Text/Borders):** `#6F767E` to `#9A9FA5`
*   **Neutral Light (Backgrounds):** `#F8F9FC`
*   **Primary Brand Blue:** `#3B76F6` (Used for active states, primary buttons, charts)
*   **Accent Purple / Indigo:** `#6C5DD3` (Used in progress pills, branding icon)
*   **Success / Completion:** `#2A85FF` / Light Blue variant `#E4E9F2`

---

## 4. Component Breakdown

### A. Top Navigation Bar
*   **Left:** Brand logo featuring a stylized red/pink abstract square icon followed by the word **radiyal** in bold dark typography.
*   **Center Navigation Tabs:** Pill-shaped navigation menu container with a light gray background (`#F1F3F5`).
    *   Active Tab ("Dashboard"): Solid primary blue background (`#3B76F6`) with white text.
    *   Inactive Tabs ("Employee", "Devices", "Hiring", "Calendar", "Performance"): Transparent background with dark gray text (`#6F767E`). Hover state transitions to darker text.
*   **Right Utilities:** 
    *   "Setting" button with gear icon.
    *   Search icon button.
    *   Notification bell icon button.
    *   User profile avatar circle placeholder.

### B. Summary Metric Cards (Top Row)
Four distinct metric cards displaying high-level statistics:
1.  **Employees:** User icon + `45` (Bold) / `Employee` (Gray label).
2.  **Hirings:** User-plus icon + `26` (Bold) / `Hirings` (Gray label).
3.  **Projects:** Folder/Dashboard icon + `200+` (Bold) / `Projects` (Gray label).
4.  **Performance Progress Bar:** 
    *   Labels: Interviews (`15%`), Hired (`15%`), Project Time (`15%`).
    *   Multi-segmented visual progress bar using dark slate (`#272B30`), blue (`#3B76F6`), and light track backgrounds.

### C. Left Profile & Schedule Section (Interactive Calendar & User Card)
*   **User Profile Card:**
    *   **Image Description:** Professional studio portrait of a smiling woman with shoulder-length dark brown hair, wearing a black blazer over a white button-down shirt, set against a neutral gradient background.
    *   **Text Details:** "Kianna Curtis" (Bold, 16px) / "Product Manager" (Gray, 12px).
*   **Calendar / Weekly Schedule Grid:**
    *   **Header:** Date range (`02 - 06 March`) with left/right pagination chevrons and timezone selector (`(GMT +06:00) Public Time`).
    *   **Grid Columns:** Monday 02 through Friday 06.
    *   **Time Slots:** Vertical axis ranging from `09:00` to `13:00`.
    *   **Events:** 
        *   "Weekly Team Sync" (Mon, 10:00 - 11:30) with discussion subtitle and overlapping attendee avatar icons.
        *   "Onboarding Session" (Wed, 12:00 - 13:30) with dark charcoal background (`#1A1D1F`), white text, and attendee avatars.
        *   "Webinar" (Fri, 10:44 am) featuring a bright blue event card with Zoom integration badge.

### D. Central Analytics & Progress Widgets
1.  **Progress Work Time Card:**
    *   Displays `6.1 h` Total Work Time.
    *   Includes a diagonal arrow icon badge (`↗`) and a `4.5 hour` highlight pill.
    *   **Bar Chart:** Vertical frequency bars representing daily work hours from Monday (S) to Sunday (S), with active data points highlighted in solid black/dark blue.
2.  **Circular Progress Tracker:**
    *   Radial progress ring showing `03:45` Work Time.
    *   Includes play/pause media controls at the bottom (`▶` / `⏸`).
3.  **Onboarding Status Card:**
    *   Displays large `18%` completion metric.
    *   Segmented task progression breakdown bars (Task: 30%, 20%, 0%).

### E. Right Sidebar: Top Performers & Accordion Modules
1.  **Top Performer List:**
    *   Scrollable vertical list containing employee rows.
    *   Each row features: Circular user avatar image, Employee Full Name (Bold), and Job Title (Gray subtext).
    *   *Included Profiles:* Terry Ekstrom (Sr. Software Engineer), Giana Bator (Web Developer), Lindsey Dias (Graphics Designer), Leo Torff (UI/UX Designer), Kaylynn Bator (Software Engineer).
2.  **Collapsible Accordion Sections:**
    *   **Pension Contribution:** Expandable dropdown header with arrow indicator.
    *   **Devices:** Expanded view featuring a thumbnail image of a MacBook Air (Version M4), device label, and options menu (`⋮`).
    *   **Compensation Summary:** Expandable section.
    *   **Employee Benefits:** Expandable section.

---

## 5. Iconography & Interactive States

*   **Icons:** Use clean, minimalist 1.5px stroke vector icons (Lucide, Feather, or Heroicons standard set).
*   **Interactive States:**
    *   **Hover:** Subtle background tint change (`#F1F3F5`) on list items and interactive buttons.
    *   **Active/Selected:** Primary blue text/backgrounds with smooth CSS transitions (`all 0.2s ease-in-out`).
