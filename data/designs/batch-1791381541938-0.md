# UI/UX Specification & Replication Guide: "Yummy Burgers" Landing Page

This document provides a comprehensive, pixel-accurate blueprint for replicating the provided landing page design. The specification is structured for full-screen implementation, completely omitting presentation mockups (like drop shadows or device frames).

---

## 1. Global Layout & Canvas

*   **View:** Full-Screen / Edge-to-Edge (`100vw` width, `100vh` height).
*   **Base Background Color:** Deep Warm Red (`#C42323` or `#B81D1D` range, with a subtle radial gradient radiating slightly brighter from the center).
*   **Overflow:** Hidden (to prevent scrollbars from interactive elements or floating chips).
*   **Layout Engine:** CSS Grid / Absolute positioning for overlapping typographic and interactive layers.

---

## 2. Typography & Font Specifications

*   **Primary Heading ("Stacked Happiness"):**
    *   **Font Family:** `Poppins`, `Inter`, or `Montserrat` (Clean Sans-Serif, Geometric).
    *   **Weight:** Bold (700) / Semi-Bold (600).
    *   **Color:** Pure White (`#FFFFFF`).
    *   **Text Transform:** Sentence case (as styled in design).
*   **Sub-heading / Brand ("since 1967"):**
    *   **Font Family:** `Playfair Display` or `Great Vibes` (Cursive/Serif italic style).
    *   **Weight:** Italic / Light.
    *   **Color:** Soft off-white / light red tint (`#F5C2C2`).
*   **Background Giant Typography ("YUM BURGER"):**
    *   **Font Family:** Heavy Sans-Serif (e.g., `Impact`, `Bebas Neue`, or `Montserrat Black`).
    *   **Style:** Outlined / Stroke-only (Transparent fill with thin white stroke at `opacity: 0.15` to `0.2`).
    *   **Orientation:** Vertical layout spanning the height of the screen behind the central content.
*   **Action Text ("CLICK THE BURGER"):**
    *   **Font Family:** Monospace or tracking-heavy Sans-Serif (`Letter-spacing: 4px`).
    *   **Color:** White with low opacity (`0.7`).
*   **Fallback Font Stack:** 
    ```css
    font-family: 'Poppins', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
    ```

---

## 3. UI Components & Layout Breakdown

### A. Header Section
*   **Top-Left Brand Logo:**
    *   Text: "yummy" (small, white) stacked above "burgers" (orange-yellow `#FFAA00`, script/rounded font).
*   **Top-Right Navigation:**
    *   Hamburger Menu Icon: Simple 3-line stack inside a circular yellow background button (`#FFD700`).

### B. Left Sidebar (Pagination / Carousel Indicators)
*   **Position:** Fixed vertically centered on the left edge.
*   **Content:** A vertical stack of dots representing slides/pages.
    *   Active Dot: Solid yellow (`#FFD700`), slightly larger or elongated.
    *   Inactive Dots: Semi-transparent white dots.

### C. Right Sidebar (Social Links)
*   **Position:** Fixed vertically along the right edge, rotated 90 degrees upwards or stacked vertically.
*   **Content:** Text links for `facebook`, `instagram`, `youtube` in lowercase, small, muted white text.

### D. Central Hero Section
1.  **Main Headline:** Centered horizontally near the top ("Stacked Happiness" with "since 1967" positioned just above it).
2.  **Central Interactive Element (The Burger):
    *   **Asset:** High-resolution cutout of a gourmet cheeseburger (brioche bun, lettuce, tomato, cheese, patty, onions).
    *   **Interaction:** Clickable/Tappable element (functions as a counter incrementer).
3.  **Floating Elements (Potato Chips):**
    *   Scattered dynamically around the burger.
    *   Varying sizes, rotations, and blur depths (simulating a depth-of-field effect with CSS `blur()`).
4.  **Bottom Interactive Counter:**
    *   A large number (`0`) positioned directly beneath the burger, centered, serving as an interactive click counter.

---

## 4. Animation & Interaction Specifications

### A. Idle / Floating Animations (CSS Keyframes)
*   **Floating Chips:**
    *   Apply a gentle floating loop using CSS `transform: translateY()`.
    *   *Duration:* 3s – 5s infinite ease-in-out alternate.
    *   *Rotation:* Subtle random rotation offsets (`rotate(15deg)`).
*   **Depth-of-Field Blur:**
    *   Chips closer to the foreground or background should have a slight CSS blur (`filter: blur(2px)`) to enhance spatial depth.

### B. Interactive States (JavaScript / CSS)
*   **Burger Click Action:**
    *   **Scale Effect:** On `mousedown` or `click`, the burger scales down slightly (`scale(0.95)`) with a spring transition, then bounces back to `scale(1)`.
    *   **Counter Increment:** Every click increments the bottom counter number (`0` -> `1` -> `2`...).
    *   **Chip Burst (Optional Polish):** Clicking the burger could trigger a micro-animation where extra chip crumbs scatter outward.
