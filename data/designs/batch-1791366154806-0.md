# App Design Specification: "Daylog" E-Commerce Mobile App

This document provides the exact design specifications for a high-end, minimalist fashion e-commerce application inspired by the provided 3D UI concept. It is optimized for full-screen implementation on modern mobile devices (iOS/Android).

---

## 1. Global Styles & Design Tokens

### **Color Palette**
*   **Background (App Canvas):** `#141414` (Deep Charcoal / Near Black)
*   **Surface / Glass Panels:** `#1F1F1F` with 70% opacity and Backdrop Blur (`blur(20px)`)
*   **Primary Text:** `#F5F5F7` (Off-White)
*   **Secondary Text / Muted:** `#A1A1A6` (Cool Gray)
*   **Accent / CTA Color:** `#E0C09E` (Warm Sand / Beige)
*   **Price / Highlight Text:** `#FFFFFF` (Pure White)
*   **Borders / Dividers:** `#2C2C2E` (Subtle Dark Gray, `1px` stroke)

### **Typography (San Francisco / Inter Style)**
*   **App Logo / Brand:** `20px`, Medium, Tracking: `0.5px`, Color: `#F5F5F7`
*   **Section Headers:** `18px`, Semi-Bold, Color: `#F5F5F7`
*   **Body Text / Descriptions:** `12px`, Regular, Line-height: `1.4`, Color: `#A1A1A6`
*   **Prices / CTAs:** `14px`, Bold, Color: `#FFFFFF` / `#141414`

---

## 2. Layout Structure

### **Screen Architecture**
*   **Layout Mode:** Full-screen responsive layout (Edge-to-Edge).
*   **Z-Index Hierarchy:**
    *   `Layer 0`: App Background (`#141414`)
    *   `Layer 1`: Left Navigation Drawer (Glassmorphism sidebar)
    *   `Layer 2`: Main Feed / Product Display Area
    *   `Layer 3`: Floating 3D Product Card & Sticky Bottom Action Bar

---

## 3. Component Specifications

### **A. Left Navigation Sidebar (Glassmorphic Drawer)**
*   **Dimensions:** Fixed width (`~110px`), Full height.
*   **Style:** Translucent dark panel with frosted glass blur effect.
*   **Header:**
    *   Hamburger Menu Icon (3 horizontal lines)
    *   App Title: **"Daylog"** (Vertical or stacked styling)
    *   Category Switcher: **"Women"** with an active underline indicator.
*   **Navigation Links (Icon + Label vertical stack):**
    1.  `New In` (Icon: Sparkles/Tag)
    2.  `Dresses` (Icon: Dress silhouette)
    3.  `Tops` (Icon: T-shirt silhouette)
    4.  `Outerwear` (Icon: Coat silhouette) — *Active State: Highlighted background pill (`#2C2C2E`)*
    5.  `Pants` (Icon: Trousers silhouette)
    6.  `Shoes` (Icon: Sneaker silhouette)
    7.  `Bags` (Icon: Handbag silhouette)
    8.  `Accessories` (Icon: Glasses/Ring silhouette)
*   **Promo Banner (Bottom of Sidebar):**
    *   Card background with a model preview image.
    *   Text: **"Spring Collection 2024"**
    *   Action Link: **"SHOP NOW >"**

---

### **B. Main Content Area**

#### **1. Top Search Bar**
*   **Shape:** Pill-shaped input field (`border-radius: 99px`), dark surface (`#222222`).
*   **Placeholder Text:** `"Search for products..."`
*   **Trailing Icon:** Magnifying glass search icon (`#A1A1A6`).

#### **2. Floating 3D Hero Product Showcase**
*   **Container:** Floating glass card displaying a layered product assembly.
*   **Featured Items:**
    *   **Beige Trench Coat:** Centered main visual with depth shadow.
    *   **Matching Baseball Cap:** Positioned above the coat.
    *   **Casual Sneakers:** Positioned overlapping the lower left of the coat.
*   **Interactive Details Panel (Right side of card):**
    *   Title: **"Beige Trench Coat"**
    *   Description: Short micro-copy regarding fabric and cut.
    *   Price: **"$129.99"**
    *   Color Swatches: Interactive circular pills (Black, Taupe, Beige).
    *   Action Icons: Bookmark/Save (Heart) and Share icons.

#### **3. Horizontal Carousel: "You May Also Like"**
*   **Section Title:** `"You May Also Like"` (14px, Semi-bold).
*   **Card Specifications:**
    *   Width: `~100px` per card.
    *   Background: Dark neutral (`#1E1E1E`), rounded corners (`12px`).
    *   Content per card:
        *   Product Image (Apparel/Accessory thumbnail).
        *   Product Name (e.g., *Wool Blend Coat*, *Over-sized Blazer*).
        *   Price (e.g., `$129.99`, `$99.99`).
        *   Favorite Icon (Heart outline).

---

### **C. Utility Badges & Bottom Action Bar**

#### **1. Secondary Floating Bar (Above Footer)**
*   **Features:**
    *   Shipping Info Badge (`🚚 Free Shipping over $150`)
    *   Easy Returns Badge (`🔄 Easy Returns`)
    *   Secure Payment Badge (`🔒 Secure Checkout`)

#### **2. Sticky Bottom Checkout Bar**
*   **Layout:** Full-width container fixed to the bottom screen edge.
*   **Buttons:**
    1.  **"ADD TO BAG" Button:**
        *   Background: `#E0C09E` (Warm Sand)
        *   Text Color: `#141414` (Dark, Bold)
        *   Icon: Shopping Bag icon preceding text.
        *   Border Radius: `8px`
    2.  **"BUY NOW" Button:**
        *   Background: `#2C2C2E` (Dark Neutral)
        *   Text Color: `#FFFFFF` (White, Bold)
        *   Border Radius: `8px`

---

## 4. Interaction & Animation Notes
*   **Scroll Behavior:** Smooth inertia scrolling for the main product feed and horizontal carousels.
*   **Micro-interactions:** 
    *   Heart icons trigger a smooth scale animation and fill with solid color on tap.
    *   Sticky bottom bar remains anchored during scroll actions.
    *   Glassmorphism panels utilize hardware-accelerated backdrop filters for high fidelity.
