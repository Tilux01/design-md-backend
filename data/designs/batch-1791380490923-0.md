# Design Specification: Ship Faster Landing Page (`design.md`)

## 1. Overview & Layout Strategy
* **Goal:** Replicate the minimalist, high-converting SaaS landing page seen in the media.
* **Layout Structure:** 
  * **Full-Screen Canvas:** The application must take up `100vw` and `100vh` (or scrollable `min-h-screen`) without any extraneous device mockups, frames, or browser chrome backgrounds.
  * **Container Max-Width:** Content sections are centered with a max-width of roughly `1200px` to `1280px` and generous horizontal padding (`px-6` or `px-8`).
  * **Color Palette:** Clean, modern, high-contrast light mode.
    * Background: Pure white (`#ffffff`) or very light warm gray (`#fafafa`).
    * Primary Text: Near-black / Dark Slate (`#0f172a` or `#111827`).
    * Secondary Text: Muted Gray (`#64748b` or `#6b7280`).
    * Accent Colors: Gradient text spanning from vibrant pink/magenta (`#db2777` / `#ec4899`) to deep indigo/blue (`#4f46e5` / `#2563eb`).

---

## 2. Typography & Fallback Strategy

The design heavily relies on modern, clean geometric sans-serif typefaces typically found in contemporary SaaS products (like Inter, Geist Sans, or SF Pro).

### Font Family Stack
* **Primary Font:** `Inter`, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Oxygen, Ubuntu, Cantarell, "Open Sans", "Helvetica Neue", sans-serif
* **Secondary/Heading Font:** (Can share the same family or use a tighter geometric font like `Geist`, `Plus Jakarta Sans`, or `Outfit`).

### Typography Hierarchy
1. **Top Navigation Logo & Links:**
   * Size: `14px` / `0.875rem`
   * Weight: Medium (`500`)
   * Color: Muted dark gray (`#4b5563`)
2. **Social Proof / Client Logos Bar:**
   * Text/Logos: Monochromatic muted gray to avoid distracting from the main CTA.
3. **Hero Main Headline ("Ship faster"):**
   * Size: `clamp(3rem, 6vw, 5.5rem)` (Responsive fluid typography)
   * Weight: Bold (`700` or `800`)
   * Letter-spacing: Tight (`-0.03em`)
   * Color Effect: 
     * "Ship" -> Solid dark gray/black (`#111827`).
     * "faster" -> Dynamic gradient text (Pink to Blue/Indigo).
4. **Sub-headline / Feature Card Title ("Description to Sitemap ✨"):**
   * Size: `24px` to `30px` (`1.5rem` to `1.875rem`)
   * Weight: Semi-bold (`600`)
   * Color: Dark Neutral (`#1f2937`)

## 3. Section-by-Section Breakdown

### A. Navigation Bar (`<nav>`)
* **Position:** Sticky or fixed at the top with a subtle backdrop blur (`backdrop-blur-md bg-white/80`).
* **Content Left:** Brand logo/icon.
* **Content Center:** Minimalist navigation links (optional, or left clean as seen in minimalist setups).
* **Content Right:** Primary Call-to-Action (CTA) button, e.g., *"Start for free"* (Dark pill button with white text, or subtle border).

### B. Hero Section (`<header>` / `<section>`)
* **Top Subheader / Badge:** A subtle pill tag containing brand mentions or social proof text (e.g., *#TEXAS*, *Product Hunt*, etc., styled in pill badges with light gray borders).
* **Main Hero Title:**
  * Markup: `<h1><span>Ship</span> <span class="gradient-text">faster</span></h1>`
* **Feature Card Component ("Description to Sitemap"):**
  * Placed directly below or integrated into the hero.
  * **Card Styling:** Clean white surface card with a very soft, multi-layered shadow (`box-shadow: 0 10px 30px -10px rgba(0,0,0,0.05)`), subtle 1px border (`#e5e7eb`), and rounded corners (`border-radius: 16px` or `24px`).
  * **Inner Elements:** A minimal input/preview UI mockup showing how text turns into a structured sitemap visualization.

## 4. Animations & Interactions

To capture the polished, interactive feel seen in modern high-end web designs, implement the following micro-interactions:

1. **Hero Text Gradient Animation (Optional/Subtle):**
   * Smooth shifting gradient on the word "faster".
   * *CSS Implementation:*
     ```css
     .gradient-text {
       background: linear-gradient(135deg, #ec4899 0%, #8b5cf6 50%, #3b82f6 100%);
       -webkit-background-clip: text;
       -webkit-text-fill-color: transparent;
     }
     ```
2. **Card Hover Effects:**
   * Feature cards lift slightly on hover (`transform: translateY(-4px)`) with a transition duration of `300ms cubic-bezier(0.16, 1, 0.3, 1)`.
3. **Button Hover States:**
   * Scale-up micro-interaction (`scale(1.02)`) and brightness shift on primary buttons.
4. **Page Load Entry Animation:**
   * Fade-in and slide-up (`opacity: 0; transform: translateY(20px)` -> `opacity: 1; transform: translateY(0)`), staggered across the nav, headline, and cards using CSS transitions or Framer Motion.
