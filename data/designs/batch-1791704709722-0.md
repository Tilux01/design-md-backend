# DBS02 Intelligent Robot - UI/UX Design Specification & Clone Guide

This document provides a comprehensive design specification to create an exact, pixel-perfect clone of the DBS02 intelligent robot presentation page. The layout spans a full-screen viewport using a light gray/off-white background system, featuring high-tech product renders, asymmetric grid layouts, and minimalist typography.

---

## 1. Global Styles & Design Tokens

### Color Palette
*   **Page Background:** `#EAEAEA` to `#F0F0F0` (Subtle off-white/light gray gradient or solid neutral).
*   **Pure White Containers/Cards:** `#FFFFFF` (Used for floating information cards).
*   **Text Primary (Dark):** `#111111` (Used for primary headers like "DBS02", "Intelligent robot").
*   **Text Secondary (Muted):** `#7A7A7A` or `#8A8A8A` (Used for descriptions, subheadings, and specs).
*   **Accent/UI Lines (Glows):** Pure `#FFFFFF` emission (Simulated via drop-shadow or backdrop glow for the robot's visor light and logos).

### Typography Stack
*   **Primary Font Family:** `Inter`, `SF Pro Display`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, sans-serif.
*   **Fallback Stack:** Standard sans-serif system fonts if web fonts fail to load.
*   **Headings (Hero Section):** 
    *   `DBS02`: `font-weight: 700`, uppercase, letter-spacing: `0.05em`.
    *   `Intelligent robot`: `font-weight: 400`, subtle lowercase/sentence case.
*   **Body & Specs:** 
    *   `font-weight: 400`, optimized with anti-aliasing (`-webkit-font-smoothing: antialiased`).

---

## 2. Layout Structure & Grid System

The design is structured as a vertical scrolling experience consisting of two primary full-width modular sections, utilizing CSS Grid and Flexbox for precise alignment.

*   **Global Max-Width Container:** `1440px` centered horizontally with generous padding (`40px` to `80px` horizontal margins).
*   **Vertical Gap Between Sections:** `40px` to `60px`.

---

## 3. Section-by-Section Breakdown

---

### Section 1: Hero Header (The Robot Head Showcase)

#### Dimensions & Positioning
*   **Container:** Full viewport-inspired hero card with rounded corners (`border-radius: 24px`), background color `#EBEBEB` or light neutral gradient.
*   **Layout:** Relative positioning container acting as a stage for the central head render and floating UI cards.

#### Content Elements

1.  **Central Robot Head Render:**
    *   **Image Description:** Studio-lit, glossy black humanoid robot head facing forward. Features a distinctive horizontal glowing white visor slit across the face, subtle white corporate branding/icon on the forehead, and metallic neck structure transitioning into a bright white background.
    *   **Background State:** Backgroundless / Isolated product crop integrated seamlessly into the card background.
    *   **Positioning:** Centered horizontally (`left: 50%`, `transform: translateX(-50%)`), vertically aligned to occupy the central focal point of the hero box.
    *   **Rotation:** 0 degrees (Symmetrical front-facing portrait).

2.  **Top-Right Typography (Hero Title):**
    *   **Content:** 
        *   `DBS02` (Large, heavy bold display text, color: `#FFFFFF` with slight drop shadow or crisp white `#FFFFFF` depending on backdrop contrast).
        *   `Innovative Guard` (Small uppercase sub-label).
        *   `Intelligent robot` (Medium-weight descriptive title below the main heading).
    *   **Positioning:** Absolute positioned on the right side of the hero container, aligned vertically with the upper-middle section of the robot head.

3.  **Bottom-Left Floating Info Card:**
    *   **Container Style:** Solid white background (`#FFFFFF`), rounded corners (`border-radius: 16px`), subtle shadow, padding (`24px`).
    *   **Content:**
        *   Header: **"Ultimate software and hardware reliability"** (`font-weight: 600`, color: `#111`).
        *   Subtext: `"Total: 16 core CPU+GPU (384Core, 1.5TFLOPS)"` (`font-size: 12px`, color: `#777`).
        *   Action link: `"Explore more >"` (`color: #111`, font-weight: 500).
    *   **Positioning:** Absolute positioned at the bottom-left corner of the hero section.

### Section 2: Product Architecture & Feature Grid

#### Dimensions & Positioning
*   **Container:** White card container (`#FFFFFF` or matching page background system with interior modular cards), rounded corners (`border-radius: 24px`), padding (`40px`).
*   **Layout:** CSS Grid layout featuring an asymmetric 2-column or multi-column layout split between a large feature showcase on the left and a 2x3 grid of sub-features on the right.

#### Left Column: Main Product View & Header

    *   `DBS02` (Bold, size medium).
    *   `Patent body Structure and layout design` (Muted gray subtitle).

    *   **Positioning:** Bottom-left of the section grid, perfectly scaled to balance the right-hand feature cards.
    *   **Rotation:** 0 degrees (Front-facing symmetrical chest shot).

#### Right Column: Feature Grid (5 Modular Cards)

    *   **Image State:** Dark theme container (`#0A0A0A` background with white-trimmed robot shoulders).

4.  **Card 4 (Middle Right of Sub-Grid): Endurance Specs**
