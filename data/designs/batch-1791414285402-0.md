# UI/UX Specification: "Today" Habit & Wellness Dashboard

A comprehensive design specification for recreating the mobile app interface shown in the source image. This document provides exact layout, typography, color palettes, spacing rules, and animation behaviors for a pixel-perfect, cross-platform implementation.

---

## 1. Global Layout & Canvas Strategy

*   **Target Viewport:** Full-screen mobile layout (fluid width, safe-area-aware vertical scrolling).
*   **Base Container:** `min-height: 100vh; width: 100%;`
*   **Background:** 
    *   Solid base: `#F3F4FB` (Very pale lavender-gray)
    *   Ambient gradient/mesh background overlay centered behind the primary mascot illustration: Radial gradient transitioning from `rgba(180, 160, 240, 0.25)` to transparent.
*   **Corner Radius (Device Frame if applicable):** Outer wrapper uses `border-radius: 40px` (for preview frames) with internal padding:
    *   Top padding: `env(safe-area-inset-top, 24px) + 16px`
    *   Horizontal padding: `20px`
    *   Bottom padding: `24px`

## 5. Animation & Interaction Specifications

To achieve the fluid, polished feel of the original app, apply the following micro-interactions:

1.  **Card Entrance Animation:**
    *   *Trigger:* On page load.
    *   *Behavior:* Fade in with a slight upward translateY (`15px` to `0`), staggered by `0.08s` per card/element.
    *   *Timing Function:* `cubic-bezier(0.16, 1, 0.3, 1)` (Smooth ease-out).

2.  **Date Pill Selection:**
    *   *Trigger:* Tap/Click on any date in the weekly calendar strip.
    *   *Behavior:* Scale down slightly (`scale(0.95)`) on press, spring back to `scale(1)` with background color transition (`#F3F4FB` $\rightarrow$ `#6851FF`).
    *   *Duration:* `250ms`.

3.  **Mascot / Hero Breathing Effect:**
    *   *Trigger:* Continuous subtle loop.
    *   *Behavior:* Gentle vertical translation (`translateY(-4px)` to `translateY(0)`) paired with a slight scale pulsation on the background aura.
    *   *Duration:* `3000ms` infinite ease-in-out.
