# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Clean Enterprise SaaS & AgTech Dashboard Interface (Minimalist Editorial, Light Surface with High-Contrast Typography).
- **Visual Density & Whitespace Ratio**: High whitespace-to-data ratio. Card containers feature generous internal padding (`24px`), clean separation between metric summaries, and structured analytical charts.
- **Surface Elevation Model**: Layered flat-surface hierarchy. Base canvas uses subtle radial gradient background tones (`#F8F9FA` to `#E9ECEF`), topped by crisp white surface cards (`#FFFFFF`) with 1px fine borders (`#E5E7EB`) and soft ambient drop shadows (`0 4px 20px rgba(0, 0, 0, 0.04)`).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase pill badges, green trend indicator capsules (`+4.1%`), minimalist iconography, backdrop-blur floating user profiles.
- **Pill Badge Specification**: Padding `4px 10px`, font-size `12px`, font-weight `500`, tracking `0.05em`, border-radius `9999px`, background `#D1FAE5`, text color `#047857`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;` or `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
