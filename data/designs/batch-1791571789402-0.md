# UI Design & Implementation Specification

## 1. Global Layout & Structure
- **Canvas / Viewport**: Designed as a modern, full-screen SaaS desktop interface (optimized for 1440px+ ultra-wide displays).
- **Background Palette**: Light, airy, desaturated cool gray-blue background (`#eef0f6`), providing contrast for floating, rounded white cards (`#ffffff`) with subtle drop shadows and inner glows.
- **Border Radius Philosophy**: Extreme use of pill-shaped buttons (`9999px`) and heavily rounded container cards (`16px` to `24px`).
- **Layout Architecture**: 
  - **Left Sidebar**: Fixed-width navigation/work queue panel housing user avatars, tabs, and filters.
  - **Top Navigation Bar**: Global search, action icons, and active user profile ("Dylan Grace").
  - **Main Content Area**: Split into a dynamic multi-column dashboard grid featuring status progress bars, profile headers, lead info blocks, activity/campaign timelines, and AI-driven analytics scoring modules.

---

## 2. Typography & Fonts
- **Primary Font Family**: Inter, SF Pro Display, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif.
- **Fallback Stack**: Sans-serif.
- **Font Scale & Weights**:
  - **App Title / Brand ("Sales Enagagement")**: Bold (`700`), ~22px, dark charcoal (`#111827`).
  - **Section Headings ("Lead Information", "Campaign History", "AI Scoring")**: Semi-bold (`600`), ~14px–16px, dark neutral (`#1f2937`).
  - **Body / Metadata Text**: Regular (`400`), ~12px–13px, medium gray (`#4b5563`).
  - **Badges, Statuses, and Values**: Medium (`500`), ~11px–12px.
