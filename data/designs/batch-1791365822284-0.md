# 404 Error Page Design Specification

## Global Styles

*   **Background Color:** Deep Black (`#000000` or `#0a0a0a`)
*   **Primary Text Color:** White (`#FFFFFF`)
*   **Secondary Text/Accent Color:** Muted Gray / Red (for rose petals)
*   **Font Family:** Serif / Sans-Serif mix (Clean, modern aesthetic for UI elements, dramatic serif/display feel for headings)

---

## 1. Header Navigation

*   **Layout:** Fixed or absolute full-width header overlaying the hero section.
*   **Left Section:**
    *   **Hamburger Menu Icon:** Three horizontal lines (`#FFFFFF`).
*   **Center Section:**
    *   **Logo:** Text logo **"B&Y"** in a bold, elegant serif font.
    *   **Sub-logo text:** "YOUR • GOAL • TRAINER" in small, uppercase tracked letters directly beneath the main logo.
*   **Right Section:**
    *   **Icons (Left to Right):**
        1.  Search Icon (Magnifying glass)
        2.  User Account Icon
        3.  Shopping Bag / Cart Icon

---

## 2. Hero / Main Content Section

*   **Layout:** Full-width container divided visually into two zones:
    *   **Left Side:** Dark, moody photographic portrait.
    *   **Right Side:** Deep black background with floating elements.

### Visual Elements (Left Side)
*   **Subject:** A high-contrast, black-and-white cinematic portrait of a woman in gothic/royal attire.
    *   **Attire/Props:** Wearing an ornate crown, draped in sheer black veil/fabric, holding a dark flower (peony/rose).
    *   **Lighting:** Dramatic low-key lighting highlighting facial contours and textures in grayscale.

### Visual Elements (Center / Foreground)
*   **Error Code (`404`):**
    *   **Typography:** Large, bold, clean white sans-serif numbers.
    *   **Styling:** Layered partially over the portrait and the black background.
*   **Vertical Text:**
    *   **Content:** "PAGE NOT FOUND"
    *   **Orientation:** Vertical, reading bottom-to-top, positioned right beside the "404" graphic.
*   **Call to Action (CTA) Button:**
    *   **Text:** "BACK HOME" (Uppercase, tracked out)
    *   **Style:** Transparent background with a crisp white rectangular border.
*   **Floating Elements:**
    *   **Red Rose Petals:** Numerous scattered, realistic red rose petals floating across the upper-right and center portions of the screen, creating depth and a dynamic falling effect over the dark background.

---

## 3. Footer / Edge Navigation Elements

### Left Edge / Bottom-Left
*   **Navigation Lines:**
    *   A horizontal dash followed by the word **"BACK"**.
*   **Utility Icons:**
    *   Home icon (`🏠`)
    *   Adjustment / Filter sliders icon

### Center Bottom
*   **Pagination / Carousel Indicators:**
    *   Three small dots (one highlighted white, two gray/inactive: `o O o`).

### Right Edge / Bottom-Right
*   **Navigation Lines:**
    *   The word **"HOME"** followed by a horizontal dash.
*   **Social Media Icons:**
    *   Twitter / X icon
    *   Facebook icon
    *   Instagram icon
