# Design Specification: Crypto Wallet Dashboard

This document provides the complete design specifications to build an exact, full-screen clone of the cryptocurrency wallet dashboard interface shown in the reference image. 

---

## 1. Global Styles & Typography

### Fonts
*   **Primary Font Family:** Inter, Roboto, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif.
*   **Fallback Stack:** `sans-serif`
*   **Font Weights:** 
    *   Regular (400) for body copy, timestamps, table data, and labels.
    *   Medium (500) for navigation items, secondary headers, and interactive buttons.
    *   Bold (600 / 700) for major numerical values, balances, and main headers.

### Color Palette
*   **Background (Canvas):** `#f8f9fa` (Very light cool gray)
*   **Sidebar Background:** `#ffffff` (Pure white)
*   **Card Backgrounds:** `#ffffff` (Pure white, with slight tinted backgrounds for asset cards)
*   **Dark Overlay / Card Background:** `#12141c` (Deep dark slate, used for the "Sell Order" and "History Available" widgets)
*   **Primary Text (Dark):** `#1a1a1a`
*   **Secondary Text (Muted):** `#8c93a0`
*   **Borders / Dividers:** `#edf0f4`
*   **Green Accent (Success / Positive Growth):** 
    *   Light tint card background: `#e8f7ee`
    *   Line / Icon color: `#27ae60` (or similar vivid mint green)
*   **Blue Accent (Neutral / Ethereum):**
    *   Light tint card background: `#edf2fc`
    *   Line / Icon color: `#3b82f6`
*   **Orange / Peach Accent (Binance / Third Asset):**
    *   Light tint card background: `#fdf2ed`
    *   Line / Icon color: `#e67e22`

---

## 2. Layout Structure

The layout is divided into two primary sections in a full-screen viewport:
1.  **Left Sidebar (Navigation):** Fixed width (~240px), pure white background, vertical stacking of logo, navigation links, and a bottom promotional card.
2.  **Main Content Area:** Flexible width (`flex: 1`), padding-heavy container holding the top navigation bar, metric cards, market overview graph, recent activity table, and floating widgets.

### D. Market Overview (Center Section)
*   **Header Area:**
    *   Title: **"Market Overview"** (Bold).
    *   Subtitle: "Prices value updates" (Small, muted).
    *   Filter Dropdown (Top Right): **"Weekly (2020)"** with a downward chevron arrow.
*   **Chart Area:**
    *   Type: Line graph with data points plotted across days of the week (Mon through Sun).
    *   Y-Axis Labels: `800K`, `600K`, `500K`, `200K` with faint horizontal grid lines.
    *   X-Axis Labels: Mon, Tue, Wed, Thu, Fri, Sat, Sun.
    *   Curve: Smooth bezier curve connecting data points (peaks at Tue, Wed, and Sat).
    *   Interactive Tooltip: Floating dark pill over Saturday reading **$2954** ("Nov 29 2020"), pinned with a numbered indicator (**15**).

### E. Recent Activities Table (Bottom Left)
*   **Header:** **"Recent Activities"** (Bold).
*   **Table Rows:** Each row includes:
    1.  **Icon:** Circular badge with an angled directional arrow (e.g., top-left or bottom-left pointing arrow) matching the asset color theme.
    2.  **Asset Name:** Bitcoin, Ethereum, Binance (Medium weight).
    3.  **Timestamp:** e.g., `10:42:23 AM`, `12:00:23 AM` (Muted gray text).
    4.  **Amount:** e.g., `+1545,00`, `+1745,00`, `+255,00` (Bold).
    5.  **Status Badge:** **"Completed"** written in dark text.

### F. Floating Dark Widgets (Right Side)

#### 1. "Sell Order" Table Widget
*   **Container Style:** Floating dark card (`#12141c`), rounded corners (~16px), white text.
*   **Header:** **"Sell Order"** with a three-dot menu icon on the right.
*   **Column Headers:** `Price`, `Amount`, `Total` (Muted gray, small text).
*   **Data Rows:** Tabular list of trading orders.
    *   *Example Row 1:* Price `89.03` | Amount `0.15` | Total `$126,00`
    *   *Example Row 3 (Highlighted):* Price `92.06` | Amount `0.22` | Total `$252,00` (Row background highlighted with a lighter dark shade, e.g., `#212530`).
    *   *(Additional rows continue downwards with decreasing precision up to `97.34`).*

## 4. Image Handling Guidelines
*   *Icons & Badges:* Render cryptocurrency icons (Bitcoin `₿`, Ethereum diamond, etc.) using clean vector graphics or standard SVG font glyphs inside styled circular containers.
*   *Sparklines / Trend Graphs:* Render small background trend lines using simple SVG `<path>` elements with smooth Bézier curves (`d="M... C..."`), styled with respective stroke colors (`#27ae60`, `#3b82f6`, `#e67e22`).
*   *Market Overview Graph:* Implement using an SVG graph component or a charting library (like Chart.js or Recharts) configured with a gradient fill under the curve and circular data points (`<circle>`) at each coordinate.
