# UI/UX Design Specification & Clone Blueprint

This document outlines the precise specifications required to build a pixel-perfect, full-screen frontend clone of the "Chicvow" e-commerce landing page. 

---

## 1. Global Layout & Viewport
* **Layout Structure:** Single-page vertical scroll, full-bleed width (`width: 100vw`).
* **Root Background Color:** `#FFFFFF` (White) for the lower content section; `#E71D32` (Vibrant Red) for the top hero section.
* **Max Content Width:** Container restricted to `1280px` centered with auto margins, ensuring spacing on ultra-wide viewports.

---

## 2. Typography & Fonts
* **Primary Font Family:** `Inter`, fallback to `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
* **Brand/Logo Font:** Serif/Geometric display font like `Playfair Display` or `Montserrat` (Bold weight).
* **Text Hierarchy:**
  * **Hero Header Title:** `font-size: 56px`, `font-weight: 800`, `line-height: 1.1`, Color: `#FFFFFF`.
  * **Hero Subtitle:** `font-size: 16px`, `font-weight: 400`, Color: `rgba(255, 255, 255, 0.9)`.
  * **Nav Links:** `font-size: 14px`, `font-weight: 500`, Color: `#FFFFFF`.
  * **Section/Card Headings:** `font-size: 15px`, `font-weight: 600`, Color: `#1A1A1A`.
  * **Prices:** `font-size: 14px`, `font-weight: 700`, Color: `#1A1A1A`.

---

## 3. Section-by-Section Breakdown

### A. Navigation Bar (Sticky Top)
* **Background:** Transparent over the red hero section.
* **Height:** `80px`.
* **Left Element:** Logo text **"Chicvow."** (`font-size: 24px`, italicized/bold serif style, color `#FFFFFF`).
* **Center Navigation Links:** 
  * Home (active indicator: small white underline bar)
  * Shop | Deals | About Us | Blog | Contact
  * *Color:* `#FFFFFF`
* **Right Elements:** 
  * Search Icon (Magnifying glass)
  * Shopping Cart Icon with notification badge (`2`, red pill with white text)
  * *Color:* `#FFFFFF`

### B. Hero Section
* **Background:** Solid Red (`#E71D32`) with a large offset soft pink accent circle (`#ED5161` or opacity-layered SVG) on the right side.
* **Left Column Content:**
  * **Heading:** "Stylish Female Clothes"
  * **Paragraph:** "Made from Soft, Durable, US-grown Supima Cotton."
  * **Call-to-Action Buttons:**
    1. Primary Button: **Shop Now** (Solid White background `#FFFFFF`, text color `#E71D32`, border-radius: `30px`, padding: `12px 28px`, includes a shopping bag icon).
    2. Secondary Dropdown: **All Categories** (Translucent white/red border, dropdown chevron icon, border-radius: `30px`).
* **Social Proof Element (Overlapping bottom right of hero image):**
  * Rounded pill container with white background and subtle drop shadow.
  * 3 overlapping circular avatar images.
  * Text: **"Our Happy Customer"** + Star Rating (`★★★★★` in gold/yellow `#FFC107`) + Text: `4.5 (453k Reviews)`.
* **Right Column Content:**
  * High-res cutout image of a smiling model wearing a bright red textured cardigan, red sunglasses, and curly dark hair, positioned neatly inside the pink background disc.

---

### C. Category Banners Carousel / Grid
* **Layout:** 4 distinct horizontal rounded cards side-by-side (`display: flex; gap: 20px;`).
* **Card Styling:** 
  * Soft pastel pink/peach gradient backgrounds (`#FCE4EC` to `#F8BBD0`).
  * Border-radius: `16px`.
  * Padding: `24px`.
  * Hover Animation: Subtle `translateY(-4px)` with box-shadow elevation.
* **Cards Content:**
  1. **Women Gallery** → Circular model image + Text + White arrow pill icon (`→`).
  2. **Children Fashion** → Circular model image + Text + White arrow pill icon.
  3. **Men's Fashion** → Circular model image + Text + White arrow pill icon.
  4. **Women's Fashion** → Circular model image + Text + White arrow pill icon.

---

### D. Sub-Category Filter Navigation (Icon Bar)
* Horizontal list of filter pills centered below category banners.
* Items: 
  * **All** (Highlighted with soft pink background pill `#FCE4EC` and red text/icon)
  * Dresses, T-shirts, Denim, Jackets, Coats, Shoes.
* Each item features a clean minimalist line-art vector icon above the category label.

---

### E. Product Grid Section
* **Layout:** 4-column responsive grid (`grid-template-columns: repeat(4, 1fr); gap: 24px;`).
* **Product Card Structure:**
  * **Image Container:** Light grey/pinkish background (`#F5F5F5`), rounded top corners (`16px`), containing model photography.
  * **Badges (Absolute positioned on card):** Red/Green "Hot" and "New" pills on specific items.
  * **Wishlist Icon:** Outline heart icon (`♡`) positioned at the bottom right of the image container.
  * **Product Details (Below image):**
    * Title (e.g., *Casual Checkered Flannel*, *Short Party Dress*).
    * Price in bold (e.g., `$49.00`, `$790.00`).
* **Interactive Hover State (Active Featured Card):**
  * The second card (**Short Party Dress**) is highlighted with a distinct red outline border (`2px solid #E71D32`).
  * Features an interactive red **"Add to Cart"** button slide-over/overlay with a shopping bag icon directly on the bottom edge of the image.

---

## 4. Animations & Micro-Interactions (CSS / JS)

* **Button Hovers:** Scale transform `scale(1.02)` with transition duration `0.2s ease-in-out`.
* **Product Cards:** `transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);` lifting up slightly on mouse enter.
* **Wishlist Icon:** On click, animate heart fill from transparent outline to solid red (`#E71D32`) with a quick bounce scale effect (`scale(1.2)`).
* **Hero Image:** Subtle floating CSS keyframe animation (`translateY`) to give dynamic life to the landing page.
