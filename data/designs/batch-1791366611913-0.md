# Quantix Trading Dashboard - Design System & Specification

## 1. Global Styles & Foundations

### Color Palette
- **Backgrounds:**
  - Main App Background: `#0B0C10` (Dark obsidian)
  - Sidebar Background: `#0F1015` with subtle glassmorphism/gradient overlays
  - Card/Container Background: `#13141C` (Slightly lighter dark surface)

- **Primary / Brand:**
  - Accent White: `#FFFFFF`
  - Muted Gray (Text/Icons): `#8C8F9E`
  - Disabled / Subtle Text: `#5A5E70`
