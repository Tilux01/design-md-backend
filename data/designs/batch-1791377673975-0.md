# Comprehensive Design Specification: Ceramic Product Catalog

## 1. Overview & Creative Direction
This document specifies the exact layout, typography, color palette, imagery, and structural hierarchy for the **Ceramic Product Catalog** layout shown in the reference image. The design is a minimalist, modern, editorial-style print/digital catalog heavily focused on neutral aesthetics, high contrast, asymmetry, and generous negative space. 

* **Theme:** Scandinavian/Wabi-Sabi Minimalist.
* **Aspect Ratio / Format:** Multi-page spread layout (A4/US Letter vertical orientation).
* **Core Philosophy:** Form follows function; typography serves as layout structure; heavy emphasis on whitespace and photographic grid harmony.

The design utilizes a sophisticated, natural, earthy, and high-contrast monochrome palette.

| Role | Color Name | Hex Code / Description | Usage |

## 3. Typography & Font Stack
The typography relies heavily on high-fashion editorial styling, contrasting a classic high-contrast serif with a clean, highly legible grotesque sans-serif.

### Primary Display Serif (Headings, Cover Titles, Featured Copy)
* **Target Style:** Didone / Modern high-contrast serif (similar to *Didot*, *Bodoni*, or *Playfair Display*).
* **Font Fallbacks:** `Playfair Display`, `Didot`, `Bodoni MT`, `Times New Roman`, `serif`.
* **Characteristics:** Extreme stroke contrast, delicate hairline serifs, vertical stress.

### Secondary Sans-Serif (Body Copy, Metadata, Navigation, Labels)
* **Target Style:** Modern Geometric/Neo-Grotesque Sans-Serif (similar to *Inter*, *Helvetica Neue*, or *Neue Haas Grotesk*).
* **Font Fallbacks:** `Inter`, `Helvetica Neue`, `Arial`, `sans-serif`.
* **Characteristics:** Neutral, clean, highly legible at small sizes, minimal contrast.

#### Hierarchy Rules:
1. **Cover / Major Titles:** Serif, Italic or Light weight, massive scale (e.g., "Catalog" text on cover).
2. **Section Headers (e.g., "Signature Collections"):** Serif, Regular weight, medium-large scale.
3. **Product Names / Captions:** Sans-serif, Medium weight, small scale.
4. **Body / Descriptive Text:** Sans-serif, Light/Regular weight, tiny scale with generous line-height (`1.6` to `1.8`).

## 7. Interactive / Animation Specifications (If Digital)
If implemented as a digital flipbook or interactive web application, apply the following smooth micro-interactions:
* **Page Turn Transition:** Realistic 3D book-curl easing cubic-bezier (`0.645, 0.045, 0.355, 1`) over `800ms`.
* **Hover States on Product Cards:** Subtle zoom-in on imagery (`transform: scale(1.02); transition: transform 0.4s ease`).
* **Fade-in Reveal:** As pages load into view, staggering elements using `opacity: 0` to `1` with a `150ms` delay offset per grid item.
