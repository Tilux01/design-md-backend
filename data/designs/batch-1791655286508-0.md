# Design Specification: "LIGHT VS DARK" Dashboard UI Clone

This document provides the precise layout, visual hierarchy, typography, colors, spacing, and component breakdown for cloning the dashboard UI shown in the media. The implementation must cover the full screen (viewport width and height) and support both **Light Mode** and **Dark Mode** themes. Device mockups, shadows, frames, and background canvases shown in the original showcase image (like the smartphone shells) are omitted; the UI will stretch to fill the full viewport.

---

## 1. Global Layout & Canvas

*   **Viewport:** Full screen width (`100vw`) and height (`100vh`).
*   **Base Layout Framework:** Single-column mobile application interface, centered horizontally if viewed on larger screens, with a max-width typical of mobile viewports (e.g., `max-width: 430px`, `width: 100%`).
*   **Safe Area:** Padding at the top for status bar (`44px` or standard iOS safe area top) and bottom for the home indicator bar (`34px`).

---

## 2. Color Palette & Theming

### Light Mode Theme
*   **Background:** Off-white / Light gray (`#F2F2F2` or `#EAEAEA`)
*   **Surface / Cards:** Pure White (`#FFFFFF`) with subtle shadow/border definitions.
*   **Primary Text (Headers/Titles):** Deep Charcoal / Near Black (`#111111`)
*   **Secondary Text (Subtitles/Labels):** Medium Gray (`#777777` to `#888888`)
*   **Accent / Interactive elements:** Black (`#000000`) for primary buttons/pills, with white text.
*   **Borders / Dividers:** Light gray (`#E0E0E0`)

### Dark Mode Theme
*   **Background:** Deep Black (`#0A0A0A` to `#121212`)
*   **Surface / Cards:** Dark Charcoal Gray (`#1C1C1E` or `#18181A`)
*   **Primary Text (Headers/Titles):** Pure White (`#FFFFFF`)
*   **Secondary Text (Subtitles/Labels):** Muted Light Gray (`#8E8E93` to `#A0A0A5`)
*   **Accent / Interactive elements:** Pure White (`#FFFFFF`) for primary buttons/pills, with dark text (`#000000`), or inverted depending on state.
*   **Borders / Dividers:** Dark border gray (`#2C2C2E`)

---

## 3. Typography & Fonts

*   **Primary Font Family:** **SF Pro Display** / **Inter** / **Helvetica Neue**
*   **Fallback Font Stack:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`

### Type Hierarchy:
1.  **Greeting Title ("Hello, Visux"):**
    *   *Font Weight:* Bold (`700`)
    *   *Font Size:* `28px`
    *   *Line Height:* `34px`
2.  **Subtitle ("What you want do today?"):**
    *   *Font Weight:* Regular (`400`)
    *   *Font Size:* `14px`
    *   *Color:* Secondary Text
3.  **Card Headings / Values (e.g., "$50,428", "70°"):**
    *   *Font Weight:* Bold (`700` / `600`)
    *   *Font Size:* `20px` to `24px`
4.  **Body / Button Text / Labels:**
    *   *Font Weight:* Medium (`500`) / Regular (`400`)
    *   *Font Size:* `12px` to `14px`

---

## 5. Image & Asset Guidelines

*   **Icons Used:** Use standard outline vector icon sets (such as *Lucide*, *Heroicons*, or *SF Symbols*).
*   **Format:** All icons and graphics must be vector-based (`SVG`) and **backgroundless (transparent)** to seamlessly adapt to both Light and Dark modes.
*   **Rotation / Placement:** 
    *   Icons inherit the standard orientation ($0^\circ$ rotation).
    *   Circular progress indicators and bar charts are structurally rendered via CSS/SVG components rather than static raster images to ensure crisp scaling and theme reactivity.
