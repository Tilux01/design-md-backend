# Design Specification: Health Monitoring Dashboard UI ("Flux")

---

## 1. Design Philosophy & Overall Aesthetic
* **Primary Mood:** Modern, medical-grade yet consumer-friendly, high-performance, and clean. 
* **Brand Archetype:** Precision, wellness-tech, and data-dense productivity.
* **Visual Density:** High data density balanced with generous whitespace, card-based modular isolation, and a distinct dual-tone split (dark command sidebar/widgets vs light content surfaces).
* **Theme Architecture:** Hybrid high-contrast light mode with dark contextual elements (e.g., dark sidebar, dark sleep analysis cards, dark profile header banner).

---

* **Primary Lime/Green:** `#A3E635` (Tailwind `lime-400` / dynamic neon lime accent)

* **Positive Green Badge:** `#84CC16` with text `#1A2E05`

* **Energy Purple Variant:** `#A78BFA`

### Borders & Dividers
* **Light Mode Border:** `#E2E8F0` (Slate-200)

## 4. Layout Architecture & Spatial Grid
* **Container Max-Width:** 1440px fluid centered dashboard wrapper.
* **Layout Structure:** Fixed Sidebar + Flexible Multi-Column Bento Grid Layout.
* **Sidebar Width:** Fixed `280px`.
* **Grid Spacing (Gutter):** `24px` gap across bento card items.
* **Padding Scale:** 
  * App Canvas Outer Padding: `32px`
  * Card Internal Padding: `24px`

### Section Sequence & Stacking Order
1. **Left Navigation Sidebar:** Fixed vertical layout containing Brand, Navigation Links, and Status indicators (`z-index: 20`).
2. **Top Bar Header:** User profile banner, Search input, and Global date filter (`z-index: 10`).
3. **Primary Content Grid (Bento Layout):**
   * Row 1: Energy Used (Donut/Progress split card) | Heart Rate Card | Wellness Index Card
   * Row 2: Activity Card | Sleep Analysis Card (Dark Theme Span)

---

## 5. Component Blueprint & Element Placement

### Cards & Containers
* **Border Radius:** `24px` (`rounded-3xl`) for primary structural panels; `16px` (`rounded-2xl`) for internal metric widgets.
* **Borders:** `1px solid #E2E8F0` on light surfaces; `1px solid #3F3F46` on dark surfaces.
* **Shadows:** Soft diffuse elevation `0px 10px 30px -5px rgba(0, 0, 0, 0.05)`.

### Navigation Elements
* **Active Sidebar Link:** Pill background `#27272A` with `#FAFAFA` text and active Lime pill indicator (`#A3E635`).
* **Badges (Notification/Counters):** Rounded full pill with solid Lime `#A3E635` background and dark text `#09090B`, exact height `20px`.

### Buttons & Controls
* **Primary Interactive Control:** Pill-shaped dropdowns and filters (`border: 1px solid #E2E8F0`, interior text with chevron icon).
* **Icon Buttons:** Circular `40px x 40px`, background `#F1F5F9`, borderless, center-aligned icon with hover color shifts.

---

## 6. Motion Mechanics & Interactions
* **Transitions:** `cubic-bezier(0.16, 1, 0.3, 1)` (Spring physics for snappy panel expansion and hover elevations).
* **Hover States:** 
  * Cards scale upward slightly (`transform: translateY(-2px)`) with heightened shadow opacity.
  * Interactive rows trigger background color transitions (`background-color 200ms ease`).
* **Data Visualization Animations:** SVG stroke-dashoffset interpolation on load for Donut progress meters and bar chart height expansions.
