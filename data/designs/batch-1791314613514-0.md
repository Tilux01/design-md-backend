# Real Estate Platform UI/UX Specification

---

## 1. Design Philosophy & Overall Aesthetic
- **Brand Archetype:** High-end PropTech, Futuristic Architectural Luxury (Orizon Design concept).
- **Visual Density:** Balanced; generous whitespace with heavy, layered, translucent card surfaces (Neumorphism / Glassmorphism approach).
- **Theme Balance:** Hybrid Light/Glassmorphic Mode. Background utilizes atmospheric, muted photographic backdrops overlaid with multi-layered frosted glass panels (`backdrop-filter: blur()`).
- **Whitespace Balance:** High emphasis on breathable negative space, structured asymmetrical grid framing, and spatial depth created via z-indexing and multi-layered shadows.

## 2. Color Palette & Design Tokens

### Semantic Color Definitions
- **Primary (Brand):** Deep Midnight Indigo (`#171336`, `#120E2E`)
- **Secondary / Accent:** Crisp Sky Blue (`#60A5FA`, `#3B82F6`)
- **Base Backgrounds:** 
  - Canvas App Background: Off-White Slate / Ice (`#EEF2F6`)
  - Frosted Glass Surface (Light): `rgba(255, 255, 255, 0.75)`
  - Frosted Glass Surface (Dark/Muted): `rgba(15, 23, 42, 0.65)`
- **Borders & Dividers:** Translucent White/Slate (`rgba(255, 255, 255, 0.4)` and `rgba(226, 232, 240, 0.6)`)
- **Text Colors:**
  - Primary Headings: Dark Navy / Obsidian (`#0F172A`)
  - Muted / Secondary: Slate Gray (`#64748B`)
  - Inverse / Light Text: Pure White (`#FFFFFF`)

## 4. Layout Architecture & Spatial Grid
- **Container Max-Width:** 1440px fluid container with dynamic 40px outer padding.
- **Grid Layout:** 12-column structural layout with asymmetric focal cards overlapping the central hero canvas.
- **Spatial Padding/Gaps:**
  - Micro components (icon buttons): `8px` to `12px` padding.
  - Card internal padding: `24px` to `32px`.
  - Section gaps: `32px` to `48px`.
- **Z-Index Hierarchy:**
  - Canvas Background: `z-0`
  - Hero Media & Typography: `z-10`
  - Floating UI Cards & Overlays: `z-20`
  - Navigation Toolbar & Sidebar: `z-30`
  - Modals / Dropdowns: `z-50`

## 6. Motion Mechanics, Framer Motion & Animation Code

- **Animation Triggers:** Page load staggered entry, hover state scaling on cards, backdrop blur expansion on hover.
- **Transition Physics:** Spring physics (`type: "spring"`, `stiffness: 300`, `damping: 30`) and smooth cubic bezier curves (`cubic-bezier(0.16, 1, 0.3, 1)`).

## 7. Accessibility (a11y) & WCAG Contrast Audit

- **Contrast Ratios:**
  - Dark text on light frosted glass (`#0F172A` on `rgba(255,255,255,0.85)`): **14.2:1** (Passes WCAG AAA)
  - White text on primary dark background (`#FFFFFF` on `#171336`): **16.8:1** (Passes WCAG AAA)
  - Secondary text (`#64748B` on light glass): **4.6:1** (Passes WCAG AA for normal text)
- **Keyboard Focus Rings:**
  ```css
  :focus-visible {
    outline: 2px solid #3B82F6;
    outline-offset: 3px;
    box-shadow: 0 0 0 4px rgba(59, 130, 246, 0.25);
  ```
