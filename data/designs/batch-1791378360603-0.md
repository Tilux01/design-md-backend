# UI/UX Specification: "Burger Menu" Interactive Digital Interface

## 1. Executive Summary & Design Overview

This specification defines a high-fidelity digital restaurant menu system designed for kiosk, tablet, or web application usage. The interface features a dark-mode-first aesthetic with a rich dark chocolate-brown background (`#211A16`), accented by warm golden-yellows (`#F4C430`, `#E5B239`) and crisp typography. 

The layout is split into two primary view panels (or a responsive dual-column grid):
1. **Left Panel (Hero & Item Details):** Features a large, hyper-realistic 3D hamburger hero image, pricing, nutritional information, and categorized menu item lists ("SILCTCKE", "NAIAIS", "SPELIS", "LILLCH").
2. **Right Panel (Order Customizer & Side Menu):** Displays smaller item cards (burgers, buns, chips), interactive pill toggles, slider indicators, and order-summary action blocks.

---

## 2. Color Palette & Theming

| Color Role | Hex Code | Usage / Context |
| :--- | :--- | :--- |
| **Primary Background** | `#211A16` | Main screen canvas, cards, dark surfaces |
| **Surface / Card BG** | `#2C241F` | Elevated containers, menu panels |
| **Primary Accent / Gold** | `#F4C430` | Badges, hero price circles, active CTA backgrounds |
| **Secondary Accent** | `#E5B239` | Highlight lines, sub-indicators, rating/score accents |
| **Text Primary** | `#FAF8F5` | Headings, main menu titles, prices |
| **Text Secondary** | `#B3A8A0` | Body copy, descriptions, secondary labels |
| **Muted Dark Brown** | `#181311` | Deep shadows, recessed inputs |

---

## 3. Typography & Font Stack

The design uses a heavy, condensed grotesque sans-serif for headings (evoking modern street-food branding) and a clean geometric sans-serif for body copy and data tables.

### Font Definitions
- **Heading Font:** `Impact, "Arial Black", "Helvetica Neue", sans-serif` *(Fallback: Heavy geometric sans-serif with compressed width)*
- **Body / Data Font:** `"Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`

### Type Scale
- **App Title / Brand ("BAIGLEN SHBLUS"):** 
  - Size: `32px` / Line-height: `36px` / Weight: `900` / Tracking: `2px` / Color: `#FAF8F5`
- **Section Headers ("SILCTCKE", "NAIAIS"):** 
  - Size: `20px` / Line-height: `24px` / Weight: `800` / Tracking: `1px` / Color: `#FAF8F5`
- **Item Titles / Body Headings:** 
  - Size: `13px` / Line-height: `16px` / Weight: `700` / Color: `#FAF8F5`
- **Body Text / Ingredients:** 
  - Size: `10px` / Line-height: `14px` / Weight: `400` / Color: `#B3A8A0`
- **Prices & Numeric Badges:** 
  - Size: `12px` / Line-height: `12px` / Weight: `800` / Color: `#FAF8F5`

---

## 4. Layout Structure & Grid System

### Canvas Dimensions
- **Container:** Fluid CSS Grid / Flexbox setup mimicking dual portrait panels side-by-side.
- **Border Radius:** `24px` for major structural card wrappers.
- **Padding:** `24px` internal padding across all panels.

### Panel Breakdown

#### Left Panel (Hero & Category List)
- **Top Bar:** 
  - Left: Back/Menu icon buttons in circular container (`#382E28`).
  - Center: Brand Title (`BAIGLEN SHBLUS`).
  - Right: Price/Calorie Badge (`301` kcal or currency indicator in a solid gold pill).
- **Hero Image Area:** 
  - Centered high-resolution 3D burger render featuring sesame seed bun, double beef patties, melted cheese layers, and stylized sauce drips.
- **Bottom Menu Split (2 Columns):**
  - Left Column: Category `SILCTCKE` with item rows containing icons, titles, ingredient descriptions, and prices (`255`, `405`, `1050`).
  - Right Column: Category `NAIAIS` with structured list items and prices (`200`, `350`, `1650`).
  - Lower Columns: `SPELIS` and `LILLCH` sub-blocks.

#### Right Panel (Customizer & Side Selection)
- **Top Row (Product Carousel Cards):**
  - Three horizontal preview slots showing a stacked burger, plain bun, and textured potato chips (crinkle cut).
- **Interactive Toggles & Sliders:**
  - Slider bars with draggable thumb indicators (`-` / `+` scale style).
  - Grid of circular icon buttons for ingredient additions/removals (cheese, sauce, onions, pickles).
- **Action Buttons & CTA Blocks:**
  - Full-width golden button modules (`#F4C430`) with bold dark labels (`#181311`).

---

## 5. UI Component Specifications

### A. Price / Metric Badges
- **Shape:** Pill / Circle (`border-radius: 50%` or `16px`).
- **Background:** `#F4C430`.
- **Text:** `#181311`, bold, centered.

### B. Menu Item Row
- **Layout:** Flex row with left icon, middle text block (Title + 2 lines of truncated description), and right-aligned price.
- **Divider:** Subtle 1px dotted or low-opacity horizontal separator (`#3A302A`).

### C. Action Buttons (Bottom Right Panel)
- **Background:** Solid `#F4C430`.
- **Hover/Active State:** Shifts to `#E5B239` with slight scale reduction (`scale(0.98)`).
- **Text:** Uppercase, letter-spacing `0.5px`.

---

## 6. Animation & Interaction Specifications

### Page Load / Entry Animation
- **Hero Burger:** Scales up from `0.9` to `1.0` with an ease-out cubic-bezier curve over `600ms`.
- **Panels:** Slide in from bottom-to-top with a `400ms` stagger between the Left Panel and Right Panel.

### Hover & Tap Micro-Interactions
- **Menu Items:** Background highlight shifts to a lighter shade of dark brown (`#332A24`) on hover.
- **Buttons / Pills:** Tap triggers a rapid `scale(0.96)` bounce animation with haptic feedback trigger (if implemented on mobile/kiosk).
- **Sliders:** Smooth CSS transition on thumb drag (`transition: transform 0.1s ease`).
