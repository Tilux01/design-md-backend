# Coffee App UI Design Specification

## Global Styles & Theme

### Color Palette
*   **Background (Dark Slate):** `#2D3139` (Main dark grey-blue canvas tone)
*   **Card / Surface (Darker Charcoal):** `#21242A` (Elevated components like buttons, category blocks, search bar background)
*   **Accent / Primary (Vibrant Orange):** `#F37A20` (Buttons, search icon/filter, active states, pricing)
*   **Text Primary (Off-White):** `#FFFFFF` (Headings, primary typography)
*   **Text Secondary (Muted Gray):** `#9E9E9E` or `#888C94` (Subtitles, placeholders, category labels)

### Typography
*   **Font Family:** Sans-serif (Clean geometric sans-serif for UI, stylistic script/serif for promotional taglines)
*   **Body / UI Text:** Regular weight, clean legibility at small scales.
*   **Headings / Quotes:** Italicized stylistic serif fonts for marketing copy ("*Good morning, Michael*", "*Coffee so good...*").

---

## Screen 1: Welcome / Splash / Onboarding Screen

### Layout Structure
*   **Container:** Full-bleed dark slate background with floating 3D coffee bean illustrations scattered across the z-plane.
*   **Vertical Alignment:**
    *   Top/Center: 3D rendered hero asset (Black paper cup with lid coming off, dynamic coffee splash).
    *   Bottom 1/3: Typography block and CTA button.

### Components

#### 1. Hero Asset (3D Illustration)
*   **Visual:** A matte black takeaway coffee cup with a subtle logo graphic ("BlakBull" inside a ribbon banner surrounded by white abstract lines).
*   **Action Effect:** The lid is dynamically popping off with a splash of dark coffee liquid and droplets frozen in mid-air.
*   **Environment:** Floating coffee beans (`#3D2314`) drifting around the central cup at various opacities.

#### 2. Typography Block
*   **Title / Tagline:**
    *   *Text:* "Coffee so good, your teste buds will love it" *(Note: preserving original typo "teste" if replicating literal text, or correct to "taste")*
    *   *Style:* Italicized white serif font, centered alignment.
    *   *Font Size:* Large, prominent display text.

#### 3. Primary Call-to-Action (CTA) Button
*   **Shape:** Pill button with fully rounded corners.
*   **Background Color:** `#F37A20` (Vibrant Orange).
*   **Text:** "CHOOSE COFFEE" (Bold, uppercase, white).
*   **Icon:** Dual coffee bean illustration positioned on the right interior side of the button.

---

## Screen 2: Dashboard / Home Screen

### Layout Structure
*   **Container:** Full-bleed dark slate background (`#2D3139`), scrollable layout.
*   **Padding:** Generous side margins with standard mobile safe-area padding.

### Components

#### 1. Header Navigation
*   **Left Element:** Hamburger menu icon (Three horizontal orange lines, `#F37A20`).
*   **Right Element:** User Profile Avatar (Circular masked image of a person wearing sunglasses).

#### 2. Greeting Section
*   **Text:** "Good morning, Michael"
*   **Style:** Italicized white serif headline, medium-large weight.

#### 3. Search Bar Component
*   **Container:** Rounded rectangle pill input field (`#3A3F47` or `#353A42`).
*   **Left Icon:** Search magnifying glass (Orange, `#F37A20`).
*   **Placeholder Text:** "Search Coffee" (Muted gray).
*   **Right Icon:** Filter / Settings sliders icon inside an orange square container (`#F37A20`).

#### 4. Category / Filter Selector Cards
*   **Layout:** Horizontal row of square/rounded cards (`#24272E`).
*   **Card Contents:**
    *   Minimalist outline icon representing the category (e.g., Coffee cup for "Size", Coffee cup with steam for "Taste", etc.).
    *   Label underneath the icon in muted gray (e.g., "Size", "Taste", "Type").
*   **Indicator:** Horizontal thin orange slider bar below the category row with an active pill indicator.

#### 5. "Spesial offers" Section
*   **Section Header:** "Spesial offers" (White, clean sans-serif font).
*   **Promo Card:**
    *   **Background:** Dark elevated container (`#21242A`) with subtle rounded corners.
    *   **Left Element:** Graphic illustration of a tall iced coffee drink with a colorful unicorn graphic on the cup.
    *   **Right Details:**
        *   Title: "Fresh unicorn drink" (White).
        *   Price: "$1.2" (Bold, white).
    *   **Action Button:**
        *   *Text:* "ADD TO CART"
        *   *Style:* Orange pill button (`#F37A20`) with white bold text, positioned inside the right side of the card.

#### 6. Bottom Navigation Indicator
*   **Home Indicator Bar:** Thin horizontal capsule pill at the bottom center representing standard OS navigation bars.
