# UI Design & Implementation Specification: Tasklyn Dashboard

## 1. Global Layout & Canvas Architecture

### Viewport & Background
*   **Viewport Canvas:** Full-screen responsive layout optimized for desktop viewports ($1440\text{px}$ standard base width).
*   **Background Style:** Soft, ethereal radial gradient using a cool grayish-blue palette. 
    *   Center point: Light gray-blue (`#E4E9F0`).
    *   Outer edges: Muted periwinkle-blue (`#C1C7D6`).
*   **Main Container Card:** Floating frosted-glass container with rounded outer borders.
    *   `border-radius`: $32\text{px}$
    *   `background`: Semi-transparent white/light-blue gradient with high backdrop blur (`backdrop-filter: blur(20px)`).
    *   `box-shadow`: Soft, layered diffusion shadows (`0 30px 60px rgba(0, 0, 0, 0.08)`).

## 2. Typography & Font Stack

### Primary Font Family
*   **Primary Typeface:** `Inter`, `SF Pro Display`, system-ui, `-apple-system`, `sans-serif`.
*   **Fallback Font:** Standard sans-serif stack ensuring clean readability across all modern operating systems.

### Text Hierarchy
*   **Brand / Logo Title:** `20px`, Bold (`700`), Dark Navy (`#111122`), letter-spacing: `-0.5px`.
*   **Page / Section Headers:** `18px`, Semi-bold (`600`), Dark Navy (`#111122`).
*   **Card Titles / Widget Headers:** `16px`, Semi-bold (`600`), Dark Slate (`#1A1A2E`).
*   **Body Text & Subtitles:** `13px` to `14px`, Regular (`400`) / Medium (`500`), Gray-Blue (`#5A607F`).
*   **Micro-copy / Badges:** `11px`, Medium (`500`), uppercase or capitalized.
