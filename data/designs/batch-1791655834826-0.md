# Design Specification: BIORG Health Watch Concept (2026)

This document provides a comprehensive blueprint for replicating the BIORG Health Watch interface and presentation, rendered across three distinct smartwatch contexts.

---

## 1. Global Layout & Typography Architecture

### 1.1 Color Palette
*   **Primary Background (Watch UI):** Deep Black (`#0A0A0A`)
*   **Surface/Card Color (Watch UI):** Dark Charcoal/Green Tint (`#141A14`)
*   **Primary Text:** Pure White (`#FFFFFF`)
*   **Secondary Text:** Muted Gray (`#8E8E93` / `#A1A1A6`)
*   **Accent Color (Sage Green):** `#9DB588` or `#8FB373` (Used for active states, progress bars, and calendar highlights)
*   **Presentation Backgrounds:** 
    *   Top lifestyle frame: Dark cinematic athlete photo (`#000000` base)
    *   Bottom mockups frame: Off-white canvas (`#F4F4F4`)

### 1.2 Typography System
*   **Primary Font Family:** **SF Pro Display** / **Inter** / **Helvetica Neue** (Clean, geometric sans-serif with high legibility at small sizes).
*   **Fallback Stack:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
*   **Type Scale & Hierarchy:**
    *   *Greeting / Subtitle:* 12px–14px, Regular, tracking: normal, color: Secondary Text.
    *   *Section Titles / User Name:* 22px–28px, Bold, tracking: tight.
    *   *Data/Numbers:* 32px–40px, Bold (Heavy weight for high-impact stats like "3/5").
    *   *Body/Labels:* 11px–13px, Medium/Regular.

## 3. Implementation Guidelines for Developers

*   **Watch Frame Dimensions:** Design for standard Apple Watch Ultra aspect ratios (approx. 410 x 502 pixels base resolution for UI layouts).
*   **Shadows & Depth:** Use layered semi-transparent dark containers (`rgba(255, 255, 255, 0.05)` to `0.1`) with subtle backdrop blurring (`backdrop-filter: blur(20px)`) to achieve the modern watchOS glassmorphism aesthetic.
*   **Image Assets:** Ensure all supplement bottle and pill renders are exported as transparent PNGs or WebP formats with crisp drop shadows to maintain the high-end product presentation standard.
