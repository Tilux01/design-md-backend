# Comprehensive Design & Implementation Specification: "LÄMPZ Lumier Dark" Web Banner

---

## 1. Executive Summary & Design Overview

This specification details a pixel-perfect, responsive frontend clone of the "LÄMPZ Lumier Dark" landing page/banner. The design leverages a **dark mode luxury/minimalist** aesthetic tailored for high-end interior lighting products. 

### Core Aesthetic Pillars
* **Color Palette:** Deep carbon/navy dark mode backgrounds (`#12161E`), ultra-clean white typography (`#FFFFFF`), high-contrast muted grays (`#8C929D`), and a vibrant **Burnt Orange/Coral** accent (`#FF5C35`) used sparingly for interactive states, progress indicators, and call-to-actions.
* **Typography:** Modern geometric sans-serif typefaces combining heavy tracking (letter spacing) with clean hierarchy.
* **Layout Structure:** Asymmetrical full-screen hero banner featuring a left-aligned brand header, vertical pagination indicators, striking headline typography with dual product descriptions, and a prominent right-aligned 3D product render of a contemporary desk lamp.
* **Motion & Animation:** Subtle hover states, smooth fade-ins, and linear progress updates for pagination indicators.

   * **Primary:** `Space Grotesk`, sans-serif

## 6. Micro-Interactions & Animation Specifications

1. **Product Float Animation:** The lamp image floats gently using CSS keyframes (`floatAnimation`) with a 6-second infinite loop to give a dynamic, premium presentation feel.
2. **Button Hover States:** The `discover` pill button shifts upwards by `1px` with a darkening orange transition.
3. **Pagination State Transitions:** The active pagination number (`03`) features an animated orange accent line (`.active-indicator`) positioned cleanly to its left.
4. **Header Navigation Links:** Menu and search icons transition smoothly with `opacity: 0.7` on hover.
