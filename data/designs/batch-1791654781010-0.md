# UI/UX Specification & Design System: Onboarding Screen

## 1. Global Layout & Canvas Specifications
* **Screen Type:** Mobile Full-Screen Viewport (Responsive / Fluid Container).
* **Base Dimensions (Reference):** 375px × 812px (Standard iPhone proportions).
* **Background Color:** Off-White / Cream (`#F9F8F5` or `#FDFCFA`).
* **Layout Structure:** Flexbox / Vertical Stack (`column`) with centered alignment and defined padding (`24px` horizontal, `32px` vertical).

---

## 2. Typography System
> **Font Stack:** 
> * Primary: **Inter**, sans-serif
> * Fallback 1: **SF Pro Display**, -apple-system, BlinkMacSystemFont
> * Fallback 2: **Roboto**, **Helvetica Neue**, Arial, sans-serif

### Typography Hierarchy:
1. **Header / Title**
   * **Text:** "Welcome! Let’s get to it."
   * **Font Size:** `24px` / `1.5rem`
   * **Font Weight:** Bold (`700`)
   * **Line Height:** `1.2`
   * **Color:** Charcoal / Near-Black (`#1A1A1A`)
   * **Alignment:** Center / Left-aligned depending on layout bounds (Centered in reference).

2. **Button / Option Labels**
   * **Text:** Standard interactive button text (e.g., "Continue with email", etc.)
   * **Font Size:** `14px` / `0.875rem`
   * **Font Weight:** Medium (`500`)
   * **Color:** Dark Slate (`#2C2C2C`)

---

## 3. Image Assets & Illustrations

### Main Hero Illustration
* **Description:** A playful, 3D-isometric vector illustration featuring abstract stacked shapes, flowing ribbons, and footwear/sneaker-like elements rendered in a vibrant palette of yellow, orange, red, black, and white. 
* **Properties:**
  * **Background:** Transparent / Backgroundless (PNG/SVG format).
  * **Placement:** Centered horizontally, positioned directly beneath the header section with generous spacing.
  * **Rotation/Angle:** Isometric skew (approximately 15° to 30° tilt).
  * **Dimensions (Suggested):** Max width `220px` to `260px`, auto height.

---

## 4. UI Components & Interactive Elements

### Buttons / Option Cards
The screen utilizes a list of stacked pill-shaped buttons/cards for user choices.

* **Shape:** Rounded Rectangle / Pill (Border Radius: `28px` or `50px`).
* **Background Color:** Pure White (`#FFFFFF`).
* **Border:** Subtle light grey border (`1px solid #E5E5E0`).
* **Shadow / Elevation:** Soft, low-opacity drop shadow (`0px 4px 12px rgba(0, 0, 0, 0.04)`).
* **Padding:** `14px` vertical, `20px` horizontal.
* **Layout:** Flex container with space-between alignment (Icon/Badge on the left/right, text centered or left-aligned next to an icon).

---

## 5. Spacing & Grid System (The 8pt Grid)
* **Top Header Margin:** `48px` from the top safe area.
* **Header-to-Illustration Gap:** `32px`.
* **Illustration-to-Actions Gap:** `48px`.
* **Inter-Button Gap:** `12px` to `16px` vertical space between option cards.
* **Horizontal Page Padding:** `24px` uniform gutters.
