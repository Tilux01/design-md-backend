# Comprehensive UI/UX & Design System Specification

---

## 1. Design Philosophy & Overall Aesthetic
- **Primary Mood & Archetype:** E-commerce / Lifestyle marketplace with a calming, wellness-oriented, and holistic tone.
- **Visual Density:** Medium-high content density featuring a multi-column card grid layout, category pills, promotional banners, and navigation bars.
- **Whitespace Balance:** Balanced using compact padding within containers (8px–16px increments) coupled with soft pastel sections to segregate content blocks.
- **Theme Architecture:** Predominantly light mode interface built on soft lilac, lavender, and white surfaces with high-contrast dark text and deep purple/indigo interactive accents.

---

## 2. Color Palette & Design Tokens
- **Primary Color (Brand Purple):** `#8B5CF6` (Default), `#7C3AED` (Hover), `#6D28D9` (Active)
- **Secondary / Accent Colors:** Lavender/Lilac soft tints (`#EDE9FE`, `#F5F3FF`), Deep Indigo (`#4C1D95`), Coral/Peach accents on cards (`#FBCFE8`, `#FFE4E6`)
- **Base Background:** `#F8FAFC` (Canvas), `#FFFFFF` (Surface / Card Background)
- **Surface & Backdrop Blur:** `rgba(255, 255, 255, 0.85)` with `backdrop-filter: blur(12px)`
- **Border & Divider Colors:** `#E2E8F0` (Default borders), `#DDD6FE` (Accent borders)
- **Text Colors:** Primary (`#0F172A`), Muted (`#64748B`), Inverse (`#FFFFFF`), Accent (`#7C3AED`)

## 3. Typography System & Hierarchy
- **Font Families:** 
  - Headings & UI: `Inter`, `Plus Jakarta Sans`, system-ui, -apple-system, sans-serif
  - Body: `Inter`, sans-serif
- **Scale Breakdown:**
  - **H1 (Page Title):** 24px / 1.25 line-height, font-weight: 700, tracking: `-0.02em`
  - **H2 (Section Header):** 18px / 1.35 line-height, font-weight: 600, tracking: `-0.01em`
  - **Body / Card Title:** 14px / 1.4 line-height, font-weight: 500, tracking: `0em`
  - **Caption / Metadata:** 12px / 1.33 line-height, font-weight: 400, tracking: `0.01em`
  - **Badge / Pill Label:** 11px / 1.2 line-height, font-weight: 600, tracking: `0.05em` (Uppercase)

---

## 4. Layout Architecture & Spatial Grid
- **Container Max-Width:** `1200px` centered with fluid horizontal padding (`16px` to `24px`).
- **Spacing Scale:** `4px`, `8px`, `12px`, `16px`, `24px`, `32px`, `48px`.
- **Section Sequence (Top to Bottom):**
  1. Global Navigation Bar & Search/Filter Header
  2. Hero Promotional Banner Carousel
  3. Category Icon Grid (Horizontal Scrollable / Row)
  4. Featured Product Cards Carousel / Grid
  5. Promotional Split Banner (Call-to-Action)
  6. Sub-category Navigation & Footer Links
- **Stacking Order (z-index):**
  - Base Content: `z-0`
  - Sticky Headers: `z-20`
  - Floating Overlays / Modals: `z-50`

## 7. Motion Mechanics, Framer Motion & CSS Animation Code

- **Animation Triggers:** Card hover elevation, image zoom on hover, page transitions via layout presence.
- **Transition Physics:** `cubic-bezier(0.16, 1, 0.3, 1)` with a standard duration of `300ms`.

## 8. Accessibility (a11y) & WCAG Contrast Audit
- **Color Contrast Ratios:**
  - Primary Text (`#0F172A`) on Base Background (`#F8FAFC`): **15.2:1** (Passes WCAG AAA)
  - Muted Text (`#64748B`) on Base Background (`#F8FAFC`): **4.6:1** (Passes WCAG AA)
  - Primary Button Text (`#FFFFFF`) on Primary Background (`#8B5CF6`): **4.8:1** (Passes WCAG AA)
- **Keyboard Focus Ring:**
  ```css
  :focus-visible {
    outline: 2px solid #8B5CF6;
    outline-offset: 2px;
  }
  ```
