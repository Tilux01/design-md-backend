# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial Minimalist Hardware Showcase (Clean, high-end tech presentation blending brutalist typographic layout with sleek product rendering).
- **Visual Density & Whitespace Ratio**: High whitespace-to-content ratio with precise geometric framing, generous horizontal margins, and focused focal point hierarchy.
- **Surface Elevation Model**: Monochromatic flat-surface styling with sharp micro-borders (`1px`), subtle inner drop shadows, and minimalist pill-shaped interactive overlays.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase typography, modular asymmetric feature callouts, precision tech hardware wireframing, high-contrast CTA pill button.
- **Pill Badge Specification**: Padding: `4px 12px`, font-size: `12px`, font-weight: `600`, tracking: `0.05em`, border-radius: `9999px`, background: `rgba(255, 69, 0, 0.08)`, border width: `1px`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content to prevent rendering glitches.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;` or `<span class="w-2 h-2 rounded-full bg-orange-500 inline-block"></span>`.
