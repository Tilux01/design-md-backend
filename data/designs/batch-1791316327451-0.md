# Comprehensive Production UI/UX Design Specification

---

## 1. Design Philosophy & Overall Aesthetic
* **Primary Mood & Archetype:** Contemporary, editorial e-commerce platform combining minimalist luxury with high-density product discovery. The layout prioritizes visual merchandising through high-contrast photography and streamlined grid systems.
* **Visual Density:** Medium-high desktop density, featuring a prominent horizontal utility bar, category navigation, multi-column banners, and dynamic product grids.
* **Whitespace Balance:** Balanced whitespace using strict vertical rhythms ($8\text{px}$ base grid), allowing imagery to drive visual engagement while maintaining legible UI framing.
* **Theme Balance:** Light mode-first architecture utilizing neutral paper backgrounds (`#FFFFFF`, `#F9F9F9`) paired with high-contrast obsidian typography (`#111111`) and subtle borders.

---

## 2. Color Palette & Design Tokens

* **Primary Colors:** Obsidian (`#111111`), Pure White (`#FFFFFF`)
* **Secondary & Accent Colors:** Soft Stone (`#F4F4F4`), Warm Taupe (`#E5E0DA`), Muted Grey (`#8E8E93`)
* **Base & Surface Backgrounds:** Canvas (`#FFFFFF`), Card Surface (`#F9F9F9`), Overlay (rgba(0,0,0,0.4))
* **Border & Divider Colors:** Light Border (`#E5E5EA`), Dark Border (`#C7C7CC`)
* **Text Colors:** Primary Text (`#111111`), Muted Text (`#6E6E73`), Inverse Text (`#FFFFFF`)

## 3. Typography System & Hierarchy
* **Font Families:** 
  * Headings: Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif
  * Body: Inter, sans-serif
* **Scale Breakdown:**
  * **H1 (Hero Headers):** $28\text{px}$ / $1.2$ line-height / `font-weight: 600` / tracking `-0.02em`
  * **H2 (Section Titles):** $20\text{px}$ / $1.3$ line-height / `font-weight: 600` / tracking `-0.01em`
  * **H3 (Card Titles):** $14\text{px}$ / $1.4$ line-height / `font-weight: 500` / tracking `0`
  * **Body Copy:** $13\text{px}$ / $1.5$ line-height / `font-weight: 400` / tracking `0`
  * **Micro / Captions:** $11\text{px}$ / $1.4$ line-height / `font-weight: 500` / tracking `0.05em` (uppercase)

---

## 4. Layout Architecture & Spatial Grid
* **Container Max-Width:** $1440\text{px}$ with fluid horizontal padding ($24\text{px}$ mobile, $48\text{px}$ desktop).
* **Grid Specifications:** 12-column flexible grid system with standard $16\text{px}$ gutters.
* **Section Sequence:**
  1. Top Utility Navigation (Search, Brand Logo, Account, Wishlist, Cart)
  2. Category Navigation Bar (Horizontal scrolling pill list)
  3. Hero Multi-Banner Section (Editorial imagery with overlay CTAs)
  4. Promotional Split Banners
  5. Trending Products Grid (Product cards with image, title, price, and quick-add)
* **Z-Index Hierarchy:** 
  * Base content: `z-0`
  * Sticky Headers: `z-40`
  * Modals & Dropdowns: `z-50`
  * Toast Notifications: `z-60`

## 5. AI Design Traits, Micro-Badges & Special Glyphs
* **Visual Hallmarks:** High-tracking uppercase typography, minimalist glyph icons, monochrome badges with subtle borders.
* **Pill Badge CSS Specification:**
  ```css
  .ui-badge {
    display: inline-flex;
    align-items: center;
    padding: 4px 12px;
    font-size: 11px;
    font-weight: 500;
    letter-spacing: 0.05em;
    text-transform: uppercase;
    border-radius: 9999px;
    border: 1px solid var(--color-border-subtle);
    background-color: var(--color-bg-canvas);
    color: var(--color-text-primary);
  }
  ```
* **Symbol Safety & Entities:** Use explicit Unicode symbols with CSS pseudo-elements:
  * Sparkle: `&#10022;` or `content: "\2726";`
  * Bullet: `&#8226;` or `content: "\2022";`
  * Arrow: `&#8594;` or `content: "\2192";`

## 7. Motion Mechanics, Framer Motion & CSS Animation Code
* **Animation Triggers:** Page load staggered fade-ins, card hover zoom (`scale(1.05)`), dropdown expansion.
* **Transition Timings:** `0.3s cubic-bezier(0.16, 1, 0.3, 1)`

### Framer Motion Variants
```jsx
export const containerVariants = {
  hidden: { opacity: 0 },
  show: {
    opacity: 1,
    transition: {
      staggerChildren: 0.1
    }
  }
};

export const itemVariants = {
  hidden: { opacity: 0, y: 20 },
  show: { opacity: 1, y: 0, transition: { duration: 0.4, ease: [0.16, 1, 0.3, 1] } }
};
```

### CSS Keyframes
```css

  from { opacity: 0; transform: translateY(10px); }
  to { opacity: 1; transform: translateY(0); }
}

.animate-fade-in {
  animation: fadeIn 0.4s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}
```

## 8. Accessibility (a11y) & WCAG Contrast Audit
* **Contrast Ratios:**
  * Primary Text (`#111111`) on Canvas (`#FFFFFF`): **18.5:1** (Passes WCAG AAA)
  * Muted Text (`#6E6E73`) on Canvas (`#FFFFFF`): **5.2:1** (Passes WCAG AA)
* **Keyboard Focus Rings:**
  ```css
  *:focus-visible {
    outline: 2px solid #111111;
    outline-offset: 2px;
  }
  ```
