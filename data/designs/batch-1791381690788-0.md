## 5. Figma Prototyping & Carousel Animation Guide

To replicate this exact carousel interaction in Figma:

1.  **Create Components & Variants:**
    *   Create a component set for the main Hero section named `Hero Carousel`.
    *   **Variant 1 (Pomegranate):** Shows Pomegranate bottle active in the center, relevant text, and pomegranate fruit on the left.
    *   **Variant 2 (Next Fruit e.g., Orange/Mango):** Shows the next bottle shifted to the center, text updated, and background fruit swapped.
2.  **Apply Smart Animate:**
    *   Select the **"NEXT"** button (or the peek bottle on the right) in *Variant 1*.
    *   Connect a prototype interaction: **On click** $\rightarrow$ **Navigate to** $\rightarrow$ *Variant 2*.
    *   Animation settings: **Smart Animate** | **Ease Out** | **300ms–500ms**.
3.  **Auto Layout Setup:**
    *   Ensure the image container and text frames use **Auto Layout** with `Fill Container` and `Hug contents` appropriately configured so text reflows smoothly during the transition.
