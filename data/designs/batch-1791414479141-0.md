# UI Design & Implementation Specification

This document provides a highly detailed, production-ready specification to create an exact, pixel-perfect clone of the mobile application interface shown in the design mockup. 

The implementation focuses solely on the **full-screen application interface** itself. All presentation mockups (the physical iPhone frame, shadows, and the outer grid paper background) are omitted to deliver a clean, edge-to-edge mobile web/app layout.

## 5. UI Animations & Interaction States

To transform the static design into a dynamic user experience, implement the following transitions and animation specifications:

### Micro-Interactions

#### 1. Interactive Button Hover/Active Scale
All primary actionable items (Action Buttons, Quick Actions, and Transaction Row items) must feature high-fidelity tactile feedback.
* **CSS Property transition**: `transform 0.2s cubic-bezier(0.25, 1, 0.5, 1), background-color 0.2s ease`
* **Interaction States**:
  * **Hover (Web)**: Scale up smoothly: `transform: scale(1.02);`
  * **Active/Tap (Mobile touch)**: Scale down to indicate physical compression: `transform: scale(0.96); opacity: 0.95;`

#### 2. Send Again Contact Hover State
The rounded profile tiles in the "Send Again" grid should lift when hovered:
* **Effect**: `transform: translateY(-4px); filter: drop-shadow(0 4px 12px rgba(0, 0, 0, 0.08));`

---

### Keyframe Animations

#### 1. Page Entrance Transition
On view load, elements should cascade onto the screen from top to bottom.

```css
@keyframes slideFadeUp {
  from {
    opacity: 0;
    transform: translateY(24px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* Application to containers */
.main-wallet-header {
  animation: slideFadeUp 0.6s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}

.action-hub {
  animation: slideFadeUp 0.6s cubic-bezier(0.16, 1, 0.3, 1) 0.1s forwards;
}

.bottom-content-sheet {
  animation: slideFadeUp 0.7s cubic-bezier(0.16, 1, 0.3, 1) 0.2s forwards;
}
```

#### 2. Chart Drawing Entrance
The green trendline in the "Your Income" section should animate as if drawing itself in real-time.

```css
@keyframes drawPath {
  to {
    stroke-dashoffset: 0;
  }
}

@keyframes fillFadeIn {
  from {
    opacity: 0;
  }
  to {
    opacity: 1;
  }
}

/* To be applied onto the inline SVG Path object */
.income-chart-line {
  stroke-dasharray: 1000;
  stroke-dashoffset: 1000;
  animation: drawPath 1.6s cubic-bezier(0.25, 1, 0.5, 1) 0.4s forwards;
}

.income-chart-fill {
  opacity: 0;
  animation: fillFadeIn 0.8s ease-out 1.2s forwards;
}
```
