# Design Specification: Minimalist Editorial Tech E-Commerce App

This document outlines the precise design token system, layout structures, typography, and motion specifications required to build an exact, pixel-perfect clone of the provided UI mockup. 

The implementation should be **full-screen mobile** (designed for standard viewports such as $390\text{px} \times 844\text{px}$), omitting any external presentation backgrounds, device frames, or mockups.

---

## 1. Visual & Aesthetic Identity

The application features a premium, modern, editorial-style e-commerce interface for high-end tech/lifestyle gadgets. It uses asymmetric layouts, capsule-masked container shapes, generous whitespace, and a high-contrast sophisticated color scheme.

## 3. Typography & Font Stack

The typography alternates between a high-end editorial serif for prominent headings and a highly legible, clean geometric sans-serif for interface elements, body copy, and metadata.

### Font Families
1. **Primary Serif (Headings, Product Titles):**
   * **Preferred:** `Instrument Serif`, `Playfair Display`, or `Cormorant Garamond`
   * **Fallback CSS Stack:** `"Instrument Serif", "Playfair Display", Georgia, serif`
2. **Interface Sans-Serif (Body, Labels, Prices):**
   * **Preferred:** `Inter`, `SF Pro Display`, or `Instrument Sans`
   * **Fallback CSS Stack:** `"Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`

### Typography Hierarchy

| Style / Element | Font Family | Font Weight | Font Size | Line Height | Letter Spacing |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Logo/Brand Mark** | Primary Serif | Semi-Bold (`600`) | `24px` | `1.1` | `-0.02em` |
| **Product Title (Detail Screen)** | Primary Serif | Regular (`400`) | `28px` | `1.15` | `-0.01em` |
| **Grid Card Title** | Interface Sans | Medium (`500`) | `13px` | `1.3` | `0` |
| **Grid Card Price** | Interface Sans | Regular (`400`) | `12px` | `1.2` | `0` |
| **Body Copy** | Interface Sans | Regular (`400`) | `14px` | `1.5` | `0.01em` |
| **Button Text** | Interface Sans | Semi-Bold (`600`) | `15px` | `1.2` | `0.02em` |

## 4. Screen 1: Home / Browse Screen

This screen uses an alternating, asymmetric staggered grid of vertical capsule-shaped product cards.

```
+-----------------------------------+
|  [Logo]                  [Search] |  <- Header (32px padding-x)
|                                   |
|   +-----------+   +-----------+   |
|   |  Capsule  |   |           |   |
|   |  Image    |   |  Capsule  |   |  <- Staggered Grid (offset heights)
|   |  (Tall)   |   |  Image    |   |
|   +-----------+   |  (Short)  |   |
|     Title         +-----------+   |
|     Price           Title         |
|                     Price         |
|   +-----------+                   |
|   |           |   +-----------+   |
|   |  Capsule  |   |  Capsule  |   |
|   |  (Short)  |   |  Image    |   |
|   +-----------+   |  (Tall)   |   |
|     Title         +-----------+   |
|     Price           Title         |
|                     Price         |
|                                   |
|   [ Home    Search    Cart  User ]|  <- Bottom Navigation Bar
+-----------------------------------+
```

### Layout Specifications:
* **Outer Padding:** `24px` horizontal (`padding-left`, `padding-right`), `16px` vertical offset from safe areas.
* **Header:**
  * **Brand Mark:** `"techy."` styled in lowercase serif typography.
  * **Actions:** Minimalist vector search/menu icon (`24px` box size) aligned to the right.
* **Product Grid (Asymmetrical Staggered/Masonry):**
  * Two-column grid layout.
  * **Gap:** `20px` horizontal gap, `32px` vertical gap.
  * **Alternating Column Offset:** 
    * Column 1 (Left) has top items shifted down by `24px`.
    * Column 2 (Right) aligns normally to the top edge.
* **Card Component details:**
  * **Image Container:** Perfect stadium/capsule shape (`border-radius: 120px` or `9999px` with explicit width/height ratios).
    * *Ratio Left Col Card 1:* `width: 100%`, `aspect-ratio: 1 / 1.4`
    * *Ratio Right Col Card 1:* `width: 100%`, `aspect-ratio: 1 / 1.1`
    * *Background:* Clean `#E8EAED` flat fill.
  * **Image Placement:** Centered with `padding: 20px`, using `object-fit: contain` to showcase the hardware device cleanly.
  * **Card Metadata Stack:**
    * Centered or left-aligned directly below the capsule (left-aligned preferred for modern editorial feel).
    * `8px` top margin between capsule and Title.
    * `4px` top margin between Title and Price.

### Bottom Navigation Bar:
* Floating or bottom-aligned layout, high transparency canvas background or solid white base.
* **Icons:** Ultra-fine stroke vectors (1.5px line weight), space-between distribution.

## 5. Screen 2: Product Detail Screen

This screen is split into a upper product showcase card and a bottom contextual detail sheet.

```
+-----------------------------------+
|  [Back Icon]             [Fav]    |  <- Top Bar Navigation
|                                   |
|     +-----------------------+     |
|     |                       |     |
|     |     Product Image     |     |  <- Hero Image Card (Centered)
|     |                       |     |
|     +-----------------------+     |
|                                   |
|  +=============================+  |
|  |  Product Title              |  |  <- Start of White Info Sheet
|  |  Product Subtitle / Rating  |  |
|  |                             |  |
|  |  Body Description           |  |
|  |                             |  |
|  |  [Config Selector Tabs]     |  |
|  |                             |  |
|  |  +-----------------------+  |  |
|  |  |   [Add To Cart]       |  |  |  <- Full-Width Pill CTA Button
|  |  +-----------------------+  |  |
|  +=============================+  |
+-----------------------------------+
```

### Hero Showcase Container:
* **Margin/Padding:** `20px` lateral margins.
* **Hero Card Background:** `#E8EAED` block container with distinct soft rounded corners (`border-radius: 32px`).
* **Drop Shadow:** Extremely soft elevation shadow to separate card from the background:
  `box-shadow: 0 20px 40px rgba(0, 0, 0, 0.04);`
* **Image:** Centered with `padding: 40px` around the graphic element.

### Information Sheet (Bottom Half):
* Slides up to meet the bottom of the hero card container.
* **Background:** Solid white (`#FFFFFF`).
* **Border Radius:** Rounded top corners only (`border-radius: 36px 36px 0 0`).
* **Layout Structure:**
  * **Product Title:** Primary Serif, large scale (`28px`), primary text color.
  * **Body Description:** Secondary text color, standard sans-serif font, `1.5` line-height for optimal legibility.
  * **Product Configurator/Specs:** 
    * Modular small pills for choosing variations (e.g. storage size, color options).
    * Border style: `1px solid var(--border-muted)`.
  * **Add to Cart CTA Block (Fixed Bottom):**
    * **Button Shape:** Full pill-shaped outline or dark fill (`border-radius: 9999px`).
    * **Fill:** `#1A1C1E` deep dark charcoal.
    * **Text:** `#FFFFFF` bold sans-serif, centered text layout with an elegant right-facing arrow asset (`→`) nested inside the button container on the right-hand edge.

## 6. Motion & Micro-interactions (CSS Transitions)

To capture the high-end feel of this interface, use smooth, natural transitions instead of rigid cuts.

### Shared Element Transition (Navigation transition Screen 1 -> Screen 2)
* **Target Elements:** Product Capsule Image (Screen 1) morphs seamlessly into Hero Showcase Container (Screen 2).
* **Transition Property:** `transform`, `width`, `height`, `border-radius`.
* **Timing Function:** Custom cubic-bezier (anticipatory/smooth out):
  `transition: all 550ms cubic-bezier(0.16, 1, 0.3, 1);`

### Hover / Press States on Cards:
* Gentle scale down transition on touch down:
  `transform: scale(0.98); transition: transform 0.2s ease;`

### Bottom Detail Sheet Entrance:
* Slides up from viewport bottom on Screen 2 initialization.
  * **Keyframes:** `from { transform: translateY(100%); } to { transform: translateY(0); }`
  * **Duration:** `600ms` using `cubic-bezier(0.25, 1, 0.5, 1)`.
