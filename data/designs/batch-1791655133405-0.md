# Design Specification: "Workouts" Mobile App UI Clone

This document provides a comprehensive design and layout specification for replicating the provided "Workouts" mobile app interface. It covers screen dimensions, typography, color palette, layout structure, component hierarchy, and asset handling.

---

## 1. Global & Screen Layout

*   **Screen Type:** Full-Screen Mobile View (No device frame/mockup background).
*   **Dimensions (Reference):** Designed for standard modern iOS viewport (e.g., iPhone 14/15 Pro: `393px × 852px`).
*   **Background Color:** Pitch Black (`#000000`).
*   **Layout Architecture:** Vertical scrollable feed (or fixed viewport layout if content fits) with a fixed bottom navigation bar and a sticky/header top bar.

---

## 2. Color Palette

| Role | Color Name / Description | Hex Code | Usage |
| :--- | :--- | :--- | :--- |
| **Background** | Pitch Black | `#000000` | Main canvas background and bottom nav background |
| **Card Fill** | Dark Charcoal Gray | `#161618` | Background for all content cards and widgets |
| **Primary Text** | Pure White | `#FFFFFF` | Headers, primary metrics, prominent titles |
| **Secondary Text** | Muted Gray | `#8E8E93` | Subtitles, dates, timestamps, labels |
| **Accent / Highlight** | Bright White (Glow/Active) | `#FFFFFF` | Active calendar dots, progress rings, icons |
| **Card Border / Divider**| Subtle Dark Border | `#2C2C2E` *(Optional)* | Used implicitly via contrast or ultra-thin borders if needed |

---

## 3. Typography & Fonts

*   **Primary Font Family:** **San Francisco (SF Pro)** (iOS System Font).
*   **Fallback Stack:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.

### Type Scale & Hierarchy:
1.  **Screen Title ("Workouts"):**
    *   *Size:* ~34px (Large Title)
    *   *Weight:* Bold (700)
    *   *Color:* `#FFFFFF`
2.  **Section / Card Primary Values:**
    *   *Size:* ~24px – 28px (e.g., "200 lbs", "3.200 lbs")
    *   *Weight:* Semi-Bold / Bold (600/700)
    *   *Color:* `#FFFFFF`
3.  **Card Titles / Routine Names ("Chest + Triceps"):**
    *   *Size:* ~15px – 17px
    *   *Weight:* Medium / Semi-Bold (500/600)
    *   *Color:* `#FFFFFF`
4.  **Metadata / Timestamps ("Saturday", "31 min ago"):**
    *   *Size:* ~13px
    *   *Weight:* Regular (400)
    *   *Color:* `#8E8E93`

---

## 4. Header Section

*   **Top System Status Bar:** Standard iOS status bar (White time "9:41", cellular, wifi, battery icons).
*   **Main Header Row:**
    *   **Title:** Left-aligned text reading **"Workouts"**.
    *   **Action Icons (Right-aligned):**
        1.  *Filter / Adjust Icon:* Vertical sliders/toggles icon inside a rounded dark capsule button (`#161618`).
        2.  *Add / Plus Icon:* `+` sign inside a rounded dark capsule button (`#161618`).

---

## 5. Main Content Grid & Cards

The dashboard is composed of rounded cards with a corner radius of **`20px` to `24px`** and background color `#161618`.

### Row 1: Two-Column Layout (Split Cards)
*   **Card A (Left - Workout Summary):**
    *   *Top-Left:* Circular progress ring (Number "1" centered inside, partial stroke filled in white).
    *   *Top-Right:* Filter/Adjust icon (small).
    *   *Bottom-Left Text:* "Chest + Triceps" (White, Medium) -> "Saturday" (Gray, Regular).
*   **Card B (Right - Body Weight):**
    *   *Top-Left Value:* **"200"** (large, white) with **"lbs"** subscript/inline (smaller, gray).
    *   *Top-Right:* Filter/Adjust icon (small).
    *   *Bottom-Left Text:* "Body Weight" -> "31 min ago".

---

### Row 2: Calendar & Routine Card (Large Combined Card)
*   **Card Header:** Month labels horizontally distributed across the top: **Jan**, **Feb**, **Mar**.
*   **Activity Heatmap Matrix:**
    *   A grid of small circular dots representing workout frequency/intensity per day.
    *   Inactive dots: Dim dark gray (`#2C2C2E`).
    *   Active/Filled dots: Glowing white (`#FFFFFF`).
*   **Workout Info Footer (Inside or attached below the matrix):**
    *   Left: Circular badge with number **"2"**.
    *   Middle: Text **"Back + Biceps + Legs"** (White) -> **"Monday"** (Gray).
    *   Right: Filter/Adjust icon.

---

### Row 3: Volume Lifted Card
*   **Layout:** Horizontal banner card.
*   **Left Side:** Label **"Volume lifted"** (White, Medium) stacked above **"Last 7 days"** (Gray).
*   **Right Side:** Metric value **"3.200 lbs"** (Large White) alongside a small filter/adjust icon.

---

### Row 4: Small Widget / Action Card
*   **Layout:** Compact square or rectangular card on the left side.
*   **Content:** A grid-like icon with a `+` symbol (representing adding a custom widget, routine, or metric block) centered in a subtle outline/icon group.

---

## 6. Bottom Navigation Bar

*   **Placement:** Fixed to the bottom of the screen, spanning full width with top padding.
*   **Background:** Matches app background (`#000000`) with a subtle blur or dark container effect.
*   **Navigation Items (Left to Right):**
    1.  *Dashboard / Grid Icon:* 4 small squares (Active/Highlighted state - solid white).
    2.  *Calendar / History Icon:* Calendar outline with a date badge "10".
    3.  *Activity / Workout Icon:* Person exercising / wave icon.
    4.  *Social / Feed / Chat Icon:* Chat bubble / profile outline icon.
*   *Note:* The active tab (first icon) is rendered in bright white; inactive tabs are rendered in muted gray (`#8E8E93`).

---

## 7. Assets & Icons Specification

All icons used throughout the interface (filter sliders, plus signs, navigation items, calendar) should ideally be implemented using an icon library like **SF Symbols** (matching iOS native aesthetics) or clean SVG vectors with the following properties:
*   **Stroke Width:** 1.5px to 2px (Thin/Medium weight).
*   **Color:** `#8E8E93` for inactive states, `#FFFFFF` for active states.
*   **Images:** There are *no raster images* (photos) on this screen; all visuals are composed of vector icons, typography, and programmatic UI components (progress rings, matrix dot grids).
