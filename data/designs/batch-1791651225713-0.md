# Design Specification: DOTDNA Website Clone

This document provides the exact design specifications to create a pixel-perfect full-screen clone of the provided DOTDNA cybersecurity landing page.

---

## 1. Global Layout & Viewport Specifications

- **Display Type:** Full-screen viewport (`width: 100vw; height: 100vh;` or `min-height: 100vh;`).
- **Layout Direction:** Single-page absolute/flex hybrid layout centered inside a dark, immersive theme.
- **Base Padding:** 
  - Top padding (Logo to top edge): ~32px (`2rem`)
  - Side gutters: ~64px (`4rem`)
  - Bottom padding (Navigation to bottom edge): ~32px (`2rem`)
- **Overflow:** Hidden (`overflow: hidden;`) to maintain a locked, interactive viewport application feel.

---

## 2. Color Palette & Styling System

| Role | Color Name | Hex Code / Value | Usage |
| :--- | :--- | :--- | :--- |
| **Background** | Deep Emerald Green / Black | `#030f0a` to `#010503` | Main radial/linear gradient background |
| **Primary Text** | Pure White | `#FFFFFF` | Main headings ("Defending the Digital", "the Dot.") |
| **Accent Text / Highlights** | Neon Matrix Green | `#85FF00` or `#A3FF33` | Buttons, interactive states, subtitle tags |
| **Muted Text** | Pale Gray / Sage Green | `#A8B8B0` | Body copy ("We assist our clients..."), subheaders |
| **Glassmorphism / UI Backdrops**| Translucent Dark Green/Black | `rgba(0, 0, 0, 0.4)` with `backdrop-filter: blur(12px)` | Navigation pill background |

---

## 3. Typography & Font Stack

### Primary Font Family (Headings & UI)
- **Primary Font:** **Syne** or **Clash Display** (Geometric, wide grotesque sans-serif with unique artistic terminals).
- **Fallback Stack:** `'Syne', 'Helvetica Neue', Arial, sans-serif`

### Secondary Font Family (Body & Small Caps)
- **Primary Font:** **Inter** or **Plus Jakarta Sans** (Clean, modern geometric sans-serif).
- **Fallback Stack:** `'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`

### Typography Hierarchy Scale

1. **Main Headline ("Defending the Digital on the Dot.")**
   - **Font Family:** `Syne`, sans-serif
   - **Font Size:** Responsive clamp (e.g., `clamp(3.5rem, 6vw, 6.5rem)`)
   - **Font Weight:** 500 (Medium) / 600 (Semi-bold)
   - **Line Height:** `1.05` (Tight)
   - **Letter Spacing:** `-0.03em`

2. **Sub-tag ("CYBER SECURITY")**
   - **Font Family:** `Inter`, sans-serif
   - **Font Size:** `11px` / `0.7rem`
   - **Font Weight:** 600
   - **Letter Spacing:** `0.2em` (Uppercase)
   - **Color:** White with a vertical left accent line in Neon Green.

3. **Body Text ("We assist our clients in integrating...")**
   - **Font Family:** `Inter`, sans-serif
   - **Font Size:** `13px` / `0.85rem`
   - **Font Weight:** 400 (Regular)
   - **Line Height:** `1.5`
   - **Color:** `#A8B8B0` (Muted gray-green)
   - **Max Width:** `220px`

4. **Navigation & UI Labels (Home, Services, Contact us)**
   - **Font Family:** `Inter`, sans-serif
   - **Font Size:** `13px` / `0.85rem`
   - **Font Weight:** 400 to 500

---

## 4. Component Breakdown & Positioning

### A. Header (Top Bar)
- **Position:** `position: absolute; top: 0; left: 0; width: 100%;`
- **Padding:** `32px 64px` (or proportional padding matching gutters).
- **Left Element (Logo):**
  - Text/Icon combo: "DO DNA" with a custom intertwined geometric monogram (`DC` or interconnected loops).
  - Color: White/Neon Green.
  - Font Size: `16px`, bold.
- **Right Element (Top Contact Button):**
  - Pill-shaped button: `border-radius: 50px;`
  - Background: Semi-transparent dark green with a subtle white border (`1px solid rgba(255,255,255,0.15)`).
  - Text: "Contact us" (White).
  - Trailing Icon: A small circular button embedded on the right with a neon green background and a dark arrow icon pointing up-right (`↗`).

### B. Hero Section (Center Content)
- **Layout Structure:** Split/Layered composition where typography wraps around a central graphic element.
- **Top Subtitle:**
  - Located above "Defending the Digital".
  - Includes a vertical green marker bar preceding the uppercase text `| CYBER SECURITY`.
- **Headline Layout:**
  - **Left block:** "Defending the Digital" aligned to the left.
  - **Right block (wrapping the image):** "on the Dot." positioned lower-right of the central image.
- **Interactive Call-to-Action (CTA):**
  - Positioned directly below "Defending the Digital".
  - Pill shape matching the top-right button.
  - Text: "Contact us" followed by the same neon green circular arrow icon button (`↗`).
- **Body Copy Placement:**
  - Positioned adjacent to the phrase "on the Dot." on the middle-right.
  - Width: Fixed to approx. `220px`.
  - Copy: *"We assist our clients in integrating cybersecurity by design in their digital transformation."*

### C. Central Graphic / Image Element
- **Visual Description:** A complex, organic, amorphous cloud-like formation resembling a swirling swarm of microscopic particles, digital data points, or a biological cell cluster. The texture has depth, rendered in rich cybernetic neon greens, deep forest greens, and dark charcoal shadows. A slight motion-blur/dispersion effect trails off to the right side, giving it dynamic energy.
- **Asset Properties:**
  - **Transparency:** Backgroundless (PNG or WebP with alpha transparency) to seamlessly blend into the dark emerald background gradient.
  - **Placement:** Centered horizontally/vertically within the middle viewport canvas, sitting *behind* the typography or weaving between the words "Defending the Digital" and "on the Dot." (`z-index` layer management required: Background < Central Image < Typography).
  - **Rotation / Transform:** Slight counter-clockwise or dynamic tilt (approx. `-5deg` to give it a forward-moving momentum).

### D. Footer / Bottom Navigation Bar
- **Position:** `position: absolute; bottom: 32px; width: 100%;`
- **Elements:**
  - **Left Side:** `← Scroll to explore` with small arrow icon in muted gray.
  - **Center:** Floating Pill Navigation Bar
    - **Background:** Dark glassmorphism (`rgba(10, 20, 15, 0.6)`, `backdrop-filter: blur(16px)`).
    - **Border:** Subtle translucent border (`1px solid rgba(255, 255, 255, 0.08)`).
    - **Border Radius:** Fully rounded pill (`9999px`).
    - **Links:** 
      - Active item: `Home` (highlighted with a dark active pill background).
      - Standard items: `Services +`, `Product`, `About`.
  - **Right Side:** (Empty balance spacing to match left margin).

---

## 5. Responsive Behavior Notes
- **Desktop (>1200px):** Exact layout as specified above with full horizontal spacing.
- **Tablet (768px – 1199px):** Scale headline down via `clamp()`, stack body copy beneath headlines, reduce side padding to `32px`.
- **Mobile (<768px):** Convert layout to a single vertical stack: Logo -> Subtitle -> Headline -> Central Image (scaled down) -> Body Copy -> CTA Button -> Bottom Navigation collapses into a hamburger menu.
