# Design Specification: ZROBIM Architects ("TERRA cotta") Landing Page

---

## 1. Design Philosophy & Overall Aesthetic
- **Primary Mood & Brand Archetype**: High-end architectural studio portfolio emphasizing structural minimalism, monolithic typography, organic context (Mongolian steppe), and precision. Luxurious, editorial, yet industrial.
- **Visual Density & Whitespace Balance**: Generous whitespace framing heavy typographic focal points. Layout is content-driven with asymmetrical hero staging.
- **Theme Architecture**: Dark-mode-first aesthetic (`#1A1A1A` base) paired with desaturated organic photography, warm terracotta undertones, and crisp off-white (`#F4F1EA`) typography.

---

| Token Name | Hex Code / Value | Usage & Application |

---

## 3. Typography System & Hierarchy

- **Font Family (Headings & Display)**: Heavy Sans-Serif / Geometric Display (e.g., *Helvetica Neue Bold*, *Syne*, or *Montserrat Black*) for "TERRA", combined with a high-contrast Cursive/Script typeface for "cotta".
- **Font Family (UI & Body)**: Clean Neutral Sans-Serif (e.g., *Inter*, *Manrope*).

### Scale Breakdown
| Level | Font Size | Weight | Line Height | Tracking (Letter-Spacing) |
| :--- | :--- | :--- | :--- | :--- |

---

## 4. Layout Architecture & Spatial Grid

- **Container Max-Width**: Fluid layout scaled to `1440px` max viewport width with `40px` lateral window padding.
- **Grid Structure**: 12-column fluid grid with flexible gutters (`24px`).
- **Z-Index Hierarchy**:
  - `z-0`: Background image layer
  - `z-10`: Typography layer (`TERRA`)
  - `z-20`: Architectural render photo overlay & feature cards
  - `z-30`: Top navigation bar, social floating icons

---

## 5. Component Blueprint & Element Placement

### Top Navigation Bar
- **Height**: `80px` (Flex container, space-between layout).
- **Left Group (Pills)**: 
  - Pill list container with `border-radius: 9999px`, `border: 1px solid rgba(255,255,255,0.15)`, inner padding `6px`.
  - Individual items: `border-radius: 9999px`, padding `10px 24px`, uppercase text (`13px`). Active state uses solid `#F4F1EA` background with dark text.
- **Center Logo**: 
  - Grid matrix icon (4x4 dotted square) + `ZROBIM architects` stacked label.
- **Right Group**:
  - Contacts link + `ЗАКАЗАТЬ ПРОЕКТ` CTA pill featuring an animated trailing arrow icon (`→`).

### Hero Section Architecture
- **Staging**: 
  - Massive background headline "TERRA" placed behind architectural visualization.
  - Script accent "cotta" overlaid bottom-right overlapping the architectural render frame.
- **Metadata Card (Bottom-Left)**:
  - Position: Absolute (`bottom: 120px`, `left: 40px`).
  - Dimensions: Width `380px`, auto height.
  - Styling: Backdrop blur (`backdrop-filter: blur(12px)`), background `rgba(18, 18, 18, 0.4)`, border `1px solid rgba(255,255,255,0.15)`, border-radius: `16px`, padding: `24px`.
  - Content: Studio name, Architects list, Location, Area, Year, Category.

### Floating Action Links (Bottom-Left Corner)
- Circular icon buttons (Behance, Telegram, Instagram).
- Dimensions: `40px × 40px`, `border-radius: 50%`, background `rgba(255,255,255,0.08)`, border `1px solid rgba(255,255,255,0.15)`.
- Gap: `12px` horizontal stack.

---

## 6. Motion Mechanics & Interactions

- **Transitions**: 
  - Nav item hover: `cubic-bezier(0.4, 0, 0.2, 1)`, duration `250ms`.
  - Pill active switch: Spring physics (`stiffness: 300`, `damping: 25`).
- **Scroll Effects**: 
  - Parallax depth effect between background typography (`TERRA`), middle architectural render, and foreground description blocks.
  - Fade-in-up entrance animation for metadata card (`translateY(20px)` to `0`, opacity `0` to `1`, duration `600ms`).
