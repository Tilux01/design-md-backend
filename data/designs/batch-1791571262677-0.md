# UI Design Specification: Gaming Launcher Dashboard

This document provides the exact design specifications for recreating the gaming launcher dashboard interface shown in the media. 

---

## 1. Global Layout & Structure

*   **View:** Full-screen layout (designed to occupy 100% of the viewport width and height).
*   **Border Radius (Outer Container):** Rounded corners with a radius of approximately `24px` to `28px`.
*   **Layout Grid:** Three-column asymmetrical layout:
    1.  **Left Sidebar (Navigation):** Fixed width (~70px to 80px), containing brand logo, primary navigation icons, and user action buttons.
    2.  **Main Content Area (Center/Left):** Fluid width, containing the hero featured game (Valorant), "New Games" section, and "Last Downloads" section.
    3.  **Right Sidebar (Secondary & Social):** Fixed width (~80px to 90px), containing search/notification indicators, user profile avatar, and a vertical list of friend avatars/status icons.

---

## 2. Color Palette & Typography

### Color Palette (Hex Values Approximate)
*   **Deep Burgundy (Background Base):** `#2A161D`
*   **Dark Card Backgrounds:** `#351D26`
*   **Selected / Active State Highlights:** `#E64848` (Coral Red)
*   **Hero Gradient / Accent Backgrounds:** Linear gradients blending `#C0392B`, `#E67E22`, and dark purples.
*   **Text Primary (White):** `#FFFFFF`
*   **Text Secondary (Muted Gray/Pink):** `#C8B6BA` or `#8D7B80`

### Typography
*   **Font Family:** Modern, geometric sans-serif (Recommended Fallback Stack: `Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`).
*   **Weights Used:** Regular (400), Medium (500), Semi-Bold (600), Bold (700).
*   **Hierarchy:**
    *   *Greeting:* ~16px, Regular/Medium (Muted text).
    *   *Section Headings ("New Games", "Last Downloads", etc.):* ~18px, Semi-Bold.
    *   *Hero Title ("Valorant"):* ~32px - 36px, Bold.
    *   *Body / Descriptions:* ~12px - 14px, Regular, leading/line-height relaxed for readability.

---

## 3. Detailed Component Breakdown

### A. Left Navigation Sidebar
*   **Logo:** Top-most element. A stylized geometric "N" symbol in white on the dark background.
*   **Navigation Icons:** Vertical stack of outlined or filled circular/rounded icons representing dashboard modules (home, library, store, chat, settings, etc.).
    *   Active/Selected item features a subtle red/coral background pill or glowing indicator.
*   **Bottom Action:** A prominent "+" icon button encased in a rounded square with a subtle red/coral accent, used for adding games or manual imports.

### B. Header Area
*   **Greeting:** "Good evening, NIKITIN" displayed in a clean sans-serif typeface.
*   **Global Search Bar:** A rounded pill-shaped search input with a magnifying glass icon and placeholder text "Search". Background is a semi-transparent dark shade.
*   **Action Icons:** Notification bell and download/inbox indicators aligned to the top right of the main content area.

### C. Hero Section (Valorant)
*   **Background Banner:** A large horizontal card spanning the main area width with a dynamic gradient background transitioning from coral red to deep red-brown.
*   **Hero Character Art:** A stylized digital illustration of a character (resembling Gekko from *Valorant*) rendered in vibrant purples, greens, and yellows, dynamically overlapping the card borders.
*   **Badges & Metadata:** 
    *   "Popular" tag with a flame icon inside a rounded pill badge.
    *   Supported platform icons (Steam, Epic Games).
*   **Title & Description:** Large bold title "Valorant" accompanied by a short game synopsis.
*   **User Reviews / Rating:** A pill-shaped badge displaying user avatars followed by "+53 Reviews".

### D. Queue / Secondary Lists (Top Right)
*   Vertical stack of horizontal list cards for active or recommended games (*Unravel 2*, *Subway Surf*, *Red Dead Redemption 3*).
*   Each card features a small game thumbnail image, game title with edition details, and a subtle chevron (`>`) indicating navigation.

### E. "New Games" Section
*   **Header:** "New Games" with an "See More" action link aligned to the right.
*   **Cards Layout (Horizontal scroll or grid):**
    *   *Card 1 (Uncharted 4):* Dark card with a gameplay screenshot thumbnail, play button overlay, title, and descriptive subtitle.
    *   *Card 2 (Dishonored: Standard Edition):* Card featuring atmospheric character key art with the title overlay.
    *   *Card 3 (Elden Ring):* Partially visible adjacent card hinting at horizontal scroll functionality, featuring a navigation arrow button (`>`).

### F. Statistics Module ("Your Statistic")
*   **Header:** "Your Statistic" with an arrow indicator.
*   **Visual Graphic:** A circular badge displaying "Total hours" with a large bold metric **"12,340h"**, surrounded by an abstract multi-colored fluid gradient ring.
*   **Sub-metrics:** Row of circular game icons (*Dota 2*, etc.) with corresponding playtime statistics underneath (*2,340h*, *5,420h*, *4,580h*).

### G. "Last Downloads" Section
*   **Header:** "Last Downloads" with "See More".
*   **Download Card:** 
    *   Game icon (FIFA 23) inside a red accent container.
    *   Title and category ("Sports simulator").
    *   Progress status: "1 hour 23 min." with file size indicator ("265Mb of 1,23Gb").
    *   Interactive playback controls (pause/cancel icons).

### H. Right Social Sidebar
*   **User Profile:** Top-most circular user avatar with an online status indicator ring.
*   **Friend / Community List:** Vertical scrollable list of circular user avatars representing online friends. Some avatars feature small notification badges or game activity icons.
