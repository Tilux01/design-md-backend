# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Ultra-modern fintech dark mode UI featuring high-contrast neon acid green accents, glassmorphic card containers, and sleek rounded pills.
- **Visual Density & Whitespace Ratio**: High-density mobile UI optimized for glanceability. Generous internal card padding (16px–24px) combined with tight element stacking for financial data hierarchy.
- **Surface Elevation Model**: Deep charcoal/black canvas (`#000000` / `#0B0B0B`) layered with dark grey-to-black structural cards (`#141414`) and an ultra-vibrant electric lime-green primary asset zone (`#CCFF00`) to draw immediate focus to total liquid capital.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Acid-green glowing hero section, translucent pill navigation bar with active indicator pill, circular ring progress gauges.
- **Pill Badge Specification**: Padding: `4px 10px`, font-size: `11px`, font-weight: `600`, tracking: `0.05em`, border-radius: `9999px`, background: `rgba(255, 255, 255, 0.08)`.
- **Symbol & Glyph Safety Mapping**:
  - Arrow Up-Right (↗) -> Use `&nearr;` or SVG icon component.
  - Arrow Down-Left (↙) -> Use `&swarr;` or SVG icon component.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-[#CCFF00] inline-block"></span>`.
