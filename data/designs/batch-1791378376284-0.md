# Design Specification: Premium Steakhouse Landing Page

## 1. Overview & Layout Strategy
- **Layout Type:** Full-Screen Hero Section (Single-page app view).
- **Aspect Ratio / Container:** Designed for standard desktop viewports (`1440px` baseline width). Scaled to `100vw` / `100vh` without device mockups or borders.
- **Grid Structure:** 
  - **Header:** Flexbox with `space-between` alignment (Logo left, Navigation links center-right, Language selector far right).
  - **Hero Body:** Asymmetrical two-column visual layout. Left side reserved for typography and CTA; right side features a dynamic, centralized cooking scene with layered flat-lay ingredients.

---

## 2. Color Palette
| Color Name | Hex Code / RGBA | Usage |
| :--- | :--- | :--- |
| **Deep Charcoal Black** | `#141414` (approx.) | Primary background color |
| **Pure White** | `#FFFFFF` | Primary headers, navigation, and key call-out text |
| **Muted Grey** | `#A0A0A0` | Secondary navigation links, inactive state items |
| **Natural Wood Tone** | `#D49B57` (approx.) | Skillet handle accent |
| **Tomato Red** | `#E74C3C` / Varied | Accent for fresh cherry tomatoes |

---

## 3. Typography & Fonts
*Note: Due to exact styling replication constraints, use these primary web fonts with specified fallbacks:*

### A. Logo Font
- **Font Family:** Script / Cursive aesthetic (e.g., *Playball*, *Great Vibes*, or *Pinyon Script*).
- **Fallback Stack:** `cursive`, `Georgia`, `serif`.
- **Styling:** Italicized, smooth vector curves.

### B. Headings (Hero Title)
- **Font Family:** Classic transitional serif (e.g., *Playfair Display*, *Cinzel*, or *Merriweather*).
- **Fallback Stack:** `"Playfair Display", Georgia, "Times New Roman", serif`.
- **Weight:** Regular to Bold (`400`–`700`).
- **Properties:** Italicized on specific words for editorial elegance.

### C. Body & Navigation Links
- **Font Family:** Clean sans-serif (e.g., *Inter*, *Montserrat*, or *Open Sans*).
- **Fallback Stack:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`.
- **Weight:** Light to Regular (`300`–`400`).
- **Letter Spacing:** Generous tracking (`0.05em` to `0.1em`) for a luxury look.

---

## 4. UI Components & Elements Breakdown

### A. Navigation Bar (`<header>`)
- **Logo:** "Steakhouse" script text positioned at the top left.
- **Nav Links:** `Home` (active/underlined), `About Us`, `Menu`, `Events`, `Contact`, `Reservations`.
- **Language Switcher:** `EN ▾` positioned at the far right.
- **Interactions:** Subtle opacity transition on hover (`1` to `0.7`).

### B. Hero Section Content (`<section class="hero">`)
- **Main Heading:** 
  - Line 1: "A Premium"
  - Line 2: "And Authentic"
  - Line 3: "Steakhouse"
- **Call-to-Action (CTA) Button:**
  - Text: "Book A Table"
  - Style: Ghost/Outline button. Thin white border (`1px solid rgba(255, 255, 255, 0.4)`), transparent background, sharp rectangular edges, hover state fills with a subtle white backdrop (`rgba(255,255,255,0.1)`).

### C. Visual Scene / Flat-Lay Assembly (`.food-composition`)
*The visual elements are positioned dynamically over the background using absolute positioning to achieve a natural, organic composition:*
1. **Cast-Iron Skillet:** Central focal point containing a seared ribeye steak, sprigs of rosemary, and melting butter. Features an angled wooden handle extending toward the bottom right.
2. **Scattered Ingredients:**
   - Fresh garlic cloves and sliced shallots at the top-left.
   - Coarse sea salt crystals and cracked black peppercorns scattered around the pan base.
   - Sprigs of fresh herbs (rosemary, thyme, basil leaves) framing the bottom and right edges.
   - Wooden spoon holding cherry tomatoes at the top-right, paired with loose whole cherry tomatoes and basil near the bottom-left.

---

## 5. Animations & Transitions (Micro-Interactions)
- **Page Load (Entrance Animation):**
  - **Fade-In Up:** Hero typography fades in from a `Y: 20px` offset with a `1.2s` cubic-bezier easing.
  - **Staggered Reveal:** Navigation items slide down sequentially by `0.1s`.
  - **Visual Elements Scale:** The skillet and surrounding flat-lay ingredients scale up subtly from `0.95` to `1.0` over `1.5s` with a smooth ease-out curve.
- **Hover States:**
  - Nav links: Underline grows smoothly from left to right using a pseudo-element (`transform: scaleX`).
  - CTA Button: Border gains full opacity and inner background tint shifts gently over `0.3s`.
