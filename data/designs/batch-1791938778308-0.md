This document provides a comprehensive design specification to recreate the provided gaming UI clone. The design is a clean, modern, "Glassmorphism-lite" dashboard characterized by high-contrast imagery, bold accent colors, and soft shadows.

---

## 1. Global Styles & Theme

*   **Background:** The main application background is pure white (`#FFFFFF`).
*   **Border Radius:** A consistent large border radius of `24px` is used for the main container and all primary cards. Smaller elements (buttons, tags) use `8px` to `12px`.
*   **Shadows:** Elements use soft, diffused drop shadows to create depth. 
    *   *Example:* `box-shadow: 0 10px 30px rgba(0, 0, 0, 0.05);`
*   **Color Palette:**
    *   **Primary Blue:** `#0055FF` (Used for "Read More" button and page indicators).
    *   **Accent Red:** `#FF0044` (Used for active navigation background and logo).
    *   **Text Primary:** `#1A1A1A` (Deep charcoal/black).
    *   **Text Secondary:** `#8E8E93` (Medium grey for labels and counts).
    *   **Card Overlays:** Linear gradients from `transparent` at the top to `rgba(0,0,0,0.8)` at the bottom.

---

## 2. Typography

The design utilizes a clean, geometric Sans-Serif typeface.

*   **Primary Font:** **Inter** or **Montserrat**.
*   **Fallback Stack:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif, "Apple Color Emoji", "Segoe UI Emoji"`.
*   **Header Links:** `14px`, Medium weight, Uppercase or Title Case.
*   **Section Titles:** `18px`, Bold.
*   **Hero Title:** `28px`, Extra Bold.
*   **Card Titles:** `14px`, Bold.
