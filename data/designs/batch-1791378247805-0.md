# Design & Implementation Specification: Neon Sprint Landing Page

## 1. Global Layout & Canvas Strategy
*   **Full-Screen Viewport:** The layout must stretch to **100vw** and **100vh** (or `min-height: 100vh` on mobile) with zero margin/padding on the `body`.
*   **Canvas Gradient Background:** A vibrant radial/linear gradient transitioning from a bright sky/turquoise blue in the center/top to a deeper teal/cyan at the edges/bottom.
    *   *CSS Approximate Gradient:*
        ```css
        background: radial-gradient(circle at 50% 50%, #00b4d8 0%, #0077b6 50%, #03045e 100%);
        /* Alternatively, a clean linear vertical gradient: */
        background: linear-gradient(135deg, #00c6ff 0%, #0072ff 100%);
        ```
*   **Grid Structure:** A 12-column CSS Grid or Flexbox container with maximum width bounds (`max-width: 1440px`), centered on the screen, keeping generous padding on left and right margins (approx. 5% viewport width).

## 2. Typography System & Fallbacks

### Primary Heading Font (Hero Title: "FIND YOUR GREATNESS")
*   **Font Family:** Impact, "Anton", "League Gothic", or "Bebas Neue" (Sans-serif, ultra-bold, condensed).
*   **Fallback Stack:** `Impact, Anton, 'Arial Black', sans-serif`
*   **Properties:**
    *   `font-weight: 900;`
    *   `text-transform: uppercase;`
    *   `line-height: 0.95;`
    *   `letter-spacing: -0.5px;`

### Secondary / Body Font (Descriptions & Navigation)
*   **Font Family:** "Inter", "Roboto", or "Helvetica Neue"
*   **Fallback Stack:** `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
*   **Properties:**
    *   Weights used: `400` (Regular) for body text, `500` (Medium) for navigation links and buttons.

## 4. Animations & Micro-Interactions (Motion Design)

1.  **Hero Entrance Animation (On Load):**
    *   **Logo & Nav:** Fade down from top (`opacity: 0; transform: translateY(-20px);` $\rightarrow$ `1`).
    *   **Left Hero Text:** Slide in from left (`opacity: 0; transform: translateX(-30px);`).
    *   **Sneaker Float & Entrance:** The central sneaker drops in from a higher Z-axis with a scaling spring effect (`scale: 0.8` $\rightarrow$ `1`), accompanied by the vertical white pillars sliding up.
2.  **Continuous Floating Loop (Idle state):**
    *   Apply a gentle CSS keyframe float animation to the main sneaker image:
        ```css
        @keyframes float {
            0% { transform: translateY(0px) rotate(0deg); }
            50% { transform: translateY(-10px) rotate(1deg); }
            100% { transform: translateY(0px) rotate(0deg); }
        }
        .product-stage img {
            animation: float 4s ease-in-out infinite;
        }
        ```
3.  **Interactive Hover States:**
    *   **Color Swatches:** Scale up slightly on hover (`transform: scale(1.1);`). Clicking switches the active shoe image with a smooth cross-fade transition.
    *   **Buttons (`Place order`, `See all products`):** Slight shadow expansion and vertical translation (`transform: translateY(-2px);`).
