# UI Design Specification: iDraft Dashboard

## 1. Global Layout & Viewport

- **Canvas Type:** Full-screen responsive desktop application interface.
- **Orientation:** Landscape.
- **Layout Architecture:** Fixed vertical sidebar on the left, top utility/header bar spanning the right area, and a scrollable grid-based dashboard main content area containing mixed modular widgets.
- **Border Radius:** 24px container rounding on primary wrapper cards and dashboard modules.
- **Spacing/Padding:** Consistent 24px internal padding for dashboard cards; 16px to 24px grid gaps between modules.

---

## 2. Color Palette

- **Primary Dark (Sidebar & Dark Cards):** `#111111` (Deep Charcoal Black)
- **Secondary Dark Card Background:** `#1c1c1c` (Dark Grey surface for contrast)
- **Canvas/Background Base:** `#f0f2f5` (Light cool grey backdrop)
- **Card Background (Light Mode Modules):** `#ffffff` (Pure White) with subtle transparency/blur effects.
- **Primary Text (Dark Mode):** `#ffffff` (White)
- **Primary Text (Light Mode):** `#111111` (Dark Charcoal)
- **Secondary Text / Muted:** `#71717a` (Cool Grey)
- **Accent Highlight (Green/Success):** `#10b981` (Vibrant Emerald Green)
- **Accent Highlight (Yellow/Orange):** `#f59e0b` (Warm Amber for tags/progress)
- **Borders & Dividers:** `#e4e4e7` (Light mode dividers), `#27272a` (Dark mode borders)

---

## 3. Typography

- **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif.
- **Fallback Stack:** `sans-serif` (Universal web-safe fallback).
- **Weights Used:**
  - Regular (400): Body copy, labels, secondary metadata.
  - Medium (500): Navigation links, button text, task titles.
  - Semi-Bold (600): Section headers, card titles, key metric numbers.

---

## 4. Component Breakdown

### A. Sidebar Navigation (Left Panel)
- **Width:** Fixed (approx. 240px).
- **Background:** Solid Pure White (`#ffffff`).
- **Logo Area:**
  - Icon: Abstract geometric vector knot icon in dark charcoal.
  - Text: "iDraft" in bold, modern sans-serif typography.
- **Main Navigation Menu (Vertical List):**
  - **Dashboard:** Active state highlighted with a dark charcoal pill background (`#111111`) and white text.
  - **Calendar**, **My Tasks**, **Statistics**, **Documents**: Standard list items with left-aligned icons and grey text (`#71717a`).
- **Integrations Section:**
  - Category header: "INTEGRATIONS" (Uppercase, 10px, bold grey).
  - List items: **Slack**, **Notion**, **+ Add new plugin**.
- **Teams Section:**
  - Category header: "TEAMS".
  - List items with colored status indicator dots: **SEO** (Black dot), **Marketing** (Grey dot).
- **Footer:**
  - **Settings:** Gear icon with "Settings" text label.

## 5. Imagery & Asset Specifications

- **User Avatar (Header):**
  - **Description:** Professional headshot of a man wearing a dark suit jacket, cropped inside a perfect circle. Neutral lighting, clean studio background.
  - **Background:** Backgroundless/transparent avatar cutout.
  - **Placement:** Top right corner of the dashboard header bar, positioned adjacent to the search and notification icons.
  - **Rotation:** 0 degrees (straight).
- **Icons:**
  - All UI icons (Dashboard, Calendar, Tasks, Statistics, Documents, Settings, Notifications, Search, Filters, Share) are vector-based line icons rendered uniformly in 1.5px stroke width. Matching the color context of their container (dark icons on white backgrounds, white icons on dark backgrounds).
