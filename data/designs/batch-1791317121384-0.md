# 1. Design Philosophy & Overall Aesthetic

- **Primary Mood:** Modern, ultra-clean fintech and personal wealth dashboard emphasizing clarity, security, and effortless portfolio management.
- **Brand Archetype:** High-performance, minimalist digital banking / crypto investment application.
- **Visual Density:** Clean and airy (macrominimalism) with high white-space balance, structured cards, and high-contrast numerical highlights.
- **Theme Balance:** Primarily **Light Mode** implementation featuring crisp white/off-white canvas backgrounds (`#F4F5F7`), contrasted with deep obsidian text/UI elements and vibrant neo-mint financial accents (`#00F252` / `#10B981`).

# 3. Typography System & Hierarchy

- **Font Families:**
  - *Headings & Body:* Inter, system-ui, -apple-system, sans-serif

# 4. Layout Architecture & Spatial Grid

- **Container Scale:** Modeled within simulated mobile viewports (iPhone 14/15 Pro frame simulation width: ~390px - 430px).
- **Spacing Scale:** 
  - `px-4` (16px) standard horizontal screen padding.
  - `gap-3` (12px) to `gap-4` (16px) card and element spacing.
- **Section Sequence Breakdown (Top to Bottom):**
  1. Status Bar & App Header (Profile avatar, App Title "Wallet", Notification/Action icon)
  2. Total Balance Display (Label "My Balance", Numeric Value with gradient accent card)
  3. Interactive Balance Card / Quick Actions (Primary green gradient background card with deposit/send actions)
  4. Asset List / Portfolio Section (Categorized lists with horizontal dividers, crypto/asset icons, names, and fiat/percentage values)
  5. Bottom Navigation Bar (Fixed bottom tab bar with 4 primary navigation icons: Home, Analytics/Wallet, Activity/History, Profile/Settings)

---

# 5. AI Design Traits, Micro-Badges & Special Glyphs

- **Pill Badges:** High-contrast indicator pills with rounded corners (`border-radius: 9999px`), subtle background opacities (`rgba(16, 185, 129, 0.1)`), and bold uppercase micro-text.
- **Status Indicators:** Glowing or solid micro status dots (`●`) indicating active portfolio synchronization or live market connections.
- **Symbol Safety:** Standardized representation using HTML entities and safe unicode characters:
  - Arrow Up/Down: `&uarr;` / `&darr;`
  - Sparkle / Highlight: `&#10022;` (`✦`)
  - Status Dot: `&bull;` (`●`)

# 8. Accessibility (a11y) & WCAG Contrast Audit

- **Contrast Ratios:**
  - `#111827` on `#FFFFFF` background exceeds **14:1** (Passes WCAG AAA).
  - `#10B981` / `#059669` on white backgrounds exceeds **4.5:1** (Passes WCAG AA).
- **Focus Rings:**
  - All interactive elements include explicit focus states: `focus:outline-none focus:ring-2 focus:ring-emerald-500 focus:ring-offset-2`.
