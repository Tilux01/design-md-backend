# Hyper Massage Gun Landing Page Design System & Specifications

## 1. Global Styles & Foundations

### Colors
*   **Background (Primary Dark):** `#0C0D10` (Deep, near-black slate)
*   **Accent (Purple Glow):** `#7A04E8` / `#9333EA` (Vibrant neon purple used for highlights, typography glows, and ring light)
*   **Text Primary (White):** `#FFFFFF`
*   **Text Secondary (Muted Gray):** `#9CA3AF` / `#8B949E`
*   **Button Background:** `#FFFFFF`
*   **Button Text:** `#0C0D10`

### Typography
*   **Font Family:** Inter, system-ui, -apple-system, sans-serif (Geometric Sans-Serif)
*   **Hero Heading ("HYPER"):**
    *   **Font Weight:** 900 (Black / Ultra Bold)
    *   **Text Transform:** Uppercase
    *   **Style:** Layered effect with a massive, stylized white block font and a deep purple drop shadow/offset.
*   **Subheading ("TRAIN WITHOUT PAIN"):**
    *   **Font Size:** 12px - 14px
    *   **Letter Spacing:** 4px (Wide tracking)
    *   **Font Weight:** 600 (Semi-Bold)
    *   **Text Transform:** Uppercase
*   **Body Copy:**
    *   **Font Size:** 13px
    *   **Line Height:** 1.5
    *   **Color:** Muted gray (`#9CA3AF`)

*   **View:** Full-screen responsive hero section.
*   **Container Width:** Max-width ~1280px, centered with horizontal padding (`24px` to `48px`).
*   **Layout Strategy:** Absolute positioning over a background image layer, utilizing CSS flexbox/grid for navigation and feature callouts.
