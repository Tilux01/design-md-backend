# DESIGN SPECIFICATION: BIORG APP UI (PRESENTATION MODE)

## 1. Global Layout & Canvas Architecture
*   **Target Aspect Ratio / Viewport:** Full-screen responsive desktop viewport showcasing a mobile application frame centered against a rich multimedia backdrop.
*   **Base Background:** Solid Jet Black (`#000000`).
*   **Backdrop Elements (Atmospheric 3D Landscapes):
    *   **Foreground/Background Hills:** A hyper-realistic, macro-photographic landscape of rolling green hills covered in soft, velvety, moss-like green vegetation interspersed with fine, wispy white seed-hair or grass textures.
    *   **Placement & Composition:** The landscape bleeds dynamically off the bottom edge and sides of the screen. A massive, out-of-focus atmospheric hill cut-out spans the lower-right third of the screen, creating depth of field (blurred foreground).
    *   **Typography Watermark:** Giant, ultra-low-opacity dark gray (`#151515`) typographic logomark ("Biorg") positioned in the deep background behind the mobile device frame, extending off-screen to the left and right.

---

## 2. Typography System & Fallbacks

### Primary Font Family
*   **Primary Typeface:** **Inter** (or **SF Pro Display** for Apple ecosystem aesthetics).
*   **Fallback Stack:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.

### Type Scale & Hierarchy
*   **Header Meta Data (Top Bar):** 
    *   Font: Inter, Light / Regular, 10px / 12px uppercase, tracking (letter-spacing): `0.05em`. Color: White (`#FFFFFF`).
*   **App Greeting ("Good morning"):**
    *   Font: Inter, Regular, 13px, Color: Light Gray (`#A0A0A0`).
*   **App User Name ("Michael C."):**
    *   Font: Inter, Bold, 32px, Color: Pure White (`#FFFFFF`).
*   **Widget Metrics ("3 / 5"):**
    *   Font: Inter, Bold, 36px, Color: Pure White (`#FFFFFF`).
*   **Widget Labels ("taken today", "TODAY'S INTAKE"):**
    *   Font: Inter, Medium, 10px - 11px uppercase, Color: Muted Gray (`#8E8E93`).
*   **Section Headers ("Next dose", "Your Stack"):**
    *   Font: Inter, SemiBold, 14px / 16px, Color: Pure White (`#FFFFFF`).
*   **List Item Primary Text ("Magnesium", "Daily Formula", etc.):**
    *   Font: Inter, SemiBold, 15px, Color: Pure White (`#FFFFFF`).
*   **List Item Metadata ("Morning · Done"):**
    *   Font: Inter, Regular, 12px, Color: Gray (`#8E8E93`).

## 4. Mobile App Interface Breakdown (Inside Phone Frame)

### Phone Frame Specs
*   **Device Shell:** Dark metallic bezel with rounded corners and hardware status bar (iOS style: 9:41 time, signal strength, Wi-Fi, battery indicator in pure white).
*   **App Screen Background:** Deep rich black (`#0B0B0B`).

#### A. Header Section
*   **User Greeting Block:**
    *   "Good morning" (muted gray, small text).
    *   "Michael C." (large bold white text).
*   **Top Right Icon Button:**
    *   Circular container (`background: rgba(255, 255, 255, 0.1)` with backdrop blur).
    *   Contains a thin white line-art analytics/chart icon.

#### B. Landscape Banner Hero Card
*   **Container:** Rounded rectangular card featuring an embedded crop of the velvety green moss landscape texture, overlaid with a dark translucent gradient for text legibility.
*   **Layout (Two-Column Split):**
    *   **Left Side:** Large metric display ("3 / 5" taken today).
    *   **Right Side:** 
        *   Label: "TODAY'S INTAKE"
        *   Progress Bar: Slim horizontal track with a white progress fill indicating "60% of daily stack complete".

#### C. Next Dose Card
*   **Container:** Dark rounded glassmorphism card (`background: #161814`, subtle inner shadow/border).
*   **Text Content:**
    *   "Next dose" (small muted text).
    *   "Magnesium" (bold white text).
    *   "in 2 hours" (gray subtext).
*   **Visual Asset (Pill Capsule Image):**
    *   **Description:** A macro 3D render of a luxury capsule pill. The left half is frosted translucent white filled with tiny micro-pellets/granules; the right half is polished reflective metallic dark chrome/gold. 
    *   **Background:** Transparent (backgroundless PNG/asset).
    *   **Positioning:** Placed on the right side of the card, floating horizontally with a soft ambient drop shadow.

#### D. "Your Stack" List Section
*   **Section Header:** "Your Stack" (bold white, left-aligned).
*   **List Items (Stack Rows):**
    *   **Item 1: Daily Formula**
        *   Primary Text: "Daily Formula"
        *   Subtext: "Morning · Done"
        *   Action Element: Pill-shaped status button with text "Done" (`background: rgba(255, 255, 255, 0.15)`). Separated by a thin horizontal divider line (`#1C1C1E`).
    *   **Item 2: Omega-3**
        *   Primary Text: "Omega-3"
        *   Subtext: "Morning · 2h left"
        *   Divider line below.
    *   **Item 3: Brain Health**
        *   Primary Text: "Brain Health"
        *   Subtext: "Evening · Pending"

#### E. Bottom Navigation Bar (Dock)
*   **Container:** Floating pill-shaped glassmorphism dock (`background: rgba(20, 20, 20, 0.8)`, heavy backdrop blur).
*   **Icons (Left to Right):**
    *   1. **Home/Dashboard Icon:** Highlighted/Active state inside a solid white pill-shaped active background with a dark icon (`#000000`).
    *   2. **Capsule/Supplement Icon:** Thin outline (`#8E8E93`).
    *   3. **Calendar Icon:** Thin outline (`#8E8E93`).
    *   4. **Bag/Store Icon:** Thin outline (`#8E8E93`).
