# Design Specification: Landbook 404 & Cookie Consent Architecture

---

## 1. Design Philosophy & Overall Aesthetic
- **Primary Mood:** Minimalist, approachable, highly professional SaaS utility.
- **Brand Archetype:** Reliable developer/designer utility platform.
- **Visual Density:** Low-density, spacious, highly generous whitespace designed to reduce cognitive load and isolate attention on structural actions.
- **Theme Balance:** Monochromatic Light Mode (`#F7F7F7` base canvas) accented by high-contrast typographic hierarchy and a singular high-impact brand accent color (Deep Teal).
- **Surface Architecture:** Floating layered card design using a clean white surface card (`#FFFFFF`) on top of an off-white background (`#F9F9F9`), grounded by subtle drop shadows.

---

## 2. Color Palette & Design Tokens
- **Primary Brand / Action Color:** 
  - Default: `#007864` (Deep Teal)
  - Hover/Active: `#006151`
- **Secondary / Accent Colors:**
  - Neutral Dark (Text Primary): `#111111`
  - Neutral Muted (Text Secondary): `#666666`
- **Base Background & Surfaces:**
  - Window/Page Base: `#F7F7F7`
  - Floating Cookie Card Surface: `#FFFFFF`
  - Secondary UI Surface (Manage Preferences button): `#EFEFEF` (Hover: `#E5E5E5`)
- **Border & Divider Colors:**
  - Card/Button Borders: `#E5E5E5` / `#EAEAEA`
  - Dividers: `#EEEEEE`
- **Text Colors:**
  - Heading & Primary Copy: `#111111`
  - Subheadings & Description Copy: `#555555` / `#666666`
  - Inverse Text (on CTA): `#FFFFFF`
  - Footer Links: `#444444` (Hover: `#111111`)

---

## 3. Typography System & Hierarchy
- **Font Families:**
  - Headings & Body: Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif.
- **Scale Breakdown:**
  - **Logo Wordmark:** 18px, Weight: 600 (Semi-bold), Line-height: 24px, Tracking: -0.02em.
  - **H1 (Page Title):** 36px–40px, Weight: 700 (Bold), Line-height: 44px, Tracking: -0.03em.
  - **Subtitle / Body Lead:** 14px–15px, Weight: 400 (Regular), Line-height: 22px, Tracking: normal.
  - **Card Heading:** 16px, Weight: 600 (Semi-bold), Line-height: 24px.
  - **Button Text:** 14px, Weight: 500 (Medium), Line-height: 20px.
  - **Footer/Caption Text:** 12px, Weight: 400 (Regular), Line-height: 16px.

---

## 4. Layout Architecture & Spatial Grid
- **Container Max-Width:** Fluid body with centered content constraints. Max layout width: 1440px.
- **Padding & Margin Scale:**
  - Page outer vertical framing: Flexbox centered with auto margins.
  - Cookie Consent Card padding: `24px` internal spacing.
  - Vertical stack gap in Cookie Card: `16px` structural separation.
- **Section Sequence Breakdown:**
  - Top: Brand Logo Header (`Landbook` with icon mark).
  - Center: 404 Error State (Icon -> Title -> Description -> Primary CTA).
  - Bottom-Right Floating Layer: GDPR Cookie Consent Modal (`z-index: 50`).
- **Stacking Order (Z-Index):**
  - Base Layer (Background): `z-index: 0`
  - Main 404 Content: `z-index: 10`
  - Modal / Cookie Overlay Container: `z-index: 50`

---

## 5. Component Blueprint & Element Placement

### **Navbar / Brand Header**
- **Placement:** Centered horizontally at the top of the viewport (`margin-top: 60px`).
- **Structure:** Inline Flexbox combining a circular brand glyph (stacked line art book icon) and the text "Landbook".

### **404 Error State Centerpiece**
- **Alignment:** Absolute horizontal center, vertical offset.
- **Stack Order:**
  1. Brand Logo mark
  2. `Page not found` (H1)
  3. `The requested page couldn't be located. Checkout for any URL misspelling or...` (Body description)
  4. Pill-shaped primary button: `Return to the homepage`

### **Cards & Containers (Cookie Consent)**
- **Placement:** Absolute bottom-right corner (`bottom: 24px`, `right: 24px`).
- **Dimensions:** Width approx. 360px–400px.
- **Border-Radius:** `16px` (`rounded-2xl`).
- **Border:** 1px solid `#EAEAEA`.
- **Drop-Shadow:** `0 10px 25px -5px rgba(0, 0, 0, 0.05), 0 8px 10px -6px rgba(0, 0, 0, 0.05)`.

### **Buttons & Action Triggers**
- **Primary Action (Solid - "Return to the homepage", "Accept all", "Reject all"):**
  - Shape: Pill-shaped (`border-radius: 9999px` for navigation CTA) / Rounded-lg (`border-radius: 8px` for modal buttons).
  - Background: `#007864`.
  - Color: `#FFFFFF`.
  - Micro-interaction: Scale 1.01 transform or slight darkening on hover (`#006151`).
- **Secondary Action ("Manage preferences"):**
  - Shape: Rounded-lg (`border-radius: 8px`).
  - Background: `#EFEFEF`.
  - Color: `#111111`.
  - Hover: Background shifts to `#E2E2E2`.

---

## 6. Motion Mechanics & Interactions
- **Animation Triggers:** 
  - On-load fade-in for the main 404 container.
  - Slide-in and fade-in for the bottom-right Cookie consent modal (`translateY(20px)` to `0`).
- **Easing Curves & Timing:**
  - Modal entry transition: `0.4s cubic-bezier(0.16, 1, 0.3, 1)` (Smooth out).
  - Button hover states: `0.15s ease-in-out`.
- **Inferred Libraries:** Standard CSS Transitions/Animations coupled with React state management for toggling the cookie consent modal visibility upon user interaction.
