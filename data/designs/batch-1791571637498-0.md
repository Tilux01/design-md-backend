# UI/UX Specification & Design Document

This document outlines the exact design specifications for a modern, minimalist project management and productivity dashboard interface. It covers layout structures, typography, color palettes, and component descriptions.

---

## 1. Global Layout & Canvas

*   **View Style:** Full-screen responsive viewport (implied modern SaaS dashboard layout).
*   **Background:** Clean, light off-white background (`#F3F3F5` / `#ECECEE`) with subtle depth differentiation for container elements.
*   **Corner Radius:** High-radius container styling (approx. `16px` to `24px`) for cards and floating elements.
*   **Shadows & Elevation:** Soft, multi-layered drop shadows (`box-shadow: 0px 10px 30px rgba(0, 0, 0, 0.05)`) giving a floating, skeuomorphic "glass/paper" layered feel.

---

## 2. Typography

### Font Family
*   **Primary Typeface:** Clean, geometric sans-serif (e.g., **Inter**, **SF Pro Display**, or **Plus Jakarta Sans**).
*   **Fallback Stack:** `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif`.

### Hierarchy & Scale
*   **Header / Navigation Text:** Medium weight (500), small to medium size (`12px` - `14px`), high contrast dark text.
*   **Card Titles:** Semi-bold weight (600), dark slate/black (`#1E1E1E`), `13px` - `15px`.
*   **Metrics / Numbers:** Large, bold (700), monospaced or proportional numeric figures (`24px` - `32px`).
*   **Metadata / Secondary Text:** Light gray (`#8A8A8E`), regular weight (400), `11px` - `12px`.

---

## 3. Color Palette

*   **Neutrals:**
    *   `#FFFFFF` (Pure white for primary cards)
    *   `#F8F8FA` (Secondary background fills)
    *   `#1E1E1E` (Primary text and high-contrast dark elements)
    *   `#8A8A8E` (Secondary labels and icons)
*   **Accents & Highlights:**
    *   **Lime/Neon Green:** Used for progress indicators, active states, and focus highlights (`#CCFF00` / `#A3E635`).
    *   **Deep Purple/Indigo:** Used for primary branding components, top navigation accents, and specific media cards (`#2E1065` / `#3B0764`).
    *   **Status Indicators:** Standard soft UI palette for status dots (Green for complete, Red/Orange for alerts).

---

## 4. Component Breakdown & Structure

### A. Top Navigation Bar
*   **Left:** Brand logo icon followed by workspace/app name ("Aura" or similar).
*   **Center:** Pill-shaped dark indigo/purple navigation pill containing primary tabs (e.g., "My Tasks", search filters, date selectors highlighted in neon lime).
*   **Right:** User profile avatar / settings trigger button.

### B. Left Sidebar (Navigation Icons)
*   A narrow vertical toolbar anchored to the left containing stacked iconography:
    *   Dashboard/Home icon (active state marked with a dot).
    *   Analytics, Calendar, Folders, Settings, and collaboration icons.
    *   Color-coded notification indicator dots (Green, Yellow, Red) next to specific navigation items.

### C. Main Content Grid (Upcoming Tasks & Cards)
The central workspace utilizes an asymmetrical card-based grid layout:

1.  **Standard Task Cards (Top-Left & Mid-Row):**
    *   *Structure:* White background, rounded corners, subtle border.
    *   *Content:* Task title, large numeric counter (e.g., "8", "30"), duration/timeline label ("Minutes"), and small status badges.
    *   *Interactivity:* Floating "+" or action buttons positioned in the top-right corner of individual cards.

2.  **Color Palette / Design System Card (Top-Right):**
    *   *Structure:* Split layout displaying UI color swatches with HEX codes (e.g., `#FF5733`, `#33FFF3`) organized in a grid format with a vertical divider line.

3.  **Analytics / Progress Ring Card (Bottom-Left):**
    *   *Structure:* Vertical card featuring a prominent circular progress chart (multi-color gradient ring: Green, Blue, Purple) with numeric completion data inside.

4.  **Checklist / To-Do List Card (Bottom-Center):**
    *   *Structure:* Floating white card with list items, status checkmarks, and assigned user avatars.

5.  **Media / Audio Report Card (Bottom-Right):**
    *   *Structure:* Dark mode card (`#0F0F14`) titled "Audit Report Meeting". Features a glowing thumbnail image, status text ("Live Now"), and a bright lime action button at the bottom.

### D. Floating Interaction Elements
*   **Collaborative Cursor / Chat Bubble:** A floating highlighter tooltip anchored to the right side displaying overlapping user avatars and a message preview ("*Alex left 1 new goal*") attached to a dark pill button.
