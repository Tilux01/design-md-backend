# Braun Watch Website Clone - Design Specification

## 1. Global Styles & Variables

### 1.1 Colors
*   **Background (Light Theme - Default):** `#e6e9eb` (Soft, cool gray)
*   **Background (Dark Theme - Variant):** `#2c3237` (Deep charcoal gray)
*   **Primary Text / Headings:** `#ffffff` (Pure white)
*   **Secondary Text / Meta:** `#b0b8bc` (Light muted gray)
*   **Accent Color (Gold/Yellow second hand):** `#e5a93b`
*   **Accent Color (Green UI elements):** `#4cd964`
*   **Shadows:** `0 20px 40px rgba(0, 0, 0, 0.15)`

### 1.2 Typography
*   **Primary Font Family:** `'Helvetica Neue', Helvetica, Arial, sans-serif`
*   **Logo:** Bold, tracked-out sans-serif (ALL CAPS).
*   **Hero Heading ("Less, but better"):**
    *   *Desktop Size:* `56px` / `3.5rem`
    *   *Weight:* `700` (Bold)
    *   *Line Height:* `1.1`
*   *Body Copy / Description:*
    *   *Size:* `11px` / `0.6875rem`
    *   *Weight:* `300` (Light)
    *   *Line Height:* `1.6`
    *   *Opacity:* `0.85`
*   **Navigation Links:**
    *   *Size:* `12px` / `0.75rem`
    *   *Weight:* `400` / `500`
    *   *Letter Spacing:* `0.5px`

## 2. Layout Structure (Full Screen Viewport)

*   **Display:** CSS Grid / Flexbox
*   **Width:** `100vw`
*   **Height:** `100vh`
*   **Overflow:** `hidden`
*   **Layout Splits (Desktop):**
    *   **Left Column (Brand, Nav, Content):** `35%` width, aligned vertically with generous padding (`80px` left padding).

    *   Items: `Recommend`, `Media`, `Shop`, `Contact`, `Repair`, `Member`

    *   Font Size: `11px`

    *   Position: Below secondary navigation.
    *   Layout: Horizontal row of 4 small squares (`8px x 8px`).
    *   Active State: White square (`#ffffff`).

    *   Text: `Less,` (break) `but better`

    *   Text: `より少なく、しかしより良く`

## 4. Interactive States & Micro-Interactions

*   **Hover on Navigation Links:** Smooth color transition from secondary gray to pure white (`#ffffff`).
*   **Hover on Carousel Arrows:** Slight scale-up (`scale(1.1)`) with transition duration `0.3s ease`.
*   **Background Transition:** Smooth cross-fade when switching between light (`#e6e9eb`) and dark (`#2c3237`) variants.
