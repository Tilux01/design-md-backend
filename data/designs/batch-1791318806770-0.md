# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial E-Commerce Minimalist with sleek, high-contrast sportswear branding.
- **Visual Density & Whitespace Ratio**: High whitespace ratio with well-structured grid layouts, clean card divisions, and generous padding for optimal visual hierarchy.
- **Surface Elevation Model**: Flat, clean cards with subtle 1px borders (`#E2E8F0`), elevated product badges with pill-shaped chips, and clean drop shadows for interactive elements (`0 4px 12px rgba(0,0,0,0.05)`).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase pill badges, clean grid alignment, subtle drop shadows, interactive category navigation pills.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `0.75rem`, font-weight `600`, tracking `0.05em`, border-radius `9999px`, background translucency `rgba(0,0,0,0.05)`, border width `1px`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content to prevent rendering glitches.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;` or `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
