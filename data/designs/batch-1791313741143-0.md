# SCOOPA Mobile Application Design Specification

---

## 1. Design Philosophy & Overall Aesthetic
* **Primary Mood & Brand Archetype:** Playful, vibrant, high-energy gourmet dessert commerce. It evokes a joyful, modern boutique ice cream parlour experience with a modern pastel color narrative.
* **Visual Density:** Medium-high content density on screens (home feed, cart, order tracking) with generous whitespace around critical interactive triggers (CTAs, floating sheets).
* **Whitespace Balance:** Balanced through rounded container isolation (card-based categorization) and floating bottom navigation panels with generous thumb-zone clearance.
* **Theme Balance:** Primarily Light mode architecture featuring soft rose-tinted surfaces (`#FFF1F2`), crisp white cards, and high-saturation magenta accent elements (`#E11D48` / `#FF3B7F`).

## 3. Typography System & Hierarchy
* **Font Families:** 
  * Headings: `Plus Jakarta Sans`, `Poppins`, `sans-serif` (Rounded, playful geometric sans)
  * Body: `Inter`, `sans-serif`
* **Scale Breakdown:**
  * **Screen Title / Header:** 28px (1.75rem), Font Weight: 800, Line-Height: 1.2, Letter-Spacing: -0.02em
  * **Card Heading (H2):** 18px (1.125rem), Font Weight: 700, Line-Height: 1.3, Letter-Spacing: -0.01em
  * **Section Header (H3):** 16px (1rem), Font Weight: 700, Line-Height: 1.4
  * **Body Main:** 14px (0.875rem), Font Weight: 500, Line-Height: 1.5
  * **Caption / Meta:** 12px (0.75rem), Font Weight: 400 / 600, Line-Height: 1.4, Letter-Spacing: 0.01em

## 4. Layout Architecture & Spatial Grid
* **Container Max-Width:** Fluid mobile viewports (390px - 430px layout width reference).
* **Padding & Margin Scale:**
  * Screen Padding Horizontal: `20px` (`1.25rem`)
  * Element Spacing / Gaps: `12px`, `16px`, `24px`
* **Section Sequence Breakdown (Home View):**
  1. Top App Bar (Hamburger menu, brand logo, cart icon badge)
  2. Hero Promo Banner (Gradient surface, headline, image illustration, CTA)
  3. Category Filter Chips Icon Row (All flavors, sundaes, shakes, pints, vegan)
  4. Featured Flavors Grid Section
  5. Promotional Discount Banner ("20% OFF on your first order")
  6. Floating Bottom Navigation Bar (Home, Menu, Rewards, Profile)

## 7. Accessibility (a11y) & WCAG Contrast Audit
* **Contrast Checks:**
  * Primary Pink Button (`#FF3B7F`) with White Text (`#FFFFFF`): **4.52:1** (Passes WCAG AA for large text/UI components).
  * Main Text (`#1E1E24`) on White Background (`#FFFFFF`): **14.2:1** (Passes WCAG AAA).
  * Muted Text (`#71717A`) on White Surface (`#FFFFFF`): **4.6:1** (Passes WCAG AA standard text).
* **Keyboard Focus Rings:**
  ```css
  *:focus-visible {
    outline: 2px solid #FF3B7F;
    outline-offset: 2px;
  }
  ```
