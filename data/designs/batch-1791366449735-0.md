# Aloo Design Agency Web Application Design Specification

## 1. Executive Summary & Overview
This specification details the frontend architecture for the **Aloo Design Agency** landing page. The interface is optimized for high-end digital branding, utilizing a sophisticated dark-mode palette, crisp typography, and high-precision spatial alignment to reflect creative professionalism.

---

## 2. Global Layout & Canvas Architecture
* **Viewport Strategy:** Full-screen responsive viewport (`100vw`, `100vh`), designed to scale cleanly across standard desktop resolutions.
* **Background Color:** Deep charcoal slate (`#1b2330` to `#242f40` radial gradient or flat deep slate base).
* **Grid Structure:** CSS Grid / Flexbox layout featuring an explicit structural margin frame with top, bottom, and side padding parameters.
* **Structural Accents:**
  * Top horizontal orange accent bar.
  * Vertical orange separator/rule spanning from the top header border down through the main "aloo" title structure.

---

## 3. Typography System
* **Primary Display Font:** Clean, modern Sans-Serif (e.g., Inter, Poppins, or Montserrat variant).
* **Type Hierarchy:**
  * **Brand / Logo Title ("aloo"):** Extra-bold, lowercase, large scale (`~8rem` to `10let`), tracking/letter-spacing optimized for compactness.
  * **Tagline ("| design agency"):** Medium weight, uppercase or title-case, smaller scale positioned inline with the brand mark.
  * **Navigation & Micro-copy ("MENU", "PLAY VIDEO", language selectors, social links):** Light-to-regular weight, small size (`12px` - `14px`), high legibility, uppercase tracking.
  * **Vertical Side Text ("FUTURE OF DESIGN"):** Vertical text alignment (`writing-mode: vertical-rl`), spaced out via letter spacing.

---

## 4. Component Breakdown & Spatial Positioning

### 4.1 Header Bar
* **Position:** Fixed / Absolute top boundary.
* **Left Element:** Menu trigger containing a hamburger icon (`≡`) paired with the label `"MENU"`.
* **Center Element:** Company branding or portfolio identifier (`Marketmold`).
* **Right Element:** Video action trigger labeled `"PLAY VIDEO"` with a subtle underline or arrow cue.

### 4.2 Hero Content Area (Center Canvas)
* **Main Branding Mark:** `"aloo"` set in solid white (`#ffffff`).
* **Vertical Divider:** An orange accent line (`#ff5722`) intersecting between the letters 'l' and 'o'.
* **Subtitle Descriptor:** `| design agency` placed adjacently to the core brand text.
* **Watermark Background Detail:** A subtle, oversized translucent outline or drop-shadow text reading `"aloo"` offset in the lower right background quadrant.

### 4.3 Left-Hand Rail
* **Vertical Text:** `"FUTURE OF DESIGN"` aligned vertically along the left margin.
* **Language Selector:** Dual options `EN` / `SPN` positioned at the bottom-left corner (`EN` highlighted/active).

### 4.4 Right-Hand Rail & Footer Elements
* **Social Navigation:** Footer links aligned to the bottom-right corner reading `Facebook`, `Twitter`, `Google+`.
* **Page Navigation Controls:** Vertical interaction controls featuring an up arrow (`↑`), a central divider line, and a down arrow (`↓`) positioned near the mid-right boundary.

---

## 5. Color Palette & Styling Tokens

| Token Name | Hex Value / Gradient | Usage |
| :--- | :--- | :--- |
| **Background Primary** | `#1e2634` | Main screen canvas background |
| **Accent Orange** | `#ff5b24` | Top accent line, vertical layout divider line |
| **Text Main** | `#ffffff` | Primary headings, logos, and high-emphasis labels |
| **Text Muted** | `#8c96a5` | Secondary labels, social links, and menus |
| **Background Overlay (Watermark)** | `rgba(255, 255, 255, 0.03)` | Large background decorative text |

---

## 6. Interactive States & Micro-Interactions
* **Hover States:** Links (`MENU`, `PLAY VIDEO`, social items) transition to pure white with subtle opacity shifts.
* **Scroll Indication:** Up/down directional arrows on the right border suggest full-page section scrolling.
