# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial Industrial Minimalist / Brutalist Architecture Portfolio.
- **Visual Density & Whitespace Ratio**: High-contrast dark presentation layout utilizing generous framing, structural typography, and grid-aligned architectural photography.
- **Surface Elevation Model**: Flat, monolithic surface layers contrasted against subtle 1px structural borders (`#2A2A2A`), avoiding soft drop shadows in favor of hard architectural lines and material contrast.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Monospaced color hex codes, thin geometric border dividers, high-contrast industrial typography pairings, split-panel photography showcasing structural components.
- **Pill Badge Specification**: Padding: `4px 12px`, font-size: `11px`, font-weight: `500`, tracking: `0.05em`, border-radius: `9999px`, background: `rgba(255,255,255,0.05)`, border: `1px solid rgba(255,255,255,0.1)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;`
  - Structural Bullet (●) -> Use `&#9679;`

# 7. Motion Mechanics, Framer Motion & CSS Animations
- **Motion Principles**: Crisp, instant feedback matching industrial machinery mechanics. Zero superfluous spring bounce; strict linear and swift cubic-bezier transitions.
- **Framer Motion Variants Code**:
```jsx
export const panelRevealVariants = {
  hidden: { opacity: 0, y: 10 },
  visible: { 
    opacity: 1, 
    y: 0,
    transition: { duration: 0.3, ease: [0.25, 1, 0.5, 1] }
  }
};
```

- **CSS `@keyframes` Animations**:
```css
@keyframes industrialFade {
  from { opacity: 0; transform: scale(0.99); }
  to { opacity: 1; transform: scale(1); }
}
.animate-industrial {
  animation: industrialFade 0.25s cubic-bezier(0.16, 1, 0.3, 1) forwards;
```
