# Design System Specification: Minimalist Architecture Hero Showcase

This document provides the exact design specification required to recreate the UI displayed in the image as a 100% full-screen, edge-to-edge web application. All external device frames, styluses, and ambient studio shadows are omitted in favor of a true `100vw` by `100vh` layout.

---

## 1. Canvas & Global Layout Strategy

- **Viewport Dimensions**: Full viewport (`width: 100vw; height: 100vh; overflow: hidden;`).
- **Layout Model**: Two-tier split background layout with a 12-column grid overlay.
  - **Upper Section (~74% height)**: Canvas background `#292D33`.
  - **Lower Section (~26% height)**: Subtly darker base container `#212429` (visual boundary aligns cleanly with the bottom shelf of the architecture model).
- **Global Spacing Units**:
  - Horizontal screen margins: `clamp(2rem, 5vw, 5rem)`.
  - Vertical screen margins: `clamp(2rem, 4vh, 3.5rem)`.

---

## 2. Color Palette & Design Tokens

```css
:root {
  /* Canvas Backgrounds */
  --bg-primary: #292D33;         /* Upper charcoal slate background */
  --bg-secondary: #212429;       /* Lower dark slate footer panel */
  
  /* Text & Foreground */
  --text-white: #FFFFFF;         /* Primary headers, active states, branding */
  --text-muted: #8F96A3;         /* Nav links, subtext, inactive markers */

  /* Accents */
  --accent-warm-light: #FF9E44;  /* Architectural interior glow reference */
  --accent-flag-red: #D9383A;    /* Micro-flag accent red */
}
```

### 4.1 Header Bar
- **Position**: `absolute; top: 0; left: 0; width: 100%;`
- **Padding**: `2.5rem 4rem` (matching viewport padding).
- **Flex Layout**: `display: flex; justify-content: space-between; align-items: center;`
- **Left Cluster**:
  - `M · HOME`: Bold `M`, middle dot `·`, medium `HOME`.
- **Center-Left Navigation**:
  - Distance from logo: `margin-left: 5rem;`
  - Hamburger icon: 3 parallel lines (`width: 18px; height: 12px; stroke: #FFFFFF; stroke-width: 2px;`).
  - Menu Items: `HOME` (active, slightly brighter), `ABOUT`, `CONTACT` spaced `2rem` apart.
- **Right Cluster**:
  - Language indicator: Circular or rectangular miniature flag badge (`14px` wide, British/Cross motif with red `#D9383A` accents) followed by `· ENG`.
  - Search trigger: Minimalist stroke-based magnifying glass icon (`stroke-width: 2px; stroke: #FFFFFF; width: 16px; height: 16px;`).

---

### 4.2 Main Left Content (Hero Copy)
- **Vertical Alignment**: Centered vertically within the upper 74% section.
- **Horizontal Position**: Aligned with the left grid margin.
- **Elements**:
  1. **Category Tag & Index Row**:
     - `01` sits on the left column guide.
     - `Arhitecture` sits `4rem` to the right, aligning perfectly over the headline.
  2. **Main Headline**:
     - Text:
       ```
       Minimalism
       style
       ```
     - Margin-top: `2rem`.
     - Two lines, high-impact weight (800), tight letter spacing (`-0.03em`).
  3. **Call-to-Action (CTA)**:
     - Margin-top: `3.5rem`.
     - Layout: Inline flex item (`align-items: center; gap: 0.75rem;`).
     - Content: `See project` followed by a solid right-pointing equilateral triangle (`width: 7px; height: 7px; fill: #FFFFFF;`).

---

### 4.3 Feature Architectural Visual (Image Specification)

- **Asset Presentation**:
  - **Type**: High-end 3D architectural render / photographic cutout.
  - **Background**: **Fully transparent/backgroundless (PNG or WebP)**. It casts no external bounding box and blends directly over both `--bg-primary` and `--bg-secondary`.
- **Subject & Angle**:
  - Ultra-modern, sharp-angled minimalist villa viewed from a dynamic low-angle, isometric three-quarter perspective.
  - **Left Wing**: A steep, razor-sharp triangular A-frame facade with pure white outer walls and dark charcoal/matte black recessed soffit framing.
  - **Ground Floor Cutout**: Expansive glass facade revealing an interior radiating a warm amber/golden architectural glow (`#FF9E44` to `#D97706`).
  - **Right Wing**: Pure white, cubical cantilevered residential volume with a dark framed panoramic window.
  - **Base / Terrace**: Crisp white concrete patio deck jutting out horizontally towards the bottom-left with a minimalist outdoor patio set (white low-slung table and cube lounge chairs).
- **Position & Sizing**:
  - **Width**: Approximately `52vw` to `56vw`.
  - **Horizontal Alignment**: Anchored to the right side of the screen (`right: 2vw;`).
  - **Vertical Alignment**: Spans across the background partition. The lowest edge of the building patio anchors approximately `18vh` above the bottom edge of the viewport, grounding naturally into the footer sector.
- **Rotation**: None (straight isometric alignment; lines taper upward toward the dramatic roof peak).

---

### 4.4 Bottom Control Bar (Footer / Slider Navigation)
- **Container**: Sits inside the `--bg-secondary` (`#212429`) zone.
- **Height**: `26vh`.
- **Sub-components**:

1. **Social Links (Far Left)**:
   - Sits at `left: 4rem; bottom: 3rem; position: absolute;`
   - Vertical stack:
     ```
     IN
     FB
     YT
     ```
   - Spacing: `display: flex; flex-direction: column; gap: 0.75rem;`
   - Color: `--text-dim` (`#5B6270`), hover transition to `#FFFFFF`.

2. **Metric / Project Code**:
   - Label: `090`
   - Sits inline with the main text column alignment, approximately `14rem` from the left edge.
   - Vertically centered relative to the pagination dots.

3. **Carousel Pagination Dots (Center)**:
   - Position: Horizontally centered (`left: 50%; transform: translateX(-50%); bottom: 3.5rem;`).
   - Three dots:
     - Dot 1 (Active): Solid white circle (`6px × 6px`, `#FFFFFF`).
     - Dot 2 & 3 (Inactive): Muted white/grey circles (`6px × 6px`, `#8F96A3` at 40% opacity).
     - Gap between dots: `1rem` (16px).

4. **Slide Counter (Far Right)**:
   - Position: `right: 4rem; bottom: 3.25rem; position: absolute;`
   - Structure:
     - `01`: Large display weight (`2rem`, bold, `#FFFFFF`).
     - `/03`: Superscript format (`vertical-align: super; font-size: 0.875rem; color: #8F96A3; font-weight: 400;`).

## 5. Micro-Interactions & States

- **Navigation Links**: Subtle opacity change (`opacity: 0.7` to `1.0`) with `transition: opacity 0.25s ease`.
- **See Project CTA**: On hover, triangle moves `+4px` horizontally (`transform: translateX(4px); transition: transform 0.2s ease`).
- **Pagination Dots**: Clicking dot transitions active state, slides in the next architectural cutout asset via a smooth lateral translate and fade (`transform: translateX(-30px); opacity: 0;` to `0` / `1.0`).
- **Slide Numbers**: Increments smoothly via a vertical roll transition when changing slides.
