# 1. Design Philosophy & Overall Aesthetic
- **Primary Mood:** Editorial, eco-technical, illustrative editorial presentation blending isometric technical diagrams with sustainable energy themes.
- **Brand Archetype:** Sustainable Tech / Green Innovation Editorial.
- **Visual Density:** Airy, content-balanced layout with expansive negative space on the left and structured typographic hierarchies on the right.
- **Theme Balance:** Single-mode Light Theme utilizing soft pastel sage tones (`#E3EBD8`), crisp black strokes, and high-contrast editorial typography.

---

# 3. Typography System & Hierarchy

- **Headings Font Family:** Serif editorial display typeface (e.g., *Playfair Display* / *Lora* / *Editorial New*)
- **Body & Labels Font Family:** Clean geometric sans-serif (e.g., *Inter* / *Space Grotesk*)

## Scale Breakdown
- **Display Heading:**
  - Font Size: `3rem` (48px) / Line-Height: `1.05` / Weight: `700` / Tracking: `-0.03em`
- **Section Subtitles / Column Headers:**
  - Font Size: `0.75rem` (12px) / Line-Height: `1.2` / Weight: `700` / Tracking: `0.15em` (Uppercase)
- **Body Copy:**
  - Font Size: `0.875rem` (14px) / Line-Height: `1.5` / Weight: `400` / Tracking: `0`

---

# 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** `1140px` centered with fluid padding.
- **Grid Structure:** Two-column split layout (Left: Interactive 3D/Isometric illustration canvas; Right: Editorial content and feature breakdowns).
- **Padding & Margins:** Generous grid gutters (`32px` to `48px`).

---

# 5. AI Design Traits, Micro-Badges & Special Glyphs

- **Editorial Glyphs:** Uses minimal nature/technical iconography (`🌿`, `⚡`) alongside uppercase high-tracking labels.
- **Pill Badge Specs:**
  - Padding: `4px 10px`
  - Font Size: `10px`
  - Letter-Spacing: `0.1em`
  - Border: `1px solid #1A1A1A`

# 8. Accessibility (a11y) & WCAG Contrast Audit
- **Text Contrast:** `#111111` on `#E3EBD8` exceeds WCAG AAA standard (> 7:1).
- **Focus Rings:** Explicit `focus-visible:ring-2 focus-visible:ring-[#3A5A40]` required on all interactive triggers.
