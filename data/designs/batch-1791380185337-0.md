```markdown
# Design Specification: Hartwell Construction & Restoration Clone

This document provides the exact design specifications for cloning the landing page shown in the media. All components are designed for a **full-screen, edge-to-edge layout** (browser frame and laptop hardware have been omitted).

---

## 1. Global Styles & Typography

### Fonts
*   **Primary Font:** `Montserrat` (Sans-serif)
    *   *Fallback Stack:* `Montserrat, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
*   **Display / Hero Font:** A heavy, elegant serif font, similar to `Playfair Display` or `Cinzel` (used for "We build what lasts.").
    *   *Fallback Stack:* `Playfair Display, Georgia, Cambria, "Times New Roman", Times, serif`

### Color Palette
*   **Primary Dark (Text & Backgrounds):** `#111827` (Dark Charcoal)
*   **Pure White (Text & Highlights):** `#FFFFFF`
*   **Muted Overlay:** `rgba(0, 0, 0, 0.35)` (Dark overlay on top of the hero background image for text contrast)
*   **Navigation Links / Borders:** White with varying opacities (`rgba(255, 255, 255, 0.8)` hover to `1`)
*   **CTA Button Background:** `#FFFFFF`
*   **CTA Button Text:** `#111827`

---

## 2. Layout Structure & Sections

### A. Navigation Bar (Header)
*   **Layout:** Fixed or sticky top navigation, full width with inner padding (approx. `max-width: 1440px`, centered).
*   **Left Component (Logo):**
    *   Logo Box: Dark square background with a white bold letter "H" (`#FFFFFF` text).
    *   Brand Name: "Hartwell" (Bold, white).
    *   Sub-brand: "CONSTRUCTION · RESTORATION" (Small, uppercase, tracked out / spaced).
*   **Right Component (Nav Links):**
    *   Links: `Story`, `Projects`, `Services`, `Process`, `Contact`.
    *   Style: White, uppercase/sentence-case as shown, 14px, medium weight. Hover state adds a subtle underline or brightness shift.
    *   CTA Button: "Get an estimate"
        *   Shape: Fully rounded pill button (`border-radius: 50px`).
        *   Background: Solid white.
        *   Text: Dark charcoal, semi-bold.

### B. Hero Section (Main Viewport)
*   **Background:** 
    *   High-resolution architectural photograph showing a modern suburban home under construction with wooden framing and concrete foundations in a backyard setting.
    *   Dark overlay gradient to ensure readability of foreground text.
*   **Sub-headline (Top Center inside image):**
    *   Text: `HARTWELL — EST. 1996 — VANCOUVER, BC`
    *   Style: All caps, white, small tracking/letter-spacing, semi-transparent (`rgba(255,255,255,0.85)`).
*   **Main Headline:**
    *   Text: `We build what lasts.`
    *   Style: Serif font (`Playfair Display`), italicized on "lasts.", massive scale (`clamp(3rem, 6vw, 6rem)`), centered, pure white.
*   **Tagline / Description:**
    *   Text: `Construction & restoration, done the old way — properly.`
    *   Style: Sans-serif (`Montserrat`), light/regular weight, white, centered, positioned just below the main headline.
*   **Scroll Indicator (Bottom Center):**
    *   Text: `SCROLL TO BUILD` with a downward-pointing chevron icon.
    *   Style: Uppercase, small, tracked out, semi-transparent white, positioned near the bottom edge of the hero viewport.

---

## 3. Animations & Interactions

1.  **Page Load / Entrance Animation:**
    *   *Hero Text:* Fade up / slide up with a subtle stagger effect (Sub-headline appears first, followed by "We build what lasts.", then the tagline).
    *   *Background Image:* Subtle zoom-in (Ken Burns effect) from `scale(1.05)` to `scale(1)` over 2 seconds on initial load.
2.  **Hover States:**
    *   *Nav Links:* Color shift to pure white with smooth transition (`transition: color 0.2s ease`).
    *   *CTA Button ("Get an estimate"):* Slight elevation shadow increase and scale up (`transform: scale(1.02)`).
3.  **Scroll Indicator Animation:**
    *   Infinite subtle bouncing/floating animation up and down (translate Y by `±5px`) to prompt the user to scroll down.
```
