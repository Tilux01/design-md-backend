# Design System & Implementation Specification: Lamplby UI

## 1. Global Specifications & Foundations

### 1.1 Palette & Color System
The UI utilizes a dual-theme structure: deep luxury dark modes transitioning into high-contrast warm cream light modes.

```css
:root {
  /* Dark Theme / Hero / Cards */
  --bg-dark-primary: #0F0F0F;
  --bg-dark-secondary: #161616;
  --bg-dark-card: #1C1C1E;
  --bg-dark-glass: rgba(255, 255, 255, 0.07);
  --border-dark-glass: rgba(255, 255, 255, 0.12);

  /* Light Theme / Best Sellers / Editorial */
  --bg-light-primary: #FAF8F5;
  --bg-light-card: #F2EFEA;
  --bg-light-pure: #FFFFFF;

  /* Accent & Highlight Colors */
  --accent-amber: #E5A93B;
  --accent-amber-glow: #F3B749;
  --accent-gold-subtle: #D4AF37;

  /* Typography Colors */
  --text-light-primary: #FFFFFF;
  --text-light-muted: #A0A0A0;
  --text-dark-primary: #121212;
  --text-dark-muted: #666666;
  --text-amber: #D99B26;

  /* UI Accents & Badges */
  --badge-bg-dark: rgba(0, 0, 0, 0.4);
  --interactive-hover: #222222;
}
```

### 1.2 Typography Hierarchy

#### Primary Serif Font (Headings, Branding, Titles)
*   **Font Family:** `Italiana`, `Bodoni Moda`, or `Playfair Display`
*   **Fallback Stack:** `Georgia, "Times New Roman", serif`

#### Secondary Sans-Serif Font (Body, Navigation, Buttons, UI Meta)
*   **Font Family:** `Plus Jakarta Sans` or `Inter`
*   **Fallback Stack:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`

### 1.3 Layout & Elevation
*   **Container Width:** `1440px` max-width (Full bleed canvas, scalable).
*   **Grid Padding:** `64px` desktop inline padding, `24px` mobile inline padding.
*   **Border Radius Tokens:**
    *   `radius-sm`: `8px` (Small tags, inner buttons)
    *   `radius-md`: `16px` (Glass cards, inputs)
    *   `radius-lg`: `24px` (Main section cards)
    *   `radius-pill`: `9999px` (Navigation pills, CTA tags)
*   **Glassmorphic Effect Standard:**
    ```css
    .glass-panel {
      background: rgba(255, 255, 255, 0.08);
      backdrop-filter: blur(16px);
      -webkit-backdrop-filter: blur(16px);
      border: 1px solid rgba(255, 255, 255, 0.15);
    }
    ```

## 3. Micro-Interactions, States & Animations

1.  **Pill Buttons:**
    *   *Default:* Transparent or subtle fill with `1px` border.
    *   *Hover:* Background translates to solid text color, text color flips to contrasting background. Scaled upward by `1.02x` with a fast cubic-bezier transition (` cubic-bezier(0.16, 1, 0.3, 1)`).
2.  **Product Hotspots (Hero Section):**
    *   Pulsing amber outer ring around the hotspot anchor dot (`animation: pulse 2s infinite`).
    *   Hovering displays extended metadata box with spring transition.
3.  **Accordion Expand/Collapse:**
    *   Smooth height expansion (`transition: max-height 0.35s ease-out`).
    *   Background smoothly morphs to dark background `#121212` on active state.
4.  **Marquee Text:**
    *   Infinite seamless linear horizontal loop translation (`animation: marquee 25s linear infinite`).
