# Design System & Implementation Specification: CRYSTAL TECH UI

## 1. Overview & Layout Strategy
* **Viewport Dimensions:** Fullscreen `100vw` × `100vh` (Edge-to-edge, no outer margins, frames, or mockup background padding).
* **Scroll Behavior:** Non-scrollable hero dashboard (`overflow: hidden`).
* **Visual Theme:** Futuristic, dark sci-fi, high-contrast minimal UI over a glossy 3D liquid backdrop.
* **Layout Structure:** 3-tier absolute container architecture (Background Layer → Character Layer → UI Overlay Layer).

## 7. Interactive Hover & Motion States

1. **Header "REGISTER" & Menu:**
   * Transition: `color 0.3s ease, opacity 0.3s ease`.
   * Hovering over `MENU` rotates hamburger lines into an "X" or shifts lines slightly.
2. **Category Navigation Tabs (`TRAINING`, `GALLERY`, `COLLECTIONS`):**
   * Default state cursor: `pointer`.
   * Non-active tabs transition color to `#FFFFFF` on hover.
3. **Play Trailer Circle:**
   * Transition: `transform 0.3s cubic-bezier(0.16, 1, 0.3, 1), border-color 0.3s ease`.
   * Scale up to `1.08` on mouse hover.
4. **Slide Navigation Arrows (`←`, `→`):**
   * Hover state opacity increases to `1.0` with `translateX(-3px)` and `translateX(3px)` subtle offset animations respectively.
