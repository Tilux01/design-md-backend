# UI Design Specification & Layout Blueprint

This specification details a complete, production-ready clone of the provided modern classified advertisements marketplace web application UI. The layout features a clean, high-end, rounded aesthetic with heavy use of modern typography, soft drop shadows, a vibrant blue and neutral color palette, and floating 3D/abstract elements integrated into the viewport.

---

## 1. Global Viewport & Container Setup

*   **Width & Behavior:** Full-width viewport (`width: 100vw; min-height: 100vh`), bypassing any simulated device bezels or desktop wrapper frames. 
*   **Background:** Clean, bright off-white / very light gray backdrop (`#F8FAFC` to `#F3F4F6`), creating a high-contrast canvas for content cards.
*   **Border Radius & Geometry:** The primary UI wrapper utilizes soft, rounded structural corners (`border-radius: 24px` to `32px` internally for panels) with layered card elevations.
*   **Visual Elements:** Floating, translucent 3D geometric shapes (spheres, pill-shaped cylinders, abstract curved ribbons) are layered delicately in the periphery (left and right margins) over the background to give a dynamic, modern depth effect.

---

## 6. Content Grid Sections

The layout features two primary product listing grids separated by section headers ("Featuree d isstriving ads" and "me feadings").

### Grid Architecture
*   **Columns:** 4-column responsive grid layout (`grid-template-columns: repeat(4, 1fr)`).
*   **Card Component Specifications:**
    *   **Background:** Pure white (`#FFFFFF`).
    *   **Border Radius:** `16px`.
    *   **Shadow:** Soft elevation (`box-shadow: 0 4px 20px rgba(0, 0, 0, 0.04)`).
    *   **Padding:** `12px` internal padding around image and metadata.
    *   **Image Container:** Rounded inner corners (`12px`), maintaining an aspect ratio of roughly `4:3`, displaying crisp photography.
    *   **Metadata Layout:**
        *   Title line (Left-aligned, dark text).
        *   Subtitle / Location string (Small muted text).
        *   Rating stars (Gold 5-star representation: `★★★★★`).
        *   Price tag (Bold, aligned right or bottom-left opposite tags).
        *   Small action/badge tags (Orange/Blue pill badges in the top right corner of images).
