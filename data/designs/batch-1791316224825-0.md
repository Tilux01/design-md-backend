# Design System & UI/UX Specification

---

## 1. Design Philosophy & Overall Aesthetic
- **Primary Mood & Brand Archetype**: Clean, minimalist e-commerce catalog featuring interior design and furniture products. The archetype is modern retail / homeware curation.
- **Visual Density**: Clean, airy layout with generous padding and clear hierarchical separation between promotional headers, product grid listings, and category carousels.
- **Whitespace Balance**: High whitespace ratio; structural elements use contained whitespace grids (standard 16px/24px gutters) to emphasize individual product photography.
- **Theme Balance**: Strictly light mode (`#FFFFFF` background canvas with `#0F172A` primary text and neutral slate surface accents).

---

## 2. Color Palette & Design Tokens

- **Primary Color (Brand Green)**: Default `#166534` (Tailwind `green-800`), Hover `#14532D` (`green-900`), Active `#052E16` (`green-950`).
- **Secondary & Accent Colors**: Charcoal (`#0F172A`), Warm Gray (`#F8FAFC`), Border Gray (`#E2E8F0`).
- **Base Background**: `#FFFFFF`
- **Surface Backgrounds**: Card containers (`#F8FAFC`), Dropdowns/Modals (`#FFFFFF`), Promotional Banner background (`#F1F5F9`).
- **Border & Divider Colors**: `#E2E8F0` (Default), `#CBD5E1` (Hover/Focus).
- **Text Colors**: Primary (`#0F172A`), Muted (`#64748B`), Inverse (`#FFFFFF`), Accent (`#166534`).

## 3. Typography System & Hierarchy
- **Font Families**: Sans-serif system stack (`Inter`, system-ui, `-apple-system`, sans-serif).
- **Scale Breakdown**:
  - **H1 (Page Title)**: `1.5rem` (24px), font-weight: `700`, line-height: `1.2`, tracking: `-0.025em`.
  - **H2 (Section Heading)**: `1.25rem` (20px), font-weight: `600`, line-height: `1.3`, tracking: `-0.015em`.
  - **Body Copy**: `0.875rem` (14px), font-weight: `400`, line-height: `1.5`, tracking: `0`.
  - **Micro / Captions**: `0.75rem` (12px), font-weight: `500`, line-height: `1.4`, tracking: `0.025em`.

---

## 4. Layout Architecture & Spatial Grid
- **Container Max-Width**: Fluid container constrained at `1280px` max-width with responsive horizontal padding (`1rem` mobile, `2rem` desktop).
- **Padding & Margin Scale**: Base unit `4px`. Scales used: `4px`, `8px`, `12px`, `16px`, `24px`, `32px`, `48px`.
- **Section Sequence**:
  1. Top Navigation & User Utility Bar
  2. Promotional Hero / Feature Grid Showcase
  3. Filter & Category Bar (`Explore Categories & Seating Options`)
  4. Product Grid Catalog (Multi-column responsive card layout)

---

## 5. AI Design Traits, Micro-Badges & Special Glyphs
- **Badges**: Pill badges use uppercase, tracking `0.05em`, font-weight `600`, font-size `11px`, border-radius `9999px`.
- **Symbols**: Use clean HTML entities for decorative indicators (`&bull;` for status dots, `&mdash;` for dividers).

```html

  &bull; Featured Product
</span>
```

## 8. Accessibility (a11y) & WCAG Contrast Audit
- **Text Contrast Ratios**:
  - Primary text (`#0F172A`) on base white background (`#FFFFFF`) exceeds **14.5:1** (Passes WCAG AAA).
  - Muted text (`#64748B`) on base white background exceeds **4.6:1** (Passes WCAG AA).
  - Primary button text (`#FFFFFF`) on brand green (`#166534`) exceeds **7.1:1** (Passes WCAG AAA).
- **Focus Rings**: All interactive elements must implement clear focus visibility:
```css
:focus-visible {
  outline: 2px solid #166534;
  outline-offset: 2px;
}
```
