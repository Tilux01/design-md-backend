# Design System Specification: "Coders" Management Dashboard

This document provides the exact design specifications for replicating the "Coders" Management Dashboard shown in the reference image. The layout is designed for a modern desktop/tablet viewport, treated as a full-screen application.

---

## 1. Global Styles & Typography

### Fonts
*   **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
*   **Fallback Font:** Arial, sans-serif
*   **Weights Used:** Regular (400), Medium (500), Semi-Bold (600), Bold (700)

### Color Palette (Monochrome & Glassmorphism)
*   **Background (Canvas):** `#E5E7EB` (Light gray surrounding the glassmorphic card)
*   **App Background (Glass Card):** Semi-transparent white/gray (`rgba(255, 255, 255, 0.75)` with backdrop blur `blur(20px)`)
*   **Pure White:** `#FFFFFF` (Card surfaces, pill buttons)
*   **Pure Black:** `#000000` (Dark UI blocks, active states, text highlights)
*   **Text Primary:** `#111827` (Headings, main labels)
*   **Text Secondary / Muted:** `#6B7280` (Subheadings, inactive nav items, timelines, metadata)
*   **Borders / Dividers:** `#E5E7EB` or `rgba(0, 0, 0, 0.06)`

---

## 2. Layout Structure & Grid

The dashboard is structured into a full-screen layout divided into three primary vertical sections:
1.  **Left Sidebar (Navigation):** Fixed width (~220px), houses the brand, navigation links, and user profile.
2.  **Top Bar / Header:** Spans the main content area, containing search, quick actions, time/weather widgets, and notification icons.
3.  **Main Content Area (Bento Grid):** A flexible multi-card layout containing:
    *   **Row 1:** Project Timeline / Gantt chart widget (left) + Ongoing Projects / Sales Trend (middle) + File Preview / 3D Render widget (right).
    *   **Row 2:** All Files list widget (left) + Team / Department Progress cards (right).

---

## 3. Component Specifications

### A. Left Sidebar
*   **Background:** Solid white (`#FFFFFF`) or slightly tinted glass surface.
*   **Logo:** "Coders" text accompanied by a stylized 'C' icon at the top (`x: 24px`, `y: 24px`).
*   **Navigation Items:** Vertical list with icon + text labels.
    *   *Icons:* Home, Schedule, Projects (Active - highlighted with a pill-shaped black background `#000000` and white text), Analytics/Reports (three repeat project rows).
    *   *Inactive State:* Icon and text in `#6B7280`, font weight 400.
    *   *Active State:* Background `#000000`, text `#FFFFFF`, rounded pill shape (`border-radius: 9999px`).
*   **User Profile (Bottom):** Circular avatar image of "Ann Kowalski", name label, and settings gear icon.

### B. Header / Top Bar
*   **Title Section:** "Management" (Font size ~28px, Bold, `#111827`) with current date sub-label ("JUNE 1, 2023").
*   **Quick Action Pills:**
    *   "Video call" button with camera icon (dark background `#000000`, white text).
    *   Time & Weather widget ("14:20", "23° Sunny") in a rounded capsule.
*   **Search Bar:** Rounded input field with magnifying glass icon and placeholder text `"Type searching..."`.
*   **Utility Icons:** Notification bell and message icon with unread indicator dot.

### C. Widget 1: Project Timeline (Gantt Chart)
*   **Container:** White card with rounded corners (`border-radius: 16px`).
*   **Left Axis Categories:** Design, Mobile Apps, Infography, Wireframes, Team Management.
*   **Timeline Axis (Horizontal):** 1 PM, 2 PM, 3 PM, 4 PM, 5 PM, 6 PM, 7 PM, 8 PM.
*   **Bars:** Rounded black capsule bars spanning specific hour ranges (e.g., "about 2 hours", "about 5 hours"). Some bars include collaborator avatars embedded inside.

### D. Widget 2: Ongoing Projects (Sales Trend)
*   **Header:** "Ongoing projects" with subtitle "Sales trend".
*   **Metric:** "68,5%" large bold typography, accompanied by subtitle "Compared to last month".
*   **Chart:** Smooth dual-line wave graph tracking trend metrics.
*   **Legend List:** Finance (`14.500`), Design Reviews (`15.200`), Other (`00,00`).

### E. Widget 3: File Preview
*   **Container:** Dark card (`background: #000000`, text `#FFFFFF`, rounded corners).
*   **Header:** "File Preview" with file options icon.
*   **Main Visual:** An abstract 3D monochrome metallic/liquid sphere floating against a dark backdrop (Described in Section 4).
*   **Footer:** File name (`"Vint_In_Scope.mp4"`, timestamp `"23-08, 01"`), and assigned user avatar with name ("Marta Adams").

### F. Widget 4: All Files List
*   **Header:** File folder icon + "All files" title + grid toggle icon.
*   **List Items:** Pill-shaped rows containing a small file-type icon and document name:
    *   `Licence on Figma templates.pdf`
    *   `Devinspire_UI-Kit.fig`
    *   `Devinspire redesign.word`
    *   `National Bank.fig`

### G. Widget 5: Team / Department Progress
*   **Header:** "Team" with badge count.
*   **Sub-cards (UX UI Design & Marketing & Development):**
    *   Dark/Black containers with thumbnail previews of abstract liquid wave backgrounds.
    *   Team member overlapping circular avatars.
    *   Progress tracking metrics and mini charts (bar charts for Development).

## 4. Image & Graphic Assets Description

Since specific raster/3D assets cannot be dynamically generated via code, use placeholders or high-quality image URLs matching these descriptions:

1.  **User Avatars:** Circular portrait photos of professionals (diverse genders, clean studio lighting, monochrome or neutral tones preferred to match the UI).
2.  **File/Brand Icons:** Minimalist vector line icons representing folders, search, video, calendar, home, settings, notifications, and document types (PDF, Figma, Word).
3.  **3D Visual Asset (File Preview Widget):** A high-contrast, monochrome 3D render of an organic, liquid-like metallic sphere suspended in space with soft lighting and glossy reflections against a pitch-black background.
4.  **Abstract Background Graphics (Team Cards):** Dark, silky, fluid abstract wave patterns with glossy monochrome gradients (`#000000` to dark charcoal grays).
