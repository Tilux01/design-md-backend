This document outlines the design tokens, typography, color palette, and component specifications required to build an exact, full-screen UI clone of the provided mobile app interface.

---

## 1. Global Layout & Structure

*   **Platform:** Mobile (iOS / Android)
*   **Layout Style:** Full-screen views (No device mockup frames, container shadows, or external background backdrops included).
*   **Border Radius (Containers):** 
    *   Bottom Sheet / Product Detail Panels: `32px` (top-left and top-right corners).
    *   Card / Thumbnail Elements: `12px` to `16px`.
*   **Spacing / Padding:** 
    *   Horizontal Screen Padding: `24px`

## 2. Color Palette

The interface uses a rich, monochromatic terracotta/brick-red color scheme with high-contrast white text and deep shadow overlays.

### Primary Colors
*   **Background / Base:** `#7A3225` (Deep terracotta red)
*   **Surface / Dark Card:** `#561D15` (Deep dark brick red for bottom info cards and image sections)
*   **Surface / Elevated Card:** `#68251B` (Mid-tone red for secondary containers)

### Accent & Text Colors
*   **Text Primary (High Emphasis):** `#FFFFFF` (Pure White)
*   **Text Secondary (Medium Emphasis):** `#D1A59E` (Muted pinkish-beige for descriptions and labels)
*   **Button Primary / CTA:** `#C8634B` (Warm terracotta orange-red)
*   **Button Text:** `#FFFFFF` (Pure White)
*   **Icon / Action Elements:** `#FFFFFF` (White)

### Color Swatches (Product Variations)
*   **CG (Concrete/Grey):** `#A3A09E`
*   **OG (Olive Green):** `#626B52`
*   **SY (Yellow/Mustard):** `#D4BC4C`
*   **W (White):** `#EAE5E0`
*   **R (Red/Brick):** `#A85A48`

    *   Size: `12px`

## 4. Component Specifications

### A. Navigation & Top Bar
*   **Back Button:** 
    *   Shape: Rounded square (`8px` radius)
    *   Background: Semi-transparent white (`rgba(255, 255, 255, 0.15)`)
    *   Icon: Left chevron (`<`), Size: `16px`, Color: `#FFFFFF`
*   **Page Indicator / Dots:** 
    *   Active/Inactive dot indicators positioned at the top right of the media view.

### B. Product Image / Media View
*   **Aspect Ratio:** Edge-to-edge photography with immersive background color matching the product tone.
*   **Horizontal Image View (Technical Details Screen):**
    *   Cropped horizontal banner style displaying the top connection/stem of the pendant light against the background color.

### C. Bottom Product Card (Screen 1)
*   **Background:** `#561D15`
*   **Padding:** `24px` (Top, Left, Right), `32px` (Bottom)
*   **Content Stack:**
    1.  Category label (`SUSPENSION`)
    2.  Product Title (`Aplomb - Brick Red`)
    3.  Body description text (3 lines)
    4.  Price (`€ 315.00`)
    5.  Action Row: 
        *   Primary Button: **"ADD TO BAG"** (Pill shape, `#C8634B` background, centered text).
        *   Secondary Icon Button: Circular background with right arrow icon (`>`).

### D. Technical Details & Specifications (Screen 2)
*   **Header:** Title `Technical Details` centered with a back button on the left.
*   **Product Header:** `Aplomb - Brick Red` (`22px`, Bold).

    *   **MATERIAL:** Label (`11px`, Uppercase) + Value (`14px`, `#FFFFFF`).

### E. Product Gallery Bottom Sheet (Screen 2)
*   **Background:** `#561D15`
*   **Header:** "Product Gallery" (Left aligned), "15 Photos" (Right aligned, Muted text), Up caret indicator (`^`) centered above.
*   **Thumbnail Grid:** 
    *   2 columns of image cards.
    *   Border Radius: `12px` per thumbnail.
    *   Gap: `12px`.

---

## 5. Interaction States
*   **Buttons:** Slight opacity reduction (`0.9`) on active press state.
*   **Color Swatches:** Active swatch displays a crisp inner or outer indicator ring.
