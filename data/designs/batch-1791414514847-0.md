# Cyberpunk Glassmorphic Crypto Wallet & Analytics UI

This design specification document outlines the complete architectural layout, typography, visual styles, components, and animations needed to build an exact, high-fidelity, full-screen clone of the dark-mode crypto wallet application.

---

## 1. Global Visual System & Theme

### 1.1 Color Palette

The interface uses a futuristic, deep-space dark aesthetic featuring glassmorphism, neon glows, and highly-saturated accents against high-contrast dark backgrounds.

#### Background Gradients
*   **Primary App Background**: Radial gradient originating from the top-center to create depth.
    *   *CSS*: `radial-gradient(circle at top, #0A1128 0%, #030712 100%)`
*   **Ambient Glow Elements**: Giant, highly blurred decorative background blobs.
    *   *Primary Glow Blue*: `rgba(59, 130, 246, 0.15)` with `filter: blur(120px)`
    *   *Secondary Glow Purple/Indigo*: `rgba(99, 102, 241, 0.12)` with `filter: blur(100px)`

#### UI Element Colors
| Element | Hex Code / RGBA | Role / Usage |
| :--- | :--- | :--- |
| **Electric Cyan** | `#00F0FF` | Primary active actions, highlight strokes |
| **Neon Blue** | `#3B82F6` | Primary accents, interactive states, glows |
| **Base Glass Fill** | `rgba(15, 23, 42, 0.45)` | Base card background |
| **Base Glass Stroke**| `rgba(255, 255, 255, 0.08)` | Card borders |
| **Text Primary** | `#FFFFFF` (100% Opacity) | Major headers, values, active tab text |
| **Text Secondary** | `#94A3B8` (Cool Gray 400) | Labels, inactive tabs, dates |
| **Trend Up (Green)** | `#10B981` | Positive changes, growth indicators |
| **Trend Down (Red)** | `#EF4444` | Negative changes, dip indicators |

---

### 1.2 Typography
To maintain clean legibility with a futuristic technical aesthetic, use a modern sans-serif typeface combined with high-readability geometric monospace elements for numerals.

*   **Primary System Font**: `Inter`, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `Helvetica`, `Arial`, `sans-serif`.
*   **Monospace Numerals Font** (for balances, percentages, ticks): `JetBrains Mono`, `"SF Mono"`, `Fira Code`, `monospace`.

```css
/* Core text styling variables */
--font-sans: 'Inter', -apple-system, sans-serif;
--font-mono: 'JetBrains Mono', monospace;
```

#### Typography Scale
*   **Display Value (Balance)**: `36px` | Bold (`700`) | Monospace | Tracking: `-0.02em` | Blue Glow Filter
*   **Section Header**: `18px` | Semi-Bold (`600`) | Sans-serif | Tracking: `0.01em`
*   **Body / Regular**: `14px` | Medium (`500`) | Sans-serif
*   **Labels / Captions**: `12px` | Regular (`400`) | Sans-serif | Color: Text Secondary

---

### 1.3 Glassmorphic Styling Specs

All cards, headers, and bottom navigation bars utilize a unified glassmorphism CSS architecture:

```css
.glass-card {
  background: rgba(15, 23, 42, 0.45);
  backdrop-filter: blur(16px) saturate(180%);
  -webkit-backdrop-filter: blur(16px) saturate(180%);
  border: 1px solid rgba(255, 255, 255, 0.08);
  border-radius: 24px;
  box-shadow: 0 8px 32px 0 rgba(0, 0, 0, 0.37);
}
```

This global nav bar anchors both screen states. It sits absolutely at the bottom of each view canvas.

```css
.bottom-nav {
  position: absolute;
  bottom: 0;
  left: 0;
  right: 0;
  height: 80px;

  justify-content: space-around;
  align-items: center;

```

### 4.1 Navigation Elements
*   **Standard Tabs (Home, Analytics, Wallet, Settings)**:
    *   SVG Icon (Width: `24px` | Height: `24px`).
    *   *Active state*: Icons utilize bright `#00F0FF` SVG stroke elements with clean drop-shadow reflections below.
    *   *Inactive state*: Icons utilize `#64748B` slate icon styles.
*   **Center Action Button (Floating Highlight)**:
    *   Positioned directly in the middle or offset depending on custom flow.
    *   Structure: Perfect circle (`56px` diameter).
    *   **Background**: Radial/Linear Gradient combo (`#00F0FF` merging into `#3B82F6`).
    *   **Outer Glow**: Strong visual ambient drop shadow:
        ```css

        }
        ```

    *   **Icon**: Clean centered `+` sign or custom circular transfer arrow icon in deep absolute dark navy (`#030712`).

## 5. UI Micro-interactions & Animations

To bring the cyberpunk interfaces to life, apply these lightweight micro-interactions:

### 5.1 Card Shimmer Hover (CSS Gradient Mask)
Hovering over glass components triggers a subtle diagonal reflection shine running left-to-right across the border.
```css
@keyframes glass-shimmer {
  0% { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}

.glass-card:hover {
  background: linear-gradient(
    120deg,
    rgba(15, 23, 42, 0.45) 30%,
    rgba(255, 255, 255, 0.1) 40%,
    rgba(15, 23, 42, 0.45) 50%
  );
  background-size: 200% 100%;
  animation: glass-shimmer 1.5s infinite linear;
}
```

### 5.2 Dynamic Bar Chart Entry
Upon screen transition, chart bar items scale upwards sequentially using CSS `transform-origin: bottom` and staggered animation delays:
```css
@keyframes grow-bar {
  from { transform: scaleY(0); }
  to { transform: scaleY(1); }
}

.chart-bar {
  transform-origin: bottom;
  animation: grow-bar 0.8s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}

.chart-bar:nth-child(1) { animation-delay: 0.1s; }
.chart-bar:nth-child(2) { animation-delay: 0.2s; }
.chart-bar:nth-child(3) { animation-delay: 0.3s; }
.chart-bar:nth-child(4) { animation-delay: 0.4s; }
.chart-bar:nth-child(5) { animation-delay: 0.5s; }
```
