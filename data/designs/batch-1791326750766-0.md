# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Dark Mode Glassmorphism & Neo-Skeuomorphic UI Components.
- **Visual Density & Whitespace Ratio**: Generous internal card padding, spacious margins, and centered spatial balance focused entirely on high-impact micro-interaction surfaces.
- **Surface Elevation Model**: Multi-layered depth via deep dark gradients (`#0d0c11` to `#16151f`), subtle 1px transluscent top/side borders (`rgba(255,255,255,0.08)`), multi-stage backdrop filters (`blur(24px)`), and expansive, colored ambient drop-shadows (red error aura vs. green success aura).

- **AI Visual Traits**: Multi-layered glassmorphic cards, 3D skeuomorphic glass spheres containing glowing SVG/raster icons, bottom gradient fades on cards, double action button configurations.

## Copyable Component JSX Blueprints
```jsx
import React from 'react';

export function ToastNotificationCard({ type = 'error', title, description, primaryAction, secondaryAction }) {
  const isError = type === 'error';
  
  return (
    <div className={`relative flex flex-col items-center justify-between w-[380px] h-[480px] p-8 rounded-[28px] bg-gradient-to-b from-[#16151f] to-[#0e0d13] border border-white/10 backdrop-blur-2xl shadow-2xl overflow-hidden ${isError ? 'shadow-[0_0_60px_rgba(239,68,68,0.12)]' : 'shadow-[0_0_60px_rgba(16,185,129,0.12)]'}`}>
      
      {/* Bottom Glow Gradient Reflection */}
      <div className={`absolute bottom-0 left-0 right-0 h-40 pointer-events-none opacity-40 bg-gradient-to-t ${isError ? 'from-red-600/30 via-red-600/5' : 'from-emerald-600/30 via-emerald-600/5'} to-transparent`} />

      {/* 3D Glass Sphere Graphic */}
      <div className="relative flex items-center justify-center w-36 h-36 mt-4">
        <div className={`absolute inset-0 rounded-full blur-xl opacity-50 ${isError ? 'bg-red-500/20' : 'bg-emerald-500/20'}`} />
        <div className="relative w-full h-full rounded-full bg-gradient-to-br from-white/20 via-white/5 to-black/80 border border-white/20 backdrop-blur-md flex items-center justify-center shadow-inner">
          {/* Inner Icon */}
          <div className={`w-12 h-12 flex items-center justify-center rounded-full ${isError ? 'text-red-400 drop-shadow-[0_0_12px_rgba(239,68,68,0.8)]' : 'text-emerald-400 drop-shadow-[0_0_12px_rgba(16,185,129,0.8)]'}`}>
            {isError ? (
              <svg className="w-8 h-8" fill="none" stroke="currentColor" strokeWidth="3" viewBox="0 0 24 24"><path strokeLinecap="round" strokeLinejoin="round" d="M6 18L18 6M6 6l12 12"/></svg>
            ) : (
              <svg className="w-8 h-8" fill="none" stroke="currentColor" strokeWidth="3" viewBox="0 0 24 24"><path strokeLinecap="round" strokeLinejoin="round" d="M5 13l4 4L19 7"/></svg>
            )}
          </div>
        </div>
      </div>

      {/* Content Section */}
      <div className="text-center z-10 my-auto">
        <h3 className="text-xl font-semibold text-white tracking-tight mb-2">
          {title}
        </h3>
        <p className="text-sm text-slate-400 max-w-[280px] mx-auto leading-relaxed">
          {description}
        </p>
      </div>

      {/* Action Buttons */}
      <div className="grid grid-cols-2 gap-3 w-full z-10 mt-4">
        <button className="w-full py-3 px-4 rounded-xl bg-white text-slate-950 font-medium text-sm hover:bg-slate-100 active:scale-95 transition-all shadow-lg">
          {primaryAction}
        </button>
        <button className="w-full py-3 px-4 rounded-xl bg-white/[0.06] hover:bg-white/[0.12] text-white font-medium text-sm border border-white/10 active:scale-95 transition-all backdrop-blur-md">
          {secondaryAction}
        </button>
      </div>
    </div>
  );
}
```
