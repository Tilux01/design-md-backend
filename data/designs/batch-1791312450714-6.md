# Design Specification: Nestive Smart Home Web Application

---

## 1. Design Philosophy & Overall Aesthetic
* **Primary Mood & Archetype:** Futuristic, minimal, luxurious, and human-centric. The platform positions home automation as seamless, organic, and effortlessly sophisticated.
* **Visual Density:** Airy, spacious, and deliberate. High emphasis on horizontal breathing room and asymmetric weight distribution (balancing heavy 3D structural elements with delicate typography).
* **Theme Balance:** Monochromatic soft sage-gray background (`#89948D`) paired with high-contrast milky off-white typography (`#F7F8F7`) and warm amber interior illumination highlights (`#FFC875`).

---

## 2. Color Palette & Design Tokens

### Core Semantic Colors
* **Primary (Accent):** `#FFFFFF` (White action fills)
* **Secondary / Warm Light:** `#FFC875` (Interior glow / Active indicators)
* **Muted Text / Secondary:** `#D0D6D2` (Subtitles, nav links)

### Surfaces & Backgrounds
* **Base Canvas Background:** `#89948D` (Muted soft sage)
* **Card Surface (Glassmorphism / Frosted):** `rgba(255, 255, 255, 0.08)`
* **Card Surface Border:** `rgba(255, 255, 255, 0.15)`
* **Backdrop Blur:** `blur(16px)`

### Borders & Dividers
* **Subtle Dividers:** `rgba(255, 255, 255, 0.12)`
* **Focus Rings:** `#FFFFFF` (1px solid with outer glow)

---

## 3. Typography System & Hierarchy

### Font Families
* **Headings / Display:** Serif (Playfair Display / Editorial Serif style), `font-weight: 400`
* **Body / Navigation / UI:** Sans-Serif (Inter / SF Pro style), `font-weight: 300` - `400`

### Scale Breakdown
* **Display / Hero Title (`<h1>`):**
  * Font Size: `64px` / `4rem`
  * Line Height: `1.05`
  * Letter-spacing: `-0.02em`
  * Weight: `400` (Serif italicized accents)
* **Subtitle / Lead Paragraph (`<p>`):**
  * Font Size: `16px` / `1rem`
  * Line Height: `1.5`
  * Letter-spacing: `0`
  * Weight: `300`
* **Navigation Links (`<a>`):**
  * Font Size: `14px` / `0.875rem`
  * Line Height: `1.2`
  * Letter-spacing: `0.01em`
  * Weight: `400`
* **Step Labels (`.step-label`):**
  * Font Size: `13px`
  * Weight: `400`
  * Uppercase / Sentence-case tracking: `0.05em`

---

## 4. Layout Architecture & Spatial Grid

### Container & Grid Structure
* **Max-Width:** `1440px` (Centered with fluid horizontal padding)
* **Horizontal Padding:** `80px` (Desktop)
* **Vertical Padding:** `40px` (Header top spacing)

### Section Sequence Breakdown
1. **Global Header:** Fixed/Sticky top navigation with logo, anchor links, language selector, search, and hamburger menu.
2. **Hero Core Left:** Social proof avatar stack, main value proposition (`<h1>`), secondary explanatory copy (`<p>`), and primary CTA button (`"CONNECT YOUR SPACE"`).
3. **Hero Core Right:** Interactive 3D structural model showcasing real-time interior lighting and modular layout.
4. **Onboarding / Step Navigation:** Bottom sequence bar (`01 Register`, `02 Add Devices`, `03 Customize`, `04 Start Using`).

---

## 5. Component Blueprint & Element Placement

### Global Navigation
* **Logo:** Left-aligned, vector home icon with clean text `"Nestive"`.
* **Nav Links:** Center-aligned cluster (`Home`, `Features`, `Devices`, `Support`, `Login`) separated by subtle bullet points (`•`).
* **Utility Icons:** Right-aligned language dropdown (`EN`), search glass icon (`🔍`), and hamburger menu (`☰`).

### Social Proof Avatar Stack
* **Layout:** Overlapping circular avatars (`width: 32px`, `height: 32px`, `border: 2px solid #89948D`).
* **Text:** `" +10,000 people are already using 'Nestive' "` in 12px muted text adjacent to avatars.

### Primary CTA Button ("CONNECT YOUR SPACE")
* **Shape:** Pill / Rounded Rectangle (`border-radius: 32px`).
* **Padding:** `16px 28px`.
* **Background:** Solid White (`#FFFFFF`).
* **Text Color:** Charcoal/Dark (`#1E2220`).
* **Icon:** Circular dark badge with abstract spark/star icon on the left.

### Step Cards (Bottom Navigation)
* **Layout:** 4-column horizontal grid.
* **Dimensions:** `height: 80px`, flex-row with icon on left and label on right.
* **Border:** Thin frosted white border (`1px solid rgba(255, 255, 255, 0.2)`).
* **Border Radius:** `12px`.
* **Active Indicator:** Subtle bottom progress tick for current step (`01`).

---

## 6. Motion Mechanics & Interactions

* **Hover Transitions:** `cubic-bezier(0.16, 1, 0.3, 1)` with `duration: 300ms` for all button elevations and color shifts.
* **3D Isometric Model:** Floating vertical parallax loop with subtle z-axis translation (`transform: translateY(-8px)` on an 8-second infinite sine wave).
* **Lighting Effects:** Real-time opacity pulses on interior window elements (`#FFC875`) simulating active smart-home routines.
