# Design Specification: Tenista - Tennis Training Platform

## 1. Global Styles & Design Tokens

### Color Palette
- **Background (Light):** `#F4F5F7` (Off-white / light neutral gray)
- **Primary Text & Headers (Dark):** `#0C1017` (Near black)
- **Hero Blue Overlay / Brand Blue:** `#1B4A8F` with gradient fade to lighter electric blue (`#4C8EEB`)
- **Accent / Highlight:** `#D9E2EC` (Subtle UI borders and cards)
- **White:** `#FFFFFF` (Card backgrounds, header text)
- **Dark UI Elements (Buttons/Cards):** `#111111` with high blur backdrop filters (`backdrop-filter: blur(16px)`)

### Typography
- **Primary Sans-Serif Font:** `Inter`, `SF Pro Display`, `-apple-system`, `sans-serif`
- **Headline Font (Bold, Serif/Grotesque Display):** `Clash Display`, `Syne`, or heavy weight `Inter` (900 weight used for massive hero typography: "MOVE FASTER").
- **Fallback Stack:** `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif`

## 3. Micro-Interactions & Animation Specifications (Framer Motion / CSS)

1. **Hero Entry Animation:**
   - Background image scales down slightly from `1.05` to `1.0` with a smooth ease-out.
   - Text elements (`MOVE FASTER`, `GAME ON, PLAY HARD`) fade up with a `y: 30` to `0` offset over `0.8s`.
2. **Floating Glass Cards:**
   - Continuous gentle floating keyframe animation (`translateY` oscillating between `-6px` and `6px` over `4s` infinite).
3. **Carousel / Tilt Card Interactions:**
   - The central instructor card features a subtle 3D tilt effect following mouse movement (`perspective: 1000px`, `rotateX`, `rotateY`).
4. **Interactive Buttons:**
   - All circular arrow buttons (`<` and `>`) scale to `1.08` on hover with a smooth transition.
