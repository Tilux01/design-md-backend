# Design System Specification: "We Build Digital" Ethereal Glassmorphism Landing Page

---

## 1. Overview & Visual Direction

This document details the visual styling, component architecture, layout structure, typography, and asset specifications to create a pixel-perfect, full-screen clone of the provided landing page.

- **Design Philosophy**: Minimalist, high-end editorial UI combined with tactile 3D elements, frosted glassmorphism, and subtle analog film grain.
- **Viewport Target**: Fullscreen (`100vw` × `100vh`), borderless, edge-to-edge layout without presentation frames or outer shadows.
- **Key Visual Phenomenon**: A semi-transparent frosted-glass pane splits the screen vertically down the middle-left (~48% width). The hairy 3D purple torus sits behind this pane, causing its left half to be heavily blurred and diffuse, while its right half remains crisp and in sharp focus.

  * `background: rgba(255, 255, 255, 0.08)`

  * An absolute full-screen overlay at `pointer-events: none; z-index: 999;`

## 3. Typography System

### 3.1 Primary Typeface Families
* **Display Headline Font**: **Gilroy ExtraBold** or **Syne Bold**
  * *Primary Fallbacks*: `Poppins` (Bold/ExtraBold, 800), `Outfit` (Bold, 800), `Montserrat` (ExtraBold, 800).

  * *Font Weights*: Regular (400), Medium (500), SemiBold (600).

## 4. 3D Visual Asset Specification

### 4.1 Description of the 3D Asset
* **Asset Type**: High-resolution, transparent-background PNG / WebP or Realtime WebGL Mesh (Three.js/Spline).
* **Shape**: A smooth geometric Torus (doughnut-shaped ring) with an open center.
* **Surface Treatment**: Dense, fur-like / hair-particle system ("fuzzy velvet"). Strands radiate outward from the outer perimeter and inward toward the center hole, creating a soft, tactile, dandelion/fluffy carpet look.
* **Coloration**:
  * Outer and inner fringe: Vibrant violet-magenta (`#9B32E8`).
  * Body thickness: Deep rich royal purple (`#6613A8`).
* **Placement & Sizing**:
  * **Position**: Horizontally centered slightly right of middle (`left: 55%`, `top: 50%`, `transform: translate(-50%, -50%)`).
  * **Size**: Diameter is approximately `55vw` to `60vw` (roughly `600px` to `750px` on desktop displays).
  * **Layering**: Sits physically **behind** the Left Frosted Glass Layer and **behind** all UI text, but **above** the base purple gradient background.

## 5. Screen Layout & Component Structure

### 5.1 Root Architecture
```
[ Viewport: 100vw x 100vh ]
 ├── [ Layer 0: Base Lilac Background (#C3AEDA) ]
 ├── [ Layer 1: Centered-Right 3D Furry Torus Asset ]
 ├── [ Layer 2: Left Glass Panel (Width: 48vw, Backdrop Blur: 28px) ]
 ├── [ Layer 3: Foreground UI Elements (Z-Index: 10) ]
 │    ├── Header (Logo, Nav Items, Hamburger)
 │    ├── Left Hero Content (Headline, Tagline, Button)
 │    ├── Slider Controls (< >)
 │    └── Bottom Right Social Icon Group
 └── [ Layer 4: Global Film Grain Overlay (Z-Index: 999) ]
```

## 6. Detailed Component Specifications

### 6.1 Top Navigation Bar
* **Position**: Fixed/Absolute at `top: 0; left: 0; width: 100%; height: 100px;`
* **Padding**: `0 4.5rem` (scaled to `2rem` on tablet/mobile).
* **Components**:
  1. **Logo (Top-Left)**:
     * Graphic icon constructed of solid white circular dots in a rounded diamond/cross matrix (5 columns: 1 dot, 3 dots, 5 dots, 3 dots, 1 dot; dot size: `4px`, gap: `3px`).
     * Vertically aligned at `top: 2.8rem; left: 4.5rem`.
  2. **Navigation Links (Top-Right)**:
     * Positioned at the top right, starting around `right: 8rem`.
     * Items: `Home` &nbsp;&nbsp;|&nbsp;&nbsp; `About us` &nbsp;&nbsp;|&nbsp;&nbsp; `Portfolio`
     * Gap: `2.2rem` between items.
     * Color: `#FFFFFF`, opacity `0.9`. No underlines.
  3. **Hamburger Menu Icon**:
     * Positioned at the extreme top-right (`right: 4.5rem`).
     * Structure: 3 horizontal white bars.
     * Dimensions: Width `24px`, bar height `2px`, vertical spacing between bars `5px`.

---

### 6.2 Left Hero Section (Glass Overlaid)
* **Container**: Anchored on the left half of the screen.
* **Padding**: Left margin `4.5rem`, vertically aligned around `top: 38%`.

#### A. Main Headline
* **Text**:
  ```text
  We
  Build
  Digital
  ```
* **Layout**: Stacked across 3 distinct lines with tight leading.
* **Color**: `#FFFFFF`.
* **Font**: ExtraBold Geometric Sans, `line-height: 0.92`.
* **Drop Shadow**: None; sharpness creates high contrast against the blurred purple backdrop.

#### B. Tagline / Subtitle
* **Text**: `We Design | We Develop | We Inspire.`
* **Position**: `2.2rem` below the word "Digital".
* **Color**: `#FFFFFF` with `0.85` opacity.
* **Style**: Font size `0.95rem`, font weight `500`. Divider pipes (`|`) have `0.6rem` margin on each side.

#### C. Primary CTA Button ("KNOW MORE")
* **Position**: `1.8rem` below the tagline.
* **Shape**: Sharp-cornered rectangle (`border-radius: 0px`).
* **Dimensions**: Height `38px`, Width approx. `120px` (padding: `0.6rem 1.4rem`).
* **Border**: `1px solid rgba(255, 255, 255, 0.75)`.
* **Background**: `transparent` (fills to `rgba(255, 255, 255, 0.15)` on hover).
* **Text**: `KNOW MORE`, size `0.7rem` (11-12px), uppercase, bold, letter-spacing `0.15em`, color `#FFFFFF`.

---

### 6.3 Slider Pagination Controls (`< >`)
* **Position**: Top-right quadrant, placed in the negative space above the 3D Torus right half.
* **Coordinates**: `top: 38%`, `right: 22%`.
* **Style**:
  * Thin stroke white chevrons: Left arrow `<` and Right arrow `>`.
  * Height: `18px`.
  * Spacing: `24px` horizontal gap between the two chevrons.
  * Color: `rgba(255, 255, 255, 0.85)`.

---

### 6.4 Social Icons Group (Bottom-Right)
* **Position**: Fixed/Absolute at `bottom: 2.5rem; right: 4.5rem;`.
* **Layout**: Horizontal row of 3 square stroked button containers.
* **Gap**: `0.6rem` between icons.
* **Box Dimensions**:
  * Width: `32px`, Height: `32px`.
  * Border: `1px solid rgba(255, 255, 255, 0.55)`.
  * Border-radius: `2px` (nearly sharp with ultra-subtle micro-radius).
  * Background: `transparent`.
* **Icons (from Left to Right)**:
  1. **Instagram**: Standard glyph outline (camera/lens dot).
  2. **Twitter**: Classic Twitter bird silhouette or current X glyph (the image displays the bird outline).
  3. **Facebook**: Lowercase `f` standard logo outline.
* **Icon Size & Color**: Centered inside the box, `14px` height, color `#FFFFFF`.
