# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase navigation links, vertical gridline architectural framing, glowing volumetric background halos, minimalist editorial contrast.
- **Pill Badge Specification**: Padding: 4px 12px, Font-Size: 11px, Font-Weight: 600, Tracking: 0.15em, Border-Radius: 9999px, Background: Transparent, Border: 1px Solid `rgba(255,255,255,0.2)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Grid Indicator Dot (●) -> Use `&#9679;` or `<span className="w-1.5 h-1.5 rounded-full bg-blue-500 inline-block"></span>`.
  - Grid Icon (☷ / ☲) -> Use SVG path grid icon.
