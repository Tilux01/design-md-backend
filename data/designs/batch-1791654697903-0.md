# Comprehensive Design Specification: Fitness Tracking Application Clone

This document serves as the absolute, pixel-precise blueprint to replicate the provided mobile application interface. Every measurement, color code, typographic choice, and structural element is explicitly defined to ensure an exact visual and functional clone.

---

## 1. Global Layout & Canvas Architecture

*   **Platform Target:** iOS (Optimized for iPhone 14/15 Pro form factors with dynamic island and rounded display corners).
*   **Device Frame:** Omit device bezels, frames, and background drop-shadows. The output must be rendered as a **pure full-screen viewport**.
*   **Viewport Dimensions:** 
    *   Width: 390pt (Standard base iPhone viewport)
    *   Height: 844pt
*   **Base Background Color:** 
    *   Hex: `#F8F9FA` (Soft neutral off-white surface canvas)
*   **Layout Structure:** A dual-screen reference display showing two distinct states within the application. Each screen utilizes a standard vertical scrolling layout featuring top navigation bars, card-based component grouping, and bottom tab navigation bars.

---

## 2. Typography System

### Primary Font Family Stack
*   **Primary Font:** **SF Pro Display** / **SF Pro Text** (Native Apple System UI font)
*   **Fallback Font Stack:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`

### Typographic Hierarchy

| Role | Font Weight | Font Size | Line Height | Letter Spacing | Hex Color / Usage |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Top Navigation Title** | Semi-Bold (600) | 17pt / 22pt | 22pt / 28pt | -0.41pt | `#1A1A1A` (Primary headers) |
| **Card Header / Metric Title** | Medium (500) | 13pt | 16pt | -0.08pt | `#4A4A4A` or `#2E5A1C` |
| **Primary Metric Value (Large)** | Bold (700) | 34pt / 42pt | 40pt / 48pt | -0.50pt | `#1A1A1A` or `#3B7A12` |
| **Secondary Data / Labels** | Regular (400) | 11pt / 12pt | 14pt / 16pt | 0.00pt | `#6E6E6E` (Subtitles & axis markers) |
| **Tab Bar Labels** | Medium (500) | 10pt | 12pt | 0.0px | `#8E8E93` (Inactive), `#3B7A12` (Active) |

---

## 3. Color Palette Specifications

*   **Primary Brand Green (Light):** `#D4F0B0` (Used for background tints in featured metric cards)
*   **Primary Brand Green (Vibrant):** `#3B7A12` (Used for active states, high-value data points, and primary highlights)
*   **Muted Green (Bars/Charts):** `#A3D977` (Standard data visualization elements)
*   **Text & UI Dark:** `#1A1A1A` (Primary body text, high-contrast labels)
*   **Text & UI Muted:** `#8E8E93` (Secondary captions, inactive icons, timestamps)
*   **Card Background:** `#FFFFFF` (Pure white containers floating on the off-white canvas)
*   **Card Border / Dividers:** `#E5E5EA` (Subtle 1pt borders or separation lines)
*   **Status Indicators (Red/Coral):** `#FF453A` (Used for alerts, uncompleted states, or secondary metrics)

---

## 4. Screen 1: Dashboard / Summary View (Left Frame)

### 4.1. Top Navigation Bar
*   **Height:** 44pt (excluding status bar)
*   **Left Element:** Profile/User Avatar icon (Circular container holding a silhouette or user image, diameter: 32pt).
*   **Center Element:** Screen Title / Segmented Selector ("Overview" or app logo with dropdown arrow).
*   **Right Element:** Settings / Notification gear icon (Monochrome stroke icon, size: 24x24pt).

### 4.2. Featured Summary Card (Top Hero Component)
*   **Dimensions:** Width: 358pt (16pt side margins), Height: ~120pt.
*   **Border Radius:** 20pt rounded corners.
*   **Background Fill:** Linear Gradient or solid soft green fill (`#D4F0B0` to `#E3F5CE`).
*   **Content Layout:**
    *   Top left: Small category indicator ("Daily Summary" or app badge, 11pt, Medium, `#2E5A1C`).
    *   Center/Left value: Large prominent progress status or remaining metric (e.g., "Goal Reached!", Bold 700, 24pt, `#1A1A1A`).
    *   Right element: Circular SVG progress ring indicator showing completion percentage with an integrated checkmark icon.

### 4.3. Secondary Metrics Grid (Row 1)
*   **Layout:** Two equal-width cards placed side-by-side with 12pt gap spacing.
*   **Card Dimensions:** Width: ~173pt each, Height: ~80pt.
*   **Background:** `#FFFFFF` with 16pt border radius.
*   **Content (Left Card):** Small metric title, numeric value with unit (e.g., "120" / "bpm" or similar vital sign), paired with a small trend line icon.
*   **Content (Right Card):** Secondary vital metric (e.g., calorie burn or active minutes) with corresponding icon.

### 4.4. Activity / Bar Chart Breakdown Module
*   **Dimensions:** Width: 358pt, Height: ~140pt.
*   **Background:** `#FFFFFF`, Border Radius: 20pt, Padding: 16pt.
*   **Header:** Section title ("Activity Level" or "Heart Rate Distribution") on the left; time filter ("Weekly") on the right.
*   **Chart Content:** A series of 7 vertical bar elements representing days of the week.
    *   Bar widths: ~6pt with rounded top caps.
    *   Colors: Standard bars are `#A3D977`; the peak/highlighted bar is colored in vibrant `#3B7A12`.
    *   X-Axis Labels: Single-letter day indicators (`M`, `T`, `W`, `T`, `F`, `S`, `S`) positioned directly beneath each bar in 10pt `#8E8E93` font.

### 4.5. Detailed Metrics List Items (Bottom Sections)
*   **Layout:** Stacked horizontal list rows inside a grouped white container.
*   **Row Structure:**
    *   Left: Category title (e.g., "Sleep Quality", "Recovery Score") + secondary subtitle ("7h 42m - Deep sleep optimal").
    *   Right: Graphical indicator pill (e.g., dual-status indicator dots or a compact horizontal progress bar showing range distribution).
*   **Separation:** Thin 1pt divider line (`#E5E5EA`) between stacked items.

---

## 5. Screen 2: Detailed Analytics View (Right Frame)

### 5.1. Top Navigation Bar
*   **Layout:** Left-aligned back chevron arrow, centered screen title ("Trend" or specific metric name), right-aligned action icon (calendar or share sheet).

### 5.2. Primary High-Level Metric Display
*   **Layout:** Left-aligned stacked text block.
*   **Top Label:** Metric classification ("Total Steps" or equivalent) in 12pt Regular `#6E6E6E`.
*   **Value Line:** Large numeric display (e.g., **"12,345"**) in 36pt Bold `#1A1A1A`, followed inline by the unit ("steps" or "kcal") in 14pt Medium `#8E8E93`.
*   **Comparison Subtext:** Trend indicator (e.g., "+12% from last week") styled with a green upward arrow icon and text in `#3B7A12`.

### 5.3. Main Trend Chart Module (Histogram/Bar Graph)
*   **Dimensions:** Width: 358pt, Height: ~220pt.
*   **Background:** `#FFFFFF`, Border Radius: 20pt.
*   **Visual Structure:**
    *   Vertical bar chart mapping data points across a time series.
    *   Gridlines: 3 faint horizontal dashed guidelines spanning the width of the chart area (`#E5E5EA`).
    *   Bars: Variable heights based on data density. One specific day features an extended peak bar with an exact numerical callout tooltip floating directly above it (e.g., data tag in a small rounded pill).
    *   Color coding: Muted green `#A3D977` for standard bars, vibrant `#3B7A12` for the highlighted peak bar.

### 5.4. Secondary Metric Grid Cards (Bottom Half)
*   **Layout:** 2x2 grid of compact metric cards.
*   **Card Design:**
    *   Background: `#FFFFFF`, Border Radius: 16pt.
    *   Padding: 12pt internal padding.
    *   Structure: Small icon/label at the top-left, primary data value centered or bottom-aligned in bold typography, accompanied by micro-trend badges.

## 6. Bottom Navigation Tab Bar (Present on Both Views)

*   **Position:** Fixed at the absolute bottom of the viewport.
*   **Height:** 83pt (including home indicator safe area spacing).
*   **Background:** `#FFFFFF` with a subtle top border (`0.5pt solid #D1D1D6`). Translucent glassmorphism effect (`backdrop-filter: blur(20px)`).
*   **Tab Items (Left to Right):**
    1.  **Dashboard / Home Icon:** (House silhouette) + "Home" label. (Inactive: `#8E8E93`, Active: `#3B7A12`)
    2.  **Analytics / Trends Icon:** (Line chart icon) + "Trends" label.
    3.  **Action / Record Center:** Central prominent circular button featuring a solid vibrant green background (`#3B7A12`) and a white plus/heart icon, elevated slightly above the tab bar plane.
    4.  **Community / Social Icon:** (User group or chat bubble icon) + "Community" label.
    5.  **Profile / Settings Icon:** (Gear or user profile icon) + "Profile" label.

## 7. Asset & Image Specifications (Non-Code Implementation Guidelines)

*   **User Avatar Images:** 
    *   *Type:* Raster portrait graphic (circular crop).
    *   *State:* Backgroundless frame integration (standard circular mask applied via CSS `border-radius: 50%` or clipping path).
    *   *Placement:* Top-left header of Screen 1.
*   **Icons:** 
    *   All UI iconography (chevrons, settings gear, activity trends, status rings) must utilize standard vector symbol assets (SF Symbols equivalent) rendered in clean monochrome vector paths with precise stroke weights (1.5pt to 2.0pt width).
