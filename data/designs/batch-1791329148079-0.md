# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Clean Enterprise SaaS / Financial Dashboard.
- **Visual Density & Whitespace Ratio**: High-density data presentation balanced with clean structural padding (16px–24px gaps), card isolation, and soft pastel/neutral container fills.
- **Surface Elevation Model**: Flat card layers set against a soft violet-grey canvas. Cards utilize 1px subtle borders (`#E2E8F0` / `#E5E7EB`) with high-contrast foreground text hierarchy and minimal drop-shadows.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-contrast currency metrics, minimalist status icons inside rounded mint-tinted pill badges, segmented analytics tabs, dynamic line charts with gradient fills.
- **Pill Badge Specification**: Padding `4px 10px`, font-size `12px`, font-weight `500`, border-radius `9999px`, background `#ECFDF5`, text `#059669`.
- **Symbol & Glyph Safety Mapping**:
  - Currency symbol (₹) -> Use `&#8377;` or `₹`.
  - Status Dot (●) -> Use `&#9679;`.
