# Design Specification: Financial Dashboard (Neumorphic Style)

## 1. Overview & Layout Architecture
This is a modern, light-themed financial analytics and portfolio management dashboard. It uses a **soft UI (neumorphic/skeuomorphic)** design language with frosted glass effects, subtle drop shadows, and soft gradients.

* **Layout Structure:**
  * **Global Container:** Full-width viewport (`100vw` / `100vh`), light grey background (`#f3f4f6`).
  * **Main Grid:** Two-column split layout:
    * **Left/Main Section (approx. 70% width):** Header, Quick stats overview cards, and a large graphical analytics chart.
    * **Right/Sidebar Section (approx. 30% width):** Cards & Balances overview, virtual card representation, and supplementary metric blocks.
* **Border Radius Strategy:** Extremely rounded elements (`border-radius: 20px` to `28px`) for containers, cards, and buttons to maintain the soft aesthetic.

---

## 2. Typography & Fonts
* **Primary Font Family:** `Inter`, `SF Pro Display`, `Roboto`, `Helvetica Neue`, sans-serif.
* **Fallback Stack:** `sans-serif`
* **Type Hierarchy:**
  * **Page Title ("Dashboard"):** `24px` / Bold / Dark Charcoal (`#1a1a1a`)
  * **Section Headers ("Quick Stats About Your Portfolio", "Cards & Balances"):** `14px` - `16px` / Semi-Bold / Medium Gray (`#4b5563`)
  * **Card Titles ("Bitcoin Balance", "Ethereum Balance", "USDT Returns"):** `12px` / Medium / Light Gray (`#6b7280`)
  * **Primary Monitary Values (Large):** `20px` - `28px` / Bold / Dark Charcoal (`#111827`)
  * **Secondary Values/Labels:** `10px` - `12px` / Regular / Muted Gray (`#9ca3af`)

---

## 3. Color Palette
* **Backgrounds:**
  * App Background: Soft Off-White / Light Gray (`#f4f5f8`)
  * Card Backgrounds: Pure White (`#ffffff`) with subtle alpha transparency or soft inner/outer shadows.
* **Accents & Highlights:**
  * **Orange/Gold (Bitcoin/Primary Accent):** `#f59e0b` transitioning to soft peach (`#fef3c7`).
  * **Pink/Red (Ethereum):** `#ec4899` transitioning to soft pink (`#fce7f3`).
  * **Green (USDT/Growth):** `#10b981` transitioning to soft mint (`#d1fae5`).
  * **Card Gradient (Right Sidebar):** Soft warm peach-to-pink gradient overlaying white (`linear-gradient(135deg, #fff5f0 0%, #fff 100%)`).
* **Text Colors:**
  * Primary Text: `#1f2937`
  * Secondary Text: `#4b5563`
  * Muted Text: `#9ca3af`

---

## 4. Component Breakdown

### A. Top Navigation Bar
* **Left:** Dashboard title.
* **Right:** 
  * Interactive action pills (notification icon, currency switcher, profile avatar).
  * Avatar: Circular user profile image with a glowing border ring.

### B. Quick Stats Cards (Row of 3)
* **Visual Style:** White floating cards with soft drop shadows (`box-shadow: 0 10px 25px -5px rgba(0, 0, 0, 0.05)`).
* **Content per card:**
  1. **Bitcoin Balance:** Orange circular progress/pie graphic representation, label, and value (`$ 3,35,450.00`).
  2. **Ethereum Balance:** Pink circular graphic representation, label, and value (`$ 89,215.00`).
  3. **USDT Returns:** Green circular graphic representation, label, and value (`$ 12,176.00`).
* **Action Element:** A "Global Stats" pill button at the top right of this section.

### C. Main Analytics Section (Chart & Portfolio Valuation)
* **Header:** Total Portfolio Valuation (`$ 1,58,490.00`) with a timeframe dropdown selector ("1M / 3M / 1Y").
* **Graphical Area:** 
  * Multi-colored stacked area chart combining green, orange, and pink gradients fading upwards from the baseline.
  * Interactive tooltip / active marker pinpointing a specific data point on the timeline (e.g., highlighting a specific peak with a dark vertical line and a floating red data tag).
* **X-Axis Labels:** Time intervals (Jan, Feb, Mar, Apr, May, Jun, Jul, Aug, Sep, Oct, Nov, Dec).

### D. Right Sidebar: Cards & Balances
* **Section Header:** "Cards & Balances" with an action button ("+ Add Card").
* **Virtual Card Component:**
  * Glassmorphism / soft gradient card (peach/orange undertones).
  * Displays Balance (`$ 12,449,391.00`), API status, and masked card numbers (`**** **** **** 7020`).
* **Mini Metric Blocks (Grid of 4 small cards below the virtual card):**
  * Soft pastel background tints (peach, light pink, light gray, soft yellow).
  * Each contains a small icon, a metric label (`0.00` / `1.48m`), and a percentage indicator.

---

## 5. Shadows, Elevation, & Depth (Neumorphism Details)
* **Card Elevation:** Use soft, diffused shadows rather than harsh borders.
  * `box-shadow: 0 12px 30px rgba(0, 0, 0, 0.04), 0 1px 3px rgba(0, 0, 0, 0.02);`
* **Interactive States:** Hovering over cards should subtly elevate them further on the Z-axis (`transform: translateY(-2px)`).
