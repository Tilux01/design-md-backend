# UI/UX Specification: SSENSE E-Commerce Product Landing Page

## 1. Global Layout & Canvas

*   **View Mode:** Full-Screen / Edge-to-Edge Responsive Web View (Viewport width: 100vw, height: 100vh).
*   **Background Color:** Pure White (`#FFFFFF`) with subtle radial lighting diffusion behind the central product model.
*   **Grid System:** 12-Column asymmetrical layout.
    *   Left Rail (Navigation & Categories): Columns 1–3
    *   Center Stage (3D/Interactive Product Showcase): Columns 4–9
    *   Right Rail (View controls / Utilities): Columns 10–12 (pinned top-right).
*   **Z-Index Layers:**
    *   `z-index: 0`: Background illumination canvas.
    *   `z-index: 10`: Background blurred/parallax sneaker assets (left and right out-of-focus states).
    *   `z-index: 20`: Navigation bar, category list, main central 3D sneaker asset.
    *   `z-index: 30`: Typography overlay (GUCCI title, pricing, call-to-action).

---

## 2. Typography System

*   **Primary Display Font (Branding & Headings):** `Helvetica Neue`, `Arial Black`, sans-serif.
*   **Body & Navigation Font:** `Inter`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, sans-serif.
*   **Fallback Stack:** `sans-serif` (Universal Web-Safe fallback).

### Type Hierarchy:
1.  **Top Navigation Links (MEN, WOMAN, SSENSE, WISHLIST, BLOG):**
    *   Font Family: `Inter`, sans-serif
    *   Font Weight: 600 (Semi-bold)
    *   Font Size: `12px`
    *   Letter Spacing: `0.1em`
    *   Color: `#111111`
    *   Transform: Uppercase
2.  **Category Menu (ACCESSORIES, BAG, CLOTHING, SHOES):**
    *   Font Family: `Helvetica Neue`, `Arial Black`, sans-serif
    *   Font Weight: 900 (Heavy)
    *   Font Size: `24px` to `32px` (fluid scale)
    *   Color: Light gray outline/stroke style (`#D0D0D0`) for unselected items; Solid Black (`#000000`) for the active item (**SHOES**).
    *   Sub-category (**Sneakers**): Font Size `11px`, Regular weight, `#666666`, underlined/active state.
3.  **Product Title (GUCCI):**
    *   Font Family: `Helvetica Neue`, `Arial Black`, sans-serif
    *   Font Weight: 900
    *   Font Size: `36px`
    *   Letter Spacing: `0.05em`
    *   Color: `#1A1A1A`
    *   Alignment: Center-aligned below the product stage.
4.  **Product Subtitle & Pricing (Crystals Flashtrek Sneakers | 1590$):**
    *   Font Family: `Inter`, sans-serif
    *   Font Weight: 400 (Regular)
    *   Font Size: `13px`
    *   Color: `#777777`
    *   Alignment: Center-aligned below the product title.

---

## 3. Header & Navigation Structure

```
+---------------------------------------------------------------------------------+
|  MEN   WOMAN      SSENSE      WISHLIST   BLOG                     Q   [O]   En  |
+---------------------------------------------------------------------------------+
```

*   **Top Bar:** Fixed sticky position, spanning full width with generous horizontal padding (`40px`).
*   **Left Section:** Menu items (`MEN`, `WOMAN`) spaced evenly.
*   **Center Section:** Brand logotype **SSENSE** rendered in extra-bold extended grotesque typography.
*   **Right Section:**
    *   Wishlist & Blog links.
    *   Search icon (`Q` magnifying glass symbol).
    *   Shopping bag/Cart icon with item count badge (`[O]`).
    *   Language/Locale selector (`En v`).

---

## 4. Left Sidebar: Category Navigation

```
[Icon] RECHERCHER
ACCESSORIES
BAG
CLOTHING
SHOES
  └ Sneakers
```

*   **Position:** Absolute / Sticky, aligned to the middle-left of the viewport.
*   **Search Input Indicator:** Small search icon + italicized/mono-style label `RECHERCHER` (Font Size: `10px`, Color: `#999999`).
*   **Interactive States:**
    *   Hovering over inactive categories (`ACCESSORIES`, `BAG`, `CLOTHING`) applies a smooth text-stroke or color transition to solid black.
    *   Active category (`SHOES`) is rendered in solid high-contrast black (`#000000`) with a sub-tier menu item (`Sneakers`) displayed below it with an active tracking indicator.

---

## 5. Center Stage: 3D Interactive Product Display

*   **Core Asset:** A floating, rotating 3D model of the **Gucci Crystals Flashtrek Sneaker** suspended dynamically at a 45-degree angle.
*   **Surrounding Carousel Assets:**
    *   **Left & Right Parallax Items:** Blurred, out-of-focus background variations of the sneaker moving on a slow depth-of-field z-axis track.
*   **Shadow & Depth:** A soft, blurred elliptical drop shadow (`rgba(0,0,0,0.08)`) directly beneath the floating sneaker to anchor the composition in 3D space.

---

## 6. Footer Call-to-Action (CTA)

```
       [  SEE MORE  ]
```

*   **Position:** Centered directly underneath the product pricing details.
*   **Component Specifications:**
    *   Pill-shaped button wrapper (Border Radius: `20px`).
    *   Background Color: Semi-transparent neutral gray (`#E5E5E5`).
    *   Text: `SEE MORE` (Font: `Inter`, 600 weight, Size `11px`, Letter-spacing `0.1em`, Color `#333333`).
    *   Hover State: Background shifts to `#111111`, text color inverts to `#FFFFFF` with a soft drop-shadow elevation.

---

## 7. Motion & Animation Specification

### 1. Page Load Entrance Animation (Staggered Fade-In):
*   **Navigation Bar:** Slides down from `Y: -20px` to `0`, opacity `0 -> 1` over `0.6s` cubic-bezier(0.16, 1, 0.3, 1).
*   **Left Sidebar:** Fades in from left (`X: -30px` to `0`) with a `0.2s` delay.
*   **Central 3D Sneaker:** Scales up from `0.9` to `1.0` with simultaneous rotation adjustment, duration `1.2s`.

### 2. Micro-Interactions & Hover Dynamics:
*   **3D Product Rotation:** Continuous subtle mouse-following parallax tilt (max tilt angle: `±10deg` on X/Y axes).
*   **Background Sneaker Blur Transition:** On scroll or category switch, peripheral items swap z-index layers with a fast Gaussian blur transition (`filter: blur(8px) -> blur(4px)`).
*   **Button Hover:** Scale transform `transform: scale(1.03)` with a smooth `0.2s` ease-out transition.
