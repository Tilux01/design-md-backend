# Comprehensive UI/UX Design Specification Document

## 1. Global Layout & Viewport Strategy

- **Design Philosophy**: Full-screen, edge-to-edge layout designed with a single viewport focus (100vw × 100vh). Outer decorative mock frames or presentation canvas backdrops are omitted in favor of a native, immersive web page.
- **Background**: Solid pale cornflower blue (`#889CE6` / `rgb(136, 156, 230)`).
- **Page Structure**:
  1. **Top Header/Nav Bar**: Floating navigation with logo, standard navigation links, and utility icons (user/cart).
  2. **Hero Section**: 
     - **Left Column**: Brand hook, massive hero headline ("Nature’s Organic Fruit Juices"), body description, and primary/secondary CTAs ("Shop Now" & "See more").
     - **Right Column**: Circular/oval image mask feature containing a rich, detailed graphic composition of fresh blueberries and a central product mockup bottle. Vertical carousel arrow controls are positioned to the right.
  3. **Footer/Credits**: Minimalist bottom bar featuring copyright information on the left and a social tag (`@uiuxzaid`) on the right.

---

## 2. Color Palette

| Color Role | Hex Code | RGB | Usage |
| :--- | :--- | :--- | :--- |
| **Primary Background** | `#889CE6` | `136, 156, 230` | Canvas and base container backdrops |
| **Deep Blueberry/Purple**| `#383C6C` | `56, 60, 108` | Hero card surface container, deep accents |
| **White / Text Light** | `#FFFFFF` | `255, 255, 255` | Primary headings, button text, logo, icons |
| **Secondary Text Muted**| `#C4CEF0` | `196, 206, 240` | Body text, unselected nav links, copyright text |
| **Accent / Button Base** | `#FFFFFF` | `255, 255, 255` | "Shop Now" primary CTA background |
| **Dark Button Text** | `#1A1D36` | `26, 29, 54` | Text inside white solid buttons |

## 3. Typography & Font Stack

### Headings (Hero Title: "Nature’s Organic Fruit Juices")
- **Font Family**: *Caveat*, *Pacifico*, or high-end script fonts.
- **Fallback Stack**: `'Caveat', 'Brush Script MT', cursive, sans-serif`
- **Weight**: Bold / Semi-bold (700)
- **Style**: Fluid script, highly legible yet organic brush strokes.

### UI Text, Navigation & Body Text
- **Font Family**: *Inter*, *SF Pro Display*, *Roboto*
- **Fallback Stack**: `'Inter', system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- **Weights**:
  - Navigation / Buttons: Medium (500)
  - Body Copy: Regular (400)
  - Logo ("Cream."): Bold (700)

## 4. Component-by-Component Specifications

### A. Navigation Header
- **Logo**: 
  - Text: `Cream.`
  - Font Size: `18px`, Weight: `700`, Color: `#FFFFFF`.

- **Utility Icons**:
  - Profile user icon and Shopping bag/cart icon (with a red notification badge "2").
  - Icon color: `#FFFFFF`, size: `16px`.

### B. Hero Section (Left Column)

- **Main Heading**:
  - Text: `Nature’s Organic Fruit Juices`
  - Style: Multi-line flowing script, line height tightly packed.

  - Text: `"They aren't just about incredible sound, they're designed for your well-being. With immersive audio and noise cancellation."` *(Note: placeholder audio copy in source design)*.

  - **Primary Button ("Shop Now")**:

  - Two circular floating arrow buttons (Up arrow, Down arrow) aligned vertically to the right of the hero container.

## 5. Animation & Interaction Specification

- **Page Load (Entrance Animation)**:
  - *Fade In Up*: The central hero card container scales up slightly from `0.95` to `1.0` with an opacity transition over `0.8s` using an `cubic-bezier(0.16, 1, 0.3, 1)` ease.
  - *Staggered Text*: Hero headline elements slide up from `y: 20px` with a `0.1s` stagger delay.
- **Hover States**:
  - Nav links transition color from `#C4CEF0` to `#FFFFFF` (`0.2s ease`).
  - Primary CTA ("Shop Now") lifts slightly (`translateY(-2px)`) with an enhanced drop shadow.
- **Carousel Interaction**:
  - Clicking the Up/Down arrow controls triggers a smooth vertical slide transition of the hero visual card, swapping out the fruit and product mockup combination.
