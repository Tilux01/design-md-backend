# 1. Design Philosophy & Overall Aesthetic
- **Primary Mood:** Serene, futuristic, highly refined healthcare/wellness dashboard blending organic fluid botanical elements with high-tech glassmorphic telemetry.
- **Brand Archetype:** Premium digital health / mindful wellness.
- **Visual Density:** Medium-high density with layered floating translucent panels (Glassmorphism), creating a profound sense of visual depth.
- **Whitespace Balance:** Balanced through precise padding (typically `16px` to `24px` internal card spacing) and asymmetric grid alignments.
- **Theme Balance:** Primarily **Dark/Glass Dark Mode** layered over luminous aquatic-blue botanical backdrops. Utilizes high-transparency panels (`rgba(255, 255, 255, 0.1)` to `0.3`) combined with heavy backdrop filtering (`blur(20px)` to `blur(40px)`).

# 4. Layout Architecture & Spatial Grid
- **Container Architecture:** Fluid multi-column dashboard layout scaling up to `1440px` max viewport width.
- **Padding & Margin Scale:** Base spatial units in multiples of `4px` (`8px`, `12px`, `16px`, `24px`, `32px`). Card internal padding is uniformly `20px` to `24px`.
- **Z-Index Hierarchy:**
  - Background Backdrop / Ambient Glow: `z-0`
  - Base Content Containers / Cards: `z-10`
  - Floating Interactive Modals / Dropdowns: `z-30`
  - Sticky Top Navigation Bar: `z-50`

# 6. Motion Mechanics, Framer Motion & CSS Animation Code

- **Easing Physics:** Smooth cubic bezier curves `cubic-bezier(0.16, 1, 0.3, 1)` simulating high-end Apple/macOS glass transitions.
- **Transition Durations:** Micro-interactions (`150ms` - `200ms`), Card hover/expansion (`400ms`).

## Framer Motion React Code Snippets
```jsx
import { motion } from 'framer-motion';

export const glassCardVariants = {
  hidden: { opacity: 0, y: 20, scale: 0.98 },
  visible: { 
    opacity: 1, 
    y: 0, 
    scale: 1,
    transition: { 
      duration: 0.5, 
      ease: [0.16, 1, 0.3, 1] 
    } 
  },
  hover: {
    scale: 1.01,
    backgroundColor: 'rgba(255, 255, 255, 0.16)',
    transition: { duration: 0.2 }
  }
};

export const FloatingCard = ({ children }) => (
  <motion.div
    initial="hidden"
    animate="visible"
    whileHover="hover"
    variants={glassCardVariants}
    className="rounded-[28px] bg-white/10 backdrop-blur-[30px] border border-white/25 p-6 shadow-glass"
  >
    {children}
  </motion.div>
);
```

# 7. Accessibility (a11y) & WCAG Contrast Audit
- **Text Contrast Ratios:**
  - Primary White (`#ffffff`) on Dark Glass Backgrounds (`rgba(15, 23, 42, 0.6)`): **> 11.5:1** (Passes WCAG AAA).
  - Muted Text (`rgba(255, 255, 255, 0.65)`) on Glass Surface: **> 4.8:1** (Passes WCAG AA).
- **Keyboard Focus Ring Specifications:**
  ```css
  *:focus-visible {
    outline: none;
    box-shadow: 0 0 0 3px rgba(56, 189, 248, 0.6), 0 0 0 1px rgba(255, 255, 255, 0.8);
  }
  ```
