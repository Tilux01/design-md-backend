# Comprehensive UI/UX Design Specification & Replication Blueprint

## 1. Executive Summary & Design System Architecture

This specification document outlines the exact architecture, layout geometry, typography, color palette, and interactive states required to build a pixel-perfect, responsive web clone of the provided "CHOPCHOP Chef's Knife" landing page concept. 

The design is engineered as a modern, minimalist split-screen hero section. It juxtaposes an organic, textured dark marble surface against a clean, geometric, light diagonal-striped gradient background. This intentional contrast frames the focal point: an artisanal round wooden cutting board resting underneath a professional chef's knife and scattered fresh produce.

## 3. Color Palette & Visual Assets

### 3.1 Color Specifications
*   **Deep Onyx Black (Marble Dark Base):** `#111111` / `#0D0D0D`
*   **Charcoal Gray (Secondary Dark Shading):** `#1E1E1E`
*   **Off-White / Light Silver (Background Base):** `#F0F0F2`
*   **Subtle Diagonal Stripe Tone:** `#E4E4E6`
*   **Primary Text & Heading Dark:** `#1A1A1A`
*   **Muted Body Text Gray:** `#6A6A6A`
*   **CTA Button Fill:** `#1A1A1A`
*   **CTA Button Text:** `#FFFFFF`

### 3.2 Visual Assets Map
1.  **Dark Marble Background Texture:** High-resolution dark veined marble or dark slate photograph.
2.  **Round Wooden Cutting Board:** End-grain or parallel-grain acacia/walnut circular cutting board PNG with realistic wood grain and drop shadow.
3.  **Chef's Knife:** Professional forged stainless steel chef's knife with riveted dark wood handle, angled precisely across the board.
4.  **Produce Elements:**
    *   Cluster of small red and yellow cherry tomatoes / yellow pear tomatoes.
    *   Pile of finely brunoise-chopped green vegetables (chives/herbs).
    *   Scattered circular slices of fresh carrots.

## 4. Typography System & Fallbacks

The layout relies heavily on a high-contrast pairing of a sophisticated serif display face and a clean, legible sans-serif for UI chrome.

### 4.1 Primary Display & Heading Font: **Playfair Display**
*   **Import:** 
    ```html
    <link href="https://fonts.googleapis.com/css2?family=Playfair+Display:ital,wght@0,400..900;1,400..900&display=swap" rel="stylesheet">
    ```
*   **Fallback Stack:** `Georgia, 'Times New Roman', Times, serif`
*   **Usage:** Logo typography ("CHOPCHOP"), Main Heading ("Chef's Knife").

### 4.2 Secondary UI & Body Font: **Inter** (or **Helvetica Neue**)
*   **Import:** 
    ```html
    <link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600&display=swap" rel="stylesheet">
    ```
*   **Fallback Stack:** `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif`
*   **Usage:** Subheadings, paragraph descriptions, navigation pagination ("01 / 04"), "PREV / NEXT" controls, copyright/meta text.

## 7. Animation & Interactive Behavior Specifications

To replicate the polished slider aesthetic (inspired by Slider Revolution), implement the following state transitions:

### 7.1 Page Load Entrance Animation (CSS Keyframes)
*   **Staggered Fade & Slide:** 
    *   Left visual composite elements fade in from 0 opacity with a slight upward translate (`translateY(20px)`) over 0.8s with an `ease-out` cubic-bezier curve.
    *   Right text block slides in from the right (`translateX(30px)`) over 0.8s.

```css
@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(25px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.content-body > * {
  animation: fadeInUp 0.8s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}

.content-body .title { animation-delay: 0.1s; }
.content-body .description { animation-delay: 0.2s; }
.content-body .cta-button { animation-delay: 0.3s; }
```

### 7.2 Slide Transition Mechanics (JavaScript / CSS State Hook)
*   When clicking **NEXT** or **PREV**:
    1. The active slide content fades out (`opacity: 0; transform: translateY(-10px);`).
    2. The composition graphic items perform a parallax shift (board and knife slide horizontally out of frame).
    3. New slide data populates DOM, triggering the entrance keyframes anew.
