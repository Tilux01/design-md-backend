# Design Specification: Neumorphic Music Player

## 1. General Aesthetic & Theme
*   **Style:** Neumorphism / Soft UI. The interface relies on soft, directional shadows to create a sense of depth (extrusion and recession) rather than flat borders.
*   **Color Palette:**
    *   **Background:** `#F0F3F8` (A very light, cool-toned grey/white).
    *   **Primary Accent (Dark):** `#1A1C20` (Deep charcoal/black for buttons and text).
    *   **Secondary Text:** `#7D8696` (Medium grey for metadata).
    *   **Shadow Light:** `#FFFFFF` (Pure white for top-left highlights).
    *   **Shadow Dark:** `#D1D9E6` (Soft grey for bottom-right shadows).
*   **Border Radius:** Highly rounded. Large containers use `32px` to `40px`. Buttons use `12px` to `20px`.

## 2. Typography
*   **Primary Font:** `Inter` or `SF Pro Display`.
*   **Fallback Stack:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
*   **Weights:**
    *   **Bold (700):** Used for Song Titles and Album Titles.
    *   **Medium (500):** Used for Navigation labels and secondary headers.
    *   **Regular (400):** Used for artist names, timestamps, and list items.

## 3. Screen 1: "Now Playing" View

### Layout Structure
A vertical stack with a fixed header, a central hero image area, a metadata section, a waveform seeker, controls, and a bottom navigation bar.

### Components
1.  **Header Bar:**
    *   **Left:** Back arrow icon (24px).
    *   **Center:** "Now Playing" text (16px, Medium weight, dark charcoal).
    *   **Right:** Options icon (Horizontal three-dots, 24px).
2.  **Album Art Container:**
    *   **Dimensions:** Square, roughly 80% of screen width.
    *   **Styling:** Large rounded corners (40px). It features a "lifted" neumorphic effect: a white highlight on the top-left and a soft grey shadow on the bottom-right.
    *   **Image Description:** (See Section 5).
3.  **Track Metadata:**
    *   **Title:** "Unsayable" (28px, Bold, dark charcoal). Centered below the image.
    *   **Artist:** "Quartless" (16px, Regular, medium grey). Centered below the title.
4.  **Waveform Seeker:**
    *   A visual audio waveform graphic.
    *   **Active Part (Left):** Dark charcoal color.
    *   **Inactive Part (Right):** Light grey color.
    *   **Timestamps:** "1:42" (left) and "3:51" (right) in small 12px grey text, placed at the far ends of the waveform.
5.  **Playback Controls:**
    *   **Layout:** Horizontal row.
    *   **Outer Buttons:** Shuffle (left) and Repeat (right) icons, styled as flat icons in medium grey.
    *   **Inner Buttons:** Previous and Next icons (24px, dark charcoal).
    *   **Play Button:** A large circular button. It is "recessed" into the background (inner shadows). Inside is a smaller dark charcoal circle containing a white Play triangle icon.
6.  **Bottom Navigation:**
    *   Four icons: Home (active, dark), Search, Library, Profile.
    *   Minimalist line-art style.

## 4. Screen 2: Album / Playlist View

### Layout Structure
A scrollable list view with a prominent header section and a floating mini-player at the bottom.

### Components
1.  **Header Bar:**
    *   **Left:** Back arrow.
    *   **Right:** Search icon.
2.  **Album Header:**
    *   **Left:** Small version of the Album Art (rounded square, 80px).
    *   **Right:** "Charcoal" (Title, 24px Bold) and "Quartless" (Artist, 14px Regular).
    *   **Bottom Icons:** Heart (outlined), Download, and Share icons in a row.
3.  **Action Buttons:**
    *   **Play Button:** Dark charcoal pill-shaped button with a white Play icon and "Play" text.
    *   **Shuffle Button:** Light grey/white pill-shaped button with a "lifted" neumorphic effect and a dark Shuffle icon with "Shuffle" text.
4.  **Track List:**
    *   Each row contains: Track number (e.g., 01), Title, Artist, Duration (e.g., 3:21), and a three-dot menu icon.
    *   **Active State:** The track "Unsayable" is highlighted. It has a subtle recessed background and a small Play icon next to the track number.
5.  **Mini Player (Floating):**
    *   A dark charcoal horizontal bar pinned just above the navigation.
    *   **Left:** Tiny thumbnail of the album art.
    *   **Center:** "Unsayable" and "Quartless" in white/light grey text.
    *   **Right:** Heart icon and Play/Pause button.
6.  **Bottom Navigation:** Identical to Screen 1.

## 5. Image Descriptions

### Main Album Artwork ("Charcoal")
*   **Content:** A high-contrast, grayscale macro photograph. It depicts a cross-section of a piece of charcoal or a weathered stone.
*   **Visual Details:** The central object is a light-grey, organic, circular shape with visible radial cracks and a rough, woody texture.
*   **Background:** The object is set against a deep, pitch-black, textured background that looks like coal dust or dark rock.
*   **Rotation/Placement:** The object is centered within its container. The radial cracks are oriented vertically and diagonally, giving it a natural, unpolished look.
*   **Background Status:** The image itself has a black background; it is **not** backgroundless/transparent. It should fill the rounded square container entirely.

## 6. Neumorphic CSS Implementation Guide (Reference)

To achieve the "exact" look, use these shadow values as a starting point:

*   **Elevated (Lifted) Elements:**
    ```css
    background: #F0F3F8;
    box-shadow: 10px 10px 20px #D1D9E6, 
               -10px -10px 20px #FFFFFF;
    ```
*   **Recessed (Pressed) Elements:**
    ```css
    background: #F0F3F8;
    box-shadow: inset 6px 6px 12px #D1D9E6, 
                inset -6px -6px 12px #FFFFFF;
    ```
*   **Dark Buttons:**
    ```css
    background: #1A1C20;
    box-shadow: 6px 6px 15px rgba(0,0,0,0.2);
    ```
