# Comprehensive Design Specifications: PayPal Mobile App UI Kit

## 1. Global Styles & Design Tokens

### Color Palette
*   **Primary Brand Blue:** `#003087` (Deep PayPal Blue, used for primary buttons, headers, dark state backgrounds)
*   **Secondary Brand Blue:** `#0079C1` (Lighter accent blue, used for interactive highlights, active icons, secondary branding)
*   **Background Canvas (Light):** `#F7F9FB` (Off-white neutral backdrop for light-mode screens and component framing)
*   **Background Canvas (Dark/Rich):** `#0F1E36` to `#003087` (Deep gradient base for dashboard and success screens)
*   **Neutral Dark (Text/Icons):** `#111827` (Primary typography, high-contrast headers)
*   **Neutral Muted (Subtext/Borders):** `#6B7280` or `#9CA3AF` (Secondary labels, borders, inactive states)
*   **Pure White:** `#FFFFFF` (Card surfaces, input backgrounds, modal containers)
*   **Success Green:** `#10B981` or `#059669` (Confirmation checkmarks, success states)
*   **Interactive Focus Blue:** `#3B82F6` (Active borders, focused text fields)

### Typography Stack
*   **Primary Font Family:** `Inter`, `SF Pro Display`, `-apple-system`, `Segoe UI`, `Roboto`, `Helvetica Neue`, `Arial`, sans-serif
*   **Fallback Font Chain:** `sans-serif` (Universal system UI sans-serif stack)
*   **Scale Specifications:**
    *   **Screen Titles / Headers:** 24px–28px, Bold (Weight: 700)
    *   **Section Headers:** 18px–20px, Semi-Bold (Weight: 600)
    *   **Body / Input Text:** 14px–16px, Regular to Medium (Weight: 400–500)
    *   **Subtext / Captions / Badges:** 11px–12px, Regular (Weight: 400)

### Elevation & Shadows
*   **Card / Floating Element Shadow:** `0px 10px 25px rgba(0, 48, 135, 0.08)`
*   **Button Shadow:** `0px 4px 12px rgba(0, 48, 135, 0.2)`

## 3. Implementation Guidelines for Developers

1.  **Component Reusability:** Create shared UI components for:
    *   Buttons (`PrimaryButton`, `SecondaryButton`, `IconButton`)
    *   Inputs (`TextField`, `PhoneInput`, `OTPInputGroup`)
    *   Navigation (`TopNavBar`, `BottomTabBar`)
    *   Cards (`BalanceCard`, `BankItemRow`, `VirtualCardPreview`)
2.  **Spacing & Padding:** Maintain consistent 16px to 24px horizontal padding across all mobile screen frames. Use 8px grid system units (8px, 16px, 24px, 32px).
3.  **Accessibility:** Ensure all text contrast meets WCAG AA standards (especially dark blue backgrounds with white text `#FFFFFF` and light grey `#F7F9FB` screens with `#111827` text).
