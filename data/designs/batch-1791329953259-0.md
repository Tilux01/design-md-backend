# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Ultra-Minimalist Dark Mode Web3 Financial SaaS.
- **Visual Density & Whitespace Ratio**: High whitespace ratio with an asymmetrical split-screen composition. Generous padding around the hero block and ample breathing room separating the navigation bar, headline copy, and lower partner logo row.
- **Surface Elevation Model**: Monochromatic flat surfaces with absolute dark canvas (`#121212`), high-contrast pure white typography, subtle glassmorphic translucent elements, and volumetric 3D monochromatic vector render accents.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Dark mode immersive canvas, volumetric 3D abstract vector nodes, high-contrast crisp typography, ghost button states, minimal glassmorphism borders.
- **Pill Badge Specification**: Padding `6px 14px`, font-size `12px`, font-weight `500`, tracking `0.05em`, border-radius `9999px`, background translucency `rgba(255, 255, 255, 0.03)`, border width `1px` solid `rgba(255, 255, 255, 0.1)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-white inline-block"></span>`.
