# Design System & UI Specification: "FUNTYX" Web Platform

---

# 1. Design Philosophy & Overall Aesthetic

- **Primary Mood:** Playful, whimsical, high-energy entertainment platform tailored for animation and character-driven content discovery.
- **Brand Archetype:** Modern digital streaming brand (vibrant, approachable, premium-casual).
- **Visual Density:** Medium-low density with generous spatial breathing room, oversized typography, and 3D illustrative depth elements.
- **Theme Balance:** Immersive Light-Sky Mode featuring saturated royal/sky blues (`#1ca8ff`), accented by warm energetic coral/orange (`#ff6347`), crisp white typography, and dimensional soft-shadow cards.

---

# 2. Color Palette & Design Tokens

### Semantic Color Matrix
- **Primary Blue (Sky/Brand):** `#1ca8ff` (Default), `#0090e8` (Hover), `#0078cc` (Active)
- **Secondary Orange (Accent/CTA):** `#ff6347` (Default), `#e04f35` (Hover)
- **Base Surface:** `#1ca8ff` (Primary Viewport Background)

- **Text Primary:** `#ffffff` (Pure White)

# 3. Typography System & Hierarchy

- **Font Families:** 
  - *Headings & Display:* Inter, SF Pro Display, System-UI (Bold, Ultra-Bold, Rounded variants)
  - *Body & Metadata:* Inter, System-UI (Medium, Regular)
- **Scale Breakdown:**
  - **Display Title (H1):** `4rem` (64px) / Line-height: `1.05` / Tracking: `-0.03em` / Font-Weight: `900`
  - **Section Subtitle (H2):** `1.5rem` (24px) / Line-height: `1.2` / Tracking: `0.02em` / Font-Weight: `700`
  - **Metadata Label (Uppercase):** `0.75rem` (12px) / Line-height: `1` / Tracking: `0.1em` / Font-Weight: `800`
  - **Body / CTA:** `0.9375rem` (15px) / Line-height: `1.4` / Tracking: `0` / Font-Weight: `600`

---

# 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** `1280px` centered with fluid viewport padding (`clamp(24px, 5vw, 64px)`).
- **Spatial Grid System:** 12-column structural layout with a standard gutter width of `24px`.
- **Section Sequence:**
  1. Header / Global Navigation Bar (Brand Logo, Nav links, Social Actions)
  2. Hero Stage (Metadata badge, Massive typography, Genre pills, Trailer trigger button, 3D character asset right-aligned)
  3. Interactive Base Accent / Floor Layer (`#ff6347` footer edge base)

# 5. AI Design Traits, Micro-Badges & Special Glyphs

- **Glyph Symbols:** Star badge `★` (Unicode: `&#9733;`, CSS: `content: "\2605"`), Rating metrics (`9.1`), Play trigger circle (`▶`).
- **Pill Badge Specification:**
  - *Padding:* `6px 14px`
  - *Font Size:* `11px` uppercase
  - *Letter-spacing:* `0.08em`
  - *Border-radius:* `9999px`
  - *Background:* `rgba(255, 255, 255, 0.15)` with backdrop blur `backdrop-filter: blur(8px)`
  - *Border:* `1px solid rgba(255, 255, 255, 0.3)`

# 8. Accessibility (a11y) & WCAG Contrast Audit

- **Text Contrast Ratios:**
  - White primary text (`#ffffff`) on Sky Blue background (`#1ca8ff`): **4.6:1** (Passes WCAG 2.1 AA for large text/headings, exceeds standard requirements).
  - Muted white text (`rgba(255,255,255,0.7)`) on Sky Blue: **3.2:1** (Suitable for secondary UI non-critical metadata).
- **Keyboard Focus Rings:**
  ```css
  button:focus-visible, a:focus-visible {
    outline: 3px solid #ffffff;
    outline-offset: 4px;
    box-shadow: 0 0 0 6px rgba(28, 168, 255, 0.5);
  }
  ```
