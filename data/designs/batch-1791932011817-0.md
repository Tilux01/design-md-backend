# Design Specification: pet&click Hero Section

## 1. Canvas & Layout Overview
- **Viewport**: 100vw, 100vh (full screen, responsive grid/flex layout).
- **Background**: Off-white to subtle light-gray gradient (`#F4F4F4` to `#EAEAEA`).
- **Structure**: 
  - Top: Navigation bar (full width with horizontal padding).
  - Center/Bottom: Two-column split layout (Left: Typography & CTA; Right: Photography & graphic overlays).

---

## 2. Color Palette
- **Primary Background**: `#F5F5F5`
- **Text & Accents (Dark)**: `#111111` / `#000000`
- **Secondary Text (Muted)**: `#666666`
- **Subtle Labels**: `#999999`
- **Accent Red**: `#E50914` (CTA button, decorative circle)
- **White**: `#FFFFFF` (Button text)

---

## 3. Typography & Fallbacks

| Element | Font Family | Weight | Size (approx.) | Fallbacks |
| :--- | :--- | :--- | :--- | :--- |
| **Logo (`pet&click`)** | Modern Serif (e.g., *Playfair Display*, *Bodoni MT*) | Medium / Regular (italic ampersand) | 24px | `Georgia, serif` |
| **Headline (`dog.`)** | Grotesk Sans (e.g., *Helvetica Neue*, *Inter*, *Arial Black*) | Heavy / 900 | 120px–140px | `Arial, sans-serif` |

| **Microcopy & Nav** | Clean Sans (e.g., *Inter*, *Roboto*) | Regular / 400 | 13px–14px | `sans-serif` |
| **CTA Button** | Geometric Sans | Bold / 700 | 12px (Uppercase, tracked) | `sans-serif` |

---

## 4. Layout Architecture

### Header
- **Placement**: Fixed or absolute at top, `padding: 2.5rem 4rem`.
- **Left**: Logo text `pet&click` in lowercase.
- **Right**:
  - Menu links: `Home`, `Galeria`, `Agenda`, `Contato` (`gap: 2rem`, font size `14px`, color `#444444`). Active state on "Home".
  - Hamburger icon: 3 thin black horizontal lines (`20px` width, `2px` stroke).

### Left Column (Content)
- **Vertical Alignment**: Centered vertically, aligned to the left edge (`padding-left: 5rem`).
- **Headline**: `dog.` in lowercase, solid black with trailing period.
- **Tagline**: `Seu melhor amigo na melhor pose` followed by an inline right-arrow vector `→`.
- **Access Section**:
  - Label: `Acesse seu ensaio com seu codigo` (`12px`, muted gray, `margin-bottom: 0.5rem`).
  - Button: Rectangular red box (`#E50914`), white bold text `LOGIN`, `padding: 10px 32px`, `border-radius: 0px`.
- **Social Icons**: Bottom-left fixed/absolute. 
  - Instagram, Facebook, Pinterest circular line icons in a row (`gap: 12px`, icon size `16px`, border `1px solid #111`).

### Right Column (Visual Area)
- **Decorative Shape**: Large hollow red ring (`border: 8px solid #E50914`, diameter ~`450px–500px`), positioned centrally behind the primary dog's head.
- **Carousel Pagination**: Bottom right corner, format `< 1/4 >` in dark gray (`14px`).

---

## 5. Image Assets & Description

### Subject Photography
- **Content**: High-contrast, black-and-white photograph of two German Shorthaired Pointers wearing nylon collars.
  - **Dog 1 (Foreground Left)**: Facing forward with alert eyes, ears relaxed down. Occupies the vertical center and intersects the red circle graphic.
  - **Dog 2 (Foreground Right)**: Shown in profile looking upward and left toward Dog 1.
- **Format**: Transparent cutout (PNG/WebP) with no background, allowing the page gradient and red ring to show behind/between the subjects.
- **Placement**: Aligned along the bottom-right viewport edge, overlapping slightly into the center stage. Scale to fill ~60% of viewport width.
