# UI/UX Design Specification: Luxury Chronograph Showcase

---

## 1. Design Overview & Global Styles

This is a high-end, dark-mode e-commerce / product showcase landing page designed for a luxury timepiece. The aesthetic relies on ultra-clean minimalism, high contrast, and tactile material cues.

### Color Palette

| Token | Hex / Value | Usage |
| :--- | :--- | :--- |
| **Background (Deep)** | `#121316` | Main viewport and card backgrounds |
| **Background (Surface)**| `#1a1b1f` | Elevated surface layers, interactive controls |
| **Primary Accent** | `#E89D78` | Soft copper / rose-gold accent for buttons, dials, and highlights |
| **Text Primary** | `#FFFFFF` | Headings and high-emphasis labels |
| **Text Muted** | `#8E9199` | Secondary descriptions, timestamps, and subtle UI text |
| **Watch Accents** | Rose gold / Copper | Hands, sub-dial markings, and bezel accents on the watch face |

### Typography

*   **Primary Font Family:** Clean, geometric sans-serif (e.g., *Inter*, *Plus Jakarta Sans*, or *SF Pro Display*).
*   **Hero Headers:** Bold, high-tracking, rounded sans-serif with stylized alternate characters (simulated AI-generated typography).
*   **Body Copy:** Light weight, optimized for legibility at small scales.

---

## 2. Layout Structure & Grid

*   **Viewport:** Fullscreen responsive layout with generous negative space (padding: `64px` desktop).
*   **Grid System:** 12-column flexible grid with asymmetric split:
    *   **Left Column (35% width):** Hero typography, primary CTA, secondary feature modules, and bottom category carousels.
    *   **Center Column (30% width):** Focal point product showcase (realistic macro render of the chronograph watch).
    *   **Right Column (35% width):** Configuration, specifications, interactive toggle states, and secondary callouts.

---

## 3. Component Specifications

### Header / Navigation Bar (`y: 32px`)
*   **Logo:** Minimalist monogram icon on the far left.
*   **Navigation Links:** Centered pill-style spacing with muted text labels (`Discover`, `Model`, `Collection`, `Support`).
*   **User Action:** Profile / Account icon on the far right.

---

### Left Column: Hero & Product Intro
*   **Main Headline (`Plome UI/UX Website`):**
    *   Font Size: `44px`
    *   Line Height: `1.1`
    *   Color: `#FFFFFF`
*   **Introductory Paragraph:**
    *   Width: `320px`
    *   Font Size: `13px`
    *   Color: `#8E9199`
    *   Line Height: `1.5`
*   **Primary CTA Button (`Explore Collection`):**
    *   Shape: Fully rounded pill (`border-radius: 999px`)
    *   Background: `#E89D78`
    *   Text Color: `#121316`
    *   Font Size: `14px`, Medium weight.
*   **Secondary Feature Module:**
    *   Sub-headline with stylized subtitle text.
    *   Progress / Slider bar with a solid copper fill segment.
*   **Bottom Carousel (`Related Editions`):**
    *   Horizontal scroll area containing 5 circular product thumbnail nodes.
    *   Each node features a copper-tinted variant of the timepiece inside a dark container card.

---

### Center Column: Focal Product Display
*   **Product Render:** Centered high-resolution macro shot of a black matte chronograph watch.
    *   **Case:** Matte black stainless steel with brushed finishing.
    *   **Strap:** Textured black leather with subtle contrast stitching.
    *   **Dial:** Deep obsidian face featuring rose-gold / copper numerals, inner subdials, and sweeping chronograph hands.
    *   **Pushers:** Knurled mechanical push-pieces on the right-hand side of the case.

---

### Right Column: Configuration & Specs
*   **Section Title (`Wex Pge` / Variant Selector):**
    *   Subtitle indicators with metadata details.
*   **Interactive Selector Chips:**
    *   A row of pill-shaped filter/selection buttons.
    *   Active State: Solid `#E89D78` background with dark text.
    *   Inactive States: Dark surface background (`#1a1b1f`) with muted text.
*   **Detailed Specifications Panel:**
    *   Icon-driven metric rows displaying movement, water resistance, and material breakdown.
*   **Secondary Purchase Card (`Homm Perr oleiretai`):**
    *   Sub-card container with unified pricing layout and secondary action button.

---

## 4. Interactive States & Micro-interactions

*   **Hover States:**
    *   Buttons transition smoothly with a slight brightness boost (`+10%` luminosity).
    *   Carousel items elevate with a subtle drop shadow on hover.
*   **Active States:**
    *   Selected filter chips retain the primary accent color (`#E89D78`).
