# Design Specification: "Leafora" Plant E-Commerce App

This document provides a comprehensive design specification to create an exact clone of the "Leafora" plant e-commerce mobile application interface shown in the media. 

---

## 1. Global Design System & Theme

### Color Palette
The design is built on a dark, nature-inspired forest green theme using varying opacities, glassmorphism, and gradients for depth.

*   **Primary Dark Background (App Canvas):** `#0c1913` (Deep, almost black forest green).
*   **Card Backgrounds & Containers:** 
    *   Solid/Opaque: `#162920` (Rich dark green).
    *   Translucent/Glass Panels: `#11211a` with 60%–80% opacity and a subtle 1px inner border (`#2a4435`).
*   **Accent & Interactive Greens:**
    *   Button/CTA Gradient: Linear gradient from `#d4e8cb` (light sage) to `#a3c994` (soft moss green).
    *   Active State Green: `#8ab671`.
*   **Text Colors:**
    *   Primary Headings & Titles: `#ffffff` (Pure White) and `#eaf4e2` (Soft Off-White).
    *   Body Text & Secondary Labels: `#9cb3a5` (Muted Sage Gray).
*   **Icons & Badges:** Stroke and fill colors match the text (`#9cb3a5` for inactive/secondary, `#ffffff` for active/primary).

### Typography & Fonts
The design uses a clean, modern serif for headings and a highly legible sans-serif for UI elements, pricing, and body copy.

*   **Primary Serif Font (Headings, App Title "Leafora"):**
    *   *Family:* `Playfair Display`, `Cormorant Garamond`, or fallback to standard system serif.
    *   *Weight:* Regular to Semi-Bold (400–600).
*   **Secondary Sans-Serif Font (UI, Body, Prices, Navigation):**
    *   *Family:* `Inter`, `SF Pro Display`, `Roboto`, or fallback to system sans-serif.
    *   *Weights:* Light (300), Regular (400), Medium (500), Bold (700).

## 3. Implementation Checklist & Developer Notes
1.  **Glassmorphism:** Apply CSS `backdrop-filter: blur(16px);` combined with semi-transparent background rgba values (`rgba(22, 41, 32, 0.7)`) to recreate the frosted card effects.
2.  **Asset Handling:** Ensure all plant images are supplied as transparent PNGs (backgroundless) so they blend seamlessly into the dark forest green theme.
3.  **Borders & Dividers:** Use extremely subtle, thin borders (`border: 1px solid rgba(255, 255, 255, 0.08)`) on cards and inputs to define boundaries without heavy lines.
4.  **Button States:** The primary action buttons consistently use a soft sage-to-pale-green horizontal gradient with dark green typography for high contrast and modern UI appeal.
