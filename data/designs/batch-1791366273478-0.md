# HUGINN Portfolio Website Design Specification

This document provides the exact design specifications to create a full-screen, pixel-perfect clone of the "HUGINN" portfolio landing page shown in the reference image. The outer presentation frame, drop shadow, and neutral background of the preview are omitted; the implementation should be **100% viewport width and height**.

---

## 1. Global Styles & Layout

### Typography
* **Primary Font Family:** Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
* **Weights Used:** Regular (400), Medium (500), Bold (700)
* **Text Case:** Uppercase for navigation and sub-category labels; sentence/title case for main slide titles.

### Color Palette
* **Background Dark (Base):** `#16171b` (Dark charcoal/black used for footer/panel bases)
* **Primary Text:** `#ffffff` (Pure white)
* **Secondary Text / Muted Labels:** `#8b8e9b` or `#9ca3af` (Muted gray)
* **Active Indicator / Accent:** `#6d48e5` (Deep purple, used for the bottom progress bar)
* **Overlay Tints:** Linear gradients ranging from black (`rgba(0,0,0,0.4)` to `rgba(0,0,0,0.8)`) applied over photography for text readability.

---

## 2. Structure & Layout

The screen is divided horizontally into **4 distinct vertical cards/panels** that span the full height of the viewport (minus a slim top header and bottom footer bar).

* **Layout Mode:** CSS Flexbox or CSS Grid with 4 equal columns (`grid-template-columns: repeat(4, 1fr)`).
* **Full-Screen Canvas:** `width: 100vw; height: 100vh; overflow: hidden; background-color: #16171b; display: flex; flex-direction: column;`

---

## 3. Header Section (Top Bar)

Positioned absolutely or as a fixed header overlay spanning the top of the viewport.

* **Height:** `~70px`
* **Padding:** `0 40px`
* **Display:** Flexbox (`justify-content: space-between; align-items: center;`)
* **Z-Index:** `10` (above background images)

### Left Element: Brand Logo
* **Icon:** White bird/raven head silhouette (SVG).
* **Text:** "HUGINN"
* **Styling:** Bold, white, letter-spacing: `2px`, font-size: `16px`.

### Center/Right Element: Navigation Links
* **Links:** `HOME`, `ABOUT`, `WORK`, `CONTACT`
* **Styling:** Uppercase, font-size: `11px`, letter-spacing: `1.5px`, color: `rgba(255,255,255,0.7)` (Active link `HOME` is pure white).
* **Hamburger Menu Icon:** Placed to the left of the nav links (3 horizontal lines, white, subtle).
* **Search Icon:** Placed on the far right (magnifying glass outline).

---

## 4. Main Content Panels (The 4 Slides)

Each panel takes up 25% of the horizontal width and 100% of the available vertical space. Each features a full-cover background image with a dark gradient overlay.

### Common Panel Structure
* **Position:** Relative
* **Padding:** `40px` (Internal spacing for text contents)
* **Display:** Flexbox (`flex-direction: column; justify-content: flex-end;`) to anchor text to the bottom.

---

### Panel 01: "Beautiful Venice"

* **Content:**
  * **Index Number:** `01.` (White, font-size: `14px`, font-weight: bold, margin-bottom: `8px`)
  * **Title:** `Beautiful Venice` (White, font-size: `22px`, font-weight: bold, margin-bottom: `4px`)
  * **Category:** `TRAVEL` (Muted gray/white uppercase, font-size: `10px`, letter-spacing: `1px`)
* **Left Arrow Indicator:** Subtle left-pointing chevron on the left edge of the first panel.

  * **Index Number:** `02.`

  * **Category:** `INTERIOR`

### Panel 03: "Amazing Mountain"

  * **Index Number:** `03.`

### Panel 04: "Street Portrait"

## 5. Footer Section (Bottom Bar)

* **Height:** `~40px`
* **Background:** Solid dark charcoal matching the base theme (`#16171b`).
* **Padding:** `0 40px`
* **Display:** Flexbox (`justify-content: space-between; align-items: center;`)

### Left Element: Copyright
* **Text:** `© All Rights Reserved 2017`
* **Styling:** Muted gray text, font-size: `11px`.

### Center Element: Pagination / Progress Bar
* **Design:** A horizontal track line with an active purple progress segment indicating the current position (first slide selected).
* **Track Color:** `rgba(255, 255, 255, 0.1)`
* **Active Bar Color:** `#6d48e5` (Purple)
* **Dimensions:** Width approx. `80px`, height `2px`.
