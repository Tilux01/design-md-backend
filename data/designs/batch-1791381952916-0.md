# UI/UX Specification: "Creating a Biocomputer" Landing Page Clone

This document provides a comprehensive blueprint to recreate the provided landing page with pixel-perfection. It abstracts away the presentation framing (the browser/device window mock) to deliver a **full-bleed, immersive viewport experience**.

---

## 1. Global Layout & Viewport Strategy

*   **Display Mode:** Full-screen (`width: 100vw; height: 100vh; overflow: hidden;`)
*   **Grid System:** Asymmetric layout.
    *   **Left Region (approx. 40% width):** Houses branding, navigational cues, heading typography, and call-to-action buttons.
    *   **Right/Center Region (approx. 60% width):** Houses the hero 3D organic cellular render.
*   **Subtle Background Grid:** A technical, blueprint-style vertical grid is overlaid across the canvas with extremely low opacity (`rgba(255, 255, 255, 0.03)`), giving a futuristic, scientific interface feel.

---

## 2. Color Palette & Lighting

*   **Background (Canvas Base):** Deep Violet/Midnight Indigo
    *   `HEX: #120A21` / `RGB: (18, 10, 33)`
*   **Primary Text & Highlights:** Pure White
    *   `HEX: #FFFFFF`
*   **Secondary Text / Sub-labels:** Muted Lilac/Gray
    *   `HEX: #A5A1B8`
*   **Accent Color (UI Badges, Buttons, Indicators):** Neon Crimson / Magenta-Red
    *   `HEX: #E52E4D` / `RGB: (229, 46, 77)`
*   **Hero 3D Object Gradient (The Biocell):**
    *   Top/Core Bloom: Electric Pink / Magenta (`#FF53B2`)
    *   Mid Body: Vibrant Purple (`#8C3BFF`)
    *   Base/Shadow: Deep Cobalt Blue (`#0B2BFF`)

---

    *   Color: `#A5A1B8`

## 4. Component Breakdown & Positioning

### A. Header (Top Navigation)
*   **Position:** Absolute, top-left and top-right pinned with generous padding (`48px` from edges).
*   **Left Element:** Logo string `IOCO` in tracking-heavy bold caps.
*   **Right Element:** Standard hamburger menu icon (`≡`), stroke width `2px`, color `#FFFFFF`, clickable target area with hover state.

### B. Hero Content Area (Left Column)
*   **Position:** Absolute, vertically centered-left (`left: 8%`, `top: 45%`, `transform: translateY(-50%)`).
*   **Content Stack:**
    1.  *Category kicker:* `HACKING THE CELL`
    2.  *Spacing:* `16px` margin-bottom.
    3.  *Main Headline:* Two-line block (`Creating a` / `Biocomputer`).
    4.  *Spacing:* `32px` margin-bottom.
    5.  *CTA Button:*
        *   Container: Outlined rectangular box with a thin stroke (`1px solid rgba(255, 255, 255, 0.2)`).
        *   Active/Hover Variant: The container or the nested play button features the Accent Crimson background (`#E52E4D`).
        *   Layout: Flex container with internal text `LEARN MORE` and a trailing circular play icon button.
        *   Dimensions: Padding roughly `16px 24px`.

### C. Carousel & Interactive Controls
*   **Left Carousel Controls (Below main text block):**
    *   Two circular arrow buttons (`<` and `>`).
    *   Inactive: Semi-transparent dark backing.
    *   Active/Hover: Enclosed within a glowing Crimson border/fill (`#E52E4D`).
*   **Right Pagination Indicator:**
    *   **Position:** Absolute, vertical alignment on the mid-right side (`right: 8%`, `top: 50%`).
    *   **Display:** Large active number `01` sitting above a subtle vertical line or indicator track showing progression out of total slides (e.g., `/ 05`).

## 5. 3D Hero Asset ("The Biocomputer Organism")

*   **Nature:** A fluid, translucent, organic 3D simulation resembling a blooming cellular or floral structure.
*   **Position:** Anchored prominently center-right, overlapping the middle-to-right viewport canvas.
*   **Visual Properties:**
    *   **Subsurface scattering:** Soft gradients blending magenta, electric purple, and deep blue.
    *   **Edges:** Delicate, petal-like folds catching a bright rim light.
    *   **Depth:** Lower section fades smoothly into darkness to maintain high contrast with the typography.

---

## 6. Animation & Interaction Specification

To achieve the polished digital-experience look of the reference, incorporate the following animations:

1.  **Entrance Animation (On Load):**
    *   *Staggered Fade-in:* The background grid fades in over `1.2s`.
    *   *Text Rise:* The category text, main headline, and CTA container slide up from `Y: 30px` to `0` with an ease-out cubic bezier (`cubic-bezier(0.16, 1, 0.3, 1)`) over `0.8s`, staggered by `150ms`.
    *   *3D Object Reveal:* The biocomputer mesh scales up slightly from `0.95` to `1.0` while fading from opacity `0` to `1` over `1.5s`.
2.  **Continuous Micro-Interactions:**
    *   *3D Organic Drift:* The biocomputer asset should have a perpetual, slow sine-wave rotation and vertex displacement (idle floating animation).
    *   *Hover States:* 
        *   Buttons scale up by `2%` (`transform: scale(1.02)`) with a smooth transition.
        *   Crimson accent elements glow via box-shadow luminescence (`box-shadow: 0 0 20px rgba(229, 46, 77, 0.4)`).
3.  **Carousel Transitions:**
    *   Clicking pagination arrows triggers a cross-fade and morph animation of the 3D asset into the next state/shape, paired with a sliding text transition for the headline.
