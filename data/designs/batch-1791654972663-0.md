# Design Specification: Smart Home Automation App ("Hey, Ektiar!")

This document details the exact visual, structural, and typographic specifications to recreate the provided smartphone interface. The specification excludes device frames (e.g., the iPhone mockup casing and background studio shadow) to focus purely on a full-screen, edge-to-edge application UI.

---

## 1. Global Layout & Canvas Properties

*   **Screen Orientation:** Portrait
*   **Background Color:** Dark Charcoal/Navy Gradient
    *   *Top/Center Stop:* `#161B22` (Deep dark slate)
    *   *Bottom Stop:* `#0D1117` (Near-black navy)
*   **Container/Safe Areas:**
    *   Top padding accommodates standard status bar / dynamic island area (approx. 44px–54px).
    *   Bottom navigation bar fixed above the bottom safe area inset.
*   **Border Radius:** Full screen (no outer rounding, edge-to-edge layout).

---

## 2. Typography & Fonts

The user interface uses a modern, clean geometric sans-serif typeface (similar to **SF Pro Display** / **Inter** / **Plus Jakarta Sans**).

*   **Primary Font Family:** `Inter`, `SF Pro Display`, system-ui, `-apple-system`, sans-serif
*   **Fallback Font:** `Roboto`, `Helvetica Neue`, `Arial`, sans-serif

### Text Styles Hierarchy:

1.  **Greeting Header ("Hey, Ektiar!")**
    *   Font Size: `22px`
    *   Font Weight: `600` (Semi-bold)
    *   Color: `#FFFFFF` (Pure White)
    *   Letter Spacing: `-0.3px`

2.  **Date Subtitle ("Saturday, Dec 09, 2023")**
    *   Font Size: `12px`
    *   Font Weight: `400` (Regular)
    *   Color: `#8B949E` (Muted Cool Gray)

3.  **Weather Widget - Location & Main Condition ("Cloudy", "Rajshahi, Bangladesh")**
    *   Title ("Cloudy"): `20px`, Weight: `700` (Bold), Color: `#12181F` (Dark text on light card)
    *   Subtitle ("Rajshahi, Bangladesh"): `11px`, Weight: `400`, Color: `#334155`

4.  **Weather Widget - Temperature ("28°")**
    *   Font Size: `28px`
    *   Font Weight: `700` (Bold)
    *   Color: `#12181F`

5.  **Weather Metrics Labels & Values (Sensible, Humidity, W. force, Pressure)**
    *   Values (`31°`, `65%`, `3`, `1009hpa`): `13px`, Weight: `600`, Color: `#0F172A`
    *   Labels (`Sensible`, `Humidity`, `W. force`, `Pressure`): `10px`, Weight: `400`, Color: `#475569`

6.  **Room Filter Chips ("All Devices", "Living Room", etc.)**
    *   Font Size: `13px`
    *   Font Weight: `500` (Medium)
    *   Active Chip Text Color: `#0F172A`
    *   Inactive Chips Text Color: `#8B949E`

7.  **Device Card Titles ("Air Condition", "Smart TV", etc.)**
    *   Font Size: `15px`
    *   Font Weight: `600` (Semi-bold)
    *   Active Card Text Color: `#0F172A`
    *   Inactive Cards Text Color: `#F1F5F9`

8.  **Device Card Subtitles ("4 Devices", "2 Devices", etc.)**
    *   Font Size: `12px`
    *   Font Weight: `400`
    *   Active Subtitle Color: `#334155`
    *   Inactive Subtitle Color: `#64748B`

---

## 3. Section-by-Section Component Breakdown

### A. Top Bar Header
*   **Left Side:**
    *   Stack containing greeting text ("Hey, Ektiar!") and date.
*   **Right Side:**
    *   **Menu/Grid Icon:** 2x2 grid of rounded white dots forming a square button.
    *   Background: Translucent dark circle (`rgba(255, 255, 255, 0.08)`).
    *   Icon Color: `#FFFFFF`.

---

### B. Weather Card Widget
*   **Dimensions:** Span full horizontal content width with standard side margins (approx. `16px`).
*   **Background:** Horizontal/diagonal gradient from bright mint-cyan (`#5EEAD4`) to soft sky blue (`#7DD3FC`).
*   **Border Radius:** `24px`.
*   **Internal Layout:**
    *   **Top Row:**
        *   Left: Weather Illustration (Sun behind a stylized cloud).
        *   Center/Left adjacent: "Cloudy" text stack with location underneath.
        *   Right: Large temperature reading ("28°").
    *   **Bottom Row (Metrics Grid):**
        *   4 equal columns divided horizontally: Sensible (`31°`), Humidity (`65%`), W. force (`3`), Pressure (`1009hpa`).
*   **Weather Illustration Description:**
    *   *Type:* Backgroundless vector illustration.
    *   *Details:* A vibrant yellow/orange 3D-styled sun partially obscured by a soft, matte white/light-blue fluffy cloud with smooth rounded contours. No harsh outlines; smooth gradient shading.

---

### C. Room Filter Horizontal Tabs
*   **Layout:** Horizontal scrolling or flex row with spacing.
*   **Tabs:** `All Devices` (Active), `Living Room`, `Bedroom`, `Kitchen`.
*   **Active Tab ("All Devices"):**
    *   Background: Solid Mint/Cyan (`#5EEAD4`).
    *   Border Radius: `20px`.
    *   Padding: `8px 16px`.
*   **Inactive Tabs:**
    *   Background: Translucent dark fill (`rgba(255, 255, 255, 0.04)`).
    *   Border: Subtle stroke (`1px solid rgba(255, 255, 255, 0.08)`).
    *   Border Radius: `20px`.
    *   Padding: `8px 16px`.

---

### D. Smart Device Cards Grid (2x2 Layout)
*   **Card Structure:** Standardized rounded rectangular cards arranged in a two-column grid with gap spacing (`12px`).
*   **Card 1: Air Condition (Active State)**
    *   **Background:** Mint-cyan gradient matching the weather widget (`#5EEAD4` to `#7DD3FC`).
    *   **Border Radius:** `24px`.
    *   **Top-Left Icon:** Minimalist line icon representing an AC/Vent unit (color: `#0F172A`).
    *   **Top-Right Icon:** Wi-Fi / connectivity signal arcs icon (color: `#0F172A`).
    *   **Text Content:** "Air Condition" (Title), "4 Devices" (Subtitle).
    *   **Bottom Control:** Toggle switch labeled "ON" on the left, with the toggle pill switched to the right (Active state: solid dark background `#0F172A` with white knob).

*   **Card 2: Smart TV (Inactive State)**
    *   **Background:** Dark translucent slate (`#1E222B`).
    *   **Border Radius:** `24px`.
    *   **Top-Left Icon:** Minimalist line icon of a television set (color: `#94A3B8`).
    *   **Top-Right Icon:** Wi-Fi arcs icon (color: `#94A3B8`).
    *   **Text Content:** "Smart TV" (Title), "2 Devices" (Subtitle).
    *   **Bottom Control:** Toggle switch labeled "OFF" on the left, with the toggle pill switched to the left (Inactive state: muted gray track with dark knob).

*   **Card 3: Smart Lighting (Inactive State)**
    *   **Background:** Dark translucent slate (`#1E222B`).
    *   **Border Radius:** `24px`.
    *   **Top-Left Icon:** Minimalist line icon of a standing desk lamp / light fixture (color: `#94A3B8`).
    *   **Top-Right Icon:** Wi-Fi arcs icon (color: `#94A3B8`).
    *   **Text Content:** "Smart Lighting" (Title), "8 Devices" (Subtitle).
    *   **Bottom Control:** Toggle switch labeled "OFF", toggle in inactive left position.

*   **Card 4: Speaker (Inactive State)**
    *   **Background:** Dark translucent slate (`#1E222B`).
    *   **Border Radius:** `24px`.
    *   **Top-Left Icon:** Minimalist line icon of a smart speaker / cylinder device (color: `#94A3B8`).
    *   **Top-Right Icon:** Wi-Fi arcs icon (color: `#94A3B8`).
    *   **Text Content:** "Speaker" (Title), "6 Devices" (Subtitle).
    *   **Bottom Control:** Toggle switch labeled "OFF", toggle in inactive left position.

---

### E. Bottom Navigation Bar
*   **Background:** Dark floating bar / bottom dock (`#12161E`) with rounded top edges or full-width container.
*   **Icons (Left to Right):**
    1.  **Home Icon (Active):** Outline of a house with a solid accent dot underneath (Color: Mint Cyan `#5EEAD4`).
    2.  **Routine / Automation Icon:** Outline of a clock/activity circle with arrows (Color: `#64748B`).
    3.  **Settings / Gear Icon:** Outline of a gear cog with adjustment nodes (Color: `#64748B`).
    4.  **Profile / User Icon:** Outline of a user avatar head/bust (Color: `#64748B`).
*   **Indicator:** Small glowing dot positioned underneath the active Home icon to denote current selection.
