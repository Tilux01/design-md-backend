# Design System & Implementation Specification: "019 AU CABARET SAUVAGE" Landing Page

> **Notice:** This document defines the exact full-screen web layout (100vw × 100vh). All hardware presentation mockups (monitor bezels, webcams, shadows, and outer borders) present in the source reference are stripped away.

---

## 1. Global Layout & Canvas Properties

- **Viewport Size:** Fullscreen standard desktop baseline `1920px × 1080px` (Scales fluidly to viewport `100vw × 100vh` without vertical scroll on base screen).
- **Base Background Color:** Soft architectural off-white / light warm-gray (`#ECECEC` to `#EFEFEF`).
- **Canvas Clipping:** `overflow: hidden` on the primary viewport wrapper to contain ambient gradient glows.
- **Grid Structure:** 
  - 12-column responsive layout with `48px` to `64px` screen edge padding (left/right/top).
  - 3 main horizontal content zones:
    1. **Top Bar (Header):** Height ~`80px`.
    2. **Middle Hero Canvas:** Fluid height spanning ~`65vh` to `70vh`.
    3. **Bottom Lineup Carousel:** Fixed baseline anchoring ~`15vh` from bottom.

## 4. Visual Assets & Media Specifications

### 4.1 Central Portrait Model Image
- **Description:** Studio fashion portrait cut-out of a model with short textured pixie/buzzcut hair, turned in a soft three-quarter profile facing toward the left. High contrast, clean editorial monochrome grading (greyscale / black and white).
- **Background:** **Pure Transparent (Alpha PNG / WebP)**. Absolutely no baked-in background; the torso and hair cut cleanly against the underlying pink atmospheric glow.
- **Artistic Makeup / Glow Integration:** Across the eye area (from temple to temple over the bridge of the nose) is a wide, vibrant horizontal stroke/mask of solid electric magenta-pink (`#F51EBA`).
- **Dimensions & Scale:** 
  - Height: ~`65vh` to `70vh`.
  - Position: Horizontally centered within the viewport (`left: 50%; transform: translateX(-50%)`).
  - Vertical Alignment: Anchored so the chest fades or crops cleanly just above the bottom lineup text (`bottom: 12vh`).

### 4.2 Background Magenta Glow / Smoke Element
- **Description:** Soft, fluid, organic neon-pink aerosol/smoke gradient cloud.
- **Positioning:**
  - Originates heavily from the middle-left canvas (behind the "019" title).
  - Traverses horizontally behind the model's eyes and ears.
  - Tapers off and diffuses into transparency as it reaches the right date badge.
- **Implementation (CSS / SVG):**
  - High blur radius (`filter: blur(80px) to blur(120px)`).
  - Multiple radial gradients layered using `mix-blend-mode: multiply` or `normal` at `80% - 90%` opacity:
    ```css
    background: radial-gradient(circle at 20% 50%, rgba(245, 30, 186, 0.85) 0%, rgba(255, 73, 216, 0.45) 45%, rgba(236, 236, 236, 0) 75%);
    ```

## 6. Interaction & Motion Blueprint

1. **Hover States:**
   - Nav items (`HOME`, `ABOUT`, `CONTACT`) reveal a subtle opacity shift from `1.0` to `0.6` with `transition: opacity 0.2s ease`.
   - Arrow controls (`<`, `>`) invert on hover: background turns `#F51EBA` with white icon.
   - Artist names scale slightly (`transform: scale(1.02)`) on cursor hover with smooth transition.
2. **Carousel Transition:**
   - Clicking `>` or `<` shifts the artists horizontally.
   - The central model image fades/swaps with dynamic slide easing (`cubic-bezier(0.16, 1, 0.3, 1)`).
3. **Responsive Adaptation (Mobile Breakpoint `< 768px`):**
   - Main menu collapses fully into hamburger icon.
   - Central model scales to `85vw`.
   - "019" moves above the model's head to prevent collision.
   - Lineup reduces to a single visible artist column at a time (`DJEBALI`) flanked by the pagination arrows.
