# UI/UX Design Specification & Clone Blueprint

This document provides a comprehensive, pixel-level specification to replicate the provided mobile user interface. It is designed to guide developers and designers in creating a faithful, production-ready clone of the app screen.

---

## 1. Global Viewport & Layout Settings

*   **Screen Aspect Ratio:** Mobile vertical portrait (optimized for modern iOS devices, e.g., iPhone 14/15 Pro: 393 x 852 pt reference).
*   **Base Layout Model:** Full-screen vertical stack with absolute positioning overlays for interactive card elements.
*   **Corner Radius (Device Container):** `44px` (Simulated via outer shell, inner content extends to full screen width).
*   **Safe Area Margins:**
    *   Top: `44px` (Dynamic Island / Status bar area)
    *   Bottom: `34px` (Home indicator area)
    *   Horizontal Padding (Screen edges): `24px`
