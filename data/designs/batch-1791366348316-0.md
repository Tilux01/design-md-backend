# Design Specification: Mood & Journaling App

## 1. Global Styles & Theme

### Color Palette
* **Primary / Accent (Yellow/Orange):** `#FFB323` (Buttons, active state, "Happy" emotion bar, sun illustration)
* **Background (App):** `#F4F4F2` (Off-white / light cream)
* **Card Backgrounds:** `#FFFFFF` (Pure white for cards and widget sections)
* **Text Primary:** `#1C1C1E` (Dark charcoal for titles and high-emphasis text)
* **Text Secondary:** `#6E6E73` (Medium gray for subtitles, dates, and labels)
* **Text Muted:** `#8E8E93` (Light gray for secondary hints)

### Emotion & Category Colors
* **Happy:** `#FFB323` (Bright Amber)
* **Sad:** `#68352C` (Deep Brown)
* **Calm:** `#7D9E3B` (Olive Green)
* **Anxious:** `#6A705E` (Muted Slate Green)
* **Personal Tag (Pink):** `#F3D3D3` (Light pink background), `#8C4040` (Darker pink text)
* **Family Tag (Purple):** `#E1D5F8` (Light purple background), `#563E8C` (Darker purple text)

### Typography
* **Font Family:** System Default Sans-Serif (e.g., Inter, -apple-system, BlinkMacSystemFont)
* **App Bar / Greeting:** 24px, Bold (`#1C1C1E`)
* **Section Header:** 18px, Semi-Bold (`#1C1C1E`)
* **Body Text:** 14px, Regular (`#6E6E73`)
* **Caption / Tags:** 12px, Medium

---

## Screen 1: Home Dashboard (`/home`)

### Layout Structure
* **Container:** Full screen vertical flex container, padding: 24px horizontal, 16px vertical.
* **Top Bar:** 
  * Left: User greeting ("Hi, Jose Maria" with "Hi," in normal weight and name in bold).
  * Right: Circular profile avatar (approx. 40px diameter, rounded corners).

### Calendar Strip Component
* Horizontal scrollable row of dates (Mon to Sun).
* **Item States:**
  * **Default/Inactive:** White background circle, gray text (e.g., "7", "8", "9").
  * **Active/Selected:** Solid yellow background (`#FFB323`), white text, bold font (e.g., "10").
* Days labels ("Mon", "Tue", etc.) displayed above the date numbers in muted gray.

### "My Journal" Section
* **Header:** 
  * Title: "My Journal" (Left aligned)
  * Action: "See all" (Right aligned, primary color or muted text).
* **Main Card (Morning / Let's Start Your Day):**
  * Background: Linear gradient shifting from soft yellow to warm orange.
  * Illustration: Stylized sunrise over hills with trees and a smiling sun face.
  * Text content: 
    * "Let's start your day" (Bold, 16px)
    * "Begin with a mindful morning reflections." (Regular, 12px)
  * Border radius: 24px.
* **Adjacent Card (Evening preview):**
  * Rotated/Vertical text label ("Evening") with soft gray-brown background.

### "Quick Journal" Section
* **Header:** 
  * Title: "Quick Journal"
  * Action: "See all"
* **Grid / Scrollable Cards:**
  * **Card 1 (Pause & Reflect):**
    * Background: `#FCEAE8` (Soft pink)
    * Title: "Pause & reflect" + Leaf icon
    * Description: "What are you grateful for today?"
    * Footer Tags: `[Today]` (gray pill), `[Personal]` (pink pill)
  * **Card 2 (Set Intentions):**
    * Background: `#EBE5FD` (Soft purple)
    * Title: "Set Intentions" + Smiley emoji
    * Description: "How do you want to feel?"
    * Footer Tags: `[Today]`, `[Family]`

### Bottom Navigation Bar
* Fixed bottom navigation bar with 5 items:
  1. **Home** (House icon, active state highlighted in black/primary)
  2. **Explore** (Compass icon)
  3. **Add (+)** (Floating action style circular button, solid yellow `#FFB323` with white `+` icon)
  4. **Journey** (Book/Journal icon)
  5. **Profile** (User profile outline icon)
* Home indicator bar at the very bottom (iOS style thin horizontal pill).

## Screen 2: My Journal Details / Stats (`/journal/stats`)

### Layout Structure
* **Container:** Full screen vertical flex container, top padding for status bar.
* **Top Navigation Bar:**
  * Left: Back arrow (`<`) inside a circular button.
  * Center: "My Journal" (Title, centered).
  * Right: Options button (`...`) inside a circular button.

### Counter Section
* **Big Number:** `420` (Size: 48px+, Bold, centered).
* **Subtitle:** "Celebrate what made you smile today." (Centered, secondary text color).

### Emotions Breakdown Card
* **Card Container:** White background, rounded corners (24px), drop shadow/border.
* **Header:** 
  * "Emotions" (Bold)
  * "Here are four core emotions for your journal" (Muted, 12px)
* **Vertical Bar Chart (4 columns):**
  * Container for each bar features a tall pill-shaped track with a light gray background (`#E5E5EA`).
  * Filled liquid fill inside each track representing percentages:
    * **Happy:** 48% filled from bottom with `#FFB323`
    * **Sad:** 33% filled from bottom with `#68352C`
    * **Calm:** 27% filled from bottom with `#7D9E3B`
    * **Anxious:** 40% filled from bottom with `#6A705E`
  * Text indicators inside/below the filled bars showing percentages (e.g., "48%").
  * Labels underneath each bar: "Happy", "Sad", "Calm", "Anxious".

### Action Button
* **Button:** Full-width rounded button (Pill shape).
  * Background: `#FFB323` (Yellow)
  * Text: "Create a New Journal" (Dark charcoal/black text, Bold, centered).
* Home indicator bar at the bottom.
