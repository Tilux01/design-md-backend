# UI/UX Specification & Reconstruction Blueprint: "E-Commerce 3D Dimensional Interface"

## 1. Global Overview & Aesthetic Direction
This design is a high-concept, minimalist e-commerce interface that merges 2D mobile app UI with surreal, floating 3D product elements. It leverages the **"Neumorphism meets Glassmorphism"** design trend.

*   **Design Philosophy:** Clean, tactile, and immersive. Elements cast soft, realistic shadows to create depth, simulating augmented reality (AR) or spatial computing (like visionOS).
*   **Color Palette:**
    *   **Background / Canvas:** `F2F2F2` to `E6E6E6` (Soft warm/neutral grey gradient).
    *   **Primary Surface:** Pure White (`FFFFFF`) with high opacity for floating cards.
    *   **Primary Text & Accents:** Dark Charcoal (`222222` to `333333`).
    *   **Secondary / UI Accents:** Muted warm taupe, soft beige (`D9C3B0`), and earthy brown (`8C6D53`).
*   **Typography:**
    *   **Primary Font Family:** **SF Pro Display** (iOS System Font) / **Inter** as a web fallback.
    *   **Secondary/Brand Font:** Clean geometric sans-serif (e.g., **Helvetica Neue** or **Geist**).
    *   **Fallback Stack:** `font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;`

---

## 2. Layout & Screen Structure (Full Screen Execution)

The viewport is treated as an immersive infinite canvas where a vertical mobile device frame is implied, but content and floating UI elements break out of the boundaries.

### A. Background Layer
*   **CSS Style:**
    ```css
    background: radial-gradient(circle at center, #F7F5F0 0%, #E2DDD5 100%);
    ```
*   **Lighting & Shadows:** Soft ambient lighting coming from top-left, casting long, diffuse drop-shadows beneath the phone and floating elements:
    ```css
    box-shadow: 0 30px 60px rgba(0, 0, 0, 0.08), 0 10px 20px rgba(0, 0, 0, 0.04);
    ```

---

## 3. Component Breakdown & Positioning

### 3.1. The Central Mobile Device Frame
*   **Dimensions:** Aspect ratio ~19.5:9, centered horizontally and vertically with a slight 3D perspective tilt (approx. 5–10 degrees on the Y-axis).
*   **Hardware Styling:** Matte titanium/off-white bezel (`#E5E0DA`), rounded corners (`border-radius: 44px`), with a subtle inner bezel shadow.
*   **Status Bar:** Standard iOS layout (Time on left, Wi-Fi/Battery icons on right) in dark charcoal.

### 3.2. App Internal UI (Inside the Phone Screen)
*   **Header Navigation:**
    *   Hamburger menu icon (top left).
    *   Brand title/logo ("Spamre" or similar stylized minimalist serif/sans typography).
    *   Wishlist/Heart icon (accented with a soft coral/orange dot).
*   **Product Grid / Card 1 (Jacket):**
    *   **Position:** Upper half of the screen.
    *   **Card Styling:** Floating white card with rounded corners (`16px`), drop shadow (`0 8px 24px rgba(0,0,0,0.06)`).
    *   **Content:** Image of an olive green oversized jacket/hoodie. Text lines below it simulating product title and price.
*   **Product Grid / Card 2 & 3 (Footwear):**
    *   **Position:** Center to lower half of the screen.
    *   **Content:** White chunky sneakers displayed at dynamic angles.

### 3.3. Floating 3D Elements (Breakout Elements)
These elements break the 2D plane of the phone screen, floating in the 3D space around it to emphasize spatial commerce.

1.  **Floating Baseball Cap (Top Right):**
    *   **Item:** Minimalist beige/off-white dad cap.
    *   **Behavior:** Floats diagonally out of the top right of the phone screen, casting a soft shadow onto the screen surface below it.
2.  **Floating Sneakers (Center Right & Lower Center):**
    *   **Item:** Futuristic white athletic sneakers with straps/laces.
    *   **Behavior:** Appears to levitate outward from the device UI into the negative space.
3.  **Micro-UI Thumbnail Cards (Ambient floating widgets):**
    *   Scattered small square glassmorphic cards (`background: rgba(255,255,255,0.85); backdrop-filter: blur(12px);`) containing miniature product icons (shoes, jackets, accessories).
    *   Positioned dynamically on the left and right margins of the main phone body, creating depth of field (blurred elements in the far background/foreground).

## 5. Animation & Motion Design Specification (Framer Motion / CSS Keyframes)

To achieve the exact floating, immersive feel seen in the reference media, apply the following micro-interactions and continuous loops:

### 1. Ambient Floating (Levitation Effect)
Applied to the cap, sneakers, and micro-cards to simulate weightlessness.
```css
@keyframes float {
  0% {
    transform: translateY(0px) rotate(0deg);
  }
  50% {
    transform: translateY(-12px) rotate(1.5deg);
  }
  100% {
    transform: translateY(0px) rotate(0deg);
  }
}

.floating-element-1 {
  animation: float 6s ease-in-out infinite;
}

.floating-element-2 {
  animation: float 8s ease-in-out infinite reverse;
  animation-delay: 1s;
}
```

### 2. Parallax Depth on Mouse Move / Gyroscope (JS / React Spring)
*   **Depth Layers:**
    *   `Layer 0 (Background):` Moves at `0.05` multiplier.
    *   `Layer 1 (Phone Frame):` Moves at `0.1` multiplier.
    *   `Layer 2 (Floating 3D Objects):` Moves at `0.25` to `0.4` multiplier (creates a strong stereoscopic parallax effect).

### 3. Glassmorphism & Lighting Shimmer
*   Add a subtle moving gradient overlay on the floating cards to mimic light catching glossy surfaces:
```css
@keyframes shimmer {
  0% { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}
```
```css
.glass-card {
  background: rgba(255, 255, 255, 0.75);
  backdrop-filter: blur(16px);
  -webkit-backdrop-filter: blur(16px);
  border: 1px solid rgba(255, 255, 255, 0.6);
}
