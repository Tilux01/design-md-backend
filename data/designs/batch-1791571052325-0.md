# UI Design Specification: Niond Dashboard

## 1. Global Styles & Layout Structure

### 1.1. Viewport & Canvas
- **Layout Type:** Full-screen CSS Grid / Flexbox application layout.
- **Background Color:** Light grayish-white canvas (`#F4F6F9` or similar modern SaaS dashboard background).
- **Border Radius (Main Container):** `24px` for the central floating dashboard card, set against a soft neutral backdrop.

### 1.2. Typography System
- **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif.
- **Fallback Font:** Standard system sans-serif stack.
- **Scale:**
  - **Dashboard Header:** 24px, Bold (Weight: 700), Color: `#1A1D1F`
  - **Section Titles (e.g., "Regular Sell", "Top Store"):** 16px - 18px, Semi-bold (Weight: 600), Color: `#1A1D1F`
  - **Card Metrics / Values:** 20px - 28px, Bold (Weight: 700)
  - **Body / Metadata Text:** 12px - 14px, Regular to Medium (Weight: 400–500), Color: `#6F767E`
