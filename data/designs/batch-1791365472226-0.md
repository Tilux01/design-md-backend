# Creative Agency Web Design Specification (Full Screen Replica)

This document outlines the precise specifications to create a full-screen, pixel-perfect clone of the provided creative agency landing page design. 

---

## 1. Global Styles & Variables

### 1.1 Colors
*   **Background (Canvas):** `#f0f0f0` (Off-white / light gray)
*   **Primary Accent / Hand Color:** `#0c6c77` (Deep Teal / Cyan)
*   **Secondary Accent (Drip/Liquid):** `#ffffff` (Pure White with shadow depth)
*   **Text Dark (Headings/Body):** `#1a1a1a` (Near Black)
*   **Text Light (Nav/Subtext):** `#666666` (Medium Gray)
*   **Subtle Line / Border Color:** `#d1d1d1`

### 1.2 Typography
*   **Font Family:** Inter, Roboto, or Helvetica Neue (Sans-serif)
*   **Navigation Links:** 11px, Uppercase, Letter-spacing: `1.5px`, Weight: `500`
*   **Main Hero Typography ("CREATIVE"):** 
    *   Size: Responsive, approx. `14vw`
    *   Weight: `700` (Bold)
    *   Style: Outline/Stroke style with inner/drop shadow (Neumorphic debossed effect)
*   **Body Copy ("We create beautiful things for you"):** 
    *   Heading: `24px`, Weight: `600`
    *   Sub-label ("LEARN MORE"): `10px`, Uppercase, Letter-spacing: `1px`
    *   Year ("2018"): `12px`, Weight: `400`, Color: `#888888`

---

## 2. Layout & Structure

### 2.1 Viewport Setup
*   **Layout:** Full screen (`100vw` width, `100vh` height)
*   **Overflow:** Hidden (prevent scrolling)
*   **Centering:** Flexbox/Grid container with max-width limits for inner content aligned to standard desktop container padding (`80px` left/right).

---

## 3. Component Breakdown

### 3.1 Header / Navigation
*   **Position:** Absolute / Fixed at the top (`top: 40px`, `left: 80px`, `right: 80px`)
*   **Layout:** Flexbox, Space-between (Left: Nav Links, Right: Controls)
*   **Left Section (Nav Links):**
    *   Items: `HOME`, `ABOUT`, `PORTFOLIO`, `CONTACT`
    *   Spacing: `30px` gap between items
*   **Right Section (Controls):**
    *   Indicator: `01 / 03` (Font size: `12px`, tracking `1px`)
    *   Search Icon (`🔍`)
    *   Menu/Hamburger Icon (`☰`)
    *   Spacing: `25px` gap between control items

### 3.2 Left-Side Elements
*   **Vertical Label:** 
    *   Text: `LATEST PROJECT`
    *   Position: Absolute (`left: 40px`, vertically centered)
    *   Transform: `rotate(-90deg)`
    *   Font Size: `10px`, Letter-spacing: `2px`
*   **Bottom-Left Hero Text Block:**
    *   Position: Absolute (`bottom: 60px`, `left: 80px`)
    *   Includes small vertical indicator line, "LEARN MORE" label, main heading ("We create beautiful things for you"), and year ("2018").

### 3.3 Center Visual (Hero Artwork)
*   **Central Composition:** 
    *   A stylized 3D hand rendered in **Deep Teal (`#0c6c77`)**, angled diagonally upwards towards the right.
    *   White liquid/paint (`#ffffff`) is shown peeling/dripping off the fingers and down the forearm.
    *   **Shadows:** Soft, layered drop shadows beneath the hand and liquid to give a paper-cut / 3D floating effect against the `#f0f0f0` background.
*   **Background Typography ("CREATIVE"):**
    *   Position: Centered horizontally behind the hand graphic.
    *   Rendering: Large hollow/outline text with realistic drop shadows simulating depth embedded into the page background.
*   **Inline Annotations:**
    *   A thin dashed vertical line extending down from the right-hand side with a dot and the text label: `CREATIVE AGENCY` (`9px`, uppercase).

### 3.4 Right-Side Elements
*   **Social Links:**
    *   Position: Absolute (`right: 80px`, vertically centered)
    *   Items: Pinterest (`P`), Twitter (`t`), Facebook (`f`) stacked vertically with `20px` gap.
*   **Bottom-Right Video Widget:**
    *   Position: Absolute (`bottom: 60px`, `right: 80px`)
    *   Dimensions: Approx. `220px` width $\times$ `120px` height
    *   Content: Light background card with a thumbnail of a person, a play button overlay (`▶` inside a teal circle), and a "watch video" label at the top-left corner (`10px`).

---

## 4. Interactive States (CSS Hover / Transitions)
*   **Nav Links:** Smooth color transition from `#666666` to `#0c6c77` on hover.
*   **Video Widget:** Slight scale-up (`scale(1.02)`) and deeper box-shadow on hover.
*   **Social Icons:** Opacity shift from `0.7` to `1` on hover.
