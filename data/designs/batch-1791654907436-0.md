# Design Specification: "Library" Mobile App Interface

## 1. Global Layout & Canvas

*   **Screen Orientation:** Portrait (Mobile view optimized for iPhone 14/15 Pro style frame layout, displayed edge-to-edge).
*   **Background Color:** Light off-white / very pale cool gray (`#EFEFEF` to `#F4F4F4` gradient/solid).
*   **Grid System:** Asymmetric vertical layout with staggered cards, horizontal scrolling carousels, and explicit padding (`24px` horizontal margins).
*   **Status Bar:** Standard iOS layout at the top:
    *   Time: `9:41` (Bold, dark gray/black).
    *   Right Icons: Cellular signal, WiFi, and Battery icon in black.
    *   Dynamic Island / Notch: Centered pill cutout at the top.

---

## 2. Typography & Fonts

### Primary Font Family
*   **Primary Typeface:** SF Pro Display / Inter (Clean, geometric sans-serif).
*   **Fallback Stack:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.

### Text Hierarchy

*   **Main Header ("Library"):**
    *   Font Size: `36px` / `2.25rem`
    *   Font Weight: Medium / Semi-bold (`600`)
    *   Line Height: Tight (`1.1`)
    *   Color: Near-black (`#111111`)
    *   Letter Spacing: Tightly tracked (`-0.03em`)

*   **Subtitle ("A curated collection of stories and inspiration"):**
    *   Font Size: `13px` / `0.8125rem`
    *   Font Weight: Regular (`400`)
    *   Color: Muted Gray (`#6B6B6B`)
    *   Margin Bottom: `24px`

*   **Card Title ("Silent Echoes"):**
    *   Font Size: `24px` / `1.5rem`
    *   Font Weight: Medium (`500`)
    *   Color: Dark Charcoal (`#1A1A1A`)
    *   Line Height: `1.2`

*   **Section Header ("Discover something new every day"):**
    *   Font Size: `12px` / `0.75rem`
    *   Font Weight: Regular (`400`)
    *   Color: Muted Gray (`#555555`)

*   **Featured Category Headers ("Life Stories", "Personal Moments"):**
    *   Font Size: `28px` / `1.75rem`
    *   Font Weight: Medium (`500`)
    *   Color: Dark Gray (`#222222`)
    *   Line Height: `1.1`

---

## 3. UI Components & Elements

### A. Top Navigation / Header Area
*   **Filter/Settings Button:**
    *   Position: Top right, aligned with the "Library" title.
    *   Shape: Circular pill button with a light gray fill (`#E5E5E5`).
    *   Icon: Minimalist slider/filter control icon in black.

### B. Main Featured Card ("Silent Echoes")
*   **Container:**
    *   Shape: Rounded rectangle (Large corner radius, approx. `28px`-`36px`).
    *   Background: Light neutral gray (`#E2E2E2`).
    *   Padding: `24px`.
*   **Internal Elements:**
    *   **Text Block:** Positioned top-left ("Silent Echoes").
    *   **Platform Badges:** Two small circular white icons positioned top-right of the card content area:
        *   Left: Apple logo icon inside a white circle.
        *   Right: Spotify logo icon inside a white circle.
    *   **Circular Graphic Elements (Bottom row):**
        *   *Left Image Circle:* Vibrant macro photograph of a bright orange poppy flower against a warm orange/amber gradient background. Perfectly circular crop.
        *   *Center Action Circle:* Solid white circular badge containing a black square button with an external link arrow icon (`↗`).
        *   *Right Preview Circle:* Partial view of a dark moody landscape image with a red/orange sunset horizon, hinting at a carousel continuation.

### C. Secondary Discover Card ("Discover something new every day")
*   **Container:**
    *   Shape: Rounded rectangle overlapping or sitting directly below the main card.
    *   Background: Pure White (`#FFFFFF`).
    *   Padding: `18px`.
    *   Arrow Icon: Small top-right diagonal arrow (`↗`) indicating interactivity.

### D. Bottom Featured Section ("Featured")
*   **Section Label:** Small uppercase/regular caption reading "Featured" in light gray (`#777777`).
*   **Carousel Cards:**
    *   Horizontal scrolling layout with peek effect for adjacent cards.
    *   *Card 1 ("Life Stories"):* White background, large typography, clean padding.
    *   *Card 2 ("Personal Moments"):* White background, matching typography style.

---

## 4. Images & Asset Descriptions

1.  **Orange Poppy Flower Image:**
    *   **Description:** A close-up photograph of a vibrant California poppy with textured orange petals and delicate green stem, set against a warm, sunlit amber gradient background.
    *   **Format/Style:** Circular masked image, backgroundless relative to the card container (fills its own circular frame seamlessly).
    *   **Placement:** Bottom-left inside the "Silent Echoes" featured card.

2.  **Moody Sunset Landscape Image (Right edge):**
    *   **Description:** A dark, moody horizon shot featuring silhouettes of trees or architecture against a deep crimson-orange twilight sky.
    *   **Placement:** Peeking in from the right side of the main card container, indicating a horizontal swipe action.

---

## 5. Interactive States & Micro-interactions
*   **External Link Button:** The center white circle with the black `↗` icon features a subtle drop shadow to indicate a clickable elevation state.
*   **Carousel Behavior:** The bottom section ("Life Stories", "Personal Moments") hints at overflow scrolling to the right.
