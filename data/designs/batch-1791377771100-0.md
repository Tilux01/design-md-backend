# UI/UX Specification: "Science Made Stylish" Landing Page Clone

## 1. Overview & Layout Strategy
This specification details a pixel-perfect, full-screen clone of the provided promotional landing page for a smart water bottle (CrazyCap). The layout is structured as a modern, minimalist hero section centered on a clean white canvas. 

* **Canvas Setup:** Full-screen viewport (`100vw` width, `100vh` height).
* **Background Integration:** The outer environment consists of a dynamic, smooth gradient transitioning from **Cyan/Teal** (top-left) to **Coral/Orange** (bottom-right). A soft, dark drop shadow is cast beneath the central white card to create depth.
* **Inner Card:** A central, rounded rectangular container (`border-radius: ~24px`) housing all primary elements, maintaining generous whitespace (padding).

---

## 2. Color Palette
| Color Role | Hex Code / Description | Usage |
| :--- | :--- | :--- |
| **Primary Dark** | `#111111` | Main headings ("Science made stylish"), body text, and the primary bottle color. |
| **Primary Teal** | `#00C2CB` | Central circular vector backdrop, website accents, and the top-left background glow. |
| **Primary Orange** | `#FF5722` | CTA button fill and the bottom-right background gradient tone. |
| **Muted Grey** | `#757575` | Subheadings and secondary description text. |
| **Card White** | `#FFFFFF` | Main content container background. |
| **UI Dark Pill** | `#1A1A1A` | Background for the bottom-left input/domain pill. |

---

## 3. Typography & Font Stack
The design relies on a clean, geometric sans-serif typeface family (comparable to **Inter**, **Poppins**, or **SF Pro Display**).

### Font Stack Hierarchy:
1. **Primary/Fallback Stack:** `font-family: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;`

### Text Elements:
* **Main Heading ("Science made stylish"):**
  * **Font Weight:** 700 (Bold)
  * **Line Height:** Tight (`1.1`)
  * **Size:** Responsive scaling (approx. `48px` to `56px` on desktop).
* **Body Description ("CrazyCap packs multiple tech..."):**
  * **Font Weight:** 400 (Regular) / 500 (Medium)
  * **Line Height:** Relaxed (`1.5`)
  * **Size:** `14px` - `16px`
  * **Color:** `#757575`
* **CTA Button Text ("Our tech"):**
  * **Font Weight:** 600 (Semi-bold)
  * **Size:** `14px`
  * **Color:** `#FFFFFF`

---

## 4. Component Breakdown & Positioning

### A. Left Column: Text & Call to Action
* **Heading:** Stacked across three lines:
  ```
  Science
  made
  stylish
  ```
* **Paragraph:** Located directly below the heading with standard paragraph spacing (`margin-bottom: 24px`).
* **Interactive Bottom Pill:** A composite UI element positioned at the lower-left of the content area.
  * **Input/Domain Display:** A dark pill (`#1A1A1A`) displaying placeholder text like `name@domain.com` in muted white/grey text.
  * **Action Button:** An overlapping vibrant orange (`#FF5722`) pill button reading **"Our tech"** with a subtle right-pointing arrow icon or clean typographic finish.

### B. Center: The Hero Product & Splash Effect
* **Teal Circular Backdrop:** A large solid cyan/teal circle positioned slightly right of center, acting as a focal point for the main product.
* **Main Product (Black Bottle):** A sleek, matte-black insulated bottle angled diagonally (approx. `-30` to `-45` degrees). Features a metallic silver cap.
* **Splash/Water Effect:** Dynamic, semi-transparent water splash graphics rendered around the lower half of the bottle to emphasize hydration, freshness, and technology.

### C. Right Column: Variant Selector / Thumbnail Stack
A vertical column containing three smaller color/style variants of the bottle floating inside matching water splash bubbles:
1. **Top Variant:** Ice Blue / Silver bottle variant.
2. **Middle Variant:** Pastel Pink / Rose Gold variant.
3. **Bottom Variant:** Glossy White variant.
* *Interaction:* Clicking any of these thumbnails can trigger a state change to swap the main central bottle color.

---

## 5. Micro-Interactions & Animations (CSS / JS)

To achieve an exact clone, implement the following smooth animations:

1. **Floating Product Animation:**
   * Apply a continuous subtle floating keyframe animation (`translateY`) to the central black bottle and water splash element to give it a weightless, premium feel.
   ```css
   @keyframes float {
     0% { transform: translateY(0px) rotate(-35deg); }
     50% { transform: translateY(-8px) rotate(-35deg); }
     100% { transform: translateY(0px) rotate(-35deg); }
   }
   ```
2. **Hover Effects on Thumbnails:**
   * Scale up (`transform: scale(1.05)`) with a smooth `transition: all 0.3s ease` when hovering over the right-hand variant thumbnails.
3. **CTA Button Hover:**
   * The **"Our tech"** orange button should feature a brightness increase or subtle box-shadow elevation on hover (`box-shadow: 0px 8px 20px rgba(255, 87, 34, 0.4)`).
