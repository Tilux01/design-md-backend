# UI/UX Specification & Design System Clone Document

**Project Name:** Trantor Crypto Wallet Mobile App  
**Target Platform:** iOS & Android (Mobile Viewport: 390px × 844px standard frame)  
**Design Philosophy:** Sleek, high-contrast fintech interface combining deep dark mode cards, neon mint green accents (`#A3F2CD`), frosted glass panels, and data-dense analytics visualizations.

---

## 1. Typography & Font Stack

The interface uses a clean, geometric sans-serif typeface optimized for financial legibility and dense tabular data.

*   **Primary Font Family:** `Inter`, `SF Pro Display`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `Helvetica Neue`, `Arial`, `sans-serif`
*   **Fallback Strategy:** System-native UI sans-serif stack prioritized to ensure zero layout shift during font loading.

### Type Scale & Hierarchy
*   **Greeting / Secondary Header:** 
    *   Size: `14px` / `0.875rem`
    *   Weight: Regular (`400`) / Medium (`500`)
    *   Line Height: `1.2`
*   **Screen Title / Main Balance Value:** 
    *   Size: `24px` to `32px` (`1.5rem` - `2rem`)
    *   Weight: Bold (`700`)
    *   Letter Spacing: `-0.02em`
*   **Card Labels & Currency Symbols:** 
    *   Size: `12px` / `0.75rem`
    *   Weight: Medium (`500`)
    *   Color: Muted Slate / Secondary Text
*   **Button Text / Interactive Elements:** 
    *   Size: `14px` / `0.875rem`
    *   Weight: Semi-Bold (`600`)

---

## 2. Color Palette & Theming

The design uses a sophisticated high-contrast dark theme with bright mint highlights and neutral charcoal surface layers.

### Primary Colors
*   **Mint Green (Accent):** `#A3F2CD` (Used for primary buttons, active tabs, positive percentage changes, and highlights)
*   **Mint Hover / Light Tint:** `#C8F9E2`
*   **Dark Mode Background (App Canvas):** `#F0F0F2` (Outer presentation canvas; actual app backgrounds are deep dark charcoal/black `#121214` and `#1A1A1E`).

### Neutral & Surface Colors
*   **Pure Black / Void:** `#000000` (Used for bottom navigation bars, primary conversion containers)
*   **Dark Card Surface:** `#1E1E24` (Cryptocurrency list items, secondary containers)
*   **Muted Border / Divider:** `#2C2C35`
*   **Primary Text (Light Theme elements):** `#111111`
*   **Primary Text (Dark Theme elements):** `#FFFFFF`
*   **Secondary Text / Subtitles:** `#8E8E93`
*   **Success Green (Badges):** `#34C759`

## 4. Micro-Interactions & Animations

1.  **Swap Node Rotation:** Tapping the central circular swap icon (`⇄`) triggers a **360-degree rotation animation** while smoothly cross-fading the input and output currency values.
2.  **Timer Countdown:** The exchange rate timer (`00:08:43`) features a live, decrementing second-by-second countdown animation.
3.  **Tab Switching:** Smooth layout sliding animation when toggling between timeframes (`7 days`, `1m`, `1y`) on the analytics chart.
4.  **Active Button States:** Scale-down transform (`scale(0.96)`) on active press for all primary buttons and interactive cards.
