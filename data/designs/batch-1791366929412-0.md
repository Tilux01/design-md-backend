# Lamborghini Showcase Landing Page Design Specification

## 1. Global Styles & Variables

*   **Background Color:** Pure White (`#FFFFFF`)
*   **Primary Font Family:** Clean, geometric sans-serif (e.g., *Helvetica Neue*, *Arial*, or *Inter*)
*   **Secondary/Stylized Font (Header Titles):** Custom angular/futuristic geometric display font for car names (Aventador SVJ, Huracán, Urus).
*   **Border Color / Dividers:** Light gray (`#E5E5E5`)
*   **Text Primary:** Dark Charcoal/Black (`#1A1A1A`)
*   **Text Secondary (Labels):** Muted Gray (`#8C8C8C`)
*   **Layout Structure:** Responsive card-based layout featuring 3 distinct full-width horizontal presentation modules.

---

## 2. Navigation Bar (Header)

*   **Position:** Fixed/Sticky at the top of each view card, spanning full width with inner padding.
*   **Left Element:** 
    *   Lamborghini Shield Logo (Gold/Black crest).
*   **Center Menu Items:** 
    *   Hamburger menu icon (3 horizontal lines)
    *   "Models"
    *   "Custom solution"
    *   "Ownership"
    *   "Motorsport"
*   **Right Element:** 
    *   Search icon (Magnifying glass).

---

## 3. Hero Modules (Per Car Variant)

Each car card contains a brand-specific color-themed display area:

### Module 1: Aventador SVJ
*   **Accent Color / Typography:** Cyan/Teal (`#00E5FF` or turquoise gradient feel).
*   **Stylized Header Text:** "AVENTADOR SVJ" (Futuristic custom glyphs).
*   **Car Asset:** Side-profile render of a cyan/teal Aventador SVJ with a large rear wing and black wheels.
*   **Specs Bar:**
    *   *Brand / Model:* LAMBORGHINI / AVENTADOR LP 780-4 ULTIMAE ROADSTER
    *   *Max Speed:* `355 km/h`
    *   *0–100 km/h:* `2.9 s`
    *   *HP:* `770`
    *   *Action Button:* Circular `+` (Plus) icon button on the far right.

### Module 2: Huracán
*   **Accent Color / Typography:** Lime Green (`#76FF03`).
*   **Stylized Header Text:** "HURACÁN" (Futuristic custom glyphs).
*   **Car Asset:** Side-profile render of a lime green Huracán Tecnica.
*   **Specs Bar:**
    *   *Brand / Model:* LAMBORGHINI / HURACÁN TECNICA
    *   *Max Speed:* `325 km/h`
    *   *0–100 km/h:* `3.2 s`
    *   *HP:* `630`
    *   *Action Button:* Circular `+` (Plus) icon button on the far right.

### Module 3: Urus
*   **Accent Color / Typography:** Deep Charcoal / Subtle Neon Lime accents on wheels/trim (`#333333` with `#C6FF00` highlights).
*   **Stylized Header Text:** "URUS" (Futuristic custom glyphs).
*   **Car Asset:** Side-profile render of a black Urus Graphite Capsule with lime brake calipers/accents.

    *   *Brand / Model:* LAMBORGHINI / URUS GRAPHITE CAPSULE
    *   *Max Speed:* `305 km/h`
    *   *0–100 km/h:* `3.6 s`
    *   *HP:* `640`
    *   *Action Button:* Circular `+` (Plus) icon button on the far right.

---

## 4. Specs Bar Layout Structure

The specs bar sits directly below each car graphic, enclosed in a thin-bordered container with a white background:

*   **Column 1 (Identity):** Model name in bold, submodel in smaller muted text.
*   **Column 2 (Max Speed):** Label "max speed" (small, muted) stacked above value `XXX km/h` (bold).
*   **Column 3 (Acceleration):** Label "0-100 km/h" (small, muted) stacked above value `X.X s` (bold).
*   **Column 4 (Horsepower):** Label "HP" (small, muted) stacked above value `XXX` (bold).
*   **Column 5 (Action):** Dedicated vertical cell containing a centered minimalist `+` icon button inside a subtle border box.
