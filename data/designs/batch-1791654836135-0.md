# DESIGN SPECIFICATION: Coffee Shop Mobile Application UI Clone

## 1. Global Styles & Theming

### Color Palette (Warm Coffee/Retro Aesthetic)
*   **Primary Background (`#F5F0EA`):** Soft, warm off-white used as the main screen background for high-contrast readability against dark elements.
*   **Card Background (`#FFFFFF`):** Pure white used for content containers, lists, and floating cards.
*   **Primary Accent / Dark Coffee (`#2C1E1A`):** Deep espresso brown used for headers, primary buttons, major text, and dark theme screens.
*   **Secondary Accent / Warm Caramel (`#C88A58`):** Rich amber-brown used for primary CTA buttons, highlighted items, and accent badges.
*   **Muted Brown / Gray (`#8E7D73`):** Used for secondary text, descriptions, inactive states, and icons.
*   **Light Tint (`#EADCC9`):** Soft cream tone used for subtle section separators, inactive tabs, and inner card fills.

### Typography
*   **Primary Font Family:** `Inter`, fallback to `SF Pro Display`, `-apple-system`, `sans-serif` for clean UI labels.
*   **Display / Header Font Family:** `Playfair Display`, fallback to `Georgia`, `serif` for editorial/heading elements (e.g., brand titles, prominent prices, or coffee names).

## 3. Asset Guidelines (Images & Icons)

*   **Images:** All product and avatar images should be high-resolution, professionally styled lifestyle photography of coffee, cups, and beans filtered through a warm, high-contrast sepia/espresso color grade. 
*   **Transparency:** Any profile avatars or standalone icons must be supplied as **backgroundless PNGs or SVGs** to blend seamlessly into the `#F5F0EA` and `#FFFFFF` containers.
*   **Icons:** Use a consistent iconography set (preferably Feather Icons or Lucide with a stroke width of `2px` and colored in `#2C1E1A` or `#8E7D73`).
