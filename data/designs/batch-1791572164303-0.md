# Design Specification: Task Management Dashboard

## 1. Global Layout & Structure
- **Viewport:** Designed for a wide, desktop screen (minimum width: 1440px suggested).
- **Background:** 
  - Main application container: Pure white (`#FFFFFF`) with subtle rounded corners and drop shadows.
  - Outer background: Very light grayish-blue (`#F1F5F9`).
- **Layout Paradigm:** 3-Column Dashboard structure:
  1. **Left Sidebar:** Navigation and icons.
  2. **Center Section:** Timeline view (Gantt-style) and Kanban boards (Draft, In Progress, Editing, Done).
  3. **Right Sidebar:** User profile, Plan schedule, Efficiency metrics, and Completed tasks statistics.

---

## 2. Typography & Fonts
- **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif.
- **Fallback Stack:** Sans-serif.
- **Font Hierarchy:**
  - **Dashboard Title ("Task Management"):** 28px, Bold (700), Color: `#0F172A`.
  - **Section Headers ("DRAFT", "IN PROGRESS", etc.):** 11px, Bold (700), Letter-spacing: 0.05em, Color: `#64748B`.
  - **Card Headings / Main Tasks:** 13px, Semi-bold (600), Color: `#0F172A`.
  - **Body / Metadata Text:** 11px–12px, Regular (400) to Medium (500), Color: `#475569`.

---

## 3. Left Sidebar (Navigation)
- **Width:** Narrow icon/text navigation rail (approx. 80-100px wide).
- **Top Brand/Menu Icon:** Hamburger icon (`#0F172A`).
- **Navigation Items:**
  - Dashboard (Grid icon)
  - Message (Envelope icon)
  - Tasks (Checkmark icon)
  - Planning (Calendar/Grid icon)
  - Global (Globe icon)
  - Analytics (Chart icon)
  - Finance (Wallet/Card icon)
- **Active State:** Highlighted with a subtle tint or distinct primary color indicator.

---

## 4. Center Section: Timeline & Kanban Board

### A. Timeline / Gantt Chart (Top Center)
- **Date Axis:** Ranges horizontally from `28` to `06` (representing consecutive days). Vertical grid lines drop down across the rows.
- **Task Rows (Color-Coded Bars with Progress):**
  - **Row A (Blue):** "Incididunt ut labore et..." — Progress bar spans from day 29 to 02, displaying **55%** completion. Features a circular avatar icon on the left (`A`).
  - **Row B (Purple):** "Ipsum..." — Progress bar spans from day 30 to 04, displaying **80%** completion. Features avatar icon `B`.
  - **Row C (Pink):** "Dolor..." — Progress bar spans from day 30 to 03, displaying **65%** completion. Features avatar icon `C`.
  - **Row D (Yellow/Orange):** "Magna..." — Progress bar spans from day 01 to 05, displaying **75%** completion. Features avatar icon `D`.

### B. Kanban Board Columns (Bottom Center)
Divided into four distinct columns: **Draft**, **In Progress**, **Editing**, and **Done**. Each column contains card components with rounded corners, drop shadows, and internal padding.

1. **DRAFT Column:**
   - Card headers: "Main Task".
   - Sub-items with assignee initials (`A`, `B`), comment counts, and attachment indicators.
   
2. **IN PROGRESS Column:**
   - Card with assignee initial (`C`).
   - Progress bar showing **75%** complete.
   - Interactive metric badges (Comments count, attachments, star indicator).

3. **EDITING Column:**
   - Task list containing bulleted text rows with small circular avatars/status dots on the right.
   - "Supervisor" section at the bottom with avatar bubbles and a star icon.

4. **DONE Column:**
   - Completed task items marked with green checkmark icons (`#10B981`).

---

## 5. Right Sidebar (User Profile & Analytics)

### A. User Profile Header
- **Avatar:** Multi-colored geometric abstract avatar graphic (circular composition of pink, blue, yellow, and purple shapes).
- **Name:** "Name Surname" (Bold, 16px, `#0F172A`).
- **Subtitle:** "Adipiscing elit sed do eiusmod" (11px, `#94A3B8`).

### B. Plan Section
- **Header:** "Plan"
- **Schedule Items:**
  - Time blocks with colored indicator pills (`ABC` in purple/pink, `ABD` in blue).
  - Time ranges: `12:00 - 13:00` and `13:00 - 14:00` with vertical active status bars on the right edge.

### C. Efficiency Metrics
- **Header:** "Efficiency"
- **Circular Progress Indicators:** Four circular progress rings labeled **A** (75%), **B** (44%), **C** (68%), and **D** (55%) rendered in Blue, Purple, Pink, and Yellow respectively.

### D. Completed Tasks Statistics
- **Header:** "Completed tasks"
- **Bar Chart:** Vertical column chart showing fluctuating productivity metrics across days/categories.
- **Metric Totals at Bottom:**
  - Author A: **210**
  - Author B: **110**
  - Author C: **176**
  - Author D: **145**

---

## 6. Color Palette Reference
- **Primary Blue:** `#3B82F6`
- **Secondary Purple:** `#8B5CF6`
- **Accent Pink:** `#EC4899`
- **Accent Yellow/Orange:** `#F59E0B`
- **Success Green:** `#10B981`
- **Dark Neutral (Text):** `#0F172A`
- **Gray Neutral (Muted Text):** `#64748B`
- **Light Neutral (Backgrounds):** `#F8FAFC` / `#F1F5F9`
- **Card Background:** `#FFFFFF` with soft shadows (`box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.05)`).
