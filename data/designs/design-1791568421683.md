# PAYROT - Global Payment Platform Landing Page Clone

This document provides a comprehensive design specification for cloning the landing page shown in the reference image. The design is built around a modern, tech-forward fintech aesthetic using deep navy blues, icy cyan gradients, clean white spaces, and vibrant imagery.

## 1. Global Styles & Design Tokens

### Color Palette
*   **Primary Dark (Navy):** `#0A192F` or `#0b1d35` (Used for background framing, text, and primary callout sections)
*   **Primary Light (Background):** `#F0F4F8` to `#E4EDF6` (Linear vertical gradient for main container backgrounds)
*   **Accent Cyan/Blue:** `#0072FF` to `#00C6FF` (Used for buttons, glowing effects, UI highlights)
*   **Pure White:** `#FFFFFF` (Card backgrounds, header elements)
*   **Text Primary:** `#0A192F` (Dark headings)
*   **Text Secondary:** `#5A6A85` (Muted descriptions, body copy)

### Typography
*   **Primary Font Family:** `Inter`, system-ui, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `sans-serif`
*   **Fallback Stack:** `sans-serif`
*   **Font Weights Used:** 
    *   Regular (400) - Body text, descriptions
    *   Medium (500) - Nav links, subheadings
    *   Semi-Bold / Bold (600/700) - Main headings, buttons, stats
