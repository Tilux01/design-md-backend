# Design Specification & UI/UX System

---

## 1. Design Philosophy & Overall Aesthetic
* **Mood & Archetype:** Clean, minimalist e-commerce/utility dashboard with a structured, component-driven architecture.
* **Visual Density:** High density, organized into compact grid layouts and tabular panels with clean card containers.
* **Whitespace Balance:** Balanced vertical rhythm with dense horizontal element groupings. Padding inside cards is compact (`8px` to `16px`).
* **Theme Balance:** Light-mode primary interface with neutral grey structural elements (`#F8F9FA` to `#FFFFFF`) paired with high-contrast dark text (`#1A1A1A`) and high-saturation interactive accents (Yellow/Amber `#F59E0B`, Indigo `#6366F1`).

---

## 2. Color Palette & Design Tokens

* **Primary Color:** Deep Blue / Indigo (`#2563EB`, Hover: `#1D4ED8`, Active: `#1E40AF`)
* **Secondary & Accent:** Amber/Yellow (`#F59E0B`), Emerald Green (`#10B981`)
* **Base Background:** Off-white canvas (`#F3F4F6`)
* **Surface Backgrounds:** Pure white (`#FFFFFF`) card containers, semi-transparent grey overlays (`rgba(0, 0, 0, 0.05)`)
* **Border & Divider Colors:** Light grey subtle dividers (`#E5E7EB`)
* **Text Colors:** Primary (`#111827`), Muted (`#6B7280`), Inverse (`#FFFFFF`), Accent (`#2563EB`)

## 3. Typography System & Hierarchy

* **Font Families:** Inter, system-ui, -apple-system, sans-serif
* **Scale Breakdown:**
  * **Page Title:** 24px (1.5rem), Font-weight: 600, Line-height: 32px, Letter-spacing: -0.02em
  * **Section Heading:** 18px (1.125rem), Font-weight: 600, Line-height: 24px, Letter-spacing: -0.01em
  * **Card Title / Subhead:** 14px (0.875rem), Font-weight: 500, Line-height: 20px, Letter-spacing: 0
  * **Body Copy:** 13px (0.8125rem), Font-weight: 400, Line-height: 18px, Letter-spacing: 0
  * **Captions / Micro-labels:** 11px (0.6875rem), Font-weight: 500, Line-height: 14px, Letter-spacing: 0.05em (Uppercase)

---

## 4. Layout Architecture & Spatial Grid

* **Container Max-Width:** Fluid max 1280px with standard 24px horizontal padding.
* **Spacing Scale:** 4px (tight), 8px (sm), 16px (md), 24px (lg), 32px (xl).
* **Section Sequence:** Top Navigation Bar $\rightarrow$ Filter/Category Tabs $\rightarrow$ Primary Feature Grid $\rightarrow$ Secondary Action/List Area.
* **Z-Index Hierarchy:** Base content (`z-0`), Dropdowns/Tooltips (`z-10`), Modals/Overlays (`z-50`).

---

## 5. AI Design Traits, Micro-Badges & Special Glyphs

* **Micro-Badges:** Pill callouts with high-tracking uppercase labels.
  * *CSS Spec:* `padding: 2px 8px; font-size: 10px; font-weight: 600; letter-spacing: 0.08em; border-radius: 9999px; text-transform: uppercase;`
* **Symbols & Glyphs:** Use Unicode and safe HTML entities (`✦` / `&#10022;`, `—` / `&mdash;`, `●` / `&#9679;`).

## 7. Motion Mechanics, Framer Motion & CSS Animation Code

* **Transition Durations & Easing:** Standard UI transitions use `200ms cubic-bezier(0.16, 1, 0.3, 1)`.

### Framer Motion React Component Variant
```jsx
export const cardVariant = {
  hidden: { opacity: 0, y: 8 },
  visible: { 
    opacity: 1, 
    y: 0,
    transition: { duration: 0.2, ease: [0.16, 1, 0.3, 1] }
  },
  hover: {
    y: -2,
    boxShadow: "0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -1px rgba(0, 0, 0, 0.06)",
    transition: { duration: 0.15, ease: "easeOut" }
  }
};
```

## 8. Accessibility (a11y) & WCAG Contrast Audit

* **Text Contrast:** Primary text (`#111827`) on White Surface (`#FFFFFF`) exceeds 14:1 ratio (Passes WCAG AAA). Muted text (`#6B7280`) on White Surface exceeds 4.6:1 ratio (Passes WCAG AA).
* **Keyboard Focus Ring:** 
  ```css
  :focus-visible {
    outline: none;
    box-shadow: 0 0 0 2px #FFFFFF, 0 0 0 4px #2563EB;
  }
  ```
