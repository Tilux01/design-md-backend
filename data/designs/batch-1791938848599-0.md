# Design Specification: STREAMPULSE Web UI

## 1. Global Styles & Theme
*   **Background Color:** Deep Charcoal/Black (`#050505`).
*   **Primary Accent Color:** Vivid Orange-Red (`#FF4D00`) used for the logo, primary buttons, and progress indicators.
*   **Text Colors:**
    *   Primary: Pure White (`#FFFFFF`) - 100% opacity.
    *   Secondary: Light Grey (`#B3B3B3`) - used for metadata and descriptions.
    *   Tertiary: Muted Grey (`#666666`) - used for footer links.
*   **Layout:** Full-width (edge-to-edge), responsive container with horizontal padding of `4%` for content rows.

## 2. Typography
*   **Primary Font:** **Inter** or **Montserrat** (Sans-serif).
*   **Fallback Stack:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
*   **Weights:**
    *   Bold (700): Hero titles, Logo, Section Headers.
    *   Medium (500): Navigation links, Button text.
    *   Regular (400): Descriptions, Metadata, Footer.

---

## 3. Header (Navigation Bar)
*   **Position:** Fixed at top, `z-index: 1000`.
*   **Background:** Transparent to solid black gradient (top-down).
*   **Components:**
    *   **Logo (Left):** An orange play-button triangle icon followed by "STREAMPULSE" in all-caps, bold white text.
    *   **Nav Links (Center-Left):** "Browse", "TV Shows", "Movies", "New & Popular", "My List". White text, font-size `14px`.
    *   **Actions (Right):** 
        *   Search Icon (Magnifying glass).
        *   Notification Icon (Bell with a small orange dot).
        *   Profile: Circular avatar image of a woman (Sarah), followed by the name "Sarah" and a downward chevron.

## 7. Technical Implementation Notes
*   **Image Assets:** All movie posters and hero images should be high-resolution `.jpg` or `.webp`. Backgrounds must be integrated with CSS gradients (`linear-gradient(to bottom, transparent, #050505)`) to avoid harsh edges.
*   **Hover States:** Movie cards should slightly scale up (`transform: scale(1.05)`) and increase brightness on hover.
*   **Icons:** Use a consistent SVG icon set (like Lucide or FontAwesome) for the search, bell, and social media icons.
