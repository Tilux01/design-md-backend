# Production Design Specification: BMW M8 GTE Landing Page

---

## 1. Design Philosophy & Overall Aesthetic
- **Primary Mood:** High-end, precision-engineered automotive performance mixed with clean, editorial minimalist art direction.
- **Brand Archetype:** Luxury Sport / High-Performance Motorsport.
- **Visual Density:** Spacious, breathable asymmetric grid with heavy content overlaps to create depth.
- **Whitespace Balance:** High white balance framing stark, heavy photography and dark high-contrast component cards.
- **Theme Balance:** Light base background (`#FFFFFF`) structured with high-contrast stark black (`#0A0A0A`) editorial typography and vivid primary blue accents (`#0066FF`).

## 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** `1280px` centered with fluid horizontal padding (`clamp(1.5rem, 4vw, 4rem)`).
- **Spatial Scale Factor:** 4px baseline grid (`4`, `8`, `12`, `16`, `24`, `32`, `48`, `64`).
- **Section Sequence Breakdown:**
  1. Top Global Navigation Bar (Logo, Category Links, Press links, BMW badge).
  2. Hero Section split grid:
     - Left: Immersive photography viewport with angled car framing.
     - Right: Editorial typography stack ("THE NEW BMW M8 GTE", #MISSION8, Indicator dots).
  3. Overlapping Floating Component Card: Rear diffuser detail shot with prominent primary CTA ("VIEW DETAILS").
  4. Editorial Content & Social Sidebar Section: Two-column layout with social icons on the left, descriptive editorial prose on the right.
- **Z-Index Hierarchy:**
  - Base Background: `z-0`
  - Main Hero Viewport: `z-10`
  - Floating Card Overlays: `z-20`
  - Fixed Navigations / Modals: `z-50`

## 5. AI Design Traits, Micro-Badges & Special Glyphs

- **High-Tracking Labels:** All navigation items and micro-headers use uppercase tracking (`tracking-widest`, `letter-spacing: 0.1em`).
- **Indicator Dots:** Minimalist state indicators using exact circular dots (`●`, class `.status-dot`) with subtle accent glows.
- **Pill Callout Badges:** 
  - Padding: `4px 12px`
  - Font Size: `11px`
  - Font Weight: `700`
  - Tracking: `0.15em`
  - Border Radius: `9999px` (Full)
  - Background: `rgba(0, 102, 255, 0.08)`
  - Text Transform: `uppercase`
- **Symbol Safety:** Use safe HTML entities for micro-icons and indicators:
  - Bullet / Status Dot: `&bull;` (`&#8226;`)
  - Em Dash: `&mdash;` (`&#8212;`)
  - Star / Sparkle: `&#10022;`

## 8. Accessibility (a11y) & WCAG Contrast Audit

- **Primary Text on Base Background (`#0A0A0A` on `#FFFFFF`):** Contrast ratio **18.5:1** (Passes WCAG AAA).
- **Muted Text on Base Background (`#71717A` on `#FFFFFF`):** Contrast ratio **4.8:1** (Passes WCAG AA).
- **White Text on Primary Button (`#FFFFFF` on `#0066FF`):** Contrast ratio **4.56:1** (Passes WCAG AA).
- **Keyboard Focus Ring:**
  ```css
  :focus-visible {
    outline: 2px solid var(--color-primary);
    outline-offset: 2px;
  }
  ```
