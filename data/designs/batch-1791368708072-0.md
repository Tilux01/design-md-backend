# GOMIFY - Modern Elegance E-Commerce Design Specification

## 1. Global Styles & Foundations

### Color Palette
- **Primary Dark / Background (Hero):** `#0a0a0a` (Deep Rich Black)
- **Primary Light / Background (Body):** `#f8f8f8` (Off-White / Light Cream)
- **Text Primary (Dark Theme):** `#ffffff` (Pure White)
- **Text Secondary (Dark Theme):** `#a0a0a0` (Muted Gray)
- **Text Primary (Light Theme):** `#1a1a1a` (Dark Charcoal)
- **Text Secondary (Light Theme):** `#666666` (Medium Gray)
- **Border / Divider:** `#e0e0e0` (Light Gray)
- **Accent / Interactive:** `#1a1a1a` (Black for buttons and borders)

### Typography
- **Primary Serif Font (Headings):** Playfair Display / Editorial Serif (Fallbacks: `Georgia, serif`)
- **Secondary Sans-Serif (Nav & Body):** Inter / System Sans-Serif (Fallbacks: `-apple-system, BlinkMacSystemFont, sans-serif`)

---

## 2. Header & Navigation

- **Layout:** Sticky/Fixed top banner, full width with inner padding (`max-width: 1440px`, centered).
- **Background:** `#ffffff` (White)
- **Height:** `80px`
- **Left Element:** Brand Logo
  - Text: `GOMIFY` with a custom eye icon in place of the "O".
  - Font: Bold uppercase serif.
- **Center Navigation Links:**
  - `Shop ∨` (with dropdown caret)
  - `Just landed`
  - `Best Sellers`
  - `About Gomify`
  - Font Style: `14px`, Sans-Serif, Medium weight, `#1a1a1a`.
- **Right Icons:**
  - Search Icon (Magnifying glass)
  - User Account Icon
  - Shopping Bag Icon (with item count indicator if needed)

---

## 3. Hero Section

- **Layout:** Full-width banner (`100vw`), immersive dark aesthetic.
- **Background Image:** Dark studio setting featuring a model in a black outfit walking forward, surrounded by luxury handbags on the floor.
- **Visual Overlay:** Subtle dark gradient vignette (`rgba(0, 0, 0, 0.4)`).
- **Content Positioning:** Absolute/Flex positioned on the middle-left.
- **Typography & Elements:**
  - **Subheading:** `Redefining Modern Elegance`
    - Font: `14px`, Sans-Serif, uppercase letter-spacing (`2px`), `#ffffff`.
  - **Main Heading:** `YOU FORWARD`
    - Font: `64px`+, Editorial Serif, uppercase, `#ffffff`.
  - **Call to Action Button:**
    - Text: `SHOP NOW →`
    - Border: `1px solid #ffffff`
    - Padding: `12px 24px`
    - Background: Transparent (Hover: White background with black text)
    - Text Color: `#ffffff`

---

## 4. Product Section Template ("Just Landed" / "Best Sellers")

- **Section Header:**
  - Title: `JUST LANDED` (Editorial Serif, `32px`, uppercase).
  - Action Link: `View All Product →` (Right-aligned, bordered underline or clean arrow link).
- **Grid Layout:** 4-column responsive grid (`grid-template-columns: repeat(4, 1fr)`).
- **Product Card Component:**
  - **Image Container:**
    - Background: `#f0f0f0` (Light gray product studio backdrop).
    - Image: Centered product shot of luxury handbags.
    - Badge: Top-left absolute tag `NEW IN` (`10px` uppercase, subtle border/background).
    - Quick Action: Bottom-right floating `+` button in a dark circular container.
  - **Product Details:**
    - **Product Title:** `CLEARNEST CLEANSER` (Uppercase, `12px`, Sans-Serif, `#1a1a1a`).
    - **Price:** `$ 280.00 USD` (Right-aligned or below title, `12px`, Sans-Serif, `#666666`).

---

## 5. Layout & Spacing Rules

- **Container Max-Width:** `1440px`
- **Section Vertical Padding:** `80px` top and bottom.
- **Grid Gap:** `24px` between product cards.
- **Border Separators:** Thin `1px` lines separating major sections if required by visual flow.
