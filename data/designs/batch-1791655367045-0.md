# Design Specification: "Sofa Cake" Storehouse Web Application UI

## 1. Global Layout & Canvas Structure

### 1.1 Fullscreen Application Setup
- **Background / Canvas:** Solid light gray (`#f0f0f0` or off-white equivalent) occupying the entire screen viewport (`100vw` × `100vh`).
- **Main Container Card:** 
  - Centered rounded rectangle card with an ultra-smooth boundary.
  - **Border-Radius:** Large, pill-like corners (~`32px` to `40px`).
  - **Background:** Crisp solid white (`#FFFFFF`) interior.
  - **Shadow & Depth:** Soft, diffused ambient drop shadow (`0px 24px 60px rgba(0, 0, 0, 0.08)`), giving it a floating 3D glassmorphic/neumorphic card elevation.

---

## 2. Left Side: Brand Visual Panel (Purple Section)

### 2.1 Background Organic Shape
- **Shape & Position:** Anchored to the left half of the main card, spanning from the top edge down to roughly 70% height, curving inward dynamically into the white background via a sweeping bezier curve.
- **Color Fill:** Rich, vibrant purple gradient or solid block (`#8250FF` to `#6935E8`).
- **Additional Floating Shapes (Inside Purple Area):**
  - **Small Pill Shape:** Near the middle-left, a tilted white rounded capsule (`#FFFFFF`) with soft edges (`opacity: ~0.9`).
  - **Geometric Triangle/Diamond Outline:** Near the top-left, a subtle, minimal white wireframe triangle icon.

### 2.2 Typography ("Sofa Cake")
- **Text Content:** 
  ```
  Sofa
  cake
  ```
- **Font Family:** Modern, geometric rounded sans-serif (e.g., *Comfortaa*, *Quicksand*, or *SF Pro Rounded*). 
- **Fallback Stack:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
- **Styling:**
  - **Font Weight:** Bold / Extrabold (`700`).
  - **Color:** Pure White (`#FFFFFF`).
  - **Line Height:** Tight (`1.05` to `1.1`), stacking "Sofa" above "cake".
  - **Font Size:** Large display scale (`~48px` to `64px`).

---

## 3. Right Side: Dashboard & Storehouse Panel

### 3.1 Header Section
- **Title ("My storehouse"):**
  - **Font Family:** Clean modern geometric sans-serif (*Inter*, *SF Pro Display*).
  - **Font Weight:** Regular to Medium (`400` – `500`).
  - **Font Size:** `~24px`.
  - **Color:** Dark charcoal/black (`#111111`).
  - **Line Structure:**
    ```
    My
    storehouse
    ```
- **Top-Right Profile / Avatar Icon:**
  - Rounded yellow circle (`#FFC53D`) containing a stylized minimalist cartoon facial expression (black eyes and an open laughing/grinning mouth). Size: `~36px` × `36px`.

---

## 4. Data Table Section ("My Storehouse" Inventory)

### 4.1 Table Headers
- **Columns:** Two main header labels located beneath the title:
  - **Left Header:** `PRODUCT` (Uppercase, tracked out, small muted gray font `#8E95A0`, `11px`).
  - **Right Header:** `NO` (Uppercase, aligned with the right action column).
- **Divider:** Subtle light gray horizontal dividing lines separating rows (`#EAEFF4`).

### 4.2 Table Rows (Items List)
Each row consists of three columns: **Product Name**, **Dimensions**, and **Item Thumbnail + Add Action (`+`)**.

#### Row 1: Worktop
- **Product Name:** "Worktop" (Medium weight, dark gray `#2D3142`, `14px`).
- **Dimensions:** "110 x 110" (Light gray, `12px`).
- **Thumbnail Image:** 
  - **Description:** 3D rendered abstract multi-colored stacked object (red, orange, yellow rings on a dark blue base with thin pink/orange legs). 
  - **Background:** Backgroundless (isolated transparent render).
  - **Placement:** Right-aligned inside the row slot.
- **Action:** `+` symbol (bold, charcoal gray, positioned right next to the thumbnail).

#### Row 2: Couch capsule
- **Product Name:** "Couch capsule" (`14px`).
- **Dimensions:** "110 x 110" (`12px`).
- **Thumbnail Image:** 
  - **Description:** 3D rendered glossy, vibrant orange pill/capsule-shaped cushion floating diagonally.
  - **Background:** Backgroundless.
  - **Placement:** Right-aligned inside the row slot, subtly tilted.
- **Action:** `+` symbol.

#### Row 3: Couch cake
- **Product Name:** "Couch cake" (`14px`).
- **Dimensions:** "110 x 110" (`12px`).
- **Thumbnail Image:** 
  - **Description:** 3D rendered miniature royal-purple modern armchair/sofa with rounded backrest and armrests.
  - **Background:** Backgroundless.
  - **Placement:** Right-aligned inside the row slot.
- **Action:** `+` symbol.

---

## 5. Floating 3D Elements (Overlaid on Canvas)

### 5.1 Centerpiece 3D Sofa
- **Description:** A large, highly detailed 3D rendered modern sofa upholstered in textured velvet purple fabric. Features a curved wrap-around backrest and a thick rectangular seat cushion raised on short dark legs.
- **Placement & Rotation:** Positioned centrally, overlapping the boundary between the purple section and the white table background, creating a dramatic layered depth effect.
- **Shadow:** Soft drop shadow cast downward onto the UI layers beneath it.

### 5.2 Floating Orange Capsule (Top Center)
- **Description:** Identical 3D glossy orange capsule cushion to the one in the table row, rendered at a larger scale.
- **Effects:** Heavy vertical Gaussian motion blur to simulate rapid floating/falling motion in 3D space.
- **Placement:** Hovering dynamically over the upper-left boundary of the white panel.

### 5.3 Floating Color-Stack Object (Mid-Left)
- **Description:** Larger version of the multi-colored stacked object (red, orange, yellow layers on a blue pedestal with legs).
- **Effects:** Slight motion blur on edges.
- **Placement:** Floating between the purple curve and the table rows.

---

## 6. Floating Control Dock & Bottom Navigation Bars

### 6.1 Bottom-Left Navigation Bar
- **Container:** A compact, rounded pill container anchored to the bottom-left of the inner white card.
- **Background:** Light off-white/gray translucent fill (`#F4F6F9`).
- **Icons Included (Left to Right):**
  1. Sofa/Furniture icon (active state indicator).
  2. Thin separator line.
  3. Wireframe configuration/settings icon.
  4. Thin separator line.
  5. Layout/grid icon.
- **Styling:** Minimalist dark gray line icons (`#4A5568`), spaced evenly with smooth hover states.

### 6.2 Bottom-Right Layout Toggle
- **Container:** Small rounded square button matching the bottom-left dock style (`#F4F6F9`).
- **Icon:** Grid / columns layout icon in dark gray.

### 6.3 Central Floating Action Toolbar (Bottom Center-Right)
- **Container:** A pill-shaped floating toolbar overlapping the bottom of the table.
- **Background:** Solid white (`#FFFFFF`) with a clean shadow (`0px 10px 30px rgba(0,0,0,0.06)`).
- **Controls Inside (Left to Right):**
  1. **Icon 1:** Window/Browser icon.
  2. **Icon 2:** Pen/Draw squiggle curve icon (`~`).
  3. **Icon 3:** User profile avatar icon with a small downward chevron dropdown arrow (`👤 v`).
  4. **Action Button (Far Right of Toolbar):**
     - **Shape:** Solid dark charcoal/black rounded square/pill button (`#1E2229`).
     - **Icon:** Pure white right-pointing arrow (`→`).
