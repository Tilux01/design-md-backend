# Design Specification: Dark-Themed E-Commerce UI (Gaming Peripherals)

---

## 1. Global Styles & Variables

*   **Background Color:** Dark charcoal/navy `#12141C` (Primary surface color for all cards, sections, and backdrop).
*   **Secondary Surface / Container Color:** `#1A1D27` (Slightly lighter panels/cards).
*   **Primary Accent Color (Blue/Indigo):** `#5E6AD2` (Used for active states, badges, buttons, prices, and highlights).
*   **Text Colors:**
    *   **Primary Text (White):** `#FFFFFF` (Headings, titles, prices).
    *   **Muted/Secondary Text (Light Gray):** `#8A8F9D` (Descriptions, category labels, out-of-stock or old prices).
*   **Font Family:** Inter or system sans-serif (Clean, modern, geometric).
*   **Border Radius:** 
    *   Cards & Banners: `16px` to `24px`
    *   Buttons & Badges: `12px` to `9999px` (Pill style)

---

## 2. Layout Structure

*   **Layout:** Vertical scrolling dashboard / e-commerce homepage layout.
*   **Content Width:** Centered container with generous padding (approx. `1200px` max-width).
*   **Spacing:** Generous whitespace between sections (`60px` to `80px`).

---

## 3. Component Breakdown

### A. Navigation Header
*   **Position:** Top left/right.
*   **Elements:**
    *   **Page Indicator:** Pill-shaped badge `5 Design` (Blue border, white text).
    *   **Section Title:** Right-aligned header link `Categories`.

---

### B. Category Grid Section ("Categories")
*   **Grid System:** 2x2 asymmetric or equal 2-column grid.
*   **Cards (Mice, Mousepads, Headsets, Keyboards):**
    *   **Background:** `#161922` with subtle rounded border.
    *   **Content Layout:** 
        *   Left side: "Starting from `$XX`", Category Title (`Mice`, `Mousepads`, etc.), and a circular Browse icon button (`+` or `→`).
        *   Right side: High-resolution product render overlapping the card edge (Mouse, Mousepad art, Headset, Keyboard edge).
    *   **Large Watermark Text:** Faint background typography inside the card (`MICE`, `MOUSEPADS`, etc.) set at very low opacity (`~3%`).

---

### C. Featured Product Sliders / Hero Banners ("Slider")
*   **Section Title:** Right-aligned `Slider`.
*   **Banner Cards (Full-Width Horizontal Banners):**
    *   **Dimensions:** Wide aspect ratio (`~1100px` x `~450px`).
    *   **Background:** Dark slate `#161821` with a subtle dark outline.
    *   **Top Navigation (Inside Banner):**
        *   Left: Logo/Brand icon (`GG`).
        *   Center: Navigation links (`Mouses`, `Keyboards`, `Headsets`, `Mousepads`, `...`).
        *   Right: User profile (`John Doe` with avatar) and a notification/cart counter badge (`3`).
    *   **Left Column (Typography & Action):**
        *   Vertical tracking label on the far left: `WELCOME TO GAMING - GERAS`.
        *   Main Heading: Bold, large text (e.g., `Headset — HyperX Cloud`).
        *   Pricing: Strikethrough original price (`$299`) and highlighted discounted price (`$200,-`).
        *   Call to Action: Pill button `+ ADD TO CART` in white/dark contrast.
        *   Social Links: Vertical or horizontal minimal icons (`f`, `twitter`, `instagram`).
    *   **Center/Right Column (Product Visual):**
        *   Large, centered product render (e.g., HyperX Cloud Headset, Steelseries Sensei 310 Mouse) with soft drop shadows.
        *   Price tag floating on the far right: vertical text style (`$ 250,-`).
        *   Carousel Navigation Arrows: `<` and `>` vertically centered on the right edge.
        *   Pagination / Slider Track at the bottom: Progress bar with active number indicator (`2 / 4` or `1 / 4`).

---

## 4. Interactive States & Micro-interactions
*   **Buttons:** Hover state shifts to a lighter shade of blue or increases brightness.
*   **Arrows & Icons:** Thin, clean vector line weights (stroke width `1.5px` to `2px`).
*   **Typography Hierarchy:**
    *   *Display Headings:* `32px` - `48px`, Bold.
    *   *Card Titles:* `20px` - `24px`, Semi-bold.
    *   *Body/Prices:* `14px` - `18px`, Medium.
