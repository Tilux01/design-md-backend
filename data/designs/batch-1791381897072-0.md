# Comprehensive Design Specification: ShopEase E-Commerce Marketing Email / Web Template

This document serves as the absolute blueprint for recreating the provided visual asset (an e-commerce promotional template/email) as a pixel-perfect, responsive web application or HTML email template. It details every design token, typography rule, layout container, component state, and interaction.

---

## 1. Global Styles & Design Tokens

### 1.1 Color Palette
- **Primary / Accent Orange**: `#FF5722` (Used for CTAs, deal tags, badges, discount percentages).
- **Secondary Dark Green**: `#0C2318` or `#0b1f15` (Used for top utility bar, hero background, footer, dark text blocks).
- **Surface Light Gray / Off-White**: `#F9F6F0` or `#F7F5F0` (Used for overall page background, category cards, product backgrounds, value proposition banner background).
- **Pure White**: `#FFFFFF` (Used for inner card backgrounds, input fields, highlighted containers).
- **Text Primary (Dark)**: `#1E1E1E` (Headings, primary body text).
- **Text Secondary (Muted)**: `#666666` or `#777777` (Subtitles, descriptions, strikethrough prices, metadata).
- **Border / Divider Color**: `#E5E0D8` or `#E2DDD5` (Subtle card borders, container separations).
- **Timer Background Pill**: `#FFF0EB` (Light orange-tinted background for countdown timers).

### 1.2 Typography
- **Primary Font Family**: `'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif`.
- **Fallback Font Stack**: `sans-serif`.
- **Font Weights Used**: 
  - Regular (`400`)
  - Medium (`500`)
  - Semi-Bold (`600`)
  - Bold (`700`)
  - Extra-Bold / Black (`800`)

---

## 2. Layout & Structure

- **Canvas/Wrapper Width**: Centered layout constrained to a maximum width of **`600px`** (standard email template width) or scaling fluidly up to **`1200px`** if used as a landing page. (The structural anatomy mirrors modern modular e-commerce layouts).
- **Vertical Spacing / Gutters**: Consistent padding of `24px` to `32px` between major sections. Card grids use a `12px` to `16px` gap.
- **Border Radius**: 
  - Buttons: `8px` to `50px` (pill style for main CTAs).
  - Cards & Images: `12px` to `16px`.
  - Badges: `4px` to `8px`.

## 4. Animations & Micro-Interactions (If implemented as Web App)

- **Hover States**:
  - **Buttons**: Scale up slightly (`transform: translateY(-2px)`) with enhanced box-shadow on hover. Transition: `all 0.2s ease-in-out`.
  - **Product Cards**: Lift effect (`transform: translateY(-4px)` with shadow elevation).
  - **Navigation Links / Footer Links**: Color transition from muted text to `#FF5722`.
- **Countdown Timer**: 
  - Dynamic JavaScript interval ticking down seconds and milliseconds in real-time.
- **Wishlist Heart**:
  - Toggle animation: Filling with solid red/orange when clicked.

## 5. Responsive Behavior & Breakpoints

- **Desktop (`>= 1024px`)**: Full multi-column layouts (5-column category grid, 4-column product grid, 2-column hero and deal sections).
- **Tablet (`768px - 1023px`)**: 
  - Categories switch to a 3-column wrap or scrollable row.
  - Product grid switches to 2 columns.
- **Mobile (`< 768px`)**:
  - Single-column stacked layout for all sections.
  - Horizontal scrolling carousels for Categories and New Arrivals to preserve vertical screen space.
  - Hamburger menu toggle for main navigation.
