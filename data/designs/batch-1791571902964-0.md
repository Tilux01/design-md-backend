# Design Specification: Mooney Dashboard UI

This document outlines the exact specifications for recreating the Mooney Dashboard UI as a full-screen, responsive web application. The design system follows a modern neomorphic/glassmorphism aesthetic with soft shadows, rounded containers, and a purple-to-blue color palette.

---

## 1. Global Layout & Canvas

*   **View:** Full-screen viewport (`100vw` width, `100vh` height).
*   **Background:** 
    *   Linear gradient transitioning from a soft lavender/purple (`#d6d5ef`) at the top-left to a warm peach/pink (`#f4e3e3`) at the bottom-right.
*   **Main Container:** 
    *   Centrally docked card with high border-radius (`24px` to `32px`).
    *   Background: Semi-transparent white/light lavender (`#f2f3f9`) with soft multi-layered drop shadows (`box-shadow: 0 20px 40px rgba(100, 100, 150, 0.15)`).

---

## 2. Typography & Fonts

*   **Primary Font Family:** **Inter**, with fallbacks to **SF Pro Display**, **Roboto**, system-ui, `-apple-system`, `sans-serif`.
*   **Font Weights Used:** Regular (400), Medium (500), Semibold (600), Bold (700).

### Hierarchy:
1.  **Dashboard Title:** 24px, Bold (`#1a1c29`).
2.  **Section Headers (History, Efficiency, Recent Transaction):** 16px, Semibold (`#1a1c29`).
3.  **Card Labels / Subtext:** 12px - 14px, Regular (`#7c7e93`).
4.  **Amounts / Numbers:** 14px - 20px, Bold (`#1a1c29`).

---

## 3. Color Palette

| Role | Color Name | Hex Code / Gradient |
| :--- | :--- | :--- |
| **Primary Accent / Brand** | Royal Purple | `#5c56ed` |
| **Secondary Accent / Cards** | Gradient Blue/Purple | `#4d46f8` to `#6b72ef` |
| **Background Base** | Soft Light Grey-Blue | `#f0f2f7` |
| **Container Background** | Pure White / Translucent | `#ffffff` / `rgba(255, 255, 255, 0.85)` |
| **Text Primary** | Dark Slate | `#1e2235` |
| **Text Secondary / Muted** | Cool Grey | `#8c8fa3` |
| **Income / Positive** | Emerald Green | `#2ecc71` (or implied blue/purple accents) |
| **Expense / Negative** | Coral Red | `#e74c3c` |
