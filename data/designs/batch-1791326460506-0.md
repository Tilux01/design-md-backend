# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: High-Tech Immersive Gaming & Immersive Hardware Portfolio (Cyberpunk Minimalist / Dark Mode Tech-Retail).
- **Visual Density & Whitespace Ratio**: High-contrast, spacious asymmetric grid framing. Generous negative space balances vibrant glowing neon accents and bold repetitive typography.
- **Surface Elevation Model**: Layered obsidian cards, subtle 1px transluscent borders (`rgba(255,255,255,0.08)`), multi-stop radial lighting gradients, and deep shadow halos.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase micro-badges, glowing ambient background orbs, glassmorphism containers, repeating kinetic background typography streams.
- **Pill Badge Specification**: Padding `6px 14px`, font-size `12px`, font-weight `700`, tracking `0.1em`, border-radius `9999px`, background `rgba(255,255,255,0.06)`, border `1px solid rgba(255,255,255,0.12)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or inline SVG.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-[#CCFF00] inline-block shadow-[0_0_8px_#CCFF00]"></span>`.

# 7. Motion Mechanics, Framer Motion & CSS Animations
- **Motion Principles**: Spring physics for interactive cards, smooth cubic-bezier easing curves (`[0.16, 1, 0.3, 1]`) for layout transitions.
- **Framer Motion Variants Code**:
```jsx
export const containerVariants = {
  hidden: { opacity: 0, y: 24 },
  visible: { 
    opacity: 1, 
    y: 0,
    transition: { duration: 0.6, ease: [0.16, 1, 0.3, 1], staggerChildren: 0.12 }
  }
};
```

- **CSS `@keyframes` Animations**:
```css
@keyframes pulseGlow {
  0%, 100% { transform: scale(1); opacity: 0.7; }
  50% { transform: scale(1.08); opacity: 1; filter: drop-shadow(0 0 25px rgba(204,255,0,0.6)); }
```
