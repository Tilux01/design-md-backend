# UI/UX Specification: iDraft Dashboard UI Clone

This document provides a comprehensive design and layout specification to recreate the provided **iDraft Dashboard** interface as a full-screen, production-ready web application (HTML/CSS/Tailwind CSS or React).

---

## 1. Global Layout & Canvas Settings

* **Viewport:** Full screen (`width: 100vw`, `height: 100vh`), filling the browser canvas.
* **Background:** Soft, ambient abstract grayscale gradient with subtle lighting/shadow depth (`#e6e6e6` to `#f4f4f4` base tones).
* **Base Container:** The internal dashboard layout is a structured CSS Grid/Flexbox dashboard scaled to fill the available space with a consistent margin padding (approx. `24px`).
* **Border Radius System:** 
  * Main Container: `24px`
  * Cards / Containers: `16px`
  * Buttons / Badges: `8px` to `12px`
* **Color Palette:**
  * **Primary Dark (Backgrounds & Text):** `#111111` / `#1b1b1b` (Deep Charcoal Black)
  * **Secondary Dark (Cards):** `#1e1e1e` / `#222222`
  * **Light Backgrounds:** `#ffffff` (Pure White cards on light sections)
  * **Text Muted:** `#71717a` (Zinc 500)
  * **Accents:** Monochrome black/white with distinct high-contrast indicator dots (e.g., green indicators for active statuses).

---

## 2. Typography & Fonts

* **Primary Font Family:** `Inter`, `SF Pro Display`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `Helvetica Neue`, `Arial`, `sans-serif`.
* **Fallback Strategy:** If `Inter` or `SF Pro Display` fail to load, the system falls back to standard modern sans-serif fonts (`system-ui`, `-apple-system`, `sans-serif`).
* **Hierarchy:**
  * **Dashboard Title ("Hi, Dilan!"):** `24px` / `700 Bold` / Dark charcoal.
  * **Card Titles:** `14px` – `16px` / `600 Semi-bold`.
  * **Body Text / Items:** `12px` – `13px` / `400 Regular`.
  * **KPI Numbers:** `24px` – `28px` / `700 Bold`.
  * **Small Labels / Tags:** `10px` – `11px` / `500 Medium`.
