# Comprehensive UI/UX Design Specification: "Plantinum" Interactive List Interface

## 1. Global Layout & Viewport Architecture

*   **Screen Orientation:** Portrait mode, optimized for mobile display (9:16 aspect ratio).
*   **Viewport Dimensions:** Full-screen implementation (`width: 100vw; height: 100vh;`).
*   **Background Treatment:** 
    *   Radial gradient featuring an intense, deep violet core (`#1a0b36`) transitioning outward to a near-black, dark midnight indigo (`#05010d`).
    *   Subtle ambient light diffusion radiating from the center of the viewport to create depth and focus the user's attention on the central interactive components.
*   **Component Structure:** Vertical flex column layout centered horizontally and vertically, featuring a primary header pill followed by a vertically stacked list of interactive user rows with consistent negative/positive spacing.

---

## 2. Typography & Font Stack Strategy

### Primary Font Family
*   **Target Font:** `Inter`, `SF Pro Display`, `Roboto`, or modern system sans-serif equivalents.
*   **Characteristics:** Clean geometric structure, high legibility at small scale, neutral weight distribution.

### Fallback Stack
```css
font-family: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
```

### Typographic Hierarchy

1.  **Header Pill ("Plantinum")**
    *   **Font Size:** `20px` to `24px` (Fluid clamp suggested: `clamp(1.25rem, 3vw, 1.5rem)`).
    *   **Font Weight:** `700` (Bold).
    *   **Letter Spacing:** `0.025em` (Slight tracking for crisp rendering).
    *   **Color:** Pure White (`#FFFFFF`).
    *   **Text Transform:** Sentence case with capitalized initial letter.

2.  **Row Names (John, Meg, Kevin, Sally)**
    *   **Font Size:** `16px` (`1rem`).
    *   **Font Weight:** `600` (Semi-bold).
    *   **Color:** Pure White (`#FFFFFF`).

3.  **Action/Points Indicators (+15, +18, +23, +20)**
    *   **Font Size:** `16px` (`1rem`).
    *   **Font Weight:** `700` (Bold).
    *   **Color:** Soft Lavender/Periwinkle (`#9b92cc` or `#a295db`).

---

## 3. Detailed Component Specifications

### 3.1. Primary Header Component ("Plantinum")
*   **Shape & Geometry:** Elongated pill/capsule container with fully rounded ends (`border-radius: 9999px`).
*   **Dimensions:** 
    *   `width`: ~65% to 75% of container max-width.
    *   `padding`: `16px 24px`.
*   **Styling & Effects:**
    *   **Background:** Deep vibrant purple gradient (`linear-gradient(135deg, #7c3aed 0%, #6366f1 100%)`).
    *   **Border:** Subtle inner highlight border (`1px solid rgba(255, 255, 255, 0.25)`).
    *   **Box Shadow:** Deep multi-layered drop shadow for elevation:
        ```css
        box-shadow: 0 10px 25px -5px rgba(109, 40, 217, 0.5), 
                    0 8px 10px -6px rgba(109, 40, 217, 0.3);
        ```
*   **Iconography:** 
    *   Preceding the text are dual four-point sparkle/star vectors.
    *   **Color:** Bright Gold/Yellow (`#fde047`) or vibrant white, positioned vertically centered to the left of the text.

---

### 3.2. List Row Components (John, Meg, Kevin, Sally)

Each row is encapsulated within an interactive card container styled as a rounded pill/button.

*   **Shape & Geometry:** Pill-shaped container (`border-radius: 9999px`).
*   **Spacing:** Vertical gap between rows is set to `16px`.
*   **Dimensions:**
    *   `width`: Matches header container (`min-width: 280px`).
    *   `padding`: `10px 18px` (Compact to emphasize horizontal flow).
*   **Styling & Effects:**
    *   **Background:** Semi-translucent dark indigo glassmorphism surface (`rgba(20, 10, 45, 0.75)`).
    *   **Border:** Thin, subtle border to define boundaries (`1px solid rgba(120, 90, 180, 0.2)`).
    *   **Backdrop Filter:** `blur(12px)` for depth rendering over the background gradient.
    *   **Box Shadow:** Soft ambient drop shadow:
        ```css
        box-shadow: 0 4px 16px rgba(0, 0, 0, 0.3);
        ```

#### Internal Row Layout (Flexbox Row):
1.  **Leading Avatar/Icon:**
    *   Circular container (`width: 32px`, `height: 32px`, `border-radius: 50%`).
    *   Background: Solid deep purple/violet (`#4c1d95`).
    *   Contains a simplified white silhouette user icon.
2.  **Center Label (Name):**
    *   Left-aligned text taking up remaining flex-grow space with standard text margins.
3.  **Trailing Score/Action Badge:**
    *   Displays value (e.g., `+15`) alongside a trailing four-point star icon (`✦`).
    *   Alignment: Right-aligned inside the flex container.

---

## 4. Animation & Micro-Interaction Specifications

To replicate the dynamic feel of the media, apply the following motion design tokens:

### 1. Entrance / Load Animation (Staggered Fade-Up)
*   **Trigger:** Component mount.
*   **Properties:** `opacity` (0 to 1), `transform` (`translateY(20px)` to `translateY(0)`).
*   **Timing:** 
    *   Duration: `400ms` per element.
    *   Easing: `cubic-bezier(0.16, 1, 0.3, 1)` (Smooth ease-out).
    *   Stagger Delay: Increment by `80ms` for each subsequent row down the list.

### 2. Hover / Tap Micro-Interactions (Active States)
*   **Transform:** `scale(0.98)` on `mousedown`/`active`, `scale(1.02)` on `hover`.
*   **Background Transition:** Brighten row background opacity slightly on hover (`rgba(40, 20, 80, 0.85)`).
*   **Transition Duration:** `200ms ease`.

### 3. Ambient Sparkle Pulse
*   The sparkle icons (`✦`) feature a continuous subtle breathing/pulsing animation:
    *   **Keyframes:** Scale oscillating between `1.0` and `1.15`, with opacity shifting from `0.8` to `1.0`.
    *   **Duration:** `2000ms` infinite alternate loop.
```css
@keyframes sparkle-pulse {
  0%, 100% { transform: scale(1); opacity: 0.8; }
  50% { transform: scale(1.15); opacity: 1; }
}
```
