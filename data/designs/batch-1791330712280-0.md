# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Ultra-Dark, High-Performance Sports & Recovery Tech Editorial Minimalist (Dark Mode Glassmorphism).
- **Visual Density & Whitespace Ratio**: Expansive viewport scale with a high-impact typography-to-image overlap ratio. Generous horizontal canvas framing with dense typographic tracking for sub-headers and clean negative space separating navigation elements.
- **Surface Elevation Model**: Layered canvas composition featuring an absolute deep black background (`#070709`), central volumetric 3D product render overlay, subtle radial purple/magenta ambient lighting glows (`rgba(168,85,247,0.15)`), and high-contrast stark white typography for maximal hero legibility.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase pill badges (`0.2em` letter-spacing), volumetric radial background glow orbs, glassmorphism containers (`backdrop-filter: blur(16px)`), monochromatic dark mode sports branding.
- **Pill Badge Specification**: Padding `6px 14px`, font-size `12px`, font-weight `600`, tracking `0.2em`, border-radius `9999px`, background translucency `rgba(255,255,255,0.03)`, border width `1px solid rgba(255,255,255,0.08)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `<span class="w-1.5 h-1.5 rounded-full bg-purple-400 inline-block"></span>`.

# 7. Motion Mechanics, Framer Motion & CSS Animations
- **Motion Principles**: Smooth cubic-bezier easing (`[0.16, 1, 0.3, 1]`), staggered typographic reveals, volumetric glow pulsing.
- **Framer Motion Variants Code**:
```jsx
export const heroVariants = {

  visible: { 
    opacity: 1,

    y: 0,

  }

```
