# 1. Design Philosophy & Overall Aesthetic

- **Mood & Brand Archetype:** Futuristic "Neumorphic Glass" (Liquid Glass / Neo-Glassism), optimized for high-end SaaS developer tools, creator dashboards, and AI control rooms. Evokes an immersive, cyber-sleek environment.
- **Visual Density:** High density with generous spatial grouping. Dense functional controls are balanced by heavy atmospheric lighting and translucent volumetric cards.
- **Whitespace Balance:** Tight internal padding (12px–20px) balanced by expansive outer containment and glowing volumetric drop-shadows that act as optical spacers.
- **Theme Balance:** Dark Mode exclusive architecture. Employs deep obsidian backgrounds (`#0B0E14`) contrasted with high-saturation neon aqua (`#00F2FE`), vibrant electric purple (`#7F00FF`), and soft pink gradient accents (`#FF758C`).

# 2. Color Palette & Design Tokens

- **Base Background:** `#0B0E14` (Deep Obsidian)
- **Surface Backgrounds (Cards/Modals):** Translucent glass panels utilizing `rgba(18, 24, 38, 0.65)` with backdrop blur (`blur(20px)`).
- **Primary Accent (Cyan Glow):** `#00F2FE` (Default), `#4FACFE` (Hover/Active)
- **Secondary Accent (Purple/Pink):** `#7F00FF` to `#FF758C` gradient.
- **Borders & Dividers:** High-spec refractive borders using `rgba(255, 255, 255, 0.12)` on top edges, fading to `rgba(255, 255, 255, 0.02)` on bottom edges.
- **Text Colors:**
  - *Primary Text:* `#FFFFFF` (Pure White)
  - *Muted Text:* `#8E9BB0` (Cool Slate Gray)
  - *Accent Text:* `#00F2FE` (Neon Cyan)

# 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** Fluid card grid inside a fixed 480px–1200px container shell (represented here as a unified UI kit canvas).
- **Padding & Margin Scale:** 
  - Outer Container Padding: `24px`
  - Component Gap: `16px` to `24px`
  - Internal Card Padding: `16px` to `20px`
- **Section Sequence Breakdown:**
  1. Header Bar (Title + Status Indicator + User Avatar)
  2. Primary Interactive Triggers (Neon pill buttons & dropdowns)
  3. Search & Filtering Bar
  4. Control Inputs (Toggles, Switchers, Checkboxes)
  5. Content Display Cards (Invite Member, Upgrade Plans, Progress rings)
- **Stacking Order (Z-Index):**
  - Base canvas: `z-0`
  - Glass cards / surface containers: `z-10`
  - Floating badges & glowing rims: `z-20`
  - Modals / Dropdown menus: `z-50`

# 6. Motion Mechanics, Framer Motion & CSS Animation Code

- **Animation Triggers:** Hover scaling, glowing border pulsing, smooth tab sliding, toggle switches with spring physics.
- **Timing/Easing:** Spring physics with `stiffness: 300, damping: 25` for micro-interactions; `cubic-bezier(0.16, 1, 0.3, 1)` for page elements.

### Framer Motion React Code Snippets
```jsx
import { motion } from 'framer-motion';

export const GlassCard = ({ children }) => (
  <motion.div
    initial={{ opacity: 0, y: 20 }}
    animate={{ opacity: 1, y: 0 }}
    transition={{ duration: 0.6, ease: [0.16, 1, 0.3, 1] }}
    whileHover={{ scale: 1.01, boxShadow: "0 25px 50px rgba(0,0,0,0.6), 0 0 30px rgba(0,242,254,0.2)" }}
    className="p-6 rounded-[24px] bg-[rgba(18,24,38,0.65)] backdrop-blur-[20px] border border-white/10"
  >
    {children}
  </motion.div>
);

export const NeonToggle = ({ isOn, setIsOn }) => (
  <div 
    className={`w-14 h-8 flex items-center rounded-full p-1 cursor-pointer transition-colors duration-300 ${isOn ? 'bg-gradient-to-r from-[#00F2FE] to-[#4FACFE]' : 'bg-white/10'}`}
    onClick={() => setIsOn(!isOn)}
  >
    <motion.div
      layout
      transition={{ type: "spring", stiffness: 500, damping: 30 }}
      className="w-6 h-6 bg-white rounded-full shadow-md"
    />
  </div>
);
```

# 7. Accessibility (a11y) & WCAG Contrast Audit

- **Contrast Ratios:**
  - White Text (`#FFFFFF`) on Obsidian Surface (`#0B0E14`): **16.5:1** (Passes WCAG AAA)
  - Muted Text (`#8E9BB0`) on Obsidian Surface (`#0B0E14`): **5.4:1** (Passes WCAG AA for normal text)
  - Neon Cyan (`#00F2FE`) used strictly for large branding, accents, and icons with dark backgrounds supplemented by legible white labels.
- **Keyboard Focus Ring Specs:**
  - Focus state must provide a crisp, accessible ring to override native outlines without breaking the glass aesthetic:
  ```css
  :focus-visible {
    outline: none;
    box-shadow: 0 0 0 2px #0B0E14, 0 0 0 4px #00F2FE;
  }
  ```
