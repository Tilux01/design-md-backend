# UI Design & Implementation Specification: Lordbank Portal Dashboard

## 1. Global Layout & Structure

- **Viewport Orientation:** Full-screen desktop application layout. Designed natively for a wide-screen fluid viewport (optimized for 1440px+ widths).
- **Core Grid System:** Asymmetric multi-card dashboard grid divided into two distinct primary regions:
  - **Main Content Area (Left/Center):** Fluid width, multi-column bento box layout encompassing user greeting, widgets, metrics, charts, and team structures.
  - **Sidebar Panel (Right):** Fixed-width contextual panel (approx. 320px–360px) dedicated to global search, payout management, payment logs, and salary breakdown summaries.
- **Background Palette:** Clean, high-key minimalist aesthetic.
  - **App Base Background:** Soft off-white canvas (`#F4F6F8` to `#F0F4F8`).
  - **Widget Surfaces / Cards:** Pure white (`#FFFFFF`) with ultra-subtle ambient drop shadows (`0px 4px 20px rgba(0, 0, 0, 0.03)`).
- **Border Radius System:** Highly rounded, friendly UI components.
  - **Primary Cards/Containers:** `24px` (`border-radius: 24px`).
  - **Inner Badges, Pills, Buttons:** `12px` to `9999px` (fully rounded capsules).

---

## 2. Typography System & Fallbacks

- **Primary Font Family:** `Inter`, fallback to `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
- **Secondary / Headings Font Family:** Geometric modern sans-serif like `Plus Jakarta Sans` or `Outfit`, falling back to `Inter, sans-serif`.

### Font Scale & Hierarchy:
- **Main Greeting ("Good morning Jhon"):**
  - Size: `32px` / `2rem`
  - Weight: Semi-bold / Bold (`600` or `700`)
  - Color: Dark charcoal (`#111827`)
- **Card Section Titles ("Track your team", "Talent recruitment", "Salaries and insentive"):**
  - Size: `18px` / `1.125rem`
  - Weight: Semi-bold (`600`)
  - Color: `#1F2937`
- **Metric Numbers (e.g., "46,5", "120", "$2,540.00"):**
  - Size: Varies (`36px` to `48px` for core KPIs)
  - Weight: Bold (`700`)
  - Color: `#111827`
- **Body & Metadata Text:**
  - Size: `13px` to `14px`
  - Weight: Regular / Medium (`400` / `500`)
  - Color: Muted slate gray (`#6B7280`)

  - "+ Add report": Solid vibrant sage green button (`#4ADE80`) with dark text and a document icon.
