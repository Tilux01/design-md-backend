# Design Specification: Mobile App UI Clone

## 1. Global Layout & Viewport Specifications

*   **Target Device:** Modern smartphone (iOS/Android native app aesthetic).
*   **Layout Structure:** Full-screen multi-view comparison (Left: "The Serning" dashboard, Right: "Sorgte Mons" map/activity view).
*   **Screen Framing:** Edge-to-edge content container with safe area insets respected (dynamic island/notch area at top, home indicator bar at bottom).
*   **Spacing & Padding:** 
    *   Horizontal screen edge padding: `16px` to `20px`.
    *   Vertical spacing between primary card modules: `12px` to `16px`.
    *   Border radius for major card containers: `24px` to `32px`.
*   **Shadows & Depth:** Soft, diffused drop shadows using warm beige/brown undertones (`rgba(100, 80, 70, 0.08)` to `0.12`).

---

## 2. Color Palette & Typography System

### Color Palette (Warm Earthy Minimalist Theme)
*   **Background Base (`--bg-primary`):** `#F7F2EC` (Warm cream/off-white)
*   **Surface Cards (`--bg-card`):** `#FDFBF7` to `#FAF6F0` (Subtle off-white contrast against base)
*   **Primary Accent (`--accent-primary`):** `#E5835C` (Warm terracotta/burnt orange)
*   **Secondary Accent (`--accent-secondary`):** `#C86442` (Darker rust/terracotta for active states)
*   **Primary Text (`--text-main`):** `#2C2724` (Deep charcoal/espresso)
*   **Secondary Text (`--text-muted`):** `#8C827A` (Muted warm gray-brown)
*   **Graphical/Illustration Tones:** Deep forest greens (`#2D5248`), mountain browns (`#C28E6A`, `#A66E4C`), and soft sky gradients (`#EAE3D9`).

### Typography System
*   **Primary Font Family:** **SF Pro Rounded** (iOS system font) or **Quicksand** / **Nunito** as web fallbacks.
*   **Fallback Stack:** `font-family: 'Quicksand', 'Nunito', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif;`
*   **Font Weights Used:** Regular (400), Medium (500), SemiBold (600), Bold (700).
