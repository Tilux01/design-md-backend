# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Dark Mode Glassmorphism & High-Performance Developer SaaS Dashboard.
- **Visual Density & Whitespace Ratio**: High-density UI balanced with deep radial glow lighting, subtle gradient mesh borders, and spacious card padding (`24px` to `32px`).
- **Surface Elevation Model**: Multi-layered depth utilizing absolute-positioned ambient lighting (`blur-3xl`), translucent glass surfaces (`backdrop-filter: blur(16px)`), micro-inset shadows, and 1px linear gradient borders (`rgba(255, 255, 255, 0.08)`).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase pill badges, radial ambient glow orbs, glassmorphism panels, circular speedometer dials, checkmark validation icons.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `12px`, font-weight `600`, tracking `0.05em`, border-radius `9999px`, background translucency `rgba(59, 130, 246, 0.1)`, border width `1px`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or inline SVG.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
