# UI Design Specification: Financial Mobile App Clone

## 1. Global Layout & Structure

*   **Screen Orientation:** Portrait (Mobile Device Viewport).
*   **Background:** 
    *   Upper (Dark Section): Deep dark gradient/charcoal (`#16181d` to `#0d0f12`), featuring subtle atmospheric lighting highlights (yellow and turquoise glow in the upper right quadrant).
    *   Lower (Light Section): Solid crisp white (`#ffffff`) card container with rounded top corners (`border-top-left-radius: 32px`, `border-top-right-radius: 32px`), overlapping the dark section.
*   **Dimensions & Bounds:** Edge-to-edge full screen mobile application layout (omitting external device bezels/shadows).

---

## 2. Typography & Font Stack

*   **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif.
*   **Fallback Strategy:** Modern sans-serif stack prioritized for clean, highly legible UI readability.

| Element | Font Size | Font Weight | Color / Hex | Notes |
| :--- | :--- | :--- | :--- | :--- |
| **Status Bar (Time/Icons)** | 14px | Semi-bold (600) | `#ffffff` | Clean Apple iOS style status indicators |
| **Total Balance Label** | 13px | Regular (400) | `#94a3b8` (Muted gray) | Uppercase/Sentence case spacing |
| **Total Balance Amount** | 36px | Bold (700) | `#ffffff` | Large primary currency display |
| **Cents Decimal (`.43`)** | 20px | Medium (500) | `#94a3b8` | Subscript/Smaller scale next to balance |
| **Button Text (Send/Request)** | 14px | Semi-bold (600) | `#1a1d24` (Send) / `#ffffff` (Request) | Action buttons |
| **Spending Header Label** | 13px | Regular (400) | `#94a3b8` | Sub-card header |
| **Spending Amount** | 20px | Bold (700) | `#ffffff` | Secondary financial metric |
| **Transactions Title** | 15px | Semi-bold (600) | `#1e293b` | Section header inside white sheet |
| **Transaction Item Title** | 14px | Medium (500) | `#1e293b` | Merchant/App name |
| **Transaction Negative Amount** | 14px | Semi-bold (600) | `#1e293b` | Outflow (e.g., `-60 $`) |
| **Transaction Positive Amount** | 14px | Semi-bold (600) | `#16a34a` (Green) | Inflow (e.g., `2 000 $`) |

---

## 3. Component Breakdown & Styling

### A. Header & Status Bar
*   **Top Bar:** Displays time `"1:01"` on the left, standard iOS signal strength, Wi-Fi, and battery icons on the right in pure white (`#ffffff`).
*   **Top Navigation Row:**
    *   **Profile Avatar:** Circular profile image positioned on the top left.
    *   **Notification Bell:** Minimalist outline notification bell icon on the top right.

### B. Total Balance & Quick Actions Card
*   **Balance Display:** 
    *   Label: "Total balance"
    *   Value: `"$ 7,854 .43"` (Large bold display with subtle styling for cents).
*   **Action Buttons:**
    *   **"Send" Button:** Pill-shaped button, white background (`#ffffff`), dark text (`#1a1d24`), featuring a left-aligned circular arrow icon inside a dark circle.
    *   **"Request" Button:** Pill-shaped button, translucent/dark glassmorphism background (`rgba(255, 255, 255, 0.1)`), white text (`#ffffff`).
*   **Virtual Card Graphic (Top Right):**
    *   Vertically oriented stacked card graphic peeking from the right edge.
    *   Gradient fills ranging from bright yellow to vibrant turquoise/cyan.

### C. Spending Widget
*   **Container:** Dark rounded container card (`background: rgba(255, 255, 255, 0.05)`, `border-radius: 16px`).
*   **Content Left:** Label `"Spending"` and amount `"$1,385"`.
*   **Content Right:** Horizontal stack of circular avatar/icon thumbnails representing recent categories or contacts (overlapping layout with a `+2` indicator).

### D. Transactions Sheet (White Section)
*   **Container:** Large white surface taking up the bottom half of the screen.
*   **Header Controls:** 
    *   Left: Filter/List icon (`#64748b`).
    *   Center: Title `"Transactions"` (`#1e293b`, centered).
    *   Right: Search magnifying glass icon (`#64748b`).

*   **Transaction List Items:**
    *   Each row contains:
        1.  **Leading Icon:** Circular or branded logo badge (e.g., Apple logo, Threads `@` symbol, Exoplan `31` badge, Orange C-logo). Each icon includes a small colored notification status dot (turquoise, yellow, blue) positioned at the bottom right of the icon.
        2.  **Title:** Merchant name (e.g., "Apple", "Threads", "Exoplan").
        3.  **Trailing Amount:** Right-aligned monetary value. Outflows are prefixed with a minus sign and standard dark text (`-60 $`, `-300 $`, `-20 $`, `-140 $`); inflows are displayed in green (`2 000 $`).

### E. Floating Bottom Navigation Bar
*   **Container:** Floating pill-shaped dock (`background: #16181d`, `border-radius: 32px`, centered horizontally near the bottom).
*   **Icons (Left to Right):**
    1.  People/Group icon (dimmed gray).
    2.  Home icon enclosed in a solid white active circle badge (`background: #ffffff`, icon color `#16181d`).
    3.  Wallet/Card icon (dimmed gray).

---

## 4. Image Assets Description & Placement

1.  **Profile Avatar (Top Left):**
    *   *Description:* Circular headshot image of a person in monochrome/grayscale tones.
    *   *Properties:* Backgroundless/transparent circular mask, diameter ~36px, zero rotation.
2.  **Spending Participant Avatars (Middle Right):**
    *   *Description:* A series of small circular profile pictures and brand icons (orange C logo, user portrait).
    *   *Properties:* Circular crop, layered horizontally with negative margins for an overlapping stack effect, zero rotation.
3.  **Transaction Icons (List):**
    *   *Apple Logo:* Black silhouette vector icon inside a clear circular container.
    *   *Threads Logo:* Stylized `@` symbol in black on a white/light circular background with a yellow status dot.
    *   *Exoplan Icon:* Dark green circular badge featuring the number "31" in bold white typography with a turquoise status dot.
    *   *Orange C Icon:* Vibrant orange circular icon with a white stylized letter "C".
    *   *Properties:* All icons are backgroundless/transparent circular elements aligned vertically on the left side of each transaction row, standard 24px–32px sizing.
