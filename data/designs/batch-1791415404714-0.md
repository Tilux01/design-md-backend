# Design Specification: Creator Portfolio App

## 1. Overview
A minimalist, high-contrast dark-mode creator portfolio featuring monochrome editorial photography, clean data typography, and a vivid gradient call-to-action (CTA).

---

## 2. Color Palette

| Token | Hex / Value | Usage |
| :--- | :--- | :--- |
| `background-dark` | `#0A0A0C` | App canvas, card panels |
| `surface-elevated` | `#16161A` | Secondary cards, button containers |
| `text-primary` | `#FFFFFF` | Primary headers, values |
| `text-secondary` | `#8E8E93` | Metadata, bio text, inactive labels |
| `accent-gradient` | `linear-gradient(90deg, #FAD7A1 0%, #E8998D 45%, #C2719E 100%)` | Primary bottom CTA pill |
| `pill-dark` | `rgba(255, 255, 255, 0.12)` | Navigation pills, chip backgrounds |

---

## 3. Typography

* **Primary Display**: `Syne` or `Clash Display` (700 Bold)
  * Fallback: `Helvetica Neue`, `Arial Black`, `sans-serif`
* **Body & Data**: `Inter` or `Plus Jakarta Sans` (400 Regular, 500 Medium, 600 SemiBold)
  * Fallback: `system-ui`, `-apple-system`, `sans-serif`

| Style | Font | Size / Weight | Line Height |
| :--- | :--- | :--- | :--- |
| **Hero Title** | Display | 32px / 700 | 1.1 |
| **Section Header** | Display | 20px / 600 | 1.2 |
| **Stat Value** | Body | 18px / 600 | 1.2 |
| **Stat Label** | Body | 12px / 400 | 1.3 |
| **Body / Bio** | Body | 14px / 400 | 1.4 |
| **CTA Text** | Body | 15px / 600 | 1.0 |

---

## 4. Screen Specifications

### Screen 1: Profile View

#### Layout Structure
* **Top App Bar**:
  * Left: Circular blur icon button (`40x40px`, back icon).
  * Right: Rounded dark pill (`80x36px`) with action label.
* **Hero Image**:
  * High-contrast B&W editorial portrait covering top 55% of viewport.
  * Base blend: Dark gradient fade at the bottom (`rgba(10,10,12,0)` to `#0A0A0C`).
* **Profile Info Panel**:
  * Name header with adjacent circular social/badge chips.
  * 3-line bio text (`text-secondary`).
* **Metrics Row**:
  * 3 equal-width columns: Metric value stacked above metadata label.
  * Subtle vertical dividers (`1px solid rgba(255,255,255,0.08)`).
* **Sticky Bottom Bar**:
  * Gradient CTA button (`width: calc(100% - 32px)`, `height: 52px`, `radius: 26px`).

---

### Screen 2: Gallery & Content Feed

#### Layout Structure
* **Sticky Collapsed Header**:
  * Minified hero portrait blurred in background.
  * Compact title and compact action pills.
* **Work Gallery Carousel**:
  * Horizontal snapping list with `16px` padding.
  * Item dimensions: `140px` width, `160px` height, `16px` corner radius.
  * Centered dot pagination below carousel (`active: 16px` pill, `inactive: 6px` dot).
* **Feed / Article Card**:
  * Surface card with `16px` corner radius, dark background (`#16161A`).
  * Top: 32px circular creator avatar + title + timestamp.
  * Excerpt text with max 3 visible lines.

---

## 5. Animations & Transitions

* **Scroll Transition (Profile → Feed)**:
  * Hero image scale down: `1.0` to `0.85`, opacity drops to `0.4`.
  * Title transitions from display size (32px) to inline header (18px) via `transform` interpolation.
* **CTA Button Press**:
  * `transform: scale(0.97)`, duration: `120ms ease-out`.
* **Horizontal Carousel Snap**:
  * Physics: CSS scroll-snap (`snap-type: x mandatory`).
  * Friction: Deceleration rate `0.992` with Spring ease (`cubic-bezier(0.25, 1, 0.5, 1)`).
