# UI/UX Specification & Design System Clone: "Lourve - Museum of Ancient Art"

This document provides the complete, pixel-accurate blueprint to recreate the "Museum of Ancient Art" web interface. The design is tailored for a full-screen, cinematic dark-mode experience.

---

## 1. Global Layout & Canvas Strategy

*   **View Mode:** Full-Screen Edge-to-Edge (`100vw` × `100vh`).
*   **Background:** Deep Obsidian Black (`#0a0a0a` to `#000000` radial gradient) with a subtle vertical grid/column line overlay to evoke structural architectural layout.
*   **Grid Structure:** 
    *   Divided into 6 vertical layout columns using hairline borders (`rgba(255, 255, 255, 0.04)`).
    *   Centered focal stage for the 3D asset/statue and glowing neon halo.

---

## 2. Typography System & Fallbacks

### Primary Brand Typography (Logotype)
*   **Font Family:** `Cinzel`, `Didot`, or `Playfair Display`
*   **Fallback:** `Times New Roman`, `Georgia`, `serif`
*   **Usage:** Logo ("LOURVE"). High tracking/letter-spacing, uppercase.

### Hero Heading Typography
*   **Font Family:** `Baskerville`, `Cormorant Garamond`, `Bodoni MT`
*   **Fallback:** `Georgia`, `serif`
*   **Usage:** "Museum of Ancient Art". High contrast serifs, italicized elements ("of"), and dramatic line-height.

### UI & Navigation Typography
*   **Font Family:** `Inter`, `Helvetica Neue`, `Arial`
*   **Fallback:** `sans-serif`
*   **Usage:** Navigation links (HOME, COLLECTION, ARTISTS, EVENTS, VISIT). Uppercase, tracked out, small font size (`11px` - `12px`).

---

## 3. Color Palette & Tokens

| Token Name | Hex Value / CSS Value | Usage |
| :--- | :--- | :--- |
| **Canvas Background** | `#050505` | Main viewport background |
| **Pure White** | `#FFFFFF` | Primary text, navigation items, halo illumination |
| **Muted Grey** | `#7A7A7A` | Inactive nav links, secondary body text |
| **Electric Blue Accent** | `#1a73e8` / glowing `#00d2ff` | Active state indicator line, subtle selection states |
| **Vertical Grid Lines** | `rgba(255, 255, 255, 0.05)` | Structural architectural column dividers |

---

## 4. Component Breakdown & Spatial Specifications

### A. Header Navigation Bar
*   **Position:** Absolute top, spanning full width with padding (`padding: 32px 48px`).
*   **Logo ("LOURVE"):** 
    *   Left-aligned.
    *   Font-size: `18px`, Letter-spacing: `0.2em`, Weight: Bold.
*   **Menu Items ("HOME", "COLLECTION", "ARTISTS", "EVENTS", "VISIT"):**
    *   Position: Centered horizontally.
    *   Font-size: `11px`, Letter-spacing: `0.15em`, Uppercase.
    *   **Active State ("HOME"):** Features a short, solid electric-blue bottom accent bar (`width: 16px`, `height: 2px`, color: `#2979ff`).
*   **Menu Icon (Top Right):**
    *   3×3 grid of dots (Hamburger/Menu drawer icon), aligned to the far right.

### B. Left Vertical Indicator
*   **Position:** Absolute left center.
*   **Elements:** 
    *   One active blue horizontal dash.
    *   Four inactive muted dots stacked vertically below it, serving as pagination or carousel scroll indicators.

### C. Hero Section (Center Stage)
*   **Central Visual (Statue):**
    *   A high-fidelity 3D/photorealistic render of a classical bronze/dark marble female bust (Venus/antique sculpture profile).
    *   Lighting: Dramatic chiaroscuro lighting hitting the right profile of the face and shoulder.
*   **Background Halo:**
    *   A massive, glowing soft-white circular neon ring positioned directly behind the statue, creating a halo effect. Soft radial drop-shadow bloom (`blur: 40px`).
*   **Hero Typography ("Museum of Ancient Art"):**
    *   Position: Overlaying the bottom-left portion of the statue.
    *   "Museum" (Line 1): Large serif, white, regular.
    *   "of" (Line 2, indented): Small, italicized serif.
    *   "Ancient" (Line 3): Large serif.
    *   "Art" (Line 4, right-aligned to block): Large serif.
*   **Body Copy (Description Block):**
    *   Position: Bottom right of the central statue.
    *   Content: Standard placeholder text (*"Lorem Ipsum is simply dummy text of the printing and typesetting industry..."*).
    *   Font-size: `10px` / `11px`, Line-height: `1.5`, Color: `#8c8c8c`, Max-width: `180px`.

## 5. Animation & Interaction Specifications

1.  **Page Load Entrance:**
    *   **Fade In:** The background and grid lines fade in from black (`opacity: 0` to `1`) over `1.2s` with an `ease-out` curve.
    *   **Statue Reveal:** The 3D statue scales up slightly from `0.95` to `1.0` while fading in with a soft parallax lag.
    *   **Halo Pulse:** The background glowing ring subtly pulses in intensity (opacity oscillates between `0.85` and `1.0` on a 4-second loop).
2.  **Hover States:**
    *   **Nav Items:** Transition color from `#7A7A7A` to `#FFFFFF` with a `0.3s ease` transition. The active blue underline slides smoothly when switching categories.
    *   **3D Statue Parallax:** On mouse movement (`mousemove`), the statue tilts slightly on the X and Y axes (max rotation: `±3deg`) to create a depth-of-field 3D effect.
