# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Cinematic Sci-Fi, High-Performance Aerospace Minimalist, Dark Mode Speculative Design.
- **Visual Density & Whitespace Ratio**: Immersive wide-format composition with deliberate atmospheric isolation. The focal elements (futuristic aircraft) command primary visual weight against expansive, low-contrast natural terrain and dynamic cloudscapes.
- **Surface Elevation Model**: Metallic specularity and multi-layered atmospheric depth. Foreground and mid-ground spacecraft exhibit sharp, polished titanium/chrome surfaces with subtle edge-highlight reflections, separating them from the matte, desaturated geological topology below.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase pill badges with pulsating status indicators, glassmorphic HUD framing, cinematic vignette lighting.
- **Pill Badge Specification**: Padding (`4px 12px`), font-size (`12px`), font-weight (`600`), tracking (`0.05em`), border-radius (`9999px`), background translucency (`rgba(56, 189, 248, 0.1)`), border width (`1px`).
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-cyan-400 inline-block animate-pulse"></span>`.
