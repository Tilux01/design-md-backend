# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Modern E-Commerce Web Application / Clean Editorial Minimalist Landing Page.
- **Visual Density & Whitespace Ratio**: High whitespace-to-content ratio with large asymmetric typography, smooth rounded containers, and high-fidelity 3D product visualization as the central hero element.
- **Surface Elevation Model**: Clean flat backgrounds (`#F4F4F6`), subtle layered frosted glass containers (`background: rgba(255,255,255,0.7)`), soft ambient shadows, and pill-shaped interactive floating elements.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Floating status micro-badges, avatar group stacks for social proof, stylized circular search/utility actions, asymmetrical container layout framing a 3D product render.
- **Pill Badge Specification**: Padding `6px 12px`, font-size `12px`, font-weight `500`, border-radius `9999px`, background `#FFFFFF`, border `1px solid rgba(0,0,0,0.08)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before`.
  - Sparkle / Star (✦) -> Use `&#9733;` for rating stars.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
