# `design.md`: Valentine's Day Interactive Website Specification

## 1. Executive Summary & Canvas Setup
This document specifies the UI/UX design for a romantic, full-screen mobile-first Valentine webpage. The layout must cover 100% of the screen without any framing, margins, or device mockups.

* **Target Viewport:** Full Screen / Responsive Mobile (e.g., `100vw`, `100dvh`).
* **Canvas Alignment:** Centered vertical flexbox column layout.
* **Overall Vibe:** Dark, romantic, vintage, elegant, atmospheric.
* **Overflow:** `hidden` (no scrollbars).

---

---

## 3. Typography & Fonts

### **Main Headline Text ("Will You Be My Valentine?")**
* **Primary Font:** `Dancing Script` (Google Font) or `Great Vibes` (Google Font)
* **Fallback Stack:** `'Brush Script MT', 'Sacramento', 'Parisienne', cursive, serif`
* **Font Weight:** 600 (Semi-Bold) or 700 (Bold)
* **Font Size:** `2.5rem` (Mobile) / `3.2rem` (Desktop)
* **Line Height:** `1.3`
* **Letter Spacing:** `0.02em`
* **Text Alignment:** Center
* **Text Shadow:** Soft subtle dark blur `0px 2px 8px rgba(0, 0, 0, 0.6)`

### **Call-To-Action Text ("click here")**
* **Primary Font:** `Dancing Script` / `Caveat` / `Sacramento`
* **Fallback Stack:** `cursive, sans-serif`
* **Font Size:** `0.95rem` / `15px`
* **Font Weight:** 400 (Regular)
* **Color:** Translucent Cream (`rgba(255, 240, 226, 0.7)`)

---

## 4. Background & Atmosphere

1. **Base Gradient Layer:**
   * Radial gradient originating from screen center:
     * Center: `#4A060E`
     * Edge: `#1A0103`
2. **Texture Overlay (Background Grain/Noise):**
   * High-frequency subtle noise/paper texture overlay at `4% - 6%` opacity to give a rich, matte paper feel.
3. **Floating Dust Particles:**
   * Subtle, tiny ambient specks (white/gold specks at `20%` to `40%` opacity) scattered across the background canvas to mimic floating dust particles under dim warm lighting.

---

## 5. UI Elements Layout & Placement

The layout is arranged vertically in a single flex column centered horizontally:

```
+------------------------------------------+
|                                          |
|         Will You Be My                   |
|           Valentine?                     |  <- Upper Middle (Y: ~35%)
|                                          |
|              [  Wax  ] -> click here     |
|            [ Envelope ]                  |  <- Lower Middle (Y: ~60%)
|                                          |
+------------------------------------------+
```

### A. Headline Text
* **Position:** Top `32%` of screen height.
* **Width:** `85%` of viewport width max.
* **Content:**
  Line 1: "Will You Be My"  
  Line 2: "Valentine?"

---

### B. Envelope Image Asset

* **Asset Type:** Transparent Background PNG (`envelope.png`).
* **Visual Description:**
  * A traditional rectangular paper envelope made of deep crimson red cardstock.
  * Closed triangular flap pointing downward towards the horizontal center.
  * Subtle realistic inner fold lines and soft shadows underneath the flap edge to create realistic depth.
  * Matte finish (no bright metallic glossy highlights).
* **Dimensions:**
  * Width: ~`300px` to `340px` on mobile screens (`~82vw`).
  * Aspect Ratio: ~`1.5:1` (Standard envelope ratio).
* **Position & Alignment:**
  * Centered horizontally (`margin: 0 auto`).
  * Vertical position: Top edge at ~`52%` from screen top.
* **Rotation / Tilt:**
  * **Angle:** Rotated **`-6 degrees` counter-clockwise** (`transform: rotate(-6deg)`).
* **Drop Shadow:**
  * `filter: drop-shadow(0px 18px 25px rgba(0, 0, 0, 0.6))`

---

### C. Wax Seal Image Asset (Interactive Button)

* **Asset Type:** Transparent Background PNG (`wax-seal.png`).
* **Visual Description:**
  * A circular wax stamp impression made of champagne/beige-gold wax.
  * Slightly organic, irregular circular edges (mimicking real pressed wax).
  * Center features an intricate embossed vintage cursive monogram emblem (Letter "M" or decorative crest).
  * Subtle 3D embossing effect with light source coming from top-left.
* **Dimensions:**
  * Diameter: `72px` to `80px`.
* **Position:**
  * Placed directly on top of the envelope's lower flap tip (dead center of the envelope).
* **Interactivity:**
  * Acts as a clickable button (`cursor: pointer`).
  * Hover state: Slight scale up (`transform: scale(1.05)`).

---

### D. "click here" Pointer Prompt

* **Visual Description:**
  * Consists of small handwritten cursive text reading `"click here"`.
  * Accompanied by a thin, hand-drawn curved arrow pointing from the right side of the text directly towards the wax seal.
* **Positioning:**
  * Relative to the wax seal: Located to the **right/lower-right side** of the wax seal.
  * Distance: ~`20px` to the right of the wax seal boundary.
  * Slight downward tilt matching the curve of the arrow.
* **Color:** Warm semi-transparent off-white (`rgba(255, 240, 226, 0.65)`).

## 7. Responsive Adjustments

* **Mobile (Default, 320px - 480px):** Envelope width `290px` to `330px`. Font size `2.4rem`.
* **Tablet / Desktop (768px+):** Envelope max-width `380px`. Font size `3.2rem`. Entire container stays vertically centered in full viewport without scaling breaking the composition.
