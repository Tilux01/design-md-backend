This document provides a comprehensive technical specification for cloning the Dignitas Esports web interface shown in the provided media. The design is a high-contrast, dark-mode "Player Profile" and "Dashboard" layout featuring a mix of brutalist graffiti elements and clean, modern data visualization.

# Design Specification: Dignitas Esports Player Profile

## 1. Global Theme & Visual Language
*   **Color Palette:**
    *   **Primary Background:** `#0A0A0A` (Deep Matte Black).
    *   **Accent Yellow:** `#F5D415` (Vibrant "Dignitas" Yellow).
    *   **Secondary Background (Cards):** `#161616` with a slight border/glow.
    *   **Text Primary:** `#FFFFFF` (Pure White).
    *   **Text Secondary:** `#A0A0A0` (Medium Gray).
    *   **Status Red:** `#FF4B4B` (For "Live Now" indicator).
*   **Aesthetics:** High-contrast, layered depth (Z-index stacking), graffiti-inspired typography, and glassmorphism for data cards.

## 2. Typography
*   **Primary Heading Font:** A heavy, condensed Sans-Serif (e.g., **"Inter"** Extra Bold or **"Barlow Condensed"**).
*   **Body & Stats Font:** A clean, geometric Sans-Serif (e.g., **"Roboto"** or **"Montserrat"**).
*   **Graffiti Font:** A custom brush-stroke or spray-paint style font (e.g., **"Road Rage"** or **"Street Soul"**).
*   **Fallback Stack:** `System-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.

## 3. Layout Structure

### A. Global Navigation & Sidebar
*   **Top Header:**
    *   **Left:** Dignitas Logo (White).
    *   **Center:** Breadcrumb navigation: `LEAGUE OF LEGENDS > PROFILE` (Uppercase, small font size, tracked out).
    *   **Right:** "LIVE NOW" text with a pulsing red circular icon.
*   **Right Sidebar:**
    *   A slim, semi-transparent dark bar containing vertical social icons (Twitter, Instagram, Facebook, Twitch, YouTube, TikTok).
    *   A "Game Controller" icon at the bottom to toggle game-specific views.

### B. Hero Section (The "Aphromoo" Profile)
*   **Background Layer:** Solid `#0A0A0A`.
*   **Mid Layer (Graffiti):** A massive, stylized yellow spray-paint graphic of the word "APHROMOO". It should be slightly rotated (approx. -2 degrees) and feature "drip" effects on the right side.
*   **Foreground Image (Player):** 
    *   **Description:** A high-resolution, **backgroundless PNG** of the player (Zaqueri Black). He is facing forward, wearing a black and yellow Dignitas camo-pattern jersey and glasses.
    *   **Placement:** Centered horizontally, cut off at the waist. The image should overlap the graffiti text but sit behind the stats cards.
*   **Player Info (Left):**
    *   Name: "Aphromoo" (Large, White, Bold).
    *   Real Name: "ZAQUERI BLACK" (Smaller, Yellow).
    *   Socials: Small white icons for Twitter, Instagram, and Twitch.
    *   Flag: A small US flag icon.

### C. Statistics Cards (The Glassmorphism Row)
Three main cards overlaying the player's waist area:
1.  **Matches Played:** "59" (Large white text).
2.  **Games Played:** "71" (Large white text). This card features a yellow-to-transparent gradient overlay.
3.  **AVG KDA:** "2.40" (Large white text).
*   **Styling:** Dark semi-transparent background (`rgba(25, 25, 25, 0.8)`), rounded corners (approx 12px), and a thin 1px border.
*   **Sub-stats:** A thin horizontal bar below the cards containing "KP% 62%", "VSPM 2.40", "AVG DMG% 6.6%", and "GOLD% 12.9%".

## 5. Asset Descriptions for Implementation

*   **Player Portrait (Aphromoo):** A professional studio portrait. Lighting should be "Rembrandt" style (high contrast). Ensure the PNG transparency is clean around the hair and glasses.
*   **Graffiti Graphic:** This should be an SVG or a high-res PNG with transparency. Color: `#F5D415`. It should look like hand-drawn street art, not a standard font.
*   **Icons:** Use a consistent line-art icon set (like FontAwesome or Phosphor Icons) with a weight of "Regular" or "Light".
*   **Live Indicator:** A CSS animation: `@keyframes pulse { 0% { opacity: 1; } 50% { opacity: 0.3; } 100% { opacity: 1; } }`.

---

## 6. CSS Implementation Notes
*   **Container:** Use `display: flex` for the sidebar/main content split.
*   **Hero Stacking:** Use `display: grid` where all children occupy `grid-area: 1/1` to stack the graffiti, player, and stats easily using `z-index`.
*   **Text Rendering:** Use `-webkit-font-smoothing: antialiased;` to ensure the white text remains sharp against the black background.
*   **Gradients:** The "Games Played" card uses a linear gradient: `linear-gradient(to bottom, rgba(245, 212, 21, 0.4), rgba(245, 212, 21, 0))`.
