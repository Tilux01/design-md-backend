# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Modern FinTech Mobile App UI with Clean Glassmorphism & High-Contrast Light Mode.
- **Visual Density & Whitespace Ratio**: High-density mobile canvas utilizing structured 8pt spacing tokens, generous rounded containers (`24px` - `36px`), and soft layered surface depth to prioritize financial clarity.
- **Surface Elevation Model**: Clean multi-tier surface architecture featuring an off-white app canvas, crisp white container cards with subtle borders, vibrant lime-green (`#b4ff54`) interactive gradient zones, and minimal drop-shadows.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-contrast financial balance displays, lime-to-white card gradients, rounded bottom navigation pills, status indicator dots.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `12px`, font-weight `600`, tracking `0`, border-radius `9999px`, background `#111111`, text `#ffffff`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content to prevent rendering glitches.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;` or `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
