# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial E-Commerce / Clean Modern Tech Marketplace.
- **Visual Density & Whitespace Ratio**: High structural clarity with balanced padding density, utilizing generous whitespace around feature banners, multi-column card grids, and pill-based navigation bars.
- **Surface Elevation Model**: Clean flat cards separated by subtle 1px light gray borders (`#E2E8F0`), elevated surfaces using soft shadows (`0 4px 12px rgba(0,0,0,0.05)`), and vibrant crimson primary branding accents (`#DC2626`).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase pill badges, subtle glowing product highlights, crisp icon containers, clean multi-item filter navigation.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `12px`, font-weight `600`, tracking `0.05em`, border-radius `9999px`, background translucency `rgba(220, 38, 38, 0.1)`, border width `1px`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content to prevent rendering glitches.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;` or `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
