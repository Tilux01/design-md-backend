# Design System & Implementation Guide

This document outlines the exact design tokens, typography, layout structure, and component specifications required to build a pixel-perfect, full-screen clone of the provided mobile app UI.

---

## 1. Global Design Tokens

### Color Palette
- **Primary Background / Base:** `#7A372B` (Rich terracotta/brick red)
- **Screen Canvas / Backdrop:** `#63271D` (Deep muted rust)
- **Card / Surface Dark:** `#4A1E17` (Dark reddish-brown container surface)
- **Primary Text:** `#FFFFFF` (Pure white)
- **Secondary Text (Muted):** `#C29288` (Light terracotta/dusty rose)
- **Button Fill:** `#A64B3C` (Lighter warm terracotta)
- **Icon/Action Background (Translucent):** `#FFFFFF1A` (White with 10% opacity)

### Typography
- **Font Family:** Inter / System UI Sans-Serif (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`)
- **Font Weights Used:** Regular (400), Medium (500), Bold (700)

#### Scale:
- **Screen Header:** 16px / Weight: 500 / Letter Spacing: Wider
- **Product Title:** 20px / Weight: 700
- **Section Headers:** 12px / Weight: 500 / Uppercase / Letter Spacing: Wider
- **Body / Description:** 12px / Weight: 400 / Line Height: 1.5
- **Price Display:** 18px / Weight: 700
- **Button Text:** 12px / Weight: 700 / Uppercase / Letter Spacing: Wide

---

## 2. Layout Structure & Containers

- **Layout:** Mobile application view split into two representative screens (Product Details & Technical Specifications).
- **Border Radius (App Frame):** `40px` (smooth continuous corners)
- **Shadows (Depth):** 
  - Ambient shadow: `0 24px 48px rgba(0, 0, 0, 0.35)`

---

## 3. Component Specifications

### A. Screen 1: Product Details View

#### 1. Top Navigation Bar
- **Height:** 60px (top padding included)
- **Back Button:** Circular icon button (`36px × 36px`, border-radius: `50%`, background: `#FFFFFF1A`), containing a left-facing chevron.
- **Pagination / Indicator:** 3 horizontal dots (active dot is elongated/pill-shaped, white; inactive are muted/faded).

#### 2. Hero Image Section
- **Height:** ~50% of screen height
- **Content:** High-resolution product render of the suspended "Aplomb" lamp positioned centrally against a vertical gradient background shifting from dark terracotta to lighter ambient light.

#### 3. Bottom Information Card
- **Background:** `#4A1E17`
- **Border Radius (Top Only):** `32px 32px 0 0`
- **Padding:** `24px`
- **Content Stack:**
  - **Category Label:** `SUSPENSION` (10px, uppercase, tracking: 1.5px, color: `#C29288`)
  - **Title:** `Aplomb - Brick Red` (20px, bold, white, margin-top: 4px)
  - **Description:** Paragraph text detailing the material and acoustic properties (12px, color: `#C29288`, line-height: 1.6, margin-top: 12px)
  - **Price & CTA Row:** (flexbox, space-between, align-items: center, margin-top: 24px)
    - **Price:** `€ 315.00` (18px, bold, white)
    - **Add to Bag Button:** 
      - Background: `#A64B3C`
      - Border Radius: `50px` (pill)
      - Padding: `12px 24px`
      - Label: `ADD TO BAG` + Right Arrow icon inside a small circular wrapper.

---

### B. Screen 2: Technical Details View

#### 1. Top Navigation Bar
- **Back Button:** Same as Screen 1.
- **Title:** `Technical Details` (Centered, 14px, medium weight).

#### 2. Upper Showcase Section
- **Content:** Horizontal layout shot of the top fixture and cord of the lamp against the primary brick red background.
- **Product Title Heading:** `Aplomb - Brick Red` (18px, bold, white, padding-left/right: `24px`).

#### 3. Specifications List
- **Padding:** `24px`
- **Section 1: MATERIAL**
  - Label: `MATERIAL` (10px, uppercase, `#C29288`, tracking: 1px)
  - Value: `Concrete and aluminium` (14px, medium, white, margin-top: 4px)
- **Section 2: LIGHT SOURCE**
  - Label: `LIGHT SOURCE` (10px, uppercase, `#C29288`, tracking: 1px, margin-top: 20px)
  - Value: `LED retrofit, Halo 60WG9` (14px, medium, white, margin-top: 4px)
- **Section 3: COLORS**
  - Label: `COLORS` (10px, uppercase, `#C29288`, tracking: 1px, margin-top: 20px)
  - **Color Swatches Row:** Horizontal scroll or flex wrap of 5 color variants (Grey, Green, Yellow, White, Brown), each shown as a tilted/skewed circular material sample chip with abbreviation labels underneath (`CG`, `OG`, `SY`, `W`, `B`).

#### 4. Product Gallery Drawer (Bottom)
- **Background:** `#4A1E17`
- **Border Radius (Top Only):** `32px 32px 0 0`
- **Padding:** `20px 24px`
- **Header:** 
  - Collapse/Expand Indicator: Up Chevron (`^`) centered.
  - Title: `Product Gallery` (14px, medium, white)
  - Counter: `15 Photos` (12px, `#C29288`, aligned right)
- **Image Grid:** Horizontal scrollable row of thumbnail images with rounded corners (`12px` border radius), showing interior and architectural shots of the lamp in use.
