# Design Specification: Nespresso E-Commerce Product Page (Clone)

This document outlines the exact design specifications for a full-screen, responsive web clone of the provided Nespresso product page interface.

---

## 1. Global Layout & Canvas

*   **View:** Full-screen responsive viewport (`width: 100vw`, `height: 100vh`).
*   **Base Background:** Dark teal gradient radial/linear background.
    *   *Top/Center Gradient Color:* Deep teal `#153b3d` transitioning outwards into a richer, darker forest/teal `#081d1f`.
*   **Typography Base:** Clean, modern sans-serif typeface (e.g., *Helvetica Neue*, *Arial*, or *Montserrat* for titles). Uppercase styling is utilized extensively for navigation and metadata.

---

## 2. Header & Navigation

### Top Bar
*   **Left Element:** 
    *   Text/Action: `FILTER v`
    *   Font size: `11px`, Uppercase, Letter spacing: `1px`, Color: `#ffffff`.
*   **Center Element:** 
    *   Logo: Official **NESPRESSO** wordmark in centered uppercase serif/sans-serif styling with a registered trademark symbol (`®`), Color: `#ffffff`.
*   **Right Element:** 
    *   Action: `CART (3)` (with shopping cart icon).
    *   Font size: `11px`, Uppercase, Letter spacing: `1px`, Color: `#ffffff`.

### Category Navigation Menu
Positioned horizontally below the primary header.
*   **Items:** `MY FAVOURITES`, `INTENSO`, `ESPRESSO`, `PURE ORIGIN`, `LUNGO`, `DECAFFEINATO`, `VARIATION`.
*   **Font Size:** `10px` – `11px`, Uppercase, Letter spacing: `1.5px`.
*   **Active State (`INTENSO`):** 
    *   Text Color: Pure White (`#ffffff`), bolded.
    *   Indicator: Small white dot positioned immediately below the active category text.
*   **Inactive State:** 
    *   Text Color: Muted Teal/Grey (`#547072`).

---

## 3. Main Product Carousel / Showcase Area

The central viewport features a horizontal carousel displaying coffee pods at varying depths and opacities, with the active product centered.

### Background Typography (Watermark)
*   Large watermark text behind the active product: **`11`**
*   Font Size: Extremely large (approx. `180px` – `220px`).
*   Color: White/Teal overlay with very low opacity (`opacity: 0.05` to `0.08`), creating a subtle typographic depth effect.

### Product Pods (Horizontal List)
Each pod is rendered at a dynamic 3D angle pointing downward-left.
1.  **Left Pod 1 (Inactive - Purple):**
    *   Colorway: Deep Purple / Violet (`#4b164c`).
    *   Opacity: Reduced (`opacity: 0.4`).
    *   Scale: Slightly smaller (scale-down effect for peripheral carousel items).
2.  **Center Pod (Active - Teal / Dark Cyan):**
    *   Colorway: Deep Blue-Teal (`#2c5963`).
    *   Opacity: `1.0` (Fully opaque with realistic shadow cast underneath).
    *   Features: Small '+' info icon badge positioned top-right of the capsule.
3.  **Right Pod 1 (Inactive - Brown):**
    *   Colorway: Dark Brown / Bronze (`#4a3530`).
    *   Opacity: Reduced (`opacity: 0.4`).
4.  **Right Pod 2 (Inactive - Black):**
    *   Colorway: Charcoal Black (`#1c1c1c`).
    *   Opacity: Reduced (`opacity: 0.2`).

---

## 4. Active Product Details & Actions

Positioned directly beneath the active (center) coffee capsule:

### Intensity Label
*   Text: `Intensity - 11`
*   Font Style: Italicized serif font, medium weight.
*   Color: Soft off-white (`#d2d2d2`).
*   Font Size: `12px`.

### Cup Size Indicators
*   Text: `25ml, 40ml`
*   Font Size: `10px`, Italic serif, Color: `#8fa4a6`.

### Product Name
*   Text: **`DHARKAN`**
*   Font Size: `22px` – `24px`, Bold, Uppercase, Letter spacing: `2px`.
*   Color: Pure White (`#ffffff`).

### Price
*   Text: `£3.30`
*   Font Size: `12px`, Bold.
*   Color: Soft White (`#ffffff`).

### Quantity Selector (Stepper)
*   **Container Box:** Semi-transparent dark background card (`rgba(255, 255, 255, 0.05)` to `0.08`) with subtle border.
*   **Controls:** 
    *   Minus symbol (`–`) on the left.
    *   Text: `1 Sleeve` (Centered, uppercase, `11px`).
    *   Plus symbol (`+`) on the right.
*   **Color:** `#ffffff`.

### Primary CTA Button (`ADD TO CART`)
*   **Background:** Semi-transparent dark slate/teal pill or rounded rectangle button (`rgba(255, 255, 255, 0.15)`).
*   **Content:** Shopping cart icon + `ADD TO CART` text.
*   **Typography:** Uppercase, `11px`, letter-spacing `1px`, Bold, White (`#ffffff`).
*   **Hover/Active States:** Slight lightening of the background fill.

---

## 5. Footer / Side Utilities

### Right Margin Utilities (Vertical Socials)
*   Icons: Facebook (`f`) and Twitter (`t` bird outline).
*   Text rotated 90 degrees reading upwards: `SHARE`
*   Positioning: Fixed to the bottom-right viewport edge.
*   Color: Muted white/grey (`#8fa4a6`), size `10px`.

---

  overflow: hidden;

  font-family: 'Helvetica Neue', Arial, sans-serif;

}
