# UI/UX Specification: "FRAGMENTED REALITY" Landing Page

## 1. Overview & Layout Strategy
* **Design Philosophy:** Immersive, atmospheric, surrealist minimalism. It combines cinematic 3D realism with clean, modern web UI.
* **Viewport Structure:** **Full Screen (100vw x 100vh)** hero section. The actual mockup sits centered inside a futuristic, reflective landscape environment, but the code implementation should target a full-bleed viewport interface.
* **Grid System:** 12-column flexible layout with absolute positioning for floating spatial elements and a centralized navigation system.

---

## 2. Color Palette
* **Primary Background:** `#0B0F12` (Deep Obsidian / Dark Slate)
* **Atmospheric Grays (Atmosphere/Fog):** `#3A424A`, `#5A6570`
* **Text Primary (Headings/Navigation):** `#EAEFF2` (Off-white / Silver Moon)
* **Text Secondary (Sub-navigation/Labels):** `#9DA5AF`
* **Accents / Highlights:** Pure White (`#FFFFFF`) for active states and primary CTAs.
* **Gradients:** Subtle radial gradients (`rgba(10, 15, 20, 0.4)` to `rgba(0, 0, 0, 0.8)`) overlaying the background image to ensure text contrast.

---

## 3. Typography & Fallbacks

### Heading / Hero Title (`FRAGMENTED REALITY`)
* **Font Family:** `Syncopate`, `Montserrat`, or `Space Grotesk`
* **Fallback Stack:** `sans-serif`
* **Weight:** Bold (`700`)
* **Letter Spacing (Tracking):** Extremely wide (`0.35em` to `0.4em`)
* **Text Transform:** Uppercase

### Navigation & UI Elements (`Home`, `About`, `Service`, `Contact`, `Let's Start`)
* **Font Family:** `Inter`, `SF Pro Display`, `Roboto`
* **Fallback Stack:** `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`
* **Weight:** Medium (`500`) / Regular (`400`)
* **Size:** `14px` (Desktop)
* **Letter Spacing:** `0.05em`

---

## 4. Component Breakdown & Structure

### A. Navigation Bar (`<nav>`)
* **Position:** Fixed / Absolute at the top (`top: 32px`, `left: 48px`, `right: 48px`).
* **Layout:** Flexbox, spaced-between.
* **Left Element:** Logo/Brand indicator (`FR` with a stylized geometric monogram icon).
* **Center Element (Nav Pill):** 
  * A floating, translucent pill container (`background: rgba(255, 255, 255, 0.05)`, `backdrop-filter: blur(12px)`).
  * Pill border: `1px solid rgba(255, 255, 255, 0.1)`.
  * Border-radius: `50px`.
  * Links: `Home` (Active pill indicator), `About`, `Service`, `Contact`.
* **Right Elements:** 
  * Utility icon (e.g., sound/lock toggle button inside a circular glassmorphism container).
  * CTA Button: `Let's Start` (Pill-shaped, solid white `#FFFFFF` background, dark text `#0B0F12`, hover scale/glow effect).

### B. Hero Section (`<header>`)
* **Background Visual:** Cinematic, moody landscape featuring a desolate, misty coast with colossal floating/levitating monolithic rocks.
* **Center Hero Content:**
  * Sub-headline/Context (implied subtle styling).
  * **Main Title:** `FRAGMENTED REALITY` centered horizontally and vertically within the core viewport.

---

## 5. Animations & Interactive States (Motion Design)

### 1. Page Load Entrance (Cinematic Reveal)
* **Duration:** `1.8s`
* **Easing:** `cubic-bezier(0.16, 1, 0.3, 1)` (Smooth exponential out)
* **Elements:**
  * **Background & Floating Rocks:** Parallax depth zoom-in (scale from `1.08` to `1.0`).
  * **Typography (`FRAGMENTED REALITY`):** Fade in with a letter-spacing expansion from `0.1em` to `0.38em` and opacity from `0` to `1`.
  * **Navigation:** Slide down from `Y: -20px` to `Y: 0` with fade-in.

### 2. Continuous Ambient Animation (Idle Loop)
* **Floating Rocks (Parallax / Levitation):**
  * Gentle, non-linear floating keyframe animation (`translateY` offset of `10px` to `15px` over a `6s-8s` infinite alternate cycle).
* **Mouse Movement Parallax (Tilt.js / Custom JS):**
  * The floating rocks and background layers subtly shift opposite to the user's cursor position (`max-tilt: 5deg`).

### 3. Hover & Click States
* **Nav Links:** Smooth color transition from `#9DA5AF` to `#FFFFFF`.
* **Active Nav Pill:** Morphing background indicator slide or smooth backdrop transition between menu items.
* **`Let's Start` Button:** Scales up by `1.04` with a drop-shadow bloom effect (`box-shadow: 0 0 20px rgba(255, 255, 255, 0.3)`).
