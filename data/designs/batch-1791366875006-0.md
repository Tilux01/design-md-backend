# Website Design Specification: Jason Martin Portfolio

This document outlines the complete specifications to build a 1:1, full-screen clone of the Jason Martin Graphic Designer portfolio website.

---

## 1. Global Styles & Variables

### Typography
*   **Primary Font Family:** Inter, Roboto, or system sans-serif (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`).
*   **Font Weights:**
    *   Light: `300`
    *   Regular: `400`
    *   Semi-Bold: `600`
    *   Bold: `700`

### Color Palette
*   **Primary Dark (Backgrounds):** `#111113` (Very dark charcoal/black)
*   **Container / Card Background:** `#18181b` (Slightly lighter dark shade)
*   **Primary Text:** `#FFFFFF` (Pure White)
*   **Secondary / Muted Text:** `#A1A1AA` (Cool Gray)
*   **Accent Color (Icons/Highlights):** `#38BDF8` (Bright sky blue used in circular background nodes)
*   **Border / Divider Color:** `#27272A` (Dark gray lines)

### Layout Grid & Spacing
*   **Max Width:** `1200px` centered with responsive horizontal padding (`24px` to `48px`).
*   **Sections:** Built as full-viewport height sections (`min-height: 100vh`) with vertical scrolling.

---

## 2. Common Components

### Header / Navigation
*   **Position:** Fixed or sticky at the top of the viewport.
*   **Background:** Semi-transparent dark overlay (`rgba(17, 17, 19, 0.9)`) with a blur backdrop (`backdrop-filter: blur(8px)`).
*   **Layout:** Flexbox, space-between.
    *   **Left (Nav Links):** `Home` (active/bold), `About`, `Resume`, `Portfolio`. Gap: `32px`. Font size: `14px`. Color: `#A1A1AA`, hover color: `#FFFFFF`.
    *   **Right (Contact):** Phone number icon + text (`774-555-3021`). Font size: `14px`. Color: `#A1A1AA`.

---

## 4. Interactivity & Responsiveness

*   **Scroll Behavior:** Smooth scrolling between sections (`scroll-behavior: smooth`).
*   **Responsive Breakpoints:**
    *   **Desktop (>1024px):** Multi-column layouts as specified.
    *   **Tablet (768px - 1024px):** 2-column layout where applicable, reduced font sizes.
    *   **Mobile (<768px):** Single-column stacked layout, collapsible navigation menu (hamburger menu).
