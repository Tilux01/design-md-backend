# Comprehensive Design System & Implementation Specification: "Roboforge" Landing Page

This document serves as the absolute blueprint for a pixel-perfect, full-screen clone of the provided **Roboforge** landing page. All device frames, shadows, and outer website mockups from the source image are omitted; this specification details the **100% viewport-width, full-screen production layout**.

---

## 1. Global Layout & Canvas Architecture

*   **View:** Full-screen responsive viewport (`width: 100vw; height: 100vh; overflow: hidden;`).
*   **Base Background:** Deep, high-contrast cybernetic blue-black gradient.
    *   *CSS Background Rule:* `background: radial-gradient(circle at 60% 40%, #0d2350 0%, #061126 50%, #020713 100%);`
*   **Content Container:** Centered flex/grid container with a maximum width of `1440px` and horizontal padding of `60px`.

---

## 3. Typography & Font Stack

### Font Families
*   **Primary Display / Headings:** **`Syne`** (Fallback: `sans-serif`) – Geometric, futuristic, uppercase style used for the main brand title.
*   **Secondary / Body & Navigation:** **`Plus Jakarta Sans`** or **`Inter`** (Fallback: `system-ui, -apple-system, sans-serif`) – Clean, modern, highly legible sans-serif for UI labels and body copy.

### Typographic Hierarchy

1.  **Main Hero Title (`.hero-title`)**
    *   Text: `ROBOFORGE`
    *   Font Family: `Syne, sans-serif`
    *   Font Weight: `800` (Extra Bold)
    *   Font Size: `clamp(4rem, 8vw, 9.5rem)`
    *   Line Height: `0.9`
    *   Letter Tracking: `0.05em`
    *   Color: `#FFFFFF`
    *   *Visual Effect:* The central character overlapping the glowing portal experiences a subtle mask effect, blending white text with the portal's luminous cyan radiance (`mix-blend-mode: overlay` or structural SVG clipping).

2.  **Subtitle / Descriptor (`.hero-subtitle`)**
    *   Text: `for ROBOTICS and AUTOMATION`
    *   Font Family: `Plus Jakarta Sans, sans-serif`
    *   Font Weight: `500` / `600`
    *   Font Size: `clamp(0.85rem, 1.2vw, 1.1rem)`
    *   Letter Tracking: `0.15em` (Uppercase)
    *   Color: `#FFFFFF`

3.  **Navigation Links (`.nav-link`)**
    *   Items: `Home`, `About`, `Products`
    *   Font Family: `Plus Jakarta Sans, sans-serif`
    *   Font Size: `0.875rem` (`14px`)
    *   Font Weight: `400`
    *   Color: `#94A3B8` (Active/Hover: `#FFFFFF`)

4.  **Brand Logo (`.brand-logo`)**
    *   Text: `roboforge`
    *   Font Family: `Syne, sans-serif`
    *   Font Weight: `700`
    *   Font Size: `1.25rem` (`20px`)
    *   Color: `#FFFFFF`
    *   Text-Transform: `lowercase`

## 4. Section-by-Section UI Blueprint

### A. Navigation Header (`<header>`)
*   **Position:** Fixed top, full width, padded horizontally (`60px`). Height: `90px`.
*   **Layout:** Flexbox, `justify-content: space-between`, `align-items: center`.
*   **Border-Bottom:** Subtle translucent separator line (`border-bottom: 1px solid rgba(255, 255, 255, 0.08)`).
*   **Elements:**
    1.  **Logo:** `roboforge` (Lowercase, bold).
    2.  **Center Nav Pill:** Floating glassmorphism pill (`background: rgba(255, 255, 255, 0.03)`, `backdrop-filter: blur(10px)`, `border-radius: 50px`, `padding: 8px 24px`). Contains links: `Home` (with a subtle underline indicator), `About`, `Products`.
    3.  **Contact Button:** Pill button with rounded border (`border: 1px solid rgba(255, 255, 255, 0.2)`), containing text `Contact Us` and a right-pointing diagonal arrow icon inside a small circular badge (`↗`).

---

### B. Hero Visual & Composition (`<main class="hero">`)
*   **Layout:** CSS Grid / Absolute positioning context covering the viewport beneath the header.
*   **Central Hero Graphic:**
    *   **The Portal Ring:** A massive glowing cyan ring positioned centrally-right (`transform: translate(15%, -5%)`). Features high-intensity outer glow, smoke/fog effects pouring from the base, and caustic water reflections at the floor level.
    *   **The Cybernetic Figure:** A futuristic humanoid figure stepping forward through the glowing portal, backlit by intense white-blue atmospheric backlighting.
*   **Typography Placement:** Left-aligned overlay intersecting with the left edge of the portal ring.

---

### C. Action Callout & Interactive Buttons
*   **"Send Your RFQ" Button:**
    *   Shape: Pill button (`border-radius: 50px`).
    *   Background: White text/icon on dark translucent fill, or inverted. (In design: Dark pill with thin white border, white text, and a circular arrow icon on the right).
    *   Icon: White circle containing a black/dark diagonal up-right arrow (`↗`).
    *   Transition: Smooth hover scale (`transform: scale(1.03)`) with enhanced box-shadow glow.

---

### D. Footer / Bottom UI Elements (`<footer>`)
*   **Social Links (Bottom Left):**
    *   Icons: `in` (LinkedIn), `f` (Facebook), `📷` (Instagram).
    *   Styling: Monochromatic white/light grey, minimal spacing, aligned with the left baseline margin.
*   **Abstract Background Grid / Particle FX:**
    *   Faint geometric wireframe blocks and square nodes scattered subtly across the lower screen canvas to establish a technical, automation-themed environment.
*   **Slider / Carousel Pagination Controls (Bottom Right):**
    *   Navigation arrows: Left (`←`) and Right (`→`) minimalist chevron buttons enclosed in dark circular containers with subtle borders.

---

## 5. Animation & Interaction Specifications

1.  **Portal Ambient Glow Pulse (`@keyframes portalPulse`):**
    *   The outer cyan ring of the portal gently pulses in opacity and scale to simulate energy generation.
    *   *Duration:* `4s`, *Timing Function:* `ease-in-out`, *Iteration:* `infinite`.

2.  **Atmospheric Fog Drift (`@keyframes fogDrift`):**
    *   Subtle horizontal shifting of layered semi-transparent blue smoke elements at the base of the portal.
    *   *Duration:* `12s`, *Iteration:* `infinite`.

3.  **Hover States:**
    *   **Navigation Links:** Color transition from `#94A3B8` to `#FFFFFF` with a `0.3s ease` transition.
    *   **Buttons ("Contact Us", "Send Your RFQ"):** Background shifts slightly brighter with a soft radial drop shadow expansion.
