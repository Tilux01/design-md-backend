# 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Brand Archetype**: Futuristic minimalist luxury. Blends Apple-esque spatial computing design language (VisionOS) with soft neumorphic depth, high-end editorial styling, and rich gradient-driven surfaces.
- **Visual Density**: Clean, breathable, and structured using asymmetric bento grids. Generous whitespace ensures card groups never feel cramped.
- **Theme Balance**: Light-mode primary interface (`#F7F7F9` base surface) utilizing tactile, organic multi-stop gradients for cards, alongside deep emerald green (`#0F5132`) and sunset amber (`#E08E35`) accent blocks. 
- **Depth Architecture**: Neumorphic layered surface logic utilizing soft dual-drop-shadows (diffuse ambient lighting + sharp directional shadows) to simulate extruded frosted panels.

- **Padding & Margin Scale**: Base spacing unit = `4px`. Common tokens: `p-4` (16px), `p-6` (24px), `p-8` (32px), `gap-6` (24px grid gaps).
- **Section Sequence Breakdown**:
  1. Top Floating Navigation Bar (Pill-shaped global bar).
  2. Brand Identity / Header Sub-Bar (`Vision Pro` + secondary menu tabs).
  3. Asymmetric Bento Grid Section:
     - Left Column: Large Hero Feature Card (`Largunt elegort Apple hero design`).
     - Center Column: Gradient Card Stack (Peach Amber card, Emerald Graphic card).
     - Right Column: Amber Card, White Glass Card (`Visions`), Bottom Pill Control.

- **Stacking Order & Z-Index**:
  - Base canvas: `z-0`
  - Bento cards & layout containers: `z-10`
  - Floating pills / CTA buttons: `z-20`
  - Modals / Popovers: `z-50`

# 6. Motion Mechanics, Framer Motion & CSS Animation Code

- **Animation Triggers**: Page load stagger entrance, scroll-triggered card elevation, button scale-down on active click (`scale(0.96)`).
- **Transition Durations & Easing**: Spring physics (`stiffness: 300, damping: 25`) for interactive hovers.

### Framer Motion React Code Snippets
```jsx
import { motion } from "framer-motion";

export const cardVariant = {
  hidden: { opacity: 0, y: 20 },
  visible: (i) => ({
    opacity: 1,
    y: 0,
    transition: {
      delay: i * 0.1,
      duration: 0.6,
      ease: [0.16, 1, 0.3, 1],
    },
  }),
};

export const AnimatedCard = ({ index, children }) => (
  <motion.div
    custom={index}
    initial="hidden"
    animate="visible"
    variants={cardVariant}
    whileHover={{ y: -4, transition: { duration: 0.2 } }}
    whileTap={{ scale: 0.98 }}
    className="bg-white rounded-[2rem] p-6 shadow-neu-card"
  >
    {children}
  </motion.div>
);
```

# 7. Accessibility (a11y) & WCAG Contrast Audit

- **Contrast Ratios**:
  - Primary Text (`#111827`) on White Surface (`#FFFFFF`): **16.5:1** (Passes WCAG AAA)
  - Muted Text (`#6B7280`) on White Surface (`#FFFFFF`): **4.6:1** (Passes WCAG AA)
  - Inverse Text (`#FFFFFF`) on Primary Green (`#10B981`): **3.2:1** (Passes WCAG AA for large text/UI components)
- **Keyboard Focus Ring Specs**:
  ```css
  *:focus-visible {
    outline: 2px solid #10B981;
  ```
