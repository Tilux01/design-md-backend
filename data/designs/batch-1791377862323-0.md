# UI/UX Specification & Design System Clone: "Kitchen King" (Kadhi Chawal Hero Section)

This document provides a pixel-for-pixel specification to clone the modern, high-end food-delivery/restaurant web interface shown in the screenshot. It is designed for full-screen viewports (1920x1080 and fluid responsiveness downward) while stripping away all outer browser frames/mockups.

## 1. Global Layout & Canvas Specifications

### Viewport & Background
*   **Root Container:** Full-screen (`100vw` width, `100vh` height), `overflow: hidden`.
*   **Base Background Color:** `#EAE7E1` (A warm, ultra-light sandy/stone gray).
*   **Decorative Backdrop Shapes (Abstract Organic Waves):**
    *   **Top-Left Shape:** A soft sweeping curve stretching from the top-left header down to mid-page. Color: `#F5EBE0` with a subtle gradient/shadow.

## 2. Typography & Font Stack

The design uses a stark contrast between a minimalist clean sans-serif (for UI elements) and an ultra-bold, commanding geometric display typeface (for headlines).

### Font Families
1.  **Display Font (Headlines - e.g., "KADHI CHAWAL"):**
    *   *Primary:* **"Clash Display"** or **"Cabinet Grotesk"** (by Indian Type Foundry) for that high-end, contemporary editorial look.
    *   *Fallback:* `Impact`, `Arial Black`, sans-serif.
    *   *Weight:* `700` (Bold) or `900` (Black).
    *   *Text Transform:* Uppercase.
2.  **UI & Body Font (Navigation, descriptions, labels):**
    *   *Primary:* **"Inter"** or **"Plus Jakarta Sans"**.
    *   *Fallback:* `Helvetica Neue`, `Arial`, sans-serif.
    *   *Weights:* `400` (Regular), `500` (Medium), `600` (Semi-bold).

## 4. Animation & Interaction Specifications (Framer Motion / CSS)

1.  **Page Load / Entrance Animation:**
    *   **Staggered Fade-Up:** The headline ("KADHI CHAWAL") and subheadings should slide up from `Y: 30px` to `0` with `opacity: 0` to `1` over `0.8s` using cubic-bezier (`0.16, 1, 0.3, 1`).
    *   **Hero Image Rotation/Scale:** The main dish plate scales up from `0.9` to `1.0` with a smooth rotation ease-in-out.
2.  **Carousel Item Switch (State Change):**
    *   When switching dishes (e.g., from Kadhi Chawal to Chole Bhature):
        *   The main plate image performs a cross-fade (`opacity 0.4s`) and a slight scale punch.
        *   The active card pill slides smoothly to the newly selected item using layout animations (`layoutId` in Framer Motion).
3.  **Hover States:**
    *   CTA Links: Underline reveal or subtle color shift from `#221E1C` to `#D97706` (warm amber).
    *   Carousel Thumbnails: Scale up by `1.05` on hover with a smooth transition (`duration: 0.3s`).
