# UI Design & Implementation Specification: "Virtual School" Dashboard

This document provides a comprehensive, pixel-accurate blueprint for recreating the "Virtual School" dashboard interface. It covers layout structures, typography, color palettes, spacing, and content descriptions to ensure an exact-match implementation.

---

## 1. Global Layout & Viewport

*   **Viewport Type:** Full-screen responsive web application dashboard.
*   **Background Canvas:** Soft peach/coral-to-teal gradient or solid off-white background (`#F4F6F9`) with floating layout containers.
*   **Main Container:** Centered white card (`#FFFFFF`) with heavy rounded corners (`border-radius: 24px` or `32px`) and a soft, diffused multi-layered drop shadow (`box-shadow: 0 20px 40px rgba(0,0,0,0.06)`).
*   **Grid System:** 
    *   **Header Bar:** Dark navy blue (`#1D334A`) curved or angled header zone spanning the top.
    *   **Main Body:** 3-column asymmetric layout structure:
        *   *Left Column:* Days to holiday, Exams progress.
        *   *Middle Column:* Calendar timeline & scheduled events.
        *   *Right Column:* Your Classes & Statistics/Analytics graphs.

---

## 2. Typography & Font Stack

The interface relies on a clean, modern, geometric sans-serif typeface (similar to **Inter**, **Poppins**, or **SF Pro Display**).

*   **Primary Font Family:** `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
*   **Font Weights Used:** Regular (400), Medium (500), Semi-Bold (600), Bold (700).

### Typography Scale Hierarchy:
*   **App Title ("Virtual School"):** 18px, Semi-Bold (600), Color: White (`#FFFFFF`)
*   **Section Headers ("Upcoming events", "Calendar", "Your Classes", "Statistics"):** 16px–18px, Semi-Bold (600), Color: Dark Navy (`#1D334A`)
*   **Card Titles (e.g., "Roma Theatre", "Biology"):** 14px–15px, Semi-Bold (600), Color: Dark Navy (`#1D334A`)
*   **Body Text & Descriptions:** 12px, Regular (400), Line-height: 1.4, Color: Muted Gray-Blue (`#687588`)
*   **Microcopy / Time Stamps / Metadata:** 10px–11px, Regular/Medium, Color: Light Gray (`#9AA5B1`)

## 5. Implementation Notes & Asset Guidelines

*   **Images & Icons:** Replace emoji placeholders or visual icons with clean vector icon sets (e.g., **Lucide Icons**, **FontAwesome**, or **Heroicons**).
*   **Avatars:** Use placeholder avatar images from sources like *Unsplash* or *DiceBear* for the user profile and attendee circles.
*   **Shadows & Depth:** Implement soft CSS box-shadows to maintain the modern neumorphic/floating card aesthetic:
    ```css
    .card {
      background: #FFFFFF;
      border-radius: 16px;
      box-shadow: 0 10px 30px rgba(29, 51, 74, 0.05);
    }
    ```
