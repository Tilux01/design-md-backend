# Design Specification: Glassmorphism Toggle Switch

## 1. Overview & General Principles
* **Style:** Liquid Glass / Neumorphic Glassmorphism.
* **Layout:** Centered full-screen interface on a uniform background.
* **Background:** Solid neutral medium-gray canvas with a subtle vignette effect to enhance lighting highlights.
* **Dimensions:** Fluid responsive layout scaling cleanly across viewports, defaulting to a centered canvas layout.

---

## 2. Color Palette
* **Background Canvas:** `#7A7B7E` (Mid-tone Neutral Grey)
* **Background Vignette / Shadow Depth:** `#4A4B4E` (Deep Grey/Black for drop shadows)
* **Glass Track Surface:** `rgba(255, 255, 255, 0.08)` to `rgba(255, 255, 255, 0.15)`
* **Glass Knob Surface:** `rgba(255, 255, 255, 0.18)`
* **Reflective Highlights (Borders/Glows):** Pure White (`#FFFFFF`) with varying opacities.
* **Text & Icon Color:** Pure White (`#FFFFFF`) with slight soft shadow filtering.

---

## 3. Typography
* **Primary Font Family:** `SF Pro Display`, `Inter`, `system-ui`, `-apple-system`, `sans-serif`
* **Fallback Stack:** `Inter`, `Segoe UI`, `Roboto`, `Helvetica`, `Arial`, `sans-serif`

### Hierarchy:
1. **Title ("How to Create"):**
   * **Font Size:** `18px` – `22px`
   * **Font Weight:** 400 (Regular)
   * **Letter Spacing:** Normal
   * **Color:** `rgba(255, 255, 255, 0.8)`

2. **Main Heading ("Glass Toggle"):**
   * **Font Size:** `48px` – `64px`
   * **Font Weight:** 700 (Bold / Heavy)
   * **Letter Spacing:** `-1.5px` (Tight)
   * **Color:** `#FFFFFF` with inset shadow / soft outer highlight.

3. **Toggle Label ("Light"):**
   * **Font Size:** `16px` – `18px`
   * **Font Weight:** 500 (Medium)
   * **Color:** `#FFFFFF`

---

## 4. Component Structure & Styling: The Glass Toggle

### A. The Track (Pill Background)
* **Shape:** Fully rounded capsule (Pill shape).
* **Dimensions:** Width: `240px`, Height: `80px`.
* **Background:** Semi-transparent linear gradient (`rgba(255, 255, 255, 0.1)` to `rgba(255, 255, 255, 0.04)`).
* **Backdrop Filter:** `blur(20px)`
* **Borders:** 
  * Inner / Outer highlight border: `1px solid rgba(255, 255, 255, 0.3)`
* **Shadows (Depth):**
  * Inner Shadow: `inset 0px 2px 4px rgba(0, 0, 0, 0.25)`
  * Outer Drop Shadow: `0px 20px 40px rgba(0, 0, 0, 0.3)`

### B. The Knob (Draggable Handle)
* **Shape:** Circular / Ergonomic indented thumb.
* **Dimensions:** `96px × 96px` (Slightly larger than track height for an organic, tactile feel).
* **Position:** Left-aligned (Active "On" state) with an indented ring cutout.
* **Background:** Soft radial gradient glass base.
* **Backdrop Filter:** `blur(12px)`
* **Borders & Highlights:** 
  * Top/Left Edge highlight: `1.5px solid rgba(255, 255, 255, 0.6)`
  * Bottom/Right Edge shadow: `1.5px solid rgba(0, 0, 0, 0.2)`
* **Inner Content:** 
  * Sun/Lightbulb SVG Icon centered precisely within the knob.

---

## 5. Animation & Interaction Specs (Optional / Interactive State)

* **Transition Duration:** `0.3s` to `0.4s`
* **Easing Function:** `cubic-bezier(0.25, 1, 0.5, 1)` (Spring / Smooth Ease-Out)
* **Hover State:** 
  * Knob scale up slightly to `1.05`.
  * Track border brightness increases (`rgba(255, 255, 255, 0.5)`).
* **Active / Drag State:**
  * Knob morphs fluidly as it slides from left to right along the track, retaining its backdrop distortion refraction effect over the background text.

---
