# 1. Design Philosophy & Overall Aesthetic
- **Primary Mood & Archetype:** Nostalgic Industrial Skeuomorphism blended with modern high-contrast tactile minimalism. Inspired by classic Nokia feature phones (Series 40 / Symbian era), engineered with high-gloss metallic accents, physical-grade button geometry, and deep obsidian finishes.
- **Visual Density:** High density, compartmentalized grid layout optimized for precise physical-style interaction paradigms.
- **Whitespace Balance:** Tight ergonomic padding with distinct boundaries separating functional input blocks from navigational chrome.
- **Theme Balance:** Strictly dark-mode dominant (`#0B0C0E` base canvas) utilizing multi-stop radial lighting gradients, subtle inner bevels, and specular highlights to emulate physical injection-molded plastic and brushed aluminum surfaces.

# 3. Typography System & Hierarchy

- **Font Families:**
  - *Headings/Branding:* `Nokia Standard / Geometric Sans-Serif` (`system-ui, -apple-system, sans-serif`)
  - *Keycap Numbers & Letters:* `OCR-A / Engineered Mono / Industrial Sans` (`"SF Pro Display", "Roboto", sans-serif`)
- **Scale Breakdown:**
  - **Brand Logotype (NOKIA):** `font-weight: 700`, `font-size: 24px (1.5rem)`, `line-height: 1.1`, `letter-spacing: 0.2em (2px)`
  - **Keycap Digits (1-9, 0, *, #):** `font-weight: 400`, `font-size: 28px (1.75rem)`, `line-height: 1`, `letter-spacing: 0.05em`
  - **Keycap Sub-labels (ABC, GHI, etc.):** `font-weight: 500`, `font-size: 11px (0.6875rem)`, `line-height: 1.2`, `letter-spacing: 0.1em`

# 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** Fixed mobile viewport structure (`max-width: 420px`), centered flex layout.
- **Padding & Margin Scale:** 
  - Outer housing padding: `16px`
  - Keypad grid gap: `6px` vertical / `8px` horizontal
- **Structural Section Sequence (Top to Bottom):**
  1. *Black Canvas / Screen Viewport Area* (Upper section, empty black state)
  2. *Brand Plate* (`NOKIA` debossed logotype with specular lighting bars)
  3. *Navigation & Function Control Deck* (D-pad, Soft keys, Call/End, Calendar/Contacts shortcuts)
  4. *Alphanumeric Keypad Grid* (3x4 matrix from `1` to `#`)
- **Stacking Order (Z-Index):**
  - Base background: `z-0`
  - Physical housing shell: `z-10`
  - Interactive keycaps & buttons: `z-20`
  - Specular lighting overlays: `z-30`

# 5. Structural DOM Layout Blueprints & Component Specs

### Alphanumeric Keypad Grid Component
```jsx
export function KeypadGrid() {
  const keys = [
    { num: '1', sub: 'oo' },
    { num: '2', sub: 'ABC' },
    { num: '3', sub: 'DEF' },
    { num: '4', sub: 'GHI' },
    { num: '5', sub: 'JKL' },
    { num: '6', sub: 'MNO' },
    { num: '7', sub: 'PQRS' },
    { num: '8', sub: 'TUV' },
    { num: '9', sub: 'WXYZ' },
    { num: '*', sub: '+ ✆' },
    { num: '0', sub: '_ 🌐' },
    { num: '#', sub: '⇧ 🎵' },
  ];

  return (
    <div className="grid grid-cols-3 gap-2 bg-[#050507] p-3 rounded-b-[24px]">
      {keys.map((k, index) => (
        <button
          key={index}
          className="relative flex flex-col items-center justify-center h-14 bg-gradient-to-b from-keycap-from to-keycap-to rounded-md shadow-key border border-metal-dark/40 active:translate-y-[2px] active:shadow-none transition-all duration-75 group"
        >
          <span className="text-white text-2xl font-light tracking-wide">{k.num}</span>
          <span className="text-metal-light text-[10px] font-medium tracking-widest uppercase mt-0.5">{k.sub}</span>
        </button>
      ))}
    </div>
  );
}
```

- **Border Radius:** Keycaps (`6px`), Main Frame (`24px`), D-Pad Center (`8px`).
- **Borders:** 1px solid `rgba(56, 60, 70, 0.4)` with upper specular highlight.
- **Shadows:** `box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.6), inset 0 1px 0 rgba(255, 255, 255, 0.1);`
