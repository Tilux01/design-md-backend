# Design Specification: Lunis Ambient & Soundscape Application

This document defines the exact layout, typography, visual specs, and interactive behaviors for the **Lunis** ambient/travel discovery mobile application. 

---

## 1. Design Overview & Theme

The Lunis application features a minimal, high-end, editorial user interface blending organic lifestyle elements with modern glassmorphism. It uses soft gradients, ample whitespace, high-contrast typography, and rich visual cards.

- **Interface Style:** Minimalist, Editorial-Wellness
- **Target Screen Resolution:** Designed natively for modern mobile viewports (e.g., 393 × 852 px / 19.5:9 aspect ratio). 
- **Layout Model:** Full-screen borderless layout (omitting device frames or outer mockup drop-shadows).

## 3. Typography Specs & Fallbacks

The typography balances a premium editorial serif for headers with a clean, modern sans-serif for UI, numbers, and navigation.

### 3.1 Display & Brand Headers
*   **Font Family:** `Lunis Display` (Custom Brand Serif)
*   **Web Safe / CDN Alternative:** [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) or [Playfair Display](https://fonts.google.com/specimen/Playfair+Display)
*   **CSS Fallback Stack:** `Cormorant Garamond, "Playfair Display", Georgia, "Times New Roman", serif`
*   **Scale:**
    *   Brand Header (App Logo): `28px`, Medium-Bold, Letter-spacing `-0.02em`
    *   Screen Hero Title: `32px`, Regular to Medium, Line-height `1.2em`

### 3.2 UI, Buttons, and Body Copy
*   **Font Family:** [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)
*   **CSS Fallback Stack:** `Plus Jakarta Sans, "Inter", "SF Pro Text", -apple-system, sans-serif`
*   **Scale:**
    *   Tab Titles / Section Headers: `14px`, Semi-bold (Weight `600`), Letter-spacing `0.05em`, uppercase
    *   Body / Card Titles: `15px`, Medium (Weight `500`), Line-height `1.4em`
    *   Captions / Navigation: `12px`, Regular (Weight `400`), Letter-spacing `0.02em`

#### 4.1 Header Bar
- **Dimensions:** Height `56px`, dynamic padding-left/right: `24px`.
- **Elements:**
  - **Left Icon:** Thin vector back chevron or ambient toggle icon (Stroke width: `1.5px`).
  - **Center Title:** "Lunis" in Brand Serif (`28px`).
  - **Right Icon:** Minimalist user profile vector representation or quick filter icon.

#### 4.2 Category Horizontal Scroll Bar
- **Dimensions:** Height `40px`. Padding-left: `24px`.
- **Interactive Items:** Text tabs ("Popular", "Nature", "Calm", "Focus").
  - **Selected State:** Bold primary black text (`--color-text-primary`), underline or dot accent underneath.

#### 4.3 Circle Icon Selection Row
- **Layout:** Flexbox container, `gap: 16px`, padding-left/right `24px`.
- **Icon Container:** `52px` × `52px` perfect circles.
  - **Inactive Background:** Soft light gray gradient or transparent with `--color-border-light` (1px solid border).
  - **Active State:** `--color-brand-primary` with icon inverted to white.
  - **Icons:** Highly stylized minimalist line art representing environmental features (mountain landscape, wind wave, evergreen pine tree, acoustic sound waves).

#### 4.4 Carousel Grid Cards
- **Layout:** Two asymmetric columns, or standard side-by-side flex layout with dynamic overflow. Padding: `24px`.
- **Card Specs:**
  - **Width:** `45%` of view width each.
  - **Aspect Ratio:** `1:1.2` (Portrait card format).
  - **Border Radius:** `20px` (smooth squircles).
  - **Card 1 Image:** Warm gradient sunset view, mountains cast in shadow.
  - **Card 2 Image:** Cool deep blue foggy mountain lake.
  - **Label below cards:** `15px` Medium font, `--color-text-primary`. Space-top: `10px`.

#### 4.5 Controls & Presets Bar
- **Layout:** Flexbox row, padding: `0 24px`.
- **Control Pill:** Rounded capsule (`height: 48px`, background: `--color-text-primary`). 
  - Contains two inner toggle labels ("Sounds" and "Music") with a sliding capsule highlight selector.
- **Action Buttons:** Two matching dark circular utility icons next to the pill, size: `48px` × `48px`, filled with `--color-text-primary`.

#### 4.6 Floating Bottom Navbar
- **Layout:** Fixed floating container, `height: 72px`, margin: `0 16px 16px 16px`, border-radius: `36px`, background: `--color-brand-white` with `--shadow-card`.
- **Navigation Icons:** 5 items evenly distributed.
  - **Center Button (Play Accent):** Slightly elevated. Large gold circular shape with glowing background shadow (`--shadow-button-glow`), styled with a central play symbol and light concentric ring vectors mimicking expanding soundwaves.

## 5. Transitions & Micro-Interactions

To achieve the premium, tactile feel of this design, the following animation rules must be applied during implementation:

### 5.1 Card Expansion (Transition from Screen 1 to Screen 2)
When a user selects a scenic card on Screen 1 (e.g., Sunset/Deep Lake):
*   **Transition Type:** Shared Element Transition.
*   **Target:** The selected card image scales smoothly to occupy the full viewport background of Screen 2.
*   **Timing Function:** `cubic-bezier(0.34, 1.56, 0.64, 1)` (Custom spring-back easing).
*   **Duration:** `550ms`.

### 5.2 Ambient Play Button Ripple Effect
The central gold play button uses continuous interactive breathability states:
*   **Animation Loop:** An infinite keyframe scale pulsing the background concentric gold rings.
*   **Animation Details:**
    ```css
    @keyframes soundwave-pulse {
      0% {
        transform: scale(1);
        opacity: 0.6;
      }
      50% {
        transform: scale(1.15);
        opacity: 0.2;
      }
      100% {
        transform: scale(1.3);
        opacity: 0;
      }
    }
    ```

### 5.3 Bottom Sheet Gesture Pull
*   **Behavior:** The frosted bottom sheet on Screen 2 responds to vertical drag gestures.
*   **Friction Curve:** Restrict upward dragging past its anchor threshold of `50%` screen height using dynamic resistance formulas (`friction = 0.4`).
*   **Closing Interaction:** Dragging the panel downwards past `20%` screen height collapses the detail view and gracefully returns to Screen 1.
