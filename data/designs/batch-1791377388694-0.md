# Comprehensive UI/UX Design Specification & Replication Blueprint

This document serves as the absolute, production-ready specification for cloning the provided web interface. It breaks down every visual layer, typography system, spacing metric, color code, asset interaction, and animation state to guarantee a 100% pixel-perfect implementation.

---

## 1. Global Layout & Foundation

* **Base Viewport:** Responsive fluid layout, desktop-first architecture scaling down to mobile viewports.
* **Canvas Dimensions:** Full screen width (`100vw`), unconstrained by outer device frames.
* **Global Background Color:** 
  * Dark mode header & footer sections: Deep Obsidian Black (`#0A0A0A` or `#050505`).
  * Content section: Pure White (`#FFFFFF`).
* **Grid System:** 12-column fluid grid with standard lateral padding (`80px` on desktop, `24px` on mobile) and a maximum content container width of `1440px`.

---

## 2. Typography System & Fallbacks

The design relies on a clean, modern sans-serif aesthetic characterized by high-contrast font weights (from Light to Extra-Bold).

### Primary Font Family
* **Primary:** `Inter`, `SF Pro Display`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`.
* **Fallback Strategy:** System-ui stack ensuring native platform rendering if web fonts fail to load.

## 4. Animation & Interaction Specifications

1. **Smooth Hover Transitions:** All buttons, cards, and links must use cubic-bezier easing curves (`transition: all 0.3s cubic-bezier(0.16, 1, 0.3, 1)`).
2. **Hero Background Parallax:** The atmospheric background image in the hero section should subtly shift against mouse movement on desktop viewports (`transform: translate(x, y)` capped at `15px`).
3. **Card Lift Effect:** Portfolio cards scale up slightly (`scale(1.02)`) and elevate their drop shadow upon cursor hover.
4. **Counter / Metric Reveal:** Metrics count up from `0` to their target values once scrolled into the viewport view threshold (Intersection Observer API).
