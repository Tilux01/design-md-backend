# UI/UX Specification: "New Way Of Living" Real Estate Web App

## 1. Global Layout & Structure
- **Viewport:** Designed as a responsive desktop web application displayed within a stylized, rounded mockup window. The actual implementation should be **full-screen (100vw, 100vh)**.
- **Background Layer (App Level):** A high-resolution, moody photographic background of a misty, snowy mountain range overlaid with a subtle dark vignette to enhance contrast.
- **Main UI Container:** Centered application canvas with soft rounded corners (`border-radius: 36px`), a semi-transparent glassmorphic frosted border, and deep ambient drop shadows (`0px 30px 60px rgba(0, 0, 0, 0.4)`).
- **Color Palette:**
  - **Primary / Brand Accent:** Deep Indigo/Navy (`#171336` or `#1E1B4B`) used for key interactive elements, branding icons, and primary buttons.
  - **Text Colors:** Pure White (`#FFFFFF`) for primary headings, soft muted white/light gray (`#E2E8F0` / `rgba(255,255,255,0.7)`) for body text and secondary labels.
  - **Glassmorphism Base:** Translucent white/blue tones (`rgba(255, 255, 255, 0.15)` to `rgba(255, 255, 255, 0.4)`) with backdrop blur (`backdrop-filter: blur(20px)`).

---

## 2. Typography & Fonts
*Note: Since specific proprietary design files are unavailable, use the following web-safe and Google Fonts fallback chain to achieve the exact modern, clean architectural aesthetic.*

- **Primary Heading Font:** `SF Pro Display`, `Inter`, `Helvetica Neue`, sans-serif.
  - *Characteristics:* Geometric, clean, ultra-wide tracking on large headers, highly legible.
- **Body & UI Font:** `Inter`, `system-ui`, `-apple-system`, sans-serif.
  - *Weights Used:* Regular (400), Medium (500), Semi-Bold (600), Bold (700).
