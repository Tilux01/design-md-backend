# Design Specification: Padel Social Club Landing Page

This document provides the complete, production-ready design specification for replicating the **Padel Social Club** web interface. The design is a dark-mode, high-energy luxury sports aesthetic combining brutalist typography, neon accents, and editorial athletic photography.

---

## 1. Global Design Tokens & Variables

### 1.1 Color Palette
```css
:root {
  /* Brand Primary Accents */
  --color-accent-neon: #D4F932;       /* High-visibility padel ball neon yellow/lime */
  --color-accent-neon-hover: #E3FF54; /* Slightly brighter for interactive hover */
  --color-accent-gold: #C2AB61;       /* Subtle metallic accent for founder signature */

  /* Neutral & Base Colors */
  --color-bg-base: #080808;           /* Pitch charcoal/black primary background */
  --color-bg-surface-dark: #121214;   /* Surface layer for cards/overlays */
  --color-bg-glass: rgba(18, 18, 20, 0.65); /* Translucent frosted glass effect */

  /* Text & Foreground */
  --color-text-primary: #FFFFFF;     /* Optical pure white for titles and primary labels */
  --color-text-secondary: #A1A1AA;   /* Neutral mid-gray for descriptions/subheadings */
  --color-text-muted: #66666E;       /* Low-contrast gray for minor metadata */
  --color-text-neon: #D4F932;        /* Highlight text color */

  /* Borders & Dividers */
  --color-border-subtle: rgba(255, 255, 255, 0.12);
  --color-border-accent: rgba(212, 249, 50, 0.4);

  /* Shadows & Glassmorphism */
  --glass-blur: blur(16px);
  --glass-border: 1px solid var(--color-border-subtle);
  --shadow-card: 0 20px 40px rgba(0, 0, 0, 0.6);
}
```

---

### 1.2 Typography System

* **Primary Display Headline Font**: `Syne` or `Cabinet Grotesk` (Weight: 800 ExtraBold / 700 Bold).  
  *Fallback*: `'Space Grotesk'`, `'Inter'`, `-apple-system`, `BlinkMacSystemFont`, `'Segoe UI'`, `sans-serif`.  
  *Characteristics*: Geometric, tightly kerned (`letter-spacing: -0.03em`), high impact.
* **Primary Body & UI Font**: `Inter` (Weights: 400 Regular, 500 Medium, 600 SemiBold).  
  *Fallback*: `'Plus Jakarta Sans'`, `'Helvetica Neue'`, `Arial`, `sans-serif`.  
  *Characteristics*: Clean, legible at small sizes, neutral neo-grotesque.
* **Signature Font**: `Caveat` or `Reenie Beanie` (Weight: 400).  
  *Fallback*: `'Brush Script MT'`, `cursive`.

#### Typography Scale:
* **Display XXL** (Hero single-word anchors): `clamp(3.5rem, 7vw, 7.5rem)` | Line height: `1.0` | Weight: `700`
* **Display XL** ("EXPERIENCE THE TRUE ENERGY..."): `clamp(2.2rem, 4.5vw, 4.2rem)` | Line height: `1.05` | Weight: `800`
* **Headline Large** (Coach Names, "Elevate Your Padel Game"): `clamp(1.8rem, 3.2vw, 3.5rem)` | Line height: `1.1` | Weight: `700`
* **Section Header** ("TRAIN LIKE A PRO", "COURT BLACK"): `0.9rem` to `1.25rem` | Uppercase | Letter spacing: `0.08em` | Weight: `700`
* **Body Normal**: `0.85rem` to `0.95rem` | Line height: `1.5` | Weight: `400`
* **Micro Label / Badges**: `0.7rem` to `0.75rem` | Uppercase | Letter spacing: `0.05em` | Weight: `500`

## 4. Responsive Breakpoints & Adaptations

| Breakpoint | Screen Width | Adjustments |
| :--- | :--- | :--- |
| **Desktop (Default)** | `>= 1200px` | Full multi-column grids, horizontal 4-word spans, side-by-side coach cards. |
| **Tablet** | `768px - 1199px` | Hero headline words stack vertically or scale down to `48px`. Coach cards convert to a horizontal scroll snap slider. |
| **Mobile** | `< 768px` | Navigation collapses to hamburger menu with logo centered. Display typography reduces to `32px - 40px`. Hero player image scales down with stats cards pinned underneath. "Elevate Your Padel Game" text wraps into a 2x2 grid. |

## 5. Micro-Interactions & Animation Specs

1. **Buttons (`RESERVE A COURT`, `BOOK A SESSION`)**:
   * Initial: Opacity `0.9`, scale `1.0`.
   * Hover: Arrow translates `+3px` top-right (`transform: translate(3px, -3px)`), text color brightens to `#E3FF54`.
2. **Infinite Marquee**:
   * Continuous linear loop: `animation: marquee 25s linear infinite;`.
3. **Coach Card Hover**:
   * Image zoom: Subtle scale `1.03` over `0.6s cubic-bezier(0.16, 1, 0.3, 1)`.
   * Stats and badges remain sharply layered on top.
4. **Court Selector Thumbnails**:
   * Border lights up with `--color-accent-neon` upon active selection.
