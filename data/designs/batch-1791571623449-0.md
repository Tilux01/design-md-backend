# UI Design & Implementation Specification: Calendar Application

## 1. Overview & Layout Strategy
This specification details a modern, clean web-based calendar application interface (similar to Notion Calendar, Cron, or Google Calendar). 

* **Viewport:** Full-screen responsive layout (`width: 100vw`, `height: 100vh`).
* **Root Container Background:** Clean, crisp white (`#FFFFFF`) or off-white backdrop for the main calendar grid, framed by a very light neutral gray interface shell (`#F7F7F7` to `#FAFAFA`).
* **Grid System:** A multi-column layout representing days of the week (Monday through Sunday) with a vertical time axis on the far left.

---

## 2. Typography & Font Stack
The interface relies on a clean, humanist or neo-grotesque sans-serif typeface family common in productivity software.

* **Primary Font Stack:** `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
* **Fallback Strategy:** If `Inter` is unavailable, the browser defaults to the native system sans-serif font (`-apple-system` for macOS/iOS, `Segoe UI` for Windows, `Roboto` for Android/ChromeOS).
* **Text Hierarchy:**
  * **App Header / Search / Dates:** 12px–14px, Medium (`500`) weight, Dark Gray (`#111111` or `#222222`).
  * **Event Titles:** 12px–13px, Semi-Bold (`600`) weight, Dark Charcoal (`#1A1A1A`).
  * **Event Times & Details:** 11px, Regular (`400`) weight, Muted Gray (`#666666` or `#888888`).
  * **Time Axis Labels (Left Column):** 10px–11px, Regular (`400`), Light Gray (`#999999`).

---

## 3. Color Palette & Theming

### Neutrals
* **Background (App):** `#FAFAFA`
* **Card Backgrounds:** `#FFFFFF` with subtle transparency/shadows.
* **Borders & Grid Lines:** `#EFEFEF` (light horizontal/vertical time grid dividers).
* **Text Primary:** `#1A1A1A`
* **Text Secondary:** `#717171`

### Event Card Color Coding (Semantic Tags)
Events use pastel, low-saturation background fills with matching darker accent text and small circular status icons:
* **Orange / Amber (Meetings / Planning):**
  * Background: `#FFF2E8` or `#FEF3EC`
  * Border/Accent: `#F5A623` or warm amber
* **Green (Tasks / Focus Time / Green Team):**
  * Background: `#EDF7ED` or `#F0F8F1`
  * Accent: `#4CAF50`
* **Red / Pink (Personal / High Priority / Alerts):**
  * Background: `#FDEDEC` or `#FCE8E6`
  * Accent: `#EB5757`
* **Neutral / Gray (General Events / Syncs):**
  * Background: `#F1F3F4`
  * Accent: `#5F6368`

---

## 4. Component Breakdown & Structure

### A. Top Navigation Bar
* **Left:** App icon/logo placeholder, collapse sidebar toggle.
* **Center / Left-aligned:** Search bar (`Search...` placeholder with a search glass icon and keyboard shortcut indicator like `⌘K`).
* **Right:** Month/View navigation indicators, user profile avatar placeholder.

### B. Sidebar (Left Panel)
* **Width:** Thin collapsible rail (~60px to 240px if expanded).
* **Content:** Navigation icons (Calendar view, Settings, Workspace switcher, quick action buttons colored in solid dark/orange accent).

### C. Calendar Grid Area
* **Header Row:** Displays days of the week and dates (e.g., `Mon 04`, `Tue 05`, `Wed 06`, `Thu 07`, `Fri 08`, `Sat 09`, `Sun 10`). The current selected day (`Wed 07`) features a subtle blue or active state highlight.
* **Time Axis (Left Column):** Vertical time markers spaced hourly (e.g., `09:00`, `10:00`, `11:00`, `12:00`, `13:00`, etc.).
* **Current Time Indicator:** A horizontal blue line stretching across the grid with a small timestamp badge on the left, marking the exact current time of day.

### D. Event Cards
Events are rendered as rounded rectangular cards (`border-radius: 6px` to `8px`) positioned absolutely or via CSS grid within their respective time slots.

* **Card Structure:**
  * **Header/Icon:** A tiny square or circular colored icon indicating the calendar source or category (e.g., orange square, green circle).
  * **Title:** Bold concise text describing the event (e.g., "Client Strategy Sync", "Design Review", "Weekly Sync").
  * **Time Range:** Displayed immediately below the title (e.g., `10:00 - 11:30`).
  * **Metadata / Attendees:** Small circular avatar placeholders or indicator dots at the bottom of the card.
* **Stacked / Multi-event Slots:** On busy days (like Sunday/Thursday columns), smaller compact blocks stack vertically with distinct color coding (Orange, Red, Green blocks layered cleanly).

---

## 5. Asset & Image Guidance
* *No complex raster images or photos are utilized in this interface.* 
* **Icons:** Use SVG-based icon libraries (such as Lucide Icons, Phosphor Icons, or Tabler Icons) styled uniformly with a `14px` to `16px` bounding box and stroke width of `1.5px` to `2px`.
* **Avatars:** Represent user avatars using simple colored circular divs with initials or generic vector user silhouettes.
