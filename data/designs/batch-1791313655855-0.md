# UI/UX & Design System Specification: Notion Prompt Playbook

---

## 1. Design Philosophy & Overall Aesthetic

- **Primary Mood:** Brutalist Minimalist, Professional Productivity, Editorial Software Aesthetic (Notion-inspired).
- **Brand Archetype:** The Creator / Pragmatist. Clean, structured, highly utilitarian, emphasizing clarity and raw organization over ornamentation.
- **Visual Density:** High information density balanced by generous whitespace inside containers, sharp geometric borders, and high-contrast typography.
- **Theme Architecture:** Predominantly Light Mode interface (`#FFFFFF` surfaces, `#000000` text) embedded within a structured black-and-white editorial layout framework. Flat spatial depth with crisp 1px solid borders (`#000000` or `#E5E7EB`) replacing soft drop-shadows.

---

## 2. Color Palette & Design Tokens

### Semantic Color Definitions
* **Primary / Neutral 900 (Dominant):** `#000000` (Headers, solid cards, primary icons)
* **Primary / Neutral 50 (Surface):** `#FFFFFF` (Page background, main container surfaces)
* **Neutral 100 (Subtle Background):** `#F3F4F6` (Tag backgrounds, alternating row fills)
* **Neutral 200 (Borders/Dividers):** `#E5E7EB` (Card boundaries, separator rules)
* **Neutral 500 (Muted Text):** `#6B7280` (Secondary labels, metadata, captions)
* **Accent / Brand:** Notion Logo Black (`#000000`) with monochromatic support.

## 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** `1200px` centered with responsive padding (`1rem` to `2.5rem`).
- **Grid System:** 12-column CSS Grid with asymmetrical split layout (Left column: List of prompts; Right column: Simulated Notion app workspace mockup).
- **Spacing Scale:** Uses an 8pt base grid system (`8px`, `16px`, `24px`, `32px`, `48px`).
- **Z-Index Hierarchy:**
  - Base Layout / Background: `z-0`
  - Floating Mockup Elements / Cards: `z-10`
  - Sticky CTA Bar / Banners: `z-40`
  - Modals / Overlays: `z-50`

- **Border-Radius:** `8px` (`--radius-md`)

## 6. Motion Mechanics, Framer Motion & CSS Animation Code

- **Animation Triggers:** Hover elevation on prompt cards, smooth scale transformations on buttons, and subtle scroll-entry reveals.
- **Easing Physics:** Spring physics for snappy, tactile feedback (`stiffness: 400, damping: 25`).

### Framer Motion Variants
```jsx
import { motion } from 'framer-motion';

export const cardVariants = {
  hidden: { opacity: 0, y: 20 },
  visible: (i) => ({
    opacity: 1,
    y: 0,
    transition: {
      delay: i * 0.1,
      type: "spring",
      stiffness: 300,
      damping: 24,
    },

  hover: {
    y: -4,
    x: -4,
    boxShadow: "6px 6px 0px #000000",

  }
};
```

## 7. Accessibility (a11y) & WCAG Contrast Audit

- **Primary Text (#000000) on Base Background (#FFFFFF):** Contrast Ratio **21:1** (Passes WCAG AAA easily).
- **Muted Text (#6B7280) on Base Background (#FFFFFF):** Contrast Ratio **4.54:1** (Passes WCAG AA for standard text).
- **Keyboard Focus Ring:**
  ```css
  *:focus-visible {
    outline: 3px solid #000000;
    outline-offset: 2px;
  }
  ```
