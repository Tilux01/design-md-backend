# Design Specification: Dark Mode Fitness Tracker App UI

This document provides the exact design guidelines, color codes, typography, layout dimensions, and component structures required to construct a pixel-perfect, full-screen replica of the fitness tracker interface shown in the screenshot. 

This specification targets the **screen canvas area only**, omitting the physical device bezel, frame, and hardware dynamic island.

---

## 1. Aesthetic Guidelines & Design Tokens

### 1.1 Color Palette
The interface utilizes an ultra-dark, high-contrast monochrome color scheme to create a premium, modern, and focused athletic aesthetic.

| Token Name | Hex Value | CSS Custom Property | Usage |
| :--- | :--- | :--- | :--- |
| **Canvas Background** | `#09090B` | `--bg-canvas` | Main app background |
| **Card Background** | `#18181B` | `--bg-card` | Surface color for widgets/containers |
| **Active Accent** | `#FFFFFF` | `--color-active` | Titles, values, highlighted states |
| **Muted Text** | `#8E8E93` | `--text-muted` | Subtitles, time-stamps, inactive labels |
| **Dimmed Element** | `#3F3F46` | `--text-dimmed` | Inactive dots, minor icon paths |
| **Border / Divider** | `#27272A` | `--border-subtle` | Card strokes, splitters, tab-bar top border |

### 1.2 Typography
The typography is clean, geometric, and high-readability sans-serif.

*   **Primary Font Family**: `SF Pro Display` (macOS/iOS system)
*   **Fallback Stack**: `Inter`, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `sans-serif`
*   **Tracking (Letter Spacing)**: 
    *   Large Titles: `-0.03em`
    *   Body text: `-0.01em`
    *   Small labels: `0.01em`

| Style Name | Font Size | Font Weight | Line Height | Case |
| :--- | :--- | :--- | :--- | :--- |
| **Main Header** | `32px` | `700` (Bold) | `1.2` | Sentence |
| **Card Primary Value** | `48px` | `700` (Bold) | `1.0` | Sentence |
| **Card Secondary Value** | `24px` | `600` (Semi-Bold) | `1.1` | Sentence |
| **Card Title** | `18px` | `600` (Semi-Bold) | `1.3` | Sentence |
| **Card Subtitle** | `13px` | `400` (Regular) | `1.4` | Sentence |
| **Month Header** | `11px` | `600` (Semi-Bold) | `1.0` | Title Case |
| **Unit Label (lbs)** | `16px` | `500` (Medium) | `1.0` | Lowercase |

### 1.3 Spacing & Layout
*   **Base Grid Unit**: `4px` / `8px`
*   **Screen Padding**: `16px` left and right horizontal margins.
*   **Card Gap**: `12px` vertical and horizontal spacing between grid elements.
*   **Card Corner Radius**: `24px` (`border-radius: 24px`) for standard cards; `16px` for small sub-components.

## 4. Animation & Interactive Behaviors (CSS / JS)

To elevate the user experience from static design to interactive product, implement the following smooth, high-frame-rate transitions:

### 4.1 Card Hover & Touch States
*   **State transition**: Tap-down or click-hold scales components down slightly to mimic organic press physics.
    *   `transition: transform 0.2s cubic-bezier(0.25, 1, 0.5, 1), background-color 0.2s ease;`
    *   `:active { transform: scale(0.97); background-color: #202023; }`

### 4.2 SVG Progress Circle Dynamic Path Fill
*   When cards render, progress badge circles animate from 0 offset to their designated fill positions:
    *   `stroke-dasharray` transition from full empty state to active state segments on runtime mount with a smooth ease-out curve.

### 4.3 Active Dot Pulse Effect
*   Active history matrix dots within the Calendar widget have a subtle, low-frequency infinite pulse breathing cycle using opacity changes in the shadow glow element:
    ```css
    @keyframes pulseGlow {
      0% { box-shadow: 0 0 4px rgba(255, 255, 255, 0.6); }
      50% { box-shadow: 0 0 10px rgba(255, 255, 255, 1); }
      100% { box-shadow: 0 0 4px rgba(255, 255, 255, 0.6); }
    }
    ```

### 4.4 Transition/Route Swapping
*   Pressing alternative active bottom tab bar items transitions the selected icon fill to pure white, while fading the previous icon down to muted zinc (`#3F3F46`) over `150ms`.
