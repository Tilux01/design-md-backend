# App Design Specification: Sneaker E-Commerce Application

## Global Design System

### Colors
- **Primary Background:** `#F8F9FA` (Off-white / Light gray canvas)
- **Secondary Background / Card Background:** `#FFFFFF` (Pure white)
- **Dark Theme / Accent Card Background:** `#1A1D24` (Deep charcoal/navy)
- **Primary Text:** `#1A1D24` (Deep charcoal/navy)
- **Secondary Text:** `#6C757D` (Muted gray)
- **Accent / Highlight:** `#FF6B35` (Vibrant orange for buttons/CTAs)
- **Rating Star Color:** `#FFC107` (Warm yellow)
- **Active Navigation / Indicator:** `#007AFF` or `#1A1D24` (Dark navy)

### Typography (Inter / System Sans-Serif)
- **Screen Titles (Explore, Details, Profile):** 22px – 24px, Bold (`#1A1D24`)
- **Section Headers (Categories):** 16px – 18px, Semi-Bold (`#1A1D24`)
- **Product Titles:** 14px – 15px, Medium/Semi-Bold (`#1A1D24`)
- **Prices:** 14px – 16px, Bold (`#1A1D24`)
- **Body / Descriptions:** 12px – 13px, Regular (`#6C757D`), Line-height: 1.4
- **Captions / Ratings:** 11px – 12px, Regular/Medium
