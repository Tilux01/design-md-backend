# Design Specification: Mobile Finance / Wallet App

## 1. Global Layout & Styling

*   **Platform Target:** iOS / Android (Modern smartphone display).
*   **Color Palette:**
    *   `Background (Canvas)`: `#F5F5F7` (Very light cool gray/off-white)
    *   `Card Background (Dark)`: `#1C1C1E` (Deep charcoal, Apple dark mode style)
    *   `Card Background (Light)`: `#FFFFFF` (Pure white)
    *   `Primary Text (Dark Mode)`: `#FFFFFF`
    *   `Primary Text (Light Mode)`: `#000000`
    *   `Secondary / Muted Text`: `#8E8E93` (iOS System Gray)
    *   `Accent / Border Color`: `#E5E5EA` (Light separator lines)
*   **Typography Hierarchy:**
    *   *Primary Font Family:* Inter, SF Pro Display, or Roboto.
    *   *Fallback Stack:* `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
    *   *Font Weights Used:* Regular (400), Medium (500), Semibold (600), Bold (700).

## 4. Animations & Micro-Interactions (Motion Design)

*   **Screen Transition:**
    *   Standard iOS navigation push/pop transition (slide from right on enter, slide back on exit with parallax scaling on the background screen).
*   **Button Press Feedback:**
    *   Scale down effect (`transform: scale(0.97)`) with opacity fade on press (`duration: 150ms`, ease-out).
*   **Toggle Switch Animation:**
    *   Smooth sliding indicator knob (`duration: 250ms`, spring physics).
*   **Loading States:**
    *   Shimmer skeleton loaders for balance amounts and transaction lists during network fetching.
