# UI/UX Specification: Red X Visors Landing Page

This document outlines the exact design specifications for replicating the "Red X Visors" landing page interface. All structural framing, perspective drop shadows, and non-content backgrounds from the presentation mock-up are omitted to ensure the layout renders full-screen.

---

## 1. Global Layout & Canvas

*   **View Mode:** Full-Screen Responsive Viewport (`100vw` × `100vh`).
*   **Color Palette:**
    *   **Background Base (`--bg-primary`):** Light Cool Grey (`#EBEFF2`)
    *   **Hero Container (`--bg-hero`):** Soft Blue-Grey Tone (`#8A9EB5`)
    *   **Text / Brand Accent (`--text-primary`):** Deep Charcoal / Black (`#0F1115`)
    *   **Glow / Accent (`--accent-glow`):** Vibrant Cyberpunk Orange (`#FF5C35`)
    *   **Card / Component Fill (`--bg-card`):** Pale Off-White (`#F3F5F8`)
*   **Grid Structure:** Asymmetric 3-column compositional flow.
    *   *Left Column (Content & Navigation):* ~32% Width
    *   *Center Column (Hero Visual):* ~45% Width
    *   *Right Column (Interactive Modules & Socials):* ~23% Width

---

## 2. Typography

### Font Families
1.  **Primary Headings / Brand Logotype:** `Orbitron`, sans-serif.
    *   *Fallback:* `Eurostile`, `Arial Black`, `sans-serif`.
2.  **UI Navigation / Body Copy / Captions:** `Space Grotesk`, sans-serif.
    *   *Fallback:* `Inter`, `Helvetica Neue`, `sans-serif`.

### Text Hierarchy
*   **Main Logo ("RED X VISORS"):**
    *   Font: `Orbitron` (Bold / 900 weight)
    *   Size: `48px` (Fluid scaling via `clamp(32px, 5vw, 48px)`)
    *   Letter Spacing: `0.1em`
*   **Sub-brand Tag ("CYBERP**R**OMPT"):**
    *   Font: `Orbitron` (Medium / 500 weight)
    *   Size: `10px`
    *   Letter Spacing: `0.15em`
*   **Section Heading ("WE ARE THE PIONEERS"):**
    *   Font: `Space Grotesk` (Bold / 700 weight)
    *   Size: `12px`
    *   Letter Spacing: `0.05em`
*   **Body Description:**
    *   Font: `Space Grotesk` (Regular / 400 weight)
    *   Size: `11px`
    *   Line Height: `1.4`
    *   Color: `rgba(15, 17, 21, 0.75)`
*   **Navigation Links ("Home", "About", "Roadmap", "News"):**
    *   Font: `Space Grotesk` (Medium / 500 weight)
    *   Size: `12px`

---

## 3. Component Breakdown & Positioning

### A. Header Navigation
*   **Top-Left Navigation Pill:**
    *   Shape: Pill container with rounded capsule ends (`border-radius: 50px`).
    *   Fill: `#FFFFFF` (Solid white background).
    *   Padding: `8px 24px`.
    *   Elements: Links (`Home`, `About`, `Roadmap`, `News`) arranged horizontally with flex spacing. Active state ("Home") contains a subtle soft pill background highlight.
*   **Top-Right Actions:**
    *   **Contact Button:** Pill-shaped (`50px` radius), solid white background, bold black typography (`CONTACT`), featuring an ultra-thin subtle border.
    *   **User Icon & Menu Toggle:** Circular pill containers (`36px` diameter) matching the contact button, housing simple vector line icons (User profile outline, Hamburger menu).

### B. Hero Visual & Framing
*   **Center Hero Image Container:**
    *   Shape: Asymmetric viewport cut. The bottom-left corner features an angled diagonal clip path (`polygon(0 0, 100% 0, 100% 100%, 0 85%)`).
    *   Visual Asset: 3D-rendered character wearing a futuristic white helmet structure and glowing orange digital visor.
    *   Lighting Effect: Real-time bloom simulation on the orange LED visor element (`drop-shadow(0 0 12px rgba(255, 92, 53, 0.6))`).

### C. Secondary Thumbnail Cards (Right Sidebar)
*   **Card Specifications:**
    *   Layout: Stacked vertically or in a compact flex row on the right-hand panel.
    *   Background: `#FFFFFF` inside a subtle rounded container (`border-radius: 16px`).
    *   Internal Elements:
        *   Thumbnail preview of alternate product angles (Square aspect ratio with rounded corners).
        *   Descriptive caption label ("Your Future is Bionic.", "Our flagship product").
        *   Action button: Circular blue/dark button with a white diagonal arrow icon (`↗`).

### D. Footer & Social Elements
*   **Bottom-Right Social Icons:**
    *   Links: `in` (LinkedIn), `YT` (YouTube), `D` (Dribbble), `X` (Twitter/X).
    *   Font/Style: Monospaced/Clean sans-serif icons, dark charcoal color, spaced evenly with high legibility.

---

## 4. Animation & Interaction Specifications

### Hover States
*   **Navigation Links:** Smooth color transition from `rgba(15, 17, 21, 0.7)` to `#0F1115` with a scaling underline effect (duration: `0.2s ease`).
*   **Pill Buttons (Contact, User Menu):** Slight upward translation (`translateY(-2px)`) with enhanced drop shadow on hover.
*   **Thumbnail Cards:** Subtle scale-up (`scale(1.02)`) with increased border contrast.

### Dynamic / Entrance Animations
*   **Page Load Sequence:**
    1.  *Fade-In Slide:* Left-hand text block and navigation components slide in from the left (`opacity: 0` to `1`, `transform: translateX(-20px)` to `none`, duration: `0.8s cubic-bezier(0.16, 1, 0.3, 1)`).
    2.  *Hero Reveal:* Center image frame scales up smoothly from `0.95` to `1` with an opacity fade.
    3.  *Glow Pulse:* The orange visor glow pulses gently on an infinite loop (`animation: visorGlow 3s ease-in-out infinite`).

```css
@keyframes visorGlow {
  0%, 100% {
    filter: drop-shadow(0 0 8px rgba(255, 92, 53, 0.4));
  }
  50% {
    filter: drop-shadow(0 0 18px rgba(255, 92, 53, 0.8));
  }
}
```
