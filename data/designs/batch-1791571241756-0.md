# Design Specification: Crextio HR & Analytics Dashboard

## 1. Global Layout & Viewport Architecture
- **Target Viewport**: Full-screen desktop application layout (`100vw` × `100vh`), optimized for 1440px+ horizontal viewports.
- **Background System**: 
  - Base backdrop: Soft, muted cool gray (`#E2E5EB` / `#D4D9E2`) creating a floating UI canvas effect.
  - Core application container: Warm gradient-washed canvas (`linear-gradient(135deg, #FBF8ED 0%, #F5E8C7 50%, #ECE1BD 100%)` or equivalent warm cream `#FDFBF4` to pale yellow `#F3E2B3`).
  - Border radius of main container: Rounded corners (`32px` to `40px`) with a soft, multi-layered ambient shadow (`0 20px 40px rgba(0, 0, 0, 0.08)`).
- **Grid Structure**: Modular card-based grid layout with consistent `24px` internal and external gutters.

---

## 2. Typography System
- **Primary Font Family**: Inter, SF Pro Display, system-ui, -apple-system, sans-serif.
- **Fallback Stack**: `sans-serif` (system default sans).
- **Text Hierarchy**:
  - **Main Heading ("Hello Valentina")**: 
    - Size: `32px` / `36px`
    - Weight: Semi-Bold / Medium (`600`)
    - Color: `#1A1A1A`
  - **Section Titles (Schedule, Salary, Hiring Statistics, etc.)**: 
    - Size: `18px` / `20px`
    - Weight: Semi-Bold (`600`)
    - Color: `#1A1A1A`
  - **Body / Table Text**: 
    - Size: `13px` / `14px`
    - Weight: Regular / Medium (`400`–`500`)
    - Color: `#4A4A4A` (primary text), `#8A8A8A` (muted/secondary text)
  - **Micro / Metric Labels**: 
    - Size: `11px` / `12px`
    - Weight: Medium (`500`)
    - Color: `#6A6A6A` / Uppercase tracking where applicable.

---

## 3. Navigation & Header Component
- **Logo Area**: 
  - Text/Brand: "Crextio" inside a pill-shaped container (`background: #FFFFFF`, rounded full pill, subtle border). Font: Bold serif/sans hybrid (`20px`).
- **Main Nav Pills**:
  - Horizontal pill-shaped navigation bar centered in the top header.
  - Items: *Dashboard* (Active pill: Dark charcoal/black background `#1A1A1A` with white text), *People*, *Hiring*, *Devices*, *Apps*, *Salary*, *Calendar*, *Reviews*.
  - Font size: `13px`, Medium weight.
- **Header Actions (Right)**:
  - Setting gear icon, Notification bell icon, and User profile avatar placeholder.

---

## 4. Top KPI & Progress Metric Bar
- **Greeting**: "Hello Valentina" followed by a 4-column metric & progress row directly underneath:
  1. **Interviews**: Progress bar indicator at `70%` inside a dark charcoal container (`#2A2A2A`).
  2. **Hired**: Progress/percentage tag at `10%` inside a soft pastel yellow pill (`#F5E06B`).
  3. **Project time**: Progress status at `15%` with striped pattern fill.
  4. **Output**: Circular progress indicator at `5%`.
- **Top Right Counter Cards**:
  - Three distinct large metrics:
    - **91** (Employe / Users icon)
    - **104** (Hirings / User-plus icon)
    - **185** (Projects / Folder icon)
  - Typography: Extra-large display numbers (`32px`, light/thin-to-medium weight).

## 6. Color Palette Specifications
- **Primary / Dark Accent**: `#2A2A2A` (Charcoal Black)
- **Primary Background Cream**: `#F7F4E9` / `#FAF6EB`
- **Card Surfaces**: `#FFFFFF` (Solid White with subtle transparency/layering) or `#FDFCF7`
- **Highlight Gold / Yellow**: `#F5C12E` / `#EFCB68`
- **Status Tags**:
  - Paid For: `#EFE1F8` (Purple tint)
  - Absent: `#EBEBEB` (Neutral gray)
  - Pending: `#D8F3DC` (Soft green)
- **Text Colors**: `#1A1A1A` (Primary headings), `#6A6A6A` (Labels/Subtext)

---

## 7. Imagery & Iconography Guidelines
- **Avatars**: Circular profile photographs representing real individuals (use high-quality professional headshots placeholder or Unsplash portrait URLs).
- **Icons**: Minimalist, clean vector stroke icons (Feather icons or Lucide icon set style: Search, Settings, Bell, Calendar, Folder, Users, Diag-Arrows).
- **Charts**: Clean SVG-based multi-series line graphs and donut charts with crisp anti-aliased strokes.
