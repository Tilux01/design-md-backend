# DESIGN SPECIFICATION: KFC MOBILE APP INTERFACE (CLONE)

## 1. Global & Layout Specifications
* **Screen Mode:** Full-screen responsive viewport (device frame omitted).
* **Base Layout Style:** Single-column vertical scrolling interface featuring top-level navigation, promotional banners, horizontal category selectors, and grid/card-based product rows.
* **Border Radius System:** 
  * Cards / Banners: `16px` to `24px`
  * Buttons / Pill badges: Full rounded (`50px` or `999px`)
  * Input fields: `12px`
* **Spacing Scale:** Standard 8pt grid system (`8px`, `12px`, `16px`, `24px`).

---

## 2. Color Palette
| Role | Color Name | Hex Code | Usage |
| :--- | :--- | :--- | :--- |
| **Primary** | KFC Red | `#E4002B` | Brand logo, primary action buttons, active tabs, promotional badge fills |
| **Secondary/Accent** | Orange / Gold | `#F58220` | Promotional pill badges ("POPULAR", "LIMITED TIME"), star ratings |
| **Background** | Off-White / Cream | `#FDFBF7` | App background canvas |
| **Surface** | Pure White | `#FFFFFF` | Content cards, search bar, navigation bar background |
| **Text Primary** | Dark Charcoal | `#1C1C1E` | Main headings, product titles, prices |
| **Text Secondary** | Muted Gray | `#6B6B70` | Subtitles, descriptions, ratings count, helper text |
| **Border / Divider** | Light Gray | `#EAEAEA` | Subtle borders, unselected state elements |

---

## 3. Typography & Fonts
> **Primary Font Family:** `Montserrat`, `Helvetica Neue`, or system sans-serif fallback.
> **Fallback Stack:** `font-family: 'Montserrat', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;`

| Element | Weight | Size | Line Height | Color |
| :--- | :--- | :--- | :--- | :--- |
| **App Header Title** | Bold (700) | `20px` | `24px` | `#E4002B` (KFC) / `#1C1C1E` |
| **Section Headings** | Bold (700) | `18px` | `22px` | `#1C1C1E` |
| **Card Title** | Semi-Bold (600) | `15px` | `19px` | `#1C1C1E` |
| **Card Subtext / Details** | Regular (400) | `12px` | `16px` | `#6B6B70` |
| **Price Display** | Bold (700) | `16px` | `20px` | `#1C1C1E` |
| **Buttons / Badges** | Bold (700) | `12px - 14px` | `16px` | `#FFFFFF` |

---

## 4. Component-by-Component Breakdown

### A. Top Navigation Bar
* **Left Element:** Hamburger Menu icon (`☰`) inside a circular white container (`40x40px`, subtle shadow).
* **Center Branding:** 
  * Greeting: "Hello, Chicken Lover! 🍗" (`12px`, Muted Gray)
  * Brand Logo: **"KFC"** in custom heavy serif/sans-serif italicized red typography with tagline: *"It's finger lickin' good."* (`10px`, italic).
* **Right Elements:** 
  * Notification Bell icon with red notification badge (`3` unread items).
  * Shopping Cart icon with red notification badge (`2` items).

### B. Search & Filter Bar
* **Container:** Rounded pill input field (`Height: 48px`, `#FFFFFF`, subtle inner shadow/border).
* **Left Icon:** Magnifying glass (`#6B6B70`).
* **Placeholder Text:** "Search for your favorite chicken..." (`14px`, `#6B6B70`).
* **Right Element:** Filter/Sliders icon button inside a matching white square/rounded box (`40x40px`).

### C. Hero Promotional Banner ("Crispy. Juicy. Irresistible.")
* **Container:** Large gradient card (`Background`: Deep red-to-brown `#7A0C14` fading into `#3A0307`, rounded `24px`).
* **Typography:**
  * Subtitle: "LIMITED TIME" (`10px`, tracked, uppercase, white).
  * Main Headline: **"CRISPY. JUICY. IRRESISTIBLE."** (`24px`, Extra Bold, Uppercase, White).
  * Body Text: "100% Real Chicken. Made Fresh. Always." (`11px`, `#E0E0E0`).
* **CTA Button:** Pill-shaped solid red button (`Background: #E4002B`) with white text **"Order Now"** and a right-pointing arrow icon (`→`).
* **Imagery:** High-resolution cutout composition of a KFC bucket, French fries carton, gravy bowl, and fresh fried chicken pieces.
* **Pagination Dots:** 4 tiny dots at the bottom center (active dot is red and elongated, remaining 3 are smaller white/gray circles).

### D. Horizontal Category Selector
* **Scrollable Row:** 7 circular category items with text labels underneath.
* **Categories:** 
  1. *All* (Highlighted with a red circular border outline)
  2. *Buckets*
  3. *Burgers*
  4. *Snacks*
  5. *Sides*
  6. *Drinks*
  7. *Desserts*
* **Visual Style:** Each category features a miniature photographic preview inside a circular badge (`64x64px`, `#FFFFFF` background with subtle drop shadow). Labels are centered below (`12px`, Semi-Bold).

### E. Section: Popular Combos
* **Header:** "Popular Combos" (Left-aligned, Bold `18px`) | "View All →" link in KFC Red (Right-aligned, Bold `14px`).
* **Layout:** Horizontal scroll or 3-column card grid containing product cards.

#### Product Card Specifications:
* **Card Container:** Pure white background (`#FFFFFF`), rounded corners (`16px`), light border/shadow.
* **Top Badges (Absolute Positioned):**
  * *Bestseller / Popular:* Rounded pill badge at top-left (`Background: #E4002B` or `#F58220`, White text, `10px`).
  * *Wishlist Icon:* Outline heart icon (`♡`) at top-right inside a circular container.
* **Product Image:** Centered high-resolution cutout of the combo meal.
* **Card Content:**
  * **Title:** E.g., *"8 Pcs Chicken Bucket"* (`15px`, Bold).
  * **Description:** E.g., *"2 Large Fries + 2 Dips + 2 Drinks"* (`12px`, Muted Gray, 2-line clamp).
  * **Rating:** Star icon (Gold) + *"4.8 (12.5K+)"* (`12px`).
* **Footer / Pricing:**
  * Price Display: **"$24.99"** (Bold, `16px`).
  * Add Action: Solid red circular button with a white plus sign (`+`) positioned at the bottom right of the card.

### F. Bottom Promotional Banner (Exclusive Offer)
* **Container:** Light cream/white gradient banner (`Background: #F7EFE2`, rounded `20px`).
* **Content Left:**
  * Tag: "EXCLUSIVE OFFER" (`10px`, Bold, `#E4002B`).
  * Heading: **"Up to 30% OFF"** (`18px`, Bold).
  * Subtext: "On selected combos" (`12px`, Muted Gray).
  * CTA Button: Solid red pill button **"Order Now →"**.
* **Content Right:**
  * Circular badge overlapping the right edge: **"30% OFF"** (`Background: #E4002B`, White text, bold).
  * Image: Burger, fries, and drink photography.

### G. Bottom Navigation Bar (Fixed Footer)
* **Container:** Floating white bar spanning the bottom screen width (`Height: 64px`, `#FFFFFF`, top border stroke).
* **Items (5 Tabs):**
  1. 🏠 **Home** (Active state: Icon & text highlighted in **KFC Red `#E4002B`**).
  2. 🗂️ **Menu** (Inactive state: Muted gray icon & text).
  3. 🛍️ **Orders** (Highlighted with a prominent floating red circular action button `Background: #E4002B`, white bag icon).
  4. 🏷️ **Offers** (Inactive state).
  5. 👤 **Profile** (Inactive state).

---

## 5. Micro-Interactions & Animations (Specs for Development)
* **Horizontal Scrolls:** Smooth-momentum touch scrolling enabled for Category pills and Popular Combos rows.
* **Button Hover / Active States:** Scale down slightly (`transform: scale(0.96)`) on press/tap.
* **Badges & Counters:** Notification badges scale in with a subtle spring bounce (`spring(1, 400, 20)`) when counts update.
* **Hero Banner Carousel:** Auto-scrolls every 4 seconds with a smooth horizontal slide transition.
