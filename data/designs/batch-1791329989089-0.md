# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Modern FinTech SaaS & Web3 Glassmorphism (High-end financial platform with deep purple/violet gradients, gold 3D asset rendering, and minimalist editorial typography).
- **Visual Density & Whitespace Ratio**: High whitespace-to-content ratio on the left content block with expansive negative space on the right canvas, providing a balanced asymmetrical hero composition.
- **Surface Elevation Model**: Layered canvas architecture utilizing dark radial background gradients, semi-transparent frosted glass panels (`backdrop-filter: blur(16px)`), subtle 1px border highlights, and 3D floating metallic gold elements.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Floating translucent pill navigation, ambient radial gradient backdrop lighting, high-contrast gold metallic circular arrays.
- **Pill Badge Specification**: Padding `6px 16px`, Font-size `12px`, Font-weight `500`, Tracking `0.05em`, Border-radius `9999px`, Background translucency `rgba(255, 255, 255, 0.05)`, Border width `1px` solid `rgba(255, 255, 255, 0.1)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or `\2014`.
  - Arrow / Dropdown (▾) -> Use `&#9662;`.
  - Status Dot (●) -> Use `<span class="w-1.5 h-1.5 rounded-full bg-emerald-400 inline-block"></span>`.

# 7. Motion Mechanics, Framer Motion & CSS Animations
- **Motion Principles**: Smooth cubic-bezier spring physics for UI reveals (`[0.16, 1, 0.3, 1]`), slow rotational ambient loops for 3D elements, and micro-scale interactions on buttons.
- **Framer Motion Variants Code**:
```jsx
export const containerVariants = {
  hidden: { opacity: 0, y: 20 },
  visible: { 
    opacity: 1, 
    y: 0,
    transition: { duration: 0.6, ease: [0.16, 1, 0.3, 1], staggerChildren: 0.15 }
  }
};
```

- **CSS `@keyframes` Animations**:
```css
@keyframes slowSpin {
  0% { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}
.animate-spin-slow {
  animation: slowSpin 35s linear infinite;
}
```
