# UI Design System Specification: Premium Minimalist FinTech App

This document provides a highly detailed, exact engineering-ready specification for cloning the modern FinTech mobile wallet design shown in the reference image. It focuses on the core screens, omitting external physical device frames or mock-ups to deliver clean, full-screen interactive views.

---

## 1. Design Tokens & Variables

### 1.1 Brand Palette

| Token Name | Hex Code | Usage |
| :--- | :--- | :--- |
| `--bg-dark-primary` | `#0D0D10` | Primary background for dark interfaces / Screen 2 background |
| `--bg-dark-secondary`| `#18181C` | Card background on dark theme / intermediate control areas |
| `--bg-dark-tertiary` | `#2E2E32` | Button and active state fills on dark containers |
| `--bg-light-primary` | `#F3F3F5` | Main background for light dashboard surfaces and bottom drawers |
| `--bg-light-secondary`| `#FFFFFF` | Core highlight containers / numeric keypad buttons |

| `--text-muted-dark`  | `#6E6E73` | Subtitles, disabled tabs, metadata labels on light backgrounds |
| `--text-primary-light`| `#FFFFFF` | Primary labels, headers, and inputs on dark backgrounds |
| `--text-muted-light` | `#8E8E93` | Metadata, disabled states, and system labels on dark backgrounds |

| `--accent-green-text`| `#113A00` | Dark green text contrast for positive trend badges |

---

### 1.2 Typography
To replicate the high-fashion, premium neo-grotesque styling, use a custom geometric sans-serif typeface optimized for tabular figures.

*   **Primary Font Family:** `SF Pro Display`, `Inter`, system-ui, sans-serif.
*   **Balance Display Font:** `Clash Display` (or `Helvetica Neue Condensed` / `Inter` with custom tracking parameters).

#### Typography Scale
*   **Hero Balance (Large Screen 1 & 2):** `size: 48px`, `weight: 600 (Semibold)`, `letter-spacing: -0.04em`, `line-height: 1.1`.
*   **Section Headers:** `size: 16px`, `weight: 600`, `letter-spacing: -0.01em`.
*   **Body / Profile Names:** `size: 14px`, `weight: 500`, `letter-spacing: -0.01em`.
*   **Metadata / Captions:** `size: 11px`, `weight: 400`, `letter-spacing: 0em`.

---

### 1.3 Key Interface Characteristics
*   **Border Radius:**
    *   Outer wrapper/viewport corner radius: `40px` (standard high-end mobile curve).
    *   Standard UI cards & Drawers: `28px`.
    *   Keypad Buttons & Quick Actions: `16px`.
    *   Trend Pills & Status Indicators: `9999px` (Fully rounded).
*   **Shadows:** 
    *   No hard borders or skeuomorphic dropshadows. 
    *   Use highly diffused, soft ambient occlusion shadows for elevated elements:
        *   `box-shadow: 0px 10px 40px rgba(0, 0, 0, 0.04);` (For light cards).

## 2. Layout & Screen Architecture

### Screen 1: Wallet Dashboard (Light/Dark Hybrid)

This screen utilizes a layered three-section design stacked vertically:
1.  **Light Top Balance Header (`--bg-light-primary`)**
2.  **Dark Middle Quick Actions Bar (`--bg-dark-primary`)**
3.  **Light Bottom Drawer (`--bg-light-primary`)**

```
+------------------------------------------+
|                  9:41                    | [Dynamic Island Pill]
|  Hi Ben! Welcome ...       [::]  [Bell]  |
|                                          |
|                [$ USD]                   |
|              $12,329                     |
|                                          |
|              [+2.10%]                    |
+------------------------------------------+
| [ Send ^ ]     [ [QR] ]     [ Recieve ]  | (Dark Section)
+------------------------------------------+
|  Send Again                              | (Scrollable Row)
|  (Avatar) (Avatar) (Avatar) [+]          |
|                                          |
|  Recent Activity                         | (List View)
|  [Dribbble] Yesterday                    |
|  [Hannah] 3h ago                         |
+------------------------------------------+
```

#### Detailed Breakdown & Specifications:

*   **Dynamic Island / Status Bar Overlay:**
    *   Centered status bar block featuring a rounded pill style cutout: `width: 110px`, `height: 30px`, `background: #000000`.
    *   Status indicators (Signal strength, WiFi, Battery) aligned 24px from the right edge. Time (`9:41`) aligned 24px from the left edge.
*   **Welcome & Balance Area (Top Container):**
    *   Background fill: `--bg-light-primary`. Padding: `24px` top, left, right.
    *   **Welcome Message:** Left-aligned. "Hi Ben!" (`weight: 600`, `--text-primary-dark`), newline: "Welcome to your wallet" (`weight: 400`, `--text-muted-dark`).
    *   **Action Icons:** Row aligned to the right. 
        *   *App Menu Icon:* Grid of 4 rounded dots inside a square tile, visual dimension: `44px x 44px`, background: `--bg-light-secondary`.
        *   *Notification Bell:* Stroke icon inside a matching white circular button.
    *   **Currency Switcher Badge:** Pill element centered above the balance. Text: `USD` with a solid circular prefix containing `$`.
    *   **Main Balance:** Centered `$12,329` (styled with highly compressed letter tracking `-0.05em`).
    *   **Trend Indicator:** Hovering below the balance card, a bright green pill capsule containing `+2.10%` (`background: --accent-green`, `color: --accent-green-text`, `font-size: 12px`, `font-weight: 600`).
*   **Quick Action Bar (Middle Layer):**
    *   Transition container: styled in deep dark slate (`--bg-dark-primary`) with custom top/bottom inverse border-radius overlaps.
    *   **Action Buttons Row:**
        *   *Send Button:* Dark grey pill (`--bg-dark-tertiary`), text "Send" with an up-right arrow in a circular container inside the button.
        *   *QR Scanner Button:* Square icon button (`width: 50px`, `height: 50px`) with high contrast white layout, featuring an abstract nested frame icon.
        *   *Receive/Context Buttons:* Symmetrical layout extending off-canvas.
*   **Bottom Activity Drawer:**
    *   Background fill: `--bg-light-primary`. Starts seamlessly beneath the Dark Middle Bar.
    *   **"Send Again" Section:**
        *   Label: `font-size: 14px`, `weight: 600`, colored in `--text-primary-dark`.
        *   Horizontal scroll area containing rounded dynamic avatar components (48px diameter) with smooth profile visuals.
        *   `+` Add Button: Styled with dashed outline circular frame or a rounded square (`width: 48px`, `height: 48px`, `--bg-light-secondary`).
    *   **"Your Income" Preview Panel:**
        *   Cards showing mini-line-charts (sparklines) capturing dynamic visual updates in `--accent-green`. Value reading `$2,432.00` underneath label: "This Month".
    *   **"Recent Activity" List:**
        *   Clean tabular rows separating items.
        *   *Dribbble Transaction:* High density round SVG icon displaying the Dribbble vector. Text elements stacked: "Dribbble" (Primary dark, bold), "Yesterday" (Muted dark, regular).
        *   *Hannah Jones Transaction:* Profile bubble on left side, "Hannah Jones", "3h ago" indicator aligned seamlessly below.

## 3. UI Micro-Animations & Dynamic States

To elevate the implementation to a world-class standard, execute the following UI transitions using CSS Keyframes or Framer Motion:

### 3.1 Screen Routing Transitions
*   **Shared Element Transition (Hero Amount):** When transitioning from Dashboard to Send Money screen, the Balance pill `$12.329` seamlessly shrinks and morphs into the "Total Balance: $12.329" badge floating above the keypad drawer.
*   **Slide Sheet Animation:** The light-grey keypad drawer on Screen 2 slides vertically upward from the bottom of the viewport (`transform: translateY(100%)` to `translateY(0)`) with a custom cubic bezier transition curve: `cubic-bezier(0.16, 1, 0.3, 1)` (duration: 450ms).

### 3.2 Dynamic Tap & Active States
*   **Tactile Buttons (Send, Scan, Recipient Chevrons):**
    ```css
    button:active {
      transform: scale(0.96);
      filter: brightness(0.9);
      transition: transform 0.1s cubic-bezier(0, 0, 0.2, 1);
    }
    ```
*   **Keypad Click Animation:** When a number is pressed on the numeric drawer, the corresponding key displays a brief scale pulse effect (`scale(0.95)`) accompanied by a subtle background shift to light grey (`#E2E2E5`).
