# E-Commerce & Editorial Fashion UI Design Specification

## 1. Design Philosophy & Overall Aesthetic
- **Primary Mood:** Modern luxury retail meets minimalist editorial curation; high-contrast photography with refined grid layouts.
- **Brand Archetype:** High-end boutique e-commerce, sophisticated, clean, and content-driven.
- **Visual Density:** Medium-low density, prioritizing whitespace, large lifestyle photography, and clean typography.
- **Whitespace Balance:** Generous padding around product grids (`3rem` to `4rem`), strict alignments, and structured multi-column breakouts.
- **Theme Balance:** Clean light mode base (`#FFFFFF` backgrounds, `#000000` text elements) accented with dark action buttons (`#111111`) and translucent overlays.

## 2. Color Palette & Design Tokens

### Core Palette
- **Primary / Action:** Pure Black (`#111111`)
- **Secondary / Muted:** Neutral Gray (`#666666` / `#8E8E93`)
- **Base Background:** Pure White (`#FFFFFF`)
- **Surface / Card Background:** Off-White / Soft Gray (`#F7F7F9`)

- **Text Primary:** Deep Charcoal / Black (`#1C1C1E`)
- **Text Muted:** Medium Gray (`#8A8A8E`)
- **Text Inverse:** Pure White (`#FFFFFF`)

## 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** `1280px` centered with auto margins.
- **Grid Structure:** 12-column responsive flex/grid system.
- **Section Sequence:**
  1. Header / Navigation Bar
  2. Hero Banner Showcase
  3. Category Grid ("New Arrivals") with 3-column product cards & pill action triggers
  4. Secondary Editorial Banner / Lookbook Feature

---

## 5. AI Design Traits, Micro-Badges & Special Glyphs

- **Pill Action Triggers ("Shop Now"):**
  - **Padding:** `0.5rem 1.25rem`
  - **Font Size:** `0.75rem`
  - **Font Weight:** `600`
  - **Letter-Spacing:** `0.08em` (Uppercase)
  - **Border-Radius:** `9999px` (Fully rounded pill)
  - **Background / Text:** Solid Black (`#111111`) background with White text (`#FFFFFF`), reversing on hover.
- **Symbol Safety:** Standard UTF-8 entities used for arrows and separators (`→`, `—`, `•`).

## 7. Motion Mechanics, Framer Motion & Animation Code

- **Animation Triggers:** Hover scaling on images, smooth color inversion on buttons, fade-in scroll triggers.
- **Timing & Easing:** `cubic-bezier(0.16, 1, 0.3, 1)` (Swift out), duration `300ms`.

### Framer Motion Variants

## 8. Accessibility (a11y) & WCAG Contrast Audit

- **Text Contrast Ratio:** Primary text (`#1C1C1E`) on white background exceeds **14:1**, meeting WCAG AAA requirements.
- **Button Contrast Ratio:** White text on solid black (`#111111`) exceeds **18:1**, passing WCAG AAA standards.
- **Focus Rings:** All interactive elements feature a visible high-contrast outline state:
```css
button:focus-visible, a:focus-visible {
  outline: 2px solid #111111;
  outline-offset: 2px;
}
```
