# Raspberry Rhapsody — Design Specification & Clone Guide

This document provides the exact design specifications for cloning the "Raspberry Rhapsody" digital experience shown in the media. 

---

## 1. Global Layout & Canvas

*   **View:** Fullscreen (100vw / 100vh), responsive layout.
*   **Background Color:** Rich, vibrant raspberry pink.
    *   *Hex Code (Approximate):* `#E72E71` or `#DF2A6A` (with subtle gradient lighting, darker at the top/edges, brighter in the center).
*   **Layout Structure:**
    *   **Left Column:** Branding (Heading, Paragraph, CTA Button).
    *   **Right/Center Area:** 3D interactive floating elements (Raspberries, main ice cream cone, smaller background cones).

---

## 2. Typography & Fonts

### Primary Heading ("Raspberry Rhapsody")
*   **Font Family:** High-contrast, elegant Modern Serif / Didone style (resembling *Playfair Display*, *Bodoni Moda*, or *Cinzel Decorative*).
*   **Style:** Italic.
*   **Color:** Pure White (`#FFFFFF`).
*   **Fallback Stack:** `Georgia`, 'Times New Roman', serif.

### Body Text (Description paragraph below heading)
*   **Font Family:** Clean, legible Sans-Serif (resembling *Inter*, *SF Pro Display*, or *Roboto*).
*   **Size:** Small, readable.
*   **Color:** Semi-transparent white (`rgba(255, 255, 255, 0.8)`).
*   **Fallback Stack:** `-apple-system`, 'BlinkMacSystemFont', 'Segoe UI', 'Roboto', sans-serif.

### CTA Button Text ("Order Now")
*   **Font Family:** Sans-Serif (matching body text).
*   **Weight:** Medium / Semi-bold.
*   **Color:** Pure White (`#FFFFFF`).

---

## 3. UI Components

### Call-to-Action (CTA) Button
*   **Shape:** Pill-shaped (fully rounded corners / `border-radius: 50px`).
*   **Border:** Thin white stroke (approx. 1px–2px solid white).
*   **Background:** Transparent (Glassmorphism effect with a very subtle white blur, or completely transparent until hovered).
*   **Interaction:** Hover state triggers a solid white background with pink text (`#E72E71`).

---

## 4. Visual Elements & 3D Assets

*   **Main Visual (Center-Left):**
    *   A large waffle cone filled with swirling, glossy pink raspberry soft-serve ice cream.
    *   Melting syrup dripping realistically down the sides of the cone.
*   **Floating Raspberries:**
    *   Multiple hyper-realistic raspberries scattered mid-air above and around the main ice cream cone, giving a sense of dynamic motion and freshness.
*   **Secondary Elements (Background Cones):**
    *   Smaller miniature ice cream cones positioned further back in the depth of field.
    *   *Note on Interaction (from media):* The user interface allows transforming or swapping cone flavors/colors dynamically (e.g., swapping a pink cone to a blue/teal-swirled unicorn cone via touch/click).

---

## 5. Animation & Motion Design

To achieve the exact feel of the media, implement the following animations:

1.  **Parallax Floating Effect:** 
    *   The floating raspberries and ice cream cones should subtly bob up and down using continuous CSS keyframe animations or JavaScript mouse-move parallax (responding to cursor/gyroscope movement).
2.  **Entry Animation (Load):**
    *   Elements fade in and float up from their starting positions (`opacity: 0; transform: translateY(20px)` to `opacity: 1; transform: translateY(0)`).
3.  **State Transition (Flavor Swap):**
    *   When clicking/tapping a secondary cone or triggering the flavor change, use a smooth 3D morph/cross-fade transition to swap texture maps and color palettes (e.g., Pink to Blue/Cyan).
