# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Dark Mode Generative Topography & Data Visualization (Atmospheric, Scientific, Immersive).
- **Visual Density & Whitespace Ratio**: High-contrast dark-mode immersion with dense, organic textured surfaces balanced by precise geometric overlay lines and sparse micro-indicators.
- **Surface Elevation Model**: Multi-layered dark depth utilizing deep obsidian charcoal (#020408) as base canvas, layered mossy tactile terrain (#0B1C0B), and glowing emissive white/emerald nodes (`rgba(255, 255, 255, 0.95)`).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Generative dotted contour curves, topographic elevation mapping, high-contrast moss textures, ambient emerald emissive lighting, real-time node tracking indicators.
- **Pill Badge Specification**: Padding `6px 14px`, font-size `12px`, font-weight `600`, tracking `0.08em`, border-radius `9999px`, background translucency `rgba(16, 185, 129, 0.1)`, border width `1px` (`rgba(16, 185, 129, 0.3)`).
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;`.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-emerald-400 inline-block animate-pulse"></span>`.
