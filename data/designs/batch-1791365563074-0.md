# Ferrari 458 GT3 Showcase Interface - Design Specification

A dark-themed, high-end automotive showcase web interface designed for luxury sports car presentation, featuring an immersive central 3D car viewer, technical specifications timeline, rating system, and carousel navigation.

---

## Global Design System

### Color Palette
- **Primary Background:** `#13161c` (Deep Charcoal Black)
- **Secondary/Card Surface:** `#1c212c`
- **Text Primary:** `#ffffff` (Pure White)
- **Text Secondary / Muted:** `#737b8c` (Cool Muted Gray)
- **Accent Color (Car):** `#e66712` (Dynamic Racing Orange)
- **Interactive Highlights:** `#ffffff` (White accents, buttons, and active states)

### Typography
- **Primary Font Family:** Inter / San Francisco (Clean, modern sans-serif)
- **Logo/Brand:**
  - Font Size: `14px`
  - Weight: Bold (`700`)
  - Letter Spacing: `2px`
- **Headings (Car Model):**
  - Font Size: `28px` - `32px`
  - Weight: Bold (`700`)
  - Text Transform: Uppercase
- **Body / Description Text:**
  - Font Size: `11px`
  - Weight: Regular (`400`)
  - Line Height: `1.5`
- **Navigation / Menu Items:**
  - Font Size: `12px`
  - Weight: Medium (`500`)
  - Letter Spacing: `1px`

---

## Layout & Structure

### Canvas Dimensions
- **Layout Type:** Full-Screen Immersive Viewport (`100vw` × `100vh`)
- **Grid Structure:** Three-column layout (Left: Details, Center: Main Showcase, Right: Specs) with header navigation and bottom carousel.

---

## Component Specifications

### 1. Header Navigation
- **Position:** Absolute, top (`top: 32px`), spanning full width with padding (`padding: 0 64px`).
- **Left Element (Logo):**
  - Text: `HARRI'S`
  - Color: `#ffffff`
- **Right Elements (Menu):**
  - Links: `GALLERY`, `ABOUT`, `CONTACT`
  - Font Size: `11px`
  - Letter Spacing: `1.5px`
  - Spacing between links: `32px`
  - Color: `#737b8c` (Hover state: `#ffffff`)

---

### 2. Left Column: Vehicle Details & Rating
- **Position:** Absolute, left side (`left: 64px`, vertically centered).
- **Width:** `280px`
- **Content Stack:**
  - **Car Title:**
    - Text: `FERRARI` / `458 GT3` (Stacked)
    - Font Size: `28px`
    - Line Height: `1.1`
    - Color: `#ffffff`
    - Bottom Margin: `16px`
  - **Description Paragraph:**
    - Text: Descriptive summary of the vehicle specifications and aerodynamic design.
    - Font Size: `10.5px`
    - Color: `#737b8c`
    - Bottom Margin: `24px`
  - **Rating Section:**
    - Score Number: `4.2` (`24px`, Bold, White)
    - Star Rating: 4 filled stars + 1 empty/half star icon beneath the score.
  - **Copyright Notice:**
    - Positioned at the bottom left (`bottom: 32px`).
    - Text: `Copyright 2021.`
    - Font Size: `9px`
    - Color: `#4a5160`

---

### 3. Center Column: Main 3D Showcase & Controls
- **Position:** Center stage of the viewport.
- **Visual Element:**
  - High-resolution render of the orange Ferrari 458 GT3 angled dynamically toward the viewer.
  - Subtle radial gradient/glow beneath the vehicle to anchor it to the dark space.
- **Action Button ("DETAILS"):**
  - Position: Centered horizontally beneath the car render.
  - Style: Pill-shaped outline button with thin white border.
  - Padding: `8px 24px`
  - Font Size: `10px`
  - Letter Spacing: `1.5px`
  - Color: `#ffffff`

---

### 4. Right Column: Technical Specifications (SPECS)
- **Position:** Absolute, right side (`right: 64px`, vertically centered).
- **Width:** `200px`
- **Header:**
  - Title: `SPECS`
  - Font Size: `11px`
  - Letter Spacing: `2px`
  - Color: `#ffffff`
  - Bottom Margin: `20px`
- **Timeline / Specification List:**
  - Vertical connecting line in muted gray (`#2a303e`).
  - Bullet points indicating specs (active item highlighted in white, inactive in muted gray):
    1. `4.5L V8 engine` (Inactive)
    2. `Dual-clutch transmission` (Active - filled dot indicator)
    3. `Max torque: 540 Nm at 6000 rpm` (Inactive)
    4. `Top speed: 340 km/h` (Inactive)
    5. `Weight: 1250 kg` (Inactive)
  - Font Size: `10px`
  - Color: `#737b8c`

---

### 5. Bottom Navigation & Footer Controls
- **Position:** Absolute, bottom (`bottom: 32px`), centered horizontally.
- **Elements:**
  - **Previous Arrow (`<`):** Navigates carousel left.
  - **Car Thumbnail Carousel:**
    - Three miniature preview renders of the vehicle variations/angles.
    - Center thumbnail is active/highlighted.
  - **Next Arrow (`>`):** Navigates carousel right.
- **Social / Utility Icons:**
  - Positioned at bottom right (`right: 64px`, `bottom: 32px`).
  - Minimalist white icons: Facebook, Instagram, Twitter/X.
  - Icon size: `14px`
  - Spacing: `16px`
