# Design System & Engineering Specification: Matte Black Coke Landing Page

---

## 1. Design Philosophy & Overall Aesthetic
*   **Primary Mood:** Ultra-premium, minimalist, moody, and sophisticated. Designed for a high-end product showcase or concept reveal.
*   **Brand Archetype:** Luxury / Disruptor / Experimental. 
*   **Visual Density:** Low density, high negative space (whitespace/negative black space), prioritizing single-focus object storytelling.
*   **Theme Balance:** 100% Dark Mode. The interface utilizes ultra-deep monochromatic gradients (`#0a0a0a` to `#161616`) combined with a high-contrast hero subject (the matte black condensation-covered can).

## 4. Layout Architecture & Spatial Grid

*   **Container Width:** Max `1280px` centered canvas frame with fixed aspect ratio (`16:10` presentation shell).
*   **Grid System:** 12-Column fluid structural layout with an 8px base spacing grid.
*   **Padding & Margins:**
    *   Outer Canvas Padding: `48px` desktop viewport edges.
    *   Content Margin Left: `80px` from container edge.
    *   Bottom Content Padding: `48px`.
*   **Section Sequence:**
    1.  **Top Navigation Bar:** Logo (left), Hamburger Menu (right).
    2.  **Hero Grid Layer:** 
        *   Left Column: Typography block (`Matte Black Coke`), Sub-tagline, and interactive feature card.
        *   Right Column / Center Focus: 3D Product render (Coke Can) offset by abstract circular vector framing and carousel pagination trigger (`→`).
    3.  **Bottom Supporting Elements:** Designer attribution chip (bottom-left) and action/share card element (bottom-right).
*   **Stacking Order (Z-Index):**
    *   `z-0`: Base Canvas Background & Radial Spotlight Gradients.
    *   `z-10`: Abstract background ring & ambient lighting.
    *   `z-20`: Central 3D Product Renders (Coke Can).
    *   `z-30`: UI Content, Typography, and Floating Cards.
    *   `z-40`: Navigation, Header, and Floating Action Triggers.

## 5. Component Blueprint & Element Placement

### A. Navigation Bar
*   **Placement:** Fixed top layout, vertical alignment centered, horizontal spread (`space-between`).
*   **Logo:** Left-aligned, vector script `Coca-Cola` logo in white (`110px` width).
*   **Hamburger Icon:** Right-aligned standard three-line menu icon (`24px × 24px`, `#FFFFFF`, stroke width `2px`, rounded caps).

### B. Hero Typography Block
*   **Layout Stack:** Vertical flex column (`gap: 12px`).
*   **Elements:** 
    *   `H1`: "Matte Black Coke" (Stacked on two lines: "Matte" / "Black Coke").
    *   Subtitle: "Hello Mostazir!" (Secondary weight, color `#A0A0A0`).

### C. Feature Cards (Left & Right Anchors)
*   **Left Bottom Card (Black Version Info):**
    *   *Dimensions:* Width `~220px`, Auto height.
    *   *Background:* Translucent dark slate (`#141414` at `80%` opacity with backdrop blur `blur(12px)`).
    *   *Border-Radius:* `4px`.
    *   *Content:* Title ("Black Version"), Description text (Lorem Ipsum, size `11px`, color `#888888`), and 3-star rating graphic (`★★★`, `#FFFFFF`).
*   **Right Bottom Card (Action / Share):**
    *   *Dimensions:* Width `~250px`, Auto height.
    *   *Background:* Solid dark surface (`#111111`).
    *   *Border-Radius:* `4px`.
    *   *Content:* Header ("Black Version"), small description, and floating Share / Network Icon (`svg` node sharing node links, color `#FFFFFF`).

### D. Central Product & Abstract Framing
*   **Product:** Centered-right 3D render of a black matte aluminum beverage can with hyper-realistic condensation droplets and gloss-engraved dark branding.
*   **Geometric Accent:** Perfect outline circle vector (`stroke: #FFFFFF`, stroke-width: `3px`, opacity: `0.8`) framing the upper-right shoulder of the can.
*   **Pagination Control:** Right-aligned navigation chevron (`→`) inside a subtle hit-target circle for carousel interaction.

---

## 6. Motion Mechanics & Interactions (Recommended Implementation)

*   **Page Load / Entrance Animation:**
    *   *Staggered fade-in* for typography using `opacity: 0 -> 1` and `transform: translateY(20px) -> translateY(0)`.
    *   *Can Render:* Scale up from `0.95` to `1.0` with subtle rotational tilt easing (`cubic-bezier(0.16, 1, 0.3, 1)`).
*   **Hover States:**
    *   *Cards:* Scale `1.02`, background shifts from `#141414` to `#1c1c1c`, drop shadow deepens (`box-shadow: 0 12px 24px rgba(0,0,0,0.5)`).
    *   *Carousel Arrow (`→`):* Horizontal translation `translateX(4px)` on hover.
*   **Transitions:** Standard micro-interactions duration `300ms` with `cubic-bezier(0.4, 0, 0.2, 1)` (ease-in-out).
