# UI/UX Specification & Design Document

## 1. Global & Layout Architecture
- **Layout Type:** Three-column desktop web application layout mimicking a modern Instagram web dashboard.
- **Background:** 
  - Outer padding/canvas color: `#EAEFF7` (soft cool-toned grey-blue).
  - Main application window background: Pure white (`#FFFFFF`) with subtle rounded corners (`border-radius: 24px`) and a soft, diffused multi-layered drop shadow (`box-shadow: 0 20px 40px rgba(0,0,0,0.06)`).
- **Grid Structure:**
  - **Left Sidebar:** Fixed width (~280px), containing user profile widget, bio, story highlights, and navigation links.
  - **Center Feed / Stories Area:** Flexible fluid width, housing the top horizontal "Stories" reel and the vertical cascading "Feed" post grid.
  - **Top Navigation Bar:** Spans horizontally across the top containing the Instagram wordmark, live search input field, notification bell, direct message icon, and the primary CTA button ("+ Create a post").

---

## 2. Typography & Fonts
- **Primary Font Family:** System UI stack mimicking modern sans-serif aesthetics (Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif).
- **Fallback Font Stack:** `sans-serif`.
- **Font Weights Used:**
  - Regular (`400`): Body text, handles, secondary descriptions, timestamps.
  - Medium (`500`): Navigation labels, secondary usernames, counts.
  - Bold (`600` / `700`): Primary headings ("Stories", "Feed"), usernames, buttons, major stats.

---
