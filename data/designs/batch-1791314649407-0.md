# Comprehensive UI/UX Design System Specification

---

## 1. Design Philosophy & Overall Aesthetic

- **Primary Mood:** Organic, sustainable, eco-luxury, apothecary, high-end botanical.
- **Brand Archetype:** Nature-focused wellness platform emphasizing holistic care, natural ingredients, and mindful aesthetics.
- **Visual Density:** Balanced; generous negative space paired with textured layered cards and rich dimensional shadows to create physical tactility.
- **Theme Balance:** Dark-forest green and deep espresso earth tones dominate. Flat elements are avoided in favor of subtle glassmorphism, soft multi-layered drop shadows, radial lighting highlights, and tactile organic textures (leaf veins, ribbed paper, layered card surfaces).

## 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** `1280px` centered with auto margins and responsive padding (`24px` mobile, `64px` desktop).
- **Grid System:** CSS Grid with 12 columns, variable gaps (`24px` to `32px`).
- **Section Breakdown (Top to Bottom):**
  1. **Hero Header & Organic Visual Banner:** Dual-tone background panel with intersecting botanical photo assets and primary CTA.
  2. **Feature Metric / Pill Row (Dark Green Card):** Rounded multi-column icon feature strip (`border-radius: 32px`).
  3. **Modular Grid Section:** Mixed card grid featuring solid green, earth brown, sand, and media thumbnail blocks.
- **Stacking Order (Z-Index):**
  - Background textures: `z-0`
  - Cards & Content containers: `z-10`
  - Floating badges & Interactive pills: `z-20`
  - Modals & Overlays: `z-50`

## 6. Motion Mechanics, Framer Motion & CSS Animation Code

- **Transitions:** Smooth spring physics for cards, subtle fade-in-up on scroll for content blocks.
- **Duration:** `0.4s` to `0.6s` with custom easing (`cubic-bezier(0.16, 1, 0.3, 1)`).

### Framer Motion React Code Snippets
```jsx
import { motion } from 'framer-motion';

export const cardVariant = {
  hidden: { opacity: 0, y: 24 },
  visible: { 
    opacity: 1, 
    y: 0,
    transition: { 
      duration: 0.5, 
      ease: [0.16, 1, 0.3, 1] 
    }
  }
};

export const AnimatedCard = ({ children }) => (
  <motion.div
    initial="hidden"
    whileInView="visible"
    viewport={{ once: true }}
    variants={cardVariant}
    whileHover={{ y: -4, transition: { duration: 0.2 } }}
    className="bg-forest-600 rounded-[20px] p-6 shadow-card"
  >
    {children}
  </motion.div>
);
```

### CSS `@keyframes` Animation Snippets
```css
@keyframes floatUp {
  0% {

  }

  }

.animate-float-up {
  animation: floatUp 0.6s cubic-bezier(0.16, 1, 0.3, 1) forwards;
```

## 7. Accessibility (a11y) & WCAG Contrast Audit

- **Text Contrast Ratios:**
  - `sand-light` (`#f5f1eb`) on `forest-900` (`#113627`): **13.5:1** (Passes WCAG AAA)
  - `forest-200` (`#b2c2b6`) on `forest-900` (`#113627`): **7.2:1** (Passes WCAG AAA)
  - `earth-900` (`#291d18`) on `sand` (`#ecd8b7`): **11.8:1** (Passes WCAG AAA)
- **Keyboard Focus States:**
  - All interactive elements feature a high-contrast focus ring: `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-sand focus-visible:ring-offset-2 focus-visible:ring-offset-forest-900`.
