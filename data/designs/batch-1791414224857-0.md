# UI/UX Specification & Design Document
**Project:** Cyber-Glow / Sci-Fi Tactical Analytics Dashboard  
**Resolution:** Full-Screen Responsive (Desktop First, Optimized for 16:9 Displays)  
**Theme:** Cyberpunk / Futuristic / Holographic HUD  

---

## 1. Global Layout & Structure

The interface follows a **multi-column grid dashboard layout** with a dark, immersive command-center aesthetic. It relies on a "floating HUD on dark canvas" design pattern where functional modules sit atop a deep, void-like background.

*   **Screen Coverage:** 100% Full-Screen (Edge-to-Edge). No padding constraints on the outer viewport; elements align organically to a simulated central axis.
*   **Grid System:** 
    *   **Top Header:** Global metrics, primary system clock, central core visualization.
    *   **Left Column:** Diagnostic telemetry, primary status indicators, power/system levels.
    *   **Center Column:** Core visualizer, wave monitors, pulse analyzers, time-series charts.
    *   **Right Column:** Secondary data metrics, pie/radial status rings, spatial/network diagnostics.
    *   **Bottom Tier:** Comparative radial dials, micro-charts, subsystem status grids, live event logs.
*   **Spacing & Gaps:** Tight, highly dense spacing (`8px` to `16px` gaps) to mimic military/sci-fi terminal interfaces.

---

## 2. Color Palette & Lighting

The design utilizes a high-contrast dark mode with high-saturation neon glows to simulate laser/plasma interfaces.

| Token | Hex Value | Role / Usage |
| :--- | :--- | :--- |
| **Canvas Base** | `#03020A` | Deep space black/dark purple background |
| **Primary Core** | `#3B1A78` to `#7F22FE` | Central core illustration gradients, container shadows |
| **Neon Violet** | `#BF40FF` | Primary headers, active states, key accents |
| **Cyan Glow** | `#00F0FF` | Secondary accents, data highlights, technical readouts |
| **Magenta/Pink**| `#FF2A6D` | Critical alerts, thresholds, warning pulses |
| **Text Primary**| `#E0D9FF` | Main labels, alphanumeric readouts |
| **Text Muted**  | `#6B5E99` | Secondary labels, disabled states, grid lines |

### Lighting & Effects
*   **Glow Effect (Box-Shadow / Drop-Shadow):** Extensively used on active elements. 
    *   *Cyan Elements:* `box-shadow: 0 0 12px rgba(0, 240, 255, 0.4);`
    *   *Violet/Magenta Elements:* `box-shadow: 0 0 15px rgba(191, 64, 255, 0.5);`
*   **Gradients:** Linear and radial gradients on icons, progress bars, and background glows to create a volumetric, lit-from-within appearance.

---

## 3. Typography & Font Stack

To achieve the precise futuristic cyber aesthetic, lean towards geometric sans-serif typefaces with technical monospaced numbers.

*   **Primary Font Family (Headings & UI Labels):** 
    *   `"Rajdhani"`, `"Orbitron"`, or `"Eurostile"`
    *   *Fallback:* `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
*   **Monospace Font Family (Data, Numbers, Metrics):**
    *   `"Share Tech Mono"`, `"JetBrains Mono"`, or `"Courier New"`
    *   *Fallback:* `Consolas, Monaco, monospace`

### Typographic Hierarchy
*   **Main Clock / Core ID:** `32px` / Bold / Monospace / Cyan-to-White gradient.
*   **Section Headers:** `14px` / Semi-Bold / All-Caps / Neon Violet / Letter-spacing: `1.5px`.
*   **Data Readouts / Values:** `18px` to `24px` / Bold / Monospace / High contrast.
*   **Body / Sub-labels:** `10px` to `12px` / Regular / Muted Violet-Grey.

---

## 4. Component Breakdown & Micro-Design

### A. Header & Central Core Module (Top Center)
*   **Central Illustration:** A stylized abstract neural/vortex core rendered in neon violet and electric blue. Features layered translucent vectors with pulse opacity animations.
*   **Top Bar Clocks:** Digital countdown/countup timer flanked by glowing curved brackets (`[` and `]`).
*   **Status Badges:** Small pill-shaped containers with 1px borders, filled with a 10% opacity background glow.

### B. Left Data Panels (Diagnostics & Telemetry)
*   **Structure:** Vertical stack of framed cards with notched corners (clipped polygon paths: `polygon(0 0, calc(100% - 8px) 0, 100% 8px, 100% 100%, 0 100%)`).
*   **Content:** 
    *   Linear level indicators (segmented progress bars that glow when active).
    *   Numerical matrices with alternating row opacities.

### C. Center Waveform & Chart Area
*   **Waveform Graph:** A continuous smooth bezier curve line graph representing real-time frequency or signal fluctuation.
    *   *Stroke:* `2px` solid neon violet with a soft drop-shadow blur.
    *   *Fill:* Semi-transparent gradient fade from the line down to the axis baseline (`rgba(191, 64, 255, 0.2)` to `transparent`).
*   **Grid Lines:** Subtle dashed horizontal and vertical grid lines in dark slate blue (`#1A1433`).

### D. Right Metrics & Radial Rings
*   **Radial Progress Dials:** Circular SVG stroke-dasharray progress circles.
    *   *Track:* Thin dashed grey ring.
    *   *Indicator:* Solid glowing cyan or magenta arc with rounded line caps.
*   **Data Readouts:** Percentage indicators centered inside the radial rings in bold monospace font.

### E. Bottom Tier (Subsystem Dials & Log Matrix)
*   **Multi-Dial Row:** A series of 6 identical circular metric gauges aligned horizontally. Each contains an internal vertical bar chart or circular progress meter with distinct color accents (Cyan/Violet).
*   **Terminal Log Box:** Bottom-aligned micro-text console displaying scrolling system logs in monospace font with alternating timestamp tags.

## 5. Animation & Motion Design Specs

To bring this interface to life, the UI must incorporate subtle, continuous sci-fi animations:

1.  **Core Pulse (Central Illustration):**
    *   *Property:* `transform: scale(1 to 1.03)` + `opacity: 0.8 to 1.0`
    *   *Duration:* `3s` infinite ease-in-out alternate.
2.  **Waveform Live Stream:**
    *   *Behavior:* Horizontal translation or dynamic SVG path morphing to simulate live telemetry data feeding into the chart.
3.  **Neon Glow Failsafe (Pulse):**
    *   *Property:* Box-shadow intensity pulsing on critical alert badges.
    *   *Duration:* `1.5s` infinite ease.
4.  **Data Refresh Flicker:**
    *   *Behavior:* Random micro-opacity flickers (`0.95` to `1.0`) on numeric readouts every few seconds to mimic active data streams.
5.  **Scanline Overlay (Optional Retro Touch):**
    *   *Effect:* A very faint, semi-transparent horizontal striped overlay spanning the entire screen moving downwards slowly (`keyframes scanline`).
