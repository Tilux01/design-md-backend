# Lotek Perkedel Interactive Kitchen Wall Design System

## Overview
This design system specifies the interactive projected UI shown on a kitchen wall, demonstrating a smart-home culinary interface. The UI features dish showcases, chef profiles, interactive navigation, and voice-control integration.

---

## Typography

### Primary Font Family
- **Font:** Inter (or system sans-serif fallback)
- **Weights Used:**
  - Regular (`400`) — Body text, descriptions, captions
  - Medium (`500`) — Navigation labels, chef names, ratings
  - Bold (`700`) — Headings, dish titles, key metadata

---

## Layout & Color Palette

- **Background:** Clean neutral wall / minimalist kitchen aesthetic.
- **UI Canvas:** Frosted glass / translucent white panels (`rgba(255, 255, 255, 0.85)`).
- **Primary Text:** Dark charcoal / near-black (`#1A1A1A`) for high contrast readability.
- **Accent Colors:** Soft peach/coral tones in background header graphics (`#E6B8AD`), and gold/yellow for star ratings (`#F5A623`).

---

## UI Components & Structure

### 1. Header & Navigation (Top Bar)
- **Left:** `#1 street food disk` (small uppercase subtitle).
- **Center/Right:**
  - Search icon (magnifying glass)
  - Menu icon (hamburger menu)

### 2. Main Hero Showcase (Center Left)
- **Dish Image:** Large overhead plate photography with a subtle drop shadow.
- **Dish Title:** Huge bold typography (**LOTEK PERKEDEL**, etc.).
- **Action Buttons:**
  - ▶ `Play video`
  - 🛒 `Order food`

### 3. Chef & Recipe Card (Right Side Panel)
- **Tabs:** `Overview` | `Ingredients`
- **Rating:** Large numeric score (e.g., `4.9`) with yellow star indicator.
- **Chef Profile:** Circular avatar with Chef name (**Chef Feny**).
- **Description:** Two lines of descriptive text in Indonesian regarding the dish preparation.

### 4. Dish Carousel / Selection Tray (Bottom Left)
- Horizontal thumbnail scroll featuring alternative dishes:
  - *Tahu Lontong*
  - *Lamb Steak Potato*
  - *Martabak Pak Adin*
  - *Urur Asli Wonogiri*
- Active item is highlighted with a circular frame and active indicator dot.

### 5. Quick Action Toolbar (Bottom Center)
- Iconography row for quick utilities:
  - Cutlery / Dining icon
  - Fork & Spoon icon
  - User / Profile icon
  - Heart / Favorites icon
- **Microphone / Voice Search Icon:** Centered prominently with a glowing animation pulse indicating active voice input readiness.

---

## Animations & Transitions

- **Carousel Slide:** Smooth horizontal sliding transition when switching between dishes (Lotek Perkedel ➔ Lamb Steak Potato ➔ Pak Adin ➔ Urur Asli).
- **Fade Transitions:** Subtle opacity fade between UI states when selecting a new recipe.
- **Voice Pulse:** Continuous subtle pulsing animation around the microphone icon at the bottom center.
