# UI Implementation Blueprint: CSS Animations Guide

## 1. Global Layout & Typography

*   **Background Color**: Deep navy blue (`#101726` or similar dark theme gradient)
*   **Font Family**: Inter,system-ui, -apple-system, sans-serif
*   **Primary Text Color**: Pure white (`#ffffff`)
*   **Accent/Brand Color**: Cyan (`#00f2fe`) for icons, titles, and simulated UI code blocks.
*   **Layout Structure**: Full-screen view, vertical scrolling feed with a sticky header.

---

## 2. Component Blueprint

### A. Header Component
*   **Content**: Large bold title reading "CSS Animations" with a vibrant cyan gradient effect on the text.
*   **Alignment**: Left-aligned at the top of the viewport with ample vertical padding.

### B. Animation Showcase Container (`.showcase-card`)
A repeated vertical card element containing:
1.  **Visual Demo Area**: A glowing cyan rounded-square `.box` executing a specific CSS keyframe animation continuously.
2.  **Code Snippet Box**: A dark VS Code-like window displaying the matching CSS code.

#### 1. Code Window Styling (`.code-editor`)
*   **Background**: Darker slate (`#0B101D`)
*   **Border Radius**: `12px`
*   **Header Bar**: Three macOS-style dots (Red, Yellow, Green) on the left, file name (`.css`) centered/left-aligned.
*   **Syntax Highlighting**:
    *   Selectors/Properties (`.box`, `animation`, `transform`): White/Light Gray
    *   Values (`3s`, `infinite`, `rotate(360deg)`): Cyan/Light Blue
    *   Percentages (`0%`, `50%`, `100%`): Purple/Pink tone

---

## 3. CSS Animations & Keyframes Reference

### Example 1: Rotate
```css
.box { animation: rotate 3s infinite; }
@keyframes rotate {
  0% { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}
```

### Example 2: Pulse
```css
.box { animation: pulse 2s infinite; }
@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.2); }
}
```

### Example 3: Slide In
```css
.box { animation: slideIn 2s infinite; }
@keyframes slideIn {
  0% { transform: translateX(-50%); }
  50% { transform: translateX(0); }
  100% { transform: translateX(50%); }
}
```

### Example 4: Fade In
```css
.box { animation: fadeIn 2s infinite; }
@keyframes fadeIn {
  0% { opacity: 0; }
  50% { opacity: 1; }
  100% { opacity: 0; }
}
```

### Example 5: Bounce
```css
.box { animation: bounce 2s infinite; }
@keyframes bounce {
  0% { transform: translateY(0); }
  40% { transform: translateY(-20px); }
  60% { transform: translateY(-10px); }
}
```
