# Design Specification: NEURA Landing Page Clone

This document provides a highly detailed specification for creating an exact, pixel-perfect, full-screen clone of the **NEURA** landing page. 

---

## 1. Design System & Aesthetics

### Visual Style
* **Theme:** Futuristic, minimalist, ultra-clean, high-tech, and human-centric.
* **Canvas Style:** Full-viewport (`100vh` height), stretching to the edges of the browser window. The design utilizes a layered look with floating white cards on a soft, light-grey background.
* **Depth & Shadows:** Soft, highly diffused drop shadows (`box-shadow`) are used on container elements to create a subtle sense of elevation.

### Color Palette
| Color Role | Hex Code | Usage |
| :--- | :--- | :--- |
| **Canvas Background** | `#F3F4F6` to `#EAECEF` | Subtle, soft grey-to-blue gradient spanning the background of the viewport. |
| **Card Background** | `#FFFFFF` | Used for the white floating content containers. |
| **Text Primary** | `#0E1111` | Jet black; used for main headings, active UI states, and major labels. |
| **Text Secondary** | `#6B7280` | Muted slate grey; used for body copy, subheaders, and metadata. |
| **Accent Glow** | `#4AD2FF` | A soft, luminous cyan/neon blue; used for UI accents and robot indicators. |
| **Rating Stars** | `#F9A825` | Warm amber/yellow for product review stars. |

### Typography
* **Primary Font Family:** `Plus Jakarta Sans` or `Satoshi` (Geometric, clean, modern Sans-serif).
* **Fallback Stack:** `System-UI, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
* **Sizing & Hierarchy:**
  * **Brand Logo:** `24px` (`1.5rem`), Semi-Bold, heavy tracking (`letter-spacing: 0.15em`), uppercase.
  * **Hero Subtitle:** `12px` (`0.75rem`), Bold, extreme tracking (`letter-spacing: 0.2em`), uppercase.
  * **Hero Headline:** `64px` (`4rem`), Bold, tight line-height (`line-height: 1.05`), letter-spacing: `-0.02em`.
  * **Card Headings:** `24px` (`1.5rem`), Semi-Bold, line-height: `1.2`.
  * **Body Text / Labels:** `14px` (`0.875rem`) to `16px` (`1rem`), Regular or Medium, line-height: `1.5`.

---

## 2. Layout & Grid Architecture

The page is structured as a **three-column flex/grid container** inside a main container padding box of `40px` (or `2.5rem`) on all sides, ensuring full-height coverage (`height: 100vh; overflow: hidden;`).

```
+---------------------------------------------------------------------------------+
|                                     HEADER                                      |
+---------------------------------------------------------------------------------+
|                                                                                 |
|  [COLUMN 1: HERO CONTENT]       [COLUMN 2: ROBOT]      [COLUMN 3: TECH SPECS]   |
|  - Subtitle                     - Large, centered      - Reviews (Top)          |
|  - Main Headline                  3D Render            - Detailed Specs Card    |
|  - Paragraph Description          (Layered depth)        (Bottom)               |
|  - "X1" Float Card (Bottom)                                                     |
|                                                                                 |
+---------------------------------------------------------------------------------+
```

### C. Column 2: Center Robot Image Render
* **Placement:** Positioned in the center of the viewport. Must overlap slightly with the left card and the right tech card using z-index layers.
* **Asset Specifications:**
  * **File Type:** High-resolution PNG format with a fully transparent background.
  * **Orientation & Pose:** The robot is captured in a vertical crop from the upper thighs up. The torso is angled in a three-quarter profile facing left, while the head is turned slightly back toward the front-left viewer.
  * **Visual Design Details:**
    * **Materials:** High-gloss white polished ceramic/polycarbonate outer body plates, contrasted with matte black articulated carbon-fiber joints and neck cables.
    * **Head:** Sleek, black glass dome faceplate styled like a smooth visor. Features a thin, glowing neon-white horizontal LED horizontal slit near the temple. The ear area is characterized by a circular ring glowing with soft cyan-blue LED light.
    * **Torso:** The white chest plate features the word "NEURA" subtly printed on the upper right breast in a black sans-serif typeface. A thin, horizontal cyan LED light strip glows on the center-left chest.
    * **Left Arm/Shoulder:** Features a prominent white rounded shoulder armor piece bearing a small vertical block of black text: `"X1 / PEOPLE / IDEAS / PROGRESS"`.
    * **Hands:** Semi-visible at the bottom, with precision-jointed black fingers tipped with white back-plates.
  * **Lighting:** Studio-quality key lighting from the upper left, casting soft, diffused shadows across the robot’s chest and back-plate to establish dynamic depth.

## 4. UI Polish & Interactive States

* **Hover Effects:**
  * **Buttons:** Main navigation items smoothly fade to `#0E1111` upon hover. The black pill buttons scale up slightly (`transform: scale(1.03)` with a ease-in-out transition).
  * **Action Cards:** Both white floating cards feature a very slight hover lifting motion (`transform: translateY(-4px)`) and a subtle increase in shadow depth to emphasize interactive tactile elements.
* **Transition Timings:**
  * Use a global timing function of `transition: all 0.3s cubic-bezier(0.16, 1, 0.3, 1);` for fluid, high-end response times on all interactive components.
