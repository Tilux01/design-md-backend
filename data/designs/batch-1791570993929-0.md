# Design Specification: Profile Card Component

This document provides the exact design specifications for creating a pixel-perfect implementation of the profile cards shown in the reference image. The implementation should be responsive and fill the full screen width/height while centering the content area.

---

## 1. Global Layout & Canvas

*   **Background Color**: Light neutral grey (`#F5F5F5` or similar soft off-white).
*   **Layout Structure**: Centered flex container holding one or more profile card components side-by-side (or stacked on mobile).
*   **Card Dimensions**:
    *   **Width**: Fixed at approx. `360px` per card.
    *   **Border Radius**: `32px` outer card border radius.
    *   **Background Color**: Pure White (`#FFFFFF`).
    *   **Box Shadow**: Soft, multi-layered diffuse shadow for depth (`0px 20px 40px rgba(0, 0, 0, 0.06)`).

---

## 2. Typography & Fonts

*   **Primary Font Family**: Inter, SF Pro Display, or system sans-serif.
*   **Fallback Font Stack**: `font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;`

### Text Hierarchies:
1.  **Card Header Button ("Follow")**:
    *   Size: `14px`
    *   Weight: Medium (`500`)
    *   Color: Dark Charcoal (`#1A1A1A`)
2.  **Profile Name ("Noah Thompson")**:
    *   Size: `22px`
    *   Weight: Bold (`600` / `700`)
    *   Color: Near Black (`#111111`)
3.  **Bio Description ("Product Designer who focuses on simplicity & usability.")**:
    *   Size: `13px` / `14px`
    *   Weight: Regular (`400`)
    *   Line Height: `1.4`
    *   Color: Medium Grey (`#6B6B6B`)
4.  **Metric Numbers (72.9K, 828, 342.9K)**:
    *   Size: `16px`
    *   Weight: Semi-bold (`600`)
    *   Color: `#111111`
5.  **Metric Labels (Likes, Posts, Views)**:
    *   Size: `12px`
    *   Weight: Regular (`400`)
    *   Color: `#8C8C8C`

---

## 3. Component Breakdown (Left vs. Right Card Variations)

Both cards share the same structural anatomy, with minor variations in the header and metrics container.

---

### A. Header / Cover Image Area
*   **Dimensions**: Height approx. `160px`, full card width.
*   **Border Radius**: Top corners curved to match card (`32px`), bottom corners flat.
*   **Image Description**: A photographic background depicting a soft, bright blue sky filled with gentle, fluffy white cumulus clouds during daytime.
*   **Action Element (Top Right)**:
    *   *Left Card*: Pill-shaped button containing the text "Follow" and a `+` icon. Background: Semi-transparent white / frosted glass effect with soft shadow. Padding: `8px 16px`. Border radius: `20px`.
    *   *Right Card*: Circular icon button containing a `+` symbol. Size: `36px × 36px`. Background: Solid white with soft shadow. Border radius: `50%`.

---

### B. Avatar / Profile Picture
*   **Positioning**: Overlapping the boundary between the cover image and the white content area (centered horizontally).
*   **Dimensions**: Approx. `88px × 88px`.
*   **Border**: Solid white circular border (`4px` width) acting as a separation buffer.
*   **Image Description (Avatar)**: A 3D render illustration of a young male character with short brown hair, wearing round wire-rimmed glasses, an orange strap crossing his dark grey shirt, and a neutral, calm facial expression against a neutral grey circular backdrop.
*   **Variant Detail (Right Card Only)**: Surrounded by a vibrant circular gradient border (transitioning from purple to pink, orange, and green, resembling an Instagram-style story ring).

---

### C. Experience Indicator (Left Card Only)
*   **Positioning**: Placed directly below the avatar area, right-aligned or centered above the name.
*   **Content**: Text label "exp." followed by a segmented visual progress bar consisting of alternating purple and grey vertical ticks indicating level progress.

---

### D. User Information Section
*   **Alignment**: Center-aligned text block.
*   **Spacing**: Generous vertical whitespace separating the avatar from the name and the name from the bio paragraph.

---

### E. Metrics Bar
*   **Layout**: 3-column horizontal grid.
*   **Structure Variations**:
    *   *Left Card*: Divided by thin vertical dividers (`#EAEAEA`). No background container.
    *   *Right Card*: Enclosed inside a unified rounded container (Background: `#F7F7F7`, Border Radius: `16px`, Padding: `12px 0`).
*   **Data Points**:
    1.  `72.9K` / `Likes`
    2.  `828` / `Posts`
    3.  `342.9K` / `Views`

---

### F. Footer / Social Links Bar
*   **Positioning**: Bottom of the card.
*   **Layout**: 3-column evenly spaced flex row.
*   **Icons (Monochrome, `#4A4A4A`, size `20px`)**:
    1.  Instagram Outline Icon (`@`)
    2.  X / Twitter Logo (`𝕏`)
    3.  Threads / Custom Social Icon (`🌐` or `@` symbol)
*   **Dividers**: Thin light-grey vertical borders (`1px`) separating the three icon buttons.

---

## 4. Implementation Guidelines
1.  Use **CSS Flexbox** or **Grid** for aligning metrics and social icons.
2.  Ensure all interactive elements (Follow button, social links) include subtle hover states (e.g., slight scale up or background opacity shift).
3.  Maintain exact padding and margin proportions to preserve the clean, modern minimalist aesthetic of the UI.
