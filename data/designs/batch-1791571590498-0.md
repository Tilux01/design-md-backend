# Design Specification: Arion E-Commerce Account Page

This document provides the exact design specifications for building a pixel-perfect, full-screen clone of the Arion E-Commerce Account Dashboard.

---

## 1. Global Styles & Layout Structure

### **Layout Configuration**
*   **Viewport:** Full screen width (`100vw`) and height (`100vh`), non-scrolled or standard vertical scroll container.
*   **Grid Structure:** Two-column master layout.
    *   **Sidebar (Left):** Fixed width (approx. `260px`).
    *   **Main Content Area (Right):** Fluid width (`flex: 1`), containing the top header, breadcrumb, and a multi-card dashboard grid.
*   **Background Colors:**
    *   Main App Background: `#f4f6f9` (Light cool grey)
    *   Cards / Containers: `#ffffff` (Pure white) with rounded corners (`border-radius: 12px` to `16px`) and subtle drop shadows (`box-shadow: 0 4px 20px rgba(0, 0, 0, 0.03)`).
    *   Sidebar Background: `#ffffff` with a right-side light border (`1px solid #edf0f5`).

### **Typography & Fonts**
*   **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif.
*   **Fallback Font:** Arial, Helvetica, sans-serif.
*   **Text Weights:**
    *   Regular (400): Body text, metadata, labels.
    *   Medium (500): Navigation items, table headers, card titles.
    *   Semi-Bold (600): Main headings, user names, active states, key metrics.
