# Visual Design Specification: Blue Aesthetic Collage

## 1. Global Layout & Document Structure
- **Full-Screen Implementation**: The design must occupy 100% of the viewport width (`100vw`) and height (`100vh`), removing any default margins or paddings (`margin: 0; overflow: hidden;`).
- **Base Layer**: A light grey-blue grid paper background pattern filling the entire viewport to replicate the topmost layer seen in the top-right corner.
- **Layering Architecture (Z-Index Hierarchy)**:
  1. `z-index: 1`: Base grid background.
  2. `z-index: 2`: Bottom-left French newspaper snippet (`.newspaper-layer`).
  3. `z-index: 3`: Main central torn paper featuring a light blue plaid/tartan pattern (`.central-plaid-paper`).
  4. `z-index: 4`: Top-left blue gingham patch with a white ribbon bow (`.top-left-patch`).
  5. `z-index: 5`: Top-right blue flower (`.top-right-flower`).
  6. `z-index: 6`: Bottom-right dark blue torn paper and dual stars (`.bottom-right-decor`).

---

## 2. Color Palette
- **Primary Blue**: `#87CEEB` (Sky Blue - main plaid lines)
- **Secondary Blue**: `#4682B4` (Steel Blue - deeper grid accents)
- **Dark Navy**: `#1A365D` (Bottom torn paper and star outlines)
- **Grid Lines**: `#D3E0EA` (Subtle light blue-grey graph lines)
- **Paper White**: `#F9F9FB` (Textured off-white for torn papers)
- **Text Color**: `#222222` (Dark charcoal for the French newspaper body copy)

---

## 3. Element-by-Element Specifications

### A. Base Grid Background
- **CSS Implementation**: Use a repeating linear-gradient to create graph paper.
  ```css
  background-color: #F0F4F8;
  background-image: 
    linear-gradient(to right, #D8E2EC 1px, transparent 1px),
    linear-gradient(to bottom, #D8E2EC 1px, transparent 1px);
  background-size: 20px 20px;
  ```

### B. Newspaper Snippet (Bottom Left)
- **Positioning**: Absolute, anchored to `bottom: 0; left: 0;`.
- **Content**: Multi-column French prose typography (simulated or actual public domain text).
- **Styling**: 
  - Off-white newsprint paper texture with visible grain.
  - Skewed slightly at an organic angle (`transform: rotate(-3deg);`).

### C. Central Plaid/Tartan Paper
- **Positioning**: Center-aligned, occupying roughly 70% of the viewport.
- **Shape**: Irregular torn-paper edges simulated via CSS `clip-path: polygon(...)` or an SVG mask with a rugged edge filter (`feTurbulence`).
- **Pattern**: 
  - Vertical and horizontal thick stripes in `#87CEEB` overlaid on textured white paper.
- **Texture**: Heavy watercolor/handmade paper texture (achieved via CSS grain overlay or SVG displacement filter).

### D. Top-Left Gingham Patch & Ribbon
- **Positioning**: `top: 0; left: 0;`.
- **Pattern**: Blue and white checkered (gingham) pattern (`background: repeating-linear-gradient(...)`).
- **Ribbon Accent**: A white vector bow icon positioned overlapping the corner of the patch, featuring subtle drop shadows for depth (`filter: drop-shadow(0px 2px 4px rgba(0,0,0,0.15));`).

### E. Top-Right Flower
- **Positioning**: `top: 2%; right: 5%;`.
- **Asset**: 5-petaled soft blue watercolor flower with detailed central stamens.
- **Effects**: Slight drop shadow and organic rotation (`transform: rotate(15deg);`).

### F. Bottom-Right Dark Blue Elements
- **Positioning**: `bottom: 0; right: 0;`.
- **Elements**: 
  - Dark navy torn paper base layer with rough jagged top edge.
  - Two outlined star stickers/cutouts with white borders and dark navy fills, layered over the torn paper.

---

## 4. Typography Specification

### Primary Font (Newspaper Text)
- **Font Family**: `Georgia`, `Times New Roman`, serif
- **Fallback Stack**: `serif`
- **Font Size**: `11px` / `1.2` line-height
- **Weight**: Regular (`400`)
- **Color**: `#2b2b2b`

### Decorative Elements (If any textual stamps/labels are added)
- **Font Family**: `Courier New`, monospace (for typewriter aesthetic)
- **Fallback Stack**: `monospace`

---

## 5. Micro-Interactions & Animation (Optional Polish)
- **Entrance Animation**: 
  - On page load, individual collage elements drop in slightly from random offsets with a subtle fade-in and spring physics effect.
- **Hover Micro-Interactions**:
  - Elements tilt slightly toward the cursor using CSS `transform: rotate(...) scale(1.02)` with a smooth `transition: transform 0.3s ease`.
