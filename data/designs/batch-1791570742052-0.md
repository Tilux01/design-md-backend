# Design Specification: Healthcare Mobile Application

## 1. Global Styles & Design Tokens

### Color Palette
- **Primary / Deep Navy:** `#0a192f` (Dark UI backgrounds, major headers, and bottom bar)
- **Secondary / Ocean Blue:** `#1d4ed8` or `#2563eb` (Primary brand accent, buttons, selected states)
- **Soft Blue / Tinted Surface:** `#e0f2fe` or `#eff6ff` (Health metric cards, quick-access icon backgrounds)
- **Background (Light Mode):** `#f8fafc` (App canvas background)
- **Card Background (White):** `#ffffff` (Containers, widgets)
- **Text Primary:** `#0f172a` (Headings, primary labels)
- **Text Secondary / Muted:** `#64748b` (Subtitles, helper text, inactive navigation items)
- **Border / Divider:** `#e2e8f0` (Subtle container outlines)

### Typography
- **Primary Font Family:** `Inter`, `SF Pro Display`, `-apple-system`, `sans-serif`
  - *Fallback:* If `Inter` is unavailable, fall back to system sans-serif fonts (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`).
- **Font Weights Used:**
  - Regular (`400`) - Body copy, descriptions, secondary stats
  - Medium (`500`) - Navigation labels, input placeholders, subsection headers
  - Semi-Bold (`600`) - Screen titles, primary buttons, key data values
  - Bold (`700`) - Main greeting, hero titles

### Corner Radii & Spacing
- **Screen Container:** Full-screen responsive (or mocked with `border-radius: 40px` for presentation views)
- **Cards & Widgets:** `border-radius: 20px` to `24px`
- **Buttons & Pills:** `border-radius: 12px` to `9999px` (Fully rounded pills)
- **Spacing Scale:** Base unit `8px` (`8px`, `12px`, `16px`, `24px`, `32px`)
