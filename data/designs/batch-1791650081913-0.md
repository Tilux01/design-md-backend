# DIGITAL KENSEI — Design Specification (`design.md`)

This document defines the exact layout, typography, color system, UI architecture, components, and asset specifications to reproduce the **NEXON: DIGITAL KENSEI** NFT landing page with 1:1 pixel accuracy across full-width displays.

---

## 1. Color System & Design Tokens

### Primary Palette
*   **Deep Obsidian / Base Dark:** `#060709` (Main hero and stats section background)
*   **Pure Black:** `#000000` (Footer and underlying viewport canvas)
*   **Pure White:** `#FFFFFF` (Middle feature section background, primary hero headlines, contrast stats)
*   **Vibrant Crimson / Cyber Red:** `#E50914` / `#FF1E27` (Accent brand color: "KEN SEI", status badges, graph stroke, icons, focal dots)
*   **Deep Crimson Shade:** `#8B0000` / `#4A080B` (Gradients, chart glow accents)

### Neutral & Secondary Palette
*   **Muted Text Light:** `#8E8F94` (Secondary Japanese text, metadata, descriptions)
*   **Muted Gray (Feature Section):** `#A3A4A8` (De-emphasized second half of the main manifesto headline)
*   **Body Copy Dark (Feature Section):** `#1A1A1A` (Headings inside the white section)
*   **Subtle Gray (Feature Section):** `#5E6065` (Body copy inside the white section)
*   **Border Gray (Dark Mode):** `rgba(255, 255, 255, 0.08)` (Subtle card borders and grid dividers)
*   **Card Dark Background:** `#0D0E12` (Stats cards background color)
*   **Glassmorphism Surface:** `rgba(18, 19, 24, 0.65)` with `backdrop-filter: blur(20px)`

## 2. Typography & Font Stack

### Font Families
1.  **Primary Display & Headlines:**
    *   *Primary:* **Clash Display** or **Syne** (Weights: 700 Bold, 800 ExtraBold)
    *   *Fallbacks:* `'PP Neue Montreal', 'Neue Haas Grotesk Display Pro', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
2.  **Body Text, Labels & UI Data:**
    *   *Primary:* **Inter** or **Space Grotesk** (Weights: 400 Regular, 500 Medium, 600 SemiBold)
    *   *Fallbacks:* `'Helvetica Neue', Helvetica, Arial, sans-serif`
3.  **Japanese Typography (Kanji / Katakana):**
    *   *Primary:* **Noto Sans JP** or **Zen Kaku Gothic New** (Weights: 400 Regular, 700 Bold)
    *   *Fallbacks:* `'Hiragino Sans', 'Hiragino Kaku Gothic ProN', Meiryo, sans-serif`
4.  **Monospace / Technical Codes:**
    *   *Primary:* **JetBrains Mono** or **Space Mono** (Weight: 400 Regular)

---

## 3. Global Layout Structure

*   **Viewport Canvas:** Full-width (`100vw`), strictly no outer borders or browser frames.
*   **Max Content Width:** `1440px` (centered with fluid horizontal padding `clamp(24px, 5vw, 80px)`).
*   **Vertical Flow:**
    1.  **Hero Section:** Full viewport height, dark cybernetic aesthetic with layered typography and visual samurai focus.
    2.  **Manifesto & Features Section:** Large rounded white container with pill-curved top edges (`border-top-left-radius: 64px`, `border-top-right-radius: 64px`), high-contrast light theme.
    3.  **Metrics & Statistics Section:** Deep obsidian background with subtle perspective wireframe grid, containing a 3-column metric dashboard.

## 6. Micro-Interactions & Animation Guidelines

1.  **Hero Title Reveal:**
    *   Split-text staggered slide-up animation (`opacity: 0 -> 1`, `translateY: 40px -> 0px`, ease: `cubic-bezier(0.16, 1, 0.3, 1)` duration: `0.8s`).
2.  **Floating Sakura Petals:**
    *   Light particle physics drifting downward and to the right across the hero viewport (`animation: drift 12s linear infinite`).
3.  **Mythic Card Pulse:**
    *   The red notification dot on the Mythic Tier pill glows with a continuous subtle breath animation (`box-shadow: 0 0 0 0 rgba(255, 30, 39, 0.7)` expanding to `0 0 0 8px rgba(255, 30, 39, 0)`).
4.  **Stat Numbers Count-Up:**
    *   Numbers (`180+`, `3 Tiers`, `500+`, `200+`) trigger a rapid rolling counter on viewport intersection.
5.  **Hover States on Cards:**
    *   Metric cards smoothly elevate with a border highlight shift: `border-color: rgba(255, 255, 255, 0.2)` and a soft red ambient back-glow.
