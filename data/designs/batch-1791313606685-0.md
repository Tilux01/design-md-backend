# 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Brand Archetype**: Fintech Neobank / Modern Consumer Wealth Management. Clean, trustworthy, accessible, yet highly sophisticated.
- **Visual Density**: Medium-High. Neumorphic-influenced flat minimalism with distinct separation of card modules, maintaining strict hierarchy and breathing room.
- **Whitespace Balance**: Generous vertical rhythm using consistent spacing increments (8px grid system). Interior component paddings average 16px to 24px, while outer viewport bounds maintain balanced gutters.
- **Theme Balance**: Predominantly Light Mode UI (`#F2F4F7` background with `#FFFFFF` card surfaces), featuring a sleek dark mode card surface component (`#1C1F21`) for high-contrast contrast balance and debit/credit card realism.

# 3. Typography System & Hierarchy

- **Font Family**: Inter, SF Pro Display, -apple-system, sans-serif (System UI Stack).
- **Scale Breakdown**:
  - **Screen Header / Balance**: 32px (2rem), Font Weight: 700 (Bold), Line-Height: 1.1, Tracking: -0.03em.
  - **Section Title / Card Name**: 18px (1.125rem), Font Weight: 600 (Semi-bold), Line-Height: 1.3, Tracking: -0.01em.
  - **Body / List Items**: 14px (0.875rem), Font Weight: 500 (Medium), Line-Height: 1.4, Tracking: normal.
  - **Caption / Metadata**: 12px (0.75rem), Font Weight: 400 (Regular), Line-Height: 1.4, Tracking: 0.01em.
  - **Monospace Financial Amounts**: Inter tabular-nums, 16px/14px, Font Weight: 600.

# 4. Layout Architecture & Spatial Grid

- **Container Max-Width**: Mobile viewport constrained (`max-width: 414px`, `min-height: 896px`).
- **Padding & Margin Scale**: 
  - Screen Padding: 20px horizontal, 16px vertical safe areas.
  - Component Gaps: 12px (grid cards), 16px (list stack).
- **Section Sequence (Dashboard View)**:
  1. Status Bar & Greeting Header (User avatar, name, notification bell).
  2. Savings Account Number & Total Balance Widget with visibility toggle.
  3. Quick Actions 2x2 Grid (Send Money, Airtime/Data, Pay Bills, Cards).
  4. Transaction History Section (Header with "See all" link + 3 item rows).
  5. Fixed Floating Bottom Navigation Bar (Home, Cards, Analytics, Settings).
- **Stacking Order (Z-Index)**:
  - Base Canvas: `z-0`
  - Cards & Content Blocks: `z-10`
  - Sticky Navigation / Floating Elements: `z-50`

# 7. Accessibility (a11y) & WCAG Contrast Audit

- **Contrast Compliance**:
  - Primary Text (`#111827`) on White Surface (`#FFFFFF`): **16.5:1** (Passes WCAG AAA)
  - Secondary Text (`#4B5563`) on White Surface (`#FFFFFF`): **7.4:1** (Passes WCAG AAA)
  - Muted Text (`#9CA3AF`) on White Surface (`#FFFFFF`): **2.8:1** (Fails for body text, restricted to decorative captions/labels only).
  - Primary Button Text (`#FFFFFF`) on Primary Background (`#2563EB`): **4.6:1** (Passes WCAG AA).
- **Focus Ring Specifications**:
  ```css
  *:focus-visible {
    outline: 2px solid #2563EB;
    outline-offset: 2px;
  }
  ```
