# Design System: TRUSDO Web-Designer Landing Page

## 1. Global Styles & Theme

### Theme
- **Dark Mode Only**: The entire design is built on a dark, textured charcoal background with stark white typography.

### Colors
- **Background (Base)**: `#1e1e1e` (Dark Charcoal with subtle grain/noise texture)
- **Primary / Text (White)**: `#ffffff`
- **Secondary / Muted Text (Gray)**: `#8c8c8c`
- **Card / Form Background**: `#252525` (slightly lighter charcoal for contrast)
- **Input Borders / Lines**: `#404040`

### Typography
- **Font Family**: Montserrat (Sans-Serif)
- **Weights Used**: Regular (400), Medium (500), Bold (700)

#### Type Scale
- **Main Heading (Hero Name)**: 72px / Bold / Uppercase / Letter-spacing: 2px
- **Section Heading (Projects / Contact / Footer)**: 28px - 36px / Bold / Uppercase
- **Subheading (Hero Role / Section Title)**: 14px / Regular / Uppercase / Letter-spacing: 1px
- **Body Text**: 13px / Regular / Line-height: 1.6 / Muted Gray color (`#8c8c8c`)
- **Small / Meta Text (Scroll, Year)**: 10px / Uppercase / Letter-spacing: 2px

---

## 2. Layout & Structure

- **Container Max-Width**: 1200px (Centered horizontally)
- **Layout Type**: Single-page vertical scrolling landing page layout composed of distinct full-width sections.
- **Spacing System**: Consistent padding (60px vertical, 80px horizontal per section).

---

## 3. Component Breakdown

### A. Navigation Bar (Header)
- **Position**: Sticky or absolute top of each section.
- **Height**: 80px
- **Elements**:
  - **Logo**: "TRUSDO" (Bold, 16px, White, Uppercase)
  - **Menu Links**: "PROJRCTS" (spelled with a typo in original design, maintain as is or fix), "CONTANT" (spelled with typo, maintain as is).
  - **Style**: Right-aligned, uppercase, 12px, Muted Gray with hover effect to White.

---

### B. Section 1: Hero
- **Background**: Dark charcoal gradient (`linear-gradient(135deg, #2b2b2b 0%, #181818 100%)`)
- **Content Elements**:
  - **Pre-title**: "I AM" (10px, uppercase, letter-spacing: 2px, muted)
  - **Main Title**: "TRUSDO" (72px, bold, white, centered or left-aligned depending on layout style)
  - **Role Subtitle**: "A SPECIAL WEB-DESIGNER" (12px, letter-spacing: 2px, white)
  - **Social Icons**: Vertical stack of 3 minimal circular/outlined icons on the left (Instagram, Dribbble, Twitter/X equivalents).
  - **Scroll Indicator**: Vertical text "SCROLL" with a small tick line on the right edge.

### C. Section 2: Projects / Portfolio Showcase
