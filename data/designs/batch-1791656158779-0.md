# UI/UX Specification: Mobile App Design (Casino/Social Hybrid Interface)

## 1. Global Layout & Document Structure
* **App Context:** Dual-view mockup showing two distinct dark-mode mobile screens (Left: Casino/Live Stream Hub; Right: User Profile & Feed).
* **Viewport Dimensions:** Standard modern smartphone ratio (approx. 390x844pt / iPhone 14/15 Pro frame).
* **Color Palette:**
  * **Dominant Background:** Pitch Black (`#0A0A0A` to `#121212`)
  * **Glassmorphism/Surfaces:** Translucent dark overlays (`rgba(255, 255, 255, 0.05)` to `rgba(255, 255, 255, 0.12)`) with backdrop blur (`blur(20px)`).
  * **Primary Accents:** Vibrant Neon Orange (`#FF5C00` / `#FF7A00`), Electric Blue (`#00C2FF`), and Hot Pink/Purple gradients.
  * **Text Colors:** Primary White (`#FFFFFF`), Secondary Muted Grey (`#8E8E93`), Dark Input text (`#1C1C1E`).
* **Typography Hierarchy:**
  * **Primary Font Family:** Inter, SF Pro Display, or system sans-serif fallback (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`).
  * **Font Weights:** Regular (400), Medium (500), Semibold (600), Bold (700).

## 4. Design Token Summary (Quick Reference for CSS/Tailwind)

* **Background Color:** `bg-[#0B0B0C]`
* **Surface Glass:** `bg-white/10 backdrop-blur-xl border border-white/10`
* **Primary Accent:** `text-[#FF5C00]` / `bg-[#FF5C00]`
* **Secondary Text:** `text-[#8E8E93]`
* **Border Radius:** 
  * Cards: `rounded-2xl` (16px - 24px)
  * Buttons/Pills: `rounded-full`
  * Avatars: `rounded-full`
