# UI Design & Implementation Specification: Nike Hyperflux 90+ Product Page

This document provides a comprehensive design and implementation specification for the "Nike Hyperflux 90+" e-commerce product card interface shown in the source media. The specification is structured for a full-screen, immersive web implementation, removing any standalone UI "device frames" from the original mockup.

---

## 1. Global Layout & Canvas

### 1.1 Viewport & Composition
*   **Layout Structure:** A full-screen horizontal flex/grid layout with three primary content zones:
    1.  **Left Sidebar (People Also Views):** Fixed-width recommendation panel (`~320px`).
    2.  **Center Card (Hero Product Showcase):** The dominant, elevated product display card (`~580px` width) with soft drop shadows and rounded corners (`border-radius: 28px`).
    3.  **Right Sidebar (Pricing & Variant Selection):** Interactive configuration panel (`~360px`).
*   **Background:** 
    *   Linear or radial gradient transitioning smoothly from a deep indigo-violet (`#241f45`) on the left to a warm burgundy/coral-red (`#8a323a`) on the right.
    *   CSS Approximation: `background: linear-gradient(135deg, #1b1638 0%, #3a223f 40%, #7e2d36 75%, #9b3131 100%);`

---

## 2. Color Palette

| Token / Usage | Hex Code | Description |

---

## 3. Typography & Font Stack

### 3.1 Typefaces
*   **Header / Brand Title ("NIKE HYPERFLUX 90+"):**
    *   *Style:* Distressed, gritty, hand-drawn serif/display aesthetic.
    *   *Primary Font:* **"Bebas Neue"**, **"Anton"**, or a stylized grunge display font like **"Dirty Headline"**.
    *   *Fallback:* `Impact, Haettenschweiler, 'Arial Narrow Bold', sans-serif`.
*   **Subtitles & UI Labels ("ULTRA ESSENTIAL", "PRICE", "SELECT SIZE"):**
    *   *Style:* Clean, tracked-out, uppercase sans-serif.
    *   *Primary Font:* **"Montserrat"**, **"Inter"**, or **"Poppins"** (Weight: `600 Semi-Bold` / `700 Bold`, `letter-spacing: 1px`).
    *   *Fallback:* `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
*   **Numeric Display ("£120", Sizes):**
    *   *Primary Font:* **"Outfit"** or **"Inter"** (Weight: `700 Bold`).
    *   *Fallback:* `Arial, sans-serif`.

---

## 4. Component Breakdown & Specifications

### 4.1 Left Section: "People Also Views"
*   **Header:**
    *   Text: "PEOPLE ALSO VIEWS" (Uppercase, small, muted pink).
    *   Pagination Indicator: `< 1 OF 2 >` (Small, centered horizontally above the items).
*   **Product Thumbnail Cards:**
    *   Container: Rounded glassmorphic cards (`background: rgba(255, 255, 255, 0.05)`, `border-radius: 16px`).
    *   Content: High-end sneaker renders floating on semi-transparent dark purple wells.
    *   State: Hover state elevates slightly with a glowing border ring (`box-shadow: 0 0 15px rgba(255,255,255,0.2)`).

### 4.2 Center Section: Hero Product Card
*   **Header Area:**
    *   Brand/Title: "NIKE HYPERFLUX 90+" (Large display font, dark charcoal).
    *   Subtitle: "ULTRA ESSENTIAL" (Smaller spaced tracking, muted red).
*   **Hero Visual Display:**
    *   Background Element: Large subtle dot-grid pattern (`rgba(0,0,0,0.06)`) arranged in a soft circular burst behind the shoe.
    *   Product Render: 3D rendered futuristic sneaker with glowing translucent orange/yellow air bubbles and metallic silver upper panels.
    *   Carousel Navigation Arrows: Circular white floating buttons with dark blue arrows (`<` and `>`) vertically centered on the left and right edges of the product window.
*   **Thumbnail Row:**
    *   Three small rounded tiles below the main image previewing alternative angles/colorways of the same shoe.
*   **Primary Action Button ("ADD TO CART"):**
    *   Background: Solid coral-red (`#d14d4d`).
    *   Border Radius: `12px`.
    *   Text: White, uppercase, bold (`14px`, letter spacing `0.5px`).
    *   Hover/Active: Subtle scale-up (`scale(1.02)`) and brightness increase.

### 4.3 Right Section: Pricing & Size Selector
*   **Price Display:**
    *   Label: "PRICE" (Small uppercase sans-serif).
    *   Value: "£120" (Large, bold white text, `font-size: 42px`).
*   **Colorway Swatches:**
    *   A row of circular color selection pills.
    *   *Active Swatch:* Dual-tone gradient circle (Blue/Orange) with a soft outer drop shadow/ring indicating selection.
    *   *Inactive Swatches:* Solid pastel/muted tones (Lavender, Teal, Ochre).
*   **Size Selector Grid:**
    *   Label: "SELECT SIZE" (Small uppercase sans-serif).
    *   Layout: 3x2 grid of rounded rectangular tiles.
    *   Sizes: `7`, `7.5`, `8`, `8.5`, `9`, `9.5`.
    *   *Active State (9.5):* Solid crisp white background, dark text (`#1b1924`), prominent drop shadow.
    *   *Inactive States:* Semi-transparent frosted glass style (`background: rgba(255,255,255,0.12)`, text color: white).

---

## 5. Animations & Interactive States

1.  **Hover Transitions:**
    *   All interactive elements (buttons, size tiles, pagination arrows, color swatches) utilize a smooth `transition: all 0.25s cubic-bezier(0.4, 0, 0.2, 1);`.
2.  **Hero Image Carousel / 3D Rotation:**
    *   Clicking the side arrows (`<` / `>`) triggers a slide-fade transition (`opacity: 0` -> `transform: translateX()` -> `opacity: 1`) of the central sneaker render.
3.  **Size Selection:**
    *   Clicking an unselected size tile triggers a micro-interaction scale down-up (`scale(0.95)` -> `scale(1.0)`) while shifting the active background state to the newly chosen tile.
4.  **Add to Cart Feedback:**
    *   Clicking "ADD TO CART" initiates a loading state or success checkmark morph animation within the button container.
