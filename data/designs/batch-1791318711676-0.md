# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Futuristic Editorial Glassmorphism, Luxury Real Estate Platform.
- **Visual Density & Whitespace Ratio**: High airy whitespace surrounding the primary container, balanced by high-density glass panels, floating filter pills, and dense data badges internally.
- **Surface Elevation Model**: Multi-layered glassmorphic depth. Base application shell features a translucent frosted glass backdrop (`backdrop-filter: blur(20px)`), offset by crisp white inner cards with soft white specular top borders, and dark floating accent cards with deep blur shadows (`box-shadow: 0 16px 40px rgba(0, 0, 0, 0.2)`).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Floating glass cards, high-tracking uppercase filter headers, neon-tinted action arrows in circular buttons, backdrop blur filters.
- **Pill Badge Specification**: Padding `6px 16px`, font-size `12px`, font-weight `600`, tracking `0.05em`, border-radius `9999px`, background translucency `rgba(255, 255, 255, 0.7)`, border width `1px` solid white.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;` or `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
  - Arrow Icon (↗) -> Use `&#8599;` or SVG.
