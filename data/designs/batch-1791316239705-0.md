# E-Commerce Mobile Application UI/UX Design Specification

---

## 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Brand Archetype**: Modern minimalist commerce with a warm, lifestyle-oriented, and organic aesthetic. Designed for a home furniture / interior decor retailer.
- **Visual Density**: Clean and airy. Ample whitespace between modular product sections, horizontal carousels, and grid listings to maintain a breathable experience on mobile viewports.
- **Theme Balance**: Light-mode first interface (`#FFFFFF` base canvas) layered with soft pastel backdrops (`#FFF4F0` peach/cream header tints), neutral card surfaces (`#F7F8F9`), and dark slate structural text (`#1A1A1A`).

---

## 2. Color Palette & Design Tokens

### Core Color Roles
- **Primary / Brand**: Coral Orange (`#E85D36`), Hover (`#D44C25`), Active (`#BD3F1C`)
- **Secondary / Accent**: Warm Sage Green (`#4A7C59`), Soft Gold (`#D4AF37`)
- **Backgrounds**: 
  - Canvas Base: `#FFFFFF`
  - Header / Hero Backdrop: `#FAF6F2` (Soft warm peach/cream tint)
  - Card Surfaces: `#F8F9FA`
  - Modal / Overlay Backdrop: `rgba(0, 0, 0, 0.45)` with `backdrop-filter: blur(8px)`
- **Borders & Dividers**: `#E5E7EB` (Gray 200), `#F3F4F6` (Gray 100)
- **Text Colors**: 
  - Primary Headings: `#111827` (Gray 900)
  - Body & Descriptions: `#4B5563` (Gray 600)
  - Muted / Captions: `#9CA3AF` (Gray 400)
  - Inverse Text: `#FFFFFF`

## 4. Layout Architecture & Spatial Grid

- **Container Constraints**: Max-width `430px` (Standard mobile viewport frame emulation).
- **Spacing Scale (8pt Grid derivative)**:
  - `xs`: 4px
  - `sm`: 8px
  - `md`: 12px
  - `lg`: 16px
  - `xl`: 24px
  - `2xl`: 32px
- **Section Sequence (Top to Bottom)**:
  1. Top Promotional Banner & Hero Card (Soft peach background, lifestyle image preview)
  2. Primary Category Quick-Icon Grid (4 columns, rounded tile icons)
  3. Featured Editorial / Room Inspiration Banners (2-column scrollable grid)
  4. Curated Product Tabs / Grid (Filterable catalog with price tags and quick-add indicators)

## 8. Accessibility (a11y) & WCAG Contrast Audit

- **Text Contrast Ratios**:
  - Primary text (`#111827`) on White (`#FFFFFF`): **15.4:1** (Passes WCAG AAA)
  - Body secondary (`#4B5563`) on White (`#FFFFFF`): **7.4:1** (Passes WCAG AA/AAA)
  - Primary button text (`#FFFFFF`) on Brand Coral (`#E85D36`): **4.6:1** (Passes WCAG AA)
- **Focus Ring Specification**:
  ```css
  :focus-visible {
    outline: 2px solid #E85D36;
    outline-offset: 2px;
  }
  ```
