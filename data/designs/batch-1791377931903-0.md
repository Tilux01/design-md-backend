# UI Design Specification: "Welcome to the Jungle" E-Commerce Landing Page

This document provides a comprehensive design specification for recreating the provided bike e-commerce landing page. The goal is to build a full-screen, high-fidelity responsive clone that faithfully captures the color palette, typography, visual hierarchy, and subtle atmospheric animations present in the preview.

---

## 1. Global Layout & Viewport Specifications

*   **View:** Full-Screen / Edge-to-Edge (`width: 100vw`, `height: 100vh`).
*   **Box-Sizing:** `border-box`
*   **Overflow:** `hidden` (to prevent scrollbars and contain background elements).
*   **Grid/Alignment:** Centered hero layout featuring a prominent central product showcase, a layered typographic backdrop, and decorative foreground foliage elements.

---

## 2. Color Palette

The interface relies on an immersive monochromatic green palette spanning deep emerald shadows, vibrant mid-tone greens, and crisp off-white accents.

| Role | Color Name | Hex Code | CSS Variable | Usage |
| :--- | :--- | :--- | :--- | :--- |
| **Background (Base)** | Jungle Emerald | `#1A4B0C` (approx.) | `--bg-jungle` | Page outer background gradient / vignette |
| **Hero Backdrop** | Vivid Lime-Green | `#57B435` | `--hero-bg` | Main card/canvas background |
| **Primary Text** | Forest Shadow / Semi-transparent | `rgba(26, 75, 12, 0.15)` | `--text-backdrop` | Background "WELCOME TO THE JUNGLE" typography |
| **UI Elements / Icons**| Crisp White | `#FFFFFF` | `--ui-white` | Navigation links, hamburger menu, shopping cart |
| **Shadows & Depths** | Deep Black/Green | `rgba(0, 0, 0, 0.35)` | `--drop-shadow` | Bicycle drop shadow on the ground plane |

---

## 3. Typography

The design uses a dual-type system: an ultra-bold, condensed geometric sans-serif for the giant atmospheric backdrop text, and a clean, legible sans-serif for functional UI navigation.

### Primary Display Font (Atmospheric Heading)
*   **Font Family:** *Impact*, *Anton*, *Bebas Neue*, or heavy condensed grotesque (Fallback: `sans-serif`).
*   **Role:** Background watermark text (`WELCOME TO THE JUNGLE`).
*   **Weight:** `900` (Ultra Black/Heavy)
*   **Text Transform:** `uppercase`
*   **Letter Spacing:** `0.05em`
*   **Styling Note:** Rendered with a low opacity overlay to sit seamlessly behind the central product model.

### Secondary UI Font (Navigation & Metadata)
*   **Font Family:** *Inter*, *Roboto*, *Helvetica Neue* (Fallback: `sans-serif`).
*   **Role:** Top navigation links, account details, search inputs.
*   **Weight:** `400` (Regular) to `600` (Semi-Bold)
*   **Font Size:** `14px` - `16px` (Responsive scale)
*   **Color:** `#FFFFFF`

---

## 4. Component Breakdown

### A. Navigation Bar (`header`)
*   **Position:** Absolute top overlay (`top: 0`, `left: 0`, `width: 100%`).
*   **Layout:** Flexbox, `space-between` alignment with generous horizontal padding (`40px`).
*   **Left Element:**
    *   **Hamburger Menu Icon:** Three horizontal white lines (`3 lines`, `2px` height, rounded edges).
*   **Right Elements:**
    *   **Links:** "BIKE ACCESSORIES", "BA", "OUR COMPANY"
    *   **Search/Cart:** Search icon, account icon, shopping bag indicator.
    *   **Color:** Pure White (`#FFFFFF`), hover states transition to `0.7` opacity.

### B. Atmospheric Background Typography ("WELCOME TO THE JUNGLE")
*   **Position:** Centered absolutely behind the bicycle product.
*   **Layout:** Two-line stacked block:
    *   Line 1: `WELCOME`
    *   Line 2: `TO THE JUNGLE`
*   **Styling:**
    *   Extremely large font size (scales fluidly via `vw` units, e.g., `clamp(4rem, 12vw, 14rem)`).
    *   Color: Dark green translucent (`rgba(26, 75, 12, 0.18)`).
    *   Z-index: `1` (Behind bike, above background).

### C. Hero Product: Mountain Bike (`.product-showcase`)
*   **Asset:** High-resolution cutout of a modern black full-suspension mountain bike (side profile view facing left).
*   **Position:** Centered horizontally and vertically within the hero canvas.
*   **Shadow:** Soft elliptical drop shadow underneath the tires to anchor the bicycle onto the green plane (`background: radial-gradient(ellipse at center, rgba(0,0,0,0.4) 0%, transparent 70%)`).
*   **Z-Index:** `2` (Layered above background typography).

### D. Foreground Foliage Elements (`.foliage-layer`)
*   **Elements:** Realistic tropical plant leaves (Monster / Banana leaf style) framing the bottom corners.
*   **Left Foliage:** Large dark green tropical frond anchored to the bottom-left edge (`position: fixed; bottom: 0; left: 0;`).
*   **Right Foliage:** Bright green sunlit tropical foliage clustered on the bottom-right edge (`position: fixed; bottom: 0; right: 0;`).
*   **Z-Index:** `3` (Top layer, overlapping the lower half of the bicycle wheels for atmospheric depth).

---

## 5. Animation & Motion Specifications

To recreate the immersive "living jungle" feel, apply the following CSS keyframe animations:

### 1. Parallax / Subtle Floating (Bicycle)
*   **Effect:** A gentle, continuous vertical bobbing motion to make the bike feel weightless.
*   **Duration:** `4s`
*   **Timing Function:** `ease-in-out`
*   **Iteration:** `infinite`
*   **Keyframes:**
    ```css
    @keyframes floatBike {
      0%, 100% { transform: translateY(0px); }
      50% { transform: translateY(-12px); }
    }
    ```

### 2. Foliage Sway (Wind Effect)
*   **Effect:** Subtle rotation and skewing of the foreground leaves simulating a gentle jungle breeze.
*   **Duration:** `6s`
*   **Timing Function:** `ease-in-out`
*   **Iteration:** `infinite`
*   **Keyframes:**
    ```css
    @keyframes leafSway {
      0%, 100% { transform: rotate(0deg) skewX(0deg); }
      50% { transform: rotate(1.5deg) skewX(-1deg); }
    }
    ```

### 3. Fade-In Entrance (Page Load)
*   **Effect:** Smooth opacity transition and upward slide for all elements upon initial load.
*   **Duration:** `1.2s`
*   **Timing Function:** `cubic-bezier(0.16, 1, 0.3, 1)` (Smooth out).

---

## 6. Responsive Behavior Guidelines

*   **Desktop (`> 1024px`):** Full widescreen experience with edge foliage fully visible and large typography scaled to maximum width.
*   **Tablet (`768px` - `1024px`):** Typography scales down slightly; side foliage scales down to prevent overlapping critical bike geometry.
*   **Mobile (`< 768px`):**
    *   Navigation collapses into a mobile drawer activated by the hamburger menu.
    *   Background text wraps into tighter lines or reduces opacity to maintain contrast with the bicycle.
    *   Foreground foliage scales down and tucks tightly into the bottom corners.
