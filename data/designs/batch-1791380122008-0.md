# VELORA — Artisanal Ice Cream E-Commerce Concept
## Exact UI/UX & Design Specification (Design.md)

This document provides the complete, pixel-accurate design blueprint for cloning the **VELORA** artisanal ice cream web application interface shown in the media. 

---

## 1. Global Specifications & Layout

### **Canvas & Viewport**
* **Layout Type:** Full-width responsive desktop layout (designed around a modern 16:10 or 16:9 viewport ratio).
* **Grid System:** 12-column fluid grid with centered max-width constraints (`max-width: 1440px`).
* **Background Color:** 
  * Primary Canvas Background: `#FBF9F7` (Warm Off-White / Cream)
  * Secondary Card Backgrounds: `#FFFFFF` (Pure White) and Deep Burgundy Accents (`#581D23`).

---

## 2. Typography System

The interface uses an editorial, high-end print style mixing modern clean sans-serif navigation with high-contrast serif headers.

### **Primary Fonts & Fallbacks**
1. **Headline Serif (e.g., "A WORLD OF BERRY.", "WORLD HOIP CHERRY"):**
   * *Primary:* **Bodoni Moda** or **Playfair Display** (High-contrast editorial serif)
   * *Fallback:* `Georgia, Cambria, "Times New Roman", serif`
2. **Body & Navigation (e.g., "Wild fruit, frozen milk...", Nav links):**
   * *Primary:* **Plus Jakarta Sans** or **Inter** (Clean, geometric grotesque sans-serif)
   * *Fallback:* `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`

### **Type Scale & Styles**

## 5. Animations & Interactions (Interactive Specs)

Since the reference image is from a video featuring a `"Wait till the end"` hook, expect the following motion design specs for implementation:

* **Page Load Entrance (Staggered Fade-Up):**
  * Navigation bar drops in instantly (`opacity: 0` to `1`, `translateY(-10px)` to `0`).
  * Hero text fades and slides up with a stagger of `0.1s` per element (`duration: 0.8s`, easing: `cubic-bezier(0.16, 1, 0.3, 1)`).
  * Hero image scales up slightly from `0.95` to `1` with a soft blur-to-crisp transition.
* **Hover States:**
  * **Buttons:** Scale up slightly (`transform: scale(1.03)`) with a subtle drop shadow increase (`box-shadow: 0 10px 25px rgba(0,0,0,0.1)`).
  * **Product Cards:** Zoom image container by `1.05x` using smooth `transform: 0.5s cubic-bezier(0.25, 1, 0.5, 1)`.
  * **Navigation Links:** Underline expand animation from left to right on hover.
* **Scroll-Triggered Animations (GSAP / Framer Motion):**
  * The bottom grid cards (`WORLD HOIP CHERRY`, `HOILY CREAM`) fade up as the user scrolls into the viewport (`IntersectionObserver`).
