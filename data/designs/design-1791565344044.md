# Design Specification: Lordbank Portal Dashboard

## 1. Global Layout & Viewport
- **Canvas Type:** Full-screen responsive web application dashboard.
- **Orientation:** Landscape (Desktop layout).
- **Background Color:** Off-white/light gray (`#F3F4F6` or `#ECEFF1`).
- **Container Structure:** 
  - Left-hand side navigation/sidebar indicators (implied by brand logo top left).
  - Main top navigation bar with tabs and search.
  - Core Workspace split into two main columns:
    - **Left/Center Grid:** Main metrics, user greeting, charts, employee tracking, and hiring statistics.
    - **Right Column:** Financial ledger (Payout monthly: Salaries and incentive) and detailed breakdown cards.

---

## 2. Typography & Font Specifications
- **Primary Font Family:** `Inter`, fallback to `SF Pro Display`, `Roboto`, `Helvetica Neue`, `sans-serif`.
- **Secondary/Heading Font:** Clean, modern geometric sans-serif (e.g., `Plus Jakarta Sans`, `Poppins`, fallback to `sans-serif`).
- **Font Weights Used:**
  - Regular (400): Body text, secondary labels, timestamps.
  - Medium (500): Navigation items, table text, subheadings.
  - Bold (600 / 700): Page titles, key metrics, numeric values, primary buttons.

---

## 3. Color Palette & Theme
- **Backgrounds:**
  - App Background: `#F2F4F8`
  - Card/Container Backgrounds: `#FFFFFF` (Pure white) with soft shadows (`0px 4px 20px rgba(0, 0, 0, 0.03)`).
  - Dark Slate Blue Containers (Bottom right financial summary): `#244158` to `#1D3446` (Gradient or solid dark teal-slate).
- **Text Colors:**
  - Primary Headings: `#111827` (Dark charcoal/near black).
  - Secondary/Muted Text: `#6B7280` (Cool gray).
  - Inverted/Dark Card Text: `#FFFFFF` (White) and `#94A3B8` (Muted light gray).
- **Accent & Status Colors:**
  - **Success / Positive Growth:** `#10B981` (Emerald green for `+0,5%`, `+2,6%`, `Matched`, and `Done` status badges).
  - **Waiting / Pending Status:** `#F59E0B` (Amber/Yellow for pending statuses).
  - **Failed / Error Status:** `#EF4444` (Red for failed transactions).
  - **Primary Brand Accent (Teal/Green):** `#10B981` (Used on active tabs, buttons, and progress indicators).
