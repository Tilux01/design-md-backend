# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: High-Performance Sports Editorial / Dark Mode Glassmorphism with neon athletic accents.
- **Visual Density & Whitespace Ratio**: Structured grid layout with generous canvas framing, balanced asymmetrical content distribution, and high-contrast typography hierarchy optimized for sports analytics and academy branding.
- **Surface Elevation Model**: Layered green gradient field with semi-transparent frosted glass cards (`backdrop-filter: blur(16px)`), crisp 1px subtle white/green borders, and atmospheric emerald/neon glow backdrops.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Neon lime text highlights, glassmorphic panel containers, high-tracking uppercase pill badges, dynamic tennis motion blur trails, and crisp territorial border separations.
- **Pill Badge Specification**: Padding: `6px 14px`, font-size: `12px`, font-weight: `600`, tracking: `0.1em`, border-radius: `9999px`, background: `rgba(212, 255, 0, 0.1)`, border: `1px solid rgba(212, 255, 0, 0.3)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-[#D4FF00] inline-block"></span>`.
