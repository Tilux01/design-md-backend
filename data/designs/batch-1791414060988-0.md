# Design Specification: Mobile App UI/UX Flow

## 1. Global Styles & Design Tokens

### Color Palette
* **Primary (Brand Color):** Deep Indigo / Violet (`#4F378B` or `#5A3E96`) – Used for primary CTA buttons, active states, and key navigational accents.
* **Primary Container / Tints:** Light Lavender (`#EADDFF` / `#F3EDF7`) – Used for selected item backgrounds, search bars, and subtle highlights.
* **Background (Canvas):** Off-white / Pure White (`#F8F9FA` or `#FFFFFF`) – Main screen background to maintain high readability.
* **Surface / Cards:** White (`#FFFFFF`) with subtle shadow/border separation.
* **Text Primary:** Dark Slate / Charcoal (`#1D1B20`) – Headers, primary body copy.
* **Text Secondary:** Muted Gray (`#49454F`) – Subtitles, placeholder text, secondary icons.
* **Borders / Dividers:** Light Gray (`#E0E0E0` or `#CAC4D0`).

### Typography & Fonts
* **Primary Font Family:** **Inter**, with **SF Pro Display** (iOS) and **Roboto** (Android) as seamless system fallbacks.
* **Fallback Chain:** `font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif;`

#### Typography Scale
* **Screen Title / Header:** 20px / 24px line-height, Bold (Weight: 700)
* **Section Header:** 16px / 22px line-height, Semi-Bold (Weight: 600)
* **Body Regular:** 14px / 20px line-height, Regular (Weight: 400)
* **Caption / Meta:** 12px / 16px line-height, Medium (Weight: 500)

## 2. Layout & Screen-by-Screen Breakdown

> *Note: All screens are designed for standard mobile viewports (Width: ~375px–390px, full-screen edge-to-edge layout without mock device frames).*

### Row 1: Onboarding / Setup Flow
1. **Screen 1 (Splash/Welcome):** Minimalist layout. Centered illustration/icon at the top, bold headline, brief subtext, and a full-width sticky primary button at the bottom (`#4F378B`).
2. **Screen 2 (Input Form):** Standard form layout with input fields (rounded corners `8px`, subtle border). Bottom CTA button enabled once inputs are valid.
3. **Screen 3 (List Selection):** Vertical list items with checkmark indicators on the left or radio toggles on the right. Generous vertical padding (`16px` per row).
4. **Screen 4 (Configuration/Toggles):** Settings-style layout featuring toggle switches, categorized sections with light gray section headers.

### Row 2: Dashboard & Interactive Flows
5. **Screen 5 (Dashboard / Summary):** 
   * Top card with summary stats/balance.
   * Horizontal or grid-based category cards with soft pastel icons.
   * List of recent activity below.
6. **Screen 6 (Media / Visual Content):** Grid-based layout displaying image/video thumbnails with overlay titles and status tags.
7. **Screen 7 (Detailed List):** Detailed breakdown items with left-aligned icons, multi-line text (Title + Subtitle), and chevron indicators on the right.
8. **Screen 8 (Detail / Confirmation Page):** Clean document-style view with key-value pairs, a highlighted status badge, and clear spacing.

### Row 3: Forms, Tables & Empty States
9. **Screen 9 (Multi-step Form):** Complex input fields with validation states (helper text in red/gray).
10. **Screen 10 (Table / Data View):** Structured tabular data with clear column separation and alternating row tints.
11. **Screen 11 (Settings / Profile):** Grouped list items divided by subtle horizontal rules.
12. **Screen 12 (Empty State):** Centered minimalist illustration, friendly prompt text, and a secondary or primary CTA button to encourage action.

* **Border Radius:** `16px`

### Input Fields
* **Height:** `48px`

## 4. Animations & Transitions

To ensure a native app feel, implement the following micro-interactions:
* **Page Transitions:** Slide-in from right (`transform: translateX(100%)` to `0`) with a duration of `300ms` using cubic-bezier easing (`cubic-bezier(0.4, 0, 0.2, 1)`).
* **Button Press State:** Scale down slightly (`transform: scale(0.97)`) over `100ms`.
* **Toggle Switches:** Smooth sliding animation (`200ms` ease-in-out) changing background color from gray (`#E0E0E0`) to primary (`#4F378B`).
* **List Item Feedback:** Ripple effect or subtle background darkening on tap (`#F3EDF7`).
