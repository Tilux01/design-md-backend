# Design Specification: Project Twelve Website

This document provides a comprehensive design specification for recreating the provided landing page interface. The specifications detail layout, typography, colors, assets, and component placement to ensure a pixel-perfect, full-screen clone.

---

## 1. Global Layout & Canvas

*   **Display Mode:** Full-screen responsive viewport (100vw x 100vh).
*   **Base Background Color:** Pitch Black (`#000000`).
*   **Container/Bounds:** The main interface sits within a centered container with rounded corners (approx. `16px` border-radius) on larger viewports, but spans full-width (`100%`) for standard execution.
*   **Overall Theme:** Dark mode, futuristic, immersive, utilizing glowing neon purple/magenta elements against a dark backdrop.

---

## 2. Color Palette

*   **Primary Background:** `#000000` (Pure Black)
*   **Primary Text & Accents:** `#FFFFFF` (Pure White)
*   **Secondary Text / Sub-navigation:** `#8A8A8A` / Muted Gray
*   **Glow / Visual Element Colors:** 
    *   Vibrant Purple / Magenta (approx. `#9400D3` to `#DA70D6` gradient glow)
    *   Deep Dark Plum / Eggplant (inside the central orb object)

---

## 3. Typography

### Font Family
*   **Primary Headings & Brand:** Geometric, futuristic sans-serif typeface with wide tracking (e.g., **"Orbitron"**, **"Syncopate"**, or **"Rajdhani"**). 
*   **Fallback Stack:** `sans-serif`, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto.
*   **Body & Navigation Text:** Clean, minimal sans-serif (e.g., **"Inter"** or **"Roboto"**).

### Typography Hierarchy

1.  **Brand Logo (`P12`):**
    *   Style: Custom geometric/futuristic monogram.
    *   Color: White (`#FFFFFF`).
    *   Position: Top-Left corner.

2.  **Navigation Links (Header):**
    *   Text: "Loram Ipsum" (x3)
    *   Font Size: Small (~`12px` - `14px`).
    *   Weight: Regular / Medium.
    *   Color: White (`#FFFFFF`).
    *   Letter Spacing: Wide.

3.  **Left Vertical Navigation / Section Indicators:**
    *   Text: `Project 12` | `Overview` | `Econs`
    *   Orientation: Vertical text (rotated 90 degrees counter-clockwise or stacked vertically downwards).
    *   Font Size: Small (`~11px`).
    *   Color: Muted Gray to White.
    *   Position: Fixed vertically along the middle-left edge.

4.  **Hero Heading ("PROJECT TWELVE"):**
    *   Text: 
        *   Line 1: `PROJECT`
        *   Line 2: `TWELVE`
    *   Font Size: Extra Large (Responsive, approx. `4rem` to `6.5rem`).
    *   Font Weight: Bold / Ultra-Bold.
    *   Line Height: Tight (`~0.95`).
    *   Alignment: Left-aligned.
    *   Color: Solid White (`#FFFFFF`).
    *   Z-Index: Placed *above* the central glowing orb background layer.

5.  **Bottom CTA / "LEARN MORE":**
    *   Text: `LEARN MORE` accompanied by a right-pointing arrow icon (`→`).
    *   Style: Uppercase, tracked out.
    *   Color: White (`#FFFFFF`).
    *   Decoration: Accompanied by a small horizontal line above it.

6.  **Top-Right CTA Button:**
    *   Text: `Learn More`
    *   Style: Outlined rectangular button with thin white borders.
    *   Padding: Compact (`~8px 20px`).
    *   Border Radius: Sharp or minimally rounded.

7.  **Bottom-Right Body Copy (Lorem Ipsum):**
    *   Text: Paragraph starting with *"Lorem ipsum dolor sit amet, consectetur adipiscing elit..."*
    *   Font Size: Small (`~11px` to `12px`).
    *   Line Height: Relaxed (`1.5`).
    *   Color: Muted Gray (`#AAAAAA`).
    *   Max-Width: Restricted to a compact text block (~`300px`).

---

## 4. Visual Assets & Imagery Descriptions

All graphical elements are rendered as backgroundless (transparent background PNG/WebP or SVG) layers positioned with precise coordinates and layering.

### Asset 1: Central Glowing Orb / Organic Shape
*   **Description:** An abstract, organic, spherical 3D render resembling a futuristic cell or liquid orb. It features a deep dark plum/eggplant core with a vibrant neon magenta/purple outer bloom and glow. A smaller bulbous appendage or droplet emerges from the bottom-right side of the main sphere.
*   **Background:** Transparent (`backgroundless`).
*   **Placement:** Centered horizontally/vertically behind the main "PROJECT TWELVE" typography text block, acting as the primary hero focal point.
*   **Layering (Z-Index):** Below the main hero text (`PROJECT TWELVE`), but above the pitch-black canvas background.

### Asset 2: Secondary Translucent Sphere (Top-Left)
*   **Description:** A subtle, semi-transparent dark glass-like sphere with a faint blue/cyan rim light.
*   **Background:** Transparent (`backgroundless`).
*   **Placement:** Positioned in the upper-left quadrant, floating just to the left of the central orb and above the "PROJECT" typography.
*   **Layering (Z-Index):** Behind the main text layer.

---
