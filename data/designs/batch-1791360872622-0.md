# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial Luxury E-Commerce / Warm Ambient Minimalism with rich monochromatic terracotta/amber gradients, premium typography hierarchy, and glassmorphism interactive elements.
- **Visual Density & Whitespace Ratio**: High whitespace ratio focusing attention onto central high-contrast product imagery; generous outer padding with balanced asymmetrical hero alignment.
- **Surface Elevation Model**: Layered depth using semi-transparent frosted glass containers (`backdrop-filter: blur(16px)`), subtle inner borders (`rgba(255, 255, 255, 0.15)`), and warm ambient glow orbs behind focal points.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Glassmorphism frosted pill navigation, high-tracking uppercase categorization, floating interactive size selectors, ambient 3D product showcase.
- **Pill Badge Specification**: Padding `6px 16px`, font-size `12px`, font-weight `600`, tracking `0.08em`, border-radius `9999px`, background `rgba(255, 255, 255, 0.12)`, border width `1px solid rgba(255, 255, 255, 0.25)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before`.
  - Arrow (→) -> Use `&#8594;` or SVG icon component.
  - Heart (♥) -> Use `&#9825;` or SVG icon.
