# UI Implementation Blueprint: Calendly Customer Stories Section

This document provides the exact specifications, layout structure, typography, styling, and animation logic required to build a pixel-perfect clone of the Calendly "Real customers. Real results." interactive customer stories component.

---

## 1. Global Layout & Canvas Specifications

*   **View Type:** Full-screen responsive viewport (100vw × 100vh) with a vertical center-aligned content container.
*   **Background Style:** A smooth, multi-stop radial/linear gradient mesh transitioning across pastel hues.
    *   *Top-Left / Center Base:* Soft pastel blue (`#e0eafc` to `#cfdef3` blended with soft purple).
    *   *Center / Bottom Right:* Warm glowing peach-yellow (`#fcefee` to `#fdfbf7`) transitioning into soft violet (`#e8dff5`).
    *   *Implementation Strategy:* A base gradient background layered with high-blur pseudo-elements (`backdrop-filter` or SVG mesh gradients) to achieve the organic, ethereal aura seen in Calendly’s design system.
*   **Max Width Container:** Centered flex column container max-width approx. `1280px` with responsive horizontal padding (`24px` to `48px`).

---

## 2. Typography & Font Family Stack

Calendly utilizes a clean, geometric sans-serif design system optimized for readability and modern SaaS aesthetics.

### Primary Font Family
*   **Primary Family:** `Inter`, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `Helvetica`, `Arial`, sans-serif.
*   **Fallback Stack:** If `Inter` fails to load, the system falls back to standard modern system sans-serif fonts.

### Typography Hierarchy Matrix

| Element | Font Size | Line Height | Font Weight | Letter Spacing | Color / Opacity |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Section Eyebrow** ("CUSTOMER STORIES") | `11px` | `1.2` | `700` (Bold) | `1.5px` (Uppercase) | `#006bff` or muted dark gray with opacity (`rgba(0, 0, 0, 0.6)`) |

## 3. Component Architecture

### A. Navigation Header (Top Bar)
*   **Positioning:** Fixed or static top bar (`height: 72px`, full-width).
*   **Background:** Clean translucent white (`rgba(255, 255, 255, 0.85)`) with a subtle bottom border (`1px solid rgba(0, 0, 0, 0.06)`) and backdrop blur (`backdrop-filter: blur(12px)`).
*   **Elements:**
    *   **Left:** Calendly Logo (SVG, standard brand blue `#006bff`).
    *   **Center Nav Links:** Product, Solutions, Resources, Pricing (with chevron dropdown indicators). Font size: `14px`, Weight: `500`, Color: `#334155`.
    *   **Right Actions:**
        *   "Talk to sales" (Text button, hover state color transition).
        *   "Log in" (Outline or ghost button, padding `8px 16px`).
        *   "Get started for free" (Primary solid pill button: Background `#0b132b`, Text `#ffffff`, border-radius `100px`, padding `10px 20px`).

### B. Customer Stories Carousel / Accordion Slider Component
The core interaction zone consists of a central active card flanked by shrinking peripheral preview cards connected via a horizontal layout flow.

#### 1. Central Active Card (The Focal Point)
*   **Dimensions:** Split-panel card layout (Left: Text & Metrics, Right: Image Media). Max width approx. `780px`, Height approx. `380px`.
*   **Background:** Pure white (`#ffffff`).
*   **Border Radius:** `24px`.
*   **Box Shadow:** Deep, soft shadow for elevation (`0 20px 40px -15px rgba(0, 0, 0, 0.08)`, `0 0 1px 1px rgba(0, 0, 0, 0.04)`).
*   **Layout Structure (CSS Flexbox / Grid):**
    *   **Left Side (Text Content):** Padding `40px`, flex-direction column. Contains the bold metric header, quote body, divider line (optional), and author info block.
    *   **Right Side (Visual Content):** Image container holding the customer photo (e.g., dog-walking scene). Border-radius clipped to match the right side of the main card (`0 24px 24px 0`), object-fit `cover`. Includes a small caption pill overlay at the bottom ("Barking with the Bradley’s...").

#### 2. Peripheral Preview Cards (Carousel Sibling Elements)
*   **Visual Treatment:** Scaled down, semi-transparent, vertically centered relative to the main card.
*   **Dimensions:** Width approx. `80px` – `120px`, Height approx. `220px` – `280px`.
*   **Styling:** Rounded corners (`16px`), overflow hidden, CSS scale/opacity drop-off based on distance from the active center index.
*   **State Transition:** Clicking any peripheral card triggers a state change that swaps its content into the central active card position with a smooth layout animation.

#### 3. Carousel Pagination Indicators
*   **Position:** Directly beneath the central active card.
*   **Design:** A row of horizontal dots/capsules. The active indicator is elongated (pill shape, width `24px`, background `#0b132b`), while inactive dots are circles (width `8px`, background `#cbd5e1`).

---

## 4. Animation & Interaction Specifications

To achieve the fluid, high-end SaaS feel demonstrated in the reference media, implement the following animation rules:

### A. Card Transition Animation (Carousel Switch)
*   **Trigger:** User clicks a peripheral card or pagination dot.
*   **Transition Properties:** CSS Transitions / Framer Motion Layout animations (`layout`, `layoutId`).
*   **Timing Function:** `cubic-bezier(0.25, 1, 0.5, 1)` (Smooth ease-out deceleration).
*   **Duration:** `400ms` to `500ms`.
*   **Behavior:** 
    *   The incoming card expands from its thumbnail width/height to the full active card dimensions.
    *   Text elements fade out (opacity `0` to `1`, translateY `10px` to `0`) during the layout shift.

### B. Hover Micro-Interactions
*   **Peripheral Cards:** Hovering over any adjacent preview card increases its opacity from `0.6` to `0.9` and scales it up slightly (`transform: scale(1.03)`).
*   **CTA Buttons:** Scale up by `2%` with a subtle shadow intensification on hover.
