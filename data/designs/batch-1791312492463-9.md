# Design System Specification: "Rennale Renuelly" Interface

---

## 1. Design Philosophy & Overall Aesthetic
* **Primary Mood & Archetype:** Organic Luxury, Eco-Wellness, Sophisticated Naturalism, Editorial Botanical.
* **Visual Density:** Balanced; generous breathing room paired with layered information-rich modular cards.
* **Whitespace Balance:** High. Employs asymmetric organic elements balanced against rigid geometric container alignment.
* **Theme & Texture:** Dark/Deep botanical green base coupled with warm, earthy secondary tones (ochre, beige, terracotta). Heavily utilizes fine-grain textures, soft neumorphic drop shadows, and subtle internal depth layering (`box-shadow` with blurred radiuses).

## 4. Layout Architecture & Spatial Grid

### Container & Grid Specifications
* **Max-Width:** `1200px` centered with fluid margins (`24px` mobile, `48px` desktop).
* **Grid Systems:** 
  * 4-column feature breakdown (`grid-template-columns: repeat(4, 1fr)`)
  * 3-column modular content grid (`grid-template-columns: repeat(3, 1fr)`)
* **Spacing Scale (Tokens):**
  * `xxs`: `4px`
  * `xs`: `8px`
  * `sm`: `16px`
  * `md`: `24px`
  * `lg`: `36px`
  * `xl`: `64px`
  * `2xl`: `96px`

### Section Sequence Breakdown
1. **Hero Section:** Asymmetric split layout featuring high-impact editorial typography, primary CTA pill button, and organic botanical overlay elements (leaves, depth gradients).
2. **Feature Grid (Icon Strip):** 4-column glassmorphism/deep-surface container displaying icons, bold titles, and micro-body copy.
3. **Core Modular Matrix (3-Column Card Grid):** Interactive container cards featuring rounded inner badges, dual-tone surface variations, and descriptive sub-layouts.
4. **Secondary Multimedia/Data Grid:** Mixed media container layout integrating photography, icon badges, and structured text cards.

---

## 5. Component Blueprint & Element Placement

### Hero Section
* **Alignment:** Left-aligned text framework, floating overlapping asset graphics on the top-right.
* **Stack Order (z-index):** Background canvas (`z-0`), organic leaf vectors (`z-10`), typography & CTA button (`z-20`).

### Cards & Containers (`.card-modular`)
* **Border Radius:** `24px` (`border-radius: 24px`)
* **Border Width:** `1px` solid `rgba(255, 255, 255, 0.08)`
* **Drop Shadow Spec:** `0 16px 32px rgba(10, 24, 18, 0.35), inset 0 1px 0 rgba(255, 255, 255, 0.15)`
* **Inner Padding:** `28px` (top/bottom), `24px` (left/right)

### Buttons & Action Triggers (`.btn-primary`)
* **Shape Profile:** Fully rounded pill (`border-radius: 50px`)
* **Padding:** `14px 32px`
* **Typography:** `14px`, Medium (`500`), Dark Text (`#20332B`)
* **Background:** Linear gradient top-to-bottom (`#EBD0B5` to `#E2B68E`)
* **Interaction States:**
  * *Hover:* Scales up by `2%` (`transform: scale(1.02)`), brightness filter `+5%`.
  * *Active:* Scales down (`transform: scale(0.98)`).
  * *Transition:* `all 0.25s cubic-bezier(0.16, 1, 0.3, 1)`

---

## 6. Motion Mechanics & Interactions

* **Transition Physics:** Organic, fluid easing using custom cubic-bezier curves mimicking natural weight (`cubic-bezier(0.16, 1, 0.3, 1)`).
* **Micro-Interactions:**
  * Card hover states trigger a smooth lift: `transform: translateY(-4px)` with shadow expansion (`0 24px 48px rgba(0,0,0,0.4)`).
  * Icon badges float with a subtle inner drop shadow shift.
* **Duration Tokens:**
  * Fast micro (color/state changes): `150ms`
  * Standard UI transitions (cards, drawers): `300ms`
  * Complex layout shifts: `500ms`
