# 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Brand Archetype**: Enterprise-grade, high-performance logistics automation platform. The aesthetic marries organic, human-centric wellness greens with high-tech computational crispness, projecting trust, efficiency, and ecological consciousness ("green logistics").
- **Visual Density**: Clean, breathable interface with structured card layouts, generous padding, and high scannability.
- **Whitespace Balance**: Intentional negative space framing the central conversational AI value proposition. Generous padding (`py-20` to `py-32`) allows background ambient gradients to breathe.
- **Theme Balance**: Predominantly bright, luminescent light surfaces (`#FFFFFF` and frosted glass whites) supported by dark forest green contrast elements (`#0A342B`) and deep ocean blues (`#0D3149`), establishing a dynamic, high-contrast, professional-grade visual hierarchy.

# 4. Layout Architecture & Spatial Grid

- **Container Max-Width**: `1280px` (Max-w-7xl) with responsive horizontal padding (`px-4 sm:px-6 lg:px-8`).
- **Spacing Scale (8pt Grid)**:
  - `4px` (xs), `8px` (sm), `16px` (md), `24px` (lg), `32px` (xl), `64px` (2xl), `128px` (3xl).
- **Section Sequence Breakdown**:
  1. **Sticky Navigation Bar**: Logo, navigational links, and quick-action CTA.
  2. **Hero Section**: Value proposition headline, conversational input box, and trust sub-copy.
  3. **Ambient Gradient Background**: Organic blurred gradient fields providing atmospheric depth.
- **Stacking Order & z-index**:
  - Background Orbs / Glows: `z-0`
  - Main Layout Container: `z-10`
  - Sticky Navigation / Modals: `z-50`
  - Floating Tooltips / Toast Notifications: `z-100`

# 6. Motion Mechanics, Framer Motion & CSS Animation Code

- **Animation Triggers**: Scroll-driven fade-ups for cards, spring physics on button hover, and pulsing keyframes for AI status indicators.
- **Durations & Easing**: Standard transitions use `0.3s cubic-bezier(0.16, 1, 0.3, 1)` (easeOutExpo).

## Framer Motion React Snippet
```jsx
import { motion } from 'framer-motion';

export const fadeInUpVariant = {
  hidden: { opacity: 0, y: 24 },
  visible: { 
    opacity: 1, 
    y: 0,
    transition: { 
      duration: 0.6, 
      ease: [0.16, 1, 0.3, 1] 
    }
  }
};

export function AnimatedCard({ children }) {
  return (
    <motion.div
      initial="hidden"
      whileInView="visible"
      viewport={{ once: true, margin: "-100px" }}
      variants={fadeInUpVariant}
      whileHover={{ y: -4, transition: { duration: 0.2 } }}
      className="bg-white rounded-[24px] p-6 shadow-ambient border border-[#0A342B]/10"
    >
      {children}
    </motion.div>
  );
}
```
