# Design Specification (`design.md`) — FinTech Application Flow & UI Kit

## 1. Global Styles & Design Tokens

### 1.1 Color Palette
*   **Primary / Brand Color:** Deep Indigo (`#5E35B1` or `#6200EE`) — Used for primary CTA buttons, active states, and key navigational elements.
*   **Background (App Canvas):** Pure White (`#FFFFFF`) for card/screen surfaces; Off-White/Light Gray (`#F4F5F7`) for screen boundaries/background wrappers.
*   **Text Hierarchy:**
    *   **Primary Text (Headings):** Dark Charcoal / Near Black (`#1A1A1A`)
    *   **Secondary Text (Labels/Subtitles):** Medium Gray (`#757575`)
    *   **Placeholder / Inactive:** Light Gray (`#BDBDBD`)
*   **Accent / Status Colors:**
    *   **Success / Positive:** Mint Green (`#4CAF50` or `#E8F5E9` background with `#2E7D32` text)
    *   **Warning / Alert:** Soft Amber (`#FFC107`)

### 1.2 Typography & Fallbacks
The UI uses a clean, highly legible sans-serif typeface (standard for modern mobile design systems, matching fonts like **Inter**, **SF Pro Display** (iOS), or **Roboto** (Android)).
*   **Primary Font Family:** `Inter`, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif
*   **Fallback Font Stack:** `sans-serif`
*   **Type Scale:**
    *   *Screen Title (H1):* 24px / Bold (Line-height: 32px)
    *   *Section Header (H2):* 18px / Semi-Bold (Line-height: 24px)
    *   *Body Text / Input:* 14px / Regular to Medium (Line-height: 20px)
    *   *Caption / Metadata:* 12px / Regular (Line-height: 16px)

### 1.3 Global UI Components
*   **Buttons (CTA):** Full-width or pill-shaped buttons with rounded corners (`border-radius: 8px` to `12px`), filled with Primary Indigo (`#6200EE`) and white text (`16px`, Medium, Centered).
*   **Inputs / Form Fields:** Outlined or soft-filled light-grey containers with subtle borders (`border-radius: 8px`, border color `#E0E0E0`), containing left-aligned placeholder text and optional trailing icons.
*   **Cards:** White rectangular containers with soft drop shadows (`box-shadow: 0px 4px 20px rgba(0, 0, 0, 0.05)`) or subtle 1px borders (`#EBEBEB`).

## 3. Implementation Guidelines for Exact Cloning

1.  **Remove Canvas Frames:** Do not render device bezels (like iPhone frames) or drop shadows around the outer wrapper of each screen. Render each screen as a flat, full-bleed UI canvas with sharp or softly rounded corners (`border-radius: 16px` for the individual screen cards if displayed in a grid, or pure full-screen if built natively).
2.  **Spacing & Padding:** Maintain a consistent **16px to 24px horizontal padding** across all screens for content containers.
3.  **Icons:** Use a uniform icon library (such as **Lucide Icons**, **Phosphor Icons**, or **Feud / Material Symbols**) set to a consistent stroke weight (1.5px to 2px) and primary icon color (`#5E35B1` or `#757575`).
4.  **Shadows & Depth:** Use subtle shadows (`0px 2px 8px rgba(0,0,0,0.04)`) exclusively for floating cards, buttons, and bottom navigation bars to maintain the clean, modern fintech aesthetic.
