# Design Specification: Offers Dashboard (Pending State)

## 1. Global Layout & Canvas

### Viewport & Window Frame
- **Application Type:** Web Dashboard (Full-screen responsive UI).
- **Background:** Soft, muted gradient backdrop transitioning from pale sage green to cool turquoise/cyan (`#E2ECE9` to `#CBEAE0`).
- **Container Card:** Rounded main application window with a dark charcoal/black border (`#2B2D2F`), thick rounded corners (`border-radius: 28px`), and an internal padding area.
- **Top Bar Text (External to Window):** 
  - Left: `/OFFERS: PENDING` in uppercase sans-serif typography.
  - Right: `06` (Page or screen number identifier).

---

## 2. Color Palette

### Primary / Surface Colors
- **App Background (Internal):** Very light creamy sage/off-white (`#F4F5F0`).
- **Sidebar Background:** Slightly darker cream/sage tint (`#EAECE4`).
- **Card Backgrounds:** Pure white (`#FFFFFF`) for offer cards and metric/filter tabs.
- **Input/Pill Fills:** Light grey-green tint (`#EFEFEF` or `#ECEEE6`).

### Accent & Status Colors
- **Dark Neutral (Text/Icons):** Charcoal black (`#1A1C1E`).
- **Subtle Text/Muted Labels:** Medium gray (`#7E8280`).
- **Active State / Highlight:** Deep charcoal black for buttons (`#1A1C1E`).
- **Status Green (Success / Resolved / High Priority):** Emerald green (`#10B981` or `#1E8A54`).
- **Status Yellow/Orange (Medium Priority):** Muted orange/gold (`#D97706`).
- **Status Red (Low Priority):** Soft coral red (`#EF4444`).
- **Badge Background Tints:** Light pastel tints for badges (e.g., light green `#ECFDF5`, light blue/purple `#EFF6FF`).

---

## 3. Typography

### Font Family Strategy
- **Primary Font Stack:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif.
- **Fallback Stack:** Generic sans-serif.
- **Font Weight Distribution:**
  - Regular (`400`): Body text, metadata labels, descriptions.
  - Medium (`500`): Navigation labels, secondary buttons, card headers.
  - Semi-Bold (`600`): Main headings, active states, key counts.

### Text Hierarchy
- **Dashboard Title ("Offers"):** ~24px, Semi-Bold (`600`), Charcoal (`#1A1C1E`).
- **Section Header ("Need More Information"):** ~18px, Semi-Bold (`600`), Charcoal.
- **Card Titles (Brand/Offer Names):** ~14px, Semi-Bold (`600`).
- **Card Body Descriptions:** ~12px, Regular (`400`), Muted Gray (`#5A5E5C`), with standard line-height (~1.4).
- **Metadata / Labels ("Type", "Extracted date"):** ~11px, Medium (`500`), Muted Gray.

---

## 4. Sidebar Navigation (Left Panel)

- **Width:** ~72px fixed vertical strip.
- **Top Icon:** Circular avatar/brand logo placeholder with a flame/fire icon inside a dark rounded square (`#1A1C1E`).
- **Navigation Icons (Vertical Stack):**
  - Home / Dashboard icon (outline).
  - Briefcase / Offers icon (Filled active state with dark pill background: `#1A1C1E`, white icon).
  - Checkmark / Task icon.
  - Target / Compass icon.
  - Users / Contacts icon.
- **Bottom Utilities:**
  - Moon / Theme toggle icon.
  - Sun / Brightness icon (active/selected state with glowing ring).
  - Settings / Gear icon.

---

## 5. Top Header Bar

- **Left:** Page title **"Offers"** in large semi-bold text.
- **Center:** Empty search/action space.
- **Right Cluster:**
  - Help / Question mark icon inside a light circular button.
  - Notification bell icon inside a light circular button.
  - **User Profile Pill:** Displays user avatar thumbnail, name **"William Terra"**, and a dropdown chevron arrow, all encased in a rounded white pill with a subtle border.

---

## 6. Filter & Status Tab Bar

A horizontal scrollable/flex row containing filter pills:
1. **All offers:** Gray pill with counter badge `9` inside a dark circle.
2. **Pending review:** Gray pill with counter badge `54`.
3. **Pending follow-up:** Purple-tinted pill (`#EEF2FF`) with counter badge `5`.
4. **Offer resolved (Notification Banner on the far right):** Green checkmark icon with text **"Offer resolved"** and sub-text **"Moved to "Under review""** inside a crisp white pill with a light green border.

---

## 7. Content Grid: "Need More Information"

A responsive 3-column grid of white rectangular cards (`border-radius: 16px`). Each card has internal padding (~16px), subtle border separation, and contains the following structure:

### Card Anatomy
1. **Header Row:**
   - **Brand Identity:** Brand logo icon (e.g., Monster Energy, Nike, Pepsi, Sprite, Instagram, Rive) alongside the brand name in bold text.
   - **Priority Badge:** Positioned on the top right (e.g., `Medium 5/10`, `High 8/10`, `Low 5/10`) with color-coded dot and text.
2. **Metadata Grid (Two Light Grey Boxes inside Card):**
   - **Type Box:** Icon (document/tag) + Label `"Type"` + Value `"Paid sponsorship"`.
   - **Extracted Date Box:** Icon (calendar) + Label `"Extracted date"` + Value `"15 December 2025"`.
3. **Offer Title & Description:**
   - Bold title (e.g., *"Monster Energy Collaboration Offer"*).
   - 2-line truncated description detailing the sponsorship terms (e.g., *"Monster Energy is offering either a free drink or $2500 to mention the word 'Anker' for 30 seconds"*).
4. **Action Footer Buttons:**
   - **Left Button:** White/Light background with border, containing an info icon and text **"View details"**.
   - **Right Button:** Dark charcoal background (`#1A1C1E`) with white text, containing a checkmark icon and text **"Mark resolved"**.

### Grid Items (6 Cards Displayed)
1. **Monster Energy:** Medium priority (`Medium 5/10`). Paid sponsorship, 15 Dec 2025.
2. **Nike:** Medium priority (`Medium 5/10`). Paid sponsorship, 15 Dec 2025.
3. **Pepsi:** Medium priority (`Medium 5/10`). Paid sponsorship, 15 Dec 2025.
4. **Sprite:** High priority (`High 8/10`). Paid sponsorship, 15 Dec 2025.
5. **Instagram:** High priority (`High 8/10`). Paid sponsorship, 15 Dec 2025.
6. **Rive:** Low priority (`Low 5/10`). `$15k Rive x Contra challenge`.

---

## 8. Imagery & Icons Description

- **Brand Logos:** Circular vector or raster icons representing corporate brands (Monster Energy claw logo, Nike swoosh, Pepsi globes, Sprite starburst, Instagram camera gradient, Rive geometric logo). These should be rendered as clean SVG or PNG assets centered in circular containers next to the brand name.
- **UI Icons:** Standard outline iconography set (Lucide/Phosphor style) including:
  - Flame / Fire icon (App logo)
  - Briefcase / Bag icon (Offers navigation)
  - Calendar icon (Extracted date)
  - Document / Tag icon (Type)
  - Information (i) icon (View details)
  - Checkmark inside circle (Mark resolved)
  - Notification bell & Question mark
  - User avatar thumbnail (Real photography of a man in profile view).
