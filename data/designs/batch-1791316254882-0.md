# Design Specification: Cross-Border Finance Web Application

---

# 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Brand Archetype:** Ultra-modern fintech, global high-frequency liquidity, premium enterprise software, and secure borderless financial architecture.
- **Visual Density:** High-tech minimalist, spacious immersive layout, centered around an interactive core visualization.
- **Whitespace Balance:** Balanced grid with generous negative space surrounding the central 3D/abstract globe visualization.
- **Theme Architecture:** Dark-mode native (near-black atmospheric backdrops `#0A0A0F`), characterized by multi-layered deep purple glows (`#581C87` through `#9333EA`), crisp white typography, and translucent glassmorphism panels.

---

# 2. Color Palette & Design Tokens

### Color Inventory
- **Primary / Brand:** Deep Electric Purple (`#9333EA`), Glow Violet (`#A855F7`), Dark Ambient Purple (`#3B0764`).
- **Base Surfaces:** Pure Black / Void (`#05050A`), Surface Dark (`#0F0F17`), Elevated Glass Panel (`rgba(15, 15, 23, 0.75)`).
- **Borders & Dividers:** Subtle Purple-Tinted Border (`rgba(168, 85, 247, 0.2)`), High-Contrast Border (`rgba(255, 255, 255, 0.1)`).
- **Text Hierarchy:**
  - Primary Headings: Pure White (`#FFFFFF`)
  - Subheadings/Body: Muted Silver (`#94A3B8`)
  - Accent / Links: Bright Violet (`#C084FC`)

# 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** 1280px (`max-w-7xl`), centered with fluid horizontal padding (`clamp(1.5rem, 5vw, 4rem)`).
- **Spacing Scale:** 4px base multiplier (`2` = 8px, `4` = 16px, `6` = 24px, `8` = 32px, `12` = 48px, `16` = 64px).
- **Section Sequence (Top to Bottom):**
  1. Fixed Glassmorphism Global Navigation Bar
  2. Immersive Hero Section (Centered headline, abstract globe visualization backdrop, primary CTA buttons)
  3. Feature / Metrics Sub-grid
- **Z-Index Stacking Layer:**
  - Background Glow Orbs: `z-0`
  - Interactive Globe / Visuals: `z-10`
  - Content Layer (Text / Buttons): `z-20`
  - Fixed Navigation Bar: `z-50`

# 5. AI Design Traits, Micro-Badges & Special Glyphs

- **Visual Hallmarks:** Ambient purple volumetric lighting, high-tracking uppercase micro-labels, blurred radial gradients behind containers.
- **Pill Callout Badge Specs:**
  - Padding: `6px 14px`
  - Font Size: `12px` (`0.75rem`)
  - Letter Spacing: `0.08em` (Uppercase)
  - Border Radius: `9999px` (Full)
  - Border: `1px solid rgba(168, 85, 247, 0.3)`
  - Background: `rgba(147, 51, 234, 0.1)` (10% opacity purple)
- **Symbol Safety & Entities:**
  - Sparkle: `✦` or `&#10022;` (`::before`)
  - Bullet Status Dot: `●` or `&bull;`
  - Em Dash: `—` or `&mdash;`

# 7. Motion Mechanics, Framer Motion & CSS Animation Code

- **Transitions:** Smooth spring physics and cubic-bezier easing (`cubic-bezier(0.16, 1, 0.3, 1)`).
- **Framer Motion React Variant:**
```jsx
export const fadeInScale = {
  initial: { opacity: 0, scale: 0.95, y: 20 },
  animate: { 
    opacity: 1, 
    scale: 1, 
    y: 0,
    transition: { duration: 0.8, ease: [0.16, 1, 0.3, 1] }
  }
};
```
- **CSS Keyframes (Ambient Globe Pulse):**
```css
@keyframes pulseGlow {
  0%, 100% {
    transform: scale(1);
    opacity: 0.4;
  }
  50% {
    transform: scale(1.08);
    opacity: 0.7;
  }
}

.animate-glow-pulse {
  animation: pulseGlow 6s ease-in-out infinite;
}
```

# 8. Accessibility (a11y) & WCAG Contrast Audit

- **Contrast Ratios:**
  - `#FFFFFF` on `#05050A` (Hero Text): **18.5:1** (Passes WCAG AAA)
  - `#94A3B8` on `#05050A` (Muted Subtitle): **7.2:1** (Passes WCAG AAA)
  - `#C084FC` on `#05050A` (Accent Text): **9.1:1** (Passes WCAG AAA)
- **Keyboard Focus Rings:**
  ```css
  *:focus-visible {
    outline: 2px solid #A855F7;
    outline-offset: 4px;
  }
  ```
