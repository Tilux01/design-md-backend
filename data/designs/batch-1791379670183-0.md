# Comprehensive Design Specification: Futuristic Multi-Panel Interactive UI

## 1. Global Layout & Viewport Architecture

### 1.1 Canvas & Background
- **Outer Viewport Background:** Vibrant Cyan/Turquoise solid color (`#00F2FE` or similar high-chroma cyan) acting as a display frame/backdrop.
- **Main Application Container:** A centered, horizontally split multi-panel card layout with a subtle drop shadow (`box-shadow: 0 30px 60px rgba(0, 0, 0, 0.4)`).
- **Layout Structure:** Multi-column layout consisting of **3 distinct vertical panels** arranged side-by-side. 
  - *Panel 1 (Left/Active):* ~48% width (wider, featured panel).
  - *Panel 2 (Middle):* ~26% width.
  - *Panel 3 (Right):* ~26% width.
- **Full-Screen Implementation Rule:** Remove the outer cyan backdrop in production and stretch the card container to `width: 100vw; height: 100vh; overflow: hidden; display: flex;`.

## 5. Micro-Interactions & Animation Specification

### 5.1 Hover & Focus States (Accordion Expansion)
- **Panel Hover:** When the user hovers over any panel (e.g., Panel 2 or Panel 3), that panel smoothly expands in width (`flex: 2` or `width: 50%`), while the adjacent panels smoothly contract (`flex: 1` or `width: 25%`).
- **Transition Curve:** `transition: flex 0.6s cubic-bezier(0.16, 1, 0.3, 1);` (Spring-like smooth deceleration).

### 5.2 3D Element Parallax
- **Mouse Move Parallax:** The central 3D elements (Model, Geodesic Sphere, Hardware Object) subtly shift position relative to cursor coordinates (`transform: translate(calc(var(--mouse-x) * 15px), calc(var(--mouse-y) * 15px))`).
- **Background Wireframe Rotation:** The abstract wireframe vectors behind each object rotate continuously via CSS keyframes:
  ```css
  @keyframes slowRotate {
    from { transform: rotate(0deg); }
    to { transform: rotate(360deg); }
  }
  ```

### 5.3 Interactive Play Buttons
- **Pulse Effect:** The circular play buttons feature an infinite subtle outer ring pulse animation to invite user engagement.
- **Hover Scale:** `transform: scale(1.1); transition: transform 0.3s ease;` on hover. Clicking triggers a modal open state or audio/video showcase reel.
