# Comprehensive Visual & Technical Specification: Multi-Screen Mobile App UI System

This document provides an exhaustive, pixel-for-pixel specification for cloning the multi-screen mobile application UI system shown in the reference image. The design system features a cohesive branding palette dominated by deep reds, pale rose accents, dark espresso/black theme elements, and clean white-background screens.

---

## 1. Global Design Tokens & Typography

### 1.1 Color Palette
*   **Primary Brand Red:** `#D32F2F` (Used for primary CTA buttons, active state indicators, and key branding headers).
*   **Deep Crimson / Wine:** `#880E4F` or `#7A0C2E` (Used for top header backgrounds on deep-theme screens).
*   **Pale Rose / Accent Pink:** `#FFEBEE` or `#FCE4EC` (Used for card backgrounds, highlighted table rows, and secondary backgrounds).
*   **Dark Neutral / Espresso:** `#1C1C1E` / `#121212` (Used for dark-mode screens and food item card backgrounds).
*   **Pure White:** `#FFFFFF` (Used for standard screen backgrounds and text containers).
*   **Text Primary (Light Mode):** `#212121`
*   **Text Secondary (Light Mode):** `#757575`
*   **Border / Divider:** `#E0E0E0`

### 1.2 Typography & Fallbacks
*   **Primary Font Family:** `Inter`, `SF Pro Display`, `SF Pro Text`, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif.
*   **Fallback Strategy:** If system fonts or Google Fonts (`Inter`) fail to load, the stack defaults to native sans-serif (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto`).
*   **Type Scale:**
    *   **Screen Titles / Headers:** 18px–20px, Bold (Weight: 700).
    *   **Body / List Item Text:** 14px, Regular (Weight: 400) to Medium (Weight: 500).
    *   **Button Text / Call to Action:** 15px–16px, Semi-Bold (Weight: 600), Uppercase or Title Case depending on the button context.
    *   **Captions / Subtext:** 11px–12px, Regular (Weight: 400).

## 2. Screen-by-Screen Layout & Component Specifications

The reference grid contains multiple interconnected screens representing different states of a food ordering, browsing, and reservation/delivery workflow. Below is the breakdown of each unique screen layout.

---

### SCREEN A: White List/Detail View (Left-Most Column, Upper Screen)
*   **Layout Structure:** Standard vertical mobile screen layout with a white background (`#FFFFFF`).
*   **Header Section:**
    *   Left: Back arrow icon (`←`).
    *   Center: Screen title (e.g., "Details" or "Menu Item") in 16px Bold `#212121`.
*   **Content Area:**
    *   A central text grouping showing a structured item description.
    *   Alternating text rows with light rose background highlights (`#FFEBEE`), creating a receipt or itemized list layout.
    *   Vertical spacing: 12px padding between list blocks.
*   **Footer / CTA:**
    *   Bottom sticky button spanning the width (minus 24px side padding).
    *   Background: Primary Brand Red (`#D32F2F`).
    *   Text: White (`#FFFFFF`), centered, 15px Semi-Bold.
    *   Corner Radius: 8px to 12px.

---

### SCREEN B: Dark/Image Grid Feed (Center-Left Column, Upper Screen)
*   **Layout Structure:** Dark-themed screen with a rich wine/crimson header transitioning into a dark espresso background (`#1C1C1E`).
*   **Header Section:**
    *   Deep crimson banner (`#7A0C2E`) spanning the top width.
    *   Contains app branding/logo and profile avatar icon.
*   **Content Area:**
    *   Grid/List of food or product cards with dark backgrounds (`#2C2C2E`).
    *   Each card contains rich food photography (described in Section 3).
    *   Horizontal category pill selector underneath the header (rounded buttons with dark gray backgrounds and red active states).

---

### SCREEN C: Order History / List Screen (Right Column, Upper Screen)
*   **Layout Structure:** Clean white background list view with structured transaction or order rows.
*   **Content Area:**
    *   Multiple stacked list items, each containing a small circular thumbnail image on the left, a bold title, a subtitle timestamp/status, and a price/status indicator on the right.
    *   Rows alternate with very pale pink highlights (`#FCE4EC`) to differentiate items.
*   **Bottom Navigation Bar:**
    *   Standard floating or pinned bottom tab bar with 4–5 minimalist icon indicators. Active tab highlighted in Primary Brand Red (`#D32F2F`).

---

### SCREEN D: Product Catalog / Grid View (Left-Most Column, Lower Screen)
*   **Layout Structure:** White background browsing screen featuring a 2-column product grid.
*   **Header:** Minimalist top bar with a search/filter icon and category title.
*   **Product Grid:**
    *   2 columns with 12px gap.
    *   Cards feature a rounded top container holding a food/product image, followed by item title (14px Medium) and price in red (`#D32F2F`).

---

### SCREEN E: Map / Location Tracking View (Right-Most Column, Lower Screen)
*   **Layout Structure:** White background screen featuring a stylized map route interface.
*   **Map Graphic:**
    *   Pale gray/pink map vector representation showing streets and a distinct delivery route polyline in Primary Brand Red (`#D32F2F`).
    *   Pin icon marking the destination.
*   **Bottom Sheet / Card:**
    *   Overlaid white container at the bottom showing delivery status, driver info, and a full-width red CTA button (`#D32F2F`) for tracking confirmation.

## 3. Asset & Image Inventory

*All images described below are **backgroundless / transparent-ready where applicable** or styled as high-contrast photographic cards.*

1.  **Header Profile / Brand Avatar:**
    *   *Placement:* Top headers of dark and light screens.
    *   *Description:* Circular avatar containing a stylized portrait or brand logo.
    *   *Rotation/Styling:* 0° rotation, drop-shadow (elevation 2) for depth.
2.  **Product & Food Photography Thumbnails (Grid & List Items):**
    *   *Placement:* Embedded inside product cards across dark and light catalog screens (e.g., burger, steak, beverage thumbnails).
    *   *Description:* High-resolution food photography shot from a 45-degree angle against warm lighting. Images are cropped into rounded rectangles (Corner Radius: 12px) with no harsh bounding boxes.
    *   *Rotation/Styling:* 0° rotation.
3.  **Map Route Graphic:**
    *   *Placement:* Screen E (Location Tracking).
    *   *Description:* Minimalist vector map tile featuring light gray topography lines (`#F2F2F2`) and a bold red curved path indicating navigation progress.

## 4. Interaction & State Specifications

*   **Buttons:** Default state uses `#D32F2F`. Hover/Active state darkens by 10% (`#B71C1C`). Disabled state uses `#E0E0E0` with text color `#9E9E9E`.
*   **List Rows:** Subtle tap feedback (ripple effect or background color shift to `#FFEBEE`).
*   **Corner Radii:**
    *   Screen Containers / Modals: `16px` to `24px`.
    *   Cards & Buttons: `8px` to `12px`.
    *   Pills & Badges: Fully rounded (`9999px`).
