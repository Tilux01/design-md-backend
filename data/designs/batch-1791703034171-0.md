# Exact Design Specification (`design.md`)

This document provides the complete, exact design system and visual specification for reproducing the high-fashion editorial e-commerce landing page interface shown in the reference image.

---

## 1. Design Vibe & Core Aesthetics

* **Theme**: High-Fashion Editorial E-Commerce / Luxury Monochrome Banner.
* **Color Scheme**: High-contrast black, white, and soft neutral studio grays.
* **Visual Language**: Bold typography, layered cutouts, dramatic monochrome photography, wide-extended sans-serif headers, asymmetrical alignment, and minimal UI chrome.
* **Canvas Boundary**: Full-screen viewport design (0 margin, 0 padding base canvas), seamless background edge-to-edge layout.

## 3. Typography Hierarchy & Font Specifications

### Primary Font Families & Fallbacks
1. **Extended Display Headlines** (e.g., `ADDICTED TO FASHION`, `SPRING IS AROUND THE CORNER`, Navigation Tabs):
   * **Primary**: *Monument Extended*, *Syncopate*, or *Syne Extended* (Weight: 700 / Bold / Extra Bold).
   * **Fallback Stack**: `'Monument Extended', 'Syncopate', 'Arial Black', sans-serif`.
   * **Text Transform**: `uppercase`.
2. **Body / Branding / UI Labels**:
   * **Primary**: *Inter*, *Helvetica Neue*, or *Arial* (Weight: 400 / Regular, 600 / Semi-Bold).
   * **Fallback Stack**: `'Helvetica Neue', Inter, Arial, sans-serif`.

## 6. Structural Layout & CSS Guidelines

### 1. Header (Navbar)
* **Height**: `70px`
* **Padding**: `0px 40px`
* **Elements**:
  * **Left**: `W.CONCEPT` logo.
  * **Right**: Horizontal cluster containing:
    * Social Icons: Pinterest (`p`), Twitter/X (`y`/bird), Facebook (`f`). Icon size `14px`, black fill, `20px` gap between icons.
    * Menu Icon: Hamburger icon consisting of two parallel horizontal black bars (Length: `18px`, Height: `2px`, Gap: `4px`).

### 2. Hero Section
* **Dimensions**: Height ~`680px`, Width `100vw`.
* **Elements & Interactive Controls**:
  * **Left Action Button**: `Shop now` wrapped in a `1px solid #000000` rectangular border (`padding: 6px 14px`). Connected to the left boundary of the screen via a horizontal `1px solid #000000` line extending `40px` to the left.
  * **Vertical Scroll Indicator**:
    * Situated on the far-left edge (`left: 30px`).
    * Rotated 90 degrees counter-clockwise (`transform: rotate(-90deg)`).
    * Text: `SCROLL`. Followed by a vertical hairline indicator stretching downwards (`60px` height).
  * **Slide Counter / Indicator (Top Right of Hero)**:
    * Text: `01/04` in thin semi-bold type.
    * Followed by a horizontal hairline and 4 small vertical ticks representing pagination steps.
  * **Hero Main Typography Alignment**:
    * `ADDICTED`: Left-aligned relative to center axis, top overlay.
    * `TO`: Below `ADDICTED`, center-aligned.
    * `FASHION.`: Below `TO`, wide bold alignment.
    * `• 2020`: Positioned inline to the right of `FASHION.` with a solid black circle separator dot (`•`).

### 3. "Spring is Around the Corner" Category Section
* **Padding**: `60px 0px 30px 0px`
* **Main Title**: `SPRING IS AROUND THE CORNER`
  * Alignment: Center.
  * Margin Bottom: `24px`.
* **Category Tabs**:
  * Options: `CLOTHING`, `BAGS`, `SHOES`, `ACCESSORIES`.
  * Display: Horizontal Flex row, `gap: 40px`, centered.
  * State: `CLOTHING` is active (`color: #000000`), remaining options (`color: #888888`).

### 4. Product Grid & Slider Section
* **Layout**: 3-column horizontal grid centered in the viewport.
* **Outer Margins / Horizontal Padding**: `0 60px`
* **Column Gap**: `24px`
* **Carousel Navigation Arrows**:
  * **Left Arrow (`←`)**: Positioned absolute on left canvas margin, slender vector arrow (`width: 24px`, stroke `1px`).
  * **Right Arrow (`→`)**: Positioned absolute on right canvas margin, slender vector arrow (`width: 24px`, stroke `1px`).
* **Card Structure**:
  1. **Image Area**: Aspect Ratio `3:4` (e.g., `300px` width × `400px` height). Background light gray `#F2F2F2`.
  2. **Product Details Block**:
     * Alignment: Center aligned.
     * Top Margin: `16px`.
     * Brand Name: `STRATEAS CARLUCCI` (Bold, uppercase).
     * Subtitle: `Plated Surgical Coat` (Gray / Regular).
     * Price Row:
       * Strikethrough price: `$1200` (Gray line-through, stacked top).
       * Discounted price: `$899` (Bold black, stacked bottom).

## 7. Interactive & Hover States Specification

* **Header Links & Social Icons**: `opacity: 1` -> hover `opacity: 0.5` with `transition: opacity 0.2s ease`.
* **Category Navigation Tabs**: Active item has an explicit underline or bold black color (`#000000`); hovered inactive items transition from `#888888` to `#000000`.
* **Shop Now Button**: Hover state fills background with black (`#000000`) and changes text color to white (`#FFFFFF`) with a smooth `0.3s` ease-in-out transition.
* **Product Cards**: On image hover, slight vertical zoom `transform: scale(1.02)` on the model asset inside the light gray clipping card frame.
