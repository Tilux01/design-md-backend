# Design System Specification: "Reimagined History" (Daily UI 036)

## 1. Design Philosophy & Overall Aesthetic
- **Brand Archetype:** Minimalist Luxury / Avant-Garde Editorial
- **Visual Density:** Ultra-sparse, high-whitespace composition dominated by asymmetric negative space.
- **Theme Balance:** High-contrast Light Mode UI featuring a polarized asymmetric Dark Mode accent drawer/footer component.
- **Texture & Depth:** Clean vector surfaces paired with high-realism product photography (amber glass, organic tree bark, hemp twine, warm candle flame). Soft, diffused ambient drop shadows underneath physical items.

## 4. Layout Architecture & Spatial Grid
- **Viewport Frame:** Fluid responsive container bounded by desktop canvas ratios (`1440px` max-width baseline).
- **Global Padding:** 
  - Horizontal Outer Margins: `64px`
  - Vertical Outer Margins: `48px`
- **Spatial Rhythm (8pt scale derivatives):**
  - Tight: `8px`
  - Base: `16px`
  - Relaxed: `32px`
  - Section Spacing: `64px`

### Section Sequence Breakdown
1. **Global Header:** Logo (`Si`) left-aligned, navigation items center-aligned, utility actions (Search, Menu) right-aligned.
2. **Hero Core Section:**
   - *Left Column:* Micro-brand title (`realreason.`), massive H1 headline (`Reimagined History.`).
   - *Right Column:* High-definition asymmetrical product mock (Amber jar with tree bark wrap and lit candle).
3. **Bottom Contextual Footer / Drawer:**
   - *Left Segment (Dark Split):* Creator profile card (Jackson Wagner, status text).
   - *Center/Right Segment:* Carousel pagination dots, interactive navigation chevrons (`<`, `>`), and `.more` action trigger.

## 5. Component Blueprint & Element Placement

### Navigation Component
- **Logo:** Minimalist monogram `Si`, font weight `700`, size `16px`.
- **Nav Links:** Inline horizontal distribution with `32px` gap. Uppercase/Title-case country filters: `Ghana`, `Canada`, `United States`, `United Arab Emirates`.
- **Utility Icons:** Search magnifying glass and Hamburger menu toggle (Right aligned, `20px` bounding box).

### Hero Section & Product Visuals
- **Product Presentation:** Floating card/object container with directional drop shadow (`0px 24px 48px rgba(0, 0, 0, 0.08)`).
- **Typography Placement:** Absolute vertical centering relative to left viewport axis; top padding offset from nav equals `180px`.

### Bottom Action Bar (Split Architecture)
- **Background:** Split composition (`#000000` solid dark left anchor merging into `#FFFFFF` light surface right anchor).
- **Height:** `80px` fixed bottom boundary.
- **Profile Block (Dark Side):** Circular avatar (`36px` diameter, `50%` border-radius), white primary text, gray secondary text.
- **Action Controls (Light Side):**
  - Carousel indicators: 3 dots (`6px` diameter active state pill/dot, `#000000` fill; inactive `#D8D8D8`).
  - Pagination Chevrons: Circular outlined icon buttons (`36px` diameter, `1px` solid border `#E5E5E5`, hover fill `#000000` with inverted text).
  - Text Action: `.more` link in bold sans-serif with leading dot.

---

## 6. Motion Mechanics & Interaction Specifications

### Transition Tokens
- **Duration (Fast):** `150ms` (Hover states, icon color swaps)
- **Duration (Standard):** `300ms` (Carousel slide transitions, menu drawer reveals)
- **Duration (Complex):** `500ms` (Hero image cross-fade & parallax scale)
- **Easing Function:** `cubic-bezier(0.16, 1, 0.3, 1)` (Custom Apple-style ease-out-expo for crisp, smooth deceleration).

### Interactive States
- **Buttons / Chevrons:** 
  - *Default:* Border `#E5E5E5`, Icon `#000000`
  - *Hover:* Background `#000000`, Border `#000000`, Icon `#FFFFFF`
  - *Active:* Scale down to `0.96` transform.
- **Carousel Pagination:** Smooth horizontal translation (`transform: translateX(-100%)`) triggered via chevron click or drag gesture.
