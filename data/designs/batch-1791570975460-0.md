# UI Design Specification: HR Portal Dashboard ("Good Morning Stevano!")

## 1. Global Layout & Structure
- **Viewport/Canvas**: Full-screen layout with a light gray-white background (`#f4f6f8`). The main content area sits centered with structured padding, utilizing a modular card-based UI grid system.
- **Top Navigation Bar**: 
  - Height: ~70px, white background, stretching full-width.
  - Left: Brand logo (Orange stylized "C" inside a white circle with a drop shadow).
  - Center-Left: Primary navigation pills/tabs: **Dashboard** (active, dark rounded-pill background `#1e2124` with white text), **Calendar**, **Salary**, **Team**, **Documents**.
  - Right: 
    - Search bar input ("Search everything...") with magnifying glass icon.
    - Notification bell icon with a red alert badge (`7`).
    - Date display ("Sat, 27 Jan").
    - Settings gear icon.
    - User avatar (Young man with short brown hair and glasses).

---

## 2. Typography & Fonts
- **Primary Font Family**: Inter, Poppins, or system sans-serif stack (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`).
- **Fallback Stack**: Fallback safely to standard system sans-serif if Google Fonts/Inter are unreachable.
- **Hierarchy Specifications**:
  - **Main Greeting**: ~28px, Bold, Dark Charcoal (`#1a1a1a`).
  - **Section Headings / Card Titles**: ~16px, Semi-bold, Dark Gray (`#2c2c2c`).
  - **KPI Numbers**: ~32px to 42px, Bold, High contrast.
  - **Body / Metadata Text**: ~12px to 14px, Regular/Medium, Muted Gray (`#6c757d`).
