# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Dark Mode Immersive Media Gallery / Coverflow Carousel. Clean editorial dark theme with ambient spatial depth.
- **Visual Density & Whitespace Ratio**: High whitespace-to-content ratio focusing absolute user attention on the central interactive media carousel.
- **Surface Elevation Model**: Layered Z-axis depth using scale reduction (`transform: scale()`), horizontal translation offsets, and varying opacity gradients for off-center items in the 3D coverflow projection.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase labels, ambient background vignette, glassmorphism pills, subtle interactive scaling.
- **Pill Badge Specification**: Padding: 8px 16px; Font-size: 12px; Font-weight: 600; Tracking: 0.1em; Border-radius: 9999px; Background: rgba(255,255,255,0.05); Border: 1px solid rgba(255,255,255,0.1);
- **Symbol & Glyph Safety Mapping**:
  - Left Arrow (‹) -> Use `&lsaquo;` or SVG chevron.
  - Right Arrow (›) -> Use `&rsaquo;` or SVG chevron.
  - Em-dash (—) -> Use `&mdash;`.
