# Design Specification: Verification Stats Dashboard

## 1. Global Layout & Structure

- **Viewport/Canvas:** Designed as a full-screen application layout (responsive web/desktop dashboard).
- **Layout Architecture:** Three-column master structure:
  - **Left Sidebar:** Narrow vertical navigation and status bar.
  - **Main Content Area (Center/Left-Center):** Multi-widget dynamic dashboard containing stats overview, activity charts, usage bars, protection metrics, and AI verification modules.
  - **Right Sidebar:** User profile management, team members overview, connected resources list (Snapchat, Behance, Dribbble, Instagram), and subscription status.
- **Color Palette:**
  - **Background (Canvas):** Light gray/off-white (`#f1f3f6`).
  - **Card Backgrounds:** Pure white (`#ffffff`) with subtle drop shadows and rounded corners (`border-radius: 16px` to `24px`).
  - **Dark Cards/Elements:** Deep charcoal/black (`#121316`) used for highlights (e.g., Verification speed card, subscription upgrade card).
  - **Primary Accents:** Soft mint green (`#d4f0e7` / `#e4f5ed`), vibrant turquoise/blue gradients, and dark slate grays (`#334155`).
  - **Text Colors:** Primary dark gray/black (`#0f172a`), secondary muted gray (`#64748b`), and white (`#ffffff`) on dark backgrounds.
- **Typography:**
  - **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif.
  - **Fallback Stack:** Arial, sans-serif.
  - **Font Weights:** Regular (400), Medium (500), Semi-bold (600), Bold (700).
