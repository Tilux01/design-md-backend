# Design Specification: Sovereign Wallet (Clone Spec)

This document provides a highly detailed, pixel-perfect UI specification to clone the modern digital wallet interface shown in the design. It focuses on the full-screen layout of the application itself, omitting the external mobile device mock frame.

---

## 1. Core Visual Concept & Philosophy

The UI utilizes a striking **"Sandwich Layout Layering"** style:
*   The parent viewport background is **true black (`#000000`)**.
*   The screen is divided into two dominant curved plates (Top Panel and Bottom Panel) with deep border-radii facing inwards.
*   This design exposes the black background in the middle third of the screen, creating a custom dark channel where the main floating call-to-action buttons (`Send`, `QR-Scan`, `Request`) reside.

*   **Right-align:** Minimalist native iOS/Android style indicator icons (Cellular Signal, Wi-Fi, Battery status indicator) in crisp solid black `#000000`.

*   **Background:** Color `#D6DBE5`.
*   **Border Radius:** Bottom-left `38px`, Bottom-right `38px`.
*   **Padding:** Top `24px` (below status bar), Bottom `36px`, Horizontal `24px`.
*   **Welcome Row:**
    *   Left: `Hi Ben! ` (Bold, `#0E0F12`) followed by `Welcome to your wallet` (Medium, `#666B77`, transitions inline).

## 5. Micro-Interactions & Animation Specs

To create a natural and premium user experience, the interface should incorporate the following subtle animations:

```
[Screen Load] 
   └── Fade-in both curved Panels (Top panel descends 15px, Bottom panel rises 15px)
   └── Balance Counter ($12.329,20) counts up from $12.000,00 over 800ms
   └── SVG Income Line-Graph draws along path (stroke-dashoffset transition)
```

### 5.1 CSS Keyframes and Transition System

To implement these effects, use these transition parameters:

```css
/* Custom Global Cubic-Bezier for Fluid Premium Feel */
:root {
  --transition-fluid: all 0.45s cubic-bezier(0.16, 1, 0.3, 1);
}

/* Button Pressed Animation */
.interactive-btn {
  transition: var(--transition-fluid);
}
.interactive-btn:active {
  transform: scale(0.96);
  filter: brightness(0.9);
}

/* Card Hover Elevation on Desktop Hover States */
.hover-card {
  transition: var(--transition-fluid);
}
.hover-card:hover {
  transform: translateY(-4px);
  box-shadow: 0 10px 25px -5px rgba(0, 0, 0, 0.05);
}

/* SVG Line Draw-In Motion */
@keyframes svg-draw {
  from {
    stroke-dashoffset: 150;
  }
  to {
    stroke-dashoffset: 0;
  }
}

.sparkline-path {
  stroke-dasharray: 150;
  stroke-dashoffset: 150;
  animation: svg-draw 1.2s cubic-bezier(0.25, 1, 0.5, 1) forwards 0.3s;
}
```
