# UI/UX Design Specification: Skincare E-Commerce Landing Page

## 1. Global Layout & Structure
- **Viewport:** Full-screen responsive layout (100vw, 100vh).
- **Border Radius & Framing:** The entire layout is contained within a large rounded-corner container (approx. `border-radius: 32px` on desktop) floating over a neutral taupe/gray backdrop (`#E5E0DC`). 
- **Grid Structure:** Asymmetric layout featuring a prominent hero section on the left/center and product cards positioned in the bottom left, middle left, and bottom right corners.

## 2. Color Palette
- **Background / Canvas:** Soft Neutral Taupe (`#EAE5E0` to `#DED6CE` gradient/flat tone).
- **Primary Text:** Deep Charcoal / Off-Black (`#1A1A1A`).
- **Secondary Text:** Muted Gray-Taupe (`#6B6661`).
- **Card & Component Backgrounds:** Semi-transparent frosted white / solid off-white (`#FFFFFF` with soft shadows).
- **Interactive Elements (Buttons/Badges):** Pure Black (`#000000`) for primary CTAs.
- **Accents:** Warm golden-yellow tones extracted from the serum liquid (`#D4A373`).

## 3. Typography & Fonts
- **Primary Header Font:** *Playfair Display* (Fallback: *Georgia*, *Times New Roman*, serif). Used for large, elegant editorial headlines ("Flourish in Daily Pover").
- **Body & UI Font:** *Inter* (Fallback: *Helvetica Neue*, *Arial*, sans-serif). Used for navigation links, body copy, prices, and button labels.

### Font Styles:
- **Main Hero Headline:** 
  - Font: *Playfair Display*, Bold.
  - Size: `56px` / `64px` line-height.

- **Body Copy:** 
  - Font: *Inter*, Regular.
