# Comprehensive Design & Implementation Specification
## Project: Patagonia "Originals Hooded Windbreaker" E-Commerce Landing Page

---

### 1. Global Viewport & Layout Architecture

#### 1.1 Responsive Container & Scaling
* **Target Viewport:** Desktop/Laptop screen layout (approx. `1440px` × `900px` base canvas, fluidly scaling down to tablet/mobile via breakpoints).
* **Display Mode:** Full-screen viewport takeover (`100vw` width, `100vh` height). Outer presentation mock-up frames, shadows, and device bezels from the screenshot are strictly stripped away; only the internal web layout is rendered.
* **Grid Structure:** 12-column fluid grid system with a consistent horizontal margin/padding (`80px` on desktop, `24px` on mobile).
* **Vertical Rhythm:** Flexbox/CSS Grid centered layout ensuring the hero content remains vertically balanced within the browser viewport without requiring initial vertical scrolling.

#### 1.2 Color Palette & Design Tokens
```css
:root {
  /* Backgrounds */
  --color-bg-primary: #EAEAE4;        /* Warm off-white / light neutral canvas */
  --color-bg-gradient-start: #E5E9E2; 
  --color-bg-gradient-end: #DCDFD6;

  /* Typography */
  --color-text-primary: #1A1A1A;      /* Deep charcoal / near black for headings */
  --color-text-secondary: #595959;    /* Muted gray for body and metadata */
  --color-text-inverse: #FFFFFF;

  /* Accent & Interactive */
  --color-accent-sun: #FCEFD2;        /* Soft pale yellow/orange circular gradient backdrop */
  --color-accent-sun-fade: rgba(252, 239, 210, 0);
  --color-btn-bg: #1A1A1A;
  --color-btn-hover: #333333;

  /* Brand */
  --color-brand: #000000;
}
```

### 3. Component-by-Component Breakdown

#### 3.1 Header / Navigation Bar (`<header>`)
* **Position:** Sticky or Absolute top banner, spanning full width with padding (`40px` top/sides).
* **Layout:** Flexbox container with `justify-content: space-between` and `align-items: center`.
* **Left Section:**
  * **Brand Logo:** Patagonia wordmark (`patagonia`) rendered in lowercase, bold classic gothic/sans-serif treatment.
  * **Menu Trigger:** Hamburger menu icon (`=` symbol) paired with text links: `New Collection`, `Man`, `Woman`, `Stories`. (All items spaced with `32px` gap).
* **Right Section:**
  * `Find a store` link.
  * Cart / Bag icon with item counter indicator (`0`).
  * Account / Profile icon (minimalist outline).

#### 3.2 Hero Background Visual Element (The Sun / Halo)
* **Shape:** Absolute-positioned soft circular element centered behind the left-mid region of the windbreaker.
* **Styling:** Radial gradient transitioning from `--color-accent-sun` (`#FCEFD2`) in the center outward to transparent (`rgba(252, 239, 210, 0)`).
* **Dimensions:** Approx. `450px` × `450px`.

#### 3.3 Hero Product Visual: The Floating Windbreaker
* **Visual Asset:** High-resolution isolation shot of a deep-red / rust-colored hooded windbreaker jacket posed mid-air at a dynamic, flying/tumbling angle. White inner lining visible at cuffs and hem.
* **Positioning:** Angled diagonally across the left-center canvas.
* **Effects:** 
  * Multi-layered soft drop-shadow underneath (`box-shadow: 0 30px 60px rgba(0, 0, 0, 0.12), 0 10px 20px rgba(0, 0, 0, 0.08)`).
  * Creates a strong 3D levitation/floating effect.

#### 3.4 Hero Content & Typography Section (Right Column)
* **Alignment:** Right-aligned text block (`text-align: right` or flex column aligned to the right edge).
* **Eyebrow:** `New Collection` (Small, tracked out).
* **Main Heading:** Multi-line serif display title:
  ```html
  <h1>Originals<br>Hooded<br>Windbreaker</h1>
  ```
* **Body Copy:** Two-line muted descriptive text block:
  ```html
  <p>Lorem ipsum dolor sit amet, consectetur adipiscing elit maecenas<br>varius tortor nibh sit amet tempor nibh finibus.</p>
  ```
* **Call to Action (CTA):** 
  * Dark pill/rounded rectangle button (`background: var(--color-btn-bg)`, color white, rounded corners).
  * Text: `Explore more`.
  * Padding: `12px 24px`. Hover state shifts background to `#333333` with a smooth scale transition (`transform: scale(1.02)`).

#### 3.5 Footer / Bottom Bar Elements
* **Left Footer (Socials):**
  * Label: `FOLLOW US`
  * Social links: `Fb`, `Ig`, `Tw` separated by light spacing.
* **Center / Right Footer (Pagination & Navigation Controls):**
  * Page Indicator: `01`
  * Navigation Arrows: Left arrow (`←`) and Right arrow (`→`) housed inside clean, minimalist clickable icon wrappers for carousel navigation.
* **Bottom-Right Watermark:**
  * Subtle design credit logo (`W//.`) placed discreetly in the lower right corner.

### 4. Micro-Interactions & Animation Specifications

#### 4.1 Page Load Entrance Animation (CSS Keyframes / GSAP)
1. **Staggered Fade-In:** Elements fade in sequentially with a `0.8s` cubic-bezier easing (`cubic-bezier(0.16, 1, 0.3, 1)`).
2. **Jacket Levitation Float:** Continuous infinite CSS keyframe animation on the windbreaker image to simulate floating in the wind:
   ```css
   @keyframes floatWindbreaker {
     0% { transform: translateY(0px) rotate(0deg); }
     50% { transform: translateY(-12px) rotate(1.5deg); }
     100% { transform: translateY(0px) rotate(0deg); }
   }
   .windbreaker-img {
     animation: floatWindbreaker 6s ease-in-out infinite;
   }
   ```
3. **Background Halo Pulse:** Subtle pulsing scale on the yellow sun backdrop (`scale` from `1` to `1.05` over `8s`).

#### 4.2 Interactive States
* **Nav Links:** Hover underline transition or opacity shift (`opacity: 0.7` to `1`).
* **Buttons:** `transition: all 0.3s cubic-bezier(0.25, 0.8, 0.25, 1);` on hover/active.
* **Carousel Arrows:** Cursor changes to pointer; subtle horizontal shift on hover (`translateX(4px)` for right arrow).
