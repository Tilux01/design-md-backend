# Design Specification: Alex Walker Portfolio (Full-Screen Clone)

## 1. Global Layout & Structure
*   **Viewport:** Full-screen responsive layout, designed primarily for desktop viewing with a dark-mode-first aesthetic.
*   **Background Color:** Deep charcoal/black (`#0c0d12` or `rgb(12, 13, 18)`).
*   **Lighting/Visual Effects:** A soft, ethereal purple/lavender radial gradient glow positioned in the top-right corner (`rgba(180, 160, 220, 0.15)` fading into transparency) to mimic the moonlight/planet effect in the design.
*   **Layout Grid:** Asymmetrical layout split into two primary zones:
    1.  **Left Sidebar (Mobile/Card Mockup):** Floating smartphone-style glassmorphism card featuring the profile picture, title, and quick action buttons.
    2.  **Right Main Hero Area:** Navigation bar at the top, bold main typography statement, and a circular badge in the bottom-right corner.

## 3. Component Breakdown

### A. Header / Navigation Bar
*   **Position:** Fixed or absolute at the top, spanning full width with generous horizontal padding (`60px`).
*   **Left:** Brand logo / Name (`Alex Walker` in a minimalist icon + text format).
*   **Center:** Navigation links: `Home`, `Portfolio`, `About me`, `Services`, `Contact`.
*   **Right:** "Let's Talk" button—an oblong pill shape with a soft light-pink/white background (`#f4e8f1` or `#f2dfec`) and rounded corners (`border-radius: 50px`).

### B. Left Floating Card (Glassmorphism Sidebar)
*   **Container:** A vertical card styled like a smartphone interface embedded in the desktop view.
    *   Background: Semi-transparent dark glass (`rgba(255, 255, 255, 0.03)`).
    *   Border: Subtle 1px border (`rgba(255, 255, 255, 0.08)`).
    *   Border Radius: `24px`.
*   **Content inside Card:**
    *   **Avatar:** Circular image showing a 3D-rendered cartoon portrait of a person with brown hair.
    *   **Bio / Role:** "UI/UX designer and front-end developer".
    *   **Location:** "Odesa, Ukraine".
    *   **Action Button:** A bottom pill button labeled **"Let's work together"** with a gradient background (soft purple to pink).

### C. Bottom-Right Interactive Badge
*   **Design:** A circular vector text path reading *"SCROLL DOWN • SCROLL DOWN •"* rotating slowly around a central downward-pointing arrow (`↓`).
*   **Animation:** Infinite CSS rotation (`animation: spin 15s linear infinite;`).

## 4. Animations & Interactions

1.  **Hover States for Navigation:** Smooth color transition from grey to solid white (`transition: color 0.3s ease`).
2.  **Button Hover:** Subtle scale up (`transform: scale(1.02)`) and brightness boost on CTA buttons.
3.  **Scroll Indicator:** Continuous slow rotation of the bottom-right circular badge (`transform: rotate(360deg)`).
4.  **Entrance Animation:** Fade-in-up effect (`opacity: 0; transform: translateY(20px);` transitioning to `1` and `0` on load) for the headline text and floating card.
