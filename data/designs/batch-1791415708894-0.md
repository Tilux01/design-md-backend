# Design Specification: Game App & Gaming Store UI

## 1. Visual Theme & Style
- **Aesthetic:** Dark gaming aesthetic featuring soft neumorphism, subtle glows, and high-contrast neon cyan highlights.
- **Background:** Deep dark charcoal with subtle radial gradients (`#14171C` to `#0B0D11`).
- **Elevation/Surfaces:** Floating dark cards with soft ambient drop shadows and subtle 1px border highlights.

---

## 2. Color Palette

| Token | Hex Value | Usage |
| :--- | :--- | :--- |
| **Background Primary** | `#0E1116` | Main full-screen background |
| **Surface Dark (Card)** | `#1A1E24` | Card containers, bottom nav bar |
| **Surface Elevated** | `#222730` | Interactive states, inner card containers |
| **Accent Primary (Cyan)** | `#00F0FF` | Primary buttons, active tabs, highlights |
| **Accent Secondary** | `#00B4D8` | Button gradient endpoint, glow effects |
| **Text Primary** | `#FFFFFF` | Headings, active values |
| **Text Secondary** | `#8E95A5` | Meta labels, dates, secondary icons |
| **Border / Stroke** | `#262C36` | Subtle 1px dividers and borders |
| **Rating Gold/Cyan** | `#00F0FF` | 5-star rating icons |

---

## 3. Typography

- **Primary Font:** `Poppins` or `Gilroy` (Geometric Sans)
- **Fallback Stack:** `Inter`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`

### Hierarchy
- **Header 1 (Screen Titles):** 20px / Semi-Bold (`600`) / `#FFFFFF`
- **Header 2 (Item Titles):** 18px / Bold (`700`) / `#FFFFFF`
- **Body / Labels:** 12px–14px / Regular (`400`) / `#8E95A5`
- **Data Values / Meta:** 11px–12px / Medium (`500`) / `#FFFFFF`
- **Button Text:** 13px / Semi-Bold (`600`) / `#FFFFFF` (Upper or Title Case)

---

## 4. Navigation & Layout Grid

### Global Bottom Navigation
- **Height:** 64px, floating 16px above screen bottom with 28px border radius.
- **Background:** `#161920` with a `0 -4px 20px rgba(0,0,0,0.5)` shadow.
- **Tabs (4):**
  1. `Home` (House icon)
  2. `Store / Grid` (4-block grid icon)
  3. `Games` (Game controller icon)
  4. `Profile` (User avatar icon)
- **Active State:** Cyan glow (`#00F0FF`) with a pill indicator or highlighted white icon.

---

## 5. Screen Specifications

### Screen A: Skin Details (Detail View)
- **Layout:** Full-screen modal with character asset popping out vertically over the card container.
- **Hero Image:** High-res 3D character cutout overlapping the card header by 25%.
- **Detail Card:**
  - `Title`: Character name (e.g., "Aeronaut", "Flapjackie") centered with a 5-star cyan rating.
  - `Grid Spec`: 2-column key-value data list:
    - *Type:* Outfit
    - *Release Date:* Mon DD, YYYY
    - *Availability:* Shop Now
    - *Price:* 1,200 V-Bucks
- **CTA:** Full-width rounded cyan pill button (`height: 48px`, `border-radius: 24px`, background: `linear-gradient(90deg, #00B4D8, #00F0FF)`), labeled **"CHOOSE SKIN"**.

### Screen B: Skins List (Store / Trending)
- **Header:**
  - Title: "Skins List" (left-aligned) + Filter icon (right-aligned).
  - Search Bar: Pill input field (`#161920`), magnifying glass icon, placeholder "Search".
- **Section 1: "Trending Skins":**
  - Horizontal swipe carousel.
  - Card dimensions: `220px × 300px`, rounded corners (`20px`).
  - Contains character render, name, 5-star rating, and price in V-Bucks.

### Screen C: Skins List (Most Popular Grid)
- **Section 2: "Most Popular Skins":**
  - 2-column vertical grid layout (`gap: 12px`).
  - Cards: Compact aspect ratio (`~1:1.3`), dark surface, 16px radius.
  - Content: Character avatar, name centered below, cyan 5-star rating row.

### Screen D: User Profile
- **Header:**
  - Avatar: Circular image (64px) with a 2px `#00F0FF` ring.
  - Identity: Username ("Skull Crusher"), Badge ("Pro Gamer").
  - Stats Row: `Rating: 8.2/10`, `Rarity: Shadow Series`.
- **Menu List:**
  - Full-width list items with left icon, title, and right chevron (`>`).
  - Items: "Personal Info", "Game Progress", "Billing Methods" (active highlight), "Settings", "Logout".

### Screen E: Payment & Checkout
- **Header:** Back chevron + "Select Your Payment Method".
- **Method Selector:**
  - 3 pill/square toggle buttons: Stripe (`S`), PayPal (`P`), Credit Card icon.
  - Active button highlighted with cyan border/glow.
- **Saved Cards Section ("Your Card Details"):**
  - Card Item: `#1A1E24` surface with rounded corners (`16px`).
  - Active card outlined with a 1.5px `#00F0FF` border and active checkmark.
  - Content: Card brand chip, masked number (`•••• •••• •••• 4853`), expiration date (`Expiry 09/2025`).

---

## 6. Motion & Micro-interactions

- **Card Hover / Touch Feedback:** Scale up (`scale(1.02)`) over `200ms ease-out`.
- **Character Reveal (Detail Screen):** Slide up with fade-in (`translateY(20px) -> translateY(0)`, `350ms cubic-bezier(0.16, 1, 0.3, 1)`).
- **Carousel Scroll:** Inertial scroll with snap-to-center physics.
- **Button Press:** Scale down (`scale(0.97)`) on tap with an inner shadow pulse.
