# Design Specification: AIAIAI "Catch the Beat" Hero Screen

---

## 1. Color Palette

* **Primary Dark (Canvas Right):** `#3A3A3A` (Dark Charcoal)
* **Primary Light (Canvas Left - Top):** `#EEEEEE` (Off-White)
* **Secondary Light (Canvas Left - Bottom):** `#D8D8D8` (Soft Light Grey)
* **Accent Brand Red:** `#E51A1A` (Vibrant Crimson Red)
* **Text - High Contrast:** `#FFFFFF` (Pure White)
* **Text - Muted:** `#B3B3B3` (Neutral Grey)
* **Hotspot Overlay:** `rgba(255, 255, 255, 0.35)` with solid `#FFFFFF` center

---

## 2. Typography

* **Primary Font Family:** *Helvetica Neue*, *Inter*, or *Montserrat*
* **Fallback Fonts:** `Arial, sans-serif`

| Element | Size | Weight | Letter Spacing | Transform | Color |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Brand Logo** | 20px | 900 (Black) | 2px | Uppercase | `#2B2B2B` |
| **Nav Links** | 13px | 400 (Regular) | 0.5px | Capitalize | `#E0E0E0` |
| **Hero Title** | 56px | 800 (Extra Bold)| 1px | Uppercase | `#FFFFFF` |
| **Slide Index ("02")** | 72px | 300 (Light) | -1px | None | `#FFFFFF` |
| **Body Copy** | 13px | 400 (Regular) | 0.2px | None | `#B3B3B3` |
| **Button Text** | 10px | 700 (Bold) | 1.5px | Uppercase | `#FFFFFF` |
| **Rotated Date** | 12px | 500 (Medium) | 1px | None | `#FFFFFF` |
| **Footer Socials** | 10px | 600 (Semi-Bold)| 2px | Uppercase | `#E0E0E0` |

---

## 3. Layout Structure

* **Grid:** 2-column split layout across a 100vw × 100vh canvas.
  * **Left Column:** ~40% width. Split horizontally (70% top light `#EEEEEE`, 30% bottom `#D8D8D8`).
  * **Right Column:** ~60% width. Dark textured background `#3A3A3A`.

---

## 4. Header & Navigation

* **Height:** 80px, pinned to top, 0–80px vertical padding.
* **Left Section (Col 1):**
  * Logo: `AIAIAI` anchored left (padding-left: 60px).
* **Right Section (Col 2):**
  * Horizontal link group: `Headphones`, `Discovery`, `Configuration`, `Artist` (gap: 32px).
  * Right Utilities: Profile icon (`👤`), Search icon (`🔍`) spaced 16px apart; anchored right (padding-right: 60px).

---

## 5. Main Visual Assets

### 5.1 Primary Subject Image
* **Description:** Matte-black modular AIAIAI TMA-2 over-ear headphones. Features foam ear cushions, adjustable headband pins, and coiled driver cables.
* **Format:** Backgroundless (Transparent PNG).
* **Placement & Size:**
  * Straddles the boundary at 40% width.
  * Anchored vertically centered (`top: 50%`, `transform: translateY(-50%)`).
  * Dimensions: ~650px wide, 700px high.
  * Rotation: 0°, facing 3/4 front-left angle with a natural downward tilt.

### 5.2 Interactive Hotspot Markers
* **Node 1 (Headband Right):** Placed at top-right curve of the headband. Outer halo: 28px diameter (`rgba(255,255,255,0.3)`), inner dot: 6px solid `#FFFFFF`.
* **Node 2 (Earcup Hinge Left):** Placed near the lower left pivot hinge. Identical structure and dimensions.

### 5.3 Video Preview Card (Left Column)
* **Placement:** `top: 32%`, `left: 48px`.
* **Dimensions:** 160px width × 110px height.
* **Content:**
  * Square thumbnail of TMA-2 headphones resting on a dark surface.
  * Right edge vertical stripe: 24px wide, solid `#E51A1A`.
  * Label inside stripe: "PLAY VIDEO" rotated 270°, white, 8px font.
