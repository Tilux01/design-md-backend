# Comprehensive UI/UX & Design System Specification

## 1. Design Philosophy & Overall Aesthetic
- **Primary Mood & Brand Archetype**: Modern minimalist, refined e-commerce / editorial hybrid. Combines high-contrast utility sections with curated product displays.
- **Visual Density & Whitespace**: Moderate-to-high whitespace balance, prioritizing product visual hierarchy and clean typographic separation.
- **Theme Balance**: Light-mode primary interface with dark-mode contrasting accent banners (`#2C343D`) used for high-impact promotional blocks.

---

## 2. Color Palette & Design Tokens

### Core Color Palette
- **Primary Base**: `#121212` (Rich Charcoal / Black)
- **Primary Banner Dark**: `#2C343D` (Slate Dark)
- **Secondary / Accent**: `#D4AF37` (Muted Gold) / `#C5B358`
- **Surface / Background (Light)**: `#F8F9FA` (Off-White / Cool Gray)
- **Card Surfaces**: `#FFFFFF` (Pure White) with subtle neutral borders
- **Border & Divider**: `#E2E8F0` (Light Gray) / `#3D4752` (Dark Theme Borders)
- **Text Primary**: `#0F172A` (Slate 900)
- **Text Muted**: `#64748B` (Slate 500)
- **Text Inverse**: `#FFFFFF` (Pure White)

## 3. Typography System & Hierarchy
- **Font Families**: 
  - Headings: `Inter`, `Helvetica Neue`, sans-serif
  - Body: `Inter`, system-ui, sans-serif
- **Scale Breakdown**:
  - **H1 (Hero Heading)**: 2.5rem (40px) / Line-height: 1.2 / Tracking: -0.02em / Weight: 700
  - **H2 (Section Heading)**: 1.75rem (28px) / Line-height: 1.3 / Tracking: -0.01em / Weight: 600
  - **H3 (Card Title)**: 1.125rem (18px) / Line-height: 1.4 / Weight: 500
  - **Body Regular**: 1rem (16px) / Line-height: 1.5 / Weight: 400
  - **Caption / Metadata**: 0.875rem (14px) / Line-height: 1.4 / Tracking: 0.05em (Uppercase) / Weight: 500

---

## 4. Layout Architecture & Spatial Grid
- **Container Max-Width**: `1280px` with fluid horizontal padding (`1rem` to `2rem`).
- **Spacing Scale**: 4px base multiplier (`4`, `8`, `16`, `24`, `32`, `48`, `64`).
- **Section Sequence**:
  1. Top navigation & brand header
  2. Hero banner with immersive imagery
  3. Dark promotional announcement bar (`#2C343D`) with high-tracking typography & circular badge
  4. Product showcase grid (Bestsellers section)

---

## 5. AI Design Traits, Micro-Badges & Special Glyphs
- **Promotional Badge Specs**:
  - Text-transform: `uppercase`
  - Font-size: `0.75rem` (12px)
  - Letter-spacing: `0.1em` to `0.15em` (High-tracking)
  - Border-radius: `var(--radius-full)` (Pill shape)
  - Background: Solid white (`#FFFFFF`) with dark slate typography or translucent dark overlay.
- **Unicode & HTML Symbols**:
  - Sparkle / Accent: `✦` (`&#10022;`)
  - Status Indicator: `●` (`&#9679;`)
  - Em-dash: `—` (`&mdash;`)

## 8. Accessibility (a11y) & WCAG Contrast Audit
- **Dark Banner Text (`#FFFFFF` on `#2C343D`)**: Contrast Ratio ~11.5:1 (Passes WCAG AAA)
- **Muted Text (`#64748B` on `#FFFFFF`)**: Contrast Ratio ~4.6:1 (Passes WCAG AA)
- **Focus Ring Specification**:
  ```css
  :focus-visible {
    outline: 2px solid #D4AF37;
    outline-offset: 2px;
  }
  ```
