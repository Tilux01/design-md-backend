# UI/UX Specification & Design System: HealthCare Mobile Application

This document provides a comprehensive technical blueprint for cloning the provided healthcare mobile application UI. It translates every visual token, layout structure, typography rule, and interaction state into actionable frontend specifications (suitable for React Native, Flutter, or native Swift/Kotlin).

## 1. Global Design Tokens & Theme Setup

### Color Palette
The application utilizes a sophisticated, clinical dark-mode and light-mode hybrid system based on deep midnight blues, clean whites, and vibrant accent blues.

| Color Token | Hex Code | Usage / Context |
| :--- | :--- | :--- |
| **Primary Base (Dark UI)** | `#0a1128` | Background for dark screens (Screen 2 navigation header area & bottom navs). |
| **Surface Dark** | `#111c38` | Cards in dark mode (e.g., "Find the Right Treatment" cards). |
| **Primary Light** | `#f0f4f9` | Main screen background for light mode (Screen 1 & 3). |
| **Card White / Surface Light**| `#ffffff` | Floating white containers, cards, bottom navigation backing. |
| **Brand Blue** | `#1a50e0` / `#0055ff` | Primary interactive elements, active states, highlights. |
| **Soft Blue Tint** | `#e6f0ff` | Health Overview background container, subtle highlights. |
| **Text Primary (Dark)** | `#ffffff` | Headings on dark backgrounds. |
| **Text Primary (Light)** | `#111827` | Headings and primary titles on light backgrounds. |
| **Text Secondary** | `#6b7280` | Subtitles, helper text, inactive navigation items. |
| **Border / Divider** | `#e5e7eb` | Subtle structural dividers and input field borders. |

### Typography Stack
The UI relies on a clean, humanist Sans-Serif typeface family optimized for digital readability (similar to **Inter**, **SF Pro Display**, or **Roboto**).

*   **Primary Font Family:** `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
*   **Fallback Stack:** System-default sans-serif.

#### Type Scale Definitions:
*   **H1 (App Titles / Screen Headers):**
    *   *Size:* 24px / 28px (Bold, Weight: 700)
    *   *Letter Spacing:* -0.5px
*   **H2 (Section Headers / Widget Titles):**
    *   *Size:* 18px / 20px (Semi-Bold, Weight: 600)
*   **Body / Content Primary:**
    *   *Size:* 14px / 16px (Regular/Medium, Weight: 400–500)
*   **Caption / Meta Text:**
    *   *Size:* 11px / 12px (Regular, Weight: 400)

## 3. Micro-Interactions & Animations Specification

To replicate this application natively or via web frameworks (Framer Motion / React Native Reanimated), implement the following state transitions:

1.  **Bottom Navigation Selection Transition:**
    *   *Behavior:* When switching tabs (e.g., Home to Calendar), the active item expands from a standalone icon to a pill-shaped container (`background: #e6f0ff`, `color: #1a50e0`) using a **Spring Animation** (`damping: 20`, `stiffness: 300`).
2.  **Search Input Focus State:**
    *   *Behavior:* Tapping the search bar expands the input border stroke from `1px solid transparent` to `1.5px solid #1a50e0` with a subtle outer glow shadow (`box-shadow: 0 0 0 4px rgba(26,80,224,0.15)`).
3.  **Card Press Interaction:**
    *   *Behavior:* Cards scale down slightly on touch (`transform: scale(0.98)`, duration: `150ms`, ease: `ease-out`) and return to `scale(1)` on release before triggering navigation.
4.  **Smooth Screen Transitions:**
    *   *Transition Type:* Native Stack Push/Pop. Slide from right (`translateX: 100% -> 0%`) with simultaneous fade-in for entering screens, and parallax shift for exiting screens.
