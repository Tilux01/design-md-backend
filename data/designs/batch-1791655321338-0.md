# Design Specification: "LingGuang" Glassmorphism & Neumorphic UI System

## 1. Global Design System & Typography

### Color Palette
*   **Primary Theme Accent:** Electric Blue / Cyan (`#00A3FF`, `#2684FF`)
*   **Light Mode Surfaces:**
    *   App Background: `#EAEFF5` to `#F3F7FA` (Soft neutral blue-gray gradient)
    *   Glass Surfaces: `rgba(255, 255, 255, 0.65)` with heavy backdrop blur (`blur(20px)`)
    *   Neumorphic Shadows (Light Mode): 
        *   Highlight: `-6px -6px 16px rgba(255, 255, 255, 0.9)`
        *   Shadow: `6px 6px 16px rgba(163, 177, 198, 0.6)`
    *   Text Primary: `#1E293B` (Slate 800)
    *   Text Secondary: `#64748B` (Slate 500)
*   **Dark Mode Surfaces:**
    *   App Background: `#0B0F19` to `#111827` (Deep space blue/black)
    *   Glass Surfaces: `rgba(255, 255, 255, 0.05)` to `rgba(255, 255, 255, 0.1)`
    *   Neumorphic Shadows (Dark Mode):
        *   Highlight: `-4px -4px 12px rgba(255, 255, 255, 0.05)`
        *   Shadow: `6px 6px 16px rgba(0, 0, 0, 0.8)`
    *   Text Primary: `#FFFFFF`
    *   Text Secondary: `#9CA3AF`

### Typography Stack
*   **Primary Font Family:** `Inter`, `SF Pro Display`, `-apple-system`, `sans-serif`
*   **Fallback Font Stack:** `Roboto`, `Helvetica Neue`, `Arial`, `sans-serif`
*   **Type Scale:**
    *   *Screen Headers (Titles):* 18px - 20px, Semi-Bold (`font-weight: 600`), Letter spacing: `-0.01em`
    *   *Section Headings:* 14px - 16px, Medium (`font-weight: 500`)
    *   *Body / Card Text:* 12px - 13px, Regular (`font-weight: 400`)
    *   *Captions / Subtext:* 10px - 11px, Regular (`font-weight: 400`), Slate color

## 2. Screen-by-Screen Breakdown (Top to Bottom, Left to Right)

---

### ROW 1

#### Screen 1.1: Light Dashboard (Minimalist)
*   **Layout Structure:** Single vertical scroll view, rounded card container.
*   **Top Bar:** Standard iOS status bar (9:41, Wi-Fi, Battery icons). Back arrow icon + Center-aligned title text ("LingGuang").
*   **Main Components:**
    *   **Profile Row:** Circular avatar placeholder with user details text next to it.
    *   **Primary Action Card:** Large floating pill-shaped button with soft inner shadows and prominent outer drop shadow. Text: "Services" with a small dropdown/chevron.
    *   **Quick Menu Grid:** 4-icon horizontal row inside a frosted glass pill container (Home, Search, Profile, Settings).
*   **Bottom Navigation Bar:** Floating bottom nav bar with 5 circular neumorphic icon buttons. Active item features an indented inner shadow with a blue glowing dot.

#### Screen 1.2: Light Profile & Activity Hub
*   **Layout Structure:** Structured vertical stack with data cards.
*   **Top Bar:** User name label, dual action buttons on the right (Notifications, Settings).
*   **Main Components:**
    *   **Recent Activity Card:** Dark-themed floating container (`#0F172A`) embedded inside the light UI. Displays statistical rows with white and blue numerical data labels (`3589`, `7500`).
    *   **Icon Grid:** Row of 5 circular glyph buttons featuring soft borders and subtle inset highlights.
*   **Bottom Bar:** Standard floating navigation bar matching Screen 1.1.

#### Screen 1.3: Dark Theme Menu & Settings
*   **Layout Structure:** Deep dark mode UI (`#0B0F19` background).
*   **Main Components:**
    *   **Header:** "LingGuang" title centered.
    *   **Interactive List Items:** Full-width frosted glass list tiles (`Setting`, `Notifications`, `Preferences`, `Database`). Each tile features a right-aligned circular arrow button (`>`) with a glowing blue border.
    *   **Borders:** Subtle 1px translucent borders (`rgba(255,255,255,0.08)`) defining structural containers.

#### Screen 1.4: 3D Floating Glass Deck (Light Mode)
*   **Layout Structure:** Clean, expansive light background showcasing a 3D isometric stack of floating glass cards.
*   **Main Visual Element:** 
    *   **Floating UI Deck:** Two stacked, translucent glass morphism cards tilted at an isometric angle (approx. 15-degree rotation). 
    *   The cards display miniature UI widgets (charts, toggles, icon grids) rendered in high-gloss transparency with glowing blue/cyan inner light reflections.
*   **Bottom Navigation:** Standard floating dock with active center tab.

## 3. Implementation Guidelines for Developers

1.  **Glassmorphism Effect CSS Formula:**
    ```css
    background: rgba(255, 255, 255, 0.65);
    backdrop-filter: blur(20px);
    -webkit-backdrop-filter: blur(20px);
    border: 1px solid rgba(255, 255, 255, 0.4);
    ```
2.  **Neumorphism Box-Shadow Formula (Light):**
    ```css
    box-shadow: -8px -8px 20px rgba(255, 255, 255, 0.8), 
                 8px 8px 20px rgba(163, 177, 198, 0.5);
    ```
3.  **Glow Effects:** Use multi-layered box shadows with primary theme colors (`#00A3FF`) at 30% to 50% opacity for floating active states and glowing elements.
