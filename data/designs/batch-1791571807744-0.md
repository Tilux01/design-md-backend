# UI Design Specification: Healthcare Appointment Management App

## 1. Global Layout & Structure

### Viewport & Background
- **Layout Mode**: Full-screen layout (ignoring the device frame/mockup borders from the source image).
- **Background Color**: Light aqua/mint tint (`#E8F4F2` or similar soft pastel gradient).
- **Decorative Elements**: Faded botanical leaf illustrations positioned in the bottom-left and bottom-right corners behind the primary application window.

### Main Container
- **Card Container**: Rounded container spanning most of the viewport with a clean white background (`#FFFFFF`), subtle drop shadow (`box-shadow: 0px 10px 40px rgba(0, 0, 0, 0.05)`), and rounded corners (`border-radius: 24px`).
- **Layout Split**: Two-column master-detail layout:
  - **Left Sidebar**: Fixed vertical navigation bar (`width: ~100px`) seamlessly integrated with a "Your Treatment" timeline list panel (`width: ~350px`).
  - **Right Panel**: Main interactive area for "Your Doctor", "Your Data", and "Make an Appointment" actions (`flex: 1`).

---

## 2. Typography & Fonts

### Primary Font Family
- **Font Stack**: `Inter`, `SF Pro Display`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`.
- **Fallback Hierarchy**: If Google Fonts (`Inter`) or system sans-serif fonts are unavailable, fallback to standard system sans-serif fonts.

| Element | Font Size | Weight | Line Height | Color / Hex |

## 5. Image & Asset Placeholders (Descriptions)
