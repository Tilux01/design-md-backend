# Visual Design Specification: "Creative Gradients" UI Component

## 1. Global Layout & Canvas Architecture
*   **Target Viewport:** Full-screen responsive (CSS `min-height: 100vh`, `width: 100vw`).
*   **Background Color:** Soft, clean off-white `#F3F3F3` or pure `#FAFAFA`.
*   **Z-Index Layering (Back to Front):**
    1.  *Background layer:* Canvas surface.
    2.  *Header text:* Left-aligned metadata (`ICON LIBRARY`, `DESIGN RESOURCES`).
    3.  *Stacked cards (Back to Front):*
        *   Card 4 (Top/Deepest in stack, Dark Teal-to-Blue): `top: 255px`
        *   Card 3 (Purple-to-Pink): `top: 285px`
        *   Card 2 (Green gradient): `top: 325px`
        *   Card 1 (Foreground Red/Pink primary card): `top: 375px`
    4.  *Footer:* Social handle (`@nina skrbic`) and minimalist bookmark icon.

## 3. Component Breakdown & Styling

### A. Top Navigation Metadata
*   **Layout:** Flex row, pinned near the top-left of the content wrapper (`gap: 24px`, padding top `40px`).
*   **Left Item:** `"ICON LIBRARY"` — Dark black uppercase text.
*   **Right Item:** `"DESIGN RESOURCES"` — Muted gray uppercase text (`#717171`).

### B. Stacked Gradient Cards (The Stack Effect)
The stack uses absolute positioning or relative shifting with overlapping negative margins to create a physical card-deck illusion, complete with subtle drop shadows to separate layers.

*   **Common Card Properties:**
    *   `border-radius`: `28px` (Top corners match, bottom cards are hidden mostly by foreground card).
    *   `box-shadow`: `0px 10px 30px rgba(0, 0, 0, 0.08)` (gives depth between sheets).

*   **Card 4 (Back / Topmost visual slice):**
    *   *Gradient:* Horizontal linear gradient from dark navy `#1E3A5F` to bright cyan `#00BCD4`.
    *   *Dimensions:* `width: 580px`, `height: 80px`.
*   **Card 3 (Middle-Back):**
    *   *Gradient:* Soft radial/linear transition from deep indigo `#1C2341` to lavender-pink `#C084FC`.
    *   *Dimensions:* `width: 630px`, `height: 90px`.
*   **Card 2 (Middle-Front):**
    *   *Gradient:* Deep emerald green `#1E513A` fading to vibrant mint green `#34D399`.
    *   *Dimensions:* `width: 680px`, `height: 100px`.
*   **Card 1 (Foreground Hero Card):**
    *   *Gradient:* Linear gradient angled diagonally from soft pastel pink (`#F472B6`) at top-left to vibrant rich red (`#EF4444`) at bottom-right.
    *   *Dimensions:* `width: 740px`, `height: 410px`.
    *   *Border Radius:* `32px` on top-left and top-right, `32px` on bottom-left and bottom-right.
    *   *Content inside Foreground Card:*
        *   **Volume Tag:** Absolute positioned top right (`right: 48px`, `top: 40px`). Text: `VOL.01` (stacked) / `2025` in white.
        *   **Main Title:** `"Creative Gradients"` placed at `left: 48px`, `bottom: 110px`. Font size 56px, bold white.
        *   **Description Text:** `"Gradients are a simple way to bring movement into static design. Here are my four favorite variations from this week's experiments."`
            *   Max-width: `460px`.
            *   Color: Pure white with high legibility.

### C. Footer Elements
*   **Layout:** Flex row, space-between, pinned near the bottom.
*   **Left Element:** `@nina skrbic` (Inter Medium, 12px, dark gray).
*   **Right Element:** Minimalist **Bookmark Icon** (SVG path styled with a solid fill matching the neutral dark gray `#9CA3AF` or `#6B7280`).

## 4. Animation Specification (Interactive / Motion)

If building this as an interactive UI component (e.g., Framer, React/CSS), implement the following transitions:

1.  **Hover State on Card Stack:**
    *   When the user hovers over the card container, the background cards fan upward and outward (`translateY` offset increases by `-12px` per card, with slight rotation angles like `rotate(-1deg)` for Card 4 and `rotate(1deg)` for Card 3).
    *   *Transition property:* `all 0.4s cubic-bezier(0.16, 1, 0.3, 1)` (Spring-like easing).

2.  **Entrance Animation (Load):**
    *   *Initial state:* Cards are stacked flat on top of each other at the center (`translateY(40px)`, `opacity: 0`).
    *   *Keyframes:* Animate up to their respective stacking positions sequentially with a `0.08s` stagger delay.
