# 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Brand Archetype**: Futuristic, tactile, ultra-modern, skeuomorphic-neumorphic fusion (Neo-Skeuomorphism / Claymorphic Soft-UI). It feels like touching physical clay or translucent sculpted glass in zero-gravity space.
- **Visual Density**: Medium-high functional density arranged in distinct hierarchical groupings, wrapped with airy whitespace and generous padding ratios.
- **Whitespace Balance**: Generous internal component padding (16px–24px) paired with compact grid gaps (12px–16px) to maximize touch target ergonomics.
- **Theme Balance**: Dual-state interface featuring both deep abyssal dark mode (`#0b0d19`) and pristine pearl light mode (`#f0f2f8`), seamlessly blended via an organic, diagonal liquid-peel transition line.
- **Texture & Depth Architecture**: Multi-layered soft shadows (`box-shadow`), inner bevel highlights, subtle linear gradients, and frosted glass backdrops (`backdrop-filter: blur()`) to simulate realistic soft-light illumination from the top-left source.

# 4. Layout Architecture & Spatial Grid

- **Container Max-Width**: Fixed mobile viewport simulation (`max-width: 412px`, `min-height: 844px`).
- **Padding & Margin Scale**:
  - Screen Outer Padding: `24px` horizontal, `28px` vertical
  - Grid Gap (Cards): `14px` horizontal, `14px` vertical
  - Inner Component Padding: `16px`
- **Section Sequence Breakdown**:
  1. **Status / Header Navigation Bar**: Profile avatar, cloud sync icon, menu triggers.
  2. **Search / Utility Bar**: Rounded pill search input with query placeholder and search glyph.
  3. **Featured Document Capsule**: Large banner card with storage loading bar and item counts.
  4. **Categorized Grid Matrix**: 3-column interactive shortcut grid for assets, folders, media, and tools.
  5. **Floating Action Dock**: Centered bottom action bar with quick actions and home/settings anchors.
- **Stacking Order & z-index**:
  - Background Canvas: `z-index: 0`
  - Base Cards & Content: `z-index: 10`
  - Floating Liquid Overlay Panel: `z-index: 20`
  - Floating Action Dock / Bottom Nav: `z-index: 30`
  - Modals / Tooltips: `z-index: 50`

      </div>

      </span>
      <span className={`text-[10px] mt-0.5 ${isDark ? 'text-slate-400' : 'text-slate-500'}`}>
        {subtitle}
      </span>
    </div>
  );
}

# 7. Accessibility (a11y) & WCAG Contrast Audit

- **Contrast Ratios**:
  - Dark Mode Text (`#f8fafc`) on Dark Surface (`#191d30`): **13.4:1** (Passes WCAG AAA)
  - Light Mode Text (`#1e293b`) on Light Surface (`#ffffff`): **14.2:1** (Passes WCAG AAA)
  - Muted Secondary Text (`#64748b`) on Light Surface (`#ffffff`): **5.1:1** (Passes WCAG AA)
- **Keyboard Focus Ring Specs**:
  ```css
  button:focus-visible, input:focus-visible {
    outline: none;
    box-shadow: 0 0 0 3px rgba(99, 102, 241, 0.6), var(--shadow-clay-light);
  }
  ```
- **Touch Target Minimums**: All interactive shortcut cards and icon buttons exceed `48px × 48px` to ensure optimal touch ergonomics on mobile viewports.
