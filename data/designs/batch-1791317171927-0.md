# Comprehensive Design Specification & Technical Architecture

---

## 1. Design Philosophy & Overall Aesthetic
* **Primary Mood:** High-performance, immersive, energetic, premium athletic-tech.
* **Brand Archetype:** Elite sports coaching & performance optimization platform.
* **Visual Density:** Medium-high; multi-layered sports analytics dashboard balanced with dark, rich forest tones.
* **Whitespace Balance:** Structured alignment utilizing precise grid-based containment and clear zonal separation.
* **Theme Balance:** Dark mode dominant (100% dark theme architecture) featuring deep forest green surfaces, vibrant neon chartreuse accent highlights (`#CCFF00`), and layered translucency to create depth.

## 3. Typography System & Hierarchy

* **Headings / Display:** `Inter`, `Syne`, or high-impact grotesque sans-serif (Font-weight: 800 italic for sports impact).
* **Body / Subtitles:** `Inter`, `SF Pro Display`, `-apple-system`, sans-serif.

## 4. Layout Architecture & Spatial Grid

* **Container Max-Width:** `1440px` fluid with responsive inner gutters (`24px` mobile, `48px` desktop).
* **Grid Structure:** 12-column flex/grid hybrid layout.
* **Z-Index Hierarchy:**
  * `z-0`: Base canvas & background gradients
  * `z-10`: Structural cards & interactive modules
  * `z-20`: Floating navigation headers & glass panes
  * `z-30`: Motion elements (flying tennis balls, cursor trackers)
  * `z-50`: Modals, tooltips, and overlay alerts

## 8. Accessibility (a11y) & WCAG Contrast Audit

* **Contrast Ratios:**
  * Primary Text (`#FFFFFF`) on Deep Forest Background (`#0B281B`) $\rightarrow$ **14.2:1** (Passes WCAG AAA)
  * Accent Text (`#CCFF00`) on Deep Forest Background (`#0B281B`) $\rightarrow$ **11.8:1** (Passes WCAG AAA)
  * Secondary Text (`#A3B8AD`) on Deep Forest Background (`#0B281B`) $\rightarrow$ **7.1:1** (Passes WCAG AAA)
* **Keyboard Focus Rings:**
  ```css
  *:focus-visible {
    outline: 2px solid #CCFF00;
    outline-offset: 4px;
    box-shadow: 0 0 12px rgba(204, 255, 0, 0.5);
  }
  ```
