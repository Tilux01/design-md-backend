# Design Specification: 360 POD Interface

## 1. Overview & Layout Strategy
- **Layout Model**: Full-screen, 3-column dashboard (100vw, 100vh, `overflow: hidden`).
- **Structure**:
  - **Left Panel (25%)**: Ambience and climate controls.
  - **Center Stage (48%)**: Netflix branding, 3D pod showcase, hero titles.
  - **Right Panel (27%)**: Media browser, search header, playback controls.
- **Visual Style**: Glassmorphic UI with soft radial backdrops, blurred glass panels, and ambient rim lighting.

---

## 2. Color Palette & Visual Effects
- **Background Gradient**: Multi-point mesh gradient:
  - Top-Left: Soft rose/mauve (`#E5B5C8`)
  - Center/Base: Muted slate blue (`#8FA0B8` to `#4D5C75`)
  - Bottom-Right: Ambient coral pink (`#E29CA9`)
- **Glass Panels**:
  - Background: `rgba(255, 255, 255, 0.16)` to `rgba(255, 255, 255, 0.08)`
  - Border: `1px solid rgba(255, 255, 255, 0.35)`
  - Blur: `backdrop-filter: blur(30px)`
  - Border Radius: `28px` (cards), `9999px` (pills)
- **Accents**:
  - Primary Neon Glow: `#FF4D4D` (orange-red neon)
  - Active Indicators: `#FFFFFF`
  - Secondary Text: `rgba(255, 255, 255, 0.65)`

---

## 4. Assets & Image Specifications

### Hero Capsule ("360 POD")
- **Description**: Futuristic ergonomic lounger capsule. Shell is glossy pearl-white with a contoured interior headrest and reclined seat. Inner edge features a vivid neon orange-red glowing LED ribbon.
- **Orientation**: Three-quarter angle facing right.
- **Transparency**: Fully backgroundless (transparent PNG/WebP).
- **Placement**: Centered in the middle panel, slightly floating above the ground reflection.

### User Avatar (Top-Right)
- **Description**: Circular headshot portrait of a woman against a neutral studio backdrop.
- **Badging**: 4px bright green active dot on the top-right edge.
- **Size**: 36px × 36px.

### Media Thumbnails
- **Description**: Circular video preview stills (e.g., animated robot, cinematic character shots).
- **Size**: 32px × 32px circular cutouts inside list item pills.

---

## 5. Component Breakdown

### Left Column: Environmental Controls
1. **Ambience Card**:
   - Header: "Customizable Ambience" (12px, soft white).
   - Radial Gauge: 270° circular track with glow head set to "70%".
   - Sub-icons: Dimming presets along the bottom.
2. **Temperature Card**:
   - Header: "Set Temperature".
   - Central Dial: Circular glass button displaying "24°C" with a bright red indicator dot.
   - Mode Dock: 4 square frosted buttons below (`Cool`, `Wind`, `Heat`, `Auto` icons).

### Center Column: Showcase & Brand
1. **Top Floating Pill**:
   - Small frosted capsule containing 4 minimal system icons (profile, settings, sync, power).
2. **Netflix Wordmark**:
   - Centered above the pod showcase.
3. **Hero Image**:
   - Transparent pod asset with soft base shadow.
4. **Hero Typography**:
   - Heading: "360 POD" in ultra-wide geometric font.
   - Description: Two-line concise copy detailing immersive viewing and sensory feedback.

### Right Column: Media Hub
1. **Search Bar & Profile Dock**:
   - Search input pill with magnifying glass icon and translucent placeholder text.
   - Mail/notifications button and user avatar.
2. **Media Selector Card**:
   - Segmented control: `[ Shows | Movies ]`.
   - Playlist: 5 stacked rounded list items. Each row contains:
     - Circular thumbnail (left).
     - Title and duration/genre (middle).
     - Subtle chevron or play icon (right).
   - Pagination: 4 dot indicators at bottom (first item active as a pill).
3. **Player Bar**:
   - Title: "The Wild Robot" (13px, bold).
   - Scrubber: Thin progress bar with draggable handle.
   - Controls: Shuffle, Previous, Play/Pause, Next, Repeat icons.
