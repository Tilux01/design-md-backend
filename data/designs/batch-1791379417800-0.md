# Design Specification: Agentix Landing Page Hero

## 1. Overview
This specification details the exact visual design, layout, typography, and animation cues for the **Agentix** hero section. The design features a scenic, illustrated mountain-and-lake landscape, a floating glassmorphic navigation bar, prominent centered typography with accented italicized text, and scattered semi-transparent frosted glass UI fragments.

---

## 2. Global Layout & Structure

*   **View:** Full-screen responsive viewport (`width: 100vw`, `height: 100vh` or min-height 800px).
*   **Background:** 
    *   Base color: Pure white (`#FFFFFF`) in the central content area, blending into an illustrated landscape at the top and bottom.
    *   Top: Pastel clouds with soft pink/orange sunset hues against a pale sky.
    *   Bottom: Layered blue mountain ranges, a reflective alpine lake, evergreen forests, and a foreground field of wildflowers and rocks.
*   **Content Alignment:** Flexbox or Grid, centered vertically and horizontally.

---

## 3. Navigation Bar (Header)

*   **Container:** Pill-shaped floating container centered horizontally near the top.
    *   Background: Semi-transparent white / frosted glass (`rgba(255, 255, 255, 0.85)`).
    *   Border/Shadow: Subtle drop shadow (`0px 4px 20px rgba(0, 0, 0, 0.06)`).
    *   Border-radius: `50px` (fully rounded pill).
    *   Padding: `8px 16px` (approx.).
*   **Logo (`agentix`):**
    *   Icon: Custom abstract geometric glyph (black, left of text).
    *   Text: "agentix", lowercase, bold, sans-serif, dark charcoal/black color (`#111111`).
    *   Font-family: Inter, system-ui, -apple-system, sans-serif.
    *   Fallback: `Arial, sans-serif`.
*   **CTA Button ("Try for free"):**
    *   Background: Solid dark forest green (`#2D4A22` or `#355E3B`).
    *   Text color: White (`#FFFFFF`).
    *   Border-radius: `50px` (pill shape).
    *   Padding: `10px 20px`.
    *   Font-size: `14px`, medium weight.
    *   Fallback: `Arial, sans-serif`.

---

## 4. Typography (Hero Headline)

*   **Main Text:** "Measure the performance of every *AI agent*."
*   **Line 1:** "Measure the performance"
    *   Font-weight: Regular / Medium (`400` - `500`).
    *   Font-size: `clamp(36px, 5vw, 64px)`.
    *   Color: Dark charcoal / near-black (`#1A1A1A`).
    *   Alignment: Centered.
*   **Line 2:** "of every *AI agent*."
    *   "of every ": Regular weight, same style as Line 1.
    *   "*AI agent.*": 
        *   Style: **Italic**.
        *   Color: Matching the dark forest green accent (`#355E3B`).
        *   Font-family (Primary): Inter or a clean geometric sans-serif with distinct italic styling.
        *   Fallback: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`.

---

## 5. Decorative UI Elements (Glassmorphic Cards)

Scattered across the landscape are frosted glass UI fragments (representing modular dashboard widgets/metrics):
*   **Styling:**
    *   Background: `rgba(255, 255, 255, 0.25)` to `0.40`.
    *   Backdrop-filter: `blur(12px)`.
    *   Border: `1px solid rgba(255, 255, 255, 0.4)`.
    *   Border-radius: `12px`.
    *   Box-shadow: `0 8px 32px 0 rgba(31, 38, 135, 0.07)`.
*   **Placement:** Distributed asymmetrically over the lower mountain sides, tree lines, and lake surface to add depth and a modern SaaS aesthetic.

---

## 6. Animations & Micro-Interactions

*   **Initial Load (Entrance Animation):**
    *   **Hero Text:** Fade-in with a slight upward translateY (`from { opacity: 0; transform: translateY(20px); } to { opacity: 1; transform: translateY(0); }`). Duration: `0.8s`, easing: `cubic-bezier(0.16, 1, 0.3, 1)`.
    *   **Navbar:** Drop-in from the top with fade (`translateY(-10px)` to `0`). Duration: `0.6s`.
    *   **Glass Elements:** Subtle stagger-fade, floating into position.
*   **Hover States:**
    *   **"Try for free" Button:** Scale up slightly (`transform: scale(1.03)`) with a minor increase in shadow depth on hover.
    *   **Glass Cards:** Optional subtle parallax tilt effect on mouse movement to enhance depth perception.
