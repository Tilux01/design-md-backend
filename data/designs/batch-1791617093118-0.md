# Comprehensive Design Specification (`design.md`)

This document serves as the complete, pixel-accurate blueprint for cloning the **"Discover the PLANET"** luxury exploration landing page. 

The design is rendered as a **full-bleed, edge-to-edge application** (`100vw` × `100vh`) with no external frames, drop shadows, or presentation bezels.

---

## 1. Design System & Tokens

### 1.1 Color Palette

| Token Name | Hex / RGBA | Usage |
| :--- | :--- | :--- |
| **Brand Accent (Red/Crimson)** | `#E62347` / `#EA2B58` | "the" script font, "Search" active pill, "TO BEGIN" button, Logo mark |
| **Brand Accent Hover** | `#D01B3E` | Interactive hover states on red controls |
| **Pure White** | `#FFFFFF` | "Discover" headline, icons, outlined "PLANET", active pagination buttons |

## 2. Typography Specification

### 2.1 Font Stacks & Fallbacks

1. **Primary Geometric Sans-Serif (Headings & UI Microcopy)**:
   * **Primary**: `Cabinet Grotesk`, `Syne`, or `Montserrat`
   * **Fallback**: `Inter`, `Helvetica Neue`, `Arial`, sans-serif
   * **Usage**: "Discover", "PLANET", Navigation items, CTA button text, status markers.

2. **Accent Editorial Script (Signature Font)**:
   * **Primary**: `Reenie Beanie`, `Caveat`, `Autography`, or `Brittany Signature`
   * **Fallback**: `'Brush Script MT'`, `cursive`
   * **Usage**: The flowing lowercase text **"the"** intersecting the primary headline.

## 3. Photographic Background Asset

* **Background Type**: Full-bleed photographic image (not transparent/backgroundless; complete cinematic scene).
* **Subject**: Panoramic, high-altitude view of rugged mountain chains and rolling mountain ridges fading into a misty distant valley.
* **Lighting & Atmosphere**: 
  * Early dawn or late dusk low-sun atmosphere.
  * An intense, diffused glow of the sun breaking through heavy, dramatic cumulus cloud cover in the upper-left horizon.
  * Silhouetted dark ridgelines in the foreground and midground, transitioning into hazy, atmospheric blue-grey valleys in the distance.
* **Palette**: Steel blue (`#3B4856`), deep charcoal slate (`#1C222A`), soft cloud grey (`#8B95A2`), and pale incandescent sunlight (`#EAEFF5`).
* **CSS Specs**:
  ```css
  background-image: url('/assets/images/mountain-dawn.jpg');
  background-size: cover;
  background-position: center 38%;
  background-repeat: no-repeat;
  width: 100vw;
  height: 100vh;
  ```

## 4. Layout & Grid Architecture

### 4.1 Structural Layout
* **Viewport Size**: `100vw` wide by `100vh` high. Overflow hidden (`overflow: hidden`).
* **Grid Overlay System**:
  * The entire screen is overlaid with **6 equally spaced vertical columns** created by **5 ultra-thin vertical grid lines**.
  * Line styling: `1px solid rgba(255, 255, 255, 0.12)`.
  * Grid lines span the absolute full height (`height: 100vh`) from top to bottom.
  * `pointer-events: none; z-index: 2;`

* **Symbol**: Stylized lowercase double-curved **"w"** emblem in vibrant crimson `#E62347`.

### 5.2 Center Hero Block

* **Container Position**: Absolute center of the screen (`top: 48%`, `left: 50%`, `transform: translate(-50%, -50%)`).
* **Z-Index**: `5`.
* **Content Stack**:

#### 1. First Row ("Discover the")
* **Layout**: Horizontal flex container, baseline alignment, centered.
* **Underline Bar**:
  * A thin horizontal baseline underline (`height: 1px`, `background: rgba(255, 255, 255, 0.6)`) extends horizontally across the bottom edge of "Discover the", spanning from the left of the "D" to past the "e" in "the".
* **Word "Discover"**:
  * Solid white (`#FFFFFF`), geometric, bold sans-serif.
* **Word "the"**:
  * Flowing script font, overlapping slightly at the end of "Discover".
  * Color: `#E62347`.
  * Angled naturally upwards by -6 degrees.

#### 2. Second Row ("P L A N E T")
* **Layout**: Centered directly underneath line 1 with `margin-top: 10px`.
* **Style**: Hollow / Outlined Typography.
  * Color: `transparent`.
  * Stroke: `-webkit-text-stroke: 2px #FFFFFF`.
  * Tracking / Letter-spacing: `0.32em`.
  * Text alignment: `center`.

#### 3. Third Row (Call-To-Action Button)
* **Button Text**: `"TO BEGIN"` + Magnifying Glass Icon (`Q` glyph or SVG search icon).
* **Position**: Centered, `margin-top: 32px`.
* **Dimensions & Padding**: `height: 34px`, `padding: 0 18px`.
* **Background**: Solid Crimson `#E62347`.
* **Border Radius**: `4px` (subtle rounded corners).
* **Typography**: White (`#FFFFFF`), `font-size: 10.5px`, `font-weight: 700`, `letter-spacing: 0.18em`.
* **Icon**: Search / Magnifier icon (`size: 11px`), placed `6px` to the right of "BEGIN".
