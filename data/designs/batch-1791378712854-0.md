# UI/UX Specification: Starbucks "Double Chocolate Chip Frappuccino" App Screen

This specification details the exact design, layout, typography, color palette, and interactive behavior for a full-screen mobile interface showcasing the Starbucks Double Chocolate Chip Frappuccino, as presented in the reference image.

---

## 1. Global Layout & Screen Structure

*   **Platform Target:** iOS (Optimized for modern notched/Dynamic Island displays like iPhone 14/15 Pro).
*   **Orientation:** Portrait.
*   **Viewport Dimensions:** Full-screen (`width: 100vw`, `height: 100vh`).
*   **Background:** 
    *   Solid Vibrant Green (`#00A862` or Starbucks Green variant).
    *   Subtle ambient background imagery (blurred/ghosted product silhouettes in the background layers, moving out of focus).
*   **Content Hierarchy:**
    1.  **Top Navigation / Status Bar & Brand Header:** Time, system icons, and centered Starbucks logo box.
    2.  **Hero Product Image:** Centered floating beverage illustration casting a soft drop shadow.
    3.  **Bottom Content Sheet (Card):** Rounded white card overlay containing pricing, volume, title, product description, and the primary CTA button.

---

## 2. Color Palette

| Color Role | Hex Code / Value | Usage |
| :--- | :--- | :--- |
| **Primary Brand Green** | `#006241` (Starbucks Green) / `#00A862` | Background screen tint / Logo backdrop |
| **Surface White** | `#FFFFFF` | Bottom content sheet background |
| **Primary Text (Dark)** | `#111111` or `#1E1E1E` | Headings, Product Title, Price |
| **Secondary Text (Muted)** | `#666666` or `#7A7A7A` | Body description, Volume badge text |
| **Button / Interactive** | `#111111` (Deep Charcoal/Black) | "Get it" CTA button |
| **Badge Background** | `#F0F0F0` | Volume selector pill background (`345ml`) |
| **Shadow / Elevation** | `rgba(0, 0, 0, 0.15)` | Drop shadows for floating product and bottom card |

---

## 3. Typography & Font Stack

*Note: Since exact proprietary Starbucks brand fonts (like *Sodo Sans*) are proprietary, system fallback stacks are specified for pixel-perfect cross-platform rendering.*

### Primary Font Family
*   **iOS:** `SF Pro Display`, `SF Pro Text`, `-apple-system`, `BlinkMacSystemFont`
*   **Android / Web Fallback:** `Inter`, `Roboto`, `Helvetica Neue`, `Arial`, `sans-serif`

### Type Scale & Styles

1.  **Status Bar (Top Left):**
    *   Font Size: `15px` / `16px` (Semibold)
    *   Color: `#FFFFFF`
2.  **Price Display:**
    *   Prefix (`$`): `20px` (Bold)
    *   Value (`11`): `32px` / `36px` (Heavy / Bold)
    *   Color: `#111111`
3.  **Volume Badge (`345ml`):**
    *   Font Size: `13px` (Medium)
    *   Color: `#555555`
4.  **Product Title ("Double Chocolate Chip Frappuccino"):**
    *   Font Size: `22px` – `24px` (Bold / Line-height: `1.2`)
    *   Color: `#111111`
5.  **Product Description:**
    *   Font Size: `13px` – `14px` (Regular / Line-height: `1.45`)
    *   Color: `#666666`
6.  **CTA Button Text ("Get it"):**
    *   Font Size: `16px` (Semibold)
    *   Color: `#FFFFFF`

---

## 4. Component Breakdown

### A. Header Section
*   **Top Bar:** Standard iOS Status Bar (WiFi, Cellular, Battery icons right-aligned, 9:41 time left-aligned in white).
*   **Brand Logo Box:**
    *   Container: Rounded rectangle (`border-radius: 16px`), solid Starbucks Green fill, dark border stroke.
    *   Content: Centered white siren logo graphic above the typography "STARBUCKS" in a tracked-out uppercase sans-serif font.

### B. Hero Product Illustration
*   **Placement:** Centered horizontally, positioned dynamically between the header and the bottom sheet.
*   **Visual:** High-resolution vector/PNG render of the Double Chocolate Chip Frappuccino in a clear plastic cup with whipped cream, chocolate drizzle, and a green straw.
*   **Effect:** Soft, diffused drop shadow underneath the base of the cup to create a floating depth effect.

### C. Bottom Content Sheet (Card)
*   **Shape:** Container with fully rounded top corners (`border-radius-top: 32px`).
*   **Background:** Solid `#FFFFFF`.
*   **Padding:** Generous internal padding (approx. `24px` horizontal, `28px` vertical).
*   **Layout inside the card:**
    *   **Row 1 (Price & Volume):** 
        *   Left: Price (`$11`) styled prominently.
        *   Right: Volume pill badge (`345ml`) inside a light gray capsule (`border-radius: 20px`, padding: `6px 12px`).
    *   **Row 2 (Title):** 
        *   "Double Chocolate Chip Frappuccino" spanning 2 lines.
    *   **Row 3 (Description):** 
        *   *Text:* `"Rich mocha-flavored sauce meets up with chocolaty chips, milk and ice. Top it off with whipped vanilla topping and mocha drizzle for a real party in your mouth. A coffee Free Delight"`
    *   **Row 4 (CTA Button):** 
        *   Full-width pill/rounded rectangle button (`border-radius: 28px`, height: `52px`).
        *   Background: `#111111` (Black).
        *   Text: Centered white text reading `"Get it"`.

---

## 5. Animations & Micro-Interactions

*   **Page Load / Entry Animation:**
    *   *Hero Image:* Fades in with a slight upward slide (`translateY(20px)` to `0`).
    *   *Bottom Sheet:* Slides up smoothly from the bottom of the viewport (`spring` or `cubic-bezier(0.16, 1, 0.3, 1)` easing, duration: `0.5s`).
    *   *Background Ambient Elements:* Parallax scroll or subtle crossfade if navigating between carousel items.
*   **Touch / Tap Feedback:**
    *   *CTA Button ("Get it"):* Active state scales down slightly (`scale(0.97)`) with a subtle opacity drop (`0.9`) on touch down, snapping back on release.
