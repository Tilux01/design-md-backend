# Design Specification: Chokeberry Kombucha Landing Page

## 1. Global Layout & Colors

*   **Layout Style:** Asymmetric editorial grid, centered product showcase.
*   **Background Color:** Soft Lavender Pink (`#F4E2F7` or `rgb(244, 226, 247)`).
*   **Primary Text Color:** Dark Slate / Near Black (`#111111`).
*   **Accent Color (Shapes & Graphics):** Vibrant Purple (`#B144A5`).
*   **Full Screen Mode:** Designed to fill `100vw` and `100vh` with flexbox centering.

---

## 2. Typography & Fonts

### **Primary Title Font ("Chokeberry")**
*   **Style:** Heavy, rounded sans-serif geometric display font.
*   **Suggested Font Families:** 
    *   *Primary:* `Rubik`, sans-serif (Extra Bold / 900 weight).
    *   *Fallback:* `Comfortaa`, `Arial Black`, `sans-serif`.
*   **CSS Properties:**
    *   `font-size`: `clamp(3rem, 7vw, 6.5rem)`
    *   `font-weight`: `900`
    *   `letter-spacing`: `-0.03em`

### **Body & Secondary Copy ("Seeking for unforgettable...", Ingredients)**
*   **Style:** Clean, minimal, modern geometric sans-serif.
*   **Suggested Font Families:**
    *   *Primary:* `Inter`, sans-serif.
    *   *Fallback:* `Helvetica Neue`, `Arial`, `sans-serif`.
*   **CSS Properties (Paragraphs):**
    *   `font-size`: `0.85rem`
    *   `line-height`: `1.5`
    *   `font-weight`: `400`
*   **CSS Properties (Product Details / 330 ml):**
    *   `font-size`: `0.8rem`
    *   `font-weight`: `700`

---

## 3. Section-by-Section Breakdown

### A. Top Headline
*   **Text:** `Chokeberry`
*   **Positioning:** Upper-left aligned, overlapping slightly into the center stage.
*   **Note:** The letter `b` is stylized with a smaller `e` nested inside or tucked closely beneath the main cap/loop depending on brand vector, but standard heavy typography works as a base.

### B. Left-Side Copy Block
*   **Heading/Question:** `Seeking for unforgettable taste sensations?`
*   **Subtext:** `Our exclusive chokeberry kombucha is right for you.`
*   **Width:** Max `220px` to maintain a tight editorial column layout.

### C. Center Stage (Product & Floating Shapes)
*   **Background Blobs:** 
    *   Irregular organic soft purple vectors (`#C373D6` or opacity-layered `#B144A5`).
    *   Positioned directly beneath the tilted bottle.
*   **Doodle Line Art:**
    *   Hand-drawn style thin outline vector flowers (daisies/star-petals) scattered near the purple blobs and bottle cap. Stroke color: Dark Slate (`#111111`), stroke width: `1.5px`.
*   **Product Bottle:**
    *   **Angle:** Rotated approximately `-15 degrees` (tilted to the right/upwards).
    *   **Label Details:** 
        *   Logo text: `HOIICH` (or stylized KHOIICHA lettering) in bold outlined bubble font.
        *   Graphic: Two stylized round chokeberries in deep purple.
    *   **Shadow:** Soft, diffused drop-shadow underneath the tilted bottle for 3D depth.

### D. Right-Side Product Details Panel
*   **Volume:** `330 ml` (Bold, larger font weight).
*   **Dividers:** Thin horizontal rules (`border-bottom: 1px solid rgba(0,0,0,0.1)`).
*   **List Items:**
    1.  `fermented carbonated tea`
    2.  `chokeberry juice`
    3.  `non-alcoholic`

## 4. Animations & Micro-Interactions (Optional / Recommended)

To bring the layout to life, apply the following CSS transitions and keyframe animations:

1.  **Bottle Floating Animation:**
    ```css
    @keyframes float {
      0% { transform: rotate(-15deg) translateY(0px); }
      50% { transform: rotate(-15deg) translateY(-10px); }
      100% { transform: rotate(-15deg) translateY(0px); }
    }
    .product-bottle {
      animation: float 4s ease-in-out infinite;
    }
    ```

2.  **Fade-In Load:**
    *   All elements fade up sequentially (`opacity: 0` to `1`, `transform: translateY(20px)` to `0`) with a `0.6s` delay stagger using CSS transitions.
