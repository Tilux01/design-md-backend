# UI/UX Design Specification & Clone Blueprint

This document outlines the precise specifications for cloning the mobile application interface shown in the source media. It focuses on modern e-commerce mobile design patterns, typography rules, layout grids, and interactive states.

---

## 1. Global Design System & Foundations

### 1.1 Color Palette
The interface adopts an earthy, minimalist, high-end lifestyle aesthetic combining deep botanical greens with warm, desaturated neutral paper backgrounds.

*   **Primary Brand Color (Deep Olive):** `#2A332A` (Used for app splash screens, primary headers, badges, and primary action buttons)
*   **Secondary Surface / Container (Warm Paper / Cream):** `#F4F1EA` (Used for product card backdrops and soft containers)
*   **Background (Light Mode):** `#FAF8F5` (Off-white, warm neutral body background)
*   **Text Primary (Dark Charcoal):** `#1E201E` (High contrast for main headings and titles)
*   **Text Muted (Warm Gray):** `#7A7570` (Subtitles, secondary metadata, inactive states)
*   **Border / Divider Line:** `#E2DCD3` (Soft structural dividers)
*   **Accent / Highlight:** `#D4AF37` (Muted Metallic Gold—used sparingly for ratings or special badges, if applicable)

### 1.2 Typography System & Fallbacks

The application relies on high-end serif editorial typography paired with clean, geometric sans-serif for UI legibility.

#### Primary Editorial Serif (Headings, Branding, Splash Screen)
*   **Target Font Family:** `Cormorant Garamond`, `Playfair Display`, or high-end editorial serif.
*   **Fallback Stack:** `Georgia, Cambria, "Times New Roman", Times, serif`
*   **Font Weights Used:** 
    *   *Regular (400)* for subtitles and elegant descriptions.
    *   *SemiBold / Bold (600–700)* for main branding and high-impact headings.

#### Primary UI Sans-Serif (Body, Buttons, Navigation, Prices)
*   **Target Font Family:** `Inter`, `Plus Jakarta Sans`, or `SF Pro Display` (iOS System Font).
*   **Fallback Stack:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
*   **Font Weights Used:** 
    *   *Regular (400)* for body copy.
    *   *Medium (500)* for buttons and navigation items.
    *   *SemiBold (600)* for prices and section titles.

## 2. Screen-by-Screen Layout & Component Breakdown

Assuming a standard mobile viewport (Width: `390px` to `428px` / iPhone 14/15 Pro specification with native safe areas):

---

### Screen 1: Splash / Brand Welcome Screen
*   **Background Fill:** Solid Primary Brand Color (`#2A332A`).
*   **Layout Structure:** Flexbox centered vertical alignment (`justify-content: center; align-items: center;`).
*   **Center Element (Brand Identity):**
    *   **Logo/Wordmark:** Uppercase serif typography. Example tracking (letter-spacing): `3px` to `4px`.
    *   **Subtext:** Centered smaller sans-serif subtitle placed directly beneath the primary logo.
*   **Bottom Element:** 
    *   A subtle loading indicator or secondary tagline pinned just above the bottom safe area (`padding-bottom: 48px`).

---

### Screen 2: Product Discovery / Catalog Home
*   **Background:** `#FAF8F5`
*   **Top Navigation Bar:**
    *   **Left:** Menu / Hamburger Icon (stroke-width: `1.5px`, color: `#1E201E`).
    *   **Center:** Brand Wordmark or Category title (Editorial Serif, `18px`, Medium).
    *   **Right:** Search and Cart icons with notification indicator dots.
*   **Hero / Featured Banner Section:**
    *   **Container:** Rounded card container (`border-radius: 16px`), filled with warm paper tone (`#F4F1EA`).
    *   **Content:** Asymmetric grid or stacked layout featuring lifestyle photography, bold product headline, and a call-to-action button ("Explore" or "Shop Now").
*   **Grid / Horizontal Scroll Carousels:**
    *   Product cards featuring high-end square or portrait imagery (`aspect-ratio: 4/5`), minimal padding, minimalist typography for titles and prices (aligned left).

---

### Screens 3 & 4: Product Detail, Cart & Checkout Flow
*   **Background:** `#FAF8F5`
*   **Header Nav:**
    *   Back chevron icon on the left, clear screen title ("Cart" or "Checkout") centered, contextual action on the right (e.g., Edit, Close, or Item Count).
*   **List Items / Cart Cards:**
    *   **Structure:** Horizontal flex row (`thumbnail image` + `metadata text block` + `quantity/price controls`).
    *   **Thumbnail:** Fixed dimensions (e.g., `72px × 88px`), `border-radius: 8px`, containing high-contrast product photography.
    *   **Metadata:** 
        *   Product Title (Sans-serif, `14px`, SemiBold, `#1E201E`).
        *   Variant / Attributes (e.g., Size, Color) (Sans-serif, `12px`, Muted `#7A7570`).
        *   Price (Sans-serif, `14px`, Medium, `#1E201E`).
*   **Summary & Action Area (Bottom Sticky Footer):**
    *   **Divider:** Subtle 1px top border (`#E2DCD3`).
    *   **Subtotals / Fees:** Clean row alignment displaying item subtotal, shipping, and calculated tax.
    *   **Primary CTA Button:** 
        *   Full-width button (`height: 52px`, `border-radius: 26px` or rounded rectangle `12px`).
        *   Background: Primary Brand Color (`#2A332A`).
        *   Text: White (`#FFFFFF`), Sans-serif, `15px`, Medium, uppercase or title case with letter spacing.

## 3. Micro-Interactions & Animation Specifications

To replicate the high-end boutique feel of the app, apply the following physics and transition rules:

1.  **Page Transitions:** 
    *   Use smooth **Shared Element Transitions** (or standard iOS slide-from-right push/pop navigation) with a duration of `350ms` and an ease-out cubic-bezier curve (`cubic-bezier(0.16, 1, 0.3, 1)`).
2.  **Button Press State (Active/Tap):**
    *   Scale down slightly on touch (`transform: scale(0.97);`) with a quick transition (`100ms`).
3.  **Image Loading:**
    *   Fade-in transition (`opacity 0 -> 1` over `400ms`) backed by a skeleton loader using the warm surface tone (`#F4F1EA`) with a gentle pulsing shimmer effect.
4.  **Cart / Item Addition:**
    *   Subtle haptic feedback simulation paired with a badge counter scaling up (`scale(1.2) -> scale(1.0)`) over `200ms`.
