# Visual Design Specification: 3D E-Commerce Mobile App Experience

## 1. Overview & Layout Strategy
This specification details a modern, high-end e-commerce interface featuring a floating, isometric 3D product-exploration experience on a mobile screen. 

* **Layout Mode:** Full-screen immersive viewport (`100vw` × `100vh`).
* **Design System:** Neumorphic/Glassmorphic 3D hybrid design. Elements exist on a z-axis depth scale, breaking out of the standard 2D mobile container.
* **Canvas Background:** Minimalist, neutral soft-gradient studio lighting (warm grey/off-white scheme with subtle directional lighting and soft drop shadows below the phone chassis).

---

## 2. Color Palette & Lighting
The aesthetic relies on a monochromatic, high-end editorial palette with selective product color accents.

| Role | Color Name | Hex Code (Approx.) | Usage |
| :--- | :--- | :--- | :--- |
| **Background Base** | Warm Platinum | `#E8E7E3` to `#F4F3EF` | Main viewport & studio surface |
| **Phone Chassis** | Off-White Ceramic | `#F7F7F7` | Mobile device border/body |
| **Primary Text** | Deep Charcoal | `#2A2A2A` | Navigation, main headings, key labels |
| **Secondary Text** | Mid Taupe | `#7A7875` | Subtitles, metadata, inactive states |
| **Accent / Brand** | Terracotta / Rust | `#C85A32` | Highlights, active selections, badges |
| **Card Background** | Frosted Glass / White | `rgba(255, 255, 255, 0.85)` | Floating product cards and UI tiles |

---

## 3. Typography & Font Stack
The typography is clean, ultra-minimalist, geometric sans-serif, giving it a luxury fashion/lifestyle editorial feel.

* **Primary Font Family:** `Inter`, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `sans-serif`.
* **Fallback Stack:** Standard sans-serif system stack.
* **Font Hierarchy:**
  * **App Header / Delivery Text:** 12px, Regular, `#7A7875`
  * **Card Titles:** 14px, Medium, `#2A2A2A`
  * **Price / Subtext:** 12px, Regular, `#7A7875`

---

## 4. UI Components & Content Breakdown

### A. Mobile Device Frame
* **Dimensions:** Standard smartphone aspect ratio (approx. 9:19.5), centered with a prominent drop shadow (`box-shadow: 0px 30px 60px rgba(0,0,0,0.12)`).
* **Notch/Dynamic Island:** Modern pill-shaped cutout at the top center.
* **App Header:** 
  * Left: Hamburger menu icon (`☰`) and localized delivery indicator.
  * Right: Profile/Status indicators.

### B. Floating 3D Elements (Out-of-Bounds UI)
Elements break free from the 2D plane of the phone screen using layered CSS `transform: translateZ()` and drop shadows:
1. **Baseball Cap:** Floating top-right, angled down towards the screen, off-white/beige canvas texture.
2. **Sneakers (Main Feature):** Two white chunky lifestyle sneakers suspended in mid-air above the lower half of the screen.
3. **Floating Media Cards:** Assorted square product thumbnail tiles (jackets, accessories, shoes) floating along the left and right perimeters in a staggered parallax arrangement.

### C. In-App Product Cards (Inside Screen)
* **Active Jacket Card:** Displays a dark olive-green windbreaker/anorak with a checkmark badge (`✓`) indicating selection.
* **Secondary Thumbnails:** Grid layout showing alternate angles and related items with soft corner radii (`border-radius: 16px`).

---

## 5. Animation & Motion Specifications (UI/UX Motion)

To replicate the fluid, floating video aesthetic, apply the following keyframe animations:

* **Ambient Float (Floating Cards & Objects):**
  ```css
  @keyframes float {
    0% { transform: translateY(0px) rotate(0deg); }
    50% { transform: translateY(-10px) rotate(1deg); }
    100% { transform: translateY(0px) rotate(0deg); }
  }
  .floating-element {
    animation: float 6s ease-in-out infinite;
  }
  ```
* **Parallax Depth on Scroll/Hover:** 
  * Background layers move slower (`translateZ(-50px)`) while foreground sneakers/caps move faster (`translateZ(100px)`) to create a true 3D depth-of-field effect.
* **Micro-interactions:**
  * **Card Hover:** Smooth scale up (`scale(1.03)`) with enhanced drop shadow (`box-shadow: 0px 20px 40px rgba(0,0,0,0.15)`).
  * **Selection State:** Smooth border color transition to `#C85A32` with a subtle spring physics pop.
