# UI/UX Specification: Apple Headphones Product Showcase

## 1. Global Layout & Structure

*   **View Type:** Full-screen immersive layout (ignoring the card's rounded framing bounds shown in the preview mockup, scaling edge-to-edge).
*   **Grid System:** Asymmetric split screen. The left 40% (approx.) is the hero display section (blue background), and the remaining 60% is split horizontally into three distinct color variant columns (Pink, Sage Green, Lavender).
*   **Responsiveness:** Fluid scaling. On mobile screens, this should convert to a vertical stack or a horizontally scrolling carousel.

---

## 2. Color Palette

*   **Hero Panel (Blue):** `#7A93A6` (Muted Steel Blue)
*   **Variant Panel 1 (Pink):** `#F2A199` (Soft Salmon/Pink)
*   **Variant Panel 2 (Green):** `#A3B1A8` (Muted Sage Green)
*   **Variant Panel 3 (Purple):** `#9A91BC` (Muted Lavender)
*   **Primary Text/Brand Accent:** `#FFFFFF` (Pure White)
*   **Secondary Text/Subtitles:** `#D1D5DB` (Light Gray, ~80% opacity)
*   **Button Background:** `#FFFFFF` (Solid White)
*   **Button Text:** `#1F2937` (Dark Charcoal)
*   **Footer Details:** `#6B7280` (Medium Gray)

---

## 3. Typography & Font Stack

*   **Primary Font Family:** `Inter`, `SF Pro Display`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`.
*   **Fallback Strategy:** If Google Fonts / system fonts fail, fallback strictly to standard sans-serif (`Arial`, `Helvetica`).

### Typographic Hierarchy

*   **Hero Background Watermark ("APPLE"):**
    *   **Font Size:** `140px` (Fluid/Viewport-based: `12vw`)
    *   **Font Weight:** `800` (Extra Bold)
    *   **Style:** Outlined text (Transparent fill, `1px` to `2px` stroke matching `#FFFFFF` at `15%` opacity).
    *   **Letter Spacing:** `0.05em`
*   **Hero Foreground Title ("APPLE"):**
    *   **Font Size:** `64px` (`5vw`)
    *   **Font Weight:** `700` (Bold)
    *   **Color:** `#FFFFFF`
*   **Price Display ("$239.00"):**
    *   **Font Size:** `18px`
    *   **Font Weight:** `600` (Semi-Bold)
    *   **Color:** `#FFFFFF`
*   **Product Description ("Experience the modernized design..."):**
    *   **Font Size:** `11px`
    *   **Font Weight:** `400` (Regular)
    *   **Line Height:** `1.4`
    *   **Max Width:** `220px`
    *   **Color:** `#E5E7EB`
*   **CTA Button Label ("Buy Now"):**
    *   **Font Size:** `10px`
    *   **Font Weight:** `600`
    *   **Text Transform:** Sentence case / Capitalized
*   **Footer Text ("© 2024 All rights reserved" / "@uiuxzaid"):**
    *   **Font Size:** `11px`
    *   **Font Weight:** `400`
    *   **Color:** `#6B7280`

---

## 4. Component Breakdown & Styling

### A. Hero Section (Left Panel)
*   **Background:** `#7A93A6`
*   **Content Alignment:** Centered horizontally, vertically balanced.
*   **Watermark Typography:** Positioned absolutely in the background layer, centered behind the product image.
*   **Product Image (Hero Headphone):**
    *   High-resolution 3D render of the space-gray/blue AirPods Max facing slightly angled toward the right.
    *   Drop shadow: Soft, large radius shadow (`0px 20px 40px rgba(0, 0, 0, 0.15)`).
*   **CTA Button ("Buy Now"):**
    *   **Shape:** Pill shape (`border-radius: 50px`).
    *   **Padding:** `6px 24px`.
    *   **Background:** `#FFFFFF`.
    *   **Transition/Hover:** Slight scale up (`transform: scale(1.05)`) with a smooth ease transition (`0.2s ease-in-out`).

### B. Color Variant Columns (Right Panels)
*   **Structure:** Three equal-width vertical columns sitting adjacent to the hero section.
*   **Backgrounds:** Pink (`#F2A199`), Sage (`#A3B1A8`), Lavender (`#9A91BC`).
*   **Product Thumbnails:**
    *   Each column features a centered 3D render of the headphones in the corresponding colorway.
    *   **Interaction State:** Hovering over a column should smoothly transition the main hero view (background color and headphone image) to match the selected variant.

### C. Footer Section
*   **Position:** Fixed or aligned to the bottom outside the primary card layout.
*   **Content:**
    *   Left-aligned: `© 2024 All rights reserved`
    *   Right-aligned: `@uiuxzaid` inside a subtle pill container (`border: 1px solid #D1D5DB`, `border-radius: 20px`, `padding: 4px 12px`).

---

## 5. Animations & Micro-Interactions

*   **Page Load / Entrance Animation:**
    *   Panels slide up sequentially with an opacity fade (`staggerChildren: 0.1s`).
    *   Product images scale up from `0.9` to `1.0` with an elastic/spring physics curve (`cubic-bezier(0.175, 0.885, 0.32, 1.275)`).
*   **Variant Switch (Click/Hover):**
    *   Cross-fade transition for background colors (`duration: 0.4s ease`).
    *   Smooth positional morphing of the headphone asset when swapping between variants.
