# 🎨 Design & Layout Specification

## 1. Overall Layout & Positioning
* **View:** Full-screen responsive container (`width: 100vw; height: 100vh;`).
* **Positioning:** The text element is placed in the **top-center** of the screen, with generous padding from the top edge to mimic the TikTok/Reels safe-zone UI layout.

---

## 2. Typography & Text Style

### **Main Text Pill Container**
* **Background:** Solid white (`#FFFFFF`).
* **Border Radius:** Fully rounded corners (Pill shape), roughly `16px` to `24px` depending on padding.
* **Shadow:** Soft, diffused drop shadow to lift the pill off the background video/content.
  * `box-shadow: 0 4px 20px rgba(0, 0, 0, 0.15);`
* **Padding:** 
  * Vertical: `12px` to `16px`
  * Horizontal: `20px` to `24px`

### **Font Details**
* **Primary Font Family:** System UI sans-serif stack commonly used in modern short-form video apps:
  * `font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;`
* **Font Weight:** Bold (`700`).
* **Font Size:** 
  * Desktop: `24px` – `28px`
  * Mobile: `18px` – `20px` (Fluid typography recommended using `clamp`).
* **Text Color:** Near-black / Dark Charcoal (`#111111`) for maximum contrast.
* **Text Content:** `Top 3D websites that will blow your mind 🚀`

---

## 3. Animation Specification (Entrance & Loop)
To match typical high-engagement short-form video UI overlays, the text pill should feature a smooth entrance animation:

* **Entrance Animation (`popIn`):**
  * **Duration:** `0.4s`
  * **Timing Function:** `cubic-bezier(0.175, 0.885, 0.32, 1.275)` (Spring/Bounce effect).
  * **Keyframes:**
    * `0%`: `opacity: 0; transform: scale(0.8) translateY(-20px);`
    * `100%`: `opacity: 1; transform: scale(1) translateY(0);`
* **Subtle Float Animation (Idle):**
  * After the entrance, a continuous subtle floating effect can be applied.
  * **Duration:** `3s` infinite alternate.
  * **Keyframes:**
    * `0%`: `transform: translateY(0px);`
    * `100%`: `transform: translateY(-5px);`
