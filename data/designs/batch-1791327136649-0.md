# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase pill badges with amber glow rings, atmospheric golden hour sun flares, steaming liquid particle dynamics, framed foreground bokeh foliage.
- **Pill Badge Specification**: Padding `6px 14px`, font-size `0.75rem`, font-weight `600`, tracking `0.1em`, border-radius `9999px`, background translucency `rgba(244, 164, 96, 0.1)`, border width `1px` (`rgba(244, 164, 96, 0.3)`).
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content to prevent rendering glitches.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;` or `<span class="w-2 h-2 rounded-full bg-amber-400 inline-block"></span>`.
