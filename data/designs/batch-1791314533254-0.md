# 1. Design Philosophy & Overall Aesthetic

- **Primary Mood:** Cinematic, haunting, surrealist cyber-noir. It evokes an unsettling, solitary atmosphere at the intersection of dense digital surveillance and foggy wilderness.
- **Brand Archetype:** Avant-garde digital gallery / immersive cyberpunk storytelling platform.
- **Visual Density:** High visual tension created by sharp, jagged geometric slicing and stark contrast between deep velvet blacks and cold cyan/neon red highlights.
- **Whitespace Balance:** Intentionally minimal structural whitespace. Negative space is instead utilized as atmospheric depth—deep vertical fog fading into absolute blackness (`#010409`).
- **Theme Balance:** Strictly immersive dark-mode environment (100% dark mode distribution). Depth is achieved using layered vertical strips simulating sliced glass or fractured portals rather than traditional drop shadows.

# 6. Motion Mechanics, Framer Motion & CSS Animation Code

- **Trigger Type:** Continuous viewport idle float, hover-activated slice expansion, and scroll-driven parallax offsets.
- **Easing Physics:** Custom cubic-bezier spring `cubic-bezier(0.16, 1, 0.3, 1)`.

## Framer Motion React Code Snippets
```jsx
import { motion } from 'framer-motion';

const sliceVariants = {
  initial: { scaleY: 0.9, opacity: 0 },
  animate: (i) => ({
    scaleY: 1,
    opacity: 1,
    transition: {
      delay: i * 0.1,
      duration: 0.8,
      ease: [0.16, 1, 0.3, 1]
    }
  }),
  hover: {
    scale: 1.03,
    zIndex: 30,
    transition: { duration: 0.4, ease: "easeOut" }
  }
};

export const SlicedContainer = ({ index, children }) => (
  <motion.div
    custom={index}
    variants={sliceVariants}
    initial="initial"
    animate="animate"
    whileHover="hover"
    className="relative h-full overflow-hidden cursor-pointer"
  >
    {children}
  </motion.div>
);
```
