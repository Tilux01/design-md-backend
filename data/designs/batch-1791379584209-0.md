# UI/UX Specification & Design Blueprint: "Explore the World" (ZUBOX)

This document serves as the absolute blueprint for a pixel-perfect, fully responsive clone of the provided ZUBOX hero interface. It omits the presentation frame/mockup borders entirely, executing the design as a modern, immersive **full-screen viewport layout**.

---

## 1. Global Layout & Viewport Configuration

*   **Display Mode:** Full-Screen / Edge-to-Edge (`100vw`, `100vh` minimum).
*   **Grid System:** 12-Column fluid grid with a maximum content container width of **1280px**, centered horizontally with standard responsive padding (`clamp(24px, 5vw, 80px)`).
*   **Z-Index Hierarchy:**
    *   `z-0`: Background landscape illustration / photography layer.
    *   `z-10`: Atmospheric gradient overlay / shadow vignette.
    *   `z-20`: Typography, structural navigation, and primary interactive components.

## 4. Component Breakdown

### A. Navigation Bar (`<header>`)
*   **Position:** Absolute / Fixed at top, spanning full width.
*   **Padding:** `24px` top/bottom, matched to outer container margins.
*   **Layout:** Flexbox, space-between alignment.
*   **Left Element (Brand):**
    *   Text: `ZUBOX`
    *   Style: Uppercase, tracking-wide.
*   **Center Element (Nav Links):**
    *   Items: `Discover` | `About us` | `Blog` | `Contact us`
    *   Spacing: `32px` gap between links.
    *   Interactive State: Smooth color transition to `#FFFFFF` on hover.
*   **Right Element (Tools):**
    *   Search Icon (`<svg>` magnifying glass, `14px`, stroke `#A5C4D4`).
    *   Language Selector: `English ⌵` (Chevron down indicator).
    *   Gap between Search and Language: `24px`.

### B. Hero Content Block (`<section class="hero">`)
*   **Vertical Alignment:** Vertically centered within the upper-middle portion of the viewport.
*   **Content Layout:** Left-aligned text stack.
*   **Heading:** *"Explore the world"*
*   **Description Paragraph:** 
    *   Text: *"Dive into the beauty of nature without the loss of daily comfort. Get rid of the hustle and bustle of urban life."*
    *   Max-Width: `420px` (Forces clean 3-line wrap).
*   **Call-to-Action (CTA):**
    *   Text: *"Start my adventure →"*
    *   Interaction: Underline or subtle shift right on hover (`transform: translateX(4px)` via CSS transition).

### C. Visual Scene / Landscape Layer (`div.hero-visual`)
*   **Background Illustration / Image:**
    *   Layered vector-style landscape (deep blue sky gradient shifting from pale cyan to rich navy, stylized jagged mountains/cliffs, silhouettes of birds in flight).
*   **The Architectural Focal Point (Modern Glass Cabin):**
    *   Positioned centrally-lower within the composition, framed by a minimal rectangular glass/wireframe border (`border: 1px solid rgba(255,255,255,0.3)`).
    *   **Interior Details:** Warm amber lighting (`#FF8C42`) illuminating a cozy interior room with bed/furniture silhouettes contrasted against vertical wooden slats on the right side.

---

## 5. Micro-Interactions & Animations

1.  **Page Load Entrance Sequence (CSS Keyframes):**
    *   *Navigation:* Fades down from `-20px` with `opacity: 0` to `opacity: 1` over `0.6s cubic-bezier(0.16, 1, 0.3, 1)`.
    *   *Hero Text:* Staggered fade-up. Heading animates first, followed by paragraph and CTA with a `0.15s` delay.
    *   *Backdrop/Cabin:* Subtle zoom-in scaling from `1.03` to `1.0` over `1.2s`.
2.  **Hover States:**
    *   Navigation Links: `transition: color 0.2s ease;`
    *   CTA Arrow: `transition: transform 0.25s ease;` (moves `+4px` on hover).
3.  **Responsive Behavior:**
    *   Below `768px` (Mobile): Navigation collapses into a hamburger menu icon; the hero text stacks cleanly above the cabin artwork which scales to fit `100%` width.
