# E-Commerce Web Application: Design System & Technical Specification

---

## 1. Design Philosophy & Overall Aesthetic
* **Brand Archetype:** Modern, clean, approachable direct-to-consumer (D2C) e-commerce marketplace.
* **Visual Density:** Balanced. Generous whitespace in container headers combined with dense, information-rich card grids.
* **Theme Balance:** Pure Light Mode design system. Built on neutral soft-beige/cream backdrops with high-contrast forest green primary branding elements and warm terracotta/gold accents.
* **Spatial Rhythm:** Built on an 8px grid system with consistent spacing milestones (`8px`, `16px`, `24px`, `32px`, `48px`, `64px`).

## 2. Color Palette & Design Tokens

### Color Roles
- **Primary:** Forest Green (`#556B2F` / `#3B5323`)
- **Primary Hover/Active:** Deep Moss (`#2C3E1B`)

- **Surface Background:** Pure White (`#FFFFFF`) & Soft Cream Neutral (`#F9F8F6`)

- **Text Primary:** Deep Charcoal (`#111827`)
- **Text Muted:** Medium Slate Gray (`#6B7280`)
- **Border / Divider:** Light Gray (`#E5E7EB`, `#F3F4F6`)

## 4. Layout Architecture & Spatial Grid
* **Container Max-Width:** `1280px` centered with fluid horizontal padding (`16px` mobile, `32px` desktop).
* **Section Sequence Breakdown:**
  1. **Hero Banner:** Split screen layout with promotional text and isometric product illustration.
  2. **Value Prop Bar:** 4-column horizontal badge strip (Free Shipping, Secure Payment, Easy Returns, 24/7 Support).
  3. **Categories Grid:** 6-column circular avatar category row.
  4. **Product Carousel / Grid:** 5-column product card system.
  5. **Promotional Banner:** Split promotional card ("Up to 50% Off").
  6. **Testimonial Slider:** 3-column customer review cards with user avatars & star ratings.
  7. **Footer:** Multi-column links and newsletter signup.

## 8. Accessibility (a11y) & WCAG Contrast Audit
* **Primary Button (`#3B5323` on `#FFFFFF`):** Contrast ratio **7.2:1** (Passes WCAG AAA).
* **Muted Text (`#6B7280` on `#FFFFFF`):** Contrast ratio **4.6:1** (Passes WCAG AA).
* **Focus States:** All interactive elements feature a visible ring outline:
  ```css
  :focus-visible {
    outline: 2px solid var(--color-primary);
    outline-offset: 2px;
  }
  ```
