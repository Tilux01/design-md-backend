# Design Specification: Unified Loading & Indicator System

## 1. Design Philosophy & Overall Aesthetic
- **Mood & Brand Archetype**: Minimalist, utility-driven, highly technical, and precise. The aesthetic leans toward developer tooling and dark-mode-first system utility suites.
- **Visual Density**: Compact, modular, grid-aligned.
- **Whitespace Balance**: High-contrast, tight cell spacing within grouped icon matrices, contrasted against deep atmospheric negative space.
- **Theme Architecture**: Strictly dark-mode native (`#111111` canvas with `#1a1a1a` surfaces and crisp monochrome iconography).

---

## 2. Color Palette & Design Tokens
- **Canvas / Base Background**: `#111111` (RGB: 17, 17, 17)
- **Surface / Card Background**: `#1a1a1a` (RGB: 26, 26, 26) with soft rounded corner raster plates.
- **Primary Text & Active Icons**: `#ffffff` (RGB: 255, 255, 255)
- **Muted Text / Secondary Elements**: `#888888` (RGB: 136, 136, 136)
- **Inactive / Dimmed State (Loaders/Dots)**: `#333333` to `#555555`
- **Border & Dividers**: Subtle chromatic contrast utilizing pure darkness boundaries rather than explicit border lines (borderless card system).

---

## 3. Typography System & Hierarchy
- **Font Family**: System monospace / geometric sans-serif (e.g., *JetBrains Mono* or *Inter*).
- **Category Labels ("CIRCLE", "DOTS", etc.)**:
  - Font Size: `10px`
  - Font Weight: `600` (Semi-bold)
  - Letter-Spacing (Tracking): `0.15em`
  - Text-Transform: Uppercase
  - Color: Muted (`#888888`)

---

## 4. Layout Architecture & Spatial Grid
- **Container Structure**: Multi-row, uniform icon grid system.
- **Grid Item Dimensions**: Square tiles (approx. `48px × 48px` bounding box per tile with `8px` rounded corners).
- **Row Spacing**: `24px` vertical gap between category sections.
- **Column Gap**: `12px` horizontal spacing between items.

---

## 5. Component Blueprint & Element Placement

### A. Icon Card Containers
- **Shape Profile**: Squircle / Rounded Rectangle (`border-radius: 8px`).
- **Surface Fill**: `#1a1a1a`.
- **Border**: None (flat design relying on depth separation through surface tone).

### B. Categories & Sub-Components
1. **Circle / Spinners**: Progressive stroke-dash arrays ranging from 12% to 100% opacity increments. Stroke width is uniform (`2px`).
2. **Dots**: Horizontal linear sequences (3-dot loading indicators) with sequential opacity steps.
3. **Fade Circles**: Radial gradient opacity scaling from solid dark center/periphery to highlighted core.
4. **Ball**: Micro-physics translation states (moving dots along linear paths or orbital arcs).
5. **Time**: Analog clock hands, hourglass states, and chronometer rings.
6. **Wifi**: Signal-strength arcs and cellular/network node telemetry icons.
7. **Icons**: Standardized utility glyphs (Search, Mail, Gallery, Folder, Download, Coin, Truck, Book).

---

## 6. Motion Mechanics & Animation Specifications
- **Easing Physics**: `cubic-bezier(0.4, 0, 0.2, 1)` (Standard Material Design / Smooth ease-in-out) for spinners; `linear` for infinite rotations.
- **Transition Durations**:
  - Infinite Spinners: `1000ms` per revolution.
  - Step Animations (Dots/Steps): `300ms` per frame state.
  - Hover States: `150ms ease-out`.
