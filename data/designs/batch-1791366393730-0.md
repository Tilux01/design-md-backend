# Project Pitch Deck Design Specifications

## Overall Layout & Global Styles
* **Layout Structure:** 5x2 Grid of presentation slides displayed against a light gray/off-white background.
* **Global Color Palette:**
  * Background (Pages): `#FFFFFF` (White)
  * Background (Canvas): `#E5E5E5` (Light Gray)
  * Primary Text / Headings: `#000000` (Pure Black)
  * Secondary Text / Body: `#666666` / `#777777` (Muted Gray)
* **Typography:** Sans-serif (Clean, modern geometric/grotesque style, e.g., Helvetica, Inter, or Arial).
* **Grid Format:** Standard 16:9 presentation slide aspect ratio for individual cells.
