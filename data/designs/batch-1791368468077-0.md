# Design System & Specification

## 1. Global Styles & Foundations

### Color Palette
- **Backgrounds:**
  - `bg-primary`: `#040a16` (Deep dark blue/black ambient canvas)
  - `bg-surface`: `#0a1222` (Card and modal containers)
  - `bg-glass`: `rgba(15, 23, 42, 0.6)` (Glassmorphism backdrop blur panels)
- **Primary Accents:**
  - `accent-cyan`: `#00f0ff` (Core interactive highlights, active states, watch dial turquoise/green highlights)
  - `accent-blue`: `#1a60cc` (Brand blue depth)
- **Text Colors:**
  - `text-main`: `#ffffff` (Primary headings, active labels)
  - `text-muted`: `#8a9bb8` (Secondary labels, descriptions, nav links)
  - `text-dim`: `#4a5d7c` (Inactive labels, watermarks, background UI elements)
- **Borders & Dividers:**
  - `border-glass`: `rgba(255, 255, 255, 0.08)`
  - `border-active`: `rgba(0, 240, 255, 0.4)`

### Typography
- **Font Family:** Inter / SF Pro Display / Modern Sans-Serif equivalent
- **Scale:**
  - `Hero Title`: 42px / Line-height: 1.05 / Tracking: -0.02em / Bold (700)
  - `Nav Links`: 12px / Tracking: 0.05em / Medium (500)
  - `Product Code / Eyebrow`: 10px / Tracking: 0.1em / Regular (400)
  - `Button / Action`: 11px / Tracking: 0.08em / Semi-bold (600)

---

## 2. Layout & Structure

- **Viewport:** 100vw, 100vh (Full-screen immersive layout)
- **Max Content Width:** `1440px` (centered horizontally with responsive padding `px-12` / `px-6`)
- **Layout Grid:** Absolute-positioned and Flexbox layered layout with dynamic depth (Z-index layering for ambient lighting).

---

## 3. Component Specifications

### A. Navigation Header
- **Position:** Fixed top (`top-0 left-0 right-0`), high z-index.
- **Left Group:**
  - Brand Logo: "CHRONOSWISS" (Uppercase, tracking-widest, bold white).
  - Menu Icon (Hamburger): 3 horizontal bars (thin, muted white).
- **Center Navigation Links:**
  - `WATCHES`, `WARRANTY & SERVICE`, `STORES`
  - Typography: 12px uppercase, `text-muted`, hover transitions to `text-main`.
- **Right Group:**
  - Currency Selector: `EUR` with down caret.
  - Language Selector: `ENG` with down caret.
  - Action Icons: Lightbulb/Feature icon, User profile icon, Shopping bag icon with notification badge (`3`).

---

### B. Hero Section (Left Column)
- **Eyebrow Tags:**
  - `LIMITED TO 15 PIECES`: Outlined capsule badge (`border-glass`, rounded pill, 10px uppercase tracking).
  - `CH-3123-PABL`: Small muted code identifier above main title.
- **Main Heading:**
  - `OPEN GEAR`
  - `FLYING TOURBILLON`
  - `PARAIBA`
  - *Style:* Massive display typography, stark white, tight line spacing.
- **Call to Action (CTA):**
  - Button text: `FIND OUT MORE`
  - Style: Rounded pill button (`rounded-full`), solid cyan/blue gradient or crisp blue (`#0f62fe` / `#00d2ff`), white text, 11px uppercase bold, subtle shadow.

### C. Hero Section (Centerpiece - Watch Display)

### D. Carousel Navigation & Secondary Indicators

  - Bottom center beneath hero watch: A finely ticked scale representing watch models (`...05 ... 06 ... 01 ... 02 ... 03 ...`), with item `01` highlighted in white.

### E. Bottom Gallery / Grid Section
- **Layout:** 3-column asymmetric card preview row positioned along the bottom.
- **Card 1 (Left):**
  - Grayscale portrait of a master watchmaker wearing a loupe.
  - Soft frosted glass border, rounded corners (`rounded-2xl`).
- **Card 2 (Middle):**
  - Macro shot of watch movement gears and blue subdials.
  - Dark atmospheric lighting.
- **Card 3 (Right):**
  - Open book showing technical watch schematics alongside a physical timepiece.
  - Crisp editorial lighting.
- **Video / Interactive Widget (Mid-Right):**
  - Small floating video preview card showing a watchmaker at work with a play button overlay (`blue circular play icon`).

---

## 4. Interactive States & Micro-Interactions

- **Hover Effects:**
  - Nav items: Transition color to pure white (`#ffffff`).
  - CTA Button: Brighten background glow (`box-shadow: 0 0 20px rgba(0,240,255,0.4)`).
  - Gallery Cards: Subtle scale-up (`scale-105`) and border illumination (`border-cyan`).
