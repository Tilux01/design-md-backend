# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Cinematic Editorial Dark Mode, Neo-Noir Executive Minimalist.
- **Visual Density & Whitespace Ratio**: High contrast editorial layout balanced with heavy negative space, emphasizing central portrait imagery and monumental display typography.
- **Surface Elevation Model**: Monolithic deep black canvas (`#000000`) with high-contrast pure white (`#FFFFFF`) typography. Subtle glassmorphism and backdrop filters utilized on navigation and interactive toggles.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase typography, monochrome cinematic background spotlighting, minimalist UI control toggles, backdrop blur navigation headers.
- **Pill Badge Specification**: Padding `6px 16px`, font-size `12px`, font-weight `600`, tracking `0.08em`, border-radius `9999px`, background `rgba(255, 255, 255, 0.05)`, border `1px solid rgba(255, 255, 255, 0.1)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-white inline-block"></span>`.

# 7. Motion Mechanics, Framer Motion & CSS Animations
- **Motion Principles**: Smooth cubic-bezier easing (`0.16, 1, 0.3, 1`), subtle image depth parallax on hover, instant tactile feedback on interactive toggles.
- **Framer Motion Variants Code**:
```jsx
export const containerVariants = {
  hidden: { opacity: 0, scale: 0.98 },
  visible: { 
    opacity: 1, 
    scale: 1,

  }
```
