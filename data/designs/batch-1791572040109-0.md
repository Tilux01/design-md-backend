# UI Design & Implementation Specification

## 1. Global Layout & Document Structure
- **Root Container**: Full-screen layout (`width: 100vw`, `height: 100vh`, `overflow: hidden`) with a light, soft gray/lilac gradient background (`#f0f2f8` to `#e6e9f2`).
- **Structure**: 
  - **Left Sidebar**: Fixed width (~80px) vertical navigation bar with rounded glassmorphism aesthetic.
  - **Main Content Area**: Flexible width container with a top header and a scrollable dashboard grid underneath.

---

## 2. Typography & Font Specifications
- **Primary Font Family**: `Inter`, `Poppins`, or system sans-serif stack.
- **Fallback Stack**: `font-family: 'Poppins', 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;`
- **Typography Scale**:
  - **App Title (`hr ad.`)**: Bold, ~20px, dark navy (`#1e1b4b`).
  - **Greeting (`Hello Admin!`)**: Bold, ~24px, dark navy (`#1e1b4b`).
  - **Subtitle**: Regular, ~12px, muted gray (`#6b7280`).
  - **Card Headers / Metric Labels**: Semi-bold, ~14px to 16px, dark slate (`#334155`).
  - **Metric Numbers**: Bold, ~22px to 28px, deep slate (`#0f172a`).
  - **Axis / Minor Labels**: Regular, ~10px to 11px, soft gray (`#94a3b8`).

---

## 3. Sidebar Navigation Panel
- **Width**: ~80px, background white with high translucency and a subtle drop shadow.
- **Top Brand Logo**: Circular gradient icon containing an abstract purple/red stylized "M" or mountain peak shape, followed by the text `hr ad.`.
- **Navigation Icons**:
  - Vertical stack of centered icon buttons (e.g., dashboard, analytics, users, folder, wallet, settings, logout).
  - **Active State**: The active item (e.g., dashboard icon at the top) is styled with a solid primary blue background (`#2563eb`) and a glowing drop shadow, featuring a white icon.
  - **Inactive States**: Soft gray icons (`#64748b`) with hover scaling/color shifts to blue.

---

## 4. Top Header Bar
- **Layout**: Flex row, space-between alignment spanning the top of the main content area.
- **Left Side**: 
  - Greeting text: "Hello Admin!"
  - Subtitle: "Measure How Fast You're Growing Monthly Recurring performance management."
- **Right Side Components**:
  - **Year Dropdown**: Pill-shaped button with gray border and dropdown caret (`Year ⁝`).
  - **Search Bar**: Rounded pill input field with a search icon and placeholder text `"Search..."`.
  - **Language Selector**: English dropdown (`English ▾`).
  - **Notification/Action Icons**: Bell icon with a red notification dot, user profile avatar image (circular photograph of a smiling man in a suit).
  - **Primary CTA Button**: "+ Create Notice" button with vibrant orange-to-coral gradient background and white bold text.

---

## 5. Overview Metric Cards Grid
- **Layout**: 5 equal-width metric cards arranged horizontally in a flex/grid row.
- **Card Styling**: Rounded white cards (`border-radius: 16px`), soft drop shadows, subtle inner borders, clean padding.
- **Card Contents (Left to Right)**:
  1. **Users**: Circular red/coral gradient icon with upward diagonal arrow inside (`348 Users`).
  2. **Events**: Circular teal/cyan gradient icon with downward/right arrow inside (`128 Events`).
  3. **Holidays**: Circular amber/yellow gradient icon with upward arrow inside (`10 Holidays`).
  4. **Payrolls**: Circular soft green gradient icon with downward arrow inside (`3458 Payrolls`).
  5. **Reports**: Circular purple/violet gradient icon with upward arrow inside (`3488 Reports`).

---

## 6. Main Dashboard Sections

### A. Salary Statistics (Left Large Card)
- **Header**: "Salary Statistics" with a dropdown filter and export/download icon button in the top right.
- **Interactive Tooltip / Badge**: Displays "2014" breakdown ("Marketing: 2437 | Design: 7689 | Development: 7689 | Others: 7689").
- **Chart Area**: 
  - Line graph with dual overlapping curves (one slate blue, one amber/orange) tracking values from `0` to `100` across years (`2010` to `2017`).
  - Smooth Bézier curves with soft gradient fills underneath.

### B. Employee Satisfaction (Right Large Card)
- **Header**: "Employee Satisfaction" with an export action button.
- **Chart Area**:
  - Large semi-circular gauge/donut chart centered in the card.
  - Progress arc transitions from coral-red (`0%`) through orange to soft gray (`100%`).
  - Central icon: Thumbs-up glyph inside a white circular badge.
  - Central text: Large bold `"74%"` with `0%` and `100%` labels at the base extremities.

### C. Performance Statistics (Bottom-Left Card)
- **Header**: "Performance Statistics" with download icon.
- **Progress Metrics List**:
  - **Developer Team**: Orange horizontal progress bar at `65%`.
  - **Design Team**: Blue horizontal progress bar at `84%`.
  - **Marketing Team**: Purple horizontal progress bar at `28%`.
  - **Management Team**: Pink horizontal progress bar at `16%`.

### D. New Employees Bar Chart (Bottom-Right Card)
- **Header**: "New Employees" with dropdown filter, sorting options (`Sort by Years`), and export button.
- **Active Data Badge**: Floating tooltip highlighting `"2014"` with `"Male: 248 | Female: 194"` and a `"28%"` indicator.
- **Chart Area**:
  - Vertical gradient bar chart representing data points from `0` to `100` across years (`2010` to `2017`).
  - Bars feature rounded tops with soft vertical opacity gradients (white/gray fading to coral/orange or blue highlights).

---

## 7. Imagery & Iconography Guidelines
- **User Avatar (Top Right)**: Professional headshot photograph of a middle-aged man smiling, wearing a dark suit and tie, cropped into a perfect circle.
- **Icons**: Minimalist, clean-stroke vector icons (Feather icons, Lucide, or Heroicons style) used consistently across buttons, metrics, and navigation items.
