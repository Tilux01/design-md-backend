# Design Specification & Implementation Guide

This document outlines the exact design specifications, typography, layout hierarchy, and animation logic required to build a pixel-perfect, full-screen clone of the provided media (`Unlimited Release IPA`).

---

## 1. Global Layout & Viewport Specifications

- **Display Type:** Full-screen responsive canvas (`width: 100vw; height: 100vh; overflow: hidden;`).
- **Background Color:** 
  - Primary Outer Frame: `#C8102E` (Lagunitas Red).
  - Central Content Card: `#F4F0E8` (Off-white / Cream).
- **Layout Structure:** 
  - The design features a bordered, cream-colored central stage set against a bold red full-bleed background.
  - *Note per user instructions:* The outer red border and structural frame are rendered full-screen without fixed padding limits.

---

## 2. Typography & Font Stack

The design uses a high-contrast typographic pairing: a condensed, heavy sans-serif typeface for large background text, and a distinct distressed serif/sans hybrid for the IPA branding.

### Font 1: Bold Condensed Headline (Background Text)
- **Primary Font:** `Impact`, `Arial Black`, sans-serif.
- **Style:** Uppercase, Extra-Bold, Condensed.
- **Color:** `#C8102E` (Lagunitas Red) with subtle texture/opacity layering.
- **Tracking / Letter-spacing:** Tight (`-0.03em`).

### Font 2: IPA Bottle Label & Sub-headline
- **Primary Font:** `Oswald`, `Anton`, `Roboto Condensed`, sans-serif.
- **Style:** Heavy weight, uppercase.
- **Color:** Deep Charcoal / Black (`#111111`) and Red (`#C8102E`).

---

## 3. Element-by-Element Specifications

### A. Background Typography ("UNLIMITED RELEASE IPA")
- **Content:** 
  ```text
  UNLIMITED
  RELEASE IPA
  ```
- **Positioning:** Centered absolutely behind the product bottle to create depth.
- **Font Size:** Responsive `clamp(4rem, 12vw, 14rem)`.
- **Line Height:** `0.85` (tightly stacked).

### B. Central Product Asset (Beer Bottle)
- **Asset Type:** High-resolution product shot of an IPA bottle angled at approximately **15 degrees clockwise**.
- **Shadow Effect:** Soft, diffused drop shadow underneath the bottle to give a floating/top-down physical depth effect (`box-shadow: 0 30px 60px rgba(0,0,0,0.25)`).
- **Positioning:** Angled diagonally, intersecting the background typography.

### C. Top-Left Brand Logo / Watermark
- **Content:** Minimalist brand logotype (`LAGUNITAS` style).
- **Color:** `#111111`.
- **Positioning:** Absolute positioning at top-left of the cream canvas.

### D. Bottom-Left Typographic Detail ("INDIA PALE ALE")
- **Content:** 
  ```text
  INDIA
  PALE ALE
  ```
- **Font Size:** `clamp(2rem, 5vw, 6rem)`.
- **Color:** `#111111`.
- **Positioning:** Bottom-left pinned.

### E. Bottom-Right Spec Box (ABV Details)
- **Container Style:** Thin black border framing a minimalist technical specification block.
- **Content:** 
  - Metric Header (`ABV`)
  - Percentage (`6.2%`)
  - Descriptive legal/product text in micro-type (sans-serif, 9px, uppercase).
- **Positioning:** Bottom-right pinned.

---

## 4. Animation & Motion Design (Optional Interactive Polish)

If implementing this as an animated web banner or landing page hero:

1. **Initial Load (Entrance):**
   - Red background fills the viewport instantly.
   - The cream central card scales up from `0.95` to `1.0` with an ease-out cubic-bezier curve (`cubic-bezier(0.16, 1, 0.3, 1)`).
2. **Text Reveal:**
   - Background red typography slides up from behind a clipping mask with a slight parallax delay.
3. **Product Floating:**
   - The central beer bottle floats infinitely along a subtle Y-axis sine wave (`transform: translateY(0px)` to `translateY(-8px)`) over a duration of `4s`.
