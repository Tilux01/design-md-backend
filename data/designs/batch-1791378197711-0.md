# Comprehensive Design Specification: Nike Concept Landing Page

This specification details the exact visual styling, typography, layout, interactivity, and animation mechanics required to build a pixel-perfect, full-screen clone of the provided media.

---

## 1. Global Layout & Viewport

*   **Display Mode:** Full-screen responsive web page. *(Note: The framing/shadow border present in the reference mockup should be omitted in the final build; the UI spans the full viewport).*
*   **Background Color:** 
    *   Main content background: Off-white / Cream `#FBF9F1` (or `#FAF8F5`).
    *   Top utility bar background: Lime green `#D4FB3A`.
*   **Grid System:** Centered maximum-width container with generous horizontal padding, featuring a horizontally aligned flex row for the product showcase.

---

## 2. Typography & Fonts

### Primary Font Family
*   **Headings / Branding:** Bold, geometric, uppercase sans-serif (e.g., **Impact**, **Anton**, or **League Spartan Bold**).
*   **Body / Navigation:** Clean, modern geometric sans-serif (e.g., **Futura**, **Helvetica Neue**, or **Inter**).

### Font Stack with Fallbacks
```css
/* Headings & Branding */
font-family: 'Anton', 'Impact', 'League Spartan', sans-serif;

/* Navigation & Body */
font-family: 'Futura', 'Helvetica Neue', 'Inter', -apple-system, sans-serif;
```

### Typography Hierarchy
1.  **Top Utility Bar Text:**
    *   *Size:* `12px` / `0.75rem`
    *   *Weight:* Regular / Medium (`400`–`500`)
    *   *Color:* Dark charcoal `#111111`
2.  **Brand Logo (Nike "Swoosh + Wordmark"):**
    *   *Style:* Classic italicized Nike corporate logo, solid black `#000000`.
3.  **Navigation Pill Menu:**
    *   *Size:* `14px` / `0.875rem`
    *   *Weight:* Medium (`500`)
    *   *Color:* `#111111`
4.  **Hero Heading ("SCROLL TO DISCOVER"):**
    *   *Size:* `36px` to `48px` (responsive)
    *   *Weight:* Black / Ultra-Bold (`900`)
    *   *Style:* Uppercase, slightly stylized/distressed stencil effect (or clean bold block capitals).
    *   *Color:* `#000000`
5.  **Button & Link Text:**
    *   *Size:* `13px` / `0.8125rem`
    *   *Weight:* Semi-bold (`600`)

## 3. UI Components & Component Breakdown

### A. Top Utility Bar
*   **Dimensions:** Full-width strip, height approx. `32px`.
*   **Background:** Lime Green (`#D4FB3A`).
*   **Content:** Links centered horizontally separated by vertical pipes (`|`).
    *   Items: `Find store | Help | Join us | Join us`
    *   *Hover state:* Underline or subtle opacity shift (`0.8`).

### B. Main Header Navigation
*   **Layout:** Flexbox container, space-between.
*   **Left:** Nike Logo (black, approx. `60px` width).
*   **Center:** Floating Pill Navigation Bar.
    *   *Shape:* Rounded pill border (`border-radius: 50px`).
    *   *Border:* Thin grey outline (`1px solid #D0D0D0`).
    *   *Background:* Pure white (`#FFFFFF`) with slight shadow.
    *   *Items:* `Dynamic` | `Woman` | `Bestsellers` | `Our story` | `About us`
    *   *Active State:* Current item (e.g., `Dynamic`) has no specific highlight in this view, but items transition on hover.
*   **Right:** Action items.
    *   "Create account" button: Pill-shaped, light grey/greenish background (`#E5F2D9` or `#EAEAEA`), dark text.
    *   Hamburger Menu Icon: Three stacked horizontal lines (`☰`), dark `#111111`, clickable.

### C. Hero Section ("SCROLL TO DISCOVER")
*   **Alignment:** Centered horizontally.
*   **Elements:**
    *   Heading text: `SCROLL TO DISCOVER`
    *   Scroll Indicator Icon: Down-arrow inside a solid dark circle (`#111111`), white arrow pointing downward.

### D. Product Showcase Row
*   **Layout:** Horizontal flex row showcasing 4 distinct running/training shoe models angled at approximately 30–45 degrees.
*   **Card / Item Details:**
    *   **Shoe 1 (Left):** Dark navy/black upper, white swoosh, vibrant lime accents along the sole and laces.

    *   **Shoe 4 (Right):** Dark navy upper, white swoosh, electric blue and green sole detailing (mirrors Shoe 1).
*   **Shadows:** Soft, diffused drop shadows beneath each shoe (`box-shadow` / SVG shadow ellipse) creating a floating 3D perspective effect.

### E. Bottom Action CTA
*   **Component:** Centered pill-shaped button.
*   **Background:** Vibrant lime green (`#2CE675` or `#4CD964`).
*   **Content:** Text ("Get this Elementor template") accompanied by a small settings/gear or play icon inside a circle.
*   **Border-radius:** Fully rounded ends (`9999px`).

## 5. Animation & Interaction Specifications

### 1. Scroll-Triggered Parallax / Entrance Animation
*   **Shoes Entrance:** On page load, the four shoe elements slide up slightly from the bottom with an ease-out cubic bezier curve (`cubic-bezier(0.16, 1, 0.3, 1)`), staggered by `0.1s` intervals from left to right.
*   **Hero Text Fade:** Fades in from opacity `0` to `1` over `0.8s` with a downward translation of `20px` to `0px`.

### 2. Interactive States (Hover & Active)
*   **Navigation Links:** Smooth color transition to opacity `0.6` on hover.
*   **Pill Menu Items:** Subtle background highlight (`#F0F0F0`) when hovered.
*   **Scroll Arrow Indicator:** Infinite subtle vertical bouncing/pulsing animation (moving up and down by `6px` on a `1.5s` loop using CSS `@keyframes bounce`).
*   **Product Hover:** When hovering over any shoe item:
    *   Scale up slightly (`transform: scale(1.05) translateY(-8px)`).
    *   Increase drop shadow intensity for enhanced depth.
    *   Transition duration: `0.3s ease`.
```css
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(6px); }
}

.scroll-indicator {
  animation: bounce 1.5s infinite ease-in-out;
}
```
