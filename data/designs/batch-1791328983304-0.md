# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Clean Enterprise SaaS / Modern Glassmorphism Dashboard.
- **Visual Density & Whitespace Ratio**: High-density information architecture balanced with generous component-level padding (16px–24px), soft translucent surface layering, and light-mode ambient separation.
- **Surface Elevation Model**: Multi-tier elevation using subtle borders (`1px solid rgba(255,255,255,0.6)`), soft drop shadows (`0 8px 32px rgba(0,0,0,0.04)`), and translucent backdrop blurs (`backdrop-filter: blur(16px)`).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase pill badges with subtle dot indicators, glassmorphic card backdrops (`backdrop-blur-md`), ambient soft borders, and floating contextual toolbars.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `11px`, font-weight `600`, tracking `0.05em`, border-radius `9999px`, background translucency `rgba(59, 130, 246, 0.08)`, border width `1px`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
