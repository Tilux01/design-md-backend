# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Modern Financial SaaS Dashboard, Clean Minimalist Enterprise.
- **Visual Density & Whitespace Ratio**: High whitespace with structured card partitioning. Uses clean typographic hierarchy and rounded containers to present complex financial metrics clearly without visual clutter.
- **Surface Elevation Model**: Layered surface architecture featuring an off-white app background (`#F4F4F6`), pristine pure white cards (`#FFFFFF`) with subtle multi-stop drop shadows, and coral/red accent styling (`#E25050`) for key visual focus areas.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-contrast coral metric highlights, smooth SVG trend curves, pill-shaped action buttons, soft drop shadows.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `12px`, font-weight `500`, border-radius `9999px`, background `#FDF2F2`, border width `1px` border color `#F8D7D7`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
