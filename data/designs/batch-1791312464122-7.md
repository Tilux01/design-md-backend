# Comprehensive Design System & Architecture Specification
**Platform:** E-Commerce Product Detail View (Web / Desktop Layout)  
**Design System Name:** Kalli UI / Minimal Luxe

---

## 1. Design Philosophy & Overall Aesthetic
*   **Primary Mood:** Minimalist luxury, high-end editorial streetwear, tactile and premium.
*   **Brand Archetype:** Sophisticated, clean, focused heavily on product imagery and structural typography.
*   **Visual Density:** Low-density, high-whitespace composition with clear visual hierarchy and asymmetrical balance.
*   **Theme Architecture:** Light Mode predominant (`#F0F0F0` base surface) accented by deep monochromatic black tones and high-contrast charcoal typography (`#111111`).

## 3. Typography System & Hierarchy
*   **Font Family Stack (Headings & Body):** `Inter`, `Helvetica Neue`, `Arial`, sans-serif
*   **Monospace Stack (Numeric/Metadata):** `SF Pro Mono`, `Courier New`, monospace

### Scale Breakdown
*   **Brand Logo (`kalli`):**
    *   Size: `24px` | Weight: 700 (Bold) | Letter-spacing: `-0.03em` | Color: `--color-text-primary`
*   **Heading 1 (Product Title):**
    *   Size: `22px` | Line-height: `28px` | Weight: 600 (SemiBold) | Letter-spacing: `-0.01em` | Color: `--color-text-primary`
*   **Subtitle / Category:**
    *   Size: `10px` | Line-height: `14px` | Weight: 700 (Bold) | Letter-spacing: `0.08em` (Uppercase) | Color: `--color-text-muted`
*   **Body Text (Description):**
    *   Size: `13px` | Line-height: `20px` | Weight: 400 (Regular) | Color: `--color-text-muted`
*   **Micro / Metadata (Price, Size, Reviews):**
    *   Size: `12px` | Line-height: `16px` | Weight: 500 (Medium) | Color: `--color-text-primary` / `--color-text-muted`

## 4. Layout Architecture & Spatial Grid
*   **Container Width:** Fixed aspect workspace centered within viewport (`900px` width × `600px` height internal frame).
*   **Spacing Token Scale:** `4px`, `8px`, `16px`, `24px`, `32px`, `48px`, `64px`.
*   **Section Sequence Breakdown (Top to Bottom):**
    1.  **Top Navigation Bar:** Brand logo (left), Back action link (center), Cart icon (right). Height: `60px`.
    2.  **Main Content Core Grid:**
        *   *Left Column (Product Metadata):* Category, Title, Description, Thumbnail Carousel. Width: ~30%.
        *   *Center Column (Hero Visual):* Large scale product render with soft drop shadow. Width: ~45%.
        *   *Right Column (Configuration Panel):* Size selector, Star ratings, Price display, Colorways. Width: ~25%.
    3.  **Bottom Action / Control Bar:** Video play trigger, pagination controls, progress indicator, Add to Cart action, and Wishlist icon. Height: `70px`.

---

## 5. Component Blueprint & Element Placement

### A. Navigation & Header
*   **Logo:** Left-aligned at `x: 50px`, `y: 40px`.
*   **Back Button:** Text link (`← BACK`) centered horizontally in the upper region with tracking of `2px`.
*   **Cart Icon:** Outline shopping bag icon positioned at top right (`x: 840px`).

### B. Product Hero & Thumbnails
*   **Hero Image Frame:** Centered product rendering with zero bounding box limits, elevated via soft multi-layered drop shadow (`0px 20px 40px rgba(0, 0, 0, 0.08)`).
*   **Thumbnail Row:**
    *   Item size: `40px × 40px`, border-radius: `4px`.
    *   Active thumbnail features subtle border ring; inactive thumbnails show desaturated preview.
    *   Overflow indicator (`+3`) styled as a dark solid square with centered white text (`11px` Medium).

### C. Size Selector Component
*   **Layout:** Horizontal row of circular interactive radio buttons.
*   **Dimensions:** Diameter `32px`.
*   **States:**
    *   *Default/Inactive:* Border `1px solid #D0D0D0`, background transparent, text `#707070`.
    *   *Active/Selected:* Solid fill `#111111`, text `#FFFFFF`, border none.

### D. Action Buttons
*   **Primary CTA (`ADD TO CART`):**
    *   Height: `40px`, Padding horizontal: `24px`.
    *   Background: `#111111`, Text: `#FFFFFF`, Weight: 600, Size: `11px` (Uppercase, tracked `0.05em`).
    *   Border-radius: `0px` (Sharp architectural edges).
*   **Secondary Icon Button (Wishlist Heart):**
    *   Size: `40px × 40px`, Border: `1px solid #D0D0D0` (implied by container), centered heart icon.

---

## 6. Motion Mechanics, 3D & Mobile Gestures
*   **Transition Durations:** 
    *   Micro-interactions (Hover, color selection, size toggle): `150ms ease-out`
    *   Macro-transitions (Carousel slide, image switching, view modal): `350ms cubic-bezier(0.25, 1, 0.5, 1)`
*   **Animation Triggers:**
    *   Clicking pagination arrows triggers a horizontal slide-fade transition of the main product visual.
    *   Hovering over color variant pills scales the preview render with a crossfade effect.
*   **Suggested Implementation Stack:** React / Next.js with Framer Motion for layout transitions and smooth spring-physics pagination steps.
