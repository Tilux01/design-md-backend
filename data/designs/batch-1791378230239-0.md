# Comprehensive UI/UX & Design Specification: BRUTAL® Creative Agency

This specification provides the exact technical and visual blueprint required to build a pixel-perfect, fully responsive clone of the **BRUTAL® Creative Agency** landing page.

## 1. Global Design Tokens & Architecture

### 1.1 Color Palette
*   **Primary Background (Light):** `#FFFFFF` (Pure White)
*   **Secondary Background (Dark):** `#0A0A0A` (Near Black / Off-Black for absolute contrast)
*   **Accent / Brand Orange:** `#FF4500` (Vibrant Brutalist Orange-Red)
*   **Text Primary (Dark Theme):** `#FFFFFF`
*   **Text Primary (Light Theme):** `#0A0A0A`
*   **Text Muted:** `#7A7A7A` (Mid-tone Gray used for metadata and subtext)

### 1.2 Typography System & Fallbacks
The layout relies heavily on extreme contrasts between thick, uppercase sans-serif display headers and technical, monospaced/grotesque metadata.

*   **Display & Headings Font:** `Syne`, `Anton`, or `Helvetica Neue`, fallback to `sans-serif`.
    *   *Characteristics:* High-impact, heavy geometric weight, tight letter-spacing (`letter-spacing: -0.04em`).
*   **Body & UI Font:** `Space Grotesk`, `Inter`, or `Roboto`, fallback to `sans-serif`.
*   **Monospace Elements (Numbers/Labels):** `JetBrains Mono`, `Courier New`, fallback to `monospace`.

## 3. Micro-Interactions & Animations (CSS/JS)

1.  **Hover States on Portfolio Cards:**
    *   *Scale Effect:* Images zoom in slightly (`transform: scale(1.05)`) using smooth cubic-bezier transitions (`transition: transform 0.4s cubic-bezier(0.16, 1, 0.3, 1)`).
    *   *Arrow Shifts:* All interaction arrows (`↗`) translate diagonally up-right by `4px` on hover.
2.  **Rotation Animation:**
    *   The circular badge (`· BRUTAL CREATIVE AGENCY ·`) should have a continuous slow CSS keyframe rotation (`transform: rotate(360deg)` over 20 seconds linear infinite).
3.  **Smooth Scrolling & Reveal:**
    *   Sections fade up using an Intersection Observer API trigger (`opacity: 0; transform: translateY(30px);` transitioning to `opacity: 1; transform: translateY(0);`).
