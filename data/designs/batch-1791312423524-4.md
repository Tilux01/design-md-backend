# 1. Design Philosophy & Overall Aesthetic
- **Primary Mood & Brand Archetype**: Playful luxury meets 3D product-focused digital commerce. The aesthetic bridges high-end furniture eCommerce with soft, tactile spatial computing interfaces (reminiscent of visionOS and modern spatial UI).
- **Visual Density**: Low to medium density; ample negative space combined with high-contrast, rounded card layouts.
- **Whitespace Balance**: Generous macro-whitespace, especially on the left-side hero zone and outer card framing. Micro-whitespace inside list views is kept concise (8–16px gaps).
- **Theme Balance**: Light mode predominant surface architecture with dark UI control floats. Extensive use of 3D volumetric glassmorphism, soft directional lighting, and multi-layered drop shadows.

# 4. Layout Architecture & Spatial Grid
- **Container Sizing**: Fixed desktop application frame width `960px`, height `560px` with a large border radius (`24px`).
- **Grid Layout**: 12-column internal grid split asymmetrically:
  - Left Hero Zone: `41.6%` (5 columns) with dual-tone gradient background (`#C4B5FD` to `#9333EA` mesh effect).
  - Right Content Zone: `58.4%` (7 columns) white surface with item data grid.
- **Padding & Margin Scale**:
  - Window outer padding: 0px (edge-to-edge internal layout).
  - Table row vertical padding: 16px top/bottom.
- **Stacking Order & Z-Index Hierarchy (`z-index`)**:
  - Base UI Canvas: `z-index: 0`
  - 3D Floating Elements (Sofa, Orbs, Capsules): `z-index: 10`
  - Floating Control Pill / Action Bar: `z-index: 30`
  - Tooltips / Dropdowns: `z-index: 50`

# 5. Component Blueprint & Element Placement

### A. Window Container & Hero Section
- **Border Radius**: `28px` outer container, `16px` for internal pills and action buttons.
- **Shadows**:
  - Main Window: `0 24px 48px -12px rgba(0, 0, 0, 0.12), 0 0 0 1px rgba(0, 0, 0, 0.04)`
  - Floating Elements: Deep volumetric soft shadows `0 16px 32px rgba(108, 56, 255, 0.25)`

### B. Table List Component
- **Structure**: Clean borderless rows with subtle divider lines (`1px` solid `#EFEFF3`).
- **Row Anatomy**: [3D Thumbnail Preview] | [Product Name] | [Dimensions: 110 X 110] | [Category/Type] | [Action Trigger (+)]
- **Thumbnails**: 32x32px isometric rendered 3D asset icons embedded directly inside table cells with transparent padding.

### C. Floating Action Bar (Bottom Center)
- **Geometry**: Pill-shaped container (`border-radius: 9999px`), height `52px`.
- **Background**: `#FFFFFF` with ultra-fine border `#E2E2E6`.
- **Shadow**: `0 10px 25px -5px rgba(0, 0, 0, 0.08)`
- **Internal Elements**: Icon buttons (`View`, `Pencil/Draw`, `User/Select`, Dropdown arrow) separated by subtle vertical dividers, terminating with a solid dark action button (`#1A1A1E` circular button with white arrow icon).

### D. Navigation & Controls
- **Bottom Navigation Dock (Left Panel)**: Minimalistic outlined icon buttons set inside rounded pill containers (`border-radius: 12px`, background `#F4F4F6`).

# 6. Motion Mechanics, 3D & Mobile Gestures
- **Animation Triggers**:
  - Hover over table rows: Scale up `1.01`, background tint transition to `surface_subtle`.
  - Floating Bar hover: Slight vertical lift (`translateY(-2px)`) with drop shadow expansion.
  - 3D Parallax: Mouse-move tilt effect on background 3D assets (Sofa & floating geometric primitives).
- **Library Inferences**: Framer Motion (React) for UI spring physics; Three.js / WebGL for real-time 3D object rendering.
- **Transition Durations & Easing**:
  - Micro-interactions (Buttons, toggles): `150ms` cubic-bezier(0.4, 0, 0.2, 1).
  - Spatial/Spring transitions (Modals, floating bars): `400ms` spring physics (`stiffness: 300, damping: 25`).
- **Gestures & Mobile Adaptations**:
  - Horizontal swipe to reveal hidden row actions on touch viewports.
  - Pinch-to-zoom supported on the 3D canvas viewport.
