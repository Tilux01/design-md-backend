# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Clean Enterprise SaaS / Fintech Dashboard.
- **Visual Density & Whitespace Ratio**: High-density UI layout optimized for financial data navigation, featuring clean card grids, compact vertical lists, and generous peripheral canvas whitespace.
- **Surface Elevation Model**: Layered surface architecture featuring a crisp white canvas (`#FFFFFF`), neutral light gray background surfaces (`#F8FAFC`), subtle 1px border separation (`#E2E8F0`), and soft contextual hover states.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Clean financial iconography, pill-shaped interactive tabs, subtle card selection highlights, status indicator dots.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `12px`, font-weight `500`, border-radius `9999px`, background `#F1F5F9`, border width `1px` (`#E2E8F0`).
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
