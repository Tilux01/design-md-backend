## 4. Micro-Interactions & Animations (Framer Motion / CSS Specifications)
1. **Initial Page Load Sequence:**
   * Header items slide down smoothly from `Y: -20px` to `0` with `opacity: 0` to `1` over `0.8s` cubic-bezier.
   * Massive typography ("TERRA cotta") scales up from `scale: 0.95` with fade-in over `1.2s`.
   * Metadata card fades in from bottom-left with a `15px` upward translation.
2. **Interactive Hover States:**
   * Navigation links scale slightly or shift text color smoothly (`transition: all 0.25s ease`).
   * Hotspots feature a continuous CSS keyframe pulse animation (`scale` looping from `1` to `1.25` with fading opacity ring).
3. **Responsive Scaling:**
   * On mobile viewports (`< 768px`), the massive typography scales down using CSS `clamp()`, metadata card drops below the image canvas, and the navigation transforms into a hamburger menu overlay.
