# Design System & Implementation Specification (`design.md`)

This document provides exact specifications for replicating the **SpaceEdu - Planet Earth** landing page UI. It covers layout structure, color tokens, typography, component details, image descriptions, and placement rules for a **fullscreen, borderless web application**.

---

## 1. Page Layout & Viewport Setup

*   **Canvas/Container**:
    *   Width: `100vw` (Full width)
    *   Height: `100vh` (Full viewport height, non-scrollable or smooth snap-scroll)
    *   Overflow: `hidden` (or `overflow-x: hidden`)
    *   Display: Flexbox (Vertical direction) or CSS Grid layout.
*   **Background**:
    *   Base color: Deep space dark blue/black gradient (`#060913` at top to `#0A0E1A` at bottom).
    *   Background Effect: Subtle cosmic star field pattern (soft white noise/dust particles scattered at low opacity ~15-20%).

---

## 2. Color Palette & Design Tokens

### **Primary & Background Colors**
*   **Deep Space Background**: `#070A12`
*   **Card / Header Overlay**: `rgba(255, 255, 255, 0.03)`

*   **Button Radial Glow**: `0px 0px 25px rgba(255, 255, 255, 0.4)`
*   **Earth Atmosphere Radial Glow**: `0px -30px 80px rgba(56, 189, 248, 0.45)`

## 3. Typography & Fonts

### **Font Families**
1.  **Primary Serif (Main Title)**:
    *   *Primary*: `Cinzel`, `Cinzel Decorative`, or `Playfair Display`
    *   *Fallbacks*: `Georgia`, `Garamond`, `Times New Roman`, `serif`
    *   *Usage*: "EARTH" main visual title.
2.  **Primary Sans-Serif (UI, Navigation, Subheadings, Buttons)**:
    *   *Primary*: `Inter`, `Plus Jakarta Sans`, or `Montserrat`
    *   *Fallbacks*: `system-ui`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `sans-serif`
    *   *Usage*: Brand name, navigation, "PLANET" eyebrow text, body copy, CTA text.

## 4. Component Breakdown & Structure

### **A. Top Navigation Header**
*   **Layout**: Fixed top, full width, height `70px`, horizontal flexbox (`justify-content: space-between`, `align-items: center`), padded `padding: 0 48px`.
*   **Bottom Border**: `1px solid rgba(255, 255, 255, 0.08)`.
*   **Left Section**:
    *   `spaceedu` branding text logo.
*   **Center-Right Navigation Links**:
    *   Horizontal list with gap of `32px`.
    *   Items: `Planets` (Active with cyan indicator line under it), `Trailer`, `Tickets`, `Blog`.
*   **Far-Right Action**:
    *   `Enroll` Pill Button: Rounded outline button (`border-radius: 9999px`), `border: 1px solid rgba(255,255,255,0.4)`, dark transparent background, white text. Size: `100px x 34px`.

---

### **B. Central Hero Section**
*   **Layout**: Centered flexbox column (`align-items: center`, `text-align: center`), absolute/flex layout occupying top 50% of the screen.

1.  **Category Eyebrow**:
    *   Text: `PLANET`
    *   Margin-bottom: `12px`.
2.  **Hero Heading**:
    *   Text: `EARTH`
    *   Margin-bottom: `16px`.
3.  **Accent Line**:
    *   Centered horizontal cyan bar (`width: 40px`, `height: 2px`, `background: #22D3EE`).
    *   Margin-bottom: `20px`.
4.  **Description Paragraph**:
    *   Max Width: `540px`.
    *   Text: *"Learn more about this facinating miracle that we call our home, Planet Earth. Course enrollment starts today. Early Bird tickets typically last a week, don't miss out!"*
    *   Text Alignment: Center. Line height: `1.6`.
    *   Margin-bottom: `32px`.

---

### **C. Call to Action & Navigation Controls**

1.  **Center "GET STARTED" Button**:
    *   Position: Centered below the description.
    *   Shape: Full pill capsule (`border-radius: 9999px`).
    *   Size: `160px` width, `44px` height.
    *   Background: Soft off-white to cyan soft light (`#F8FAFC`).
    *   Glow: Soft outer white/cyan radial shadow glow surrounding the button.
    *   Text: `GET STARTED` in dark blue-grey `#0F172A`.

2.  **Side Planet Carousel Items (Left & Right Controls)**:
    *   **Left Element (Venus)**:
        *   Position: Absolute left edge (`left: -40px`), vertically centered (~55% from top).
        *   Content: Half-visible planet image + label `VENUS` on the right side of the image.
    *   **Right Element (Mars)**:
        *   Position: Absolute right edge (`right: -40px`), vertically centered (~55% from top).
        *   Content: Half-visible planet image + label `MARS` on the left side of the image.

---

### **D. Bottom Hero Asset (Planet Earth) & Scroll Indicator**

1.  **Main Earth Image**:
    *   Position: Absolute bottom center (`bottom: -250px` to `-300px` depending on screen ratio, showing top hemisphere ~40-50%).
    *   Width: ~`900px` - `1000px` (Scales dynamically with viewport width).
    *   Visual Glow: Intense neon cyan-blue atmospheric aura glowing along the top outer curved edge.

2.  **Scroll Down Indicator**:
    *   Position: Superimposed at top-center of the Earth curve (`bottom: 120px` from screen bottom).
    *   Shape: Circle (`width: 40px`, `height: 40px`, `border-radius: 50%`).
    *   Background: Dark transparent blue/grey (`rgba(15, 23, 42, 0.8)`).
    *   Border: `1px solid rgba(255, 255, 255, 0.2)`.
    *   Icon: White downward arrow (`↓`).

## 5. Precise Asset & Image Specifications

### **1. Planet Earth (Main Hero Asset)**
*   **Format**: PNG / WebP with transparent background (No rectangle bounding box or background noise).
*   **Description**: Photorealistic 3D rendering of Earth viewed from space. High contrast showing the North American / Atlantic ocean side, bright daylight section on top, white swirl clouds, bright electric blue atmospheric glow along the horizon arc.
*   **Transform/Placement**: Center-bottom anchored.

### **2. Venus (Left Carousel Preview)**
*   **Format**: PNG with transparent background.
*   **Description**: Spherical planet with smooth yellow-beige/greyish atmospheric cloud density.
*   **Placement**: Cropped by screen boundary on left edge (50% off-screen). Lit from the right.

### **3. Mars (Right Carousel Preview)**
*   **Format**: PNG with transparent background.
*   **Description**: Spherical planet displaying vibrant reddish-orange rusty surface texture with visible crater details and polar caps.
*   **Placement**: Cropped by screen boundary on right edge (50% off-screen). Lit from the left.

---

## 6. Micro-Interactions & States

*   **Nav Items**: Hover state transitions color to `#FFFFFF` with smooth `color 0.2s ease`.
*   **"Get Started" Button**: Hover state increases radial box shadow intensity (`box-shadow: 0 0 35px rgba(56, 189, 248, 0.6)`) and slight scaling (`transform: scale(1.03)`).
*   **Scroll Button**: Hover state brightens border and shifts arrow downwards slightly (`transform: translateY(2px)`).
*   **Side Planets**: Hover state slightly moves inwards (`transform: translateX(10px)`) to signal clickability to switch view to Venus/Mars.
