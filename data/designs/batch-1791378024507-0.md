# Design Specification: Berry Pie Interactive Showcase

This document outlines the exact design and functional specifications for recreating the interactive "Berry Pie" web application shown in the media. 

---

## 1. Global Layout & Viewport

*   **View:** Full-screen immersive layout (`width: 100vw; height: 100vh`).
*   **Overflow:** Hidden (`overflow: hidden`) to prevent scrolling.
*   **Background:** 
    *   **Color Type:** Radial Gradient.
    *   **Colors:** Deep purple (`#2a0845`) transitioning outward into a vibrant violet-magenta hue (`#4a1578` / `#641975`).
*   **Lighting Effect:** A soft overhead/top-center radial vignette simulating studio lighting.

---

## 2. Typography & Font Stack

### Primary Header Font (Script / Cursive)
*   **Used For:** Main title ("*Berry pie*")
*   **Style:** Elegant, flowing script with moderate slant.
*   **CSS Font Family:** `'Playball', 'Great Vibes', 'Lucida Handwriting', cursive`
*   **Fallback Stack:** `cursive`

### Secondary UI Font (Sans-Serif / Geometric)
*   **Used For:** Navigation links, metrics, carousel labels, circular track text.
*   **Style:** Clean, monospaced or geometric sans-serif with wide letter-spacing.
*   **CSS Font Family:** `'Space Mono', 'Courier New', monospace` (or `'Inter'` / `'Montserrat'` with `letter-spacing: 0.1em`).
*   **Fallback Stack:** `monospace`

---

## 3. UI Components & Elements

### A. Top Navigation Bar
*   **Position:** Absolute / Fixed, top center.
*   **Elements:**
    1.  **Logo Icon:** Top-left corner (abstract pie/slice icon in gold/yellow).
    2.  **Navigation Links:** Horizontal alignment (`Home`, `Menu`, `Contacts`).
        *   Font Size: `14px`
        *   Font Weight: Medium / Semi-bold
        *   Color: White with `0.8` opacity (Active/Hover: `1.0` opacity).
    3.  **Chat/Message Icon:** Top-right corner (speech bubble icon).

### B. Main Header & Metrics
*   **Title:**
    *   Text: `Berry pie`
    *   Font: Script typography, large display size (`~42px`).
    *   Color: Pure white (`#FFFFFF`).
*   **Social Proof / Reactions:**
    *   Position: Directly beneath the main title.
    *   Elements:
        *   **Like Count:** `3,654` followed by a Thumbs-Up icon.
        *   **Dislike Count:** `102` followed by a Thumbs-Down icon.
    *   Font Size: `12px`
    *   Color: Off-white / Muted purple-grey (`#D1C4E9`).

### C. Circular Carousel & Selection Wheel (Core Feature)
*   **Structure:** An arc/circular track positioned behind/around the dessert image.
*   **Track Items (Pastries):**
    *   Arranged along the curved path: `peach tart`, `berry tart`, `apple pie`, `lemon cake`, `[ACTIVE: Berry pie]`, `straw tart`, `lemon tart`.
    *   Active Item (`Berry pie`): Positioned at the top-right of the arc, highlighted with a solid white indicator dot on the track line.
*   **Interactive Controls:**
    *   **Left Navigation Button:** Circular translucent button on the middle-left with a left chevron icon (`<`).
    *   **Right Navigation Button:** Circular translucent button on the middle-right with a right chevron / audio / interaction icon (`>`).
    *   *Styling:* Frosted glass effect (`background: rgba(255, 255, 255, 0.15)`, `border-radius: 50%`, `backdrop-filter: blur(4px)`).

### D. Featured Dessert Image
*   **Position:** Centered lower half of the screen, clipping past the bottom edge.
*   **Visuals:**
    *   A freshly baked berry pie inside a dark fluted tart tin.
    *   Rich purple/red berry filling visible under a golden, buttery crust.
    *   Generously dusted with powdered sugar (creating a snowy texture on top).
*   **Shape & Depth:**
    *   Slight drop shadow behind the pie dish to lift it off the purple background.

---

## 4. Animations & Interactions

1.  **Circular Carousel Rotation (Drag / Scroll / Click):**
    *   When navigating between desserts (e.g., clicking the left/right arrows or dragging along the arc), the circular track rotates smoothly.
    *   **Easing:** `cubic-bezier(0.25, 1, 0.5, 1)` (Smooth deceleration).
    *   **Duration:** `0.6s`.
2.  **Text Transitions:**
    *   When a new item is selected, the main title ("Berry pie") and like/dislike counts fade out and slide upward, replaced by the newly selected pastry's metadata.
3.  **Hover States:**
    *   Navigation items and arrow buttons scale up slightly (`transform: scale(1.05)`) with an increased opacity transition (`0.2s ease`).
