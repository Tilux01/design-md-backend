# UI/UX Specification & Design System: E-Commerce Product Page ("Nextgen")

## 1. Overview & Global Layout
- **Target Screen:** Desktop web application (min-width: 1440px viewport recommended).
- **Layout Architecture:** 
  - Centered container layout with a maximum content width of approximately 1280px.
  - Generous whitespace and padding (consistent 24px–40px grid scaling).
  - Background color: Pure White (`#FFFFFF`) for content cards and base sections, set against a very light neutral gray background canvas (`#F4F5F7` / `#ECEEF1`).
- **Responsive Behavior Notes:** Switch to single-column stacking below 1024px. Carousel controls transform to horizontal swipe gestures on touch devices.

---

## 2. Typography & Font Stack
*Primary Font Family:* **Inter** (Fallback: `system-ui`, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `Helvetica`, `Arial`, `sans-serif`).

| Role / Element | Font Size | Line Height | Font Weight | Color Code |
| :--- | :--- | :--- | :--- | :--- |
| **Brand / Logo** | 18px | 24px | Bold (700) | `#111111` |
| **Main Navigation** | 14px | 20px | Regular / Medium (400/500) | `#333333` |
| **Product Title (H1)** | 26px | 32px | Semi-Bold (600) | `#111111` |
| **Price (Primary)** | 22px | 28px | Semi-Bold (600) | `#111111` |
| **Section Headings (H2)** | 20px | 28px | Semi-Bold (600) | `#111111` |
| **Subheadings / Card Titles**| 15px | 22px | Medium (500) | `#111111` |
| **Body / Description text** | 13px | 20px | Regular (400) | `#555555` |
| **Labels / Microcopy** | 12px | 16px | Regular (400) | `#777777` |

- **Transitions:**
  - Smooth 250ms ease-in-out transitions applied to button hover states, accordion toggles, and image gallery switches.
