# DESIGN SYSTEM & UI SPECIFICATION: "PURE DESIGN ('25)"

---

## 1. DESIGN OVERVIEW & ARCHITECTURE

This document provides the complete, high-fidelity design specification for cloning the modern editorial landing page shown in the target image. 

The aesthetic is **High-End Technical Editorial / Neo-Grotesk Minimalism**, characterized by high-contrast monochrome tones, precision typography, layered glassmorphism components, asymmetric grid alignment, and cut-out subject photography.

*   **Layout Type:** Full-viewport fluid layout (100vw, no outer device frames or artboard margins).
*   **Theme Mode:** Dual Split (Light Hero Canvas transition into Deep Dark Mode body).
*   **Grid System:** 12-column dynamic grid with a centered content container max-width of `1440px`.

## 6. INTERACTION & MICRO-ANIMATION SPECS

1.  **Cursor Effects:** Custom precise circular dot cursor over dark surfaces, expanding slightly when hovering over interactive pills and arrow buttons (`↗`).
2.  **Navigation Pill Switch:** Smooth sliding indicator background (`transition: all 0.3s cubic-bezier(0.16, 1, 0.3, 1)`) when switching navigation items (`Home`, `Studio`, `Works`, `Blog`).
3.  **Floating Glass Badges:** Subtle floating physics animation (`transform: translateY(-4px to 4px)` loop over 4 seconds) on the glassmorphism badges over the title text.
4.  **Text Reveal Effect (Philosophy Section):** Scroll-triggered opacity transition where low-opacity text (`#555555`) brightens to white (`#FFFFFF`) as the user scrolls into view.
5.  **Hover State on Cards:** Scale up preview thumbnail images (`scale(1.04)`) inside dark frames on hover with hidden diagonal arrow icons animating up and to the right (`translate(2px, -2px)`).
