# UI Design Specification: Vitality Fitness Dashboard

## 1. Global Layout & Structure

- **Viewport/Canvas:** Full-screen responsive layout (designed on a desktop viewport, approximately 1440px × 900px standard).
- **Background Color:** Soft, pastel cyan/mint (`#D8F2F0` or similar light teal tint) framing the entire application window.
- **Main Container Card:** Centered dashboard container with a solid white (`#FFFFFF`) background, large border-radius (approx. 24px), subtle drop shadow (`box-shadow: 0 10px 30px rgba(0, 0, 0, 0.05)`), and structured internal grid padding.
- **Layout Grid:** 
  - **Left Sidebar:** Fixed width (approx. 240px), vertical navigation panel spanning full height of the main container.
  - **Main Content Area:** Flexible grid area spanning the remaining width, divided into horizontal rows containing widget cards.

---

## 2. Typography & Fonts

- **Primary Font Family:** `Inter`, `SF Pro Display`, `Roboto`, or system sans-serif.
- **Fallback Font Stack:** `sans-serif`
- **Font Weights Used:** Regular (400), Medium (500), Semi-Bold (600), Bold (700).

### Type Hierarchy:
- **Logo ("Vitality"):** Bold (700), ~24px, italicized/slanted modern sans-serif with a custom running figure icon integrated into the 'y'.
- **Top Navigation Tabs ("Popular", "Attention", "Topic", "Diary"):** Medium (500), ~14px. Active state ("Popular") underlined with a teal indicator bar.
- **Section Headers ("Training Time", "Training type", "Group", "Clients"):** Semi-Bold (600), ~16px–18px.
- **Metric Values ("27 Day", "179 kcal"):** Bold (700), large scale (~32px for numbers, ~12px for labels).
- **Body & Metadata Text (Names, descriptions, timestamps):** Regular/Medium (400/500), ~12px–14px, colored in muted gray (`#8C9BA5`).

---

## 3. Color Palette

- **Primary Brand / Accent Teal:** `#35C2B4` (Used for active tabs, primary buttons, chart lines, circular progress rings).
- **Sidebar Gradient Background:** Vertical gradient transitioning from a vibrant turquoise (`#45C4BE`) at the top to a softer sky blue (`#62A8DF`) at the bottom.
- **Background Tint (Cards & Fields):** `#F4F8F8` or `#F7FAFA` for light container backgrounds (e.g., search bar, training type card).
- **Text Dark (Primary):** `#2C3E50` or `#1E293B` (High-contrast text for headers and primary values).
- **Text Muted (Secondary):** `#7F8C8D` or `#94A3B8` (Subtitles, labels, inactive tabs).
- **Highlight Yellow:** `#FDCB58` (Used for interactive CTA plus button inside the training type widget).
- **Notification Badge Teal:** `#1ABC9C` with white text.

---

## 4. Component Specifications

### A. Left Sidebar Navigation
- **Dimensions:** Full height of the main white card, rounded left corners to match the container.
- **Logo Area:** Top-left of the sidebar featuring the "Vitality" wordmark in white with a running runner glyph.
- **Navigation Links:** Vertical list with icon + text pairing.
  - *Active State ("Community"):* White pill-shaped background spanning the width with dark teal icon and bold text.
  - *Inactive States ("Sport", "Plan", "Category", "Store"):* Clean white text and icons without background containers, spaced evenly.
- **Bottom Action ("Go Out"):** Pill-shaped button at the bottom of the sidebar with an icon and white text.

### B. Top Header Bar
- **Navigation Tabs:** Horizontal text links ("Popular", "Attention", "Topic", "Diary"). Active tab features a solid teal underline pill.
- **Search Bar:** Pill-shaped input field, light gray background (`#F1F5F9`), magnifying glass icon on the left, placeholder text `"Search"` in muted gray.
- **Notification Bell:** Circular icon button on the far right with a small orange notification dot indicator.

### C. Hero Widget: Training Time & Trend Card
- **Background:** Gradient card shifting from rich teal to soft cyan (`#38C4BD` to `#61A7DE`), featuring white text.
- **Left Metric:** Large bold number `"27"` with `"Day"` superscript, followed by sub-metrics ("Fat burning 49Kcal", "Duration 13minutes").
- **Right Chart ("Training trend"):** Smooth dual-line area chart with data points, mini UI preview cards floating on top of the graph, and mini bar-chart/line-chart utility icons in the top right corner. Day selector pills ("Mon", "Tue", "Wen") positioned underneath the main metric container.

### D. Burn Calories Card (Right Side)
- **Background:** Solid white card with subtle rounded corners and thin border or soft shadow.
- **Header:** `"Burn calories"` (left) and `"Jun 2019"` date (right).
- **Chart:** Circular progress ring (thick teal track with rounded ends) displaying `"179 cal / USD"` in the center, flanked by indicator dots. Footer notes `"Avg 8%"` and `"You 8%"`.

### E. Training Type Section
- **Header:** `"Training type"` with a "See more training time" link aligned to the right.
- **Interactive Tiles:** 
  - Three rounded square cards containing glyphs representing athletic activities (e.g., running, swimming, weightlifting) on solid teal icon plates.
  - A yellow square action button (`#FDCB58`) featuring a bold black plus (`+`) sign for adding custom workouts.

### F. Group & Community Section ("Group")
- **Header:** `"Group"` with a vertical three-dot menu icon on the right.
- **List Items:** 
  - User avatar thumbnail (circular image).
  - User name (e.g., "Lillian", "Helena", "Strickland") in bold dark text.
  - Status message or achievement text underneath (e.g., "Congratulations", "Thank you", "You can check it").
  - Unread/activity count badge on the far right (solid teal pill with white number).

### G. Clients Section
- **Header:** `"Clients"` with a `"View all >"` navigation link on the right.
- **Content:** Layout structured for business profile cards or lists extending downward.

---

## 5. Asset & Image Placeholders

- **Avatars:** Circular user profile pictures (e.g., photos of young adults smiling or in athletic wear). Use high-quality photographic placeholders matching modern fitness app aesthetics.
- **Icons:** Minimalist, clean vector glyphs (Feather Icons, FontAwesome, or Lucide style) representing search, bell, bookmark, lightning bolt, calendar, categories, store, logout, and activity metrics.
