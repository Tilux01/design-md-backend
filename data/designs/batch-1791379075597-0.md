# UI/UX Specification & Design System: E-Commerce Landing Page ("Catch The Style")

This document provides the exact specifications, layout, typography, and interactive behaviors required to create a pixel-perfect, full-screen responsive clone of the provided e-commerce landing page design. 

---

## 1. Global Layout & Structure

*   **View:** Full-screen edge-to-edge layout (zero outer padding/margins on desktop, adapting to mobile viewport scales).
*   **Background Hierarchy:**
    *   **Hero Section:** Multi-stop radial/linear gradient from deep crimson/burgundy (`#60132b`) on the left to vibrant orange-coral (`#e06634` / `#f08552`) on the right.
    *   **Content Section:** Clean, minimalist pure white background (`#ffffff`) for readability of product lists and cards.
*   **Layout Grid:** Centered container layout for content with a max-width of approximately `1200px` for desktop, scaling to full-width fluidity on mobile devices.

---

## 2. Typography & Fonts

### Font Family Strategy
*   **Primary Font:** `Inter` (Sans-serif) for general UI text, prices, and small labels.
*   **Secondary/Heading Font:** `Poppins` or `Montserrat` (Geometric Sans-serif) for high-impact headers like "New Arrival" and "Best Seller".
*   **Ticker Font:** Uppercase bold sans-serif with tracked-out letter spacing for the top promotional marquee.

### Fallback Stack
```css
font-family: 'Poppins', 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
```

## 3. Component Breakdown & Styling

### 3.1. Top Promotional Ticker (Marquee)
*   **Background:** `#111111` (Dark Charcoal) or transparent overlaying the hero gradient.
*   **Content:** Repeating string: `CATCH THE STYLE ✳ CATCH THE STYLE ✳ CATCH THE STYLE`
*   **Icon:** Four-pointed star (`✳` or SVG spark).
*   **Animation:** Infinite horizontal CSS marquee scroll from right to left.

### 3.2. Hero Section
*   **Hero Visuals:**
    *   **Main Model:** Central portrait of a model wearing a bright yellow puffer jacket and tinted sunglasses.
    *   **Floating Cards (New Arrival Thumbnails):** 
        *   Positioned dynamically over the hero background.
        *   Styled with a white semi-transparent frosted glass border (`rgba(255, 255, 255, 0.4)`), rounded corners (`border-radius: 12px`), and a subtle drop shadow (`box-shadow: 0 8px 32px rgba(0,0,0,0.15)`).
        *   Includes a small bottom red/coral pill badge reading **"New Arrival"**.
    *   **Pagination Dots:** Vertical stack of white dots on the right side of the hero image (one active elongated pill, two circular inactive dots).
*   **Hero Call-to-Action (CTA) Button:**
    *   **Label:** "Explore items"
    *   **Background:** `#111111` (Solid Black)
    *   **Text Color:** `#ffffff` (White)
    *   **Border Radius:** `20px` (Fully rounded pill shape)
    *   **Padding:** `10px 20px`
    *   **Hover Effect:** Slight scale up (`transform: scale(1.05)`) with shadow intensification.

### 3.3. Section Headers ("New Arrival" & "Best Seller")
*   **Alignment:** Flex container with `justify-content: space-between` and `align-items: center`.
*   **Left Element:** Bold section title (e.g., "New Arrival").
*   **Right Element ("See All" Button):**
    *   **Background:** `#111111`
    *   **Text:** White, `11px`, bold.
    *   **Shape:** Pill button (`border-radius: 16px`).
    *   **Padding:** `6px 14px`.

### 3.4. Product Cards (New Arrival Row)
*   **Card Container:**
    *   **Background:** `#f9f9f9` (Soft off-white / light gray) or `#ffffff` with subtle border.
    *   **Border Radius:** `16px`.
    *   **Padding:** `12px`.
    *   **Dimensions:** Fixed width layout supporting horizontal scrolling on mobile or a 3-column grid on desktop.
*   **Product Image:**
    *   Centered model/product shot with transparent or neutral background.
    *   Aspect ratio: `4:5`.
    *   Border radius inside card: `12px`.
*   **Product Details:**
    *   **Title:** e.g., "Daisy Shirt", "Rei Blue Jac...", "Rozz Jacket". Truncated with ellipsis if text overflows.
    *   **Rating:** 5 gold stars (`#ffc107`) followed by review count in parentheses (e.g., `(129 Reviews)`).
    *   **Price:** Bold black text formatted with currency symbol (`$58.00`).

### 3.5. Best Seller Row (Circular / Card Carousel)
*   **Layout:** Horizontal scrolling row of cards featuring rounded bottom images with gradient overlays.
*   **Card Design:**
    *   **Background Gradients:** Deep coral-to-burgundy vertical gradients mirroring the hero aesthetic.
    *   **Border Radius:** `20px`.
    *   **Content:** High-fashion portraits centered inside each card.

## 4. Animations & Micro-Interactions

1.  **Marquee Ticker Animation:**
    ```css
    @keyframes marquee {
      0% { transform: translateX(0%); }
      100% { transform: translateX(-50%); }
    }
    .ticker-track {
      display: flex;
      width: 200%;
      animation: marquee 20s linear infinite;
    }
    ```
2.  **Hover States for Product Cards:**
    *   `transition: transform 0.3s ease, box-shadow 0.3s ease;`
    *   On hover: `transform: translateY(-4px); box-shadow: 0 12px 24px rgba(0,0,0,0.08);`
3.  **Smooth Scrolling:** Enabled globally for all anchor and carousel interactions (`scroll-behavior: smooth;`).
