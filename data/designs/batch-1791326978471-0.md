# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Generative Sci-Fi Dark Mode / Cyber-Organic Spatial Interface.
- **Visual Density & Whitespace Ratio**: High-density atmospheric immersion with precise focal contrast between organic textures and structured illumination.
- **Surface Elevation Model**: Layered depth using sub-surface luminescent particle matrices, stepped elevation tiers with 3D topological lighting gradients, and deep shadow drop-offs.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Luminescent point-cloud wireframes, high-tracking uppercase telemetry pills, deep atmospheric drop-off gradients, procedural noise textures.
- **Pill Badge Specification**: Padding: `6px 14px`, font-size: `12px`, font-weight: `600`, tracking: `0.08em`, border-radius: `9999px`, background: `rgba(0, 240, 255, 0.08)`, border width: `1px` solid `rgba(0, 240, 255, 0.3)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-[#00f0ff] inline-block shadow-[0_0_8px_#00f0ff]"></span>`.
