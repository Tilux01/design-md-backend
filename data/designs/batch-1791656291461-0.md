# Comprehensive UI/UX Design Specification & Replication Blueprint

This specification serves as an exact, production-ready blueprint for replicating the multi-screen educational mobile application showcased in the reference media. The UI follows a modern, playful, yet professional EdTech design system characterized by organic wave structures, soft glassmorphism, rounded card modules (iOS/Android hybrid aesthetic), and distinct pastel/vibrant color-coding per screen context.

---

## 1. Global Typography System & Font Stack

All font weights must strictly use standard sans-serif weights (`Regular/400`, `Medium/500`, `Semibold/600`, `Bold/700`, `Black/900`).

*   **Primary Font Family:** **'Poppins', 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif**
*   **Fallback Font Strategy:** 
    1. If `Poppins` is unavailable, fall back to `Inter`.
    2. If `Inter` is unavailable, fall back to native system UI fonts (`-apple-system` for iOS, `Roboto` for Android).
*   **Scale & Usage:**
    *   **App Header Greetings ("Hi, Elizabeth"):** `20px` to `24px`, Weight: `Bold (700)`.
    *   **Section Headers ("Learning plan", "Leaderboard", "My courses"):** `22px` to `26px`, Weight: `Bold (700)`.
    *   **Card Titles ("A series of Olympiads", "Creative approaches..."):** `16px` to `18px`, Weight: `Semibold (600)`.
    *   **Body & Meta Text (Timestamps, progress notes):** `12px` to `14px`, Weight: `Regular (400)` or `Medium (500)`.
    *   **Micro-metrics (Numbers inside statistics bubbles):** `18px` to `28px`, Weight: `Bold (700)` or `Black (900)`.

---

## 2. Global Design Tokens & Colors

*   **Border Radius Strategy:** 
    *   Outer screen canvas (if mocked with frame, ignore for full-screen view): `0px` (Full Screen).
    *   Primary Cards / Containers: `24px` to `32px`.
    *   Badges, Pills, Buttons: `16px` to `999px` (fully rounded capsule).
*   **Shadows:** Soft diffuse shadows with high blur and low opacity (`0px 10px 30px rgba(0, 0, 0, 0.08)`).

## 3. Image Assets Description Guidelines

Since specific photo assets cannot be generated via code alone, use the following guidelines for sourcing or substituting images:
*   **Avatars:** Circular, high-contrast, backgroundless headshot portraits of diverse students and young professionals (smiling expressions, clean lighting).
*   **Illustrations:** 3D vector-style isometric graphics (e.g., golden trophy cup with purple accents, graduation cap floating over a diploma background) utilizing soft drop shadows and rounded claymorphic textures.
