# UI/UX Specification & Frontend Implementation Guide

## 1. Global Layout & Viewport
* **Layout Structure:** Full-screen viewport (`width: 100vw; height: 100vh; overflow: hidden;`)
* **Background Gradient:** A deep, radial blue gradient simulating a studio lighting effect.
  * `background: radial-gradient(circle at center, #0056b3 0%, #001e3d 70%, #000814 100%);`
* **Card Container:** A centered, floating glassmorphic container with rounded corners and a soft drop shadow.
  * Dimensions: Max-width ~1200px, centered via CSS Flexbox/Grid.
  * Border-radius: `24px`
  * Box-shadow: `0 25px 50px -12px rgba(0, 0, 0, 0.7)`
  * Border: `1px solid rgba(255, 255, 255, 0.15)`

---

## 2. Typography & Font Stack
* **Primary Display/Branding Font:** **Futura** or **Montserrat** (Bold, Geometric Sans-Serif)
  * *Fallback Stack:* `font-family: 'Montserrat', 'Futura', -apple-system, BlinkMacSystemFont, sans-serif;`
* **Body/UI Font:** **Inter** or **Roboto** (Clean, Modern Sans-Serif)
  * *Fallback Stack:* `font-family: 'Inter', 'Roboto', sans-serif;`

---

## 4. Animations & Micro-Interactions

* **Page Load Entrance:**
  * *Fade-in & Scale:* The main card container scales up from `0.95` to `1.0` with opacity transition over `0.8s cubic-bezier(0.16, 1, 0.3, 1)`.
  * *Staggered Reveal:* Left text elements slide in from the left (`translateX(-20px)`); the shoe drops in from above with a soft bounce; the right panel slides in from the right.
* **Product Float Animation:**
  * Continuous subtle vertical floating loop on the shoe element:
    ```css
    @keyframes float {
      0%, 100% { transform: translateY(0px) rotate(0deg); }
      50% { transform: translateY(-10px) rotate(1deg); }
    }
    animation: float 6s ease-in-out infinite;
    ```
* **Hover States:**
  * **BUY NOW Button:** Scales up slightly (`transform: scale(1.05)`) with an intensified neon glow (`box-shadow: 0 0 30px rgba(0, 242, 254, 0.9)`).
  * **Navigation Links:** Smooth color transition to pure white with an expanding underline indicator.
  * **Dropdown Selectors:** Subtle background highlight on hover (`background: rgba(255,255,255,0.1)`).
