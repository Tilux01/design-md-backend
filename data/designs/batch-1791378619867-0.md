# Design Specification: Chocolate Ice Cream Interactive Landing Page

This document outlines the exact visual design, layout, typography, color palette, and interactive animations for the "Chocolate Ice Cream" landing page shown in the media.

---

## 1. Global Layout & Structure

*   **View:** Full-screen immersive layout (ignoring the laptop mockup).
*   **Background:** 
    *   Concentric circles creating a retro/modern bullseye effect radiating outward.
    *   Alternating shades of warm brown and cream.
*   **Centerpiece:** 
    *   A massive, highly detailed 3D/rendered sphere of chocolate ice cream loaded with visible dark chocolate chunks.
    *   Positioned directly in the visual center of the concentric circles.
*   **Scattered Elements:** 
    *   5 individual squares of chocolate pieces scattered at various angles around the central ice cream scoop.
*   **Navigation Controls:** 
    *   Left circular arrow button (`<`) located mid-left.
    *   Right circular arrow button (`>`) located mid-right.

---

## 2. Color Palette

| Color Name | Hex Code (Approximate) | Usage |
| :--- | :--- | :--- |
| **Deep Chocolate** | `#3B1E08` | Darkest concentric rings, chocolate chunks, typography base |
| **Warm Medium Brown** | `#8C4A2E` | Mid-tone concentric rings |
| **Cream / Pale Sand** | `#EEDCC5` | Lightest background rings, text container contrast |
| **Pure White** | `#FFFFFF` | Text highlights, navigation button icons |

---

## 3. Typography & Fonts

### **Primary Display Font (Heading)**
*   **Text:** "Chocolate Ice cream"
*   **Style:** Stylized script/retro brush font. Connected lowercase letters with a sweeping baseline for "Ice cream" and a bold, stylized serif/sans-serif hybrid for "Chocolate".
*   **CSS / Web Font Recommendation:** 
    *   *Primary:* `Pacifico` or `Great Vibes` (for the script portion) combined with a bold slab serif like `Playfair Display` or `Abril Fatface` (for "Chocolate").
    *   *Fallback Stack:* `font-family: 'Pacifico', 'Brush Script MT', cursive;`

### **Secondary Font (Body / Description)**
*   **Text:** *"Indulge in the ultimate chocolate experience with our rich, creamy chocolate ice cream, loaded with decadent chocolate chunks! A heavenly treat that melts in your mouth, satisfying every chocolate lover's dream."*
*   **Style:** Clean, highly legible sans-serif. Small font size, light weight, tight line-height, justified or left-aligned within a defined text block.
*   **CSS / Web Font Recommendation:**
    *   *Primary:* `Inter` or `Poppins`
    *   *Fallback Stack:* `font-family: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;`
    *   *Properties:* `font-size: 12px;` / `font-weight: 300;` / `line-height: 1.4;` / `color: #3B1E08;`

---

## 4. UI Elements & Components

### **Navigation Arrows**
*   **Shape:** Perfect circle (`border-radius: 50%`), semi-transparent backdrop with a solid white or dark icon.
*   **Position:** Absolute positioning on the far left and far right centers of the viewport.
*   **Interaction:** Scale up slightly on hover (`transform: scale(1.05)`).

### **Brand / Decorative Flairs**
*   **Splash/Steam lines:** Small radiating curved dash marks above the word "Chocolate" giving a handcrafted/organic feel.

---

## 5. Animation & Interactive Behaviors

If building this as an interactive web page (HTML/CSS/JS), include the following animations:

1.  **Page Load Entrance:**
    *   **Background Circles:** Scale up from center with a slight opacity fade-in (`ease-out`).
    *   **Central Ice Cream Scoop:** Drop down or zoom in with a gentle spring/bounce effect (`cubic-bezier(0.175, 0.885, 0.32, 1.275)`).
    *   **Chocolate Squares:** Float into place from random offset directions with subtle rotation angles.

2.  **Hover & Parallax Effects:**
    *   **Mouse Move Parallax:** The background concentric circles shift slightly in the opposite direction of the mouse cursor to create a 3D depth effect.
    *   **Ice Cream Hover:** Gentle floating loop animation (up and down by 5-10px infinitely using CSS `@keyframes float`).

3.  **Navigation Transition (Slider):**
    *   Clicking the left/right arrows triggers a slide transition where the central ice cream and background rings slide horizontally off-screen while the next flavor slides in.
