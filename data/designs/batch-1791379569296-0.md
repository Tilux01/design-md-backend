# Design Specification: Watermelon Juice Landing Page

## 1. Overview & Layout Strategy

This document provides the exact technical and visual specification to recreate the watermelon landing page as a **full-screen, edge-to-edge experience** (omitting the browser mockup frame shown in the reference image).

*   **View Mode:** Full viewport (`width: 100vw; height: 100vh; overflow: hidden;`).
*   **Layout Architecture:** Single-page hero section with a centered focal point.
*   **Grid / Flex Alignment:** 
    *   **Header:** Flexbox (`display: flex; justify-content: space-between; align-items: center;`) with absolute positioning over the hero background.
    *   **Hero Content:** Flex column layout (`display: flex; flex-direction: column; align-items: center; justify-content: center;`) centered vertically and horizontally within the viewport.

---

## 2. Color Palette & Visual Styling

The design relies entirely on a monochromatic magenta/burgundy gradient palette to create a moody, premium aesthetic.

| Element | Color Value (HEX / RGBA) | Usage |
| :--- | :--- | :--- |
| **Background (Top/Mid)** | `#7a1c3e` to `#5e1530` | Radial or linear gradient shifting from lighter magenta-burgundy to deep plum. |
| **Background (Bottom)** | `#420d20` | Darkest tone at the lower fold for ground shadow anchoring. |
| **Primary Text (Headings)** | `#FFFFFF` | Used for `"THE PERFECT WATERMELON JUICE"` and logo text. |
| **Secondary Text (Subheading)** | `rgba(255, 255, 255, 0.4)` (Outline style) | Used for `"SUBHEADING"`. |
| **Navigation Links** | `#FFFFFF` | Menu items in the header. |
| **CTA Button Fill** | `#FFFFFF` | Background for the "CONTACT US" pill button. |
| **CTA Button Text** | `#320918` | Dark burgundy text inside the "CONTACT US" button for high contrast. |

---

## 3. Typography & Font Stack

All typography is uppercase. Letter spacing is wide to match modern minimalist luxury web design trends.

### Font 1: Logo & Body Headings (`"WATERMELON"`, `"THE PERFECT WATERMELON JUICE"`)
*   **Target Font:** **Anton** or **Oswald** (Heavy Sans-Serif, Condensed).
*   **Fallback Stack:** `Impact, 'Arial Black', sans-serif`.
*   **Weight:** 700 / Bold.
*   **Text Transform:** Uppercase.
*   **Letter Spacing:** `1px` to `2px`.

### Font 2: Subheading (`"SUBHEADING"`)
*   **Target Font:** **Syne** or **Montserrat** (Geometric Sans-Serif).
*   **Fallback Stack:** `Helvetica, Arial, sans-serif`.
*   **Weight:** 700 / Bold.
*   **Style:** Hollow/Stroke text effect (Transparent fill with a thin white/translucent outline stroke).
*   **Letter Spacing:** `4px` (Wide tracking).

### Font 3: Navigation & UI (`"HOME"`, `"HARVESTING"`, etc.)
*   **Target Font:** **Inter** or **Roboto**.
*   **Fallback Stack:** `-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`.
*   **Weight:** 600 / Semi-Bold.
*   **Text Transform:** Uppercase.
*   **Font Size:** Small (~`12px` to `14px`).
*   **Letter Spacing:** `1.5px`.

---

## 4. Component Breakdown & Positioning

### A. Header Navigation Bar
*   **Position:** `position: absolute; top: 0; left: 0; width: 100%;` with internal padding (`padding: 30px 60px;`).
*   **Left Element:** Logo
    *   Icon: Minimalist triangle/slice logo vector in white.
    *   Text: `"WATERMELON"` placed inline next to the icon.
*   **Right Element:** Navigation Links & CTA
    *   Links: `HOME`, `HARVESTING`, `SOWING SIMPLICITY`, `ABOUT US`. Spaced evenly with generous gaps (~`32px`).
    *   CTA Button: `CONTACT US`
        *   Shape: Pill/Rounded rectangle (`border-radius: 50px;`).
        *   Padding: `10px 24px`.
        *   Background: White (`#FFFFFF`), Text: Dark Burgundy (`#320918`).

### B. Hero Content (Center Stack)
*   **Subheading:**
    *   Text: `"SUBHEADING"`
    *   Styling: `-webkit-text-stroke: 1px rgba(255, 255, 255, 0.4); color: transparent;`
    *   Font Size: Medium-Large (~`24px` to `32px`).
    *   Margin Bottom: `8px`.
*   **Main Headline:**
    *   Text: `"THE PERFECT WATERMELON JUICE"`
    *   Font Size: Extra Large (~`48px` to `64px`, responsive vw scaling recommended).
    *   Alignment: Center aligned.
    *   Margin Bottom: `40px`.

### C. Focal Element (Watermelon & Shadow)
*   **Asset:** High-resolution 3D-rendered or studio-lit whole watermelon floating centrally.
*   **Positioning:** Placed directly beneath the main headline.
*   **Shadow Effect:** 
    *   A soft, blurred dark elliptical drop-shadow directly underneath the watermelon on the floor plane to sell the "floating/levitating" effect.
    *   `box-shadow` or a separate blurred pseudo-element ellipse with low opacity (`opacity: 0.3; filter: blur(12px);`).

---

## 5. Animation & Interaction Specifications

To match the floating, modern presentation style seen in WebGL/Elementor showcase templates:

1.  **Levitation Animation (Watermelon):**
    *   **Type:** CSS Keyframe Infinite Float.
    *   **Duration:** `4s` to `6s`.
    *   **Timing Function:** `ease-in-out`.
    *   **Behavior:** Translate vertically up and down by `10px` to `15px`.
    ```css
    @keyframes float {
      0% { transform: translateY(0px); }
      50% { transform: translateY(-12px); }
      100% { transform: translateY(0px); }
    }
    ```

2.  **Hover States (Navigation & CTA):**
    *   **Nav Links:** Smooth opacity shift on hover (`opacity: 0.7; transition: opacity 0.3s ease;`).
    *   **CTA Button (`CONTACT US`):** Slight scale-up (`transform: scale(1.05);`) or background color shift on hover with a smooth transition.
