# Design Specification: RENTRA Car Rental App (Porsche 816 Detail View)

This document outlines the exact design specifications for replicating the RENTRA car rental app user interface displayed in the media. 

---

## 1. Global Styles & Layout Architecture

* **Layout Mode:** Full-screen responsive mobile layout (simulating an iPhone 14/15 Pro display with a dynamic island and rounded bezel aesthetic).
* **Color Palette:**
  * **Primary Background:** `#EAEAEA` (Light Gray / Off-white) to `#F4F4F4` gradient.
  * **Card Fill Color (Frosted Glass Effect):** `#E2E2E2` with a subtle white backdrop blur or solid translucent light gray `#EDEDED`.
  * **Primary Text (Dark):** `#111111` (Near Black).
  * **Secondary Text (Muted):** `#666666` (Medium Gray).
  * **Accent Color (CTA & Indicators):** `#000000` (Black) for main buttons, `#D64527` (Burnt Orange / Red) for the small diagonal arrow indicators and car taillight glow.
* **Typography:**
  * **Primary Typeface:** *Helvetica Neue*, *Arial*, or *Inter* (Clean, geometric sans-serif).
  * **Fallback Stack:** `sans-serif`.
  * **Font Weights Used:** Regular (400), Medium (500), Bold (700), Heavy/Black (900).

---

## 2. Screen 1: Car Detail & Specifications View

### Header Section
* **Status Bar:** Standard iOS layout showing time (`16:26`), cellular signal, WiFi, and battery icon in `#111111`.
* **Top Navigation Bar:**
  * **Left:** Brand Logo icon (Stylized bold "R" monogram in black).
  * **Center:** Brand text `RENTRA` (Tracking/Letter-spacing: wide, font-weight: Bold, size: ~14px).
  * **Right:** Menu hamburger icon inside a rounded circular container (`#E0E0E0`).

### Hero Title & Image Section
* **Main Title:** `PORSCHE 816`
  * **Typography:** Heavy/Black sans-serif, uppercase, centered, size: ~26px, color: `#111111`.
* **Car Image (Hero - Front View):**
  * **Description:** Front-facing studio shot of a vintage black wide-body sports car (Porsche 959/König-style modification) with prominent horizontal glowing amber-red rectangular taillights/headlights and dual exhaust pipes underneath.
  * **Background State:** Backgroundless/Transparent cutout blending seamlessly into the light gray card surface.
  * **Placement:** Positioned centrally below the main title, overlapping slightly into the specifications grid.

### Specifications Grid (2x2 Layout)
Four rounded cards (`border-radius: 20px`, fill: `#E5E5E5`) displaying vehicle metrics:

1. **Top Speed Card:**
   * **Value:** `262` (Bold, 22px) <span style="font-size: 12px; font-weight: 400;">km/h</span>
   * **Label:** `Top Speed` (Muted gray, 12px)
   * **Action Icon:** Small red circular button in the top-right corner containing a diagonal black/red up-right arrow (`↗`).

2. **Speed Up (Acceleration) Card:**
   * **Value:** `120` (Bold, 22px) <span style="font-size: 12px; font-weight: 400;">in 6s</span>
   * **Label:** `Speed Up`
   * **Action Icon:** Up-right arrow (`↗`).

3. **Fuel Tank Card:**
   * **Value:** `38` (Bold, 22px) <span style="font-size: 12px; font-weight: 400;">lit</span>
   * **Label:** `Fuel Tank`
   * **Action Icon:** Up-right arrow (`↗`).

4. **Average (Fuel Economy) Card:**
   * **Value:** `08` (Bold, 22px) <span style="font-size: 12px; font-weight: 400;">km/l</span>
   * **Label:** `Average`
   * **Action Icon:** Up-right arrow (`↗`).

### Bottom Floating Action Bar
* **Container:** Floating pill-shaped container spanning the bottom width, solid white/light gray background with a soft drop shadow.
* **Pricing Text:** 
  * **Price:** `$1200` (Bold, 18px)
  * **Interval:** `/ Per Day` (Muted, 12px)
* **Book Button:**
  * **Shape:** Pill/Capsule button, solid black background (`#111111`).
  * **Text:** `BOOK` (White, Bold, uppercase, letter-spaced).

---

## 3. Screen 2: Brand Splash / Gallery View

* **Status Bar:** Matching iOS status bar (`16:26`, signal, wifi, battery).
* **Center Branding:**
  * **Logo:** Large stylized "R" monogram icon in black.
  * **Wordmark:** `RENTRA` centered directly beneath the logo in heavy bold sans-serif.
* **Background Image (Bottom Anchor):**
  * **Description:** Rear-three-quarter studio angle of the same black wide-body Porsche showing its aggressive rear louvers, illuminated multi-segment red rear light bar, and dual metallic exhaust tips.
  * **Placement:** Anchored to the bottom right of the screen, cropped organically by the device frame.

---

## 4. Implementation Guidelines (CSS / Tailwind Reference)

* **Border Radius Standards:** 
  * App containers / cards: `rounded-3xl` (24px)
  * Buttons / Badges: `rounded-full`
* **Shadows:** Use soft, diffused shadows for the floating bottom bar (`shadow-lg shadow-black/5`).
* **Images:** Ensure all car assets are high-resolution PNG cutouts with transparent backgrounds to adapt dynamically to the light theme surfaces.
