# UI Design Specification: Marvel "Choose Character" Interface

This document outlines the exact design specifications for creating a pixel-perfect, full-screen HTML/CSS/JS clone of the provided Marvel character selection interface.

---

## 1. Global Layout & Viewport

*   **Display Mode:** Full-screen (`width: 100vw; height: 100vh; overflow: hidden;`)
*   **Background:** 
    *   Solid deep royal blue.
    *   **Color Hex:** `#102a71` (approximate based on standard Marvel blue branding) with a subtle radial or linear gradient fading into a slightly darker navy at the bottom.
*   **Grid System:** A centered container structure with absolute/flex positioning for UI overlays, ensuring responsiveness across viewports.

---

## 2. Typography & Font Stack

The interface utilizes a heavy, bold, sans-serif display font for headers and a clean, highly readable sans-serif for body text.

### Primary Display Font (Headers: "CHOOSE CHARACTER", "MARVEL", "AVENGERS")
*   **Primary Font:** `Impact`, `Bebas Neue`, or `Montserrat` (Extra Bold, Italicized/Slanted if applicable).
*   **CSS Stack:** 
    ```css
    font-family: 'Bebas Neue', 'Impact', sans-serif;
    font-weight: 800;
    text-transform: uppercase;
    ```
*   **Fallback Stack:** `sans-serif`

### Body Copy Font (Description: "Earth's Mightiest Heroes...")
*   **Primary Font:** `Roboto`, `Open Sans`, or `Helvetica Neue`.
*   **CSS Stack:**
    ```css
    font-family: 'Roboto', 'Helvetica Neue', sans-serif;
    font-weight: 400;
    font-size: 11px;
    line-height: 1.4;
    letter-spacing: 0.5px;
    ```
*   **Fallback Stack:** `sans-serif`

---

## 3. Header Section

*   **Top Navigation Bar:**
    *   **Left Element:** Hamburger Menu Icon (3 horizontal lines). White, `opacity: 0.8`.
    *   **Center Element:** MARVEL Logo. Centered horizontally. Styled in bold, spaced-out white lettering with a small red underline accent block or standard Marvel typographic styling.
    *   **Right Element:** User Profile / Account Icon (User silhouette inside a circle). White, `opacity: 0.8`.

*   **Main Title ("CHOOSE CHARACTER"):**
    *   **Position:** Left-aligned, positioned below the top navigation bar with generous top margin.
    *   **Styling:**
        *   Font Size: Large display scaling (approx. `64px` to `72px`).
        *   Line Height: Tight (`0.9`).
        *   Color: Pure White (`#FFFFFF`).
        *   Text Transform: Uppercase.
    *   **Divider Line:** A thin horizontal red rule (`#ED1D24`) spanning underneath the title block. Height: `2px`.

---

## 4. Character Roster Display

*   **Layout:** Horizontal flex/grid alignment featuring full-body character renders standing on a subtle grid-perspective floor plane.
*   **Floor Plane:** A faint blue/cyan grid perspective fading into the background to anchor the characters in a 3D space.
*   **Characters (Left to Right):**
    1.  **Black Panther** (Prowling/Crouched stance)
    2.  **Iron Man** (Standing, armor glowing accents)
    3.  **Captain America** (Holding shield ready)
    4.  **Hulk** (Bulking, aggressive stance)
    5.  **Black Widow** (Standing upright, tactical pose)
    6.  **Falcon / The Falcon** (Wings extended, tactical flight gear)
    7.  **Thor / Hawkeye** (Partially visible on the right edge, indicating a scrollable carousel).

---

## 5. Footer & Navigation Controls

*   **Carousel Navigation Arrows:**
    *   Two circular outline buttons with arrows (`←` and `→`).
    *   **Styling:** 
        *   Border: 1px solid white (`rgba(255, 255, 255, 0.4)`).
        *   Background: Transparent or semi-transparent dark blue on hover.
        *   Icon Color: Pure White.
        *   Size: ~40px diameter.
*   **Team / Faction Info Panel:**
    *   **Header:** "AVENGERS" (Bold, white, medium size).
    *   **Description Text:** "Earth's Mightiest Heroes stand as the planet's first line of defense against the most powerful threats in the universe." (Muted light gray/blue, `rgba(255, 255, 255, 0.7)`).

---

## 6. Animations & Interactions

*   **Page Load / Entrance Animation:**
    *   *Staggered Fade-In:* The header elements fade down from top to bottom, while the title scales in with a slight upward translation (`transform: translateY(-20px)` to `0`).
    *   *Character Slide-In:* The character sprites slide in from the right or fade up sequentially from the floor grid with a slight parallax depth effect.
*   **Hover & Click States:**
    *   **Navigation Arrows:** Scale up slightly (`transform: scale(1.05)`) and background fill shifts to solid white with dark text on hover.
    *   **Characters:** Hovering over a character should trigger a subtle zoom (`scale(1.05)`) and enhance drop shadows beneath their feet. Active/selected character gets a distinct highlight ring or lighting effect.
*   **Carousel Sliding Mechanism:**
    *   Clicking the left/right arrows smoothly translates the entire character roster horizontally along the grid axis using CSS Transitions (`transition: transform 0.5s cubic-bezier(0.25, 1, 0.5, 1)`).
