## 3. Typography & Font Stack

The typography utilizes a **high-contrast, elegant serif typeface** with distinct calligraphic/italic flair, paired with a clean **sans-serif** for metadata.

### Primary Font (Headings: "Olive Green" / "Royal Yellow")
* **Style:** Italicized, high-contrast Editorial Serif (reminiscent of fonts like *Bodoni*, *Playfair Display Italic*, or *GT Alpina Italic*).
* **CSS Font Stack:**
  ```css
  font-family: 'Playfair Display', 'Bodoni MT', Didot, 'Didot LT STD', 'Hoefler Text', Garamond, 'Times New Roman', serif;
  font-style: italic;
  font-weight: 600; /* Medium to Semi-Bold */
  ```
* **Fallback Strategy:** If Google Fonts or local serif typefaces fail to load, the browser falls back to system serif fonts (`Georgia`, `Times New Roman`), keeping the `font-style: italic` to preserve the design's signature look.

### Secondary Font (Hex Code Badges & Footer: "HEX CODE: #...", "DGTL DSNR")
* **Style:** Clean, geometric uppercase sans-serif.
* **CSS Font Stack:**
  ```css
  font-family: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
  font-weight: 500; /* Medium */
  text-transform: uppercase;
  letter-spacing: 0.05em;
  ```
* **Fallback Strategy:** Standard system sans-serif stack.
