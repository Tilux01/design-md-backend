# Comprehensive Design Specification: Vital Landing Page

---

## 1. Executive Design Overview & Architecture

### 1.1 Aesthetic Paradigm
The interface represents an ultra-clean, minimalist, high-end neo-luxury financial technology (FinTech) web design. It relies on:
- **Atmospheric Palette:** Pure whites, silvery platinum undertones, pale slate gradients, deep carbon/graphite typography, and an electric chartreuse (lime) accent.
- **Surface Elevation:** Skeuomorphic soft shadows, subtle glassmorphic blurs, and metallic textures contrasted against clean, flat typography.
- **Viewport Layout:** Full-bleed, edge-to-edge canvas ($100\text{vw} \times 100\text{vh}$ or minimum $1440\text{px} \times 900\text{px}$ baseline) with no decorative device-frame bezels; content spans a structured 12-column grid.

## 4. Layout Architecture & Viewport Grid

* **Canvas Dimensions:** `100vw` by `100vh` (non-scrolling desktop experience, overflow hidden or clamped).
* **Grid Layout:** 12-column grid system.
  * Margin Left & Right: `64px` (dynamic responsive range: `40px` to `80px`).
  * Gutter: `32px`.
* **Two-Column Hero Split:**
  * **Left Column (Text & Features):** Spans columns 1 through 6.
  * **Right Column (Visual & Mockup):** Spans columns 7 through 12.
