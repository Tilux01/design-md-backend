# 1. Design Philosophy & Overall Aesthetic
- **Primary Mood & Archetype:** The design exemplifies a playful, high-energy, modern consumer mobile-first UI with heavy playful branding (featuring stylized mascot art, high-contrast neon accents, and bold streetwear-inspired typography). It blends playful character design with clean, high-utility UI widgets.
- **Visual Density & Whitespace:** High density with organized module spacing. Utilizes distinct card containers, floating badges, and high-contrast bounding boxes.
- **Theme Balance:** Primarily light mode with striking neon lime and acid-green accent backdrops, balanced by dark charcoal/navy structural elements, pastel cards, and crisp white typography containers.

# 3. Typography System & Hierarchy
- **Font Families:**
  - *Headings:* Inter, system-ui, -apple-system, sans-serif (Bold / Heavy variants)
  - *Body:* Inter, sans-serif (Regular / Medium variants)
  - *Monospace/Code:* JetBrains Mono, monospace

## Scale Breakdown
- **Display Heading:** `font-weight: 800`, `font-size: 2.5rem` (40px), `line-height: 1.1`, `letter-spacing: -0.03em`.
- **H1 / Section Title:** `font-weight: 700`, `font-size: 1.75rem` (28px), `line-height: 1.2`, `letter-spacing: -0.02em`.
- **H2 / Card Header:** `font-weight: 600`, `font-size: 1.25rem` (20px), `line-height: 1.3`, `letter-spacing: -0.01em`.
- **Body Regular:** `font-weight: 400`, `font-size: 1rem` (16px), `line-height: 1.5`, `letter-spacing: 0`.
- **Caption / Badge:** `font-weight: 600`, `font-size: 0.75rem` (12px), `line-height: 1.4`, `letter-spacing: 0.05em` (uppercase).

# 4. Layout Architecture & Spatial Grid
- **Container Max-Width:** Fluid mobile application wrapper (`max-width: 480px` for mobile viewports, scaling up cleanly to `1280px` for desktop grids).
- **Spacing Scale:** 4px baseline grid (`space-1: 4px`, `space-2: 8px`, `space-4: 16px`, `space-6: 24px`, `space-8: 32px`).
- **Section Sequence:**
  1. Top utility bar & Avatar/Profile header indicator
  2. Hero banner container with high-impact color block
  3. Interactive feature cards / item selector row
  4. Bottom navigation / action triggers
- **Z-Index Hierarchy:** 
  - Base canvas: `z-0`
  - Cards & Content: `z-10`
  - Floating Badges / Tooltips: `z-30`
  - Sticky Navigation / Modals: `z-50`

# 8. Accessibility (a11y) & WCAG Contrast Audit
- **Contrast Ratios:**
  - Dark Charcoal text (`#0F172A`) on Light Surface (`#FFFFFF`): **16.5:1** (Passes WCAG AAA)
  - Muted Gray text (`#64748B`) on Light Surface (`#FFFFFF`): **4.6:1** (Passes WCAG AA)
- **Keyboard Focus Ring Specs:**
