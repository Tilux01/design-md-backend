# UI Design Specification: "Workouts" Dashboard

## 1. Global Layout & Canvas Specifications
- **Target Screen:** Mobile Full Screen (iOS Style Smartphone).
- **Background Color:** Deep Pitch Black (`#0a0a0a` or pure `rgb(0, 0, 0)` with dark grey card containers).
- **Layout Structure:** Single-column vertical scrolling dashboard featuring rounded modular widget cards.
- **Root Container Padding:** Symmetric horizontal margins (~16px), generous top padding below the status bar, bottom padding to allow scrolling above the navigation bar.

---

## 2. Typography & Fonts

### Primary Font Family
- **Font Stack:** `-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Helvetica Neue", Helvetica, Arial, sans-serif`
- **Fallback Hierarchy:** If Apple's SF Pro is unavailable, the system defaults cleanly to **Inter**, **Roboto**, or standard **Helvetica Neue**.

### Text Styles & Hierarchy
1. **App Title ("Workouts")**
   - **Font Size:** 34px (Large Title)
   - **Font Weight:** Bold (700)
   - **Color:** Pure White (`#FFFFFF`)
   - **Alignment:** Left-aligned

2. **Section Headings / Card Titles (e.g., "Chest + triceps", "Volume lifted")**
   - **Font Size:** 17px – 18px (Body / Subheadline)
   - **Font Weight:** Semi-Bold (600)
   - **Color:** Pure White (`#FFFFFF`)

3. **Subtitles / Metadata (e.g., "Fridays", "Last 7 days", "31 min ago")**
   - **Font Size:** 13px – 14px (Footnote)
   - **Font Weight:** Regular (400)
   - **Color:** Muted Cool Gray (`#8E8E93` or `#707074`)

4. **Large Metric Numbers (e.g., "190", "3.200", "1", "2")**
   - **Font Size:** 32px – 48px
   - **Font Weight:** Bold (700 / 800)
   - **Color:** Pure White (`#FFFFFF`)

5. **Unit Labels (e.g., "lbs")**
   - **Font Size:** 16px – 20px
   - **Font Weight:** Medium (500)
   - **Color:** Light Gray / Off-White (`#C7C7CC`)

---

## 3. UI Components & Detailed Breakdown

### A. Status Bar & Navigation Bar Area
- **Time ("4:44"):** Top-left, 15px, Semi-Bold, White.
- **System Icons (Cellular, Wifi, Battery):** Top-right, monochrome white, standard iOS status bar layout.
- **Action Buttons (Top Right):**
  - **Filter / Controls Icon:** Rounded square container (`#1c1c1e`), containing a minimalist horizontal adjustment/slider icon in white.
  - **Add (`+`) Icon:** Rounded square container (`#1c1c1e`), featuring a crisp white plus symbol.

---

### B. Widget Cards Layout

#### Card 1 (Top Left): "Chest + triceps"
- **Background:** Dark charcoal gray rounded container (`#141416`), corner radius ~20px.
- **Top Section:** 
  - Circular progress ring/badge showing `"1"` in the center. The ring stroke is partially filled with bright white (`#FFFFFF`) against a darker muted track.
  - Top-right corner features a small adjustment/filter icon (muted gray).
- **Bottom Section:**
  - Title: **"Chest + triceps"** (White, 17px, Semi-Bold).
  - Subtitle: **"Fridays"** (Muted gray, 13px).

#### Card 2 (Top Right): "Body weight"
- **Background:** Matching dark charcoal gray container (`#141416`), corner radius ~20px.
- **Top Section:**
  - Large Metric: **"190"** (White, ~42px, Bold) followed inline or slightly baseline-adjusted by **"lbs"** (Light Gray, ~20px).
  - Top-right corner: Small adjustment/filter icon.
- **Bottom Section:**
  - Subtitle: **"Body weight"** (White, 15px, Medium).
  - Timestamp: **"31 min ago"** (Muted gray, 13px).

---

#### Card 3 (Middle Wide): Calendar & Routine Card ("Back + bicep + legs")
- **Background:** Large unified dark charcoal container (`#141416`), corner radius ~24px.
- **Calendar Grid Section:**
  - Month Headers: **"Jan"**, **"Feb"**, **"Mar"** spaced horizontally above respective dot-matrix subgrids.
  - Dot Matrix: 
    - Inactive days: Dimmed tiny gray dots (`#333336`).
    - Active workout days: Solid bright white glowing dots highlighting completed dates.
- **Workout Routine Section (Lower Half of Card):**
  - Left: Circular badge displaying `"2"` with a partial progress ring stroke.
  - Middle: 
    - Title: **"Back + bicep + legs"** (White, 17px, Semi-Bold).
    - Subtitle: **"Mondays"** (Muted gray, 13px).
  - Right: Adjustment/filter icon aligned vertically center.

---

#### Card 4 (Lower Wide): "Volume lifted"
- **Background:** Dark charcoal container (`#141416`), corner radius ~20px.
- **Left Side:**
  - Label: **"Volume lifted"** (White, 17px, Semi-Bold).
  - Subtext: **"Last 7 days"** (Muted gray, 13px).
- **Right Side:**
  - Large Metric: **"3.200"** (White, ~34px, Bold) + **" lbs"** (Gray).
  - Subtle vertical divider or subtle background fill split line.
  - Adjustment icon on the far right.

---

#### Card 5 (Bottom Placeholder): Empty / Add Widget Card
- **Background:** Dark charcoal container with a translucent or darker recess.
- **Content:** Large centered white **`+`** icon acting as a placeholder to add custom dashboard widgets.

---

### C. Bottom Navigation Bar
- **Position:** Fixed to the absolute bottom of the screen with slight blur/translucency over the dark background.
- **Icons (Left to Right):**
  1. **Dashboard/Grid Icon:** Four small rounded squares (Active state, highlighted in bright white).
  2. **Calendar Icon:** Outline style (Inactive, muted gray).
  3. **Analytics/Chart Icon:** Vertical bar graph representation (Inactive, muted gray).
  4. **Document/Notebook Icon:** Outline style (Inactive, muted gray).
- **Home Indicator Bar:** Standard white horizontal pill-shape indicator centered at the very bottom edge.

---

## 4. Color Palette Reference
| Element | Hex Code / Description | Usage |
| :--- | :--- | :--- |
| **Canvas Background** | `#000000` / `#0a0a0a` | App background |
| **Card Fill** | `#141416` or `#1c1c1e` | Modular widget containers |
| **Primary Text** | `#FFFFFF` | Titles, large numbers, active states |
| **Secondary Text** | `#8E8E93` | Subtitles, descriptions, timestamps |
| **Unit Text** | `#C7C7CC` | "lbs", secondary labels |
| **Inactive Dots/Icons** | `#333336` | Calendar grid dots, inactive elements |
