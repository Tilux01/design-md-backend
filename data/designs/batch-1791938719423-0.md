# Design Specification: Steam Concept UI (Dark Mode)

## 1. Global Styles

### 1.1 Color Palette
*   **Primary Background:** `#0B0B0D` (Deep charcoal/near-black).
*   **Surface Background (Sidebar/Cards):** `#161618` with a subtle linear gradient or low-opacity overlay to create depth.
*   **Accent Color (Active/Highlight):** `#FF5C00` (Vibrant Orange-Red).
*   **Primary Text:** `#FFFFFF` (Pure White).
*   **Secondary Text:** `#A0A0A5` (Muted Grey).
*   **Tertiary Text/Icons:** `#606065` (Dark Grey).
*   **Glow/Shadows:** Subtle outer glows using the accent color (`rgba(255, 92, 0, 0.2)`) for active elements.

### 1.2 Typography
*   **Primary Font:** `Inter` (or `Geist Sans`).
*   **Fallback Stack:** `Inter`, `-apple-system`, `BlinkMacSystemFont`, "Segoe UI", `Roboto`, `Oxygen`, `Ubuntu`, `Cantarell`, "Open Sans", "Helvetica Neue", sans-serif.
*   **Weights:**
    *   Regular: 400
    *   Medium: 500
    *   Semi-Bold: 600
    *   Bold: 700
*   **Sizes:**
    *   Heading (Hero Title): Stylized Logo (approx. 48px equivalent).
    *   Section Header ("Special offers"): 18px, Semi-Bold.
    *   Nav Items: 14px, Medium.
    *   Body Text (Hero Description): 13px, Regular, Line-height 1.5.

### 1.3 Effects & Borders
*   **Border Radius:** 16px for large containers (Hero, Cards), 8px for smaller elements (Buttons, Search Bar).
*   **Glassmorphism:** Sidebar and top bar should have a subtle background blur (`backdrop-filter: blur(10px)`) and a very thin 1px border (`rgba(255, 255, 255, 0.05)`).

---

## 2. Layout Structure

The application is a full-screen desktop interface divided into a left sidebar and a main content area.

### 2.1 Sidebar (Left)
*   **Width:** 220px.
*   **Top Section:** Steam Logo (white) followed by navigation links.
*   **Nav Items:** "Store", "Library", "Community", "Friends".
    *   *Active State (Store):* Text and icon colored in `#FF5C00`. A vertical 3px wide orange bar is placed on the far left of the active item.
*   **Bottom Section:** "Settings" and "Help" links with secondary icons.
*   **Footer:** A small, dark card labeled "Check the last badge" with a small icon.

### 2.2 Top Navigation Bar
*   **Search Bar:** Centered. Darker than the background, rounded corners, "Search store" placeholder text in secondary grey.
*   **User Actions (Right):** Notification bell icon, message icon, and user profile (Circular avatar next to the name "Jesse Wilson").

## 3. Main Content Area

### 3.1 Hero Section (Featured Game: Stray)
*   **Container:** Large rectangular card with a background image.
*   **Background Image:** *See Image Description 4.1.*
*   **Logo Overlay:** The "STRAY" stylized logo (white) is positioned bottom-left of the cat's face.
*   **Info Panel (Right):** A semi-transparent dark pane with a red/orange radial glow behind it.
    *   **Content:** Game title "Stray", a short paragraph of description text.
    *   **Button:** "Available now" - Rectangular with rounded corners, orange background, white bold text.
    *   **Controls:** Small volume/mute icon in the bottom right of the info panel.

### 3.2 "Special Offers" Section
*   **Header:** "Special offers" (Left) and "Learn more" (Right, secondary text).
*   **Grid:** A horizontal row of four vertical game cards.
