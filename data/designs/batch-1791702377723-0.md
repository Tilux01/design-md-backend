# Design Specification (`design.md`): Mindly Landing Page

## 1. Overview & Visual Identity
* **Brand:** Mindly°
* **Concept:** High-end, clean, editorial SaaS landing page combining modern glassmorphism, monochrome portrait photography, and elegant typography.
* **Canvas:** Fullscreen (`100vw` × `100vh` or auto height with `min-height: 100vh`), borderless, no frame wrap.
* **Overall Theme:** Soft off-white canvas with dark monochrome accents, floating translucent glass cards, and vibrant pastel icon accents inside dark/glass UI chips.

---

## 2. Color System

### Backgrounds & Surfaces
* **Main Canvas Background:** Light Off-White / Cream Tone  
  `#F5F4F0` (or `#FAF9F5`)
* **Solid Dark Elements:** Deep Charcoal / Almost Black  
  `#0D0D0D`
* **Glassmorphic Card Surface:** Semi-transparent White with Blur  
  `background: rgba(255, 255, 255, 0.65)`  
  `backdrop-filter: blur(16px)`  
  `border: 1px solid rgba(255, 255, 255, 0.8)`  
  `box-shadow: 0 20px 40px rgba(0, 0, 0, 0.04)`
* **Active Pill / Tab Surface:** Light Warm Gray  
  `#EAE8E1` or `#EFECE6`

### Text Colors
* **Primary Text:** Dark Charcoal / Black (`#0D0D0D`)
* **Secondary / Muted Text:** Soft Slate Gray (`#686765` or `#7A7977`)
* **Inverted Text:** Pure White (`#FFFFFF`)

### Accent Badge Colors (Inside 3D Orbit Chips)
* **Focus Icon Accent (Yellow-Green):** `#D2E635` (Background: `#D2E63520` or solid badge `#D2E635`)
* **Ideas Icon Accent (Lavender / Light Purple):** `#C3B1E1`
* **Plan Icon Accent (Soft Orange):** `#FF9F68`
