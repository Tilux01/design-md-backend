# UI Design Specification: Project Management Dashboard

## 1. Global Layout & Viewport

- **Canvas Background:** A solid, muted grayish-green (`#B2B8AD` approximately, or Tailwind `bg-zinc-400` / custom hex `#A9ADA2`).
- **Layout Type:** Asymmetric grid layout composed of distinct modular cards/widgets floating on the background.
- **Spacing (Gaps):** Consistent spacing of `24px` to `32px` between major UI modules.
- **Corner Radius (Border-radius):** Rounded corners universally applied to cards (`24px` to `32px`), pill buttons (`100px`), and widget containers.

---

## 2. Typography & Fonts

- **Primary Font Family:** Clean, geometric sans-serif (e.g., **Inter**, **SF Pro Display**, or **Plus Jakarta Sans**).
- **Fallback Stack:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
- **Text Hierarchies:**
  - **Large Titles (e.g., "Upcoming Meetings", "Project Roadmap"):** 
    - Weight: Bold (`700`)
    - Size: `28px` - `32px`
    - Letter Spacing: Tight (`-0.02em`)
  - **Section/Widget Headings (e.g., "OxeliaMetrix"):**
    - Weight: Semi-Bold / Medium (`600` / `500`)
    - Size: `20px` - `24px`
  - **Body / Metadata (e.g., "Industry: SaaS", "Project Manager"):**
    - Weight: Regular / Medium (`400` / `500`)
    - Size: `12px` - `14px`
    - Color: High-contrast dark grey (`#1A1A1A`) for primary text, muted grey (`#666666`) for secondary text.

---

## 3. Color Palette

- **Primary / Brand Lime Green:** `#CCFF00` (Used for active indicators, primary call-to-actions, progress bars, and highlighted date chips).
- **Dark Mode Card (Efficiency Widget):** `#111111` (Pure dark black with lime green trend line).
- **Card Backgrounds:** 
  - Light cards: Off-white / very light gray (`#F3F3F5`).
  - Muted gray cards: `#8C9387`.
- **Text & Icons:** 
  - Primary text: `#111111` (Dark Charcoal).
  - Secondary text: `#6B7280` (Cool Gray).

---
