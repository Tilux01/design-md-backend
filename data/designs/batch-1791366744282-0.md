```markdown
# Website Design Specification

## Global Styles & Variables

### Color Palette
- **Primary Background (Dark):** `#111113`
- **Secondary Background/Card:** `#1a1a1e` (Dark gradient fade in the banner area)
- **Primary Accent / Red:** `#b82424` (Deep crimson red used for statue tint, background circle, and brand mark)
- **Secondary Accent (Darker Red):** `#8b1c1c`
- **Text Primary (White):** `#ffffff`
- **Text Muted (Gray):** `#9e9e9e`
- **Border / Outline Color:** `#2a2a30`

### Typography
- **Font Family:** `Inter`, `sans-serif` (or modern sans-serif equivalent like `Montserrat` or `Roboto`)
- **Logo / Brand Mark:** Abstract geometric shapes (three slanted red bars)
- **Navigation Links:**
  - Font Size: `14px`
  - Font Weight: `400`
  - Letter Spacing: `1px`
  - Text Transform: `uppercase`
- **Section Subheading ("OUR VERSION"):**
  - Font Size: `12px`
  - Font Weight: `600`
  - Letter Spacing: `2px`
  - Text Transform: `uppercase`
  - Color: `#ffffff`
- **Main Heading ("DESIGN"):**
  - Font Size: `56px` - `64px`
  - Font Weight: `700`
  - Line Height: `1.1`
  - Letter Spacing: `1px`
  - Color: `#ffffff`
- **Body Copy:**
  - Font Size: `14px`
  - Font Weight: `400`
  - Line Height: `1.6`
  - Color: `#b0b0b5`
  - Max Width: `320px`
- **Button Text ("See More"):**
  - Font Size: `14px`
  - Font Weight: `500`
  - Color: `#ffffff`

---

## Layout Structure (Full-Screen Viewport)

### 1. Navigation Bar (`<header>`)
- **Position:** Absolute / Fixed at the top, full width with horizontal padding (`60px`).
- **Layout:** Flexbox, space-between.
- **Left Element (Logo):**
  - Icon: Three diagonal red rectangles arranged in a stack/grid.
- **Right Elements (Nav Links):**
  - Links: `ABOUT`, `GALLERY`, `CONTACTS`
  - Spacing: `32px` gap between items.
  - Hover Effect: Slight opacity shift or color change to white.

### 2. Hero Section (`<main>` / `<section>`)
- **Layout:** Two-column layout or absolute positioning layered over a full-width dark background.
- **Background Details:**
  - Dark radial/linear gradient base.
  - Large background accent circle positioned on the right side behind the statue (`fill: #b82424`, opacity/gradient blend).
  - Smaller decorative red circle at the bottom-center.

#### Left Column (Content Area)
- **Position:** Aligned to the left with generous padding (`60px` left offset).
- **Stack Elements:**
  - Subheading: `OUR VERSION`
  - Main Heading: `DESIGN` (placed directly below subheading with tight margin)
  - Paragraph text: *"Our hobby is a modern and convenient design, the key to successful communication with the client."*
  - Call to Action Button:
    - Circular outline button featuring a right-arrow icon (`→`).
    - Label text `"See More"` placed horizontally next to the circular button.
    - Hover: Border brightens or button background fills slightly.

#### Right Column (Visual / Imagery Area)
- **Content:** High-contrast statue photograph (classical Greek/Roman male bust/torso with draped fabric/toga).
- **Color Treatment:** Filtered/graded with a deep red/crimson monochrome or duotone overlay to match the design palette.
- **Position:** Anchored to the bottom-right of the viewport, overlapping the large background red circle.

### 3. Footer / Carousel Pagination
- **Position:** Bottom-left of the viewport.
- **Elements:**
  - Current Slide Number: `01`
  - Progress Bar: Thin horizontal track with an active white progress fill line extending from `01` to `03`.
  - Total Slide Number: `03`
  - Layout: Flexbox aligning the numbers and progress bar horizontally with a `16px` gap.

---

## Interactive States & Animations
- **Hover on Nav Links:** Smooth transition of color to pure white.
- **Hover on "See More":** Arrow inside the circle moves slightly to the right (`translateX(4px)`).
- **Background Elements:** Subtle parallax or ambient lighting effect on the red background circles.
```
