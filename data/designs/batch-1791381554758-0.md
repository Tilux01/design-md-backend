# Design Specification: BBC Earth — Seven Worlds One Planet (Africa)

## 1. Global Layout & Viewport Architecture
* **Layout Mode:** Full-screen responsive viewport (`width: 100vw; height: 100vh; overflow: hidden; position: relative;`).
* **Background Layer:** Fixed high-resolution landscape image of African elephants crossing a savanna under a dramatic cloudy sky, with a dark cinematic gradient overlay (`linear-gradient(180deg, rgba(0,0,0,0.5) 0%, rgba(0,0,0,0.2) 50%, rgba(0,0,0,0.7) 100%)`) to guarantee high contrast for UI text.
* **Layout Structure:** Flexbox / CSS Grid stack comprising three distinct zones:
  1. **Header (Navigation & Branding):** Absolute positioned at the top (`z-index: 10`).
  2. **Hero Core (Title, Subtitle, Elephants):** Centered viewport anchor.
  3. **Footer Action Bar (Tagline, Trailer CTA, Carousel Navigation):** Absolute positioned at the bottom.

---

## 2. Typography System & Fallback Chains

### Primary Display Font (Headers & Titles)
* **Font Family:** `Futura`, `Futura PT`, `Montserrat`, `Helvetica Neue`, sans-serif
* **Usage:** "SEVEN WORLDS ONE PLANET" and "AFRICA"

### Secondary UI Font (Navigation, Links, Buttons, Body)
* **Font Family:** `Inter`, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `Helvetica`, `Arial`, sans-serif
* **Usage:** Menu items, taglines, interactive buttons.

| Element | Font Family | Size (Desktop) | Weight | Letter Spacing | Color |

| **Nav Links ("ABOUT", etc.)** | Secondary | `13px` | Semi-Bold (600) | `1.5px` | `#FFFFFF` |

## 3. Component Breakdown & Spatial Hierarchy

### A. Header Navigation (`<header>`)
* **Position:** Fixed / Absolute top (`top: 0; left: 0; width: 100%; padding: 32px 5%;`).
* **Layout:** Flexbox (`justify-content: space-between; align-items: center;`).
* **Left Section:**
  * Hamburger Menu Icon (3 horizontal bars, stroke-width: `2px`, color: `#FFFFFF`, size: `20px`).
  * Text Link: "ABOUT" (Uppercase, interactive hover underline).
  * Text Link: "WHERE TO WATCH" (Uppercase).
* **Center Section:**
  * Logo: BBC Earth branding. A white/light grey outlined square box containing the text **BBC** next to the word **earth** in lowercase rounded typography.
* **Right Section:**
  * Social Media Icons (Flat white SVGs): Facebook (`f`), Twitter/X (`t`), Instagram (`o`), YouTube (`▶`). Gap: `20px`.

### B. Hero Core (`<main>`)
* **Layout:** Centered absolute or flex column container (`top: 50%; transform: translateY(-50%); text-align: center; width: 100%;`).
* **Super-heading:** `SEVEN WORLDS ONE PLANET` (Centered above the giant title, lowercase/uppercase tracking active).
* **Main Title:** `AFRICA`
  * *Special Visual Effect:* The text color is solid white, but positioned such that the elephants graze in the lower third of the frame, creating a striking visual depth against the colossal typography.

### C. Footer Action Bar (`<footer>`)
* **Position:** Absolute bottom (`bottom: 32px; left: 5%; right: 5%;`).
* **Layout:** Flexbox (`justify-content: space-between; align-items: flex-end;`).
* **Left Element (Tagline):** 
  * `"This film celebrates nature's ingenuity, no matter how tough it gets."` (Max-width restricted, muted opacity).
* **Center Element (CTA Button):**
  * `"WATCH TRAILER"` button.
  * Dimensions: Padding approx. `12px 28px`.
  * Border: `1px solid rgba(255, 255, 255, 0.4)`.
  * Hover State: Background transitions to white with dark text (`#000000`).
* **Right Element (Carousel Control):**
  * Arrow navigation + Region labels: `←` **AFRICA** | **AUSTRALIA** `→`
  * Active state highlighted in solid white; inactive regions dimmed.

## 4. Micro-Interactions & Animations

1. **Page Load Entrance (Fade Up Sequence):**
   * Background image scales down slightly from `1.05` to `1.0` over `1.5s` using `cubic-bezier(0.16, 1, 0.3, 1)`.
   * Title elements ("SEVEN WORLDS ONE PLANET" and "AFRICA") slide up from `Y: +20px` to `Y: 0` with opacity fading from `0` to `1` over `1.0s` (staggered delay).

2. **Hover States:**
   * **Nav Links / Social Icons:** Opacity shifts from `0.8` to `1.0`, with a smooth transition (`transition: opacity 0.2s ease`).
   * **Watch Trailer Button:** Background color fills with `#FFFFFF`, text color changes to `#000000` (`transition: all 0.3s ease`).
   * **Carousel Navigation Items:** Cursor changes to pointer; inactive items brighten to `#FFFFFF` on hover.

---

## 5. Responsive Behavior & Breakpoints

* **Desktop (`> 1024px`):** Full horizontal spread as specified in the mockup, generous padding (`5%` side margins).
* **Tablet (`768px - 1024px`):** 
  * Header links compress; social icons may collapse into a drawer if space demands.
  * Title size scales down via CSS `clamp()` (`clamp(80px, 12vw, 160px)`).
* **Mobile (`< 768px`):**
  * Header simplifies to Hamburger + Center Logo.
  * Footer stacks vertically: Tagline moves above the CTA button; carousel selector shifts to bottom-center.
