# Design Specification: 3D Model Showcase Web Page

This document provides a pixel-for-pixel design blueprint and specifications to rebuild the provided web interface in Figma and code. The design follows an earthy, monochromatic beige-brown color palette, layered typography, and a central 3D character illustration.

---

## 1. Global Layout & Structure

*   **View Type:** Full-screen responsive viewport (Desktop layout shown).
*   **Background Color (Outer):** Solid Earthy Sand/Beige (`#D4C29D` approx).
*   **Main Hero Container:**
    *   **Border Radius:** 16px to 24px (Rounded corners on the central card element).
    *   **Background Color (Card):** Muted Brownish-Tan (`#A3906F` / `#8C7755` range).
    *   **Content Alignment:** Centered vertically and horizontally with generous padding.

---

## 2. Typography & Font Stack

The design uses bold, ultra-thick sans-serif display typography layered behind a 3D character, paired with a clean geometric sans-serif for body copy.

### Primary Display Font (Headers & "3D MODEL")
*   **Style:** Heavy, geometric, blocky sans-serif (similar to *Anton*, *Clash Display*, or *Impact*).
*   **Fallback Font Family:** `Impact`, `Arial Black`, `sans-serif`.
*   **Usage:** Large background heading `"3D MODEL"`.

### Secondary/Body Font
*   **Style:** Clean, highly legible neutral sans-serif.
*   **Fallback Font Family:** `Inter`, `Helvetica Neue`, `Arial`, `sans-serif`.
*   **Usage:** Subheadings, paragraphs, interactive links, and copyright text.

---

## 3. UI Component Breakdown

### A. Navigation Bar (Header)
*   **Position:** Top-left inside the main container.
*   **Elements:** Simple brand logo or minimal text placeholder (e.g., "LOGO" in white uppercase).

### B. Hero Typography ("3D MODEL")
*   **Placement:** Positioned centrally behind the 3D character cutout.
*   **Color:** Off-white / Cream (`#F5EBE0`).
*   **Effect:** Layered effect where the 3D character breaks the z-plane (appears in front of the text).
*   **Sub-element ("SWIPE ALL"):** Small call-out text located near the bottom right of the text block with a directional arrow icon (`↗`).

### C. Body Copy (Left Column)
*   **Position:** Bottom-left of the hero card.
*   **Content:** Short introductory paragraph explaining the 3D model project or assets.
*   **Styling:** 
    *   Font Size: Small (~12px–14px).
    *   Color: Muted cream/off-white for high contrast against the dark card background.
    *   Line Height: Generous (approx. 1.5) for readability.

### D. Interactive UI Elements & Controls
*   **Pagination/Slider Dots:** Located below the paragraph text (active dot + inactive dot indicator).
*   **Mini Character Thumbnail (Bottom Right):** A smaller variant or alternative angle preview card of the 3D character.
*   **Footer Links (Bottom Right of outer screen):** Pill-shaped outline button (e.g., "Showcase" or external link).
*   **Copyright Text (Bottom Left of outer screen):** Standard small text (`Copyright © 202X. All rights reserved.`).

---

## 4. Imagery & Assets

*   **Central 3D Character:** 
    *   **Subject:** Stylized 3D render of a character wearing a white beanie, green puffer jacket, white hoodie, and orange patterned shorts, throwing peace signs with both hands.
    *   **Lighting:** Warm studio lighting casting soft shadows downward.
    *   **Integration:** Rendered with transparent background/cutout layered directly over the background and typography.

---

## 5. Animation & Interaction Specifications (Optional / For Code & Prototyping)

1.  **Parallax Scroll / Mouse Move:** 
    *   *Effect:* As the user moves the mouse across the screen, the background typography ("3D MODEL") shifts slightly slower than the foreground 3D character to create depth.
2.  **Hover States:**
    *   *Buttons/Pills:* Subtle background color shift or opacity change on hover (`transition: all 0.2s ease-in-out`).
3.  **Entrance Animation:**
    *   *Fade-in Up:* The central 3D character and large text scale up slightly (`scale(0.95)` to `scale(1)`) with a smooth cubic-bezier easing curve upon loading.
