# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial Minimalist, Luxury Hospitality Branding, Warm Organic Modernism.
- **Visual Density & Whitespace Ratio**: High whitespace focus, generous padding, structured grid layout separating typography, mood imagery, and color swatches.
- **Surface Elevation Model**: Flat design system with subtle contrast framing, structured using dark backgrounds (#0D0D0D) with warm neutral typography and rich material photography.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase captions, minimal editorial borders, high-contrast photographic curation, restrained color palette badges with hex codes.
- **Pill Badge Specification**: Padding: `4px 12px`, font-size: `11px`, font-weight: `500`, tracking: `0.1em`, border-radius: `2px`, background translucency: `rgba(243, 238, 230, 0.08)`, border width: `1px`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;`
  - Bullet (•) -> Use `&#8226;`

## 6.2 Typeweight Specimen Grid
- **Layout & Positioning**: `grid`, `grid-cols-5`, border-divided columns.
- **Box Model & Spacing**: Padding `24px`, gap `0px`.
- **Typography**: 
  - Heading: Plus Jakarta Sans, `14px`, Uppercase, tracking `0.1em`.
  - Sample text: Cormorant Garamond, `14px`, lowercase alphabet.
- **JSX Blueprint**:
```jsx
export function TypeweightGrid() {
  const weights = [
    { name: "ExtraLight", weight: "font-light" },
    { name: "Light", weight: "font-normal" },
    { name: "Regular", weight: "font-medium" },
    { name: "Medium", weight: "font-semibold" },
    { name: "Bold", weight: "font-bold" },
  ];
  return (
    <div className="grid grid-cols-5 border-b border-[#2A2A2A] bg-[#1C1A18]">
      {weights.map((w, idx) => (
        <div key={idx} className="p-6 border-r border-[#2A2A2A] last:border-r-0">
          <p className="text-xs font-sans uppercase tracking-widest text-[#A39E93] mb-4">{w.name}</p>
          <p className="font-serif text-sm text-[#F3EEE6] tracking-wide">abcdefghijklmnopqrstuvwxyz</p>
        </div>
      ))}
    </div>
  );
}
```

## 6.4 Color Palette Swatch Bar
- **Layout & Positioning**: `grid`, `grid-cols-5`, background colors matched directly from design tokens.
- **JSX Blueprint**:
```jsx
export function ColorPaletteBar() {
  const swatches = [
    { name: 'Dusk', hex: '#1C1A18', textColor: '#F3EEE6' },
    { name: 'Linen', hex: '#F3EEE6', textColor: '#1C1A18' },
    { name: 'Sand', hex: '#D4C4B0', textColor: '#1C1A18' },
    { name: 'Brass', hex: '#B8956C', textColor: '#1C1A18' },
    { name: 'Velvet', hex: '#6B2E3A', textColor: '#F3EEE6' },
  ];
  return (
    <div className="grid grid-cols-5 border-b border-[#2A2A2A]">
      {swatches.map((s, idx) => (
        <div key={idx} style={{ backgroundColor: s.hex, color: s.textColor }} className="p-8 flex flex-col justify-between h-40">
          <span className="text-xs uppercase tracking-widest font-sans opacity-80">{s.name}</span>
          <span className="font-mono text-sm tracking-wider">{s.hex}</span>
        </div>
      ))}
    </div>
  );
}
```
