# Design Specification: Digital Product Designer Portfolio

## 1. Global Theme & Foundations

### 1.1 Color Palette
* **Canvas Background:** `#F0F3F9` with ambient radial gradients (`#E0E7FF` top-right, `#F5E8FF` bottom-right).
* **Glass Fill (Cards):** `rgba(255, 255, 255, 0.65)` to `rgba(255, 255, 255, 0.85)`
* **Glass Border:** `1px solid rgba(255, 255, 255, 0.7)`
* **Primary Text:** `#0F172A` (Slate 900)
* **Secondary Text:** `#64748B` (Slate 500)
* **Accent Purple/Indigo:** `#6366F1` to `#8B5CF6` (linear gradient)
* **Dark Button Fill:** `#0B0F19` with text `#FFFFFF`
* **Box Shadows:** `0 10px 30px -5px rgba(112, 144, 176, 0.12)`

### 1.2 Typography
* **Primary Font:** `Plus Jakarta Sans` or `Inter`
* **Fallback Stack:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
* **Weights:** Regular (400), Medium (500), Semi-bold (600), Bold (700)

### 1.3 Universal UI Elements
* **Border Radii:** Outer sections: `24px` to `32px`. Inner cards: `16px` to `20px`. Buttons/Pills: `9999px`.
* **Glass Effect:** `backdrop-filter: blur(16px); -webkit-backdrop-filter: blur(16px);`
