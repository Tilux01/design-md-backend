# Design Specification: Finance App Interface (iOS Style)

This document provides the exact design specifications for recreating the two screens of the mobile finance application shown in the image. The design features a dark mode aesthetic with soft, frosted-glass (neumorphic/glassmorphic) elements, vibrant color accents, and a clean typography hierarchy.

---

## 1. Global Styles & Variables

### Color Palette
*   **Background (App Base):** `#121212` (Dark Charcoal)
*   **Surface Cards (Dark):** `#1E1E1E` (Dark Grey for containers)
*   **Surface Cards (Light Gradient):** Gradient from `#E2E8D8` to `#C8D4B4` (Used for header cards and accent containers)
*   **Primary Text:** `#FFFFFF` (Pure White)
*   **Secondary Text:** `#A0A0A0` (Muted Grey)
*   **Border/Divider Lines:** `#2C2C2C` (Subtle dark grey)

### Typography
*   **Primary Font Family:** `SF Pro Display`, `SF Pro Text`, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif
*   **Fallback Font:** `Inter`, system-ui, sans-serif

### Icons
*   Use standard iOS SF Symbols or equivalent vector set (Lucide/Feather icons work well: `menu`, `search`, `plus`, `minus`, `check`, `arrow-right`).

## 2. Screen 1: Dashboard (`Bienvenida Sara!`)

### A. Status Bar (iOS Standard)
*   **Time:** `9:41` (Bold, White, ~14px)
*   **Right Icons:** Cellular signal, Wi-Fi, Battery icon (White)

### B. Header Section
*   **Top Navigation:**
    *   **Left:** Menu icon inside a circular dark button (`#1E1E1E`, ~40px diameter, white icon).
    *   **Right:** Circular user avatar placeholder (`36px` diameter, rounded) showing a profile picture of a person with glasses. Beside/near it, a search icon inside a circular dark button.
*   **Greeting:**
    *   **Label:** "Bienvenida" (`16px`, Regular, Color: `#A0A0A0`)
    *   **Name:** "Sara!" (`28px`, Bold, Color: `#FFFFFF`)

### C. Balance Card (Hero Component)
*   **Container:**
    *   **Background:** Solid dark grey `#1E1E1E` with subtle rounded corners (`border-radius: 20px`).
    *   **Padding:** `20px`
    *   **Label:** "Saldo disponible" (`12px`, Regular, Color: `#A0A0A0`)
    *   **Amount:** `$ 2,800.00` (`32px`, Bold, Color: `#FFFFFF`, aligned right)

### D. Recent Activity Summary
*   **Container:** Dark surface card (`#1E1E1E`, `border-radius: 12px`, padding `16px`).
*   **Rows (Flex justify-between):**
    *   Row 1: "Ingresos recientes" (Left, White) | `$ 3,500.00` (Right, White)
    *   Divider line (`1px`, `#2C2C2C`)
    *   Row 2: "Gastos recientes" (Left, White) | `$ 1,025.00` (Right, White)

### E. Quick Action Buttons
*   Three circular/rounded square buttons in a horizontal row:
    1.  **Agregar Gasto** (Minus icon, `#1E1E1E` background)
    2.  **Agregar Ingreso** (Plus icon, `#1E1E1E` background)
    3.  **Ver Transacción** (Check icon, `#1E1E1E` background)
*   *Labels:* Centered underneath each icon (`12px`, Color: `#FFFFFF`).

### F. Financial Report Section (`Informe financiero`)
*   **Section Title:** "Informe financiero" (`16px`, Bold, White)
*   **Bar Chart / Progress Representation:**
    *   Vertical bar visualizer showing percentages (`40%`, `30%`, `15%`, `10%`, `5%`).

        2.  Soft Sage Green (`#D2E0B4`) - 30%
        3.  Yellow/Gold (`#EADFA8`) - 15%
        4.  Dark/Neutral (`#333333`) - 10%
        5.  Dark/Neutral (`#222222`) - 5%

        *   ■ Alimentación (Pink)

## 4. Image Assets Description
*   **User Avatar:** Located in the top right header of both screens. It is a circular photographic portrait of a person with short dark hair and glasses, smiling softly against a neutral background. Rendered inside a `36px x 36px` circular mask with `border-radius: 50%`.
