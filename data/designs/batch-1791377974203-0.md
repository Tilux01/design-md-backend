# Design Specification: VR BOXXX Landing Page (Full-Screen Responsive Clone)

## 1. Overview & Layout Strategy
* **Target Layout:** Full-width, full-viewport immersive landing page (Edge-to-edge). No outer browser frames, mockups, or decorative drop shadows.
* **Aspect Ratio / Viewport:** Designed for 1440px+ desktop displays with fluid downscaling to mobile (single-column stack).
* **Grid System:** 12-column fluid grid with centered max-width container (`max-width: 1320px`) for content boundaries, while background graphics bleed edge-to-edge.
* **Z-Stacking (Layering):**
  * **Z-0:** Deep Space Black background (`#06060c`) with subtle radial gradient illumination (deep magenta/purple ambient glow behind central character).
  * **Z-1:** Background typography (`VR BOXXX` watermark) and ambient particle/fiber brushes.
  * **Z-2:** Main Hero character (Alpaca), Navigation Header, Floating CTA circle, and Product Cards (`BC 2 LIGHT` & `BR 3 LIGHT`).
  * **Z-3:** Foreground fiber strand art (ultra-fine glowing blue/purple/magenta fiber bundles framing the extreme left and right vertical edges).

---

## 2. Typography & Font Stack
The UI utilizes a clean, geometric, high-tech sans-serif typeface tailored for futuristic UI designs.

* **Primary Font Family:** `Inter`, `SF Pro Display`, `Rajdhani`, or `Orbitron` (Clean modern geometric sans-serif).
* **Fallback Stack:** `font-family: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;`

### Type Scale & Hierarchy:
| Element | Font Size | Weight | Line Height | Letter Spacing | Color |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Brand Logo ("VR BOXXX")** | 16px / 1.0rem | Bold (700) | 1.1 | 0.05em | `#FFFFFF` |
| **Nav Links (Services, etc.)** | 12px / 0.75rem | Medium (500) | 1.0 | 0.1em | `#8c8c99` (Hover: `#FFFFFF`) |
| **Explore CTA Text** | 12px / 0.75rem | SemiBold (600) | 1.0 | 0.08em | `#FFFFFF` |

## 3. Color Palette & Gradients
* **Background Primary:** `#050508` (Near-black with subtle cool-blue undertones)
* **Ambient Glow Center:** Radial gradient at center-middle (`rgba(160, 20, 100, 0.25)` blending into transparent black)
* **Neon Pink / Magenta Accent:** `#ff0055`, `#ff2a85` (Used on VR goggles, active highlights, and fiber glows)
* **Electric Cyan / Blue Accent:** `#00d2ff`, `#3b00ff` (Used on side fiber strands and subtle interface highlights)
* **Card Surface Background:** Glassmorphism style — `rgba(18, 18, 28, 0.65)` with a 1px frosted white border (`rgba(255, 255, 255, 0.08)`) and backdrop blur (`backdrop-filter: blur(16px);`)
* **Text Muted:** `#7c7c8c`
* **Text High Contrast:** `#ffffff`

## 4. Component-by-Component Specifications

### A. Navigation Bar (`<header>`)
* **Layout:** Flexbox, space-between, fixed or absolute overlay at top (`top: 32px`, `padding: 0 48px`).
* **Left - Brand:**
  * Custom vector logo icon (Interlinked geometric hearts/cube outline in pink/purple gradient: `#ff2a85` to `#7928ca`).
  * Brand text stacked: "VR" (small above) / "BOXXX" (bold below), or horizontal depending on viewport.
* **Center - Navigation Links:**
  * Items: `SERVICES`, `SOLUTIONS`, `GLASSES`, `COMPANY`
  * Spacing: `gap: 36px`
  * Styling: Uppercase, small tracking, muted gray transitioning to solid white on hover with a subtle transition (`transition: color 0.2s ease`).
* **Right - Explore Action:**
  * Text: `EXPLORE` + Right Arrow icon (`▶`)
  * Styling: Pill-shaped container or clean text link with border-bottom indicator. Pill style: `background: rgba(255,255,255,0.05)`, `border: 1px solid rgba(255,255,255,0.1)`, `padding: 8px 18px`, `border-radius: 50px`.

### B. Background Typography (Watermark)
* **Content:** `VR BOXXX` spanning across the mid-upper background.
* **Styling:** Massive scale (`font-size: clamp(100px, 18vw, 320px)`), center-aligned, extremely low opacity (`opacity: 0.03`), pointer-events none, non-selectable.

### C. Hero Section (Centerpiece)
* **Central Character (Alpaca/Llama):**
  * 3D Rendered character wearing glowing neon-magenta futuristic VR goggles.
  * Position: Centered horizontally, vertically aligned overlapping the mid-to-lower section.
  * Lighting: Rim lighting on fur from the neon goggles (`#ff0055` bounce light).
* **Floating Circular CTA ("LEARN MORE"):**
  * Position: Absolute/Relative placed to the mid-left of the central character.
  * Styling: Perfect circle (`width: 90px`, `height: 90px`), `background: rgba(20, 20, 30, 0.6)`, `border: 1px solid rgba(255, 255, 255, 0.12)`, `border-radius: 50%`, `backdrop-filter: blur(8px)`.
  * Text inside: Centered text "LEARN MORE" stacked or curved, tiny font, uppercase.

### D. Product Feature Cards (Bottom Grid)
* **Container:** 2-column flex/grid layout placed at the lower portion of the screen, symmetrically flanking the lower neck/shoulders of the central character.
* **Card Dimensions:** `max-width: 440px`, `height: auto`, curved corners (`border-radius: 20px`).
* **Glassmorphism Spec:**
  * Background: `linear-gradient(135deg, rgba(25, 25, 38, 0.7) 0%, rgba(10, 10, 16, 0.8) 100%)`
  * Border: `1px solid rgba(255, 255, 255, 0.1)`
  * Backdrop Blur: `backdrop-filter: blur(20px); -webkit-backdrop-filter: blur(20px);`
  * Box Shadow: `0 20px 40px rgba(0, 0, 0, 0.5)`
* **Card Content Structure:**
  * **Left Side:** Thumbnail image of animal model wearing VR (Bear model on left card `BC 2 LIGHT`, Cyber-cat/Feline model on right card `BR 3 LIGHT`). Encapsulated in a rounded sub-container with dark vignette gradient.
  * **Top Right / Header:** Pill badge with title (`BC 2 LIGHT` / `BR 3 LIGHT`), dark pill background with subtle white border.
  * **Middle Right / Description:**
    * Left Card: *"This headset offers sharp visuals and a comfortable fit, perfect for gaming, movies, and virtual tours."*
    * Right Card: *"Featuring advanced motion tracking, ultra-high-definition graphics and a wide field of view."*
  * **Bottom Right / Action Button:**
    * Pill button: `background: #ffffff`, `color: #000000`, `border-radius: 50px`, `padding: 6px 14px`.
    * Text + Icon: `"LEARN MORE"` + White circle with black chevron/plus icon (`+` or `→`).

### E. Edge Fiber Art (Left & Right Borders)
* **Visual Effect:** Abstract generative fiber strands / particle strings streaming vertically along the left and right outer edges.
* **Color Composition:** Gradient threads shifting from electric blue (`#00f0ff`) to deep purple (`#7928ca`) and hot pink (`#ff0055`).
* **Implementation:** Absolute positioned SVG or WebGL canvas overlay (`pointer-events: none`, `z-index: 3`).

## 5. Animations & Interactive States

### 1. Hover Effects:
* **Nav Links:** Color transition from `#8c8c99` to `#ffffff` with a micro scale up (`transform: translateY(-1px)`).
* **Product Cards:** Subtle lift and border glow on hover:
  ```css
  transition: transform 0.3s cubic-bezier(0.16, 1, 0.3, 1), border-color 0.3s ease;
  ```
  *Hover state:* `transform: translateY(-6px); border-color: rgba(255, 0, 85, 0.4);`
* **Buttons ("LEARN MORE"):** Scale up slightly (`scale: 1.05`) with background color brightening.

### 2. Entrance Animations (Page Load / AOS):
* **Background & Watermark:** Fade in with scale (`opacity: 0` -> `1`, `scale: 0.98` -> `1`, duration: 1.2s).
* **Central Alpaca Hero:** Slide up from bottom with fade (`translateY(40px)` -> `0`, duration: 1.0s, ease-out).
* **Product Cards:** Staggered slide up from bottom:
  * Left Card: `transition-delay: 0.2s`
  * Right Card: `transition-delay: 0.4s`
* **Edge Fibers:** Ambient pulsing/waving animation using subtle CSS keyframes (`keyframes fiberWave { 0%, 100% { transform: translateY(0); } 50% { transform: translateY(-8px); } }`).

---

## 6. Responsive Breakpoints Strategy
* **Desktop (`>= 1200px`):** Exact layout as specified (Full side fibers visible, 2-column card grid flanking center character).
* **Tablet (`768px <= width < 1200px`):**
  * Reduce side fiber widths.
  * Scale down Hero Alpaca slightly.
  * Cards stack or scale down horizontally with tighter padding (`padding: 0 24px`).
* **Mobile (`< 768px`):**
  * Hide extreme edge fiber graphics to preserve screen real estate.
  * Stack Navigation into a hamburger menu.
  * Center hero character, scale down watermark typography.
  * Stack Product Cards vertically into a single column (`flex-direction: column`).
