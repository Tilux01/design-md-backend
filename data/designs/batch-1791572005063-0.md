# Bankio Financial Dashboard & Transactions UI Specification

## Global Layout & Foundations
- **Canvas / Viewport**: Full-screen split view showing two distinct pages of the Bankio web application ("Financial Insights Dashboard" and "Transactions Activity Overview").
- **Layout Structure**: 
  - Two-column application shell: Fixed/sticky left sidebar for navigation and a main content area on the right with a light gray background (`#F4F5F7`).
  - Container border radius: Rounded application card containers with a subtle drop shadow.
- **Color Palette**:
  - **Backgrounds**: App backdrop (`#EAEBED`), Card/Widget background (`#FFFFFF`), Sidebar background (`#FFFFFF`).
  - **Primary Brand / Interactive**: Deep forest green (`#00473B`) used for active sidebar states, primary buttons, chart bars, and total metrics highlights.
  - **Text Colors**: Dark charcoal/black for primary headings (`#111827`), medium gray for secondary labels/descriptions (`#6B7280`), and light gray for borders/dividers (`#E5E7EB`).
  - **Accents**: Positive growth green (`#10B981` / `+8.5%`), negative change red (`#EF4444` / `-4.2%`).
- **Typography**:
  - **Primary Font Family**: Inter, SF Pro Display, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif.
  - **Fallback Chain**: `sans-serif` (system default sans-serif font stack).
  - **Hierarchy**:
    - **Page Title**: 24px, Bold, `#111827`.
    - **Section Header**: 18px, Semi-bold, `#111827`.
    - **Card Metric / Number**: 28px - 32px, Bold, `#111827`.
    - **Body / Labels**: 13px - 14px, Regular/Medium, `#6B7280`.
    - **Table Data / Metadata**: 12px - 13px, Regular, `#374151`.
