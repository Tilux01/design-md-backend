# Design Specification: Minimalist Cream & Terracotta Editorial Grid

## 1. Global Design Tokens & Theme

### Color Palette
*   **Background (Canvas):** Off-white / Cream `#F9F6F0`
*   **Primary Text & Headings:** Dark Taupe / Charcoal `#2C2623`
*   **Secondary Text / Subtitles:** Muted Brown-Grey `#7A706B`
*   **Accent Buttons & CTA Backgrounds:** Terracotta / Muted Rose `#C87D6B`
*   **Button Text:** Crisp White `#FFFFFF`
*   **Image / Graphic Holders:** Soft warm grey-beige tinted containers `#EFECE6`

### Typography (Editorial Serif & Modern Sans-Serif)
*   **Primary Heading Font:** `Playfair Display` (Fallback: `Georgia`, `serif`)
    *   *Usage:* Card titles, hero headings, major statements.
*   **Secondary / Body Font:** `Inter` or `Plus Jakarta Sans` (Fallback: `system-ui`, `-apple-system`, `sans-serif`)
    *   *Usage:* Paragraphs, lists, metadata, call-to-action button labels.

---

## 2. Component Blueprint: The Content Card

Each card in the grid is a modular, vertical layout container designed for high-end aesthetic content (e.g., fashion, lifestyle, recipe, or curation).

### Structural Layout (Flexbox / Column)
*   **Padding:** `24px` internal padding all around.
*   **Border Radius:** `16px` smooth rounded corners.
*   **Box Shadow (Depth):** Subtle elevation to mimic floating paper cards.
    *   `box-shadow: 0 10px 30px rgba(44, 38, 35, 0.06);`

---

## 3. Layout Variations (The 9-Grid Breakdown)

Depending on which slide/card is rendered full-screen, the internal components follow one of three specific patterns visible in your media:

### Layout Type A: Image-Centric (Hero / Visual Showcase)
1.  **Top Header:** Small category tag or title in uppercase serif tracking (`letter-spacing: 2px; font-size: 11px;`).
2.  **Central Visual:** Circular or rounded rectangular media container taking up ~60% of vertical height. Includes subtle drop shadow.
3.  **Footer CTA:** Full-width rounded button in Terracotta `#C87D6B` with white centered text.

### Layout Type B: Typography & Quote Heavy
1.  **Top Header:** Section marker (serif).
2.  **Central Content:** Multi-line editorial quote or statement in centered serif font (`line-height: 1.5;`).
3.  **Footer CTA:** Outline or solid terracotta pill button at the bottom.

### Layout Type C: List / Information Heavy
1.  **Top Header:** Section title.
2.  **Body Content:** Bulleted list or step-by-step instructions (using Inter, size 13px, generous line height for readability).
3.  **Footer CTA:** Full-width button anchored to the bottom.

---

## 4. Interactive States & Animations

To replicate the polished feel of the media templates, implement the following interactions:

*   **Hover Effect (Cards):** 
    *   `transform: translateY(-4px);`
    *   `transition: all 0.3s cubic-bezier(0.16, 1, 0.3, 1);`
*   **Button State:**
    *   Default: `#C87D6B`
    *   Hover: Darken by 10% (`#B46C5A`) with a smooth opacity transition.
*   **Page Entrance Animation (Framer Motion / CSS Keyframes):**
    *   Fade-in and upward slide for the card container.
    *   `opacity: 0; transform: translateY(20px) scale(0.98);` -> animate to `opacity: 1; transform: translateY(0) scale(1);` over `0.6s` with an ease-out expo curve.
