# DESIGN SPECIFICATION: Portfolio / Studio Landing Page

## 1. Global & Layout Settings
*   **Theme:** Dark Mode (`#0a0a0a` or pure black `#000000` background).
*   **Layout Structure:** Full-screen responsive viewport container with generous horizontal padding (approx. 5% to 8% margins on desktop). Fixed or sticky top navigation.
*   **Grid System:** Asymmetric multi-column layout utilizing CSS Grid and Flexbox.

---

## 2. Typography & Fonts

### Primary Font Families (or Fallbacks)
1.  **Sans-Serif (UI & Body Text):** 
    *   *Primary:* `Inter`, `Helvetica Neue`, `Arial`, sans-serif.
    *   *Usage:* Navigation, subtitles, descriptions, meta text.
2.  **Serif / Italic Serif (Hero Heading Accent):**
    *   *Primary:* `Instrument Serif`, `Playfair Display`, `Georgia`, serif (italicized).
    *   *Usage:* The " *end* " word inside the main hero headline (`FRONT end DEVELOPER`).

### Typography Hierarchy
*   **Logo:** Uppercase, Bold Sans-Serif, tracking/letter-spacing wide. (`Olive.`)
*   **Hero Main Title (`FRONT end DEVELOPER`):**
    *   `FRONT` & `DEVELOPER`: Extra-bold, sans-serif, uppercase, massive scale.
    *   `end`: Italicized serif font, lower-case, styled gracefully between the two bold words.
*   **Section Headers (`FEATURED WORK`, `WEB DESIGN`):** Bold, uppercase, tracked-out sans-serif.
*   **Body Copy & Paragraphs:** Regular weight, muted color (light gray), optimized line-height for readability.
