# Comprehensive UI/UX Design System Specification

---

## 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Brand Archetype:** Friendly, dynamic, and health/lifestyle-focused. The application balances playful, organic editorial layouts with clean utility widgets, appealing to modern wellness-conscious users.
- **Visual Density:** Medium-to-high. Cards are layered tightly with generous internal padding while maximizing real estate through compact inline data displays and horizontal scroll containers.
- **Whitespace Balance:** Dynamic. Uses asymmetric layouts, overlapping abstract shapes, and soft rounded structural surfaces to create visual rhythm rather than rigid grid uniformity.
- **Theme Balance:** Multi-themed contextual application. It utilizes soft pastel and warm chromatic palettes across different modules:
  - *Yellow/Warm Mode:* High-energy discovery and event scheduling.
  - *Lavender/Pastel Mode:* Activity tracking and progress reviews.
  - *Pink/Magenta Mode:* Detailed event flow, timeline analytics, and media controls.
  - *Light Blue/Teal Mode:* Sleep and biometric health summaries.

## 4. Layout Architecture & Spatial Grid

- **Container Constraints:** Max width `430px` (Mobile viewport master spec), fluid padding scaling from `16px` to `24px`.
- **Spacing Scale:** Uses an 8pt base grid system (`4px`, `8px`, `12px`, `16px`, `24px`, `32px`, `48px`).
- **Section Sequence Breakdown:**
  1. *Header Bar:* Context indicator, Back/Home triggers, Search & Profile avatars.
  2. *Hero Editorial Block:* High-contrast typography paired with overlapping organic shape cards.
  3. *Primary Metric / Dashboard Grid:* Asymmetrical card distribution (2-column mixed cards).
  4. *Secondary Recaps & Charts:* Full-width scrollable data visualizations with smooth curves.
  5. *Bottom Floating Navigation:* Pill-shaped bar with iconography, active indicator dot, and quick-add actions.
- **Stacking Order (Z-Index):**
  - Base Background: `z-0`
  - Card Surfaces: `z-10`
  - Sticky Headers & Overlays: `z-30`
  - Floating Navigation Bar: `z-50`

## 6. Motion Mechanics, Framer Motion & CSS Animation Code

- **Animation Triggers:** Page mount slide-ups, layout spring morphs on card selection, horizontal pagination slides.
- **Timing Physics:** Spring configuration `stiffness: 300`, `damping: 30`.

### Framer Motion React Code Snippets
```jsx
import { motion } from 'framer-motion';

export const cardVariant = {
  hidden: { opacity: 0, y: 20 },
  visible: { 
    opacity: 1, 
    y: 0,
    transition: { 
      type: "spring", 
      stiffness: 300, 
      damping: 30 
    }
  },
  hover: { 
    scale: 1.02,
    transition: { duration: 0.2 }
  },
  tap: { 
    scale: 0.98 
  }
};

export const AnimatedCard = ({ children, className }) => (
  <motion.div
    variants={cardVariant}
    initial="hidden"
    animate="visible"
    whileHover="hover"
    whileTap="tap"
    className={className}
  >
    {children}
  </motion.div>
);
```

## 7. Accessibility (a11y) & WCAG Contrast Audit

- **Contrast Ratios:**
  - Dark text (`#1A1D20`) on Yellow Surface (`#FFDD55`): **12.4:1** (Passes WCAG AAA)
  - Dark text (`#1A1D20`) on White Surface (`#FFFFFF`): **16.1:1** (Passes WCAG AAA)
  - Muted text (`#68707C`) on White Surface (`#FFFFFF`): **5.4:1** (Passes WCAG AA)
- **Focus Ring Specifications:**
  ```css
  :focus-visible {
    outline: none;
    box-shadow: 0 0 0 3px rgba(230, 74, 133, 0.4), 0 0 0 1px #E64A85;
  }
  ```
