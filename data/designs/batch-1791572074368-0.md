# UI Design Specification: Fleet Management Dashboard

This specification details the layout, styling, typography, iconography, and content of the Fleet Management Dashboard UI, adapted for a full-screen, responsive web application (omitting the outer mockup frame/shadow).

---

## 1. Overall Layout & Architecture

The application is structured into a **three-column layout** with a persistent dark sidebar navigation on the far left.

```
+-------------------------------------------------------------------------------------------------+
| SIDEBAR | LEFT PANE (Lists)              | CENTER PANE (Vehicle & Route Details)  | RIGHT PANE   |
| (Dark)  | - Favorites                    | - Vehicle Header & Specs               | - Driver     |
|         | - Trucks                       | - Active Route Map & Metrics           |   Statistics |
|         | - Vans                         | - Recent Route History                 |              |
+-------------------------------------------------------------------------------------------------+
```

### Color Palette (Design Tokens)
*   **Background (Canvas):** `#f4f7f6` (Light grayish-cyan neutral)
*   **Sidebar Background:** `#181925` (Deep dark slate/navy)
*   **Sidebar Active Item:** `#0066ff` (Vibrant blue)
*   **Card / Panel Background:** `#ffffff` (Pure white)
*   **Primary Text:** `#1b1f26` (Off-black)
*   **Secondary/Muted Text:** `#7a869a` (Cool gray)
*   **Status Indicators:**
    *   *On the Way / Active:* `#38ef7d` / `#11998e` (Green)
    *   *Loading / Unloading:* `#ff9900` (Orange)
    *   *Waiting:* `#ff4b4b` (Red)

---

## 2. Typography & Fonts

*   **Primary Font Family:** `Inter`, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `Helvetica`, `Arial`, sans-serif
*   **Fallback Font:** `sans-serif`
*   **Font Weights Used:** 
    *   Regular (400) - Body copy, metadata
    *   Medium (500) - Labels, subheaders, active states
    *   Semi-Bold (600) - Headings, prominent metrics, card titles

---

## 3. Component Breakdown

### 3.1. Far-Left Sidebar (Navigation)
*   **Background:** `#181925`
*   **Width:** `~72px` (Icon rail)
*   **Top Section:** Logo / App switcher icon.
*   **Middle Section:** Vertical stack of monochrome iconography (dashboard, analytics, users, vehicle list, documents, settings).
*   **Active Indicator:** The vehicle icon has a solid `#0066ff` background pill indicator.
*   **Bottom Section:** User profile avatar rounded circle.
