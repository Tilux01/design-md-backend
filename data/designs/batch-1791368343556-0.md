# NovaTrend E-Commerce Homepage - Design Specification

---

## 1. Global Styles & Variables

### 1.1 Color Palette
* **Primary Background:** `#FFFFFF` (White)
* **Secondary / Off-White Background:** `#F8F9FA` / `#F3F4F6` (Light Gray)
* **Dark / Text Primary:** `#111111` (Near Black)
* **Text Secondary / Muted:** `#6B7280` (Gray)
* **Accent / Brand Orange:** `#FF4500` / `#FF5500`
* **Border / Divider Color:** `#E5E7EB` (Light Border Gray)
* **Hero Banner / Secondary Background:** `#F0F2F5` (Soft neutral grey/off-white)
* **Flash Sale Banner Gradient:** `#FF6A00` to `#FF3300` (Warm Orange to Red-Orange Gradient)
* **Dark Promo Banner:** `#111111` to `#1F2937` (Dark Charcoal Gradient)

### 1.2 Typography
* **Font Family:** Inter, system-ui, -apple-system, sans-serif
* **Font Weights:** 
  * Regular: `400`
  * Medium: `500`
  * Semibold: `600`
  * Bold: `700`

---

## 2. Layout Structure & Containers

* **Max Width:** `1280px` (Centered with auto margins for desktop)
* **Global Spacing:** 
  * Section Vertical Padding: `60px` top/bottom
  * Container Horizontal Padding: `24px`

---

## 4. Interaction & State Notes
* **Hover States:** 
  * Buttons elevate slightly with a subtle scale or color shift.
  * Product cards show a subtle shadow lift on hover (`box-shadow: 0 10px 25px rgba(0,0,0,0.08)`).
* **Links:** All text links and "View All" prompts include hover underline or color shift to orange (`#FF4500`).
