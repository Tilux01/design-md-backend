# Haven Landing Page — Design System Specification

---

## 1. Design Philosophy & Overall Aesthetic
* **Mood & Archetype:** Tranquil, modern, innovative, and premium AI-first workspace product. Blends organic visual metaphors (breathtaking alpine landscapes, natural flora) with ultra-clean, minimalist software design.
* **Visual Density:** Airy and spacious. Relies on heavy whitespace and high-contrast typography overlaid on immersive background imagery to create depth.
* **Theme Balance:** Light-mode focused UI elements (navbars, pill badges, and buttons) floating gracefully over a photorealistic, warm-toned natural photography background. High contrast is maintained using deep near-black text (`#111111`) against light pills/backgrounds.

---

## 2. Color Palette & Design Tokens

### Core Brand & Accents
* **Primary (Brand Orange):** `#F36F21` (Used for logo glyph and key interactive highlights)
* **Secondary / Accent:** `#D45412` (Hover state for brand orange)

### Base & Surfaces
* **Page Backdrop / Canvas:** Immersive Photography (Alpine range, valley, and wildflower meadow)
* **Navbar / Floating Container Surface:** `rgba(255, 255, 255, 0.85)` with `backdrop-filter: blur(16px)`
* **Pill Badge / Sub-container Surface:** `#FFFFFF` (Solid white)
* **Button Primary (Dark/Pill):** `#111111` (Near-black)
* **Button Primary Hover:** `#222222`

### Text Colors
* **Primary Heading:** `#111111` (Deep Charcoal / Black)
* **Body / Subtitle Text:** `#4B5563` (Cool Gray)
* **Navbar Links:** `#374151` (Dark Gray)
* **Inverse Text (Buttons):** `#FFFFFF` (Pure White)

### Borders & Dividers
* **Subtle Container Border:** `rgba(255, 255, 255, 0.4)` or `rgba(0, 0, 0, 0.06)`

---

## 3. Typography System & Hierarchy
* **Font Family:** Inter / Plus Jakarta Sans (Clean geometric sans-serif system)
* **Scale Breakdown:**
  * **H1 (Hero Heading):** 
    * Font Size: `56px` / `3.5rem` (Fluid scaling up to `64px`)
    * Font Weight: `700` (Bold)
    * Line Height: `1.1`
    * Letter-Spacing: `-0.03em`
  * **Subtitle / Lead Paragraph:** 
    * Font Size: `18px` / `1.125rem`
    * Font Weight: `400` (Regular)
    * Line Height: `1.5`
    * Letter-Spacing: `-0.01em`
  * **Navigation Links:** 
    * Font Size: `14px` / `0.875rem`
    * Font Weight: `500` (Medium)
    * Line Height: `1.2`
  * **Pill Badge / Micro Copy:** 
    * Font Size: `12px` / `0.75rem`
    * Font Weight: `500` (Medium)

---

## 4. Layout Architecture & Spatial Grid
* **Container Max-Width:** `1280px` (Centered with auto margins)
* **Global Padding:** Horizontal `24px` to `48px`, Vertical spacing driven by expansive vertical whitespace.
* **Section Sequence:**
  1. Floating Top Navigation Bar (`position: fixed; top: 24px;`)
  2. Hero Announcement Pill (`"We just raised 20M 🚀"`)
  3. Main Hero Typographic Lockup (H1 + Subtitle)
  4. Primary Call-to-Action Group (`Get Started` + `Watch Demo`)
  5. Immersive Visual Backdrop with Foreground Parmo/Meadow layer
  6. Scroll Indicator (`SCROLL ↓`) pinned to bottom center

---

## 5. Component Blueprint & Element Placement

### A. Floating Navigation Bar
* **Dimensions:** Height `52px`, width approx. `620px`, fully rounded pill (`border-radius: 9999px`).
* **Structure:** Left aligned Logo icon + wordmark, centrally grouped navigation links (`Home`, `Use cases`, `Pricing`, `Careers`, `Contact`), right-aligned primary `Login` pill button.
* **Effects:** `box-shadow: 0 8px 32px rgba(0, 0, 0, 0.08)`, `backdrop-filter: blur(12px)`.

### B. Announcement Pill
* **Dimensions:** Height `30px`, inline-flex, fully rounded.
* **Background:** Solid `#FFFFFF` with ultra-fine border `1px solid rgba(0,0,0,0.04)`.
* **Content:** Sparkle/Rocket emoji + `"We just raised 20M 🚀"` in `12px` medium weight text.

### C. Hero Section CTA Buttons
* **Primary Action (`Get Started`):**
  * Height: `44px`, Padding: `0 24px`, Border-radius: `9999px`.
  * Background: `#111111`, Text: `#FFFFFF`.
  * Icon: Right-pointing arrow (`→`) with `8px` spacing.
* **Secondary Action (`Watch Demo`):**
  * Text-only button style, semi-transparent backdrop or clean ghost button, `14px` medium weight text, color `#111111`.

---

## 6. Motion Mechanics & Interactions
* **Transitions:** Smooth cubic-bezier curves (`cubic-bezier(0.16, 1, 0.3, 1)`) for hover states and state changes.
* **Hover States:** 
  * Buttons elevate slightly with a subtle scale transform (`scale(1.02)`) and intensified shadow depth.
  * Nav links shift from `#374151` to `#111111`.
* **Scroll Indicator:** Continuous subtle vertical floating keyframe animation (`translateY(0px)` to `translateY(6px)`).
