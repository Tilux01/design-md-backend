# Design Specification: 404 Gothic Editorial Page

## 1. Overview & Color Palette

A luxury, dark-editorial 404 error page featuring high-contrast monochrome photography, bold typography, and floating crimson rose petals.

### Palette
* **Background Primary**: `#000000` (Pure Black)
* **Text / Accents Primary**: `#FFFFFF` (Pure White)
* **Muted Text / Borders**: `rgba(255, 255, 255, 0.4)`
* **Accent (Rose Petals)**: Deep Crimson to Vibrant Ruby (`#7A0012` to `#D61834`)

## 3. Visual Assets & Imagery

### 1. Subject Image (Veiled Figure)
* **Description**: Grayscale portrait of a woman wearing an intricate gothic tiara/crown and sheer black veil, holding a desaturated peony/rose near her face with gloved hands.
* **Format**: PNG with transparent edges, or JPG blended via CSS `mask-image: linear-gradient(to right, black 50%, transparent 95%)`.
* **Placement**: Left half (`left: 0`, bottom-aligned), occupying ~60% viewport width, layered beneath text and foreground petals.

### 2. Floating Rose Petals
* **Description**: Multi-layered crimson and red rose petals scattered dynamically across the center and right screen.
* **Layers**:
  * *Foreground*: Larger, slightly motion-blurred petals overlapping the "404" numbers.
  * *Midground*: In-focus petals dispersed between typography and background.
  * *Background*: Smaller, deeply shadowed petals.

## 4. Layout & UI Elements

### Viewport Setup
* Full screen: `width: 100vw; height: 100vh; overflow: hidden; background: #000000; position: relative;`

### A. Header (Top Bar)
* `height: 80px; padding: 0 40px; display: flex; justify-content: space-between; align-items: center; position: absolute; top: 0; width: 100%; z-index: 10;`
* **Left**: 3-line hamburger menu icon (`24px`, white).
* **Center**: 
  * Logo: `B&Y` (font-size: `32px`).
  * Subtitle: `YOUR • GOAL • TRAINER` (font-size: `8px`, positioned directly below `B&Y`).
* **Right**: Icons (`20px`, white, gap: `24px`): Search (magnifying glass), Account (profile silhouette), Bag (shopping tote).

### B. Center / Main Display
* **Error Code "404"**:
  * Positioned center-right (`left: 52%`, `top: 55%`, `transform: translate(-50%, -50%)`).
  * Size: `~22vw` (~240px–320px). Color: `#FFFFFF`.
  * Depth: Subtle drop shadow (`0 20px 40px rgba(0,0,0,0.8)`).
* **Vertical Text ("PAGE NOT FOUND")**:
  * Positioned along the right outer edge of the last digit "4".
  * Rotation: `-90deg` (reading upwards). Font size: `10px`.
* **Button ("BACK HOME")**:
  * Positioned above the "0" and right "4" (`top: 38%`, `left: 56%`).
  * Style: Rectangular, transparent background, solid `1px` white border.
  * Padding: `12px 36px`. Font size: `13px`.

### C. Side Nav Indicators
* **Left ("BACK")**:
  * Position: Absolute left, vertically centered (`top: 50%`, `left: 30px`).
  * Element: Horizontal thin line (`60px`, `1px`, white) with "BACK" (`9px`) positioned centrally along the line.
* **Right ("HOME")**:
  * Position: Absolute right, vertically centered (`top: 50%`, `right: 30px`).
  * Element: Horizontal thin line (`60px`, `1px`, white) with "HOME" (`9px`) positioned centrally along the line.

### D. Footer (Bottom Bar)
* `height: 80px; padding: 0 40px; display: flex; justify-content: space-between; align-items: center; position: absolute; bottom: 0; width: 100%; z-index: 10;`
* **Left**: Home outline icon + Equalizer/sliders icon (`gap: 16px`, white, `18px`).
* **Center**: 3 small inline dots (`...`), white, indicating carousel or page status.
* **Right**: Social media icons (`gap: 20px`, white, `16px`): Twitter/X, Facebook, Instagram.
