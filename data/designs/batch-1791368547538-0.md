# Design Specification: Solid Gray Surface

## 1. Overview
* **Type:** Solid color background / full-screen canvas.
* **Layout:** Simple single-layer element occupying 100% of the viewport width and height.

---

## 2. Color Palette
* **Background Color:** `#808080` (Medium Gray / Hex value equivalent to RGB `128, 128, 128`).

---

## 3. Typography & Text Elements
* **None.** No text content, headings, or labels are present.

---

## 4. UI Elements & Components
* **None.** No interactive components, buttons, icons, or borders.

---

## 5. Layout & Spacing
* **Dimensions:** Full-screen (`width: 100vw`, `height: 100vh`).
* **Margins & Padding:** `0px` throughout.
* **Frames/Containers:** Omitted (flat, full-bleed design).

---

## 6. CSS Implementation Code
```css
html, body {
  margin: 0;
  padding: 0;
  width: 100vw;
  height: 100vh;
  background-color: #808080;
  overflow: hidden;
}
