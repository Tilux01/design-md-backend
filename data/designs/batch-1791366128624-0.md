# Visual Design Specification: MacBook-Style Menu Bar with Notch Dropdown

This specification details a macOS-inspired desktop environment UI featuring a custom notch/camera housing integrated into the top menu bar, complete with an interactive widget preview dropdown.

---

## 1. Global Layout & Typography

### Canvas / Window
* **Background:** Dark abstract gradient or textured backdrop (simulating a dark mode desktop wallpaper).
* **Frame:** The UI is housed within a device bezel (e.g., MacBook Pro rounded display corners and camera housing/notch).

### Typography
* **Font Family:** System sans-serif (e.g., `-apple-system`, `BlinkMacSystemFont`, `SF Pro Text`, `Segoe UI`, `sans-serif`).
* **Base Text Color:** White (`#FFFFFF`) with varying opacities for inactive/secondary states.
* **Font Size (Menu Bar):** 13px – 14px, medium weight.

---

## 2. Top Menu Bar

* **Position:** Fixed to the top of the screen (`top: 0`, `left: 0`, `right: 0`).
* **Height:** Standard macOS menu bar height (~24px to 28px).
* **Background:** Translucent dark gray / frosted glass effect (backdrop blur with `background: rgba(20, 20, 20, 0.4)`).
* **Border Bottom:** Subtle border or gradient fade if applicable.

### Menu Bar Items (Left to Right)

1. **Spotify Icon:** Minimalist Spotify green or monochrome white icon (`#FFFFFF`).
2. **Temperature Display:** `"78°"` text.
3. **Wi-Fi Icon:** Standard wireless connection signal arcs.
4. **Search / Magnifying Glass Icon:** Outline style.
5. **Control Center / Settings Icons:** Two pill-shaped or stacked sliders/toggles icon.
6. **System Status Indicator:** Small colored dot (e.g., green/blue recording or active indicator) on the far right.

---

## 3. The Notch & Dropdown Widget

### Notch Housing
* **Shape:** Centered pill-shaped cutout extending downward from the top menu bar (simulating the physical MacBook Pro display notch).
* **Fill:** Solid dark gray/black (`#111111`) seamlessly blending into the bezel.

### Expanded Dropdown Panel (Hover / Active State)
* **Shape:** Rounded container expanding downward directly below the central notch.
* **Background:** Frosted glass / dark translucent panel (`rgba(30, 30, 30, 0.85)` with backdrop filter blur).
* **Border Radius:** Fully rounded bottom corners with smooth transitions connecting to the notch.
* **Content inside the Dropdown:**
  * **Text/Weather Info:** `"78° Cloudy"` (white text, secondary gray text for conditions).
  * **Secondary Icon/Widget Elements:** Weather icon (cloud symbol) and miniature visual indicators.

---

## 4. Interactive Elements & Cursor

* **Cursor:** Standard white macOS pointer arrow positioned pointing upward toward the temperature/notch area.
* **Hover States:** Semi-transparent white background highlight (`rgba(255, 255, 255, 0.15)`) with rounded corners on interactive menu items.
