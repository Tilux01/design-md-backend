# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: High-end Dark Mode Glassmorphism & Micro-Interactions Showcase (Portfolio / UI Component Showcase).
- **Visual Density & Whitespace Ratio**: High whitespace focus with deep dark ambient depth (`#050505`), utilizing layered translucent glass panes to create dimensional hierarchy and fluid refractive distortion effects.
- **Surface Elevation Model**: Multi-tier depth using dark translucent frosted glass (`rgba(20, 20, 25, 0.7)`), ultra-thin crisp white/silver borders (`rgba(255, 255, 255, 0.08)`), heavy background blur (`backdrop-filter: blur(24px)`), and radial ambient lighting.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase typography, glass distortion refraction simulation, dot-matrix coordinate background pattern, minimal monochromatic aesthetic.
- **Pill Badge Specification**: Padding `6px 14px`, font-size `12px`, font-weight `500`, tracking `0.08em`, border-radius `9999px`, background translucency `rgba(255,255,255,0.04)`, border width `1px`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-emerald-400 inline-block"></span>`.
