## 1. Global System Configuration & Theme

### Color Palette (Exact Hex Codes)
*   **Primary Dark / Navy:** `#0F172A` (Used for headers, dark cards, bottom navigation backgrounds)
*   **Deep Accent Navy:** `#1E293B` (Used for active navigation states, dark card borders)

*   **Background Light (Canvas):** `#F8FAFC` (Off-white canvas color for light mode screens)

*   **Text Primary:** `#0F172A` (Main headings, prominent user names)

## 6. Implementation Checklist for Developers

1.  **Setup Canvas:** Ensure the viewport is constrained to mobile dimensions (`393px` width standard) with `#F8FAFC` base background.
2.  **Reusable Components:**
    *   Create a reusable `Card` component with configurable background colors and border radii (`16px`, `20px`, `24px`).
    *   Create a reusable `BottomNavigation` bar pinned to the bottom.
3.  **Images & Assets:** Ensure all placeholder images (avatars, medical equipment, oncology chair) use high-resolution medical photography with clean lighting and cool color grading.
4.  **Spacing & Padding:** Maintain consistent spacing multiples of `4px`/`8px` (e.g., `8px`, `12px`, `16px`, `24px`).
