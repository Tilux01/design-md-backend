# Design System Specification: Mindly

---

## 1. Design Philosophy & Overall Aesthetic
- **Primary Mood:** Calm, focused, professional, productivity-enhancing, intellectual, and refined.
- **Brand Archetype:** The Creator & The Sage.
- **Visual Density:** Clean, generous whitespace, avoiding clutter to mirror the app's core promise ("Less chaos. More clarity.").
- **Theme Balance:** Light mode dominant with high contrast, ultra-clean off-white background (`#FAFAFA`), paired with frosted glass cards (`backdrop-filter: blur`), dark/black primary elements (`#111111`), and soft neutral grays.

## 3. Typography System & Hierarchy

- **Font Family (Headings):** `Instrument Serif`, `Playfair Display`, or high-end Editorial Serif fallback to `Times New Roman`, serif.
- **Font Family (Body/UI):** `Inter`, `-apple-system`, `BlinkMacSystemFont`, sans-serif.

### Type Scale Breakdown:
* **Display Hero Title:**
  * Size: `64px` / `4rem` (Desktop fluid up to `76px`)
  * Weight: `400` (Italicized accents)
  * Line Height: `1.05`
  * Letter-Spacing: `-0.03em`
* **H1 / Section Header:**
  * Size: `40px` / `2.5rem`
  * Weight: `500`
  * Line Height: `1.1`
  * Letter-Spacing: `-0.02em`
* **Body Lead / Subtitle:**
  * Size: `18px` / `1.125rem`
  * Weight: `400`
  * Line Height: `1.5`
  * Letter-Spacing: `-0.01em`
* **UI Button Text / Nav Links:**
  * Size: `14px` / `0.875rem`
  * Weight: `500`
  * Line Height: `1.2`
  * Letter-Spacing: `0`
* **Captions & Microcopy:**
  * Size: `12px` / `0.75rem`
  * Weight: `400`
  * Line Height: `1.4`
  * Letter-Spacing: `0.01em`

## 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** `1280px` centered with responsive horizontal padding (`32px` desktop, `16px` mobile).
- **Grid System:** 12-column flexible CSS Grid with consistent `24px` gap gutters.
- **Section Sequence Breakdown:**
  1. **Global Header:** Logo left, pill-shaped nav menu centered, CTA button right ("Get the app").
  2. **Hero Section:** Centered headline + subtitle, dual CTAs, surrounded by asymmetrical floating glassmorphism thought/feature cards and a central 3D photographic/graphic portrait asset.
  3. **Social Proof Footer-Left:** "Trusted by 50,000+ creators worldwide" with stacked avatar group.
  4. **Brand Stamp Footer-Right:** Circular badge typography ("MORE FOCUSED EVERYDAY") and minimalist status indicators ("Less chaos. More clarity.").
- **Stacking Order (Z-Index):**
  * Base Background: `z-index: 0`
  * Hero Central Imagery & 3D Cards: `z-index: 10`
  * Floating UI Cards & Connection Paths: `z-index: 20`
  * Global Navigation Header: `z-index: 100`

## 5. Component Blueprint & Element Placement

### A. Global Navigation Header
* **Dimensions:** Height `72px`, full width contained inside padding.
* **Navigation Pill:** Floating pill wrapper with `background: rgba(255, 255, 255, 0.8)`, `border: 1px solid #EAEAEA`, `border-radius: 9999px`, padding `6px 12px`, gap `24px`. Active link indicator styled with a light gray background pill.
* **CTA Button ("Get the app"):** Pill button (`border-radius: 9999px`), `background: #111111`, `color: #FFFFFF`, padding `10px 20px`, typography size `14px` medium weight with a trailing arrow icon (`↗`).

### B. Floating Glass Cards
* **Border Radius:** `24px`
* **Background:** `rgba(255, 255, 255, 0.75)`
* **Backdrop Blur:** `blur(16px)`
* **Border:** `1px solid rgba(255, 255, 255, 0.8)`
* **Shadow:** `0 20px 40px -15px rgba(0, 0, 0, 0.05)`
* **Inner Padding:** `20px` to `24px`
* **Connection Lines:** Thin bezier curves (`stroke: #D1D5DB`, `stroke-width: 1.5px`, dashed or solid) linking peripheral cards to the central character container.

### C. Primary Action Buttons
* **Solid Dark CTA ("Get started free"):**
  * Height: `48px`
  * Border-Radius: `9999px` (Full pill)
  * Background: `#111111`
  * Text Color: `#FFFFFF`
  * Icon: Right-aligned arrow inside a subtle circular container.
* **Ghost CTA ("Watch video"):**
  * Height: `48px`
  * Border-Radius: `9999px`
  * Background: `transparent` (or very light white tint on hover)
  * Border: `1px solid #EAEAEA`
  * Icon: Left-aligned play icon inside a circle.

## 6. Motion Mechanics, 3D & Mobile Gestures

- **Animation Triggers:** Page load staggered entry, scroll-linked parallax for floating glassmorphism cards, and subtle mouse-move cursor tracking (tilt effect on central portrait and orbital cards).
- **Inferred Animation Stack:** Framer Motion (React) or CSS Custom Properties combined with `transform: perspective(1000px) rotateX() rotateY()`.
- **Transition Physics:** 
  * Hover transitions: `cubic-bezier(0.16, 1, 0.3, 1)` (Spring-like decelerating ease), duration `300ms`.
  * Float loop: Infinite keyframe translation along the Y-axis (`translateY(-8px)` to `translateY(8px)` over `4000ms` sinusoidal loop).
- **Mobile Responsive Adaptations:**
  * Floating cards collapse into a stacked vertical carousel or sequential accordion list.
  * Navigation pill converts to a hamburger menu drawer with smooth slide-in transitions (`translateX(100%)`).
