# UI/UX Specification & Design System: Roboforge Hero Section

## 1. Global Layout & Reset

*   **View Mode:** Full-screen responsive viewport (`width: 100vw`, `height: 100vh`, `min-height: 700px`).
*   **Box Sizing:** `border-box` applied globally.
*   **Background Gradient:**
    *   Dark, immersive cyber-industrial radial and linear gradient.
    *   `background: radial-gradient(circle at 70% 50%, rgba(10, 35, 75, 0.6) 0%, rgba(5, 10, 25, 0.95) 60%), linear-gradient(135deg, #02040a 0%, #081124 50%, #030612 100%);`

---

## 2. Color Palette

| Color Name | Hex Code / Value | Usage |
| :--- | :--- | :--- |
| **Primary Dark / Void** | `#02040a` | Deepest background shadows |
| **Surface Blue** | `#081124` | Main container and base layer |
| **Cyber Cyan** | `#38bdf8` / `#e0f2fe` | Glowing portal ring, highlights, active states |
| **Pure White** | `#ffffff` | Primary typography (Brand, Hero Title) |
| **Muted Silver** | `#94a3b8` | Secondary typography, nav links, borders |
| **Button Dark** | `rgba(255, 255, 255, 0.05)` | Glassmorphism CTA background |
| **Button Hover** | `rgba(255, 255, 255, 0.15)` | Interactive state background |

---

## 3. Typography & Fallbacks

### Primary Font Family: **Inter / Space Grotesk / Outfit** (Modern Geometric Sans-Serif)
*   *Fallback Stack:* `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif;`

### Font Hierarchy:

1.  **Brand Logo (`roboforge`)**
    *   Font Weight: `700` (Bold)
    *   Font Size: `18px`
    *   Letter Spacing: `-0.02em`
    *   Color: `#ffffff`

2.  **Navigation Links (Home, About, Products, Contact Us)**
    *   Font Weight: `400` (Regular) / `500` (Medium for Contact)
    *   Font Size: `13px`
    *   Color: `#94a3b8` (Hover: `#ffffff`)

3.  **Hero Title (`ROBOFORGE`)**
    *   Font Weight: `900` (Black) / Heavy Display
    *   Font Size: Clamp responsive (`clamp(3.5rem, 7vw, 7.5rem)`)
    *   Letter Spacing: `0.05em`
    *   Text Transform: `uppercase`
    *   Special Effect: Digital glitch/stencil cutouts via SVG masking or multi-layered positioning.

4.  **Subtitle (`for ROBOTICS and AUTOMATION`)**
    *   Font Weight: `500` (Medium)
    *   Font Size: `12px` to `14px`
    *   Letter Spacing: `0.15em`
    *   Color: `#94a3b8`

5.  **CTA Button (`Send Your RFQ`)**
    *   Font Weight: `500` (Medium)
    *   Font Size: `13px`
    *   Color: `#ffffff`

---

## 4. Component Breakdown & Structure

### A. Navigation Bar (`<header>`)
*   **Position:** Fixed / Absolute top, spanning full width with inner horizontal padding (`padding: 24px 48px`).
*   **Layout:** Flexbox, `space-between` alignment.
*   **Left Element:** Brand logo text (`roboforge`) with a subtle lowercase styling.
*   **Center Element:** Floating capsule navigation menu.
    *   Container: Semi-transparent dark pill background (`background: rgba(255, 255, 255, 0.03)`, `border: 1px solid rgba(255, 255, 255, 0.08)`, `border-radius: 9999px`, `backdrop-filter: blur(12px)`).
    *   Links: `Home` (with a bottom indicator line active state), `About`, `Products`.
*   **Right Element:** Contact CTA button.
    *   Pill shape matching the nav, ending with a circular white icon button containing a top-right diagonal arrow (`↗`).

### B. Hero Section Core (`<main>` / `<section>`)
*   **Layout Structure:** CSS Grid or Flexbox with absolute positioning overlays.

#### 1. Left Content Area (Z-index: 2)
*   Vertical stack aligned to the left (`max-width: 650px`, `padding-left: 60px`).
*   **Main Headline:** `ROBOFORGE` rendered in a striking, wide geometric sans font with stylized horizontal cuts across the letters `O`, `F`, `O`, `R`, `G`.
*   **Sub-headline:** `for ROBOTICS and AUTOMATION` in tracked-out uppercase letters.
*   **CTA Button:** "Send Your RFQ" pill button featuring an enclosed white circular icon with a black diagonal arrow (`↗`).

#### 2. Right Visual & Portal Graphic (Z-index: 1)
*   **Central Subject:** Silhouette/render of an advanced cybernetic/robotic humanoid figure stepping forward.
*   **Portal Ring:** A massive, glowing cyan ring (`#38bdf8`) positioned behind the robotic figure, casting volumetric blue light rays and mist onto the dark floor grid.
*   **Glitch/Grid Accents:** Subtle floating square wireframe elements scattered around the lower-middle backdrop to give a high-tech blueprint feel.

### C. Footer / Bottom Bar
*   **Left:** Social Media Icons (`in`, `f`, `📷`) housed in minimal text/icon format.
*   **Center:** Floating wireframe UI square indicators.
*   **Right:** Carousel / Pagination navigation arrows (`←`, `→`).

---

## 5. Animations & Micro-Interactions (CSS / JS)

1.  **Portal Glow Pulse:**
    *   *Effect:* Continuous subtle scaling and opacity fluctuation of the glowing ring.
    *   *CSS:* `@keyframes portalGlow { 0%, 100% { filter: drop-shadow(0 0 30px rgba(56, 189, 248, 0.4)); } 50% { filter: drop-shadow(0 0 60px rgba(56, 189, 248, 0.8)); } }`
2.  **Button Hover State:**
    *   *Effect:* Background color transition, subtle scale up (`transform: scale(1.02)`), and arrow rotation inside the CTA button.
    *   *Transition:* `all 0.3s cubic-bezier(0.4, 0, 0.2, 1);`
3.  **Page Load Entrance:**
    *   *Effect:* Fade-in and upward slide (`translateY(20px) -> translateY(0)`) for typography elements and the central robot visual. Staggered delays for Nav (0.1s), Title (0.3s), and Visuals (0.5s).
