# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Clean Enterprise SaaS, Dark Mode Analytics Dashboard, Eco-Tech Dashboard.
- **Visual Density & Whitespace Ratio**: High information density balanced by structured container cards with generous padding (`space-4` to `space-6`), utilizing a crisp 8pt spatial grid to separate complex metrics, charts, and regional data tables.
- **Surface Elevation Model**: Layered depth architecture using subtle surface contrast and crisp 1px borders rather than heavy drop-shadows:
  - **App Canvas**: Deep dark teal-black (`#0d191d` / `#13252a`).
  - **Sidebar Nav**: Darker structural canvas (`#0b1519`).
  - **Card Surfaces**: Semi-translucent dark slate-teal (`#15282e` / `#12242a`) with hairline borders (`#1d3740`).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase pill badges (`&#10022;` sparkle indicators, live status pulsing dots), glassmorphism metric cards, compact trend sparklines, interactive map region highlights.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `11px`, font-weight `600`, tracking `0.05em`, border-radius `9999px`, background translucency `rgba(16,185,129,0.1)`, border width `1px`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;`
  - Sparkle / Star (✦) -> Use `&#10022;`
  - Status Dot (●) -> Use `<span className="w-2 h-2 rounded-full bg-emerald-500 inline-block animate-pulse"></span>`
