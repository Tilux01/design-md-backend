# Design Specification: Reboot UI/UX System

## 1. Design Philosophy & Overall Aesthetic
- **Primary Mood:** Avant-garde, sophisticated, high-tech, yet deeply human and community-driven. Combines raw digital art (dot-matrix/generative patterns) with clean enterprise minimalism.
- **Visual Density:** Airy, spacious, highly structured with extreme restraint. Heavy reliance on negative space to draw focus to the central typography and abstract map/network graphics.
- **Theme Balance:** Pure Light Mode default (`#FFFFFF` background, `#0A0A0A` foreground) with targeted dark-mode elements (e.g., the primary "Sign in" button and interactive states using radial/linear gradient glows).

---

## 2. Color Palette & Design Tokens

### Core Colors
- **Background Base:** `#FFFFFF` (Light mode base canvas)
- **Primary Text:** `#0A0A0A` (Deep charcoal, near black)
- **Secondary / Muted Text:** `#666666` (Neutral gray for secondary copy)
- **Tertiary / Subdued Text:** `#8C8C8C` (For lower hierarchy meta-text)

### Brand Accent & Interactive Gradients (Button / Glow)
- **Glow Gradient Start:** `#FF4D4D` (Neon Coral)
- **Glow Gradient Mid:** `#7928CA` (Electric Violet)
- **Glow Gradient End:** `#0070F3` (Vibrant Cyan)
- **Solid Dark Background (Pill Button):** `#0F0F10`

### Surface & Border Tokens
- **Surface Layer / Card Background:** `#F9F9FB`
- **Border / Divider:** `#E5E7EB` (Subtle light gray separator)

---

## 3. Typography System & Hierarchy

### Font Families
- **Headings & Primary UI:** Inter, system-ui, -apple-system, sans-serif
- **Body Copy:** Inter, sans-serif

### Scale Breakdown
- **Nav Logo / Brand:** 14px / Bold (700) / Tracking: -0.02em
- **Nav Links:** 13px / Regular (400) / Tracking: -0.01em
- **Hero Title (H1):** 48px – 56px / Semi-Bold (600) / Line-Height: 1.1 / Tracking: -0.03em
- **Hero Subtitle / Body:** 14px / Regular (400) / Line-Height: 1.5 / Tracking: -0.01em
- **Button Text:** 13px / Medium (500) / Tracking: -0.01em

---

## 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** `1280px` centered with auto margins.
- **Horizontal Page Padding:** `40px` (Desktop), scaling down to `20px` on mobile.
- **Spatial Scale (8pt grid system):**
  - `4px`, `8px`, `12px`, `16px`, `24px`, `32px`, `48px`, `64px`

### Section Sequence Breakdown
1. **Global Header / Navigation Bar:** Fixed/Sticky top bar containing Logo, Nav links, and "Sign in" CTA.
2. **Hero Section:** Centered micro-copy, headline, multi-stop gradient pill CTA, flanked by generative dot-matrix world map graphics.
3. **Social Proof / Partner Logo Ticker:** Monochromatic logo wall displayed horizontally along the bottom footer margin.

---

## 5. Component Blueprint & Element Placement

### Navigation Bar
- **Layout:** Flexbox, space-between alignment. Height: `72px`.
- **Left Group:** Logo icon (`16x16px` SVG) + "Reboot" text label (`14px` Medium). Spacing: `8px`.
- **Center Group:** Navigation items (Platform, Manifesto, Perks, Download, Articles). Spacing: `32px`. Color: `#4A4A4A`, hover to `#0A0A0A`.
- **Right Group:** "Sign in" Pill Button (`height: 36px`, `padding: 0 20px`, `border-radius: 18px`, `background: #0A0A0A`, `color: #FFFFFF`).

### Hero Section & Generative Graphic
- **Layout:** Absolute/Relative composite layout. Central text container stacked vertically above the "Join our World" CTA.
- **Generative Dot-Matrix Graphics:** Left and right abstract pointillism map formations composed of variable-radius dots (`1px` to `3px`) in varying opacity steps (`0.2` to `0.8`).

### Primary Action Button ("Join our World")
- **Shape:** Pill container (`border-radius: 9999px`, height: `40px`, padding: `0 24px`).
- **Inner Background:** `#0A0A0A` text/fill with an underlying blurred conic gradient glow (`filter: blur(12px)`, opacity `0.6`).
- **Typography:** `#FFFFFF`, `13px`, Medium weight.

---

## 6. Motion Mechanics & Interactions

- **Hover States (Nav Links):** Instant color transition (`transition: color 0.15s ease-in-out`).
- **Hover States (CTA Buttons):** Subtle scale transform (`transform: scale(1.02)`) with intensified drop-shadow blur on the ambient gradient halo.
- **Page Load Animation:** Staggered fade-in (opacity `0` to `1`) and translateY (`10px` to `0`) across the Navigation Bar, Hero Typography, and Generative Dot Matrix assets with a total duration of `0.8s` using cubic-bezier `0.16, 1, 0.3, 1` (ease-out-expo).
