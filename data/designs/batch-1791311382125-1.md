# Design Specification: Nike Minimalist Landing Page (Concept UI)

---

## 1. Design Philosophy & Overall Aesthetic
- **Brand Archetype:** High-end, minimalist luxury sportswear concept.
- **Visual Density:** Extremely low (high whitespace ratio, generous negative space).
- **Mood:** Clean, architectural, forward-thinking, and editorial.
- **Theme Balance:** Predominantly light-mode canvas paired with stark black typography and high-impact neon coral accents. Balanced with a dark vertical column to anchor the right edge.

---

## 2. Color Palette & Design Tokens

| Token Category | Token Name | Hex Code / Value | Usage |
| :--- | :--- | :--- | :--- |
| **Primary Base** | `--bg-main` | `#FFFFFF` | Main page background |
| **Surface Dark** | `--bg-dark` | `#1E2028` | Right-side panel / container |

---

## 3. Typography System & Hierarchy
- **Primary Font Family:** Inter / Helvetica Neue (Sans-serif, geometric neo-grotesque)
- **Monospace/Accent:** DIN / Custom Brand Tracker

| Tier | Font-Size | Font-Weight | Line-Height | Tracking (Letter-Spacing) |
| :--- | :--- | :--- | :--- | :--- |
| **Brand Mark (N I K E)** | `64px / 4rem` | Light / 300 | `1.0` | `16px` (Wide tracked) |
| **Sub-Navigation** | `12px / 0.75rem` | Medium / 500 | `1.2` | `2px` |
| **Body / Caption** | `14px / 0.875rem` | Regular / 400 | `1.5` | `normal` |

---

## 4. Layout Architecture & Spatial Grid
- **Container Model:** Fixed aspect-ratio hero canvas (Desktop view representation).
- **Grid Layout:** Asymmetrical 3-Column structural split:
  - **Left Pane (Brand Area):** ~50% width, pure white canvas with oversized spaced typography.
  - **Center/Editorial Image Pane:** ~35% width, featuring editorial photography.
  - **Right Action Rail:** ~15% width, split into dark navigation header and solid coral interactive footer.
- **Spacing Scale:**
  - Base unit: `8px`
  - Container padding: `48px` outer boundary.

---

## 5. Component Blueprint & Element Placement

### Hero Section Architecture
- **Logo:** Top-left placed classic Nike Swoosh (`width: 32px`), aligned with the top navigation grid.
- **Brand Title (`N I K E`):** Positioned at the bottom-left quadrant using a 2x2 character matrix with generous horizontal and vertical gaps.
- **Interactive Carousel / Split Trigger:** A circular floating badge (`--accent-coral`) positioned precisely on the boundary seam between the white canvas and the editorial image, featuring a glowing drop shadow (`0px 8px 24px rgba(255,66,55,0.5)`).

### Navigation & Action Rails
- **Top Sub-Nav:** Minimalist text links (`SHOP`, `MANUFACTURING`) centered in the upper third of the white section.
- **Right Action Panel:**
  - Upper dark box (`#1E2028`) featuring an icon button/search trigger.
  - Lower solid coral block (`#FF4237`) serving as a high-visibility primary call-to-action or pagination anchor.

---

## 6. Motion Mechanics & Interaction Guidelines
- **Transition Triggers:** Hover states on navigation elements, image slide transitions on the central editorial canvas.
- **Easing Physics:** Cubic-bezier (`0.25, 1, 0.5, 1` - smooth outQuint) for layout shifts and image scaling.
- **Durations:**
  - Micro-interactions (hover states, indicator scaling): `200ms`
  - Page/View transitions: `600ms`
