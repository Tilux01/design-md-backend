# Visual Design Specification: Two-Tone Color Palette Showcase

This document provides the exact design specifications to replicate the provided color palette showcase media (consisting of two stacked color blocks, typography, HEX badges, and a branding watermark) as a full-screen, responsive web interface.

## 1. Global Layout & Structure

*   **View:** Full-screen layout (100vw, 100vh), split into two equal horizontal sections or stacked as a vertical flex container.
*   **Total Content Blocks:** 
    1. **Top Section:** Dark background with light text.
    2. **Bottom Section:** Light background with dark text.
*   **Watermark:** Fixed or flex-aligned subtle logo ("DGTL DSNR") positioned at the absolute bottom center of the viewport.

## 3. Typography & Text Styles

The design uses a high-contrast pairing of a **serif/italic display typeface** for the primary titles and a **sans-serif monospace/geometric typeface** for the HEX code badges.

### Primary Titles ("Champion Blue" & "Lavender Tonic")
*   **Style:** Italic Serif
*   **Font Family Recommendation:** 
    *   *Primary:* **Playfair Display** (Italic), **Lora** (Italic), or **Bodoni Moda** (Italic)
    *   *CSS Fallback:* `Georgia, Cambria, "Times New Roman", Times, serif`
*   **Font Weight:** Bold (`700`)
*   **Text Transform:** Title Case (Standard capitalization)
*   **Visual Appearance:** High elegance, traditional editorial feel.

### HEX Code Badges (`HEX CODE: #151130`)
*   **Style:** Clean Sans-Serif / Monospace uppercase
*   **Font Family Recommendation:**
    *   *Primary:* **Inter**, **Space Mono**, or **JetBrains Mono**
    *   *CSS Fallback:* `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
*   **Font Size:** Small (~12px - 14px relative to scale)
*   **Letter Spacing:** Wide tracking (`0.05em` to `0.1em`)
*   **Container Badge Style:**
    *   Rounded pill / rectangle container.
    *   Thin border matching the respective text color with low opacity (approx. 30%–40% alpha).
    *   Internal padding: ~8px vertical, 16px horizontal.
