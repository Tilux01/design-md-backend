# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: High-Tech Editorial Dark Mode Genomics Platform (Combining scientific precision with premium SaaS aesthetics).
- **Visual Density & Whitespace Ratio**: Spacious viewport-driven layout (`100vw` / `100vh`) with generous horizontal padding and a central hero focal point emphasizing 3D interactive graphics.
- **Surface Elevation Model**: Layered glassmorphism utilizing subtle dark translucent surfaces (`rgba(10, 15, 30, 0.6)`), backdrop blur (`blur-xl`), and crisp 1px borders (`rgba(255, 255, 255, 0.08)`) with ambient blue/amber subsurface glow orbs.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase typography, ambient glow orbs behind 3D models, glassmorphism surface layers, minimalist monochrome branding with high-chroma interactive accents.
- **Pill Badge Specification**: Padding `6px 14px`, font-size `0.75rem`, font-weight `600`, tracking `0.05em`, border-radius `9999px`, background translucency `rgba(59, 130, 246, 0.1)`, border width `1px` (`rgba(59, 130, 246, 0.3)`).
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;`.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-blue-400 inline-block"></span>`.
