# DESIGN SPECIFICATION: Kitchen King (Kadhi Chawal Landing Page)

## 1. Global Layout & Viewport
* **Layout Structure:** Full-screen CSS Grid / Flexbox layout.
* **Canvas Size:** 100% width, 100% viewport height (`100vw` × `100vh`).
* **Scrolling:** Non-scrolling/Fixed layout (Single-viewport dashboard feel with a horizontal carousel slider at the bottom).
* **Base Background:** Warm cream/off-white (`#F4F1EA` or `#ECE6DA`) with large, abstract soft-beige diagonal geometric shapes creating depth.

---

## 2. Typography & Fonts

### **Primary Heading Font (Logo & Main Titles):**
* **Font Family:** Geometric/Grotesque Sans-Serif (e.g., *Montserrat*, *Inter*, or *Helvetica Neue*).
* **Fallback Stack:** `sans-serif`
* **Weight:** Bold / Extra Bold (700–900).

### **Display/Hero Title ("KADHI CHAWAL"):**
* **Font Family:** Heavy Serif or Display Font (e.g., *Playfair Display*, *Bodoni Moda*, or *Cinzel*).
* **Fallback Stack:** `serif`
* **Weight:** Ultra-Bold / Black (900).
* **Transform:** Uppercase.
* **Tracking/Letter-spacing:** Tight/Condensed.

### **Body & UI Font (Metadata, Descriptions, Navigation):**
* **Font Family:** Clean Sans-Serif (e.g., *Inter*, *Roboto*, or *System-UI*).
* **Fallback Stack:** `sans-serif`
* **Weight:** Regular (400) for descriptions, Medium (500) for navigation and tabs.

---

## 3. Component Breakdown & Styling

### **A. Navigation Header (Top)**
* **Position:** Absolute / Fixed at the top (`z-index: 10`).
* **Layout:** Flexbox, Space-between.
* **Left Element:**
  * Brand Logo/Text: `"KITCHEN KING *"` in a bold, tracked-out sans-serif font.
* **Right Elements:**
  * Search Icon (Magnifying glass).
  * Hamburger Menu Icon (3 horizontal lines).
  * Color: Dark charcoal/black (`#1A1A1A`).

---

### **B. Hero Center Section ("01 / GHAR JAISA COMFORT")**
* **Tagline/Subheading ("01 / GHAR JAISA COMFORT"):**
  * Font Size: Small (`~12px`), tracked out.
  * Color: Muted gray-brown.
* **Main Hero Title ("KADHI CHAWAL"):**
  * Layout: Stacked vertically ("KADHI" on top, "CHAWAL" directly beneath).
  * Font Size: Massive display scale (`~5vw` to `~7vw`).
