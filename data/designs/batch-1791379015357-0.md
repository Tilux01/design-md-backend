# Design Specification: Dapper & Amp Homepage

This specification outlines the exact design details required to build a pixel-perfect, full-screen responsive clone of the provided e-commerce homepage, excluding any mockup browser/window frames.

---

## 1. Global Styles & Layout

*   **View:** Full-screen (`width: 100vw; min-height: 100vh;`).
*   **Background Color (Main):** `#FFFFFF` (White) for the header, shifting to a gradient/solid tone for the hero section.
*   **Hero Background:** Soft lavender/periwinkle gradient.
    *   *Top/Left tint:* `rgb(190, 190, 220)`
    *   *Bottom/Right tint:* `rgb(150, 150, 200)`
*   **Container Max-Width:** Fluid layout, spanning full viewport width with standard side padding (`max-width: 1440px` centered for ultra-wide screens).

---

## 2. Typography & Fonts

### Font Family Stack
*   **Primary Font:** `Inter`, `Helvetica Neue`, `Arial`, sans-serif
*   **Fallback Stack:** `system-ui`, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, sans-serif

### Type Hierarchy
| Element | Font Size | Font Weight | Letter Spacing | Color |
| :--- | :--- | :--- | :--- | :--- |
| **Logo** (`dapper & amp`) | `20px` / `1.25rem` | `600` (Semi-bold) | `-0.03em` | `#111111` |
| **Nav Links** | `13px` / `0.8125rem` | `400` (Regular) | `normal` | `#333333` |
| **Hero Supertitle** (`YOUR`) | `16px` / `1rem` | `500` (Medium) | `0.15em` | `rgba(255, 255, 255, 0.85)` |
| **Hero Main Title** (`EVERDAY`) | `clamp(4rem, 10vw, 11rem)` | `800` (Extra Bold) | `-0.02em` | `#FFFFFF` |
| **Hero Subtitle** (`OUTFITS`) | `18px` / `1.125rem` | `600` (Semi-bold) | `0.3em` | `rgba(255, 255, 255, 0.9)` |
| **Bottom Left Tag** | `11px` / `0.6875rem` | `500` (Medium) | `0.1em` | `rgba(255, 255, 255, 0.7)` |
| **Bottom Right Tag** | `11px` / `0.6875rem` | `500` (Medium) | `0.05em` | `rgba(255, 255, 255, 0.7)` |

---

## 3. Header & Navigation Component

*   **Height:** `80px`
*   **Layout:** Flexbox, `space-between` alignment with 3 primary sections:
    1.  **Left:** Search icon (thin stroke, ~`20px` size).
    2.  **Center:** Brand Logo (`dapper & amp` in lowercase, modern bold sans-serif).
    3.  **Right:** Shopping cart icon + Hamburger menu icon (spaced evenly, ~`18px`–`20px`).

### Sub-Navigation Bar
*   **Position:** Directly below the top header bar, centered horizontally.
*   **Items:** 
    *   `Best sellers`
    *   `Recovery`
    *   `New in`
    *   `Clothing` *(active/bold state or standard)*
    *   `Trending`
    *   `Shoes`
    *   `Accessories`
    *   `Brands`
*   **Spacing:** `32px` gap between links.
*   **Hover State:** Subtle opacity shift (`0.7`) or color darken to `#000000`.

---

## 4. Hero Section Component

*   **Height:** `calc(100vh - 120px)` (fills remaining viewport below the header).
*   **Layout:** Relative positioning container with absolute-positioned typographic layers and a centered foreground subject.

### Layering Structure (Z-Index Hierarchy):
1.  **Background (`z-index: 1`):** Lavender gradient container.
2.  **Typography Background (`z-index: 2`):** Large oversized text (`EVERDAY`) positioned centrally behind the model.
3.  **Model/Subject (`z-index: 3`):** Cutout image of a male model wearing a grey crewneck sweatshirt, positioned centrally, overlapping the background typography.
4.  **Foreground Typography/UI (`z-index: 4`):** 
    *   Top-left of hero: `"YOUR"`
    *   Bottom-right of hero: `"OUTFITS"`
    *   Bottom-left badge: `"NEW SPRING ESSENTIALS"`
    *   Bottom-right badge: `"FREE SHIPPING OVER €70"`

---

## 5. Animation & Interactive Behaviors (If Applicable)

*   **Page Load / Entry Animation:**
    *   **Hero Text:** Fade in with a slight upward translateY (`20px` -> `0`) over `0.8s` cubic-bezier(0.16, 1, 0.3, 1).
    *   **Model Image:** Scale-up subtle zoom effect from `0.98` to `1.0` over `1.2s`.
*   **Hover States:**
    *   Nav links transition color instantly (`0.2s ease`).
    *   Icons scale up slightly (`1.05`) on mouseover.
