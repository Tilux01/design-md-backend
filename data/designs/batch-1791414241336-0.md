# design.md: Cute Character Dashboard (CC)

## 1. Overview & General Layout
* **Viewport:** Mobile (e.g., iPhone 13/14 Pro dimensions: `390px` × `844px`).
* **Background:** Off-white / light cream (`#FAF9F5` or `#F7F5F0`).
* **Layout Structure:** Flexbox / CSS Grid column layout centered inside a vertical card.
  * **Header:** Purple brand card with mascot character (`CC`) and arms/face.
  * **Dashboard Grid:** 2×2 grid of stat/action cards (Mint, Blue, Lime Green, Pink).
  * **Bottom Action:** Full-width purple pill button with an arrow icon.
  * **Mascot Elements:** Legs positioned at the bottom outside/overlapping the main content container.

---

## 2. Typography & Fonts

### **Primary Font Family**
* **Target Font:** `Quicksand`, `Poppins`, or `Inter` (Rounded sans-serif style is essential).
* **Fallback Stack:** `font-family: 'Quicksand', 'Poppins', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;`

### **Text Styles**
* **Header Brand Text ("CC"):**
  * **Size:** `32px` to `36px`
  * **Weight:** `Bold` (`700`)
  * **Color:** White (`#FFFFFF`)
  * **Alignment:** Centered
* **Card Big Numbers (e.g., 750, 507, 943):**
  * **Size:** `24px` to `28px`
  * **Weight:** `Bold` (`700`)
  * **Color:** Dark charcoal/black (`#1E1E1E` or `#121212`)
* **Card Sub-labels (e.g., "129 ELO"):**
  * **Size:** `13px` to `14px`
  * **Weight:** `Semi-Bold` (`600`)
  * **Color:** Dark charcoal with opacity or solid dark tone.
* **Bottom Button Text ("Find match..."):**
  * **Size:** `16px`
  * **Weight:** `Medium` / `Semi-Bold` (`500`/`600`)
  * **Color:** White (`#FFFFFF`)

## 4. Component Breakdown & Styling

### **A. Top Brand Header ("CC" Mascot Banner)**
* **Shape:** Rounded rectangle with friendly curved top corners.
* **Background:** Deep Purple (`#5B43B7`).
* **Border Radius:** `24px` (top), or fully rounded capsule shape.
* **Content:**
  * Centered text **"CC"** in bold white.
  * **Mascot Details:** Simple line-art arms extending outward from the sides of the purple block. A minimal smiling face expression inside.

### **B. The 2×2 Grid Cards**
* **Grid Properties:** `display: grid; grid-template-columns: repeat(2, 1fr); gap: 12px;`
* **Card Common Properties:**
  * **Border Radius:** `20px`
  * **Padding:** `16px`
  * **Shadow:** Soft drop shadow (`box-shadow: 0px 4px 12px rgba(0, 0, 0, 0.05)`)
* **Card 1 (Mint):** Top number + small sub-label stacked vertically.
* **Card 2 (Blue):** Top number + small sub-label.
* **Card 3 (Lime):** Top number + small sub-label.
* **Card 4 (Pink):** Text label ("Start matching") aligned vertically with a small icon badge in the top right corner.

### **C. Bottom Action Button ("Find match...")**
* **Shape:** Full-width capsule / pill button.
* **Background:** Deep Purple (`#5B43B7`).
* **Height:** `56px`
* **Border Radius:** `28px`
* **Content:** Left-aligned text ("Find match...") and a right-aligned forward arrow/icon (`>`).

### **D. Mascot Legs (Bottom Floating Elements)**
* **Style:** Minimalist cartoon legs hanging down from beneath the main UI components.
* **Color:** Dark grey outline / fill matching the arm strokes.

## 5. Animation & Interaction Specifications (Micro-interactions)

* **Hover / Tap States (Cards):**
  * `transform: scale(0.98);` on active press.
  * Smooth transition: `transition: transform 0.2s cubic-bezier(0.4, 0, 0.2, 1);`
* **Bottom Button Hover:**
  * Slight elevation increase (`box-shadow: 0px 6px 16px rgba(91, 67, 183, 0.3)`) and brightness shift.
* **Entrance Animation (Page Load):**
  * Staggered fade-in and slide-up for the grid cards:
    * `animation: slideUp 0.5s ease forwards;`
    * `animation-delay: calc(var(--index) * 0.1s);`
