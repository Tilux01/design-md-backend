# Design Specification: "wehu" Task Management Dashboard

This document provides the precise layout, visual style, typography, and component specifications required to build a 1:1 clone of the provided "wehu" task management dashboard interface.

---

## 1. Global Layout & Structure

*   **View Type:** Full-screen application layout (fluid width/height, non-contained or edge-to-edge frame).
*   **Structure:** Two-column master layout:
    1.  **Sidebar (Left):** Fixed width (approx. `260px`), containing branding, primary navigation, record sections, and system links.
    2.  **Main Content Area (Right):** Fluid remaining width, containing the top header/search bar, contextual date/view switcher, and a multi-column Kanban board.

---

## 2. Color Palette

The interface uses a frosted-glass, pastel-accented design system with subtle gradients and soft drop-shadows.

### Neutrals & Backgrounds
*   **App Background:** Soft off-white to pale lilac gradient (`#F8F9FE` to `#F3F4F9`).
*   **Sidebar Background:** Semi-transparent white/lilac glassmorphism effect (`rgba(255, 255, 255, 0.7)`).
*   **Card Background (Base):** Solid pure white (`#FFFFFF`) with subtle rounded corners (`border-radius: 16px`).
*   **Primary Text (Dark):** Deep charcoal/navy (`#1E2235`).
*   **Secondary Text (Muted):** Cool grey (`#7C839B`).
*   **Borders / Dividers:** Ultra-light grey/blue (`#EAEFF5`).

### Accent & Brand Colors
*   **Primary Brand Color (Purple/Indigo):** `#5E5CE6` (used for active states, logos, primary buttons).
*   **Badge Colors (Tags):**
    *   *Blue Tag:* Background `#E1EFFE`, Text `#1E429F`
    *   *Green Tag:* Background `#DEF7EC`, Text `#03543F`
    *   *Orange/Peach Tag:* Background `#FDF6B2`, Text `#723B13`
    *   *Purple Tag:* Background `#EDEBFE`, Text `#3C3694`
    *   *Pink Tag:* Background `#FCE8E6`, Text `#9B1C1C`

---

## 3. Typography

*   **Primary Font Family:** `Inter`, `SF Pro Display`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`.
*   **Fallback Stack:** If `Inter` or system fonts fail to load, fall back to generic `sans-serif`.
*   **Font Weights Used:** Regular (`400`), Medium (`500`), Semi-bold (`600`).

### Hierarchy & Sizes
*   **Page Title (e.g., "Welcome, Brooklyn Simmons"):** 
    *   Size: `20px` / `24px`
    *   Weight: Semi-bold (`600`)
    *   Color: `#1E2235`
*   **Section Headers (e.g., "MAIN", "RECORDS", "May"):** 
    *   Size: `11px`
    *   Weight: Semi-bold (`600`)
    *   Letter-spacing: `0.05em` (uppercase)
    *   Color: `#9CA3AF`
*   **Navigation & Menu Items:** 
    *   Size: `13px` / `14px`
    *   Weight: Medium (`500`)
    *   Color: `#4B5563` (Active: `#5E5CE6`)
*   **Card Headings:** 
    *   Size: `14px`
    *   Weight: Semi-bold (`600`)
    *   Color: `#1E2235`
*   **Body Text & Notes:** 
    *   Size: `12px`
    *   Weight: Regular (`400`)
    *   Color: `#6B7280`

---

## 4. Component Breakdown

### A. Sidebar (Left)
*   **Brand Header:**
    *   Logo mark: Rounded square icon containing a stylized lowercase 'w' in white on a vibrant purple gradient background (`#5E5CE6`).
    *   Brand Name: "wehu" in bold, dark lowercase typography.
    *   Collapse Icon: Outline icon inside a subtle square container on the top right of the sidebar.
*   **Active Tab Pill ("Tasks"):**
    *   Highlighted with a light purple/white background capsule, active purple dot indicator, bold text, and a counter badge (`16`) on the right.
*   **Navigation Groups:**
    *   *MAIN:* Dashboard, Schedule, Note, Products, Report.
    *   *RECORDS:* Team, Clients (with a dropdown chevron).
    *   *SYSTEM:* Settings, Support.
    *   *Icons:* Minimalist 16px line-art icons preceding every navigation item (e.g., grid for dashboard, calendar for schedule, notes icon, folder for products, chart for report, users for team/clients, gear for settings, headset for support).

### B. Top Header Bar
*   **Greeting Section:** Left-aligned text reading "Welcome," (muted) followed by "Brooklyn Simmons" (bold dark text).
*   **Global Search Bar:** 
    *   Pill-shaped input field with a search magnifying glass icon on the left.
    *   Placeholder text: "Find something".
    *   Background: `#F1F3F9`.
*   **Collaborator Avatars:** 
    *   A horizontal stack of 5 circular profile photos of team members on the far right of the top bar.

### C. Board Controls Bar
*   **Date Indicator:** Displays current month/date ("May" large, subtitle "Today is Wednesday, May 10th, 2023").
*   **View Switcher:** Dropdown component labeled "Board - Daily Tasks" with a dropdown chevron.

### D. Kanban Board Columns
The board consists of three distinct vertical status columns:
1.  **Todo list** (Counter: active/implicit)
2.  **In Progress**
3.  **In Review**

Each column features:
*   Column header with status title, an "Add" (`+`) button, and a triple-dot options menu.
*   Stacked interactive task cards with varying internal layouts (tags, checklists, progress bars, attached screenshots, comments/likes counters, and assignee avatars).

---

## 5. Image & Asset Descriptions

*   **App Logo:** A rounded rectangle badge featuring a clean, modern vector 'w' symbol against a solid indigo/purple backdrop.
*   **User Avatars (Sidebar & Header):** Circular portrait photographs of diverse professionals smiling or posing neutrally against soft-focus backgrounds. Used to represent project assignees and team members.
*   **Task Card Attachment Thumbnail (In Progress column):** A miniature UI preview screenshot of a dashboard analytics page containing colorful UI cards, charts, and data grids, displayed inside a bordered container with an inner shadow.
