# Design Specification: Breadberries Mango Product Landing Page

This document provides the exact design specifications, layout hierarchy, typography, color palette, and interactive animations required to build a pixel-perfect, full-screen responsive clone of the provided website media.

---

## 1. Global Layout & Structure

*   **View Mode:** Full-screen immersive viewport (`100vw` width, `100vh` height minimum).
*   **Background:** 
    *   Radial or linear gradient transitioning from warm orange/tangerine to deeper amber edges (`#f37322` to `#e85d04` range).
    *   Includes soft atmospheric lighting effects, floating mango slices, and subtle drop shadows behind typography and product elements to create depth.
*   **Grid System:** Asymmetric hero layout with absolute positioning for floating elements, utilizing CSS Flexbox and Grid for responsive adaptation.

| Role | Color Name | Hex Code / Value | Usage |
| :--- | :--- | :--- | :--- |

## 3. Typography & Font Stack

Because the exact brand font is proprietary, use modern geometric sans-serif typefaces with the following fallback strategy:

### Primary Display Font (Headlines: "MANGO")
*   **Font Family:** `Montserrat`, `Inter`, `Helvetica Neue`, `Arial`, sans-serif
*   **Weight:** `900` (Black / Ultra Bold)
*   **Style:** Uppercase, wide letter-spacing.

### Body & UI Font (Navigation, Descriptions, Pricing)
*   **Font Family:** `Inter`, `Roboto`, `-apple-system`, `sans-serif`
*   **Weights:** 
    *   Navigation / Links: `500` (Medium)
    *   Product Titles: `700` (Bold)
    *   Descriptions: `400` (Regular)

## 5. Animation & Interaction Specifications (Developer Notes)

To capture the high-end interactive feel implied by the meme (where the developer's soul leaves their body trying to code it):

1.  **Parallax Mouse Movement (`mousemove`):**
    *   The floating mango slices, background typography, and central can must respond to cursor movement with slight depth offsets (using CSS variables and vanilla JS or Framer Motion).
2.  **Liquid Pour Simulation / Lottie Animation:**
    *   The liquid pouring out of the can should ideally be a smooth SVG path morph or Lottie animation loop.
3.  **Hover States:**
    *   Navigation pills scale up smoothly (`transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1)`).
    *   CTA button gains a soft glowing box-shadow on hover.
4.  **Entrance Animation (Page Load):**
    *   *Fade-in & Slide-up:* Typography slides up from `translateY(30px)` with `opacity: 0` to `1`.
    *   *Can Zoom-in:* The central can scales in from `scale(0.8)` to `scale(1)` with a spring physics easing curve.
