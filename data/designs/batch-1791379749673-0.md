# UI Design Specification: Bubble Menu

## 1. Global & Layout
- **Layout Model**: Full-screen flex container centered both horizontally and vertically.
- **Background**: 
  - Primary color: `#E3EEF9` (Soft pastel blue).
  - Subtle grid overlay: Light semi-transparent grid lines (`rgba(255, 255, 255, 0.4)` or similar faint stroke) spaced evenly to create a blueprint aesthetic.
- **Header Text**:
  - Small tracker text: "How to Create"
  - Main title: "Bubble Menu"

---

## 2. Typography & Fonts
- **Primary Font Family**: Inter, SF Pro Display, or a clean modern geometric sans-serif (e.g., *Plus Jakarta Sans* or *Outfit*).
- **Fallbacks**: `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif`.
- **Header Styles**:
  - **"How to Create"**: 
    - Font size: ~16px – 18px
    - Weight: Medium (500)
    - Color: `#1E1E1E` (Dark charcoal/black)
  - **"Bubble Menu"**: 
    - Font size: ~56px – 64px
    - Weight: Bold (700)
    - Color: Deep vibrant blue (`#0A58CA` or `#0055FF`)
- **Menu Item Label ("Account")**:
  - Font size: ~12px – 14px
  - Weight: Semi-bold (600)
  - Color: Pure White (`#FFFFFF`)

---

## 3. Component Breakdown: The Bubble Menu

### Container Shape & Base State
- **Shape**: Pill-shaped horizontal container (rounded rectangle with fully rounded capsule ends).
- **Dimensions (Approximate scale)**:
  - Width: ~450px – 500px
  - Height: ~75px – 85px
- **Styling & Gradients**:
  - Background fill: Smooth linear gradient from a mid-blue (`#0062FF`) to a deeper royal blue (`#0042D9`).
  - Drop shadow: Soft, diffused shadow providing depth against the light blue background (`0px 16px 32px rgba(0, 85, 255, 0.25)`).

### Menu Items & Layout
- **Structure**: Flexbox row evenly distributing the items horizontally inside the capsule.
- **Inactive Items (Home & Chart icons)**:
  - Color: White with low opacity (~0.5 – 0.6) or muted icon style.
  - Size: Standard icon viewport (~24px).
- **Active Expanded Item ("Account")**:
  - Highlighted via an overlapping circular/pill "bubble" that expands outward.
  - **The "Bubble" Effect**:
    - A distinct circular container overlapping the right side of the main pill.
    - Features a subtle glassmorphism/inset stroke effect: Light border ring (`rgba(255, 255, 255, 0.4)`) creating a glossy lens illusion.
    - Contains a stacked layout:
      1. **Icon**: Profile/User icon (White, ~28px).
      2. **Label**: "Account" (White, 12px, tracking/letter-spacing slightly applied).

---

## 4. Footer Promo Pill
- **Position**: Fixed or flex-aligned near the bottom center of the viewport.
- **Shape**: Rounded capsule (pill shape).
- **Styling**:
  - Background: Semi-transparent frosted glass (`rgba(200, 215, 235, 0.6)`).
  - Border/Shadow: Soft inner/outer blur.
- **Content**:
  - Left: Logo icon + `bundle.webvizion.co`
  - Right: `150+ Web Design Assets`
  - Font: Small sans-serif (~12px, dark gray text color `#333333`).

---

## 5. Animation & Interaction Specs (State Transition)
If building an interactive clone (e.g., in React/Framer Motion):
- **Default State**: Only icons are visible inside a compact pill, or one default item is active.
- **Hover / Click Transition (The Bubble Expansion)**:
  - **Spring Physics**: Use a bouncy spring transition (`stiffness: 300, damping: 25`).
  - **Morphing Effect**: When an item is selected, the active background pill morphs/slides to the target item, expanding into the rounded "bubble" shape with a smooth scale-up animation.
  - **Text Reveal**: The label ("Account") fades in and slides up slightly (`opacity: 0 -> 1`, `y: 4px -> 0px`) concurrently with the bubble expansion.
