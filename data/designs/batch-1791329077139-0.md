# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Clean Enterprise Financial SaaS with Modern Minimalist Dashboard aesthetics.
- **Visual Density & Whitespace Ratio**: High-density UI layout optimized for data visualization and financial tracking, utilizing 16px to 24px padding matrices with strict card containment and high whitespace contrast against a soft pastel-green canvas background.
- **Surface Elevation Model**: Layered surface hierarchy consisting of a soft pale mint/sage canvas background (`#EBF3EE`), pure white card containers (`#FFFFFF`), neutral light gray secondary containers (`#F4F7F5`), and subtle translucent pill overlays with light neutral borders (`#E2E8F0`).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase pill badges, emerald financial status meters, subtle glassmorphism cards, interactive sparkline charts.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `12px`, font-weight `600`, tracking `0.05em`, border-radius `9999px`, background translucency `bg-emerald-50`, border width `1px` (`border-emerald-200`).
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;`
  - Sparkle (✦) -> Use `&#10022;`
  - Status Dot (●) -> Use `<span className="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`

# 7. Motion Mechanics, Framer Motion & CSS Animations
- **Motion Principles**: Smooth page transitions, micro-interactions with 200ms cubic-bezier easing (`0.16, 1, 0.3, 1`), staggered card entrance animations.
- **Framer Motion Variants Code**:
```jsx
export const containerVariants = {
```
