# Design Specification & Frontend System Architecture

---

## 1. Design Philosophy & Overall Aesthetic
* **Brand Archetype:** High-performance e-commerce marketplace specializing in cutting-edge tech, wearables, and audio hardware.
* **Visual Density:** High-density, content-driven layout optimized for browsing structured product grids with minimal friction.
* **Theme Balance:** Immersive dark-mode first design utilizing deep charcoal/slate surfaces (`#111111`, `#1c1c1e`) contrasted with vibrant high-visibility neon/lime action elements (`#00e676` / `#22c55e`).
* **Whitespace Balance:** Tight grid gutters (`12px` to `24px`) with generous container margins (`40px+` outer padding) providing a clean, professional retail hierarchy.

## 3. Typography System & Hierarchy
* **Font Family:** Inter / system-ui sans-serif stack for ultimate readability at small scales.

| Level | Size (rem/px) | Weight | Line-Height | Tracking |
| :--- | :--- | :--- | :--- | :--- |
| **Heading 1** | `1.75rem / 28px` | Bold (700) | `1.2` | `-0.02em` |
| **Heading 2** | `1.25rem / 20px` | Semi-Bold (600) | `1.3` | `-0.01em` |
| **Body Primary**| `0.875rem / 14px` | Regular (400) | `1.5` | `normal` |
| **Caption / Price** | `0.75rem / 12px` | Medium (500) | `1.4` | `0.02em` |
| **Badge / Pill** | `0.625rem / 10px` | Bold (700) | `1` | `0.08em` (Uppercase) |

## 4. Layout Architecture & Spatial Grid
* **Container Max-Width:** `1280px` centered with fluid horizontal padding (`16px` mobile, `32px` desktop).
* **Grid Spacing Scale:** `4px`, `8px`, `12px`, `16px`, `24px`, `32px`.
* **Section Sequence:**
  1. Global Sticky Navigation / Header Bar
  2. Hero Banner Showcase
  3. Trending Hardware Grid (4-column layout)
  4. Promotional Banner Callout
  5. Secondary Category Grids (Audio, Wearables)

---

## 5. AI Design Traits, Micro-Badges & Special Glyphs
* **Pill Badges:** High-tracking uppercase tags (e.g., `NEW`, `HOT`, `SALE`).
  * **CSS Specs:** `padding: 2px 8px`, `font-size: 10px`, `font-weight: 700`, `letter-spacing: 0.08em`, `border-radius: 4px`, `text-transform: uppercase`.
* **Symbol Safety (Unicode & Entities):**
  * Sparkle: `✦` (`&#10022;`)
  * Em-dash: `—` (`&mdash;`)
  * Status Dot: `●` (`&#9679;`)

## 6. Structural DOM Layout Blueprints & Component Specs

### Product Card Component (JSX)
```jsx
export function ProductCard({ title, price, imageUrl, badge }) {
  return (
    <div className="relative flex flex-col bg-[#161616] border border-white/10 rounded-lg p-4 shadow-card hover:border-[#00e676]/40 transition-all duration-200">
      {badge && (
        <span className="absolute top-3 right-3 bg-[#00e676] text-black text-[10px] font-bold px-2 py-0.5 rounded uppercase tracking-wider">
          {badge}
        </span>
      )}
      <div className="w-full h-40 bg-black/40 rounded-md flex items-center justify-center mb-4 overflow-hidden">
        <img src={imageUrl} alt={title} className="object-cover h-full w-full opacity-90 hover:scale-105 transition-transform duration-300" />
      </div>
      <h3 className="text-white text-sm font-medium mb-1 truncate">{title}</h3>
      <div className="flex items-center justify-between mt-auto pt-2">
        <span className="text-white font-semibold text-sm">${price}</span>
        <button className="bg-[#00e676] hover:bg-[#00c853] text-black text-xs font-bold px-3 py-1.5 rounded transition-colors">
          Add to Cart
        </button>
      </div>
    </div>
  );
}
```

## 8. Accessibility (a11y) & WCAG Contrast Audit
* **Primary Text (`#ffffff`) on Base Surface (`#161616`):** Contrast ratio > `15:1` (Passes WCAG AAA).
* **Muted Text (`#9ca3af`) on Base Surface (`#161616`):** Contrast ratio > `4.5:1` (Passes WCAG AA).
* **Focus Ring Spec:** 
  ```css
  :focus-visible {
    outline: 2px solid #00e676;
    outline-offset: 2px;
  }
  ```
