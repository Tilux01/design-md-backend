# Design Specification: Glassmorphic Surface Concepts (Frosted, Clear, Blur)

---

## 1. Design Philosophy & Overall Aesthetic
- **Primary Mood & Archetype:** Modern, experimental, minimalist, immersive glassmorphic design system. Evokes a futuristic, atmospheric feel inspired by modern operating system design languages (iOS, One UI).
- **Visual Density & Whitespace:** Medium-high spaciousness. Elements rely on heavy backdrop blur to separate visual layers from the underlying complex, high-detail background imagery.
- **Theme Balance:** Dark-mode dominant aesthetic with high transparency values. Texture is paramount, utilizing fine surface grain, chromatic dispersion simulation, and high-diffusion blurring.

---

## 2. Color Palette & Design Tokens

### Token Breakdown
- **Surface Dark Frosted:** `rgba(20, 20, 20, 0.45)` with `backdrop-filter: blur(40px) saturate(180%)`
- **Surface Clear iOS:** Multi-stop optical distortion layer with refractive edge lighting.
- **Surface Blur One UI:** Warm golden-brown translucent gradient `rgba(60, 45, 35, 0.55)` with heavy gaussian blur.
- **Text Primary:** Pure white `#FFFFFF` (100% opacity for headings, 85% for subheadings).
- **Borders & Highlights:** Inner specular borders `rgba(255, 255, 255, 0.25)` top-to-bottom subtle gradient.

## 7. Accessibility (a11y) & WCAG Contrast Audit
- **Text Contrast Ratios:**
  - White text (`#FFFFFF`) on Frosted/Blur dark backdrops: **> 7.5:1** (Exceeds WCAG AAA requirements).
  - Muted text (`rgba(255,255,255,0.65)`) on dark tinted glass surfaces: **> 4.6:1** (Meets WCAG AA requirements).
- **Focus Ring Specifications:**
  ```css
  :focus-visible {
    outline: none;
    box-shadow: 0 0 0 3px rgba(255, 255, 255, 0.8), 0 0 0 6px rgba(0, 122, 255, 0.6);
  }
  ```
