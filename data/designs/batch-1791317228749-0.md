# 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Brand Archetype**: Premium luxury automotive showcase. The design projects exclusivity, technological precision, and high performance through a dark, cinematic canvas.
- **Visual Density**: Low density, high whitespace and breathing room, focused on single-focus hero imagery and clean typography.
- **Theme Balance**: Dark mode exclusive. It employs a deep navy-to-midnight blue gradient (`#050811` to `#0A1128`) layered with ambient radial lighting to frame the vehicle.
- **Texture & Depth Architecture**: Flat structural elements layered over atmospheric volumetric lighting, subtle drop shadows, and delicate hairline white/cyan borders (`rgba(255,255,255,0.08)`).

# 3. Typography System & Hierarchy

- **Font Families**: 
  - Headings & UI: `Inter`, system-ui, -apple-system, sans-serif
  - Brand Watermark / Hero Typography: Geometric Sans-Serif (`Helvetica Neue`, `Arial Black`)
- **Scale Breakdown**:
  - **Nav Links / Micro-labels**: `11px` / `0.6875rem`, Font-Weight: `500`, Line-Height: `1.2`, Tracking: `0.15em` (`uppercase`)
  - **Hero Watermark (BMW)**: `180px` / `11.25rem`, Font-Weight: `900`, Line-Height: `1`, Tracking: `0.05em`
  - **Body / Descriptive**: `14px` / `0.875rem`, Font-Weight: `400`, Line-Height: `1.5`, Tracking: `normal`

# 4. Layout Architecture & Spatial Grid

- **Container Max-Width**: `1440px` centered with fluid horizontal padding (`clamp(24px, 5vw, 64px)`).
- **Section Sequence**:
  1. Top Navigation Bar (Logo centered/left-aligned with distributed utility links)
  2. Hero Cinematic Display (Watermark typography background, dynamic vehicle cutout, ambient vignette)
  3. Interactive Thumbnail Carousel (Horizontal flex layout for vehicle color/trim variants)
- **Stacking Order (Z-Index)**:
  - Canvas background: `z-0`
  - Watermark typography: `z-1`
  - Hero Vehicle & Vignette: `z-10`
  - Navigation & Interactive Thumbnails: `z-30`

# 5. AI Design Traits, Micro-Badges & Special Glyphs

- **Visual Hallmarks**: High-tracking uppercase navigation, outline-only vector typography watermark, glowing radial spotlights behind primary focal objects, and glassmorphic preview cards.
- **Badge Specifications**:
  - Padding: `4px 12px`
  - Font-Size: `11px`
  - Font-Weight: `600`
  - Letter-Spacing: `0.15em`
  - Border-Radius: `9999px` (Full pill)
  - Border: `1px solid rgba(255, 255, 255, 0.2)`
- **Symbol Safety**: Utilize standard Unicode entities for decorative indicators (`●`, `—`) or CSS pseudo-elements for clean asset independence.

# 7. Motion Mechanics, Framer Motion & CSS Animation Code

- **Animation Triggers**: Initial page load reveal (staggered fade-up), hover scaling on thumbnails, and smooth car variant cross-fading.
- **Timing & Physics**: Spring physics for card selection (`stiffness: 300, damping: 30`), cubic bezier for fades (`cubic-bezier(0.16, 1, 0.3, 1)`).
