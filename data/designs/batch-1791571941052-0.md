# UI Design Specification: Financial Dashboard (Neumorphism / Glassmorphism)

This document provides a comprehensive design specification for recreating the financial dashboard shown in the reference image. The style blends **neumorphism** (soft shadows, inset elements, extruded components) with **glassmorphism** (translucent frosted glass overlays, subtle borders).

---

## 1. Global Layout & Structure

*   **Viewport:** Fullscreen (100vw × 100vh), centered layout.
*   **Base Background:** Soft light gray (`#E8ECEF` to `#F0F3F6`), with subtle directional lighting.
*   **Main Container:** Rounded rectangular card filling the screen with generous padding and a prominent drop shadow (`box-shadow: 0 20px 40px rgba(0, 0, 0, 0.08)`).
*   **Layout Grid:** Two-column structural divide:
    *   **Sidebar (Left):** Fixed width (~240px), housing the branding and primary navigation links.
    *   **Main Content Area (Right):** Flexible grid layout (approx. 3 columns of cards) displaying financial metrics, interactive charts, a virtual card, dispute inbox, and transaction tables.

---

## 2. Typography & Fallback Fonts

The interface relies on a clean, modern sans-serif typeface family characterized by high legibility at small sizes and rounded numeric glyphs.

*   **Primary Font Family:** Inter, SF Pro Display, Roboto, system-ui, -apple-system, sans-serif.
*   **Font Fallback Chain:** `font-family: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;`
*   **Hierarchy:**
    *   **Dashboard Title / Headers:** 20px – 24px, Semi-bold (`font-weight: 600`), Dark Slate (`#1A202C`).
    *   **Card Metrics / Values:** 18px – 28px, Bold (`font-weight: 700`), Dark Slate (`#1A202C`).
    *   **Body Text / Labels:** 12px – 14px, Regular / Medium (`font-weight: 400` to `500`), Muted Gray (`#718096`).
    *   **Microcopy / Badges:** 10px – 11px, Medium (`font-weight: 500`).

---

## 3. Color Palette

*   **Background / Canvas:** `#EEF2F6`
*   **Surface Cards (Neumorphic Raised):** `#FFFFFF` with dual shadows (`box-shadow: -5px -5px 15px rgba(255, 255, 255, 0.8), 5px 5px 15px rgba(174, 174, 192, 0.2)`)
*   **Text Primary:** `#1E293B` (Dark Blue-Gray)
*   **Text Secondary / Muted:** `#94A3B8` (Cool Gray)
*   **Brand / Accent Blue:** `#3B82F6` (Electric / Royal Blue)
*   **Success / Growth Green:** `#10B981` (Emerald Green)
*   **Chart Colors:**
    *   Blue Line/Bar: `#3B82F6`
    *   Orange Line/Bar: `#F59E0B`
    *   Purple/Pink Accent: `#EC4899`

---

## 4. Component Breakdown

### A. Left Sidebar
*   **Logo Area:** Top-left containing a rounded square icon with a dual-chevron abstract logo in vibrant blue (`#3B82F6`), paired with the bold title **"Overview"**.
*   **Search Bar:** Pill-shaped input field with a search icon and placeholder text (`Search merchant or ID...`) alongside an action plus (`+`) icon.
*   **Navigation Menu:** Vertical list of navigation items with icons and text labels.
    *   *Active Item:* "Overview" (highlighted with a soft inset pill background and primary blue text).
    *   *Inactive Items:* Aervice, Cards, Transactions, Limits (repeated), Security, Reports (repeated), Settings.
    *   *Icon Styling:* Monochromatic stroke icons in muted gray, shifting to primary blue on active states.

### B. Top Header Bar
*   **User Context:** Displays breadcrumb/workspace context (`My overview / www.verdiange`), notification indicators (`1`, `0`), and an avatar thumbnail on the far right.

### C. Main Content Grid (Row 1)

#### 1. Virtual Card Component (Glassmorphism)
*   **Visual Style:** Translucent frosted glass card (`background: rgba(255, 255, 255, 0.4)`, `backdrop-filter: blur(12px)`, `border: 1px solid rgba(255, 255, 255, 0.6)`).
*   **Content:**
    *   Chip icon (metallic silver/gold gradient chip representation).
    *   Contactless payment symbol.
    *   Masked card number (`€8** 1357` and `**** 31357`).
    *   Status label: **"Virtual card ready"**.
    *   Action Button: Pill-shaped primary blue button with white text: **"Reveal details"**.
*   **Thumbnail Row:** Below the main card, a row of 4 miniature stacked debit card variations showing different color themes (purple, dark blue, white, abstract patterns).

#### 2. Metrics Cards (Balance, Spend, Rewards)
*   **Layout:** Three side-by-side metric containers with soft raised neumorphic shadows.
    *   **Balance:** Label "Balance", value `€8,910.20`, growth indicator `+2.0% WoW` in green.
    *   **Spend:** Label "Spend", value `€1,120.05`, growth indicator `+2.0% WoW`.
    *   **Rewards:** Label "Rewards", percentage `1.5% cashback`, numerical badge `3`.

#### 3. Charts Section
*   **Payout Tiinere (Line Chart):**
    *   Smooth dual-line graph tracking trends over a period.
    *   Gridlines rendered in very faint gray.
    *   Lines colored in gradient orange/pink and soft blue.
*   **Net vs Fees (Bar Chart):**
    *   Grouped and stacked vertical bar columns representing categorical financial comparisons in pastel tones of purple, blue, and peach.

---

### D. Main Content Grid (Row 2)

#### 1. Dispute Inbox Card
*   **Header:** "Dispute inbox" with explanatory subtitle text.
*   **Data Rows:** Compact transaction rows displaying transaction icons, merchant names, timestamps, and percentage/status tags (e.g., `355%`, `562.55`).
*   **Action Buttons:** Bottom buttons for quick actions: **"Sasee cones"** and **"Duroncad report"**.

#### 2. Quick Action Toolbar
*   Row of pill buttons for common tasks: **"New payout"**, **"Issue card"**, search triggers, and filter icons.

#### 3. Transactions Table
*   **Tabs Header:** Filter tabs ("All", "Spend", "Flittes", "Actions").
*   **Table Structure:**
    *   Columns: Status icon, Amount (`€ 005`, `€ 130`, etc.), Category/Merchant icons, Time/Date stamps, numerical values, and right-aligned action buttons (e.g., **"Deniala"**, **"Deniero"**, **"Deniole"**, **"Deniord"**).
    *   **Styling:** Clean alternating row spacing, muted typography for dates, bold typography for currency amounts.

---

## 5. Image & Asset Guidelines

*   **Avatars:** Rendered as circular profile picture placeholders containing real photographs of individuals (professional headshots).
*   **Card Thumbnails:** Rendered as miniature vector or raster graphics representing branded credit/debit cards with chip icons and geometric visual patterns.
*   **Icons:** Use a consistent icon set (e.g., Lucide Icons, Heroicons, or Phosphor Icons) rendered in stroke weight 1.5px to 2px.
