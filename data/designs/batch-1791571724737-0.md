# Design Specification: Desktop Analytics Dashboard

This document provides a comprehensive design specification for recreating the desktop analytics dashboard shown in the reference image. The specification is structured to serve as a blueprint for frontend implementation.

---

## 1. Global Styles & Layout

### 1.1. Color Palette
*   **Background (Canvas):** `#A5C4F4` (Soft pastel blue covering the entire viewport/screen).
*   **Card Container Background:** `#FFFFFF` (Clean white with subtle rounded corners and soft drop shadow).
*   **Primary Text / Headings:** `#1D1D2C` (Dark navy/black for high contrast).
*   **Secondary Text / Subtitles:** `#5B5B6D` (Muted grey-blue for labels and small text).
*   **Accent / Positive Change (Green):** `#23A050` (Used for positive percentage changes, e.g., `+52%`, `+166%`).
*   **Accent / Negative Change (Red):** `#E04848` (Used for negative percentage changes, e.g., `-0.6%`).
*   **Chart Lines:**
    *   *Past 28 days:* `#3C71F5` (Vibrant blue).
    *   *Prev 28 days:* `#D670D6` / Magenta-pink.
*   **Grid Lines & Borders:** `#E5E7EB` (Light grey for table dividers and chart grid lines).

### 1.2. Typography
*   **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif.
*   **Fallback Strategy:** If `Inter` is unavailable, the stack falls back to standard clean sans-serif system fonts.
*   **Hierarchy:**
    *   *Page Title ("Desktop"):* 44px, Bold (Weight: 700), Color: `#1D1D2C`.
    *   *Section Header ("Key Performance Summary"):* 20px, Semi-bold (Weight: 600), Color: `#1D1D2C`.
    *   *Metric Values (Large, e.g., "325", "32.6k"):* 36px, Bold (Weight: 700), Color: `#1D1D2C`.
    *   *Card Sub-labels ("vs 214 last month"):* 12px, Regular (Weight: 400), Color: `#5B5B6D`.
    *   *Table Data / Body text:* 13px, Regular/Medium (Weight: 400/500), Color: `#1D1D2C` / `#5B5B6D`.

### 1.3. Layout Structure
*   **Viewport:** Full-screen width and height, utilizing a centered container with a max-width of approximately `1200px` to `1280px`, surrounded by generous padding.
*   **Dashboard Card:** A large white container with a border-radius of `24px` and padding of `32px`.
*   **Grid System:** 
    *   The dashboard uses a structured multi-column layout.
    *   Top section metrics (Conversions, Conversion rate, Sessions, Stickiness, Engagement) span across flexible grid columns.
    *   Bottom section splits into equal-width columns for "Top Sources" tables and sidebar metrics ("Bounce rate", "Devices used for visits").

---

## 2. Component Specifications

### 2.1. Header & Controls
*   **Page Header:** 
    *   Small overline text: "Final Work" (11px, Uppercase, Medium, `#5B5B6D`).
    *   Main heading: "Desktop" (44px, Bold).
*   **Section Header:** 
    *   Title: "Key Performance Summary" on the left.
    *   Control on the right: **Time Range Selector** dropdown displaying "Month" with a chevron icon (`▼`), styled with a subtle border and rounded corners.

---

### 2.2. Metric Cards (Top Row)

Each metric card follows a consistent internal structure:
1.  **Header:** Metric name on the left (e.g., "Conversions") and change badge on the right (e.g., `▲ 52%` in green pill/text format).
2.  **Core Value:** Large bold number (e.g., `325`, `2.1%`, `32.6k`).
3.  **Context:** Comparison text below the value (e.g., `vs 214 last month`).
4.  **Inline Line Chart (For first 3 cards):**
    *   X-axis labels: Dates formatted as `6 Apr`, `13 Apr`, `20 Apr`, `27 Apr`.
    *   Y-axis scale marks on the left (e.g., `150`, `100`, `50`, `0`).
    *   Legend above the chart: Blue square dot (`• past 28 days`), Pink square dot (`• prev 28 days`).
    *   Dual-line visualization representing performance trends over time.

## 3. Implementation Guidelines
1.  **Responsiveness:** While designed for desktop (`Desktop` view), ensure the CSS grid collapses gracefully into stacked columns on smaller viewports.
2.  **Borders & Radius:** Use consistent border-radii (`16px` for internal metric blocks, `24px` for the main dashboard wrapper).
3.  **Icons:** Use standard UI icon sets (like Lucide, FontAwesome, or Heroicons) for the dropdown chevron (`▼`) and trend arrows (`▲`, `▼`).
