# Design System Specification: MagicHeal Health Overview Dashboard

This document provides a comprehensive design specification for replicating the "MagicHeal" health dashboard UI. The layout is optimized for a desktop viewport with a modern, medical-tech aesthetic utilizing clean white space, soft drop shadows, rounded cards, and vibrant accent colors.

---

## 1. Global Styles & Foundations

### 1.1 Color Palette
* **Backgrounds**
  * Application Canvas: `#F4F5F7` (Light cool gray)
  * Cards / Surfaces: `#FFFFFF` (Pure white)
  * Active Navigation Item: `#0055FF` (Vibrant Blue)
* **Text Colors**
  * Primary Headings: `#111827` (Dark charcoal/near-black)
  * Secondary Text / Labels: `#4B5563` or `#6B7280` (Cool gray)
  * Muted / Placeholder Text: `#9CA3AF`
* **Accents & Status Colors**
  * Primary Brand / Interactive Blue: `#0066FF`
  * Success / Good Status: `#10B981` (Green pill background: `#D1FAE5` with `#047857` text)
  * Indicator/Badge Blue: `#2563EB`

### 1.2 Typography
* **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif
* **Fallback Stack:** `sans-serif`
* **Type Scale:**
  * **Brand Logo:** 20px / Bold (700)
  * **Page Title ("Health Overview"):** 28px / Bold (700)
  * **Card Headings (e.g., "Heartbeat", "Doctors", "My Medicine"):** 14px–16px / Semi-bold (600)
  * **Data Values (e.g., "83 bpm", "115/70"):** 18px–22px / Bold (700)
  * **Body / Meta Labels:** 12px / Regular (400) to Medium (500)

### 1.3 Radii & Shadows
* **Card Border Radius:** `16px` to `24px` (smooth, organic rounded rectangles)
* **Button/Pill Border Radius:** `20px` to `9999px` (fully rounded)
* **Card Shadows:** `0px 4px 20px rgba(0, 0, 0, 0.04)` (subtle elevation)

---

## 2. Layout Structure & Grid

The application utilizes a **full-screen fluid canvas** with a centered, padded content area (approx. 80-90% max width with generous outer margins).

* **Header Section:** Top navigation bar containing the brand logo, primary navigation links, a CTA consultation button, notification icon, and user profile avatar.
* **Main Content Area:**
  * **Title Row:** Page header ("Health Overview") paired with time-range dropdown filters ("24 Hrs", "Weekly") on the right.
  * **Upper Grid:** 
    * Left side: Vital signs cards stacked vertically/horizontally (Heartbeat, R-R Interval, Blood Status).
    * Center: Large 3D interactive-style human heart model graphic.
    * Right side: Glucose Level and Blood Count charts.
  * **Organ Selector Row:** Horizontal scrollable/clickable icons for organ systems (Heart, Kidney, Liver, Brain).
  * **Lower Grid (Two Columns):**
    * Left: **"Doctors"** roster card list.
    * Right: **"My Medicine"** medication inventory card list.

---

## 3. Component Specifications

### 3.1 Header
* **Logo:** Text "MagicHeal" prefixed with an asterisk/starburst icon in vibrant blue (`#0066FF`).
* **Navigation Links:** Pill-shaped active state container (`#0066FF` background, white text) for "Overview", with inactive links ("Document", "Messages", "Labs Results") in dark gray text.
* **Actions:** 
  * "Consultation" button: Pill shape, bright blue background, white text, featuring an external link arrow icon (`↗`).
  * Notification Bell icon inside a rounded square/circle button.
  * User Avatar: Circular thumbnail image of a smiling woman.

### 3.2 Time Filters
* Dropdown selectors labeled "24 Hrs" and "Weekly" positioned on the upper right, styled with subtle border lines and small downward chevron arrows (`⌄`).

### 3.3 Metric & Vital Cards
* **General Card Styling:** White surface, rounded corners (`16px`), soft drop shadow, internal padding.
* **Heartbeat Card:**
  * Header: Icon + "Heartbeat" label.
  * Value: "83 bpm" (large bold text).
  * Status Badge: Small green pill labeled "GOOD" (`#10B981` theme).
  * Chart: Line graph representing an ECG/EKG sine wave in blue, set against a light background grid.
* **R-R Interval Card:**
  * Value: "0.8 sec".
  * Chart: Line graph with highlighted interval markers (vertical dashed lines with node points).
* **Blood Status Card:**
  * Value: "115/70".
  * Chart: Vertical bar code visualization representing systolic/diastolic metrics.
* **Glucose Level & Blood Count Cards:**
  * Values: "230/ml" and "80-90".
  * Inline blue badge tags (e.g., "230/ml", "80/90") marking threshold peaks.
  * Minimalist sparkline charts tracking metric fluctuations over time.

### 3.4 Central Organ Visualizer
* **3D Heart Graphic:** A central, highly detailed 3D anatomical heart render, angled slightly. 
* **Interactive Hotspots:** Circular radar-pulse rings positioned on specific areas of the heart, accompanied by small blue notification badges containing numeric counters (e.g., `+1`, `+3`).
* **Organ Navigation Tabs:** A sub-menu bar underneath the heart containing round icon buttons for:
  * **Heart** (active, highlighted with a selection ring)
  * **Kidney**
  * **Liver**
  * **Brain**

### 3.5 Doctors Section ("Doctors")
* **Header:** Title "Doctors" on the left, "View All" action link on the right.
* **Doctor Cards:** Horizontal arrangement of individual cards.
  * **Card Contents:**
    * Specialty tag ("Cardiology") at the top left.
    * Doctor avatar (circular photo).
    * Doctor name ("Dr. Kirsten", "Dr. Edward", "Dr. Bryant") with professional title.
    * Subtle medical icon watermark on the card background.

### 3.6 My Medicine Section ("My Medicine")
* **Header:** Title "My Medicine" on the left, "View All" action link on the right.
* **Medicine Cards:** A row of distinct white product cards.
  * **Card Contents:**
    * Centered image of the medication package/bottle (e.g., Benazepril, Captopril, Quinapril, Fosinopril).
    * Medication name label centered directly beneath the bottle image (e.g., "Benazepril", "Captopril").

---

## 4. Iconography & Imagery Guidance

* **UI Icons:** Use clean, minimalist outline icons (Stroke-based, 1.5px to 2px stroke width, rounded caps) for metrics, notifications, and navigation.
* **Images (Avatars & Medical Assets):**
  * *User & Doctor Avatars:* Professional headshots with natural lighting against neutral backgrounds, cropped into circles.
  * *Central Heart Graphic:* High-resolution 3D medical render of a human heart with realistic muscle texture, arteries, and veins, rendered against a clean transparent/white space.
  * *Medicine Bottles:* Clean product photography of pharmaceutical bottles/blister packs isolated on a plain white background with soft drop shadows.
