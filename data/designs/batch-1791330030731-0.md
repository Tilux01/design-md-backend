# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Dark Mode Web3 Financial Tech & Cryptographic SaaS.
- **Visual Density & Whitespace Ratio**: High atmospheric impact with controlled central concentration. Immersive, high-contrast dark space centered around high-value protocol identity copy and action items.
- **Surface Elevation Model**: Layered obsidian backdrop (`#050805`) with multi-stop radial emerald green volumetric lighting (`#082415`), translucent dark glassmorphic pills (`rgba(255, 255, 255, 0.03)` with thin 1px border highlights), and 3D architectural perspective grids.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Ambient green backlighting, glassmorphic pill elements with subtle inset borders, glowing status glyphs, architectural grid perspective floors.
- **Pill Badge Specification**: Padding `6px 14px`, font-size `13px`, font-weight `500`, tracking `0.04em`, border-radius `9999px`, background `rgba(255, 255, 255, 0.04)`, border width `1px` solid `rgba(255, 255, 255, 0.1)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG.
  - Status Dot (●) -> Use `<span class="w-1.5 h-1.5 rounded-full bg-emerald-400 inline-block"></span>`.

# 7. Motion Mechanics, Framer Motion & CSS Animations
- **Motion Principles**: Smooth deceleration curves (`cubic-bezier(0.16, 1, 0.3, 1)`), subtle ambient pulse for glow lighting, responsive active scaling on button presses.
- **Framer Motion Variants Code**:
```jsx

    opacity: 1,

  }
```
