# Design Specification: Nike Air Max 270 Product Screen

## 1. Overview & Layout
* **Platform:** Mobile (iOS / Android portrait viewport, 390 × 844 pt base).
* **Base Background:** Pure White (`#FFFFFF`).
* **Grid & Spacing:** 16px to 24px horizontal screen padding; flex-based vertical arrangement with 3 columns in the central interactive area.

---

## 2. Typography

* **Primary Font:** `Futura`, `Nike Futura ND`, or `Inter`
* **Fallback Stack:** `system-ui`, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `Helvetica Neue`, `Arial`, `sans-serif`

| Element | Size | Weight | Color | Line Height |
| :--- | :--- | :--- | :--- | :--- |
| **Product Title** | 24px | 700 (Bold) | `#111111` | 1.2 |
| **Subtitle** | 14px | 400 (Regular) | `#7E7E7E` | 1.3 |
| **Price Value** | 24px | 800 (Extra Bold) | `#111111` | 1.2 |
| **Labels (Size, Fav, Color, Price)** | 12px | 500 (Medium) | `#7E7E7E` | 1.2 |
| **Pill Options (Text)** | 13px | 600 (Semi-Bold) | `#111111` / `#FFFFFF` | 1.0 |
| **Action Cue ("Swipe down")** | 12px | 500 (Medium) | `#111111` | 1.2 |

---

## 3. Color Palette

* **Neutral Dark:** `#111111` (Text, Active states, Action handle)
* **Neutral Light:** `#F5F5F7` (Inactive containers, borders)
* **Text Muted:** `#7E7E7E`
* **Background Watermark:** `#EFEFEF` (Opacity 0.6)
* **Brand Accent Orange:** `#FF5F00` (Shoe box body)
* **Shoe Box Inner:** `#C88339` (Cardboard interior shadow)
* **Color Dots:**
  * Option 1: `#FA4D1A` (Red-Orange gradient)
  * Option 2: `#4638F2` (Purple-Blue)

---

## 4. UI Components

### 4.1 Header Bar
* **Back Button (Left):** 44×44px pill/rounded rectangle, border `1px solid #E5E5E5`, centered left-arrow icon (`#111111`).
* **Brand Logo (Center):** Subtle Nike Swoosh (`#E0E0E0`, ~40px wide).
* **Cart Icon (Right):** 44×44px pill container with shopping bag icon. Overlaid circular badge (`#111111`, text `#FFFFFF`, 8px font, size 16×16px) displaying count `"2"`.

### 4.2 Title Section
* Centered directly below the header.
* Contains "Nike Air Max 270" and "Men's shoes".

### 4.3 Central Showcase & Flanking Controls
* **Background Watermark:** Large diagonal light-gray text/vector (`#F0F0F0`) positioned behind the product.
* **Left Column (Size Selector):**
  * Vertical list with label `"Size"`.
  * Pill buttons: 44×32px, border radius `16px`.
  * Inactive: `#FFFFFF` fill, `1px solid #E5E5E5` border, `#111111` text.
  * Active (`9.5`): `#111111` fill, `#FFFFFF` text.
* **Center (Product Display):**
  * Angled sneaker cutout (~-35° tilt pointing bottom-left), soft floating drop shadow (`rgba(0, 0, 0, 0.15)`, blur `20px`, offset `y: 15`).
* **Right Column (Favorites & Colors):**
  * Top: `"Fav"` label above a rounded button with a Heart outline icon.
  * Bottom: `"Color"` label with vertical pill color chips (40×32px, `1px solid #E5E5E5`, rounded radius `16px`). Active pill has subtle outer border highlight.

### 4.4 Bottom Action & Cart Area
* **Price Block (Bottom Left):** Left-aligned `"$170"` with label `"Price"` underneath.
* **Swipe Action & Box (Bottom Center):**
  * Text `"Swipe down"` centered above the handle.
  * **Handle:** Dark vertical pill (`#111111`, ~48×80px, border-radius `24px`) containing a cart icon and downward triple chevrons (`>>>` rotated 90°).
  * **Box Container:** Open orange Nike shoe box (`#FF5F00`) pinned to bottom screen edge, yellow Nike Swoosh on the front face.

---

## 5. Micro-Interactions & Animations

1. **Swipe Down to Add:**
   * **Trigger:** Dragging the floating sneaker or the black handle downward toward the open box.
   * **Animation:** Sneaker scales down (from `1.0` to `0.4`) and drops into the orange box on release.
   * **Feedback:** Haptic click on completion; cart badge increments from `2` to `3`; handle resets to default position.
2. **Size / Color Selection:**
   * Instant transition with spring scale (`1.0 -> 0.95 -> 1.0`) on tap.
   * Active border/color state changes over `150ms ease-out`.
3. **Chevron Cue:**
   * Downward loop animation for chevrons inside the handle (translate Y + fade out, 1.2s infinite ease-in-out).
