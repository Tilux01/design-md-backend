# UI/UX Design Specification & Component Breakdown

This document outlines the exact specifications for a mobile shopping application user interface, structured as a multi-screen UI kit based on the provided visual reference.

---

## 1. Global Design Tokens

### 1.1 Color Palette
*   **Primary / Neutral Dark:** `#000000` (Pure Black for primary typography, active states, buttons, and structural icons)
*   **Secondary Neutral:** `#666666` (Medium Gray for secondary text, metadata, inactive states, and unselected tabs)
*   **Background / Surface:** `#FFFFFF` (Pure White for screen background, card surfaces, and input fields)
*   **Subtle Background / Border:** `#EAEAEA` to `#F2F2F2` (Light Gray for card separators, borders, and image placeholders)

### 1.2 Typography
*   **Font Family:** System Sans-Serif (e.g., `-apple-system`, `SF Pro Display`, `Roboto`, `Helvetica Neue`)
*   **Scale:**
    *   **Screen Header / Title:** 20px–24px, Bold (`700`)
    *   **Section Heading:** 16px–18px, Semi-Bold (`600`)
    *   **Body / Primary Text:** 14px, Regular (`400`) to Medium (`500`)
    *   **Caption / Metadata:** 11px–12px, Regular (`400`)

---

## 2. Shared Layout & Component Anatomy

### 2.1 Navigation Bar (Header)
*   **Height:** 44px – 56px (plus safe area)
*   **Left Element:** Back chevron (`<`) or Hamburger menu icon.
*   **Center Element:** Screen Title or Brand wordmark (Centered or Left-aligned depending on view style).
*   **Right Element:** Action icon (Search lens, Shopping bag with badge counter, or Close `X`).

### 2.2 Bottom Navigation Bar (Tab Bar)
*   **Height:** 49px – 60px (plus safe area)
*   **Items (Left to Right):**
    1.  Home / Dashboard Icon
    2.  Search / Explore Icon
    3.  Saved / Wishlist Icon
    4.  Profile / User Account Icon
*   **State Styling:** Active item uses `#000000`; inactive items use `#999999`.

---

## 3. Screen-by-Screen Breakdown

### Screen 1: Splash / Dark Entry Screen (Top-Left)
*   **Background:** Full solid `#000000` (Black).
*   **Content:**
    *   Centered minimalist brand logo or graphical mark (White).
    *   Bottom CTA: Solid white pill-shaped button or primary text button (`#FFFFFF` background, `#000000` text).

### Screen 2: Onboarding / Welcome Screen (Top - Second)
*   **Background:** `#FFFFFF`.
*   **Layout:** Vertical stack.
*   **Content:**
    *   Top thumbnail image block (monochrome/dark product visual or abstract graphic).
    *   Heading: Bold, left-aligned statement (e.g., *"Discover minimalist design"*).
    *   Body text: Subdued gray description paragraph.
    *   Bottom Action: High-contrast primary black button (`#000000`, full width, rounded corners) with white text.

### Screen 3: Sign-In / Authentication (Top - Third)
*   **Background:** `#FFFFFF`.
*   **Layout:** Form-based structure.
*   **Content:**
    *   Header title ("Sign In" or "Welcome back").
    *   Input fields: Outlined or underlined text fields for Email and Password with inline placeholder text.
    *   Primary Action Button: Full-width black button (`#000000`).
    *   Secondary Action: Text link for password recovery or alternate sign-up flow.

### Screen 4: User Profile / Account Settings (Top-Right)
*   **Background:** `#FFFFFF`.
*   **Content:**
    *   Top user identification header (Avatar placeholder + Name + Email).
    *   List-based menu structure separated by fine horizontal rules (`#EAEAEA`):
        *   "Orders"
        *   "Shipping Addresses"
        *   "Payment Methods"
        *   "Settings"
        *   "Log Out" (Styled distinctively or placed at bottom).

### Screen 5: Category / Menu List (Row 2, Column 1)
*   **Background:** `#FFFFFF`.
*   **Layout:** Vertical text menu with chevron indicators.
*   **Content:**
    *   List items spanning full width with generous vertical padding:
        *   Category names in bold uppercase or large font (e.g., `NEW ARRIVALS`, `CLOTHING`, `SHOES`, `ACCESSORIES`, `SALE`).
    *   Right-aligned directional chevron (`>`) for each row.

### Screen 6: Product Grid - 2 Column (Row 2, Column 2)
*   **Background:** `#FFFFFF`.
*   **Layout:** 2-column uniform grid with standard gutters (8px–12px).
*   **Card Components:**
    *   **Image Container:** Square or portrait aspect ratio, light gray background holding monochromatic product imagery.
    *   **Product Title:** 1-line truncation (`12px`, Regular).
    *   **Price:** Bold font below title (`12px`, Bold).
    *   **Wishlist Icon:** Subtle outline heart icon overlaid on the top-right of the image thumbnail.

### Screen 7: Product Filtering / Search Results (Row 2, Column 3)
*   **Background:** `#FFFFFF`.
*   **Layout:** Filter chips at the top followed by a scrollable item feed.
*   **Content:**
    *   Horizontal scrollable pill filters (e.g., *"All"*, *"Category"*, *"Price"*, *"Color"*).
    *   Compact list or grid layout showing matching catalog items with tags and prices.

### Screen 8: Detail View / Expanded Card (Row 2, Column 4)
*   **Background:** `#FFFFFF`.
*   **Layout:** Vertical stack focusing on a primary visual entity.
*   **Content:**
    *   Large hero image occupying the upper half of the viewport.
    *   Detailed specs, metadata, and related thumbnail strip underneath.

### Screen 9: Variant Selection / Gallery (Row 3, Column 1)
*   **Background:** `#FFFFFF`.
*   **Layout:** Multi-image layout showing detail angles.
*   **Content:**
    *   Stacked or carousel product angles with clean whitespace borders.

### Screen 10: Horizontal Product Cards (Row 3, Column 2)
*   **Background:** `#FFFFFF`.
*   **Layout:** 2-column grid featuring wider thumbnail cards with clean pricing alignment below.

### Screen 11: Cart / Checkout Summary (Row 3, Column 3)
*   **Background:** `#FFFFFF`.
*   **Layout:** Itemized list with total calculation breakdown.
*   **Content:**
    *   Thumbnail + Item Name + Quantity Selector + Price per line item.
    *   Subtotal, shipping, and grand total text block at the bottom.
    *   Sticky bottom checkout action button (`#000000`).

### Screen 12: Notification / Empty State / Grid Variant (Row 3, Column 4)
*   **Background:** `#FFFFFF`.
*   **Layout:** Mixed vertical layout containing search bar, filter tags, and modular product cards.
