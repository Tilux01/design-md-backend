# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial E-Commerce Dark Mode, Luxury Minimalist, High-End Architectural Showcase.
- **Visual Density & Whitespace Ratio**: Spacious and breathable layout with distinct focal blocks; generous padding (24px–48px) around interactive filters, furniture cards, and category items.
- **Surface Elevation Model**: Multi-layered dark surface architecture using neutral charcoal bases (`#2A2826`, `#33312E`), subtle 1px translucent borders (`rgba(255,255,255,0.08)`), and soft drop shadows (`0 8px 32px rgba(0,0,0,0.5)`) for card containers and search filters.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase pill badges, translucent frosted glass overlays (`backdrop-blur-md`), ambient dark surfaces, minimalist monochrome typography with gold/amber accents.
- **Pill Badge Specification**: Padding `6px 14px`, font-size `12px`, font-weight `600`, tracking `0.05em`, border-radius `9999px`, background translucency `rgba(255,255,255,0.06)`, border width `1px` solid `rgba(255,255,255,0.1)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content to prevent rendering glitches.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;` or `<span class="w-2 h-2 rounded-full bg-amber-400 inline-block"></span>`.
