# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Dark Mode Glassmorphism / Spatial AI Prompt Bar.
- **Visual Density & Whitespace Ratio**: High focus on central command interface with generous outer canvas whitespace and atmospheric depth.
- **Surface Elevation Model**: Layered translucency featuring frosted glass (`backdrop-filter: blur(16px)`), subtle inner white borders (`1px solid rgba(255, 255, 255, 0.2)`), and multi-stop ambient lighting.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Frosted glass capsules, subtle glowing icons (snowflake/sparkle), ambient gradient mesh backgrounds.
- **Pill Badge Specification**: Padding `16px 24px`, font-size `18px`, font-weight `400`, border-radius `9999px`, background `rgba(25, 27, 42, 0.75)`, border width `1px solid rgba(255, 255, 255, 0.15)`.
- **Symbol & Glyph Safety Mapping**:
  - Snowflake Icon -> Use SVG `<svg>` component or `&#10052;`.
  - Action Glyphs -> Use Lucide React or standard SVG line icons.
