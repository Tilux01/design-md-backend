# UI/UX Specification & Replication Guide: Pallet Ross Landing Page

This document provides a comprehensive blueprint to replicate the provided landing page design as a full-screen, production-ready web application. All decorative frames, shadows, and mockups from the presentation layer are stripped away to focus entirely on the core browser viewport layout.

---

## 1. Global Styles & Design Tokens

### Color Palette
| Token | Hex / Value | Usage |
| :--- | :--- | :--- |
| `background` | `#FFFFFF` or `#FAFAFA` | Page background |
| `text-primary` | `#111111` | Main headings & brand name |
| `text-secondary` | `#666666` | Body text & subheaders |
| `nav-text` | `#444444` | Header navigation links |
| `accent-blue` | `#2563EB` (approx.) | `@coplin` badge background |
| `accent-green` | `#10B981` (approx.) | `@andrea` badge background |
| `badge-text` | `#FFFFFF` | Text inside interactive floating pills |
| `button-dark` | `#1A1A1A` | Primary CTA background |
| `button-text` | `#FFFFFF` | Primary CTA text |

### Typography System
*Note: Since the exact font file may be proprietary, use system fallback chains prioritizing modern geometric sans-serif typefaces.*

* **Brand & Headings ("Pallet Ross", "A place to display your masterpiece.")**
  * *Primary:* Inter, Plus Jakarta Sans, or SF Pro Display
  * *Fallback:* `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
  * *Weight:* Bold (700) for Headings, Medium (500) for Brand Name
* **Navigation & Subtext**
  * *Primary:* Inter, Roboto
  * *Fallback:* `sans-serif`
  * *Weight:* Regular (400) to Medium (500)

---

## 2. Layout Structure & DOM Tree

The application is structured into three main vertical sections:
1. **Header / Navbar** (Sticky or fixed top, full-width)
2. **Hero Section** (Centered layout containing headline, floating tags, stacked artwork cards, and subcopy)
3. **Action Area** (Primary & Secondary Call-to-Action buttons)

---

## 3. Component Breakdown & Detailed Specs

### A. Navigation Bar (`<nav>`)
* **Layout:** Flex row, space-between alignment, padded horizontally (e.g., `padding: 24px 64px`).
* **Left Element (Brand):**
  * Green abstract icon + Bold text: **Pallet Ross**
* **Center/Right Element (Links):**
  * Items: `Get Started`, `Create strategy`, `Pricing`, `Contact`, `Solution`, `E-Commerce`
  * Styling: Font-size `14px`, color `#444444`, hover state changes to `#000000`.
* **Far-Right Elements:**
  * User profile avatar icon & Search/Utility icon.

---

### B. Hero Section (`<header>` or `<section class="hero">`)
* **Layout:** Flex column, centered items (`align-items: center`, `text-align: center`).
* **Main Heading (`<h1>`):**
  * Text: *"A place to display your masterpiece."*
  * Styling: Font-size approx. `56px` - `64px`, Line-height tight (`1.1`), maximum width constrained to prevent lines from breaking awkwardly (e.g., `max-width: 800px`).

---

### C. Floating User Badges (`.badge`)
* **Positioning:** Absolute or relative offsets hovering above the artwork stack.
* **Badges:**
  1. **Left Tag:** `@coplin` (Blue pill badge with white text, rounded corners `border-radius: 9999px`, padding `6px 14px`, box-shadow).
  2. **Right Tag:** `@andrea` (Green pill badge with white text, positioned near the right side of the card fan).

---

### D. Artwork Card Fan / Stack (`.card-stack`)
* **Visual:** A cascading fan-out of 6–8 distinct digital art cards/prints overlapping one another.
* **Layout Container:** Relative positioning container with a set width/height to anchor the absolute/transformed child cards.
* **Card Transformations (CSS Rotation & Translate):**
  * Each card utilizes CSS `transform: rotate(deg) translateY(px)` to create a natural curved arc layout.
  * Cards feature drop shadows (`box-shadow: 0 10px 25px rgba(0,0,0,0.15)`) and rounded corners (`border-radius: 12px`).

---

### E. Subtext & Call-to-Action Buttons
* **Subcopy (`<p>`):**
  * Text: *"Artists can display their masterpieces, and buyers can discover and purchase works that resonate with them."*
  * Styling: Font-size `14px` / `16px`, color `#666666`, max-width `500px`, centered.
* **Buttons Container (`.cta-group`):**
  * **Primary Button:** 
    * Text: *"Join for $9.99/m"*
    * Styling: Dark background (`#111111`), white text, rounded capsule shape (`border-radius: 9999px`), padding `12px 24px`, font-weight `500`.
  * **Secondary Link/Button:**
    * Text: *"Read more"*
    * Styling: Transparent background, dark text, medium weight, subtle hover underline.

---

## 4. Animations & Micro-Interactions (CSS / JS)

To match modern aesthetic landing pages, implement the following smooth micro-interactions:

1. **Page Load Entrance (Framer Motion / CSS Keyframes):**
   * **Fade-in Up:** Hero heading and subcopy fade in with a slight upward translation (`translateY(20px)` to `0`) over `0.8s` with an `ease-out` cubic-bezier curve.
   * **Card Stagger:** The artwork cards cascade into position sequentially with a staggered delay (`0.1s` per card).
2. **Hover States:**
   * **Navigation Links:** Smooth color transition (`transition: color 0.2s ease`).
   * **Primary CTA:** Slight scale up (`transform: scale(1.02)`) and brightness shift on hover.
   * **Floating Badges:** Gentle floating/bobbing CSS keyframe animation (`infinite` loop, `3s` duration) to give a dynamic, living feel to the hero art.

---

## 5. Responsive Breakpoints

* **Desktop (`>= 1024px`):** Full multi-item horizontal nav, large hero typography (`64px`), fully expanded card fan.
* **Tablet (`768px - 1023px`):** Navigation collapses into a hamburger menu or scrolls horizontally; font-size scales down to `42px`; card fan scales down to fit viewport bounds.
* **Mobile (`< 768px`):** Single-column layout, compact header, headline reduced to `32px`, card stack simplified or made swipeable/scrollable horizontally.
