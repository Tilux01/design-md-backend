# Design System & Specification: Car Marketplace App

## 1. Typography

* **Primary Font:** `Plus Jakarta Sans` or `Inter`
* **Fallback Stack:** `San Francisco (SF Pro Display/Text)`, `Segoe UI`, `Roboto`, `Helvetica Neue`, `sans-serif`
* **Hierarchy:**
  * **H1 / Screen Title:** SemiBold 20px, line-height 26px
  * **H2 / Card Title:** SemiBold 18px, line-height 24px
  * **Body / Subtitle:** Medium 14px, line-height 20px
  * **Caption / Meta:** Regular 12px, line-height 16px
  * **Price Large:** Bold 22px, line-height 28px
  * **Price Small:** SemiBold 13px, line-height 18px

---

## 2. Color Palette

* **Neutral Dark (Primary Action / Hero):** `#161618`
* **Neutral Light (App Background):** `#F8F9FA`
* **Card Surface:** `#FFFFFF`
* **Card Sub-surface / Spec Boxes:** `#F2F4F7`
* **Text Primary:** `#101828`
* **Text Secondary:** `#667085`
* **Text Inverted:** `#FFFFFF`
* **Accent / Rating:** `#FDB022`
* **Border / Divider:** `#EAECF0`

---

## 3. Screen 1: Home Dashboard

### Layout & Container
* **Background:** `#F8F9FA`
* **Padding:** Horizontal 20px, Vertical 16px safe-area inset.

### Header
* **Left:** 42px circular user avatar + vertical text stack (`Welcome 👋` in 12px `#667085`, `Shahinur Rahman` in 16px `#101828`).
* **Right:** 42px circular notification bell button with `#EAECF0` outline.

### Search Bar
* **Container:** 50px height, rounded-full (`border-radius: 9999px`), background `#FFFFFF`, border `1px solid #EAECF0`.
* **Content:** Search icon (left, 18px), placeholder `"Search your car"` (14px `#98A2B3`), filter action button (right, 38px circle, `#161618` with adjustment icon).

### Brand Category Slider
* **Layout:** Horizontal scroll / flex row, 12px gap.
* **Item:** 60px circular button (`#161618`) containing centered white SVG logo (Cadillac, Tesla, BMW, Mazda), followed by 12px medium label centered below.

### Popular Car Grid
* **Section Header:** `"Popular Car"` (18px SemiBold) left; `"View All"` (13px `#667085`) right.
* **Grid:** 2-column grid, 12px gap.
* **Card:**
  * Background `#FFFFFF`, border-radius 20px, padding 12px.
  * Favorite toggle (top-left, 16px heart icon outline).
  * Car image: Transparent PNG, centered, 80px max height.
  * Model name: 14px SemiBold `#101828`.
  * Price & Rating: Single line flex (`$45,590` left, `★ 4.5` right in `#FDB022`).

### Bottom Navigation Dock
* **Layout:** Floating pill docked at bottom center, margin 16px, height 64px, background `#161618`, border-radius 32px.
* **Items:** 4 evenly spaced icon actions: Home (active, white fill), Wishlist (outline), Cart (outline), Profile/Settings (outline).

## 4. Screen 2: Car Details

### Hero Section (Top 42%)
* **Background:** Solid `#161618` with slight bottom vignette.
* **Top Bar:** 
  * Left: 40px circular button (Back arrow, `#FFFFFF1A` translucent fill, white icon).
  * Center: `"Car Details"` (16px SemiBold `#FFFFFF`).
  * Right: 40px circular button (Heart icon, `#FFFFFF1A` fill).
* **Hero Image:** Cutout vehicle view, 3/4 front angle, vertically aligned to overlap the sheet division.

### Detail Sheet (Bottom 58%)
* **Container:** Background `#FFFFFF`, top border-radius 32px, padding 24px, full height overlay.
* **Title Row:**
  * Left: `"Tesla Model 3"` (22px Bold `#101828`).
  * Right: `★ (4.5)` (14px SemiBold `#101828`, star `#FDB022`).
* **Description:** 13px Regular `#667085`, 2-line clamp with inline `"more"` bold action.
* **Features Section:**
  * Heading: `"Features"` (16px SemiBold `#101828`, margin-bottom 12px).
  * Grid: 3-column horizontal row, gap 10px.
  * Spec Box: Background `#F2F4F7`, border-radius 16px, padding 12px.
    * Center icon (20px).
    * Sub-label (11px `#667085`, e.g., "Total Capacity").
    * Value (13px SemiBold `#101828`, e.g., "6 seats").
* **Bottom Action Bar:**
  * Left: Label `"Price"` (12px `#667085`), Value `"$45,590"` (22px Bold `#101828`).
  * Right: `"Buy now"` button: 52px height, 140px min-width, background `#161618`, color `#FFFFFF`, border-radius 26px, font 15px SemiBold.

---

## 5. Micro-Interactions & Transitions

* **Route Push (Home → Details):** Shared element transition on car image with ease-out curve (`cubic-bezier(0.16, 1, 0.3, 1)`, 350ms).
* **Sheet Entry:** Slide up from bottom with 300ms damping.
* **Heart / Favorite Toggle:** Scale spring (`scale(1.25)` to `scale(1.0)`) on tap, toggling between stroke and filled state.
* **Button Feedback:** `transform: scale(0.97)` on active press.
