# Design Specification: Sirnik Agency Portfolio Clone (`design.md`)

---

## 1. Design Overview & Creative Direction

### 1.1 Philosophy & Aesthetic
* **Style:** High-contrast Swiss-style Neo-Brutalist Editorial Minimalism.
* **Structure:** Alternating stark light and dark block-themed sections (Dark `#0A0A0A` $\rightarrow$ Light `#FFFFFF` $\rightarrow$ Dark `#080808`).
* **Visual Rhythm:** Asymmetric multi-column typographic layouts, hairline borders (`1px`), extreme contrasts between giant display typography and microscopic editorial metadata text.

## 4. Grid, Layout & Spatial Dimensions

* **Viewport Bounds:** Full-bleed (`100vw`), horizontal edge-to-edge layout without extraneous external canvas shadows or framing.
* **Base Grid:** 12-Column Grid with fluid column widths and fixed gutters.
* **Content Margins:**
  * Desktop ( $\ge 1280\text{px}$ ): Horizontal padding `48px` to `64px`.
  * Tablet: `32px`.
  * Mobile: `20px`.
* **Section Transitions:** Sharp horizontal cutoffs between contrasting background sections (no soft gradients).

## 7. Interactive Behaviors & States

1. **Header Navigation Links:**
   * Normal: `--color-text-light-70` (`#B3B3B3`).
   * Hover: `--color-text-light-100` (`#FFFFFF`). Transition `color 0.2s ease`.
2. **"Contact" Pill Button:**
   * Normal: Background `#FFFFFF`, Text `#000000`.
   * Hover: Background `#E5E5E5`, scale `1.02`. Transition `transform 0.2s ease, background 0.2s ease`.
3. **"Start a project" CTA:**
   * Hover: Underline gap expands or shifts to a full-width arrow slide transition.
4. **Project List Selection (Section 4):**
   * Default: First item (`SmartPlan AI`) has active color `#FFFFFF`, others remain dimmed (`#555555` to `#1A1A1A`).
   * Hover on inactive items: Color brightens to `#A0A0A0` with cursor set to `pointer`. Clicking switches active state, cross-fading the left-hand mockup image and metadata specifications.
