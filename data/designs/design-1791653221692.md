# UI/UX Design Specification: N99° Beauty Studio App

## 1. Global Styles & Typography

### Color Palette
*   **Background (App Base):** `#0a0a0a` (Deep Midnight Black)
*   **Card Background (Light Mode Overlay):** `#f4f4f4` (Off-White / Light Gray)
*   **Card Background (Dark Mode Overlay):** `#181818` (Dark Charcoal)
*   **Primary Text (Dark Mode):** `#ffffff` (Pure White)
*   **Secondary Text (Dark Mode):** `#8e8e93` (Muted Gray)
*   **Primary Text (Light Mode):** `#111111` (Near Black)
*   **Secondary Text (Light Mode):** `#666666` (Medium Gray)
*   **Action/Button Color:** `#1a1a1a` (Dark Slate / Black with subtle shadow)
*   **Badge/Tag Backgrounds:** 
    *   Dark pills: `#262626` with subtle white border `#3a3a3a`
    *   Unconfirmed status badge: `#e2e2e4` (Light grayish-beige)

### Typography Stack
*   **Primary Font Family:** `Inter`, `SF Pro Display`, `-apple-system`, `sans-serif`
*   **Fallback Stack:** Arial, Helvetica, sans-serif
*   **Font Weights Used:**
    *   `Regular (400)`: Body copy, captions, timestamps.
    *   `Medium (500)`: Button text, tags, usernames, labels.
    *   `Bold (700)`: Screen titles, main headings, prices.
