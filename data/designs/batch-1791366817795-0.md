# UI Layout Specification: Dark Interior Design Landing Page

This specification details a modern, dark-themed landing page for an interior design brand, featuring a split-screen hero section, a navigation bar, and an interactive product spotlight.

---

## 1. Global Styles & Theme

### Colors
- **Background (Dark Dark Gray):** `#1E2024` (or similar deep charcoal tone)
- **Primary Text (Off-White):** `#F3F4F6`
- **Muted Text (Light Gray):** `#9CA3AF`
- **Accent Color (Vibrant Orange):** `#F97316` (used for interactive hotspot icons)
- **Overlay/Card Background:** Semi-transparent dark gray with backdrop blur (`rgba(30, 32, 36, 0.75)` with `backdrop-filter: blur(10px)`)

### Typography
- **Headings / Brand:** Serif font (e.g., *Playfair Display* or *Lora*), white, large scale.
- **Body / Navigation:** Clean Sans-Serif (e.g., *Inter* or *Roboto*).

---

## 2. Layout Structure

The layout uses a **full-screen viewport (100vw × 100vh)** with a **two-column split layout** below the fixed top navigation bar.

```
+-----------------------------------------------------------------+
| [Logo]        [About us]  [Projects]  [Services]  [Shop]  [Contact] [Search] | (Header)
+-----------------------------------------------------------------+
|                     |                                           |
|                     |                                           |
|   LEFT COLUMN       |                 RIGHT COLUMN              |
|   - Large "01"      |                 - Room Background Image   |
|   - "INTERIOR"      |                 - Sofa with Cushions      |
|   - "Design"        |                 - Orange Hotspots (+)     |
|   - Descriptive text|                 - Floating Product Card   |
|   - "Read more"     |                                           |
|                     |                                           |
+-----------------------------------------------------------------+
```

---

## 3. Component Breakdown

### A. Navigation Bar (`header`)
- **Position:** Fixed to the top, spanning 100% width.
- **Background:** Semi-transparent dark overlay (`rgba(20, 22, 26, 0.85)`).
- **Height:** `70px`
- **Elements (Flexbox, space-between):**
  - **Left:** Brand logo text (`Botika` in bold white serif).
  - **Center:** Navigation links (`About us`, `Projects`, `Services`, `Shop`, `Contact`) in uppercase/sentence case, small sans-serif font, muted gray, changing to white on hover.
  - **Right:** Search icon (`🔍`).

---

### B. Left Column: Typography & Intro (`div.hero-left`)
- **Width:** ~35% of the viewport.
- **Background:** Solid dark charcoal (`#232529`).
- **Content:**
  - **Watermark Number:** Large background digit `"01"` positioned behind the text, low opacity (`opacity: 0.05` to `0.1`).
  - **Category Tag:** `"INTERIOR"` in small uppercase sans-serif, tracking (letter-spacing) wide, muted gray color.
  - **Main Heading:** `"Design"` in a very large, elegant Serif font, white color.
  - **Body Paragraph:** 
    > "The stylish interior makes us want to spend more time in it. We present interesting sets to create an apartment. We choose the right colors according to our own taste."
    - *Styling:* Small sans-serif, muted gray (`#A0A4A8`), line-height relaxed.
  - **Call to Action:** `"Read more"` link at the bottom, with a subtle underline or arrow indicator.

---

### C. Right Column: Visual & Interactive Area (`div.hero-right`)
- **Width:** ~65% of the viewport.
- **Background:** Interior photograph featuring a dark grey/black textured wall, wooden flooring, and a modern dark sofa.
- **Elements:**
  1. **Top descriptive text (floating on the wall):**
     - `"A beautiful Sofa"` (small heading)
     - `"The sofa is made of solid materials. Comfortable to use with matched effects. Perfect for the living room."` (small muted text).
  2. **Interactive Hotspots:**
     - Orange circular buttons with a white plus sign (`+`) positioned over specific items (e.g., above the sofa backrest and on the sofa base).
  3. **Floating Product Card (Bottom Right):**
     - **Background:** Dark frosted glass effect (`background: rgba(30, 32, 36, 0.7); backdrop-filter: blur(12px); border-radius: 12px;`).
     - **Content Layout (Flex row):**
       - **Thumbnail Image:** Small preview image of the featured item (e.g., minimalist vase/flowers).
       - **Text Block:**
         - Title: `"Redced"` (Bold white, small).
         - Description: `"Flowers in a beautiful glass composition."` (Muted gray, smaller font).

---

## 4. Responsive Behavior Guidelines
- **Desktop (>1024px):** Exact split layout as specified above.
- **Tablet / Mobile (≤1024px):** Stack the left column above the right column vertically, or convert the hero into a full-background image layout with centered typography.
