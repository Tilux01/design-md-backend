# UI/UX Specification & Design System Clone Guide

This specification details the visual design, typography, color palette, layout structure, and interactive animations required to build an exact, production-ready full-screen clone of the **Dala** landing page shown in the reference image.

---

## 1. Global Layout & Structure

*   **View Mode:** Full-screen immersive viewport (`width: 100vw; height: 100vh; overflow: hidden;`).
*   **Background:** Deep obsidian/near-black space (`#08080c` to `#000000` radial gradient) with sparse, floating abstract geometric triangle particles (`rgba(255, 255, 255, 0.1)`).
*   **Layout Architecture:** Two-column asymmetry on desktop:
    *   **Left Column (Typography & CTA):** Fixed/flex positioning taking up approximately 45% of the viewport width. Contains branding, main headline, subheadline, explanatory body text, and primary call-to-action button.
    *   **Right Column (Visual / 3D Asset):** Occupies the remaining 55% of the viewport. Features a high-density, particle-based 3D digital human brain composed of thousands of glowing triangular vector nodes in yellow, purple, cyan, and white.

---

## 2. Typography & Fonts

### Primary Font Families
The interface uses a clean, geometric grotesque sans-serif typeface similar to **Inter**, **Plus Jakarta Sans**, or **Geist Sans**.

*   **Fallback Stack:** `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`

## 4. Component Breakdown

### A. Navigation Header
*   **Position:** Absolute top, padding `24px 48px`.
*   **Layout:** Flexbox, `justify-content: space-between`, `align-items: center`.
*   **Left Element (Logo):**
    *   Geometric abstract cube/portal icon in multi-color gradient (Purple/Cyan/Blue).
    *   Brand text `"Dala"` in clean bold sans-serif (`18px`, White, subtle trademark `®` superscript).
*   **Right Elements (Nav Links & CTA):**
    *   Links: `MANIFESTO`, `TEAM`, `BLOG` (`13px`, uppercase, medium tracking).

### B. Hero Section (Left Column)
*   **Spacing:** `margin-top: 15vh`, `padding-left: 6vw`.

### C. Right Column (Neural Brain 3D Visualization)
*   **Element:** Particle-instanced 3D brain network rendered via WebGL (Three.js / React Three Fiber recommended).
*   **Visual Characteristics:**
    *   Composed of thousands of tiny luminous geometric triangles (`<triangle>` wireframes).
    *   **Color Distribution:** 
        *   Front/Bottom: Warm amber and gold clusters.
        *   Core/Left: Deep purple and violet volumetric lighting.
        *   Top/Right: White and subtle cyan starfield particles.
    *   Interactive custom cursor pointer floating near the center.

## 5. Animation & Interaction Specification

1.  **Page Load Entrance (Framer Motion / CSS Keyframes):**
    *   *Staggered Fade In:* Navigation bar slides down from `-20px` with `opacity: 0` to `1` over `0.6s`.
    *   *Hero Text Reveal:* Headline lines mask-slide upward from a hidden container with a `0.8s` cubic-bezier easing (`0.16, 1, 0.3, 1`).
    *   *3D Brain Initialization:* Particles scale up from center with a soft opacity fade and organic floating oscillation.
2.  **Interactive States:**
    *   **Nav Links:** Hover state triggers subtle color transition to `#FFFFFF` with a `0.2s` ease.
    *   **Buttons:** Hover triggers a slight brightness increase (`brightness(1.1)`) and a soft drop-shadow blur (`box-shadow: 0 0 20px rgba(124, 58, 237, 0.4)`).
    *   **Mouse Parallax:** The background 3D neural brain subtly tilts and reacts to mouse coordinates (`clientX / clientY`) for an immersive depth effect.
