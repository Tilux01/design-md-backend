# Design Specification: Fitness Dashboard UI

## 1. Global Layout & Structure
- **View:** Full-screen immersive web application (designed with a futuristic, translucent glassmorphism UI overlaying an interior living room background).
- **Color Palette:**
  - **Primary Base/Background:** Semi-transparent frosted glass (`rgba(255, 255, 255, 0.55)` or dark mode equivalents with heavy backdrop blur `blur(20px)`).
  - **Accent Colors:** 
    - Vibrant Orange (`#FF7A00` / `#FF8C00`) used for highlights, active states, and key data points.
    - Soft Greens (`#2ECC71`) for success, steps, and calendar dates.
    - Soft Pinks/Reds (`#E74C3C`) for heart rate and active calendar rings.
    - Dark Charcoal (`#2C3E50`) for main typography and structural borders.
  - **Text Colors:** Primary dark gray (`#222222`), muted gray (`#7F8C8D`) for secondary info and labels.
- **Typography:**
  - **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif.
  - **Fallback:** Sans-serif.
  - **Font Weights Used:** Regular (400), Medium (500), Semi-Bold (600), Bold (700).

---

- **Position:** Fixed to the left edge, vertical orientation, floating glass pill container.

  - Top icon: Dumbbell logo (Orange/Green gradient circle).

    - Dashboard grid icon (Active state: solid orange rounded rectangle background).
    - Analytics / stats graph icon.
    - Calendar / schedule icon.
    - Heart / vitals icon.
