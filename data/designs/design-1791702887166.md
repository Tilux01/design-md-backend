# Exact Design Blueprint: **AZENTOS / Pure Design Hero Page** (`design.md`)

This document serves as the complete, pixel-accurate design specification for recreating the full-screen web interface displayed in the reference image. This layout represents an ultra-minimalist, high-fashion agency/portfolio landing page combining brutalist typography with refined glassmorphic UI elements.

---

## 1. Global Viewport & Frame Rules
* **Canvas Dimensions**: Fullscreen edge-to-edge layout (`100vw` wide, minimum `100vh` tall).
* **Frame Removal**: Strip all outer device mockups, browser windows, or laptop frames. The design must render directly into the browser viewport seamlessly.
* **Scroll Behavior**: Smooth vertical scroll, custom thin scrollbar or hidden scrollbar.
* **Overall Style**: Monochrome grayscale, high contrast, editorial brutalism, tactile glassmorphism.

## 3. Typography Hierarchy & Font Fallbacks

### Primary Typography Rules

1. **Display / Headline Font** (Wide / Extended Grotesk)
   * **Exact Font**: *Neue Haas Grotesk Display Max*, *PP Neue Montreal*, or *Syne Bold*.
   * **Google / Standard Fallbacks**: `'Space Grotesk', 'Plus Jakarta Sans', 'Arial Black', sans-serif`.
   * **Characteristics**: Uppercase, tight line-height (`0.9`), wide tracking (`letter-spacing: -0.03em`), bold weight (700/800).

2. **Body & UI Font** (Technical Grotesk)
   * **Exact Font**: *Inter*, *SF Pro Display*, or *Helvetica Now*.
   * **Google / Standard Fallbacks**: `'Inter', system-ui, -apple-system, sans-serif`.
   * **Characteristics**: Clean geometric aesthetic, medium/regular weight (400/500), high legibility.

3. **Script / Accent Logos Font**
   * Custom brand SVGs or handwritten fonts (e.g., *Pacifico* / custom vector script for Dribbble-style branding).

## 7. Interactive States & Micro-Interactions

1. **Nav Items Hover**: Inactive nav pills change opacity from `0.6` to `1.0` with `transition: all 0.2s ease`.
2. **Book A Call & Contact Us Buttons**: Black fill transitions to dark gray (`#222222`), arrow icon translates diagonally `translate(2px, -2px)`.
3. **Glass Bar (`AZENTOS`)**: Subtle floating float animation keyframes (`transform: translateY(-4px)` over 4 seconds infinite ease-in-out).
4. **Circular Arrow Buttons**: Expand scale `1.05` on hover with shadow glow.
5. **Scroll Indicator**: Arrow bounces vertically infinitely (`translateY(0)` to `translateY(4px)`).
