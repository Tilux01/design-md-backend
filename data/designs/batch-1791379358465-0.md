# Comprehensive UI/UX & Frontend Architecture Specification

This document provides the exact structural, visual, styling, and behavioral blueprint required to build a pixel-perfect, fully responsive clone of the **Formix** brand agency landing page.

## 1. Global Page Setup & Design Tokens

### 1.1 Color Palette
*   **Background Base (`#0a0807`):** Deep, ultra-dark warm charcoal/espresso black dominating the secondary section.
*   **Hero Background Gradient (`#c13f1d` to `#6b1907`):** Rich burnt orange transitioning into deep amber/rust.
*   **Primary Accent (`#e0451a`):** Vibrant, high-visibility sunset orange used for primary CTAs, key stat highlights, and core branding cards.
*   **Pure White (`#ffffff`):** Dominant typography color across dark sections.
*   **Muted Text (`#a09590` to `#8c827d`):** Secondary descriptions, subheadings, and partner logo placeholders.
*   **Card/Container Background (`#141110`):** Slightly lifted dark neutral for internal cards, distinct from the `#0a0807` page canvas.

### 1.2 Typography System
*   **Primary Font Family:** `Inter`, `Plus Jakarta Sans`, or `system-ui, -apple-system, sans-serif`.
*   **Fallback Stack:** `sans-serif` (with font smoothing enabled: `-webkit-font-smoothing: antialiased;`).

#### Typographic Scale
*   **Hero Heading (H1):** `clamp(3rem, 5vw, 4.5rem)`, Line-height: `1.05`, Letter-spacing: `-0.03em`, Font-weight: `700`.
*   **Section Heading (H2):** `clamp(2rem, 3.5vw, 3rem)`, Line-height: `1.1`, Letter-spacing: `-0.02em`, Font-weight: `600`.
*   **Card Heading (H3):** `1.5rem` to `1.75rem`, Line-height: `1.2`, Font-weight: `600`.
*   **Body Text:** `0.95rem` to `1.05rem`, Line-height: `1.5`, Font-weight: `400`.
*   **Small/Caption Text:** `0.8rem` to `0.85rem`, Line-height: `1.4`, Font-weight: `400`.

## 3. Interactive States & Micro-Animations

### 3.1 Hover Effects
*   **Buttons & Pills:** Scale up slightly (`transform: scale(1.02)`), background color deepens or brightens by 10%, arrow icons shift diagonally up-right (`transform: translate(2px, -2px)`).
*   **Bento Cards:** Subtle lift effect (`transform: translateY(-4px)`, shadow deepens from `0 4px 20px rgba(0,0,0,0.4)` to `0 12px 32px rgba(0,0,0,0.6)`).

### 3.2 Page Animations (Framer Motion / CSS Keyframes)
*   **Hero Entrance:** Fade-in and slide-up (`opacity: 0 -> 1`, `translateY: 20px -> 0`) staggered across text elements, imagery, and floating cards.
*   **Bento Grid Stagger:** Scroll-triggered reveal where cards cascade into view sequentially with a duration of `0.6s` and cubic-bezier easing (`0.16, 1, 0.3, 1`).

---

## 4. Responsive Breakpoints Strategy

*   **Desktop (`> 1024px`):** Full multi-column bento grids, side-by-side hero layouts, floating UI elements fully visible.
*   **Tablet (`768px - 1023px`):** 2-column bento grid layouts, stacked hero content with imagery scaling down proportionally.
*   **Mobile (`< 768px`):** Single-column stacked layout for all cards, simplified navigation bar (hamburger menu toggle), and responsive typography scaling via `clamp()`.
