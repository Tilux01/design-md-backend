# Design Specification: GoMart Mobile Application

## 1. Typography & Hierarchy

* **Primary Typeface:** SF Pro Display (iOS native) or Inter
* **Fallback Stack:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
* **Hierarchy:**
  * **H1 (Hero Headlines):** 32px / Bold (700) / Line height: 1.2 / Letter spacing: -0.5px (`#111111`)
  * **H2 (User Name):** 15px / Semi-bold (600) (`#111111`)
  * **Body / Subtitles:** 14px / Regular (400) / Line height: 1.4 (`#71717A`)
  * **Input / Tags:** 13px / Medium (500) (`#18181B`)
  * **Micro-labels:** 11px / Regular (400) (`#A1A1AA`)

---

## 2. Color Palette

* **Primary Dark / Text:** `#121212`
* **Primary Light / Canvas:** `#FFFFFF`
* **Card & Tag Background:** `#F4F4F5`
* **Border Subtlety:** `#E4E4E7`
* **Secondary Text:** `#71717A`
* **Accent (Voice AI):** Linear gradient from `#7C5DF7` to `#6242EA`
* **Icon Inactive:** `#A1A1AA`
* **Floating Dock:** `#1C1C1E`

---

## 3. Screen 1: Onboarding / Welcome Screen

### 3.1 Status Bar
* Full native iOS status bar: Time (`10:41`), Dynamic Island cut-out, cellular, Wi-Fi, battery indicators.

### 3.2 Visual Grid (Hero Graphic)
* **Layout:** Asymmetric, rotated product collage angled at approximately -12°.
* **Tiles:** Rounded rectangular frames (`border-radius: 28px`) displaying high-end consumer hardware (smartwatch, gadget controls, sunglasses, ambient audio equipment).
* **Bottom Mask:** Linear gradient alpha mask fading from transparent to `#FFFFFF` starting at 65% vertical height to cleanly blend into the text container.

### 3.3 Text Block
* **Title:** "Welcome to\nGoMart" (Centered, 34px, Bold, `#121212`).
* **Description:** "Your go-to destination for smart, fast, and hassle-free shopping" (Centered, max-width: 280px, `#71717A`).

### 3.4 Call-to-Action
* **Button:** Full-width pill button (`height: 56px`, `border-radius: 9999px`, background: `#121212`, text: `#FFFFFF`, 16px font weight: 600).
* **Label:** "Next"
* **Spacing:** 24px padding from horizontal edges, 16px bottom padding above home indicator bar.

---

## 4. Screen 2: AI Search & Discovery Screen

### 4.1 Header Bar
* **Avatar:** 40px circular user profile image on the left.
* **Greeting:** Stacked text next to avatar:
  * Top: "Good Morning," (11px, `#A1A1AA`)
  * Bottom: "Jhonathon Troot" (14px, `#121212`, Semi-bold)
* **Action:** Right-aligned 40px circular subtle border button containing a minimal shopping bag outline icon.

### 4.2 Central Prompt Block
* **Vertical Alignment:** Positioned around 40% down from viewport top.
* **Heading:** "Need anything?" (30px, Bold, Centered).
* **Subheading:** "Our smart AI assistant helps you find exactly what you need—faster and easier than ever." (14px, Centered, max-width: 310px, `#71717A`).

### 4.3 Search / AI Input Bar
* **Container:** Pill-shaped text field (`height: 58px`, `border-radius: 9999px`, background: `#FAFAFA`, border: `1px solid #E4E4E7`).
* **Leading Icon:** Camera/Lens outline icon (`#71717A`).
* **Placeholder:** "Ask Anything..." (14px, `#A1A1AA`).
* **Trailing Action:** 44px circular purple accent button (`#7C5DF7`) with a centered soundwave/equalizer icon in white.

### 4.4 Quick Filter Chips
* **Layout:** Single-row horizontal scroll view (`overflow-x: auto`), `gap: 8px`, hiding scrollbars.
* **Chip Style:** Capsule (`height: 36px`, `border-radius: 9999px`, background: `#F4F4F5`, border: `1px solid #E4E4E7`, padding: `0 14px`).
* **Items:**
  1. Gift box icon + "Best mothers day gift"
  2. Sparkle/Ribbon icon + "Independent Day"
  3. Basketball icon + "Sports"

### 4.5 Floating Navigation Dock
* **Dock Container:** 
  * Dimensions: `height: 64px`, `border-radius: 9999px`, background: `#1E1E20`, padding: `6px 10px`.
  * Position: Fixed floating bottom dock, 24px above screen bottom, centered (`width: auto`, minimum 260px).
* **Navigation Items:**
  * **Search (Active):** White circle (`width: 48px`, `height: 48px`), containing dark search glass icon.
  * **Compass / Explore:** Unselected icon (`#8E8E93`).
  * **Planet / Hub:** Unselected icon (`#8E8E93`).
  * **Profile / Saved:** Unselected icon (`#8E8E93`).

---

## 5. Micro-Interactions & Animation Specs

* **Collage Entrance (Screen 1):** Subtle zoom-in (`scale: 0.95 -> 1.0`, duration: 600ms, easing: `ease-out`) and opacity fade.
* **Button Press Effect:** All buttons scale to `0.97` on active press with 150ms spring transition.
* **AI Mic Pulse:** Continuous soft pulsing glow on the trailing purple search button (`box-shadow: 0 0 12px rgba(124, 93, 247, 0.4)`).
* **Dock Tab Transition:** Morphing background bubble indicator with spring curve (`stiffness: 400`, `damping: 30`).
