# 1. Design Philosophy & Overall Aesthetic
- **Primary Mood:** Modern minimalist e-commerce & curation gallery with a clean, high-contrast editorial sensibility.
- **Brand Archetype:** High-end boutique retail, clean-tech minimalist, and modern consumer goods marketplace.
- **Visual Density:** Medium-low; high emphasis on generous whitespace, clean grid alignments, and card separation.
- **Theme Balance:** Light-mode dominant layout structured around clean neutral backdrops (`#F9F9F9` to `#FFFFFF`) paired with stark black typography, high-contrast image cards, and subtle hairline borders.

---

# 2. Color Palette & Design Tokens
- **Primary Color & Variants:** 
  - Default: `#000000` (Pure Black)
  - Hover: `#1A1A1A`
  - Active: `#333333`
- **Secondary & Accent Colors:**
  - Accent: `#EAEAEA` (Interactive borders / Neutral hover)
- **Base Background & Surface Backgrounds:**
  - Base Background: `#FFFFFF` (Page root / canvas)
  - Surface Backgrounds: `#F7F7F7` (Card containers, filter blocks)
- **Border & Divider Colors:**
  - Hairline: `#E5E5E5`
- **Text Colors:**
  - Primary Text: `#111111`
  - Muted Text: `#737373`
  - Inverse Text: `#FFFFFF`

# 3. Typography System & Hierarchy
- **Font Families:** 
  - Headings: `Inter`, system-ui, sans-serif
  - Body: `Inter`, system-ui, sans-serif
- **Scale Breakdown:**
  - **Section Title / Heading 2:** 20px / 28px, Font-weight: 600, Letter-spacing: -0.01em
  - **Card Title / Subheading:** 14px / 20px, Font-weight: 500, Letter-spacing: -0.005em
  - **Body / Item Label:** 13px / 18px, Font-weight: 400, Letter-spacing: 0em
  - **Caption / Metadata:** 11px / 14px, Font-weight: 400, Letter-spacing: 0.02em (Uppercase tags)

---

# 4. Layout Architecture & Spatial Grid
- **Container Max-Width:** 1200px centered with responsive horizontal padding (`24px` mobile, `48px` desktop).
- **Padding & Margin Scale:** 4px baseline grid (4px, 8px, 16px, 24px, 32px, 48px).
- **Section Sequence Breakdown:**
  1. Top navigation / Header utility bar.
  2. Primary Section Header ("Best-proof" or category dividers with center-aligned typography & decorative side rules).
  3. Product/Content Grid (4-column horizontal card track or responsive flex grid).
  4. Secondary Section Group ("Best-seller" category collections with thumbnail previews).
- **Stacking Order & Z-Index:**
  - Base canvas: `z-0`
  - Sticky Headers: `z-40`
  - Modals / Popovers: `z-50`

# 6. Motion Mechanics, Framer Motion & CSS Animation Code
- **Transition Durations:** 200ms to 300ms for micro-interactions and card hovers.
- **Easing Physics:** `cubic-bezier(0.16, 1, 0.3, 1)` (Smooth ease-out).

### Framer Motion Variant
```jsx

  hover: { 
    scale: 1.02,

  }
```

```css
    opacity: 0;
    transform: translateY(6px);
  }

    transform: translateY(0);
  }
```
