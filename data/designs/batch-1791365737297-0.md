# Design System

## Colors
- **Background Gradient:** `linear-gradient(135deg, #d3693e 0%, #a24b2b 50%, #462215 100%)` (Simulated via a rich orange-to-dark-brown atmospheric gradient)
- **Primary / Brand Orange:** `#f16723` (Used in jacket and text accents)
- **Dark Neutral / Charcoal:** `#1e1e1e` (Dark overlay/footer regions)
- **Light Text / Off-White:** `#ffffff` (Primary text elements)
- **Muted Text / Secondary:** `#c5927c` (Credits, labels)
- **Button / Panel Backgrounds:** 
  - Style button: `rgba(255, 255, 255, 0.15)`
  - Place Bid button: `#5c2e1f` (Deep brown)

## Typography
- **Font Family:** `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- **Vertical Branding Text ("POSSESSD"):**
  - Font Size: `82px`
  - Font Weight: `800`
  - Letter Spacing: `12px`
  - Transform: `uppercase`
  - Writing Mode: `vertical-rl`
  - Text Orientation: `mixed`
- **Navigation Items:**
  - Font Size: `14px`
  - Font Weight: `500`
  - Transform: `capitalize` / `uppercase`
- **Headings & Price:**
  - Price: `32px`, Bold (`700`)
  - Product ID: `12px`, Monospace/Light

## Layout & Structure
- **Screen Architecture:** Full-bleed viewport (`100vw` width, `100vh` height), absolutely no wrapper frames, drop shadows, or mockup borders.
- **Grid Layout:** 
  - **Left Sidebar:** Vertical branding text accompanied by 5 rounded navigation indicator dots. Footer social links (`IN`, `TW`, `YT`, `OS`).
  - **Header:** Top navigation spanning `Men`, `Women`, `Customise`, alongside `Search`, `My Account`, and a Cart icon.
  - **Center Stage:** High-fashion 3D mannequin wearing an orange textured puffer jacket, matching head/face wrap, and futuristic ski goggles.
  - **Right Panel (Product Specs):** 
    - Colour attribute: "Blood Orange"
    - ID: `3534R4`
    - Price: `$1250`
    - Action Buttons: `Style` and `Place Bid` (side-by-side pill/rounded rectangle design).
  - **Thumbnails Carousel:** Lower-center image switcher showing alternative colorways/outfit angles with a "Next →" prompt.
  - **Background Typography:** Oversized typographic watermark (`ELEC...`) fading into the dark lower-right vignette.

## Components & UI Elements
- **Navigation Dots:** 5 stacked rounded rectangles (`width: 16px`, `height: 8px`, `border-radius: 4px`, `background: rgba(255, 255, 255, 0.4)`).
- **Interactive Buttons:** Pill-shaped (`border-radius: 6px` or fully rounded), semi-transparent glassmorphism style over dark sections.
- **Credits Section:** Small font size (`11px`), line-height `1.5`, detailing agency credits (`@wesayhi`), AI generation (`@maison.meta`), retouching, and production team credits.
