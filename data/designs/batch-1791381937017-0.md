# Design Specification: Sellix Cross-Border Finance Landing Page

This document provides the exact design specifications, visual styles, typography, layout, and animation cues required to build a pixel-perfect, full-screen clone of the provided Sellix landing page. 

*Note: All device frames, bezels, perspective warps, and surrounding studio backgrounds from the source image are omitted. The implementation should render full-screen inside a standard browser viewport.*

---

## 1. Global Layout & Color Palette

### Color System
*   **Background (Canvas):** `#0a0a0f` (Deep, near-black space-navy)
*   **Primary Text:** `#ffffff` (Pure White)
*   **Secondary/Muted Text:** `#b3b3c2` (Soft cool gray for body copy)
*   **Brand / Glow Accents:** 
    *   Deep Violet: `#2b0057`
    *   Vibrant Purple: `#8a2be2` / `#a855f7`
    *   Neon Edge Glow: `#d8b4fe` to `#ffffff` (White-hot gradient highlights along the sphere rim)
*   **Buttons:**
    *   Primary (White Pill): Solid `#ffffff` background with `#0a0a0f` text.
    *   Secondary (Outlined Pill): Transparent background with a 1px solid white/translucent border (`rgba(255, 255, 255, 0.2)`).

### Layout Structure
*   **Viewport:** Full-screen (`100vw` width, `100vh` minimum height), vertically centered content.
*   **Max-width Container:** The main content wrapper centers at a max-width of approximately `1200px` with responsive horizontal padding (`24px` to `48px`).

---

## 2. Typography & Fonts

### Font Family Stack
*   **Primary Font:** **Inter** (Fallback: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`).
*   **Alternative Style Notes:** The headings use a geometric, high-contrast grotesque sans-serif style with tight letter-spacing and strong tracking control.

### Typography Hierarchy
1.  **Navigation Links:**
    *   Font-size: `14px`
    *   Font-weight: `400` (Regular)
    *   Color: `#b3b3c2` (Hover: `#ffffff`)
2.  **Logo ("Sellix"):**
    *   Font-size: `20px`
    *   Font-weight: `700` (Bold)
    *   Color: `#ffffff`
3.  **Hero Heading ("Cross-border finance"):**
    *   Font-size: `clamp(48px, 6vw, 76px)` (Responsive scaling)
    *   Font-weight: `700` (Bold)
    *   Line-height: `1.05`
    *   Letter-spacing: `-0.03em` (Tightly tracked)
    *   Alignment: Center
4.  **Hero Body Copy ("Accept payments, manage and custody..."):**
    *   Font-size: `clamp(15px, 1.2vw, 17px)`
    *   Font-weight: `400`
    *   Line-height: `1.5`
    *   Color: `#b3b3c2`
    *   Max-width: `540px`
    *   Alignment: Center
5.  **Button Labels:**
    *   Font-size: `14px`
    *   Font-weight: `500` (Medium)
    *   Letter-spacing: `-0.01em`

---

## 3. Header & Navigation

*   **Position:** Fixed or Sticky at the top of the viewport (`z-index: 100`).
*   **Layout:** Flexbox layout with space-between.
    *   **Left:** Brand Logo (`Sellix`).
    *   **Center:** Navigation links: `Products`, `Pricing`, `Developers`, `Resources`, `Contact Sales`. (Spaced with `32px` gaps).
    *   **Right:** Action buttons:
        *   `Login` (Text-only link, color `#ffffff`, weight `500`).
        *   `Get Started` (Pill button with right arrow icon `→`, dark background with white text or inverted depending on scroll state).

---

## 4. Hero Section & Globe Graphic

### Background Visual (The Dotted Globe & Purple Glow)
*   **Globe Treatment:** A stylized 3D sphere rendered using a dot-matrix / point-cloud pattern representing continental outlines (North America and Europe clearly visible).
*   **Color Profile:** 
    *   The globe matrix dots fade from deep purple into bright white/cyan nodes where light hits.
    *   Surrounded by a massive, soft radial gradient representing an atmospheric purple glow (`radial-gradient(circle, rgba(138, 43, 226, 0.4) 0%, rgba(10, 10, 15, 0) 70%)`).
    *   Scattered ambient starfield/dust particles (`rgba(255, 255, 255, 0.4)` dots of varying sizes `1px` - `2px`) floating in the background space.
*   **Layering Strategy:** 
    *   `z-index: 0`: Background canvas / starfield / glow.
    *   `z-index: 1`: 3D Dotted Globe graphic (positioned centrally behind the text).
    *   `z-index: 2`: Typography and interactive buttons.

### Hero Content Positioning
*   Vertically centered over the globe graphic.
*   Stacked column layout (Flexbox/Grid):
    1.  **Heading:** "Cross-border finance" (Line break between "Cross-border" and "finance").
    2.  **Paragraph:** Centered text block directly below the heading.
    3.  **CTA Button Group:** Horizontal row containing two pill buttons with a `16px` gap:
        *   `Get Started →` (Primary solid white button)
        *   `Contact Sales →` (Secondary outlined button)

---

## 5. Animation & Interaction Specs (For Implementation)

### Hover States
*   **Nav Links:** Smooth color transition to `#ffffff` over `0.2s ease`.
*   **Pill Buttons:** 
    *   Slight scale transform (`transform: scale(1.02)`) and brightness increase.
    *   Arrow icons (`→`) translate `4px` to the right on hover using CSS transitions (`transform: translateX(4px)`).

### Atmospheric Animations (Subtle Motion)
*   **Globe Rotation:** A slow, continuous 360-degree horizontal rotation along the Y-axis (e.g., complete rotation over `60s` linear infinite).
*   **Floating Star Particles:** Subtle random keyframe floating effect (`translateY` offset by `±5px` over `4s` ease-in-out infinite) to simulate a living space/cosmos background.
*   **Glow Pulsing:** The radial purple glow behind the globe should gently pulse in opacity (between `0.35` and `0.5`) over an `8s` loop to create an organic breathing effect.
