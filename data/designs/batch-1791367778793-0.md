# UI Layout Specification: Mobile E-Commerce Product Gallery

A responsive, high-density mobile e-commerce layout showcasing product imagery, color variant selectors, and styled lifestyle model shots in a vertical stack.

---

## Global Container & Reset
```css
.app-container {
  width: 100%;
  max-width: 480px;
  margin: 0 auto;
  background-color: #FFFFFF;
  font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
  box-sizing: border-box;
  overflow-x: hidden;
  display: flex;
  flex-direction: column;
}
```

---

## Component 1: Top Header / Hero Image Grid (2-Column)
A split grid showing two different lifestyle/product angles at the top of the view.

```css
.hero-image-grid {
  display: grid;
  grid-template-columns: 1fr 1fr;
  width: 100%;
  gap: 2px;
  background-color: #FFFFFF;
}

.hero-image-grid__item {
  position: relative;
  width: 100%;
  aspect-ratio: 4 / 5;
  overflow: hidden;
  background-color: #F5F5F5;
}

.hero-image-grid__img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  display: block;
}
```

## Design Tokens & Palette

| Token Name | Value | Usage |
| :--- | :--- | :--- |
| `--color-bg` | `#FFFFFF` | Main page background |
| `--color-surface` | `#F5F5F5` | Image skeleton/placeholder background |
| `--color-border` | `#EFEFEF` | Dividers and borders |
| `--color-primary` | `#111111` | Active state borders |
| `--spacing-unit` | `4px` | Base spacing scale |

---

## Responsive Breakpoints
* **Mobile (Default):** `max-width: 480px` (Full-bleed fluid layout matching app screenshots).
* **Desktop Wrapper:** Centered with max-width container, simulating mobile viewport presentation.
