# Design System Specification: Neumorphism Smart Home UI

---

## 1. Design Philosophy & Overall Aesthetic

- **Primary Mood:** Modern, tactile, clean, ambient, and physically intuitive (skeuomorphic-minimalist hybrid).
- **Brand Archetype:** High-end IoT dashboard, contextual home automation, user-centric simplicity.
- **Visual Density:** Airy and spacious with a low information-to-whitespace ratio, prioritizing glanceability and ergonomic touch targets.
- **Whitespace Balance:** Generous padding around all grouping containers. Outer page padding is large, creating a dedicated framed look.
- **Theme Balance:** Monochromatic soft light theme. Depth is entirely simulated through dual-shadow rendering (extruded highlights and deep ambient drop shadows) characteristic of strict **Neumorphism (Soft UI)**.

---

## 2. Color Palette & Design Tokens (HEX / HSL CODES)

### Backgrounds & Surfaces
- **Page Background:** `#E0E0E0` *(HSL: 0, 0%, 88%)* — Neutral light gray canvas.
- **Surface / Card Background:** `#E0E0E0` *(HSL: 0, 0%, 88%)* — Matches the canvas base to enable pure shadow/highlight illusion.
- **Raised Interactive Pill / Button:** `#E0E0E0` *(HSL: 0, 0%, 88%)*
- **Inset / Recessed Track & Container:** `#D6D6D6` *(HSL: 0, 0%, 84%)*

### Neumorphic Shadow Tokens
- **Light Highlight (Top-Left Source):** `rgba(255, 255, 255, 0.8)`
- **Dark Shadow (Bottom-Right Cast):** `rgba(163, 177, 198, 0.6)`
- **Inset Light Highlight:** `inset 2px 2px 5px rgba(255, 255, 255, 0.7)`
- **Inset Dark Shadow:** `inset -2px -2px 5px rgba(163, 177, 198, 0.6)`

### Text Colors
- **Primary Text:** `#2D3142` *(HSL: 228, 19%, 22%)* — Deep charcoal for maximum legibility.
- **Secondary / Muted Text:** `#7C8293` *(HSL: 221, 9%, 53%)* — Mid-gray for secondary labels and metadata.
- **Accent / Interactive:** `#2D3142` / Dark Charcoal with active states.

## 3. Typography System & Hierarchy

- **Recommended Font Families:** 
  - **Headings & Body:** Inter, SF Pro Display, System-UI sans-serif.
  - **Numbers / Metrics:** SF Pro Rounded (or equivalent geometric sans).

### Scale Breakdown
- **Screen Title:** 36px, Bold (700), Line-Height: 44px, Letter-Spacing: -0.5px.
- **Card Title / Value (Large):** 32px, Medium (500), Line-Height: 38px, Letter-Spacing: -0.2px (e.g., "24°").
- **Section Heading:** 16px, Semi-Bold (600), Line-Height: 22px, Letter-Spacing: 0px.
- **Body / Primary Label:** 14px, Medium (500), Line-Height: 18px, Letter-Spacing: -0.1px.
- **Secondary / Caption:** 12px, Regular (400), Line-Height: 16px, Letter-Spacing: 0.2px.

## 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** Fluid desktop frame centered on canvas (approx. 1024px working width).
- **Grid Structure:** Two-column asynchronous dashboard layout.
  - **Left Column:** Width ~460px (Primary control widget, grouped scene shortcuts, banner).
  - **Right Column:** Width ~380px (User profile header, analytics master container).
- **Spacing Scale:** 
  - `xs`: 4px
  - `sm`: 8px
  - `md`: 16px
  - `lg`: 24px
  - `xl`: 32px

## 5. Component Blueprint & Element Placement

### Cards & Containers
- **Border Radius:** `28px` to `36px` consistently applied across all primary cards.
- **Elevation / Shadows:**
  - *Default Card:* `8px 8px 16px rgba(163, 177, 198, 0.5), -8px -8px 16px rgba(255, 255, 255, 0.8)`
- **Inner Padding:** `24px` internal padding for major widgets.

### Air Conditioner Controller Widget (Hero Card)
- **Dimensions:** Width: ~440px, Height: ~440px.
- **Layout Top:** Horizontal flex. Left: Icon (Snowflake in embossed circle) + Title ("Air Conditioner") + Subtitle ("Auto Cooling") + Timer badge ("2h"). Right: "On." Toggle Switch with Power Icon.
- **Layout Center:** Circular arc dial gauge spanning 240 degrees (from 10°C to 40°C markers). Radial tick marks with a main selector handle pointing to 24°.
- **Center Value:** Large typography "24°" with "Temprature" label beneath.

### Scene & Quick Action Cards
- **Morning / Night Cards:** Width ~200px, Height ~160px. Features top-left icon (Sun/Moon), top-right status dots, bottom-aligned titles ("Morning Scene", "Night Scene") and device counters ("7 Devices").
- **Bottom Banner ("You created 8 scenes"):** Full-width pill container with inline leading plus-icon button and trailing "See All" pill button.

### List Items (AI Power Analytics Panel)
- **Item Container:** Inset or softly raised pill rows (`height: 56px`, `border-radius: 18px`).
- **Structure:** Leading icon inside a subtle inset circle, vertical text stack (Device Name + Units/kWh), and trailing chevron arrow button (`>`).

---

## 6. Motion Mechanics, 3D & Mobile Gestures

- **Animation Triggers:** 
  - Toggle switches: Smooth sliding thumb transition with state color inversion.
  - Rotary dial / Thermostat arc: Drag gesture along the angular track with real-time numeric updates.
  - Card press / Touch-down: Reverses shadow vectors (`inset` shadow state) to physically simulate a depressed button.
- **Suggested Transition Durations:** 
  - Micro-interactions (toggles, buttons): `150ms` to `200ms`.
  - Layout expansions / Panel swaps: `350ms` cubic-bezier(0.4, 0, 0.2, 1).
- **Haptic Hints:** Subtle medium-impact haptic feedback upon crossing temperature degree increments or toggling device states.
