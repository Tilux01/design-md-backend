# Design Specification: Finexy Financial Dashboard

## 1. Overview & Layout Strategy
This document outlines the exact specifications for a full-screen, responsive web financial dashboard. The design uses a dual-sidebar layout with a top navigation bar and a content area filled with modular cards displaying financial metrics, charts, wallet details, and recent activities.

- **Canvas Dimensions:** Designed for a desktop viewport (approx. 1440px wide).
- **Background Color:** Light neutral gray (`#F3F4F6` or similar off-white canvas).
- **Layout Structure:**
  - **Top Navigation Bar:** Fixed/sticky top containing branding, main tabs, search/notifications, and user profile.
  - **Left Sidebar:** Slim vertical icon-based navigation panel.
  - **Main Content Area:** A CSS Grid layout populated with rounded white (`#FFFFFF`) card containers with subtle shadows and corner radiuses.

---

## 2. Typography & Fallbacks
- **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif.
- **Font Fallback Stack:** If `Inter` is unavailable, fall back to system sans-serif fonts to maintain readability and exact UI metrics.
- **Weights Used:**
  - Regular (400): Body text, labels, secondary metadata.
  - Medium (500): Navigation items, table headers, card titles.
  - Semi-Bold (600): Key figures, primary buttons, user names.

---

## 3. Color Palette
- **Backgrounds:**
  - App Background: `#F4F5F7`
  - Card Background: `#FFFFFF`
- **Primary / Accent Colors:**
  - Orange/Coral Gradient & Solid: `#FF6B35` to `#FF8C42` (Used for Total Earnings card, active states, buttons, progress bars).
- **Text & Neutral Colors:**
  - Primary Dark (Headings/Numbers): `#111827`
  - Secondary Gray (Labels/Subtext): `#6B7280`
  - Border/Divider Gray: `#E5E7EB`
- **Status Colors:**
  - Completed (Green): `#10B981` (with soft green dot indicators)
  - Pending (Orange/Red): `#EF4444` / `#F59E0B`
  - In Progress (Yellow/Amber): `#F59E0B`
