## 5. Typography Specification & Fallbacks

### Primary Brand / UI Font: **Eurostile** / **Tesla Font**
*   *Fallback Stack:* `font-family: 'Eurostile', 'Orbitron', 'Helvetica Neue', Arial, sans-serif;`
*   *Usage:* Navigation items, big title (`ROADSTER`), and spec numbers.

### Secondary Body Font: **Inter** / **Roboto**
*   *Fallback Stack:* `font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;`
*   *Usage:* Subtitles and descriptions.

## 6. Animation & Interaction Specification

To ensure this concept functions as a high-end modern website, implement the following keyframe animations and interactive states:

1.  **Page Load Entrance:**
    *   **Fade In:** The entire main wrapper scales up slightly from `0.98` to `1.0` with an ease-out cubic bezier curve (`cubic-bezier(0.16, 1, 0.3, 1)`).
    *   **Text Reveal:** The background text `ROADSTER` slides upwards from behind the vehicle image with an opacity transition from `0` to `1`.
2.  **Spec Card Hover / Selection State:**
    *   Hovering over any of the sectors (`01` through `05`) triggers a bright red neon line (`#FF1E26`) to sweep across the top curved border of that sector.
    *   The corresponding vehicle stat scales up slightly (`transform: scale(1.05)`).
3.  **Car Parallax Effect:**
    *   As the user moves their mouse across the screen, the top-down Roadster image shifts slightly on the X and Y axes using a subtle mouse-move listener (`transform: translate(calc(var(--mouse-x) * 10px), calc(var(--mouse-y) * 10px))`) to create a 3D depth illusion.
