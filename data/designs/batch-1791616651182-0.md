# Design Specification (`design.md`)

## 1. Overview & Design Philosophy

This design is a sophisticated, minimalist, high-end landing page for an organic tech/educational platform (*SexTech School*). The aesthetic relies on ultra-soft, tactile luxury with a warm monochromatic nude palette. It features hyper-realistic, fluid 3D visual art paired with clean, ultra-modern typography.

The interface occupies the **full screen viewport** (100vw × 100vh) without outer device frames, shadows, or rounded canvas borders.

---

## 2. Color Palette

The palette is composed of soft skin tones, warm creams, blush neutrals, and deep espresso shadows.

| Role | Color Name | Hex Code | Usage |
| :--- | :--- | :--- | :--- |
| **Canvas / Background** | Soft Cream / Warm Nude | `#F5ECE5` | Base background color across the viewport |
| **Primary Text & Logo** | Espresso Dark / Near-Black | `#1A120E` | Navigation links, logo, interactive cues |
| **3D Image Highlights** | Pure Gloss White | `#FFFFFF` | Specular highlights on the liquid forms |
| **3D Soft Midtones** | Warm Flesh / Rose Beige | `#E0C0AE` | Primary body of the fluid structure |
| **3D Deep Shadow** | Deep Espresso / Core Shadow | `#2D1912` | Center cavity and deep sculptural folds |

---

## 3. Typography & System

The typography is ultra-clean, neutral, and minimalist. It uses a modern geometric sans-serif typeface set at light/regular weight with wide tracking for a delicate, refined look.

*   **Primary Font Family:** `Inter` or `Plus Jakarta Sans`
*   **Secondary/Fallback Fonts:** `SF Pro Display`, `Helvetica Neue`, `-apple-system`, `BlinkMacSystemFont`, `sans-serif`

```css
font-family: 'Inter', 'SF Pro Display', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
```

### Font Styles & Hierarchy

#### Navigation Links
*   **Font Size:** `13px` / `0.8125rem`
*   **Font Weight:** `400` (Regular) / `500` (Medium)
*   **Letter Spacing:** `0.02em` (Slightly relaxed tracking)
*   **Color:** `#1A120E`
*   **Transform:** Sentence Case / Title Case (`About`, `Podcast`, `Industry Hub`, `SexTech School`)

#### Call To Action ("Sign In >")
*   **Font Size:** `13px` / `0.8125rem`
*   **Font Weight:** `500` (Medium)
*   **Letter Spacing:** `0.02em`
*   **Color:** `#1A120E`
*   **Suffix:** Includes a subtle right angle bracket (`>`) with 4px left margin.

## 4. Visual Assets & Imagery Details

### 4.1. Brand Mark / Logo (Top Left)
*   **Type:** Abstract geometric pixelated mark.
*   **Appearance:** Consists of small, crisp dark brown/black rectangular blocks arranged in a stylized step pattern (an upright block, a horizontal block, and an isolated top-right pixel/dot).
*   **Color:** `#1A120E` (Solid).
*   **Dimensions:** `32px` wide × `18px` high.
*   **Placement:** Fixed top-left corner padding.

---

### 4.2. Main Hero 3D Artwork (Center Background)

*   **Asset Type:** High-resolution 3D Render (PNG with subtle background integration or full-bleed JPEG matching background `#F5ECE5`).
*   **Subject Matter:** An abstract, organic, liquid-sculpture featuring fluid, silky folds that resemble undulating skin, soft liquid satin, or layered anatomical curves.
*   **Key Compositional Elements:**
    *   **The Crest (Top Right):** A translucent, high-arched fluid wave rising smoothly toward the top-right corner, catching soft top light along its rim.
    *   **The Vortex / Core (Center-Left Bottom):** A deep, funnel-like depression that dips into rich espresso shadows (`#2D1912`). Inside this cavity, delicate, paper-thin, ribbon-like organic layers curve in tight concentric ridges.
    *   **The Foreground (Bottom Edge):** A glossy, horizontal liquid pool stretching across the entire width of the page, acting as the base for the sculpture.
*   **Surface Texture & Material Settings:**
    *   **Finish:** High-gloss glass/liquid hybrid with subtle subsurface scattering (soft light transmission through edges).
    *   **Reflection:** Highly reflective top edges with smooth, crisp white specular highlights (`#FFFFFF`).
*   **Placement & Alignment:**
    *   Centered horizontally (`left: 50%`, `transform: translateX(-50%)`).
    *   Spans approximately `90%` to `100%` of the screen width.
    *   Positioned to allow the soft cream top background to bleed into the top navigation area without obscuring legibility.

### Grid & Layout Properties

*   **Viewport:** `width: 100vw`, `height: 100vh`, `overflow: hidden`
*   **Main Container:** Full-bleed relative container.

#### Top Header Navigation (`<nav>`)
*   **Position:** `absolute` (or `fixed`), `top: 0`, `left: 0`, `width: 100%`, `z-index: 10`
*   **Padding:** `36px 56px` (Desktop)
*   **Layout:** Flexbox (`display: flex; justify-content: space-between; align-items: center;`)

##### Header Sections:
1.  **Left Block:** Holds the geometric Logo.
2.  **Center Block:** Holds the main navigation menu items.
    *   `display: flex`
    *   `gap: 48px`
    *   `align-items: center`
3.  **Right Block:** Holds the "Sign In >" action link.

---

## 6. Interactive Behavior & Hover States

*   **Navigation Items (`About`, `Podcast`, `Industry Hub`, `SexTech School`):**
    *   **Default:** `color: #1A120E`, `opacity: 0.85`, transition duration `0.2s ease`.
    *   **Hover:** `opacity: 1.0`, subtle shift or opacity focus.
*   **Sign In Button:**
    *   **Default:** `color: #1A120E`, `font-weight: 500`.
    *   **Hover:** The trailing arrow `>` moves horizontally `+3px` right using `transform: translateX(3px)` with `transition: transform 0.2s ease`.

---

## 7. Responsive Behavior Guidelines

*   **Desktop (> 1024px):** Full layout with expanded horizontal navigation menu (gap `48px`).
*   **Tablet (768px – 1024px):** Navigation item gap reduced to `24px`.
*   **Mobile (< 768px):**
    *   Main navigation items (`About`, `Podcast`, `Industry Hub`, `SexTech School`) collapse into a mobile hamburger menu icon on the top right.
    *   "Sign In >" remains visible or moves inside the mobile drawer.
    *   The 3D Hero image scales down (`object-fit: cover` or `contain`), retaining focus on the central dark vortex cavity.
