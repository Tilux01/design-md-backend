# UI/UX Specification & Design System Clone: "Find Your Tribe" Landing Page

This document outlines the exact specifications required to build a pixel-perfect, full-screen clone of the provided landing page. The design excludes any outer browser chrome or device mockup frames, scaling responsibilities to the full viewport.

---

## 1. Global & Layout Specifications

*   **View:** Full-screen responsive viewport (`width: 100vw; min-height: 100vh;`).
*   **Background Color:** Pure white (`#FFFFFF`) for the main canvas, with very subtle soft off-white canvas styling typical of modern SaaS landing pages (`#F8FAFC` or `#F9FAFB`).
*   **Grid System:** Max-width container centered horizontally (`max-width: 1280px`), utilizing absolute positioning for header elements and central flexbox layouts for the hero content.

---

## 2. Typography & Fonts

### Primary Typeface Family
*   **Primary Font:** **Inter**, fallback to **system-ui**, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `Helvetica`, `Arial`, sans-serif.
*   **Heading Font Weights:** Bold (700) and Extra Bold (800).
*   **Body Font Weights:** Regular (400) and Medium (500).

### Type Hierarchy Specs

1.  **Main Hero Heading ("Find Your Tribe, Build Your Network.")**
    *   **Font Size:** `48px` to `56px` (Responsive clamp: `clamp(36px, 4vw, 56px)`).
    *   **Line Height:** `1.15` (tight).
    *   **Font Weight:** Bold (700).
    *   **Color:** `#111827` (Gray 900).
    *   **Text Alignment:** Centered.

2.  **Hero Subtitle ("Connect with like-minded students for fun, friendships, and future opportunities.")**
    *   **Font Size:** `16px` to `18px` (`clamp(15px, 1.2vw, 18px)`).
    *   **Line Height:** `1.5`.
    *   **Font Weight:** Regular (400).
    *   **Color:** `#4B5563` (Gray 600).
    *   **Text Alignment:** Centered.

3.  **Navigation Links (Home, Community, Login, About Us)**
    *   **Font Size:** `14px`.
    *   **Font Weight:** Medium (500).
    *   **Color:** `#374151` (Gray 700).

---

## 3. Component Breakdown

### A. Navigation Bar (Header)
*   **Position:** Sticky / Fixed top (`top: 0`, `z-index: 50`).
*   **Padding:** `24px` horizontal/vertical padding relative to viewport edges.
*   **Left Element (Logo):**
    *   Brand wordmark (e.g., "Tribeout" or similar stylized script/sans-serif logo in dark slate `#0F172A`).
*   **Center/Right Navigation Items:**
    *   Links: `Home`, `Community`, `Login`, `About Us` spaced evenly (`gap: 32px`).
*   **CTA Button ("Get Started"):**
    *   **Background:** `#000000` (Black).
    *   **Text Color:** `#FFFFFF` (White).
    *   **Border Radius:** Full pill (`9999px`).
    *   **Padding:** `10px 20px`.
    *   **Font Size:** `14px` Medium.

### B. Hero Section Content
*   **Spacing:** Margin-top offset to push content cleanly beneath the navigation bar.
*   **Action Buttons:**
    1.  **Primary Button ("Join the Tribe"):**
        *   **Background:** `#111827`.
        *   **Text Color:** `#FFFFFF`.
        *   **Border Radius:** Full pill (`9999px`).
        *   **Padding:** `12px 24px`.
        *   **Shadow:** Subtle elevation (`box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.1)`).
    2.  **Secondary Action / Link ("Learn more about us"):**
        *   **Layout:** Inline flex with an icon (play button or info icon inside a small circle).
        *   **Text Color:** `#111827` Medium weight.
        *   **Hover Effect:** Opacity transition (`opacity: 0.8`).

### C. Hero Visual Element (3D Character Illustration)
*   **Asset Type:** High-resolution 3D Pixar-style character group artwork (indicative of modern AI or Blender-rendered student avatars).
*   **Placement:** Anchored to the bottom center of the viewport, overlapping slightly into the lower fold.
*   **Responsive Behavior:** Scales proportionally (`max-width: 100%`, height auto) maintaining aspect ratio without overflowing horizontally.

---

## 4. Color Palette

| Color Role | Hex Code | Tailwind Equivalent | Usage |
| :--- | :--- | :--- | :--- |
| **Primary Dark** | `#111827` | `gray-900` | Headings, Primary CTA background |
| **Secondary Text** | `#4B5563` | `gray-600` | Subtitles, secondary descriptions |
| **Nav Links** | `#374151` | `gray-700` | Header text links |
| **Surface Base** | `#FFFFFF` | `white` | Background canvas |
| **Accent / Button** | `#000000` | `black` | Navbar CTA button |

---

## 5. Micro-Interactions & Animations

*   **Button Hover States:**
    *   Scale up slightly (`transform: scale(1.02)`).
    *   Transition duration: `200ms cubic-bezier(0.4, 0, 0.2, 1)`.
*   **Nav Link Hover:**
    *   Color shift from `#374151` to `#000000` with a smooth `150ms` ease-in-out transition.
*   **Page Load Animation (Fade-Up):**
    *   *Hero Text & Subtitle:* Initial state (`opacity: 0; transform: translateY(20px);`), animating to (`opacity: 1; transform: translateY(0);`) over `600ms` with a `100ms` stagger delay.
    *   *Hero Illustration:* Slide up from the bottom with a slight fade-in (`opacity: 0; transform: translateY(40px);` $\rightarrow$ `1` / `0`) over `800ms`.
