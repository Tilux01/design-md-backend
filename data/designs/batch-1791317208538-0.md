# CARUPI Automotive Marketplace — Comprehensive UI/UX Design System Specification

---

## 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Brand Archetype**: Modern, trustworthy, clean, and consumer-centric automotive marketplace. Designed to streamline used car purchasing (`seminovos`) with security and transparency.
- **Visual Density**: Clean, airy, spacious layout with low-to-moderate density, relying heavily on generous padding and whitespace to emphasize clarity and approachability.
- **Whitespace Balance**: Intentional use of asymmetric asymmetry in the hero area (split layout with stark white typography canvas juxtaposed against a vibrant coral-red geometric background block).
- **Theme Balance**: Predominantly Light Mode (`#FFFFFF` base surfaces) accented by warm coral-red branding statements (`#FF5A43`) and deep navy-black typography (`#121826`).

## 4. Layout Architecture & Spatial Grid

- **Container Max-Width**: `1200px` centered with fluid horizontal padding (`24px` mobile, `48px` desktop).
- **Spacing Scale**: Based on an 8px grid (`4px`, `8px`, `16px`, `24px`, `32px`, `48px`, `64px`, `96px`).
- **Section Sequence Breakdown**:
  1. **Global Header / Navigation Bar**: Brand logo + navigation links ("Compra", "Venda", "Assine", "Ajuda").
  2. **Hero Section**: Value proposition headline ("Compre seu seminovo com praticidade e segurança"), search/filter bar (`Marca ou Modelo` / `Ano`), and floating isometric car visual against coral geometric background.
  3. **Partner Brand Strip**: Logos of validated trust partners / financing institutions.
  4. **Value Proposition Grid ("Com a CARUPI você evita")**: 3-column feature cards highlighting consumer pain-points solved (Fraudes, Perda de tempo, Custos surpresa).
  5. **Interactive Floating Elements**: Floating micro-cards (e.g., "Test drive onde quiser", "Seu novo carro na sua garagem").
  6. **Vehicle Catalog Grid**: Horizontal card carousels displaying available filtered models.

## 5. AI Design Traits, Micro-Badges & Special Glyphs

- **Pill Callout Badges**: Used for feature highlights and floating status cards.
  - *CSS Specs*: `padding: 6px 12px; font-size: 12px; font-weight: 600; letter-spacing: 0.05em; border-radius: 9999px; background: rgba(255, 90, 67, 0.1); color: #FF5A43; text-transform: uppercase;`
- **Iconography & Symbols**: Clean vector glyphs for location markers (`📍`), search indicators (`🔍`), and checkmarks (`✓`).
- **Floating UI Widgets**: Glassmorphism and high-elevation white cards (`backdrop-filter: blur(12px); background: rgba(255, 255, 255, 0.95); box-shadow: var(--shadow-lg); border-radius: 16px;`) overlapping hero backgrounds.

## 7. Motion Mechanics & Framer Motion Animation Code

- **Transition Durations**: Standard UI interactions use `0.2s` to `0.3s` with `cubic-bezier(0.16, 1, 0.3, 1)` (easeOutExpo).
- **Floating Floating Card Animation**: Gentle floating loop for overlapping floating cards.

```jsx
import { motion } from 'framer-motion';

export const FloatCard = ({ children, delay = 0 }) => (
  <motion.div
    initial={{ opacity: 0, y: 20 }}
    animate={{ 
      opacity: 1, 
      y: [0, -8, 0],
    }}
    transition={{
      opacity: { duration: 0.6, delay },
      y: { duration: 4, repeat: Infinity, ease: "easeInOut", delay }
    }}
    className="bg-white/95 backdrop-blur-md p-4 rounded-2xl shadow-xl border border-gray-100"
  >
    {children}
  </motion.div>
);
```

```css
@keyframes float {
  0%, 100% { transform: translateY(0px); }
  50% { transform: translateY(-8px); }
}

.animate-float {
  animation: float 4s ease-in-out infinite;
}
```

## 8. Accessibility (a11y) & WCAG Contrast Audit

- **Contrast Ratios**:
  - `#FF5A43` (Primary Red) on `#FFFFFF` Background: **3.02:1** (Passes WCAG AA for Large Text / UI Components; recommended to use `#D8432E` for small body text if required).
  - `#121826` (Primary Text) on `#FFFFFF` Background: **16.8:1** (Passes WCAG AAA).
  - `#475569` (Body Muted Text) on `#FFFFFF` Background: **7.4:1** (Passes WCAG AAA).
- **Keyboard Focus Rings**: 
  ```css
  *:focus-visible {
    outline: 2px solid #FF5A43;
    outline-offset: 2px;
  }
  ```
