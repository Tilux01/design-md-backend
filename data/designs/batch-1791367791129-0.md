# Ice Cream Shop Landing Page Design Specification

## 1. Global Styles & Theme
- **Color Palette:**
  - Background / Canvas: `#74C391` (Muted Green)
  - Primary UI / Card Container: `#3A9664` (Darker Green)
  - Cream / Drip Details (Bottom & Accents): `#FFFDF0` (Off-White / Cream)
  - Text Color (Main): `#FFFFFF` (White)
  - Text Color (Secondary / Accents): `#E2F5E9` (Light Mint Green)
- **Typography:**
  - Font Family: Clean, rounded sans-serif (e.g., *Poppins*, *Inter*, or *Quicksand*).
  - Headings: Bold, rounded, friendly weights.
  - Body: Regular weight, highly legible at small sizes.
- **Layout & Structure:**
  - Full-screen container (`100vw` / `100vh`) with a centered main website frame (or responsive fluid layout).
  - Distinct fluid "melted ice cream" organic shape baseline at the bottom edge.

---

## 2. Header & Navigation Bar
- **Position:** Fixed top, spanning the width of the main container with horizontal padding.
- **Left Element:** Logo / Brand Icon (minimalist icon placeholder).
- **Center Element:** Search bar / Navigation pill (`#FFFFFF` background, rounded corners, subtle shadow/border).
- **Right Elements:** Navigation icons / User actions (three circular icon placeholders in light green/white).

---

## 3. Hero Section

### Left Content Block
- **Headline:**
  - Text: `"Treats Day & Sweetly Scoop"` (Multi-line layout, bold, large font size).
- **Sub-headline / Description:**
  - Text: `"Delicious and creamy frozen treats made fresh daily."` (Smaller font, lighter weight).
- **Call-to-Action (CTA) Button:**
  - Text: `"Get Yours"`
  - Style: Pill-shaped button, dark green or contrasting accent color, bold white text.

### Right Visuals (Product Display / 3D Illustrations)
- **Main Cup (Center-Right):**
  - Large illustrated ice cream sundae / cup featuring soft-serve texture, toppings, and mint green branding.
- **Secondary Cup (Right):**
  - Smaller red/strawberry-themed ice cream cup illustration next to the main one.
- **Third Element (Far Right):**
  - A small, minimalist cone or popsicle icon floating as a decorative element.

---

## 4. Bottom Section
- **Organic Drip Wave:**
  - A smooth, cream-colored (`#FFFDF0`) wave graphic spanning the entire bottom width, overlapping the green background and giving a "melting ice cream" visual effect.
- **Footer Elements (embedded within the cream area):**
  - Left: Small branding badge or icon.
  - Right: Minimalist pagination dots or slider indicators.

---

## 5. Responsive Behavior
- **Desktop (1200px+):** Full multi-column layout with generous spacing.
- **Tablet (768px - 1199px):** Stacked content layout with scaled-down typography and illustrations.
- **Mobile (< 768px):** Single-column stack (Text content on top, illustrations centered below, full-width bottom wave).
