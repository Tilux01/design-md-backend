# Comprehensive Design Specification: Cardiology Dashboard (Full-Screen Clone)

This document provides a precise, pixel-accurate design and structural blueprint for recreating the Cardiology Dashboard UI displayed in the reference image. The layout is designed to be **full-screen (edge-to-edge)**, completely omitting outer device frames, window wrappers, or canvas backdrops.

---

## 1. Global Layout & Canvas Architecture

*   **View Mode:** Full-screen responsive web/desktop application (Target resolution baseline: 1440px width minimum).
*   **Background Color:** 
    *   Main Canvas/App Background: Light cream/off-white (`#F2F3EE` or `#F7F7F4`).
    *   Top Navigation Header: Dark charcoal/slate (`#2B2D31`).
*   **Border Radius System:** 
    *   Cards/Containers: Soft, heavily rounded corners (typically `16px` to `24px`).
    *   Pills/Badges: Fully rounded (`9999px` capsule style).
*   **Shadows & Depth:** Minimalist, soft, diffused drop shadows with low opacity to create subtle elevation (`box-shadow: 0px 4px 20px rgba(0, 0, 0, 0.04)`).

---

## 2. Typography Specification

### Primary Font Family Stack
*   **Primary Typeface:** *Inter* or *Plus Jakarta Sans* (Modern geometric sans-serif with clean terminal strokes).
*   **Fallback Stack:** `font-family: 'Plus Jakarta Sans', 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;`

### Hierarchy Rules
1.  **Header Title ("Cardiology"):** 
    *   Size: `20px` / `24px` (Bold, 700 weight).
    *   Color: Dark charcoal (`#1A1A1A`) inside light panels, white inside dark headers.
2.  **Patient Name ("Maya Blackwell"):** 
    *   Size: `16px` (Semi-bold, 600 weight).
3.  **Metric Values (89 bpm, 100%, etc.):** 
    *   Size: `24px` - `32px` (Bold/Extra-bold, 700/800 weight).
4.  **Labels & Secondary Text (Diagnosis, Avg, etc.):** 
    *   Size: `12px` - `14px` (Regular/Medium, 400/500 weight).
    *   Color: Muted gray (`#6B7280`).

---

## 3. Structural Breakdown & Component Details

### A. Top Navigation Header (Dark Section)
*   **Background:** Dark slate/charcoal (`#2B2D31`).
*   **Height:** ~70px.
*   **Elements (Left to Right):**
    *   **Search Bar:** Rounded pill container with a search icon and placeholder text ("Search patient..."), featuring a subtle inner background (`#3C3F44`).
    *   **Action Filters/Tabs:** Pill buttons for switching views or tools (e.g., *All*, *Analytics*, *List*, *Details*). Active states highlighted with solid white or accent tones; inactive states use muted text.

### B. Patient Profile & Vital Summary Header Panel
Located directly beneath the top navigation across the upper main canvas:

1.  **Patient Profile Card (Left):**
    *   **Background:** Off-white/cream rounded container with soft borders.
    *   **Content:** 
        *   **Image Description:** A professional portrait photo of a young woman with long dark hair, wearing a white top, looking toward the camera with a gentle, confident expression.
        *   **Text:** "Patient ID" / Name: **Maya Blackwell**.
2.  **Clinical Vital Metrics (Right of Profile):**
    *   Horizontal layout displaying key live indicators:
        *   **Diagnosis:** Hypertension (Highlighted tag).
        *   **Heart Rate:** `89` bpm (with a pulsing heart or activity icon).
        *   **Oxygen Saturation:** `100` % (SpO2).
        *   **Respiration Rate:** `18` breaths/min.
        *   **Body Temperature:** `36.6` °C.
    *   **Filter/Timeframe Toggles:** Pill buttons below metrics (*Day*, *Week*, *Month*, *Year*) with "Day" selected by default (solid dark pill style).

---

### C. Interactive Timeline & Clinical Workflow Tree (Core Canvas)

The central and lower area features a branching node-based timeline tracking patient data across time intervals (marked by numbered/lettered circular yellow nodes like **A** and **B**):

#### Node A & Node B Columns
*   **Connector Lines:** Thin, curved dark/gray bezier lines linking timeline nodes and sub-cards together.
*   **Sub-Cards & Modules (Attached to nodes):**
    *   **Blood Pressure Card:** 
        *   Header: "Blood Pressure" with a settings/menu icon.
        *   Visual Data: Dual-line chart or waveform graph indicating systolic/diastolic trends, accented with pale yellow background highlights (`#FDFDE0`).
        *   Data Footer: "Average 120/80" with status indicators (`+2%`).
    *   **Symptoms Card:**
        *   Header: "Symptoms".
        *   Content: Text listing ("Dizziness") accompanied by a minimal anatomical line-drawing illustration highlighting the chest/heart region.
    *   **ECG / Waveform Card:**
        *   Header: "ECG".
        *   Visual Data: Classic electrocardiogram sinusoidal wave readout plotted against a clean grid background.

---

### D. Bottom Dock / Floating Tool Bar

*   **Position:** Fixed or docked horizontally along the bottom center of the full screen.
*   **Design:** Floating dark/translucent pill toolbar containing quick-action icons:
    *   Annotation tools (pencil/brush markers).
    *   Zoom / scaling controls.
    *   Timeline scrubber indicators.
    *   Export / settings toggles.
