# UI/UX Specification & Design System: Kiwi Pie Interactive Showcase

This document outlines the exact visual specifications, layout architecture, typography, and motion design required to replicate the interactive "Kiwi Pie" landing page seen in the media.

---

## 1. Global Layout & Canvas Specifications

*   **Viewport:** Fullscreen (100vw × 100vh), responsive adaptation for desktop viewports.
*   **Background Style:** Deep, rich gradient with organic lighting effects.
    *   **Base Color (CSS):** Radial gradient shifting from `#4f7c46` (center-top) to `#244520` (edges).
*   **Visual Elements (Static Decors):**
    *   **Top-Right Kiwis:** Two sliced kiwis with water droplets overlaying the top right corner (`position: absolute; top: 2rem; right: 2rem; z-index: 2;`).
    *   **Left Kiwis:** A cluster of sliced kiwis overlapping the mid-left border (`position: absolute; top: 20%; left: -20px; z-index: 2;`).

---

## 2. Typography & Font Stack

The design relies on a clean, modern sans-serif typography system with high legibility.

### Primary Font Stack
*   **Font Family:** `Inter`, `SF Pro Display`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `Helvetica Neue`, `Arial`, sans-serif.

### Text Hierarchy

1.  **Main Heading ("KIWI PIE")**
    *   **Font Size:** `2.5rem` (Desktop) / `2rem` (Mobile)
    *   **Font Weight:** `700` (Bold)
    *   **Color:** `#FFFFFF`
    *   **Letter Spacing (Tracking):** `0.15em` (Wide)
    *   **Text Alignment:** Centered relative to its container.

2.  **Body Copy (Lorem Ipsum Description)**
    *   **Font Size:** `0.875rem` (14px)
    *   **Font Weight:** `400` (Regular)
    *   **Color:** `rgba(255, 255, 255, 0.85)` (Off-white / 85% opacity)
    *   **Line Height:** `1.5`
    *   **Text Alignment:** Centered (`max-width: 450px`).

3.  **Carousel Navigation Labels ("KIWI", "ORANGE", "BLUEBERRY", "STRAWBERRY")**
    *   **Font Size:** `0.8rem` (12.8px)
    *   **Font Weight:** `600` (Semi-Bold)
    *   **Color:** `#FFFFFF`
    *   **Text Transform:** Uppercase
    *   **Letter Spacing:** `0.1em`
    *   **Positioning:** Arranged along an arc path matching the circular carousel.

---

## 3. UI Component Breakdown

### A. Header Section
*   **Layout:** Flexbox column, centered horizontally.
*   **Spacing:** `margin-top: 4vh;`

### B. Circular Menu / Carousel Component
*   **Structure:** A rotating semi-circular arc interface positioned behind/around the main pie product image.
*   **Active Indicator:** A prominent white glowing dot (`width: 8px; height: 8px; background: #FFF; border-radius: 50%; box-shadow: 0 0 10px #FFF;`) marking the currently selected item ("KIWI").
*   **Navigation Arrow:** A faint, semi-transparent circular button with a right chevron (`>`) positioned on the right edge of the arc track (`background: rgba(255,255,255,0.15); border-radius: 50%; width: 36px; height: 36px; color: #FFF;`).

### C. Featured Product (Hero Element)
*   **Asset:** High-resolution circular render of a Kiwi Pie topped with whipped cream, kiwi slices, and gold dust/sprinkles.
*   **Container:** Circular wrapper with a subtle drop shadow and a thin golden/metallic border simulating a plate edge.
*   **Positioning:** Centered lower-middle viewport (`transform: translateY(10%)`).

---

## 4. Animation & Interaction Specifications

### 1. Carousel Rotation (Transition)
*   **Trigger:** Clicking the right arrow (`>`) or swiping horizontally.
*   **Easing:** `cubic-bezier(0.25, 1, 0.5, 1)` (Smooth deceleration).
*   **Duration:** `600ms`.
*   **Behavior:** The arc rotates smoothly, shifting the active text label ("KIWI" $\rightarrow$ "ORANGE") to the primary selection node, while the central product image cross-fades (`opacity: 0` $\rightarrow$ `1`) and scales slightly (`scale(0.95)` $\rightarrow$ `scale(1)`).

### 2. Floating Background Elements (Parallax)
*   The background kiwis exhibit a subtle floating CSS keyframe animation to create depth:
    ```css
    @keyframes float {
      0% { transform: translateY(0px) rotate(0deg); }
      50% { transform: translateY(-8px) rotate(2deg); }
      100% { transform: translateY(0px) rotate(0deg); }
    }
    .floating-kiwi {
      animation: float 6s ease-in-out infinite;
    }
    ```
