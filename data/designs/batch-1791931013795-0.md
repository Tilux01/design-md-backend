# Design Specification: Aer Landing Page

---

## 1. Color Palette & Theme

- **Background (Main)**: `#141416` (Deep charcoal/matte black)
- **Bottom Panel Fill**: `#1D1D20` (Slightly elevated dark gray)
- **Left Rail Background**: `#18181A` with top accent block `#222225`
- **Text Primary**: `#FFFFFF`
- **Text Secondary / Muted**: `#7C7C82`
- **Dividers / Borders**: `#2C2C30` / `rgba(255, 255, 255, 0.08)`

---

## 2. Typography

- **Primary Font**: `Inter`, `Helvetica Neue`, `Arial`, sans-serif.
- **Hierarchy**:
  - **Logo ("Aer")**: 24px, Bold (700), tight tracking.
  - **Hero Headline ("Work Anywhere")**: 48px–56px, Semi-Bold (600), line-height `1.1`.
  - **Hero Description**: 13px, Regular (400), line-height `1.5`, muted text with subtle underline accent.
  - **Nav Links / Sub-navigation**: 12px, Regular (400) to Medium (500).
  - **Section Labels (`EVENTS`, `NEWS`, `/ 01`)**: 10px–11px, Medium (500), uppercase, letter-spacing `1.5px`.
  - **Body / Metadata (Footer)**: 11px–12px, Regular (400).

---

## 3. Layout Architecture

A full-screen viewport layout (`100vw`, `100vh`) split into a fixed left rail and a main dynamic content area.

```
+----+---------------------------------------------------+
|    |  [Logo: Aer]              [Nav Links] [Search]    |
| R  |                                                   |
| A  |  [/ 01]              [Hero Image]   [Hero Copy]   |
| I  |  [Collections]       (Back view)    "Work         |
| L  |                                      Anywhere"     |
|    +---------------------------------------------------+
|    |  EVENTS (2 Cols)   | Thumbnail |  NEWS            |
+----+--------------------+-----------+------------------+
```

### 3.1. Left Sidebar Rail
- **Width**: `64px` fixed.
- **Top Section**: Square block (`64px × 64px`, `#222225`) containing a custom menu icon (three left-aligned horizontal bars: medium, long, short).
- **Bottom Section**: Social links (`Tw`, `In`, `Fb`) rotated 90° counter-clockwise, spaced vertically at `10px` font size.

---

## 4. Main Stage Layout

### 4.1. Header (Top Navigation)
- **Height**: `80px`, flexbox, items centered, horizontal padding `40px`.
- **Left**: "Aer" brand mark.
- **Right Nav List**: Horizontal flex, gap `28px`.
  - Items: `Home` (with a small underline indicator), `Products`, `About`, `Locations`, `Cart`.
  - Search trigger: Magnifying glass icon.

### 4.2. Hero Body Section
- **Central Focus**: Large hero visual centered vertically and horizontally.
- **Left Overlay**:
  - Counter: `/ 01`.
  - Divider: 1px thin horizontal line (`#2C2C30`, ~100px wide).
  - Collection Switcher:
    - `Work Collection` (White, active).
    - `Active Collection` (Muted gray).
    - `Travel Collection` (Muted gray).
- **Right Overlay**:
  - Title: "Work<br/>Anywhere".
  - Paragraph: "Introducing the Work Collection, a line of minimalist bags designed for a *new generation specifically for the modern professional*" (italicized phrase underlined).

### 4.3. Bottom Information Dock
- **Height**: `180px`, anchored to the bottom.
- **Background**: Solid `#1D1D20` with a `1px` top border (`#2C2C30`).
- **Grid Layout**: 3 columns (roughly `45%` | `18%` | `37%`).

#### Column 1: Events
- Top label: `EVENTS`.
- Content: Two-column sub-grid:
  - Event A: `Pop-up @ Steven Alan Fillmore` / `SF — Sat, August 12 / 5-8PM`.
  - Event B: `Pop-up @ Steven Alan Brooklyn` / `NYC — Sat, August 12 / 5-8PM`.
- Bottom: 3-dot carousel pagination indicators (dot 1 active white, dots 2–3 muted).

#### Column 2: Visual Thumbnail
- Full-height image cell fitting seamlessly inside the dock.

#### Column 3: News
- Top label: `NEWS`.
- Body: "A fresh take on our Active Collection, just in time for spring. Available in black."
- Action: "Read More" text link.

## 5. Imagery & Asset Specifications

### Image 1: Main Hero
- **Subject**: Medium-close shot of an anonymous person seen from behind, wearing a black technical hooded jacket and a matte black minimalist backpack.
- **Lighting & Style**: Low-key, moody studio lighting with gentle rim lights highlighting fabric textures against a solid dark gray backdrop.
- **Framing**: Centered horizontally, heads cut near the collar/hood apex, base aligned behind the lower dock.
- **Background**: Integrated dark background (no hard clipping or cutout borders).

### Image 2: Dock Thumbnail
- **Subject**: Full-body rear-three-quarter view of a man walking down an urban concrete ramp/hallway, wearing a beige/tan jacket and the black backpack.
- **Framing**: Portrait orientation, vertical framing filling the middle dock slot edge-to-edge.
- **Style**: Natural, muted architectural daylight.
