# 1. Design Philosophy & Overall Aesthetic
- **Primary Mood:** Modern, clinical yet approachable, highly professional, trusted healthcare companion.
- **Brand Archetype:** Caregiver & Creator — combining clinical accuracy with consumer-grade consumer app polish.
- **Visual Density:** Medium-high in data-heavy screens (dashboard), balanced with generous whitespace in content/hero cards.
- **Theme Balance:** Dual-mode architecture. Screen 1 and Screen 3 utilize clean, light-mode card-over-surface layouts (`#F4F6FB` backdrop), while Screen 2 employs a deep, immersive dark theme (`#081229`) optimized for high-contrast scanning of technical treatments and medical imaging.
- **Surface & Depth Architecture:** Multi-layered elevation system utilizing subtle shadows (`box-shadow`), backdrop blurs, and soft corner radii (`border-radius: 24px` to `36px`) to mimic iOS native glassmorphism and modern medical interface guidelines.

# 6. Motion Mechanics, Framer Motion & CSS Animation Code

- **Interaction Triggers:** Tap scaling on cards (`scale: 0.98`), smooth page/tab sliding transitions, ripple feedback on buttons.
- **Timing & Physics:** Spring animations with `stiffness: 300, damping: 30`.

### Framer Motion React Code Snippets
```jsx
import { motion } from 'framer-motion';

export const CardHoverMotion = ({ children }) => (
  <motion.div
    whileHover={{ scale: 1.02, y: -2 }}
    whileTap={{ scale: 0.98 }}
    transition={{ type: "spring", stiffness: 400, damping: 25 }}
  >
    {children}
  </motion.div>
);

export const ScreenTransition = ({ children }) => (
  <motion.div
    initial={{ opacity: 0, y: 15 }}
    animate={{ opacity: 1, y: 0 }}
    exit={{ opacity: 0, y: -15 }}
    transition={{ duration: 0.3, ease: [0.16, 1, 0.3, 1] }}
  >
    {children}
  </motion.div>
);
```

### CSS `@keyframes` Animation Snippet
```css
@keyframes pulseSubtle {

  50% { transform: scale(1.04); opacity: 1; }

  animation: pulseSubtle 3s ease-in-out infinite;
```

# 7. Accessibility (a11y) & WCAG Contrast Audit
- **Text Contrast Ratios:**
  - Primary Dark Text (`#0F172A`) on White Card (`#FFFFFF`): **16.5:1** (Passes WCAG AAA)
  - Primary Light Text (`#F8FAFC`) on Navy Card (`#0B1B3D`): **14.8:1** (Passes WCAG AAA)
  - Secondary Muted Text (`#64748B`) on White Card: **4.6:1** (Passes WCAG AA)
- **Focus Rings:** 
  - Standard interactive elements implement `focus-visible:ring-2 focus-visible:ring-blue-600 focus-visible:ring-offset-2`.
