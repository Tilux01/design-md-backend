# Design Specification: Noteform Pitch Deck Clone

This document outlines the exact design specifications for recreating the "Noteform Pitch Deck" interface presented in the provided media. 

---

## 1. Global Styles & Typography

### Fonts
The design relies on a bold, high-contrast, geometric sans-serif aesthetic, typical of modern editorial pitch decks. 

- **Primary Heading Font:** `Inter`, `Helvetica Neue`, `Arial`, sans-serif
  - *Weights Used:* Bold (700), Extra Bold (800)
- **Monospace/Data Font (Metrics):** `JetBrains Mono`, `SF Mono`, `Courier New`, monospace
  - *Weights Used:* Regular (400), Medium (500)

### Color Palette
- **Primary Red:** `#F02D22` (High-visibility vivid red used for brand identity and accent elements)
- **Dark Neutral (Dark UI):** `#111111` (Deep matte black used for dark-themed slides and interface cards)
- **Light Neutral (Light UI):** `#F4F4F4` (Off-white canvas for light-themed slides)
- **Text Primary (Dark Theme):** `#FFFFFF`
- **Text Secondary (Dark Theme):** `#888888`
- **Text Primary (Light Theme):** `#111111`
- **Text Secondary (Light Theme):** `#666666`

---

## 2. Layout Structure & Presentation (Full Screen)

The layout features a dynamic, cascading isometric/stacked deck presentation. For a full-screen, production-ready clone, the primary view should feature a **Master Slide / Carousel View** where cards transition smoothly into focus.

- **Background:** Clean solid background (suggested: `#E5E5E5` or dark gradient to create depth underneath the floating UI cards).
- **Layout Approach:** Flexbox / CSS Grid with 3D perspective transforms (`perspective: 1000px; transform: rotateX(...)`) to replicate the floating angled deck appearance.

---

## 4. Animation & Interaction Specifications

To match the dynamic presentation flow of the reference media:

1. **Scroll-Driven Parallax / Stack Effect:**
   - As the user scrolls or navigates, the cards scale down and shift upwards along the Y-axis with a slight 3D rotation (`rotateX(15deg) translateY(-20px)`).
2. **Card Hover State:**
   - Elevate the active card to the foreground (`scale(1.02)`, drop shadow increase).
3. **Fade-In Transitions:**
   - Text elements use an upward slide-fade (`opacity: 0; transform: translateY(20px)` transitioning to `opacity: 1; transform: translateY(0)` over `0.6s cubic-bezier(0.16, 1, 0.3, 1)`).
