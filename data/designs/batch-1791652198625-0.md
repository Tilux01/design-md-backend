# Comprehensive UI/UX Design Specification & Replication Blueprint

## 1. Global & Page-Level Setup
- **Theme/Mode:** Dark Mode (`#0a0a0a` base background)
- **Grid Structure:** Centered content layout with a max-width container (approx. 1200px content width), floating header spanning edge-to-edge with horizontal padding (`64px` desktop).
- **Primary Accent Colors:** 
  - Vivid Orange: `#FF5500` (Used for primary buttons, active states, key analytics trend lines, and critical highlights)
  - Dark Surface Base: `#121212` to `#161616` (Card backgrounds)
  - Subtle Border/Stroke: `#262626`
  - Text Primary: `#FFFFFF`
  - Text Secondary: `#9CA3AF` (Muted gray)

---

## 2. Typography Strategy & Fallbacks
*Note: Due to the high-end modern SaaS aesthetic, clean geometric or neo-grotesque sans-serif fonts are required.*

- **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif.
- **Fallback Stack:** `Arial, sans-serif`
- **Type Scale:**
  - **Hero Heading:** `56px` / Line height: `1.1` / Weight: `700` (Bold) / Color: `#FFFFFF` (with specific words highlighted in `#FF5500`).
  - **Section Heading (H2):** `36px` / Line height: `1.2` / Weight: `600` / Color: `#FFFFFF`.
  - **Card Heading (H3):** `18px` / Line height: `1.4` / Weight: `600` / Color: `#FFFFFF`.
  - **Body Text:** `14px` / Line height: `1.5` / Weight: `400` / Color: `#9CA3AF`.
  - **Navigation/Buttons:** `14px` / Line height: `1` / Weight: `500` (Medium).

---

## 4. Image & Graphic Assets Specifications
*Note: All UI mockups, charts, and icons must be implemented using native vector elements (SVG) or cleanly composed CSS cards rather than rasterized screenshots to maintain crisp scalability.*

1. **Brand Logo Icon:** Backgroundless SVG vector. Geometric orange dual-path flame/triangle mark.
2. **User Avatar / Cursor Graphic:** Backgroundless cursor pointer asset (`cursor-pointer.svg`) positioned precisely over the Performance Metrics chart node.
3. **Analytics Chart Lines:** Pure SVG polylines styled with stroke `#FF5500` and glowing drop-shadow filters (`filter: drop-shadow(0px 4px 12px rgba(255,85,0,0.4))`).
4. **Partner Logos:** Monochrome white/gray SVG vectors set to uniform height (`24px`) with variable widths based on brand proportions.
