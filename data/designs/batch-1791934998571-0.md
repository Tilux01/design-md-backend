# Design System Specification: HeroUI Pro License Showcase

## 1. Typography

* **Primary Font:** `Inter`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`.
* **Headings:**
  * Sub-badge: 13px, Medium (500), tracking +0.02em, Color: `#006FEE`.
  * Headline Line 1 ("Get your license."): 44px–48px, Bold (700), tracking -0.03em, Color: `#000000`.
  * Headline Line 2 ("Start building today."): 44px–48px, Regular (400), tracking -0.03em, Color: `#888888`.
* **Body & Labels:**
  * Navigation / Secondary links: 13px, Regular (400), Color: `#666666`.
  * Active Card Name ("Shutu"): 28px, Bold (700), Color: `#FFFFFF`.
  * Active Card Subtitle ("Web Hero"): 11px, Regular (400), Color: `#A1A1AA`.
  * Card Meta Labels ("Joined", "Member"): 10px, Regular (400), Color: `#71717A`.
  * Card Meta Values ("Jul 9, 2026", "# 1531"): 11px, Medium (500), Color: `#E4E4E7`.
  * Metadata text ("Shutu claimed 3 hours ago"): 12px, Regular (400), Color: `#71717A`.
  * Footer: 12px, Regular (400), Color: `#888888`.

## 2. Color Palette

* **Background:** Canvas: `#FFFFFF` (Full screen, no outer bezel/padding).
* **Text:**
  * Primary: `#000000`
  * Secondary / Muted: `#71717A`
  * Subdued Footer: `#888888`
  * Brand Accent: `#006FEE`
* **UI Elements:**
  * Pill Button ("Get HeroUI Pro"): Background `#000000`, Text `#FFFFFF`.
  * Secondary Pill ("View pricing"): Background `#FFFFFF`, Border `1px solid #E4E4E7`, Text `#18181B`, Shadow `0 1px 2px rgba(0, 0, 0, 0.05)`.
  * Carousel Arrows: Background `#FFFFFF`, Border `1px solid #E4E4E7`, Color `#71717A`.
* **Card Stack Colors:**
  * Active (Center): Dark Matte `#121214` to `#18181B`.
  * Back Left: `#3F3F46` / `#27272A`.
  * Back Right Stack: Deep Slate Blue (`#1E3A5F`) and Cerulean Blue (`#3884D6`).

## 3. Layout Structure

* **Page Layout:** Single full-viewport column (`min-h-screen`, `flex flex-col justify-between`, centered content).
* **Max Width:** `1280px` for navbar; content centrally constrained.

### Navigation Bar
* **Dimensions:** `h-16`, padding `px-8`, full width.
* **Left:** 
  * Logo mark: Geometric abstract rounded polygon.
  * Wordmark: "hero" (lower-case, bold).
  * Pill Badge: Text "Pro", background `#006FEE`, color `#FFFFFF`, border-radius `9999px`, padding `2px 8px`, font-size `10px`.
* **Right:** 
  * Horizontal link group (gap: `24px`): "Documentation", "Login".
  * Primary CTA: "Get HeroUI Pro" pill button (radius: `9999px`, padding `8px 16px`, text: `13px`).

## 4. Main Section (Hero & Showcase)

### Hero Header
* **Spacing:** `pt-16 pb-8`, centered text.
* Small badge: "HeroUI Pro" centered above headline.
* Two-line headline with tight leading (`leading-tight`).

### 3D Layered Card Carousel
* **Container:** Relative positioning, centered horizontally, width `400px`, height `380px`.
* **Navigation Controls:**
  * Circular buttons (`w-8 h-8`, rounded-full, flex center, border `#E4E4E7`).
  * Left arrow placed at `left: -48px`, vertically centered.
  * Right arrow placed at `right: -48px`, vertically centered.

#### Card Asset Descriptions & Layers
1. **Back-Left Layer:**
   * Dimensions: `240px x 340px`, corner-radius `24px`.
   * Appearance: Solid dark charcoal backgroundless vector surface. 
   * Placement: Offset `x: -30px`, rotated `-6deg`, `z-index: 1`, opacity `0.8`.
2. **Back-Right Layers (Stacked):**
   * Dimensions: `240px x 340px`, corner-radius `24px`.
   * Outer Blue: Offset `x: +35px`, rotated `+7deg`, deep ocean blue solid finish, `z-index: 1`.
   * Mid Blue: Offset `x: +20px`, rotated `+4deg`, bright electric blue, `z-index: 2`.
3. **Front Active Card:**
   * Dimensions: `250px x 350px`, corner-radius `24px`, `z-index: 10`.
   * Styling: Solid matte-black finish (`#121214`), subtle internal inset border `1px solid rgba(255,255,255,0.12)`, shadow `0 20px 40px -10px rgba(0,0,0,0.3)`.
   * Contents:
     * **Top:** Centered white Hero logo icon and "hero" label (`opacity: 0.8`).
     * **Middle:** Centered "Shutu" (large) with "Web Hero" subtitle below.
     * **Bottom:** Split two-column row with subtle separator line:
       * Left: "Joined" above "Jul 9, 2026".
       * Right: "Member" above "# 1531".

### Call to Action & Timestamp
* Text: "Shutu claimed 3 hours ago" (`mt-6 mb-4`, text-center, color `#71717A`).
* Button: "View pricing" (pill shape, centered, padding `8px 24px`, text `13px`, weight `500`).
