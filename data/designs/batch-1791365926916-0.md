## Component Specifications

### 1. Root Container
*   **Dimensions:** `100vw` width, `100vh` height.
*   **Background:** Solid `--bg-main`.
*   **Layout:** CSS Grid / Absolute positioning for overlapping abstract shapes on the right.
*   **Padding:** `40px 60px` (scaled relative to viewport).

### 2. Navigation Header
*   **Position:** Absolute top-left.
*   **Layout:** Flex row, gap: `32px`.
*   **Items:** `HOME`, `ABOUT`, `WORK`, `CONTACT`.
*   **Typography:** Uppercase, `--font-size-nav`, `--letter-spacing-nav`, font-weight: `500`.
*   **Color:** `--text-secondary`.
*   **Active State (`HOME`):** `--text-primary`.

### 3. Hero Text & CTA Block
*   **Position:** Absolute bottom-left (`left: 60px`, `bottom: 60px`).
*   **Heading:**
    *   Text: "Focussing on the power of teams"
    *   Font-size: `--font-size-heading`
    *   Line-height: `1.2`
    *   Color: `--text-gold`
    *   Weight: `600`
*   **Paragraph:**
    *   Text: "Unlocking the key to connect and synergise for you."
    *   Font-size: `--font-size-body`
    *   Color: `--text-secondary`
    *   Margin-top: `12px`
*   **CTA Button ("Feeling this"):**
    *   Padding: `12px 24px`
    *   Border-radius: `20px`
    *   Background: Linear gradient from `#d4af87` to `#b8865a` (Warm Gold)
    *   Color: `#1a1c1e` (Dark text for contrast)
    *   Shadow: `--shadow-outset`, combined with `--shadow-gold-glow`
    *   Hover/Active: Invert inner shadow (`--shadow-inset`).

### 4. Abstract Neomorphic / Skeuomorphic Art (Right Side)
Composed of layered SVG paths and CSS border-radius shapes utilizing dual drop-shadows (inset/outset) to create debossed and embossed physical UI impressions.

*   **Shape 1 (Top-Right Leaf):**
    *   Curved leaf/petal geometry pointing left.
    *   Debossed effect (`--shadow-inset`).
    *   Features an embedded circular indented well with a small protruding dot.
*   **Shape 2 (Top-Right Circle):**
    *   Concentric rings (embossed outer ring, debossed inner well).
*   **Shape 3 (Center Feature):**
    *   Large circular container (`width: 220px`, `height: 220px`, `border-radius: 50%`).
    *   Deeply inset (`--shadow-inset`).
    *   Exact center: A glowing raised metallic gold dot (`width: 14px`, `height: 14px`, background `--accent-gold`, radial shadow).
*   **Shape 4 (Bottom-Left Leaf):**
    *   Mirrored leaf shape extending from the center art block.
    *   Debossed with an indented small circular well.
*   **Shape 5 (Bottom Quarter Circle & Semicircle):**
    *   Interlocking geometric arcs completing the right-side grid matrix.
