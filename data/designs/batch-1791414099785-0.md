# Design Specification: Fitness Tracking Mobile Application (iOS/Android Clone)

This document provides the exact design specifications for cloning the fitness tracking interface shown in the source media. The specification assumes a full-screen mobile implementation, omitting device bezels and exterior hardware shadows.

---

## 1. Global Layout & Typography

### **Fonts & Fallbacks**
The UI uses a clean, modern sans-serif typeface matching Apple's **SF Pro** or Google's **Inter**.
*   **Primary Font Family:** `-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Inter", "Roboto", sans-serif`
*   **Font Weights Used:** 
    *   Regular (400) - Body text, labels, units
    *   Medium (500) - Secondary titles, chart labels
    *   Semibold (600) - Section headers, primary values
    *   Bold (700) - Large statistics / header values

---

## 2. Color Palette

### **Core Colors**
*   **Background (Primary):** `#FFFFFF` (Pure White)
*   **Card Background (Tinted):** `#F0F8EC` (Very light mint green, used for main summary cards)
*   **Card Background (Neutral):** `#F8F9FA` or `#F4F6F5` (Subtle off-white for metric cards)
*   **Text Primary:** `#1A1D1A` (Dark slate/near-black)
*   **Text Secondary:** `#737973` (Medium gray)
*   **Text Muted:** `#A4A9A4` (Light gray for disabled/inactive items)

### **Accent Colors (The "Neon/Lime Green" Theme)**
*   **Accent Primary (Lime Green):** `#86D233` (Used for active bars, primary states, toggle ON state)
*   **Accent Light (Pale Lime):** `#C4E89B` (Used for secondary chart bars or background gradients)
*   **Accent Dark/Olive:** `#4E7A1C` (Used for high-contrast text over light green)

### **Functional Colors**
*   **Danger / Red:** `#E04B4B` (Used for alerts, heart rate indicators, or toggle OFF states)
*   **Border / Divider:** `#EAEAEA`

---

## 3. Screen 1: Dashboard / Overview

### **3.1 Header**
*   **Top Bar:** Minimalist layout.
    *   Left: User avatar / Profile icon (circular, approx. `32px` diameter).
    *   Center/Left: Greeting or App Title ("Dashboard" / "Summary").
    *   Right: Notification / Settings icon (`24px`).

### **3.2 Main Summary Card (Top)**
*   **Container:** 
    *   Background: `#EAF6E2` (Soft lime gradient or solid fill)
    *   Border-Radius: `20px`
    *   Padding: `20px`
*   **Content:**
    *   Large primary text: **"Good morning!"** or **"Daily Activity Goal"** (Semibold, `18px`, `#2D4A16`)
    *   Large secondary value or progress stat (e.g., progress ring or completion status).
    *   Right side: Circular progress indicator ring (Lime green stroke on light green track).

### **3.3 Quick Metrics Grid (Row 1)**
*   A 2x2 or horizontal scrollable metric card layout.
*   **Card Style:**
    *   Background: `#F9FBF8`
    *   Border-Radius: `16px`
    *   Padding: `14px`
    *   Border: `1px solid #EFEFEF`
*   **Content Examples:**
    *   Metric 1: Heart Rate / Calories / Sleep (Icon + Label + Value + Unit).
    *   Typography: Value is Bold (`18px`), Label is Regular (`12px`, `#737973`).

### **3.4 Activity Breakdown (Bar Chart Widget)**
*   **Container:** Card with rounded corners (`16px`).
*   **Header:** "Activity Levels" or "Weekly Stats" with a small dropdown/chevron on the right.
*   **Chart Design:**
    *   Vertical bar chart showing days of the week (Mon–Sun).
    *   Bars are thin, rounded at the top (`border-radius: 4px`).
    *   Inactive bars: Light pale lime (`#D4EFC2`).
    *   Selected/Peak bar: Vibrant lime green (`#86D233`), slightly taller with a highlighted value label hovering above it.
    *   X-Axis Labels: Single letters (`M`, `T`, `W`, `T`, `F`, `S`, `S`) in muted gray (`11px`).

### **3.5 List Items (Toggles / Status Rows)**
*   Used for status monitoring (e.g., Sleep tracking, Hydration reminder).
*   **Layout:** Row with Icon -> Title/Subtitle -> Toggle Switch or Status Badge.
*   **Toggle Switch Style:**
    *   Width: `50px`, Height: `30px`, Border-Radius: `15px`.
    *   Active State (ON): Background `#86D233`, thumb aligned right.
    *   Inactive State (OFF): Background `#D1D1D6`, thumb aligned left.

### **3.6 Bottom Navigation Bar**
*   **Container:** Fixed to bottom, blurred translucent background (`backdrop-filter: blur(20px)`), white with subtle top border (`#EAEAEA`).
*   **Items (Left to Right):**
    1. Home / Dashboard Icon (Active, highlighted with a small lime dot or colored icon).
    2. Statistics / Analytics Icon.
    3. Central Floating Action Button (FAB): Large circular lime green button (`50px`) with a white icon in the center.
    4. Profile / Settings Icon.
    5. Menu / More Icon.
*   *Color:* Unselected items are `#A4A9A4`; Selected items are `#86D233`.

---

## 4. Screen 2: Statistics / Deep-Dive View

### **4.1 Header**
*   Title centered: **"Statistics"** or **"Activity"** (Semibold, `18px`).
*   Right action: Calendar / Filter button.

### **4.2 Primary Metric Display**
*   **Big Number:** E.g., **`12,345`** (Bold, `36px`, `#1A1D1A`).
*   **Unit/Label:** "Steps" or "Calories Burned" (`14px`, `#737973`).
*   **Trend Indicator:** Small pill badge showing `+12%` in green with an upward arrow.

### **4.3 Main Histogram Chart**
*   Tall vertical bar chart occupying the upper-middle section.
*   Grid lines: Subtle horizontal dashed lines (`#F0F0F0`).
*   Bars: Dynamic heights representing hourly or daily metrics. One specific peak bar stands out with a solid lime fill and value annotation above it.

### **4.4 Secondary Metric Cards (2-Column Grid)**
*   **Card 1 (Distance):** E.g., `8.4 km` with a mini line chart thumbnail.
*   **Card 2 (Active Time):** E.g., `1h 45m` with progress fill.
*   **Card 3 (Calories):** E.g., `650 kcal`.
*   **Card 4 (Heart Rate Zone):** E.g., `120 bpm` average.

---

## 5. Animations & Interactions

1.  **Tab Transitions:** Smooth slide or fade transition when switching between the Dashboard and Statistics screens.
2.  **Chart Bar Hover/Tap:** Tapping a bar in the histogram highlights it, scales it up by `5%`, and displays a tooltip popup with exact metric data.
3.  **Toggle Switch Animation:** Spring-based sliding animation when toggling settings on/off (`duration: 0.25s`, `easing: cubic-bezier(0.4, 0, 0.2, 1)`).
4.  **Pull-to-Refresh:** Standard native iOS/Android pull-to-refresh spinner at the top of the scrollable views.
