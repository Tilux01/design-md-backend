# Design Specification: Financial Mobile App UI (Clone Guide)

This document provides complete, production-ready design specifications to build an exact, pixel-perfect clone of the provided financial mobile application interface. 

This specification targets a **full-screen edge-to-edge responsive mobile viewport** (omitting the physical phone mockup frame, bezel, status bar notch, and shadows shown in the source media).

## 4. Component Technical Specifications

### A. Global Viewport Container
* **Background:** `--color-bg-dark`
* **Padding:** None (components handle internal safe-area offsets to ensure true edge-to-edge layouts).

### B. Header Elements
#### 1. Top Navbar Row
* **Height:** `56px`
* **Layout:** Flexbox, `justify-content: space-between`, `align-items: center`
* **Profile Picture:** `38px x 38px` circle. Clean metallic grayscale stylized avatar.
* **Notification Bell:** Transparent pill with custom SVG bell vector, thin stroke, colored in white.

#### 2. Balance Container
* **Margin Top:** `28px`
* **Layout:** Flexbox, `align-items: baseline`
* **Cents Offset:** `.43` font size is `55%` of primary balance text size, baseline-aligned, opacity `0.8`.

#### 3. Right Peak Card Preview
* **Position:** `absolute`, `right: -32px`, `top: 140px` (or aligned horizontally with the balance display).
* **Dimensions:** Width `64px`, Height `140px`.
* **Border Radius:** Left corners rounded `16px`, right corners hidden off-screen.
* **Background:** Smooth linear gradient transitioning from `--gradient-card-yellow` (top-left) to `--gradient-card-green` (mid) to `--gradient-card-cyan` (bottom).

#### 4. Action Buttons (Send & Request)
* **Gap:** `8px`
* **Send Button:**
  * Background: `--color-white`
  * Text Color: `--color-black`
  * Icon: Left-pointing arrow in a small dark outline circle inside the button.
  * Padding: `12px 20px`
  * Border Radius: `100px` (pill shape)
* **Request Button:**
  * Background: `--color-card-dark`
  * Text Color: `--color-white`
  * Padding: `12px 20px`
  * Border Radius: `100px`

#### 5. Spending Widget & Interactive Avatar Stack
* **Layout:** Flexbox, `align-items: center`, `justify-content: space-between`
* **Spending Box:**
  * Background: `--color-card-dark`
  * Padding: `16px 20px`
  * Border Radius: `20px`
  * Width: `60%`
* **Avatar Stack Overlay:**
  * Positioned to the right of the spending box.
  * Overlapping layout using negative margins (`margin-left: -10px`).
  * Circles details (order: bottom layer to top layer):
    1. **Exoplan Circle:** Teal-green background with white calendar `31` logo.
    2. **C Circle:** Vibrant orange background with stylized white `c` logo.
    3. **More Badge:** Vibrant blue background with `+2` text.
    4. **Threads Circle:** Dark background with white Threads spiral.
    5. **Apple Circle:** White background with dark gray Apple logo.
    6. **User Portrait:** Real photo avatar.

---

### C. Bottom Sheet (Transactions)
* **Position:** Fixed or absolute container attached to the viewport bottom.
* **Border Radius Top-Left / Top-Right:** `36px`
* **Background:** `--color-bg-sheet`
* **Top Spacing/Padding:** `24px` internal top padding.

#### 1. Header Row
* **Layout:** Flexbox, `justify-content: space-between`, `align-items: center`
* **Left Icon:** Horizontal filter line icon (three lines of varying widths).
* **Center Title:** "Transactions" in dark primary text.
* **Right Icon:** Minimalist search magnifying glass vector icon.

#### 2. Transaction List Items
* **Row Height:** `72px`
* **Layout:** Flexbox, `justify-content: space-between`, `align-items: center`
* **Icon Container:**
  * Rounded circle (`44px x 44px`) with dynamic background matching the brand (e.g., pure black background for Apple and Threads, bright green for Exoplan, bright orange for C).
  * **Tag Indicator Dot:** A small circular colored dot (`8px x 8px`) overlapping at the bottom-right of the main icon container (e.g., Apple icon has a cyan dot, Threads has a yellow dot).
* **Middle Column (Title & Subtitle):**
  * Layout: Vertical Stack, `gap: 2px`
  * Title text is crisp dark slate.
* **Right Column (Amount):**
  * Displays value with explicit spacing before currency symbol (`-60 $`, `2 000 $`).
  * Positive values use `--color-green-deposit` and exclude any plus sign (`2 000 $`).

### D. Floating Bottom Navigation Bar
* **Position:** Fixed at bottom center of viewport, suspended `24px` above the bottom edge.
* **Dimensions:** Width `220px`, Height `54px`.
* **Background:** `--color-nav-bg` (dark slate gray/black), transparency optional (`backdrop-filter: blur(10px)` with `rgba(25, 28, 33, 0.9)`).
* **Border Radius:** `100px` (pill container).
* **Flex Layout:** `display: flex`, `justify-content: space-between`, `align-items: center`, `padding: 0 8px`.
* **Children Elements:**
  * **Left Action (Grid):** A standard 2x2 modular grid dot icon.
  * **Center Capsule (Home):**
    * Dynamic highlight capsule: White background container, pill-shaped, height `40px`, width `70px`.
    * Contains the black "Home" icon.
  * **Right Action (Wallet):** Minimalist card-overlap wallet vector icon.

## 6. Interactions & Animations

### A. Bottom Sheet Gestures
* **Drag-to-Dismiss / Expand:** The white transactions container must support native drag-and-drop mechanics.
  * *Standard State:* Renders as shown, covering approximately `55%` of viewport height.
  * *Expanded State:* Dragging upward smoothly transitions the sheet container to `92%` height, hiding header metadata gracefully using opacity fades.
  * *Spring Dynamics:* Implement smooth spring physics instead of flat linear eases:
    ```javascript
    const springConfig = { damping: 25, stiffness: 180, mass: 0.8 };
    ```

### B. Touch States
* **Buttons (Send, Request, Navigation Items):**
  * Press state triggers immediate scale transform scaling downward slightly (`scale(0.96)`) using CSS transition properties:
    ```css
    transition: transform 0.15s cubic-bezier(0.2, 0.8, 0.2, 1);
    ```
* **Transaction Items:** 
  * Tap state should highlight the row with a momentary subtle background change (`rgba(0,0,0,0.03)`).

### C. Entry Animations (Page Load)
To produce an elite, high-end production application feel, chain page load actions in this specific order:
1. **Background Dark:** Fades in immediately.
2. **Balance & Peeking Card:** Slide in horizontally from the right edge with a elastic bounce.
3. **Transaction Bottom Sheet:** Slides upward from the bottom of the screen (`transform: translateY(100%)` to `0`) with a duration of `0.6s` using an out-exponential ease: `cubic-bezier(0.16, 1, 0.3, 1)`.
