# UI/UX Specification & Frontend Architecture Document
**Project:** Cyberpunk E-Commerce Landing Page ("Hoodie")
**Viewport Target:** Fullscreen Responsive (Desktop First: 1440px Base)
**Aesthetic Profile:** Brutalist-Minimalist Streetwear, Monochromatic Techwear, Cyberpunk Industrial.

---

## 1. Global Styles & Design Tokens

### 1.1 Color Palette
*   **Primary Background (Canvas):** `#F0F2F4` (Cool Off-White/Light Gray)
*   **Primary Surface / Dark Block:** `#1A1E21` (Matte Dark Charcoal / Near Black)
*   **Secondary Surface / Sage Accent:** `#7B9085` (Muted Sage Green - used for "New Arrivals" module and selective branding)
*   **Text Primary:** `#0D0E0F` (True Obsidian Black)
*   **Text Secondary / Subdued:** `#687179` (Cool Medium Gray)
*   **Text Inverted / Light:** `#FFFFFF` (Pure White)
*   **Border / Divider:** `#D6DADE` (Subtle UI Border)
*   **Highlight / Accent:** `#D94E34` (Industrial Safety Orange - used sparingly for rating stars or interaction hints)

### 1.2 Typography System
*   **Primary Font Family (Headings/Display):** `Space Grotesk`, sans-serif
*   **Fallback Font Stack:** `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
*   **Body Font:** `Inter`, sans-serif

#### Type Scale:
*   **Hero Brand Title:** `72px`, Font Weight: `700`, Line Height: `1.0`, Tracking: `-0.03em`
*   **Section Heading (H2):** `32px`, Font Weight: `600`, Line Height: `1.2`, Tracking: `-0.02em`
*   **Card Title (H3):** `18px`, Font Weight: `500`, Line Height: `1.3`
*   **Body Text:** `14px`, Font Weight: `400`, Line Height: `1.5`
*   **Micro / Tags / Nav:** `12px`, Font Weight: `500`, Letter Spacing: `0.05em`, Uppercase

---

## 2. Layout Structure & Grid Architecture

*   **Max Container Width:** `1280px` centered with auto margins.
*   **Grid System:** 12-Column Flexible Grid with `24px` gutter spacing.
*   **Layout Flow:** Vertical stacking sections with generous whitespace (`80px` to `120px` vertical padding between major sections).

---

## 3. Component-by-Component Breakdown

### 3.1 Header / Navigation Bar
*   **Position:** Fixed / Sticky top navigation.
*   **Background:** Transparent with a subtle backdrop blur on scroll (`backdrop-filter: blur(8px)`).
*   **Height:** `80px`
*   **Elements:**
    *   **Left:** Brand Logo ("Hoodie") in Bold `Space Grotesk`.
    *   **Center:** Navigation Links (`Shop`, `Product`, `Manufacturing`, `Collection`). Active link styled with a subtle indicator.
    *   **Right:** Utility icons (Search, Cart with counter badge, User profile).

---

### 3.2 Hero Section
*   **Layout:** Two-column asymmetric split (55% Left text/CTA, 45% Right Hero Image).
*   **Left Column Content:**
    *   Sub-brand identifier / Category Tag.
    *   **Hero Heading:** Massive typography reading `"Hoodie"` with overlapping product imagery.
    *   **Lead Paragraph:** Short, concise descriptive text about the techwear/cyberpunk collection.
    *   **CTA Buttons:** Primary solid black button ("Add to Cart") + Secondary outline button ("Quick view").
*   **Right Column Content:**
    *   Large cut-out hero photography of a model wearing the signature sage green hoodie with a bucket hat.
    *   Absolute-positioned carousel indicators (`01 / 04`).
    *   Subtle circular background geometry (`#E2E6E9`).

---

### 3.3 Dual Category Banner Section
*   **Layout:** Two side-by-side promotional cards spanning the container width.
*   **Left Card ("New Arrivals"):**
    *   Background Fill: `#7B9085` (Muted Sage).
    *   Content: Product photography silhouetted over the colored block, bold white title, and dual sub-filters (`Men` / `Women` pill buttons).
*   **Right Card ("Accessories"):**
    *   Background Fill: `#E5E8EB` (Light Neutral).
    *   Content: Modular tactical backpack photography, bold dark title, and dual sub-filters (`Men` / `Women`).

---

### 3.4 Feature / Durability Callout Section
*   **Layout:** Offset asymmetric layout highlighting material engineering.
*   **Visuals:** High-contrast editorial photography of techwear jacket details.
*   **Typography:** Clear heading ("Durability") paired with technical spec descriptions emphasizing weather-resistance and reinforced stitching.

---

### 3.5 "Our Products" Catalog Section
*   **Section Title:** Centered heading ("Our Products").
*   **Category Filter Bar:** Horizontal pill-style filter tabs (`All`, `Outerwear`, `Tops`, `Bags`, `Accessories`, etc.). Active state highlighted in solid dark charcoal.
*   **Product Grid:** 3-Column layout featuring card components:
    *   **Card Design:** Minimalist borderless container with soft hover elevation (`box-shadow: 0 10px 30px rgba(0,0,0,0.05)`).
    *   **Image Container:** Light gray background (`#F7F9FA`) with centered product shots.
    *   **Card Footer:** Product Name, SKU/Category tag, and Price (`$XXX`).

---

### 3.6 Testimonials Section
*   **Layout:** Multi-card horizontal slider or grid layout.
*   **Card Styling:** Clean white surface card on top of the gray canvas with a subtle drop shadow.
*   **Elements:** 5-star rating graphic, customer quote text, and user avatar with verified badge and name.

---

### 3.7 Newsletter / Footer Callout
*   **Layout:** Full-width dark block (`#1A1E21`) with rounded internal container corners.
*   **Content:**
    *   Heading: "Subscribe our newsletter"
    *   Input Field: Inline email input with an arrow submission button.
    *   Interactive UI Preview / Chat Widget mockup positioned on the right side of the block.

---

## 4. Animation & Interaction Specifications (CSS / Framer Motion)

*   **Hover States (Buttons):** Scale up slightly (`transform: scale(1.02)`), transition duration `0.25s cubic-bezier(0.16, 1, 0.3, 1)`.
*   **Image Reveal / Parallax:** Subtle zoom effect on product cards when hovered (`transform: scale(1.05)` over `0.4s`).
*   **Page Load Stagger:** Elements fade in from bottom-to-top with a `0.1s` stagger delay using `opacity: 0 -> 1` and `translateY(20px) -> translateY(0)`.
*   **Slider/Carousel Transition:** Smooth horizontal slide with momentum scrolling or pagination dot triggers.
