# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Futuristic Cyber-Intelligence Dark/Light Glassmorphism Enterprise SaaS (Resadex brand identity).
- **Visual Density & Whitespace Ratio**: High whitespace focus with prominent floating card surfaces (`Surface-1`), balanced inner container padding (`24px` to `48px`), and generous outer framing.
- **Surface Elevation Model**: Layered depth architecture featuring a frosted glass floating navigation pill (`backdrop-filter: blur(16px)`), distinct rounded content containers (`border-radius: 24px`), and soft ambient inner drop-shadows with subtle 1px translucent borders (`rgba(255, 255, 255, 0.4)`).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase navigation links, glassmorphic floating header capsule, abstract 3D matte-spherical node graphics, balanced soft shadows, monochrome-indigo tech aesthetic.
- **Pill Badge Specification**: Padding: `6px 16px`, Font-size: `12px`, Font-weight: `600`, Tracking: `0.05em`, Border-radius: `9999px`, Background: `rgba(255, 255, 255, 0.8)`, Border width: `1px solid rgba(203, 213, 225, 0.8)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Arrow Icon -> Use SVG inline `<svg viewBox="0 0 24 24" fill="none" stroke="currentColor"><path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M14 5l7 7m0 0l-7 7m7-7H3"/></svg>`.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-blue-600 inline-block"></span>`.
