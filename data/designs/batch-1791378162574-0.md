# UI/UX Design Specification & Implementation Guide

## 1. Executive Summary & Design Overview

This specification details the recreation of a dark, emerald-green e-commerce / catalog interface specializing in houseplants. The design employs a **Neumorphic / Soft UI** approach merged with high-end digital art direction. 

*   **Design Philosophy:** Minimalist luxury, organic ergonomics, tactile depth via subtle gradients and soft inner/drop shadows.
*   **Viewport Handling:** Full-screen layout with an infinite vertical scrolling grid experience. No rigid card wrappers around the viewport; instead, the entire interface breathes on an expansive, layered emerald canvas.
*   **Color Palette:** Monochromatic shades of deep forest, jade, and mint green, offset by earthy pot tones (terracotta, slate, natural wood).

---

### Color Tokens

## 3. Typography Strategy

The interface uses a mix of organic, rounded display fonts for branding and clean, highly legible sans-serif typefaces for UI navigation and product metrics.

### Font Family Stack & Fallbacks

1. **Brand / Display Header (`DHOLCISH` & Navigation):**
   * *Primary:* `Clash Display`, `Cabinet Grotesk`, or `Syne` (Geometric, wide aperture, art-directed display font).
   * *Fallback:* `Impact`, `Arial Black`, `sans-serif`.

2. **UI Labels, Navigation, & Pricing (`Habrus`, `Sters`, etc.):**
   * *Primary:* `Plus Jakarta Sans`, `Inter`, or `DM Sans`.
   * *Fallback:* `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `sans-serif`.

### Typography Hierarchy Table

| Role | Font Family | Weight | Size (Desktop) | Line Height | Letter Spacing |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Brand Logo** | Display / Custom | Regular | `24px` / `1.5rem` | `1.2` | `0.05em` |
| **Nav Links** | Sans-Serif | Medium | `13px` / `0.8125rem` | `1.0` | `0.02em` |
| **Action Button** | Sans-Serif | Semi-Bold | `14px` / `0.875rem` | `1.0` | `0.04em` |
| **Product Title** | Sans-Serif | Medium | `13px` / `0.8125rem` | `1.3` | `0.01em` |
| **Product Subtitle**| Sans-Serif | Regular | `11px` / `0.6875rem` | `1.2` | `0.0em` |

## 4. Layout Architecture & Grid System

### Global Viewport Setup
*   **Dimensions:** Full viewport width (`100vw`) and height (`100vh`), scrollable vertically.
*   **Padding:** Desktop wrapper uses a comfortable lateral margin (`64px` left/right, `32px` top/bottom).

### Grid Configuration (Product Catalog)
*   **Layout:** CSS Grid with 3 columns.
*   **Gap:** `24px` row gap, `24px` column gap.
*   **Card Structure:** Each card is rendered as a rounded rectangle with soft inset highlights, acting as a small display podium for each 3D botanical asset.

---

## 5. Component Breakdown & Micro-Interactions

### A. Navigation Header
*   **Left:** Hamburger Menu Icon (3 horizontal clean lines).
*   **Center-Left:** Sub-navigation links (`Habrus`, `Sonere`) with soft hover states shifting from `--text-muted` to `--text-main`.
*   **Center:** Brand Logotype (`DHOLCISH`) rendered in a wide, stylized custom typography.
*   **Right:** Pill-shaped Action Button (`Sters`) with a soft mint background (`--accent-mint`), dark text, and slight ambient glow on hover.

### B. Product Cards (Podium Style)
*   **Background:** `--bg-surface` with an inner shadow/border effect simulating soft relief.
*   **Visual Element:** Centralized high-fidelity 3D plant render standing on a floating minimal shelf/podium.
*   **Footer Data:**
    *   *Left side:* Two-line text block (Product Name + SKU/Variant count).
    *   *Right side:* Circular micro-action icon (Cart / Quick-view toggle button framed in a dark pill or circle).

### C. Bottom Indicator
*   Centered pagination or category scroll indicator pill (`Sext.oll`) at the bottom of the viewport viewport base.

---

## 6. Animation & Interaction Specification

### Hover States
*   **Product Cards:** 
    *   `transform: translateY(-4px) scale(1.01);`
    *   `background-color: var(--bg-surface-hover);`
    *   `box-shadow: 0 16px 32px rgba(0, 0, 0, 0.4), inset 0 1px 0 rgba(255, 255, 255, 0.1);`
    *   *Transition:* `all 0.3s cubic-bezier(0.16, 1, 0.3, 1);`

*   **Interactive Icon Badges (Cart/Action):**
    *   Scale up slightly (`1.1x`), background tint shifts to `--accent-mint`, text/icon color inverts to dark emerald.

### Page Load Sequence (Staggered Entrance)
1.  **Header:** Fades down from `y: -20px` to `0`, opacity `0 -> 1` (Duration: `0.6s`).
2.  **Product Grid:** Staggered card appearance using a grid index delay (`index * 0.08s`), scaling up from `0.95` with fade-in.
