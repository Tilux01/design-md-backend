# Design Specification: Nike ACG Product Landing Page

## 1. Global Styles & Layout
- **Canvas**: Full-screen desktop (`100vw`, `100vh`), overflow hidden.
- **Background Color**: `#F4F4F6` transitioning seamlessly to white `#FFFFFF` toward the right.
- **Grid Structure**: 2-column split (Left: 45% product details; Right: 55% model image & navigation counters).

---

## 2. Typography
- **Primary Font**: Helvetica Neue, Inter, or SF Pro Display.
- **Fallback Font**: Arial, sans-serif.

### Type Scale
| Element | Size | Weight | Color | Spacing / Style |
| :--- | :--- | :--- | :--- | :--- |
| **Nav Links** | 12px | Regular (400) | `#000000` | Normal |
| **Category** | 14px | Medium (500) | `#000000` | `letter-spacing: -0.2px` |
| **Title (Nike ACG)** | 56px | Bold (700) | `#000000` | `letter-spacing: -1.5px` |
| **Price** | 22px | Bold (700) | `#000000` | Inline with sizes |
| **Sizes** | 12px | Medium (500) | `#000000` | `letter-spacing: 2px` |
| **Description** | 11px | Regular (400) | `#555555` | Line-height: 1.5 |
| **CTA Text** | 11px | SemiBold (600) | `#FFFFFF` | Centered |
| **Breadcrumbs/Footer**| 10px | Regular (400) | `#333333` | Normal |
| **Counter (`01 / 05`)** | 20px / 12px | Bold (700) / Regular | `#000000` / `#999999` | Monospace feel |

---

## 3. Color Palette
- **Background**: `#F4F4F6`
- **Text / Primary UI**: `#000000`
- **Secondary / Subdued**: `#8E8E93`
- **CTA Red**: `#E50010`
- **Accents (Icons/Badges)**: `#FFFFFF` with drop shadow (`rgba(0,0,0,0.08) 0px 4px 12px`)

---

## 4. Components & Layout Sections

### Header
- **Container**: `position: absolute; top: 0; left: 0; width: 100%; height: 80px; display: flex; align-items: center; justify-content: space-between; padding: 0 40px;`
- **Logo (Left)**: Nike Swoosh vector, black, width ~40px.
- **Navigation (Center-Left)**:
  - Links: `Men`, `Women`, `Collections`, `Contact`.
  - Spacing: `gap: 48px; margin-left: 80px;`.
- **Cart Badge (Far Right)**:
  - Solid black rectangle (`width: 140px; height: 50px; background: #000000;`).
  - Text: `Bag ²` (`color: #FFFFFF; font-size: 12px; font-weight: 600; display: flex; align-items: center; justify-content: center;`).

---

### Left Column: Product Information
- **Position**: `position: absolute; left: 80px; top: 50%; transform: translateY(-50%); width: 340px;`
- **Category Label**: `Men's Hoodies`, margin-bottom: 12px.
- **Product Headline**: `Nike ACG`, margin-bottom: 32px.
- **Pricing & Sizing Row**:
  - `$ 120` followed by `S / M / L / XL` offset by 24px right.
  - Margin-bottom: 24px.
- **Product Description**:
  - Text: "Men's hoodie Nike ACG made of soft fabric provides comfort for the whole day."
  - Margin-bottom: 32px.
- **CTA Button**:
  - Width: 135px, Height: 44px.

---

### Right Column: Imagery & Interactive Hotspots
- **Image Description**:
  - Studio profile shot of a male model facing left, wearing an off-white/light-grey technical hooded windbreaker with the hood up.
  - Bold, vertical reflective silver/grey typography reading **"ACG"** runs down the upper left sleeve.
  - Seamless light grey background matching the UI background.
- **Placement**: Aligned right and centered vertically, occupying roughly 60% of the screen width from the right edge.
- **Interactive UI Pins (Hotspots)**:
  1. **Hood Base Pin**: White circle (`~24px`), centered dark grey `+` icon, placed at collar level.
  2. **Lower Hem Pin**: White circle (`~24px`), centered dark grey `+` icon, placed near bottom hem.
  3. **Arm Action Pin**: White circle (`~32px`) positioned on upper sleeve near the "A" in ACG. Features a tiny red curved motion arc and a right-pointing arrow (`→`).
