# Design Specification: "My Journal" Mobile App UI

This document outlines the exact design specifications for cloning the "My Journal" mobile application screens shown in the media. It is structured for developers and designers to build a pixel-perfect implementation.

---

## Global Design Tokens

### Color Palette

| Color Name | Hex Code / Usage | Description |
| :--- | :--- | :--- |
| **Background (App)** | `#F4F3F0` (approx.) | Warm off-white, light gray-beige used for the general background canvas. |
| **Card Background (White)**| `#FFFFFF` | Used for content containers, navigation bars, and data cards. |
| **Primary Accent (Yellow)**| `#FFB732` (approx.) | Vibrant warm yellow/amber used for active dates, the "Let's start your day" banner, the "Happy" metric bar, and primary call-to-action (CTA) buttons. |
| **Secondary Accent (Purple)**| `#D5D1F8` (approx.) | Soft pastel lavender used for the "Set Intentions" quick journal card. |
| **Tertiary Accent (Pink)** | `#FCDCD4` (approx.) | Soft pastel peach/pink used for the "Pause & reflect" quick journal card. |
| **Text Primary (Dark)** | `#1A1A1A` | Near-black used for main headings, user names, and bold metrics. |
| **Text Secondary (Muted)** | `#707070` | Medium gray used for subtitles, secondary dates, and helper text. |
| **Emotion: Sad** | `#6B3530` | Deep terracotta/brown. |
| **Emotion: Calm** | `#7EA23B` | Olive/moss green. |
| **Emotion: Anxious** | `#75796A` | Muted grayish-olive. |
| **Iconography/Nav Inactive** | `#A3A3A3` | Light gray for unselected bottom navigation items. |

---

### Typography

*   **Primary Font Family:** `Inter`, `SF Pro Display`, `Roboto`, or system sans-serif fallback.
*   **Font Fallback Stack:** `font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;`

#### Type Scale (Estimated Hierarchy)

1.  **Screen Title (Large)**: `28px` / `34px` Line Height, Bold (`700`), Text Primary.
2.  **User Greeting ("Hi, Jose Maria")**: `24px`, Semi-Bold (`600`), Text Primary.
3.  **Section Headers ("My Journal", "Quick Journal")**: `18px`, Semi-Bold (`600`), Text Primary.
4.  **Card Titles / Action Text**: `14px` – `16px`, Medium (`500`), Text Primary.
5.  **Body / Subtitles**: `12px` – `13px`, Regular (`400`), Text Secondary.
6.  **Micro Text / Badges / Percentages**: `10px` – `11px`, Medium (`500`).

## Screen 1: Home / Dashboard ("Hi, Jose Maria")

### 1. Status Bar
*   **Time:** `9:41` (Left aligned, Bold, ~15px).
*   **System Icons:** Standard iOS status bar icons (Cellular signal, WiFi, Battery) on the top right.

### 2. Header Section
*   **Greeting:** "Hi, Jose Maria" (`24px`, bold).
*   **Avatar:** Circular profile image positioned on the top right.
    *   *Image Description:* A young woman with short reddish-brown hair wearing an orange top against a soft warm-toned background.

### 3. Horizontal Date Selector
*   **Layout:** Horizontal scroll or evenly spaced flex row.
*   **Items:** Days of the week (Mon, Tue, Wed, Thu, Fri, Sat, Sun) paired with calendar dates (7, 8, 9, **10**, 11, 12, 13).
*   **Active State:** Thursday the 10th (`10`) is highlighted with a solid **Primary Accent (Yellow)** circular background, with white or dark text. Inactive dates show standard text with gray weekday labels above.

### 4. "My Journal" Section
*   **Header Row:** Title "My Journal" on the left, "See all" link on the right in muted gray (`13px`).
*   **Main Banner ("Let's start your day"):**
    *   **Background:** **Primary Accent (Yellow)** gradient or solid fill.
    *   **Content:**
        *   Heading: "Let's start your day" (Bold, Dark text).
        *   Subtext: "Begin with a mindful morning reflections."
        *   **Illustration Description:** A warm, vector-style landscape scene featuring a smiling orange sun rising over rolling green hills, dotted with dark green pine trees and small scattered clouds in a gentle morning light.
    *   **Adjacent Card (Preview):** Partially visible card on the right labeled "Evening" with a neutral beige background (`#E4E0D8`).

### 5. "Quick Journal" Section
*   **Header Row:** Title "Quick Journal", "See all" on the right.
*   **Card 1 (Pause & reflect):**
    *   **Background:** Soft Pink (`#FCDCD4`).
    *   **Content:** Leaf icon + "Pause & reflect". Subtitle: "What are you grateful for today?".
    *   **Tags at bottom:** "Today" (pill badge), "Personal" (white pill badge).
*   **Card 2 (Set Intentions):**
    *   **Background:** Soft Purple (`#D5D1F8`).
    *   **Content:** Emoji icon + "Set Intentions". Subtitle: "How do you want to feel?".
    *   **Tags at bottom:** "Today", "Family".

### 6. Bottom Navigation Bar
*   **Background:** Solid White (`#FFFFFF`), pinned to the bottom.
*   **Items (Left to Right):**
    1.  **Home:** Active state (Black/Dark icon with home silhouette + indicator dot).
    2.  **Explore:** Compass/Globe outline icon.
    3.  **Action Button (Center):** Prominent floating circular button featuring a **Primary Accent (Yellow)** background with a bold white `+` icon.
    4.  **Journey:** Book/Journal outline icon.
    5.  **Profile:** User outline profile icon.
*   *Note:* Inactive icons use `#A3A3A3`.

## Screen 2: Journal Analytics / Summary ("420")

### 1. Header Section
*   **Top Nav:**
    *   Back arrow `<` inside a soft circular button (top left).
    *   Title: "My Journal" (Centered, `16px`, Medium).
    *   Ellipsis `...` inside a soft circular button (top right).

### 2. Metric Display
*   **Big Number:** `"420"` displayed in massive typography (~`48px`–`56px`, Bold, Dark).
*   **Subtitle:** "Celebrate what made you smile today." (`13px`, Text Secondary, centered).

### 3. Emotions Analytics Card
*   **Container:** White card with rounded corners (`16px` to `24px` radius) spanning the width of the content area.
*   **Card Header:**
    *   Title: "Emotions" (Semi-bold).
    *   Subtitle: "Here are four core emotions for your journal" (Muted gray, small text).
*   **Vertical Bar Chart:**
    *   Four distinct vertical capsule/pill-shaped bars representing metrics.
    *   **Bar 1 (Happy):** Filled up to **48%** height with **Primary Accent (Yellow)**. Label underneath: "Happy".
    *   **Bar 2 (Sad):** Filled up to **33%** height with **Sad color (`#6B3530`)**. Label underneath: "Sad".
    *   **Bar 3 (Calm):** Filled up to **27%** height with **Calm color (`#7EA23B`)**. Label underneath: "Calm".
    *   **Bar 4 (Anxious):** Filled up to **40%** height with **Anxious color (`#75796A`)**. Label underneath: "Anxious".
    *   *Note:* Each bar displays its exact percentage label centered inside or near the colored fill level in white text. The unfilled upper portion of each bar is a very light neutral gray (`#EFEFEF`).

### 4. Bottom Call-to-Action (CTA)
*   **Button:** Full-width rounded pill button.
*   **Background:** **Primary Accent (Yellow)** (`#FFB732`).
*   **Text:** "Create a New Journal" (Dark text, Medium weight).
*   **Home Indicator Bar:** Standard iOS black horizontal gesture indicator line at the absolute bottom.
