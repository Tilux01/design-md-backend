## 4. Animation Specifications (Interactive / Motion)

To replicate the dynamic "live web experience" of this portfolio piece, apply the following micro-interactions:

1.  **Floating Parallax Effect:**
    *   The circular callout badges (`Dress`, `Boots`, `Bag`, `Model Face`) gently float up and down asynchronously using CSS keyframe animations (e.g., `float 4s ease-in-out infinite`).
2.  **Page Load Entrance:**
    *   `Fade In`: Background and main model fade in (`opacity: 0` -> `1`) over `0.8s`.
    *   `Slide Up`: Hero text (`Next Gen Fashion Design`) slides up from `y: +30px` to `0` with a smooth ease-out curve.
3.  **Hover States:**
    *   Circular floating elements scale up slightly (`scale(1.05)`) on mouse hover with a smooth transition (`0.3s cubic-bezier(0.4, 0, 0.2, 1)`).
