# Design Specification: Elian Kent Portfolio Clone

This document provides the exact specifications to build a 1:1 clone of the provided portfolio interface. All layout grids, typography, color palettes, and visual assets are detailed below for pixel-perfect implementation.

---

## 1. Global Layout & Structure

*   **View:** Full-screen responsive viewport (`width: 100vw; min-height: 100vh`).
*   **Background Color:** Dark charcoal/near-black (`#111111` or `#0f0f0f`).
*   **Grid System:** The page is structured on a visible grid system defined by thin borders (`rgba(255, 255, 255, 0.1)`). 
    *   **Columns:** 4 vertical columns spanning the width of the page.
    *   **Grid Crosshairs:** Small `+` markers appear at grid intersection points throughout the layout.
*   **Layout Sections:**
    1.  **Fixed Top Navigation Bar**
    2.  **Hero Section** (with split name typography and central portrait)
    3.  **Metadata Bar** (Location, Field, Approach, Clients)
    4.  **About Section** (Bio text alongside secondary portrait card)

---

## 2. Typography & Fonts

### Primary Fonts (Modern Sans-Serif)
*   **Logo / Navigation / Labels:** Clean, uppercase, tracked-out sans-serif (e.g., *Inter*, *Helvetica Neue*, or *Space Grotesk*).
*   **Hero Heading ("ELIAN KENT"):** Ultra-bold, heavy display sans-serif (e.g., *Anton*, *Syne*, or *Impact*).
*   **Body Copy ("I'M A FRAMER DESIGNER..."):** Bold, heavy-weight sans-serif with tight line-height, styled in uppercase.

### Fallback Stack
```css
font-family: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
```

### Typography Specifications:
*   **Top Nav Links:** ~11px, uppercase, letter-spacing: `0.05em`, color: `#b3b3b3`.
*   **Hero First Name ("ELIAN"):** Left-aligned, massive font weight (900), pure white (`#ffffff`).
*   **Hero Last Name ("KENT"):** Right-aligned, massive font weight (900), pure white (`#ffffff`).
*   **Hero Subtext:** 9px, uppercase, tracking: `0.05em`, line-height: `1.4`, color: `#b3b3b3`, positioned in the top-right column.
*   **Metadata Titles:** 9px, uppercase, color: `#666666`.
*   **Metadata Values:** 11px, uppercase, color: `#e0e0e0`.
*   **About Section Heading Paragraph:** ~18-20px, uppercase, heavy weight (700-800), line-height: `1.15`, color: `#e0e0e0`.

## 5. Responsive Behavior & Implementation Notes
*   **No background framing:** Render edge-to-edge across the screen without outer padding containers acting as desktop mockups.
*   **Grid Responsiveness:** On smaller screens, collapse the 4-column layout into 2 columns or a single vertical stack while maintaining the strict grid aesthetic and thin borders.
*   **Images:** Use high-resolution placeholder photography matching the described compositions (male model, blonde hair, white tank top, red studio lighting). Ensure images blend seamlessly into the dark UI without drop shadows unless specifically styled.
