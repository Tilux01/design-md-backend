# Comprehensive Design Specification: Modern UI Design Workspace
Target: Pixel-Perfect Single-File Implementation (HTML5/Tailwind CSS/Vanilla JS)

---

## 1. Global Architecture & Layout Engine

### Viewport & Canvas
*   **Dimensions:** Fluid 100vw × 100vh canvas. No horizontal scrolling. Overflow hidden unless specified.
*   **Background Ecosystem:**
    *   **Primary Wall Surface:** Vertical acoustic wood slat wall system.
    *   **Construction:** Alternating vertical dark wood/charcoal slats against an off-white/beige textured backing.
    *   **Backlight Layer:** Perimeter ambient warm glow projecting down from the top ceiling edge and up from the bottom baseboard.
*   **Workstation Layout (The Desk Setup):**
    *   **Desk Surface:** Light oak veneer solid wood desktop with a motorized white standing frame.
    *   **Seating:** Ergonomic mesh office chair with a matte white frame, adjustable lumbar support, and polished chrome caster base.
    *   **Monitor:** Ultra-wide curved desktop display mounted centrally, projecting software UI layouts (Dark Mode design software interface with multi-pane wireframes).
    *   **Peripherals:** Mechanical keyboard, ergonomic mouse, wooden desk organizer tray, spatial white headphones on a stand, and a wireless charging puck.
    *   **Plant Life:** Tall potted palm (`Dypsis lutescens`) positioned to the right of the desk, featuring a translucent globe ambient reading lamp integrated into its base.

---

## 2. Typography System

### Primary Typeface: "Montserrat" (Google Fonts)
*   **Fallback Stack:** `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif`
*   **Weights Used:** Bold (700), Extra Bold (800)

### Text Elements Specification

#### Floating Hook Header ("4 Sites to get Modern UI Designs")
*   **Container Box:**
    *   **Background:** Solid Pure White (`#FFFFFF`) with ultra-soft multi-layered drop shadow for depth.
    *   **Border Radius:** `16px` (Smooth rounded pill/card format).
    *   **Padding:** `20px 32px`.
    *   **Position:** Absolute/Fixed centered overlay near the upper third of the canvas.
*   **Typography Rules:**
    *   **"4 Sites to get":**
        *   **Font Size:** `38px` (Desktop scale) / `24px` (Mobile scale).
        *   **Font Weight:** Bold (`700`).
        *   **Color:** Deep Charcoal / Almost Black (`#111111`).
        *   **Letter Spacing:** `-0.02em` (Tight modern tracking).
    *   **"Modern UI Designs":**
        *   **Font Size:** `42px` (Desktop scale) / `26px` (Mobile scale).
        *   **Font Weight:** Extra Bold (`800`).
        *   **Color:** Deep Charcoal (`#111111`) with subtle high-contrast punch.

## 4. Lighting & Shadow Specifications

### Ambient Wall Wash (Top & Bottom)
*   **CSS Implementation:** `box-shadow` or layered radial gradients.
*   `box-shadow: inset 0 40px 60px -20px rgba(255, 176, 59, 0.4), inset 0 -40px 60px -20px rgba(255, 176, 59, 0.3);`

### Floating Header Container Shadow
*   `box-shadow: 0 20px 40px -10px rgba(0, 0, 0, 0.15), 0 0 1px 1px rgba(0, 0, 0, 0.05);`

---

## 5. Animation & Interaction Spec

### Floating Text Entrance/Pulse Animation
*   **Keyframes Name:** `@keyframes floatHeader`
*   **Duration:** `4s`
*   **Timing Function:** `ease-in-out`
*   **Iteration:** `infinite`
*   **Behavior:** Gentle vertical translation (`translateY(0px)` to `translateY(-6px)` back to `0px`) to give the UI text overlay a natural floating spatial feel.
