# Comprehensive Design & Frontend Engineering Specification

---

## 1. Design Philosophy & Overall Aesthetic
* **Brand Archetype & Mood:** Premium E-commerce / Modern Beauty & Wellness boutique. Clean, minimalist, and approachable with vibrant focal marketing moments.
* **Visual Density:** Medium-low density with generous breathing room (whitespace-heavy layouts).
* **Theme Balance:** Light-mode dominant design system utilizing a soft rose-tinted backdrop with high-contrast coral/red callout banners and crisp dark text.
* **Surface Architecture:** Flat foundational backgrounds layered with clean card surfaces, crisp 1px borders, and soft shadows on interactive modules.

---

## 2. Color Palette & Design Tokens

### Color Matrix
* **Primary / Accent Colors:** Coral Red (`#E53935` / `#D32F2F`), soft rose backdrop (`#FCE4EC` / `#F8BBD0`).
* **Base Backgrounds:** Pure white (`#FFFFFF`) for cards and content wrappers; tinted pale rose (`#FDF2F4`) for the root canvas.
* **Surface Backgrounds:** Glass-like white overlays, solid white card blocks.
* **Borders & Dividers:** Subtle cool/neutral grey (`#E0E0E0`) and soft rose borders (`#F3C6D0`).
* **Text Colors:** Primary dark slate/black (`#111827`), Muted grey (`#6B7280`), Inverse light (`#FFFFFF`), Accent red (`#D32F2F`).

## 3. Typography System & Hierarchy
* **Font Families:** 
  * Headings & Body: Inter, system-ui, -apple-system, sans-serif.
* **Scale Breakdown:**
  * **H1 / Hero Title:** 36px–48px (2.25rem–3rem), Font Weight: 700, Line-Height: 1.1, Tracking: -0.02em.
  * **H2 / Section Header:** 24px–30px (1.5rem–1.875rem), Font Weight: 600, Line-Height: 1.2, Tracking: -0.01em.
  * **H3 / Card Title:** 16px–18px (1rem–1.125rem), Font Weight: 500, Line-Height: 1.4.
  * **Body Regular:** 14px (0.875rem), Font Weight: 400, Line-Height: 1.5.
  * **Micro / Badge / Caption:** 11px–12px (0.6875rem–0.75rem), Font Weight: 600, Letter-Spacing: 0.05em (uppercase).

---

## 4. Layout Architecture & Spatial Grid
* **Container Width:** Max width 1280px, fluid padding `clamp(1rem, 3vw, 2.5rem)`.
* **Grid System:** CSS Grid multi-column product matrix (3 columns on desktop, 2 on tablet, 1 on mobile).
* **Stacking Order (Z-Index):**
  * Base canvas: `z-0`
  * Cards / Content: `z-10`
  * Sticky Navigation: `z-40`
  * Modals / Overlays: `z-50`

## 8. Accessibility (a11y) & WCAG Contrast Audit
* **Contrast Ratios:**
  * Primary Text (`#111827`) on White Background (`#FFFFFF`): **15.2:1** (Passes WCAG AAA)
  * Button Text (`#FFFFFF`) on Brand Red (`#E53935`): **4.6:1** (Passes WCAG AA)
  * Muted Text (`#6B7280`) on White Background (`#FFFFFF`): **4.8:1** (Passes WCAG AA)
* **Focus States:**
  ```css
  *:focus-visible {
    outline: 2px solid #E53935;
    outline-offset: 2px;
  }
  ```
