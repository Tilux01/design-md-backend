# UI Design Specification: Nike "Earthquake Cloud" Landing Page

## 1. Global Layout & Structure

- **View:** Fullscreen, responsive web layout (simulating a full viewport width/height).
- **Border Radius:** The design is presented inside a mock browser/device frame with rounded corners (`border-radius: 24px`), but for production, this should render edge-to-edge (fullscreen).
- **Background Color (Page Container):** Off-white / Pure white (`#ffffff`) for the header bar area.
- **Hero Background:** A dynamic, multi-layered skyscape composition featuring bright blue skies, fluffy white background clouds, and a dense, surreal bed of pink/magenta cotton-candy clouds in the foreground.

---

## 2. Navigation Bar (Header)

- **Position:** Fixed/Sticky at the top of the viewport.
- **Height:** Approx. 80px.
- **Background:** Solid White (`#FFFFFF`).
- **Padding:** Horizontal padding matching standard container gutters (approx. 40px).

### Elements:
1. **Logo:**
   - **Asset:** Classic Nike Swoosh (`.svg`).
   - **Color:** Pure Black (`#000000`).
   - **Position:** Far left.

2. **Navigation Links:**
   - **Items:** `NEW RELEASES`, `MEN`, `WOMEN`, `KIDS`, `CUSTOMIZE`.
   - **Typography:**
     - **Font Family:** 'Helvetica Neue', Arial, sans-serif (Fallback: `sans-serif`).
     - **Font Weight:** Bold (`700`).
     - **Font Size:** 12px / 0.75rem.
     - **Letter Spacing:** 1px (Uppercase).
     - **Color:** `#111111`.
     - **Alignment:** Centered horizontally.

3. **Action Icons:**
   - **Items:** User Profile icon, Shopping Bag icon (with a notification badge).
   - **Position:** Far right.
   - **Color:** `#111111`.
   - **Icon Size:** 20px.

---

## 3. Hero Section

- **Position:** Directly below the navigation bar, extending to the bottom of the viewport.
- **Height:** Calc(100vh - 80px).
- **Overflow:** Hidden.

### A. Typography & Text Layers:
1. **Category Tagline:**
   - **Text:** `ESSENTIAL MEN'S SHOE`
   - **Position:** Top right of the hero section, above the main typography.
   - **Font Size:** 10px.
   - **Letter Spacing:** 1.5px.
   - **Color:** Pure White (`#FFFFFF`), semi-transparent (approx. 90% opacity).

2. **Sub-heading:**
   - **Text:** `EARTHQUAKE` (accompanied by a miniature white Nike Swoosh).
   - **Position:** Left-aligned, overlapping the background of the main title.
   - **Font Size:** 18px.
   - **Letter Spacing:** 4px.
   - **Color:** Pure White (`#FFFFFF`).

3. **Main Background Typography:**
   - **Text:** `CLOUD`
   - **Font Style:** Massive, ultra-bold, sans-serif geometric font.
   - **Styling:** Semi-transparent white cutout effect blending into the blue sky backdrop.
   - **Position:** Centered horizontally behind the primary product imagery.
   - **Font Size:** Approx. 22vw (responsive scaling).
   - **Font Weight:** 900 (Black).

### B. Primary Product (Featured Sneaker):
- **Subject:** A futuristic, chunky, multi-layered sneaker with a bulbous, ribbed sole unit and translucent pink/blue iridescent paneling.
- **Color Palette:** Bubblegum pink, soft lilac, and iridescent sky blue.
- **Positioning:** Angled diagonally (approx. 45-degree rotation), dynamically floating centrally, emerging from the pink foreground clouds.
- **Shadow/Depth:** Soft ambient occlusion shadow cast onto the pink clouds beneath it.

### C. Interactive Elements & Calls-to-Action (CTA):
1. **Explore Now Button:**
   - **Position:** Center-right, adjacent to the sneaker.
   - **Background:** Solid Black (`#000000`).
   - **Text Color:** Pure White (`#FFFFFF`).
   - **Border Radius:** Fully rounded / Pill shape (`30px`).
   - **Padding:** 12px 24px.
   - **Font Size:** 12px.
   - **Font Weight:** 600.
   - **Hover Effect:** Slight scale up (`transform: scale(1.05)`) with a smooth CSS transition.

2. **Video / Scroll Play Indicator:**
   - **Position:** Bottom center, resting on the pink cloud layer.
   - **Design:** A circular white button (`#FFFFFF`) with a subtle border ring and a black play triangle icon pointing right inside.
   - **Size:** 44px × 44px.

## 5. Animation & Interaction Spec

1. **Initial Load (Entrance Animation):**
   - **Background/Sky:** Fades in instantly (`opacity: 0` to `1`, duration: 0.8s).
   - **Typography (`CLOUD` & `EARTHQUAKE`):** Slides up slightly from the bottom with a fade (`translateY(20px)` to `0`, duration: 1s, ease-out).
   - **Product (Sneaker):** Floats into position from slightly lower within the clouds, settling into a continuous idle floating loop.

2. **Idle Floating Animation (Sneaker):**
   - **Keyframes:**
     ```css
     @keyframes float {
       0% { transform: translateY(0px) rotate(45deg); }
       50% { transform: translateY(-10px) rotate(45deg); }
       100% { transform: translateY(0px) rotate(45deg); }
     }
     animation: float 6s ease-in-out infinite;
     ```

3. **Hover States:**
   - **Nav Items:** Color transition to a soft grey (`#666666`).
   - **Explore Now Button:** Background changes to a dark charcoal (`#222222`), smooth scale transformation (`scale(1.05)`).
   - **Play Button:** Subtle pulse animation on hover to indicate interactivity.
