# Design Specification: Layered Neumorphic Mobile Landing Page

## 1. Overview & General Principles

*   **Design Paradigm:** Neumorphism with glowing accents, layered depth (z-index stacking), and a bold orange-to-yellow gradient theme.
*   **Layout Style:** Full-screen responsive mobile interface presented in a 3D isometric exploded-view layout. The final implementation must be a **full-screen, flat 2D viewport** layout that replicates the visual hierarchy and visual layers of the floating elements.
*   **Color Palette:**
    *   **Background:** Deep Obsidian Black (`#0a0a0c`) with a subtle radial gradient to create an ambient stage light.
    *   **Primary Gradient:** Vibrant Sunrise Orange-to-Yellow (`linear-gradient(135deg, #FFB732 0%, #FF512F 100%)`).
    *   **Card Surfaces:** Frosted Glass / Off-White (`#FFFFFF` with subtle opacity variations) and Deep Orange Accent Cards (`#FF4B2B`).
    *   **Text Colors:** Pure White (`#FFFFFF`) for headers, muted gray (`#6B6B76` / `#A1A1B5`) for body copy.
    *   **Glow/Neon Effects:** Bright warm amber/orange glow (`box-shadow: 0 0 20px rgba(255, 126, 95, 0.6)`).

---

## 2. Typography & Font Stack

*   **Primary Heading Font:** *Montserrat* or *Inter* (Extra Bold, Uppercase, Tracking/Letter-spacing: `1.5px`).
*   **Body Copy Font:** *Inter* or *Roboto* (Regular / Medium).
*   **Font Fallback Chain:** `font-family: 'Montserrat', 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif;`

### Typography Hierarchy:
1.  **Main Headline (Hero):**
    *   Font-size: `32px` (Mobile view)
    *   Weight: `800` (Extra Bold)
    *   Line-height: `1.2`
    *   Transform: Uppercase
    *   Color: `#FFFFFF`
2.  **Section Headers:**
    *   Font-size: `18px`

    *   Font-size: `13px`

*   **Card Styling:**
    *   Border-radius: `24px`

### B. Header Section (Top Card)
*   **Background:** Vertical gradient from light yellow-orange to deep orange (`#FFE169` to `#FF6A3D`).

### C. Content Sections & Widgets (Middle Layers)
*   **Media/Product Thumbnail Card:**
    *   A rounded image thumbnail container (`border-radius: 12px`) showcasing a product or abstract preview.

*   **Positioning:** Prominent floating action card overlapping the lower-middle section.

## 4. Animation & Interaction Specifications

To capture the dynamic floating feel of the reference image:

1.  **Floating / Parallax Hover Effect (CSS Keyframes):**
    *   The cards should have a subtle, continuous floating animation using CSS `transform: translateY()`.
    ```css
    @keyframes float {
        0% { transform: translateY(0px) rotate(0deg); }
        50% { transform: translateY(-8px) rotate(0.5deg); }
        100% { transform: translateY(0px) rotate(0deg); }
    }
    .floating-layer {
        animation: float 6s ease-in-out infinite;
    }
    ```
2.  **CTA Glow Pulse Animation:**
    *   The glowing border around the primary action button pulses gently to draw user focus.
    ```css
    @keyframes pulse-glow {
        0% { box-shadow: 0 0 5px rgba(255,200,100,0.4), inset 0 0 5px rgba(255,200,100,0.4); }
        50% { box-shadow: 0 0 20px rgba(255,200,100,0.8), inset 0 0 10px rgba(255,200,100,0.6); }
        100% { box-shadow: 0 0 5px rgba(255,200,100,0.4), inset 0 0 5px rgba(255,200,100,0.4); }
    }
    .cta-button {
        animation: pulse-glow 3s infinite;
    }
    ```
3.  **Micro-Interactions:**
    *   **Hover on CTA:** Scale up by `1.03` with an intensified outer glow.
    *   **Card Stack Hover:** Expanding the stacked cards slightly apart on mouse hover to reveal hidden depth layers.
