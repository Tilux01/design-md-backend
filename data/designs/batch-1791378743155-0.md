# UI/UX Specification: "Tekno Master" Fruit Pie E-Commerce Experience

---

## 1. Global Layout & Structural Overview

This is a modern, minimalist, content-driven e-commerce landing page/product showcase tailored for artisanal fruit pies. It uses a dynamic grid and responsive scaling that adapts fluidly across device viewports (Desktop UI wireframed on the laptop screen, interactive single-page view active on the tablet).

### Core Layout Specifications
- **Design Philosophy:** Editorial minimalism combined with skeuomorphic high-fidelity product photography and subtle modern UI interaction loops (circular carousel selector).
- **Page Structure:**
  1. **Sticky Top Navigation Bar:** Brand logo left-aligned, centered navigational links (`INICIO`, `TIENDA`, `NOSOTROS`, `BLOG`), right-aligned user actions (Profile icon, Wishlist, Cart counter) and a pill-shaped CTA (`INICIAR SESIÓN`).
  2. **Hero/Product Hero Section:** Asymmetrical split layout.
     - **Left Column:** Headings, descriptive body copy, and a sprawling interactive circular fruit-selection dial at the bottom.
     - **Right Column:** High-resolution floating macro photography of the featured fruit (kiwi slices, whole kiwi fruits, and mint leaves).
  3. **Interactive Carousel/Selector:** A large curved arc running along the lower third of the screen with touchpoints for `KIWI`, `NARANJA`, `ARÁNDANO`, and `FRUTILLA`.

---

## 2. Typography System

The design relies on a clean, humanist sans-serif for UI elements and a refined serif/display font for hero product headers to create an organic, artisanal feel.

| Role | Font Family (Primary) | Fallback Stack | Weights Used | Usage Context |
| :--- | :--- | :--- | :--- | :--- |
| **Brand/Logo** | `Montserrat` | `sans-serif` | Bold (700) | Top navigation brand indicator |
| **Navigation & UI** | `Inter` | `system-ui, -apple-system, sans-serif` | Regular (400), Medium (500) | Nav links, buttons, category tags |
| **Product Headings** | `Playfair Display` | `Georgia, serif` | Bold (700) | Main titles (e.g., "Pie Kiwi") |
| **Body Copy** | `Inter` | `sans-serif` | Light (300), Regular (400) | Product description paragraphs |

---

## 3. Color Palette & Theming

The interface dynamically adapts its color scheme based on the active fruit theme (Green for Kiwi, Orange for Orange/Naranja, Blue for Blueberry/Arándano, Red for Strawberry/Frutilla).

### Active Theme: Kiwi (Green)
```css
/* Color Tokens */
--bg-primary: #78996b;       /* Muted sage/olive green background */
--bg-surface: #68875c;       /* Darker sage container tint */
--text-main: #ffffff;        /* Pure white for primary headers */
--text-muted: #e2ede0;       /* Soft pale green-white for body text */
--accent-cta: #ffffff;       /* White pill button background */
--accent-cta-text: #537346;  /* Deep green button text */
--border-subtle: rgba(255, 255, 255, 0.2);
```

---

## 4. Component-by-Component Specifications

### 4.1. Navigation Bar (`<nav>`)
- **Height:** `72px`
- **Padding:** `0 48px`
- **Background:** Transparent overlaying the primary background (`rgba(120, 153, 107, 0.8)` with backdrop blur `blur(12px)`).
- **Left Element:** Logo lockup with a small graphic mark and text `Tekno Master` (`16px`, `Font-Weight: 700`, Color: `#FFFFFF`).
- **Center Links:** `INICIO`, `TIENDA`, `NOSOTROS`, `BLOG` (`13px`, Uppercase, Letter-spacing: `0.05em`, Color: `#FFFFFF`, hover opacity `0.7`).
- **Right Elements:** 
  - Icon cluster: Profile, Wishlist, Cart (`18px` stroke icons, white).
  - CTA Button: `INICIAR SESIÓN` — Pill shape (`border-radius: 9999px`), background `#FFFFFF`, text color `#537346`, padding `8px 20px`, font size `12px` medium.

### 4.2. Hero Section (`<section class="hero">`)
- **Grid Layout:** CSS Grid, 2 columns (`1fr 1.2fr`).
- **Text Block (Left):**
  - **Category/H1:** `"Pie Kiwi"` — `Playfair Display`, `48px`, `Font-Weight: 700`, Color: `#FFFFFF`.
  - **Description:** `"Un postre refrescante y lleno de vida..."` — `Inter`, `13px`, Line-height: `1.6`, Color: `#E2EDE0`, Max-width: `450px`.
- **Hero Image (Right):**
  - Absolute/Floating composition featuring a whole kiwi, halved kiwis displaying black seeds and vibrant green flesh, and organic mint leaves trailing off the container bounds to create depth.

### 4.3. Interactive Circular Dial Carousel (`<div class="fruit-carousel">`)
- **Geometry:** A large SVG/CSS circular arc positioned at the bottom center, spanning across the viewport width.
- **Nodes:**
  - `KIWI` (Active node with selection ring and connection line to the main pie).
  - `NARANJA`, `ARÁNDANO`, `FRUTILLA` (Inactive nodes spaced evenly along the arc).
- **Featured Pie Preview:**
  - A circular macro shot of the baked kiwi pie resting directly inside the bottom-left curve of the carousel track.
  - Border: Thin white ring (`2px solid rgba(255,255,255,0.4)`).
- **Navigation Controls:** A floating circular chevron button (`>` icon) on the bottom right of the dial container for stepping through products. Background: translucent white, text/icon: `#333`.

---

## 5. Animation & Interaction Specification

1. **Page Load / Entrance Animation:**
   - **Fade In Up:** Hero text elements (`H1`, paragraph) stagger fade-in with a `0.4s` delay using `cubic-bezier(0.16, 1, 0.3, 1)`.
   - **Scale In:** The central pie thumbnail scales up from `0.9` to `1.0` with an opacity transition over `0.6s`.
2. **Carousel Interaction:**
   - Clicking an inactive fruit node (e.g., `NARANJA`) triggers a smooth theme transition:
     - Background color interpolates from `#78996b` to the target theme color (`#E08E45` for Orange).
     - The circular pie image cross-fades into the newly selected pie.
     - Active node indicator translates along the SVG arc path via `transform: translateX/translateY` with a duration of `0.4s`.
3. **Hover States:**
   - Nav links: Opacity shift `1 -> 0.7`.
   - Pill CTA: Slight scale up (`scale(1.02)`) and shadow intensification.
