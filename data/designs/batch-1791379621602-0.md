# Comprehensive UI/UX Design & Implementation Specification

## 1. Global Layout & Structure
- **Viewport Structure:** Full-screen responsive viewport (`width: 100vw`, `height: 100vh`, `overflow: hidden`).
- **Background System:** Multi-layered radial and linear gradients (`#f4f5f9` to pure white base) featuring subtle glassmorphic backdrop filters and 3D architectural wireframe underlays.
- **Grid Layout:** Asymmetric dynamic positioning utilizing CSS Grid and absolute positioning with `transform-style: preserve-three-D` for layered perspective depth.

---

## 2. Color Palette
| Color Role | Hex Code | Usage |
| :--- | :--- | :--- |
| **Primary Background** | `#F6F7FB` | Main viewport canvas background |
| **Surface Base** | `#FFFFFF` | Cards, buttons, and container backgrounds |
| **Primary Text** | `#111116` | Headings, brand logo, and high-emphasis labels |
| **Secondary Text** | `#696C7A` | Metadata, tags, and footer category indicators |
| **Accent Electric Blue** | `#2C58FF` | Dynamic card gradients, active states, and highlights |
| **Accent Vivid Red/Coral** | `#FF3366` | Card color-blocking elements, graphical motifs |
| **Glass Stroke** | `rgba(255, 255, 255, 0.6)` | Translucent card borders and inner highlights |

---

## 3. Typography System

### Font Families
- **Primary Font:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
- **Secondary/Display Font:** Space Grotesk, Inter, sans-serif (for numeric data and stylized cards)
- **Fallback Stack:** `sans-serif`

### Type Scale & Hierarchy
- **Main Heading ("Switch up to next generation of wallets.")**
  - *Font Size:* `clamp(2.5rem, 4.5vw, 4.2rem)`
  - *Font Weight:* `500` (Semi-bold)
  - *Line Height:* `1.05`
  - *Letter Spacing:* `-0.03em`
- **Sub-tag ("MORE THAN 200 DIFFERENT CARDS")**
  - *Font Size:* `0.7rem`
  - *Font Weight:* `600`
  - *Letter Spacing:* `0.15em`
  - *Text Transform:* `uppercase`
- **Navigation & Footer Micro-copy**
  - *Font Size:* `0.75rem` to `0.85rem`
  - *Font Weight:* `500`

---

## 4. Component Breakdown

### Header Navigation
- **Logo Area:** Swapie branding with infinity/double-circle symbol positioned at top-left (`left: 40px`, `top: 40px`).
- **Action Button ("Waitlist"):** Pill-shaped minimal button (`border: 1px solid rgba(0,0,0,0.1)`, `padding: 10px 24px`, `border-radius: 50px`, hover background transitions to `#111116` with white text).

### Hero Section & Floating Card Stack
- **Card Deck Construction:** 
  - 4 layered cascading cards offset using absolute positioning, rotations (`rotate(-12deg)` to `rotate(-2deg)`), and `translate3d` depths.
  - Cards use glassmorphism: `backdrop-filter: blur(20px)`, `background: rgba(255, 255, 255, 0.7)`, with multi-stop rich gradients (abstract 3D cubes, iridescent spheres, biometric/contactless UI indicators).
- **Interactive Badge ("MORE THAN 200 DIFFERENT CARDS"):**
  - Pill layout featuring a dynamic star/sparkle icon (`*`), subtle drop shadow (`box-shadow: 0 4px 20px rgba(0,0,0,0.04)`).

### Footer Category Markers
- Horizontal alignment of 3 distinct feature columns at the bottom (`CUSTOM THINGS`, `PEOPLE'S FIRST CHOICE`, `DIFFERENT`).
- Each marker includes a custom monochrome graphical glyph/icon followed by uppercase tracked typography.

---

## 5. Animation & Interaction Specification

### Entrance Animations (On Load)
- **Staggered Card Stack Drop:** Cards slide down from viewport top with a spring physics easing (`cubic-bezier(0.175, 0.885, 0.32, 1.275)`), scaling from `0.8` to `1.0` over `1.2s`.
- **Headline Text Reveal:** Masked vertical slide-up animation for the main headline lines.

### Micro-Interactions & Hover States
- **Card Hover Elevation:** 
  - `transition: transform 0.4s cubic-bezier(0.25, 1, 0.5, 1), box-shadow 0.4s ease;`
  - On hover, individual cards lift along the Z-axis (`translateZ(40px) scale(1.03) rotate(0deg)`).
- **Waitlist Button Hover:** Smooth color inversion (Black background, white text) with a subtle scale transformation (`scale(1.02)`).
