# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Neutral Neutral / Clean Minimalist Interface (Placeholder/Blank Canvas View).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Clean minimal layout, neutral color canvas fallback.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `12px`, font-weight `600`, tracking `0.05em`, border-radius `9999px`, background translucency `rgba(0,0,0,0.05)`, border width `1px`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content to prevent rendering glitches.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;` or `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
