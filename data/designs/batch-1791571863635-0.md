# UI Design & Implementation Specification: eProduct Dashboard - Order View

## 1. Overview & Layout Strategy
This specification details a modern, responsive web application dashboard designed for order management ("eProduct"). The interface utilizes a split-pane structural pattern common in SaaS platforms:
- **Left Navigation Sidebar:** A distinct, branded cobalt blue container (`#0D6EFD` equivalent) housing application modules, branding, and footer links.
- **Main Content Area:** A light, clean canvas (`#F8F9FA` or pure white container) dedicated to data visualization, filtering, and tabular data management.

### Global Dimensions & Responsiveness
- **Canvas Orientation:** Landscape (Desktop Application View).
- **Grid Structure:** Fixed left sidebar (approx. 240px–280px width) with fluid remaining width allocated to the primary content card.
- **Border Radius:** The main container utilizes a smooth, rounded card edge (`16px` to `24px` radius) set against a soft, abstract gradient background.

---

## 2. Color Palette & Typography

### Color System
| Role | Color Name | Hex Code / Description | Usage |
| :--- | :--- | :--- | :--- |
| **Primary Brand** | Cobalt Blue | `#0056FF` (Vibrant Blue) | Sidebar background, active navigation pill, primary CTA, selected table row highlight. |
| **Canvas Background** | Light Gray / Off-White | `#F4F6F9` | Overall application background behind the dashboard card. |
| **Card Surface** | Pure White | `#FFFFFF` | Main content container background and standard table row backings. |
| **Primary Text** | Dark Slate | `#1E293B` | Headers, primary data cells, active labels. |
| **Secondary Text** | Cool Gray | `#64748B` | Subtitles, table headers (`Id`, `Name`, `Address`), inactive nav items, page indicators. |
| **Border / Divider** | Subtle Line | `#E2E8F0` | Row separators, container borders, input field outlines. |
| **Status: Pending** | Coral Red / Pink | `#EF4444` (dot) / `#FEE2E2` | Status badge indicator for pending orders. |
| **Status: Dispatch** | Teal / Mint Green | `#10B981` (dot) | Status badge indicator for dispatched orders. |
| **Status: Completed** | Muted Gray | `#94A3B8` (dot) | Status badge indicator for completed orders. |

### Typography & Fonts
- **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif.
- **Fallback Stack:** `Arial, sans-serif` if system sans-serif fonts are unavailable.
- **Type Scale:**
  - **Dashboard Title ("Order"):** 24px, Bold (Weight: 700), Line-height: 32px.
  - **Table Headers:** 12px, Semi-Bold (Weight: 600), Uppercase or Title Case, Color: Secondary Text.
  - **Table Data & Navigation Items:** 14px, Regular to Medium (Weight: 400–500), Color: Dark Slate.
  - **Metadata / Sub-labels ("28 orders found"):** 13px, Regular (Weight: 400), Color: Secondary Text.

## 3. Component Specifications

### A. Left Navigation Sidebar
- **Background:** Solid vibrant blue (`#0056FF`).
- **Branding Header:** 
  - Logo Text: "eProduct" in bold, white, modern sans-serif typography.
- **Navigation Links:**
  - Vertical stack of interactive items featuring icons paired with text labels.
  - **Items:** Dashboard, Order (Active State), Statistic, Product, Stock, Offer.
  - **Active State:** The "Order" item features a pill-shaped background cut into the rounded sidebar card (or a smooth curved indentation effect) with white text and a blue icon container. Inactive items display white text with medium opacity.
- **Sidebar Footer:**
  - Horizontal list of social/external links at the bottom: `Facebook`, `Twitter`, `Google` in small, muted white text.

### B. Main Content Header & Filters
- **Page Title Area:**
  - **Title:** "Order" (Large bold font).
  - **Subtitle:** "28 orders found" (Placed directly below the title).
- **Tab Navigation / Filter Bar:**
  - Horizontal tabs: **All orders** (Active, underlined/bold), **Dispatch**, **Pending**, **Completed**.
- **Date Range Picker:**
  - Positioned on the top right of the content area.
  - Displays two date input capsules: `31 Jul 2020` to `03 Aug 2020`, each preceded by a small calendar icon.

### C. Data Table Architecture
- **Table Headers:**
  - Columns: `Id`, `Name`, `Address`, `Date`, `Price`, `Status`, `Action`.
  - Styled with subtle sorting arrows next to `Id`, `Name`, `Date`, and `Price`.
- **Table Rows:**
  - **Standard Row:** Alternating or clean white background with a thin bottom border (`#E2E8F0`).
  - **Selected / Active Row (e.g., #2633 - John McCormick):** Highlighted with a vibrant blue background (`#0056FF`), white text for all cell items, and a subtle floating action extension or dropdown indicator on the right.
- **Cell Content Descriptions:**
  - **Id:** Prefix `#` followed by a 4-digit number (e.g., `#2632`, `#2633`).
  - **Name:** Includes a small circular avatar image representing the customer, followed by their full name (e.g., "Brooklyn Zoe", "John McCormick").
  - **Address:** Full street address and city/state/zip code in single-line text format (truncated with ellipsis if overflow occurs).
  - **Date:** Formatted as `DD MMM YYYY` (e.g., `31 Jul 2020`).
  - **Price:** Currency formatted with a dollar sign (e.g., `$64.00`, `$35.00`).
  - **Status:** Badge format featuring a colored status dot (red for Pending, green for Dispatch, gray for Completed) alongside the status text label.
  - **Action:** Contains a settings/gear icon (`⚙️`) and a dropdown chevron (`⌄`).

### D. Pagination Footer
- Located at the bottom left of the table area: `"Showing 06-12 of 28"`.
- Pagination controls located at the bottom right: Left chevron (`<`), page numbers (`1`, `2`, `3`, `4`), and right chevron (`>`). Active page number is highlighted in bold or enclosed in a subtle pill background.

---

## 4. Asset & Imagery Guidelines
*Note: Per requirements, images are described conceptually rather than generated via code instructions.*

- **User Avatars:** Circular profile thumbnail images (approx. 28px–32px diameter) representing individual customers in the **Name** column. They should feature diverse, realistic portrait photography cropped tightly to a circle.
- **Icons:** 
  - System icons utilized: Calendar, Search, User Profile, Notifications, Settings (Gear), Sorting arrows, and Navigation chevrons. Recommended icon set: Feather Icons, Lucide, or FontAwesome (Solid/Regular variants).
