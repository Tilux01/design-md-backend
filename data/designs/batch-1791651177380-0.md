# Design System & Specification Document

---

## 1. Global Layout & Canvas Strategy
- **Viewport:** Full-screen (`100vw` × `100vh`), responsive web application layout.
- **Background Color:** Deep charcoal/obsidian black (`#0a0b0e`).
- **Lighting/Atmosphere:** Dramatic lighting effects, featuring deep burnt-orange/amber gradients (`#ff5500` / `#ff7733` with radial falloff) emanating from the top-right and core network lines, giving a futuristic, high-performance edge computing aesthetic.
- **Border Radius:** The application container utilizes an outer border radius of `16px` with a subtle semi-translucent outline (`rgba(255, 255, 255, 0.08)`).

## 4. Component Specifications

### A. Top Announcement Banner
- **Background:** Dark slate bar with a subtle border bottom.
- **Content:** Left-aligned text linking to GPU AI/ML apps ("GPU AI/ML Apps today! Nvidia A100s & H100s for €1.3/h →").
- **Right Utilities:** "Under attack?", "Log in", and language selector icon.

### B. Header / Navigation Bar
- **Logo:** GCORE logo positioned on the far left.
- **Nav Items (with dropdown carets):** Products, Pricing, Resources, Partners, Why Gcore.
- **Right Action Items:**
  - **Contact Us:** Ghost button with transparent background and thin border.
  - **Sign up for free:** Solid primary button with rounded corners (`20px`).

### C. Hero Section ("Inference at the Edge")
- **Tagline/Badge:** Pill-shaped badge containing a small icon/dot and text (`✨ Beta Release`).
- **Headline:** Centered, large bold typography (`56px`) reading *"Inference at the Edge"*.
- **Description:** Two-line centered paragraph detailing speed, efficiency, customization, and cost-efficiency for best-in-class inference.
- **CTA Buttons:**
  - **Primary CTA ("Get started"):** Solid burnt-orange pill button (`#ff5500`), white text, hover lift effect.
  - **Secondary CTA ("Book a demo"):** Transparent outline pill button with white border.

### D. Edge Network / AI Neural Visualization Area
- **Central Core Node:** A glowing rounded square element labeled **"AI"** with thin orange vertical trace lines extending outward, creating a circuit-board aesthetic.
- **Peripheral Nodes:** Floating glassmorphic cards connected by glowing orange vector traces/paths:
  - **Top-Left Node:** Features a stylized letter icon (`A`).
  - **Top-Right Node:** Features a stylized letter icon (`S.`).
  - **Mid-Left Node:** Features a small square code/terminal icon.
  - **Mid-Right Node:** Features a dual-processor grid icon.
  - **Bottom-Left Node:** Features a server rack icon.
  - **Bottom-Right Node:** Features a circular fingerprint/neural swirl icon.
- **Visual Depth:** The traces fade into the dark background with ambient orange backlighting (`box-shadow: 0 0 40px rgba(255,85,0,0.15)`).

## 5. Asset Descriptions & Placement Guide

### Logos & Icons
- **GCORE Logo:** Vector SVG wordmark on the top-left header (`color: #ffffff`).
- **Node Icons:** Minimalist white vector glyphs inside rounded dark glassmorphic containers (`background: rgba(255,255,255,0.05)`, `border: 1px solid rgba(255,255,255,0.1)`, `border-radius: 12px`).
- **Connection Lines (SVG Paths):** Dynamic organic curves (`stroke: #ff5500`, `stroke-width: 1.5px`, `opacity: 0.7`) branching out symmetrically from the central **AI** hub to the outer floating edge nodes.
