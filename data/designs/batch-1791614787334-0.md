# Design Specification: SHAKEIT Hero Landing Page

A complete design implementation specification for building an exact, pixel-accurate clone of the SHAKEIT desktop hero screen in full-screen viewport layout.

---

## 1. Design Overview & Aesthetic

* **Theme/Vibe:** Minimalist, modern industrial Scandinavian product showcase. High-contrast typography paired with soft studio-lit neutral gradient surfaces.
* **Layout Structure:** Full-screen viewport (`100vw` × `100vh`, `overflow: hidden`), anchored by an oversized central typographic title with an overlapping tilted 3D product render and four corner/perimeter balanced micro-content modules.
* **Lighting & Atmosphere:** Soft ambient top-to-bottom studio lighting with a subtle cool grayish-blue tint.

## 3. Typography & Font Stack

### Font Families
1. **Display Headline & Logo Font:**
   * **Primary:** `Syne` (Weight: 800/ExtraBold) or `Clash Display` (Bold)
   * **Alternative / Fallbacks:** `Montserrat` (900 Black), `Archivo Black`, `Arial Black`, `sans-serif`
2. **Body & Interface Font:**
   * **Primary:** `Plus Jakarta Sans` or `Inter` (Weights: 400 Regular, 500 Medium, 600 SemiBold)
   * **Alternative / Fallbacks:** `system-ui`, `-apple-system`, `BlinkMacSystemFont`, `sans-serif`

### Typographic Scale & Styling
* **Brand Logo ("SHAKEIT"):**
  * Size: `18px` / `1.125rem`
  * Weight: `800` (ExtraBold)
  * Tracking/Letter-spacing: `+0.08em` (slightly expanded)
  * Transform: `UPPERCASE`
* **Navigation Links:**
  * Size: `13px` / `0.8125rem`
  * Weight: `500` (Medium)
  * Active item ("About us"): Underlined with a `1.5px` solid dark rule placed `4px` below the text.
* **Background Watermark ("FRESH . COOL . PURE"):**
  * Size: `clamp(4.5rem, 9vw, 8.5rem)`
  * Weight: `800` (ExtraBold)
  * Tracking: `+0.05em`
  * Opacity: `0.28`
  * Color: `#A6B7C8`
* **Main Headline ("PURE"):**
  * Size: `clamp(8rem, 20vw, 19rem)`
  * Weight: `900` (Heavy/Black)
  * Line-height: `0.85`
  * Tracking: `-0.02em`
  * Color: `#0A0D14`
* **Micro-Copy & Indicators:**
  * Size: `12px` – `13px`
  * Weight: `400` (Regular) to `500` (Medium)
  * Line-height: `1.4`

## 4. Visual Assets & Image Guidelines

### 4.1. Center Hero Asset — 3D Shaker Bottle
* **Type:** Backgroundless transparent PNG or high-res WebP (photorealistic 3D render).
* **Subject:** Modern fitness protein shaker bottle.
  * **Body:** Cylindrical, slightly tapered matte cobalt blue body (`#2B52B8`).
  * **Lid:** Off-white/eggshell light gray textured screw-on cap (`#EDF2F7`).
  * **Flip-Cap / Handle:** Cobalt blue carry loop and snap lid.
  * **On-Bottle Graphic:** Clean vertical white label running upwards along the lower body: a thin top line, the word `SHAKEIT` in sans-serif capital letters, and a continuing bottom line (`— SHAKEIT —`).
* **Placement & Orientation:**
  * **Position:** Centered horizontally and vertically, layered directly over the word **"PURE"** (overlapping the right leg of **"U"** and the left vertical stem of **"R"**).
  * **Rotation:** Tilted approximately `+22deg` to `+25deg` clockwise (top leans toward the top-right, base points toward the bottom-left).
  * **Scale:** Height approximately `58vh` to `65vh`.
  * **Shadow:** Casts a soft ambient occlusion shadow (`filter: drop-shadow(0px 25px 35px rgba(20, 35, 60, 0.25))`) behind the bottle onto the headline text and background canvas.

### 4.2. Team / Social Proof Avatars (Top-Left)
* **Type:** Three (3) overlapping circular portrait photos.
* **Diameter:** `32px` each.
* **Overlap:** Left margin `-10px` on avatars 2 and 3.
* **Border:** `2px solid #E5ECF2` border on each circle for clean separation.
* **Content:** Diverse close-up portraits of people/team members.

## 5. Screen Layout & Component Structure

```
+---------------------------------------------------------------------------------+
|  [SHAKEIT]                      [About us] ■ [Technology] ■ [Products] ■ [Contact]  |
|                                                                                 |
|   (o)(o)(o) About us                                                            |
|                                                                                 |
|                   F R E S H   .   C O O L   .   P U R E                         |
|                                                                                 |
|               P   U        /===\         R   E                              |
|                           |     |                                               |
|                           |     |  <- [SHAKER BOTTLE (Rotated ~23°)]            |
|                            \===/                                                |
|                                                                                 |
|   Scroll to discover [ v ]                        We produce plastic drinkware  |
|                                                   from recycled materials...    |
+---------------------------------------------------------------------------------+
```

### 5.1. Top Navigation Bar
* **Position:** Sticky or fixed at top, spanning full width.
* **Padding:** `32px 56px` (or `2rem 3.5rem`).
* **Border:** Optional very faint full-width hairline border at top inset `y = 16px`.
* **Left:** Logo `SHAKEIT`.
* **Right:** Flex row navigation:
  * Items: `About us`, `Technology`, `Products`, `Contact`.
  * Item Spacing: `18px` gap between text and separator.
  * Separator: Solid square bullet symbol `▪` (`4px × 4px`, color `#111827`).

### 5.2. Background Typographic Watermark Layer
* **Content:** Horizontal repeating phrases: `"FRESH . COOL . PURE ."`.
* **Position:** Centered vertically, sitting directly behind the upper half of the main `"PURE"` title (`top: 38%`, `transform: translateY(-50%)`).
* **Styling:** Faint light blue-gray tone, non-selectable (`pointer-events: none`, `user-select: none`).

### 5.3. Headline & Product Composition (Center Stage)
* **Main Text Container:**
  * Displays the word **"PURE"** in full width across the center.
  * Letter distribution: `"P"` and `"U"` on the left half, `"R"` and `"E"` on the right half.
* **Bottle Interaction:**
  * The bottle sits directly in the negative space between `"U"` and `"R"`, physically covering the inner stem of `"U"` and the left corner of `"R"`.

### 5.4. Peripheral Micro-Modules

#### A. Avatar Badge (Top-Left Content Area)
* **Coordinates:** Above the letter `"P"`, approximately `top: 24%`, `left: 8vw`.
* **Layout:** Flex row with `gap: 12px`, vertically centered.
* **Elements:**
  1. Avatar stack (3 overlapping circular images, `32px` diameter).
  2. Label: `"About us"` in 13px Medium font.

#### B. Scroll Indicator (Bottom-Left)
* **Coordinates:** Below the letter `"P"`, approximately `bottom: 14%`, `left: 8vw`.
* **Layout:** Flex row with `gap: 10px`, vertically aligned.
* **Elements:**
  1. Text: `"Scroll to discover"` (`13px`, Regular, `#1F2937`).
  2. Button: Small square pill (`24px × 24px`, background `#BAC7D5`, rounded corners `4px`) housing a crisp downward-pointing chevron icon (`⌄`, size `12px`, color `#475569`).

#### C. Editorial Description (Bottom-Right)
* **Coordinates:** Below the letters `"R"` and `"E"`, approximately `bottom: 14%`, `right: 8vw`.
* **Width:** `max-width: 260px`.
* **Typography:** `11.5px` / `0.72rem`, line-height `1.45`, regular weight, color `#4B5563`.
* **Content:**
  > "We produce plastic drinkware from recycled materials. Check out our new catalog."

---

## 6. Layer Stacking Order (Z-Index Hierarchy)

1. `z-index: 0` — Radial/Linear studio background canvas (`#E5ECF2` to `#CCD6E0`).
2. `z-index: 1` — Ghost watermark text (`"FRESH . COOL . PURE"`).
3. `z-index: 2` — Main headline text (`"PURE"`).
4. `z-index: 3` — 3D Shaker bottle product render (with ambient drop shadow).
5. `z-index: 4` — Floating peripheral content:
   * Top navigation bar
   * "About us" avatar badge
   * "Scroll to discover" indicator
   * Bottom-right catalog text block

---

## 7. Responsive Scaling Behavior

* **Desktop (Full-Screen Viewport):** Exact layout as specified above; zero scrollbar (`height: 100vh`).
* **Fluid Font Scaling:** The headline `"PURE"` utilizes `clamp(7rem, 18vw, 20rem)` to remain fully contained horizontally while retaining its monumental presence.
* **Bottle Sizing:** Scales dynamically using viewport units (`height: min(60vh, 520px)`), preserving its rotational pivot at center.
