# 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Brand Archetype**: Editorial, minimalist, high-end e-commerce editorial layout blending boutique typography with structured product catalogs.
- **Visual Density**: Clean, breathable editorial grid; balanced density with generous whitespace and precise photographic framing.
- **Theme Balance**: Light-mode dominant layout (`#FFFFFF` base canvas with high-contrast `#111111` typography) accented by subtle stone gray surfaces (`#F4F4F5`) and muted borders (`#E5E7EB`).

# 2. Color Palette & Design Tokens

- **Primary / Core Dark**: `#111111` (Text Primary, Header Elements)

# 3. Typography System & Hierarchy

- **Font Families**: Sans-serif geometric editorial typeface (`Inter`, system fallback).
- **Scale Breakdown**:
  - **Hero Title / Display**: `3.5rem` / `56px` (Line-height: `1.1`, Weight: `700`, Tracking: `-0.03em`)
  - **Section Heading (H1)**: `2.25rem` / `36px` (Line-height: `1.2`, Weight: `600`, Tracking: `-0.02em`)
  - **Card Title (H2)**: `1.25rem` / `20px` (Line-height: `1.3`, Weight: `500`, Tracking: `-0.01em`)
  - **Body Copy**: `0.9375rem` / `15px` (Line-height: `1.5`, Weight: `400`, Tracking: `0em`)
  - **Captions & Meta**: `0.75rem` / `12px` (Line-height: `1.4`, Weight: `500`, Tracking: `0.05em`, Uppercase)

# 5. AI Design Traits, Micro-Badges & Special Glyphs

- **High-Tracking Uppercase Labels**: Utilized across category tags and metadata (`letter-spacing: 0.08em; font-size: 11px; text-transform: uppercase;`).
- **Symbol Safety**: Use Unicode glyphs (`✦`, `—`) or HTML entities (`&mdash;`, `&#10022;`) cleanly in pseudo-elements (`content: "✦";`).
- **Pill Badge Spec**:
  ```css
  .badge-pill {
    display: inline-flex;
    align-items: center;
    padding: 4px 12px;
    font-size: 11px;
    font-weight: 500;
    letter-spacing: 0.08em;
    text-transform: uppercase;
    border-radius: 9999px;
    border: 1px solid #E5E7EB;
    background-color: #F9FAFB;
    color: #111111;
  }
  ```

# 7. Accessibility (a11y) & WCAG Contrast Audit

- **Text Contrast Ratios**:
  - Primary text (`#111111`) on White (`#FFFFFF`): **16.1:1** (Passes WCAG AAA)
  - Muted text (`#6B7280`) on White (`#FFFFFF`): **4.6:1** (Passes WCAG AA)
- **Focus Ring Spec**:
  ```css
  :focus-visible {
    outline: 2px solid #111111;
    outline-offset: 2px;
  }
  ```
