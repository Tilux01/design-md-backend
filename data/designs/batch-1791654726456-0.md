# Design Specification Document: Mobile Sign-Up Screen

## 1. Overview & General Layout
* **Screen Type:** Mobile Application Sign-Up / Registration View.
* **Aspect Ratio:** Standard smartphone vertical aspect ratio (approx. 9:16).
* **Overall Architecture:** A two-layered layout comprising a **primary background header** and a **scrollable foreground card container**.
* **Background Layer:** Deep rich purple covering the top section and extending behind the entire viewport.
* **Foreground Container:** A rounded white card overlay that houses all form inputs, labels, and action buttons. It overlaps the lower portion of the purple header.

---

## 2. Color Palette & Styling

### Primary Colors
* **Deep Purple (Background/Header):** `#3A0CA3` (or deep royal purple variant matching the header gradient/solid background).
* **Card Background (Foreground):** `#FFFFFF` (Pure White).
* **Primary Interactive Purple (Button & Accents):** `#560BAD` (Dark violet used for the main call-to-action button).

### Text Colors
* **Header Title & Subtitle:** `#FFFFFF` (White).
* **Form Labels (Name, Email, Password, etc.):** `#333333` or dark gray `#2B2B2B`.
* **Placeholder Text / Input Borders:** Light gray `#D1D5DB` or `#9CA3AF`.
* **Footer Link Text:** `#7C3AED` (Medium purple for links like "Already have an account? Log in").

---

## 3. Typography & Font Stack

### Font Family Strategy
* **Primary Font:** **Inter** (Modern sans-serif, optimized for mobile UI readability).
* **Secondary / Fallback Font Stack:** `SF Pro Display`, `Roboto`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Helvetica`, `Arial`, `sans-serif`.

### Typography Hierarchy
* **Screen Title ("SIGN UP"):**
  * Size: `24px` to `28px` (Bold / `700` weight).
  * Color: White (`#FFFFFF`).
  * Letter Spacing: Wide (`1px` to `1.5px`).
* **Subtitle (if applicable under title):**
  * Size: `13px` to `14px` (Regular / `400` weight).
  * Color: Off-white / light translucent white (`rgba(255, 255, 255, 0.8)`).
* **Form Field Labels:**
  * Size: `12px` to `13px` (Medium / `500` weight).
  * Color: Dark Gray (`#374151`).
* **Input Field Text / Placeholders:**
  * Size: `14px` (Regular / `400` weight).
* **Button Text ("Create Account"):**
  * Size: `15px` to `16px` (Semi-bold / `600` weight).
  * Color: White (`#FFFFFF`).
* **Footer Prompt / Link:**
  * Size: `13px` (Regular / `400` weight with the interactive action in semi-bold).

---

## 4. Component-by-Component Breakdown

### A. Header Section (Top View)
* **Background:** Solid deep purple (`#3A0CA3`).
* **Content:**
  * Title text aligned to the top-left with generous padding.
  * Status bar elements (Time indicators, battery icons, Wi-Fi symbols) positioned at the very top, rendered in white.

### B. Foreground Form Card
* **Container Shape:** Rounded rectangle with pronounced top border radii (approx. `24px` to `32px` curvature on top-left and top-right).
* **Padding:** Generous internal padding (approx. `24px` on left, right, and top).

### C. Form Inputs
The form contains sequential vertical input groups (Label + Input Box):
1. **Name Field**
   * Label: "Name"
   * Input box with light border and rounded corners (`8px` border-radius).
2. **Email Field**
   * Label: "Email"
   * Input box mirroring the styling above.
3. **Password / Additional Field**
   * Label: "Password" or similar security field.
   * Includes a trailing icon on the right side (e.g., an eye toggle icon for password visibility).

### D. Primary Action Button
* **Shape:** Full-width rounded rectangle (`8px` to `12px` border-radius).
* **Background Color:** Rich purple (`#560BAD`).
* **Content:** Centered white text reading `"Create Account"`.
* **State:** Drop shadow applied subtly to give elevation over the white card background.

### E. Footer / Secondary Action
* Centered text at the bottom of the card.
* Example text: *"Already have an account? Sign in"* with the actionable phrase highlighted in primary purple.

* **Graphic Elements / Illustrations:**
