# Design Specification Document (`design.md`)

## 1. Project Overview & Aesthetic Identity
* **Brand Name:** Vertix Architecture
* **Tagline:** Spaces for a Better Tomorrow
* **Design Philosophy:** Warm brutalism, modern minimalism, understated luxury, and sustainable architectural elegance. High-contrast editorial typography paired with earthy neutrals, precise line-work, generous whitespace, and tactile imagery.
* **Layout Paradigm:** Full-width responsive canvas (`100vw`) with an inner constrained content grid (`max-width: 1440px`), strict vertical rhythm, hairline grid dividers (`1px`), and bespoke micro-interactions.

## 3. Typography Hierarchy

### 3.1 Font Families
* **Display / Editorial Serif:**
  * **Primary:** `Canela` or `Cormorant Garamond`
  * **Fallback:** `Georgia, "Times New Roman", serif`
  * **Characteristics:** High contrast between thick and thin strokes, elegant vertical axis, open letterforms.
* **Body / System / UI Sans-Serif:**
  * **Primary:** `Inter` or `Neue Haas Grotesk`
  * **Fallback:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", sans-serif`
  * **Characteristics:** Clean, neutral, high x-height, legible at microscopic sizes (caps metadata).

## 4. Layout Grid, Spacing & Container Rules

* **Page Viewport:** `100vw`, no lateral scrollbar (`overflow-x: hidden`).
* **Container Width:** `max-width: 1440px`, centered with `margin: 0 auto;`.
* **Horizontal Page Padding:**
  * Desktop: `64px` (`4rem`)
  * Tablet: `32px` (`2rem`)
  * Mobile: `20px` (`1.25rem`)
* **Vertical Section Spacing:** `96px` to `128px` padding top/bottom.
* **Border Lines:** Hairline borders (`1px solid #E5E5E3`) across sections to reinforce architectural drafting aesthetics.

## 6. Micro-Interactions & Animation Guidelines

1. **Header Navigation:**
   * Transition `padding` and `background-color` smoothly over `250ms ease` on scroll down.
2. **Featured Project Cards:**
   * Hovering over any card applies a gentle image scale (`transform: scale(1.03); transition: transform 600ms cubic-bezier(0.25, 1, 0.5, 1);`).
   * Project title color transitions to dark charcoal, accompanied by an animated right arrow indicator.
3. **Buttons (`Start a Project`, `Send Inquiry`):**
   * Default state: `#1F1F1F`.
   * Hover state: Background darkens slightly to `#383838`, and the trailing arrow `→` translates `+4px` along the X-axis.
4. **Form Controls:**
   * Active focus state: `outline: none; border-color: #1A1A1A; box-shadow: 0 0 0 1px #1A1A1A; transition: border-color 200ms ease;`.

## 7. Responsiveness & Breakpoint System

* **Desktop Large (`≥ 1280px`):** Full multi-column specifications as documented above.
* **Tablet (`768px – 1024px`):**
  * Featured Projects: 2-column by 2-row grid.
  * Capabilities: Horizontal scroll container or 3/2 split grid.
  * Stats: 2-column by 2-row layout with persistent vertical dividers.
  * Contact section: Single-column stacked (Header → Form → Image underneath).
* **Mobile (`< 768px`):**
  * Navigation collapsed into a minimalist slide-out overlay drawer.
  * Featured Projects: 1-column vertical feed with swipe pagination.
  * Capabilities: Vertical card list with icon left-aligned.
  * Stats: Vertical stack of 4 metrics with horizontal dividers.
  * Footer: Single-column stacked layout with centered text alignment.
