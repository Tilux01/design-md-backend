# UI/UX Design Specification & Clone Blueprint

This document provides the exact technical specification to build a pixel-perfect, full-screen clone of the provided "Stress Relief" meditation and breathing UI.

---

## 1. Global Layout & Structure

*   **View Type:** Full-screen immersive mobile interface (`100vw` × `100vh`).
*   **Background:** 
    *   **Base Layer:** High-resolution portrait photograph of a woman in silhouette against a warm, dramatic amber/orange studio backdrop.
    *   **Overlay:** A dark atmospheric gradient or warm orange tint layer to ensure UI component readability via glassmorphism blur effects.
*   **Layout Hierarchy (Z-Index Stack):**
    1. Background Image (`z-index: 0`)
    2. Vertical Progress Bar (`z-index: 1`)
    3. Typography & Badges (`z-index: 2`)
    4. Control Sliders (`z-index: 2`)
    5. Bottom Playback Controls (`z-index: 2`)

---

## 2. Typography & Fonts

To replicate this exact design, use clean, modern geometric or humanist sans-serif typefaces.

*   **Primary Font Family:** Apple System UI (`-apple-system`, `SF Pro Display`, `SF Pro Text`) or Inter / Plus Jakarta Sans as web-safe fallbacks.
*   **Font Fallback Stack:** `font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;`

### Text Elements:
1.  **Badge ("Stress Relief"):**
    *   *Size:* 12px / 0.75rem
    *   *Weight:* Regular / Medium (500)
    *   *Color:* White (`#FFFFFF`)
    *   *Case:* Sentence case.
2.  **Heading ("Take a deep breath..."):**
    *   *Size:* 28px – 32px / 1.75rem – 2rem
    *   *Weight:* Light / Regular (300–400)
    *   *Color:* Pure White (`#FFFFFF`)
    *   *Letter Spacing:* Tight (`-0.02em`)
3.  **Subtext / Countdown ("5...4...3...2..."):**
    *   *Size:* 13px / 0.8125rem
    *   *Weight:* Regular (400)
    *   *Color:* Semi-transparent white (`rgba(255, 255, 255, 0.7)`)
4.  **Slider Labels ("Volume", "Theme", numbers "54", "Bright"):**
    *   *Size:* 13px / 0.8125rem
    *   *Weight:* Medium (500)
    *   *Color:* White (`#FFFFFF`)

---

## 3. Glassmorphism Components (UI Elements)

All interactive containers use frosted glass (glassmorphism) styles:
*   **Background:** `rgba(255, 255, 255, 0.15)` to `rgba(255, 255, 255, 0.08)` (gradient linear or solid semi-transparent fill).
*   **Backdrop Filter:** `blur(20px)` / `-webkit-backdrop-filter: blur(20px);`
*   **Border:** Subtle 1px translucent border (`border: 1px solid rgba(255, 255, 255, 0.2);`)
*   **Border Radius:** Fully rounded pills (`border-radius: 9999px`).

### Component Breakdown:

1.  **Top Badge:**
    *   Pill container enclosing the text "Stress Relief".
    *   Compact padding (e.g., `padding: 6px 16px`).

2.  **Volume Slider:**
    *   Pill-shaped container.
    *   Left-aligned label: "Volume".
    *   Right-aligned value: "54".
    *   Center track featuring a vertical draggable thumb pill indicator (`|`).
    *   Subtle tick marks along the horizontal track.

3.  **Theme / Brightness Slider:**
    *   Pill-shaped container matching the volume slider geometry.
    *   Left label: "Theme".
    *   Right label: "Bright".
    *   Equidistant small dot indicators across the track.

4.  **Vertical Progress Track (Right side):**
    *   Vertical line running from the top timestamp (`4:15`) to the bottom timestamp (`15:10`).
    *   Color: Muted white/translucent line with a bright active top segment indicating elapsed time.

5.  **Bottom Media Controller Pod:**
    *   An interconnected pill-shaped bottom dock holding three buttons:
        *   **Left Button:** Skip backward 10 seconds (Circular icon with counter-clockwise arrow and "10").
        *   **Center Button:** Play/Pause button. Solid white circular background with a dark play triangle (`▶`).
        *   **Right Button:** Skip forward 10 seconds (Circular icon with clockwise arrow and "10").

---

## 4. Animation & Interaction Specifications

To make the clone feel fluid and organic (essential for a meditation app), incorporate the following animations:

1.  **Breathing Pulse Animation:**
    *   The background photo or subtle central glow should gently scale up and down in sync with the countdown/breath cycle:
        *   `@keyframes breathe { 0%, 100% { transform: scale(1); opacity: 0.9; } 50% { transform: scale(1.05); opacity: 1; } }`
        *   *Duration:* `8s` ease-in-out infinite.

2.  **Slider Dragging:**
    *   Smooth thumb translation (`transition: transform 0.1s ease-out`).
    *   Haptic feedback simulation on mobile touch start/end.

3.  **Play/Pause State Transition:**
    *   When pressed, the center button should feature a subtle active state scale down (`transform: scale(0.95)`).
