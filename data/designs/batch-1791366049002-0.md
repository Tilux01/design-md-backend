# Braun Minimalist Watch E-Commerce Concept — Design System & Specification

This document serves as the absolute design and structural specification to rebuild the Braun watch e-commerce landing page as a high-fidelity, full-screen digital experience.

---

## 1. Global Layout & Canvas

*   **View:** Full-screen responsive viewport (`100vw` × `100vh`), designed for desktop interfaces.
*   **Grid System:** Asymmetric layout.
    *   **Left Column (Navigation & Typography):** Fixed-position vertical content block aligned to the upper-left hierarchy.
    *   **Right Column (Visual Showcase):** Dynamic product showcase featuring macro product photography centered vertically.
*   **Background:** 
    *   Primary Color: `#EAEFF2` (Soft, neutral studio gray with subtle radial gradient vignette).
    *   Dark Variant (Slide/Theme 2): `#3A4146` (Deep slate charcoal).

---

## 2. Color Palette

| Role | Color Name | Hex Code | Usage |
| :--- | :--- | :--- | :--- |
| **Primary Text / Brand** | Pure White | `#FFFFFF` | Main headlines, BRAUN logo, active elements |
| **Secondary Text** | Cool Silver / Muted Gray | `#A8B2B8` | Navigation links, body copy descriptions, pagination |
| **Accent / Interactive** | Braun Yellow | `#F7B500` / `#FFC000` | Second hand on watches (authentic brand detail) |
| **Navigation Arrow** | Brand Green | `#00C259` | Carousel arrows, status indicators |
| **Background Light** | Studio Gray | `#EAEFF2` | Default page background |
| **Background Dark** | Slate Charcoal | `#3A4146` | Alternate dark mode background |

---

## 3. Typography

*   **Primary Font Family:** `Helvetica Neue`, `Arial`, sans-serif (Clean, modernist Swiss typography reflecting Dieter Rams / Braun design language).

### Typographic Hierarchy

1.  **Brand Logo (BRAUN):**
    *   Font Size: `24px`
    *   Letter Spacing: Wide tracking (`0.15em`)
    *   Weight: Bold (`700`)
    *   Transform: Uppercase
2.  **Hero Headline ("Less, but better"):**
    *   Font Size: `56px` - `64px`
    *   Line Height: `1.1`
    *   Weight: Bold (`700`)
    *   Color: `#FFFFFF`
3.  **Navigation Links:**
    *   Font Size: `13px`
    *   Line Height: `1.8`
    *   Weight: Normal (`400`)
    *   Color: `#A8B2B8` (Hover: `#FFFFFF`)
4.  **Body Paragraph / Manifesto:**
    *   Font Size: `11px`
    *   Line Height: `1.5`
    *   Color: `#A8B2B8`
    *   Max Width: `240px`
5.  **Footer / Copyright:**
    *   Font Size: `9px`
    *   Color: `#8C969D`

---

## 4. Component Library & UI Elements

### A. Brand Header
*   **Logo:** SVG or crisp vector text reading **BRAUN** with distinct condensed geometry.

### B. Navigation Menu
*   Split into two distinct lists separated by subtle whitespace:
    *   *Group 1:* `Concept`, `Clock`, `Watch`, `Online Shop`
    *   *Group 2:* `Recommend`, `Media`, `Shop`, `Contact`, `Repair`, `Member`
*   *Interaction:* Smooth CSS transition on hover (color shift from `#A8B2B8` to `#FFFFFF`).

### C. Carousel Pagination & Controls
*   **Pagination Indicator:**
    *   Four small horizontal rectangular blocks.
    *   Active Block: `#FFFFFF` (`width: 18px`, `height: 3px`)
    *   Inactive Blocks: `#8C969D` (`width: 6px`, `height: 3px`)
*   **Directional Arrow:**
    *   Simple chevron vector (`<`) in accent green (`#00C259`).
    *   Positioned at the bottom-left of the navigation block and right-middle edge of the product showcase.

### D. Product Showcase (Hero Asset)
*   **Asset:** High-resolution product image of a Braun minimalist watch (e.g., white leather strap with round white analog face, black baton markers, and signature yellow second hand).
*   **Placement:** Positioned on the right side of the canvas, extending vertically beyond the viewport to emphasize scale and precision.
*   **Shadows:** Soft, diffused drop-shadows casting to the right to create realistic depth against the studio background.

---
