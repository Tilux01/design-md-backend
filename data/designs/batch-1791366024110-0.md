# UI Layout Specification: Monochrome Dashboard Interface

## 1. Global Layout & Canvas Settings
- **Canvas / Background:** 
  - Outer background: Dark textured/brushed metal (`#1a1a1a` to `#262626`).
  - Main container (The "Device/Panel" frame): 
    - Width: `1100px` (or fill responsive)
    - Height: `700px`
    - Background color: `#2f2f31`
    - Border radius: `24px`
    - Outer border / glassmorphism effect: Semi-transparent white stroke (`rgba(255, 255, 255, 0.15)`), `2px` width.
- **Layout Architecture:** CSS Grid / Flexbox layout with defined component blocks mapped against a precise coordinate system.

---

- **Background:** `#222224`
- **Border Radius:** `16px`
- **Elements inside:**
  1. **Top Icon (Sparkle/Star):**
     - Shape: Circle with 4-point star icon inside.
     - Size: `44px` diameter.
     - Color: `#3a3a3d`. Star is white (`#ffffff`).
  2. **Navigation Dots/Pills:**
     - 6 vertical pill shapes.
     - Width: `24px`, Height: `8px`.
     - Color: `#3a3a3d`.
     - Spacing: `16px` vertical gap.
  3. **Bottom Actions:**
     - Small square icon slot (`24x24px`, radius `6px`, `#3a3a3d`).
     - Bottom circular button: Size `40px` diameter, color `#3a3a3d`.

---
