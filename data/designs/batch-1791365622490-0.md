# Quantix - AI-Powered Trading Dashboard Design System & Specification

This document provides the exact structural, typographical, and styling specifications to recreate the Quantix trading platform dashboard precisely as shown in the interface image.

## 1. Global Styles & Foundations

### Color Palette
The interface uses a deep, dark space-themed palette built with dark grays, translucent glassmorphism overlays, and vibrant accent colors.

| Role | Color Name | Hex Code | Usage |
| :--- | :--- | :--- | :--- |
| **Background** | Deep Space Black | `#090a0f` | Main application background (implied) |
| **Surface (Dark)** | Obsidian | `#0d0f14` | Sidebar and base card containers |
| **Surface (Card)** | Dark Slate Glass | `#12151c` | Floating card backgrounds (BTC/ETH cards) |
| **Border / Divider** | Subtle Line | `#1a1e29` | Table rows, structural dividers |
| **Text Primary** | Pure White | `#ffffff` | Headers, prices, primary labels |
| **Text Secondary**| Muted Gray | `#8c92a4` | Subtitles, descriptions, table headers |
| **Text Tertiary** | Dark Muted | `#5a6072` | Inactive icons, footnotes |
| **Brand Purple** | Neon Indigo | `#6366f1` / `#7c3aed` | Active states, badges, accents (Beta) |

## 2. Layout Structure

The layout uses a **two-column master-detail grid**:
1. **Sidebar Navigation (`w-72` / `288px`)**: Fixed width on the left, high-contrast dark background with frosted glass touches.
2. **Main Content Area (`flex-1`)**: Expansive scrolling viewport containing ticker banners, interactive feature cards, and tabular data.
