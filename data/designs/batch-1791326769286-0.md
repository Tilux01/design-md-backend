# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial Minimalist Luxury & Precision Horology Portfolio.
- **Visual Density & Whitespace Ratio**: High-contrast, spacious, dark-mode immersive layout prioritizing typographic clarity, macro product photography, and precise technical specification display.
- **Surface Elevation Model**: Deep obsidian base canvas (`#000000`) with ultra-subtle layered surface cards, single-pixel hairline borders (`rgba(255, 255, 255, 0.08)`), and matte brushed metallic containment panels.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Precision horological hierarchy, high-tracking uppercase labels, fine-line architectural framing, exact hex code metadata overlays.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `12px`, font-weight `500`, tracking `0.1em`, border-radius `9999px`, background `rgba(255, 255, 255, 0.03)`, border `1px solid rgba(255, 255, 255, 0.1)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before`.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `<span class="w-1.5 h-1.5 rounded-full bg-[#C4A35A] inline-block"></span>`.
