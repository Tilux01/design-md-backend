# UI/UX Specification: Dynamic 365 Sales Hub - Call Insights

## 1. Executive Summary & Overview
This document provides a comprehensive design specification for the "Discuss New Opportunity" phone call analysis screen within **Dynamic 365 Sales Hub**. The interface is built for enterprise CRM users (specifically sales representatives and managers) to review call metrics, monitor competitor and brand mentions, track action items, and analyze conversational sentiment via an integrated transcript.

The layout adopts a modern, light-gray minimal enterprise design system (Fluent UI inspired) with rounded card containers, subtle drop shadows, and high-contrast typography optimized for data density and readability.

---

## 2. Global Layout & Canvas Architecture

*   **View Mode:** Full-Screen Application View (100% viewport width and height).
*   **Background Canvas:** Light neutral gray (`#e5e7eb` or `#e8eaed`) base background with clean white (`#ffffff`) and soft tinted cards.
*   **Grid System:** Asymmetric two-column dashboard structure:
    *   **Left Navigation Rail:** Fixed vertical icon bar for system-wide CRM modules.
    *   **Left Sub-Navigation Panel:** Collapsible/Contextual details (Competitors, Brands, Action Items).
    *   **Main Content Area:** Call Insights analytical summary metrics, audio waveform timeline, and conversational transcript history.

---

## 3. Typography & Font Stack

To achieve an exact clone, the typography must mirror Microsoft's Fluent UI design standards.

*   **Primary Font Family:** `Segoe UI`, -apple-system, BlinkMacSystemFont, "Roboto", "Helvetica Neue", Arial, sans-serif.
*   **Fallback Strategy:** If `Segoe UI` is unavailable, modern OS-native sans-serif fonts (`-apple-system` for macOS/iOS, `Roboto` for Android/ChromeOS) will be utilized.
