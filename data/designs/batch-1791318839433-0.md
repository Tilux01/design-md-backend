# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial Minimalist E-Commerce (Clean, high-contrast, sophisticated typography paired with stark monochrome cards and high-end photographic focus).
- **Visual Density & Whitespace Ratio**: High whitespace. Generous vertical padding between sections (64px to 128px), balanced grid gaps (24px to 32px), and clear focal hierarchies allowing product photography to drive visual interest.
- **Surface Elevation Model**: Flat, clean surfaces with crisp borders (`#E5E7EB`). Minimal drop shadows restricted to interactive micro-elements, primary call-to-action buttons, and floating utility menus.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase micro-labels, perfectly rounded dark action pills, high-contrast imagery containers, clean minimal borders.
- **Pill Badge Specification**: Padding: `6px 16px`, font-size: `12px`, font-weight: `600`, tracking: `0.05em`, border-radius: `9999px`, background: `#0F172A`, text: `#FFFFFF`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content to prevent rendering glitches.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;` or `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.

# 7. Motion Mechanics, Framer Motion & CSS Animations
- **Motion Principles**: Smooth, fast entrance animations using cubic-bezier easing (`0.16, 1, 0.3, 1`) with subtle scaling and translation effects.
- **Framer Motion Variants Code**:
```jsx
export const containerVariants = {
  hidden: { opacity: 0, y: 20 },
  visible: { 
    opacity: 1, 
    y: 0,
    transition: { duration: 0.4, ease: [0.16, 1, 0.3, 1], staggerChildren: 0.1 }
  }
};
```

- **CSS `@keyframes` Animations**:
```css
@keyframes floatGlow {
  0%, 100% { transform: translateY(0px) scale(1); opacity: 0.8; }
  50% { transform: translateY(-8px) scale(1.02); opacity: 1; }
```
