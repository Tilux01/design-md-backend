# DESIGN.md — Burger Landing Page Clone

## 1. Global Layout & Viewport
* **Layout Structure:** Full-screen (`100vw` width, `100vh` height), responsive grid.
* **Base Background Color:** Warm Orange (`#E88931` or dynamic radial gradient shifting to a lighter central ambient glow `#F0A352`).
* **Content Container:** Centered max-width container (`1200px` / `1440px`) with consistent horizontal padding (`32px` to `64px` depending on screen size).
* **Z-Index Hierarchy:**
  1. Background Gradient / Base Layer (`z-index: 0`)
  2. Background Typography ("BURGER") (`z-index: 1`)
  3. Floating Ingredients & Visual Effects (`z-index: 2`)
  4. Central Hero Burger Image (`z-index: 3`)
  5. Navigation Header & UI Elements (`z-index: 4`)

---

## 2. Typography System

### Primary Headline ("BURGER")
* **Role:** Giant stylized background typography framing the central burger.
* **Font Family:** Ultra-bold, slab-serif or geometric display sans-serif (such as **Impact**, **Anton**, **Bebas Neue**, or **Montserrat Black**).
* **Font Weight:** `900` (Black)
* **Font Size:** Responsive fluid typography (e.g., `clamp(10rem, 20vw, 24rem)`)
* **Color:** Pure White (`#FFFFFF`) with reduced opacity (`opacity: 0.9` or `0.95`) to allow depth behind the burger.
* **Letter Spacing:** Tight / Negative tracking (`-0.03em`)

### Navigation & Body Fonts
* **Font Family:** Clean geometric sans-serif (e.g., **Inter**, **Poppins**, or **Roboto**)
* **Fallback Stack:** `system-ui, -apple-system, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
* **Nav Links Weight:** `600` (Semi-bold), Font Size: `14px` / `16px`, Color: White (`#FFFFFF`).
* **Body/Paragraph Copy Weight:** `400` (Regular), Font Size: `14px`, Line-height: `1.6`, Color: Off-white (`rgba(255, 255, 255, 0.85)`).

## 4. UI Components & Elements

### A. Navigation Bar (Header)
* **Position:** Fixed or absolute at the top (`top: 0`, left/right spanning with padding).
* **Height:** `80px`
* **Left:** Brand Logo (minimalist burger or icon symbol in white).
* **Center/Left-Center:** Navigation Links (`Home`, `Menu`, `About`, `Contact`) with smooth hover transitions (e.g., slight opacity drop or underline scale).
* **Right:** Utility Icons (Search icon, Shopping Cart icon with a notification dot).

### B. Hero Content Area
* **Central Visual (The Burger):**
  * High-resolution cutout PNG/WebP of a double-patty gourmet burger with melted cheese, fresh lettuce, tomatoes, and toasted sesame seed buns.
  * Positioned dead center of the viewport, overlapping the "BURGER" text.
* **Floating Elements (Parallax / Floating Effect):**
  * Detached lettuce leaves and tomato slices floating dynamically around the upper left and right flanks of the burger.
* **Body Copy (Bottom Left):**
  * A 3-to-4 line descriptive paragraph explaining the quality or origin of the burger ("Juicy, hand-crafted patties made with 100% prime beef...").
* **Call to Action (CTA) Button:**
  * **Text:** "Order Now"
  * **Background:** Deep Charcoal (`#1A1A1A`) or matching dark contrast.
  * **Border Radius:** Fully rounded pill style (`50px`) or soft rounded rectangle (`8px`).
  * **Padding:** `14px 32px`
  * **Typography:** Bold, White (`#FFFFFF`), uppercase or capitalized.
  * **Hover State:** Slight scale up (`transform: scale(1.05)`) with an enhanced box-shadow.

## 5. Animation & Interaction Specifications (For Developers)

To recreate the dynamic, modern feel of the original design, apply the following CSS/JS animations:

1. **Initial Page Load (Entrance Animation):**
   * **Background & Text:** Fade in (`opacity: 0` to `1`) over `0.8s` cubic-bezier.
   * **Hero Burger:** Scale up and fade in from slightly smaller (`transform: scale(0.95)`, `opacity: 0`) to `1` over `1s`.
   * **Floating Leaves/Ingredients:** Staggered slide-in from random directions to create immediate depth.

2. **Continuous Ambient Floating (Idle Animation):**
   * Apply a smooth infinite keyframe floating animation to the central burger and floating leaves:
   ```css
   @keyframes float {
     0% { transform: translateY(0px) rotate(0deg); }
     50% { transform: translateY(-10px) rotate(1deg); }
     100% { transform: translateY(0px) rotate(0deg); }
   }
   .hero-burger {
     animation: float 6s ease-in-out infinite;
   }
   .floating-leaf-left {
     animation: float 4s ease-in-out infinite alternate;
   }
   ```

3. **Mouse Parallax Effect (Interactive):**
   * Implement a lightweight Vanilla JS mousemove listener to subtly shift the background text, burger, and floating leaves in opposing axes based on cursor coordinates for an immersive 3D depth effect.
