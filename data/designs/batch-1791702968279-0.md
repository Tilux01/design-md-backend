# Design Specification Document: Apple VisionPro Landing Page

This document provides a detailed design specification to recreate the Apple VisionPro concept landing page layout.

---

## 1. Page Layout & Viewport Configuration

* **Viewport Bounds**: Fullscreen edge-to-edge layout (`100vw` × `100vh` minimum height).
* **Frame Removal**: No external borders, device mockups, or framing outer containers. The canvas spans the edge of the screen.
* **Canvas Background**:
  * Base Background: Light neutral gradient / off-white background (`#F5F5F7` at edges blending to `#FFFFFF` in the center).
  * Texture / Pattern: Ultra-faint vertical guideline grid spanning full height (lines spaced approximately `80px`–`100px` apart, color: `rgba(0, 0, 0, 0.03)`).
* **Overall Alignment**: Center-aligned single-column layout with fixed top header and bottom pinned visual subject.

## 3. Typography System & Fallbacks

### Font Family Stacks
* **Primary System Font**: `SF Pro Display`, `-apple-system`, `BlinkMacSystemFont`, `'Inter'`, `'Helvetica Neue'`, `sans-serif`.
* **Fallback Stack**: If custom Apple fonts are unavailable, use `Inter` or `Plus Jakarta Sans` for clean geometric structure.

### Text Elements & Hierarchy

#### 1. Main Headline
* **Line 1 ("Stay in the")**:
  * Font Weight: Light / Thin (`300` or `200`)
  * Size: `56px` (`3.5rem`)
  * Line Height: `1.1`
  * Letter Spacing: `-0.02em`
  * Color: `#1D1D1F`
* **Line 2 ("Orbit of Vision")**:
  * Font Weight: Bold / Heavy (`700` or `800`)
  * Size: `72px` (`4.5rem`)
  * Line Height: `1.05`
  * Letter Spacing: `-0.03em`
  * Color: `#000000`

#### 2. Subheading / Price Text
* Text Content: `Buy VisionPro - starting at $2,400`
* Font Weight: Regular (`400`) with Bold (`700`) on `$2,400`
* Size: `18px` (`1.125rem`)
* Color: `#6E6E73` (Price in `#000000`)
* Margin Top: `16px`

#### 3. Navigation Text
* Font Weight: Medium (`500`)
* Size: `13px` (`0.8125rem`)
* Color: Inactive `#6E6E73`, Active `#000000`

## 4. Header & Navigation Component Layout

The top navigation section consists of three distinct horizontal groups aligned along a single flex row:

```
[ Left: Logo ] ----------- [ Center: Pill Nav ] ----------- [ Right: Actions ]
```

### 1. Left Group: Logo
* Text: **Apple VisionPro**
* Styling:
  * "Apple ": Light weight (`300`), `#000000`
  * "VisionPro": Medium/Bold weight (`600`), `#000000`
  * Font Size: `18px`

### 2. Center Group: Floating Navigation Bar
* **Container**: Pill-shaped capsule with backdrop blur (`backdrop-filter: blur(20px)`).
* Background: `rgba(255, 255, 255, 0.65)`
* Border: `1px solid rgba(0, 0, 0, 0.06)`
* Border Radius: `9999px`
* Padding: `8px 24px`
* Gap between items: `20px`
* **Items**:
  1. `Home` (Active state: Black text with a small dark underline/indicator below)
  2. `Demo`
  3. *Apple Symbol Icon* (Black filled logo SVG, `14px` size)
  4. `Products`
  5. `Stores`

### 3. Right Group: Actions
* **Cart Icon**: Shopping bag outline icon (`18px`).
* **Region Select**: Pill container reading `Canada ∨`
  * Background: `transparent` or light grey pill
  * Border: `1px solid rgba(0, 0, 0, 0.15)`
  * Border Radius: `9999px`
  * Padding: `6px 14px`
  * Font Size: `12px`
* **"Buy" Button**:
  * Background: Solid Black (`#000000`)
  * Text Color: White (`#FFFFFF`)
  * Border Radius: `9999px`
  * Padding: `8px 22px`
  * Font Weight: Medium (`500`)

## 6. Product Image & Visual Effects

### 1. Headset Asset Specification
* **Asset Type**: High-resolution, transparent background PNG / WebP.
* **Device Representation**: Top-down 3/4 perspective shot of an Apple Vision Pro headset in a custom dark matte charcoal colorway.
* **Image Details**:
  * Visor glass pointing upward/frontward towards the top center of the screen.
  * Visible internal mesh light seal cushion in dark grey texturing.
  * Dual audio head straps extending downwards on both left and right sides.
  * Metallic top frame vents and camera sensor cutouts clearly visible.
* **Placement & Positioning**:
  * Position: Horizontal center (`50%`), pinned to the bottom of the viewport (`bottom: -10%` to `0%` clipping slightly off-screen or resting gracefully near the bottom edge).
  * Scale: Large hero scale (width roughly `650px` – `800px` on desktop).
  * Rotation: `0deg` neutral horizontal orientation.

### 2. Light Projection Beam Effect (Backdrop Layer)
* **Description**: A soft, trapezoidal luminous light beam that appears to emit from the top glass visor of the headset upward into the background of the text.
* **Shape**: Inverted cone/trapezoid widening from the headset top edge up to the upper third of the screen behind the text "Orbit of Vision".
* **Color/Style**: Smooth linear/radial gradient transitioning from `rgba(255, 255, 255, 0.95)` near the visor lens to a soft transparent gradient fade out `rgba(255, 255, 255, 0)` past the primary headline.
* **Layer Depth**: Placed directly behind the headline text and above the background grid lines, originating behind the headset PNG.

### 3. Decorative Sparkle Icon
* **Placement**: Located centrally directly beneath the main visor frame / below the cushion gap.
* **Shape**: Small 4-pointed star / diamond sparkle icon in solid dark grey (`#333333`).
* **Size**: Approximately `16px` × `16px`.
