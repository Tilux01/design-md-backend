# Design System & Specification: CliniQ Healthcare Mobile App

This document provides a comprehensive design system and exact specification for the **CliniQ** healthcare mobile application. The implementation targets a **full-screen, native mobile viewport** (ignoring device frames/mockup backgrounds). 

---

## 1. Global Design Tokens & Foundation

### Color Palette
The design employs a calm, clinical, and trustworthy medical aesthetic utilizing deep slate blues, crisp whites, and icy blue-grey accents.

*   **Primary Dark / Accent:** `#0a2533` (Used for primary buttons, active cards, headers, and major text accents)
*   **Primary Background / Canvas:** `#f4f6f8` (Off-white, soft light grey for screens and card backgrounds)
*   **Card Background (Light):** `#ffffff` (Pure white for unselected container blocks)
*   **Card Background (Frosted/Glass):** `rgba(255, 255, 255, 0.7)` with `backdrop-filter: blur(20px)` (Used for floating action overlays and transparent glass elements)
*   **Text Primary:** `#1a2b3c` (High-contrast dark slate for main titles and names)
*   **Text Secondary / Muted:** `#7c8b98` (Mid-tone grey-blue for subtitles, dates, metadata, and labels)
*   **Active / Selection Blue:** `#5cb8e4` / `#4fa3d1` (Soft, vibrant blue used for selected states like dates and sliders)
*   **Border / Divider:** `rgba(0, 0, 0, 0.05)` to `rgba(0, 0, 0, 0.08)`

### Typography & Fonts
The UI relies on a clean, modern geometric sans-serif typeface to ensure legibility in medical contexts.

*   **Primary Font Family:** **SF Pro Display**, **Inter**, or **system-ui** (fallback stack: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`).
*   **Font Weights Used:** 
    *   `Regular (400)`: Body text, dates, times, pricing descriptions.
    *   `Medium (500)`: Secondary headers, button labels, card titles.
    *   `Semibold/Bold (600/700)`: Screen titles, primary doctor names, price figures.

*   **Rating Badge:** Small pill badge showing a white star icon followed by `4.6`.
