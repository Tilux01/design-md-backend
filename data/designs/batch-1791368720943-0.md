# MachinaFusion - Design System & UI Specification

This specification outlines the exact design tokens, typography, layout structure, and components required to build a pixel-perfect, full-screen responsive clone of the MachinaFusion web interface.

---

## 1. Global Styles & Design Tokens

### Colors
| Role | Color Name | Hex Code / Value | Usage |
| :--- | :--- | :--- | :--- |
| **Background** | Canvas Light | `#F0F2F5` (or pure `#FFFFFF` inside viewport) | App background / Page surface |
| **Primary Text** | Deep Obsidian | `#111111` | Headings, main logo, primary labels |
| **Secondary Text**| Muted Gray | `#666666` | Body text, subheaders, inactive pills |
| **Accent / Glow** | Soft Warm Glow | Radial gradient from `#FFF4E0` to transparent | Central background sphere / focal blur |
| **Border / Stroke**| Subtle Border | `#E2E2E6` | Pill borders, divider lines |

### Typography
* **Font Family:** Inter, system-ui, -apple-system, sans-serif
* **Weights Used:** Regular (400), Medium (500), Semi-Bold (600)

| Style | Font Size | Line Height | Weight | Color |
| :--- | :--- | :--- | :--- | :--- |
| **Hero Heading** | `48px` - `72px` (Fluid) | `1.05` | Semi-Bold (600) | `#111111` |
| **Body / Lead** | `14px` | `1.4` | Regular (400) | `#555555` |
| **Navigation / Pill**| `13px` | `1.0` | Medium (500) | `#111111` / `#666666` |

---

## 2. Layout Structure & Grid

* **Viewport:** Full-screen (`100vw` × `100vh`), centered content container or edge-to-edge layout with consistent padding.
* **Padding (Desktop):** 
  * Top/Bottom: `32px`
  * Left/Right: `48px`
* **Z-Index Layers:**
  * `z-0`: Background gradient glow & organic shapes
  * `z-10`: Central visual elements (hands imagery & typography overlay)
  * `z-20`: Floating navigation, header, and footer controls

---

## 3. Component Specifications

### A. Navigation Header
* **Position:** Fixed top, spanning horizontally with padding.
* **Height:** `64px`
* **Elements:**
  1. **Brand Logo:** 
     * Icon: Abstract geometric mark (`#111111`)
     * Text: **MachinaFusion** (Semi-bold, `16px`)
  2. **Interactive Menu Pill:**
     * Background: `#000000` (Dark pill)
     * Text/Icon Color: `#FFFFFF`
     * Border Radius: `999px` (Full pill)
     * Content: Plus/Menu icon + "Menu" text label.
  3. **Nav Links / Pills:**
     * Items: `Cutting-edge R&D`, `Adaptive AI`, `Scalable Solutions`
     * Background: `#F5F5F7` with subtle `#E2E2E6` border.
     * Border Radius: `999px`
     * Padding: `8px 16px`

---

### B. Hero Section (Core Visual)

* **Layout:** Centered asymmetric composition balancing human and robotic elements.
* **Central Typography:**
  * Main Title: `MachinaFusion`
  * Sub-headline overlay: `gence that fe...` (Blending typography with visual depth, styled with opacity or blend-mode).
* **Visual Imagery (The Touch):**
  * **Left Side:** Human hand reaching forward, soft cinematic lighting, realistic skin tones.
  * **Right Side:** Articulated robotic/mechanical hand mirroring the human gesture.
  * **Atmosphere:** Central glowing aura behind the gap between the two hands, symbolizing connection and intelligence.

---

### C. Footer / Bottom Bar

* **Left Side (Meta Info):**
  * Category Tag: `Precision Engineering` (Uppercase, tracked out, `11px`, `#888888`)
  * Description Block: `"Bridging the gap between humanity and robotics for a smarter, more connected future"` (`13px`, max-width `280px`, line-height `1.4`).
* **Center:**
  * Vertical divider line (`1px` width, height `24px`, color `#CCCCCC`).
* **Right Side (Interactive Filter Pills):**
  * Circular or rounded pill buttons: `Algorithmic`, `AI`, `Robotics`
  * Styling: Outlined pills (`1px` solid `#D1D1D6`), white/transparent background, dark text. Hover states invert or darken.

---

## 4. Responsive Behavior & Interactions

* **Hover States:** 
  * Nav pills and filter buttons shift to slightly darker backgrounds (`#EBEBEF`) with smooth cubic-bezier transitions (`0.2s ease`).
* **Mobile Adaptability:**
  * Collapse navigation items into the dark "Menu" modal drawer.
  * Stack hero elements vertically (Human hand top, robotic hand bottom, typography centered).
