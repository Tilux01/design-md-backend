# Design Specification: Microsoft Dynamics 365 Sales Hub Clone

## 1. Global Layout & Structure

The interface follows a modern, enterprise SaaS layout divided into three main vertical columns/panels, overlaid with a top application header.

```
+---------------------------------------------------------------------------------+
| Top Application Header (Global Search, Actions, Profile)                       |
+-------------------+--------------------+----------------------------------------+
|                   |                    | Main Detail & Workspace Area           |
| Left Navigation   | Middle List/Feed   | - Contact & Lead Summary Cards         |
| Menu              | Panel ("My Work")  | - Process Stages (Opportunity Sales)   |
|                   |                    | - Timeline, Analytics & Lead Score     |
+-------------------+--------------------+----------------------------------------+
```

### 1.1 Color Palette
* **Background Canvas:** Soft light gray (`#E8ECEF` / `#F0F2F5`) with warm, organic gradient washes (pale yellows, creams, and mint greens in the workspace panels).
* **Sidebar Menu Background:** Neutral light gray (`#E2E5E8` to `#EAECEF`).
* **Active/Selected Elements:** 
  * Bright Yellow-Green highlight for active states and scores (`#D5F348`, `#C4EB34`).
  * Teal/Cyan for active process steps and progress meters (`#0F8B8D`, `#2EA39F`).
  * Dark Charcoal/Black for primary text and high-contrast badges (`#1A1A1A`).
* **Text Colors:**
  * Primary Headings: Dark charcoal (`#222222`).
  * Secondary Labels: Muted gray (`#6E7781`).
  * Accent/Badge Text: Pure black (`#000000`) or white depending on contrast.

### 1.2 Typography & Fonts
* **Primary Font Family:** `Segoe UI`, `-apple-system`, `BlinkMacSystemFont`, `Roboto`, `Helvetica Neue`, Arial, sans-serif.
* **Fallback Strategy:** If `Segoe UI` is unavailable, the system defaults to the native OS sans-serif stack (San Francisco on macOS, Roboto on Android/ChromeOS, Arial as a universal web-safe fallback).
* **Font Weights & Hierarchy:**
  * **App Titles / Header:** 600 Semi-Bold (approx. 16px).
  * **Section Headers (e.g., "Menu", "My Work", "Contact"):** 600 Semi-Bold (approx. 14px–18px).
  * **Names & Key Metrics (e.g., "Gabriela Christiansen", "90"):** 600–700 Bold (approx. 18px–28px for numbers).
  * **Body Text / Labels:** 400 Regular (approx. 12px–14px).
