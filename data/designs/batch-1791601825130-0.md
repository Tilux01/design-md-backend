# System Design Specification: MODERA Luxury E-Commerce Interface

---

## 1. Design Overview & Visual Identity

### 1.1 Aesthetic Style
* **Theme**: Dark frosted glassmorphism (Neomorphic/Liquid Glass), modern industrial luxury, Scandinavian-Japanese (Japandi) minimalism.
* **Surface Concept**: Translucent layered cards floating above a softly focused dark ambient base.
* **Depth & Lighting**: Subtle perimeter strokes (inner glows mimicking top-lit frosted acrylic), low-opacity drop shadows, high backdrop blur (`blur(24px)` to `blur(40px)`).
* **Corner Radius Philosophy**: Smooth continuous squircle curves ranging from `16px` to `32px`, pill shapes (`9999px`) for buttons, badges, and search inputs.

---

## 2. Color Palette & Surface Tokens

### 2.1 Base & Glass Tokens
* **Canvas Backdrop**: `#121214` (Deep charcoal obsidian)
* **Main Container Glass**: `rgba(45, 46, 50, 0.72)` with `backdrop-filter: blur(36px)`
* **Primary Card Surface**: `rgba(60, 62, 68, 0.55)`
* **Secondary / Nested Card Surface**: `rgba(75, 78, 85, 0.40)`
* **Input / Recessed Track Surface**: `rgba(28, 29, 32, 0.65)`
* **Glass Border Stroke (Light Source Top)**: `rgba(255, 255, 255, 0.14)` (1px solid)
* **Subtle Internal Border**: `rgba(255, 255, 255, 0.06)`

### 2.2 Text & Content Colors
* **Primary Text**: `#FFFFFF` (100% white, high contrast headers, prices)
* **Secondary Text**: `rgba(255, 255, 255, 0.70)` (`#B5B5BC` for descriptions, body text)
* **Muted / Placeholder Text**: `rgba(255, 255, 255, 0.42)` (`#767680` for inputs, subtitles)
* **Rating Star Accent**: `#F5B838` (Warm gold)
* **Favorite / Wishlist Accent**: `#E65377` (Soft coral rose)
* **Button Dark Accent**: `#1F2023` (Near-black solid pill background)

## 3. Typography Specification

### 3.1 Primary Font Family
* **Primary Family**: `Plus Jakarta Sans` or `Inter`
* **Alternative/Display Option**: `Outfit` or `General Sans`
* **System Fallbacks**: 
  ```css
  font-family: "Plus Jakarta Sans", "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
  ```

### 3.2 Type Hierarchy
* **Brand Logo ("MODERA")**: 15px | Weight: 700 (Bold) | Letter-spacing: +0.08em | Uppercase
* **Hero/Card Titles ("Great Value Deals")**: 22px | Weight: 600 (Semi-bold) | Line-height: 1.2
* **Section Headers ("Elegance Meets Simplicity")**: 17px | Weight: 600 (Semi-bold) | Line-height: 1.3
* **Price Value ("$302")**: 20px | Weight: 700 (Bold)
* **Category Pills & Action Tags**: 12px – 13px | Weight: 500 (Medium)
* **Body / Descriptions**: 11px – 12px | Weight: 400 (Regular) | Line-height: 1.45 | Color: Secondary
* **Micro-labels ("OUR TEAM", "EXCLUSIVE", "JOIN NOW")**: 9px – 10px | Weight: 600 | Letter-spacing: +0.06em | Uppercase
* **Slider Center Label ("SLIDE LEFT AND RIGHT")**: 9px | Weight: 700 | Letter-spacing: +0.12em | Uppercase

## 4. Layout Architecture & Grid Structure

The viewport uses a standard 16:9 or 16:10 responsive layout container centered on screen with padding `28px` to `36px`.

```
+---------------------------------------------------------------------------------------------------+
|  [Logo]  [--------- Search Bar ---------]          [App] [Wishlist] [Cart] [User Profile]       |
+---------------------------------------------------------------------------------------------------+
|  (Filter) [ Table ] [ Sofa ] [ Bed ] [ Lamps ] [ Speakers ] [ Chairs ]                            |
+---------------------------------------------------------------------------------------------------+
|                           |                                         |                             |
|                           |   [ Great Value Deals Card            ] |   [ OUR TEAM Widget       ] |
|   [ LEFT SHOWCASE         |   [ (Sculptural Chair Display)        ] |                             |
|     FEATURED PRODUCT      |-----------------------------------------|-----------------------------|
|     CARD                  |   [ EXCLUSIVE ]   |   [ Mini Product  ] |   [ JOIN NOW Widget       ] |
|     $302 Armchair         |   Elegance Meets  |     Preview       |     (Email + Subscribe)   |
|     Slider Controls ]     |   Simplicity Copy |     with "Open"   |-----------------------------|
|                           |   Card            |     Button        |   [ OUR SHOP Widget       ] |
|                           |                   |                   |     (Address + Imagery)   |
+---------------------------+-------------------+---------------------+-----------------------------+
```

### Grid Dimensions & Proportions
* **Root Container Width**: Max `1280px` – `1440px`, height auto-adjusting (min `820px`).
* **Column Breakdown**:
  * **Left Column (Featured Product Slider)**: `32%` total width.
  * **Center Column (Value Deals + Split Banners)**: `43%` total width.
  * **Right Column (Sidebar Utility Stack)**: `25%` total width.
* **Gutter / Gap**: `16px` throughout all main modules.

## 7. Interactive States & Micro-Interactions

| Element | Default State | Hover / Focus State | Active / Clicked State |
|---|---|---|---|
| **Category Pills** | `rgba(255, 255, 255, 0.05)` background, 75% text | `rgba(255, 255, 255, 0.14)` background, 100% white text | Scale `0.97`, solid white background with black text |
| **Pill Arrows (`↗`)** | Translucent circle, 70% icon opacity | Background brightens to `rgba(255, 255, 255, 0.25)`, icon scales 1.1x | Scale `0.92` |
| **Search Input** | Border `rgba(255, 255, 255, 0.08)` | Border `rgba(255, 255, 255, 0.25)`, inner glow | Cursor active, text opacity 100% |
| **Bottom Slider Bar** | `#F0EBE3` background, pure black arrows | Arrow circles scale up 1.05x on hover | Arrow click transitions featured product with horizontal slide animation |
| **Subscribe Button** | Solid dark charcoal `#1F2023` | Dark charcoal with `rgba(255, 255, 255, 0.15)` border highlight | Scale `0.98` |
| **Heart / Wishlist** | Pink glyph `#EB5A7C` | Scale `1.15`, pulse animation on toggle | Filled solid pink with light bloom glow |
