# MARV Virus Interactive Dashboard Design System

## Global Layout & Foundations
- **Canvas:** Full screen, immersive dark mode application.
- **Background:** Dark charcoal/grey (`#1e2124` to `#16181b`), clean flat backdrop without decorative outer wrapper frames.
- **Color Palette:**
  - Primary Background: Dark Slate/Charcoal (`#1A1D20`)
  - Accent / Highlights: Warm Peach / Pastel Orange (`#F2B184`)
  - Primary Text: Crisp White (`#FFFFFF`)
  - Secondary Text: Muted Cool Grey (`#8C929A`)
  - Sidebar / Secondary Surface: Darker Muted Grey (`#2B3036`)
- **Typography:**
  - Font Family: Clean, geometric sans-serif (e.g., Inter, SF Pro Display, Roboto).
  - Hierarchy: Bold uppercase headings, precise mono-style metadata labels, medium body copy.

---

## Component Specifications

### 1. Top Navigation & Branding
- **Positioning:** Top-left corner.
- **Elements:**
  - **Logo Icon:** Square outlined icon containing a minimalist geometric glyph.
  - **Company/App Name:** "AKINA SAKIVA" stacked vertically in small bold uppercase text (letter-spaced).
- **Taxonomy Metadata (Top Center):**
  - Family: `FILOVIRIDAE` (Small uppercase, white label with muted grey category title above).
  - Genus: `MARVBURGVIRUS` (Small uppercase, white label with muted grey category title above).

### 2. Hero Section & Main Title
- **Taxonomy Badge:** "Group V (–)ssRNA" in small muted uppercase typography.
- **Main Heading:**
  - Text: `MARV`
  - Font Style: Extra-bold, massive scale, pure white.
- **Severity Indicator:**
  - Label: `HIGH` in bold red/orange accent text, positioned above a subtle horizontal data progress line ending in an interactive node.

### 3. Key Metrics Bar
- **Layout:** Horizontal data display grouping critical statistics.
- **Item 1 (Case Fatality Rate):**
  - Icon: Minimalist skull/person icon inside a small circular outline.
  - Label: "Case fatality rate" (Small muted grey text).
  - Value: `27%` (Large bold white typography).
- **Item 2 (Average Incubation Time):**
  - Icon: Minimalist clock/timer outline.
  - Label: "Average incubation time" (Small muted grey text).
  - Value: `2–21 DAYS` (Large bold white typography).

### 4. Action CTA Button
- **Positioning:** Bottom-left.
- **Style:** Solid rectangular button filled with the warm peach accent color (`#F2B184`).
- **Text:** `PLAN OUTBREAK` (Bold dark uppercase text).
- **Trailing Icon:** Right arrow (`→`) in dark charcoal.

### 5. Central 3D Asset Viewer
- **Positioning:** Right-center main stage.
- **Visual Asset:** High-detail, porous organic 3D structure resembling a virus/pathogen with glowing gold inner crevasses and dark matte exterior.
- **Frame/Border:** Enclosed in a precise thin grey outline box.
- **Navigation Controls:**
  - Right-side vertical caret buttons (`>` and `<`) for sliding/paging through specimens.
  - Floating UI control pill overlapping the left border of the viewer (peach accent background with a double-square icon).

### 6. Right-Side Utility Toolbar
- **Positioning:** Docked vertically on the far right edge of the interface.
- **Background:** Darker grey panel (`#2B3036`).
- **Icon Set (Top to Bottom):**
  - Menu / Hamburger icon
  - Search icon (`⚲`)
  - List / Details icon
  - Network / Nodes icon (`☊`)
  - User profile icon (`Ω`)
- **Interactive State:** Clean minimalist icons in soft white/grey with subtle hover states.
