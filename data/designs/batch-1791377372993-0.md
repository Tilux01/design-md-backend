# Design Specification: Studio 9 Design (Mobile UI/UX Clone)

This document provides the exact design specifications, layout structures, typography, color codes, and functional states required to build a pixel-perfect, responsive mobile clone of the **Studio 9 Design** web pages shown in the media.

---

## 1. Global Styles & Typography

### Fonts
*   **Primary Font (Headings & UI):** Inter (Fallback: `sans-serif`)
*   **Secondary Font (Body Text & Descriptions):** Inter / Roboto (Fallback: `sans-serif`)
*   **Font Weights Used:** 
    *   Regular (`400`) - Body copy, input fields, footer text
    *   Medium (`500`) - Navigation links, buttons, form labels
    *   Bold / Semibold (`600`, `700`) - Section headings, major titles, brand logo

### Colors
*   **Background (Light):** `#FFFFFF` (Pure White)
*   **Text Primary (Dark):** `#000000` or `#111111` (Near Black)
*   **Text Muted / Secondary:** `#666666` to `#888888` (Medium Gray)
*   **Borders & Dividers:** `#E0E0E0` to `#CCCCCC` (Light Gray)
*   **Input Fields Background:** `#FAFAFA` with subtle borders (`#E0E0E0`)

## 3. Interaction & Animation Specifications

1.  **Mobile Menu Transition:**
    *   Sliding drawer animation from right-to-left or smooth opacity fade-in for the full-screen menu overlay (`0.3s ease-in-out`).
2.  **Accordion & Navigation Dropdowns:**
    *   Smooth height expansion when clicking categories like `Collection` to reveal nested items (`Furniture`, `Lighting`).
3.  **Form Inputs & Buttons:**
    *   Subtle hover/active state inversion (e.g., black background buttons turning slightly lighter gray or reversing to white with a black border on active states).
4.  **Smooth Scrolling:**
    *   `scroll-behavior: smooth;` enabled globally for anchor links and page navigation.
