# Web-Design Studio Landing Page - Specification

## 1. Global Styles & Reset
- **Viewport:** Fullscreen (100vw, 100vh), centered content container or full viewport layout.
- **Color Palette:**
  - Primary Yellow (Background): `#e5d13b` (or similar vibrant muted yellow `hsl(52, 75%, 56%)`)
  - Deep Black (UI, text, and 3D banana): `#1c1c1c` / `#0f0f0f`
- **Typography:**
  - Font Family: Modern sans-serif (e.g., 'Inter', 'Poppins', or system sans-serif).
  - Main Heading ("Web-Design Studio"): Bold, medium size, centered at top.
  - Vertical Text ("BANANA"): Uppercase, stacked vertically, bold.

---

## 2. Layout Structure & Components

### A. Header / Navigation
- **Top Left:**
  - Hamburger menu icon (3 horizontal lines).
- **Top Center:**
  - Logo/Brand Text: `"Web-Design Studio"`
- **Top Right:**
  - Menu / Filter icon (3 horizontal lines with downward sorting arrow).

### B. Left Sidebar
- **Vertical Text:**
  - Spelling `"BANANA"` vertically down the left margin:
    ```
    B A
    A N
    N A
    Z Z *(Note: graphic artistic spelling reads B-A-N-A-N-A)*
    ```
- **Bottom Left:**
  - Social / Portfolio link icon (Behance logo "Be" + small icon).

### C. Centerpiece (Hero Graphic)
- **Central 3D Artwork:**
  - A realistically rendered **black banana** coated in a glossy, viscous black liquid (resembling melted chocolate, tar, or glossy paint) dripping onto a flat surface at the base.
  - Realistic shadows and specular highlights on the glossy black surfaces.

### D. Footer / Bottom Navigation
- **Center Bottom:**
  - Mouse scroll icon (vertical capsule with a scrolling dot).
  - Text label: `"VIEW PORTFOLIO"` in uppercase, tracked-out small font.
- **Bottom Right:**
  - Minimalist banana graphic outline or icon pointing right.

### E. Right Sidebar (Pagination / Indicators)
- **Vertical dot navigation indicator:**
  - Active state: Top indicator is a short horizontal line (`—`).
  - Inactive states: 3 circular dots below (`•`, `•`, `•`).

---

## 3. Responsive & Behavior Notes
- **Background:** The underlying presentation shows a diagonal split or dark container shadow, but for the actual webpage implementation, use a flat `#e5d13b` background filling the entire screen.
- **Interactions:** Hover states on menu items, smooth scroll indicator animation, and interactive pagination dots on the right.
