# Design Specification: Coverd™ Hero Landing Page

---

## 1. Overview & Aesthetic Direction

A bespoke, minimalist, high-end Insurtech/Fintech landing page hero. The composition marries physical-digital surrealism (soft-diffuse 3D sculptural elements) with contemporary editorial typography (high-contrast modern serif paired with a technical geometric sans-serif).

* **Canvas Setup:** Full-screen viewport (`100vw` × `100vh`), borderless, edge-to-edge layout without browser bezels, outer mockup framing, or shadow drops.
* **Mood:** Calm, avant-garde, authoritative, institutional yet design-forward.

## 4. Visual & 3D Artwork Composition

The entire background is a cohesive architectural studio 3D scene split along a sharp diagonal line from top-right to bottom-left.

```
+----------------------------------------------------------------------+
| [Logo] Coverd™                                  See solutions  [CTA] |
|                                                                      |
|    \--- Wall: Deep Cobalt Blue Room Corner ---/                      |
|                                                                      |
|      (Protruding Tube                                                |
|       + Speckled Egg)                                                |
|                   `\                                                 |
|                     `\  Eyebrow: Insurance for every business        |
|                       `\                                             |
|                         `\   We specialise in                        |
|                           `\ the unexpected.                         |
|                             `\                                       |
|       (Concentric Disc        `\                                     |
|        Embedded in Floor)       `\         Scroll to explore (v)     |
|                                   `\                                 |
|                                     `\--- Floor: Muted Sage ---      |
| Tw In Fb                                                         :   |
+----------------------------------------------------------------------+
```

### 1. Scene Geometry & Lighting
* **Plane Split:** A crisp, razor-sharp architectural boundary cutting diagonally from approximately `(X: 68%, Y: 0%)` at the top down to `(X: 0%, Y: 72%)` on the left.
  * **Top/Left Region:** Vertical studio wall finished in matte deep cobalt blue (`#16327A`), darkening towards the far left edge (`#0E1E4F`).
  * **Bottom/Right Region:** Flat floor plane rendered in soft, powdery sage-mint green (`#A2B7AE`), illuminated by diffuse overhead-left studio light.
* **Shadow Dynamics:** Soft contact ambient occlusion shadows beneath objects; no harsh directional sun rays.

### 2. Protruding Wall Socket & Speckled Egg (3D Element 1)
* **Placement:** Positioned on the left vertical blue wall at `top: 36%`, `left: 16%` (relative to canvas width).
* **Base Cylinder:**
  * Protrudes horizontally directly toward the viewer / slightly toward the right.
  * Material: Matte cobalt blue matching the wall tone.
  * Lip/Rim: Thin, polished champagne brass/gold metallic collar (`#CFB28A`) encircling the opening.
* **Protruding Sphere/Egg:**
  * Shape: Matte ceramic, ovoid/egg-shaped capsule emerging outward from the cylinder.
  * Color: Off-white / pale ivory (`#EDF0EE`).
  * Surface Texture: Organic, sparse speckled flecks in dark cobalt blue (terrazzo / bird egg appearance).
  * Shading: Ambient shadow on the underside, soft highlight on the upper crest.

### 3. Concentric Recessed Floor Target (3D Element 2)
* **Placement:** Embedded flush into the sage green floor plane, centered horizontally at `left: 45%`, vertically at `top: 67%`.
* **Geometry:** Elliptical perspective disc laying flat on the plane, tilted along the camera’s perspective angle.
* **Concentric Layers (Outside In):**
  1. **Outer Ring:** Flat off-white/ivory ceramic ring (`#EDF0EE`).
  2. **Middle Ring:** Muted slate-sage ring (`#7A9589`), slightly recessed.
  3. **Core Dome:** Glossy, convex polished cabochon/dome in deep plum-violet obsidian (`#3B2C3E`), catching a subtle curved light reflection along its top edge.

## 6. Implementation Notes & Asset Strategy

1. **Background Layering Strategy:**
   * **Base Layer (`z-index: 1`):** A single full-bleed high-resolution rendered asset (`2560×1440` or `3840×2160` WebP format) containing the 3D diagonal split, shadows, protruding cylinder egg, and floor disc.
   * **Foreground UI Layer (`z-index: 10`):** Fixed/absolute HTML DOM nodes for all typography, buttons, social links, pagination, and navigation to preserve crisp text rendering and accessibility.
2. **Interactive States:**
   * CTA button has a micro-scale transition (`scale: 1.03`, duration `200ms`, `ease-out`).
   * "Scroll to explore" chevron initiates a gentle vertical bounce animation (`translateY(0)` to `translateY(4px)` infinite `ease-in-out`).
3. **Responsive Adaptation:**
   * On tablet (`< 1024px`): Reduce H1 font-size to `48px`; reposition text block higher.
   * On mobile (`< 768px`): Stack navigation into a compact bar; scale H1 down to `36px`; floor disc scales down by `30%` or repositions to avoid clipping text.
