# UI/UX Design Specification: Dark Mode Financial/Dashboard App

## 1. Global Layout & Viewport Strategy
* **Target Viewport:** Full-screen mobile layout (fluid width `100vw`, minimum height `100vh`).
* **Frame Removal:** Omit all device frames, mockups, shadows behind the device, and outer gradients. Render only the internal application screens edge-to-edge.
* **Layout Structure:** Since two screens are displayed side-by-side in the reference image (representing a dashboard view and an analytics/charts view), this specification details the primary **Dashboard View** (left) with its corresponding sub-elements.

---

## 2. Color Palette & Theming

### Backgrounds
* **Primary App Background (`--bg-main`):** `#070b19` (Deep obsidian navy with a rich royal blue undertone).
* **Card/Container Background (`--bg-card`):** `#0f172a` (Translucent slate blue, typically implemented with `background: rgba(15, 23, 42, 0.75)` and `backdrop-filter: blur(12px)`).
* **Interactive Button Background (`--bg-button`):** `#1e293b`.

### Text & Typography Colors
* **Primary Text (`--text-primary`):** `#ffffff` (Pure white for main values and headers).
* **Secondary Text (`--text-secondary`):** `#94a3b8` (Cool muted grey for labels and sub-descriptors).
* **Positive Indicator (`--accent-green`):** `#10b981` (Emerald green used for positive metrics/gains).
* **Negative Indicator (`--accent-red`):** `#ef4444` (Soft red used for negative adjustments).

### Accents & Gradients
* **Primary Brand Glow / Buttons (`--accent-blue`):** `#3b82f6` to `#2563eb` (Vibrant electric blue).
* **Glow/Ambient Lighting:** Subtle radial gradients of `#1d4ed8` positioned at the top-left and bottom-right corners behind containers to create depth.

## 4. Component-by-Component Breakdown

### A. Status Bar & Header
* **Status Bar:** Standard iOS/Android status icons (Wi-Fi, Battery, 5G, Current Time: `9:41`) rendered in pure white (`#ffffff`), size `12px`.
* **Top Navigation:** 
  * Left: User profile avatar/icon (circular, dark metallic gradient).
  * Center/Right: Notification bell icon and settings/menu icon, spaced evenly with `16px` padding from screen edges.

### B. Main Balance Card (Hero Section)
* **Container:** Full-width rounded card (`border-radius: 20px`), dark translucent gradient background with a subtle 1px border (`rgba(255, 255, 255, 0.08)`).
* **Content:**
  * **Label:** "Total Balance" in `--text-secondary`, uppercase or sentence case, `12px`.
  * **Value:** `$32,797.00` in `--text-primary`, `32px`, bold.
* **Action Grid (Quick Buttons):**
  * 4 horizontal action buttons (e.g., Send, Receive, Swap, Analytics) inside the card.
  * *Icon:* Minimalist line icons (white, `18px`).
  * *Label:* `10px` text underneath each icon (`--text-secondary`).

### C. List Items / Transaction / Asset Rows
* **Structure:** Stacked rows inside a rounded container card.
* **Layout per Row:**
  * **Left:** Circular icon or token logo (`36px` diameter) with a soft colored backdrop.
  * **Center:** Primary title (e.g., asset name or transaction type) in `14px` bold white; subtitle (e.g., date or quantity) in `12px` muted grey.
  * **Right:** Monetary value in `14px` white; percentage change or status underneath in `12px` green (`#10b981`) or red (`#ef4444`).
* **Dividers:** Thin, subtle dividing lines (`1px` height, `rgba(255, 255, 255, 0.04)`) between rows.

### D. Bottom Navigation Bar
* **Position:** Fixed at the bottom (`position: fixed; bottom: 0;`).
* **Background:** Solid or blurred dark backing (`#070b19` with top border line).
* **Items:** 4-5 evenly distributed navigation icons (Home, Analytics, Wallet, Settings) with active states highlighted in `--accent-blue`.

---

## 5. Image Assets & Treatment Specification

If implementing raster or vector graphics (such as token logos, graphs, or avatar icons):
* **Format:** SVG preferred for icons; high-resolution WebP/PNG for complex charts or illustrations.
* **Background Status:** All images and icons must be **backgroundless (transparent)** so they blend seamlessly into the dark `#070b19` / `#0f172a` surfaces.
* **Placement & Rotation:** 
  * Icons and currency symbols must be strictly unrotated (`0deg`), vertically centered relative to their text labels.
  * Ambient background lighting gradients should be layered at `z-index: 0` with zero rotation, positioned absolutely at coordinates `top: -10%` and `left: -20%`.
