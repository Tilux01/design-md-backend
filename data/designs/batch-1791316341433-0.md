# Comprehensive Design Specification & Frontend Blueprint

---

## 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Brand Archetype**: Luxurious, sophisticated, contemporary editorial interior design studio / boutique furniture showcase. High-end minimal editorial meets dark-mode digital gallery.
- **Visual Density**: Clean, airy, premium spacing. Intentional breathing room prioritizing high-resolution imagery and sophisticated typography.
- **Theme Balance**: Dark mode dominant (`#0B0B0B` root background) paired with warm neutral photography and subtle amber-toned lighting highlights.
- **Whitespace Balance**: Generous vertical and horizontal whitespace (`clamp(2rem, 5vw, 6rem)` container padding) balancing massive photographic grids with sleek, ultra-clean navigation headers.

---

## 3. Typography System & Hierarchy

- **Font Families**: 
  - Headings & Editorial Labels: `Playfair Display`, `Didot`, `Georgia`, serif
  - Body & Navigation: `Inter`, `-apple-system`, `sans-serif`
  - Monospace / Micro-badges: `JetBrains Mono`, `Courier New`, monospace

### Scale Breakdown
- **Display Hero (`h1`)**: 3.5rem / 56px (Desktop), font-weight: 400, line-height: 1.1, tracking: -0.02em
- **Section Heading (`h2`)**: 2.25rem / 36px, font-weight: 400, line-height: 1.2, tracking: -0.01em
- **Card Subheading (`h3`)**: 1.25rem / 20px, font-weight: 500, line-height: 1.4, tracking: normal
- **Body Copy**: 1rem / 16px, font-weight: 300, line-height: 1.6, tracking: 0.01em
- **Micro-Badge / Pill Label**: 0.75rem / 12px, font-weight: 600, line-height: 1, tracking: 0.15em (uppercase)

## 4. Layout Architecture & Spatial Grid

- **Container Max-Width**: `1440px` centered with fluid horizontal padding (`clamp(1.5rem, 4vw, 4rem)`).
- **Grid Structure**: 12-column CSS Grid with responsive gap scaling (`gap-4 md:gap-8`).
- **Section Sequence**:
  1. Fixed Header / Navigation Bar (`backdrop-blur-md`, border-bottom)
  2. Hero Cinematic Image/Text Banner with high-end editorial imagery
  3. Asymmetrical Multi-Column Image Grid (Displaying architectural details, furniture craftsmanship, and interior spaces)
  4. Feature Detail Box (Typographic breakdown with left border accent)
- **Z-Index Stack**:
  - Base Content: `z-0`
  - Floating Cards / Modals: `z-40`
  - Sticky Header / Navigation: `z-50`
  - Toast / Notifications: `z-60`

## 8. Accessibility (a11y) & WCAG Contrast Audit

- **Color Contrast Ratios**:
  - Primary text (`#FFFFFF`) on Obsidian background (`#0B0B0B`) exceeds **18:1** (Passes WCAG AAA).
  - Muted text (`#9CA3AF`) on Obsidian background (`#0B0B0B`) exceeds **4.8:1** (Passes WCAG AA).
  - Accent Gold (`#D4AF37`) used on dark surfaces meets large-text contrast minimums; supplemented with bold weights for standard sizing.
- **Keyboard Focus Ring Specification**:
  ```css
  :focus-visible {
    outline: 2px solid #D4AF37;
    outline-offset: 4px;
    border-radius: 4px;
  }
  ```
- **Semantic HTML**: Extensive use of `<header>`, `<nav>`, `<main>`, `<section>`, and `<article>` tags to ensure complete screen reader compatibility and correct document outlining.
