# 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Brand Archetype**: Premium, sustainable, calm, organic, and modern e-commerce. The brand ("Leafora") conveys trust, wellness, and botanical curation.
- **Visual Density**: Balanced; high breathing room (whitespace/negative space) paired with dense, glassmorphic data cards to maximize content readability without feeling cluttered.
- **Theme Architecture**: Exclusive Dark Mode design system. Features layered depth using semi-transparent frosted glass containers (`backdrop-filter: blur`), dark forest green monochromatic foundations, and soft emissive highlights.

# 4. Layout Architecture & Spatial Grid

- **Container Max-Width**: Fluid mobile viewport wrappers (`max-width: 430px` standard mobile frame simulation).
- **Spacing Scale**: Base unit `4px`. Common tokens: `p-3` (12px), `p-4` (16px), `p-6` (24px), `gap-3` (12px), `gap-4` (16px).
- **Section Sequence (Home Screen)**:
  1. Top Navigation Bar (Logo/Brand + Cart Badge)
  2. Hero Banner Card (Botanical photo background, transparent card container, Value Proposition text, CTA)
  3. Category Icon Row (All Plants, Indoor, Outdoor, Low Light, Pet Friendly)
  4. Section Header: "Best Sellers" + "View All" link
  5. Horizontal Product Card Grid (Snake Plant, ZZ Plant, Pothos)
  6. Bottom Navigation Bar (Home, Plants, Care, Wishlist, Profile)
- **Z-Index Hierarchy**:
  - Base Background: `z-0`
  - Cards & Content: `z-10`
  - Sticky/Fixed Navigation: `z-40`
  - Modals & Overlays: `z-50`

# 7. Accessibility (a11y) & WCAG Contrast Audit

- **Contrast Ratios**:
  - Primary white text (`#FFFFFF`) on deep dark green backgrounds (`#0B1B14`): **16.4:1** (Passes WCAG AAA)
  - Secondary text (`#A3B3AB`) on background (`#142F24`): **5.8:1** (Passes WCAG AA)
  - Accent text (`#C5D8B4`) on card surface (`#1B3B2E`): **7.1:1** (Passes WCAG AAA)
- **Keyboard Focus Ring Specifications**:
  - Interactive elements must display a distinct dual-layer focus outline:
  ```css
  :focus-visible {
    outline: 2px solid #C5D8B4;
    outline-offset: 2px;
    box-shadow: 0 0 0 4px rgba(197, 216, 180, 0.3);
  }
  ```
