# Design Specification: Tesla Cybertruck Full-Screen Clone

This specification provides a complete blueprint to build an exact, pixel-perfect, full-screen clone of the provided Tesla Cybertruck promotional interface.

---

## 1. Global Layout & Viewport Configuration

*   **View Mode:** Full-Screen (`width: 100vw`, `height: 100vh`, `overflow: hidden`).
*   **Color Palette:**
    *   **Primary Background:** Deep atmospheric night/space blue-black gradient (`#050811` to `#0d1322`).
    *   **Text/Icons Primary:** Pure White (`#FFFFFF`).
    *   **Text Secondary (Muted):** Cool Grey (`#8E94A0`).
    *   **Accent/Glow:** Soft ambient moonlight blue (`#6B8CAE`).
*   **Grid System:** Absolute positioning with responsive flexbox wrappers to ensure all elements lock into precise percentages relative to the viewport.

---

## 2. Typography Strategy

### Primary Font Stack
*   **Font Family:** `Syncopate`, `Montserrat`, `Helvetica Neue`, `Arial`, `sans-serif`
*   **Fallbacks:** If `Syncopate` or `Montserrat` cannot be loaded from Google Fonts, the system falls back to `Helvetica Neue` with wide letter-spacing (`letter-spacing: 0.15em`) to mimic the futuristic branding style.

## 3. Component Breakdown & Placement

### A. Top Navigation Bar
*   **Position:** `top: 24px`, spanning full width with `padding: 0 32px`.
*   **Left Element:**
    *   Hamburger menu icon (two horizontal lines) + text **"MENU"**.
    *   Spacing: `12px` gap between icon and text.
*   **Center Element:**
    *   Brand logo text: **"TESLA"** centered perfectly (`transform: translateX(-50%)` relative to container center).
*   **Right Element:**
    *   Three circular utility icons (Globe/Language selector, User profile icon, Settings/Control icon) aligned horizontally with a `16px` gap. Each icon circle has a subtle translucent dark background (`rgba(255, 255, 255, 0.1)`).

### B. Left Vertical Icon Sidebar
*   **Position:** `left: 32px`, vertically centered (`top: 50%`, `transform: translateY(-50%)`).
*   **Content:** A vertical stack of 3 minimalist square control/camera angle icons with rounded corners (`border-radius: 4px`) and a thin border (`1px solid rgba(255, 255, 255, 0.2)`).
*   **Active State:** The middle icon features a brighter highlight border and an active beam effect projecting outward to the right toward the vehicle.

### C. Center Hero Section
*   **Background Environment (Image 1):**
    *   **Description:** A dark, moody, cinematic night landscape featuring turbulent, dramatic storm clouds over a dark, rocky terrain and misty reflective ground.
    *   **Properties:** Backgroundless layer blended with the base color, positioned to cover the entire viewport (`background-size: cover`, `background-position: center`).
*   **Vehicle Placement (Image 2 - Cybertruck):**
    *   **Description:** A sleek, matte-black and stainless steel geometric Cybertruck viewed from a three-quarter front angle, casting realistic ground reflections. Headlights emit a sharp, horizontal volumetric beam directed toward the left edge of the screen.
    *   **Placement:** Centered horizontally and vertically (`top: 52%`, `left: 50%`, `transform: translate(-50%, -50%)`).
    *   **Rotation:** Flat horizontal plane with zero tilt, perfectly leveled to match the horizon line.
*   **Typography Overlay:**
    *   Placed directly above the vehicle:
        1. Subtitle: *"THE POWER OF INNOVATION"*
        2. Main Title: *"CYBERTRUCK"* with wide tracking.

### D. Bottom Interface Elements

*   **Bottom-Left Metric Box:**
    *   **Position:** `bottom: 32px`, `left: 32px`.
    *   **Layout:** Horizontal alignment. Large bold **"30X"** followed immediately to the right by stacked dual-line text: *"ULTRA-HARD"* / *"STAINLESS STEEL"*.

*   **Bottom-Center Call-To-Action (CTA):**
    *   **Position:** `bottom: 32px`, centered horizontally (`left: 50%`, `transform: translateX(-50%)`).
    *   **Layout:** Vertical stack. A stylized upward-pointing triangle/chevron icon (`△`) positioned directly above the tracking text: *"SEE THE CYBERTRUCK IN ACTION"*.

*   **Bottom-Right Tagline:**
    *   **Position:** `bottom: 32px`, `right: 32px`.
    *   **Layout:** Right-aligned multi-line text block:
        ```text
        UNBREAKABLE.
        UNSTOPPABLE.
        UNRIVALED.
        ```
        *(Note: Strict right alignment (`text-align: right`), with clean dot separators or line breaks matching the exact copy layout).*
