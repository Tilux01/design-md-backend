# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Dark Mode Glassmorphism & Developer Intelligence SaaS (High-end AI Workflow Dashboard).
- **Visual Density & Whitespace Ratio**: High visual density paired with soft glassmorphic depth layers (`backdrop-blur-md`), precise 8pt scaling, and glowing ambient gradients that isolate distinct capability cards.
- **Surface Elevation Model**: Layered depth architecture using translucent surfaces (`rgba(15, 23, 42, 0.7)`), subtle 1px internal borders (`rgba(255, 255, 255, 0.08)`), drop shadows (`0 8px 32px rgba(0, 0, 0, 0.4)`), and ambient radial glowing backdrops.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Ambient radial gradients behind interactive modules, code snippet mockups with syntax highlighting, glowing floating lock/bot/search orbs, glassmorphic border rings.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `12px`, font-weight `600`, tracking `0.05em`, border-radius `9999px`, background translucency `rgba(59, 130, 246, 0.1)`, border width `1px` (`rgba(59, 130, 246, 0.3)`).
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;`
  - Sparkle / Star (✦) -> Use `&#10022;`
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-blue-400 inline-block"></span>`
