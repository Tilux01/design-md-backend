# Design Specification: ArgusVPN Landing Page Clone

This document provides a comprehensive blueprint for recreating the ArgusVPN landing page. It outlines the exact layout, color palette, typography, interactive elements, and visual assets required for a pixel-perfect, full-screen clone.

---

## 1. Global Layout & Structure

*   **View:** Full-screen viewport (`100vw`, `100vh`), non-scrollable on desktop landing view.
*   **Background:** Deep radial gradient centered on the upper-middle portion of the screen.
    *   *Primary Color (Center/Glow):* Deep electric blue (`#0a15ff` or similar deep saturated blue) transitioning into absolute black (`#03050a` or `#000000`) towards the bottom and outer edges.
*   **Z-Index Layering:**
    1.  **Layer 0 (Background):** Solid dark base with radial gradient.
    2.  **Layer 1 (Visual Imagery):** Glowing abstract ring/eclipse graphic positioned centrally behind the brand typography.
    3.  **Layer 2 (Typography & Content):** Header navigation, main "ARGUS" title, subtitle, CTA buttons, and guarantee text.

---

## 3. Typography & Fonts

### Primary Font Family
*   **Family:** Futuristic geometric sans-serif (similar to *Syncopate*, *Rajdhani*, *Orbitron*, or *Eurostile*).
*   **Fallback Stack:** `font-family: 'Syncopate', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;`

### Text Styles & Hierarchy

1.  **Top Navigation Links:**
    *   Font Size: `13px` / `0.8125rem`
    *   Font Weight: `400` (Regular)
    *   Color: `#A3A7B5` (Hover: `#FFFFFF`)
2.  **Main Heading ("ARGUS"):**
    *   Font Size: `clamp(4rem, 9vw, 9rem)` (Responsive large display)
    *   Letter Spacing: Wide tracking (`0.3em` to `0.4em`)
    *   Font Weight: `700` (Bold)
    *   Color: `#FFFFFF`
3.  **Subtitle ("VPN THAT SIMPLY WORKS"):**
    *   Font Size: `clamp(1.2rem, 2vw, 1.8rem)`
    *   Letter Spacing: `0.15em`
    *   Font Weight: `600` (Semi-bold)
    *   Color: `#FFFFFF`
4.  **CTA Button Text:**
    *   Font Size: `14px`
    *   Font Weight: `600`
    *   Color: `#0B0F19`
5.  **Guarantee Text:**
    *   Font Size: `12px`
    *   Font Weight: `400`
    *   Color: `#8C90A0`

## 4. Component Breakdown

### A. Header / Top Navigation Bar
*   **Layout:** Fixed or absolute positioning at the top, centered horizontally with automatic max-width margins.
*   **Container Style:** Contained within a semi-transparent floating pill (`border-radius: 9999px`), frosted glass effect (`backdrop-filter: blur(12px)`), with a very thin dark border (`1px solid rgba(255, 255, 255, 0.1)`).
*   **Left Element:** Logo consisting of the bold text **ARGUSVPN** in a futuristic sans-serif font, accompanied by a small abstract geometric brand icon to the left.
*   **Center Links:** Horizontal flex row with generous spacing (`gap: 32px`):
    *   `Why ArgusVpn?`
    *   `Cost`
    *   `Support`
    *   `Become a partner`
    *   `Blog`
*   **Right Elements:**
    *   Language Selector: `EN` with a subtle dropdown chevron, enclosed in a small pill badge.
    *   `Login` text link.
    *   Primary CTA Button: Pill-shaped (`border-radius: 50px`), solid white background, dark text reading `Instal ArgusVPN`.

---

### B. Hero Visual Asset (Background Graphic)
*   **Description:** A high-resolution, backgroundless PNG/SVG composite graphic representing a cosmic eclipse or glowing neon portal.
    *   **Core Element:** A massive, glowing bright-white circular ring tilted on a 3D perspective plane.
    *   **Lighting Effects:** Intense lens flare/bloom effect on the top-right curve of the ring where it intersects the top banner, casting an electric blue and violet atmospheric haze across the upper canvas.
    *   **Secondary Details:** Inner concentric glowing blue arcs and subtle orbital lines passing behind the main typography.
*   **Placement & Rotation:**
    *   Centered horizontally (`left: 50%`, `transform: translateX(-50%)`).
    *   Positioned vertically overlapping the navigation bar and sitting directly behind the word "ARGUS".
    *   Rotated slightly along the Z-axis to create a dynamic, modern sci-fi aesthetic.
*   **Layering Note:** Must be positioned strictly *behind* the "ARGUS" typography layer so the letters cut through or overlay the cosmic ring seamlessly.

---

### C. Main Hero Content ("ARGUS")
*   **Layout:** Absolute or flex-centered positioning in the middle viewport.
*   **Typography:** The word **ARGUS** is spaced widely across the horizontal axis.
*   **Visual Integration:** The glowing cosmic ring passes directly through the letters (specifically weaving behind the 'R', 'G', and 'U').

---

### D. Value Proposition & Call-to-Action (Lower Center)
*   **Layout:** Flex column centered vertically below the main "ARGUS" title (`margin-top: 4vh`).
*   **Heading:**
    *   Text: `VPN THAT SIMPLY WORKS`
    *   Alignment: Centered.
    *   Transform: Uppercase.
*   **Primary CTA Button:**
    *   Shape: Fully rounded pill (`border-radius: 9999px`).
    *   Padding: `14px 36px`.
    *   Background: Solid pure white (`#FFFFFF`).
    *   Text: `Instal ArgusVPN` (Note: Retain original spelling "Instal" as shown in source).
    *   Shadow: Soft white ambient glow/drop shadow (`box-shadow: 0 0 30px rgba(255, 255, 255, 0.2)`).
    *   Interactive State: Slight scale-up (`scale(1.03)`) and intensified glow on hover.
*   **Micro-Copy:**
    *   Text: `30-days money back guarantee`
    *   Placement: Directly beneath the CTA button with a `12px` top margin.
    *   Styling: Muted gray, clean, trustworthy appearance.
