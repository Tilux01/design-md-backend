# UI Design & Implementation Specification: "The World of Plants" Landing Page

This document provides a comprehensive, pixel-level specification for replicating the "The World of Plants" landing page. It is structured to guide a frontend developer in building an exact, responsive, and interactive clone while translating the mockup from a framed card into a full-screen web application.

---

## 1. Global Layout & Structural Overview

* **Canvas Expansion:** The original design is presented within a rounded card frame on a light-grey backdrop (`#F3F5F5`). For production, this frame is **removed**, expanding the layout to **100% width and 100% height (Full-Screen Viewport)**.
* **Background Gradient/Color:** The core background is a soft, muted sage/mint tint (`#E8ECEB` to `#E0E6E5`).
* **Container Width:** Content uses a centered maximum container width of **1280px** with a fluid horizontal padding of **60px** on desktop screens.
* **Border Radius / Elevation:** While the outer container frame is dropped, inner card components retain their soft, neumorphic/shadow-based cards (`background: #FFFFFF`, `border-radius: 20px`, `box-shadow: 0 12px 32px rgba(0, 0, 0, 0.04)`).

---

## 2. Typography & Font Stack

The interface relies on a clean, geometric sans-serif aesthetic.

* **Primary Font Family:** `Inter`, `Plus Jakarta Sans`, or `Poppins`, falling back to `system-ui`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `Helvetica Neue`, `Arial`, `sans-serif`.
* **Font Weights Used:**
  * Regular (`400`): Body copy, navigation links.
  * Medium (`500`): Subheadings, small labels, card titles.
  * Semi-Bold (`600`): Section headers, buttons.
  * Bold (`700`): Hero headline.

## 4. Component-by-Component Breakdown

### A. Navigation Bar (`<header>` / `<nav>`)
* **Layout:** Flexbox, space-between alignment. Sticky or fixed at the top (`backdrop-filter: blur(8px)`).
* **Left Links:** `Home`, `Plant finder`, `Products`, `About us`, `Contact`, `My plants`.
  * Gap between links: `32px`.
  * Hover state: Text shifts from `#2D3748` to `#386641` with a smooth `0.2s ease` transition.
* **Right Icons:** User Account icon (outline profile silhouette) and Cart icon (shopping bag/cart).
  * Gap between icons: `20px`.
  * Icon size: `20px × 20px`, stroke width `1.5px`.

---

### B. Hero Section (`<section class="hero">`)
* **Layout:** Asymmetrical two-column grid.
  * **Left Column:** Overflowing oversized plant image (Snake Plant / *Dracaena Trifasciata*) breaking out of its container boundaries.
  * **Right Column:** Text block (`Go green.`, `The world of plants`, descriptive paragraph).
* **Hero Text Block Positioning:**
  * Width: ~40% of the screen width.
  * Margin-top: `40px` from the navigation bar.

---

### C. Featured Plant Showcase Card (Left Foreground)
* **Visual Structure:** A large vertical white card anchored on the left side, overlapping the hero section.
* **Dimensions:** Width `320px`, Height `420px`.
* **Content Stack:**
  1. **Image:** Potted Sansevieria plant protruding past the top boundary of the white card (giving a 3D layered/pop-out effect).
  2. **Title:** "Dracaena Trifasciata" (Bold, 24px).
  3. **Description:** "One of the most effective houseplants in air purification." (Regular, 13px).
  4. **Action Link:** "Know more →" in dark bold text with an animated right arrow icon (`#386641`).

---

### D. Carousel / Grid Section ("Top 5 of the week")
* **Section Heading:** Small tracking text: `Top 5 of the week`.
* **Layout:** Horizontal flex row or CSS Grid displaying 4 visible cards in a row.
* **Card Specifications:**
  * Background: `#FFFFFF`
  * Border Radius: `16px`
  * Padding: `16px` (image centered on top, text label at the bottom).
  * Size: Fixed width ~160px, height ~220px per card.
* **Items Displayed:**
  1. *Crassula Ovata* (Jade Plant)
  2. *Haworthiopsis Attenuata* (Zebra Plant)
  3. *Browningia Hertlingiana* (Blue Torch Cactus)
  4. *Chlorophytum Comosum* (Spider Plant)

## 5. Animations & Interactive States

To match a modern high-end UX design, implement the following micro-interactions using CSS transitions and JavaScript where necessary:

1. **Link Hovers:**
   ```css
   nav a {
     transition: color 0.2s ease-in-out;
   }
   nav a:hover {
     color: #386641;
   }
   ```
2. **Card Hover Lift:**
   ```css
   .plant-card {
     transition: transform 0.3s cubic-bezier(0.16, 1, 0.3, 1), box-shadow 0.3s ease;
   }
   .plant-card:hover {
     transform: translateY(-6px);
     box-shadow: 0 20px 40px rgba(45, 55, 72, 0.08);
   }
   ```
3. **"Know more" Arrow Animation:**
   ```css
   .know-more-btn .arrow {
     transition: transform 0.2s ease;
   }
   .know-more-btn:hover .arrow {
     transform: translateX(4px);
   }
   ```
4. **Hero Plant Entry Animation (Scroll / Page Load):**
   * *Fade-in and slide-up* entrance using `keyframes`:
     ```css
     @keyframes fadeInUp {
       from {
         opacity: 0;
         transform: translateY(20px);
       }
       to {
         opacity: 1;
         transform: translateY(0);
       }
     }
     .hero-content {
       animation: fadeInUp 0.8s cubic-bezier(0.16, 1, 0.3, 1) forwards;
     }
     ```

## 6. Responsive Breakpoints

* **Desktop (1200px and up):** Full 4-card carousel/grid displayed simultaneously alongside the main featured plant card.
* **Tablet (768px – 1199px):**
  * Hero section collapses to a single column (text stacked above/below the image).
  * Bottom carousel cards become horizontally scrollable (`overflow-x: auto; scroll-snap-type: x mandatory;`).
* **Mobile (Below 768px):**
  * Navigation links collapse into a hamburger menu.
  * Hero title font size scales down from `56px` to `36px`.
  * Featured plant card stacks vertically above the carousel items with full-width scaling.
