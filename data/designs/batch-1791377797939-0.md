# Comprehensive UI/UX Design Specification & Implementation Blueprint

---

## 1. Global Layout & Multi-State Architecture

This document details a full-screen, responsive, carousel-based e-commerce design featuring a dark mode aesthetic (`#111111` background container) with three color-themed landing states: **Teal**, **Olive Green**, and **Amber/Orange**. 

### Viewport & Scaling
* **Target Viewport**: Full-width fluid layout (`width: 100vw`, `min-height: 100vh`).
* **Content Container**: Max-width constraint around `1280px` with fluid horizontal padding (`clamp(24px, 5vw, 80px)`).
* **Frame Removal**: Outer device/browser frames are excluded. The design renders edge-to-edge as a full-viewport web application or multi-slide presentation layout.

---

## 2. Design System Tokens & Color Palette

### Color System

| Token Name | Hex Code | Usage / Context |
| :--- | :--- | :--- |
| **Global Background** | `#111111` | Root presentation frame backdrop |
| **State 1: Teal Theme** | `#205664` | Primary gradient background for slide 01 |
| **State 2: Olive Theme** | `#6b7754` | Primary gradient background for slide 02 |
| **State 3: Amber Theme** | `#c27a2b` | Primary gradient background for slide 03 |
| **Primary Text** | `#FFFFFF` | Headings, brand logo, active navigation items |
| **Secondary Text** | `#E0E0E0` | Subtitles, body descriptions, inactive nav links |
| **Muted Accents** | `rgba(255, 255, 255, 0.4)` | Carousel indicators, disabled arrow controls |
| **CTA Background** | `rgba(255, 255, 255, 0.2)` | Glassmorphism pill button fills |
| **CTA Border** | `rgba(255, 255, 255, 0.3)` | Subtle outlining on interactive pills |

---

## 3. Typography Specifications

### Font Families
* **Primary Header & Body Font**: **Inter** (Google Fonts)
  * *Fallbacks*: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
* **Logo Monogram Font**: **Montserrat** or **Cinzel** (Geometric Serif/Sans treatment)
  * *Fallbacks*: `"Times New Roman", Times, serif`

### Typographic Scale

| **Background Numbering** | `clamp(120px, 18vw, 240px)` | `1.0` | Extra Bold (`800`) | `-0.05em` |

## 4. Component Breakdown & Spatial Layout

### A. Header Component (`<header>`)
* **Layout**: Flexbox, Space-Between (`justify-content: space-between`, `align-items: center`).
* **Padding**: `32px 0` (desktop).
* **Left Section (Brand)**:
  * Monogram Box: Square border/background container with lowercase/uppercase stylized italic or heavy block letters **"qF"**.
* **Center Section (Navigation Menu)**:
  * Items: `Home`, `NEW`, `Stylish interior` / `In the interior`, `Contact us`.
  * Spacing: `32px` gap between links. Hover state shifts text opacity to `1.0`.
* **Right Section (Actions)**:
  * `Log in` Button: Pill-shaped border-radius (`20px`), thin white border, transparent background, horizontal padding `16px`, vertical padding `6px`.
  * Search Icon: Standard SVG magnifying glass.
  * Hamburger Menu Icon: 3-line stack icon for mobile responsiveness.

---

### B. Hero Section (`<main class="hero-section">`)
* **Layout**: CSS Grid / 2-Column Flex (`minmax(0, 1fr)` for text content and product image).
* **Left Column (Content & Typography)**:
  * Title: `"Design furniture"`
  * Description: `"Choose from a wide range of well-crafted premim quality wooden furniture and home decor online"` (Note: Retain original typo *"premim"* if strict replication is required).
  * Call-to-Action: Pill button labeled `"Explore collection"` with subtle background tint and right-aligned arrow or clean centered text.
* **Right Column (Hero Product & Watermark)**:
  * **Background Watermark Numbering**: Giant stylized numbers (`01`, `02`, `03`) layered behind the chair graphic with reduced opacity (`opacity: 0.15`).
  * **Product Image**: High-resolution cutout of iconic designer chairs (e.g., Arne Jacobsen Egg Chair style, Eames plastic molded chair, modern upholstered lounge chair).
  * **Decorative Dots Pattern**: A grid/matrix of small circular dots positioned in the background canvas.

---

### C. Footer / Utility Bar (`<footer>`)
* **Layout**: Flexbox aligned to the bottom baseline.
* **Left Side**: Social media vector icons (Twitter/X, Instagram, VK).
* **Center**: Carousel pagination indicator (4 dots, active indicator rendered as a rounded capsule bar).
* **Right Side**: Navigation chevron arrows (`‹` `›`) for manual slide traversal.

---

## 5. Animation & Interaction Blueprint

### 1. Carousel Slide Transition
* **Trigger**: Clicking navigation arrows (`‹` `›`) or pagination dots.
* **Animation Property**: `transform: translateX()` combined with CSS opacity cross-fade.
* **Duration**: `600ms` cubic-bezier(0.25, 1, 0.5, 1).
* **State Shift**: Smooth interpolation of background gradient colors (`#205664` ➔ `#6b7754` ➔ `#c27a2b`).

### 2. Micro-Interactions
* **CTA Buttons**: Scale transform (`scale(1.03)`) and background opacification (`rgba(255,255,255,0.35)`) on `:hover`. Transition duration: `200ms ease`.
* **Navigation Links**: Underline expansion or text color transition from `rgba(255,255,255,0.7)` to `#FFFFFF` on hover.
* **Product Image Entrance**: Subtle floating parallax or slide-up entrance animation (`translateY(20px)` to `0`) triggered on active slide activation.
