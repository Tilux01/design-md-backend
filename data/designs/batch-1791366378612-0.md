# UI/UX Design Specification: Medical Healthcare Mobile Application

## 1. Global Styles & Design Tokens

### Color Palette
- **Backgrounds:**
  - App Background (Global canvas): `#F5F6F8` (Light gray-blue)
  - Screen Background 1 & 3: `#FFFFFF` (Pure white)
  - Screen Background 2 (Dark Theme): `#0C1829` (Deep navy blue)
- **Primary / Brand:**
  - Primary Dark: `#1B2B48` / `#0C1829`
  - Accent Blue: `#3B82F6` (Standard iOS Blue)
- **Cards & Surfaces:**
  - Dark Mode Card Background: `#16253B`
  - Light Mode Card Background: `#EBF1FA` (Soft blue-gray tint used for Health Overview)
  - Image Overlay Gradient: Linear gradient from `rgba(0,0,0,0)` to `rgba(0,0,0,0.6)` on featured category cards.
- **Text Colors:**
  - Headings (Light Screen): `#111827`
  - Subtext/Body (Light Screen): `#6B7280`
  - Headings (Dark Screen): `#FFFFFF`
  - Subtext (Dark Screen): `#9CA3AF`
- **Utility / Badges:**
  - Badge Background: `#D1E7DD` / `#E0F2FE`

### Typography (System Font: Inter / San Francisco)
- **Screen Titles / Greetings:** `20px` - `24px`, Bold (`700`)
- **Section Headers:** `16px` - `18px`, Semi-Bold (`600`)
- **Body / Labels:** `13px` - `14px`, Regular (`400`) / Medium (`500`)
- **Micro / Captions:** `11px` - `12px`, Regular (`400`)

### Corner Radii
- **App Frame:** `48px`
- **Large Cards (Appointment, Hero Banners):` `20px` - `24px`
- **Standard Cards / Quick Access Icons:** `16px`
- **Buttons & Pills:** `24px` (Full rounded)

---

## 2. Screen 1: Dashboard / Home (Light Theme)

### Layout Structure
- **Container:** White background, rounded corners (`48px`), top dynamic island cutout indicator.
- **Padding:** Horizontal `20px`, Vertical `24px`.

### Component Breakdown
1. **Top Header Bar:**
   - **Left:** User Avatar (Circular, ~`40px` diameter) with photo of a woman.
   - **Text Stack:** 
     - "Good Morning," (`12px`, `#6B7280`, Regular)
     - "Sara Wilson" (`18px`, `#111827`, Bold)
   - **Right:** Notification bell icon inside a circular container (`36x36px`, `#F3F4F6`).

2. **Next Appointment Card:**
   - **Background:** Dark navy gradient (`#132238` to `#1B2B48`), rounded `20px`.
   - **Content:**
     - Top Label: "Your Next Appointment" (`11px`, `#9CA3AF`)
     - Date/Time: **"08"** (`32px`, Bold, White), "May 2025, Thursday" (`12px`, `#D1D5DB`), "10:30 AM" (`12px`, `#D1D5DB`).
     - Graphic element: Stethoscope icon illustration positioned on the right side.

3. **Health Overview Section:**
   - **Header:** "Health Overview" (Left, `14px`, Bold), "This Week" dropdown with chevron on the right (`12px`, `#6B7280`).
   - **Card Grid:** Single horizontal container with soft blue background (`#EBF1FA`), split into 3 columns:
     - **Heart Rate:** `72` bpm + Heart icon
     - **Blood Pressure:** `120/80` mmHg + Gauge icon
     - **Oxygen Level:** `98`% + Water drop icon

4. **Quick Access Grid:**
   - **Header:** "Quick Access" (`14px`, Bold).
   - **Items (4 columns):**
     1. Find Doctor (User search icon in light blue circle)
     2. Symptoms Checker (Cross icon)
     3. Medicines (Pill icon)
     4. Lab Tests (Flask icon)
   - *Label style:* `11px`, `#4B5563`, centered below icons.

5. **Bottom Navigation Bar:**
   - Fixed at bottom with 4 items: Home (active, filled), Calendar, Chat/Messages, Profile.
   - Active indicator: Pill-shaped background container (`#111827` or dark blue) with white icon and "Home" text label.

---

## 3. Screen 2: Find The Right Treatment (Dark Theme)

### Layout Structure
- **Container:** Dark navy background (`#0C1829`), rounded corners (`48px`).
- **Padding:** Horizontal `20px`, Vertical `24px`.

### Component Breakdown
1. **Top Navigation Bar:**
   - **Left:** Back arrow icon inside circular button (`36x36px`, `#16253B`).
   - **Right:** Three-dot menu icon inside circular button.

2. **Page Header:**
   - Title: **"Find The Right"** / **"Treatment"** (`24px`, `#FFFFFF`, Bold, 2-line layout).

3. **Search Bar:**
   - **Background:** `#16253B`, rounded `24px`, height `48px`.
   - **Left Icon:** Search magnifying glass (`#9CA3AF`).
   - **Placeholder Text:** "Search treatments, doctors..." (`13px`, `#6B7280`).
   - **Right Icon:** Filter / Sliders icon.

4. **Featured Treatment Categories (Grid/Cards):**
   - **Card 1 (Large - Advanced Imaging):**
     - Background image showing MRI machine room.
     - Bottom text overlay: "Advanced Imaging" (`14px`, Bold, White) + "MRI, CT, X-Ray" (`11px`, `#9CA3AF`).
     - Action arrow on the bottom right inside a white circular button.
   - **Card 2 & 3 (Small Grid):**
     - **Card 2:** "Vaccination & Immunization" with vials/syringe image.
     - **Card 3:** "Surgical Procedures" with operating room photo.

5. **Specialist Consultation Banner:**
   - **Background:** `#16253B`, rounded `16px`, horizontal layout.
   - **Text:** "Talk to a Specialist" (Title), "Get expert advice from top doctors" (Subtitle).
   - **Avatars:** Stacked circular avatars of 3 doctors on the right with an arrow button.

6. **Bottom Navigation Bar:**
   - Matching dark theme bottom bar with Home, Calendar, Chat, Profile icons (Home selected).

## 4. Screen 3: Cancer Treatment Details (Light Theme)

### Layout Structure
- **Container:** Pure white background (`#FFFFFF`), rounded corners (`48px`).
- **Padding:** Horizontal `20px`, Vertical `24px`.

### Component Breakdown
1. **Top Header Bar:**
   - **Left:** Back arrow icon (`36x36px`, `#F3F4F6`).
   - **Right:** Share / Export icon (`36x36px`, `#F3F4F6`).

2. **Hero Image / Media Area:**
   - Image showing a medical treatment room with a comfortable oncology treatment chair and IV pole.
   - Rounded corners (`20px`).

3. **Title & Rating Section:**
   - **Title:** "Cancer" (Small gray header) -> **"Chemotherapy Treatment"** (`20px`, Bold, `#111827`).
   - **Rating:** `4.8` with Star icon + `(240 Reviews)` (`12px`, `#6B7280`).
   - **Favorite Icon:** Heart icon on the right inside a circular outline button (`36x36px`).

4. **Feature Icons Row:**
   - 4 feature items horizontally spaced:
     1. Personalized Care (Heart/User icon)
     2. Expert Oncologists (Doctor icon)
     3. Advanced Technology (Tech icon)
     4. 24/7 Patient Support (Location/Support icon)
   - Labels below icons (`11px`, `#4B5563`).

5. **Treatment Overview Section:**
   - **Header:** "Treatment Overview" (`14px`, Bold, `#111827`).
   - **Body Text:** "Chemotherapy uses powerful medicine to kill cancer cells and stop them from growing and spreading." (`13px`, `#6B7280`, Line-height `1.5`).
   - **Link:** "Learn More →" (`13px`, `#3B82F6`, Semi-Bold).

6. **Bottom Action Bar (Sticky Footer):**
   - **Background:** Deep navy blue container (`#0C1829`), rounded `24px`, horizontal flex layout.
   - **Left Text Stack:**
     - "Book Consultation" (`12px`, `#9CA3AF`)
     - "From $150" (`16px`, `#FFFFFF`, Bold)
   - **Right Button:** White circular button with right arrow (`→`) inside (`40x40px`).
