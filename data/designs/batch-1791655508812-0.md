# Design Specification: Real Estate Mobile Application

## 1. Global Layout & Typography

### Screen Geometry
- **Design Target:** Full-bleed responsive mobile screens (three distinct view states: Home Dashboard, Property Details, and Agent/Location Profile).
- **Corner Radius:** `40px` (Outer device viewport frames).
- **Default Viewport Width:** `390px` to `430px` standard modern smartphone scale.

### Color Palette
- **Primary / Dominant Background:** `#F2F3F7` (Soft neutral light greyish-off-white)
- **Secondary Surfaces (Cards/Containers):** `#FFFFFF` (Pure white)
- **Active / Primary Interactive Elements:** `#111318` (Deep rich near-black)
- **Muted Text / Secondary Elements:** `#7A7F8B` (Cool medium gray)
- **Accent Gold / Rating:** `#FFC107` (Warm star yellow)
- **Border / Divider Grays:** `#E4E7ED` (Light structural grey)

### Typography Hierarchy
- **Font Family:** *Inter*, fallback to *SF Pro Display*, *Roboto*, or generic sans-serif system fonts.
- **Screen Titles (H1):** `24px` / `28px` line-height, Bold (`700`), color `#111318`.
- **Section Headers (H2):** `18px` / `22px` line-height, Semi-Bold (`600`), color `#111318`.
- **Card Titles & Subheadings:** `14px` / `18px` line-height, Medium (`500`) to Bold (`700`), color `#111318`.
- **Body & Secondary Metadata:** `12px` / `16px` line-height, Regular (`400`), color `#7A7F8B`.
- **Badge & Price Tags:** `11px` / `14px` line-height, Bold (`700`), color `#FFFFFF` (white text on dark backgrounds) or `#111318`.
