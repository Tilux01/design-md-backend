# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial Minimalist, Modern E-Commerce Landing Page with Dark Mode split hero and clean light surface framing.
- **Visual Density & Whitespace Ratio**: High whitespace-to-content ratio in product sections, with a bold, asymmetric dark-themed hero container balanced against expansive light interior grid cards.
- **Surface Elevation Model**: Layered paper model featuring subtle border separators (`#E2E8F0`), floating UI panels with backdrop blurs, and soft charcoal card containers.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase pill badges, floating interactive UI widgets, dark-mode split composition, coral CTA buttons, minimalist borders.
- **Pill Badge Specification**: Padding: `6px 14px`, font-size: `0.75rem`, font-weight: `600`, tracking: `0.05em`, border-radius: `9999px`, background: `rgba(244, 124, 87, 0.1)`, border: `1px solid rgba(244, 124, 87, 0.3)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content to prevent rendering glitches.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;` or `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
