# Design System & Specification: Nutrition Screen

---

## 1. Typography

* **Primary Font:** SF Pro Display / SF Pro Text (iOS Native)
* **Fallback Stack:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
* **Text Styles:**
  * **Screen Title:** Bold, 32px, Tracking -0.5px (`#111111`)
  * **Card Primary Stat:** ExtraBold, 38–42px (`#111111`)
  * **Section Headers:** Bold, 20–22px (`#111111`)
  * **Macro Values:** Bold, 20–22px (`#111111`) with Medium, 13px baseline target (`#8E8E93`)
  * **Subheads / Labels:** Semibold/Bold, 10–11px, Uppercase, Tracking +0.8px (`#8E8E93`)
  * **Meta / Timestamps:** Regular, 12–13px (`#8E8E93`)
  * **Badge Values:** Medium, 11px (`#636366`)

---

## 2. Color Palette

* **Background:** Canvas: `#F4F5F7`
* **Cards / Surfaces:** Surface Pure: `#FFFFFF`
* **Text / Primary UI:** Text Primary: `#0F1012`, Text Secondary: `#8A8E97`
* **Accents / Status:**
  * Primary Alert/Over: `#F59E0B` (Amber)
  * Protein: `#EF4444` (Coral Red)
  * Carbs: `#F59E0B` (Warm Amber)
  * Fat: `#8B5CF6` (Bright Violet)
* **Neutral Tints:** Card Subdued: `#F0F1F5`, Separator: `#E5E7EB`

---

## 3. Layout & Structure

* **Viewport:** Responsive Mobile (Base: 393 × 852 pt, iPhone standard full-screen).
* **Grid Margins:** Horizontal padding: `16px`; Section vertical spacing: `16px`.

```
[ Safe Area / Status Bar ]

```

---

## 4. Components

### A. Date Strip Selector
* **Days:** 7-column flex row with left vertical divider.
* **Item:** Column with 3-letter day (`11px`, gray) and day number pill (`38×38px`, radius `12px`, background `#F0F1F5`).
* **Active State (Mon 31):** Black fill (`#0F1012`), white text, bottom pill indicator (`16×3px`, radius `2px`).

### B. Calorie Overview Card
* **Container:** `#FFFFFF`, radius `24px`, padding `20px`, full width.
* **Left Content:**
  * Label: `CALORIES` (Uppercase, gray).
  * Main metric: `2520` (38px, bold).
  * Subtext: `of 2200 eaten` + inline edit pencil icon (`14px`).
* **Right Content:**
  * Semi-circle / circular progress track (`120px` diameter, `10px` stroke).
  * Base track: `#F3F4F6`; Progress stroke: `#F59E0B`.
  * Center content: `320` (Bold 24px) over `OVER` (Uppercase 10px gray).

### C. Macro Summary Cards (3-Column Grid)
* **Grid:** 3 equal columns, gap `10px`.
* **Container:** `#FFFFFF`, radius `18px`, padding `12px 10px`.
* **Structure:**
  * Header: Tiny icon + uppercase label (`PROTEIN`, `CARBS`, `FAT`).
  * Value: `153/165g`, `255/240g`, `90/70g`.
  * Progress Bar: `4px` height, radius `2px`, color-coded (`#EF4444`, `#F59E0B`, `#8B5CF6`).
  * Subtext: `[X]g left` (11px, gray).

### D. Food List Card
* **Container:** `#FFFFFF`, radius `24px`, padding `16px`.
* **List Row:**
  * Left: Icon container (`44×44px`, radius `12px`, `#F0F1F5`) with contextual icon (pancakes, fish, avocado).
  * Title & Macros: Meal title (15px semibold), macro chips (P/C/F tags with `#F0F1F5` backgrounds).
  * Right: Timestamp (`12px`, gray), Calories (`16px`, bold) + `cal`, dismiss icon (`×`).
  * Divider: `1px` border `#F0F1F5` between items.

### E. Floating Action Button (FAB)
* **Geometry:** `56×56px` circle.
* **Color:** Black (`#0F1012`), icon `#FFFFFF`.
* **Placement:** Bottom-right, stacked above bottom nav (`bottom: 90px`, `right: 20px`).
* **Shadow:** `0px 6px 16px rgba(0, 0, 0, 0.2)`.

### F. Bottom Navigation Bar
* **Surface:** Translucent white with backdrop-blur (`rgba(255, 255, 255, 0.85)`, `blur(20px)`).
* **Border:** Top line `0.5px solid rgba(0,0,0,0.1)`.
* **Tabs (4):** Chart/Analytics, Barcode/Search, Cutlery (Active, `#0F1012`), Profile.

---

## 5. Interactions & Motion

* **Date Switch:** Horizontal snap scroll with active indicator slide (spring: `damping: 25, stiffness: 300`).
* **Progress Rings & Bars:** Linear-to-ease-out fill animation (`duration: 800ms`) on screen mount.
* **FAB Click:** Rotate icon `45deg` to open quick-log modal; micro-scale click response (`0.92`).
* **Item Dismiss:** Swipe-to-delete or tap `×` with row collapse transition (`height: 0`, opacity fade out, `250ms`).
