# Repository of Remnants - Design Specification

## Overview
A moody, retro-futuristic dark mode web interface simulating an archival research database. The design blends 1960s/70s laboratory aesthetics (typewriters, measurement equipment, stamped paper cards) with clean, modern web typography and UI components.

---

## 1. Color Palette

### Backgrounds
*   **Main Page Background:** `#0c0c0c` (Very dark charcoal/near black)
*   **Hero Container Background:** `#121212` with subtle gradients/noise
*   **UI Panel Backgrounds (Cards):** `#1a1a1a`
*   **Modal/Info Box Background:** `#1c2333` (Deep slate blue)

### Accent Colors
*   **Primary Accent (Teal/Cyan):** `#2ea39f` (Used for the spectrophotometer equipment and highlights)
*   **Card Blue (Info Box):** `#2a50ef` (Vibrant electric blue)
*   **Action Button Yellow:** `#f5c518` (Retro warm yellow)
*   **Action Button Red/Coral:** `#e63946` (Used for power/action toggles)
*   **Stamp Purple/Blue:** `#4a6080` (Used on archival library check-out slips)

### Typography Colors
*   **Primary Text (White):** `#f0f0f0`
*   **Secondary Text (Muted Gray):** `#8c8c8c`
*   **Dark Neutral Text (On paper elements):** `#222222`

---

## 2. Typography

*   **Primary Font Family:** Inter, sans-serif (for UI elements, navigation, and body copy)
*   **Display/Heading Font:** Serif typeface with editorial weight (e.g., *Playfair Display* or *Lora* for "Repository of Remnants")
*   **Mono Font:** Courier / Space Mono (for metadata identifiers, numbers, and retro stamps)

### Scale & Hierarchy
*   **Header Logo / Navigation:** 13px, Medium, tracking/spacing wide.
*   **Breadcrumbs:** 11px, Uppercase, Muted Gray (`#707070`).
*   **Main Heading (H1):** 42px, Serif, Italicized elements ("of"), Regular weight.
*   **Body Copy (Intro Paragraphs):** 12px, Line height 1.6, Muted Gray (`#a0a0a0`).
*   **Data Labels (Blue Card):** 11px, Monospace/Sans-serif, Leading tight.

---

## 3. Layout & Structure

### Global Layout
*   **Full-Width Container:** 100vw width, min-height 100vh, centered core layout constrained within a clean margin framework.
*   **Grid Structure:** Asymmetrical hero display featuring a central focal image (Spectrocolorimeter E 1000) surrounded by layered overlapping archival assets (library cards, data sheets, photos).

### Navigation Bar
*   **Position:** Fixed top, spanning full width.
*   **Left Links:** `Explore`, `Timeline`, `Map`, `Collections`.
*   **Center Element:** Circular logo icon (`files`) + `Q search`.
*   **Right Links:** `About`, `Sign up`.
*   **Divider:** Subtle thin bottom border (`#222222`).

---

## 4. Component Specifications

### A. Header Section
*   **Metadata Breadcrumb:**
    ```
    Source / Drawer / Registry / Residue
    ```
    *(Color: `#666`, Uppercase, 10px)*
*   **Archival Tag (Top Right):**
    ```
    Archive Assemblage
    Jul 29, 1975
    ```

### B. Descriptive Text Block
*   Two-column justified paragraph layout describing the repository terms and conditions.
*   **Column 1:** Explains the indexing scheme and abstract identifiers.
*   **Column 2:** Details document fragments and metadata structuring.

### C. Interactive / Visual Collage (Centerpiece)
*   **Central Machine:** A high-detail illustration/rendering of a vintage *Spectrocolorimeter E 1000* in teal green (`#2ca39f`), featuring analog dials, a vacuum-fluorescent indicator meter, toggle switch, and control knobs.
*   **Background Layer (Left):** Overlapping vintage library borrow cards (`14 DAY USE`, stamped dates like `JUL 28 RECD`).
*   **Background Layer (Bottom):** Monochrome historical architectural/industrial photograph prints.
*   **Metadata Callout Card (Right):**
    *   **Background:** Electric Blue (`#2a50ef`)
    *   **Title:** `E 1009`
    *   **Description:** Definition of spectrocolorimeter functions.
    *   **Action Row:** `[ Download ]` (Yellow button) + Red circular button with pointer cursor interaction.

---

*   **Bottom Left:** `Files. Design Exploration`
*   **Bottom Right:** Circular monogram stamp `(files)`
