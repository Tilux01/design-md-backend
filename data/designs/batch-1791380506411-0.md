# UI/UX Specification: "Recharge." App Icon & Interface Clone

This document provides the exact technical specifications, design tokens, layout structure, typography, and animation logic required to recreate the "Recharge." graphic as a responsive, production-ready full-screen interface.

---

## 1. Global Layout & Container

*   **View Mode:** Full-Screen (Edge-to-Edge).
*   **Background:** 
    *   Solid Dark Base: `#121212`
    *   Subtle Radial Vignette / Ambient Glow: Centered at bottom-middle to emulate the device/icon shadow casting downwards.
*   **App Icon Container (If centered in viewport):**
    *   **Shape:** Squircle (iOS-style continuous curvature).
    *   **Border-Radius:** `22.3%` (standard iOS app icon curvature, roughly `44px` on a `200px` base, or `32px` on a `512px` base).
    *   **Background:** Dark metallic/charcoal gradient `#1c1c1e` to `#111113`.
    *   **Texture:** Ultra-subtle CSS dot matrix or noise pattern overlay (opacity: `0.05`).

---

## 2. Typography & Fonts

### Main Header: "Recharge."
*   **Text String:** `Recharge.`
*   **Font Family:** 
    *   *Primary:* **SF Pro Display** (Apple System Font) / **Inter** (Close Open Source match).
    *   *Fallback Stack:* `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
*   **Font Weight:** `700` (Bold) to `800` (Extra Bold).
*   **Font Size:** `48px` (Scalable via `clamp()`, e.g., `clamp(2rem, 5vw, 3.5rem)`).
*   **Letter Spacing (Tracking):** `-0.02em` (Tight, modern display tracking).
*   **Color:** Pure White (`#FFFFFF`).
*   **Alignment:** Center (or Left-aligned with padding, matching the image's centered balance relative to the slider).

### Scale Markers: "0", "50", "100"
*   **Font Family:** Same system sans-serif stack (`Inter` / `SF Pro Text`).
*   **Font Weight:** `500` (Medium).
*   **Font Size:** `20px`.
*   **Color:** Muted Neutral Gray (`#636366` or `rgba(255, 255, 255, 0.4)`).
*   **Positioning:** Placed evenly above the slider track:
    *   `0`: Aligned with the left edge of the track.
    *   `50`: Centered horizontally over the track.
    *   `100`: Aligned with the right edge of the track.

---

## 3. The Slider Component

The slider is the focal point of the design, featuring a glowing liquid/pill indicator and a sunken track.

### A. The Track (Background Pill)
*   **Shape:** Pill shape (fully rounded ends).
*   **Dimensions:** Width ~`80%` of container width, Height ~`80px`.
*   **Background:** Deep dark inset cavity (`#0a0a0b`).
*   **Shadow / Inner Depth:** 
    *   Inset shadow: `inset 0px 4px 8px rgba(0, 0, 0, 0.8)`
*   **Texture:** Same micro-dot pattern as the background, darkened.

### B. The Fill / Active Handle (Glowing Red Pill)
*   **Current State in Image:** Low battery / near `0` (approx. `12%` filled).
*   **Shape:** Pill-shaped thumb with a convex, liquid-like meniscus curve on the right edge.
*   **Color / Gradient:** 
    *   Intense glowing red/orange gradient from left to right:
    *   `#FF1A1A` (Bright Neon Red) $\rightarrow$ `#FF4D00` (Vibrant Orange-Red).
*   **Glow Effect (Box Shadow):**
    *   Multi-layered drop-shadow for the intense red bloom:
    *   `0 0 20px rgba(255, 26, 26, 0.6)`, `0 0 40px rgba(255, 77, 0, 0.4)`.
*   **Surface Texture:** 
    *   Radial inner highlight on the left cap to give it a 3D spherical/glass reflection.

---

## 4. Animation & Interaction Design (Motion Specs)

To bring this static design to life, implement the following micro-interactions and continuous loops:

### 1. The "Charging" Pulse Animation (Idle State)
*   **Property:** Glow intensity (`box-shadow` spread and opacity) and fill width.
*   **Keyframes:**
    *   `0%`: Glow opacity `0.5`, width `12%`.
    *   `50%`: Glow opacity `0.9` (intense surge), width `13%` (subtle breathing).
    *   `100%`: Glow opacity `0.5`, width `12%`.
*   **Duration:** `2.5s` infinite ease-in-out loop.

### 2. Drag / Swipe Interaction
*   **Physics:** Spring-based physics (`tension: 300, friction: 30`).
*   **Haptic Feedback:** Trigger light haptic pulse (`navigator.vibrate` or native iOS haptics) on drag start and when passing milestones (`0`, `50`, `100`).
*   **Dynamic Color Shift:** As the slider moves from `0` (Red: `10%` charge) to `100` (Green/White: Fully charged), smoothly interpolate the gradient:
    *   `0%`: `#FF1A1A` (Red - Depleted)
    *   `50%`: `#FFB800` (Yellow - Medium)
    *   `100%`: `#30D158` (Green - Full)
