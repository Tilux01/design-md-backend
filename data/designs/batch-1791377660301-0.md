# Design Specification: "HUGINN" Portfolio Website

This document provides the exact design specifications required to build a pixel-perfect, full-screen clone of the provided website interface.

---

## 1. Global Layout & Structure

*   **View:** Full-Screen responsive layout (expand beyond the presentation frame to 100vw × 100vh).
*   **Grid System:** 4-column split-screen layout. Each column represents a distinct portfolio category/slide.
*   **Overall Dark Theme:** Dark charcoal/near-black background palette `#121214`.

---

## 2. Typography & Font Stack

*   **Primary Font Family:** Clean, geometric sans-serif (e.g., **Inter**, **Roboto**, or **Helvetica Neue**).
*   **Fallback Stack:** `font-family: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;`

### Typography Hierarchy:
*   **Brand / Logo ("HUGINN"):** 
    *   Weight: Bold (700)
    *   Letter-spacing: Wide (`2px` - `3px`)
    *   Text-transform: Uppercase
*   **Navigation Links (HOME, ABOUT, WORK, CONTACT):**
    *   Font-size: Small (~11px - 12px)
    *   Weight: Medium (500)
    *   Letter-spacing: `1.5px`
    *   Color: White/Light Gray (`rgba(255, 255, 255, 0.7)`), transitioning to pure white on hover.
*   **Slide Numbers (01., 02., 03., 04.):**
    *   Font-size: Small (~13px)
    *   Weight: Bold (700)
    *   Color: White
*   **Slide Titles ("Beautiful Venice", "Lovely Room", etc.):**
    *   Font-size: Large (~20px - 22px)
    *   Weight: Semi-bold (600)
    *   Color: Pure White
*   **Slide Sub-categories ("TRAVEL", "INTERIOR", "LANDSCAPES", "PORTRAITS"):**
    *   Font-size: Extra-small (~10px)
    *   Letter-spacing: `2px`
    *   Text-transform: Uppercase
    *   Color: Muted gray (`rgba(255, 255, 255, 0.6)`)

---

## 3. Color Palette

| Role | Color Hex / Value | Usage |
| :--- | :--- | :--- |
| **Background / Base** | `#161619` | Main canvas background |
| **Primary Text** | `#FFFFFF` | Logo, slide titles, numbers |
| **Secondary Text** | `rgba(255, 255, 255, 0.7)` | Nav links, sub-labels |
| **Accent / Progress** | `#6c5ce7` (or similar soft purple) | Bottom progress indicator bar |
| **Overlay Gradient** | `linear-gradient(180deg, rgba(0,0,0,0) 40%, rgba(0,0,0,0.85) 100%)` | Dark gradient over images for text legibility |

---

## 4. Header & Navigation

*   **Position:** Fixed absolute top overlay (`z-index: 10`).
*   **Left Element:** 
    *   Bird/Wolf abstract icon graphic (white).
    *   Brand name text: **HUGINN**.
*   **Center/Right Navigation:**
    *   Links: `HOME`, `ABOUT`, `WORK`, `CONTACT`.
    *   Hamburger menu icon (three horizontal lines) positioned to the left of the nav links.
    *   Search icon (magnifying glass) aligned to the far top-right corner.

---

## 5. Main Content Area (The 4 Columns)

The interface is divided into **4 vertical structural columns** side-by-side. 

1.  **Column 1:** Venice canal scene (Travel) + Number `01.` + Title `Beautiful Venice` + Sub `TRAVEL`
2.  **Column 2:** Cozy indoor room with window (Interior) + Number `02.` + Title `Lovely Room` + Sub `INTERIOR`
3.  **Column 3:** Overcast mountain landscape (Landscapes) + Number `03.` + Title `Amazing Mountain` + Sub `LANDSCAPES`
4.  **Column 4:** Portrait of a man in a hat (Portraits) + Number `04.` + Title `Street Portrait` + Sub `PORTRAITS`

### Column Interactive Behavior & Hover States (Accordion Effect):
*   By default, columns share space evenly (approx. 25% width each).
*   **Hover Effect:** When a user hovers over any column, that specific column expands smoothly in width (e.g., up to 40%–50%), while adjacent columns compress proportionately.
*   **Image Styling:** High-resolution photography fitted with `object-fit: cover`. Each column has a subtle dark gradient overlay at the bottom to ensure white text remains fully readable against bright images.

---

## 6. Footer & Controls

*   **Bottom Left:** Copyright text ("© All Rights Reserved 2017").
*   **Bottom Center:** Horizontal progress bar / pagination indicator with an active glowing purple segment highlighting the current active view.
*   **Side Navigation Arrows:** Subtle small arrows (`<` PREV and `> ` NEXT) positioned on the extreme left and right margins of the viewport to cycle through slides.

---

## 7. Animations & Interactions

1.  **Accordion Expansion (CSS Transition):**
    *   `transition: width 0.6s cubic-bezier(0.16, 1, 0.3, 1);` applied to each column container.
2.  **Image Zoom on Hover:**
    *   `transition: transform 0.8s ease;`
    *   `transform: scale(1.05);` applied to the background image when its parent column is hovered.
3.  **Fade/Slide Up for Typography:**
    *   Titles and categories subtly slide up into position during page load or slide changes (`transform: translateY(0)` from `20px`).
