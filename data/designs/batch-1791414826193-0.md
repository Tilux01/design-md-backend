# Design Specification: Minimalist Monochrome Dashboard

## 1. Overview & Theme
* **Style**: High-contrast, Swiss-inspired brutalist/minimalist UI (similar to Nothing OS / KWGT widgets).
* **Mode**: Light mode, purely monochrome.
* **Canvas**: Full-screen mobile viewport (100vw, 100vh).

---

## 2. Color Palette

| Token | Hex Value | Usage |
| :--- | :--- | :--- |
| `bg-primary` | `#FFFFFF` | Canvas background, card foreground |
| `bg-secondary` | `#F4F4F4` | Card container fills (subtle off-white) |
| `border-subtle` | `#E5E5E5` | Card borders, dividers |
| `text-primary` | `#000000` | Primary headers, large numerals, icons |
| `text-secondary`| `#666666` | Labels, secondary metadata |
| `accent-black` | `#111111` | Primary action pill/button |

---

## 3. Typography & Fallbacks

* **Primary Display & Headings**: Clean, high-contrast Neo-Grotesque sans-serif.
  * *Font*: `Inter`, `Helvetica Neue`, `Arial`, sans-serif.
  * *Weights*: Bold (700), Heavy (800).
* **Body & Labels**:
  * *Font*: `Inter`, `-apple-system`, `BlinkMacSystemFont`, `sans-serif`.
  * *Weights*: Regular (400), Medium (500).
* **Fallback Stack**:
  ```css
  font-family: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
  ```

---

## 4. Layout Grid

* **Container**: `max-width: 430px; height: 100vh; padding: 16px 20px; display: flex; flex-direction: column; justify-content: space-between;`
* **Widget Grid**: 2 columns, gap: `12px`.
* **Border Radius**: Cards use `18px`–`20px` rounded corners.

---

## 5. UI Components

### Top Section: 2x2 Grid (4 Cards)

1. **Date Card (Top-Left)**
   * **Size**: 1x1 grid cell (~160px × 140px).
   * **Content**: 
     * Top row: Day abbreviation (`WED`) in `12px` medium uppercase.
     * Center/Bottom: Large date number (`18`) in `56px` bold sans-serif.
2. **Schedule / Weather Card (Top-Right)**
   * **Size**: 1x1 grid cell.
   * **Content**:
     * Header: `Thu` • `12°C` (split inline).
     * Body text: Two lines of scheduled events (`10-12 Reading time`, `Technical WP`). Font size: `11px–12px`.
3. **Quick Metric Card (Mid-Left)**
   * **Size**: 1x1 grid cell.
   * **Content**: Minimal vector icon + metric label (e.g., Battery/Weather status).
4. **Media / Utility Card (Mid-Right)**
   * **Size**: 1x1 grid cell.
   * **Content**: Glyph icon (camera/media lens) + single-line status description.

### Middle Section: Task / Agenda Card

* **Dimensions**: Full width (spans 2 columns), height ~160px.
* **Layout**: Vertical list with 3 rows:
  * Each item includes a circular checkbox outline + item string (`UI/UX Research`, `System Architecture`, etc.).
  * Right edge: Floating solid black circle button (`40px × 40px`) for quick-add actions.

### Bottom Section: Dock

* **Container**: Horizontal flex row, `justify-content: space-around`, pinned above the home indicator.
* **Icons**: 4 monochrome outlined/solid glyphs (App Drawer, Phone, Messages, Settings).
* **Size**: `48px × 48px` touch target, `24px` icon glyph size.

---

## 6. Motion & Animations

* **Card Press**: `transform: scale(0.98); transition: transform 0.15s cubic-bezier(0.4, 0, 0.2, 1);`
* **Action Button Press**: `transform: scale(0.92); opacity: 0.85;`
* **Task Complete Toggle**: Smooth fade (`opacity: 0.4`) and strike-through transition over `200ms`.
