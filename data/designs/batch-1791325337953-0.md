# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Futuristic Cyber-Minimalism, Dark Mode Glassmorphism, Immersive AI Canvas UI.
- **Visual Density & Whitespace Ratio**: High visual focus on immersive central 3D viewport balanced with compact, low-footprint toolbars and floating control panels. Generous whitespace around card boundaries with subtle border separations.
- **Surface Elevation Model**: Layered depth architecture. Base canvas is an ultra-dark gradient (`#0B0C10`), overlaid with translucent frosted glass panels (`rgba(20, 22, 28, 0.7)`), 12px backdrop blur, crisp 1px borders (`rgba(255, 255, 255, 0.08)`), and soft ambient drop shadows.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase pill badges, ambient neon glow orbs, frosted glassmorphism, subtle high-density grid texturing, interactive state indicators.
- **Pill Badge Specification**: Padding `6px 14px`, font-size `11px`, font-weight `600`, tracking `0.08em`, border-radius `9999px`, background translucency `rgba(255, 255, 255, 0.05)`, border width `1px`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or inline SVG icon component.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
