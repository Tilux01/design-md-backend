# UI Design Specification: Medical Healthcare Dashboard ("HealthPulse")

This document provides a comprehensive design specification for recreating the provided medical dashboard UI. It covers layout structures, typography, color palettes, iconography, component states, and exact asset descriptions.

---

## 1. Global Layout & Structure

*   **View Type:** Full-screen desktop application layout (`1440px` or responsive fluid layout).
*   **Background Container:** The main dashboard is enclosed in a large rounded card window positioned centrally on a dark charcoal-textured background (`#2b2d3b` / `#1e202b`).
*   **Window Border-Radius:** Large corner rounding (`32px` or `2rem`).
*   **Grid Structure:** 
    *   **Sidebar:** Fixed width on the left (`88px` – `100px`).
    *   **Main Content Area:** Split into two primary vertical columns/sections:
        *   **Left Column (Width: ~38%):** "What do you need?" category selection grid (2 columns of icon cards).
        *   **Right Column (Width: ~58%):** "Find Doctor" specialty buttons, followed by the "Your Appointments" scrollable/horizontal list.

---

| Role | Color Name | Hex Code / RGBA | Usage |
| :--- | :--- | :--- | :--- |
| **Primary Dark** | Deep Charcoal / Navy | `#141726` | Sidebar background, primary titles |
| **Canvas** | Off-White / Light Gray | `#f4f5f8` | Main dashboard background surface |
| **Card Surface** | Pure White | `#ffffff` | Individual cards, inner containers |
| **Accent / Brand** | Soft Pink / Rose | `#ffc5cb` / `#ffebec` | Active indicators, notification badges, selected states |
| **Text Primary** | Dark Slate | `#181b2a` | Headers, doctor names, active category text |
| **Text Secondary**| Muted Gray | `#6b7280` / `#8c909c` | Subtitles, helper text, dates/times |
| **Card Tints** | Soft Pastels | Various (see below) | Specialty buttons in "Find Doctor" |

## 3. Typography & Fonts

*   **Primary Font Family:** `Inter`, fallback to `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `Helvetica`, `Arial`, sans-serif.
*   **Secondary/Brand Font (Headers):** `Plus Jakarta Sans` or `Poppins` (Clean, rounded modern sans-serif).

### Typography Scale:
1.  **Dashboard Section Headers ("What do you need?", "Find Doctor", "Your Appointments"):**
    *   *Font Size:* `20px` to `24px`
    *   *Font Weight:* `700` (Bold)
    *   *Color:* `#141726`
2.  **Subtitles ("Select your requirement", "Make an appointment..."):**
    *   *Font Size:* `13px` to `14px`
    *   *Font Weight:* `400` (Regular)
    *   *Color:* `#8c909c`
3.  **Card Titles (Doctor Names, Categories):**
    *   *Font Size:* `14px` to `16px`
    *   *Font Weight:* `600` (Semi-bold)
4.  **Meta/Labels (Date, Time, Specialty sub-labels):**
    *   *Font Size:* `11px` to `12px`
    *   *Font Weight:* `500` / `400`

---

## 4. Component Breakdown

### A. Left Navigation Sidebar
*   **Background:** `#141726` (Deep Charcoal Navy).
*   **Top Brand Icon:** Rounded square pill with gradient/accent shapes (`#ff5768` mixed with dark shapes). Logo mark resembles an abstract medical cross/sparkle.
*   **Navigation Items:** Vertical stack of outlined linear vector icons (white stroke, `1.5px` thickness):
    *   Menu bars (Hamburger)
    *   Dashboard grid (4-squares)
    *   Calendar / Schedule
    *   ECG / Heartbeat line graph
    *   User / Profile icon
    *   Bell (Notifications)
    *   Folder / Document
    *   Settings / Gear
    *   Logout / Power icon at the bottom.
*   **Active Indicator:** The top icon ("Doctor" category / Dashboard home) features a selected state pill background (`#1b2033`) with a soft pink bottom-right corner accent line or circular badge.
*   **User Profile Avatar at Bottom:** Circular cropped photo of a smiling man with glasses, positioned just above the logout icon.
