# Design Specification: Custo.ai SaaS Landing Page

---

## 1. Design Philosophy & Overall Aesthetic
* **Primary Mood:** Ultra-clean, modern, minimalist SaaS aesthetic tailored for enterprise-grade B2B Artificial Intelligence platforms.
* **Brand Archetype:** High-tech, reliable, premium, authoritative.
* **Visual Density:** Generous whitespace, comfortable padding scaling, and focused scannability centered around strong typography.
* **Theme Balance:** Pure Light Mode default (`#FFFFFF` background, `#111111` primary typography) utilizing high-contrast monochromatic structural planes with 3D grayscale abstract metallic/glass renders to add depth.

---

## 4. Layout Architecture & Spatial Grid
* **Container Max-Width:** `1200px` centered with auto margins, responsive padding (`1rem` mobile, `2rem` desktop).
* **Section Sequence:**
  1. **Global Header (Sticky/Fixed):** Logo left, Navigation center links, Action button right ("Contact Us →").
  2. **Hero Section:** Centered high-impact value proposition, secondary descriptive text, primary CTA button, followed by full-width 3D abstract fluid metallic visualization.
* **Stacking Order (Z-Index):**
  * Base content: `z-0`
  * Decorative elements / 3D graphic backgrounds: `z-10`
  * Sticky Navigation Header: `z-50`
  * Floating Modals / Dropdowns: `z-100`

---

## 5. AI Design Traits & Micro-Badges
* **Action Arrows:** Clean Unicode or CSS arrows (`→`, `&rarr;`) integrated into high-contrast action triggers.
* **Minimalist Brand Identity:** Minimalist wordmark (`Custo.ai`) with a custom stylized glyph featuring overlapping circular loops representing connectivity and automation.
* **Buttons & Interaction States:**
  * *Primary Solid Button:* Inverted dark background (`#0a0a0a`), text white (`#ffffff`), border-radius `9999px` (pill style), inline flex alignment for text and trailing arrow icons. Hover state scales slightly (`scale(1.02)`) with a deep shadow.

## 8. Accessibility (a11y) & WCAG Contrast Audit
* **Primary Text (`#0a0a0a`) on White Background (`#ffffff`):** Contrast ratio > 18:1 (Passes WCAG AAA).
* **Muted Text (`#737373`) on White Background (`#ffffff`):** Contrast ratio ~ 4.6:1 (Passes WCAG AA for normal text).
* **Focus State Styles:**
```css
button:focus-visible, a:focus-visible {
  outline: 2px solid #0a0a0a;
  outline-offset: 2px;
}
```
