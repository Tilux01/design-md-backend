# Zarss Dashboard Design Specifications

## 1. Global Layout & Structure
- **Container**: Full-screen layout with a dark theme. The main dashboard sits on a subtle beige/warm-neutral background (`#F5F5F0`), while the application wrapper uses a dark charcoal/near-black theme (`#181A1C`).
- **Border Radius**: The main application wrapper features rounded corners (`approx. 24px`).
- **Layout Grid**: 
  - **Left Sidebar**: Fixed width (~220px) containing user profile, navigation links, and logout.
  - **Center Content Area**: Flexible grid handling top metrics cards, upgrade banner, weekly user statistics chart, and the "Last Orders" table.
  - **Right Sidebar**: Fixed width (~300px) displaying "Monthly Profits" (with a progress doughnut chart) and a scrollable "Recent Sales" feed.

---

## 2. Typography & Fonts

### Font Families
- **Primary Font**: Inter (Clean, modern sans-serif).
- **Fallback Stack**: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.

### Hierarchy
- **Brand Title ("Zarss")**: 18px, Bold, Pure White (`#FFFFFF`).
- **Dashboard Heading ("Dashboard")**: 20px, Bold, White (`#FFFFFF`).
- **Section Headers ("User in The Last Week", "Recent Sales", "Last Orders")**: 14px–16px, Semi-bold, White/Light Gray.
- **Body & Subtext (Usernames, Amounts, Subtitles)**: 12px–13px, Regular/Medium, Muted Gray (`#9EA2A8`).
- **Small Metrics & Labels ("+17%", "+23%", Timestamps)**: 10px–11px, Medium.
