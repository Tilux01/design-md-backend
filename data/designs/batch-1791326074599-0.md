# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Dark Mode Glassmorphism & High-Performance Enterprise SaaS Dashboard.
- **Visual Density & Whitespace Ratio**: High information density balanced by deep ambient contrast, subtle glass blur layers, rounded card containers, and glowing gradient borders.
- **Surface Elevation Model**: Multi-tier elevation using deep charcoal/black canvas (`#09090b`), elevated card surfaces (`#0f0f13`, `#121218`) with 1px translucent borders (`rgba(255, 255, 255, 0.08)`), multi-layered backdrop blur (`blur-xl`), and ambient colored glow highlights (violet, blue, amber).

# 2. Color Palette & Design Tokens

## Color Token Definitions
- **Primary Brand Color & Variants**: Indigo/Violet (`#6366f1` / `#818cf8`), Hover (`#4f46e5`), Active (`#4338ca`), Subdued (`rgba(99, 102, 241, 0.15)`).
- **Secondary & Accent Colors**: Success Green (`#10b981`), Warning Yellow (`#f59e0b`), Error Red (`#ef4444`), Info Blue (`#3b82f6`).
- **Background & Surface Architecture**: Canvas Background (`#050507`), Surface 1 - Cards (`#0d0d12`), Surface 2 - Modals/Dropdowns (`#13131a`), Surface 3 - Floating Pills (`rgba(25, 25, 35, 0.8)`).
- **Border & Divider Scale**: Base border (`rgba(255, 255, 255, 0.07)`), Muted divider (`rgba(255, 255, 255, 0.04)`), Active glow border (multi-stop gradient: violet to blue to pink).
- **Text Color Hierarchy**: Primary Text (`#f8fafc`), Secondary/Muted Text (`#94a3b8`), Disabled Text (`#475569`), Inverse Text (`#0f0f13`), Accent Text (`#818cf8`).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Glowing gradient border highlights, live status pulses, high-contrast monospace code previews, floating interactive card overlays.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `11px`, font-weight `600`, tracking `0.05em`, border-radius `9999px`, background translucency `rgba(255, 255, 255, 0.05)`, border width `1px`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before`.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG.
  - Status Dot (●) -> Use `<span className="w-2 h-2 rounded-full bg-emerald-500 inline-block" />`.
