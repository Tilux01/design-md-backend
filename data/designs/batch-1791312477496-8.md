# UI/UX & Design System Specification: Skot. Moped Showcase Platform

---

## 1. Design Philosophy & Overall Aesthetic
- **Primary Mood:** Modern, high-end, sleek, automotive-luxury e-commerce/showcase.
- **Brand Archetype:** Premium Consumer Tech & Sustainable Urban Mobility.
- **Visual Density:** Airy, spacious, high-contrast, minimalist asymmetrical layout.
- **Whitespace Balance:** High white/light-gray background dominance with intentional focal asymmetry (hero object overlapping background cards).
- **Theme Archetype:** Pure Light Mode UI built on ultra-light neutral surfaces (`#F2F2F2` / `#FFFFFF`) with stark black typography and vibrant accent pops.

## 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** `1280px` centered fluid canvas with `40px` horizontal screen padding.
- **Grid System:** 12-column structural layout with dynamic flex staging zones.
- **Spacing Scale (8pt Grid):**
  - `xs`: `4px`
  - `sm`: `8px`
  - `md`: `16px`
  - `lg`: `24px`
  - `xl`: `32px`
  - `xxl`: `48px`
- **Z-Index Hierarchy:**
  - Background structural container: `z-index: 0`
  - 3D Moped Object / Main Hero Cutout: `z-index: 10`
  - Floating UI Cards & Badges: `z-index: 20`
  - Global Navigation Bar: `z-index: 50`

---

## 5. Component Blueprint & Element Placement

### Top Navigation Bar
- **Dimensions:** Height `72px`, full-width container with horizontal padding.
- **Left Cluster:** 
  - Search Icon button (Circular border, dark outline, `36px` diameter).
  - Navigation links: `About`, `Collections`, `Services`, `Options` (Spacing: `32px` gap).
- **Center Cluster:** Brand logo (`Skot.`) with abstract red icon mark.
- **Right Cluster:**
  - Dark mode / Theme toggle icon.
  - `Contact us` text link.
  - User avatar/status indicator.
  - `Cart` button with item count badge (`Clipped Pill`, background `#FFFFFF`, border stroke).

### Hero Section Architecture
- **Left Column (Typography & Specs):**
  - Headline: `"Super fast electric Moped"` accompanied by inline minimalist graphic icons (planet and lightning bolt badge pills).
  - Feature Card (`C45` / `Classic Model`):
    - Background: Solid white translucent surface.
    - Border Radius: `24px`.
    - Padding: `24px`.
    - Content: Model heading, descriptive paragraph (`"Officially the UK's No.1 selling moped..."`), and interactive Red Action Button (Circular, `#D83226`, icon inside).
- **Center/Right Canvas (Product Showcase):**
  - Asymmetrical curved background card cutout (`border-radius: 40px` top-left, bottom-right).
  - Centerpiece 3D render of white moped featuring a contrasting red front wheel hub.
- **Floating Social Proof Widget (Top Right):**
  - Overlapping avatar stack (3 users + counter badge).
  - Rating stars (`★★★★☆`).
  - Text: `"10k+ positive reviews we achieved"`.
- **Floating Product Variant Thumbnail (Bottom Right):**
  - Card showing alternate model (`DB50QT` - `Panther Moped`).
  - Thumbnail preview with title and subtitle metadata.
  - Border-radius: `16px`.

## 6. Motion Mechanics, 3D & Mobile Gestures

- **Animation Triggers:** 
  - Page load entrance (Staggered fade-up for typography, scale-in for floating cards).
  - Hover micro-interactions on product cards and buttons (elevation lift via shadow scaling).
- **Easing Physics:** 
  - Standard UI transitions: `cubic-bezier(0.16, 1, 0.3, 1)` (Apple-style smooth out).
  - Spring physics for floating badges: `stiffness: 300`, `damping: 20`.
- **Durations:**
  - Micro-interactions (Buttons/Links): `180ms`
  - Card Hover Elevation: `250ms`
  - Hero Entry Sequence: `800ms` (Staggered by `100ms` per element)
