# Design Specification: Mobile App UI Clone

This document provides a precise, pixel-level specification for recreating the mobile application user interface shown in the source media. It covers layout structures, typography, color schemes, component hierarchies, and asset descriptions.

---

## 1. Global Layout & Viewport

*   **Platform Target:** Mobile iOS / Android native app (Responsive vertical layout).
*   **Layout Style:** Two screens displayed side-by-side in the preview. We will define the primary dashboard/overview screen (Left) and the transactional/details screen (Right).
*   **Background Canvas:** Light gray neutral canvas backdrop for presentation; actual app canvas uses pure white (`#FFFFFF`) backgrounds with high-contrast black (`#000000`) and dark neutral components.
*   **Border Radius (App Container/Screens):** Rounded corners approximate standard mobile devices (~40px radius if floating).

---

## 2. Typography & Fonts

*   **Primary Font Family:** **SF Pro Display / Inter** (Clean, modern sans-serif).
*   **Fallback Stack:** `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
*   **Font Weights Used:**
    *   `Regular (400)`: Body text, secondary labels, timestamps.
    *   `Medium (500)`: Section titles, table rows, button labels.
    *   `Bold (700)`: Primary headings, numerical balances, main balance headers.

---

## 3. Screen 1: Dashboard / Main View (Left)

### A. Status Bar & Header
*   **Status Bar:** Standard top bar containing time indicators (left: `9:41`) and system icons (battery, wifi, signal indicators on the right).
*   **Navigation Bar:**
    *   **Left:** Circular avatar/profile icon with a small notification dot.
    *   **Center/Left Aligned:** User greeting or account identifier (e.g., "Hi, Alex").
    *   **Right:** Action icon (notification bell or search icon, styled as a circular bordered icon).

### B. Primary Balance Card (Hero Component)
*   **Container:** Full-width rounded rectangular card with a solid black background (`#000000`).
*   **Border Radius:** 24px.
*   **Padding:** 20px interior padding.
*   **Content Inside Card:**
    *   **Top Row:** Small label (e.g., "Total Balance") with an eye-toggle icon to hide/show amounts.
    *   **Main Amount:** Large, bold numerical display (`$14,250.80`), 32px font size, white text.
    *   **Action Buttons (Bottom of Card):** Two side-by-side pill-shaped buttons ("Send" / "Receive" or similar financial actions) with semi-transparent dark backgrounds and white text.

### C. Section 1: "Quick Actions" or "Transactions"
*   **Section Header:** Bold title on the left ("Recent Activity"), small "See All" text button on the right in muted gray.
*   **List Items (Rows):**
    *   Each row features an icon/logo container (left), title and subtitle (middle), and amount/status (right).
    *   *Row 1:* Apple Music / Subscription icon, `- $9.99`, timestamp below.
    *   *Row 2:* Spotify / Streaming icon, `- $14.99`.
    *   *Row 3:* Transfer / Arrow icon with status pill ("Pending"), amount right-aligned.
    *   **Dividers:** Subtle 1px light gray separators between list items (`#EFEFEF`).

### D. Section 2: Cards / Wallets Carousel
*   **Section Header:** "My Cards" with a "+" add button on the right.
*   **Card Element:** Horizontal scrolling card preview showing a miniaturized dark debit card graphic with chip and card number ending.

---

## 4. Screen 2: Transaction / Analytics Detail View (Right)

### A. Header Navigation
*   **Top Bar:** Back arrow chevron on the left, centered title ("Analytics" or "Statement"), right action menu (three dots or filter icon).

### B. Summary Metric Card
*   **Container:** White card with a soft drop shadow or clean border.
*   **Data Points:** Dual-metric display comparing incoming vs. outgoing funds over a selected timeframe (e.g., "This Month").

### C. Action Button Banner
*   **Component:** Full-width solid black pill button ("Export Statement" or "Download PDF") centered horizontally with white bold text.

### D. Graph / Chart Area
*   **Visual Element:** Minimalist line or bar chart representation tracking financial flow over time, rendered in thin black strokes with subtle grid lines.

### E. Detailed Itemized List
*   **Rows:** Repeating structured rows containing a category icon, merchant name, category tag, and exact monetary value with proper currency formatting.

---

## 5. Iconography & Asset Descriptions

*   **Icons:** Minimalist, stroke-based vector icons (Lucide/SF Symbols style), consistent 1.5px stroke width, colored in solid black (`#000000`) on light backgrounds and solid white (`#FFFFFF`) inside dark containers.
*   **Avatars / Profile Images:**
    *   **Description:** Circular profile photo placeholder showing a stylized neutral portrait or abstract gradient circle (backgroundless/transparent PNG or SVG vector).
    *   **Placement:** Top-left header of the main screen.
*   **Brand Logos (within transaction lists):**
    *   **Description:** Small, rounded square icons representing third-party services (e.g., music streaming, retail brands). Rendered inside 40x40px containers with light gray background fills and centered vector logos.
