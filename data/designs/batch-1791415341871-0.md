# Design Specification: Islamic App Mobile Screens

## 1. Color Palette

* **Primary Background:** `#0A1128` (Deep Midnight Blue)
* **Secondary Surface:** `#101F42` (Dark Slate Blue)
* **Accent Warm Glow:** `#F59E0B` to `#FCD34D` (Gold / Amber gradient)
* **Card Accents:**
  * Card 1: `#EA580C` to `#F97316` (Deep Orange)
  * Card 2: `#DC2626` to `#EF4444` (Crimson)
  * Card 3: `#2563EB` to `#3B82F6` (Electric Blue)
* **Text Colors:**
  * Primary: `#FFFFFF`
  * Secondary / Muted: `#94A3B8` (Slate 400)
  * Tertiary: `#64748B` (Slate 500)
* **Overlay/Borders:** `rgba(255, 255, 255, 0.1)`

---

## 2. Typography

* **Headings:**
  * **Primary Font:** `Cinzel` (Google Fonts) or `Amiri`
  * **Fallback:** `Trajan Pro`, `Georgia`, `serif`
  * **Specs:** Bold / Semi-bold (600–700), Letter spacing: `+0.05em`
* **Body / Subtitles:**
  * **Primary Font:** `Outfit` or `Plus Jakarta Sans`
  * **Fallback:** `Inter`, `system-ui`, `-apple-system`, `sans-serif`
  * **Specs:** Regular / Medium (400–500), Line height: `1.5`

---

## 3. Screen Specifications

### Screen 1: Onboarding / Home Showcase

* **Status Bar:** Top padding `44px`, translucent background, white system icons.
* **Header:**
  * Left: Action icon (Back or Skip), `24x24px`, white with 80% opacity.
* **Hero Graphic:**
  * Top-right floating 3D Ramadan Fanous (lantern).
  * Radial gradient behind lantern: `radial-gradient(circle, rgba(245,158,11,0.35) 0%, transparent 70%)`.
* **Content Section:**
  * **Heading:** Large high-contrast display text (e.g., "The Holy Quran").
  * **Body:** 3 lines of descriptive text, muted slate color, max-width `80%`.
* **Bottom Feature Cards:**
  * Horizontal flex/scroll container.
  * 3 vertical rounded cards (`border-radius: 16px`).
  * Each card features an inner gradient, subtle drop shadow, and centered icon/feature label.
* **Pagination / Controls:**
  * Horizontal dot indicator (`active: 24px pill`, `inactive: 8px circle`).

---

### Screen 2: Splash / Pattern Screen

* **Background Layer:**
  * Base color: `#070D1E`.
  * Background texture: Repeating Islamic geometric star pattern / arabesque tessellation with `opacity: 0.12` and `blend-mode: overlay`.
* **Center Emblem:**
  * Stylized mosque dome / arched niche outline badge in warm gold/white.
  * Soft golden glow beneath the emblem.
* **Center Typography:**
  * Primary headline: "RAMADAN KAREEM" or Brand Name (All-caps, serif, `28px`, tracking `+0.1em`).
  * Sub-label: Centered descriptive badge or script font.
* **Bottom Action Area:**
  * Rounded pill CTA button: `height: 52px`, `border-radius: 26px`.
  * Style: Glassmorphism / semi-transparent border (`1px solid rgba(255,255,255,0.2)`), inner white text, centered arrow or label.

---

## 4. Layout & Dimensions

* **Viewport:** 100vw × 100vh (Mobile native full screen).
* **Grid Margins:** `24px` horizontal padding.
* **Corner Radii:** Cards `16px`, Buttons `26px` (full pill), Icons `12px`.

---

## 5. Micro-interactions & Animations

* **Ambient Glow:** Lantern light oscillates gently (`opacity: 0.25` to `0.45`, `ease-in-out`, duration `3s`, infinite).
* **Floating Lantern:** Subtle vertical float (`translateY(-6px)` to `translateY(6px)`, duration `4s`, infinite).
* **Screen Transition:** Fade and slide-up transition between Screen 1 and Screen 2 (`duration: 350ms`, `cubic-bezier(0.16, 1, 0.3, 1)`).
* **Button Feedback:** Active scale transform (`scale(0.97)` on press).
