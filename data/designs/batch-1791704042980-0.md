# Design Specification: Dark Luxury Web3/AI Creative Studio Hero Interface

This document provides the exact design system and technical specifications required to reproduce the hero interface as a **full-screen (`100vw × 100vh`), viewport-locked web experience**.

---

## 1. Visual Theme & Aesthetic Direction

*   **Aesthetic Tone:** Hyper-minimalist dark mode, high-contrast editorial typography, liquid-metal/brushed-dark sheen, luxury Web3 & AI studio feel.
*   **Viewport Strategy:** Full-screen edge-to-edge layout (`100vw`, `100vh`, `overflow: hidden`) with balanced negative space framing the central typography.

---

## 2. Color Palette & Lighting Hierarchy

### Primary Colors
*   **Deep Obsidian (Base Surface):** `#0B0C0E` / `rgb(11, 12, 14)`
*   **Vignette & Deep Shadow:** `#050506` / `rgb(5, 5, 6)`
*   **Bright White (Primary Text & Accents):** `#FFFFFF` / `rgb(255, 255, 255)`
*   **Subdued Off-White (Secondary Body & Nav):** `#C8C9CE` / `rgb(200, 201, 206)`
*   **Muted Charcoal/Gray (Tertiary & Borders):** `#4A4C53` / `rgb(74, 76, 83)`
*   **Accent Stroke / Outer Ring:** `rgba(255, 255, 255, 0.18)`

---

## 3. Background Artwork & Lighting Structure

The background is a custom dark metallic/liquid ambient texture featuring subtle directional sheen and a soft top-down diffuse light leak.

### Layer 1: Ambient Mesh Gradient (CSS / Canvas specification)
*   **Base Layer:** Solid `#0B0C0E`.
*   **Top-Center Specular Highlight:** 
    *   Type: Radial gradient / Elliptical spotlight.
    *   Position: `50% 18%` (horizontal center, upper-third).
    *   Size: `80% width`, `55% height`.
    *   Color Stop 0%: `rgba(68, 71, 79, 0.45)`
    *   Color Stop 50%: `rgba(32, 34, 38, 0.25)`
    *   Color Stop 100%: `transparent`
*   **Diagonal Sheen (Liquid Metal Light Leak):**
    *   Type: Soft angled linear gradient running from top-left (`-45deg`).
    *   Stops:
        *   `0%`: `rgba(255, 255, 255, 0.03)`
        *   `40%`: `rgba(255, 255, 255, 0.08)`
        *   `60%`: `rgba(255, 255, 255, 0.02)`
        *   `100%`: `transparent`
*   **Vignette:**
    *   Soft radial edge darkening from outer boundaries:
    *   `radial-gradient(circle at center, transparent 60%, rgba(5, 5, 6, 0.85) 100%)`.

---

## 4. Typography Specifications & Fallbacks

### Typography Stack
1.  **Primary Sans-serif Display & UI Font (Modern Grotesk):**
    *   *Primary:* **PP Neue Montreal** (Medium / Bold) or **Syne** / **Clash Grotesk**.
    *   *Web Font Fallbacks:* **Inter**, **General Sans**, **Helvetica Neue**, **Arial**, **sans-serif**.
2.  **Editorial High-Contrast Serif Font (for "AGENCY"):**
    *   *Primary:* **PP Editorial New** (Regular / Italic-leaning character shapes) or **Ogg**.
    *   *Web Font Fallbacks:* **Cormorant Garamond** (Weight 400/500), **Playfair Display**, **Didot**, **serif**.
3.  **Monospace / Utility Tracking (Badge & Small UI):**
    *   *Primary:* **Geist Mono** or **Space Mono**.
    *   *Fallbacks:* **SF Mono**, **Roboto Mono**, **monospace**.

## 6. Detailed Element Specifications

### 1. Header Navigation Bar
*   **Position:** Fixed / Absolute at top edge (`top: 0; left: 0; width: 100%;`).
*   **Height:** `88px` to `100px`.
*   **Padding:** Horizontal `48px` to `64px` (desktop), vertical `36px`.
*   **Display:** 3-column flex layout (`justify-content: space-between; align-items: center;`).

#### Left Navigation Block
*   **Links:** "About" and "Services".
*   **Style:** Font size `14px` (`0.875rem`), weight `400` / Regular, color `#D1D2D6`, letter-spacing `0.02em`.
*   **Item Spacing:** `28px` gap between links.

#### Center Brand Identifier
*   **Text:** `WEN LAUNCH`
*   **Style:** Uppercase, font size `16px` (`1.0rem`), weight `500` / Medium, color `#FFFFFF`, letter-spacing `0.08em` (`1.28px`), font-family: Primary Sans-serif.

#### Right Navigation Block
*   **Links:** "Cases" and "Contact".
*   **Style:** Font size `14px` (`0.875rem`), weight `400` / Regular, color `#D1D2D6`, letter-spacing `0.02em`.
*   **Item Spacing:** `28px` gap between links.

---

### 2. Side Floating Micro-Elements

#### Left Micro-Copy ("Creative studio")
*   **Position:** Fixed on the left edge, aligned vertically at roughly `42%` from viewport top.
*   **Offset:** `left: 48px` to `64px`.
*   **Text Structure:** 
    *   Line 1: `Creative`
    *   Line 2: `studio`
*   **Style:** Font size `12px` (`0.75rem`), font-family Primary Sans-serif, color `#C8C9CE`, line-height `1.25`, text-align: left, font-weight `400`.

#### Right Action Icon (Diagonal Arrow)
*   **Position:** Fixed on the right edge, aligned vertically at roughly `40%` to `42%` from viewport top.
*   **Offset:** `right: 48px` to `64px`.

*   **Size:** Arrow bounding box `28px × 28px`, stroke thickness approx. `3.5px` to `4px`.

### 3. Center Hero Display Block

*   **Position:** Centered in the viewport (`left: 50%; top: 52%; transform: translate(-50%, -50%);`).
*   **Text Alignment:** Center-aligned main title block with an anchored right-aligned descriptive paragraph.

#### Main Title: Line 1 & Line 2 (Sans-Serif Headline)
*   **Line 1:** `WE ARE`
*   **Line 2:** `FULL–SERVICE` (Note: Connected with a clean En-dash `–`).
*   **Font Family:** Primary Sans-Serif (**PP Neue Montreal** / **Syne** / **Inter**).
*   **Font Size:** Clamp range `clamp(4.5rem, 8vw, 8.5rem)` (approx. `110px` – `136px` on standard desktop).
*   **Font Weight:** `700` (Bold) or `800` (Extra Bold).
*   **Letter Spacing:** `-0.03em` (tight tracking).
*   **Line Height:** `0.92` – `0.95` (tight line collision).
*   **Color:** `#FFFFFF`.
*   **Text Transform:** Uppercase.

#### Main Title: Line 3 (High-Fashion Editorial Serif)
*   **Text:** `AGENCY`
*   **Font Family:** Serif Stack (**PP Editorial New** / **Cormorant Garamond** / **Playfair Display**).
*   **Font Size:** Same scale or slightly larger than Lines 1–2: `clamp(5.0rem, 9vw, 9.5rem)`.
*   **Font Weight:** `400` Regular (with high contrast between thin and thick stems; distinctive flared terminals and elegant curves).
*   **Letter Spacing:** `-0.01em` to `0.00em`.
*   **Line Height:** `0.95`.
*   **Color:** `#FFFFFF`.
*   **Text Transform:** Uppercase.

### 5. Bottom Interactive Scroll Indicator

*   **Position:** Bottom center (`bottom: 36px` to `48px`, `left: 50%; transform: translateX(-50%);`).
*   **Dimensions:** Circular container diameter `68px` to `74px`.
*   **Visual Structure:**

#### Central Disc & Arrow
*   **Inner Circle Background:** `rgba(255, 255, 255, 0.04)` with a subtle radial gradient.

*   **Center Icon:** Clean downward arrow (`↓`).

## 7. Interactive Behaviors & States

1.  **Header Navigation Links:**
    *   Default: `#C8C9CE`.
    *   Hover: `#FFFFFF` with subtle underline or opacity transition (`transition: color 250ms ease`).
2.  **Top-Right Arrow Link:**
    *   Default: Scale `1.0`, opacity `0.9`.
    *   Hover: Scale `1.15`, translate `(2px, -2px)`, opacity `1.0`.
3.  **Scroll Indicator Badge:**
    *   Default: Outer ring rotates continuously at `16s` per cycle.
    *   Hover: Center arrow bounces down subtly (`translateY(3px)`), rotation speed decelerates or inner disc brightens to `rgba(255, 255, 255, 0.12)`.
4.  **Cursor:** Custom sleek white dot (`6px`) with outer trailing circle (`32px`, `1px` translucent border) to reinforce agency feel.
