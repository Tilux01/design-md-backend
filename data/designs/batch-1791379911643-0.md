# UI/UX Specification & Design System: "Quiet Caves" (Soulful Minimalist Web Experience)

This document provides the exact architectural, design, and interactive specifications required to clone the "Quiet Caves" website shown in the media. 

---

## 1. Global Layout & Canvas Specifications
- **Display Mode:** Full-screen responsive (Desktop-first showcase: optimized for `1440px` viewports).
- **Aspect Ratio:** Fluid grid system scaling smoothly from `1200px` to `1920px` max-widths.
- **Background Color (`--bg-primary`):** Warm, aged parchment / antique cream (`#F3EFE6` or `#F5F2EA`). It should feature a very subtle, low-opacity paper grain texture overlay (`opacity: 0.03`).
- **Primary Typography Color (`--text-primary`):** Deep charcoal / muted black (`#1A1A1A`).
- **Accent Color (`--accent-rust`):** Terracotta / Japanese ink-wash red (`#B84A39`) used sparingly for emotional focal points.

---

## 2. Typography System & Fallbacks

The aesthetic relies entirely on the juxtaposition of a high-contrast classic serif and clean minimalist sans-serif.

### A. Display / Serif Font (Headings, Philosophy, Logo)
- **Primary Font Family:** `Cormorant Garamond`, `Playfair Display`, or `Bodoni Moda` (Weights: Light 300, Regular 400, Italic).
- **Fallback Stack:** `Georgia`, `Cambria`, `Times New Roman`, `serif`.
- **Usage:** Main headline ("Not every journey needs a destination."), site logo ("QUIET CAVES"), navigation links, and chapter numbers (`01`, `02`, etc.).

### B. Body / Sans-Serif Font (Subtitles, Micro-copy, Navigation)
- **Primary Font Family:** `Plus Jakarta Sans`, `Inter`, or `Outfit` (Weights: Light 300, Regular 400).
- **Fallback Stack:** `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `sans-serif`.
- **Usage:** Subtitle text ("Some paths are meant to be felt, not found."), footer micro-copy, and structural tags (`HOME`, `CHAPTERS`, `ABOUT`).

---

## 3. Structural Breakdown & Component Specs

### A. Header Navigation Bar (`<header>`)
- **Positioning:** Fixed or Absolute top, padded with generous white space (`40px` top/sides).
- **Left Element (Logo):** 
  - Icon: Minimalist line-art vector depicting a Japanese temple gate (Torii/Pagoda roof style).
  - Text: "QUIET CAVES" in spaced-out uppercase serif (Tracking/Letter-spacing: `2px`). Font size: `12px`.
- **Center Element (Nav Links):**
  - Links: `HOME`, `CHAPTERS`, `ABOUT`.
  - Styling: Uppercase sans-serif, `11px`, tracking `3px`, opacity `0.7` with hover transition to `1.0`.
- **Right Element (Menu):**
  - Text: `MENU =` (hamburger icon equivalent using typographic equals sign or dual horizontal lines). Font size: `11px`, letter-spacing `2px`.

---

### B. Hero Section (`<main>` / Hero Area)

#### Left Column: Editorial Content
- **Accent Line:** A short horizontal stroke in `--accent-rust` (`width: 24px`, `height: 2px`).
- **Main Headline:** 
  - Text: *"Not every journey needs a destination."*
  - Font: Serif Italic / Regular mix. 
  - Size: `48px` to `56px` clamp scale. Line-height: `1.1`.
- **Subtitle Paragraph:**
  - Text: *"Some paths are meant to be felt, not found."*
  - Font: Sans-serif Light, muted tone (`#666666`). Size: `14px`. Line-height: `1.6`.
- **Call-to-Action (CTA):**
  - Text: `— BEGIN AGAIN` (preceded by a directional dash).
  - Styling: Uppercase, tracking `2px`, font size `12px`, interactive hover underline slide-in animation.

#### Right Column: Visual Art Installation (The Scroll/Gate)
- **Visual Subject:** A traditional East Asian architectural stone gate (Torii style) with a large vertical scroll displaying traditional calligraphy text.
- **Surrounding Elements:** 
  - A minimalist bonsai/pine tree silhouette on the right side of the gate, growing out of a stone base.
  - A subtle flock of tiny ink-wash birds flying in the upper right sky.
- **Composition:** Positioned off-center with soft drop shadows and an atmospheric fading gradient that blends the image edges seamlessly into the `--bg-primary` parchment background.

---

### C. Footer / Carousel Pagination Bar
- **Pagination Track (`01` to `07`):**
  - Numbers displayed horizontally near the bottom left: `01` `02` `03` `04` `05` `06` `07`.
  - Active State (`01`): Highlighted with a small horizontal underline dash beneath it (`--accent-rust`). Inactive numbers are styled in muted grey with `0.5` opacity.
- **Bottom Right Meta-Text:**
  - Text: `MOVE GENTLY, LEAVE A LITTLE WIND` (rendered in lowercase tracking or sentence case).
  - Accompanying a minimalist circular outline icon (`O`).

---

## 4. Animation & Interaction Specifications (The "Soul")

To achieve the "website with a soul" feeling, interactions must be organic, slow, and intentional (no snappy or robotic transitions).

1. **Page Load / Entry Animation:**
   - **Fading In:** The parchment background loads instantly, followed by a staggered CSS opacity fade-in (`duration: 1.2s`, `easing: cubic-bezier(0.16, 1, 0.3, 1)`):
     1. Navigation bar slides down slightly from `-10px`.
     2. Hero text blocks fade up from `+20px`.
     3. The architectural gate illustration unmasks with a subtle scale effect (`0.98` to `1.0`).
2. **Parallax & Mouse Move (Ambient Depth):**
   - The background elements (birds, ink marks, and shadows) should subtly shift opposite to the user's cursor movement using a lightweight vanilla JavaScript mousemove listener (`transform: translate(x * 0.01px, y * 0.01px)`).
3. **Interactive Hover States:**
   - **Nav Links:** Smooth color shift from `#666` to `#1A1A1A` with an animated bottom border expanding from left to right.
   - **Chapter Pagination:** Clicking numbers `01–07` triggers a cross-fade transition of the main editorial content, mimicking turning the page of an ancient book.
4. **Sound Design (Optional Soul Feature):**
   - Soft, ambient audio toggle option (subtle wind chime or autumn leaf rustle when interacting with the main CTA).
