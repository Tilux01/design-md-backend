# Website Design Specification: HOODIE E-Commerce Store

---

## 1. Global Styles & Design System

### 1.1 Color Palette
* **Primary Dark / Text:** `#1A1A1A` (Deep charcoal, nearly black)
* **Background / Canvas:** `#FFFFFF` (Pure white)
* **Off-White / Neutral Light:** `#F5F5F5` (Used for section backgrounds, product cards, cards sidebar)
* **Muted Gray:** `#8C8C8C` (Secondary text, borders, star ratings, subtitles)
* **Accent/Border Line:** `#E5E5E5` (Light structural divider lines)

### 1.2 Typography
* **Font Family:** Inter, system-ui, -apple-system, sans-serif
* **Brand/Logo Typography:** Ultra-bold, heavy-weight geometric sans-serif (All-caps `HOODIE`)
* **Scale:**
  * **Hero Header Logo:** `28px`, Bold, Spaced
  * **Hero Title (`HOODIE`):** `120px`+, Extra Bold, Monospaced block styling
  * **Section Headings:** `18px`, Bold, Uppercase
  * **Body Copy / Descriptions:** `14px` / `13px`, Regular
  * **Price / Subtitles:** `13px`, Medium/Bold

---

## 2. Layout Structure & Grid Architecture

* **Max Page Width:** `1280px` centered canvas with a full-bleed background.
* **Layout Split:** 
  * **Main Content Area (Left):** ~`70%` width.
  * **Sidebar Area (Right):** ~`30%` width, spanning vertically with sticky/stacked promotional cards, value props, testimonials, and newsletter signups.
* **Padding/Gutters:** `24px` horizontal padding inside containers, `40px` vertical spacing between major sections.

---

## 3. Header & Navigation

### 3.1 Top Bar
* **Left:** 
  * Menu hamburger icon (`☰`)
  * Dropdown menus with down-arrows: `CATEGORIES` ▾, `NEW ARRIVALS` ▾
  * Search bar with search icon (`🔍`): Placeholder `"SEARCH..."` inside a pill/rounded outline box (`#E5E5E5` border).
* **Center:**
  * Brand Logo: `HOODIE` (Centered horizontally in header bar, bold tracking).
* **Right:**
  * Navigation links: `MEN`, `WOMEN`, `CHILDREN`, `PREMIUM`
  * Icon buttons: User Account profile icon (`👤`), Shopping Cart icon with item count badge (`🛒`)

---

## 4. Main Content Area

### 4.1 Hero Section
* **Tagline:** Small centered uppercase text above the title: `"THE BEST HOODIES ARE ONLY HERE"` (`11px`, bold, `#666`).

* **Hero Image Showcase:**

  * Overlay UI element bottom-left: White rectangular badge with text `"SWIPE"` + directional arrow `→`, and button `"DISCOVER NOW"`.
* **Social Proof Ticker / Footer Links:** Centered underneath hero banner: `INSTAGRAM`, `TELEGRAM`, `FACEBOOK`, `TWITTER`.

### 4.2 Shop By Collection
* **Section Header:** Left-aligned `"SHOP BY COLLECTION"` with a right-aligned `"VIEW ALL →"` link.
* **Layout:** 4-column grid of collection cards with off-white backgrounds (`#F5F5F5`).
* **Card Items:**
  1. **OVERSIZED:** Model in black oversized hoodie. Link: `"SHOP NOW →"`
  2. **ESSENTIALS:** Model in beige essentials hoodie. Link: `"SHOP NOW →"`
  3. **PREMIUM:** Model in dark charcoal premium hoodie. Link: `"SHOP NOW →"`
  4. **KIDS:** Model in kids beige hoodie. Link: `"SHOP NOW →"`

### 4.3 Best Sellers
* **Section Header:** Left-aligned `"BEST SELLERS"` with a right-aligned `"VIEW ALL →"` link.
* **Layout:** 4-column grid displaying product cards with clean minimalist frames.
* **Product Card Content:**
  * Product thumbnail image (clean isolated garment shots on light gray background).
  * Product Title (e.g., `ESSENTIAL HOODIE`, `URBAN HOODIE`, `CLASSIC HOODIE`, `COMFORT HOODIE`).
  * Price (e.g., `$59.00`, `$64.00`, `$55.00`, `$62.00`).
  * Rating badge on the bottom right (e.g., `4.8 ★`, `4.9 ★`).

### 4.4 Repeating Text Ticker Bar
* **Content:** Continuous looping uppercase marquee text: `"THE BEST HOODIES CLOTHING 2024 THE BEST HOODIES CLOTHING 2024..."` in a muted thin horizontal rule band.

### 5.1 New Collection Promo Card

  * Subtitle: `"NEW COLLECTION"`

  * CTA Button: `"SHOP NOW"` (Solid white pill button with dark text).

* **Layout:** Multi-column structured footer with a top brand logo and bottom legal line.
* **Columns:**
  1. **Brand Column:** `HOODIE` logo + brief descriptor (`"Minimal design. Maximum comfort. Worldwide shipping."`) + Social media icon links (`Instagram`, `Telegram`, `Facebook`, `Twitter`).
  2. **SHOP:** Links (`All Products`, `New Arrivals`, `Best Sellers`, `Sale`).

  * Copyright text: `© 2024 Hoodie. All rights reserved.`
