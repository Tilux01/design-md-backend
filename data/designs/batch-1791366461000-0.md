# Design Specification: Creative Agency Website

This document outlines the exact design specifications for creating a pixel-perfect, full-screen clone of the provided website interface.

---

## 1. Global Styles & Variables

### Color Palette
*   **Primary Background:** `#EAEAEA` (Off-white/light gray)
*   **Secondary Background (Outer Canvas):** `#1F7A8C` (Teal) — *Note: The main UI card sits centered on this teal background.*
*   **Accent Color (Hand/Graphic):** `#11707F` (Deep Teal / Cyan)
*   **Liquid/Drip Element:** `#FFFFFF` (Pure White with subtle drop shadows)
*   **Text Color (Dark):** `#1A1A1A` (Near Black)
*   **Text Color (Muted/Secondary):** `#7A7A7A` (Medium Gray)
*   **Typography Color (Outline Text):** `#FFFFFF` with drop shadow / inner shadow effect.

### Typography
*   **Font Family:** Inter, sans-serif (or system default modern sans-serif like Helvetica Neue).
*   **Navigation Menu:** Uppercase, 11px, Medium weight, letter-spacing: `1.5px`.
*   **Main Hero Typography ("CREATIVE"):** Extra bold, uppercase, hollow outline text with heavy depth effect, approx. 140px font size.
*   **Body / Call-to-Action Headings:** 24px, Bold (`We create beautiful things for you`).
*   **Small Captions / Labels:** 10px, uppercase, letter-spacing: `1px` (`LATEST PROJECT`, `CREATIVE AGENCY`, `LEARN MORE`).

---

## 2. Layout & Structure

*   **Viewport:** Fullscreen responsive layout (`100vw` / `100vh`).
*   **Main Container:** Centered white content card taking up approximately `85%` to `90%` of the viewport width and height, sitting on top of the dark teal background.

---

## 3. Header / Navigation Bar

*   **Position:** Absolute / Sticky at the top of the main white card, aligned with generous padding (approx. `40px` from edges).
*   **Left Navigation Links:**
    *   `HOME` (Active / Bold)
    *   `ABOUT`
    *   `PORTFOLIO`
    *   `CONTACT`
    *   *Spacing:* `35px` between items.
*   **Right Navigation Controls:**
    *   **Page Indicator:** `01 / 03`
    *   **Search Icon:** Magnifying glass symbol.
    *   **Menu Hamburger Icon:** Three horizontal lines.
    *   *Spacing:* `30px` between control items.

---

## 4. Hero Section & Core Visuals

### Central Graphic (The Hand & Liquid)
*   **Visual Element:** A surreal 3D rendered cyan-colored hand breaking through the white background surface, overlaid with dripping white liquid/paint.
*   **Positioning:** Centered slightly offset to the right.
*   **Depth & Layering:**
    *   Hollow outline background text `"CREATIVE"` sits behind the hand.
    *   The hand appears to emerge from a tear or peel in the white surface.

### Left Side Content Elements
*   **Vertical Label (Top Left):** `LATEST PROJECT` rotated 90 degrees (vertical text style).
*   **Action Label (Bottom Left):** `LEARN MORE` with a small vertical indicator line above it.
*   **Main Hero Heading:**
    *   "We create beautiful things for you"
    *   Font Size: `24px`
    *   Weight: Bold
    *   Color: `#1A1A1A`
*   **Sub-text / Year:** `2018` (Placed beneath the heading).

### Right Side Content Elements
*   **Agency Label:** `CREATIVE AGENCY` with a leader line pointing toward the hand graphic.
*   **Social Media Icons:** Vertical stack on the right edge (`Pinterest`, `Twitter`, `Facebook` or similar minimalist icon set).
*   **Video Widget (Bottom Right):**
    *   Thumbnail preview box showing a person with a play button overlay (`watch video`).
    *   Rounded corners, subtle drop shadow.

---

## 5. Footer / Page Indicators

*   **Scroll Indicator:** A centered downward chevron (`v`) at the bottom middle of the interface to prompt scrolling.
