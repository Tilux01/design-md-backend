# Design Specification (`design.md`)

## 1. Overview & Viewport
* **Layout**: Full-screen mobile onboarding flow (100vw, 100vh).
* **Base Viewport**: 390px × 844px (scalable, centered on desktop screens).
* **Theme**: Playful, warm, modern neo-brutalist / soft-pop UI.

---

## 2. Color Palette
* **Screen Background**: `#FAF7F0` (Warm Cream / Ivory)
* **Text Primary**: `#181A1B` (Deep Charcoal)
* **Text Secondary**: `#6D7278` (Muted Slate)
* **Card Surface**: `#FFFFFF`
* **Card Border**: `1.5px solid #EBE7DF`
* **Card Active/Hover**: `#F4EFE6`
* **Accent Highlights**:
  * Orange/Coral: `#FF6B4A`
  * Sunny Yellow: `#FFCE38`
  * Lavender: `#C6B5F7`
  * Soft Blue: `#A8D0E6`

---

## 3. Typography
* **Primary Font**: `Plus Jakarta Sans` or `Inter`
* **Fallback Stack**: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
* **Type Hierarchy**:
  * **Header**: Bold (700), `26px / 32px`, tracking `-0.02em`.
  * **Badge / Label**: Medium (500), `13px / 16px`, tracking `0em`.
  * **Card Text**: Semi-Bold (600), `15px / 20px`, tracking `-0.01em`.

---

## 4. Layout Structure

### Header Section
* **Padding**: Top `48px`, Horizontal `24px`.
* **Content**: `"Welcome! Let's get to it."`
* **Alignment**: Left-aligned, dark charcoal.

### Hero Media (Center)
* **Dimensions**: Max width `280px`, height `220px`.
* **Content**: Centered stylized 3D/vector sneaker/character graphic with accent color patches and ambient micro-shapes (clouds, bursts).
* **Position**: Margin `20px auto 32px auto`.

### Interactive Options Container
* **Padding**: Horizontal `20px`, bottom `32px`.
* **Subheader Pill**:
  * Style: Centered pill shape, border `1px solid #E5E1D8`, background `#FAF7F0`.
  * Content: `"Choose an option to continue"` (or equivalent onboarding prompt).
  * Padding: `8px 16px`.
* **Option Cards (3 Total)**:
  * Layout: Vertical flex stack, `12px` gap.
  * Structure: Flex row, full width.
  * Dimensions: Min-height `56px`, border radius `16px`.
  * Style: `#FFFFFF` fill, `1.5px solid #E5E1D8` border, soft shadow `0 2px 4px rgba(0,0,0,0.03)`.
  * **Elements**:
    * Leading Badge: Circular/rounded square icon container (`36px × 36px`), neutral fill (`#F2EFE9`).
    * Label: Option title centered or left-aligned next to badge.

---

## 5. Micro-Interactions & Animation
* **Initial Load**:
  * Header & Illustration: Fade-in + slight slide-down (`300ms ease-out`).
  * Option Cards: Staggered slide-up (`40ms` delay between items, `400ms cubic-bezier(0.16, 1, 0.3, 1)`).
* **Hero Graphic**: Gentle floating animation (translateY: `0px` to `-6px`, duration `3s`, infinite alternate ease-in-out).
* **Card Interactions**:
  * Hover/Focus: Border shifts to `#181A1B`, slight lift (`translateY(-2px)`).
  * Active/Tap: Scale down (`scale(0.98)`), background shifts to `#F8F6F0`.
