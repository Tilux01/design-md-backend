# Visual Design Specification: E-Commerce Product Slider UI

## 1. Global Styles & Reset
- **Viewport:** 100vw, 100vh (Full Screen)
- **Background:** Linear gradient transitioning from dark purple-blue (`#1a1f3c`) on the left to vibrant cyan-blue (`#2386a8`) on the right.
- **Font Family:** Inter / Sans-serif geometric typefaces.
- **Base Color Palette:**
  - Primary Background: `#1e2640` to `#2488a7`
  - Text Primary: `#ffffff`
  - Text Secondary/Muted: `rgba(255, 255, 255, 0.6)`
  - Accent/Highlight: Cyan glow (`#4deeea`) on product and specific typography elements.

---

## 2. Header / Navigation Bar (`position: fixed` or `absolute`, top alignment)
- **Layout:** Flexbox, space-between, full width with horizontal padding (`40px`).
- **Left Element (Logo):**
  - Text: `FLOAT`
  - Font Weight: Bold (700)
  - Letter Spacing: `2px`
  - Font Size: `14px`
- **Center Element (Subtitle):**
  - Text: `WOOCOMMERCE PRODUCT SLIDER`
  - Font Size: `10px`
  - Letter Spacing: `1px`
  - Color: `rgba(255, 255, 255, 0.5)`
- **Right Elements (Socials & Cart):**
  - Social Icons (Facebook, Twitter, Instagram): Minimalist white outline icons, small size (`12px` height).
  - Cart: `CART (0)`
    - Font Size: `11px`
    - Letter Spacing: `1px`

---

## 3. Hero Section & Product Display

### A. Navigation Arrows (Left & Right)
- **Left Arrow:**
  - Position: Absolute, vertical center, aligned to the left margin (`40px`).
  - Graphic: Thin white left-facing arrow (`←`) inside a subtle circular border outline (`1px solid rgba(255, 255, 255, 0.15)`).
- **Right Arrow:**
  - Position: Absolute, vertical center, aligned to the right margin (`40px`).
  - Graphic: Thin white right-facing arrow (`→`).

### B. Product Imagery (Center)
- **Subject:** Futuristic sci-fi style high-top sneaker/shoe floating at an angled perspective.
- **Lighting & Color:** Dark metallic/carbon texture with vibrant cyan/blue glowing under-sole and purple accents.
- **Shadow:** Soft, diffused dark drop shadow directly underneath the floating shoe to create depth (`blur: 30px`, opacity: `0.4`).

### C. Typography Overlay (`SHISHIDO`)
- **Text:** `SHISHIDO`
- **Position:** Centered horizontally, layered directly over the center of the sneaker.
- **Styling:**
  - Font Size: Large display scale (`clamp(48px, 6vw, 84px)`).
  - Font Weight: Extra Bold (800).
  - Letter Spacing: `4px`.
  - Color: Solid white with a semi-transparent outline/blend effect where it intersects the shoe body.

---

## 4. Product Details & Footer Area (Bottom alignment)

### A. Price & Rating (Bottom Left)
- **Price:**
  - Text: `$749`
  - Font Size: `20px`
  - Font Weight: Bold (600)
- **Rating:**
  - Stars: 5 filled white stars (`★★★★★`)
  - Size: `10px`
  - Spacing: Tight gap between stars.

### B. Description (Bottom Left, below Price)
- **Text:** `A WooCommerce product gallery slider for Slider Revolution with mind-blowing visuals.`
- **Font Size:** `11px`
- **Line Height:** `1.5`
- **Color:** `rgba(255, 255, 255, 0.6)`
- **Max Width:** `320px`

### C. Call to Action Button (Bottom Right)
- **Text:** `BUY NOW`
- **Styling:**
  - Padding: `10px 24px`
  - Border: `1px solid rgba(255, 255, 255, 0.3)`
  - Background: Transparent (`rgba(0, 0, 0, 0.1)` on hover)
  - Font Size: `11px`
  - Letter Spacing: `1.5px`
  - Font Weight: Bold (600)
  - Cursor: Pointer
