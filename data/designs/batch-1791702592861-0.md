# `design.md` — Zenrixa Creative Agency Landing Page Specification

## 1. Canvas & Viewport Architecture

*   **Mode:** Full-Screen Display (No device mockups, browser frames, borders, or drop shadows around the viewport).
*   **Viewport Dimensions:** 100vw × 100vh (Dynamic height adjustments for desktop displays; pinned aspect ratio layout).
*   **Grid System:** 12-Column CSS Grid / Flexbox layout with `padding: 32px 48px`.
*   **Canvas Background:** Smooth light grey gradient background.
    *   *Base Background Color:* `#E5E6E8`
    *   *Ambient Radial Glow:* `#F7F7F8` centered behind the main model silhouette (`50% 40%`) to create depth behind the central image.

## 4. Image Asset Specifications

### A. Central Visual Asset (Human Silhouette with Smart Goggles)

*   **Format:** Transparent PNG or WebP (Background must be completely removed/transparent).
*   **Dimensions/Aspect Ratio:** Vertical portrait (approx. 3:4 ratio).
*   **Subject Description:**
    *   Frontal studio portrait shot from mid-chest up of an athletic male model with short cropped hair.
    *   **Lighting Style:** Dark, dramatic silhouette / chiaroscuro effect. Features on the face and neck are rendered in deep shadow/black with soft rim light highlighting the contours of the collarbones, neck, and ears.
    *   **Eyewear:** Large wraparound futuristic smart goggles with translucent bright amber/orange lenses. A small illuminated horizontal orange light strip sits directly at the bridge of the goggles.
*   **Placement & Scale:**
    *   Centered horizontally (`left: 50%`, `transform: translateX(-50%)`).
    *   Bottom edge aligned to the bottom of the viewport (`bottom: 0`).
    *   Height relative to viewport: approximately `85vh` tall.
*   **Rotation:** `0deg` (Straight front-facing view).

## 6. Micro-Interactions & States

1.  **Header Navigation Links:** Hover state transitions color from `#6E7072` to `#121212` with a `200ms ease` animation.
2.  **Primary Button ("Chat With Us"):** On hover, scale transform `1.02`, and the arrow circle icon inside slides `2px` to the right.
3.  **Bottom Dock:** Subtle backdrop blur adjustment on scroll (`backdrop-filter: blur(24px)`).
4.  **Smart Goggles Glow Effect:** Small pulsing orange box-shadow/drop-shadow glow around the goggle lens element to simulate digital illumination (`filter: drop-shadow(0 0 12px rgba(255, 82, 0, 0.6))`).
