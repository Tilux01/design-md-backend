# Design Specification: Medical Dashboard UI ("Med Care")

This document provides a comprehensive design specification for cloning the "Med Care" medical dashboard interface shown in the image. The layout is designed to be rendered in **full screen**, omitting the outer device frame (shadow, rounded bezel, and background gradient). 

---

## 1. Global Styles & Theme

### Color Palette
*   **Background (App Canvas):** `#161a25` (Very dark slate/navy)
*   **Cards/Containers:** `#1e2333` (Slightly lighter slate for module backgrounds)
*   **Sidebar & Accents:** `#3b5ef2` (Vibrant medical blue)
*   **Primary Text:** `#ffffff` (Pure white)
*   **Secondary Text / Muted Labels:** `#7b849b` (Slate gray)
*   **Borders / Dividers:** `#283046` (Dark border lines separating sections)
*   **Status Indicators & Graphs:**
    *   Pink/Magenta (Offline work line, My Plans pink bar): `#e056fd`
    *   Teal/Mint (Online work line, progress bars): `#00d2d3`
    *   Orange/Yellow (Busyness chart segment): `#feca57`
    *   Purple (Busyness chart segment): `#5f27cd`

### Typography
*   **Primary Font Family:** `Inter`, `Roboto`, or system-ui sans-serif as fallbacks.
    *   *Fallback chain:* `font-family: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;`
*   **Font Weights Used:** Regular (400), Medium (500), Semi-bold (600), Bold (700).

---

## 2. Layout Structure (CSS Grid / Flexbox)

The layout is divided into a **Main Sidebar** on the far left, a **Top Navigation Bar**, and a **Multi-column Dashboard Grid** occupying the rest of the screen.

```
+-------------------------------------------------------------------------------------------------+
| SIDEBAR | TOP NAV BAR (Search, Icons)                                                           |
| (Icons) +---------------------------------------------------------+-----------------------------+
|         | BANNER (Good Day, Dr. Nicholls! + Illustration)         | MY PROFILE CARD             |
|         +---------------------------------+-----------------------+-----------------------------+
|         | OFFLINE | ONLINE | LAB WORK     | MY PLANS DONE         | MY CALENDAR (Mini)          |
|         +---------------------------------+-----------------------+-----------------------------+
|         | MY SCHEDULED EVENTS             | (Plans continued)     | CALENDAR SCHEDULE (April 13)|
|         | (Busyness Ring + Counters)      |                       |                             |
+-------------------------------------------------------------------------------------------------+
```

---

## 3. Component Breakdown

### A. Sidebar (Left-most Column)
*   **Logo/Brand:** Top text "Med care" in bold white, vertical orientation or stacked ("Med" over "care" with blue background pill).
*   **Navigation Icons:** Vertical stack of rounded button icons (Home, Analytics, Messages/Send, Calendar, Grid, Settings, Logout at bottom).
    *   *Active state:* Home icon has a lighter blue pill background (`#3b5ef2`).

### B. Top Navigation Bar
*   **Search Input:** Dark rounded search bar on the left with placeholder text: *"Search for events, patients etc."* and a magnifying glass icon.
*   **Utility Icons:** Notification bell and Add (`+`) button on the right side.

### C. Banner Section ("Good Day, Dr. Nicholls!")
*   **Background:** Gradient banner ranging from medium blue (`#2952db`) to lighter electric blue (`#4b72ff`).
*   **Date/Time Badge:** Top-left pill reading `📅 Apr 13, 2021  2:12 pm`.
*   **Text Content:** 
    *   Heading: "Good Day, Dr. Nicholls!" (Bold, ~24px).
    *   Subtext: "Have a Nice Monday!" (Muted light blue).
*   **Illustration (Right side):** A friendly male doctor in a white medical coat and stethoscope smiling, surrounded by floating medical icon assets (pills, capsules, dropper, clipboard, cup).

### D. Profile Card ("My Profile")
*   **Header:** Title "MY PROFILE" with an edit pencil icon in the top right.
*   **Avatar:** Circular photo of a female doctor (Dr. Alisha Nicholls) with dark hair wearing a white coat and stethoscope.
*   **Details:**
    *   Name: Dr. Alisha Nicholls (Bold)
    *   Role: DERMATOLOGIST (Uppercase, smaller muted text)
    *   Location: 📍 Bottrop, Germany
*   **Footer Stats:** 
    *   Date Birth: `17.07.86`
    *   Blood: `A(II) Rh+`
    *   Working Hours: `9pm - 5am`

### E. Metric Cards Row (Offline Work, Online Work, Laboratory Work)
1.  **Offline Work:**
    *   Header: "OFFLINE WORK" with a menu dots icon (`...`).
    *   Value: `27` (Large bold text) with label "hospital patients".
    *   Trend line/Graph: A downward trending spline chart in pink.
    *   Subtext: `-6% than average` (in red/pink).
2.  **Online Work:**
    *   Header: "ONLINE WORK".
    *   Value: `9` with label "online consultations".
    *   Trend line/Graph: An upward trending green/teal line chart.
    *   Subtext: `+2% than average` (in green/teal).
3.  **Laboratory Work:**
    *   Header: "LABORATORY WORK".
    *   Value: `19` with label "laboratory analysis".
    *   Progress/Trend line: A straight horizontal teal line.
    *   Subtext: `-3% than average`.

### F. Scheduled Events & Busyness Module ("My Scheduled Events")
*   **Header:** "MY SCHEDULED EVENTS" with a "Today" dropdown button.
*   **Visual Chart:** A large circular percentage ring chart labeled **"95% BUSYNESS"** with multi-colored segments (purple, orange, pink).
*   **Metrics List:**
    *   `2` Consultations
    *   `10` Laboratory analyzes
    *   `3` Meetings

### G. Plans Done Module ("My Plans Done")
*   **Header:** "MY PLANS DONE" with a "Today" dropdown.
*   **Progress Bars:**
    *   Consultation: Progress bar filled to ~64% (Purple/Blue).
    *   Analysis: Progress bar filled to ~50% (Pink).
    *   Meetings: Progress bar filled to ~33% (Teal).
*   **Action:** Bottom button labeled `+ Add plan`.

### H. Calendar & Daily Schedule Column
1.  **Mini Calendar Widget ("My Calendar"):**
    *   Header: "MY CALENDAR" with month selector dropdown ("April").
    *   Days Bar: Sun, Mon, Tue, Wed, Thu, Fri, Sat.
