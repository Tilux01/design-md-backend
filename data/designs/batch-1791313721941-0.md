# 1. Design Philosophy & Overall Aesthetic
- **Primary Mood:** Calming, clinical yet approachable, trustworthy, and modern health-tech.
- **Brand Archetype:** Caregiver / Creator. Balanced mix of medical authority and friendly consumer mobile wellness.
- **Visual Density:** Medium-high, cleanly compartmentalized into floating cards, rounded pills, and layered glassmorphism panels.
- **Whitespace Balance:** Generous outer padding (16px–24px mobile frame gutters), dense internal spacing inside cards (12px–16px) for efficiency.
- **Theme Balance:** Predominantly light-surface mobile apps layered over deep teal/emerald brand gradients (`#0B4F5C` to `#127A8C`). Features frosted glass surfaces (`backdrop-filter: blur`) and deep oceanic dark UI contexts for specialized mapping/radar views.

# 2. Color Palette & Design Tokens

## Color Swatch Analysis
- **Primary / Brand:** Deep Teal / Ocean (`#0B4F5C` to `#157F8F`)
- **Secondary / Interactive (Teal Green):** `#148580` / `#0D7C75` (Buttons, active states, active tab highlights)
- **Accent (Amber/Gold):** `#F39C12` / `#F1C40F` (Star ratings, notifications, badges)
- **Base Background:** Soft Off-White / Pale Cyan Tint (`#F4F8F9`)
- **Surface / Card Backgrounds:** Pure White (`#FFFFFF`) with 85% opacity, and semi-translucent frosted glass (`rgba(255, 255, 255, 0.85)` / `rgba(255, 255, 255, 0.12)`)
- **Border & Divider:** Subtle Gray-Cyan (`#E2ECEE`), Inner stroke highlights (`rgba(255, 255, 255, 0.4)`)
- **Text Primary:** Deep Slate / Charcoal (`#102A38`)
- **Text Muted:** Slate Gray (`#627D98`)
- **Text Inverse:** Pure White (`#FFFFFF`)

# 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** Mobile viewport frames (`390px` to `430px` standard mobile width simulation).
- **Padding & Margin Scale:** 
  - Outer screen padding: `20px` horizontal, `24px` vertical.
  - Inter-component spacing: `16px` vertical gaps.
  - Internal card padding: `16px` to `20px`.
- **Section Sequence Breakdown (Dashboard Screen):**
  1. Top Status & Header Navigation (Avatar, Search icon, Notification bell).
  2. Greeting & Secondary Title ("Good afternoon, What's on your health today?").
  3. Next Appointment Floating Card (Doctor metadata, Reschedule/Join Call buttons).
  4. Horizontal Scroll Category Filters (Bone, Brain expert, Dental, Digestion).
  5. "Find a Doctor" Section Header + "View All" link.
  6. Horizontal Doctor Cards Carousel (Star rating, photo, name, specialty, pricing).
  7. Bottom Navigation Dock (Calendar, Home/Dashboard, Settings).
- **Stacking Order (Z-Index):**
  - Base Background: `z-0`
  - Content Flow: `z-10`
  - Floating Action Cards / Modals: `z-20`
  - Bottom Sticky Dock / Navigation Bars: `z-30`

# 7. Accessibility (a11y) & WCAG Contrast Audit

- **Contrast Ratio Audit:**
  - Primary text (`#102A38`) on White/Glass surfaces (`#FFFFFF`): **14.2:1** (Passes WCAG AAA)
  - Muted text (`#627D98`) on White background (`#FFFFFF`): **4.6:1** (Passes WCAG AA)
  - Button text (White `#FFFFFF`) on Primary Teal (`#148580`): **4.8:1** (Passes WCAG AA)
  - Star Rating Text / Gold (`#F5A623`) on light surface requires bolding or dark backdrop for compliance.
- **Keyboard Focus Ring Specification:**
  ```css
  :focus-visible {
    outline: 2px solid #148580;
    outline-offset: 3px;
    box-shadow: 0 0 0 4px rgba(20, 133, 128, 0.2);
  }
  ```
