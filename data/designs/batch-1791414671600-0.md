# Design System & Specification: Thermos Product Page

## 1. Typography

* **Primary Font:** `Plus Jakarta Sans` or `Inter`
* **Fallback Fonts:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
* **Styles & Hierarchy:**
  * **Product Title:** 20px / Semi-Bold (600) / `#1E242B` / Line-height: 1.3
  * **Price:** 22px / Bold (700) / `#1E242B`
  * **Section/Rating Text:** 12px / Medium (500) / `#1E242B`

  * **Badges & Labels:** 10px–11px / Medium (500) / `#5A6777`

## 4. Component Specifications

### 4.1 Header Bar
* Position: `absolute`, `top: 16px`, `left: 16px`, `right: 16px`, `z-index: 10`.
* **Back Button:** 40×40px circle, `#FFFFFF` with blur (`backdrop-filter: blur(10px)`), shadow `0 4px 12px rgba(0,0,0,0.06)`, dark arrow icon centered.
* **Favorite Button:** Identical circular styling, outline heart icon (`#1E242B`).

### 4.2 Hero Section (Product Visuals)
* **Bottle Container:** Centered, vertical presentation.
* **3D Rotation Orbit:** Elliptical SVG/Canvas stroke, color `#38B6FF`, tilted ~15° with soft glow (`drop-shadow: 0 0 8px rgba(56, 182, 255, 0.4)`).
* **Left Feature Badges:** 
  * Stacked vertically, spacing: 20px.
  * Icon (18px) + Label (10px, stacked or inline).
  * Vertical page indicator pill with active segment indicator.
* **Right Color Palette Selector:**
  * Vertical floating pill (`rgba(255, 255, 255, 0.7)`), 40px width, padding: 8px vertical.
  * Swatches: 16px diameter circles, 12px vertical spacing.
  * Selected state: 2px solid ring offset.

### 4.3 Content Card
* **Rating Pill:**
  * Positioned floating over the seam between hero and bottom sheet.
  * Dimensions: ~130×32px, `border-radius: 16px`, background `#FFFFFF`.
  * Shadow: `0 4px 16px rgba(0, 0, 0, 0.06)`.
  * Layout: `4.5` + Star Icon + divider (`|`) + `Ratings` + chevron (`>`).
* **Title:** Full width, 2-line wrap.
* **Tag:** `#38B6FF` solid background, `border-radius: 12px`, padding: `4px 12px`.
* **Description:** Gray text with inline linked `#1E242B` "read more".

### 4.4 Floating Footer Bar
* **Container:** Background `#FFFFFF`, rounded corners (`border-radius: 24px`), padding: `12px 16px`, shadow `0 10px 30px rgba(0, 0, 0, 0.08)`.
* **Price:** Displayed left.
* **Stepper (Quantity Selector):**
  * Pill container with border `#E5E9F0`, height: 40px.
  * Layout: `[-]` button, `01` text, `[+]` button.
* **Cart CTA Button:**
  * Dimensions: 48×48px, `border-radius: 16px`.
  * Background: `#1F2438`.
  * Content: Centered white shopping cart icon.

---

## 5. Micro-Interactions & Animations

* **3D Orbit Drag:** Horizontal drag gesture rotates the thermos 360° on the Y-axis. The cyan orbit line scales slightly during touch interaction.
* **Color Switching:** Tapping a swatch triggers a 250ms cross-fade of the bottle texture and repositions the active halo ring.
* **Quantity Stepper:** Tap scale feedback (`scale(0.92)`) on `+` and `-`. Number slides vertically on change.
* **Cart Button Tap:** Spring scale effect (`scale(0.95)` to `scale(1.0)`) with toast confirmation.
