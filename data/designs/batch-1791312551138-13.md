# Production-Grade Design Specification: "Degrees of Love"

---

## 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Archetype:** Avant-garde editorial, high-contrast fine art, documentary/surveillance digital art, and experimental typography.
- **Visual Density:** Sparse, intentional, high-contrast, text-heavy with macro-scale negative space juxtaposed against high-frequency micro-textural photography (macro banknote engraving style).
- **Whitespace Balance:** Extreme imbalance—massive negative space surrounding a low-opacity, high-detail background graphic, framing the focal UI items.
- **Theme Architecture:** Strict monochrome dark-mode paradigm (`#050505` base) utilizing ultra-fine micro-grain overlays, high-contrast white typography, and structural linework.

## 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** Fluid 12-column grid system bounded by a strict `40px` outer margin border.
- **Spacing Scale:** Uses an 8pt base grid for macro-layout, scaling down to 4pt for micro-UI spacing:
  - `4px`, `8px`, `16px`, `24px`, `32px`, `48px`, `64px`, `96px`.
- **Section Sequence (Top to Bottom):**
  1. **Top Header Bar:** Brand identity (`DEGREES OF LOVE / ROUND AND ROUND`) left; Metadata/Tags (`#FIVE / #SIX`) right.
  2. **Hero Metric & Primary Navigation:** Large focal degree metric (`0°`) on the left paired with inline contextual tags (`SEARCH`, `CAUTION`, `EXPLAIN`).
  3. **Left Vertical Sidebar:** Rotated/Vertical orientation utility string (`S E A R C H`).
  4. **Right Vertical Pagination Indicator:** Stacked numeric page system (`12` / `15`) and persistent grid crosshair icon.
  5. **Footer Carousel / Multi-Item Sequence:** 5 horizontal tabular items (`01` through `05`) uniformly distributed across the bottom viewport canvas.
- **Z-Index Hierarchy:**
  - Background Texture (Macro Graphic): `z-index: 0`
  - Base Layout / Grids: `z-index: 10`
  - Floating UI / Typography Overlays: `z-index: 20`
  - Active Modals / Cursors: `z-index: 100`

## 5. Component Blueprint & Element Placement

### Hero Section Matrix
- **Layout:** Asymmetric split composition. Macro typographic degree token (`0°`) anchored at top-left quadrant (`X: 80px`, `Y: 220px`).
- **Background Asset:** High-detail, monochrome security-print macro engraving of a human eye, screen-blended with overlay black gradients.

### Interactive Tabular Navigation Cards (01–05)
- **Distribution:** Flexbox space-between layout across the lower horizontal viewport baseline (`Y: 740px`).
- **Item Internal Structure:**
  - Top: Numeric index (`01`, `02`, `03`, `04`, `05`) in `24px` regular font.
  - Middle: Primary title string (`DEGREES OF LOVE`) in `10px` uppercase tracked text.
  - Bottom: Sub-string (`ROUND AND ROUND`) in `9px` muted text.
- **Borders & Rules:** Separated by ultra-thin horizontal rules (`1px` height, `rgba(255,255,255,0.15)`).

### Navigation & Actions
- **Vertical Search Tag:** Rotated `-90deg` transform, tracked with wide character spacing (`0.2em`).
- **Action Triggers (`SEARCH`, `CAUTION`, `EXPLAIN`):** Text-only navigational items separated by spaces, transitioning from muted grey to bright white on hover.

---

## 6. Motion Mechanics, 3D & Mobile Gestures

- **Animation Triggers:**
  - Tab selection (`01` through `05`): Triggers a rotational shift of the primary hero metric (e.g., from `0°` to `90°`, `180°`, etc.) and scales the background graphical focus.
  - Hover on structural links: Opacity transition from `0.5` to `1.0` with micro horizontal translation (`+2px`).
- **Transition Specifications:**
  - *Standard UI Fades:* `cubic-bezier(0.16, 1, 0.3, 1)` (Apple-style smooth ease-out), duration `400ms`.
  - *Metric Rotations:* `cubic-bezier(0.7, 0, 0.3, 1)`, duration `600ms`.
- **Mobile Native Adaptation:**
  - Horizontal swipe gesture across the lower card layout updates the active degree metric state.
  - Vertical pull gestures lock/unlock the fullscreen editorial view.
