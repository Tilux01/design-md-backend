# UI Design & Development Specification: Premium Wallet App
**Designer/Creator Reference:** Nina Skrbic

This document provides a highly detailed, pixel-perfect technical specification to clone the modern, high-fidelity mobile wallet UI shown in the reference image. This guide is written for frontend engineers and UI designers to build a seamless, fully-responsive, and interactive web/native mobile implementation.

## 1. Design Tokens & Core Theme

### 1.1 Color Palette
To match the premium, soft-lit aesthetic, use these precise Hex/HSL values:

| Token Name | Hex Value | HSL Value | Usage Description |
| :--- | :--- | :--- | :--- |
| **App Background** | `#F3F3F7` | `hsl(240, 15%, 96%)` | Main screen canvas background |
| **Hero Card Background** | `#E1E0E8` | `hsl(248, 12%, 89%)` | The lavender-tinted top card container |
| **Primary Charcoal** | `#131315` | `hsl(240, 6%, 8%)` | Headers, primary texts, dark active states |
| **Accent Dark Gray** | `#2C2C2E` | `hsl(240, 2%, 18%)` | Core CTA capsule background & buttons |
| **Accent Green** | `#24A148` | `hsl(137, 63%, 38%)` | Positives, growth pills, upward trendlines |
| **Text Secondary** | `#75747C` | `hsl(248, 3%, 47%)` | Subtitles, timestamps, non-active indicators |
| **White Canvas** | `#FFFFFF` | `hsl(0, 0%, 100%)` | Secondary cards, buttons, avatars base |

### 1.2 Typography & Font Stack
The UI utilizes a geometric, warm sans-serif with excellent legibility at micro-scales. 

*   **Primary Font:** `Plus Jakarta Sans`
*   **Fallback Font Stack:** `Inter`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`
*   **Font Weights Used:**
    *   `Light`: 300 (for secondary helper text)
    *   `Regular`: 400 (for timestamps, secondary metrics)
    *   `Medium`: 500 (for UI elements, pill values)
    *   `SemiBold`: 600 (for subtitles, list titles)
    *   `Bold`: 700 (for main balance numbers, high level headers)

### 1.3 Shadows & Elevational Depth
This design avoids harsh drop-shadows, opting instead for soft, diffused, natural lighting effects.
*   **Card Soft Shadow (White cards):** 
    `box-shadow: 0px 8px 24px rgba(0, 0, 0, 0.03), 0px 2px 6px rgba(0, 0, 0, 0.02);`
*   **Hero Container Shadow:** 
    `box-shadow: 0px 12px 36px rgba(19, 19, 21, 0.04);`
*   **Button Shadow:**
    `box-shadow: 0px 4px 12px rgba(0, 0, 0, 0.08);`

### 1.4 Global Border Radii
*   **Hero & Container Cards:** `32px` (highly rounded corners consistent with modern iOS aesthetic)
*   **Action Capsule & Sub-Pills:** `20px`
*   **Small Cards / Interactive Icons:** `16px`
*   **Avatars:** `50%` (perfectly circular)

## 5. Micro-interactions & Core Animations

To elevate this clone to production-level quality, the following animations are highly recommended:

### 5.1 Interactive Hover & Active Scales
*   **Buttons (Send, Scan, Request, Circular Utilities):**
    ```css
    transition: transform 0.2s cubic-bezier(0.25, 1, 0.5, 1), background-color 0.2s ease;
    /* Active State */
    :active {
      transform: scale(0.96);
    }
    ```

### 5.2 Dynamic Entry Cascade
*   Upon screen mounting, animate components sequentially using subtle translates:
    *   **Hero Card:** Animates downward (`translateY(-20px) -> translateY(0)`) with `opacity: 0 -> 1` over `400ms`.
    *   **Floating Action Capsule:** Expands from center (`scale(0.9) -> scale(1.0)`) with `delay: 150ms`.
    *   **Left Grid / Right Card:** Fade slide upward (`translateY(24px) -> translateY(0)`) with `delay: 250ms`.
    *   **Recent Activity Rows:** staggered fade in (`delay: 350ms`, `450ms` respectively).

### 5.3 Graph Drawing Motion
Animate the SVG path trendline for the "Your Income" section when viewport visibility occurs:
```css
@keyframes drawPath {
  to {
    stroke-dashoffset: 0;
  }
}
.svg-trend-path {
  stroke-dasharray: 200;
  stroke-dashoffset: 200;
  animation: drawPath 1.4s cubic-bezier(0.45, 0, 0.55, 1) forwards;
}
```
