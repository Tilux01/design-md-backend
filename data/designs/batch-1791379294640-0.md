## 5. Animation & Interaction Specifications

To achieve the "artistic parallax slider" feel shown in the reference:

1.  **Initial Page Load (Entrance Animation):**
    *   **Staggered Fade-In:** All text elements fade up from `translateY(20px)` with an `opacity` of `0` to `1` over `1.2s` using an `cubic-bezier(0.16, 1, 0.3, 1)` easing function.
    *   **Cloud/Car Floating Effect:** The central cloud and car element should have a continuous, infinite floating keyframe animation:
        ```css
        @keyframes float {
            0% { transform: translateY(0px) rotate(0deg); }
            50% { transform: translateY(-10px) rotate(0.5deg); }
            100% { transform: translateY(0px) rotate(0deg); }
        }
        animation: float 6s ease-in-out infinite;
        ```

2.  **Parallax Mouse Movement (Interactive):**
    *   As the user moves their cursor across the viewport, implement a lightweight JavaScript mousemove listener to shift layers at different speeds:
        *   Background sky: Moves minimally (0.02 multiplier).
        *   Central cloud/car graphic: Moves moderately (0.05 multiplier).
        *   Foreground text: Moves inversely or at a higher rate to create depth.

3.  **Hover States:**
    *   `ABOUT`, `CONTACT`, and `MORE`: Transition `opacity` from `0.7` to `1` on hover (`transition: opacity 0.3s ease`).
    *   Social Icons: Scale up slightly (`transform: scale(1.1)`) on hover.
