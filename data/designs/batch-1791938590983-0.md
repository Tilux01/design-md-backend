# Design Specification: Movieto Landing Page

## 1. General Layout & Theme
*   **Background:** A deep navy-to-dark-purple radial gradient. 
    *   *Primary Color:* `#0F0C29` (Deep Navy)
    *   *Secondary Color:* `#24243E` (Dark Purple)
*   **Viewport:** Full-screen (100vw, 100vh). No outer margins or device frames.
*   **Overall Style:** Modern, dark-mode, cinematic, with a high-contrast accent color (Hot Pink).

## 2. Typography
*   **Primary Font:** **Poppins** or **Montserrat** (Bold for headings, Regular for body).
*   **Fallback Fonts:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
*   **Heading Styles:** 
    *   Main Heading: Bold, ~64px, white, tight letter spacing.
    *   Subheading: Regular, ~20px, white with 80% opacity.
*   **Navigation Styles:** Medium, ~16px, white.

## 3. Color Palette
*   **Accent Pink:** `#FF007A` (Used for Logo, Active Nav underline, and Primary Button).
*   **Primary Button Hover:** `#D60066`.
*   **Secondary Button:** `#252849` (Dark Blue/Grey).
*   **Text:** `#FFFFFF` (White).
*   **Overlay/Poster Tint:** A dark blue semi-transparent overlay (approx. 40% opacity) should be applied over the background poster grid to ensure text readability.

## 4. Header & Navigation
*   **Position:** Fixed or Absolute at the top, spanning 100% width with horizontal padding (approx 80px).
*   **Logo (Left):** 
    *   Icon: A stylized, thick, rounded "M" in Accent Pink.
    *   Text: "Movieto" in white, bold sans-serif, placed directly under or beside the "M".
*   **Nav Links (Center):** 
    *   Items: Home, Movies, Series, Category, Pricing, About.
    *   Active State: "Home" has a thick Accent Pink underline (~3px).
*   **Action Icons (Right):** 
    *   Search Icon (Magnifying glass).
    *   User Icon (Circle with a torso).
    *   Menu Icon (Three horizontal lines/hamburger).
    *   *Spacing:* Evenly spaced icons, white stroke.

## 5. Hero Section (Left-Aligned)
*   **Placement:** Centered vertically, aligned to the left (approx 80px from left edge).
*   **Main Heading:** "Unlimited movies, TV shows, and more" (Wrapped onto two/three lines).
*   **Subheading:** "Find the latest and greatest movies and shows all available on Movieto."
*   **Call to Action Buttons:**
    *   **Button 1 (Get Started):** 
        *   Background: Accent Pink.
        *   Shape: Fully rounded (pill shape).
        *   Text: White, Bold.
    *   **Button 2 (Show Plans):** 
        *   Background: Secondary Button color (`#252849`).
        *   Shape: Fully rounded (pill shape).
        *   Text: White, Bold.

## 6. Background Poster Grid (The "Mosaic")
This is the most complex element. The posters are arranged in a tilted grid behind the text.
*   **Grid Rotation:** The entire grid is rotated approximately **-15 to -20 degrees**.
*   **Poster Treatment:** Each poster should have slightly rounded corners (8-12px) and a subtle drop shadow.
*   **Image Descriptions & Placement:**
    1.  **Top Left:** *Prey for the Devil* poster. Dark, featuring a close-up of a face with hands.
    2.  **Top Center:** *Smile* poster. Features the word "SMILE" in red text.
    3.  **Top Right:** *Mr. Robot* poster. Dark, featuring the title in red block letters.
    4.  **Center Left:** *Wednesday* poster. Features Wednesday Addams in a dark, moody setting.
    5.  **Center Right:** *Dune* poster. Features a group of characters against a desert/orange background.
    6.  **Bottom Left:** *M3GAN* poster. Features the doll character looking forward.
    7.  **Bottom Right:** *Aquaman* poster. Features the character underwater with blue tones.
    8.  **Bottom Edge:** *John Wick* poster. Dark, featuring the character's silhouette/face.
*   **Technical Note:** These images should be **backgroundless** in terms of the UI (no borders), but the posters themselves are standard rectangular movie assets. They should be layered using `z-index` to sit behind the UI text and buttons.

## 7. Interactive States
*   **Buttons:** Should scale slightly (1.05x) on hover with a smooth transition.
*   **Nav Links:** Should change color to Accent Pink on hover.
*   **Posters:** A very subtle parallax effect (moving slightly as the user moves the mouse) would enhance the "perfect clone" feel.

---

### Implementation Notes for Images
*   **Source:** Use high-quality movie poster thumbnails.
*   **Masking:** Apply a `linear-gradient` overlay from the left (darker) to the right (lighter) to ensure the white hero text remains legible regardless of the poster colors behind it.
