# Design Specification: PARALLEL UNIVERSE Poster

## 1. Global Layout & Canvas Strategy
- **Orientation:** Vertical (Poster/Flyer format, typically 3:4 or 2:3 ratio).
- **Layout Type:** Layered, sci-fi/cyberpunk aesthetic with asymmetric grid alignment.
- **Background:** 
  - A deep space/sci-fi dark environment. The upper section features a metallic sci-fi hangar ceiling illuminated by cold blue/purple light strips (`#283c66` to `#101b38`). 
  - A massive, dark spherical planet or celestial body dominates the mid-background with subtle rim lighting.
  - The lower portion consists of a structured, metallic, scuffed sci-fi flooring grid with perspective lines running diagonally/orthogonally.
- **Color Palette:** 
  - Primary Dark: Deep Obsidian/Space Black (`#080c14`, `#04070a`)
  - Accent Lights: Cold Electric Blue (`#3b82f6`, `#60a5fa`, `#93c5fd`)
  - Text & UI Elements: Crisp White (`#ffffff`), Muted Gray (`#94a3b8`) for secondary text.

---

## 2. Typography System & Fallbacks

### Primary Display Font (Headers: "PARALLEL UNIVERSE")
- **Style:** Geometric, futuristic, ultra-bold sans-serif with custom horizontal cuts/stencils (e.g., the letter "E" has separated horizontal bars, "U" and "N" are wide-set).
- **Fallback:** `Impact`, `Arial Black`, `sans-serif`.
- **CSS Approximation:** `font-family: 'Space Grotesk', 'Syncopate', sans-serif; font-weight: 900; letter-spacing: 0.15em;`

### Secondary UI / Metadata Font (Dates, Coordinates, Labels like "SECRETS")
- **Style:** Clean, technical, geometric sans-serif (all-caps, wide tracking).
- **Fallback:** `Roboto`, `Helvetica Neue`, `sans-serif`.
- **CSS Approximation:** `font-family: 'Inter', 'Roboto Mono', sans-serif; font-weight: 500; letter-spacing: 0.2em;`

### Body / Micro-Copy Font (Paragraphs, Footer details)
- **Style:** Monospaced or clean technical sans-serif for high readability at small sizes.
- **Fallback:** `Courier New`, `Consolas`, `monospace`.
- **CSS Approximation:** `font-family: 'Courier New', monospace; font-weight: 400; font-size: 8px; line-height: 1.4;`

---

- **Positioning:** Left margin (`left: 5%`, stacked vertically).

  - **Logo Symbol:** An abstract geometric glyph resembling an "S" or intertwined circuit lines enclosed in a box, followed by the text `SPACE` and `SHIGOO SYMBOLIS`.

    - Large Numbers: `01`-`04` (DATE) and `05` (MONTH).

- **Image Description:** A full-body astronaut in a blue/gray spacesuit, floating upside-down as if attached to the ceiling infrastructure. The suit features detailed folds, reflective visor glow, and atmospheric rim lighting.

## 4. CSS / Layout Implementation Notes for Replication
1. **Container:** Set canvas to `position: relative; overflow: hidden; background-color: #04070a;`.
2. **Grid System:** Use `display: grid` or absolute positioning with percentages (`%`) to maintain responsive alignment across different screen sizes.
3. **Lighting Effects:** Apply subtle `box-shadow` or radial gradients (`radial-gradient(circle at 50% 30%, #1e293b 0%, #04070a 70%)`) behind the planet element to achieve the deep space atmospheric depth.
4. **Blend Modes:** Use `mix-blend-mode: screen` or `overlay` for lighting flares and blue ceiling illumination over the dark background layers.
