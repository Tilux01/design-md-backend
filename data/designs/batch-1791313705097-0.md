# 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Brand Archetype**: Futuristic, ambient, and biometric/identity-focused. Blends clean skeuomorphic realism with modern translucent glassmorphic surfaces (Neumorphism-Glass hybrid).
- **Visual Density & Whitespace Balance**: High-density mobile UI with comfortable breathing room through carefully layered card surfaces. Ample negative space is used around floating interactive elements and avatar capsules.
- **Theme Balance**: Predominantly dark-mode aesthetic with ambient glow effects, soft gradients, and subtle multi-layered lighting (simulated overhead light sources casting soft, diffuse shadows).

# 2. Color Palette & Design Tokens

### Extracted Color Tokens
- **Primary Color**: Deep Indigo/Slate (`#1A1C24` base app background)
- **Primary Highlights**: Electric Cyan / Aqua Glow (`#4CE6E6`, `#7CE3E3`)
- **Secondary & Accent Colors**: Soft Lavender/Pink (`#E8C8E8`), Muted Silver Blue (`#8E9BAE`)
- **Base Background**: Dark Slate Charcoal (`#12141A`)
- **Surface Backgrounds**: Translucent glass surfaces (`rgba(255, 255, 255, 0.04)` to `rgba(255, 255, 255, 0.12)`) with backdrop blur (`blur(16px)`).
- **Border & Divider Colors**: Subtle inner strokes (`rgba(255, 255, 255, 0.15)` top highlight, `rgba(0, 0, 0, 0.4)` bottom shadow).
- **Text Colors**: 
  - Primary text: Pure White (`#FFFFFF`)
  - Secondary text: Muted Blue-Grey (`#A0ABBA`)
  - Accent text: Cyan Glow (`#5CE1E6`)

# 3. Typography System & Hierarchy

- **Font Families**: 
  - *Headings & UI*: Inter / SF Pro Display (Clean, modern sans-serif)
  - *Numbers / Stats*: JetBrains Mono / SF Pro Rounded
- **Scale Breakdown**:
  - **Screen Title / Header**: 20px / 1.25rem, Font Weight: 600 (Semibold), Letter-spacing: -0.01em
  - **Card Title / Section Heading**: 15px / 0.9375rem, Font Weight: 500 (Medium), Letter-spacing: 0
  - **Body Copy**: 13px / 0.8125rem, Font Weight: 400 (Regular), Line-height: 1.4
  - **Caption / Meta**: 11px / 0.6875rem, Font Weight: 400, Letter-spacing: 0.02em (Uppercase tracking)

# 4. Layout Architecture & Spatial Grid

- **Container Max-Width**: 390px / 414px mobile viewport reference (Standard iOS / Android flagship width).
- **Padding & Margin Scale**: 
  - Base Screen Padding: `16px` (`p-4`)
  - Inter-component Gap: `12px` to `16px` (`space-y-3` / `space-y-4`)
- **Section Sequence Breakdown**:
  1. *Status Bar & Navigation Header* (Time, network icons, back/profile trigger)
  2. *Hero Biometric/Identity Focal Section* (Circular glowing avatar / Scanner UI)
  3. *Action Hub / Quick Chips* (Pill-shaped toggle actions)
  4. *Metric / Data Cards* (Translucent glass cards with stat counters and badges)
  5. *Bottom Navigation Bar* (Floating pill dock with 3 primary icons)
- **Stacking Order (Z-Index)**:
  - Base background: `z-0`
  - Cards & Content: `z-10`
  - Floating Bottom Nav: `z-30`
  - Modal / Overlays: `z-50`

# 7. Accessibility (a11y) & WCAG Contrast Audit

- **Contrast Ratios**:
  - Pure White text (`#FFFFFF`) on Dark Base (`#12141A`): **16.5:1** (Passes WCAG AAA)
  - Muted Blue-Grey (`#A0ABBA`) on Dark Base (`#12141A`): **7.2:1** (Passes WCAG AAA)
  - Cyan Accent (`#5CE1E6`) on Dark Surface: **11.4:1** (Passes WCAG AAA)
- **Focus Ring Specifications**:
  ```css
  :focus-visible {
    outline: 2px solid #5CE1E6;
    outline-offset: 3px;
    box-shadow: 0 0 0 4px rgba(92, 225, 230, 0.25);
  }
  ```
