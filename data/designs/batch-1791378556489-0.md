# UI/UX Specification & Design System: "NEXORA" E-Commerce Landing Page

## 1. Global Layout & Viewport Configuration
- **Layout Type:** Full-width, single-page responsive landing page.
- **Base Grid:** 12-column fluid grid system with max-width container (`1440px`).
- **Border Radius & Container Styles:** 
  - Main browser preview wrapper: rounded corners (`32px` radius) with a subtle drop shadow (`0px 24px 64px rgba(0, 0, 0, 0.08)`).
  - Internal card components use soft-rounded container blocks (`24px` to `32px`).
- **Background Palette:** 
  - Primary canvas: Clean Off-White / Light Gray (`#F3F4F6` or pure `#FFFFFF` for internal cards).
  - Brand Accent Palette: Deep Purple/Violet (`#5B3BE8` / `#6C4CD8`), Lavender gradients (`#9A7CF3` to `#E3DCF9`).

---

## 2. Typography System & Fallbacks

- **Primary Heading Font:** **Syne** or **Clash Display** (Geometric, high-contrast, bold, modern sans-serif).
  - *Fallback Stack:* `'Clash Display', 'Syne', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- **Body & UI Font:** **Plus Jakarta Sans** or **Inter** (Clean, highly legible geometric sans-serif).
  - *Fallback Stack:* `'Plus Jakarta Sans', 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`

### Typography Hierarchy:
1. **Hero Main Headline ("Define Your Style / Own Your World"):**
   - Font: Primary Heading Font (Bold / Extra Bold)
   - Size: `56px` - `68px` (Fluid scaling)
   - Line Height: `1.05`
   - Tracking: Tight (`-0.03em`)
   - Colors: Pure Dark Charcoal (`#111111`) for "Define Your", Vibrant Violet (`#5B3BE8` / `#7C5DF4`) for "STYLE" and "WORLD".
2. **Section Headings / Subheadlines ("Where Comfort Meets Confidence"):**
   - Font: Primary Heading Font (Semi-Bold)
   - Size: `36px` - `42px`
   - Color: Pure White (`#FFFFFF`) against purple containers.
3. **Body Text / Descriptions:**
   - Font: UI Font (Regular / Medium)
   - Size: `15px` - `16px`
   - Line Height: `1.5`
   - Color: Soft White / Opacity (`rgba(255, 255, 255, 0.85)`) on dark backgrounds, Dark Gray (`#4B5563`) on light backgrounds.
4. **Navigation & Micro-Copy:**
   - Font: UI Font (Medium)
   - Size: `13px` - `14px`
   - Color: `#1F2937`

---

## 3. Color Palette & Tokens

| Token Name | Hex Code / Gradient | Usage |
| :--- | :--- | :--- |
| **Primary Brand Purple** | `#5B3BE8` | Primary CTA buttons, key headings, brand logo |
| **Secondary Lavender** | `#7C5DF4` | Gradient shifts, accent badges, highlight text |
| **Light Card Background** | `#F8F9FA` | Outer app frames, neutral cards |
| **Deep Section Fill** | `#7650EC` to `#5A32D6` | Hero background container banner |
| **Text Dark** | `#111827` | Primary headings, top navigation links |
| **Text Muted** | `#6B7280` | Secondary descriptions, subtle metadata |
| **White / Contrast** | `#FFFFFF` | Buttons text, badge fills, container cards |

---

## 4. Section-by-Section Breakdown

### A. Navigation Bar (Header)
- **Position:** Sticky / Fixed top bar, padding `24px 48px`.
- **Left Cluster (Links):** `Shop`, `New In`, `Collections`, `About`, `Contact`. 
  - Typography: `14px`, Medium weight, color `#111827`. Hover state: transition to `#5B3BE8`.
- **Center Logo:** 
  - Text: **`NEXORA`**
  - Typography: Heavy bold sans-serif, uppercase, letter-spacing wide (`0.05em`), size `20px`.
- **Right Cluster (Actions):**
  - Search icon (Line/SVG loop, size `20px`).
  - User avatar thumbnail (Circular cropped user profile image, `32px` diameter with subtle border).
  - Cart Button: Pill-shaped capsule button (`border-radius: 9999px`), light gray border, containing a shopping bag icon + text **`1 item`** (`13px`, medium weight).

---

### B. Hero Banner Section
- **Headline Layout:** Split typographic composition across the top of the hero:
  - Left side: *"Define Your"* (Black) + **`STYLE`** (Massive uppercase bold purple outline/fill).
  - Right side: *"Own Your"* (Black) + **`WORLD`** (Massive uppercase bold purple) + Sparkle decorative vector icon (`✨` style, purple).
- **Central Banner Card:** 
  - Shape: Large rounded container (`border-radius: 36px`), filled with a rich violet gradient background (`#7C5DF4` to `#5B3BE8`).
  - **Left Content Block inside Banner:**
    - Small badge with sparkle icon: `✦ New Collection` (White text inside semi-transparent white badge pill).
    - Heading: *"Where Comfort Meets Confidence"* (White, bold, `38px`).
    - Paragraph: *"Elevate your everyday look with pieces that speak you."* (`15px`, light lavender text).
    - Primary CTA Button: Pill-shaped dark button (`#111111` background, white text, `border-radius: 9999px`, padding `14px 28px`), featuring text `"Explore Now"` and a right-pointing arrow inside a circular badge.
    - Social Proof Widget: Floating pill badge containing 3 overlapping circular avatar thumbnails + text `"Loved by 20K+ Trendsetters"` + White heart icon.
  - **Center Model Image:**
    - High-fashion studio cut-out portrait of an East Asian female model wearing a lavender beanie hat and an oversized white graphic t-shirt featuring a stylized purple globe graphic (`NEXORA - BE YOU. DO YOU. FOR YOU.`).
    - Positioned overlapping the left and right sections dynamically.
  - **Right Content Block inside Banner:**
    - Feature Icons List (vertical alignment with icon + label):
      1. T-Shirt Icon — `Premium Quality`
      2. Leaf Icon — `Sustainable Fashion`
      3. Diamond Icon — `Limited Edition`
    - **Featured Look Card:** Floating inner card (`border-radius: 20px`, white background with 80% opacity blur, or crisp white with shadow):
      - Label: `"Featured Look"`
      - Image: Male model wearing a matching purple hoodie.
      - Product Title: `"Graffiti Hoodie"` (`14px`, Bold).
      - Subtitle: `"Streetwear Essential"` (`12px`, Muted).
      - Action: Purple button with shopping cart icon and price `"$79.99"`.

---

### C. Below the Fold (Peek Sections)
- **Express Yourself Section (Left Peek):** Partial view of a secondary content block featuring lifestyle imagery and bold typography.
- **Our Mission Section (Right Peek):** Partial view of a corporate/brand statement container with minimal typography and check-mark features.

---

## 5. Animation & Interaction Specifications (Micro-Interactions)

1. **Page Load / Entrance Animation:**
   - **Hero Text:** Staggered slide-up and fade-in (`translateY(20px)` to `0`, duration `0.8s`, easing `cubic-bezier(0.16, 1, 0.3, 1)`).
   - **Model Cutout:** Zoom-in and fade-in from center (`scale(0.95)` to `1`, duration `1s`).
   - **Floating Badges (Social Proof & Featured Look):** Spring-physics bounce entrance delayed by `0.4s`.

2. **Hover States:**
   - **Primary Buttons ("Explore Now", Cart, Price Button):** Scale up slightly (`scale(1.03)`), drop shadow deepens (`0px 12px 24px rgba(91, 59, 232, 0.25)`).
   - **Nav Links:** Color transition from dark charcoal (`#111827`) to primary purple (`#5B3BE8`) over `0.2s` ease-in-out.
   - **Featured Look Card:** Subtle lift effect (`translateY(-4px)`) on hover.
