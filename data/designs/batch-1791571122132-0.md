# Design Specification: Client Dashboard

## 1. Global Layout & Structure
* **Viewport:** Responsive layout scaled for a desktop environment (suggested canvas size: 1440px width).
* **Background:** Light gray/off-white background (`#f0f2f5` or equivalent) framing the main application container.
* **Main Container:** Centered white card with rounded corners (`border-radius: 24px`), subtle drop shadow, and generous padding (`32px` internal grid system).
* **Grid/Alignment:** 
  * Left-side fixed vertical navigation bar.
  * Top header bar containing top-level navigation pills, user profiles, date picker, and global actions.
  * Main content area structured in an asymmetric card-based grid (Bento-box style UI).

---

## 2. Typography & Fonts
* **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif.
* **Fallback Strategy:** If Google Fonts / Inter is unavailable, fall back sequentially to system sans-serif fonts to maintain the clean, modern aesthetic.
* **Type Scale:**
  * **Page Title ("Client Dashboard"):** `28px`, Bold (Weight: 700), Color: `#111827`.
  * **Section Headers ("Activity", "Virtual cards", "Total Spent", etc.):** `16px`, Semi-Bold (Weight: 600), Color: `#1f2937`.
  * **Primary Data Points / Large Numbers ($6,010.29, 186h):** `24px` to `32px`, Bold (Weight: 700), Color: `#111827`.
  * **Body Copy & Metadata:** `12px` to `14px`, Regular/Medium (Weight: 400/500), Color: `#6b7280`.

---

## 3. Color Palette
* **Primary / Accent:**
  * Electric Violet / Indigo: `#6366f1` / `#7c3aed` (used for active states, highlights, and gradients).
  * Neon Yellow/Lime: `#ccff00` or `#d4ff00` (used for active chart bars and badges like "16:30h" and "15 Days").
  * Teal / Mint Green: `#86efac` to `#6ee7b7` (used for Visa card background and chart accents).
* **Neutral Palette:**
  * Background Main: `#f8fafc`
  * Card Backgrounds: `#ffffff` (with slight variations for nested containers like `#f1f5f9`).
  * Text Primary: `#0f172a`
  * Text Secondary / Muted: `#64748b`
  * Borders / Dividers: `#e2e8f0`

---

## 4. Component Breakdown & Specifications

### A. Navigation & Headers
* **Top Navigation Pills:** Rounded pill buttons (`Dashboard`, `Payments`, `Reports`). The active state uses a solid dark rounded pill (`#0f172a`) with white text. Inactive states use transparent backgrounds with dark gray text.
* **Breadcrumbs:** `Home Page -> Dashboard` styled in muted gray (`12px`).
* **Header Action Buttons:**
  * Search icon, filter icon, date range selector ("20-27 Jan. 2025" with dropdown arrow), "+ Add Widtet", and "Create a Report" (bordered pill button).
* **User Management Section:** Stacked circular avatar thumbnails with a `+6` counter badge and an "+ Add Manager" button. Right-side notification bell, message icon, and profile avatar.
* **Left Vertical Icon Sidebar:** Dark rounded container housing minimalist iconography (Home, Analytics, Document, Chat, Settings, Support headset at the bottom).

---

### B. Pro Version / Advantages Card (Left Column)
* **Card Style:** Light purple/blue gradient backdrop (`#e0e7ff` transitioning to `#c7d2fe`).
* **Visual Asset:** A 3D isometric render of a geometric crystal structure (Ethereum-themed diamond/prism) resting on a translucent pedestal.
* **Badges:** Top-right `×` close button; top-right badge reading `15 Days` with a star icon and yellow background.
* **Copy:** 
  * Header: "Pro Version"
  * Subheader: "Advantages"
  * Description: "Your earnings with the pro version"
* **Interactive Elements:** "Learn more" button with an arrow icon inside a dark circular pill. Footer text: "Join the elite of the crypto world with Pro Version".

---

### C. Activity Card (Top Middle)
* **Header:** "Activity", subtitle "Worked this week", large metric "186h" alongside a floating yellow highlight badge ("16:30h").
* **Data Visualization:** Vertical bar chart representing Mon–Sun. Bars are muted gray (`#f1f5f9`), except for Friday (`Fri`), which is highlighted in bright neon yellow/lime (`#d4ff00`).

---

### D. Virtual Cards Card (Top Right)
* **Header:** "Virtual cards" with a menu icon.
* **Metrics:** "Total Balance", large bold value "$6,010.29", with an incremental indicator (`↗ $205.00`).
* **Progress Breakdown:**
  * Dollar: 64% progress bar (light gray track with dark fill).
  * Tether: 28% progress bar.

---

### E. Visa Balance Card (Far Right)
* **Card Style:** Solid mint/sage green background (`#d1fae5`).
* **Branding:** VISA logo top-right in bold uppercase dark text.
* **Metric:** "$390.00" displayed prominently.
* **Footer:** Card number ending indicator (`... 6802`) and expiry date (`09/28`).

---

### F. Total Spent Card (Bottom Middle)
* **Header:** "Total Spent", subtitle "Spent this week", metric "$820.65" with trend indicator (`↘ $605.00`).
* **Sub-metrics:** Quick stat pills for "10 Wallets" and "26 Assets".
* **Data Visualization:** Line graph tracking spending from Monday to Sunday with data point nodes and a vertical dashed reference line at Wednesday (`$680.00`).

---

### G. Contract Type Card (Bottom Right)
* **Header:** "Contract Type" with an upward diagonal arrow action.
* **Content:** 
  * "Learn more" link with an arrow.
  * Multi-segment donut/pie chart displaying percentage allocations (e.g., `86%` central metric, subsidiary segments at `10%` and `4%`).
* **Footer Metrics:** 
  * Milestone: `140`
  * Bonuses: `48`
  * Hourly: `16`
