# UI/UX Design Specification & Clone Blueprint

This document provides the exact technical blueprint to rebuild the provided creative UI showcase featuring "Mary's Chrome". The specifications are structured for full-screen implementation, isolating functional elements from the visual container to create a responsive, edge-to-edge web experience.

---

## 1. Global Layout & Viewport Architecture

*   **View Style:** Full-screen container (`width: 100vw; height: 100vh; overflow: hidden;`).
*   **Base Background Color:** Soft Peach/Pink (`#FDF1EE` or `rgb(253, 241, 238)`).
*   **Central Stage Element:** 
    *   A large, rounded rectangular container (`border-radius: 24px` or equivalent dynamic scaling).
    *   **Background Fill:** Vibrant Warm Red (`#E53935` or `#EA4335`).
    *   Contains background typography ("Mary's" on the left, "Chrome" on the right) and the focal central profile asset.

---

## 2. Typography System & Fallbacks

The layout relies on clean, modern sans-serif typefaces typical of Google's material design ecosystem.

| Element | Weight | Font Family Stack | Fallback Stack | Notes |
| :--- | :--- | :--- | :--- | :--- |
| **"Mary's" / "Chrome"** | Bold / Heavy | `"Google Sans", "Product Sans"` | `Arial, Helvetica, sans-serif` | Large display text in white, positioned on the red background canvas. |
| **Card Captions** | Regular / Medium | `"Google Sans", Roboto` | `system-ui, -apple-system, sans-serif` | Small, readable text placed inside white product/activity cards. |

---

## 3. Element Breakdown & Positioning

### A. Central Profile Section
*   **Shape:** Perfect circle (`border-radius: 50%`), elevated above the red backdrop with a distinct dark red circular border/drop shadow.
*   **Content:** High-resolution portrait of an older woman smiling, wearing a rust-colored top and light green collared shirt.

### B. Floating Content Cards (Collage Style)
The design features asymmetric, overlapping UI cards floating across the red background:

1.  **Top-Left Image Card:**
    *   *Content:* Hands working with yarn/knitting.
    *   *UI Elements:* White background card layout with a small preview image and an interactive pill-shaped button at the bottom.
2.  **Top-Right Asset:**
    *   *Content:* Folded textured yellow knitted sweater.
    *   *UI Elements:* Accompanied by a pill-shaped badge/tag.
3.  **Bottom-Left Empty/Placeholder Card:**
    *   *Content:* Solid white card featuring a soft peach inner text block or placeholder bar.
4.  **Bottom-Right Activity Card:**
    *   *Content:* Hands working on a crafting project.
    *   *UI Elements:* White card container with a red action button (`border-radius: 100px`).

---

## 4. Pagination / Carousel Indicator

Located at the bottom center of the screen, indicating active slider/carousel states:
*   **Structure:** 4 circular dots horizontally aligned.
*   **State Styling:** 
    *   Inactive dots: Semi-transparent or muted pink/gray.
    *   Active dot (2nd position): Solid vibrant red (`#EA4335`), slightly wider or glowing to denote focus.

---

## 5. Animation & Interaction Specification

To replicate the polished feel of the original media, apply the following micro-interactions:

*   **Entrance Animation (`@keyframes floatIn`):**
    *   The central red block scales up from `0.95` to `1` with an ease-out cubic-bezier curve (`cubic-bezier(0.16, 1, 0.3, 1)`).
    *   The floating cards stagger their entrance (`animation-delay: 0.1s`, `0.2s`, etc.) drifting slightly into place from random offsets.
*   **Hover Effects on Cards:**
    *   `transform: translateY(-4px) scale(1.02);`
    *   `box-shadow: 0 12px 24px rgba(0, 0, 0, 0.15);`
    *   Transition duration: `300ms ease`.
*   **Carousel Transition:**
    *   Smooth horizontal sliding effect when navigating between pagination dots, triggering opacity fades on the floating cards.
