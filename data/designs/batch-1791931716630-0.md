# Dark Neumorphic Messenger UI Specification (`design.md`)

## 1. Global System & Style Tokens

### 1.1 Color Palette
* **Background Dark:** `#181B1E` (deep matte charcoal)
* **Surface / Card:** `#1F2327` (elevated dark slate)
* **Input / Inset Well:** `#131517` (depressed shadow surface)
* **Primary Accent:** `#E53935` to `#FF4B4B` (vibrant coral red)
* **Text Primary:** `#FFFFFF` (pure white, 100%)
* **Text Secondary:** `#8E959E` (cool light grey)
* **Text Muted / Placeholder:** `#555B62` (slate grey)
* **Neumorphic Light Shadow:** `rgba(255, 255, 255, 0.05)` (top-left edge)
* **Neumorphic Dark Shadow:** `rgba(0, 0, 0, 0.6)` (bottom-right edge)

### 1.2 Typography
* **Primary Family:** `SF Pro Text`, `-apple-system`, `Inter`, sans-serif.
* **Fallbacks:** `Roboto`, `Helvetica Neue`, Arial, sans-serif.
* **Scale:**
  * **Header Title:** 20px, Semi-Bold (weight: 600)
  * **Contact Name / Bubble Text:** 14px–15px, Regular to Medium (weight: 400–500)
  * **Subtitle / Last Message / Placeholder:** 12px–13px, Regular (weight: 400)
  * **Badge / Metadata / Timestamp:** 10px–11px, Medium (weight: 500)

## 2. Screen 1: Chats List

### 2.1 Status Bar
* Full-width native status bar.
* Elements: Time (`9:41`) top-left; Cellular, Wi-Fi, and Battery glyphs top-right. White fill.

### 2.2 Top App Bar
* **Left:** Circular profile avatar (40px × 40px) with subtle inset border.
* **Center-Left:** Screen title `"Chats"` (22px, Bold, white).
* **Right:** Action button (`+` icon), circular (36px), primary red fill (`#E53935`), white icon, soft outer drop shadow.

### 2.3 Search Field
* **Dimensions:** Full width minus 32px horizontal padding, 44px height.
* **Shape:** Fully rounded pill shape (border-radius: 22px).
* **Styling:** Inset neumorphic well (`#131517`), inner shadow `inset 2px 2px 5px rgba(0,0,0,0.7), inset -1px -1px 3px rgba(255,255,255,0.05)`.
* **Content:** Placeholder `"Search"` aligned left with 20px padding.

### 2.4 Chat List Item Structure
* **Container:** 72px row height, divided by 1px stroke `#22262B`.
* **Avatar (Left):** 48px circle, 12px right margin. Soft diffused glow behind active avatars.
* **Content Stack (Middle):**
  * Contact Name: 15px, `#FFFFFF`, semi-bold.
  * Last Message: 13px, `#8E959E`, regular, single line truncated.
* **Meta Stack (Right):**
  * Timestamp: 11px, red `#E53935` for unread, muted grey `#555B62` for read.
  * Unread Badge: 18px height pill, red fill (`#E53935`), white text (`100`, `99+`, `3`).

## 3. Screen 2: Conversation View

### 3.1 Header Bar
* **Back Button (Left):** 40px circular recessed button with a muted white left arrow (`←`).
* **Contact Avatar:** 40px circle, immediately adjacent to the back button.
* **User Info:**
  * Title: `"Kathy Gomez"` (16px, bold, white).
  * Status: `"Typing..."` (12px, regular, `#8E959E`).
* **Call Button (Right):** 40px embossed circular button with red phone receiver icon.

### 3.2 Chat Canvas
* **Date Pill:** Centered label `"Today"`, 12px, muted grey, no background.
* **Received Bubbles (Kathy):**
  * Background: Elevated dark slate (`#212529`).
  * Corner Radius: 16px (top-left: 4px).
  * Text: White, 14px.
  * Timestamp: Attached right, 10px, `#8E959E`.
* **Sent Bubbles (User):**
  * Background: Coral Red (`#FF4B4B`).
  * Corner Radius: 16px (bottom-right: 4px).
  * Text: White, 14px.
  * Timestamp: Attached right, 10px, semi-transparent white.

### 3.3 Bottom Input Bar
* **Main Container:** Floating dock, 52px height, inset dark background (`#131517`), rounded 26px.
* **Internal Elements:**
  * Left: Red outline smiley icon (22px).
  * Input Placeholder: `"Type a message"` (14px, muted slate).
  * Attachments: Red outline paperclip and camera icons.
* **Mic / Send Button (Far Right):** 48px floating red circle (`#FF4B4B`), centered white microphone icon, outer red diffused glow.

---

## 4. Bottom Navigation Bar (Chats Screen)

* **Layout:** Floating pill-shaped dock centered at screen bottom (16px bottom offset).
* **Styling:** Elevated dark container (`#1A1D20`), radius 30px, heavy soft shadow.
* **Buttons (4 items):**
  1. **Chats Tab (Active):** Dark squircle with a red indicator/fill accent.
  2. **Camera Tab:** Muted white camera glyph.
  3. **QR / Scan Tab:** Muted white viewfinder icon.
  4. **Settings Tab:** Muted white gear icon.
