# Visual Design Specification & Implementation Blueprint

## 1. Global Layout & Architecture
- **Viewport Structure**: Full-screen, responsive, dark-mode immersive container (`width: 100vw; height: 100vh; overflow: hidden;`).
- **Core Elements**: 
  - An upper UI overlay featuring an Instagram profile container (`olivar.dsgn`).
  - A lower text/prompt generator box with distinct input boundaries and control tokens.
- **Background Layer**: Deep radial gradient transitioning from near-black charcoal (`#090a0f`) at the center to a pure obsidian black (`#000000`) at the edges, layered with an ultra-subtle atmospheric blue-violet vignette to mimic high-end render studio environments.

---

## 2. Typography System & Font Stack
The interface relies on clean, geometric sans-serif typefaces typical of modern mobile applications (iOS/Android system standards).

### Primary Typeface Family: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
*   **Instagram Handle (`olivar.dsgn`):**
    *   *Weight:* Semibold (600)
    *   *Size:* ~16px / 1rem
    *   *Color:* Pure White (`#FFFFFF`)
*   **Name & Subheadings (`Natã Olivar | Design & IA`):**
    *   *Weight:* Bold (700) for name, Regular (400) for bio details.
    *   *Size:* ~14px / 0.875rem
    *   *Color:* Light silver-gray (`#E0E0E0`)
*   **Metric Numbers (`56,7 mil`, `132`, `202`):**
    *   *Weight:* Bold (700)
    *   *Size:* ~15px
    *   *Color:* Pure White (`#FFFFFF`)
*   **Metric Labels (`seguidores`, `posts`, `seguindo`):**
    *   *Weight:* Regular (400)
    *   *Size:* ~12px
    *   *Color:* Muted cool gray (`#A0A0A0`)
*   **Prompt Input Box Typography:**
    *   *Typeface:* Monospace / Clean Sans-serif hybrid (optimized for code/prompts).
    *   *Weight:* Regular (400)
    *   *Size:* ~15px / line-height: 1.6
    *   *Color:* Light silver (`#D1D5DB`)

*Fallback Stack:* If system fonts fail, fall back to `Inter`, `Roboto`, and generic `sans-serif`.

---

## 3. Component Breakdown & Styling

### A. Instagram Profile Card ("olivar.dsgn")
- **Container Styling:**
  - *Shape:* Rounded rectangular card with a high-radius curve (~24px).
  - *Background:* Translucent dark glassmorphism (`rgba(18, 20, 28, 0.75)`).
  - *Border:* Thin, subtle inner stroke using a linear gradient (`rgba(255, 255, 255, 0.1)` to `rgba(255, 255, 255, 0.02)`).
  - *Box Shadow:* Deep drop-shadow with wide blur (`0px 24px 48px rgba(0, 0, 0, 0.6)`).
- **Avatar Image:**
  - Circular crop, bordered by a vibrant neon-orange to red gradient ring (`#FF4500` to `#FF8C00`).
- **Verified Badge:**
  - Standard Instagram blue verification checkmark SVG positioned inline next to the handle.
- **Action Icons:**
  - Top right features bell notification and ellipsis (`...`) icons rendered in crisp white with `0.8` opacity.

### B. Prompt Generator / Text Area Box
- **Container Styling:**
  - *Shape:* Large floating container with curved borders (~20px).
  - *Background:* Solid deep charcoal black (`#0B0C10`).
  - *Border:* Subtle light border (`1px solid rgba(255, 255, 255, 0.08)`).
- **Content Elements:**
  - *Leading Icon:* Image/gallery icon on the top-left edge (`opacity: 0.7`).
  - *Trailing Icons:* Send/submit arrow icon and filter/controls icon on the right edge.
  - *Text Content:* A dense, continuous paragraph detailing a 3D render prompt (Silver metallic logo floating on matte black background, Octane Render specs, cinematic lighting, etc.).

---

## 4. Color Palette Specifications
| Token | Hex / Value | Usage |
| :--- | :--- | :--- |
| **Background Dark** | `#000000` / `#050508` | Base canvas and deep shadows |
| **Card Surface** | `rgba(18, 20, 28, 0.8)` | Floating UI panels |
| **Primary Text** | `#FFFFFF` | Headers, handles, high-emphasis metrics |
| **Secondary Text** | `#A0A0A0` | Descriptive text, labels |
| **Accent Orange** | `#FF5722` | Avatar ring and brand accent elements |
| **Verified Blue** | `#0095F6` | Instagram checkmark |
| **Border Stroke** | `rgba(255, 255, 255, 0.1)` | Structural dividers and card outlines |

---

## 5. Animation & Interaction Blueprint (For Full Implementation)
- **Entrance Animation:**
  - Elements fade in using a staggered `opacity` and `transform: translateY(10px)` to `translateY(0)` over `0.6s` with an `ease-out` cubic-bezier curve (`cubic-bezier(0.16, 1, 0.3, 1)`).
- **Hover States:**
  - *Prompt Box:* Border brightens slightly to `rgba(255, 255, 255, 0.2)` on hover.
  - *Icons:* Scale up slightly (`transform: scale(1.05)`) with transition duration of `0.2s`.
- **Glassmorphism Depth:**
  - Use a backdrop filter (`backdrop-filter: blur(20px); -webkit-backdrop-filter: blur(20px);`) to ensure proper diffusion over any dynamic backgrounds.
