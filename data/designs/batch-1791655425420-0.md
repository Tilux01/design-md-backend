# Design Specification: Whale Loans (DeFi Dashboard)

This document provides the exact design specifications for the Whale Loans DeFi dashboard, derived from the provided UI/UX mockups. It covers layout structures, typography, color systems, component states, and asset descriptions for full-screen implementation.

---

## 1. Global & Layout Specifications

### Viewport & Scaling
- **Default Frame Layout:** Responsive framework supporting Desktop (Tablet landscape wrapper), iPad/Tablet layout, and Mobile device frame sizes. 
- **Implementation Strategy:** Full-screen responsive layout utilizing CSS Grid and Flexbox. Remove all device frame mockups, bezels, shadows, and outer wrappers from the final implementation. Render directly to the browser viewport.

### Color Palette
- **Backgrounds:**
  - `bg-primary`: `#F4F6F9` (Light gray/off-white main canvas background)
  - `bg-card`: `#FFFFFF` (Pure white for cards, panels, and content containers)
  - `bg-sidebar`: `#FFFFFF` (White sidebar background)
  - `bg-dark-card`: `#12161F` (Dark theme cards, sidebar states, and statistical containers)
  - `bg-dark-element`: `#1A202C` (Input fields and nested cards inside dark containers)
- **Borders & Dividers:**
  - `border-light`: `#E2E8F0`
  - `border-dark`: `#2D3748`
- **Text Colors:**
  - `text-main`: `#1A202C` (Primary headers and text on light surfaces)
  - `text-muted`: `#718096` (Labels, captions, and secondary text)
  - `text-dark-main`: `#FFFFFF` (Primary text on dark surfaces)
  - `text-dark-muted`: `#A0AEC0` (Secondary text on dark surfaces)
  - `text-accent`: `#3182CE` / Brand specific cyan-blue (used on balances and interactive links)
- **Interactive / States:**
  - `brand-black`: `#0F172A` (Primary buttons like "Connect Wallet", "Stake HUMP")
  - `badge-green-bg`: `#E6FFFA`
  - `badge-green-text`: `#319795` (ROI and positive indicators)

## 2. Typography System

### Font Families
- **Primary Font Family:** Inter
- **Fallback Stack:** `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`

### Hierarchy Specifications
- **Page Title (e.g., "Single Stake (3,3)", "Bond (4,4)"):**
  - Font Size: `24px` / `1.5rem`
  - Font Weight: `700` (Bold)
  - Line Height: `32px`
- **Section / Card Headers:**
  - Font Size: `16px` / `1rem`
  - Font Weight: `600` (Semi-bold)
- **Body / Data Values:**
  - Font Size: `14px` / `0.875rem`
  - Font Weight: `400` (Regular) / `600` for emphasized metrics
- **Labels / Captions / Badges:**
  - Font Size: `12px` / `0.75rem`
  - Font Weight: `500` (Medium)

## 3. Component Architecture & Detailed Breakdowns

### A. Navigation & Sidebar
- **Logo Area:**
  - Whale icon + text "Whale Loans"
  - Font Weight: `700`, Size: `14px`
- **Navigation Links:**
  - Items: Dashboard, Stake, Band, Calculator, Vaults, Leverage, Flash Mint, Docs.
  - Active State Indicator: Left vertical pill/bar in primary dark (`#0F172A`), text colored bold with subtle background tint.
  - Inactive State: Muted gray text (`#718096`), hover state shifts text to `#1A202C`.
- **Footer Metadata (Bottom of Sidebar):**
  - Social / utility icons (Discord, Twitter, Medium, etc.).
  - Copyright text: `©2022 Whale Loans | All rights reserved` (`10px`, `#A0AEC0`).

### B. Header Bar
- **Left Element:** Token Price Display pill (`1 HUMP = $8.43`) with green token icon.
- **Right Element:**
  - Network Indicator / Address (`0x1T4B...B6Q0`) with a status dropdown.
  - "Connect Wallet" primary dark button (`bg: #0F172A`, `text: #FFFFFF`, pill border-radius).
  - Notification / Theme toggle icon button.

### C. Dashboard Panels (Single Stake & Bonds)

#### 1. Stake Interface (Interactive State)
- **Tabs Component:** "STAKE" vs "UNSTAKE" toggle. Active tab underlined with solid dark pill indicator.
- **Input Group:**
  - Input field with placeholder `Enter the amount`.
  - Right-aligned "MAX" button inside the input boundary.
- **Action Button:** Full-width primary button labeled `Stake HUMP` (`bg: #0F172A`, rounded corners).
- **Data Breakdown List:**
  - Your Balance: `0.0 HUMP`
  - Your Staked Balance: `0 sHUMP ($0)`
  - Next Reward Amount: `0 sHUMP ($0)`
  - Next Reward Yield: `0.5378%`
  - ROI (5 Day Rate): `8.3786%`

#### 2. Dark Metric Cards (APY & Stats)
- **Container:** Dark background (`#12161F`), rounded-2xl padding.
- **Elements:**
  - **APY Card:** Header `APY` with a percentage icon badge. Main value `257,900%` (`32px`, bold, white).
  - **Total Value Deposited Card:** Main value `$571,320` with a top-right trend arrow icon.
  - **Current Index Card:** Main value `1.99 HUMP` with a rebase wave/activity icon.

#### 3. Bond Table Structure (`Bond (4,4)`)
- **Treasury Banner:** Displays `Treasury Balance: $326,528`.
- **Table Headers:** `Bond`, `Price`, `ROI`, `Purchased`, `Duration`, `Action`.
- **Row Anatomy:**
  - **Bond Column:** Token icon (e.g., BUSD) + asset name (`BUSD`). Backgroundless icon.
  - **Price:** `$15.68`
  - **ROI:** `-76.09%` (styled in green/teal badge format).
  - **Purchased:** `$82,783`
  - **Duration:** `14 days`
  - **Action:** Primary button labeled `Bond`.
- **Disclaimer Box:** Alert note with info icon: *"New bonds are auto-staked (accrue rebase rewards) and no longer vest linearly. Simply claim as sHUMP at the end of the term."*

## 4. Asset & Icon Specifications

All icons must be implemented using clean SVG vectors matching the line-art style shown in the mockups.

- **Logo Icon:** Stylized whale tail inside a circle. (Backgroundless vector, placement: Top-left of sidebar).
- **Wallet Icon:** Outline wallet illustration with a small plus badge (`+`). Used in the empty stake state. (Backgroundless vector, centered inside the dashed/card dropzone).
- **Token Icons (HUMP / BUSD):** Circular cryptocurrency badges with respective brand symbols (Whale symbol for HUMP, multi-faceted diamond icon for BUSD). Backgroundless where applicable, styled with drop shadows.
- **Utility Icons:** 
  - Network/Gas indicators (`%` badge, trend-up arrow inside a circle, wave icon for rebase).
  - External link and chevron arrows.
