# UI Design Specification: E-Commerce Storefront

This document provides the exact design specifications for the e-commerce storefront interface shown in the reference image. The design features a minimalist, neutral-toned aesthetic with a clean, grid-based layout.

---

## 1. Global Styles

### Color Palette
*   **Background (Canvas):** `#FFFFFF` (Pure White)
*   **Primary Text/Headings:** `#1A1A1A` (Near Black / Dark Charcoal)
*   **Secondary Text/Subheadings:** `#666666` (Medium Gray)
*   **Light Gray / Borders / Card Backgrounds:** `#F2F2F2` or `#EAEAEA`
*   **Accent / Interactive Buttons:** `#1A1A1A` (Dark fills for primary CTAs)
*   **Rating Star Color:** `#FFA500` (Warm Amber/Gold)

### Typography (Sans-Serif, Geometric / Modern Grotesque)
*   **Hero / Major Headings (e.g., "Rov Lbitriog..."):**
    *   Size: 32px – 40px
    *   Weight: Bold (700)
    *   Line Height: Tight (1.1 - 1.2)
*   **Section Titles (e.g., "New Shoes"):**
    *   Size: 18px – 20px
    *   Weight: Semi-Bold (600)
*   **Product Titles:**
    *   Size: 13px – 14px
    *   Weight: Medium (500)
*   **Prices & Body Text:**
    *   Size: 12px – 13px
    *   Weight: Regular (400) / Bold for pricing

---

## 2. Layout Structure & Grid

*   **Container Width:** Max-width ~1280px, centered on the screen with generous side margins.
*   **Grid System:** 
    *   Header: Flexbox row (Logo, Navigation, Search, Icons).
    *   Hero Section: 2-column asymmetric layout (Left hero banner ~70%, Right featured card ~30%).
    *   Product Grid: 4-column layout with consistent gap spacing (~16px – 24px horizontal and vertical).

---

## 3. Component Specifications

### A. Navigation Bar (Header)
*   **Height:** ~70px
*   **Elements (Left to Right):**
    *   **Brand Logo:** Stylized "3o" or similar minimalist monogram in bold dark gray.
    *   **Navigation Links:** Clean, uppercase or sentence case text links (`Collections`, `Shop`, `About`, `Contact`).
    *   **Search Bar:** Rounded pill-shaped input field with a placeholder (e.g., "Search...") and a search icon.
    *   **Right Utilities:** User account icon, wishlist/favorites icon, and shopping bag/cart icon with a counter badge.

### B. Hero Section
*   **Left Banner (Promotional / Featured Product):**
    *   **Background:** Warm beige/taupe gradient image overlay.
    *   **Content:** Large title text, subtitle, and a primary CTA button ("Shop the Look" or similar) styled as a rounded pill button with dark text/background.
*   **Right Banner (Secondary Featured):**
    *   **Content:** Full-bleed lifestyle image with an overlay action (e.g., quick view arrow icon in the top-right corner).

### C. Filter & Search Bar (Below Hero)
*   **Layout:** Horizontal toolbar containing filter dropdowns, category selectors, and a view/sort button.

### D. Product Card Grid
Each product card follows a standardized structure:
1.  **Image Container:**
    *   Light neutral background (`#F7F7F7`).
    *   Product photography (clean studio shots or lifestyle portraits).
    *   Top-left badge/icon (optional).
    *   Top-right action icon (e.g., Bookmark / Favorite button).
2.  **Product Details:**
    *   **Title:** 2-line text limit, dark gray color.
    *   **Rating:** Row of 4-5 filled star icons followed by review count.
    *   **Price:** Bold typography (e.g., `$120.00`).
    *   **Action Button:** A circular or pill-shaped "Add to Cart" (+) button positioned on the bottom right of the card.

---

## 4. Footer / Sidebar Lists (Bottom Right Reference)
*   **List Style:** Clean vertical stack with subtle bottom border separators.
*   **Typography:** Small, legible gray text for directory/footer navigation links.
