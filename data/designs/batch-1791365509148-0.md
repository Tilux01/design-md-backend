# Design Specification: Brands - UI/UX Landing Page

## 1. Global Styles & Theme

### Color Palette
- **Background (Primary Dark):** `#181b1f` (Dark charcoal gray, dominant for the entire viewport)
- **Background (Right Panel/Hero Overlay):** `#14171a` (Slightly darker shade for depth)
- **Text & UI Accent (Orange):** `#ff4800` (Used for dots, arrows, outlined typography accents)
- **Primary Text (White):** `#ffffff`
- **Secondary Text (Muted Gray):** `#8b9096`
- **Line/Border Elements:** `#33373d`

### Typography
- **Primary Font Family:** Inter, system-ui, -apple-system, sans-serif
- **Font Weights Used:** 
  - Light (300)
  - Regular (400)
  - Medium (500)
  - Bold (700)

---

## 2. Layout & Structure

- **View:** Full-screen responsive web layout (100vw × 100vh)
- **Grid Structure:** Two-column split layout with asymmetrical emphasis
  - **Left Section (Content Area):** ~60% width, dark textured background with subtle dot matrix patterns.
  - **Right Section (Hero Image Area):** ~40% width, featuring a monochrome portrait with a vertical typography overlay.

---

## 3. Component Breakdown

### Header / Navigation
- **Position:** Absolute, top-left corner
- **Hamburger Menu Icon:** 
  - Three horizontal lines, top-aligned, left-padded.
  - Color: `#ffffff`

### Social Media Sidebar (Left Edge)
- **Position:** Vertical alignment on the mid-left side
- **Items:** Instagram, Behance, Dribbble, Pinterest icons
- **Color:** `#8b9096` transitioning to `#ffffff` on hover.

### Hero Content (Left Section)
- **Top Decorative Line:** Short horizontal orange line (`#ff4800`), width ~30px, height 2px.
- **Subheading:** 
  - Text: `"Love on UI & UX"`
  - Font Size: `12px`
  - Color: `#8b9096`
- **Main Heading:**
  - Text: `"Design Technology."`
  - Font Size: `32px` - `40px`
  - Font Weight: `700`
  - Color: `#ffffff`
- **Large Decorative Typography ("DESIGN"):**
  - Outlined hollow lettering style (stroke effect with inner lines).
  - Colors: Alternating white and orange accents (`#ffffff` and `#ff4800`).
  - Positioned directly below the main heading with a trailing hyphen (`-`).
- **Footer Navigation Link ("About us"):**
  - Text: `"About us"` followed by a dotted separator (`······`) and an orange circular button indicator (`#ff4800`).

### Vertical Center Divider Typography
- **Text:** `"Brands."`
- **Orientation:** Vertical (rotated 90 degrees)
- **Font Size:** `64px` - `80px`
- **Font Weight:** `700`
- **Color:** `#ffffff`
- **Accent:** Orange dot (`#ff4800`) positioned directly above the letter "B".
- **Metadata:** `"28.03.2018"` aligned vertically alongside the brand text in smaller muted font (`10px`, `#8b9096`).

### Hero Image & Right Panel (Right Section)
- **Background Image:** Monochrome (grayscale) studio portrait of a man in a modern suit, glasses, and styled hair, arms crossed.
- **Overlay Effect:** Subtle dark vignette and dot-matrix grid overlay.
- **Action Button (Next/Forward):**
  - Position: Bottom-right quadrant of the image.
  - Background: Solid orange (`#ff4800`).
  - Shape: Square box with rounded corners (or sharp).
  - Icon: White right-pointing arrow (`→`).
