# Design Specification: Minimalist Editorial Portfolio

## 1. Overview & Palette
A high-contrast, minimalist editorial photography portfolio layout featuring asymmetric typography and an image carousel/slider.

* **Background:** Pure White (`#FFFFFF`) or Crisp Off-White (`#FDFDFD`)
* **Primary Text / Lines:** Solid Black (`#000000`)
* **Secondary / Meta Text:** Muted Gray (`#767676`)

---

## 2. Typography

| Role | Font Family | Fallback Stack | Specs |
| :--- | :--- | :--- | :--- |
| **Hero Title** (`less.` / `Text.`) | Modern High-Contrast Serif (e.g., *Playfair Display Black*, *Didot*, *Bodoni*) | `Didot, "Bodoni MT", "Times New Roman", serif` | `font-size: clamp(8rem, 18vw, 22rem)`, weight 900, tracking -0.04em, line-height 0.8 |
| **Brand / Logo** (`neil` / `Liam`) | Bold Editorial Serif | `Georgia, "Times New Roman", serif` | `font-size: 1.25rem`, weight 700, lowercase/titlecase |
| **Navigation Links** | Geometric Grotesque Sans | `Inter, -apple-system, "Segoe UI", sans-serif` | `font-size: 0.75rem`, weight 400, capitalization optional, gap 2rem |
| **Vertical Sidebar** (`Categories +`) | Editorial Serif or Sans | `Georgia, serif` / `sans-serif` | `font-size: 1.1rem`, weight 400, vertical orientation |
| **Badge** (`Slide`) | Clean Sans-Serif | `Inter, Helvetica, Arial, sans-serif` | `font-size: 0.65rem`, uppercase/titlecase |
| **Card Captions (Headers)** | All-caps Sans-Serif | `Inter, Arial, sans-serif` | `font-size: 0.6rem`, tracking +0.15em, color `#767676` |
| **Card Captions (Titles)** | Editorial Serif | `Playfair Display, Georgia, serif` | `font-size: 1.2rem`, weight 400 |

## 3. Layout & Structure

```
+-----------------------------------------------------------------------+
| [Logo]        [Nav: Print Shop   Commercials   Covers]         [Menu =] |
|                                                                       |
|  [C           (Slide)          +------------+       +------------+    |
|   a                            |            |       |            |    |
|   t                            |  Image 1   |       |  Image 2   |    |
|   e                            |  (Portrait)|       | (Editorial)|    |
|   g                            |            |       |            |    |
|   o                            +------------+       +------------+    |
|   r                            CATEGORY             CATEGORY          |
|   i                            Title                Title             |
|   e                            — STYLE. /47°        — PORT. GQ        |
|   s +]                                                                |
|                                                                       |
| [less. / Text. ]                                                      |
+-----------------------------------------------------------------------+
```

### Main Header (`100%` width, fixed/absolute top padding: `2.5rem 3rem`)
* **Left:** Brand wordmark (`neil` or `Liam`).
* **Center-Left:** Horizontal nav list (`Print Shop`, `Commercials`, `Covers`).
* **Far Right:** Minimal hamburger icon—2 horizontal parallel lines (`width: 32px; height: 2px; gap: 6px; background: #000`).

### Left Content Zone
* **Rotated Label:** Text `Categories +` rotated -90deg (`writing-mode: vertical-rl; transform: rotate(180deg)`), anchored vertically centered at `left: 2.5rem`.
* **Slide Badge:** Circular indicator positioned mid-screen left of the first image card.
  * Border: `1px solid #000` (or `#C4C4C4`).
  * Dimensions: `46px` diameter circle.
  * Centered text: `Slide`.
* **Hero Text:** Huge display word (`less.` or `Text.`) pinned to bottom-left: `bottom: 0; left: 2.5rem; transform: translateY(10%)` allowing slight clipping at base.

### Right Showcase / Gallery
* Horizontal flex container pinned right, aligned bottom-to-center.
* **Card Dimensions:** Aspect ratio roughly `3:4` or `4:5`.

## 4. Image Assets & Media Specifications

### Card 1: Primary Portrait
* **Subject Description:** Dramatic black-and-white studio profile photograph of a clean-shaven Black man (Kobe Bryant) looking towards the right, wearing a black crew-neck t-shirt against a light gray studio background.
  * *Alternate asset version:* Black-and-white minimalist closeup of two hands gracefully interacting, fingers curved upwards against a white background.
* **Format:** Solid rectangular frame, standard photo crop (no border-radius, not cut-out).
* **Metadata Below Image:**
  * Tag: `PORTRAIT` (small, gray, all-caps).
  * Line 1: `Kobe Bryant` (Serif).
  * Line 2: `— STYLE. /47°` (Monospace/Sans with horizontal rule).
  * *Alternate:* `Untitled°` over a thin horizontal dividing line spanning the card width.

### Card 2: Secondary / Crop Portrait
* **Subject Description:** Black-and-white studio portrait of a woman (Kendall Jenner) with windblown hair covering part of her face, wearing a dark strap dress/top, facing slightly downward.
  * *Alternate asset version:* Close-up photo of an arm and hand reaching upwards in a dynamic gesture.
* **Format:** Rectangular frame matching Card 1 height.
* **Metadata Below Image:**
  * Tag: `EDITORIAL` (small, gray, all-caps).
  * Line 1: `Untitled Res` / `Kendall Jenner`.
  * Line 2: `— PORT. GQ` / `MODEL 24—` (includes trailing thin rule extending to the right).

## 5. Spacing & Fine Details
* **Container Margin:** Horizontal padding `3rem`, vertical padding `2.5rem`.
* **Card Gap:** `2.5rem` between Image Card 1 and Image Card 2.
* **Underlines/Rules:** Use `border-bottom: 1px solid #000000` with direct inline layout with text (e.g., `MODEL 24—————`).
