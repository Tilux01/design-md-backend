# Lotek Perkedel - Culinary Experience Interface

## Overview
This design presents an immersive, futuristic kitchen or dining room interface projected onto a white wall. The interface functions as an interactive recipe and food ordering system, featuring high-resolution food imagery, chef profiles, ratings, and navigation controls. The background is a clean, modern kitchen setting with a dark wood floor, white island, and black bar stools.

---

## Color Palette

### Primary Colors
- **Pure White**: `#FFFFFF` (Background UI, text)
- **Deep Charcoal / Black**: `#1A1A1A` (Headlines, icons, UI cards)
- **Muted Gray**: `#E5E5E5` (Subtext, borders, inactive states)

### Accent Colors
- **Warm Peach / Terracotta**: `#E0A996` (Background graphic wash, branding accents)
- **Sage Green**: `#A3B899` (Secondary background graphic wash)
- **Star Rating Gold**: `#FFB800` (Rating stars)

---

## Typography

### Font Family
- **Primary Font**: `Inter`, `Roboto`, sans-serif (Clean, modern geometric sans-serif for UI elements, descriptions, and metadata)
- **Headline Font**: `Montserrat`, `Helvetica Neue`, sans-serif (Bold, high-impact sans-serif for dish titles)

### Fallback Stack
```css
font-family: 'Inter', 'Montserrat', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif;
```

### Type Hierarchy
- **Main Dish Title**: 48px–64px, Bold, Uppercase (e.g., `LOTEK PERKEDEL`)
- **Category Tagline**: 12px, Medium, Uppercase, Letter-spacing: 1.5px (e.g., `#1 street food disk`)
- **Section Headers (Overview / Ingredients)**: 14px, Medium, Uppercase
- **Chef Name**: 16px, Semi-Bold
- **Body / Description Text**: 13px–14px, Regular, Line-height: 1.5
- **UI Labels & Ratings**: 12px–14px, Medium

---

## UI Components & Layout

### 1. Header & Navigation
- **Search Icon**: Top right (`<svg>` magnifying glass)
- **Menu Icon**: Top right (`<svg>` hamburger menu)

### 2. Main Hero Section (Left-Center)
- **Featured Dish Image**: Large circular plate presentation with drop shadow
- **Dish Title**: Bold, stacked typography (e.g., `LOTEK` / `PERKEDEL`)
- **Action Buttons**:
  - `Play video` (with play icon)
  - `Order food` (with shopping bag/arrow icon)

### 3. Chef & Rating Card (Right)
- **Tab Navigation**: `Overview` | `Ingredients` (Active state underlined)
- **Rating Display**: Large numeric score (e.g., `4.9`) with gold star icon and review count
- **Chef Profile**: Thumbnail image, Chef name (`Chef Feny`), and descriptive bio text

### 4. Carousel / Dish Selector (Bottom Center)
- Horizontal scroll of alternative dishes with circular thumbnail previews, labels (`Tahu Lontong`, `Lamb Steak`, etc.), and price/detail indicators
- Left and right navigation arrows

### 5. Bottom Dock (Footer UI)
- Centered floating icon dock containing:
  - Cutlery / Dining icon
  - Search / Explore icon
  - Heart / Favorites icon
  - User profile icon
  - Voice assistant / Microphone icon
```
