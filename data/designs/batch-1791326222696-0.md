# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial Minimalist / Automotive Luxury Dark Mode (Concept Roadster Presentation).
- **Visual Density & Whitespace Ratio**: High-end minimalist layout featuring generous canvas padding, bold typography-driven hero statements, expansive whitespace, and immersive full-width product imagery.
- **Surface Elevation Model**: Clean flat architectural canvas with subtle dark neutral cards, minimal borders (`1px solid rgba(255, 255, 255, 0.1)`), and sharp monochrome contrast.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase navigation items, minimalist editorial hierarchy, monochromatic luxury styling, subtle vignette lighting on vehicle renders.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `12px`, font-weight `500`, tracking `0.08em`, border-radius `9999px`, background `rgba(255, 255, 255, 0.05)`, border width `1px` solid `rgba(255, 255, 255, 0.1)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;`.
  - Status Dot (●) -> Use `<span class="w-1.5 h-1.5 rounded-full bg-white inline-block"></span>`.

# 7. Motion Mechanics, Framer Motion & CSS Animations
- **Motion Principles**: Smooth deceleration curves (`cubic-bezier(0.16, 1, 0.3, 1)`), subtle fade-in and upward drift for editorial headlines, parallax scroll behavior on full-bleed imagery.
- **Framer Motion Variants Code**:
```jsx
export const containerVariants = {
  hidden: { opacity: 0, y: 30 },
  visible: { 
    opacity: 1, 
    y: 0,
    transition: { duration: 0.6, ease: [0.16, 1, 0.3, 1], staggerChildren: 0.15 }
  }
};
```

- **CSS `@keyframes` Animations**:
```css
@keyframes fadeInSlide {
  0% { transform: translateY(20px); opacity: 0; }
  100% { transform: translateY(0); opacity: 1; }
}
.animate-fade-in {
  animation: fadeInSlide 0.8s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}
```
