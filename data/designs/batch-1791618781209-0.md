# Design System & Implementation Specification: Split Collection Interactive Showcase

---

## 1. Overview & Canvas Structure

This specification details an interactive, high-fashion dual-split lookbook interface featuring an environmental comparison between cold-weather wear (**Big Chill / Arctic Collection**) and hot-weather wear (**Mojave / Dusty Dunes Wear**). 

* **Target Viewport:** Full-screen fluid layout (Target base ratio: `16:9` / `1920x1080px`, scales to `100vw` × `100vh`).
* **Container/Frame Exclusion:** All external presentation frames (the blue mobile wrapper, drop-shadow phone mockups, and "Youtube : Kausarhsn" watermark) are completely excluded. The canvas represents the raw, borderless digital interface.
* **Layout Paradigm:** Two equal columns (50% / 50% split) divided down the center axis with an interactive split-slider handle anchored to the focal model.

## 7. Interactive State & Split Slider Mechanics

1. **Divider Axis:**
   * Vertical division line at `x = 50vw` default state.
   * Dragging the center circular puck (`O`) horizontally shifts the clipping masks:
     * `Left Side Mask`: `polygon(0 0, X% 0, X% 100%, 0 100%)`
     * `Right Side Mask`: `polygon(X% 0, 100% 0, 100% 100%, X% 100%)`
2. **Hover States on Swatch Cards:**
   * Scale transform: `1.05x` with increased shadow on hover.
3. **Responsive Scaling Rule:**
   * Elements retain strict anchor positions using percentage coordinates (`%`) from canvas center to prevent visual overlap across ultra-wide display devices.
