# Design System & Implementation Specification: Devialet Luxury Audio Webpage

---

## 1. Overview & Aesthetic Identity

* **Brand Atmosphere:** Luxury, acoustic precision, ultra-minimalist, avant-garde French industrial design.
* **Theme:** Pure Dark Mode / High-Contrast Monochromatic.
* **Canvas Style:** Full-width viewport design with continuous deep-black surfaces, subtle 3D fluid acoustic textures, and high-impact white typography.

## 3. Typography System

### Font Families
* **Display / Brand Heading Font:**
  * **Primary:** `Syne` (Weights: 700, 800) or `Monument Extended` / `Clash Display`.
  * **Fallback Stack:** `Montserrat`, `"Arial Black"`, `system-ui`, `sans-serif`.
  * **Characteristics:** Extended horizontal proportions, geometric uppercase forms, high optical impact.
* **Body & UI Font:**
  * **Primary:** `Inter` or `Plus Jakarta Sans` (Weights: 400, 500, 600).
  * **Fallback Stack:** `Helvetica Neue`, `Arial`, `sans-serif`.
  * **Characteristics:** Neutral, highly legible grotesque grotesque style, tight spacing for captions, open tracking for uppercase UI links.

### Typographic Hierarchy Scale

| Element | Size | Weight | Tracking / Letter Spacing | Line Height | Case |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Hero Background Brandmark (`DEVIALET`)** | `13vw` (~150px–180px) | 800 / Black | `+0.05em` | `0.9` | Uppercase |
| **Section Headings (`ABOUT US`, `DEVIALET COLLECTION`)** | `36px`–`42px` | 800 / Bold | `+0.04em` | `1.1` | Uppercase |
| **Hero Tagline (`Elevate the Sound.`)** | `15px` | 700 / Bold | `+0.02em` | `1.2` | Title Case |
| **Subheadings (`Sound in its purest state.`)** | `14px` | 500 / Medium | `+0.01em` | `1.4` | Sentence Case |
| **Body Paragraphs (About Grid)** | `13px` | 400 / Regular | `0.00em` | `1.65` | Sentence Case |
| **Hero Value Proposition (Bottom-Left)** | `13px` | 500 / Medium | `+0.01em` | `1.5` | Title / Sentence Case |
| **Navigation & Button Links (`HOME`, `BUY`, etc.)** | `11px`–`12px` | 600 / SemiBold | `+0.12em` | `1.0` | Uppercase |
| **Pagination & Footers (`01`, `TW IN FB`)** | `11px`–`12px` | 600 / SemiBold | `+0.15em` | `1.0` | Uppercase |

## 4. Layout & Grid Architecture

* **Viewport Width:** 100% full screen edge-to-edge layout (`1440px` standard base, fluid up to `2560px`).
* **Container Max Width:** `1280px` centered for content containers.
* **Horizontal Padding:** `48px` on desktop, `24px` on mobile/tablet.
* **Vertical Section Rhythm:** `120px` to `160px` between distinct functional blocks.

## 7. Interactive States & Micro-interactions

* **Navigation Links:** Hover opacity shifts from `0.7` to `1.0` with `transition: opacity 0.25s ease`.
* **Pill `BUY` Button:** Hover state inverses styling: `background: #FFFFFF`, `color: #000000`, `transition: all 0.3s ease`.
* **Carousel Thumbnail Capsules:** Hovering triggers subtle scale enlargement (`transform: scale(1.05)`) and increases background opacity to `rgba(255, 255, 255, 0.1)`.
* **Navigation Arrows (`Left <` / `> Right`):** Hover shifts chevron horizontally by `4px` (`transform: translateX(-4px)` for left, `translateX(4px)` for right).
* **Social Links & Text:** Hover shifts color from `#666666` to `#FFFFFF`.
* **Pagination Interaction:** Clicking on `02`, `03`, etc., slides the progress indicator bar smoothly along the baseline while switching the main active speaker image via cross-fade transition.
