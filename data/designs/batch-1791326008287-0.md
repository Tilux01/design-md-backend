# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Modern Dark & Light Dual-Mode Productivity App with Minimalist Editorial UI, high-contrast typography, asymmetrical card structures, and soft pastel accent highlights.
- **Visual Density & Whitespace Ratio**: High whitespace focus with asymmetric card paddings, generous border-radii (`24px` to `32px`), and distinct card boundaries ensuring clean section isolation.
- **Surface Elevation Model**: Deep dark mode background (`#0b0b0b`) layered with neutral dark surfaces (`#161616`, `#1f1f1f`), soft sage green containers (`#d5e0c5`), and vivid accent cards (`#f4ea92`, `#bfe3f7`).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-contrast pill badges (`Welcome Back`, `3 tasks`, `Growth: +15%`), circular avatar chips, minimal isometric image integration, floating bottom navigation docks.
- **Pill Badge Specification**: Padding `6px 14px`, font-size `12px`, font-weight `600`, border-radius `9999px`, background `#ffffff` or rgba translucent.
- **Symbol & Glyph Safety Mapping**:
  - Arrow Icon -> Use SVG paths for precise scaling.
  - Status Dot -> Use `<span className="w-2.5 h-2.5 rounded-full bg-emerald-500 inline-block" />`.

# 6. Exhaustive Component-by-Component Architectural Specs

## Component 1: Welcome Header
- **Layout & Positioning**: Flexbox row, space-between alignment, relative positioning, width 100%.
- **Box Model & Spacing**: Padding `24px 20px 16px 20px`, gap `12px`.
- **Borders, Radii & Shadows**: None.
- **Typography**: Avatar initials (14px, Bold, `#111111`), Subtitle ("WELCOME BACK" - 10px, Medium, `#8e8e93`), Title ("German!" - 24px, Bold, `#ffffff`).

- **Layout & Positioning**: Flexbox column, background `#d5e0c5`, text color `#1a2016`.
- **Box Model & Spacing**: Padding `24px`, border-radius `28px`, gap `16px`.
- **Typography**: "10 THU" (11px, SemiBold, Uppercase), "You have 3 tasks pending for today" (22px, Bold), "Work-to-do list for Voyager project" (13px, Regular, `#4a5243`).

- **Box Model & Spacing**: Padding `20px`, border-radius `28px`, gap `16px`.
- **Media**: Embedded high-resolution architectural interior photo with dark gradient overlay, overlaid circular user avatar group, and corner arrow action button.

- **Layout & Positioning**: Flexbox row, space-around, fixed/sticky bottom center, background `#161616`, border `1px solid rgba(255,255,255,0.08)`.
- **Box Model & Spacing**: Padding `12px 24px`, border-radius `9999px`, width `fit-content`, margin `0 auto 24px auto`.
- **Interactive Items**: Home icon in solid white pill container `#ffffff` with dark icon, grid menu icon, settings cog, user profile icon.
