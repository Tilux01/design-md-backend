# Comprehensive Design & Development Specification: "PIN RRY" Product Landing Page

---

## 1. Executive Summary & Design Overview

This specification details the creation of a full-screen, high-fidelity promotional landing page for a premium food/beverage product named **"PIN RRY"** (implied: Pink Berry). 

* **Art Direction:** Deep, rich, moody crimson-to-ruby-red aesthetic. It balances hyper-realistic 3D product rendering (floating raspberries, mint leaves, smoothie bowl) with clean, playful, bold typography and a modern glassmorphism UI overlay.
* **Layout Structure:** Immersive full-screen viewport. It features a floating glassmorphism browser/card container in the center that houses the primary hero interactions, navigation, and brand elements, set against a seamless radial gradient background.
* **Core Goal:** To build an exact, responsive clone focusing on rich visual layering, micro-interactions, floating physics, and polished UI components without container clipping.

* **Font Family:** *Inter*, *SF Pro Display*, or *Poppins* (Fallback: `sans-serif`).

## 5. Animation & Interaction Specification

To match the high-end presentation quality, incorporate the following CSS/JS animations:

1. **Floating / Levitation Loop (CSS Keyframes):**
   ```css
   @keyframes float {
     0% { transform: translateY(0px) rotate(0deg); }
     50% { transform: translateY(-10px) rotate(1deg); }
     100% { transform: translateY(0px) rotate(0deg); }
   }
   .hero-bowl {
     animation: float 6s ease-in-out infinite;
   }
   ```
2. **Parallax Mouse Movement:**
   * Implement a lightweight vanilla JS mouse-move listener that shifts floating elements (raspberries, mint leaves) slightly in opposing directions to create a 3D depth effect.
3. **Button Hover Micro-interactions:**
   * Smooth transitions (`transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1)`) on all interactive elements (nav links, buttons, carousel arrows).
