# Visual Design Specification & Implementation Blueprint

## 1. Global Layout & Canvas Strategy
* **Target Viewport:** Full-screen responsive viewport (`width: 100vw`, `height: 100vh`).
* **Background Color:** Soft neutral light grey (`#EBEFF0` or `#EAEFF1`).
* **Layout Paradigm:** Absolute/Relative positioning over a central anchor hub (`#WIFI DEVICES` symbol). Devices are positioned radially in a clock-face arrangement around the central Wi-Fi icon.
* **Responsive Scaling:** Scale via CSS `transform: scale()` anchored centrally based on a reference desktop viewport (`1440px` width), maintaining aspect ratios across mobile and tablet viewports.

---

## 2. Typography Specification

### Primary Font Stack
* **Font Family:** Hand-drawn / Comic Sans style display fonts.
* **Target Google Font:** `Permanent Marker`, `Bangers`, or `Architects Daughter` (used for the central arched banner).
* **Fallback Stack:** `'Comic Sans MS', 'Chalkboard SE', 'Marker Felt', cursive, sans-serif`.

### Text Element Styles
* **Central Banner Text ("WIFI DEVICES"):**
  * **Font Family:** `Permanent Marker`, cursive.
  * **Font Size:** `1.8rem` to `2.2rem` (fluid sizing via `clamp`).
  * **Color:** Deep charcoal/navy (`#1E2A38`).
  * **Text Transform:** Uppercase.
  * **Layout Effect:** Curved along the upper boundary of the blue Wi-Fi signal waves (implemented via SVG `<textPath>` for exact precision).

---

## 3. Color Palette Definitions

| Role | Color Name | Hex Code | Usage |
| :--- | :--- | :--- | :--- |
| **Background** | Light Silver-Grey | `#EAEFF1` | Global canvas backdrop |
| **Primary Blue** | Vibrant Sky Blue | `#38B6FF` | Wi-Fi waves, banner fill, device screens |
| **Dark Blue/Grey** | Outline & Shadows | `#1E2A38` | Hand-drawn stroke lines, device chassis, text |
| **Accent Yellow** | Camera Flash/Top | `#FFD60A` | Camera top indicator light |
| **Screen Cyan** | Bright Cyan | `#70E000` / `#9BF6FF` | Glow/display color on phone and tablet |

---

## 4. Component Breakdowns & Component Map

### A. Central Hub: "WIFI DEVICES" Icon
* **Structure:** 
  * An arch-shaped banner at the top reading **WIFI DEVICES**.
  * Three stacked, filled crescent arcs diminishing in size downward.
  * A solid filled circle at the bottom center.
* **Styling:** Thick hand-drawn vector outlines (`2.5px` solid `#1E2A38`), filled with solid Vibrant Sky Blue (`#38B6FF`).

### B. Connection Lines (Dashed Vectors)
* **Structure:** Dashed black/dark-blue vector strokes connecting the central Wi-Fi hub to each of the 5 peripheral devices.
* **Styling:** `stroke-dasharray: 6px 6px`, `stroke-width: 2.5px`, `stroke: #1E2A38`.

---

## 5. Peripheral Devices Breakdown

### 1. DSLR Camera (Top Left)
* **Orientation:** Angled slightly toward the center hub.
* **Key Visual Elements:**
  * Main body block with contoured grip.
  * Prominent protruding circular lens with concentric inner rings and a dark lens glass reflection.
  * Yellow flash housing at the top with a red power/indicator light dot.
  * Wi-Fi broadcast signal waves (3 curved arcs) emanating from the top right.

### 2. USB Wi-Fi Adapter / Dongle (Top Center)
* **Orientation:** Pointing diagonally down-left toward the hub.
* **Key Visual Elements:**
  * Rectangular silver USB plug with cutouts.
  * Dark grey plastic body casing with a small glowing teal activity LED.
  * Wi-Fi broadcast signal waves (3 curved arcs) emanating from the top.

### 3. Smartphone (Top Right)
* **Orientation:** Vertical portrait layout angled slightly left.
* **Key Visual Elements:**
  * Rounded rectangular phone body in dark charcoal.
  * Light cyan screen with diagonal abstract UI accent stripes.
  * Bottom physical/capacitive home circle button and top speaker slit.
  * Wi-Fi broadcast signal waves (3 curved arcs) emanating from the top left corner.

### 4. Tablet (Bottom Left)
* **Orientation:** Angled portrait layout pointing toward the center hub.
* **Key Visual Elements:**
  * Slim bezel tablet chassis in dark charcoal.
  * Bright cyan touchscreen with abstract UI glare/stripes.
  * Bottom center hardware button.
  * Wi-Fi broadcast signal waves (3 curved arcs) emanating from the top-left edge.

### 5. Laptop (Bottom Right)
* **Orientation:** Isometric perspective view.
* **Key Visual Elements:**
  * Open clamshell design with a screen displaying abstract UI/reflections.
  * Detailed keyboard base containing individual key grid lines and a trackpad.
  * Wi-Fi broadcast signal waves (3 curved arcs) emanating from the left side of the display lid.

---

## 6. Animation & Motion Specification

### Subtle Floating / Pulse Animation
To bring the static vector graphic to life, apply subtle CSS keyframe animations:

```css
/* Central Hub Pulse */
@keyframes wifi-pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.03); }
}

/* Device Floating Effect */
@keyframes float-gentle {
  0%, 100% { transform: translateY(0px) rotate(0deg); }
  50% { transform: translateY(-6px) rotate(0.5deg); }
}

/* Signal Wave Ripple Effect */
@keyframes signal-wave {
  0% { opacity: 0.3; transform: scale(0.95); }
  50% { opacity: 1; transform: scale(1.05); }
  100% { opacity: 0.3; transform: scale(0.95); }
}

.wifi-hub {
  animation: wifi-pulse 3s ease-in-out infinite;
}

.device-item {
  animation: float-gentle 4s ease-in-out infinite;
}

.signal-arcs {
  animation: signal-wave 2s ease-in-out infinite;
}
```
