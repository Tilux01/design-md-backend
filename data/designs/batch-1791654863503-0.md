# UI Design Specification: Minimalist Widget-Based Smartphone Home Screen

## 1. Global View & Layout Strategy
- **Orientation & Viewport:** Full-screen mobile view (derived from a portrait smartphone aspect ratio, typically ~9:19.5 or 9:20). The specification excludes any outer phone hardware frame/mockup; it focuses strictly on the active viewport/screen area.
- **Layout Paradigm:** Asymmetric grid system and card-based modular layout (reminiscent of iOS Widgets or Nothing OS minimalist styling).
- **Color Palette:** 
  - **Background:** Pure White (`#FFFFFF`) or off-white light mode.
  - **Primary Text / Icons:** Deep Charcoal / Near Black (`#1A1A1A` or `#000000`).
  - **Secondary Text / Muted Elements:** Medium Gray (`#767676`).
  - **Accent / Interactive Elements:** Monochromatic black with occasional high-contrast solid black pills or filled circles (e.g., `#000000`).
- **Spacing / Padding:** Generous whitespace with a consistent outer screen margin (approx. 16px–24px) and tight inner card padding (approx. 12px–16px rounded rectangular bounds with subtle borders or drop shadows, though clean flat styling is heavily favored here).

---

## 2. Typography & Font Stack
The UI utilizes a clean, modern, geometric sans-serif typeface (similar to **SF Pro**, **Inter**, or **Nothing Dot Matrix/Headline** fonts).

- **Primary Font Family:** `Inter`, `SF Pro Display`, `Roboto`, sans-serif.
- **Fallback Stack:** `font-family: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;`

### Hierarchy Specifications:
1. **Hero Display (Calendar Day Number):**
   - **Size:** ~56px–64px (Bold / Heavy weight)
   - **Weight:** 700 (Bold)
   - **Color:** `#000000`
2. **Widget Headers / Labels:**
   - **Size:** ~12px–14px (Uppercase or Capitalized)
   - **Weight:** 500–600 (Medium/Semibold)
   - **Color:** `#767676`
3. **Body / List Items:**
   - **Size:** ~13px–15px
   - **Weight:** 400 (Regular)
   - **Color:** `#1A1A1A`
4. **Dock / Navigation Icons:**
   - Minimalist stroke-based vector icons (Monoline, ~1.5px to 2px stroke width).

---

## 3. Detailed Component Breakdown (Top to Bottom)

### A. Top Widget Section (Two-Column Grid)
Divided into two primary modular cards taking up the upper third of the screen.

- **Left Card (Calendar Widget):**
  - **Top Sub-label:** "WED" + Date/Month indicator (e.g., "MAR") in small uppercase text (`~11px`, `#767676`).
  - **Hero Text:** Large numeric digit **"18"** positioned directly beneath the sub-label.
  - **Layout:** Left-aligned, vertical stack with generous breathing room.

- **Right Card (Weather / Status Widget):**
  - **Header:** "SUN" or weather condition label.
  - **Content:** Temperature indicator (e.g., "72°") accompanied by weather condition text ("Partly cloudy with light wind").
  - **Layout:** Left-aligned text hierarchy within a clean card boundary.

---

### B. Middle Grid Section (Secondary Widgets)
Two square or rectangular cards placed side-by-side below the top section.

- **Left Card (Metric / Data Widget):**
  - **Icon/Indicator:** Small minimalist icon at the top-left (e.g., graph or activity icon).
  - **Content:** Short text descriptor (e.g., "Activity" or a numerical metric summary).
- **Right Card (Quick Tool / Utility Widget):**
  - **Icon/Indicator:** Minimalist circular or square glyph representing the tool (e.g., battery status, alarm, or audio control).
  - **Content:** Short accompanying label.

---

### C. Vertical List Section (Reminders / Agenda / Notes)
A stacked list format with minimal separation lines or clean vertical spacing.

- **List Item Structure:**
  - **Leading Icon:** Tiny bullet point, checkbox ring, or category icon (left-aligned).
  - **Text Line:** Short task title or calendar event (e.g., "Team Sync at 2:00 PM").
  - **Subtext:** Optional secondary detail (e.g., time or location) in a lighter gray weight (`#888888`).
- **Interactive Elements within List:**
  - Includes a solid black circular floating action indicator or pill button on the right edge of the list area (`#000000` filled circle with white inner icon).

---

### D. Lower Banner Widget
- A wide, horizontal card spanning most of the screen width near the bottom.
- Contains subtle padding, faint placeholder lines or text representing recent media playback, notes, or a countdown timer.

---

### E. Bottom Dock (Application Icons)
Positioned fixed at the bottom edge of the screen over a clean white background.

- **Layout:** 4 to 5 evenly spaced minimalist icons.
- **Icon Style:** Monoline vector icons (outline style) representing standard apps:
  1. Phone / Messaging
  2. Browser / Globe
  3. Camera / Media
  4. Settings / Utility
- **Visual Treatment:** No background pill for the dock itself; icons float directly on the screen background with uniform sizing (`~24px` icon bounds).

---

## 4. Image & Graphic Assets Specifications
*Note: All UI graphics/icons are treated as vector assets (SVG format).*

- **Backgroundless State:** All UI cards, widgets, and icons are rendered without container backdrops unless explicitly defined as solid-border cards. Icons are backgroundless SVG vectors with transparent fills, inheriting stroke colors directly from the theme (`#1A1A1A`).
- **Placement & Rotation:** The screen layout is strictly vertical (2D orthographic plane). *(Note: The source reference image shows a perspective isometric device mockup, but this specification isolates the **pure UI surface** in flat 2D orthographic view as requested).*
