# Product List Page Design System & Layout Specification

## 1. Global Styles & Foundations

### Color Palette
- **Primary / Accent:** `#000000` (Pure Black for headers, borders, key text, and primary buttons)
- **Secondary / Neutral Dark:** `#333333` (Body text, subheadings)
- **Neutral Light Background:** `#F5F5F5` (App background, card backgrounds)
- **Card Background / Pure White:** `#FFFFFF` (Product card containers, search bars, dropdowns)
- **Muted Gray:** `#888888` (Secondary metadata, category counts, filter labels)
- **Border Gray:** `#E5E5E5` (Light structural borders and divider lines)
- **Accent Red (Price/Badges):** `#000000` (Used for active states/prices, keeping a monochrome minimal theme)

### Typography (Inter / Sans-Serif Stack)
- **Header Top (Website Branding):** 14px, Medium, Centered, `#333333`
- **Main Heading ("Product List Page"):** 48px, Bold, Centered, `#111111`
- **Nav Links ("Blogs", "FAQs"):** 12px, Medium, `#000000`
- **Hero Title ("Explore The Collection"):** 22px, Bold, `#000000`
- **Hero Subtext:** 11px, Regular, `#555555`
- **Section Heading ("Wink Collection"):** 20px, Bold, `#000000`
- **Filter Headers ("Brand", "Category", "Price"):** 11px, Bold, `#000000`, Uppercase/Normal mixed
- **Product Title:** 16px, Semi-Bold, `#000000`
- **Product Description:** 11px, Regular, `#666666`
- **Product Price:** 13px, Semi-Bold, `#000000`

---

## 2. Layout Structure & Grid

### Overall Canvas
- **Type:** Desktop Web Layout (Centered container with max-width ~1000px on a `#EAEAEA` background).
- **Margins / Padding:**
  - Outer page padding: Top 40px, Bottom 40px.
  - Inner content wrapper: Max-width 900px, centered horizontally.

### Grid Systems
- **Main Body Grid:** 2-Column asymmetrical layout.
  - **Left Sidebar (Filters):** Fixed width ~180px.
  - **Right Content Area (Products):** Flex/Grid layout containing a 3-column product grid.
- **Product Grid:** 3 columns, with ~16px horizontal and vertical gaps between cards.

---

## 3. Component Specifications

### A. Top Navigation Bar
- **Height:** 60px
- **Background:** `#FFFFFF`
- **Border-Bottom:** 1px solid `#E5E5E5`
- **Elements:**
  - **Left:** Hamburger menu icon (`☰`)
  - **Center:** Brand Logo (`WiiK` text/logo in stylized custom typography)
  - **Right:**
    - Links: "Blogs", "FAQs"
    - Icons: Notification bell, Shopping cart, User profile icon

### B. Secondary Sub-Header & Search Bar
- **Background:** `#FFFFFF`
- **Padding:** 12px 24px
- **Elements:**
- **Dropdown:** "Clothing" (with down chevron)
- **Pills / Quick Filters:** "New Arrivals", "Sale"
- **Search Input:**
  - Background: `#F4F4F6`
  - Border-radius: 20px (pill shape)
  - Placeholder: "Search..." with search magnifying glass icon on the right.
- **Category Filter Pills (Right):** "Men", "Women", "Children", "Brand"

### C. Hero Banner Section
- **Background:** Gradient/Solid light neutral gray (`#E8E8E8`) with embedded lifestyle image on the right.
- **Border-radius:** 8px
- **Height:** 180px
- **Content:**
  - Left/Center-Left: Overlapping hanger product imagery preview.
  - Right Side Text Block:
    - Eyebrow: `- Collections` (10px, uppercase, `#666`)
    - Title: "Explore The Collection of Wink Collection" (20px, bold)
    - Subtitle: "Don't miss out to shopping collection from us! You'll not be let down." (11px)

### D. Sidebar Filters
- **Width:** 180px
- **Sections:**
  1. **Brand:**
     - Header + "Reset" button (right-aligned, `#888`)
     - Checkbox list with counts:
       - Adidas (120) [Checked]
       - Zara (30)
       - Dickies (10)
       - Nike (8) [Checked]
       - Vans (8)
       - Uniqlo (8)
     - "Show more" pill button at the bottom.
  2. **Category:**
     - Checkboxes for Sneakers (120), T-Shirts (30), Jassen (10), Broeken (8), Sweaters (8), Overhemden (8), Boots (8).
     - "Show more" button.
  3. **Price Range:**
     - Slider track with dual handles (Min: 10K, Max: 5.000K)
     - Range indicators below (`10K`, `100K`, `1.100K`, `5.000K`)

### E. Product Cards (3-Column Grid)
- **Container:**
  - Background: `#FFFFFF`
  - Border-radius: 8px
  - Overflow: Hidden
  - Box Shadow: Subtle drop shadow (`0 2px 8px rgba(0,0,0,0.04)`)
- **Image Area:**
  - Aspect Ratio: ~4:5 (Portrait)
  - Background: `#F0F0F0` (Placeholder for model photography)
- **Card Content Area:**
  - **Padding:** 12px
  - **Title:** 15px, Bold (`#000000`) e.g., "Japan Green Outer"
  - **Description:** 10px, Regular (`#666666`), max 2 lines e.g., "Silk and linen blend polo shirt with stripes that fits slim"
  - **Footer inside Card:**
    - **Price:** `Rp 399.000` (Bold, 13px)
    - **Action Buttons (Right):**
      - Circular Red Heart / Favorite icon (Red background with white heart, or outlined)
      - Circular Black Shopping Bag icon (Black background with white bag)
