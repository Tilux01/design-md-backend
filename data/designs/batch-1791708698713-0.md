# Design Specification: P1 Modular Platform & Security Landing Page

## 1. Overall Layout & Global Styles
- **Viewport/Canvas:** Full-screen width layout (`max-width: 100%`), edge-to-edge responsiveness.
- **Background Color:** Pure white (`#FFFFFF`) throughout all primary sections.
- **Grid Structure:** Clean, minimalist whitespace-heavy layout following a modern tech hardware aesthetic (reminiscent of Tesla or VanMoof design language).

### Typography
- **Primary Font Family:** Clean, geometric sans-serif (e.g., *SF Pro Display*, *Inter*, *Helvetica Neue*).
- **Fallback Stack:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
- **Headings & Hierarchy:**
  - **Main Header (`<h1>`):** Large, light-to-regular weight heading (`font-weight: 300` to `400`), centered or left-aligned with ample line-height for readability.
  - **Section Titles (`<h2>`):** Bold and prominent (e.g., "Safety & Security Matters").
  - **Body / Descriptive Text:** Clean, dark gray (`#4A4A4A` or `#666666`) for optimized contrast.
