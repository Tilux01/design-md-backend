# Design Specification Document (`design.md`)

---

## 1. Overview & Aesthetic Direction
* **Style Theme:** Futuristic Dark Cyberpunk / Web3 / High-End Digital Art Showcase Landing Page.
* **Mood:** Mystical, high-tech, cinematic, immersive, dark-mode.
* **Canvas:** Fullscreen viewport (`100vw` × `100vh`), borderless, edge-to-edge layout without browser frames, device mockups, or outer margins.

### Lighting & Atmospheric Effects
* **Center Backdrop Glow:** A blurred radial gradient anchored at `50% X, 40% Y` behind the character head, creating depth and separating the dark glossy model from the void background.
* **Grain/Noise Overlay:** A subtle noise/dust texture overlay covering the background canvas (`opacity: 0.08`, `mix-blend-mode: overlay`) to give a grainy cinematic quality.

## 4. Visual Assets & Image Specifications

### 1. Environment & Background Asset
* **Description:** Dark cosmic noise background with a hazy, deep-space nebular texture consisting of fine purple, deep indigo, and faint teal specks/particles.
* **Format:** Fullscreen background element or CSS radial gradients combined with noise texture.
* **Placement:** Fixed, `top: 0`, `left: 0`, width `100vw`, height `100vh`, `z-index: 1`.

### 2. Main Hero 3D Model Asset (Foreground Subject)
* **Status:** Backgroundless PNG (Transparent background) or direct WebGL canvas render.
* **Subject Description:**
  * High-detail 3D bust rendering of a smooth, featureless human figure (head, neck, upper collarbone/shoulders).
  * **Material Surface:** Ultra-glossy, liquid-like black obsidian/chrome, reflecting ambient purple overhead highlights and white specular points.
  * **Emissive Element:** Intricate web of glowing, organic neon-purple internal channels/veins pulsing through the head, jawline, neck, and chest area.
* **Pose & Rotation:**
  * **Yaw (Y-axis):** Rotated approximately `25°` to `30°` towards the right.
  * **Pitch (X-axis):** Tilted upwards by `15°` to `20°` looking towards the top-right corner.
  * **Roll (Z-axis):** Subtle tilt (~`5°` clockwise).
* **Positioning & Layout Alignment:**
  * **Horizontal Alignment:** Center of canvas (`left: 50%`, `transform: translateX(-50%)`).
  * **Vertical Alignment:** Bottom edge anchored (`bottom: 0`). Head extends upwards to obscure the central letters (`A`, `N`, `S`, `C`) of the background title.
  * **Dimensions:** Occupies roughly `65%` to `75%` of the total viewport height (`vh`).
  * **Layer Depth:** `z-index: 3` (sits *above* the main background title text).

## 5. UI Layout & Component Architecture

```
+-----------------------------------------------------------------------+
|  [Logo]   CREATOR   COLLECTION   ABOUT               (Heart) (Search) EXPLORE |
|                                                                       |
|                       TR  [ 3D BUST ]  ND                             |
|                           [  HEAD   ]                                 |
|                           [ SUBJECT ]                                 |
|  Guided by the Glow       [  NECK   ]                                 |
|  In the haze of...        [SHOULDERS]                   @svg.graphixx |
+-----------------------------------------------------------------------+
```

### Layer Architecture (Z-Index Indexing)
1. **`z-index: 1`** – Background Canvas (Cosmic space texture + purple radial aura glow).
2. **`z-index: 2`** – Large Background Headline Text ("TRANSCEND").
3. **`z-index: 3`** – Foreground 3D Character Bust (Occludes the text behind it).
4. **`z-index: 4`** – Header Navigation Bar & Fixed Overlay UI Text (Top & Bottom metadata).

---

### UI Element Breakdown

#### A. Top Header / Navigation Bar (`z-index: 4`)
* **Container:** `display: flex`, `justify-content: space-between`, `align-items: center`.
* **Padding:** `top: 36px`, `left: 48px`, `right: 48px`.
* **Left Group:**
  * **Brand Logo:** Geometric hollow square outline (`22px` × `22px`, white stroke, `2px` thick) with an offset notch at the top-left corner.
  * **Nav Links:** `gap: 32px`. "CREATOR", "COLLECTION", "ABOUT". White text, `letter-spacing: 0.15em`, hover effect: slight opacity decrease (`0.7`).
* **Right Group:**
  * **Icon 1 (Heart):** Minimalist thin vector outline of a heart (`18px` × `18px`).
  * **Icon 2 (Search):** Minimalist thin vector magnifying glass (`18px` × `18px`).
  * **Spacing between icons:** `20px`.
  * **Spacing before primary action:** `32px`.
  * **Action Text:** "EXPLORE" in bold, condensed uppercase font.

#### B. Hero Headline ("TRANSCEND") (`z-index: 2`)
* **Content:** Text string "TRANSCEND".
* **Placement:**
  * `position: absolute`
  * `top: 42%` vertical center offset (`transform: translateY(-50%)`)
  * `left: 50%` (`transform: translateX(-50%)`)
  * `width: 92vw` (spans almost full width of screen)
  * `text-align: center`
* **Visual Texture:** Soft horizontal vintage paper/grunge grain embedded inside the fill color.

#### C. Bottom-Left Information Block (`z-index: 4`)
* **Placement:**
  * `position: absolute`
  * `bottom: 52px`
  * `left: 48px`

#### D. Bottom-Right Attribution Block (`z-index: 4`)
* **Placement:**
  * `position: absolute`
  * `bottom: 52px`
  * `right: 48px`
* **Content:** `@svg.graphixx`
* **Styling:** Monospace, light opacity white (`rgba(255, 255, 255, 0.8)`), right-aligned.
