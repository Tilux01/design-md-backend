# Design Specification: Calendar Web Application

This document provides the exact design specifications for recreating the calendar web application shown in the image. It covers layout structures, typography, color palettes, component details, and asset descriptions.

---

## 1. Global Layout & Structure

The interface is presented as a desktop browser window containing a web application with a **three-column layout** inside a dark-themed shell.

### Dimensions & Containers
*   **Browser Shell:** Dark grey rounded-corner window frame with standard macOS window controls (red, yellow, green buttons top-left) and an address bar reading `calendar.me`.
*   **Application Viewport:** Full-screen layout utilizing 100% of the available workspace height.
*   **Column 1 (Sidebar Navigation & Mini Calendar):** 
    *   Dark background (`#161618`).
    *   Width: ~25% of the viewport.
    *   Contains: Action buttons, user profile avatars, mini-calendar widget, "My Calendars", "Favorites", and "Categories" sections.
*   **Column 2 (Main Calendar Schedule Grid):** 
    *   Light/Gradient background (soft cyan to white).
    *   Width: ~75% of the viewport.
    *   Contains: Top navigation header, date selector bar (Tue 18 - Sun 23), and an hourly time-grid running from 8:00 AM to 2:00 PM+.
*   **Floating Modals:** A centered pop-up card ("Responsive Design") overlays the main calendar grid with a drop shadow.

---

## 2. Typography & Fonts

The typography uses a clean, modern, sans-serif font family similar to **Inter**, **SF Pro Display**, or **Roboto**.

*   **Primary Font Family:** `Inter`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, sans-serif.
*   **Fallback Strategy:** If `Inter` or system fonts fail to load, fall back to standard system sans-serif (`Arial`, `sans-serif`).

### Type Scale & Weights

*   **App Header / Month Titles ("October 2023"):**
    *   Weight: Bold (`700`)
    *   Size: 18px / 20px
*   **Day Headers on Grid (e.g., "18 Tue", "19 Wed"):**
    *   Weight: Medium (`500`) to Bold (`700`) for active days.
    *   Size: 14px (Day name), 20px-24px (Day number).
*   **Time Labels (8 am, 9 am, etc.):**
    *   Weight: Regular (`400`)
    *   Size: 12px
    *   Color: Muted grey (`#8E8E93`).
*   **Event Titles inside Cards (e.g., "Emails design", "UX meeting"):**
    *   Weight: Medium (`500`)
    *   Size: 12px / 13px
*   **Sidebar Labels ("My Calendars", "Work", "Personal"):**
    *   Weight: Regular (`400`) to Medium (`500`)
    *   Size: 13px

---

## 3. Color Palette

### Dark Sidebar Theme
*   **Background (Primary):** `#161618` (Deep dark grey/black)
*   **Background (Secondary/Cards):** `#1E1E22` (Slightly lighter dark grey)
*   **Text (Primary):** `#FFFFFF` (Pure White)
*   **Text (Secondary/Muted):** `#8E8E93` (Cool grey)
*   **Accent (Active/Selected):** `#7C3AED` (Vibrant Purple, used on the top-left menu icon button)
*   **Borders & Dividers:** `#2C2C30` (Dark subtle grey)

### Light Main Calendar Theme
*   **Background (Main View):** Soft gradient shifting from pale lime/yellow-green (`#E8F5B8`) to soft cyan/blue (`#D1EDF9`) at the top, transitioning down to pure white (`#FFFFFF`).
*   **Grid Lines:** `#E5E5EA` (Very light grey)
*   **Active Date Highlight (Tue 18):** Lime/Yellow-Green solid block (`#D0EE48`) with dark text.
*   **Event Cards (Purple Group):** Soft pastel purple (`#D8B4FE` or `#C4B5FD`) with dark text.
*   **Event Cards (Blue Group):** Soft pastel blue/cyan (`#BAE6FD`).
*   **Event Cards (Neutral/Gray):** Soft neutral grey-white (`#F1F5F9`).

## 4. Component Breakdown

### A. Left Sidebar
1.  **Top Navigation Controls:**
    *   Purple rounded square button with a white "X" icon.
    *   Black rounded square button with a white "+" (Add) icon.
2.  **User Profile Avatars:**
    *   A vertical stack of circular profile pictures (approx. 5-6 users), each showing a distinct portrait photograph. The top avatar has a subtle active border indicator.
    *   A "+" button at the bottom of the stack to add new users/profiles.
3.  **Mini Calendar Widget:**
    *   Header: "October 2023" with left/right pagination chevrons (`<` `>`).
    *   Days of the week row: `Mo Tu We Th Fr Sa Su` (Muted grey).
    *   Date grid numbers (1 to 31). The current date selected (**18**) is highlighted with a solid yellow-green/lime circular or rounded background badge.
4.  **Collapsible Sections:**
    *   **My Calendars:** Includes checkboxes for "Daily Tasks", "Birthdays", and "Tasks".
    *   **Favorites:** Section header with a chevron collapse icon.
    *   **Categories:** Bullet-point list with colored indicator dots:
        *   Blue dot (`#3B82F6`) — Work
        *   Pink dot (`#EC4899`) — Personal
        *   Green dot (`#10B981`) — Education
    *   **Bottom Profile Footer:** A horizontal row of three circular user avatars with a three-dot menu icon on the right.

### B. Main Calendar Grid
1.  **Top Action Bar:**
    *   Title: "October 2023" with pagination arrows.
    *   "Today" pill button (Dark background with white text).
    *   View Switcher tabs on the right: `Month` | `week` (active, highlighted white) | `Day`.
    *   Action buttons on the top right: "Join" (pill-shaped black button), share/export icon, plus icon, and window minimize/maximize icons.
2.  **Date Header Bar:**
    *   Horizontal row displaying days from Tuesday 18th to Sunday 23rd.
    *   **Tuesday 18** is styled as an accented block (lime-green background).
    *   Other days have simple text headers with date numbers below them.
3.  **Time Grid:**
    *   Vertical axis displaying hours from `8 am` down to `2 pm` (and continuing downward).
    *   Horizontal grid lines spanning across all days.
4.  **Scheduled Event Cards:**
    *   Rounded rectangular cards placed on the grid at specific times.
    *   *Examples visible:*
        *   "Emails design" (9:00 - 11:20) with mini participant avatars inside.
        *   "Youtube video" (8:20 - 9:40) in soft purple.
        *   "Designers meeting" (9:50 - 10:30).
        *   "Brain storm" (11:10 - 12:50).
        *   "Develop meeting" (12:10 - 1:40).
        *   "Landing Page" (8:00 - 10:00).
        *   "Study time" (8:00 - 9:20).
        *   "Motion design" (9:20 - 10:30) with avatars.

### C. Floating Modal ("Responsive Design")
*   **Container:** White background card with rounded corners and a soft drop shadow, overlaid on top of Wednesday's column.
*   **Header:** "Responsive Design" with an "X" close button in the top right.
*   **Tags / Filters:** Two rows of pill tags ("Projects", "Appointments", "Reminders", "Personal").
*   **Date Pickers:** Displays date entries ("Oct 12, 2023") with calendar icons and remove (`x`) buttons.
*   **Team Members Section:** Includes user avatar icons and an "Add teammates" input prompt.

## 5. Asset Descriptions (Images & Icons)

*   **User Avatars (Sidebar & Event Cards):** Real photographic headshots/portraits of diverse individuals cropped into exact circles. These should be substituted with placeholder avatars (e.g., Unsplash portraits) matching the layout positions.
*   **Icons:** 
    *   Standard vector glyphs (Feather Icons, Lucide, or FontAwesome equivalent) for: Search, Add (`+`), Close (`x`), Chevrons (`<` `>`), Menu dots (`...`), and Calendar icons.
