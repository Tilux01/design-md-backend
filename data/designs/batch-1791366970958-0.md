# Website Design Specification: Luova Studio Concept

This document outlines the exact design specifications for a full-screen, responsive web implementation of the provided design. It replicates the typography, layout, color palette, and component structure precisely.

---

## 1. Global Styles & Design Tokens

### Color Palette
*   **Primary Background (Dark):** `#18181a` (Deep Charcoal Black)
*   **Sidebar Background:** `#131315` (Slightly darker shade for depth)
*   **Text Primary (Light):** `#ffffff` (Pure White)
*   **Text Secondary (Muted):** `#a1a1aa` (Cool Gray)
*   **Accent Color (Yellow):** `#facc15` or `#eab308` (Warm Yellow)
*   **Image Grayscale Filter:** `grayscale(100%) contrast(110%)`

### Typography
*   **Primary Font Family:** `Inter`, `Helvetica Neue`, sans-serif
*   **Logo/Serif Font Family:** `Playfair Display`, `Georgia`, serif

#### Hierarchy
*   **Main Hero Title ("Design Thinking Overnights"):**
    *   *Size:* `clamp(2.5rem, 5vw, 4.5rem)`
    *   *Weight:* 300 (Light) / 400 (Regular)
    *   *Line Height:* `1.1`
*   **Navigation & Meta Text:**
    *   *Size:* `0.75rem` (12px)
    *   *Weight:* 500 (Medium)
    *   *Letter Spacing:* `0.1em` (Uppercase)
*   **Body / Subtitle Text:**
    *   *Size:* `0.875rem` (14px)
    *   *Weight:* 400

---

## 2. Layout Structure (Full Screen Grid)

The layout is divided into two primary sections:
1.  **Fixed Left Sidebar:** Contains hamburger menu, vertical text, page indicator, and social media icons.
2.  **Main Content Area:** Contains the top header, hero typography, interactive yellow frame CTA, and bottom-right "Next Article" preview.

```

|         |  [Yellow Box]  WHEN THE MORNING DAWNS             | |

+-------------------------------------------------------------+
```

## 3. Component Specifications

### A. Left Sidebar (`<aside>`)
*   **Dimensions:** Fixed width (`70px`), full viewport height (`100vh`).
*   **Background:** `#131315`
*   **Flexbox Layout:** `flex-direction: column`, `justify-content: space-between`, `align-items: center`, `padding: 2rem 0`.
*   **Elements:**
    1.  **Top:** Hamburger menu icon (`3 horizontal lines`).
    2.  **Middle:** Rotated vertical text `"SOCIAL MEDIA"` (`writing-mode: vertical-rl`, tracking spaced out). Below it, page indicator `"01/05"`.
    3.  **Bottom:** Vertical stack of social media icons (Instagram, Twitter/X, Facebook) in muted white/gray, transitioning to yellow on hover.

---

### B. Header (`<header>`)
*   **Position:** Absolute / Flex container at the top of the main content area.
*   **Alignment:** `justify-content: space-between`, `align-items: center`, `padding: 2.5rem 4rem`.
*   **Left Element:** Logo monogram `"N"` rendered in a high-contrast serif font (`1.75rem`, white).
*   **Right Navigation Links:**
    *   `WORKS`
    *   `ABOUT`
    *   `MAIL@LUOVA.STUDIO` (Accent yellow color for the email address or entire link string).

---

### C. Hero Section (`<main>` / Hero Content)
*   **Padding / Margins:** Generous left padding to align cleanly with the typography (`padding-left: 6rem`).
*   **Headline:**
    *   HTML structure:
        ```html
        <h1>
          Design<br>
          Thinking<br>
          Overnights
        </h1>
        ```
    *   Styling: Clean sans-serif, thin weight, strict alignment.

*   **Yellow Decorative Frame Component:**
    *   A rectangular outline positioned beneath the main title.
    *   *Border:* `2px solid #facc15` (Yellow)
    *   *Dimensions:* Approx. `width: 250px`, `height: 60px`
    *   *Content inside/beside:* A horizontal divider line extending left-to-right, followed by the text `"WHEN THE MORNING DAWNS"` in uppercase, tracked out.

---

### D. Hero Portrait (Right Side)
*   **Visual:** High-contrast black and white photography of a person looking upward/away.
*   **Styling:**
    *   Positioned on the middle-right of the viewport, vertically centered or subtly overlapping the right edge.
    *   CSS Filter: `filter: grayscale(100%) contrast(120%);`
    *   Soft gradient fade into the background on the left and bottom edges to blend seamlessly with `#18181a`.

---

### E. Next Article Widget (Bottom Right)
*   **Position:** Absolute / Fixed near the bottom right corner (`bottom: 3rem`, `right: 4rem`).
*   **Layout:** Flex row with a thumbnail image on the left and text details on the right.
*   **Thumbnail:** Small square image (`approx. 40x40px` or `48x48px`, border-radius small) showing a preview (e.g., yellow abstract objects).
*   **Text Stack:**
    *   *Label:* `"NEXT ARTICLE"` (Muted gray, `10px`, uppercase, letter-spacing).
    *   *Title:* `"The Idea Of God Is Not Henceforth Relevant"` (White, `12px`, medium weight).

---

## 4. Responsive Behavior (Breakpoints)

*   **Desktop (`> 1024px`):** Exact layout as specified above with fixed sidebar and split hero layout.
*   **Tablet (`768px - 1024px`):** Sidebar collapses into a top navigation bar or hamburger drawer. Portrait scales down or moves behind the text with an overlay.
*   **Mobile (`< 768px`):** Single column stack. Sidebar items move to a full-screen overlay menu. Typography scales down using `clamp()`. Portrait scales to full width with low opacity behind the primary text for readability.
