# Design System & Specification: FINDORA Mobile App

## 1. Typography & Colors

### Typography
* **Primary Font:** `Plus Jakarta Sans` or `SF Pro Display`
* **Fallback:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
* **Scale:**
  * Header 1 (Display): 28px / Bold (700)
  * Header 2: 22px / Bold (700)
  * Section Title: 16px / Semi-Bold (600)
  * Body / Subtitle: 13px–14px / Regular (400) & Medium (500)
  * Micro / Badges: 10px–11px / Semi-Bold (600)

### Color Palette
* **Primary Dark:** `#121212` (Buttons, Headings)
* **Accent Blue:** `#2F80ED` (Verification badges, Active nav)
* **Background Canvas:** `#FFFFFF` (Screens), `#F8F9FA` (Subtle backings)
* **Surfaces & Inputs:** `#F3F4F6` (Inactive chips, search field)
* **Text Colors:**
  * Primary: `#111827`
  * Secondary / Muted: `#6B7280`
  * Inverted: `#FFFFFF`
* **Rating Accent:** `#F59E0B` (Star icon)

---

## 2. Screen 1: Welcome / Onboarding

### Viewport & Layout
* **Dimensions:** 393 × 852 pt (iPhone standard full screen, responsive)
* **Structure:** Vertical two-part split.

### Top Hero Section (60% height)
* **Background Image:** Modern architectural house with dark wood siding and garden landscape.
* **Curved Mask:** Bottom edge features a concave upward arc (`border-bottom-radius: 48px` or SVG path mask).
* **Brand Overlay (Center-Aligned):**
  * **Logo Badge:** White circle (64×64 pt) containing dark emblem and text `"FINDORA DREAM HOUSE"`.
  * **Brand Title:** `"FINDORA"` (26px, Bold, `#FFFFFF`, uppercase).
  * **Tagline:** `"Dream House"` (14px, Medium, `#FFFFFF`, tracking +1px).

### Bottom Action Section (40% height)
* **Background:** Solid `#FFFFFF`.
* **Title:** `"WELCOME"` (22px, Extra Bold, `#121212`, centered, tracking +0.5px).
* **Subtitle:** `"Find your next space, feel at home\nWhere comfort meets convenience"` (13px, Regular, `#6B7280`, 2 lines, centered, line-height 1.4).
* **Button Group:**
  * **Primary (Login):** Full width (327 pt), height 52 pt, pill radius (`9999px`), background `#121212`, text `#FFFFFF` (15px, Semi-Bold).
  * **Secondary (Sign Up):** Full width (327 pt), height 52 pt, pill radius (`9999px`), border 1.5px solid `#D1D5DB`, background transparent, text `#121212` (15px, Semi-Bold).
  * **Spacing:** 12 pt gap between buttons.

## 3. Screen 2: Home / Discovery Screen

### Status & Header Bar
* **Top Spacing:** Safe Area inset (47 pt).
* **Location Chip (Left):**
  * Outlined pill badge: Pin icon + `"Kochi, Kerala"` (black pill or outlined badge).
* **Action Icons (Right):**
  * Bell icon with dot badge in circular gray container (`#F3F4F6`, 40×40 pt).
  * User avatar: 3D cartoon headshot in circular container (40×40 pt).

### Header & Search
* **Main Heading:** `"Discover\nYour New House"` (28px, Bold, `#121212`, line-height 1.2, left-aligned).
* **Search Field:**
  * Container: Height 48 pt, background `#F3F4F6`, corner radius 16 pt.
  * Left: Magnifying glass icon (`#9CA3AF`).
  * Placeholder: `"Search Place..."` (14px, `#9CA3AF`).
  * Right: Filter adjustment icon button (`#121212`).

### Category Chips (Horizontal Scroll)
* **Height:** 36 pt, pill radius (`9999px`).
* **Active State:** `"Rental House"` — Background `#121212`, text `#FFFFFF` (12px, Medium).
* **Inactive State:** `"Apartment"`, `"Houses"`, `"Rooms"` — Background `#F3F4F6`, text `#6B7280` (12px, Medium).
* **Gap:** 8 pt between items.

### Section Header
* **Text:** `"Nearby Rental House's"` (16px, Semi-Bold, `#121212`). Margin top: 16 pt, bottom: 12 pt.

### Listing Cards (2-Column Grid)
* **Grid Layout:** 2 columns, 12 pt gutter, 16 pt page padding.
* **Card Container:** Corner radius 18 pt, overflow hidden, aspect ratio 4:5.
* **Card Overlays:**
  * **Verified Icon (Top-Left):** Blue badge (`#2F80ED`) with white checkmark inside.
  * **Price Pill (Top-Right):** Frosted pill (`rgba(255, 255, 255, 0.45)`, blur 8px), text e.g., `"10.000/ Month"` (10px, Bold, `#FFFFFF`).
  * **Rating Badge (Bottom overlay):** White pill with gold star + `"4.5"` (10px, Bold).
  * **Property Title:** E.g., `"Georgie House"` (13px, Semi-Bold, `#FFFFFF`).
  * **Location:** Pin icon + `"Kochi, Kerala"` (11px, Regular, `#E5E7EB`).
  * **Gradient Scrim:** Bottom 40% linear gradient from transparent to `rgba(0, 0, 0, 0.75)` for legibility.

### Bottom Navigation Bar
* **Position:** Fixed bottom, docked or floating card with top border `#E5E7EB`.
* **Background:** Solid `#FFFFFF`, subtle top shadow (`0 -4px 16px rgba(0,0,0,0.04)`).
* **Items (4 tabs):**
  * `Home` (Active: `#2F80ED` filled house icon + label).
  * `Locations` (Inactive: Outline pin + label, `#9CA3AF`).
  * `Chat` (Inactive: Outline chat bubble + label, `#9CA3AF`).
  * `Settings` (Inactive: Outline gear + label, `#9CA3AF`).
* **Item Typography:** 10px, Medium.

---

## 4. Interaction & Animation Specs

* **Page Transitions:** Push transition (0.35s ease-out) between Welcome and Home screens.
* **Button Micro-interactions:** Scale down to `0.97` on press, 100ms response time.
* **Category Tabs:** Spring transition indicator with color cross-fade (200ms ease).
* **Card Entrance:** Subtle stagger fade-in and slide-up (Y: +12px) upon view load.
