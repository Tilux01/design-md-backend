# Design System & Specifications

## 1. Global Styles & Variables

### Typography
- **Primary Font Family:** Inter, sans-serif (or system default sans-serif)
- **Brand Logo Font:** Heavy/Bold sans-serif, uppercase
- **Font Sizes:**
  - Logo: `14px` / Letter-spacing: `2px` / Weight: `700`
  - Navigation Links: `11px` / Uppercase / Weight: `400` / Letter-spacing: `1px`
  - Card Index (`01.`, `02.`, etc.): `14px` / Weight: `600`
  - Card Title: `16px` / Weight: `700`
  - Card Category/Tag: `9px` / Uppercase / Weight: `600` / Letter-spacing: `1.5px`
  - Footer Text ("All Rights Reserved"): `10px` / Weight: `400`

### Colors
- **Background (App Viewport):** `#222429` (Dark charcoal mockup frame)
- **Page Background / Main Canvas:** `#17181c` (Deep dark slate)
- **Text Primary (White):** `#ffffff`
- **Text Muted (Subtitles/Tags):** `#9da3af` (Light cool gray)
- **Accent Color (Active State / Slider Track):** `#7c5cff` (Vibrant purple)
- **Inactive Track Color:** `#2e3038` (Dark neutral gray)
- **Overlay Gradient (Image Bottom Shadow):** `linear-gradient(180deg, rgba(0,0,0,0) 40%, rgba(0,0,0,0.85) 100%)`

---

## 2. Layout & Structure

- **Viewport Size:** Fullscreen immersive grid layout (100vw × 100vh)
- **Container Structure:**
  - Fixed Header (Top absolute positioning)
  - Horizontal Multi-Column Slider (Main Content area)
  - Fixed Footer (Bottom absolute positioning)

### Grid System (Main Content Area)
- **Columns:** 4 equal-width vertical panels spanning horizontally.
- **Panel Width:** `25%` each relative to container width.
- **Height:** `100vh` minus header/footer spacing (or full bleed `100vh`).
- **Gap/Spacing:** No gap between panels (edge-to-edge seamless imagery).

---

## 3. Component Specifications

### A. Header
- **Positioning:** Absolute top, `z-index: 10`, full width, padded horizontally (`40px`).
- **Height:** `80px`
- **Left Element:** 
  - Logo icon (Bird silhouette vector) + Text "HUGINN"
  - Spacing between icon and text: `12px`
- **Center/Right Elements:**
  - Navigation Menu Links: `HOME`, `ABOUT`, `WORK`, `CONTACT`
  - Spacing between links: `30px`
  - Menu Hover State: Opacity transitions from `0.7` to `1.0`.
- **Right Utilities:**
  - Hamburger menu icon (left side of nav)
  - Search icon (far right corner)

### B. Image Panels (Cards 01 to 04)
Each panel acts as an immersive background image card with overlaid typography.

- **Panel 01:**
  - **Image:** Venice canal with gondola and historic architecture.
  - **Content Placement:** Bottom-left aligned (`padding: 40px`)
  - **Index:** `01.`
  - **Title:** `Beautiful Venice`
  - **Category:** `TRAVEL`

- **Panel 02:**
  - **Image:** Interior room with wooden bench, sunlight filtering through window.
  - **Content Placement:** Bottom-left aligned (`padding: 40px`)
  - **Index:** `02.`
  - **Title:** `Lovely Room`
  - **Category:** `INTERIOR`

- **Panel 03:**
  - **Image:** Misty mountain landscape over ocean waters.
  - **Content Placement:** Bottom-left aligned (`padding: 40px`)
  - **Index:** `03.`
  - **Title:** `Amazing Mountain`
  - **Category:** `LANDSCAPES`

- **Panel 04:**
  - **Image:** Portrait of a stylish man in a fedora, bowtie, and round glasses against a textured backdrop.
  - **Content Placement:** Bottom-left aligned (`padding: 40px`)
  - **Index:** `04.`
  - **Title:** `Street Portrait`
  - **Category:** `PORTRAITS`

### C. Footer & Navigation Controls
- **Positioning:** Absolute bottom, full width, padded horizontally (`40px`), height `60px`.
- **Left Element:** Copyright text (`© All Rights Reserved 2017`) in muted gray (`10px`).
- **Center Element:** Custom progress/pagination slider track.
  - Track width: `120px`
  - Track height: `2px`
  - Active indicator bar: Purple (`#7c5cff`), width approx `35%`.
- **Right Element:** 
  - Subtle directional navigation arrows (`←` / `NEXT →`) positioned subtly near card edges/corners.

---

## 4. Interactive States & Animations
- **Hover on Panels:** Slight zoom-in effect on background image (`scale(1.03)` with smooth cubic-bezier transition).
- **Active Panel:** Enhanced brightness/contrast and clearly legible typography hierarchy.
- **Transition:** Smooth horizontal slide animation when switching between active panels.
