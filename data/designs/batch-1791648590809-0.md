## 1. Global Styles & Design System

### 1.1 Color Palette
*   **Background (Primary Dark):** `#09090b` (Deep obsidian/near-black used for the core canvas).
*   **Surface Cards / Containers:** `#121216` to `#16161c` (Slightly elevated dark gray with glassmorphism touches, subtle inner borders).
*   **Primary Text (Headings):** `#ffffff` (Pure white for high-impact titles and primary copy).
*   **Secondary Text (Subheadings/Descriptions):** `#9ca3af` to `#a1a1aa` (Muted cool gray for body text, subtitles, and descriptions).
*   **Accent Gradient (Primary):** Linear gradient shifting from white/silver (`#ffffff`) through metallic gray (`#94a3b8`) to deep charcoal (`#334155`).
*   **Card Border & Strokes:** Semi-transparent white (`rgba(255, 255, 255, 0.08)` to `rgba(255, 255, 255, 0.15)`).

### 1.2 Typography
*   **Primary Font Family:** Inter (Fallback: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`).
*   **Scale Specifications:**
    *   *Hero Heading:* 56px–64px, Font Weight: 700 (Bold), Line Height: 1.1.
    *   *Section Headings:* 36px–42px, Font Weight: 600 (Semi-Bold), Line Height: 1.2.

    *   *Badges & Micro-Copy:* 11px–12px, Font Weight: 500 (Medium), Letter Spacing: 0.05em, Uppercase.

## 4. Implementation Guidelines & CSS Best Practices

1.  **Layout Engine:** Use CSS Flexbox and CSS Grid exclusively for structural alignment. Ensure all grids collapse gracefully to single-column layouts on mobile viewports (< 768px).
2.  **Glassmorphism & Depth:** Apply `backdrop-filter: blur(12px)` combined with semi-transparent background fills (`rgba(18, 18, 22, 0.75)`) and subtle border strokes (`1px solid rgba(255, 255, 255, 0.08)`) to all cards and navigation bars to replicate the modern dark-mode aesthetic.
3.  **Color Consistency:** Strictly adhere to the primary dark background (`#09090b`) across the entire scroll canvas to maintain a seamless, immersive presentation.
