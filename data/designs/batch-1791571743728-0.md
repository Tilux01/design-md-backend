# Design Specification: "Dei" Learning Platform Dashboard

## 1. Global Layout & Structure
- **Viewport/Canvas**: Full-screen responsive layout (designed for a wide desktop viewport, approximately 1440px wide).
- **Global Background**: Soft, airy cyan-blue gradient background (`#E6F4F8` fading out to pure white or very light pastel cyan).
- **Main Container**: Centered floating dark-mode dashboard card with rounded corners (`border-radius: 32px`), deep black background (`#0A0A0C`), and a subtle outer shadow.
- **Color Scheme**:
  - **Primary Background (Dashboard)**: `#0A0A0C` (Deep Rich Black)
  - **Sidebar/Navigation Surface**: Dark charcoal `#141417`
  - **Card Surfaces**: Off-white / Pure White (`#FFFFFF`) with subtle tints for specific states (e.g., pastel pinks, greens, yellows, blues).
  - **Text Colors**: Dark charcoal/black (`#1D1D21`) for high contrast on light cards; white (`#FFFFFF`) and muted grey (`#9E9EA6`) on dark surfaces.

- **Primary Font Family**: **Inter** (Fallback: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`).

  - **App Title ("Dei")**: 22px, Bold, White.

  - **Card Titles (e.g., "Medical Terminology")**: 18px, Bold, Dark (`#111115`).
  - **Body / Descriptions**: 13px–14px, Regular, Muted grey-black (`#55555D`).
  - **Meta / Metadata / Timestamps / Badges**: 11px–12px, Medium/Semi-bold.
