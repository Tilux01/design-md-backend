# Design Specification: Chokeberry Kombucha Promotional Poster

This document provides the exact design specifications to clone the provided media into a fully responsive, full-screen web layout. 

*Note: The outer gradient frame and drop shadow present in the presentation image are excluded; the layout below is designed for full-screen view.*

---

## 1. Global Layout & Colors

### Color Palette
*   **Background (Canvas):** `#EEDDF4` (Soft, pale lavender)
*   **Primary Text & Brand Elements:** `#1A1A1A` (Near black)
*   **Secondary Text / Subheadings:** `#333333` (Dark gray)
*   **Accent Color (Pink/Magenta Shapes & Highlights):** `#C24C96` (Used for background blobs, icons, and label details)
*   **Bottle/Liquid Tones:** Amber glass (`#8B5A2B`), rich purple chokeberries (`#7B1E5C`)

### Canvas & Grid Structure
*   **Viewport:** Full-screen (`width: 100vw`, `height: 100vh`, `overflow: hidden`)
*   **Layout Engine:** CSS Grid or Absolute Positioning relative to a centered container to maintain spatial relationships across different screen sizes.

---

## 2. Typography & Fonts

To replicate the exact look, use geometric, heavy-weight sans-serif fonts for headings and clean sans-serif fonts for body text.

### Font Pairing
1.  **Primary Display Font (Header):**
    *   *Font Family:* **Montserrat** (Weight: 800 - Extra Bold) or **Inter** (Weight: 900).
    *   *Fallback:* `sans-serif`
    *   *Usage:* "Chokeberry" title.
2.  **Body & Copy Font:**
    *   *Font Family:* **Inter** or **Roboto** (Weights: 400 - Regular, 600 - Semi-Bold).
    *   *Fallback:* `sans-serif`
    *   *Usage:* Promotional paragraph, capacity specs, ingredients list.

---

## 3. Element-by-Element Breakdown

### A. Header Section (Top Left)
*   **Text:** "Chokeberry"
*   **Styling:**
    *   Font Size: Large display (`clamp(3rem, 6vw, 6rem)`)
    *   Letter-spacing: Tight (`-0.03em`)
    *   Color: `#1A1A1A`

### B. Promotional Copy (Middle Left)
*   **Text Block:**
    > Seeking for unforgettable taste sensations?
    > Our exclusive chokeberry kombucha is right for you.
*   **Styling:**
    *   Font Size: `0.85rem` to `1rem`
    *   Line Height: `1.5`
    *   Max Width: `220px`
    *   Color: `#333333`

### C. Background Organic Shapes (Blobs)
*   **Shapes:** Three overlapping soft pink/magenta blob vectors (`#C24C96` with opacity `~0.8` or solid soft tones) positioned behind the bottle.
*   **Vector Doodles:** Thin-line floral/starburst line art icons placed strategically on top of the blobs (top left, top right, bottom right of the central cluster).

### D. Central Product Imagery (The Bottle)
*   **Asset:** A 330ml amber glass bottle of kombucha rotated at an approximate **15-degree clockwise angle**.
*   **Label Details:**
    *   Logo: "HOMBCH" (or stylized kombucha branding).
    *   Illustration: Chokeberry graphics.
    *   Bottom accent band: Magenta/purple matching the theme.
*   **Positioning:** Centered slightly offset to the right of the canvas, overlapping the pink background blobs.

### E. Specifications & Ingredients (Right Side)
*   **Volume:** "330 ml" (Font Weight: Bold, size: `1.2rem`)
*   **Dividers:** Thin horizontal rules (`border-top: 1px solid #D1B3D8`) separating sections.
*   **Ingredient List:**
    *   `fermented carbonated tea`
    *   `chokeberry juice`
    *   `non-alcoholic`
*   **Styling:** Small, clean sans-serif text (`0.8rem`), spaced evenly vertically.

---

## 4. Animation Specifications (Interactive / Motion)

If building this as an animated web banner or landing page hero, apply the following CSS keyframes:

1.  **Bottle Entrance & Floating Animation:**
    *   *Effect:* Smooth float up-and-down with a slight tilt rotation.
    *   *CSS Keyframes:*
        ```css
        @keyframes float {
            0% { transform: translateY(0px) rotate(15deg); }
            50% { transform: translateY(-10px) rotate(17deg); }
            100% { transform: translateY(0px) rotate(15deg); }
        }
        .bottle {
            animation: float 4s ease-in-out infinite;
        }
        ```

2.  **Background Blob Pulse:**
    *   *Effect:* Subtle scaling of the pink background shapes to give organic life to the scene.
    *   *Duration:* `6s ease-in-out infinite alternate`.

3.  **Fade-In on Load:**
    *   *Effect:* Text elements fade in sequentially from bottom to top using `opacity` and `transform: translateY()`.
