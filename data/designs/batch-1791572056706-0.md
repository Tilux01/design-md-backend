# UI/UX Specification Document: HR & Payroll Dashboard

---

## 1. Global Layout & Canvas Architecture

*   **Viewport & Resolution:** Designed for wide screens (target resolution: `1440px × 960px` base canvas). The layout utilizes a fluid, responsive CSS Grid system centered on a dark canvas.
*   **Color Palette (Dark Mode Base):**
    *   **Primary Background (Canvas):** `#0c0d10` (Deep near-black)
    *   **Surface / Card Background:** `#13151a` (Slightly elevated dark gray-blue)
    *   **Card Border / Dividers:** `#1f2229` (Subtle 1px border lines)
    *   **Text Primary (Headings):** `#ffffff` (Pure white)
    *   **Text Secondary (Labels/Subtitles):** `#8b90a0` (Muted gray-blue)
    *   **Accent Gradient (Brand/Interactive):** Linear gradient from `#d946ef` (Fuchsia/Pink) to `#6366f1` (Indigo/Purple)
    *   **Status Indicators:**
        *   *Paid (Success):* Background `#112317`, Text `#22c55e` (Emerald Green)
        *   *Pending (Warning):* Background `#262013`, Text `#eab308` (Amber Yellow)
*   **Typography System:**
    *   **Primary Font Family:** *Inter*, with fallbacks `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
    *   **Secondary/Monospace Font (for financial digits):** *Plus Jakarta Sans* or *Inter* with tabular-nums enabled (`font-variant-numeric: tabular-nums`).
