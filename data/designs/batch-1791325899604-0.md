# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Dark Mode Glassmorphism & High-Density Financial SaaS Dashboard.
- **Visual Density & Whitespace Ratio**: High functional density with tight inner spacing (8px–16px), balanced by distinct dark charcoal surface layering and glowing highlights to create clear visual hierarchy.
- **Surface Elevation Model**: Multi-tier dark canvas architecture featuring a primary deep background (`#0b0d13`), elevated cards (`#141721`), floating interactive pills (`#1a1d28`), and a vertical navigation dock with soft ambient boundary borders (`#1f2430`).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Ambient status pips, high-tracking uppercase financial category subtitles, glassmorphic dark container overlays, clean typographic contrast.
- **Pill Badge Specification**: Padding: `4px 12px`, Font-size: `12px`, Font-weight: `600`, Tracking: `0.05em`, Border-radius: `9999px`, Background: `rgba(16, 185, 129, 0.1)`, Border width: `1px` solid `rgba(16, 185, 129, 0.2)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content to prevent rendering glitches.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;` or `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
