# Design Specification: Pinterest Pin Detail & Login Modal Clone

## 1. Overview
This specification details the UI layout, typography, colors, spacing, and interactivity of the Pinterest pin detail view with a superimposed login/signup modal. The layout is responsive, structured with CSS Flexbox/Grid, and uses modern web design patterns.

---

## 2. Global Styles & Typography

### 2.1 Fonts
- **Primary Font Family:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Oxygen-Sans, Ubuntu, Cantarell, "Fira Sans", "Droid Sans", "Helvetica Neue", Helvetica, "ヒラギノ角ゴ Pro W3", "Hiragino Kaku Gothic Pro", Meiryo, メイリオ, "ＭＳ Ｐゴシック", Arial, sans-serif`
- **Fallbacks:** System sans-serif stack ensuring native look across macOS, Windows, iOS, and Android.
- **Font Weights Used:**
  - Regular (`400`)
  - Medium (`500`)
  - Bold (`600` / `700`)

### 2.2 Color Palette
- **Background (Base):** `#FFFFFF`
- **Modal Overlay Backdrop:** `rgba(0, 0, 0, 0.45)` (approximate translucent dark grey)
- **Primary Red (Pinterest Brand):** `#E60023`
- **Primary Red Hover:** `#AD081B`
- **Text Dark (Headers/Primary):** `#111111`
- **Text Muted (Secondary/Metadata):** `#767676`
- **Border/Divider Color:** `#E1E1E1`
- **Input Background:** `#FFFFFF`
- **Input Border:** `#CDCDCD`
- **Input Focus Border:** `#000000`

---

## 3. Layout & Components

### 3.1 Header Navigation Bar
- **Position:** Fixed / Sticky top.
- **Height:** `60px` to `80px`.
- **Left Section:**
  - Pinterest Logo (Red circular icon + text).
  - "Explore" link.
- **Center Section:**
  - Expanded search bar with rounded pill shape (`border-radius: 24px`), light grey background (`#EFEFEF`), containing a search icon and placeholder text (e.g., *"search for agency website design"*).
- **Right Section:**
  - "Log in" button (rounded pill, neutral background/hover).
  - "Sign up" button (rounded pill, Pinterest red background with white text).

---

### 3.2 Pin Detail View (Underlying Page)
- **Container:** Centered card layout with a maximum width of roughly `1000px`.
- **Left Column (Media Preview):**
  - Large interactive image/video preview of the website UI design ("BUILD THE FUTURE").
  - Rounded corners (`border-radius: 16px` or `24px`).
  - Hover action overlay icons (e.g., maximize/explore button at the bottom right).
- **Right Column (Metadata & Actions):**
  - **Top Action Bar:**
    - Share icon, ellipsis (more options) icon, Save/Pin button, and red "Download image" button.
  - **Source Link:** `www.behance.net` (small muted text).
  - **Title:** "Website UI Inspiration | Modern Web Design, Landing Pages & Clean Layouts" (Bold, `24px`+ font size).
  - **Description:** Multi-line paragraph detailing modern landing page inspiration, responsive web sections, etc.
  - **Uploader Profile:** Circular avatar image next to username ("Noah") with follower count/metadata.
  - **Comments Section:** Header with toggle/count.

---

### 3.3 Authentication Modal (Overlay)
- **Position:** Fixed centered modal window.
- **Dimensions:** Max width ~`480px`, auto height, rounded corners (`border-radius: 32px`).
- **Shadow:** Deep drop shadow (`0 8px 16px rgba(0,0,0,0.15)`).
- **Elements:**
  1. **Logo:** Centered Pinterest red pin icon.
  2. **Heading:** "Welcome to Pinterest" (Bold, large header).
  3. **Subheading:** "Log in to discover more ideas just for you" (Muted, smaller).
  4. **Form Inputs:**
     - **Email / Username field:** Labeled placeholder, standard rounded input border.
     - **Password field:** Includes a show/hide eye toggle icon on the right.
  5. **Action Buttons:**
     - **Log in (Primary):** Full-width red pill button (`#E60023`).
     - **Alternative Logins:**
       - "Continue with Google" (White button with Google G icon, subtle border).
       - "Continue with QR code" (White button with QR icon).
  6. **Footer Links:**
     - "Not on Pinterest? **Sign up for free**"
     - Terms of Service, Privacy Policy, Notice at Collection links at the bottom.

---

### 3.4 Floating Notification Banner (Bottom Right)
- **Position:** Fixed bottom-right corner.
- **Content:** "You are signed out" prompt with quick-action buttons ("Continue with email", "Continue with Google").
- **Styling:** White card with subtle shadow and close/dismiss button.

---

## 4. Animations & Transitions
- **Modal Entrance:** Fade-in backdrop with a smooth scale-up animation (`transform: scale(0.95) -> 1`, `opacity: 0 -> 1` over `200ms` with `ease-out`).
- **Hover States:** Button color transitions (e.g., red background darkening on hover) over `150ms`.
- **Search Bar Expansion:** Smooth width transition when focused.
