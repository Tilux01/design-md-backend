# UI Design Specification: Neumorphic Financial Dashboard

## 1. Global Layout & Structure

The interface is presented as a full-screen, horizontally split financial dashboard designed with a sophisticated **Neumorphic (Soft UI)** aesthetic. The color palette revolves around soft, desaturated sage-teal/mint-gray tones with layered translucency and subtle drop shadows.

```
+-----------------------------------------------------------------+
| [Sidebar] | [Section 1: My Digital Cards] | [Section 2: Trans.] |
|           |                               |---------------------|
|           |                               | [Section 3: Affil.] |
+-----------------------------------------------------------------+
```

### Canvas & Window Properties
*   **Viewport:** Fullscreen (100vw × 100vh), centered.
*   **Background:** Radial gradient transitioning from a muted mint-teal (`#D0E2DD`) in the center to a deeper slate-teal (`#8FA8A3`) at the outer edges.
*   **Main Container:** A large, pill-shaped/rounded rectangle window holding the internal grids with a light, semi-translucent frosted glass effect (`background: rgba(235, 243, 240, 0.85)`).
*   **Border Radius:** Large rounded corners (approx. `32px` to `40px` for the main card wrappers).

---

## 2. Typography & Fonts

*   **Primary Font Family:** Inter, sans-serif.
*   **Fallback Font Stack:** `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
*   **Font Weights Used:** Regular (400), Medium (500), Semi-Bold (600), Bold (700).

### Text Hierarchy
*   **Section Headers ("My Digital Cards", "Transactions", "Affiliate income"):**
    *   Size: `18px` – `20px`
    *   Weight: Semi-Bold (600)
    *   Color: Dark slate-charcoal (`#2C3E3B`)
*   **Subheadings / Secondary Labels ("Connect all your cards", "Current transfers"):**
    *   Size: `12px` – `13px`
    *   Weight: Regular (400)
    *   Color: Muted gray-teal (`#7A928E`)
*   **Body & Numeric Data (Card balances, amounts):**
    *   Size: `14px` – `28px` (Large display values like `$59,850.00` at `28px`)
    *   Weight: Bold (700)
    *   Color: Deep charcoal (`#1A2825`)

---

## 3. Left Sidebar Navigation

A dark, vertical pill-shaped sidebar docked to the left edge of the main container.

*   **Background Color:** Dark slate-navy (`#1E2A2E`).
*   **Width:** Approx. `80px`.
*   **Top Element:** Logo area containing the brand mark **"Nom"** in a clean, bold white font inside a rounded dark container, with a user profile pill below it.
*   **Navigation Icons:**
    *   Vertical stack of outlined/filled monochromatic white/gray icons (Dashboard, Wallet/Cards, Analytics, Profile settings, Messages, Settings gear).
    *   **Active State:** The "Wallet" icon features an active white background pill with a dark icon (`#1E2A2E`) to indicate the current view.
*   **Bottom Element:** User identifier ("Nikitin") with a minimalist monogram avatar logo.

---

## 4. Column 1: "My Digital Cards"

### 4.1. Main Credit Card Component
*   **Container:** A frosted white glassmorphism rounded card (`background: rgba(255, 255, 255, 0.6)`, border-radius: `20px`).
*   **Header:** "Universal Bank" with a chip icon on the top-right.
*   **Balance Display:** Large bold text `"$59,850.00"` with a secondary smaller currency tracking string (`"$895,235.50"`).
*   **Card Footer:** Standard dual-circle overlapping credit card branding logo (Mastercard style: orange and red overlapping circles) on the bottom-left.
*   **Pagination Dots:** Four small circular dots below the card indicating carousel status (first dot active as a pill).

### 4.2. Action Buttons (Withdraw, Invite, Sell)
Three distinct pill-shaped gradient/solid action buttons styled with soft neumorphic shadows:
1.  **Withdraw:** Warm gradient coral-orange (`#F97352`) with a white arrow-up icon and text.
2.  **Invite:** Vibrant teal (`#00A896`) with a user-plus/gift icon and text.
3.  **Sell:** Soft purple-violet (`#A855F7`) with a shopping basket icon and text.

### 4.3. Add New Card Button
*   Dashed or subtle inset border button spanning the width: `[ + ] Add New Card`.

### 4.4. Quick Transfer Section
*   **Header:** "Quick Transfer" / "Connect All Your Cards"
*   **Avatar Row:** Horizontal scroll of circular user avatars with glowing green online indicators or neutral borders. Includes an initial fallback monogram ("ab").
*   **Card Number Input:**
    *   Neumorphic inset text field showing masked card details (`4321 5612 3242 2323`).
    *   Trailing icon: Barcode/QR scan icon.

---

## 5. Column 2: Transactions & Affiliate Income

Divided into two major vertical sections.

### 5.1. Transactions Panel ("Current transfers")
*   **Header Controls:** Filter icons on the top-right (sort, calendar).
*   **Transaction List Items:** Each row contains:
    1.  **Avatar:** Circular thumbnail photograph of the user.
    2.  **Name & Handle:** Bold name (e.g., "Yulia Polishchuk") with gray handle below (`@thisisyulia`).
    3.  **Status Badge:**
        *   *Complete:* Green dot with "Complete" label (`#10B981`).
        *   *Fail transfer:* Orange/Red dot with "Fail transfer" label (`#F59E0B`).
    4.  **Timestamp:** Relative time ("02 Minutes Ago", "Yesterday, 12:34").
    5.  **Amount:** Right-aligned monetary value. Green for positive (`+$675.00`), dark/neutral for negative (`-$50.00`, `-$95.00`).

### 5.2. Affiliate Income Dashboard Widget
*   **Container:** Soft white card background matching the main theme.
*   **Header:** "Affiliate income" with time-range tabs on the right (`Last Week` | `This Month` [Active] | `All Time`).
*   **Donut Chart / Progress Rings:**
    *   A multi-colored segmented circular progress chart.
    *   Segments colored in teal (`23%`), orange (`37%`), purple (`23%`), and green (`17%`).
    *   Center text displays total income: `"$5,980,237.50"` with label `"Total income"`.
*   **Statistics Breakdown Grid:** Four columns detailing income levels:
    *   *Level 1:* `$3,500.00` (37%)
    *   *Level 2:* `$5,500.00` (23%)
    *   *Level 3:* `$7,500.00` (17%)
    *   *Level 4:* `$10,000.00` (23%)
*   **Footer Link:** `"Customize board with Pro >"` centered at the bottom with a settings icon.
