# Design Specification: "Luscious" Food Landing Page

## Global Styles & Tokens

### Typography
- **Primary Font Family:** Serif (fallback: `Georgia, serif`), sans-serif for UI elements (`Inter, sans-serif`).
- **Heading 1 (Main Hero Title):** 
  - Font Size: `48px` / `3rem` (Fluid scaling up to `64px`)
  - Line Height: `1.1`
  - Font Weight: `700` (Bold)
  - Color: `#1a1a1a` (Off-black)
- **Subheading / Body Quote:** 
  - Font Size: `20px` / `1.25rem`
  - Font Weight: `600`
  - Color: `#1a1a1a`
- **Body Text (Description):** 
  - Font Size: `13px` / `0.8125rem`
  - Line Height: `1.5`
  - Color: `#555555` (Muted gray)
- **Navigation & Buttons:** 
  - Font Size: `14px` / `0.875rem`
  - Font Weight: `500`

### Color Palette
- **Background Texture:** `#f4f3f0` (Off-white / light stone marble texture)
- **Primary Brand Accent (Orange):** `#f95700` (Vibrant orange for primary CTAs)
- **Accent Hover:** `#e04e00`
- **Text Main:** `#1a1a1a`
- **Text Secondary:** `#666666`
- **Border / Outline (Login Button):** `#f95700`

---

## Layout & Structure

- **View:** Full-screen viewport (`100vw` width, `100vh` minimum height).
- **Layout Paradigm:** Modern asymmetric hero section with a fixed top navigation bar, split-screen balance (Text content on the left, visual food photography floating on the right/center), and decorative culinary elements framing the viewport edges.

---

## Component Specifications

### 1. Header / Navigation Bar (`<header>`)
- **Positioning:** Fixed / Sticky top, padding `24px 60px`.
- **Layout:** Flexbox, space-between (`justify-content: space-between`, `align-items: center`).
- **Elements:**
  - **Logo:** 
    - Text: `luscious`
    - Font: Bold lowercase serif.
    - Color: `#1a1a1a`.
  - **Navigation Links (`<nav>`):**
    - Items: `Dumplings`, `Recipes`, `Food Menu`, `Order Now`
    - Font Size: `14px`
    - Color: `#222`
    - Hover state: Color shifts to `#f95700`.
    - Spacing: `32px` gap between items.
  - **Login Button:**
    - Type: Outlined button with rounded pill shape (`border-radius: 50px`).
    - Border: `1.5px solid #f95700`.
    - Padding: `8px 24px`.
    - Text Color: `#f95700`.

---

### 2. Hero Section (`<main>` / `<section>`)

#### Left Column (Text & CTA)
- **Container:** `max-width: 480px`, aligned vertically with generous whitespace.
- **Content Hierarchy:**
  1. **Main Headline:**
     ```html
     <h1>Take a taste<br>Come join us.</h1>
     ```
  2. **Subtitle:**
     ```html
     <p class="subtitle">Life is so endlessly delicious.</p>
     ```
  3. **Paragraph / Description:**
     ```html
     <p class="description">
       Dumpling is a broad classification for a dish that consists of pieces of dough made from a variety of starch sources wrapped around a filling, or of dough with no filling.
     </p>
     ```
  4. **Primary Call to Action (Button):**
     - Text: `Explore Now`
     - Background: `#f95700` (Solid vibrant orange)
     - Text Color: `#ffffff`
     - Border Radius: `50px` (Pill button)
     - Padding: `12px 28px`
     - Box Shadow: Subtle drop shadow for depth (`0 8px 20px rgba(249, 87, 0, 0.3)`).

---

#### Right Column & Floating Visual Assets (Collage Composition)
*Note: All images should be transparent PNG cutouts or realistically masked photographic assets placed using absolute positioning.*

1. **Top-Left Spoons / Spices:**
   - Position: Absolute (`top: 40px`, `left: -20px`).
   - Content: Wooden spoons with assorted spices (turmeric, curry powder, chili flakes) and scattered peppercorns.
   - Rotation: Angled diagonally downwards.

2. **Top-Right Fresh Produce:**
   - Position: Absolute (`top: 40px`, `right: 40px`).
   - Content: Fresh tomatoes on the vine, sliced red onions, and fresh basil leaves.

3. **Central Wooden Bowl (Dumplings):**
   - Position: Absolute (`bottom: 60px`, `right: 80px`).
   - Content: 
     - Round rustic wooden bowl filled with freshly steamed pork/vegetable dumplings topped with black sesame seeds.
     - Two light-colored wooden chopsticks resting diagonally across the bowl.

4. **Dipping Sauce Bowl:**
   - Position: Absolute (`bottom: 80px`, `right: 420px`).
   - Content: Small white ceramic bowl containing red dipping sauce (chili paste/ketchup) garnished with fresh green basil leaves on top.
   - Accents: Scattered peppercorns and spices on the marble surface near the base of the bowl.

5. **Floating UI Element (Search/Icon):**
   - Position: Absolute (`top: 180px`, `right: 320px`).
   - Content: Circular white glassmorphism icon button (`width: 40px`, `height: 40px`, `border-radius: 50%`, subtle shadow).

---

## Responsive Breakpoints

- **Desktop (`>= 1024px`):** Exact layout specified above with absolute floating image coordinates.
- **Tablet (`768px` - `1023px`):** Stack text content above the visual assets; scale down image collage proportionally.
- **Mobile (`< 768px`):** 
  - Single-column layout.
  - Center-align text content.
  - Hide or simplify peripheral floating background elements (spoons, spices) to prevent clutter.
  - Scale down main dumpling bowl to fit mobile screen width (`100%`).
