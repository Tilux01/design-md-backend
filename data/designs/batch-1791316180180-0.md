# Production UI/UX Design Specification

---

## 1. Design Philosophy & Overall Aesthetic

- **Primary Mood:** Clean, e-commerce-driven utility interface blending consumer-electronic retail with high-density inventory browsing.
- **Visual Density:** High density; optimized for maximum content visibility on mobile viewports without sacrificing touch target targets.
- **Whitespace Balance:** Tight gutters (8px–12px) with structured card separation to partition heterogeneous product categories.
- **Theme Balance:** Light-mode dominant default interface (`#F4F5F7` base canvas), punctuated by a deep indigo/black promotional feature banner (`#0D0F12`) and high-contrast blue action anchors (`#1655F5`).

## 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** Fluid viewport bounded at `max-width: 480px` (mobile viewport presentation context).
- **Spatial Scale:** 4px baseline grid (`p-1 = 4px`, `p-2 = 8px`, `p-3 = 12px`, `p-4 = 16px`).
- **Section Sequence (Top to Bottom):**
  1. Top utility/status bar (Network, Battery, Time indicators).
  2. Header Navigation / Search & Barcode utility buttons.
  3. Carousel Promotional Banner / Hero Ad Slot.
  4. Quick-Category Icon Grid (2 rows x 4 items).
  5. Secondary Promotional Banners Grid.
  6. Flash Deals / Product Cards Section (Horizontal-scrollable or multi-column grid).
  7. Immersive Promotional Banner (Dark mode CTA section).
  8. Product recommendation stream.

- **Ambient Glow:** Subtle radial background vignettes behind promotional artwork (`radial-gradient(circle, rgba(22,85,245,0.15) 0%, transparent 70%)`).

## 7. Motion Mechanics & Animation Code

- **Animation Triggers:** Card scale-up on hover, smooth layout reflow on category filters, modal fade-in.
- **Timing & Easing:** Standard ease-out `cubic-bezier(0.16, 1, 0.3, 1)`, duration `250ms`.

### Framer Motion React Code Snippets
```jsx
import { motion } from 'framer-motion';

export const ProductCardMotion = ({ children }) => (
  <motion.div
    whileHover={{ y: -4, transition: { duration: 0.2, ease: [0.16, 1, 0.3, 1] } }}
    whileTap={{ scale: 0.98 }}
    initial={{ opacity: 0, y: 10 }}
    animate={{ opacity: 1, y: 0 }}
    className="flex flex-col bg-white border border-slate-200 rounded-lg p-3 shadow-card"
  >
    {children}
  </motion.div>
);
```

### CSS `@keyframes` Animation Snippets

## 8. Accessibility (a11y) & WCAG Contrast Audit

- **Text Contrast Ratios:**
  - Primary text (`#0F172A`) on White background (`#FFFFFF`): **15.8:1** (Passes WCAG AAA)
  - Muted text (`#64748B`) on White background (`#FFFFFF`): **4.6:1** (Passes WCAG AA)
  - Primary Button text (`#FFFFFF`) on Blue background (`#1655F5`): **4.8:1** (Passes WCAG AA)
- **Keyboard Focus Ring Specification:**
  ```css
  *:focus-visible {
    outline: 2px solid #1655F5;
    outline-offset: 2px;
    box-shadow: 0 0 0 4px rgba(22, 85, 245, 0.2);
  }
  ```
