# UI Design Specification: AI Dashboard

## 1. Global Layout & Viewport Architecture

- **Root Container**: Full-screen layout utilizing a responsive flex/grid structure. The outer device frame and gradient background shown in the preview are omitted; the app occupies 100% of the viewport.
- **Color Palette**:
  - **Background (Base)**: Soft lavender-gray (`#D6D5E6` / `#E2E1F0`) with subtle multi-directional gradient blends.
  - **Sidebar Background**: Semi-transparent frosted glass / deep muted violet (`#A7A5C2` with opacity).
  - **Cards & Widgets**: Solid light-violet/white glassmorphic containers (`#FFFFFF` or `#EAE9F4`) with soft, diffused drop shadows (`rgba(0, 0, 0, 0.04)`).
  - **Primary Accents**: Vibrant pink/magenta (`#FF4B72`) for activity peaks, buttons, and active indicators; soft mint green (`#A8F2C2` / `#C4F2D0`) for positive metrics and status tags; pastel purple/blue (`#C1C2F0` / `#D4D6F8`) for category tags.
- **Typography Engine**:
  - **Primary Font Family**: `Inter`, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `Helvetica`, `Arial`, sans-serif.
  - **Fallback Stack**: System UI sans-serif.
  - **Font Weights**: Regular (400), Medium (500), Semi-bold (600), Bold (700).
