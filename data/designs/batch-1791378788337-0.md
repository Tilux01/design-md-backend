# UI/UX Specification: E-Commerce Product Page (App/Web Hybrid)

## 1. Global & Layout Specifications
- **Layout Structure:** Single-column scrollable feed (Mobile Web or App Viewport).
- **Grid System:** Flexbox & CSS Grid for dynamic product variants and recommendation carousels.
- **Background Color:** Pure White (`#FFFFFF`) for the main canvas; Light Neutral (`#F8F9FA` to `#E5E7EB`) for secondary containers, buttons, and inactive states.
- **Primary Text Color:** Charcoal Black (`#111827`) for high-contrast readability.
- **Secondary Text Color:** Muted Gray (`#6B7280`) for metadata, ratings, and descriptions.

---

## 2. Typography System
*Note: If the exact proprietary fonts are unavailable, use the specified fallback stack to maintain structural integrity and visual hierarchy.*

### Primary Font Stack
- **Family:** `Inter`, `system-ui`, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `Helvetica`, `Arial`, `sans-serif`
- **Fallback Behavior:** Sans-serif fallback with optimized letter-spacing (`tracking-tight`) to mimic modern retail design systems.

### Typography Hierarchy
1. **Product Title:**
   - Size: `24px` / `1.5rem`
   - Weight: Bold (`700`)
   - Line Height: `1.2`
   - Color: `#111827`
2. **Pricing (Sale):**
   - Size: `22px` / `1.375rem`
   - Weight: Extra Bold (`800`)
   - Color: `#111827`
3. **Pricing (Strikethrough/Original):**
   - Size: `14px` / `0.875rem`
   - Weight: Normal (`400`)
   - Color: `#9CA3AF`
   - Text Decoration: Line-through
4. **Body Text / Description:**
   - Size: `14px` / `0.875rem`
   - Weight: Regular (`400`)
   - Line Height: `1.5`
   - Color: `#4B5563`
5. **Interactive Labels (Sizes, Tabs, Buttons):**
   - Size: `13px` – `14px`
   - Weight: Medium (`500`) to Semi-Bold (`600`)

---

## 3. Component Breakdown & Styling

### A. Image Gallery / Product Viewport
- **Main Display:** 
  - Aspect Ratio: `4:5` (Vertical rectangle)
  - Border Radius: Minimal/None on full mobile view; subtle `8px` rounding if contained in cards.
- **Thumbnails (Left Sidebar):**
  - Vertical stack of 4 square thumbnails (`1:1` ratio).
  - Active State: Dark outline / border around the selected thumbnail.
- **Overlay Icon:** 
  - Bottom-right corner of the main image features a floating circular zoom/expand icon (`#FFFFFF` background with a subtle black vector icon).

### B. Product Header & Pricing Section
- **Rating Component:**
  - 5 solid star icons in Amber/Gold (`#F59E0B`).
  - Review Count: Text appended in `12px` Muted Gray (`(528 Reviews)`).
- **Price Block:**
  - Current Price: `$59.99`
  - Discount Tag: Pill-shaped badge next to the price (Black background `#000000`, white text, uppercase, rounded `4px`).

### C. Variant Selection (Color & Size)
- **Color Swatches:**
  - Row of 4 circular radio buttons.
  - Colors: Charcoal Gray (Selected with outer ring), Light Gray, Off-White, Solid Black.
  - Selected State: Thick primary border offset by whitespace.
- **Size Selector:**
  - Horizontal scrollable or wrapped pill buttons (`S`, `M`, `L`, `XL`, `XXL`).
  - Default Selected Size (`M`): Inverted colors (Solid Black background `#000000`, White text `#FFFFFF`, rounded corners `6px`).
  - Unselected Sizes: Light gray border (`#D1D5DB`), transparent background, dark text.
  - **Size Guide Link:** Right-aligned inline link with a ruler/tape-measure icon.

### D. Call-to-Action (CTA) Bar
- **Add to Cart Button:**
  - Full-width rounded rectangle (`8px` border radius).
  - Background: Solid Black (`#000000`).
  - Text/Icon: White text combined with a shopping bag outline vector icon.
- **Wishlist Button:**
  - Square/Rounded button paired next to the main CTA.
  - Border: Subtle gray outline containing a heart icon (`#374151`).

### E. Trust Badges & Metadata
- **Icon Row:**
  - Three distinct micro-features separated by alignment: Free Shipping, Easy Returns, Secure Checkout.
  - Icons accompanied by micro-copy (`11px` text).

### F. Product Details & Feature Tabs
- **Tab Navigation:**
  - Horizontal text links: `Details`, `Materials`, `Size & Fit`, `Shipping & Returns`.
  - Active Tab (`Details`): Underlined with a bold 2px black line.
- **Bullet Points List:**
  - Custom micro-icons (checkmarks, squares, or minimalist dots) preceding key product specs:
    - Premium heavyweight fleece
    - Breathable comfort
    - Minimalist branding

---

## 4. Micro-Interactions & Animations
- **Tap/Click Feedback:** 
  - `scale(0.98)` transition on buttons (Add to Cart, Size Selectors) with a duration of `150ms` (`cubic-bezier(0.4, 0, 0.2, 1)`).
- **Image Swapping:** 
  - Instant state switch or subtle `200ms` opacity cross-fade when clicking side thumbnails.
- **Wishlist Toggle:** 
  - Heart icon scales up slightly (`1.2`) on press, shifting fill from transparent to solid accent red (`#EF4444`) with a spring physics transition.
