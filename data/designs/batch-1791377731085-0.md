# Design Specification: Hazelnut Milk E-Commerce Homepage

## 1. Overview & Layout Strategy
- **Viewport:** Fullscreen (100vw × 100vh), responsive single-page hero layout. No outer device frame or background vignettes.
- **Background Color:** Light soft sage / muted olive-gray (`#DCE0D5` or equivalent cream-sage pastel).
- **Grid Structure:** Centered content layout with a fixed header, a prominent central hero image (bottle) superimposed over background typography and floating illustrations, and a CTA button positioned below the bottle.

---

## 2. Typography & Fonts
The design features a bold, rounded, modern geometric serif or heavy sans-serif for the main brand wordmark, paired with a clean geometric sans-serif for UI elements.

### Primary Display Font (Wordmark: "He [bottle] z [bottle] nut")
- **Style:** Extra-bold, rounded-terminal geometric display font. 
- **Font Stack / CSS Fallback:** 
  ```css
  font-family: 'Quicksand', 'Comfortaa', 'Nunito', system-ui, -apple-system, sans-serif;
  font-weight: 800;
  ```
- **Letter Spacing:** Generous tracking to accommodate the central bottle graphic.

### UI / Navigation Font
- **Style:** Clean, neutral sans-serif.
- **Font Stack / CSS Fallback:**
  ```css
  font-family: 'Inter', 'SF Pro Text', -apple-system, sans-serif;
  font-weight: 500;
  ```

---

## 3. Color Palette
- **Background:** `#DCE0D5` (Soft Sage / Muted Cream)
- **Primary Text / Wordmark / Navigation:** `#5A3E2B` / `#3D291D` (Rich Espresso / Dark Brown)
- **Bottle Cap:** `#2C221E` (Dark Charcoal/Brown)
- **Label Accent:** Warm beige with dark brown typography (`#C2B29D`)
- **Buttons / UI Elements:** Pure White (`#FFFFFF`) with dark borders/text.

---

## 4. Header & Navigation (Top Bar)
- **Position:** Absolute / Sticky, pinned to the top with generous padding.
- **Left/Brand Icon:** Minimalist black silhouette of a milk bottle (SVG asset).
- **Center Navigation Links:** 
  - `Products`
  - `About`
  - `Partnership`
  - `Contact`
- **Right Action:** Shopping bag / cart icon (outline style).

---

## 5. Hero Section (Core Visuals)
- **Central Typography:** The word **"He"** and **"nut"** appear as giant 3D-effect brown text positioned horizontally across the screen. 
- **The "z":** Interrupted and replaced by the interactive product slider element.
- **Central Bottle Element:** 
  - Realistic 1D/3D illustration of a glass milk bottle labeled **"HAZELNUT MILK"** with a "1 Liter" callout and a hazelnut graphic.
  - Black screw cap.
  - Positioned dead-center, overlapping the typography.
- **Carousel Controls:** Small circular white arrow buttons (`<` and `>`) flanking the central bottle for product navigation.
- **Floating Assets:** Scattered, semi-blurred 3D illustrations of whole and cracked hazelnuts drifting around the background to create depth and parallax motion.

---

## 6. Interactive Elements & Call to Action (CTA)
- **Button ("Shop now"):**
  - **Shape:** Pill / Stadium shape (`border-radius: 50px`).
  - **Color:** Solid white background (`#FFFFFF`) with a subtle dark outline.
  - **Text:** Dark brown, bold, centered.
  - **Hover State:** Slight scale-up (`scale(1.05)`) with a subtle drop shadow.

---

## 7. Animations & Motion Design
To replicate the dynamic feel of the reference media, implement the following CSS/JS animations:

1. **Parallax Floating Elements (Hazelnuts):**
   - Floating organic drift animation (`translateY` oscillation) running continuously using CSS keyframes (`animation: float 6s ease-in-out infinite;`).
2. **Page Load Entrance:**
   - **Staggered Fade-In:** Background text fades in from opacity `0` to `1` with an upward slide.
   - **Bottle Drop:** The central bottle drops in from above with a soft spring physics easing (`cubic-bezier(0.175, 0.885, 0.32, 1.275)`).
3. **Carousel / Arrow Hover:**
   - Carousel navigation arrows feature a soft cursor pointer interaction and scale pulse on hover.
