## 5. Animations & Interactions

To replicate the polished look of this UI, apply the following CSS animations:

1.  **Floating Elements (Controller & Spheres):**
    *   Use a subtle CSS keyframe animation for a hovering effect:
    ```css
    @keyframes float {
      0% { transform: translateY(0px); }
      50% { transform: translateY(-8px); }
      100% { transform: translateY(0px); }
    }
    .floating-asset {
      animation: float 4s ease-in-out infinite;
    }
    ```
2.  **Button Hover:**
    *   Transition property: `all 0.2s ease`
    *   Hover state: `background-color: #333333; transform: translateY(-2px);`
3.  **Page Load Entrance:**
    *   Fade-in (`opacity: 0` to `1`) combined with a slight slide-up (`translateY(20px)` to `0`) for the central container over `0.8s` with an `ease-out` timing function.
