# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial Minimalist mixed with High-Performance Motorsport Dark Mode & Interactive WebGL Showcases.
- **Visual Density & Whitespace Ratio**: Highly balanced editorial whitespace with generous padding and large-scale imagery, contrasting clean cream/off-white content surfaces against deep charcoal/black immersive presentation layers.
- **Surface Elevation Model**: Layered paper and glass card surfaces using subtle 1px border separations (`#E2E8F0` / `#262626`), clean drop shadows, and pill-shaped interactive floating elements (`#10B981` / mint green accents).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase pill badges, mint green neon accents, interactive 3D model viewport overlays, editorial signature markers, and asymmetric grid photo layouts.
- **Pill Badge Specification**: Padding: `6px 14px`, Font-size: `12px`, Font-weight: `600`, Tracking: `0.08em`, Border-radius: `9999px`, Background: `#10B981` (Mint) or `rgba(255,255,255,0.1)`, Border width: `1px`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
