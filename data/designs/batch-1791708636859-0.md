# Design Specification: Dopler Landing Page Clone

## 1. Global Styles & Layout Structure
* **Layout:** Full-screen responsive web design.
* **Background Color:** Pure Black (`#000000`).
* **Primary Text Color:** White (`#FFFFFF`).
* **Muted Text Color:** Dark Gray (`#7B7B7B`) for subheaders and footer secondary copy.
* **Body Font:** Inter, Roboto, Helvetica Neue, or sans-serif fallback.
* **Heading Font:** SF Pro Display, Inter, Helvetica Neue, or sans-serif fallback (Clean, modern geometric sans-serif with high tracking/tight line-height).

---

## 2. Header / Hero Section

### A. Main Headline
* **Text:** "Built for What Comes Next."
* **Alignment:** Centered.
* **Typography:** Bold sans-serif, large responsive scale (approx. 48px–64px on desktop), tight line height.

### B. Subheadline
* **Text:** "Future-ready tools for teams moving at the speed of innovation."
* **Alignment:** Centered directly below the main headline.
* **Typography:** Light/Regular weight sans-serif (approx. 14px), color: `#8A8A8A`.

### C. "Get Started" Button
* **Placement:** Centered horizontally below the subheadline.
* **Shape:** Rectangular container with crisp edges.
* **Styling:** 
  * Solid white background (`#FFFFFF`).
  * Black text color (`#000000`).
  * Uppercase text: "GET STARTED".
  * Font weight: Bold, tracked out slightly.
  * Padding: Small vertical and horizontal padding (approx. 10px 20px).

---

## 3. Central Graphic Element (Abstract 3D Shape)

* **Description:** An abstract, sculptural 3D geometric ribbon/wave shape rendered in pure white. It features smooth curves with a dynamic upward swirl. 
* **Lighting/Effects:** The bottom portion of the shape fades out smoothly into the black background via a vertical gradient opacity (soft bottom blur/fade effect).
* **Properties:**
  * **Backgroundless:** Yes (transparent PNG/SVG object overlaid directly on the `#000000` background).
  * **Placement:** Centered horizontally between the Hero "Get Started" button and the Footer navigation blocks.
  * **Rotation/Angle:** Tilted diagonally upwards from bottom-left to top-right, creating a sense of forward motion.

---

## 4. Footer & Navigation Grid

### A. Social Links Header Bar (4-Column Grid)
Divided into four distinct vertical columns, each acting as a social link block with an external arrow icon (`→`) on the right.

1. **Column 1:**
   * Icon + Text: [YouTube Logo] YouTube `→`
2. **Column 2:**
   * Icon + Text: [X Logo] Twitter `→`
3. **Column 3:**
   * Icon + Text: [Instagram Logo] Instagram `→`
4. **Column 4:**
   * Icon + Text: [Facebook Logo] Facebook `→`

* *Styling:* Enclosed within subtle horizontal borders; background is slightly elevated dark gray (`#0A0A0A` or semi-transparent white on black).

---

### B. Directory / Navigation Links Grid
Structured into four standard footer categories below the social links:

* **Column 1 (PRODUCT):**
  * Section Header: PRODUCT (Small, uppercase, muted gray).
  * Links:
    * Technology
    * Integrations
    * Releases
    * Status
* **Column 2 (RESOURCES):**
  * Section Header: RESOURCES.
  * Links:
    * Docs
    * API Reference
    * Tutorials
    * System Guide
* **Column 3 (COMPANY):**
  * Section Header: COMPANY.
  * Links:
    * Team
    * Culture
    * Jobs
    * Press Kit
* **Column 4 (LEGAL):**
  * Section Header: LEGAL.
  * Links:
    * Imprint
    * Data Policy
    * Cookie Policy
    * Accessibility
    * Terms of Use

---

## 5. Bottom Brand & Newsletter Bar

* **Layout:** Two-column split layout at the very bottom of the page.

### Left Side (Branding):
* **Logo:** Dopler Logo icon (a stylized geometric abstract square icon) followed by bold white wordmark: **DOPLER.**
* **Mission Statement Paragraph:**
  * *Text:* "In the new era of technology we look a in the future with certainty and pride to for our company and business."
  * *Typography:* Small regular font size (approx. 11px), muted gray (`#8A8A8A`), constrained width.

### Right Side (Newsletter Subscription):
* **Input Field:**
  * Placeholder text: `NAME@EMAIL.COM` (All caps, monospace or clean sans-serif, dark gray placeholder text).
  * Styling: White background container with dark border/text.
* **Subscribe Button:**
  * Text: `SUBSCRIBE`
  * Styling: Dark gray/black solid background button positioned immediately to the right of the input field.
