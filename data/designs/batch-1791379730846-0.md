# UI/UX Specification & Design System: FRZN Artic 01™ E-Commerce Concept

## 1. Global Layout & Document Structure
- **Viewport Structure:** Full-screen responsive desktop-first layout (`100vw` / `100vh` scaling structure).
- **Core Container Hierarchy:**
  - `header`: Sticky/Fixed navigation bar featuring brand identity and contextual routing links.
  - `section.hero`: Primary focal point displaying the flagship product (*Artic 01™*), interactive thumbnails, size/color selectors, and CTA.
  - `section.new-collection`: Grid-based product catalog featuring secondary items (*Aurora™, Silver, Stealth, Icefield*).
  - `section.brand-banner`: Full-width atmospheric storytelling section with rugged mountain background overlays and brand manifesto typography.
  - `footer / bottom-banner`: Immersive closure block housing branding statements, utility text, and structural barcodes.
- **Background System:**
  - Deep glacial palette gradient (`#121824` to `#24334a`).
  - Immersive alpine mountain photography overlaid with structural, high-contrast spray-paint typography effects.

---

## 2. Color Palette & Theming (CSS Variables)

| Token Name | Hex Value | RGBA Equivalent | Usage Context |
| :--- | :--- | :--- | :--- |
| `--color-bg-primary` | `#17212f` | `rgba(23, 33, 47, 1)` | Deep background canvas base |
| `--color-bg-secondary` | `#24334a` | `rgba(36, 51, 74, 1)` | Card backgrounds, nested containers |
| `--color-bg-glass` | `#324866` | `rgba(50, 72, 102, 0.45)` | Transparent elements, filter pills, secondary buttons |
| `--color-text-primary` | `#ffffff` | `rgba(255, 255, 255, 1)` | Headings, core pricing, active states |
| `--color-text-secondary` | `#899cb8` | `rgba(137, 156, 184, 1)` | Subtitles, specifications, inactive filters |
| `--color-accent` | `#e2e8f0` | `rgba(226, 232, 240, 1)` | Borders, active selectors, UI frame accents |

---

## 3. Typography System & Fallbacks

- **Primary Heading / Brand Font:** 
  - *Font Family:* `Syncopate`, `Montserrat`, sans-serif
  - *Fallback Stack:* `'Syncopate', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
  - *Characteristics:* Geometric, wide-tracked, uppercase-heavy display typography used for structural layout branding.
- **Secondary / Body Font:** 
  - *Font Family:* `Space Mono`, `Courier New`, monospace
  - *Fallback Stack:* `'Space Mono', Courier, monospace`
  - *Characteristics:* Monospaced, technical feel used for sizing options (`S`, `M`, `L`, `XL`), prices, and metadata lines (`[ SERIES: STASIS 9K.1 ]`).

---

## 4. Component Breakdown & Interactive Elements

### 4.1 Navigation Bar (`header`)
- **Left:** Brand Logo text (`FRZN`) rendered in geometric custom asset style.
- **Center Links:** 
  - `[ CATALOG ]`
  - `[ PUFFERS ]`
  - `[ BOOTS ]`
- **Right:** Search icon (`🔍`) and Shopping bag icon (`🛍️`).
- **Layout Styling:** `display: flex; justify-content: space-between; align-items: center; padding: 24px 48px;`

### 4.2 Hero Section (`section.hero`)
- **Metadata Tag:** `[ SERIES: STASIS 9K.1 ] [ SERIES 1 ]` (Monospaced, muted color).
- **Primary Title:** `COLLECTION ARTIC 01™` (Extra-bold scale tracking).
- **Selectors:**
  - **Size Matrix:** `S` `M` `L` `XL` (Pill borders, active state marked with underline).
  - **Colour Options:** `WHITE`, `SILVER` (Circular indicator dots matching item finishes).
- **CTA Button (`ADD TO CART`):**
  - Circular floating glassmorphism design action containing an upper-right pointing arrow icon (`↗`).
  - Price indicator attached: `$899.99`.
- **Hero Imagery & Media Carousel:**
  - Central dominant model portrait wearing technical puffer in snowy environment.
  - Secondary thumbnail switcher on the right (`01` / `07`) showing alternate angles with frame overlays.
  - Social media micro-links (`📷`, `📘`, `🐦`) floating in the lower right of the primary frame.

### 4.3 New Collection Grid (`section.new-collection`)
- **Section Heading Group:**
  - Large display text: `NEW COLLECTION`
  - Technical metadata indicators: `[ NEW COLLECTION ]`, `[ SERIES_01 ]`, `[ PUFFERS ]`, `PUFFER JACKETS`, `METAL EDITION`, `EXTREVE COLD LINE`.
  - Action Control: `[ FILTERS ]` pill button on the right.
- **Card Grid Architecture:**
  - Multi-column grid layout containing individual product cards.
  - **Featured Hero Card (Aurora™):** Large split layout showcasing lifestyle shot alongside clean technical studio render. Includes price tag (`$1,999`) and floating arrow action button.
  - **Standard Catalog Cards:** 
    - Card surfaces use `--color-bg-secondary` with subtle inner border glow.
    - Uniform product display formatting: Centered high-detail studio asset against an icy gradient backdrop.
    - Metadata below image: Product Title (e.g., `AURORA SILVER / REFLECTIVE PUFFER JACKET`), color variant indicator dots (`WHITE`, `BLUE`), and pricing (`$999.99`).

### 4.4 Brand Banner & Footer Section (`section.brand-banner`)
- **Background Styling:** High-altitude mountain visual overlaid with semi-transparent, massive spray-painted signature typography element.
- **Manifesto Text block (Left):**
  - `"FRZN WAS BORN IN THE MOUNTAINS. NOT AS A TREND, BUT AS A RESPONSE"`
  - Metadata tag: `[ PROTOCOL: ALTITUDE OPS_01 ]`
- **Manifesto Text block (Right):**
  - `"FOR THOSE WHO CLIMB. NOT FOR THE CROWD"`
- **Footer Typography & Barcode:**
  - Lower left heading: `BUILT FOR COLD / MADE FOR HEIGHT / FORGED TO LAST`
  - Lower right structural elements: Copyright string (`©2025 FRZN WEAR ALL RIGHTS RESERVED`) paired with an authentic-looking UPC barcode vector.

---

## 5. Animation & Interaction Specifications

- **Hover States (Cards):**
  - `transform: translateY(-4px);`
  - Transition: `all 0.3s cubic-bezier(0.16, 1, 0.3, 1);`
  - Subtle drop-shadow intensification (`box-shadow: 0 12px 32px rgba(0,0,0,0.5);`).
- **Interactive Buttons & Selectors:**
  - Size pills and filter buttons undergo a background color transition from `--color-bg-glass` to `--color-text-primary` with text color inverting to dark `#17212f`.
- **Scroll Effects:**
  - Parallax depth effect applied to the background mountain imagery versus the foreground UI layer during vertical scrolling.
