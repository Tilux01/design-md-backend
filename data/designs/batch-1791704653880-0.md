# Comprehensive Design Specification: Splash Autonomous Vessels Web Experience

---

## 1. Overview & Visual Aesthetic

- **Design Philosophy:** Utilitarian, high-tech defense, industrial minimalism. The interface marries brutalist data layouts with cinematic, photorealistic 3D hardware rendering.
- **Theme:** Monochromatic dark mode dominated by deep graphite and pitch blacks, stark pure white typography, muted gray operational annotations, and punchy emergency/status red LED accents.
- **Canvas Viewport:** Full-width responsive design (100vw, min-h-screen). Outer water mockup background from the reference is omitted; all specifications represent the edge-to-edge web application.

## 4. Imagery & Visual Assets

### 4.1 Hero Vessel Render (Full Technical Description)
- **Subject:** Hyper-realistic, close-up industrial rendering of an uncrewed naval combat drone / autonomous vessel stern and thruster module.
- **Composition & Angle:**
  - Placed diagonally across the center-right of the hero section.
  - Left segment features the matte, tactical-grey spherical or elliptical composite hull with recessed panel seams, screw rivets, ventilation slots, and dual optical camera apertures.
  - Right segment features an exposed articulating gimbal/pod thruster motor connected via heavy cast metallic linkages, hoses, and mechanical mounts.
  - Extending out from the thruster are dramatic, sweeping curved composite propeller / turbine blades arching toward the top right corner and lower foreground.
- **Lighting & Textures:**
  - Cinematic, key light from the upper left casting soft industrial specular highlights on the matte composite shell.
  - Deep carbon shadows fill the machinery recesses.
  - **Sensors:** Two intensely bright, cherry-red glowing spherical indicator LEDs (`#FF2B2B` with radial bloom of 15px-25px) mounted on the central gimbal pivot. One warm amber indicator (`#FFB020`) set slightly below them.
- **Asset Integration:**
  - PNG with transparent background or high-res WebP with integrated deep vignette fading directly into `#050608` along the bottom, right, and top edges.
  - Position: Absolute, anchoring from horizontal center to right edge (`right: -5%` to `right: 0`), vertically centered behind text overlays.

### 4.2 Brand Iconography
- **Logo ("splash"):**
  - Left emblem: Stylized white angular ribbon/origami chevron formed by two overlapping geometric triangles.
  - Text: Lowercase "splash" in crisp sans-serif medium weight.
- **Status Indicator Pip:**
  - Solid 6px × 6px square in `#FF2B2B` preceding section labels.
- **Scroll Indicator:**
  - Text `"Scroll to explore"` (12px) paired with a downward-pointing slim chevron icon `v`.

## 6. Layout & Spacing Rules

- **Grid System:** 12-column grid layout with `24px` gutter, maximum container width `1440px` (centered) or edge-to-edge with `48px` gutter margin.
- **Vertical Rhythm:**
  - Section paddings: `120px` top and bottom.
  - Component spacing: Multiples of `8px` (`8px`, `16px`, `24px`, `32px`, `48px`, `64px`).
- **Responsive Adaptations:**
  - **Desktop (>1024px):** As specified above; side-by-side stats and 2-column layout.
  - **Tablet (768px - 1023px):**
    - Stats matrix maintains 2x2 layout with compressed padding.
    - Hero narrative block shifts beneath vessel graphic.
    - Navigation groups fold into a hamburger toggle except `INQUIRE TODAY` CTA.
  - **Mobile (<767px):**
    - Single-column flow: Stats grid transforms into 1-column list with horizontal dividers.
    - Hero headline font reduces to `38px`.
    - Horizontal screen padding drops to `20px`.

## 7. Interactive Behaviors & Micro-Interactions

1. **Indicator LEDs (Vessel):**
   - Subtle pulse animation on red lights using CSS keyframes:
     ```css
     @keyframes pulse-glow {
       0%, 100% { filter: drop-shadow(0 0 12px rgba(255, 43, 43, 0.9)); }
       50% { filter: drop-shadow(0 0 22px rgba(255, 43, 43, 1)); }
     }
     ```
2. **Telemetry Timestamp:**
   - Real-time digital clock rendering inside `[14:17:21]` updating current UTC or local New York time every second.
3. **Buttons & Links:**
   - CTA button hover: Inverse highlight or slight scale (`1.02`), arrow transitions 4px rightwards (`transform: translateX(4px)`).
   - Navigation links: Color transition from `#C5C8CD` to `#FFFFFF` with cubic bezier curve `ease-out` (150ms).
4. **Scroll Dynamics:**
   - Vessel 3D graphic supports subtle parallax scroll (moving at `0.15x` relative scroll speed).
