# Design Specification: Salesforce Invoices Dashboard (iPad Pro Viewport)

This document provides a comprehensive, pixel-precise specification for rebuilding the Salesforce Invoices tablet interface shown in the source image. It covers color palettes, typography, layout structures, interactive component states, and imagery descriptions.

---

## 1. Global Viewport & Layout Architecture

*   **Target Device:** iPad Pro (Horizontal / Landscape Viewport).
*   **Dimensions:** Fluid width scaled to match a 4:3 or 16:10 tablet ratio (suggested minimum canvas: `1280px` width, `900px` height).
*   **Overall Layout Structure:**
    *   **Root Container:** Deep, dark, charcoal-black canvas background (`#0A0B0E`).
    *   **Content Sections:** Divided into three primary vertical zones:
        1.  **Top Navigation Bar:** Global brand header, navigation pills, and system controls.
        2.  **Top Metrics & Analytics Panel:** Summary metric cards, historical/projected payout indicators, and interactive timeline graphs.
        3.  **Data Management Workspace:** A lower white card surface containing active filter controls, an invoice sidebar list, and a detailed invoice breakdown inspector card.

---

## 3. Typography & Font Stack

*   **Primary Font Family:** `Inter`, `SF Pro Display`, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `sans-serif`.
*   **Fallback Strategy:** System-ui sans-serif stack ensuring native rendering parity across macOS, iPadOS, Windows, and Linux environments.

### Type Scale & Hierarchy
*   **Screen Header Title ("Invoices"):**
    *   Font Size: `28px` / `1.75rem`
    *   Font Weight: `600` (Semi-bold)
    *   Line Height: `1.2`
    *   Color: `#FFFFFF`
*   **Major Metric Values (e.g., $31,211.00):**
    *   Font Size: `24px` / `1.5rem`
    *   Font Weight: `600` (Semi-bold)
    *   Color: `#FFFFFF`
*   **Card Titles / Section Labels:**
    *   Font Size: `13px` / `0.8125rem`
    *   Font Weight: `500` (Medium)
    *   Letter Spacing: `0.02em`
    *   Color: `#8C919D`
*   **Body & Table Text:**
    *   Font Size: `13px` / `0.8125rem`
    *   Font Weight: `400` (Regular)
    *   Color: `#111318` (Light surface) / `#FFFFFF` (Dark surface)
*   **Metadata & Sub-labels:**
    *   Font Size: `11px` / `0.6875rem`
    *   Font Weight: `400` (Regular)
    *   Color: `#686E7D` (Light surface) / `#8C919D` (Dark surface)

## 4. Component-by-Component Specifications

### A. Top Navigation Bar
*   **Logo & Brand:**
    *   Salesforce 4-pointed star spark icon in white (`#FFFFFF`), followed by the word "salesforce" in lowercase, regular weight.
*   **Navigation Pill Container:**
    *   Background: `#14171F`
    *   Border-Radius: Full pill shape (`9999px`)
    *   Items included: Estimates, **Invoices** (Active state highlighted with a solid `#C6FF00` background and dark text), Payments, Recurring Invoices, Checkouts.
    *   Right side contains system utility icons (search, notifications, profile avatar).
*   **Action Button:**
    *   "Create an invoice" button featuring a rounded dark container with a plus icon and clean white label text.

### B. Metrics & Overview Section (Dark Cards)
*   **Top Metric Grid:** Four distinct columns presenting financial snapshots:
    1.  *Overdue:* `$31,211.00`
    2.  *Due within next month:* `$172,560.00`
    3.  *Average time to get paid:* `12 days`
    4.  *Available for Instant Payout:* `$214,390.00` (Includes an "Expects" badge tag).
*   **Timeline & Milestone Strip:**
    *   Horizontal segmented progress track broken down by months (Sep, Oct, Nov, Dec).
    *   A neon green progress fill highlights active milestone completions.
    *   Circular avatar groups beneath timeline points represent stakeholders or client payment clusters.
*   **Payout Channel Cards:**
    *   Displays transaction identifiers (`#4443`, `#177210`, `#711221`) corresponding to payment gateways (Stripe, PayPal).
    *   The active card (`#177210`) is styled with a striking solid neon green background (`#C6FF00`) and dark text.
    *   "Pay out now" pill button positioned on the right edge.

### C. Lower Workspace & Data Management Card
*   **Container Shape:**
    *   Large white rounded card (`#FFFFFF`) with generous internal padding, overlapping the bottom of the dark canvas.
*   **Filter Bar:**
    *   Filter dropdowns for "All customers", "All statuses", date ranges ("November 2023", "December 2023"), and a quick search input field with a magnifying glass icon.
*   **Tab Switcher:**
    *   Segmented pill control with tabs: **All Invoices**, **Draft (3)**, **Unpaid (5)**. The active tab ("Unpaid") is highlighted in neon green (`#C6FF00`).
