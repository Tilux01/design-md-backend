# UI/UX Specification & Design System Clone: "FitPulse" Fitness App Suite

This document outlines the exact specifications for cloning the **FitPulse** fitness app UI shown in the image. It serves as a blueprint for developers and designers to recreate this interface with pixel-perfect accuracy.

## 1. Global Design Tokens & Theme Foundation

### Color Palette
The design utilizes a **Glassmorphism / Neumorphism** dark-mode aesthetic built on deep navy/slate backgrounds overlaid with translucent cards, crisp white typography, and electric cyan/lime interactive accents.

| Token Name | Hex Code / RGBA | Usage Context |
| :--- | :--- | :--- |
| **Canvas Background** | `#1b2230` to `#0d121c` (Radial/Linear Gradient) | Overall scene background |
| **App Screen Background** | `#0a0f1d` | Base fill for mobile frame viewports |
| **Card Surface (Glass)** | `rgba(255, 255, 255, 0.06)` | Primary structural panels & containers |
| **Card Border (Glass)** | `rgba(255, 255, 255, 0.12)` | Subtle outlines for depth separation |
| **Primary White** | `#FFFFFF` | Primary headers, key numbers, labels |
| **Secondary Gray** | `#94a3b8` (Slate 400) | Secondary metadata, descriptions, inactive icons |
| **Accent Electric Cyan** | `#38bdf8` (Sky 400) | Progress indicators, toggles, interactive states |
| **Accent Lime Green** | `#22c55e` (Green 500) | Active status dots, sync indicators |
| **Dark Pill Button** | `#0f172a` (Slate 900) | High-contrast call-to-action buttons |

### Typography Stack
*Primary UI Font Family:* **Inter** (Fallback: `SF Pro Display`, `-apple-system`, `sans-serif`)
*Brand Logo Font:* **Outfit** or **Plus Jakarta Sans** (Semi-bold, clean geometric grotesque)

* **Screen Title (H1):** 28px, Bold (Weight 700), Line-height: 1.2
* **Section Heading (H2):** 18px, Semi-bold (Weight 600)
* **Body / Subtitle:** 13px - 14px, Regular (Weight 400) to Medium (Weight 500)
* **Microcopy / Badges:** 11px, Medium (Weight 500), Uppercase tracked (Tracking: `0.05em`)

## 5. Micro-Interactions, States & Animations

To replicate the high-end feel of this interface, implement the following interactive states:

1. **Glassmorphism Blur Effect:**
   * Apply CSS `backdrop-filter: blur(16px);` combined with `-webkit-backdrop-filter: blur(16px);` on all card elements.
2. **Progress Arc Animation:**
   * SVG circles (`stroke-dasharray` and `stroke-dashoffset`) should animate smoothly from `0%` to their target values (`60%`, `50%`, `70%`) upon component mount with an `ease-out` transition (duration: `800ms`).
3. **Button Hover / Tap Feedback:**
   * Scale transform on tap: `transform: scale(0.97);` with a duration of `150ms`.
   * Glow enhancement on interactive pills when hovered (`box-shadow: 0 0 20px rgba(56, 189, 248, 0.3)`).
4. **Toggle Switches:**
   * Smooth sliding transition (`300ms cubic-bezier(0.4, 0, 0.2, 1)`) for the "Auto mode" and "Smart Tracking" switches, shifting between background states (`#22c55e` active / `#334155` inactive).
