# Design Specification: TR_FLYKNIT SHOES E-Commerce Landing Page

## 1. Global Layout & Viewport
- **Screen Strategy:** Fullscreen, edge-to-edge layout (desktop-first view shown in mockup).
- **Background:** Vibrant, warm orange radial/linear gradient (`#FF7A00` to `#E06500` or a deep saturated orange gradient fading outward).
- **Shadow/Depth:** The main container floats with a subtle dark drop shadow on a neutral grey studio background (`#2B2B2B`), simulating a digital presentation mockup.

---

## 2. Typography & Fonts
*Note: Since exact proprietary brand fonts might not be available via standard web-safe stacks, precise geometric sans-serif alternatives are provided.*

### Primary Display Font (Headings, Product Name, Navigation)
- **Font Family:** `Montserrat`, `Inter`, or `Helvetica Neue`, sans-serif
- **Fallback Stack:** `font-family: 'Montserrat', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif;`
- **Weights Used:**
  - **Extra Bold (700/800):** Product Name (`TR_FLYKNIT SHOES`)
  - **Medium (500):** Navigation items (`MENS`, `WOMEN`, `KIDS`, `CUSTOMIZE`)
  - **Regular (400):** Subheadings (`MAN'S ORIGINALS`), Callouts, and Price (`$120`)

---

## 3. Header & Navigation Bar
- **Logo Area (Top Left):**
  - Minimalist white sneaker silhouette icon pointing right.
- **Main Nav Links (Top Center):**
  - `MENS` (with a small dropdown chevron `⌄`)
  - `WOMEN` (with a small dropdown chevron `⌄`)
  - `KIDS` (with a small dropdown chevron `⌄`)
  - `CUSTOMIZE`
- **Right Sidebar / Action Rail (Black Vertical Panel):**
  - Background: Solid Black (`#0A0A0A`) vertical slice on the far right.
  - Icons (Top to Bottom):
    1. Hamburger Menu (3 horizontal lines)
    2. Shopping Cart
    3. Location Pin
    4. User Profile
    5. Search Magnifying Glass
    6. Share Icon (at the very bottom right)

---

## 4. Hero Content (Left Column)
- **Subheading:** `MAN'S ORIGINALS` (Uppercase, small, tracking/letter-spacing wide, white, low opacity).
- **Product Title:** `TR_FLYKNIT SHOES` (Extra bold, uppercase, white, large scale).
- **Price:** `$120` (Medium weight, white).
- **Left Menu Indicator:** 3 horizontal lines and a left-aligned navigation block.
- **Scroll Down Indicator:** Small chevron pointing down (`⌄`) near the bottom-left corner.

---

## 5. Product Showcase & Feature Hotspots (Center)
- **Imagery:** Two angled red/orange Nike Huarache-style sneakers floating dynamically with white soles and white laces.
- **Drop Shadow:** Soft, blurred dark elliptical drop shadow underneath the floating shoes to create depth.
- **Interactive Feature Callouts (White text with black circular `+` icons):**
  - **Top Right:** `+ NATURAL MOTION` (pointing to the upper laces/cuff)
  - **Middle Left:** `BAREFOOT STRENGTH +` (pointing to the midfoot/toe box)
  - **Bottom Left:** `GOOD TO RUN FREE +` (pointing to the front sole)

---

## 6. Footer & Call to Action (Bottom Center & Right)
- **Primary CTA Button:**
  - Text: `SHOP NOW`
  - Style: Pill-shaped (fully rounded corners), solid black background (`#000000`), white text, bold, centered horizontally below the shoes.
- **Bottom Right Meta:**
  - Email link: `HIRAKDOBARIYA@GMAIL.COM` (Small, white text, lowercase).
  - Navigation Arrows: Left and right directional arrows (`←` `→`) positioned near the right edge for carousel functionality.

---

## 7. Animation & Interaction Specifications (CSS / JavaScript)
- **Floating Shoe Animation (CSS Keyframes):**
  ```css
  @keyframes float {
    0% { transform: translateY(0px); }
    50% { transform: translateY(-10px); }
    100% { transform: translateY(0px); }
  }
  .hero-shoes {
    animation: float 4s ease-in-out infinite;
  }
  ```
- **Hotspot Pulse Animation:**
  - The `+` badges should have a subtle scale pulse (`scale(1.05)`) on hover.
- **Button Hover States:**
  - `SHOP NOW` button should invert or slightly lighten on hover (`background-color: #222`).
- **Transitions:**
  - Smooth `0.3s ease` transitions on all navigation items, icons, and buttons.
