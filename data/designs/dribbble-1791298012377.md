# Insurance Mobile App UI Design - Production Design Specification

---

## 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Brand Archetype**: Premium, trustworthy, warm, human-centric financial services (insurtech). Balances a modern glassmorphic aesthetic with friendly, high-end warmth via rich copper/sunset orange gradients and clean typography.
- **Visual Density**: Medium-high density layout. Designed with layered depth, floating cards, translucent surface blurs, and overlapping UI panels to present rich data cleanly.
- **Whitespace Balance**: Generous internal component padding offset by compact inter-card vertical gaps (12px to 16px). Uses negative space effectively to establish clear hierarchical separation between core account health and secondary actions.
- **Theme Balance**: Predominantly clean, light-mode canvas background (`#FFFFFF`) with rich, saturated, dark-mode/vibrant gradient cards serving as focal points (e.g., Welcome banner, digital e-cards, hospital list views).

## 4. Layout Architecture & Spatial Grid

- **Container Max-Width**: Fluid container inside a `1440px` desktop viewport preview frame.
- **Grid Structure**: 12-column responsive flex/grid system with standard `24px` gutter spacing.
- **Spacing Scale (Tokens)**:
  - `4px` (`0.25rem`) - Tight micro-spacing
  - `8px` (`0.5rem`) - Badge padding, icon gaps
  - `12px` (`0.75rem`) - Inner card element spacing
  - `16px` (`1rem`) - Standard card padding / external gaps
  - `24px` (`1.5rem`) - Section separation
- **Elevation & Z-Index Hierarchy**:
  - `z-index: 0`: Canvas background
  - `z-index: 10`: Standard cards and containers (`box-shadow: 0 4px 20px rgba(0, 0, 0, 0.05)`)
  - `z-index: 20`: Floating action badges / interactive toggles
  - `z-index: 30`: Modals, tooltips, and active popovers

## 5. Component Blueprint & Element Placement

### A. Welcome & Summary Card (Mobile Hero Component)
- **Dimensions**: Fluid width within mobile viewport frame (approx. `340px` fixed width).
- **Background**: Multi-stop radial warm gradient (`#FF4B2B` transitioning to `#FF416C` and `#833AB4`).
- **Border-Radius**: `24px` (outer card container).
- **Internal Layout**:
  - Top: "Welcome Back" eyebrow (`11px`, white, 80% opacity) + User Name "Willie Schulist" (`22px`, Bold, White).
  - Middle Badge: Pill-shaped notification bar (`rgba(0, 0, 0, 0.2)` backdrop blur) indicating claim status ("You have 2 claims in progress") with right chevron.
  - Bottom Metrics: Balance indicator (`$2,322.98` in `20px` Bold) alongside a pill-shaped primary button ("View Premium").

### B. Standard Content Cards (Hospitals & Services)
- **Background**: Solid `#FFFFFF` or subtle off-white `#F9FAFB`.
- **Border-Radius**: `16px` to `20px`.
- **Borders**: `1px solid #EAECEF`.
- **Shadow**: Soft ambient shadow `0 10px 30px -5px rgba(0, 0, 0, 0.04)`.

### C. Interactive Buttons & Badges
- **Primary Action Buttons**:
  - Background: Dark Charcoal (`#1E1E24`) or Gradient (`#FF6B3B`).
  - Height: `40px` (Compact) to `48px` (Standard).
  - Border-Radius: `20px` (Full pill shape).
  - Text Color: `#FFFFFF`.
- **Category Tags / Badges**:
  - Background: Soft tinted fills (e.g., Orange tint `#FFF2EC` with `#E55A2D` text for "General & Primary Care"; Blue tint `#EFF6FF` with `#3B82F6` text for "Dental & Oral Health").
  - Padding: `4px 10px`.
  - Border-Radius: `8px`.

---

## 6. Motion Mechanics, 3D & Mobile Gestures

- **Animation Triggers**:
  - Hover on interactive cards: Subtle upward translation (`translateY(-4px)`) paired with shadow expansion (`box-shadow: 0 16px 32px rgba(0,0,0,0.08)`).
  - Tab and Toggle Switches: Smooth slide transition (`transform: translateX()`).
- **Timing & Easing**:
  - Standard Transitions: `250ms` cubic-bezier(0.4, 0, 0.2, 1) (Ease-out-quad).
  - Spring Physics for Floating Cards: `tension: 300`, `friction: 20`.
- **Mobile Native Behaviours**:
  - Horizontal carousel snap behavior for Events and e-Cards (`scroll-snap-type: x mandatory`).
  - Pull-to-refresh micro-interactions on feed containers.
  - Haptic feedback trigger on primary claim status badge taps and toggle state changes.
