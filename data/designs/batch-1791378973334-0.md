# Design Specification: "Discover New Places" Landing Page

This document outlines the exact design specifications for recreating the provided landing page concept. The implementation should be responsive, full-screen, and adhere strictly to the visual hierarchy, typography, and color palette of the source material.

---

## 1. Global Layout & Structure

*   **View:** Full-screen (`100vw` width, `100vh` height), immersive hero section.
*   **Grid System:** Asymmetric layout utilizing a central focal point (the stone archway) with balanced text positioning on the left and right gutters.
*   **Background:** 
    *   Base landscape: A desert/canyon setting (reminiscent of Monument Valley) during sunset or golden hour, featuring a warm, desaturated color palette (terracotta, dusty orange, muted blues/greys in the sky).
    *   **Overlay Effect:** A subtle dark gradient or vignette applied over the base background to ensure high contrast and readability for typography.

---

## 2. Typography & Fonts

To achieve an exact match, use clean, modern sans-serif typefaces.

### Primary Font Family
*   **Main Font:** **Inter** or **Helvetica Neue** (Fallback: `sans-serif`).
*   **Weights Used:** Regular (400), Medium (500), and Bold (700).

### Text Elements Specification

1.  **Navigation Links (Header):**
    *   Font Family: Inter / Sans-serif
    *   Size: `14px`
    *   Weight: Regular (400)
    *   Color: `#FFFFFF` (White)
    *   Spacing: Evenly spaced center navigation.

2.  **Sub-header / Eyebrow Text (Left):**
    *   Text: `OUR DESTINATIONS` (or similar small-cap identifier)
    *   Font Family: Inter / Sans-serif
    *   Size: `11px` - `12px`
    *   Weight: Medium (500)
    *   Letter Spacing: `1.5px` (Uppercase)
    *   Color: `rgba(255, 255, 255, 0.7)`

3.  **Main Heading (Left):**
    *   Text: **Discover New Places**
    *   Font Family: Inter / Sans-serif
    *   Size: `48px` to `64px` (Responsive/Fluid clamp preferred)
    *   Weight: Bold (700)
    *   Line Height: `1.1`
    *   Color: `#FFFFFF`

4.  **Secondary Small Text / Location Details (Left):**
    *   Text: `01/05` (Pagination/Slide indicator)
    *   Font Family: Inter / Sans-serif
    *   Size: `12px`
    *   Weight: Regular (400)
    *   Color: `rgba(255, 255, 255, 0.6)`

5.  **Body Copy / Description (Right):**
    *   Text: Short descriptive paragraph about exploring hidden locations.
    *   Font Family: Inter / Sans-serif
    *   Size: `13px` - `14px`
    *   Weight: Regular (400)
    *   Line Height: `1.5`
    *   Color: `rgba(255, 255, 255, 0.8)`
    *   Max Width: `240px`

---

## 3. UI Components & Elements

### A. Navigation Bar (Header)
*   **Position:** Absolute / Sticky at the top (`z-index: 10`).
*   **Elements:** 
    *   Logo (Left): Minimalist text or icon in white.
    *   Nav Links (Center): Home, About, Contact (or similar).
    *   Action/Profile (Right): Minimalist user/search icon.

### B. Central Focal Point (The Portal Arch)
*   **Visual:** A surreal 3D-style stone archway placed dead-center in the composition. 
*   **Effect:** The interior of the arch reveals a slightly different perspective or lighting of the background landscape, creating a "portal" effect.
*   **Dimensions:** Proportionally centered, taking up roughly 50% to 60% of the viewport height.

### C. Call to Action (CTA) Button
*   **Position:** Right-hand side, positioned below the description paragraph.
*   **Text:** `LEARN MORE`
*   **Shape:** Pill/Rounded rectangle (`border-radius: 50px`).
*   **Background Color:** `#F4C430` (Vibrant Warm Yellow / Gold).
*   **Text Color:** `#1A1A1A` (Dark Charcoal).
*   **Font Size:** `12px`
*   **Font Weight:** Bold (700).
*   **Padding:** `12px 24px`.
*   **Hover Effect:** Slight brightness increase or subtle scale-up (`transform: scale(1.05)`).

### D. Carousel / Pagination Indicator
*   **Position:** Bottom center, directly beneath the central arch.
*   **Visual:** Minimalist dot indicator (one active white dot, subtle inactive states).

---

## 4. Animations & Interactions

To replicate the polished feel of the original UI concept, incorporate the following micro-interactions:

1.  **Page Load Animation (Entrance):**
    *   **Fade-in Up:** Text elements on the left and right fade in with a slight upward translation (`translateY(20px)` to `0`) over `0.8s` with an `ease-out` cubic-bezier curve.
    *   **Portal Zoom:** The central archway scales in slightly from `0.95` to `1.0` upon load.

2.  **Hover States:**
    *   **Navigation Links:** Smooth opacity shift from `0.7` to `1.0` on hover.
    *   **CTA Button:** Drop shadow expansion and smooth color shift on hover.

3.  **Parallax Effect (Optional Polish):**
    *   Subtle mouse movement shifts the background landscape and the central arch at different speeds to create a 2.5D depth illusion.
