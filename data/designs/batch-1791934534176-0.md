# Design Specification: Editorial Fashion Landing Page

## 1. Global Setup & Grid Structure
- **Viewport**: 100vw × 100vh, full screen, zero exterior margins.
- **Layout Grid**: 3-column split layout:
  - **Left Panel (42% width)**: Pure white background (`#FFFFFF`), primary text content, navigation.
  - **Center Panel (36% width)**: Hero imagery, numeric index, bottom horizontal navigation bar.
  - **Right Panel (22% width)**: Light gray background (`#F4F4F4`), secondary feature section with rotated sidebar text.

---

## 2. Color Palette
- **Background White**: `#FFFFFF`
- **Right Panel Background**: `#F3F3F5`
- **Primary Text**: `#1A1A1A`
- **Muted/Secondary Text**: `#9E9E9E`
- **Divider Lines**: `#E0E0E0`
- **Dark Action Block**: `#3A3C43` (Text: `#D6D6D8`)
- **Beige Action Block**: `#E5D2C9` (Text: `#3A3C43`)

---

## 3. Typography
- **Primary Headings**: Geometric Sans-Serif (Bold/Black), Uppercase.
  - *Target*: `Montserrat`, `Futura`, or `Gilroy-ExtraBold`
  - *Fallbacks*: `Helvetica Neue`, `Arial`, sans-serif
- **Body & Subtitles**: Modern Sans-Serif (Light/Regular), Uppercase for tags.
  - *Target*: `Inter`, `Helvetica Neue`
  - *Fallbacks*: `system-ui`, sans-serif
- **Hero Numeric Index (`03 /02`)**: Light Sans-Serif or Display Sans.

---

## 4. Component Layout

### Left Panel (42%)
1. **Header (Top)**:
   - **Logo**: Two overlapping outlined square icons (left) + two-line stacked label: `NEW` / `IMAGING COLLECTION` (10px, Medium).
   - **Menu**: Right-aligned text `MENU` + 2-line hamburger icon (12px, tracking-wide).
2. **Hero Copy (Middle-Bottom)**:
   - Category tag: `NEW STYLE IN COLLECTION` (11px, bold, gray, letter-spacing: 2px).
   - Main headline: `YOUR HAIR\nWOULD LOVE IT.` (48px–56px, Extra-Bold, leading: 1.05).
3. **Features Row (Bottom)**:
   - 3 equal-width sub-columns: `EXCLUSIVE`, `STYLE IN`, `COLOR WORLD`.
   - Each column contains:
     - Title (10px, Bold, Uppercase).
     - Thin horizontal divider (`#E0E0E0`).
     - 2-line placeholder copy: `The streak started in late October. Canelas 201...` (9px, gray).
     - Link: `— FIND MORE` (8px, bold, uppercase).

### Center Panel (36%)
1. **Index Display (Top Left)**:
   - Number `03` (40px, regular/light) followed by baseline-shifted `/02` (20px, light).
2. **Hero Image Area**:
   - Covers full panel area below top padding.
3. **Bottom Navigation Bar**:
   - Height: 60px; docked directly to the viewport bottom.
   - **Left Half (Dark Block - `#3A3C43`)**: Left-aligned link `— COLOR WORLD COLLECTION` (10px, light gray).
   - **Right Half (Beige Block - `#E5D2C9`)**: Right-aligned link `NEXT COLLECTION —` (10px, dark gray).

### Right Panel (22%)
1. **Top Section**:
   - Sub-title: `MODERN — ORGANIC` (9px, tracking: 1.5px, gray).
   - Headline: `MORE ABOUT\nSTYLE IN` (20px, Bold, uppercase).
2. **Rotated Vertical Text**:
   - Position: Left border of the right panel, reading upwards.
   - Text: `— NEW STYLE IN COLLECTION` (9px, tracking: 2px, rotation: `-90deg`, transform-origin: center).
3. **Bottom Feature Image Area**:
   - Aligned directly to bottom edge, fills width.

---

## 5. Imagery Specifications

### Hero Image (Center Panel)
- **Content**: Close-up portrait of a female model with a textured, layered shaggy bob and bangs. Model glances down/sideways over her shoulder; wearing a white tank top and a black outer jacket slipped off one shoulder.
- **Composition**: Studio shot with a solid, high-key white/light-gray background (not transparent).
- **Scale/Fitting**: `object-fit: cover`, anchored center.

### Feature Image (Right Panel)
- **Content**: Black-and-white full/three-quarter portrait of a female model with a short bob with bangs. Model is seated/crouched in an editorial pose wearing a black blazer, black trousers, and patterned socks.
- **Composition**: High-contrast monochrome, light studio background (not transparent).
- **Scale/Fitting**: `object-fit: cover`, anchored bottom-center.
