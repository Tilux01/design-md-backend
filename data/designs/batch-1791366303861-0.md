# Design System & Implementation Blueprint

---

## 1. Global Styles & Reset

### Colors
```css
:root {
  --bg-primary: #FFFFFF;
  --text-primary: #1A1A1A;
  --text-secondary: #777777;
  --text-muted: #B5B5B5;
  --border-light: #E5E5E5;
  --button-bg: #EAEAEA;
  --button-hover: #D6D6D6;
}
```

### Typography
- **Primary Font Family:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
- **Brand Font (Logo):** Heavy condensed sans-serif (tracking-tight, uppercase)
- **Base Font Size:** `16px`

---

## 2. Layout Structure

### Grid & Viewport
- **Container:** Full-screen viewport (`100vw` × `100vh`), centered flex column.
- **Layout Model:** Absolute/Flex hybrid layout with a clear header, vertical category sidebar on the left, centered dynamic product display, and minimal top-right utilities.

---

## 3. Component Specifications

### A. Navigation Bar (Header)
- **Position:** Absolute / Fixed top (`top: 32px`, `width: 100%`)
- **Alignment:** Space-between horizontal layout with centered brand mark.
- **Left Links:** `MEN`, `WOMAN` (Uppercase, letter-spacing: `0.05em`, fontSize: `12px`, font-weight: `500`)
- **Center Logo:** `SSENSE` (Uppercase, bold, prominent tracking, fontSize: `20px`)
- **Right Links:** `WISHLIST`, `BLOG` (Uppercase, fontSize: `12px`, font-weight: `500`)
- **Far-Right Utilities:** Search icon, Profile/Cart indicator, Language selector (`EN`)

---

### B. Category Navigation (Left Sidebar)
- **Position:** Absolute left (`left: 64px`, `top: 35%`, `transform: translateY(-50%)`)
- **Layout:** Vertical stack, left-aligned.
- **Search Header:** Small search icon + `"RECHERCHER"` (Uppercase, fontSize: `10px`, color: `var(--text-muted)`)
- **Category Links:**
  - `ACCESSORIES` (fontSize: `20px`, font-weight: `300`, color: `var(--text-muted)`)
  - `BAG` (fontSize: `20px`, font-weight: `300`, color: `var(--text-muted)`)
  - `CLOTHING` (fontSize: `20px`, font-weight: `300`, color: `var(--text-muted)`)
  - `SHOES` (fontSize: `22px`, font-weight: `700`, color: `var(--text-primary)`)
- **Sub-category:**
  - `Sneakers` (fontSize: `11px`, font-weight: `400`, color: `var(--text-secondary)`, underline style)

---

### C. Hero / Product Showcase (Center)
- **Layout:** Centered column structure.
- **Visual Display:** 
  - Central 3D floating sneaker (Gucci Crystals Flashtrek Sneakers) angled dynamically.
  - Flanked by blurred background sneakers (carousel effect / depth of field).
- **Product Typography:**
  - **Brand:** `GUCCI` (Uppercase, bold condensed font, fontSize: `32px`, tracking: `0.05em`, margin-bottom: `4px`)
  - **Details:** `Crystals Flashtrek Sneakers | 1590$` (fontSize: `11px`, color: `var(--text-secondary)`)
- **Action Button:**
  - **Label:** `SEE MORE`
  - **Shape:** Pill button (`border-radius: 50px`, padding: `8px 24px`)
  - **Background:** `var(--button-bg)`
  - **Typography:** Uppercase, fontSize: `10px`, font-weight: `600`, letter-spacing: `0.1em`

---

### D. Utility Controls (Right Side)
- **Position:** Absolute top-right (`right: 64px`, `top: 220px`)
- **Components:** View mode toggle icons (Grid view / List view icons in minimal square containers).

---

## 4. Responsive / Interaction States
- **Hover on Categories:** Color transitions from muted gray (`var(--text-muted)`) to solid black (`var(--text-primary)`).
- **Hover on Button:** Background shifts to `var(--button-hover)`.
