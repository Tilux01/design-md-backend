# UI/UX Specification & Frontend Implementation Blueprint

## 1. Overview & Global Settings

* **Design Concept:** High-end, futuristic e-commerce landing page ("BLUTOPIA" by ESCOPADE). It uses a monochromatic ultramarine/cobalt blue color story with high-contrast white typography and photographic cutout layering.
* **Layout Structure:** Full-screen immersive viewport (`100vw`, `100vh`, `overflow: hidden`), using a CSS Grid / Flexbox hybrid layout.
* **Responsive Behavior:** Desktop-first design optimized for `1440px` viewports. Scales fluidly down to mobile via media queries, collapsing navigation and repositioning the hero cutout and typography.

### Color Palette

| Color Name | Hex Code | Usage |
| :--- | :--- | :--- |
| **Primary Blue (Deep Cobalt)** | `#1734B7` (Approx.) | Background canvas, overall theme |
| **Pure White** | `#FFFFFF` | Headlines, logo, abstract background letters |
| **Metallic Silver / Gray** | `#D4D8DD` | Sub-headlines, secondary UI highlights |
| **Black / Dark Charcoal** | `#0D0E15` | Model's turtleneck, deep shadows |
| **Cyan / Neon Blue** | `#2AD4FF` | Visor lens gradients |

---

## 2. Typography & Fonts

### Primary Headline Font (BLUTOPIA)
* **Font Family:** `Syncopate` or `Syne` (Weight: Bold `700`)
* **Fallback Stack:** `sans-serif`
* **Styling:** Extra-wide letter-spacing (`letter-spacing: 0.1em`), uppercase.

### Body & Navigation Font
* **Font Family:** `Inter` or `Plus Jakarta Sans` (Weights: Regular `400`, Medium `500`, Semi-Bold `600`)
* **Fallback Stack:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`

### Abstract Background Typography
* **Font Family:** Custom ultra-heavy bubble/display font (Simulated via SVG path or custom WOFF2 font like `Monument Extended` / `Clash Display`).

---

## 3. Section-by-Section Layout & Components

### A. Header / Navigation Bar (`<header>`)
* **Position:** Fixed / Absolute at top (`top: 40px`, `left: 60px`, `right: 60px`).
* **Display:** Flexbox, `justify-content: space-between`, `align-items: center`.
* **Left Element (Logo):**
  * Text: `ESCOPADE`
  * Styling: Font-size `14px`, tracking `0.2em`, Font Weight `700`, Color: `#FFFFFF`.
* **Right Elements (Actions):**
  * Profile/Account Icon (SVG user silhouette).
  * Menu/Hamburger Icon (Two horizontal bars of unequal length).
  * Gap between icons: `24px`. Color: `#FFFFFF`.

---

### B. Hero Section (`<section class="hero">`)

#### 1. Background Layer (Z-index: 1)
* **Canvas:** Solid gradient fill (`#10289E` to `#1D3BCE`).
* **Abstract Lettering:** Large stylized white overlapping letterforms (resembling "a" or abstract loops) rendered behind the model at 15–20% opacity or with a soft blend mode (`overlay` / `soft-light`), creating depth.

#### 2. Main Typography Block (Z-index: 2)
* **Position:** Absolute, anchored to the middle-left (`top: 45%`, `left: 60px`).
* **Sub-headline:** `DISCOVER >` (Font-size: `11px`, tracking `0.15em`, color `#C0C5D0`, underline or hover transition).
* **Main Headline (`H1`):** `BLUTOPIA`
  * Styling: Font-size `clamp(48px, 6vw, 96px)`, Font Weight `800`.
  * Special Effect: Metallic horizontal gradient fill from `#FFFFFF` to `#A5B3D4` with a subtle drop shadow (`0px 10px 30px rgba(0,0,0,0.3)`).

#### 3. Central Model Imagery (Z-index: 3)
* **Asset:** Cutout photograph of a male model facing forward.
  * Wearing: Bright blue puffer jacket, futuristic blue mirrored wrap-around visor, dark turtleneck.
  * Holding: Quilted blue leather clutch bags.
* **Position:** Absolute, anchored to the bottom-right (`right: 15%`, `bottom: 0`).
* **Drop Shadow:** Deep ambient shadow underneath the bust (`box-shadow` or backdrop blur).

#### 4. Floating Elements & Widgets
* **Right-Side Social Links (Vertical Stack):**
  * Position: Absolute (`right: 60px`, `top: 50%`, `transform: translateY(-50%)`).
  * Items: `Tw` / `IN` / `YT` (Font-size: `11px`, Font Weight: `600`, Color: `#FFFFFF`, opacity `0.8`).
* **Interactive Indicator Dot:**
  * A white circular button with a black inner dot floating near the right center (`right: 25%`, `top: 55%`). Used as a product hotspot or focal point.

---

### C. Bottom Product Carousel / Feature Bar (`<div class="hero-footer">`)

* **Position:** Absolute (`bottom: 40px`, `left: 60px`, `right: 60px`).
* **Display:** Flexbox, `justify-content: space-between`, `align-items: flex-end`.

#### Left Side (Thumbnail & Copy):
* **Thumbnail Card:** Small rounded square image (`60px × 60px`, `border-radius: 8px`) showing a portrait thumbnail of the model.
* **Text Block:**
  * Paragraph 1: *"Add a bit of color to your wardrobe with one of our menu"* (Font-size: `12px`, Color: `#D0D6E2`).
  * Paragraph 2: *"blue & savy jackets & create evolution in a range of styles"* (Font-size: `12px`, Color: `#D0D6E2`).
  * Call to Action: `DISCOVER >` (Font-size: `11px`, Font Weight: `700`, Color: `#FFFFFF`).
* **Pagination Dots:** Three horizontal small circles (`8px` diameter), middle one active/white, others translucent.

#### Right Side (Carousel Controls):
* **Arrows:** Left (`<`) and Right (`>`) navigation chevrons enclosed in subtle clickable wrappers (`gap: 16px`, Color: `#FFFFFF`).

## 4. Animation & Interaction Blueprint

### Page Load Sequence (Entrance Animations via GSAP / Framer Motion):
1. **Background Fade-In:** Canvas fades in (`opacity: 0` -> `1`, duration: `0.8s`).
2. **Typography Slide-In:** The `"BLUTOPIA"` heading translates from `Y: 40px` to `0` with `opacity: 0` -> `1` (Duration: `1s`, Ease: `power3.out`, Delay: `0.3s`).
3. **Model Cutout Reveal:** The main model image scales up slightly from `0.95` to `1.0` with a smooth fade-in (Duration: `1.2s`, Delay: `0.2s`).
4. **UI Elements Stagger:** Header links, social sidebars, and the bottom carousel slide in from their respective edges with a `0.1s` stagger delay.

### Hover & Interactive States:
* **`DISCOVER >` Links:** On hover, the arrow (`>`) translates `4px` to the right with a transition time of `0.3s ease`.
* **Social Links (`Tw`, `IN`, `YT`):** Opacity shifts from `0.7` to `1.0` on hover, accompanied by a subtle letter-spacing expansion.
* **Carousel Arrows:** Background pill background scales up from `0` to `10%` white opacity on hover.
* **Product Hotspot Dot:** Pulses continuously using a CSS keyframe scale animation:
  ```css
  @keyframes pulse {
    0% { transform: scale(1); box-shadow: 0 0 0 0 rgba(255, 255, 255, 0.4); }
    70% { transform: scale(1.05); box-shadow: 0 0 0 10px rgba(255, 255, 255, 0); }
    100% { transform: scale(1); box-shadow: 0 0 0 0 rgba(255, 255, 255, 0); }
  }
  ```
