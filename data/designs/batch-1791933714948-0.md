# Design Specification: Elite Construction Landing Page

## 1. Color Palette

*   **Background**: `#F4F4F5` (Off-white / Light gray)
*   **Surface Light**: `#EBEBED` (Slightly darker tint for light metric cards)
*   **Surface Dark**: `#18181B` (Charcoal black for CTA and primary card)
*   **Overlay Glass**: `rgba(24, 24, 27, 0.45)` with `backdrop-filter: blur(12px)`
*   **Text Primary**: `#09090B` (Dark charcoal)
*   **Text Inverted**: `#FFFFFF` (Pure white)
*   **Text Muted**: `#71717A` (Medium gray)
*   **Text Muted Light**: `#A1A1AA` (Subtle light gray on dark backgrounds)

---

## 2. Typography

*   **Primary Display Font**: *Bebas Neue*, *Oswald*, or fallback `sans-serif-condensed`, `Impact`.
    *   Headline: Condensed, uppercase, weight `700`, size `56px`, line-height `1.05`, tracking `tight`.
*   **Body & Interface Font**: *Inter*, *Plus Jakarta Sans*, or fallback `Helvetica Neue`, `Arial`, `sans-serif`.
    *   Logo: `18px`, medium/bold weight.
    *   Nav Items: `14px`, weight `500`, muted gray (`#71717A`); active item is `#09090B`.
    *   Hero Subheading: `18px`, weight `400`, color `#71717A`.
    *   Metrics Numbers: `42px`, weight `700`, condensed or tight sans-serif.
    *   Metrics Subtitles: `11px`, weight `600`, tracking `wider`, uppercase.

---

## 3. Layout Structure

*   **Viewport**: Fullscreen single-page dashboard/landing view (`100vw`, `min-height: 100vh`).
*   **Content Container**: Max-width `1280px`, horizontal centered, `padding: 40px 48px`.
*   **Vertical Flow**:
    1.  Header Bar (`flex`, space-between)
    2.  Title & Primary Action Row (`grid` or `flex` with bottom alignment)
    3.  Hero Feature Banner (Rounded card with overlaid details)
    4.  Metrics Row (3-column asymmetric grid)

---

## 4. Component Details

### Header
*   **Logo**: Left-aligned text "APART" (`font-weight: 700`) + "ment.Q" (`font-weight: 300`).
*   **Navigation Menu**: Horizontal flex list (`gap: 32px`). Active link ("Home") features a small, centered horizontal black indicator line (`width: 32px`, `height: 2px`) positioned `6px` underneath.

### Hero Header Row
*   **Title Block**: Left side. Large condensed header over a single-line light-gray subtext (`margin-top: 8px`).
*   **Action Button**: Right side. "Learn More", rounded pill (`border-radius: 9999px`), background `#18181B`, text white, `padding: 12px 28px`, font size `14px`.

### Hero Image Banner
*   **Dimensions & Radius**: Height `440px`, full container width, `border-radius: 28px`, overflow hidden, relative positioning.
*   **Image Specs**:
    *   *Visual*: Low-angle shot looking up at two modern glass and steel high-rise skyscrapers against an overcast, desaturated gray sky. Dark, reflective windows, strong architectural vertical lines.
    *   *Format*: Full photograph, no alpha transparency. Centered crop, 0° rotation.
*   **Floating News Bar**:
    *   Positioned at the bottom of the banner (`left: 24px`, `right: 88px`, `bottom: 24px`).
    *   Background: Dark frosted glass (`rgba(20, 20, 20, 0.4)`), `backdrop-filter: blur(16px)`, `border: 1px solid rgba(255, 255, 255, 0.1)`.
    *   Radius: `20px`. Padding: `16px 20px`.
    *   Includes a pill tag: "NEWS" (white background, black text, `font-size: 10px`, uppercase, `font-weight: 700`).
    *   Text: "Leaders in elite construction" (`16px`, white, medium) and small secondary service description (`12px`, muted light).
*   **Floating Banner Action**:
    *   Position: Bottom right (`right: 24px`, `bottom: 24px`).
    *   Style: Circular white button (`width: 48px`, `height: 48px`, `border-radius: 50%`), containing an upward-right arrow icon (`↗`, `#18181B`, `size: 18px`).
