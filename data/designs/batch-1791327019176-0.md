# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial Organic Luxury / Neo-Brutalist Modernism. Combines high-fashion bold typography with raw organic food textures and warm, earthy color tones.
- **Visual Density & Whitespace Ratio**: High visual impact with large marquee text, balanced by spacious card grids, warm cream canvases, and crisp black UI dividers.
- **Surface Elevation Model**: Flat, minimal surface elevation relying on sharp border divisions (`1px solid #1a1a1a`), warm neutral background layers, and high-contrast typography rather than soft drop shadows.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-contrast marquee text overlays, edge-to-edge photography grids, sharp black borders, high-impact uppercase tracked typography.
- **Pill Badge Specification**: Padding `6px 16px`, font-size `12px`, font-weight `700`, tracking `0.08em`, border-radius `9999px`, background `#111111`, text `#FFFFFF`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;`.

## 3. Product Cards Grid (Featured Section)
- **Layout & Positioning**: `grid`, grid template columns `repeat(4, minmax(0, 1fr))`, gap `0px`.

- **Card Specs**: Background `#FFFFFF`, border-right `1px solid #111111`, border-bottom `1px solid #111111`, padding `24px`.
- **Typography**: Product title font `'Plus Jakarta Sans'`, size `14px`, weight `600`, price font size `14px`, weight `700`.
- **JSX Blueprint**:
```jsx
export function ProductGrid() {
  const products = [
    { title: "ALOE BAR", price: "$12.00", img: "/bar.jpg" },
```
