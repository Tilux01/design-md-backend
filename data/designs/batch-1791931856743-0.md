# Design Specification: Logitech Z150 Showcase Dashboard

## 1. Overview & Theme
A dark-mode, high-tech product showcase for the Logitech Z150 Stereo Speakers. Features rounded floating cards, sleek border outlines, and monochrome aesthetics.

- **Theme**: Dark Neumorphic / Cyber-Minimalist
- **Base Canvas**: `100vw` × `100vh` (Full screen, no outer mockup borders)

---

## 2. Color Palette
- **Canvas Background**: `#0A0A0A`
- **Surface / Card Background**: `#141414`
- **Card Borders**: `1px solid #242424`
- **Text Primary**: `#FFFFFF`
- **Text Secondary**: `#8A8A8A`
- **Text Muted**: `#4A4A4A`
- **Accent / Interactive**: `#FFFFFF` (Pill button), `#1F1F1F` (Pill base)

---

## 3. Typography
- **Primary Font**: `Inter`, `SF Pro Display`, or `Helvetica Neue`
- **Fallback**: `system-ui, -apple-system, sans-serif`
- **Styles**:
  - **Headings**: Uppercase, Bold/Semi-bold, tracked (`letter-spacing: 0.05em`).
  - **Body**: Regular (400), 12px–14px, muted gray, high readability.

---

## 4. Layout & Grid Architecture
The screen is split into a **Main Showcase Center** flanked by side interactive widgets.

```
+-------------------------------------------------------------+
| [Nav Pills]                 [Logitech Logo]          [Icon] |
|                                                             |
|                          [  MAIN  ]          [Audio Widget] |
|                          [SPEAKER ]                         |
| [Info / Buy Card]        [ IMAGE  ]          [Dial Widget]  |
|                                                             |
|                     [Carousel Scroller]                     |
+-------------------------------------------------------------+
```

---

## 5. Component Breakdown

### 5.1. Top Navigation & Header
- **Left**: Horizontal capsule containing 3 pill links: `Store`, `Products`, `App`.
  - Border: `1px solid #262626`, rounded-full.
- **Center**: Official `logitech` wordmark logo in white.
- **Right**: Small circular menu/search button with subtle border.

### 5.2. Center Stage (Product Hero)
- **Container**: Large central card container with large corner radius (`rounded-3xl`) and subtle inset shadow.
- **Hero Image Specification**:
  - **Asset**: Cutout PNG (transparent background) of a single Logitech Z150 speaker.
  - **Appearance**: Black chassis with a white/light-gray front baffle, top circular driver cone, bottom rectangular acoustic reflex port, and subtle brand logo.
  - **Placement & Rotation**: Centered, 3/4 perspective facing right, tilted back approx. 5–10 degrees.
- **Bottom Scroller**: Rounded horizontal track bar serving as a carousel/slide indicator.

### 5.3. Bottom-Left Card (Product & Purchase Info)
- **Container**: Floating card (`rounded-2xl`, background `#121212`, border `#242424`).
- **Content**:
  - **Title**: `Z150 STEREO SPEAKERS` (Uppercase, Bold).
  - **Subtitle/Specs**: Small secondary label and a short 2-3 line body description.
  - **CTA Bar**: Pill-shaped horizontal container:
    - Left text: `$49.99`
    - Center button: `ORDER NOW` (white background, black bold text).
    - Right button: Black circular button with right-pointing arrow (`→`).

### 5.4. Right Column (Feature Widgets)
Two vertically stacked cards (`rounded-2xl`, border `#242424`):

1. **Top Card — Audio Equalizer**:
   - Title: `CLEAR STEREO SOUND` (Uppercase).
   - Short body description.
   - Graphic: Dynamic white vertical-bar audio frequency visualizer waveform.
2. **Bottom Card — Controls**:
   - Visual: Minimalist volume/power rotary dial with a glowing white circular stroke arc.
   - Title: `EASY CONTROLS` (Uppercase).
   - Short body description below.

---

## 6. Micro-Interactions & Styling
- **Border Radius**: Cards `24px`; Buttons/Pills `9999px` (fully rounded).
- **Transitions**: `all 0.3s cubic-bezier(0.4, 0, 0.2, 1)`.
- **Button Hover**: Invert colors / 10% opacity glow on dark elements.
