# LUXURA Web Experience — Design Specification (`design.md`)

This document provides a comprehensive, pixel-level design specification to construct an exact, full-width responsive clone of the LUXURA web sections shown in the reference: the **"Why style lovers choose LUXURA" (Bento Grid)** section and the **"What our clients say" (Testimonials Carousel)** section.

---

## 1. Global Visual & Brand Architecture

### 1.1 Color Palette
* **Page Canvas Background:** `#FAFAFC` (Ultra-clean, crisp neutral light-gray canvas).
* **Card Surface Fill:** `#ECECED` (Uniform neutral soft-gray container fill).
* **Card Inset / Highlight White:** `#FFFFFF` (Solid pure white).
* **Text Colors:**
  * **Primary High-Contrast:** `#111111` (Near pure black for titles, primary phrases, author names).
  * **Secondary / Body Gray:** `#606066` (Subtitles, body quotes, author job titles).
  * **Two-Tone Subdued Accent:** `#9FA0A7` (Muted gray used to de-emphasize secondary clauses in dual-tone headings).
  * **Badge Text:** `#55555C` (Refined neutral for micro-caps badges).
* **Badge Background:** `#E4E4E8` (Soft matte pill background).
* **Primary Interactive Surface:** `#111111` (Deep black CTA button).
* **Secondary Interactive Outline:** `#D8D8DC` (Border for slider arrow buttons).

## 2. Typography & Font Stack

### 2.1 Font Families
* **Primary Font:** **Inter Display** or **SF Pro Display**

## 3. Layout Grid & Container Specs

* **Full Page Mode:** Full viewport width (`100vw`), content centered.
* **Maximum Content Width:** `1200px` (Max outer bounds).
* **Horizontal Padding:** `24px` (Mobile) / `48px` (Desktop).
* **Section Vertical Spacing:**
  * Top padding to Section 1: `64px`.
  * Space between Section 1 and Section 2: `100px`.
  * Bottom padding after Section 2: `64px`.
* **Section Header Alignment:** Centered text, vertical stack with `16px` spacing between badge, heading, and subtitle.

## 6. Responsive Behavior Rules

1. **Desktop (`≥ 1024px`):** Exact layout as displayed in the media reference (3-column bento, 4-column testimonial grid).
2. **Tablet (`768px – 1023px`):**
   * Bento Grid converts to a 2-column format: Left Card becomes full-width or side-by-side with Card D; Cards B and C share a row.
   * Testimonials grid shifts to a 2×2 layout or horizontal scroll snapping list.
3. **Mobile (`< 768px`):**
   * Bento Grid collapses to a clean single-column vertical stack.
   * Testimonials collapse to a touch-swipe carousel showing 1 card at a time with indicator dots/arrows intact.
