# Design Specification: Horizon Aesthetic Mental Wellness App

This document provides complete, production-ready design specifications to create an exact front-end clone of the provided UI screens. It outlines the typography, color system, spacing, component layout, and interactive behaviors for a full-screen, responsive mobile-first web application. All device borders, mockups, and external presentation backgrounds are omitted to focus entirely on the native web UI.

---

## 1. Typography & Font System

The typography mixes elegant, high-contrast serif headers with modern, clean, high-legibility sans-serif body copy to create a calm, premium editorial aesthetic.

### Font Families
*   **Serif (Display & Headings):** 
    *   *Primary:* `Playfair Display` (Google Fonts)
    *   *Alternative:* `DM Serif Display` or `Clash Display`
    *   *System Fallback:* `Georgia`, `Didot`, `serif`
*   **Sans-Serif (UI, Labels, & Body):**
    *   *Primary:* `Plus Jakarta Sans` or `Inter` (Google Fonts)
    *   *Alternative:* `Satoshi` (Fontshare)
    *   *System Fallback:* `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`

### Typography Hierarchy

| Style Role | Font Family | Weight | Size (px / rem) | Line Height | Letter Spacing |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Main Screen Header** ("Dear Horizon") | Serif | 500 (Medium) | `32px` / `2rem` | 1.2 | `-0.02em` |
| **Section Title** ("Thought of the day") | Serif | 600 (Semi-Bold) | `36px` / `2.25rem` | 1.15 | `-0.03em` |
| **Card Title (Large)** | Serif | 600 (Semi-Bold) | `24px` / `1.5rem` | 1.25 | `-0.01em` |
| **Pill / Navigation Labels** | Sans-Serif | 600 (Semi-Bold) | `14px` / `0.875rem` | 1.0 | `+0.02em` |
| **Body Text (Card Content)** | Sans-Serif | 400 (Regular) | `15px` / `0.9375rem` | 1.6 | `normal` |
| **Overline / Muted Sub-headers** | Sans-Serif | 700 (Bold) | `11px` / `0.6875rem` | 1.4 | `+0.08em` (All Caps) |
| **Date / Meta Text** | Sans-Serif | 500 (Medium) | `13px` / `0.8125rem` | 1.4 | `normal` |

## 5. Interactions, Micro-animations & Gestures

To deliver a high-quality user experience, incorporate the following web-animations:

### 1. Page Transition (Dashboard to Detail View)
*   **Trigger:** Click/Tap on the "Thought of the Day" grid card.
*   **Transition Type:** Shared Element Transition.
*   **Animation Details:**
    *   The clicked card expands to fill the viewport as a white canvas card (`transform-origin: center`).
    *   The title "Thought of the day" shifts upwards using a subtle CSS transform translation (`translateY(-20px) -> translateY(0)`) accompanied by a cubic-bezier easing (`cubic-bezier(0.16, 1, 0.3, 1)`) over `450ms`.
    *   The background shifts from the warm blue-lavender gradient to the pure soft lavender-cream scale gradient with a cross-fade transition.

### 2. Micro-interactions
*   **Category Pills:** Hovering/tapping inactive category pills changes background transparency from `0.15` to `0.25`. Clicking scales the active selector with a bounce effect (`transform: scale(0.95) -> scale(1.0)` via spring physics).
*   **Grid Hover Effect:** Cards shift upwards by `3px` with an expanded shadow when hovered on desktop displays.
    ```css
    .grid-card {
      transition: transform 0.3s cubic-bezier(0.25, 0.8, 0.25, 1), box-shadow 0.3s ease;
    }
    .grid-card:hover {
      transform: translateY(-3px);
      box-shadow: 0 12px 24px rgba(0, 0, 0, 0.06);
    }
    ```

### 3. Touch Gestures
*   **Detail Card Dismiss:** Sliding down on the main detail card on mobile triggers a spring-back anchor; dragging down past `120px` pops the screen back down into the Dashboard grid view.
