# Design Specification: Jesko Jets Homepage

## 1. Overview & Layout Strategy
* **Goal:** Create a high-end, immersive luxury private aviation landing page.
* **Layout Structure:** Full-screen (`100vw` / `100vh`), dark-mode-first aesthetic with a stark black/charcoal background (`#0b0b0b`).
* **Visual Hierarchy:** Centered around a 3D/photorealistic aircraft window graphic acting as the hero focal point, flanked by bold, layered typography.

---

## 2. Typography & Fonts

### **Primary Display Font (Headers):**
* **Font Family:** `Syne`, `Clash Display`, or `Cinzel` (or high-end geometric luxury serif/sans-serif).
* **Fallback Stack:** `font-family: 'Syne', 'Helvetica Neue', Arial, sans-serif;`
* **Styling Rules:**
  * **"We are movement" / "We are distinction":** 
    * Size: `clamp(2.5rem, 5vw, 6rem)`
    * Line-height: `1.05`
    * Weight: `700` (Bold)
    * Text transform: Lowercase or sentence case depending on strict brand assets.

### **Body Copy & UI Elements:**
* **Font Family:** `Inter`, `General Sans`, or `system-ui`.
* **Fallback Stack:** `font-family: 'Inter', -apple-system, BlinkMacSystemFont, sans-serif;`
* **Styling Rules:**
  * **Paragraph text:** `1rem` (16px), Line-height: `1.5`, Opacity: `0.8`, Color: `#d1d1d1`.
  * **Nav Links / Micro-copy:** `0.875rem` (14px), Uppercase tracking (`letter-spacing: 1px`).

---

## 3. Color Palette & Theming

| Role | Hex Code / Value | Usage |
| :--- | :--- | :--- |
| **Background Primary** | `#0a0a0a` | Deep obsidian canvas |
| **Text Primary** | `#ffffff` | Headings, primary CTA |
| **Text Muted** | `#a1a1a6` | Subtitles, paragraph blocks |
| **Sky Graphic Tint** | `#7abaff` to `#e6f0ff` | Inside the airplane window portal |
| **Border / UI Accents** | `rgba(255, 255, 255, 0.15)` | Subtle structural lines, buttons |

---

## 4. Component Breakdown & Structure

### **A. Navigation Header**
* **Position:** Fixed / Absolute top (`z-index: 100`)
* **Layout:** Flexbox, space-between.
* **Left:** Brand Logo ("Jesko Jets").
* **Center:** Nav Links: `About`, `Our Fleet`, `Advantages`, `Global`.
* **Right:** Contact info (`+971 54 433 6060`, `info@jeskojets.com`).

### **B. Hero Section (The Core Visual)**
* **Centerpiece:** A photorealistic or 3D-rendered airplane window (`<iframe>` or `<model-viewer>` or high-res WebP image with parallax layers).
* **Portal Interior:** Shows an expansive sky gradient with soft clouds and sun flare.
* **Overlapping Text Left:** 
  * *"We are movement"* (positioned overlapping the left edge of the window frame).
  * Sub-block: *"Your freedom to enjoy life"* + paragraph about personalized flight comfort.
* **Overlapping Text Right:**
  * *"We are distinction"* (positioned overlapping the right edge of the window frame).
* **Interactive Elements:**
  * **CTA Button ("Book the Flight"):** Pill-shaped, semi-transparent frosted glass (`backdrop-filter: blur(10px)`), with a white outline and an airplane icon.
  * **Scroll Indicators:** Vertical text indicators on the bottom right reading *"SCROLL DOWN"*.

---

## 5. Animations & Interactions

1. **Parallax on Scroll / Mouse Move:**
   * The central airplane window should slightly tilt or translate based on mouse coordinates (`gsap` or `vanilla-tilt.js`).
2. **Text Glitch / Fade-In on Load:**
   * Headlines (`We are movement`) should slide up from opacity `0` with a subtle blur-to-focus CSS filter effect (`filter: blur(8px) -> blur(0px)`).
3. **Hover States:**
   * **Nav Links:** Underline expand from center on hover (`transition: width 0.3s ease`).
   * **CTA Button:** Background shifts from transparent to solid white with inverted dark text (`#000000`).
