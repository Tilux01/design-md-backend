# Design System & Implementation Specification: fitup Landing Page

This document provides a 1:1 blueprint to reconstruct the **fitup** landing page canvas. It specifies layout structures, typography, color palettes, visual assets, cutout image requirements, and component hierarchies.

---

## 1. Canvas & Global Layout Settings

*   **Canvas Type:** Full-width web application landing page (no device frames, outer mockups, or bezel borders).
*   **Base Canvas Color:** Smooth vertical gradient transition from light cool gray to warm off-white.
    *   `background: linear-gradient(180deg, #E2E5E9 0%, #EEF0F3 40%, #E3E6EA 100%)`
*   **Max Container Width:** `1280px` (centered horizontally with `padding: 0 32px`).
*   **Global Radius System:**
    *   Large Content Cards: `28px`
    *   Medium Elements/Badges: `16px`
    *   Pill Buttons & Tags: `9999px` (fully rounded)
*   **Decorative Elements:** Light geometric line-art sunburst/asterisk vectors ( opacity `0.25` - `0.4`) scattered subtly in the background margins.

## 3. Typography Architecture

### Font Families
1. **Primary Sans (Headings & UI):** `Plus Jakarta Sans` or `Outfit`
   * *Fallback:* `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
2. **Body Copy:** `Inter` or `Plus Jakarta Sans`
   * *Fallback:* `"Helvetica Neue", Arial, sans-serif`
3. **Accent Signature Font (Designer Tag):** `Caveat` or `Reenie Beanie` (Handwritten script style)

### Hierarchy & Scale
*   **Hero Heading:** `56px` / Line Height: `1.1` / Weight: `800` (ExtraBold)
*   **Section Headings:** `40px` / Line Height: `1.15` / Weight: `700` (Bold)
*   **Card Headings / Subheadings:** `20px` - `24px` / Weight: `700`
*   **Body Text:** `14px` - `15px` / Line Height: `1.6` / Weight: `400` (Regular)
*   **Button Text & Badges:** `13px` - `14px` / Weight: `600` (SemiBold) / Letter Spacing: `0.02em`
*   **Footer Giant Brand Text:** `160px+` / Weight: `900` (Black)
