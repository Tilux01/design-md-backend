# UI/UX Specification & Design Document

## 1. Overview & General Layout
- **Design Type:** Full-screen landing page hero section for a beverage brand ("Tarragon").
- **Background Color:** Soft warm peach/cream solid fill (`#FDF5EC` approximately).
- **Layout Structure:** 
  - **Header (Navigation):** Fixed horizontal top bar featuring brand logo left, navigation links centered, search icon, user profile avatar, and username right.
  - **Hero Stage (Main Content):** Centered product showcase dominated by a large beverage can (`Tarragon Orange`), typography overlaying the background, floating fruit elements (leaves, sliced orange halves), and a CTA button at the bottom center.
  - **Grid/Alignment:** Symmetrical, centered composition with floating elements placed asymmetrically to create visual depth and a dynamic, playful vibe.

---

## 2. Typography & Fonts

### **Primary Font Family:** 
- **Font Name:** Sans-serif modern geometric style (resembling *Inter*, *Plus Jakarta Sans*, or *Poppins*).
- **Fallbacks:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.

### **Typography Hierarchy:**
1. **Brand Logo ("Tarragon" top-left):**
   - Font Weight: Bold (700)
   - Font Size: `24px`
   - Color: `#1A1A1A`
2. **Navigation Links ("Products", "About", "Insights"):**
   - Font Weight: Medium (500)
   - Font Size: `16px`
   - Color: `#1A1A1A`
3. **User Profile Name ("salman"):**
   - Font Weight: Medium (500)
   - Font Size: `15px`
   - Color: `#1A1A1A`
4. **Watermark / Background Text ("Orange"):**
   - Font Weight: Extra Bold (800)
   - Font Size: Huge (~`280px` scale across background)
   - Color: Translucent peach tone (`rgba(240, 180, 130, 0.4)`) positioned behind the can.
5. **Can Branding Text:**
   - **"Tarragon" (Top of can):** Black, bold serif or custom stylized sans-serif, size ~`22px`.
   - **"Orange" (Bottom of can):** Bold sans-serif, size ~`18px`.
   - **Taglines ("enjoy a refreshing drink", "Best way to enjoy fruit juice"):** Light/Regular sans-serif, size `8px` - `10px`, uppercase/sentence case.
6. **Button Text ("Click to Slide"):**
   - Font Weight: Medium (500)
   - Font Size: `14px`
   - Color: `#1A1A1A`

## 4. UI Components & Elements

### **4.1 Navigation Bar**
- **Left:** Brand logo text `"Tarragon"`.
- **Center:** Navigation links:
  - `Products`
  - `About`
  - `Insights`
- **Right:**
  - **Search Icon:** Minimalist thin-stroke magnifying glass inside a subtle circular container or floating.
  - **User Profile Pill:** Rounded pill background (`#FFFFFF`) containing:
    - Circular avatar image (3D/cartoon stylized user face).
    - Username label `"salman"`.

### **4.2 Hero Centerpiece (Product Showcase)**
- **Central Can Mockup:**
  - Metallic silver top and bottom rims with realistic cylindrical lighting gradients.
  - White label body wrapped around the aluminum can.
  - Center graphic on the can label: A stylized 2D line-art / flat illustration of a character interacting playfully with the orange juice theme (person wearing a cow-print patterned shirt and bright orange pants, mid-motion/leaping).
- **Floating Fruit & Nature Elements:**
  - **Top Left:** A pair of vibrant green fresh citrus leaves with realistic veining and lighting highlights.
  - **Bottom Left:** A crisp, glossy cross-section slice of a fresh orange, showing pulp segments and white pith.
  - **Middle Right:** A tilted half-slice of an orange floating mid-air, casting subtle drop shadows.
- **Background Typography:**
  - The letters **"Or"** appear to the left of the can, and **"e"** appears to the right, with the center part of the word obscured behind the can.

### **4.3 Call to Action (CTA)**
- **Button ("Click to Slide"):**
  - Shape: Pill-shaped button with a thin dark outline border.
  - Background: Transparent / matches background.
  - Placement: Centered horizontally beneath the main can graphic.
  - Interaction: Hover state should feature subtle scaling or background tint shift.

---

## 5. Animation & Interaction Specifications (For Developers)

- **Scroll/Entrance Animations (Framer Motion / CSS Keyframes):**
  - **Can Mockup:** Gentle floating loop animation (`transform: translateY` up and down by `10px` over 3 seconds using `ease-in-out`).
  - **Floating Fruits (Leaves & Oranges):** Parallax micro-movements reacting to mouse hover (clientX/clientY offset tracking) to create a 3D depth effect.
  - **Background Typography ("Orange"):** Fade-in with scale-up on initial page load (`opacity: 0 -> 1`, `scale: 0.95 -> 1`).
- **Button Micro-interaction:**
  - `transition: all 0.25s ease;`
  - On hover: Background color shifts to `#1A1A1A` with text color inverting to `#FFFFFF`.
