# design.md — DarkFeather Landing Page Clone

## 1. Global Specifications & Layout

*   **View Mode:** Full-screen viewport (`100vw`, `100vh`), bypassing the tablet device frame entirely.
*   **Background Color:** `#0a0a0a` (Deep Matte Black).
*   **Color Palette:**
    *   Primary Text: `#ffffff` (Pure White).
    *   Secondary Text / Muted: `#8e8e93` (Cool Gray).
    *   Accent / Image Highlights: Deep burning orange/coral gradients (`#ff4d00` to `#1a0000`) visible in the hero abstract photography.
*   **Grid System:** Asymmetric layout featuring a sticky/fixed top navigation, a left-aligned hero text block with descriptive meta-copy, and a scrolling horizontal/grid section for "Case Studies".

## 3. Component Breakdown & Structure

### A. Navigation Bar (`<header>`)
*   **Position:** Fixed top, full width, padded horizontally (`px-8 md:px-16`, `py-6`).
*   **Left Element:** Logo branding. Includes a custom SVG/icon (4-petal flower shape) followed by the text "DarkFeather".
*   **Right Element:** Menu items: `Work`, `Company`, `Blog`, `Career`, `Contact`.
    *   *Interaction:* Hover state shifts text color from `#cccccc` to `#ffffff` with a smooth `0.2s ease` transition.

### B. Hero Section (`<section class="hero">`)
*   **Layout:** CSS Grid / Flexbox splitting the viewport horizontally.
    *   *Left Column:* Small secondary text block + Interactive diagonal arrow icon (`↗`).
    *   *Center Column:* Massive stacked headline.
    *   *Right Column / Background:* Abstract 3D sphere graphic with dramatic warm rim lighting (orange/coral gradient on dark background).
*   **Arrow Icon:** Contained in a subtle circular or bordered interactive button linking to a primary call-to-action or project reel.

### C. Case Studies Section (`<section class="case-studies">`)
*   **Header Row:**
    *   Left: Pagination indicator (`1–5`).
    *   Center/Left: Section Title ("Case Studies").
*   **Content Grid:**
    *   Horizontal scroll or multi-column grid displaying project cards.
    *   *Card 1:* Light gray/white interior product shot (car interior/roof detail).
    *   *Card 2:* Warm pastel environment shot (pink/neutral tones with product bottle).
    *   *Card Styling:* Rounded corners (`border-radius: 12px`), dark subtle borders, scale-up hover animation on images.

## 4. Animations & Micro-Interactions

To replicate the high-end feel of the reference design, implement the following motion design specs:

1.  **Page Load Entrance (Framer Motion / CSS Keyframes):**
    *   **Hero Text:** Staggered slide-up fade-in.
        *   `initial`: `{ opacity: 0, y: 30 }`
        *   `animate`: `{ opacity: 1, y: 0 }`
        *   `transition`: `duration: 0.8s, ease: [0.16, 1, 0.3, 1]` (Custom cubic-bezier for buttery smooth deceleration).
    *   **Abstract Visuals:** Subtle floating / breathing animation on the 3D glowing sphere elements to mimic organic motion.
2.  **Hover States:**
    *   *Nav Links:* Color fade to white.
    *   *Case Study Cards:* Image scale (`transform: scale(1.03)`) over `0.4s cubic-bezier(0.25, 1, 0.5, 1)`.
    *   *Action Arrow:* Translates diagonally (`translate-x-1 translate-y--1`) on hover.
