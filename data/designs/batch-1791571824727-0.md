# Design Specification: "Liquid Glass Kit" UI UI Kit

## 1. Global Layout & Viewport
- **Viewport:** Full-screen immersive layout (100vw × 100vh), ignoring outer app window frames.
- **Background Base:** Soft, warm neutral cream/champagne gradient (`#EAE3DD` to `#F5EFEB`).
- **Global Light Source:** Top-left angled ambient lighting casting soft, diffuse drop-shadows toward the bottom right.
- **Glassmorphism Spec:** 
  - Backdrop blur: `blur(20px)`.
  - Background surface: Translucent white with alpha transparency (`rgba(255, 255, 255, 0.4)` to `rgba(255, 255, 255, 0.15)`).
  - Borders: Semi-transparent white 1px inner/outer border stroke (`rgba(255, 255, 255, 0.6)`).

---

## 2. Typography
- **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
- **Fallback Hierarchy:** `Inter` -> `system-ui` -> `sans-serif`
- **Type Scale:**
  - **Heading / Kit Title ("Liquid Glass Kit"):** 
    - Weight: 700 (Bold)
    - Size: 22px
    - Line-height: 28px
    - Color: `#111111`
  - **Button / Component Labels ("Secondary", "Toast", "Tabs"):** 
    - Weight: 600 (Semi-bold)
    - Size: 14px
    - Color: `#111111` (Dark variant) or `#FFFFFF` (Light variant)
  - **Body / Placeholder Text ("Search projects...", "Create workspace"):** 
    - Weight: 400 (Regular)
    - Size: 13px
    - Color: `#4A4A4A` (Inputs) / `#666666` (Subtexts)
  - **Caption / Secondary Labels ("Upgrade plan"):** 
    - Weight: 400 (Regular)
    - Size: 11px
    - Color: `#555555`

---

## 3. Color Palette
- **Neutrals:**
  - Base Light: `#FFFFFF`
  - Text Primary: `#1E1E1E`
  - Text Muted: `#7A7A7A`
  - Border Highlights: `rgba(255, 255, 255, 0.8)`
- **Accents & Gradients:**
  - **Purple/Violet:** Linear gradient from `#A855F7` to `#7C3AED` with internal soft-glass refraction.
  - **Teal/Cyan:** Linear gradient from `#2DD4BF` to `#0D9488`.
  - **Holographic / Multi-color Container:** Smooth mesh gradient transitioning from warm peach (`#FECDD3`) through soft violet (`#C084FC`) to vibrant cyan (`#22D3EE`).
  - **Success Green:** `#22C55E`

---

## 4. Component Inventory & Breakdown

### Column 1: Left Stack
1. **Purple Pill Button**
   - Shape: Fully rounded capsule (`border-radius: 9999px`).
   - Background: Vibrant purple liquid gradient (`#A366FF` to `#6B21F8`).
   - Inner Content: Centered text "decorary" in white, accompanied by a subtle floating distortion effect.
   - Effects: Outer drop shadow with purple ambient glow (`0 10px 25px rgba(139, 92, 246, 0.3)`).

2. **Teal Pill Button**
   - Shape: Capsule (`border-radius: 9999px`).
   - Background: Teal gradient (`#5EEAD4` to `#0D9488`).
   - Inner Content: "Secondary" (Bold, white).

3. **Circular Action Button & Droplet Icon**
   - Left: Circular button (`48px × 48px`, white background, soft drop shadow) containing a clean black plus icon (`+`).
   - Right: A purely decorative, glossy glass 3D droplet/sphere featuring a tiny embedded icon.

4. **Search / Input Bar**
   - Shape: Capsule input field.
   - Background: Semi-transparent white (`rgba(255, 255, 255, 0.6)`).
   - Inner Content: Placeholder text "Create workspace" on the left, and a thin vector magnifying glass search icon on the right.

5. **Text Area Card / Input Field**
   - Shape: Rounded rectangle (`border-radius: 16px`).
   - Inner Content: 
   - Left: Muted label text "Workspace".
   - Right: A vibrant green checkmark icon (`#22C55E`).

6. **Segmented Control / Toast Switcher**
   - Shape: Capsule container holding two states.
   - Left Tab ("Toast"): Highlighted with a white pill background and a purple indicator line underneath.
   - Right Tab ("Tabs"): Unselected, semi-transparent text.

---

### Column 2: Right Stack
1. **Large Search Header Widget**
   - Shape: Rounded container (`border-radius: 20px`).
   - Background: Frosted glass overlaid with a pale cyan-to-purple gradient glow.
   - Top Section: 
     - Left: A rounded app icon placeholder containing a stylized blue wave/bookmark abstract vector image.
     - Right: A circular glass button with a concentric ring icon and bright highlight dot.
   - Bottom Section: Search input bar (`Search projects...`) with an embedded vibrant purple square button containing a white plus (`+`) icon on the right edge.

2. **Compact Search Bar**
   - Shape: Capsule.
   - Left: A small purple circular badge containing a white checkmark icon.
   - Center: Placeholder text "Search projects...".
   - Right: Circular navigation button with a right chevron arrow (`>`).

3. **Mini Tag / Option Row**
   - Left: Small pill containing a purple checkbox icon (`[✔]`) and text "fiee" alongside an attached link/chain icon.
   - Right: Toggle switch component set to "On/Active" state with a circular handle containing a plus (`+`) sign.

4. **Holographic Card ("Invite member")**
   - Shape: Large container card (`border-radius: 24px`).
   - Background: Complex multi-stop pastel mesh gradient (peach-pink to soft purple to bright cyan).
   - Top-Right: Pill-shaped icon outline button.
   - Text Content:
     - Title: "Invite member" (Bold, 15px).
     - Subtitle: "Upgrade plan" (Regular, 11px, muted gray).
   - Bottom Action: Pill button containing a plus (`+`) icon and text "Upgrade plan".
