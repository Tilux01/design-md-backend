# Design Specification: Rayes Zeus X Landing Page

A responsive, full-screen dark-themed landing page showcasing high-end audio headphones.

---

## 1. Color Palette

* **Background Primary**: `#23272F` (Deep Charcoal Blue)
* **Background Accent / Watermark**: `#2A303A` (Subtle tinted slate)
* **Primary Text**: `#FFFFFF` (Pure White)
* **Secondary Text / Inactive Links**: `#8F96A3` (Muted Grey)
* **Accent Orange**: `#EE6A2B` (Buttons, price, active indicators)
* **Button Background (Secondary)**: `rgba(255, 255, 255, 0.05)` with subtle border `rgba(255, 255, 255, 0.12)`
* **Footer Icon Borders**: `rgba(255, 255, 255, 0.15)`

---

## 2. Typography

* **Primary Font**: `Poppins` or `Montserrat` (Geometric sans-serif)
* **Fallback Stack**: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
* **Hierarchy**:
  * **Brand Logo**: 24px, Font Weight: 700 (Bold)
  * **Product Title**: 32px, Font Weight: 700 (Bold)
  * **Product Subtitle**: 16px, Font Weight: 400 (Regular)
  * **Price**: 28px, Font Weight: 600 (Semi-bold), currency sign `$` superscripted at 18px
  * **Nav Links / Buttons**: 13px–14px, Font Weight: 500 (Medium)
  * **Watermark**: ~160px–200px, Font Weight: 900 (Black), All Caps, opacity ~5%
  * **Footer / Metadata**: 11px–12px, Font Weight: 400 (Regular)

---

## 3. Layout Architecture

Full viewport (`100vw`, `100vh`), non-scrolling desktop experience using a CSS Grid or Flex layout with a three-row structure: Header, Hero Content, Footer.

```
+--------------------------------------------------------------+
| Logo           [ Home  Products  About  Contact ]    [Search] [Cart] |
|                                                              |

+--------------------------------------------------------------+
```

---

## 4. Components & Content

### 4.1 Header (Navigation)
* **Logo**: Left-aligned, text: `Rayes.` with a trailing period.
* **Menu**: Center-aligned horizontal list:
  * `Home` (Active: `#FFFFFF` with a 2px horizontal orange line underneath)
  * `Our Products` (Inactive: `#8F96A3`)
  * `About Us` (Inactive: `#8F96A3`)
  * `Contact` (Inactive: `#8F96A3`)
* **Actions**: Right-aligned:
  * Minimal search icon (`stroke: #FFFFFF`, 18px).
  * Minimal shopping basket icon (`stroke: #FFFFFF`, 18px) with an orange notification pip at top-right.

### 4.2 Background Watermark
* Text: `RAYES`
* Position: Absolute, centered horizontally and vertically in the main viewport area, layered behind content (`z-index: 0`).
* Style: Semi-transparent (`opacity: 0.04`), uppercase, ultra-bold, size ~15vw.

### 4.3 Hero Left Section
* Alignment: Left-aligned, vertically centered, `z-index: 1`.
* **Title**: `Rayes Zeus X` (White, Bold, 32px).
* **Subtitle**: `Microphone Sound Studio` (Color: `#8F96A3`, 16px, margin-top: 6px).
* **Price**: `250$` (Color: `#EE6A2B`, 28px, margin: 20px 0).
* **CTAs**: Horizontal row, gap: 12px:
  * `More details`: Pill-shaped, transparent fill, subtle white border, text `#8F96A3`.
  * `Add to cart`: Pill-shaped, solid orange fill `#EE6A2B`, text `#FFFFFF`, soft drop shadow `0 6px 16px rgba(238, 106, 43, 0.3)`.

### 4.4 Hero Right Section (Visual & Slider)
* **Product Visual**:
  * Positioned in the right half of the canvas, slightly overlapping horizontal center.
  * Natural contact shadow blurred beneath the earcups.
* **Vertical Slider Controls**:
  * Located along the far right edge.
  * Top: `01` (White, 12px).
  * Vertical dot indicator: Active slide marked as an unfilled ring with an orange center, inactive slides as two faint dots below.

### 4.5 Footer
* **Left**: `Copyright 2019` in muted grey `#5E6573`, 11px.
* **Right**: Circular outline icons (28px diameter, 1px border `rgba(255,255,255,0.15)`):
  * Facebook icon (`f`).
  * Instagram icon.

---

## 5. Asset Specifications

### Product Hero Image
* **Format**: Backgroundless transparent PNG/WebP.
* **Subject**: Matte black over-ear wireless studio headphones.
* **Details**:
  * Left earcup angled flat/downward showing exterior housing with a subtle light-grey wave/accent icon.
  * Right earcup oriented forward showing plush black interior ear cushion.
  * Swivel hinges feature brushed copper/gold metallic accent plates.
  * Headband forms a smooth arc towards the top right.
* **Shadow**: Pre-rendered or CSS-based soft ambient occlusion ground shadow directly beneath the cups.
