# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial Minimalist, High-Fashion Digital Showcase, Monochromatic Avant-Garde.
- **Visual Density & Whitespace Ratio**: High whitespace ratio with asymmetric, split-screen composition. Balanced between bold editorial typography on the right and high-contrast monochrome photography on the left.
- **Surface Elevation Model**: Flat architectural layout with clean divisions, subtle soft-edged radial gradients (`#f3d2e3`, `#e5e8f0`), and absolute-positioned minimal vector glyphs.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Split asymmetrical viewport, high-fashion editorial serif lettering (`VANITY`), abstract pastel backdrop blur orbs, high-contrast monochrome photography.
- **Pill Badge Specification**: Padding `6px 16px`, font-size `10px`, font-weight `600`, tracking `0.1em`, border-radius `9999px`, background `#111111`, color `#ffffff`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before`.
  - Star / Special Issue (✦) -> Use SVG / Hex code `&#10022;`.
  - Directional Chevrons (`<`, `>`) -> Use HTML entities `&lsaquo;` and `&rsaquo;`.
