# Traverse UI Design Specification

## Overview
A full-screen, dark-themed hero landing page for a high-end audio hardware brand. The interface features an asymmetrical layout with a prominent product display, subtle typographic watermarks, and a dedicated right-hand action/social sidebar.

---

## Color Palette

| Token | Hex / Value | Usage |
| :--- | :--- | :--- |
| **Background Dark** | `#16171A` | Main canvas background |
| **Background Gradient** | Radial glow: center `#26292E` to edges `#131416` | Behind speaker |
| **Sidebar Surface** | `#222427` | Right utility panel background |
| **Text Primary** | `#FFFFFF` | Headlines, active links, logo |
| **Text Secondary** | `#7A7F88` | Body copy, inactive links |
| **Border / Outlines** | `rgba(255, 255, 255, 0.15)` | Button borders, slider track |
| **Active Accent** | `#7C95B1` | Slider active segment |

---

## Typography

* **Primary Font**: `Poppins` or `Outfit` (Fallback: `Inter`, `-apple-system`, `sans-serif`)
* **Body Font**: `Inter` (Fallback: `system-ui`, `sans-serif`)

### Font Scales
* **Logo**: 22px, Semi-Bold (600), Letter spacing `-0.5px`
* **Hero Headline**: 56px, Bold (700), Line height `1.15`
* **Body Copy**: 13px, Regular (400), Line height `1.6`
* **Nav Links / Buttons**: 13px, Medium (500)
* **Watermark Text**: ~140px, Extra-Bold (800), Opacity `0.04`
* **Numbers / Counters**: 14px, Semi-Bold (`01`) and Regular (`| 06`)

---

## Layout Architecture

* **Root Container**: Fullscreen (`100vw`, `100vh`), `overflow: hidden`, split into two main sections:
  1. **Main Canvas Area**: `flex: 1`
  2. **Right Vertical Sidebar**: Fixed width `72px`, full viewport height.

---

## Component Specifications

### 1. Right Sidebar
* **Dimensions**: Width `72px`, Height `100vh`, background `#222427`.
* **Top Element**: Hamburger menu icon (3 horizontal lines, `20px` wide, `2px` thick, `#FFF`).
* **Center/Bottom Elements**: Social links (`Twitter`, `Facebook`, `Instagram`).
  * **Orientation**: Rotated 90° clockwise (`writing-mode: vertical-rl`).
  * **Style**: Font size `12px`, color `#7A7F88`, hover color `#FFFFFF`, gap `32px`.

### 2. Header (Navbar)
* **Height**: `80px`, Horizontal padding `60px`.
* **Left**: Brand text `"Traverse."` (White).
* **Right Cluster**:
  * Navigation links: `"Home"`, `"About"`, `"Resources"`, `"Content"`.
  * `"Home"` state: Active indicator (short horizontal white bar `16px` wide directly below).
  * Inactive items: `#7A7F88`.
  * Search icon: Minimalist magnifying glass vector (`16px`, `#FFF`).

### 3. Hero Section (Left Content)
* **Padding**: Left `60px`, vertically centered.
* **Category Pill**:
  * Text: `"Traverse Audio"`, uppercase/titlecase, `11px`, Medium.
  * Container: Translucent dark gray badge (`rgba(255, 255, 255, 0.05)`), padding `6px 14px`, border-radius `2px`.
* **Headline**:
  ```text
  Unmatched
  Sound Quality.
  ```
  * Margin top: `24px`.
* **Body Text**:
  * Max-width: `340px`.
  * Margin top: `28px`, margin bottom `40px`.
  * Copy: *"A handpicked collection of the highest quality, industry standard, professional audio equipment at realistic, affordable prices."*
* **Interactive Controls**:
  * **CTA Button**: `"Check the shop"` — Transparent background, `1px solid rgba(255, 255, 255, 0.25)`, padding `12px 24px`, color `#FFF`, font size `12px`.
  * **Navigation Arrows**: Two adjacent square buttons (`42px × 42px`), `1px solid rgba(255, 255, 255, 0.15)`, containing left (`←`) and right (`→`) arrows.

### 4. Hero Section (Right Visual)
* **Background Watermark**:
  * Faint typography reading `"Travers"` in massive scale behind the product cutout.
  * Color: White at `4%` opacity.
* **Product Image**:
  * **Description**: Studio shot of a compact, cylindrical, high-fidelity wireless speaker. Matte black top and bottom caps with a micro-perforated dark silver metallic wrap-around grille.
  * **Format**: Cutout with transparent background (PNG/WebP).
  * **Alignment**: Centered horizontally in the right half of the main area, vertically positioned to ground near the baseline of the lower controls.
  * **Shadow**: Soft, blurred contact shadow beneath the base (`rgba(0, 0, 0, 0.6)`).
* **Slider Pagination (Bottom-Right)**:
  * **Counter**: `"01"` in bold white, `"| 06"` in `#7A7F88`.
  * **Progress Bar**: Total width `240px`, height `2px`, background `rgba(255, 255, 255, 0.15)`.
  * **Active Bar**: First `40px` highlighted in light gray-blue (`#7C95B1`).
