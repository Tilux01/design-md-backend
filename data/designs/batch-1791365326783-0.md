# Design Specification: Ceramic Product Catalog

## 1. Global Styles & Variables

### Color Palette
*   **Primary Dark:** `#1A1A1A` (Charcoal / Near Black)
*   **Primary Light (Backgrounds):** `#F2F2F2` (Soft Off-White / Light Gray)
*   **Secondary Light (Pages):** `#FAFAFA` (Pure White / Light Paper)
*   **Accent / Neutral Tone 1:** `#D8C9BE` (Warm Sand / Beige)
*   **Accent / Neutral Tone 2:** `#C5B4A5` (Darker Beige / Taupe)
*   **Text Dark:** `#222222`
*   **Text Light:** `#FFFFFF`
*   **Text Muted:** `#777777`

### Typography
*   **Primary Serif (Headlines, Titles):** `Playfair Display`, `Didot`, or standard high-contrast Serif.
*   **Secondary Sans-Serif (Body, Metadata, Navigation):** `Montserrat`, `Helvetica Neue`, or standard clean Sans-Serif.

---

## 2. Layout Structure

### Document Grid & Sizing
*   **Orientation:** Portrait (Vertical) for individual mockups, Grid format for presentation layout.
*   **Spreads:** Designed as symmetrical two-page spreads (Left Page / Right Page).
*   **Margins:** Generous whitespace (approx. 8–12% of total width/height).

---

## 3. Component Specifications

### A. Cover Page (Leftmost Prominent Mockup)
*   **Background:** Solid soft off-white (`#F2F2F2`).
*   **Image Feature:** Full-width top/center ceramic vase photograph with neutral background and strong shadows.
*   **Typography:**
    *   *Sub-brand / Header:* "CERAMIC" (Uppercase, tracked out, small sans-serif).
    *   *Main Title:* "Catalog" (Large serif, italicized or stylized, prominent display size).
    *   *Footer Metadata:* "Products Catalog 2030", "Ceramic Home Decorations", "Latest releases and price list", "View more yourwebsitehere" (Distributed horizontally across the bottom edge in small sans-serif).

---

### B. Spread Variations

#### Spread Type 1: Dark & Light Contrast (e.g., Row 2, Left Spread)
*   **Left Page (Dark Theme):**
    *   **Background:** `#1A1A1A`
    *   **Header:** "Best items for kitchen utensils" (Serif, white).
    *   **Left Column:** Large featured photography of ceramic kitchen items.
    *   **Right Column:** Product list (3 rows) containing thumbnail image, Product Name, and Price (e.g., `150$`).
*   **Right Page (Light Theme):**
    *   **Background:** `#FAFAFA`
    *   **Grid Layout:** 2x3 grid of product thumbnail cards with titles and prices.
    *   **Bottom Right:** Featured larger product image with clean white background.

#### Spread Type 2: Editorial / Signature Collection (e.g., Row 3, Left Spread)
*   **Left Page (Light Theme):**
    *   **Grid:** 2x2 product showcase with individual pricing.
*   **Right Page (Dark Theme - Signature Collections):**
    *   **Background:** `#1A1A1A`
    *   **Title:** "Signature Collections" (Centered serif heading).
    *   **Photography:** Artistic groupings of white ceramic vases against dark backdrops.

#### Spread Type 3: Editorial / Best Selling Products (e.g., Row 3, Right Spread)
*   **Left Page:**
    *   **Top:** Minimalist product photography.
    *   **Middle:** "Best Selling Products" header with brief editorial description and price points (`2000` / `49+`).
    *   **Bottom:** Single highlighted product image.
*   **Right Page:**
    *   **Top:** Small thumbnail image + minimalist graphic element.
    *   **Center:** Editorial copy block detailing collaboration with "Brand Name".

#### Spread Type 4: Promotional / Contact Spread (e.g., Row 4/5, Left Spread)
*   **Left Page (Dark Theme):**
    *   **Content:** Two tall white ceramic vases on dark background, vertical brand text ("Products Catalog").
    *   **Bottom Left:** "Contact Information" with standard address/phone icon placeholders.
*   **Right Page (Light Theme):**
    *   **Top Half:** Featured lifestyle image (ceramic vase with dried botanicals in a warm-toned setting).
    *   **Lower Half:** Promotional text ("Browse your entire range of ceramic decorations online or in store") + "30%" discount badge/callout.

---

## 4. UI / Presentation Grid Pattern
If replicating the entire multi-catalog presentation sheet:
*   Arrange the individual spreads in an overlapping, cascading grid from top-right to bottom-left against a clean neutral canvas (`#EAEAEA`).
*   Apply soft drop shadows to each individual catalog mockup to create depth and realism.
