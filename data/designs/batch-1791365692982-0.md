# UI Design Specifications

This document outlines the exact design specifications for cloning the provided color palette UI. The layout is designed to be fully responsive and fill the entire screen.

## Global Styles

*   **Background Color:** `#000000` (Pure Black)
*   **Font Family:** System-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif
*   **Layout Structure:** CSS Grid / Flexbox layout with rounded cards, using a multi-column setup on larger screens.
