## 4. Implementation Guidelines for Developers
1.  **Grid System:** Use CSS Grid (`display: grid`) with a standard 12-column layout for desktop views, ensuring generous whitespace (`clamp(1.5rem, 5vw, 4rem)`) around containers.
2.  **Shadows & Depth:** Apply soft, diffused box shadows (`box-shadow: 0 12px 32px rgba(0, 0, 0, 0.08)`) to cards and polaroids to maintain the playful, tactile paper-collage aesthetic.
3.  **Image Handling:** All images should be responsive (`max-width: 100%; height: auto;`), styled with border-radius where appropriate (e.g., `8px` to `12px`), and wrapped in containers with subtle inner borders (`1px solid rgba(0,0,0,0.08)`).
