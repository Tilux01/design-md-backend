# Design System & Implementation Specification (`design.md`)

This document provides the exact design specification required to build a 1:1 full-screen clone of the construction company landing page.

---

## 1. Overview & Visual Vibe

* **Theme:** Architectural, modern biophilic construction, luxury, minimalist.
* **Layout:** Fullscreen desktop layout (`100vw` by `100vh` or auto-height hero min `100vh`), edge-to-edge canvas with no device frames or outer borders.
* **Color Temperature:** Warm off-white/beige stone background paired with high-contrast obsidian black text and natural wood/vegetation tones.
* **Core Visual Mechanism:** 3D Layering effect where the centerpiece 3D house asset sits *in front* of giant typography but *behind* foreground UI widgets.

---

## 2. Color Palette & Design Tokens

### Color Tokens
```css
:root {
  /* Backgrounds */
  --bg-main: #F2ECE4;          /* Soft warm stone beige base background */
  --bg-card: #FFFFFF;          /* Pure white for floating cards and scroll button */
  --bg-dark: #181818;          /* Rich obsidian black for primary buttons & dark elements */

  /* Text Colors */
  --text-primary: #181818;       /* Primary headers, hero display, and bold numbers */
  --text-secondary: #6B6661;     /* Subheadings, body copy, and secondary labels */
  --text-muted: #948F89;         /* Very soft grey-beige for tiny secondary info */
  --text-on-dark: #FFFFFF;       /* White text inside dark buttons */

  /* Borders & Lines */
  --border-light: rgba(24, 24, 24, 0.15); /* Light translucent dark stroke for outline buttons */
  --border-divider: #E2DCD4;               /* Subtle warm grey line divider */

  /* Shadows */
  --shadow-card: 0px 20px 40px rgba(0, 0, 0, 0.04);
}
```

## 3. Typography System

### Typography Hierarchy

#### Primary Display Font (Giant Background Text & Bold Numbers)
* **Font Family:** `Unbounded`, `Syne`, or `Druk Wide Web`
* **Fallback Stack:** `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`
* **Font Style:** Display Sans-Serif, Heavy / ExtraBold (Weight: `800` or `900`), Uppercase, tight tracking.

#### Primary Interface Font (Headings, Buttons, Navigation, Body)
* **Font Family:** `Inter`, `Manrope`, or `Plus Jakarta Sans`
* **Fallback Stack:** `system-ui, -apple-system, "Helvetica Neue", sans-serif`
* **Text Specs:**
  * **Nav Links:** `14px`, Medium (500), `--text-primary`
  * **Hero Subtitle (Left):** `20px` - `22px`, Line height `1.3`, Medium (500), `--text-primary`
  * **Card Title:** `18px` - `20px`, Line height `1.2`, Bold (700), `--text-primary`
  * **Card Description:** `13px` - `14px`, Line height `1.4`, Regular (400), `--text-secondary`
  * **Metric Digits:** `28px` - `32px`, Line height `1.1`, Bold (700), `--text-primary`
  * **Metric Labels:** `13px` - `14px`, Line height `1.3`, Regular (400), `--text-secondary`

## 6. Hero Layering & 3D Composition

The visual hero consists of 4 stacked layers (z-index strategy):

```
[ Z-INDEX 3: Floating UI Controls (Left Button, Right Card, Scroll Button) ]
[ Z-INDEX 2: 3D Render Image Asset (House + Landscaping Island)            ]
[ Z-INDEX 1: Giant Background Display Text ("СТРОИМ.")                     ]
[ Z-INDEX 0: Main Canvas Background (#F2ECE4)                              ]
```

### Layer 1: Giant Background Text
* **Text Content:** `СТРОИМ.` (Includes trailing period)
* **CSS Specs:**
  * `position: absolute;`
  * `top: 120px;`
  * `left: 50%; transform: translateX(-50%);`
  * `font-size: clamp(120px, 18vw, 260px);`
  * `font-weight: 900;`
  * `color: #181818;`
  * `text-align: center;`
  * `white-space: nowrap;`
  * `z-index: 1;`

### Layer 2: Centerpiece 3D Image Asset Specification
* **Type:** Transparent background PNG (No background color, zero crop margins).
* **Asset Description:**
  * A modern two-story architectural villa with rounded beige concrete exterior frames and warm vertical timber slatted facades.
  * Structural features:
    * **Ground floor:** Floor-to-ceiling glass sliding doors, rounded wooden front door alcove on the right.
    * **Second floor:** Cantilevered rounded structure with large curved floor-to-ceiling corner windows showing ambient warm interior lighting.
  * **Landscaping Base:** The house sits on a floating organic ground island featuring green moss patches, dark shrubs, small gray boulders, gravel paths, and two small olive/bonsai trees flanking the structure.
* **Placement & Size:**
  * `position: absolute;`
  * `left: 50%; transform: translateX(-50%);`
  * `top: 220px;`
  * `width: 65%;` (Maximum width `900px`)
  * `z-index: 2;`
  * *Crucial Alignment Note:* The upper concrete roof of the second floor overlaps the lower portion of the giant text `"СТРОИМ."`, creating depth.

## 9. Interactive States & Micro-interactions

1. **CTA Hover States:**
   * Black Buttons (`--bg-dark`): Scale `1.02` on hover, opacity `0.9`. Arrow slides `3px` to the right on hover.
   * Secondary Outline Button: Background changes to `#181818`, text & icon change to `#FFFFFF` on hover.
2. **Floating Card Effect:**
   * Subtle smooth floating hover animation (`transform: translateY(-4px)` over `0.3s ease`).
3. **Scroll Button:**
   * Hover rotates down arrow or bounces slightly in Y-axis.
