# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Nocturnal Zen Garden, Cinematic Dark Mode Atmospheric, Organic Minimalism.
- **Visual Density & Whitespace Ratio**: High negative space ratio anchored by a pure absolute black canvas (`#000000`), allowing luminous focal points (lanterns, fireflies) to drive natural eye flow along the stone pathway.
- **Surface Elevation Model**: Layered topographical moss surfaces with tactile, wet basalt rock formations and glowing lantern glass. Employs subtle warm volumetric amber lighting glows (`rgba(245, 158, 11, 0.25)`) casting downward radiance without harsh drop-shadow boundaries.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Ambient glowing light nodes, asymmetric organic landscape balancing, micro-particle firefly specks, realistic moss gradient texturing.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `12px`, font-weight `600`, tracking `0.05em`, border-radius `9999px`, background translucency `rgba(245, 158, 11, 0.1)`, border width `1px` (`rgba(245, 158, 11, 0.3)`).
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Firefly (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-amber-400 inline-block"></span>`.

# 7. Motion Mechanics, Framer Motion & CSS Animations
- **Motion Principles**: Organic easing (`cubic-bezier(0.16, 1, 0.3, 1)`), gentle floating inertia, ambient pulsating illumination.
- **Framer Motion Variants Code**:
```jsx
export const containerVariants = {
  hidden: { opacity: 0, scale: 0.98 },
  visible: { 
    opacity: 1, 
    scale: 1,
    transition: { duration: 0.8, ease: [0.16, 1, 0.3, 1], staggerChildren: 0.15 }
  }

```

- **CSS `@keyframes` Animations**:
```css

  0%, 100% { opacity: 0.85; filter: drop-shadow(0 0 20px rgba(245, 158, 11, 0.3)); }
```
