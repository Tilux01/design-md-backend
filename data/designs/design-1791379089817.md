# UI Design & Implementation Specification: "Build Future" Landing Page

This document provides a comprehensive blueprint to replicate the provided landing page design with pixel-perfect accuracy. It covers layout structures, typography, color palettes, micro-interactions, responsive behavior, and animation states.

---

## 1. Global Layout & Canvas Settings

*   **View:** Full-Screen Edge-to-Edge (100vw × 100vh viewport).
*   **Background Color:** Off-white / Very light gray (`#F2F2F2` or `hsl(0, 0%, 95%)`).
*   **Grid System:** 12-column fluid grid with generous horizontal padding (approx. `64px` on desktop).
*   **Z-Index Layering:**
    *   `z-index: 0`: Background canvas.
    *   `z-index: 1`: Giant background typography (`BUILD FUTURE`).

## 2. Typography System

The design relies on a striking contrast between clean, geometric sans-serif UI elements and an ultra-condensed, heavy display typeface for the primary headline.

### Primary Display Font (Headline: "BUILD FUTURE")
*   **Font Family:** `Anton`, `Oswald`, or `Impact`, falling back to `sans-serif`.
*   **Weight:** 900 (Black / Ultra-Bold).
*   **Style:** Condensed uppercase.
*   **Letter Spacing:** Tight/Negative tracking (`-0.03em` to `-0.05em`) to compress the letters horizontally.
*   **Line Height:** `0.85` (extreme vertical compression so glyphs visually lock together).

### Secondary UI Font (Navigation & Subtext)
*   **Font Family:** `Inter`, `Space Grotesk`, or `Syne`, falling back to `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`.
*   **Weights Used:** Regular (400), Medium (500), Bold (700).

## 5. Animation & Interaction Specifications

To achieve the modern, high-end digital agency feel, implement the following motion design principles:

1.  **Page Load / Entrance Animation (Staggered):**
    *   *Header:* Fades in from top (`translateY(-20px)` to `0`) over `0.6s` with `cubic-bezier(0.16, 1, 0.3, 1)`.
    *   *Giant Headline (`BUILD FUTURE`):* Scales up slightly or slides up from background with a fade (`duration: 0.8s`, `delay: 0.2s`).
    *   *3D Robot Asset:* Smooth floating/breathing idle animation once loaded; initial entrance scales up from `0.95` with opacity fade.
    *   *Pills & Widgets:* Pop into place with spring physics (`stiffness: 300`, `damping: 20`).

2.  **Hover States:**
    *   **Primary Buttons ("BUILD WITH US"):** Scale up slightly (`scale(1.03)`) with a subtle shadow intensification.
    *   **Nav Links:** Smooth color transition to opacity `0.6`.
    *   **Floating Pills (`PREDICT`, `PROTOTYPE`, `PROPEL`):** Slight magnetic pull effect toward the mouse cursor when hovered within a `50px` radius.

3.  **Scroll Interactions (Parallax):**
    *   As the user scrolls down, the background giant typography (`BUILD FUTURE`) moves at a slightly slower speed than the foreground 3D robot, creating a multi-plane depth effect.
