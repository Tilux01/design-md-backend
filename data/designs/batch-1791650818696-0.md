# Design Specification: Mercury "Vibe Code" Landing Page

## 1. Global Layout & Viewport
- **Viewport:** Full-screen responsive web layout (`width: 100vw`, `min-height: 100vh`).
- **Background Color:** Deep solid black (`#000000`).
- **Container Structure:** 
  - Centered content container with a max-width constraint (approx. `1200px`) for the hero section elements.
  - Sticky or fixed top navigation bar spanning the full width with horizontal padding.

---

## 2. Typography & Fonts
- **Primary Font Family:** Clean, geometric sans-serif (such as **Inter**, **Geist**, or **Plus Jakarta Sans**).
- **Fallback Fonts:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.

### Text Hierarchy:
1. **Logo:**
   - Text: `Mercury`
   - Weight: Bold (`700`)
   - Color: Pure White (`#FFFFFF`)
   - Font Size: `18px` / `1.125rem`

2. **Navigation Links:**
   - Items: `Programs`, `Community`, `Resources`, `About`, `Log In`
   - Weight: Regular (`400`) to Medium (`500`)
   - Color: Light Gray (`#A1A1AA` for links, `#FFFFFF` for active/hover)
   - Font Size: `14px` / `0.875rem`

3. **Hero Main Heading:**
   - Text Line 1: `Learn to Vibe Code`
   - Text Line 2: `Build Real Apps`
   - Weight: Medium (`500`) to Semi-Bold (`600`)
   - Color: Pure White (`#FFFFFF`)
   - Font Size: Large display size (approx. `48px` to `64px` on desktop, fluid scaling via `clamp()`)
   - Alignment: Centered
   - Line Height: Tight (`1.1`)

4. **Hero Subtitle (Body Text):**
   - Text: `Master AI-powered development. Mercury teaches you to build real products using the latest vibe coding tools and techniques.`
   - Weight: Regular (`400`)
   - Color: Muted Gray (`#9CA3AF`)
   - Font Size: `16px` / `1rem`
   - Max Width: Approx. `550px`
   - Alignment: Centered

5. **Footer / Micro Copy:**
   - Text: `TRUSTED BY ASPIRING DEVELOPERS FROM`
   - Weight: Semi-Bold (`600`)
   - Color: Dark Gray (`#6B7280`)
   - Font Size: `11px` / `0.6875rem`
   - Letter Spacing: Wide (`1.5px` to `2px`)
   - Text Transform: Uppercase

---

## 3. Navigation Bar (Header)
- **Positioning:** Fixed or absolute at the top of the viewport (`top: 0`, `left: 0`, `right: 0`), spanning full width with generous horizontal padding (`24px` to `48px`).
- **Height:** Approx. `80px`.
- **Layout Structure:**
  - **Left:** Brand Logo (`Mercury`).
  - **Center:** Nav links (`Programs`, `Community`, `Resources`, `About`) spaced evenly with flexbox gap (`32px`).
  - **Right:** Action items grouped closely together:
    - Text link: `Log In`
    - Primary CTA Button: `Join Waitlist`

---

## 4. Buttons & Interactive Elements

### A. Primary White Button (`Join Waitlist` in Nav & Hero)
- **Background Color:** Pure White (`#FFFFFF`)
- **Text Color:** Deep Black (`#000000`)
- **Border Radius:** Fully rounded pill style (`9999px`) or subtle rounded corners (`8px` / `12px`).
- **Padding:** `10px 20px` (Nav) / `12px 24px` (Hero)
- **Font Weight:** Medium (`500`)
- **Font Size:** `14px`
- **Icon:** Right-facing arrow (`→`) included inside the button for the hero CTA.

### B. Secondary Action (`Book a Call`)
- **Background:** Transparent / None
- **Text Color:** Light Gray (`#D1D5DB`)
- **Font Weight:** Medium (`500`)
- **Icon:** Right-facing arrow (`→`) following the text.
- **Hover State:** Smooth opacity transition or color shift to white.

---

## 5. Visuals & Background Elements

### Background Pattern (Dots Grid with Gradient Glow)
- **Description:** A subtle, dark geometric grid pattern composed of small dots (or crosses) layered over the black background. 
- **Glow Effect:** A soft, diffused radial gradient in deep magenta/purple (`rgba(168, 85, 247, 0.15)` or `rgba(217, 70, 239, 0.2)`) positioned centrally behind the text container, fading out toward the edges.
- **Backgroundless Image Asset Note:** If implementing this as a graphic asset, it should be a transparent PNG/SVG containing only the glowing magenta dot matrix, positioned absolutely behind the central hero text block.

---

## 6. Spacing & Alignment Specifications
- **Hero Vertical Alignment:** Centered vertically and horizontally within the viewport below the navigation header.
- **Vertical Gaps:**
  - Between Heading and Subtitle: `24px`
  - Between Subtitle and CTA Buttons: `32px`
  - Between CTA Buttons and Footer Trust text: `120px+` (generous whitespace)
