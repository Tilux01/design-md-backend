# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Dark Mode Cinematic Editorial / Fantasy Gaming UI (High-end RPG & strategy brand).
- **Visual Density & Whitespace Ratio**: High contrast, immersive dark canvas with high-density card components and translucent floating UI elements balanced by expansive cinematic negative space.
- **Surface Elevation Model**: Layered glassmorphic cards with ultra-thin borders (`rgba(255, 255, 255, 0.1)`), deep directional drop shadows (`0 20px 40px rgba(0, 0, 0, 0.6)`), and heavy backdrop blurring (`blur(16px)`).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase navigation pills, radial atmospheric background glows, frosted glass cards with dual-layer gold-tinted borders, dynamic rating pill widgets.
- **Pill Badge Specification**: Padding `6px 14px`, font-size `12px`, font-weight `600`, tracking `0.08em`, border-radius `9999px`, background translucency `rgba(212, 175, 55, 0.1)`, border width `1px solid rgba(212, 175, 55, 0.3)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG inline icon.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-amber-400 inline-block"></span>`.

# 7. Motion Mechanics, Framer Motion & CSS Animations
- **Motion Principles**: Smooth deceleration curves (`cubic-bezier(0.16, 1, 0.3, 1)`), subtle vertical float translation, responsive scale transforms on interactive hover states.
- **Framer Motion Variants Code**:
```jsx
export const containerVariants = {
  hidden: { opacity: 0, y: 20 },
  visible: { 
    opacity: 1, 
    y: 0,
    transition: { duration: 0.5, ease: [0.16, 1, 0.3, 1], staggerChildren: 0.12 }
  }
};
```

- **CSS `@keyframes` Animations**:
```css

  0%, 100% { transform: translateY(0px) scale(1); opacity: 0.7; }
  50% { transform: translateY(-12px) scale(1.04); opacity: 1; }
```
