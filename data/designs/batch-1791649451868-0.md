# DESIGN.md — LUMORA Smart Home Dashboard Specification

This document provides the exact visual, structural, typographic, and component specifications required to implement the **LUMORA Smart Home Dashboard UI** as a pixel-perfect, full-screen web or desktop interface.

---

## 1. Overview & Theme Concept

*   **Design Aesthetic:** Dark Luxury Minimalism, Bento-Grid Layout, Futuristic Glassmorphism.
*   **Theme Baseline:** Deep Charcoal & Soft Black backgrounds (`#0D0E11`, `#16181D`), high-contrast pure white headers (`#FFFFFF`), subtle muted cool-grey body/caption text (`#9096A2`), translucent glass panels with thin low-opacity borders.
*   **Target Viewport:** Fullscreen responsive application (100vh / 100vw container). *Note: The external dark room backdrop and floating tilt frame in the source presentation must be omitted; the dashboard itself spans full screen.*

## 3. Typography System

### Font Families
1. **Display / Headline Font (Logo & Main Headlines):**
   * **Primary:** `Syne` or `Monument Extended` or `Space Grotesk` (Bold / Extended Geometric Sans-Serif).
   * **Fallbacks:** `Uncut Sans`, `Outfit`, `Eurostile`, `Arial Black`, `sans-serif`.
   * **Characteristics:** Extended horizontal proportions, crisp sharp geometry, futuristic tone.

2. **UI & Body Font (Navigation, Labels, Stats, Descriptions):**
   * **Primary:** `Plus Jakarta Sans` or `Inter` or `SF Pro Display`.
   * **Fallbacks:** `system-ui`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`.
   * **Characteristics:** Highly legibile at small sizes, tight tracking, clean optical kerning.

## 8. Interactive Micro-Interactions & States

1. **Hover States:**
   * **Buttons (`View video`, `View`, Search Pill):** Smooth scale transform (`transform: scale(1.03)`), transition `0.2s ease`.
   * **Hotspot Badges (`+`):** Continuous subtle pulse animation (`animation: pulse 2s infinite ease-in-out`), expanding a soft white ring blur outward.
   * **Navigation Items:** Opacity transitions from `0.6` to `1.0` on cursor hover.

2. **Slider Component (`Smart Lock`):**
   * Drag interaction along the horizontal axis with smooth snapping to lock/unlock positions.

3. **Room Category Switcher (`Room 01`, `02`, `03`):**
   * Clicking swaps the content/images in the top-right and hero views with a cross-fade transition (`opacity: 0` to `1` in `300ms`).
