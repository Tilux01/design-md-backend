# DESIGN SPECIFICATION: WORLY APP DASHBOARD

This document provides the exact specifications to build a pixel-perfect, responsive clone of the "Worly" mobile application dashboard shown in the image.

---

## 1. GLOBAL LAYOUT & CONTAINER

*   **Screen Type:** Mobile App Dashboard (Target: iOS/Android, standard portrait aspect ratio like iPhone 14/15 Pro: `393px × 852px`).
*   **Background Color:** Soft cream / off-white (`#F4F1EA` or `#F7F5F0`).
*   **Border Radius (Device Frame):** Curved corners (`32px` or `40px` if rendered as a phone mockup).
*   **Content Padding:** 
    *   Top: `20px`
    *   Horizontal (Left/Right): `20px`
    *   Bottom: `24px`

---

## 2. TYPOGRAPHY & FONTS

Since the exact proprietary font files aren't automatically embedded, use the following stack with proper fallbacks:

*   **Primary Font Family (Headings, Branding, Numbers, Bold UI):**
    *   *Primary:* **Plus Jakarta Sans** or **Poppins** (Geometric, friendly sans-serif with rounded terminals).
    *   *Fallback:* `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
*   **Secondary/Body Font (Subtitles, Captions):**
    *   *Primary:* **Inter** or **SF Pro Text**.
    *   *Fallback:* `sans-serif`
*   **Font Weights Used:**
    *   SemiBold (`600`): Labels, section headers.
    *   Bold (`700`): Main numbers, primary buttons.
    *   ExtraBold (`800` / `900`): Brand logo ("worly").

---

## 3. SECTION-BY-SECTION SPECIFICATION

### A. Header / Top Navigation Bar
*   **Logo ("worly"):**
    *   Text style: Lowercase, ultra-bold (`800`/`900`), deep purple color (`#4B2E83` or `#593288`).
    *   Size: ~`28px` to `32px`.
*   **Tagline ("Learn new words easily"):**
    *   Position: Placed right next to the logo.
    *   Style: Two-line text block, small size (`10px` to `11px`), medium weight, deep purple color.
*   **Action Icon (Top Right):**
    *   Icon: Logout / Exit arrow pointing out of a box (`⇥` style).
    *   Color: Deep purple.
    *   Size: `20px` × `20px`.

---

### B. Header Background Illustration (Mascot & Purple Blob)
*   **Purple Blob Container:**
    *   Shape: Organic, rounded asymmetrical shape filling the upper header area behind the mascot.
    *   Color: Medium-light vibrant purple (`#8A73C4` or `#9B82D0`).
*   **Mascot Character ("Worly"):**
    *   **Description:** A cute, minimalist purple bean/blob mascot with stick limbs and expressive eyes.
    *   **State:** Backgroundless (transparent PNG/SVG).
    *   **Placement:** Centered horizontally over the purple blob.
    *   **Facial Features:** Two large white circular eyes with black pupils, smiling mouth.
    *   **Limbs:** Simple black curved stick arms and legs. Left arm rests on the "Total" card; right arm waves upwards.
    *   **Rotation:** 0° (neutral upright).

---
