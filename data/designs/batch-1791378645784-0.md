# UI Design Specification: Disney Characters Web Interface

## 1. Overview & Layout Strategy
This specification details a modern, clean web interface showcasing Disney characters in a horizontal card carousel format. 

* **Display Mode:** Fullscreen application (edge-to-edge).
* **Grid / Alignment:** Left-aligned header items, centered character cards with generous whitespace, bottom-aligned navigation controls and social links.
* **Responsive Behavior:** Designed for desktop viewports (approx. 1280px+ width). Cards scale horizontally with a fixed aspect ratio.

---

## 2. Color Palette

| Token / Usage | Color Name | Hex Code | CSS Variable |
| :--- | :--- | :--- | :--- |
| **Background (Canvas)** | Pure White | `#FFFFFF` | `--bg-main` |
| **Primary Text (Headers)** | Deep Charcoal | `#111827` | `--text-main` |
| **Secondary Text (Subtitles)** | Muted Gray | `#6B7280` | `--text-muted` |
| **Search Bar Fill** | Light Gray | `#F3F4F6` | `--search-bg` |
| **Card 1 (Rosetta)** | Crimson Red | `#DC2626` | `--card-red` |
| **Card 2 (Sadness)** | Royal Blue | `#1D4ED8` | `--card-blue` |
| **Card 3 (Disgust)** | Forest Green | `#15803D` | `--card-green` |
| **Card 4 (Judy)** | Navy Blue | `#1E3A8A` | `--card-navy` |

*Note on Gradients:* The colored cards feature a subtle top-to-bottom vertical gradient, transitioning from a slightly lighter/brighter shade at the top to a deeper saturation at the bottom.

---

## 3. Typography & Font Stack

### Font Family
* **Primary (Brand/UI):** `Waltograph` (for Disney logo), `Poppins` or `Inter` (for UI elements).
* **Fallback Stack:** `font-family: 'Poppins', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif;`

### Type Scale
* **Disney Logo:** `32px`, Bold, Custom script styling.
* **"Characters" Sub-label:** `20px`, Regular/Medium, Dark Charcoal (`#111827`).
* **Card Title (e.g., Rosetta):** `24px`, Bold (`700`), Pure White (`#FFFFFF`).
* **Card Subtitle (e.g., Movie Tinkerbell):** `13px`, Regular (`400`), Light Gray/White with opacity (`#E5E7EB`).
* **Search / Navigation text:** `14px`, Regular (`400`).

---

## 4. Component Specifications

### A. Navigation Header
* **Logo:** Disney iconic wordmark positioned on the top-left (`X: 64px`, `Y: 40px`), followed by the text "Characters" separated by standard spacing.
* **Search Bar:**
  * Pill-shaped container (`border-radius: 9999px`).
  * Background: `#F3F4F6`.
  * Contains a magnifying glass icon on the left.
  * Placeholder text: *"Search characters...."*.
* **Menu Button:** Top-right aligned with a standard 4-dot grid icon + "Menu" label.

---

### B. Character Cards (Carousel Layout)
The core content consists of large, vertically-oriented rounded cards with protruding character artwork overlapping the top edge.

* **Card Dimensions:** Width approx. `260px`, Height approx. `360px`.
* **Border Radius:** `32px`.
* **Shadow / Elevation:** Soft, colored drop-shadows matching the card's theme color (e.g., a diffused red shadow beneath the Rosetta card to create depth and glow).
* **Content inside Card:**
  * Bottom-aligned text layout.
  * Character Name (White, Bold, 24px).
  * Movie attribution (White, 13px, prefixed with "Movie").
* **Character Artwork Positioning:** 
  * Absolute positioning overlapping the top-left/center of each card.
  * Extends outside the top boundary of the card container to create a 3D layered effect.

---

### C. Footer / Action Controls
* **Left Side:** Social links (`Facebook`, `Twitter`) styled in muted gray (`#9CA3AF`), hover state transitions to dark charcoal.
* **Right Side:** Pagination controls (`< Prev` and `Next >`) styled with crisp typography and directional chevron icons.

---

## 5. Micro-Interactions & Animations

* **Hover State (Cards):** 
  * Slight `translateY(-8px)` lift on mouse enter.
  * Drop shadow deepens and expands to emphasize elevation.
* **Transition Effects:** 
  * Smooth cubic-bezier easing (`transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1)`).
* **Carousel Sliding:** 
  * Clicking `< Prev` or `Next >` triggers a smooth horizontal translate animation of the card container array.
