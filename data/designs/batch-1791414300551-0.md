All device mockups, external background borders, and frames from the reference image are omitted, focusing entirely on a full-screen, edge-to-edge mobile web or native application viewport.

## 2. Typography

To capture the modern, friendly, geometric feel of the design, we use **Plus Jakarta Sans** as the primary font family.

### Font Configurations
* **Primary Font Family**: `"Plus Jakarta Sans"`, `"Inter"`, sans-serif
* **System Fallback Stack**: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`

### Text Styles Hierarchy
* **Header Title**:
  * Size: `24px` (`1.5rem`)
  * Weight: `800` (Extra Bold)
  * Line-height: `1.2`
  * Color: `#FFFFFF`
* **Card Label (Category)**:
  * Size: `13px` (`0.8125rem`)
  * Weight: `600` (Semi-Bold)
  * Tracking (Letter-spacing): `+0.05em` (uppercase or capitalized)
* **Card Value (Amount)**:
  * Size: `28px` (`1.75rem`)
  * Weight: `800` (Extra Bold)
  * Tracking: `-0.02em`

## 5. Micro-Interactions & Motion Design

To make the interface feel modern, premium, and native, implement the following animation behavior:

### Entrance Transition (On Page Load)
* **Staggered Slide-Up**:
  * Card 1 (Holiday): Translates `y: [30px -> 0px]`, opacity: `[0 -> 1]`, duration: `0.6s`, easing: `cubic-bezier(0.16, 1, 0.3, 1)` (custom ease-out expo).
  * Card 2 (Nightlife): Translates `y: [30px -> 0px]`, opacity: `[0 -> 1]`, delay: `0.15s`, duration: `0.6s`, easing: same ease-out.

### Active/Press State (Haptic Feel)
* **Card Touch Effect**:
  * When pressed, the card scales down slightly (`transform: scale(0.97)`) with a snappy spring duration of `0.1s`.
  * Release springs back to scale `1.0` with duration `0.25s`.
* **Action Button Hover/Tap**:
  * Hovering over the bottom-right square action buttons triggers a subtle background scale-up (`scale(1.1)`) and brightens the icon color.
