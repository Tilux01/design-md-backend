# Comprehensive UI/UX Design & Implementation Specification

This document provides a pixel-accurate blueprint for cloning the **CardioLife Heart Care** mobile application screens shown in the reference image.

## 1. Global Design System

### 1.1 Typography Architecture
*   **Primary Font Family:** `Inter`, `SF Pro Display`, `-apple-system`, `sans-serif`.
*   **Fallback Stack:** `Roboto`, `Helvetica Neue`, Arial, sans-serif.
*   **Font Weight Map:**
    *   `Light`: 300 (Subtitles, secondary labels)
    *   `Regular`: 400 (Body text, descriptions)
    *   `Medium`: 500 (Labels, timestamps, navigation items)
    *   `SemiBold`: 600 (Section headers, button texts, usernames)
    *   `Bold`: 700 (Screen titles, primary focal headers)

### 1.2 Color Palette
*   **Primary Crimson Core:** `#B91C1C` (Deep red for active states, brand accents, and primary containers)
*   **Secondary Blood Red Gradient Start:** `#DC2626`
*   **Dark Background (Screen 1):** `#110B0B` (Extremely deep near-black burgundy)
*   **Light Background (Screens 2 & 3):** `#F8F9FA` (Clean clinical off-white)
*   **Card Container Fill (Light Mode):** `#FFFFFF`
*   **Card Red Fill (Active/Selected):** `#B32626` (With soft white typographic overlays)
*   **Primary Text (Light Theme):** `#1F2937` (Charcoal)
*   **Secondary Text (Light Theme):** `#6B7280` (Muted gray)
*   **Primary Text (Dark Theme):** `#FFFFFF` (Pure white)
*   **Secondary Text (Dark Theme):** `#9CA3AF` (Light cool gray)
*   **Border & Divider Stroke:** `#E5E7EB` (Subtle light gray)
*   **Status Indicators:**
    *   Confirmed/Success Pill Fill: `#991B1B` or dark red with white text.
    *   Notification Bell Badge: Red dot indicator.

## 2. Screen 1: Onboarding / Welcome Splash

### 2.1 Layout & Structure
*   **Orientation:** Full-screen vertical stack.
*   **Background:** Solid dark radial gradient transitioning from deep charcoal-red (`#1E1212`) at the center to absolute dark near-black (`#0B0707`) at the edges.
*   **Status Bar:** Standard iOS layout (9:41, cellular, WiFi, battery icons in solid white). Positioned absolutely at the top ($12\text{px}$ top padding).

### 2.2 Component Breakdown
1.  **Brand Header:**
    *   **Icon:** White line-art vector heart enclosing an ECG pulse wave (`vector`). Size: $24\times24\text{px}$.
    *   **Brand Title:** "CardioLife" in bold white uppercase/title-case text ($16\text{px}$, Inter Bold).
    *   **Subtitle:** "HEART CARE" spaced out below in light tracking ($10\text{px}$, Inter Light, letter-spacing: $2\text{px}$).
    *   **Alignment:** Centered horizontally, placed just below the status bar.
2.  **Hero Image (Central Focus):**
    *   **Description:** A hyper-realistic, highly detailed 3D anatomical human heart glowing with internal bioluminescent crimson light, floating above a glowing red electrocardiogram (ECG/EKG) pulse line that cuts horizontally across the screen.
    *   **Background State:** Backgroundless (transparent PNG/SVG cutout layer).
    *   **Placement & Effects:** Centered vertically between the header and footer. Features a subtle radial drop shadow/glow behind the heart in deep red (`rgba(185, 28, 28, 0.4)`).
3.  **Typography & Copy Block:**
    *   **Heading:** "Your Heart Deserves the Best Care"
        *   *Font:* Inter Bold, $32\text{px}$, Line-height: $38\text{px}$.
        *   *Color:* White (`#FFFFFF`), with "Best Care" dynamically styled in a lighter coral-red gradient (`#FCA5A5`).
    *   **Body Copy:** "Advanced care for heart health. Early diagnosis. Better life."
        *   *Font:* Inter Regular, $14\text{px}$, Line-height: $20\text{px}$, Color: `#D1D5DB`.
4.  **CTA Footer:**
    *   **Button Container:** Dark translucent pill container (`rgba(255, 255, 255, 0.08)` border with $1\text{px}$ stroke, rounded corners $32\text{px}$).
    *   **Text:** "Get Started" (Inter SemiBold, $15\text{px}$, White).
    *   **Action Icon:** Right-pointing arrow inside a white circular floating button with a dark heart icon nested inside.
