# UI Design Specification: AIAIAI Headphones Landing Page

---

## 1. Global Styles & Variables

```css
:root {
  /* Color Palette */
  --color-bg-light: #e8e8e8;
  --color-bg-dark: #242424;
  --color-surface-dark: #1b1b1b;
  --color-accent-red: #ea230c;
  --color-text-primary: #ffffff;
  --color-text-secondary: #9e9e9e;
  --color-text-dark: #333333;

  /* Typography */
  --font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif;
  
  /* Layout */
  --max-width: 1440px;
}
```

---

## 2. Layout Structure & Responsive Breakpoints

* **Layout Type:** Full-screen responsive split-screen hero section.
* **Breakpoints:**
  * **Desktop:** 1200px and up (Two-column layout as shown).
  * **Tablet/Mobile:** Below 1200px (Stacked vertical layout, full-width columns).

---

## 3. Component Specifications

### 3.1. Navigation Header
* **Position:** Absolute / Sticky top, full width.
* **Padding:** `30px 60px`
* **Layout:** Flexbox (Space between logo, nav items, and utility icons).

#### Elements:
1. **Brand Logo:**
   * Text/SVG: `AIAIAI`
   * Font: Bold uppercase sans-serif, letter-spacing `2px`.
   * Color: `#ffffff` (over dark bg) / `#242424` (over light bg).

2. **Navigation Links:**
   * Items: `Headphones`, `Discovery`, `Configuration`, `Artist`
   * Font Size: `14px`
   * Font Weight: `400`
   * Color: `var(--color-text-secondary)`
   * Hover State: `var(--color-text-primary)` with smooth transition.

3. **Utility Icons:**
   * Account/User Icon (`👤`)
   * Search Icon (`🔍`)
   * Color: `var(--color-text-primary)`
   * Gap between icons: `24px`.

---

### 3.2. Left Section (Light Background)
* **Background Color:** `var(--color-bg-light)`
* **Width:** ~40% of viewport width.
* **Padding:** `120px 60px 60px 60px`

#### Elements:
1. **Video Thumbnail Card:**
   * Position: Absolute/Relative offset.
   * Dimensions: `180px` width, auto height.
   * Border/Shadow: Subtle drop shadow.
   * Content: Thumbnail image of headphones with a vertical red accent tag on the right reading `PLAY VIDEO` rotated or stacked vertically in uppercase.

2. **Date Indicator:**
   * Text: `13 November 2017`
   * Font Size: `12px`
   * Color: `var(--color-text-secondary)`
   * Decorative Line: Horizontal line next to the date.

3. **Carousel / Pagination Controls:**
   * Position: Bottom left.
   * Elements: Two circular buttons (Left arrow `←`, Right arrow `→`).
   * Background: `var(--color-accent-red)`
   * Icon Color: `#ffffff`
   * Size: `36px` diameter, rounded-full.

---

### 3.3. Center/Right Section (Dark Background)
* **Background Color:** `var(--color-bg-dark)`
* **Width:** ~60% of viewport width.
* **Padding:** `120px 80px 60px 60px`
* **Layout:** Flex column alignment.

#### Elements:
1. **Large Background Number:**
   * Text: `02`
   * Font Size: `120px` to `160px` (Hero scale)
   * Font Weight: `300` (Light)
   * Color: `var(--color-text-secondary)` (Opacity `0.3` or muted grey).
   * **Decorative Ring:** A thin red circular border (`var(--color-accent-red)`) framing the number `02`.

2. **Main Headline:**
   * Text: `CATCH THE BEAT`
   * Font Size: `56px`
   * Line Height: `1.1`
   * Font Weight: `700` (Bold)
   * Color: `var(--color-text-primary)`
   * LetterSpacing: `1px`

3. **Body Paragraph:**
   * Text: `AIAIAI's TMA-2 combines sleek design with immaculate sound performance. They allow users to create their own unique sense of listening. Idealy configurated and dynamic headphone for the passionate audiophile...`
   * Font Size: `15px`
   * Line Height: `1.6`
   * Color: `var(--color-text-secondary)`
   * Max Width: `480px`

4. **Call-to-Action (CTA) Button:**
   * Text: `READ MORE`
   * Background Color: `var(--color-accent-red)`
   * Text Color: `#ffffff`
   * Padding: `12px 28px`
   * Border Radius: `2px` (or sharp edges matching aesthetic)
   * Font Size: `12px`
   * Font Weight: `600`
   * Letter Spacing: `1.5px`

5. **Slider Pagination Dots:**
   * Position: Absolute right edge, vertically centered.
   * Elements: 3 vertical dots.
   * Active Dot: Solid white, larger size.
   * Inactive Dots: Semi-transparent grey, smaller size.

6. **Social Media Links (Bottom Right):**
   * Items: `FB`  `TW`  `IN`
   * Font Size: `11px`
   * Letter Spacing: `1px`
   * Color: `var(--color-text-secondary)`
   * Separator: Thin horizontal line extending from the social links.

---

### 3.4. Hero Imagery (Overlapping Element)
* **Asset:** Over-ear minimalist black matte headphones (`AIAIAI TMA-2`).
* **Position:** Centered, overlapping both the light and dark sections to create depth.
* **Shadow:** Deep, soft multi-layered drop shadow underneath the headphones and earcups to give a floating/grounded physical product look.
