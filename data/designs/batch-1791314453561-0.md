# 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Brand Archetype:** Ultra-modern, premium productivity tool with an immersive dark spatial experience. Evokes a futuristic, neumorphic-infused glassmorphism aesthetic tailored for task management and personal schedule organization.
- **Visual Density:** High information density balanced by generous inner component padding, atmospheric background gradients, and deep shadow contrast (`box-shadow`).
- **Whitespace Balance:** Controlled padding (`16px`-`24px`) around card surfaces with asymmetrical floating dialogs (`translate` offsets) that create a 3D layered hierarchy.
- **Theme Balance:** Strictly **Dark Mode First** design system. Relies on deep charcoal/slate foundations (`#0c0f14`), translucent glass surfaces with backdrop blur, and vibrant neon accents (electric blue, warm orange, soft pinks) to categorize tasks and highlight interactive elements.

# 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** Fluid mobile application frame (Max-width: `412px` viewport emulation with `border-radius: 40px` and physical notch/island padding).
- **Padding & Margin Scale:** 
  - Screen Outer Padding: `20px` (Horizontal), `24px` (Vertical)
  - Element Gap Spacing: `12px` (Cards), `16px` (Sections), `24px` (Major layout breaks)
- **Section Sequence Breakdown:**
  1. **Top Bar:** User profile avatar, Greeting text, Settings gear icon.
  2. **Search Bar:** Pill-shaped input with leading search icon.
  3. **Horizontal Project / Section Tray:** Section header ("Project", "See All") + Overlapping card stack.
  4. **Progress Hero Banner / Calendar Strip:** Interactive date switcher pills (`MON 15` through `FRI 19`) & visual summary card.
  5. **Bottom Navigation Bar:** Floating dock with Home, Search/User, Central Glowing FAB (`+`), Analytics, Notifications.
- **Stacking Order & Z-Index Hierarchy:**
  - Base Canvas: `z-0`
  - Cards & Content Blocks: `z-10`
  - Floating / Overlapping Popover Cards (e.g., Team meeting popup): `z-30`
  - Floating Action Button (FAB) & Bottom Dock: `z-40`
  - Modals / Overlays: `z-50`
