# Design System Specification

## 1. Global Styles & Foundations

### Color Palette
- **Backgrounds:**
  - App Background: `#121619` (Dark charcoal/slate)
  - Surface/Container (Unselected/Normal): `#1A2024` with inner shadow/inset highlight effect
  - Surface/Container (Active/Pressed/Highlighted): `#1F272C`
- **Text & Typography:**
  - Primary Text (White): `#FFFFFF`
  - Secondary Text (Muted Gray): `#8E959B`
  - Accent Text (Red Highlight): `#FF3B30`
- **Interactive Accents:**
  - Primary Red (Buttons/Badges/Outbound Bubbles): `#FF3B30`
  - Red Glow/Shadow: `0 4px 12px rgba(255, 59, 48, 0.3)`
- **Message Bubbles:**
  - Outbound (Sender): `#FF3B30` (Text color: `#FFFFFF`)
  - Inbound (Receiver): `#1F272C` (Text color: `#FFFFFF`)

### Typography
- **Font Family:** System Default Sans-Serif (e.g., `-apple-system, BlinkMacSystemFont, "SF Pro Text", sans-serif`)
- **Weights:** Regular (400), Medium (500), Bold (700)
- **Hierarchy:**
  - **Screen Title:** 28px, Bold, `#FFFFFF`
  - **List Item Title:** 15px, Semi-Bold, `#FFFFFF`
  - **List Item Subtitle / Message Preview:** 13px, Regular, `#8E959B`
  - **Timestamps:** 12px, Regular, `#8E959B`
  - **Badge Count Text:** 11px, Bold, `#FFFFFF`

---

## 2. Component Specifications

### 2.1 Navigation Bar & Header
- **Top Bar:**
  - Contains left profile avatar (circle, ~36px diameter with subtle border)
  - Title: "Chats" (Large typography, aligned left)
  - Right Action: Circular button with `+` icon, filled with `#FF3B30` (36px × 36px)

### 2.2 Search Bar
- **Container:** Rounded pill shape, height ~40px, background `#1A2024` with inset shadow.
- **Placeholder Text:** "Search", color `#8E959B`, aligned left with padding.

### 2.3 Chat List Item
- **Layout:** Horizontal flex (Avatar -> Text Info -> Timestamp & Badge Stack)
- **Avatar:** 48px × 48px, circular, with a dark inset border/shadow.
- **Text Block:** 
  - Top line: Contact Name (`#FFFFFF`, 15px)
  - Bottom line: Latest message preview (`#8E959B`, 13px, truncated with ellipsis)
- **Right Block:**
  - Timestamp on top (e.g., `12:35`, `#8E959B`, 12px)
  - Notification Badge below timestamp: Pill/capsule shaped, background `#FF3B30`, text white (e.g., `100`, `99+`, `3`).

### 2.4 Bottom Navigation Bar (Chats Screen)
- **Container:** Floating dark container with rounded corners, background `#161B1E`, drop shadow.
- **Icons Included:**
  1. Chat/Flag icon (Active state indicator in red)
  2. Camera icon
  3. Grid/Scanner icon
  4. Settings/Gear icon
- **Styling:** Each icon is housed within a subtle recessed circular button (`#1A2024`).
