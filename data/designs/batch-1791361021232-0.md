# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Luxury Architectural Glassmorphism, Editorial Real Estate SaaS, High-End Minimalist Modernism.
- **Visual Density & Whitespace Ratio**: High whitespace-to-content ratio, asymmetric floating container layout with immersive backdrop imagery, balancing airy negative space with information-dense interactive glass cards.
- **Surface Elevation Model**: Multi-tier glassmorphism layering utilizing translucent frosted surfaces (`backdrop-filter: blur(20px)`), ultra-fine 1px semi-transparent borders (`rgba(255, 255, 255, 0.4)`), and soft ambient drop shadows.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-contrast glassmorphism containers, translucent pill selectors with dropdown chevrons, floating thumbnail avatar stacks, frosted stat widgets.
- **Pill Badge Specification**: Padding `6px 16px`, font-size `12px`, font-weight `600`, tracking `0.05em`, border-radius `9999px`, background `rgba(255, 255, 255, 0.8)`, border `1px solid rgba(255, 255, 255, 0.6)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;`
  - Location Pin (📍) -> Use SVG icon component
  - External Arrow (↗) -> Use `&#8599;` or SVG
