# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Clean Minimalist Solid Canvas / Enterprise Neutral.
- **Visual Density & Whitespace Ratio**: High whitespace ratio with neutral dark grey canvas tones designed for structured UI wireframing and empty-state placeholders.
- **Surface Elevation Model**: Single-layer flat neutral backdrop with zero drop shadows or glassmorphism, acting as an unrendered canvas layout placeholder.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-contrast wireframe states, neutral container layout, placeholder surface rendering.
- **Pill Badge Specification**: Padding `4px 12px`, Font size `0.75rem`, Font weight `600`, Tracking `0.05em`, Border-radius `9999px`, Background translucency `rgba(107, 114, 128, 0.1)`, Border width `1px`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content to prevent rendering glitches.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;` or `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
