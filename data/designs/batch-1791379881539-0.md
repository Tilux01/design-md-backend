# UI Design Specification: Glassmorphic Music Player

This specification provides a pixel-for-pixel blueprint for reproducing the glassmorphic music player interface shown in the reference image. The layout is designed to be fully responsive and edge-to-edge (**full-screen**) against a warm gradient background, deliberately omitting any surrounding application chrome or device frames.

---

## 1. Global Layout & Typography

### Viewport & Background
*   **Layout Structure:** Full-screen CSS Grid / Flexbox container with absolute centering.
*   **Background:** Radial or linear gradient spanning warm copper/amber tones.
    *   *Gradient stops:* Deep rust-brown (`#30160a`) at the outer edges transitioning smoothly to warm golden amber (`#b8621b` / `#d4883a`) and a soft focal highlight in the center.

### Typography System
*   **Primary Font Family:** `Inter`, `SF Pro Display`, `-apple-system`, `sans-serif`
*   **Fallback Font Chain:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
*   **Weight hierarchy:**
    *   Track Titles (Bold / Semi-bold): `font-weight: 600;`
    *   Artist/Album Subtitles (Regular): `font-weight: 400;`

---

## 2. Component Specifications

### A. Cover Flow Carousel (Hero Section)
Positioned in the upper-center viewport. Features 5 stacked album cards rendered in 3D perspective space.

*   **Active Card (Center):**
    *   **Dimensions:** Width: `280px`, Height: `360px` (approximate aspect ratio 7:9)
    *   **Border-radius:** `24px`
    *   **Styling:** Frosted glass border, sharp scale (1.0), zero opacity filter, prominent drop shadow.
    *   **Layout:**
        *   Top: Album artwork image (fills top ~75% of card).
        *   Bottom: Frosted dark overlay (`rgba(0, 0, 0, 0.4)` with CSS `backdrop-filter: blur(20px)`) containing text.
        *   Track Title: `font-size: 18px; color: #FFFFFF;`
        *   Artist Name: `font-size: 14px; color: rgba(255, 255, 255, 0.7);`

*   **Side Cards (Left & Right Background):**
    *   **Scale/Transform:** Scaled down (`scale(0.85)` to `scale(0.75)`), rotated slightly on the Y-axis to create depth.
    *   **Opacity:** Reduced opacity (`0.4` to `0.6`) with increased blur.
    *   **Spacing:** Overlapping horizontal offsets relative to the center card.

---

### B. Bottom Control Dock (Floating Glass Bar)
A horizontal pill-shaped container anchored near the bottom of the screen.

*   **Container Dimensions:** 
    *   Width: `~90%` max-width `900px`
    *   Height: `72px`
    *   Border-radius: `36px` (Full pill shape)
*   **Glassmorphism Properties (CSS):**
    *   `background: rgba(255, 255, 255, 0.08);`
    *   `backdrop-filter: blur(30px);`
    *   `-webkit-backdrop-filter: blur(30px);`
    *   `border: 1px solid rgba(255, 255, 255, 0.15);`
    *   `box-shadow: 0 20px 40px rgba(0, 0, 0, 0.3);`

*   **Internal Layout Elements (Left to Right):**
    1.  **Playback Controls Group:**
        *   *Skip Back* icon (`<|`)
        *   *Pause / Play* icon (`||`) — highlighted with a solid opaque white background pill.
        *   *Skip Forward* icon (`|>`)
        *   *Icon Color:* Pure white (`#FFFFFF`), opacity `0.9`, size `20px`.
    2.  **Mini-Player Card (Embedded):**
        *   **Background:** Dark translucent rounded rectangle (`rgba(0, 0, 0, 0.5)`, blur `12px`).
        *   **Contents:** Thumbnail image (left), Track name + Artist (stacked right), Audio visualizer/EQ bars icon, and Options (`...`) menu.
        *   **Progress Bar:** A thin white line spanning the bottom edge of the mini-card showing playback progress.
    3.  **Secondary Utility Controls:**
        *   *Lyrics* icon (Speech bubble with quotes)
        *   *Queue / Playlist* icon (Bullet list)
        *   *Volume* icon (Speaker with waves) + slider track.

---

## 3. Animation & Interaction Specifications

To achieve a fluid, premium native feel, implement the following interactions using cubic-bezier easing (`cubic-bezier(0.25, 1, 0.5, 1)`):

1.  **Carousel Swipe / Click Interaction:**
    *   **Transition Duration:** `450ms`
    *   **Effect:** When a side card is clicked, it smoothly animates to the center position, scaling up while adjacent cards slide and scale down into their new depth positions. Artwork cross-fades seamlessly.
2.  **Hover States:**
    *   Dock icons elevate slightly with an increased opacity (`1.0`) on hover.
    *   Cards respond with a subtle scale up (`scale(1.02)`) when hovered.
3.  **Audio Progress:**
    *   The progress bar inside the mini-player continuously animates smoothly from 0% to 100% width based on track duration.
