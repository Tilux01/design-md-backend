# UI Design Specification: Mobile Application Clone

## 1. Global Layout & Viewport Standards
- **Target Viewport:** Mobile UI (Width: 390px / Standard iPhone 14/15 Pro dimension baseline).
- **Layout Model:** Full-screen views (no device bezels, borders, or outer shadows rendered).
- **Architecture:** Four distinct views/screens extracted from the presentation (Splash Screen, Catalog/Home View, Search/Filter View, and Cart/Checkout View).

---

## 2. Typography System

The application uses an **editorial, high-end serif** paired with a **clean, minimalist sans-serif** for UI controls.

### Primary Display Font (Headers, Titles, Splash Branding)
- **Primary Font Family:** *Playfair Display* (or *Cormorant Garamond* for a slightly more classic editorial look).
- **Fallback Stack:** `Georgia`, `Cambria`, `"Times New Roman"`, `serif`.
- **Usage:** Splash screen brand name, main page headers, category titles, pricing displays.

### Secondary Functional Font (Body text, Metadata, Navigation, Buttons)
- **Primary Font Family:** *Inter* (or *Helvetica Neue*).
- **Fallback Stack:** `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `sans-serif`.
- **Usage:** Navigation bars, search inputs, product descriptions, small UI labels, filter tags.

## 3. Screen-by-Screen Breakdown & Detailed Specifications

---

### Screen 1: Splash / Brand Landing View

#### Background & Color Palette
- **Background Color:** Deep Olive Green (`#2C352D` or `#343E36`).
- **Text Color:** Cream / Off-White (`#F4F1EA`).

#### Layout & Elements
1. **Brand Centerpiece:**
   - **Text Content:** "MICHEL" (or brand equivalent styled in large, spaced-out caps).
   - **Font:** *Playfair Display*, Bold, Letter-spacing (tracking): `0.15em`, Uppercase.
   - **Subtitle:** A small tagline centered directly beneath the primary brand text in a lighter weight or smaller scale (*Inter*, Light, tracking `0.1em`).
2. **Footer CTA:**
   - **Position:** Bottom pinned, centered with standard side padding (`24px`).
   - **Element:** Minimalist text link or subtle ghost button indicating entry or swipe-to-continue.

---

### Screen 2: Catalog / Home View (Light Mode)

#### Background & Color Palette
- **Background Color:** Warm Off-White / Cream (`#F9F8F6`).
- **Primary Text:** Charcoal / Dark Slate (`#222222`).
- **Muted Text / Borders:** Soft Taupe (`#D6D2C9`).
- **Accent/Brand Elements:** Deep Olive Green (`#2C352D`).

#### Layout Structure
1. **Top Navigation Bar:**
   - **Left:** Minimalist hamburger menu or logo icon.
   - **Center:** Brand watermark or blank space.
   - **Right:** Search icon and Shopping Bag icon (with a subtle notification badge if applicable).
2. **Hero Banner / Featured Section:**
   - Large banner card with subtle rounded corners (`radius: 12px`).
   - **Image Placement:** High-contrast editorial product shot (see Image Manifest below).
3. **Product Grid / Carousel:**
   - Two-column product card layout.
   - **Card Elements:**
     - Minimalist product thumbnail (backgroundless product shot).
     - Product title (*Inter*, Medium, 14px).
     - Price (*Playfair Display*, Regular, 14px).

---

### Screen 3: Search & Filter View

#### Background & Color Palette
- **Background Color:** Warm Off-White (`#F9F8F6`).
- **UI Card Backgrounds:** Pure White (`#FFFFFF`) for elevated search results or input containers.

#### Layout Structure
1. **Top Search Header:**
   - **Input Bar:** Pill-shaped search bar with a light grey background (`#EFECE6`), featuring a magnifying glass icon on the left and a clear/close (`X`) icon on the right.
   - Placeholder Text: *"Search items..."* (*Inter*, Regular, 14px, color `#888888`).
2. **Filter / Category Chips:**
   - Horizontal scrolling tag list below the search bar.
   - Selected Chip: Deep Olive Green fill (`#2C352D`) with cream text.
   - Unselected Chips: Light grey/cream fill (`#EAE6DE`) with dark charcoal text.
3. **Results List:**
   - Vertical list format. Each row contains:
     - Small square product thumbnail (left-aligned, backgroundless).
     - Product title and subtitle/variant details stacked vertically.
     - Price aligned to the right.
     - Subtle bottom border divider separating list items (`#EAE6DE`, height `1px`).

---

### Screen 4: Cart / Checkout Summary View

#### Background & Color Palette
- **Background Color:** Warm Off-White (`#F9F8F6`).
- **Primary Text:** Dark Charcoal (`#222222`).
- **CTA Button Fill:** Deep Olive Green (`#2C352D`).

#### Layout Structure
1. **Header:**
   - Title: "My Cart" centered (*Playfair Display*, 18px).
   - Back arrow on the far left; item count indicator on the right.
2. **Cart Item Rows:**
   - Horizontal card layout for each added item.
   - **Left:** Product image thumbnail (backgroundless, clean drop-shadow or crisp flat look).
   - **Center:** Product name, size/color variant options, and a quantity modifier selector (`- 1 +`).
   - **Right:** Item total price and a small trash/remove icon.
3. **Order Summary Footer (Pinned Bottom):**
   - Subtotal line and Shipping line.
   - Total calculation line (Bold, 16px).
   - **Checkout Button:** Full-width primary button in Deep Olive Green (`#2C352D`) with cream text ("Proceed to Checkout"), featuring rounded corners (`radius: 8px` or `24px` for pill style).

## 4. Image Manifest & Asset Guidelines

*Note: All images referenced are isolated, high-end commercial product photography with transparent or neutral matching studio backgrounds (backgroundless).*

1. **Splash Screen / Brand Imagery:**
   - *Description:* Pure minimalist typographic execution; no photographic assets required on the splash screen itself.
2. **Hero Banner Image (Catalog View):**
   - *Description:* Editorial still-life photograph of luxury cosmetic/wellness jars (e.g., dark amber glass jars with minimalist cream typography labels), shot on a soft natural stone or neutral studio backdrop with dramatic, warm side-lighting. Clean, backgroundless or seamlessly blended into the `#F9F8F6` canvas.
3. **Product Thumbnails (Grid & List Views):**
   - *Description:* E-commerce style isolation shots of glass bottles/jars or lifestyle goods.
   - *Background:* Transparent (PNG) or color-matched to `#FFFFFF` / `#F9F8F6`.
   - *Rotation/Angle:* Straight-on orthographic eye-level shot, perfectly vertical (0-degree roll), with soft, minimal contact shadows underneath to ground the object naturally.
