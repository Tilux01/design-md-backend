# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial Minimalist E-Commerce (Clean, high-contrast typography, monochrome palette with generous white space).
- **Visual Density & Whitespace Ratio**: High whitespace. Generous padding around navigation links, prominent hero image splitting typography and lifestyle imagery, and well-spaced grid sections (`Best Seller`, `Shop by Category`).
- **Surface Elevation Model**: Flat surface structure utilizing subtle grey borders (`#E5E7EB`) for cards and containers instead of complex drop shadows. Minimal elevation applied primarily to interactive hover states or action buttons.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-contrast editorial typography, minimal pill tags (`SALE`), clean product display cards on light gray backdrops (`#F9FAFB`), thin structural dividing rules.
- **Pill Badge Specification**: Padding: `4px 12px`, font-size: `11px`, font-weight: `600`, tracking: `0.05em`, border-radius: `9999px`, background: `#000000`, text color: `#FFFFFF`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content to prevent rendering glitches.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;` or `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.

## Copyable React + Tailwind Component Code
```jsx
import React from 'react';

export function ProductCard({ title, price, originalPrice, image, isSale }) {
  return (
    <div className="group relative flex flex-col bg-[#F9FAFB] border border-[#E5E7EB] rounded-lg p-4 transition-all hover:border-black">
      {/* Sale Badge */}
      {isSale && (
        <span className="absolute top-6 left-6 z-10 px-3 py-1 bg-black text-white text-[10px] font-semibold tracking-wider uppercase rounded-full">
          Sale
        </span>
      )}
      
      {/* Product Image Container */}
      <div className="w-full aspect-square flex items-center justify-center overflow-hidden mb-4 bg-white rounded-md">
        <img src={image} alt={title} className="object-contain w-3/4 h-3/4 group-hover:scale-105 transition-transform duration-300" />
      </div>

      {/* Product Details */}
      <div className="flex flex-col gap-1">
        <h3 className="text-sm font-medium text-gray-900">{title}</h3>
        <div className="flex items-center gap-2 text-sm">
          {originalPrice && (
            <span className="text-gray-400 line-through">${originalPrice} USD</span>
          )}
          <span className="font-semibold text-black">${price} USD</span>
        </div>
      </div>
    </div>
  );
}
```
