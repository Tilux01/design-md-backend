# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Editorial Minimalist / High-Fashion Portfolio. Clean, timeless luxury with high-contrast typography, subdued neutral canvases, and dramatic portraiture framing.
- **Visual Density & Whitespace Ratio**: Highly spacious and airy. Generous margins and padding around the header navigation and hero banner allow the central editorial photography and oversized background typography to dictate visual hierarchy.
- **Surface Elevation Model**: Flat, single-layer canvas architecture utilizing subtle tonal shifts in neutral grays rather than drop shadows or heavy borders, preserving a high-end editorial feel.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-tracking uppercase navigation links, oversized background typography watermarks (`MIDEN`), high-contrast monochrome editorial styling.
- **Pill Badge Specification**: Padding `6px 16px`, font-size `12px`, font-weight `600`, tracking `0.15em`, border-radius `9999px`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;`.
  - Status Dot (●) -> Use `&#9679;`.

# 7. Motion Mechanics, Framer Motion & CSS Animations
- **Motion Principles**: Smooth cubic-bezier transitions (`[0.16, 1, 0.3, 1]`), subtle fade-in entrances for typography and imagery.
- **Framer Motion Variants Code**:
```jsx
export const fadeUpVariants = {
  hidden: { opacity: 0, y: 15 },
  visible: { 
    opacity: 1, 
    y: 0,
    transition: { duration: 0.6, ease: [0.16, 1, 0.3, 1] }
  }
};
```

- **CSS `@keyframes` Animations**:
```css
@keyframes subtleFade {
  0% { opacity: 0; transform: scale(0.98); }
  100% { opacity: 1; transform: scale(1); }
```
