# Design Specification: Financial Mobile Application UI

---

## 1. Global & Architectural Layout

### A. Viewport & Device Context
* **Target Screen Resolution:** iOS standard frame (approx. `390px` width × `844px` height viewport scale, equivalent to iPhone 14/15 Pro layout).
* **Frame Removal Policy:** Per instructions, render full-screen immersive viewports (`width: 100%`, `min-height: 100vh`). Omit physical phone bezels, shadows, hardware buttons, and ambient staging backgrounds.
* **Scroll Behavior:** Vertical scrollable container (`overflow-y: auto`), with hidden default browser scrollbars.

### B. Color Palette
* **Background Colors:**
  * Application Canvas / Root Background: `#FAFAFC` (Pure, clean light off-white).
  * Card Surfaces (Containers): `#FFFFFF` (Solid White) with very soft elevation shadows (`box-shadow: 0 4px 20px rgba(0, 0, 0, 0.03)`).
* **Text & Typography Colors:**
  * Primary Headings & Dark Elements: `#111111` (Near Black).
  * Secondary Text, Subtitles & Metadata: `#7A7A85` (Medium Cool Gray).
  * Muted / Placeholder Text: `#A0A0AB` (Light Gray).
* **Accent & Brand Colors:**
  * Teal / Mint Accent (Activity chart bars, Savings graph line, "Buy" card background): `#72C4B7` (Light mint-teal), with dark teal line graphs (`#4AB09E`).
  * Peach / Warm Orange (Sales cards): `#F7E5D9` (Soft peach background), `#E59572` (Terracotta accent).
  * Purple / Lavender (Activity/Sell cards): `#9B86BD` (Dusty lavender).
  * Negative Financial Amount (Red/Dark): `#1B1B1B` (Bold black for debit display).

### C. Typography System
* **Primary Font Family:** `Inter`, `SF Pro Display`, `system-ui`, `-apple-system`, `sans-serif`.
* **Fallback Stack:** If system fonts fail to render, fall back strictly to Arial/Helvetica sans-serif. Ensure font smoothing is enabled (`-webkit-font-smoothing: antialiased`).

## 4. Implementation Guidelines for Developers
1. **CSS Flexbox/Grid:** Use strict CSS Grid for the Bento cards and standard flexbox column layouts for list structures.
2. **Spacing Tokens:** Use increments of `4px`, `8px`, `12px`, `16px`, `24px` consistently for margins, paddings, and gaps.
3. **Border Radii:** Keep card corners soft and modern using `20px` to `24px` radius; use `12px` to `16px` for inner chips and buttons.
4. **Icons & Images:** Replace UI placeholder icons with SVG strokes (`stroke-width: 2`, `stroke-linecap: round`, `stroke-linejoin: round`). Ensure avatar image assets are high-res transparent/backgroundless centered portraits cropped circularly.
