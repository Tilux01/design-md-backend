# UI/UX Specification & Design Blueprint: HIBR E-Commerce Store

This specification provides a complete blueprint to build a pixel-perfect, responsive, full-screen clone of the provided "HIBR" fashion e-commerce design. It details layout architecture, typography, color systems, interactive states, micro-interactions, and animations.

---

## 1. Global & Architectural Styles

### 1.1 Canvas & Backgrounds
* **Page Base Background:** Pure Black (`#000000`) for the primary backdrop, housing the hero section and secondary split/grid elements.
* **Content Container Background:** The "Get The Fit" product card grid uses an off-white/cream paper-textured background (`#F4F1EA` or `#EFECE6`) to contrast cleanly against the surrounding pure black canvas.
* **Text Block Background:** The descriptive text section ("HIBR IS WINTER REDEFINED...") sits directly on a cream surface (`#F4F1EA`) matching the grid area.

### 1.2 Layout Strategy
* **Full-Screen Viewport:** Designed for desktop-first scale (`1440px` base canvas width), utilizing CSS Grid and Flexbox for precise alignment.
* **Gutters & Spacing:** 
  * Outer margin/padding for hero: `40px` horizontal, `24px` vertical.
  * Grid gap between product lookbooks: `1px` to `2px` (simulating structural border dividers).

---

## 2. Typography & Font Stack

Because this is a high-fashion, streetwear-meets-luxury brand aesthetic, the typography relies heavily on high-contrast, bold, geometric sans-serif headings paired with clean, highly legible secondary text.

### 2.1 Font Families
* **Primary Heading / Brand Font:** 
  * *Primary:* `Syne`, `Futura PT`, or `Montserrat` (Extra Bold / Black weights).
  * *Fallback Stack:* `font-family: 'Syne', 'Futura', 'Helvetica Neue', sans-serif;`
* **Body & UI Font:** 
  * *Primary:* `Inter` or `Space Grotesk` (Regular, Medium, Bold).
  * *Fallback Stack:* `font-family: 'Inter', -apple-system, BlinkMacSystemFont, sans-serif;`

### 2.2 Typography Scale & Hierarchy

| Element | Font Family | Size | Weight | Tracking / Letter-Spacing | Color |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Top Navigation Items** | Inter | `12px` / `0.75rem` | Medium (500) | `+0.05em` (Uppercase) | White (`#FFFFFF`) |
| **Hero Main Title ("OUR NEW COLLECTION")** | Syne / Futura | `64px` / `4rem` | Extra Bold (800) | `-0.02em` (Tight, stacked) | White (`#FFFFFF`) |
| **Hero Brand Stamp ("THREAD FORM")** | Syne / Futura | `32px` / `2rem` | Bold (700) | `+0.1em` (Wide tracking) | White (`#FFFFFF`) |

## 3. Section-by-Section Design Breakdown

---

### Section 1: Navigation Bar & Hero Section
* **Height:** `100vh` (Viewport Height).
* **Background:** Deep sky-blue atmospheric background gradient (`#7DA1C4` to `#4A769E` photographic backdrop).

#### 1.1 Navigation Bar (`position: absolute; top: 0; width: 100%`)
* **Left:** Brand Logo ("HIBR") in bold white geometric lettering.
* **Center Links:** `WOMEN` | `MEN` | `NEW COLLECTION` | `GET THE FIT` | `ABOUT` (spaced evenly, uppercase, tracking `1px`).
* **Right:** Utility icons (Search/Magnifying glass, Account profile silhouette, Shopping Bag with counter badge).

#### 1.2 Hero Content Composition
* **Hero Title Block (Top Left):**
  * Text: `OUR NEW` (Line 1), `COLLECTION` (Line 2).
  * Color: White (`#FFFFFF`).
  * Alignment: Left-aligned against the top margin.
* **Hero Button ("CHECK IT OUT"):**
  * Shape: Pill/Rounded rectangle button (`border-radius: 4px` or full pill).
  * Background: Solid White (`#FFFFFF`).
  * Text Color: Dark charcoal (`#111111`).
  * Padding: `10px 24px`.
  * Hover State: Inverts colors (Black background, white text) with a smooth `0.2s ease` transition.
* **Hero Visual Centerpiece:**
  * High-impact editorial photography featuring a model mid-air/reclined, wearing a vibrant red puffer jacket, striped multi-colored sweater, and distressed patchwork denim.
* **Secondary Brand Stamp (Bottom Right):**
  * Text: `THREAD` (Line 1), `FORM` (Line 2).
  * Color: White, semi-translucent or crisp white overlay.

#### 2.1 The 4-Column Lookbook Grid

## 4. Micro-Interactions & Animations

To replicate the premium feel of high-end fashion e-commerce sites (like Balenciaga, Kith, or Acne Studios), apply the following interactive behaviors:

1. **Button Hover Effects:**
   * *Hero CTA ("CHECK IT OUT"):* Scales up slightly (`transform: scale(1.03)`) with a color inversion on hover. Duration: `250ms cubic-bezier(0.16, 1, 0.3, 1)`.
2. **Lookbook Card Hover States:**
   * *Image Zoom:* When hovering over any of the 4 columns in the "GET THE FIT" grid, scale the model image smoothly (`transform: scale(1.05)` over `400ms`).
   * *Link Reveal:* The `SEE THE FIT` text slides upward or displays an animated underline indicator.
3. **Smooth Scrolling:**
   * Implement CSS smooth scrolling across the entire document (`html { scroll-behavior: smooth; }`).
4. **Fade-In Reveal on Scroll (Intersection Observer):**
   * As the user scrolls down to "GET THE FIT", the cards stagger upwards with a fade-in effect (`opacity: 0; transform: translateY(30px)` transitioning to `opacity: 1; transform: translateY(0)` with a `100ms` stagger delay per card).
