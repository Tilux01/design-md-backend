# Design Specification: Seasonal Smoothie App (Strawberry UI)

## 1. Overview & Layout Strategy
* **Target Platform:** Mobile (iOS / Android responsive web app or native view).
* **Display Mode:** Full Screen (edge-to-edge, ignoring physical device frames).
* **Color Palette:**
  * **Background (Screen):** Pure White (`#FFFFFF`)
  * **Primary Card Background:** Pastel Pink (`#FFC1D6` or soft magenta-pink gradient equivalent)
  * **Primary Text (Dark):** Deep Charcoal / Black (`#111111`)
  * **Secondary Text (Inactive Tabs):** Muted Gray (`#999999`)
  * **Accent / Active Indicator:** Soft Pink / Rose (`#FF6B8B`)
* **Layout Structure:**
  * **Header:** Minimalist top navigation with a hamburger menu (`☰`) on the left and a search icon (`🔍`) on the right.
  * **Section Title:** Left-aligned multi-line heading ("Seasonal Smoothie").
  * **Hero Graphic Area:** A rounded pink card featuring a central glass of strawberry smoothie surrounded by floating strawberries, leaves, and a red straw.
  * **Category Navigation:** Horizontal text selector at the bottom ("Strawberry", "Blueberry", "Orange") with an active underline indicator.

---

## 2. Typography & Fonts

### **Primary Font Family**
* **Target Font:** **Poppins** or **Quicksand** (Clean geometric sans-serif with rounded terminals, matching the friendly app aesthetic).
* **Fallback Stack:** `font-family: 'Poppins', 'Quicksand', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif;`

### **Type Scale**
1. **App Header / Title ("Seasonal Smoothie"):**
   * **Font Weight:** Bold (`700`)
   * **Font Size:** `28px` / `1.75rem`
   * **Line Height:** `1.2`
   * **Color:** `#111111`
2. **Category Tabs ("Strawberry", "Blueberry", "Orange"):**
   * **Font Weight:** Medium (`500`) for inactive, Semi-bold (`600`) for active.
   * **Font Size:** `16px` / `1rem`
   * **Color (Active):** `#111111` with a pink underline indicator (`#FF6B8B`, height `3px`, rounded caps).
   * **Color (Inactive):** `#AAAAAA`

---

## 3. UI Component Breakdown

### A. Header Component (`header`)
* **Position:** Sticky / Fixed top.
* **Padding:** `24px` horizontal, `16px` vertical (accounting for safe areas).
* **Left Element:** Hamburger menu icon (`☰`), stroke-width: `2px`, color: `#111111`, size: `24px`.
* **Right Element:** Search magnifying glass icon (`🔍`), color: `#111111`, size: `20px`.

### B. Title Component (`hero-title`)
* **Text:** 
  ```html
  <h1>Seasonal<br>Smoothie</h1>
  ```
* **Margins:** `12px` top, `24px` bottom.

### C. Hero Card (`smoothie-card`)
* **Container Shape:** Rounded rectangle with large corner radii (`border-radius: 32px`).
* **Background Color:** Soft pastel pink gradient (`linear-gradient(135deg, #FFD1E0 0%, #FFB6CC 100%)`).
* **Visual Elements (Layered via CSS Absolute Positioning):**
  * **Central Image:** A tall, fluted glass containing a light pink strawberry smoothie and a red straw.
  * **Floating Elements:** Multiple high-res transparent PNG assets of whole/sliced strawberries and green mint leaves scattered dynamically around the glass to create a floating/explosion effect (depth of field).
  * **Shadows:** Soft, diffused drop shadows beneath the glass and bottom strawberries to give a 3D layered feel (`box-shadow: 0 20px 40px rgba(255, 107, 139, 0.25);`).

### D. Category Tab Bar (`category-tabs`)
* **Layout:** Flexbox, row-oriented, evenly spaced or left-aligned with horizontal scroll.
* **Items:**
  * `Strawberry` (Active — includes a bottom pink pill indicator: width matches text, height `3px`, color `#FF6B8B`).
  * `Blueberry` (Inactive)
  * `Orange` (Inactive)

## 4. Animations & Micro-Interactions (Framer Motion / CSS)

To replicate the dynamic, lively feel of the app, implement the following animations:

1. **Floating Fruit Animation:**
   * Apply a continuous subtle floating keyframe animation to the surrounding strawberries and leaves:
     ```css
     @keyframes float {
       0% { transform: translateY(0px) rotate(0deg); }
       50% { transform: translateY(-8px) rotate(3deg); }
       100% { transform: translateY(0px) rotate(0deg); }
     }
     .floating-item {
       animation: float 4s ease-in-out infinite;
     }
     ```
   * Stagger the animation delay (`animation-delay: 0.5s`, `1s`, etc.) for different strawberries so they don't move in unison.

2. **Tab Switching Animation:**
   * When clicking "Blueberry" or "Orange", the active pink underline should slide horizontally with a spring transition (`transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1)`).
   * The hero card contents should gently fade and scale up (`opacity: 0 -> 1`, `scale: 0.95 -> 1`) when switching categories.

3. **Touch Feedback:**
   * Interactive buttons/icons should have a `active:scale(0.95)` micro-scale effect.
