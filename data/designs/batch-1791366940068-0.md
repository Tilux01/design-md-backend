# Design Specification: Netflix Dark Glassmorphic Desktop App Clone

## 1. Global Styles & Theme

### Color Palette
* **Background (App):** Deep charcoal/black glass with backdrop blur (`rgba(18, 18, 20, 0.65)` with `backdrop-filter: blur(24px)`).
* **App Window Border:** Subtle light border (`1px solid rgba(255, 255, 255, 0.08)`).
* **Background (App Wallpaper):** Abstract fluid 3D grayscale/dark silver wave pattern (dark curves with soft highlights and deep shadows).
* **Primary Text:** Crisp White (`#FFFFFF`).
* **Secondary Text:** Muted Gray (`#9CA3AF`).
* **Active Indicator / Highlights:** Vibrant Netflix Red (`#E50914`).
* **Badge Background:** Red (`#E50914`) with white text.

### Typography
* **Font Family:** Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif.
* **Logo:** Bold, uppercase, tracked tightly (`font-weight: 700`, `letter-spacing: -0.5px`).
* **Section Headers:** Uppercase, extra-small, muted (`font-size: 10px`, `font-weight: 600`, `letter-spacing: 1.2px`, color: `#6B7280`).
* **Navigation Items:** Medium weight (`font-size: 13px`, `font-weight: 500`).

---

## 2. Layout Structure

* **Layout Mode:** Full-screen immersive view (`width: 100vw`, `height: 100vh`).
* **Main Sidebar / Panel:**
  * **Width:** Fixed `300px` (or centered floating panel styled as a vertical dock).
  * **Border Radius:** `20px` corners.
  * **Internal Padding:** `24px` top/bottom, `20px` left/right.
  * **Shadows:** Deep multi-layered drop shadow (`0 24px 48px rgba(0, 0, 0, 0.6)`).

---

## 3. Component Breakdown

### A. Window Controls (macOS Style)
* Positioned at the top-left of the panel.
* Three circular dots in a horizontal row:
  * **Close:** Red (`#FF5F56`), `12px` diameter.
  * **Minimize:** Yellow (`#FFBD2E`), `12px` diameter.
  * **Expand/Maximize:** Green (`#27C93F`), `12px` diameter.
* Spacing: `8px` gap between dots.

### B. Header Section
* **Logo:** "NETFLIX" in clean white bold typography (`font-size: 20px`).
* **Action Icon (Top Right):** Grid / app switcher icon (`4-dot grid icon`, subtle white, hover state interactive).
* **Divider:** Horizontal hairline rule (`1px` height, gradient or `rgba(255, 255, 255, 0.06)`).

### C. Navigation Sections

Grouped by uppercase headers (`MENU`, `CATEGORY`, `GENERAL`). Each item includes an icon, label, and optional badges/arrows.

#### 1. MENU
* **Browse** *(Active State)*
  * Icon: Compass / explore icon (Filled white/red accent).
  * Indicator: Vertical red pill on the far left edge of the item row.
  * Arrow: Right chevron (`>`) on the far right.
* **Watchlist**
  * Icon: Bookmark / list icon.
* **Friends**
  * Icon: Group of users icon.
* **Notifications**
  * Icon: Bell icon.
  * Badge: Red pill with white number `"2"` on the right.

#### 2. CATEGORY
* **TV-Shows**
  * Icon: Television monitor icon.
* **Movies**
  * Icon: Film clapperboard / reel icon.
* **Games**
  * Icon: Game controller icon.
  * Badge: Pill tag with text `"New"` (`background: rgba(255,255,255,0.1)`, `font-size: 10px`, rounded).

#### 3. GENERAL
* **Settings**
  * Icon: Gear / settings icon.
* **Log Out**
  * Icon: Arrow-pointing-left / door icon.

---

### D. User Profile Footer
* Positioned at the bottom of the sidebar.
* **Avatar:** Circular profile image (Stylized monochrome cartoon panda/character icon, `36px` diameter).
* **User Details:**
  * Name: "Kailash" (`font-size: 14px`, `font-weight: 600`, color `#FFFFFF`).
  * Status: "Restricted Account" (`font-size: 11px`, color `#9CA3AF`).
* **Arrow:** Right chevron (`>`) aligned to the far right.
* **Divider:** Separated from the "General" section by a subtle horizontal rule.

---

## 4. Interactive States & Micro-Interactions

* **Hover Effects:**
  * Nav items lighten background slightly (`background: rgba(255, 255, 255, 0.04)`, `border-radius: 8px`).
  * Smooth transitions (`all 0.2s ease`).
* **Active State:**
  * Highlighted item features a glowing red indicator pill on the outer left edge and slightly brighter text color.
