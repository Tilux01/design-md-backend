# Design Specification: Ice Cream Landing Page (Full-Screen)

This document provides the exact design specifications for creating a responsive, full-screen clone of the provided ice cream landing page. The design features a modern, playful, and conversion-focused aesthetic for an ice cream brand ("Creamy" / "NICK'S").

---

## 1. Global Styles & Variables

### Color Palette
| Color Name | Hex Code / RGBA | Usage |
| :--- | :--- | :--- |
| **Background / Primary Green** | `#52b788` (approx. Mint/Leaf Green) | Main viewport background & header sections |
| **Cream / Sand** | `#fefae0` or `#faedcd` | Bottom banner / hero content platform |
| **Dark Charcoal / Black** | `#1a1a1a` | Primary text, navigation pills, headers |
| **White** | `#ffffff` | Hero titles, button text, icon highlights |
| **Muted Green / Olive** | `#40916c` | Gradient elements, secondary backgrounds |

### Typography
*   **Font Family:** Inter, Poppins, or SF Pro Display (Clean, geometric sans-serif).
*   **Headings (H1):** Bold, rounded, large display font.
*   **Body Text:** Regular weight, highly legible at small sizes.

---

## 2. Layout Structure

The layout occupies **100% width and height** of the viewport (`min-height: 100vh`, `width: 100%`), designed with a centered desktop container that mimics a modern web app view.

## 3. Component Specifications

### A. Top Utility Bar (Outside the Main Card)
*   **Position:** Absolute top, floating pill tags.
*   **Tags:** `Tutorial`, `Figma`, `Motion`, `Web Design` (Left-aligned, white pill outlines with transparent/translucent backgrounds).
*   **Author Handle:** `@uiuxzaid` (Right-aligned, white pill outline).

### B. Main Container (App Window)
*   **Border Radius:** `24px` (smooth rounded corners).
*   **Background Gradient:** Vertical gradient shifting from `#60c592` (top) to `#3fa271` (bottom).
*   **Shadow:** Soft, deep drop shadow (`0 20px 40px rgba(0,0,0,0.15)`).

### C. Navigation Bar
*   **Logo:** Left-aligned text "Creamy" in a bold, script/rounded font (White).
*   **Center Navigation Pill:** 
    *   Background: White pill container (`border-radius: 50px`).
    *   Links: `HOME` (active state with dark background `#1a1a1a` and white text), `MENU`, `ABOUT`, `CONTACT` (dark text, uppercase, small tracking).
*   **Right Utilities:** 
    *   User profile icon and Cart icon with a red notification badge (`2`).

### D. Hero Section
*   **Left Column (Copywriting):**
    *   **H1 Title:** "Taste Joy in Every Bite" (Extra bold, white, multi-line).
    *   **Subtext:** "They aren't just about incredible sound, they're designed for your well-being. With immersive audio and noise cancellation." (Small, muted white/light gray, max-width ~280px).
    *   **Call-to-Action (CTA) Buttons:**
        *   `ORDER NOW`: Solid dark pill button (`#1a1a1a`), white text.
        *   `SEE MENU ITEMS`: Outlined pill button, white border/text, semi-transparent.

*   **Product Display (Right Column):**
    *   **Weight Selectors:** Small circular tags `50g`, `100g`, `500g` floating above the products.
    *   **Active Product:** NICK'S "Mint Chokladchip" ice cream tub (Center, prominent size, realistic 3D mockup with mint leaf and chocolate illustrations).
    *   **Background Products:** Strawberry/Pink flavor to the right, smaller vanilla/caramel flavor further right (layered depth effect).

### E. Bottom Wave Banner (Cream Section)
*   **Background Color:** Cream/Sand (`#fefae0`).
*   **Shape:** Organic curved top border (wave SVG).
*   **Left Side (Social Proof):**
    *   **Avatar Stack:** 3 overlapping circular profile pictures of reviewers.
    *   **Text:** "10K+ Reviews" (Bold) / "Customers are satisfied" (Regular).
*   **Center:** Left/Right arrow navigation controls (`←` `→`) in small circular white buttons.
*   **Right Side:** Social media icon placeholders (Instagram, Twitter, etc.).

### F. Footer
*   **Left:** "© 2025 All rights reserved" (Muted white, small font).
*   **Right:** `@uiuxzaid` handle in a subtle pill badge.
