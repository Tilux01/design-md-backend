# Design Specification: "Tasky" Dark Theme Dashboard

This document provides a comprehensive design specification for recreating the "Tasky" dark-themed project management and team collaboration dashboard shown in the image.

---

## 1. Global Styles & Theme

### Color Palette
- **Primary Background (Canvas):** `#1a1c23` (Very dark desaturated blue/grey, forming the backdrop of the entire viewport frame).
- **Surface / Card Backgrounds:** `#232631` to `#282b39` (Darker grey-blue surfaces used for containers, sidebar items, cards, and input fields with subtle gradient highlights).
- **Primary Text:** `#ffffff` (Pure white for high-emphasis headings and vital data points).
- **Secondary Text:** `#8b90a0` or `#6f7485` (Muted grey-blue for secondary labels, timestamps, metadata, and placeholder text).
- **Accent Color (Brand / Highlights):** `#8b5cf6` to `#a855f7` (Vibrant purple used for active indicators, pro badges, progress bars, time indicators, and CTA buttons).
- **Borders & Dividers:** Subtle inner shadows and semi-transparent borders (`rgba(255, 255, 255, 0.05)`).

### Typography
- **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif.
- **Fallback Stack:** `sans-serif`.
- **Font Scale & Weights:**
  - **Logo ("Tasky."):** Bold (700), ~18px, tracking/letter-spacing tight.
  - **Main Headers (e.g., "Ongoing 8 Projects"):** Semi-Bold (600), ~24px.
  - **Section Titles (e.g., "Roadmap", "Members"):** Medium (500), ~14px to 16px.
  - **Body / Metadata / Timestamps:** Regular (400), ~11px to 13px.

---

## 2. Layout Structure & Grid

The interface is structured as a **Full-Screen Desktop Application Dashboard (approx. 1440px × 900px canvas reference)** featuring a 3-column primary layout with a fixed navigation sidebar on the far left.

```

| BAR    |   (List of active cards)   |   (Timeline view)     |  & CHAT           |

+--------+----------------------------+-----------------------+-------------------+
```
