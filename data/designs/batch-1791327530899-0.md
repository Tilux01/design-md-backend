# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Clean, Minimalist Fitness & Lifestyle Mobile Application (Neo-Skeuomorphic Modern Dark/Light Hybrid UI).
- **Visual Density & Whitespace Ratio**: High whitespace-to-content ratio, floating pill containers, rounded card boundaries, generous interior padding (16px–24px), clear visual hierarchy with stark black-on-white and dark slate contrasts.
- **Surface Elevation Model**: Layered soft cards with subtle neutral borders, soft background gradients (very pale lavender-white canvas `#F6F5FB`), dark mode widgets (`#161B22` / `#1E232B`), and floating dark action bars with pill curvatures (`rounded-full`).

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: High-contrast dark mode cards floating on pastel lavender canvas, circular gradient avatars, glowing status indicators, pill-shaped inputs and buttons.
- **Pill Badge Specification**: Padding: `4px 12px`, font-size: `12px`, font-weight: `600`, tracking: `0.04em`, border-radius: `9999px`, background: `rgba(255, 255, 255, 0.1)`, border: `1px solid rgba(255, 255, 255, 0.15)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before`.
  - Sparkle / Trophy (🏆/✦) -> Use SVG icon components.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-orange-500 inline-block"></span>`.
