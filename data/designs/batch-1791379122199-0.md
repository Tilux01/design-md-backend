# Visual Design & Code-Clone Specification: "Fly in Luxury" (Jesko Jets Hero Section)

This document provides a precise, pixel-by-pixel engineering and design specification to clone the hero section shown in the provided media. The layout represents a high-end, cinematic web experience for a private jet charter company ("Jesko Jets").

## 1. Global Layout & Structure

*   **View:** Full-screen viewport (`100vw` × `100vh`), non-scrolling initially (`overflow: hidden`).
*   **Background:** 
    *   Linear gradient transitioning from a light warm silver/gray to deep charcoal, simulating ambient studio lighting reflecting off a metallic fuselage.
    *   Base color: `#e5e5e7` to `#c5c5c9`.
*   **Grid System:** 3-Column asymmetrical layout.
    *   **Left Column (~30% width):** Text content ("Fly in", subtext, CTA button).
    *   **Center Column (~40% width):** High-impact 3D/Video asset of the private jet nose cone pointing upward.
    *   **Right Column (~30% width):** Text content ("Luxury"), secondary feature highlights.

## 2. Typography & Fonts

The typography leans heavily on modern luxury branding—pairing a sharp, wide-spaced sans-serif for navigation with a high-contrast serif/editorial typeface for primary messaging.

### Primary Display Serif (Headings)
*   **Font Family:** *Playfair Display*, *Bodoni Moda*, or custom editorial serif.
*   **CSS Stack:** `font-family: 'Playfair Display', Didot, 'Bodoni MT', serif;`
*   **Usage:** "Luxury" (Right side).
*   **Styling:**
    *   Weight: Bold (`700`) or Semi-bold (`600`).
    *   Letter-spacing: Tight (-0.02em).
    *   Case: Title Case / Capitalized.

### Secondary Display Sans-Serif
*   **Font Family:** *Inter*, *Helvetica Neue*, or *SF Pro Display*.
*   **CSS Stack:** `font-family: 'Inter', -apple-system, BlinkMacSystemFont, sans-serif;`
*   **Usage:** "Fly in", Navigation links, contact info, secondary descriptions.
*   **Styling:**
    *   "Fly in": Weight 700, large scale, tight line-height.
    *   Navigation & Contact: Weight 400–500, small (`12px–14px`), high letter-spacing (`1px`).

## 4. Animations & Interactions (The $10,000+ Polish)

To achieve the high-end feel implied in the reference media, implement the following GSAP / Framer Motion animations:

1.  **Initial Page Load (Entrance Timeline):**
    *   **Jet Asset:** Scales up from `0.95` to `1.0` with a smooth cubic-bezier easing (`cubic-bezier(0.16, 1, 0.3, 1)`), accompanied by a fade-in from `opacity: 0`. Duration: `1.2s`.
    *   **Typography ("Fly in" & "Luxury"):** Staggered clip-path slide-up from bottom. The text reveals itself from behind an invisible overflow mask. Duration: `1.0s`, delay: `0.3s`.
    *   **Header & Nav:** Fades down from `y: -20px` to `y: 0`. Duration: `0.8s`, delay: `0.5s`.

2.  **Mouse Parallax / Tilt Effect:**
    *   As the user moves their mouse across the screen, use JavaScript to subtly shift elements on the Z-axis:
        *   **Background gradient:** Moves slightly opposite to mouse direction.
        *   **Center Jet:** Tilts on X/Y axes (`max-rotation: 3deg`) using CSS `transform: perspective(1000px) rotateX() rotateY()`.
        *   **Text layers:** Move with a higher multiplier than the background to create deep 3D separation.

3.  **Button Micro-Interaction:**
    *   On hover over "Book the Flight", the internal icon badge scales up and translates right by `4px`.
    *   Cursor changes to pointer.
