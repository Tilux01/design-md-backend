# Comprehensive Design Specification & Implementation Blueprint

## 1. Global Layout & Viewport Configuration
* **Target Viewport**: Full-screen responsive web application (`width: 100vw; height: 100vh; overflow: hidden;`).
* **Background Architecture**: 
  * The interface is split vertically down the exact center (`50vw / 50vw`), utilizing a dual-tone layout.
  * **Left Side (Neglected State)**: 
    * Background color: `#8B6F47` (Warm, desaturated earthen brown/tan).
  * **Right Side (Restored State)**: 
    * Background color: `#4CAF50` transitioning to a vibrant lawn green gradient (`#56AB2F` to `#A8E063`, standard fallback `#46A043`).
* **Visual Dividers & Elements**:
  * In the center, a spherical 3D grass sphere element sits precisely at the vertical bisector (`left: 50%; top: 50%; transform: translate(-50%, -50%);`).
  * The sphere is visually split: the left hemisphere represents dead, dried thatch/straw (`#B5905C`), and the right hemisphere represents lush, manicured dark green turf (`#2E7D32`).

---

## 2. Typography & Font Stack
* **Primary Typeface Family**: `Inter`, `SF Pro Display`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `Helvetica Neue`, `Arial`, `sans-serif`.
* **Font Weights Utilized**: 
  * Regular (`400`) for body copy.
  * Medium (`500`) for navigation and button labels.
  * Bold (`700` or `800`) for headers.

### Text Hierarchy Styles:
1. **Navigation Links**:
   * *Font Size*: `14px`
   * *Font Weight*: `500` (Medium)
   * *Color*: `#FFFFFF` (White)
   * *Tracking / Letter-spacing*: `0.5px`
2. **Section Heading ("NEGLECTED" / "RESTORE")**:
   * *Font Size*: `clamp(2rem, 4vw, 3.5rem)`
   * *Font Weight*: `800` (Extra Bold)
   * *Text Transform*: Uppercase
   * *Color*: `#FFFFFF` (Pure White)
   * *Letter-spacing*: `1px`
3. **Body Description Paragraph**:
   * *Font Size*: `13px` / Line height: `1.5`
   * *Font Weight*: `400` (Regular)
   * *Color*: `rgba(255, 255, 255, 0.85)` (Off-white/Translucent for readability)
   * *Max-Width*: `320px`
4. **Call to Action (CTA) Button Text**:
   * *Font Size*: `13px`
   * *Font Weight*: `600`
   * *Text Transform*: Capitalized ("Book a Service")

---

## 3. Component Breakdown & Spatial Positioning

### A. Navigation Bars (Dual Header)
* **Positioning**: Absolute positioning relative to the screen, split identically across both halves.
* **Layout**: Flexbox, space-between (`align-items: center; padding: 30px 50px;`).
* **Elements**:
  * Links: `Home`, `About`, `Contact`.
  * Hamburger Menu Icon: Three stacked horizontal bars (`#FFFFFF`).

### B. Center Content Blocks (Mirrored Layout)
* **Left Container (Neglected)**:
  * *Position*: Absolute, pinned to the left pane (`left: 10%`, vertically centered via Flexbox or `top: 50%`).
  * *Content Sequence*:
    1. Heading: "NEGLECTED"
    2. Description: *"Tell us within 5 days if anything's off and we'll re-mow or refund. 95% of our services satisfy the customer. For the other 5%, our guarantee kicks in. Every visit is backed by $2 million in property protection."*
    3. Button: Pill-shaped dark brown button (`background-color: #3E2723`, text color `#FFFFFF`, border-radius: `50px`, padding: `12px 28px`).
* **Right Container (Restore)**:
  * *Position*: Absolute, pinned to the right pane (`right: 10%`, vertically centered).
  * *Content Sequence*:
    1. Heading: "RESTORE"
    2. Description: *Identical copy to the left side.*
    3. Button: Pill-shaped dark green button (`background-color: #1B5E20`, text color `#FFFFFF`, border-radius: `50px`, padding: `12px 28px`).

### C. Central Interactive Element (The Grass Sphere)
* **Dimensions**: `width: 280px; height: 280px;` (Responsive scaling).
* **Border Radius**: `50%` (Perfect Circle).
* **Box Shadow**: Deep ambient shadow to create a 3D levitating effect (`box-shadow: 0 20px 40px rgba(0,0,0,0.3)`).
* **Texture**: Split asset or CSS-rendered split image where the left half is dry brown straw textures and the right half is high-density 3D grass blades.

---

## 4. Animation & Interactive Behaviors (Motion Design)

### A. Page Load Entrance Animation (CSS Keyframes / Framer Motion)
* **Containers Fade-In**: 
  * `opacity: 0; transform: translateY(20px);` transitioning to `opacity: 1; transform: translateY(0);` over `0.8s` with an `ease-out` cubic-bezier curve (`cubic-bezier(0.16, 1, 0.3, 1)`).
* **Sphere Scale-In**:
  * `transform: translate(-50%, -50%) scale(0.8); opacity: 0;` scaling up to `scale(1); opacity: 1;` with a slight delay (`0.2s`).

### B. Hover & Split-Screen Interactive State (The Core UX)
* **Split Expansion (Dynamic Slider / Hover Effect)**:
  * The interface is designed as an interactive split-screen comparison slider. 
  * *Default state*: Exactly 50/50 split.
  * *Mouse Movement / Hover*: When the user hovers or drags left/right, the dividing line shifts dynamically, expanding either the "Neglected" or "Restore" panel using CSS `clip-path` or `flex-basis` transitions (`transition: width 0.4s cubic-bezier(0.25, 1, 0.5, 1);`).
* **Button Micro-Interactions**:
  * *Hover*: Slight upward lift (`transform: translateY(-2px);`) and increased box-shadow brightness.
  * *Active/Click*: Scale down slightly (`transform: scale(0.98);`).
