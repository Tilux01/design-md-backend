# Production-Grade Design Specification: Fireblocks Digital Asset Infrastructure

---

## 1. Design Philosophy & Overall Aesthetic

- **Primary Mood & Archetype:** Institutional, high-tech, high-trust, and cutting-edge fintech/crypto infrastructure. The aesthetic projects security combined with futuristic scale, utilizing deep volumetric gradients and organic glowing orbs.
- **Visual Density:** Low-density, high-impact minimalist hero layout dominated by massive typography, generous negative space, and a bold centralized 3D glowing sphere focal point.
- **Whitespace Balance:** Intentionally asymmetrical composition favoring top-heavy typographic dominance, floating background spatial depth, and a clean baseline logo ticker.
- **Theme Balance:** 100% Dark Mode. The interface utilizes a near-black atmospheric background (`#000000` to `#0B0C10`) contrasted with vibrant red-to-blue linear gradients and crisp white typography.

## 4. Layout Architecture & Spatial Grid

- **Container Max-Width:** `1440px` (Desktop Viewport Standard) with fluid horizontal padding (`clamp(24px, 5vw, 80px)`).
- **Grid Structure:** 12-column fluid grid system with a standard `24px` gutter width.
- **Section Sequence Breakdown (Top to Bottom):**
  1. **Global Sticky Navigation Bar:** Height `80px`, fixed positioning, backdrop blur enabled.
  2. **Hero Typography & 3D Volumetric Sphere Stage:** Height `calc(100vh - 160px)`, centered layering.
  3. **Feature Info Matrix:** Two-column split layout (Left: Stacked title/subtitle; Right: Institutional trust metric/tagline).
  4. **Client/Partner Logo Ribbon:** Full-width ticker band featuring grayscale partner logos (Revolut, Triple-A, Bybit, Visa, Worldpay, Bridge).

---

## 5. Component Blueprint & Element Placement

### Navigation Bar
- **Logo:** Left-aligned, uppercase tracking, white-on-black sans-serif glyph ("FIREBLOX").
- **Nav Links:** Centered cluster (`PLATFORM`, `SOLUTIONS`, `RESOURCE`, `DEVELOPERS`, `COMPANY`) with subtle hover color transitions from `#8A93A5` to `#FFFFFF`.
- **Action CTA:** Right-aligned "REQUEST DEMO" button paired with a custom hamburger/menu icon (`☰`).
- **Border:** Bottom hairline rule (`1px solid rgba(255, 255, 255, 0.08)`).

### Hero Section & Typography Layering
- **Layer Stack (Z-Index Hierarchy):**
  - `z-index: 1`: Background canvas (Deep black radial gradients).
  - `z-index: 2`: 3D Red Volumetric Sphere (positioned centrally, overlapping the bottom half of the typography).
  - `z-index: 3`: Foreground Typography (`BLOCKCHAIN` title mask overlay).
  - `z-index: 4`: Lower descriptive text elements and partner ticker bar.

### Buttons & Action Triggers
- **Primary Ghost/Outline Button ("REQUEST DEMO"):**
  - Padding: `10px 20px`
  - Border: `1px solid rgba(255, 255, 255, 0.2)`
  - Border Radius: `4px` (Sharp institutional corners)
  - Background: Transparent (`rgba(0, 0, 0, 0)`), shifts to `rgba(255, 255, 255, 0.1)` on hover.

---

## 6. Motion Mechanics, 3D & Mobile Gestures

- **Animation Triggers:** 
  - Page load orchestration (Staggered fade-up for typography and sphere expansion).
  - Mouse-move parallax effect on the central red 3D sphere.
- **Inferred Libraries / Engines:** Three.js / WebGL for real-time volumetric sphere shading and atmospheric lighting blooms. Framer Motion for UI element transitions.
- **Transition Durations & Easing:**
  - Standard UI Hover States: `150ms cubic-bezier(0.4, 0, 0.2, 1)`
  - Page Transitions / Loaders: `800ms cubic-bezier(0.16, 1, 0.3, 1)` (Custom Apple-like spring/ease-out curve).
- **Mobile Responsive Adjustments:**
  - Hero `BLOCKCHAIN` typography scales down using clamp (`clamp(48px, 12vw, 112px)`).
  - Central 3D sphere scales proportionally to prevent clipping on mobile viewports.
  - Navigation collapses into a full-screen drawer menu triggered by the hamburger icon.
