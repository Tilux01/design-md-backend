# Design System & Implementation Specification (`design.md`)

## 1. Executive Summary & Layout Principles

### Full-Screen Viewport Requirement
* **No Framing / No Device Shells:** The UI must stretch edge-to-edge across the target device viewport. Do not wrap screens in device frames (e.g., iPhone mockups), outer drop shadows, or surrounding canvas background padding.
* **Aspect Ratio:** Dynamic 100vh / 100vw mobile viewport (`390px x 844px` base reference resolution).
* **Safe Areas:** Implement system status bar padding (`env(safe-area-inset-top)`) and home indicator padding (`env(safe-area-inset-bottom)`).

## 3. Typography System & Fallback Strategy

The application relies on a clean, highly legible modern geometric sans-serif typeface with generous line heights and tight display tracking.

### Primary Typeface Stack
* **Primary Font:** `Inter` or `SF Pro Text` / `SF Pro Display`
* **Fallback Font Chain:**
  ```css
  font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'SF Pro Text', 
               'SF Pro Display', 'Segoe UI', Roboto, 'Helvetica Neue', 
               Arial, sans-serif;
  ```

## 4. Screen-by-Screen Interface Breakdown

### Screen 1: Onboarding / Welcome Screen
* **Layout:** Vertical Flexbox (`justify-content: space-between`), `padding: 48px 24px 32px 24px`.
* **Top Area:** Minimal space reserved for top status bar.
* **Center Section:**
  * **Headline Text:** "Insightful reads, tailored for your curiosity."
    * *Font:* `Display Title` (`28px`, Bold, `#171717`). Left-aligned.
  * **Secondary Action Link:** Small text positioned right above the main button.
    * *Font:* `Caption` (`13px`, Medium, `#5A4FCF`). Text: "Get started" or similar inline action.
* **Bottom Section (CTA Area):**
  * **Primary CTA Button:**
    * *Width:* `100%` width.
    * *Height:* `52px`.
    * *Background:* `var(--accent-cta)` (`#EAD0B7`).
    * *Border Radius:* `var(--radius-lg)` (`24px` or pill shape).
    * *Text:* "Next" / "Continue" (`14px`, SemiBold, `#2A1F17`, Center aligned).
    * *Shadow:* None (flat design).

---

### Screen 2: Article Feed / Home Screen
* **Layout:** Scrollable main area (`overflow-y: auto`), fixed top navigation bar.
* **Top Navigation Bar:**
  * *Height:* `56px`, `padding: 0 20px`.
  * *Left:* Minimal text brand label or category selector.
  * *Right:* Small icon controls (Search / Settings).
* **Content Stream (Feed Cards):**
  * **Card Container:** Padding `20px 0`, separated by thin border bottom (`1px solid var(--border-subtle)`).
  * **Feed Card 1 (Text-Only / Text-First Card):**

    * **Title:** "Understanding the UI/UX Principles of 2024" (`18px`, Bold, `#171717`). Margin bottom `8px`.
    * **Snippet Text:** 2-line clamped body text (`13px`, `#6B6966`, line-height `1.5`).
    * **Author Row (Footer of Card):**
      * Flex row (`align-items: center`, `gap: 8px`), margin-top `12px`.
      * **Avatar:** `24px x 24px` circular avatar image (`border-radius: 50%`).
      * **Meta Text:** "Author Name • 5 min read" (`12px`, Medium, `#9E9C98`).
  * **Feed Card 2:**
    * Standard card layout with headline, body snippet, author meta, and inline action icon (Bookmark / Share icon at bottom right).

### Screen 3: Article Detail View
* **Layout:** Single-column reading view, full width header media, scrollable article contents.
* **Top Bar Controls:**
  * Floating or top-aligned controls: Back arrow icon (left), Bookmark / Share icons (right).

  * *Height:* `220px` to `260px`.

  * *Padding:* `20px 20px 12px 20px`.

  * Positioned at the end of the text stream or pinned to bottom bar.

## 6. Animations & Micro-Interactions

### Page Transitions
* **Screen Navigation:** Horizontal slide transition (`translateX`).
  * *Duration:* `300ms`
  * *Easing Curve:* `cubic-bezier(0.32, 0.72, 0, 1)` (Apple iOS style ease-out).
  * *Next Screen:* Enters from `100%` right to `0%`.
  * *Previous Screen:* Exits from `0%` to `-25%` left with slight darkening overlay (`opacity: 0.15`).

### Scroll Behavior
* **Momentum Scroll:** `-webkit-overflow-scrolling: touch;`
* **Nav Bar Elevation:** Navigation header gains a subtle background blur (`backdrop-filter: blur(12px)`) and border bottom upon scrolling past `10px`.

### Touch Physics & Press States
* **Cards & Clickable Items:** On `touchstart` / `:active`, reduce scale to `0.985` with a quick `150ms` transition.
* **Bookmark/Like Icons:** Scale up to `1.2` and spring back to `1.0` on toggle action (`250ms` spring timing).

## 7. Accessibility Specifications

* **Color Contrast:** All body text (`#171717` and `#6B6966`) against background (`#FAF9F5`) meets WCAG AAA standards for contrast (ratio > 7:1).
* **Touch Targets:** All interactive elements (icons, secondary links, buttons) must have a minimum clickable target area of `44px x 44px`.
* **Dynamic Type Support:** Text containers use relative font sizes (`rem`) to automatically adjust to system accessibility font scaling.
