# UI/UX Specification & Design System: NEONMORPHIC NFT Marketplace

This document provides a comprehensive, production-ready design specification for the "NEONMORPHIC" NFT Marketplace landing page. All specifications are reverse-engineered from the visual artifact to ensure an exact visual and functional clone.

---

## 1. Global Layout & Canvas

*   **View Type:** Full-screen responsive web interface (`min-height: 100vh`, `width: 100vw`).
*   **Background:** 
    *   **Base Color:** Deep obsidian black (`#08040A`).
    *   **Gradient Overlay:** A rich radial/linear ambient gradient blending deep purple (`#2A0826`), hot magenta/neon red (`#570A24`), and dark charcoal vignette at the outer edges.
*   **Grid System:** 12-column fluid grid with standard horizontal padding (~5% to 8% viewport width) to contain the hero text and navigation comfortably within 1440px max-width bounds.

## 4. Component Specifications

### 4.1 Navigation Bar (`<nav>`)
*   **Position:** Fixed / Absolute top, spanning full width.
*   **Height:** 80px.
*   **Layout:** Flexbox, `justify-content: space-between`, `align-items: center`.
*   **Elements:**
    1.  **Logo:** `NEONMORPHIC` with a stylized bracketed icon (`N` shaped or stylized lines).
    2.  **Navigation Links:** `Home` (active/white), `Explore`, `Create`, `Contact`, `Blog` (muted white/gray). Hover state shifts text to pure white with a subtle text shadow.
    3.  **CTA Button ("Connect Wallet"):**
        *   **Shape:** Pill button (`border-radius: 50px`).
        *   **Padding:** 10px 24px.
        *   **Border:** 1.5px solid gradient or solid `#FF0055` / `#E91E63`.
        *   **Background:** Transparent / semi-opaque dark.

### 4.2 Hero Section (Left Column)
*   **Eyebrow Text:** `MARKETPLACE FOR` (with stylized chevrons around "KET").
*   **Main Headline:** `CREATORS`
    *   *Visual Note:* The letters "C", "E", "A", "T", "O", "R", "S" have horizontal glowing cutout lines through them, resembling futuristic neon etching.
*   **Subheadline:** 
    > "NFTs Marketplace brings together artists, creators and crypto enthusiasts on a single platform to cerate and explore top NFTs." *(Note: Keep original typography spelling "cerate" if strictly cloning).*
*   **CTA Buttons:**
    1.  **Primary Button ("Explore"):** 
        *   Dark glassmorphic fill (`rgba(15, 10, 15, 0.8)`).
        *   Pill shape (`border-radius: 50px`).
        *   Border: Neon pink gradient ring (`1.5px`).
    2.  **Secondary Action ("Create NFT →"):**
        *   Text-only link style with an arrow icon. Pure white text.

### 4.3 Featured Artwork & Visual Focus (Right Column)
*   **Hero Image:** High-fidelity cyberpunk portrait of a futuristic model with platinum-white braided hair, glowing red laser-visor spectacles across her eyes, silver cross earrings, and detailed cyberpunk cyberware.
*   **Lighting FX:** Intense neon red/magenta horizontal light beam slicing across the eye line, casting real-time rim lighting on hair strands and skin.

### 4.4 Floating Glassmorphic Badges & Widgets
All floating UI cards use **Glassmorphism**:
*   `backdrop-filter: blur(12px);`
*   `background: rgba(20, 10, 20, 0.4);`
*   `border: 1px solid rgba(255, 255, 255, 0.18);`
*   `border-radius: 12px` (or 50px for pills).

1.  **Authenticity Badge (Top Right of model):**
    *   Text: `100% Authenticity`
    *   Shape: Pill outline.
2.  **Creators Badge (Center left of model):**
    *   Text: `50000+ Creators`
    *   Shape: Rounded rectangle.
3.  **Stored NFTs Badge (Middle right of model):**
    *   Text: `5k+ NFTs Stored`
    *   Shape: Rounded rectangle.
4.  **Live Countdown Timer (Bottom Right):**
    *   Four discrete vertical glass blocks for `12 Days`, `03 Hours`, `11 Minutes`, `43 Seconds`.
    *   Active accent glow wrapping the Hours box (`03`).
5.  **Today's Highest Bid Card (Bottom Left):**
    *   Header: `Today's Highest Bid`
    *   Sub-container: Ethereum icon + label `Current Bid`.
    *   Value: `15.50 ETH = 23932.31 USD`.

## 5. Animations & Micro-Interactions

*   **Neon Pulse Glow:** 
    ```css
    @keyframes neonPulse {
      0%, 100% { box-shadow: 0 0 15px rgba(255, 0, 85, 0.4), inset 0 0 15px rgba(255, 0, 85, 0.2); }
      50% { box-shadow: 0 0 25px rgba(255, 0, 85, 0.8), inset 0 0 25px rgba(255, 0, 85, 0.4); }
    }
    ```
    *Applied to:* The "Connect wallet" button border and active countdown container.
*   **Floating Elements (Parallax / Float):**
    ```css
    @keyframes floating {
      0% { transform: translateY(0px); }
      50% { transform: translateY(-8px); }
      100% { transform: translateY(0px); }
    }
    ```
    *Applied to:* Floating badges (`50000+ Creators`, `5k+ NFTs Stored`) with staggered animation delays.
*   **Laser Beam Flicker:** Subtle opacity flicker on the model's red visor light (`opacity: 0.9 -> 1.0 -> 0.85`).

## 6. Responsive Breakpoints

*   **Desktop (`≥ 1200px`):** Full multi-column layout as specified.
*   **Tablet (`768px – 1199px`):** Stack hero text above the portrait; scale down headline typography to `40px`.
*   **Mobile (`< 768px`):** Single-column stack, hide peripheral floating badges to preserve visual clarity, center align hero text.
