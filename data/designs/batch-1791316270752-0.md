# Design System & UI/UX Specification: E-Commerce Product Grid

---

## 1. Design Philosophy & Overall Aesthetic
* **Mood & Brand Archetype:** Clean, consumer-facing e-commerce storefront. Prioritizes product discovery, scannability, and high density of item listings.
* **Visual Density:** High density grid layout (3-column layout) featuring uniform product cards, structured spacing, and clear hierarchy between product imagery, pricing, and purchase actions.
* **Whitespace Balance:** Minimalist padding around the viewport margins with tighter intra-card padding to maximize screen utilization.
* **Theme Architecture:** Pure Light Mode interface utilizing clean white surfaces (`#FFFFFF`), light gray background canvasses (`#F5F5F5`), neutral borders (`#E5E5E5`), and high-contrast dark text.

* **Primary Color & Variants:**

## 4. Layout Architecture & Spatial Grid
* **Container Max-Width:** Fluid within mobile view (approx. 375px–420px container width context observed).
* **Grid System:** 3-column equal-width product grid with tight gutters (`gap: 12px`).
* **Section Sequence:**
  1. Main scrollable catalog grid (repeating card rows).
  2. Bottom sticky / nested promotional card slider component.
* **Z-Index Hierarchy:**
  * Base layout: `z-0`
  * Floating CTA / Action Buttons: `z-10`
  * Modals / Overlays: `z-50`

---

## 5. AI Design Traits & Micro-Badges
* **Action Pills:** Rounded pill buttons (`border-radius: 9999px`) used for primary triggers ("Buy", "Select").
* **Glyph Integration:** Clean minimalist iconography for grid wrappers and category indicators.

## 6. Structural DOM Layout Blueprints & Component Specs

### Product Card Component (JSX)
```jsx
export function ProductCard({ image, title, price, onAction }) {
  return (
    <div className="flex flex-col bg-surface border border-border rounded-md p-3 shadow-card hover:shadow-card-hover transition-all duration-200">
      <div className="w-full aspect-square bg-canvas rounded flex items-center justify-center mb-2 overflow-hidden">
        <img src={image} alt={title} className="object-contain w-3/4 h-3/4" />
      </div>
      <span className="text-xs text-primary font-normal line-clamp-2 mb-2">{title}</span>
      <div className="flex items-center justify-between mt-auto">
        <span className="text-sm font-semibold text-primary">{price}</span>
        <button 
          onClick={onAction}
          className="bg-primary hover:bg-primary-hover text-inverse text-xs px-3 py-1.5 rounded-full font-medium transition-colors"
        >
          Buy
        </button>
      </div>
    </div>
  );
}
```

## 8. Accessibility (a11y) & WCAG Contrast Audit
* **Text Contrast:** Primary text (`#111111`) on Surface white (`#FFFFFF`) exceeds **15:1 ratio**, surpassing WCAG AAA requirements.
* **Muted Text Contrast:** Muted text (`#767676`) on white exceeds **4.6:1 ratio**, meeting WCAG AA requirements for small text.
* **Focus States:** All interactive action buttons must implement a visible focus ring:
```css
button:focus-visible {
  outline: 2px solid #E56717;
  outline-offset: 2px;
}
```
