# TalentSync UI Design Specification

## 1. Global Layout & Structure
* **Full Screen Layout:** Designed as a desktop web application dashboard.
* **Viewport Base:** Optimized for wide desktop viewports (~1440px+ width).
* **Grid System:** Multi-column dashboard layout with asymmetric spacing (approx. 24px gaps between cards).
* **Border Radius:** Heavy use of soft, rounded rectangular cards (`border-radius: 16px` to `24px`).
* **Background Colors:**
  * **App Header & Top Banner:** Deep forest green (`#084C3E` / `#0B5D4E`).
  * **Main Content Area:** Warm cream / off-white (`#FBF8F2` / `#F5F2EB`).

---

## 2. Typography & Font Specifications

### Primary Font Family
* **Primary Font:** Inter (or system sans-serif stack: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`).
* **Fallback Strategy:** If Google Fonts / Inter fails to load, the browser defaults to system sans-serif fonts to maintain readability and layout integrity.

### Text Hierarchy
* **App Title / Brand ("TalentSync"):**
  * Font Size: 18px / Bold (700)
  * Color: White (`#FFFFFF`)
* **Page Greeting ("Good Morning,"):**
  * Font Size: 14px / Regular (400)
  * Color: Soft muted green/white (`#A8C5BD`)
* **User Name ("Kennedy Jones"):**
  * Font Size: 24px to 28px / Semi-bold (600)
  * Color: White (`#FFFFFF`)
* **Card Headers (e.g., "Active Jobs", "Upcoming Interviews"):**
  * Font Size: 16px / Semi-bold (600)
  * Color: Dark Charcoal (`#1F2937`)
* **Metric Numbers (e.g., "310", "1,248K"):**
  * Font Size: 28px to 32px / Bold (700)
  * Color: Dark Charcoal (`#1F2937`)
* **Body / Subtext (e.g., Job Titles, Names):**
  * Font Size: 13px - 14px / Regular to Medium (400 - 500)
  * Color: Slate Grey (`#4B5563` / `#6B7280`)

---
