# Comprehensive Design & Development Specification: "SPACES - Urbanistic Development Institute" Homepage

This document serves as the complete engineering and design blueprint for creating a 1:1, production-ready clone of the provided "SPACES" Webflow landing page. It is structured to guide UI/UX designers, frontend engineers, and animation specialists in replicating the aesthetic, layout, typography, and interactive behaviors down to the finest detail.

---

## 1. Global Layout & Canvas Architecture

*   **View Mode:** Full-Screen / Edge-to-Edge Responsive Web Application (`min-height: 100vh`).
*   **Background Color:** 
    *   Primary Canvas: `#F4F2EE` (Warm Off-White / Cream).
    *   Dark Accents / Text: `#111111` (Deep Charcoal / Pure Black).
    *   Muted Green Accent: `#2B6452` (Forest/Slate Green).
*   **Grid Framework:** 
    *   Root layout is built on a custom CSS Grid system with rigid, architectural framing lines (hairline borders: `1px solid rgba(17, 17, 17, 0.2)`).
    *   Intersection points of grid lines are accentuated with custom SVG star/cross markers (defined below).

## 2. Typography Specification & Fallbacks

The design relies heavily on a high-contrast pairing between a geometric, ultra-bold sans-serif display font and a clean, neutral grotesque sans-serif for body copy.

### 2.1 Primary Display Font (Headers & Titles)
*   **Target Font Family:** **Syne** (Extra Bold / 800 weight) or **Cabinet Grotesk** (Black).
*   **Fallback Stack:** `font-family: 'Syne', 'Cabinet Grotesk', system-ui, -apple-system, sans-serif;`
*   **Usage:** 
    *   Logo: `"SPACES"` (Uppercase, tracked out).
    *   Hero Title: `"URBANISTIC DEVELOPMENT INSTITUTE ® 2009"` (Heavy tracking hierarchy).

### 2.2 Secondary / Body Font (Metadata, Navigation & Descriptions)
*   **Target Font Family:** **Inter** or **Space Grotesk** (Regular, Medium, Bold).
*   **Fallback Stack:** `font-family: 'Inter', 'Space Grotesk', system-ui, sans-serif;`
*   **Usage:** Navigation links (`Home`, `About us`, `Projects`, `Our events`, `Road map`), captions, lecturer names, and description paragraphs.

## 4. Interactive & Animation Specifications (Webflow / GSAP / Framer Motion)

To replicate the polished Webflow "Awwwards" feel of the original design, the following animations must be implemented:

### 4.1 Page Load Entrance (Staggered Reveal)
1.  **Grid Lines Drawing:** Horizontal and vertical border lines scale/draw in from center to edges using CSS `transform: scaleX(0)` to `scaleX(1)` with an ease-out cubic-bezier curve (`0.16, 1, 0.3, 1`).
2.  **Header Fade-In:** Nav items fade down with a `translateY(-10px)` offset over `0.6s`.
3.  **Hero Typography Split Reveal:** 
    *   Each word of `URBANISTIC DEVELOPMENT INSTITUTE` uses a **Text Clip/Mask** effect (`overflow: hidden`), sliding up from `100%` over `0.8s` with a `0.1s` stagger per line.
4.  **Image & Color Block Scale-Up:** The green block and architectural image scale up from `scale(0.95)` with opacity `0` to `1` over `1s`.

### 4.2 Micro-Interactions & Hover States
*   **Navigation Links:** Hover color transition from `#111111` to `#2B6452` with a subtle underline slide-in effect.
*   **Connect Button:** On hover, background inverts from `#111111` to `#2B6452` with a smooth `0.3s ease` transition.
*   **Image Parallax:** Subtle mouse-move parallax effect (`max-translate: 15px`) applied to the main architectural image using vanilla JavaScript or Framer Motion `useMotionValue`.
