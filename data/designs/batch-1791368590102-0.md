# Design Specification: SHOID Fashion E-Commerce Clone

This document provides the exact design specifications for cloning the "SHOID" fashion e-commerce web page. It is structured to ensure pixel-perfect replication.

---

## 1. Global Styles & Variables

### 1.1 Color Palette
*   **Primary Background (`--bg-primary`):** `#fbf9f6` (Warm off-white / pale cream)
*   **Text Primary (`--text-primary`):** `#111111` (Near black)
*   **Text Muted (`--text-muted`):** `#777777` (Medium grey)
*   **Border Color (`--border-color`):** `#e5e5e5` (Light grey)
*   **Card Background (`--bg-card`):** `#ffffff` (Pure white)
*   **Button Dark (`--btn-dark`):** `#111111` (Near black)
*   **Button Text (`--btn-text`):** `#ffffff` (Pure white)

### 1.2 Typography
*   **Font Family:** Inter, system-ui, -apple-system, sans-serif
*   **Logo/Brand Font:** Bold, tracked-out sans-serif

---

## 2. Header & Navigation

### 2.1 Top Utility Bar
*   **Background:** `#fbf9f6`
*   **Padding:** `12px 32px`
*   **Border Bottom:** `1px solid var(--border-color)`
*   **Layout:** Flexbox, space-between
*   **Content (Left):**
    *   Menu Icon (hamburger)
    *   Brand text: `"SHOID"` (or custom brand)
*   **Content (Center):**
    *   Text: `"CURTUS FIORS LIST"` (Uppercase, letter-spaced)
*   **Content (Right):**
    *   Social/Utility icons: `f` (Facebook), heart icon, search icon, user icon

### 2.2 Main Navigation Bar
*   **Background:** `#ffffff`
*   **Padding:** `20px 32px`
*   **Layout:** Flexbox, space-between, centered items
*   **Left Element:**
    *   Logo: `"SHO1D"` (Font weight: 800, large, letter-spaced)
*   **Center Links:**
    *   `HOME` (Active/bold)
    *   `SHOP`
    *   `MEN ▾`
    *   `WOMEN`
    *   `ABOUT`
    *   `CART`
    *   *Styling:* Uppercase, `14px`, medium weight, color: `--text-primary`
*   **Right Icons:**
    *   User Account Icon
    *   Wishlist/Heart Icon
    *   Shopping Bag Icon (with badge)

---

## 3. Hero Section ("Step into style")

### 3.1 Section Layout
*   **Background:** `#fbf9f6`
*   **Padding:** `40px 32px`
*   **Layout:** 4-column responsive grid displaying full-body fashion models.
*   **Heading Overlay:**
    *   **Text:** `"Step into style"`
    *   **Font Size:** `clamp(40px, 6vw, 84px)`
    *   **Font Weight:** Bold (700)
    *   **Position:** Absolute center, layered horizontally across the 4 model images.
    *   **Color:** `#111111`

### 3.2 Model Grid Items
*   **Column 1:** Male model in black suit & white sneakers.
*   **Column 2:** Female model in grey blazer, blue jeans, white sneakers.
    *   *Interactive Hotspot:* Circular dark pill tag (`OOTD OUTFIT`) positioned over the jacket.
*   **Column 3:** Female model in black blazer, white top, white pants, black loafers.
*   **Column 4:** Female model in rust-brown suit, white turtleneck, black boots, holding a leather bag.

---

## 4. Product Catalog Section

### 4.1 Grid Layout
*   **Layout:** 5-column grid (Flexbox/Grid), equal spacing.
*   **Gap:** `16px`
*   **Max Width:** `1440px` (centered)
*   **Padding:** `40px 32px`

### 4.2 Product Card Anatomy
*   **Card Container:**
    *   Background: `#ffffff`
    *   Border Radius: `12px`
    *   Overflow: Hidden
    *   Box Shadow: `0 4px 12px rgba(0,0,0,0.03)`
    *   Padding: `16px` (internal)
*   **Image Area:**
    *   Background: Light grey/off-white container (`#f5f5f5`)
    *   Image: Centered product photo (sneakers/shoes)
    *   Height: `180px`
*   **Product Details:**
    *   **Title:** e.g., `"Hoosl More Shy Galng"` (Font size: `14px`, weight: 600)
    *   **Subtitle/Category:** e.g., `"Pop / Prom / Prom ..."` (Font size: `12px`, color: `--text-muted`)
    *   **Price:** e.g., `"$32.6"` (Font size: `14px`, weight: 700)
*   **Action Button:**
    *   Text: `"Add to Cart"`
    *   Background: `--btn-dark` (`#111111`)
    *   Text Color: `--btn-text` (`#ffffff`)
    *   Border Radius: `20px` (Pill shape)
    *   Width: `100%`
    *   Padding: `10px 0`
    *   Font Size: `13px`
    *   Font Weight: 500

---

## 5. Footer

### 5.1 Footer Top (Newsletter & Links)
*   **Background:** `#f5f3ef` (Slightly darker warm cream)
*   **Padding:** `60px 32px`
*   **Layout:** Two-column split or flex container.
*   **Left Side (Links & Socials):**
    *   Social icons (Facebook, Instagram, Twitter/X, Pinterest)
    *   Footer navigation links column (e.g., Wilkie, Dio Fikede Cards, Course Locator)
*   **Right Side (Newsletter Subscription):**
    *   Input Field:
        *   Placeholder: `"JOIN OUR EXCLUSIVE LIST"`
        *   Background: White/Light grey pill shape with right-aligned submit arrow button (`➔`).
        *   Border Radius: Full pill (`50px`).
    *   Checkbox / Terms: `"Join our exclusive list"` text with custom checkbox.

### 5.2 Footer Bottom
*   **Content:** Copyright / legal fine print text (`"Footwear is the required footwear matches of clothes list"`).
*   **Alignment:** Centered, small muted text (`11px`, `#888888`).
*   **Padding:** `20px`

---

## 6. Interaction States & Responsiveness

*   **Hover on Product Cards:** Subtle lift (`transform: translateY(-4px)`) with enhanced box-shadow.
*   **Hover on Buttons:** Invert colors or slight opacity change.
*   **Responsive Breakpoints:**
    *   *Desktop:* 5-column product grid, 4-column hero grid.
    *   *Tablet (768px - 1024px):* 3-column product grid, 2-column hero.
    *   *Mobile (< 768px):* Single/double column grid, collapsible hamburger menu.
