# Comprehensive Design & Implementation Guide: Coffee Shop Mobile Application

This specification document details the exact design system, layout structure, typography, color palette, and interactive animations for a complete, production-ready mobile application focused on coffee ordering and loyalty. 

---

## 1. Global Design System & Foundations

### 1.1 Color Palette
The application uses a sophisticated, warm coffee-themed monochromatic palette combined with crisp light backgrounds and deep espresso accents.

| Token Name | Hex Code | Usage |
| :--- | :--- | :--- |
| **Primary / Deep Roast** | `#3D2314` | Headers, primary buttons, active states, key icons, badges |
| **Secondary / Warm Amber**| `#D49A6A` | Splash/boarding background, primary highlight elements, loyalty stamp fills |
| **Accent / Cream Gold** | `#EADBC8` | Card backgrounds, subtle containers, unselected states |
| **Surface / Pure White** | `#FFFFFF` | Main screen background canvas, card inner surfaces |
| **Text Primary** | `#2B1810` | Main headings, prominent prices, item titles |
| **Text Muted** | `#8C7A6B` | Secondary descriptions, sublabels, inactive nav icons |
| **Border / Divider** | `#F0E6DD` | Separator lines, container borders |

### 1.2 Typography System
*Note: Due to the stylized nature of the UI, use Google Fonts or System San Francisco/Roboto as modern fallbacks.*

* **Display / Brand Font:** `Playfair Display` (Fallback: `Georgia`, `serif`) — Used for large welcome titles, store branding, and focal numbers.
* **Body / UI Font:** `Inter` (Fallback: `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`) — Used for menus, pricing, body text, and micro-copy.

#### Scale & Hierarchy:
* **H1 (Splash Title):** `32px`, Weight: `700`, Line-height: `1.2`, Font: *Playfair Display*
* **H2 (Screen Headers):** `24px`, Weight: `600`, Line-height: `1.3`, Font: *Playfair Display*
* **H3 (Card Titles / Section Headers):** `16px`, Weight: `600`, Line-height: `1.4`, Font: *Inter*
* **Body / List Items:** `14px`, Weight: `400/500`, Line-height: `1.5`, Font: *Inter*
* **Caption / Meta:** `11px` - `12px`, Weight: `400`, Line-height: `1.4`, Font: *Inter*

### 1.3 Shadows, Radius & Spacing
* **Border Radius:** 
  * Containers & Cards: `16px` to `24px`
  * Buttons & Badges: `12px` to `full` (pill shape)
* **Shadows:** Soft, diffused elevation using warm dark tints.
  * `box-shadow: 0px 8px 24px rgba(61, 35, 20, 0.08);`

## 3. Micro-Interactions & Animation Guidelines

1. **Screen Transitions:** Use smooth slide-in/slide-out animations (`300ms`, `cubic-bezier(0.25, 1, 0.5, 1)`) for navigation between screens and bottom sheets.
2. **Button Feedback:** Micro-scale effect on press (`transform: scale(0.97)`, duration `100ms`).
3. **Stamp Collection Animation:** When a stamp is added, trigger a scale-up spring animation with a subtle particle/glow effect on the coffee bean icon.
4. **Tab Switcher:** Smooth sliding indicator underline when moving between menu categories or activity filters.
