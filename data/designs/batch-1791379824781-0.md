# UI/UX Design Specification & Clone Blueprint

## 1. Overview & Global Layout
This specification details a full-screen, high-impact product showcase hero section. The design centers on a bold red/orange gradient theme meant for high-performance motorsports or tactical gear (specifically a helmet). 

* **Aspect Ratio / Viewport:** Full-screen responsive viewport (`width: 100vw`, `height: 100vh`).
* **Frame Removal:** The outer decorative black presentation box visible in the source image is **omitted**; the UI spans edge-to-edge as a true website/app hero.
* **Layout Structure:** Asymmetric layout featuring brand metadata and product details on the left, and a large typographic background watermark paired with an interactive 3D product render on the right.

---

## 2. Color Palette & Gradients
The visual tone is aggressive, modern, and high-contrast.

| Role | Color Name / Description | Hex / CSS Value |
| :--- | :--- | :--- |
| **Background Base** | Deep Crimson Red | `#590808` to `#8a1212` |
| **Gradient Highlights** | Vibrant Neon Orange / Red-Orange | `#ff3b00` (Center-Right radiant glow) |
| **Primary Text** | Pure White | `#FFFFFF` |
| **Secondary Text** | Muted Cool Gray | `#A3A3A3` |
| **Watermark Text** | Translucent Dark Red / Charcoal | `rgba(0, 0, 0, 0.25)` or dark blend |
| **Pagination Dots** | White (Active), Translucent White (Inactive) | `#FFFFFF` (Active: `opacity: 1`, Inactive: `opacity: 0.3`) |

* **Background Gradient Implementation:** 
  `background: radial-gradient(circle at 70% 50%, #ff4500 0%, #a61c0f 40%, #590303 100%);`

---

## 3. Typography & Font Stack
The UI uses clean, technical, geometric sans-serif typefaces to project precision and durability.

### Fonts Used:
1. **Primary Font (Headings & Watermark):** 
   * *Target:* **Montserrat** or **Inter** (Heavy/Black weights for headings, Light for metadata).
   * *Fallback Stack:* `font-family: 'Montserrat', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;`
2. **Body & Material Details:**
   * *Target:* **Roboto** or **Open Sans** (Regular weights).
   * *Fallback Stack:* `font-family: 'Roboto', sans-serif;`

### Type Hierarchy:
* **Brand / Top Header ("Diamond Star"):** 
  * Font-size: `14px` | Weight: `600` (Semi-bold) | Letter-spacing: `1px` | Color: `#FFFFFF`
* **Material Section Label ("Material"):** 
  * Font-size: `11px` | Weight: `400` | Color: `#9e9e9e` (Muted)
* **Material Value ("Polycarbonate, Fiberglass"):** 
  * Font-size: `12px` | Weight: `400` | Color: `#d4d4d4`
* **Main Product Title ("Diamond Star Helmet"):** 
  * Font-size: `36px` to `48px` (Responsive) | Weight: `700` (Bold) | Line-height: `1.1` | Color: `#FFFFFF`
* **Pagination Number ("01"):** 
  * Font-size: `16px` | Weight: `500` | Color: `#FFFFFF`
* **Watermark Background Text ("BLACK"):** 
  * Font-size: `22vw` (Massive, scaling with viewport) | Weight: `900` (Black) | Color: `rgba(255, 255, 255, 0.04)` (Subtle cut-out/overlay effect).

---

## 4. UI Components & Detailed Breakdown

### A. Left Column Content Group
* **Positioning:** Absolute/Flex positioned to the middle-left (`padding-left: 8vw`).
* **Stack Order:**
  1. Top small logo/brand text ("Diamond Star").
  2. Vertical spacing gap (~60px).
  3. **Material Metadata Block:** Small uppercase label stacked directly above the material types.
  4. Vertical spacing gap (~40px).
  5. **Main Title:** Two-line heading ("Diamond Star" / "Helmet").
  6. Vertical spacing gap (~60px).
  7. **Slide Indicator ("01"):** Positioned below the main title to indicate current carousel position.

### B. Right Column Content Group (Visual Focus)
* **Watermark Typography:** 
  * The word **"BLACK"** spans horizontally across the middle-right background behind the product. It has a heavy, bold presence with low opacity, creating depth.
* **Product Asset (The Helmet):**
  * **Asset Type:** High-resolution 3D render or PNG cutout of a matte black motocross/off-road helmet with red inner lining accents.
  * **Placement:** Positioned centrally-right, slightly floating over the "BL[ACK]" watermark.
  * **Effects:** Subtle drop shadow to create elevation and realism against the fiery gradient background.

### C. Bottom Navigation / Pagination
* **Positioning:** Centered horizontally near the bottom (`bottom: 40px`).
* **Elements:** 5 horizontal dots representing a carousel slider.
* **Active State:** The first dot is expanded or solid white with a slightly larger footprint; the remaining 4 dots are smaller and dimmed.

---

## 5. Animation & Interaction Specs (Motion Design)

To achieve the exact feel of a modern interactive web experience, implement the following transitions and animations:

1. **Page Load / Entrance Animation (Framer Motion / CSS Keyframes):**
   * *Background:* Fade in with a slow pulse on the radiant orange light source (`scale 1 to 1.05` over 10s infinite alternate).
   * *Left Text Block:* Slides in from the left (`translateX(-30px) to 0`) with opacity fade from `0` to `1` over `0.8s` with an `easeOut` cubic-bezier.
   * *Product Helmet:* Floats in from the right with a subtle scaling effect (`translateX(40px)`, `opacity: 0` -> `opacity: 1`).
   * *Floating Idle Animation:* Once loaded, the helmet asset should have a continuous gentle floating loop (`transform: translateY(-10px)` to `translateY(10px)` over `4s` infinite ease-in-out).

2. **Carousel / Slide Transition:**
   * When switching slides (e.g., from `01` to `02`), the helmet rotates/slides out along the X-axis while the title text cross-fades with a slight vertical slide (`translateY(-10px)`).
