# Design Specification: Nordicus Homepage Clone

## 1. Global Layout & Structure
* **Viewport:** Full-screen (`100vw` width, `100vh` height), responsive design optimized for desktop screens.
* **Base Wrapper:** Fixed/Sticky dark container with a dark overlay gradient to ensure text contrast against the background video/image.
* **Background Media:** A cinematic, high-angle aerial video loop (or static fallback image) showing a bridge spanning across a river with a cityscape at sunset/golden hour.
* **Color Palette:**
  * Primary Text / Navigation: `#FFFFFF` (White)
  * Navigation Pill Background: Semi-transparent white (`rgba(255, 255, 255, 0.15)` or solid white for active state).
  * Overlay Gradient: Linear gradient from top-to-bottom with a dark atmospheric tint (`rgba(0, 0, 0, 0.3)` to `rgba(0, 0, 0, 0.5)`).

---

## 2. Typography & Fallback Strategy

### Primary Font Stack: Serif (Headings & Hero Text)
* **Font Family:** `Playfair Display`, `Cormorant Garamond`, `Georgia`, `serif`
* **Usage:** Used for the main hero headline (`"Making the world more like your dreams."`) and brand logotype.
* **Styling Rules:** Italicized, high contrast, elegant letter-spacing.

### Secondary Font Stack: Sans-Serif (Navigation & UI Elements)
* **Font Family:** `Inter`, `Montserrat`, `-apple-system`, `BlinkMacSystemFont`, `sans-serif`
* **Usage:** Used for navigation links (`HOME`, `SOLUTIONS`, `ABOUT`, `CONTACT`), buttons (`START A PROJECT`), and vertical side labels (`SCROLL DOWN`).
* **Styling Rules:** Uppercase, tracked out (increased letter-spacing), medium-to-bold weight for readability.

---

## 3. Section-by-Section Breakdown

### A. Header & Navigation (`<header>`)
* **Layout:** Flexbox container, `justify-content: space-between`, `align-items: center`, fixed or absolute positioned over the hero section with `z-index: 10`. Padding: `24px 48px`.
* **Brand Logo:** 
  * Text: `NORDICUS`
  * Font: Serif / Bold Sans-serif, tracking `2px`, color `#FFFFFF`, font size `20px`.
* **Central Navigation Pill (`<nav>`):**
  * Background: Frosted glass effect (`backdrop-filter: blur(10px)`, `background: rgba(255, 255, 255, 0.1)`).
  * Border Radius: `50px` (Pill shape).
  * Links: `HOME`, `SOLUTIONS`, `ABOUT`, `CONTACT`.
  * Active/Hover state: The `HOME` link features a solid white pill background with dark text (`#000000`). Other links remain white text with smooth opacity hover transitions.
* **CTA Button (`START A PROJECT`):**
  * Pill-shaped white button (`background: #FFFFFF`, color: `#000000`).
  * Includes a subtle diagonal arrow icon (`↗`).
  * Hover state: Slight scale up (`transform: scale(1.05)`) with a smooth CSS transition.

---

### B. Vertical Side Elements (`.scroll-indicator-side`)
* **Left Vertical Text:** 
  * Content: `SCROLL DOWN`
  * Styling: Vertical writing mode (`writing-mode: vertical-lr`), uppercase, tracking `3px`, small font size (`11px`), color `rgba(255, 255, 255, 0.7)`, positioned absolute to the middle-left edge.
* **Right Vertical Text:**
  * Content: `SCROLL DOWN`
  * Styling: Mirroring the left side, positioned absolute to the middle-right edge.

---

### C. Hero Section (`.hero-content`)
* **Alignment:** Centered horizontally, bottom-aligned vertically with ample padding from the bottom edge.
* **Main Headline:**
  * HTML Markup: `<h1>Making the world more <br>like your dreams.</h1>`
  * Font Size: `clamp(2.5rem, 5vw, 4.5rem)`
  * Line Height: `1.1`
  * Styling: Elegant serif italic typography, pure white color with a subtle drop shadow for legibility over motion video.
* **Bottom Scroll Prompt:**
  * Content: `BEGIN SCROLLING` accompanied by a thin horizontal rule line above it.
  * Font: Sans-serif, uppercase, tracking `2px`, font size `11px`, color `rgba(255, 255, 255, 0.8)`.

---

## 4. Animations & Micro-Interactions (CSS / JS)

1. **Page Load Entrance (Fade-Up):**
   * The navigation bar fades down from the top (`translateY(-20px)` to `translateY(0)`).
   * The hero headline and "BEGIN SCROLLING" prompt fade up with a staggered delay (`opacity: 0` to `opacity: 1`, `translateY(30px)` to `translateY(0)`).
   * Animation duration: `1.2s`, easing: `cubic-bezier(0.16, 1, 0.3, 1)` (Smooth ease-out).

2. **Background Motion:**
   * Cinematic slow zoom-in (Ken Burns effect) on the background image or a continuous subtle playback of the aerial bridge drone video.

3. **Interactive States:**
   * Navigation links transition color smoothly on hover (`0.3s ease`).
   * CTA buttons use hardware-accelerated transforms (`transform: translateY(-2px)`) on hover.
