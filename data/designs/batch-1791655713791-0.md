# UI Design & Implementation Specification: Neewick App Clone

This document serves as the complete technical blueprint for creating an exact, pixel-perfect frontend clone of the "Neewick" mobile application interface displayed in the reference media. All surrounding device frames, shadows, and background gradients are omitted to focus purely on the full-screen application layout.

---

## 1. Global Design System & Tokens

### Color Palette
The interface uses a strict high-contrast dark theme utilizing deep blacks, stark whites, and a warm, glowing amber-gold as the primary accent color.

*   **Primary Background (App Canvas):** `#090A0F` (Deep Midnight Black)
*   **Surface Dark (Cards/Containers):** `#12141C` (Charcoal Black with subtle blue undertone)
*   **Surface White (Light Card):** `#F0F2F7` (Off-white / light silver, used for contrast)
*   **Primary Accent (Buttons/Gradients):** `#FFC000` to `#FF9000` (Warm Amber-Gold Gradient)
*   **Text Primary (Headings/Titles):** `#FFFFFF` (Pure White)
*   **Text Secondary (Body/Metadata):** `#8C90A0` (Muted Cool Gray)
*   **Text Dark (On White Card):** `#1E2028` (Dark Charcoal)

### Typography & Fonts
*   **Primary Font Family:** `Inter`, fallback to `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `Roboto`, `Helvetica`, `Arial`, sans-serif.
*   **Secondary/Brand Font:** `SF Pro Display` or `Poppins` (for heavy titles like "Neewick"). Fallback: `Arial`, sans-serif.

## 3. Implementation Checklist for Developers

1.  **Strict Color Codes:** Ensure background is strictly `#090A0F` and cards use `#12141C`. Do not use pure white (`#FFFFFF`) for backgrounds; reserve it exclusively for typography and icons.
2.  **Border Radii Consistency:** All interactive cards and containers must use smooth, highly rounded corners (`border-radius: 24px` or `28px`).
3.  **Image Handling:** 
    *   The avatars must be treated as backgroundless cutouts or masked inside soft rounded rectangles (`border-radius: 16px`).
    *   Apply a subtle drop shadow (`box-shadow: 0 8px 24px rgba(0,0,0,0.4)`) to all raised cards to match the layered glassmorphism/neumorphism hybrid aesthetic.
4.  **Gradient Accents:** The main feature card requires a smooth horizontal gradient blending deep gold (`#D48800`) into bright amber (`#FFC837`).
