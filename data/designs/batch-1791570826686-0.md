# UI/UX Specification: iDraft Dashboard

## 1. Global Layout & Structure

The interface uses a clean, modern dashboard design with a dark/light mixed theme relying heavily on frosted glassmorphism effects, subtle shadows, and rounded rectangular containers (cards).

*   **Viewport:** Full screen (`100vw` $\times$ `100h`), responsive multi-column grid layout.
*   **Base Background:** Deep neutral grayish-white (`#F0F2F5`) overlaid with subtle gradients and soft radial lighting. The overall UI is housed within a simulated floating tablet/window container with rounded corners (`border-radius: 24px`) and a distinct drop shadow.
*   **Grid Structure:**
    *   **Sidebar (Left):** Fixed width (~240px), vertical navigation, integrations, teams, and settings.
    *   **Main Content Area (Right):** Flexible grid container divided into distinct dashboard widgets:
        *   Top bar: Greeting ("Hi, Dilan!"), global search, notifications, user profile, and `+ Create` action.
        *   Row 1: "Overall Information" card (dark theme), "Weekly progress" card (light theme), "Month progress" card (light theme).
        *   Row 2: "Month goals" card, "Task In process (2)" horizontal list of cards.
        *   Row 3: "Last Projects" horizontal list of cards.

---

## 2. Typography & Fonts

*   **Primary Font Family:** `Inter`, fallback to `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
*   **Font Weights Used:** Regular (400), Medium (500), Semi-Bold (600), Bold (700).

### Type Hierarchy
*   **Page Title ("Hi, Dilan!"):**
    *   Font Size: `28px`
    *   Font Weight: `700` (Bold)
    *   Color: `#111827` (Dark Charcoal)
*   **Widget Headers (e.g., "Overall Information", "Month goals"):**
    *   Font Size: `18px`
    *   Font Weight: `600` (Semi-Bold)
    *   Color: `#111827` (or `#FFFFFF` inside dark cards)
*   **Body Text / Labels:**
    *   Font Size: `14px`
    *   Font Weight: `400` / `500`
    *   Color: `#4B5563` (Muted Gray)
*   **Microcopy / Captions (Dates, status indicators):**
    *   Font Size: `12px`
    *   Font Weight: `400`
    *   Color: `#9CA3AF` (Light Gray)

---

## 3. Color Palette

### Neutrals
*   **Background Base:** `#F0F2F5`
*   **Card Background (Light):** `#FFFFFF` with slight transparency (`rgba(255, 255, 255, 0.8)`)
*   **Card Background (Dark):** `#18181B` (Zinc 900)
*   **Sidebar Background:** `#FAFAFA` (Zinc 50)
*   **Primary Text:** `#111827` (Gray 900)
*   **Secondary Text / Icons:** `#6B7280` (Gray 500)

### Accents & Statuses
*   **Active / Selected State (Sidebar):** `#111827` (Dark pill background with white text)
*   **Badges / Indicators:**
    *   Green (+24% growth pill): Background `#DCFCE7`, Text `#15803D`
    *   Checkmarks: `#10B981` (Emerald)
    *   Progress Rings / Chart Lines: `#111827` (Dark slate) and `#3B82F6` (Blue accents)

## 4. Component Breakdown & Detailed Specs

### A. Sidebar Navigation
*   **Logo Area:**
    *   Icon: Custom overlapping geometric/feather glyph next to text "iDraft".
    *   Font: `18px`, Bold, `#111827`.
*   **Menu Items:**
    *   Vertical list with Lucide-style line icons (Dashboard, Calendar, My Tasks, Statistics, Documents).
    *   Active Item ("Dashboard"): Dark filled pill (`#111827`), white text and icon.
    *   Inactive Items: `#4B5563` text, hover state shifts background to `#F3F4F6`.
*   **Sections:**
    *   **INTEGRATIONS:** Slack, Notion, `+ Add new plugin`.
    *   **TEAMS:** SEO (Black dot indicator), Marketing (Gray dot indicator).
*   **Footer:** Settings gear icon + text.

### B. Top Action Bar
*   **Greeting:** "Hi, Dilan!" aligned top-left of main content.
*   **Actions (Right-aligned):**
    *   `+ Create` button: Pill-shaped dark button (`#18181B`), white text, small plus icon.
    *   Icon buttons (Circular, bordered or flat on light background): Search (magnifying glass), Notifications (bell), Profile avatar.
    *   *Avatar Image Description:* Professional headshot portrait of a smiling person wearing a dark suit against a neutral background.
