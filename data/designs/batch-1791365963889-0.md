# Netflix Desktop Application UI/UX Design System & Specification

## 1. Global Styles & Foundations

### 1.1. Color Palette
- **Primary Background (Base):** `#0a0b0e` (Deep obsidian black with cool undertones)
- **Surface/Container Fill:** `#12141a` with glassmorphic backdrop filter (`blur(24px)`) and subtle inner border (`rgba(255, 255, 255, 0.06)`)
- **Text Color - Primary (High Emphasis):** `#ffffff` (Pure white)
- **Text Color - Secondary (Medium Emphasis):** `#8e95a5` (Muted cool gray)
- **Text Color - Tertiary (Low Emphasis):** `#5c6375` (Subtle dark gray for labels/sections)
- **Interactive State / Active Background:** `rgba(255, 255, 255, 0.04)` to `0.08`
- **Accent Color (Brand/Alert):** `#e50914` (Netflix Red)
- **Badge Fill:** `#e50914`

### 1.2. Typography (Font Family: Inter / System UI Sans-Serif)
- **App Title (Netflix Logo):** 
  - Weight: Bold (700)
  - Size: `20px`
  - Tracking/Letter-spacing: `-0.5px`
- **Section Headers (MENU, CATEGORY, GENERAL):** 
  - Weight: Semi-Bold (600)
  - Size: `10px`
  - Tracking: `1.5px` (Uppercase)
  - Color: `#5c6375`
- **Navigation Items (Browse, Watchlist, etc.):** 
  - Weight: Medium (500)
  - Size: `13px`
  - Color: `#ffffff` (Active) / `#8e95a5` (Inactive)
- **User Profile Name:** 
  - Weight: Semi-Bold (600)
  - Size: `13px`
- **Profile Subtext (Restricted Account):** 
  - Weight: Regular (400)
  - Size: `11px`
  - Color: `#8e95a5`

### 1.3. Spacing & Layout Metrics
- **Sidebar Width:** Fixed width of `320px`
- **Border Radius (App Container):** `16px`
- **Border Radius (Interactive Items/Badges):** `8px` to `12px`
- **Padding (Internal Container):** `24px` vertical, `20px` horizontal
- **Item Gap/Spacing:** `8px` vertical spacing between list items

---

## 2. Component Breakdown & Structure

### 2.1. Window Controls (macOS Style Header)
- **Position:** Top-left of the container
- **Layout:** Horizontal flex row, `8px` gap
- **Elements:**
  - Close button: Circle, `12px` diameter, `#ff5f56` (Red)
  - Minimize button: Circle, `12px` diameter, `#ffbd2e` (Yellow)
  - Expand button: Circle, `12px` diameter, `#27c93f` (Green)

### 2.2. Header Section
- **Brand Logo:** Text-based "NETFLIX" in heavy sans-serif (`#ffffff`), aligned left.
- **Top Right Icon:** Grid/Dashboard icon (Four rounded squares) for quick layout switching. Size: `18px`, color `#8e95a5`.

### 2.3. Navigation Groups
Divided into three distinct vertical sections separated by subtle 1px dividers (`rgba(255, 255, 255, 0.04)`):

#### **MENU**
1. **Browse** *(Active State)*
   - Left Indicator: Vertical red pill (`#e50914`, width `3px`, height `16px`, rounded ends)
   - Icon: Compass / Navigation symbol (`18px`)
   - Label: "Browse"
   - Trailing: Right chevron (`>`)
2. **Watchlist**
   - Icon: Bookmark / List icon
   - Label: "Watchlist"
3. **Friends**
   - Icon: Users / Group icon
   - Label: "Friends"
4. **Notifications**
   - Icon: Bell icon
   - Label: "Notifications"
   - Trailing Badge: Red pill container (`#e50914`), white text `"2"`, font-size `10px`, bold.

#### **CATEGORY**
1. **TV-Shows**
   - Icon: Monitor / TV icon
   - Label: "TV-Shows"
2. **Movies**
   - Icon: Clapperboard / Film icon
   - Label: "Movies"
3. **Games**
   - Icon: Gamepad icon
   - Label: "Games"
   - Trailing Tag: Dark capsule with white text `"New"` (`background: rgba(255, 255, 255, 0.08)`, font-size `10px`, padding `2px 6px`, radius `4px`)

#### **GENERAL**
1. **Settings**
   - Icon: Gear / Settings icon
   - Label: "Settings"
2. **Log Out**
   - Icon: Logout / Arrow-left icon
   - Label: "Log Out"

---

## 3. Footer / User Profile Section
- **Container:** Fixed at the bottom of the sidebar, separated by a top border line.
- **Layout:** Flex row, vertically centered, space-between.
- **Avatar:** Circular image/icon (`36px` diameter), custom abstract avatar graphic (monochrome stylized mask/face).
- **User Details:** Stacked vertical text.
  - Title: "Kailash" (`#ffffff`, `13px`, Semi-Bold)
  - Subtitle: "Restricted Account" (`#8e95a5`, `11px`)
- **Trailing Element:** Right chevron (`>`), color `#8e95a5`.

---

## 4. Interactive States & Micro-Interactions
- **Hover on Menu Items:** Background shifts to `rgba(255, 255, 255, 0.04)` with a smooth `150ms ease` transition. Text color brightens to `#ffffff`.
- **Active Menu Item ("Browse"):** Retains the red vertical indicator pill on the outer left edge and full highlight state.
- **Scrollbar:** Hidden by default (`overflow-y: overlay`), custom thin scrollbar on hover (`width: 4px`, thumb color `rgba(255, 255, 255, 0.2)`).
