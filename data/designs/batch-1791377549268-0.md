# Visual Design Specification: Sunset Blossom

## 1. Global Layout & Viewport
- **Fullscreen Structure**: The layout occupies 100% of the viewport width and height (`width: 100vw; height: 100vh; overflow: hidden; position: relative;`).
- **Composition**: A vertical split where the upper 60% contains the sky and sun, and the lower 40% features the ocean and a foreground hand holding a cherry blossom flower as the central focal point.
- **Scroll Behavior**: None (Static full-bleed photographic composition).

---

## 2. Color Palette (Exact Hex Codes & Gradients)

### Sky Gradient (Top to Horizon)
- **Zenith (Top)**: `#5a5875` (Muted Purplish-Gray)
- **Upper Mid-Sky**: `#957b98` (Soft Lavender-Rose)
- **Lower Mid-Sky**: `#d49480` (Warm Coral Pink)
- **Horizon Band**: `#ff7e1d` (Vibrant Sunset Orange)
- **Sun Intensity Point**: `#fff6d6` (Pale Warm White/Yellow Core)

### Ocean & Sand
- **Distant Horizon Water**: `#1a3038` (Deep Teal-Black)
- **Foam & Highlights**: `#ffffff` with high diffusion opacity (`rgba(255,255,255,0.85)`)
- **Wet Sand / Foreground Base**: `#241b16` (Deep Warm Espresso Brown)

### Foreground Elements (Hand & Flower)
- **Skin Tone (Hand Shadow side)**: Warm undertones ranging from `#4a2c22` to `#8c5643`
- **Cherry Blossom Petals**: Semi-translucent pale pink `#fce8eb` with darker crimson stamen centers (`#8b1e24`).

---

## 3. Typography & Font Stack
*(Note: While this is primarily a photographic asset, any overlay text should adhere to these specifications to maintain the aesthetic.)*

- **Primary Font Family**: `'Playfair Display', Georgia, serif`
- **Secondary / UI Font**: `'Inter', system-ui, -apple-system, sans-serif`
- **Fallback Stack**: `Georgia, Cambria, "Times New Roman", Times, serif`
- **Usage Guidelines**: 
  - Serif fonts for poetic headings, set in lowercase or tracking-spaced uppercase.
  - Sans-serif for clean captions.

---

## 4. Visual Assets & Layering (Z-Index Hierarchy)

1. **Background Layer (`z-index: 1`)**:
   - Sky gradient with horizontal stratocumulus clouds softly catching the orange sunset light.
   - Distant sun setting directly on the ocean horizon line, partially dipping behind a low island silhouette.

2. **Midground Layer (`z-index: 2`)**:
   - Rolling ocean waves with white foam crests refracting the orange sunset reflection.

3. **Foreground Layer (`z-index: 3`)**:
   - Human hand holding a single 5-petaled cherry blossom (sakura).
   - **Positioning**: Bottom-left quadrant, angled slightly toward the center to frame the sun directly behind it.
   - **Lighting Interaction**: Backlit by the sunset, creating a soft translucent glow along the edges of the pink petals.

---

## 5. Animation Specifications (CSS / Web Animation API)
*If implemented in an interactive web interface, apply the following subtle ambient animations:*

- **Sunset Glow Pulsation**:
  ```css
  @keyframes sunGlow {
    0%, 100% { filter: brightness(1) drop-shadow(0 0 15px rgba(255, 165, 0, 0.4)); }
    50% { filter: brightness(1.08) drop-shadow(0 0 25px rgba(255, 200, 100, 0.6)); }
  }
  ```
- **Ocean Wave Movement**:
  - Subtle horizontal translation (`transform: translateX()`) of the foam line combined with a gentle opacity fade to simulate rolling tide wash.
- **Flower Paraview Float**:
  - Micro-floating animation on the hand/flower element using a gentle `sine-wave` transform to simulate a natural handheld jitter/breath.
