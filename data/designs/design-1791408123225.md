* **Viewport Display:** Full-screen (`width: 100vw; height: 100vh; min-height: 100vh`). All mockup frames, device bezels, or structural mock-up wrappers are stripped away. The layout spans edge-to-edge.
* **Base Grid Strategy:** 
  * Max-width container set to `1280px` centered horizontally (`margin: 0 auto`) with dynamic horizontal padding (`clamp(24px, 5vw, 64px)`).

* **Overflow Rules:** `overflow-x: hidden;` applied to body to prevent accidental horizontal scrollbars.

## 3. Typography & Font Stack Specification

The design utilizes a dual-typeface hierarchy pairing a modern geometric/humanist sans-serif for interface elements with an elegant, authoritative serif for editorial display headings.

### 3.1 Primary Interface Font (Sans-Serif)
* **Target Font:** **Inter** or **Plus Jakarta Sans**
* **CSS Font Stack:** 
  ```css
  font-family: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
  ```
* **Fallback Strategy:** If Google Fonts / CDN fails, the browser defaults to system-UI sans-serifs (`-apple-system` for macOS/iOS, `Segoe UI` for Windows, `Roboto` for Android).

### 3.2 Editorial Display Font (Serif)
* **Target Font:** **Instrument Serif** or **Playfair Display** (Italic variant utilized for emphasis words).
* **CSS Font Stack:**
  ```css
  font-family: 'Instrument Serif', 'Playfair Display', Georgia, Cambria, "Times New Roman", Times, serif;
  ```
* **Fallback Strategy:** System serif fallbacks (`Georgia` -> `Times New Roman` -> generic `serif`).

## 5. Animation & Interaction Specification

To match the fluid, modern feel of high-end SaaS applications, implement the following keyframe animations:

### 1. Page Load Staggered Entrance (Fade-Up)
* **Navbar:** Slide down from `-20px` with opacity `0 -> 1` over `0.6s` cubic-bezier(0.16, 1, 0.3, 1).
* **Headline:** Fade in and translate up (`Y: 30px -> 0px`) over `0.8s` with a `0.2s` delay.
* **Subheadline:** Fade in with `0.4s` delay.
* **CTA Buttons:** Fade in and scale up slightly (`scale: 0.95 -> 1`) with a `0.6s` delay.

### 2. Interactive Micro-Interactions
* **CTA Hover States:** 
  * Primary button scales up to `1.02` with shadow intensity increasing.
  * Secondary button background opacity transitions from `0.1` to `0.2`.
* **Nav Links Hover:** Color transitions smoothly from `rgba(255,255,255,0.9)` to `#FFFFFF` over `0.2s ease`.
