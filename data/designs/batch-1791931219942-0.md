# Design Specification: "Be The Light" Minimalist Showcase

## 1. Overview & Canvas
* **Display Mode**: Full-screen viewport (`100vw`, `100vh`), borderless, dark-themed industrial aesthetic.
* **Base Background**: Subtle dark radial gradient from center-left `#25282d` to edges `#16181b`.

---

## 2. Color Palette
* **Accent Orange**: `#F05A28` (Active indicators, primary number, arrow CTA, social arrows)
* **Pure White**: `#FFFFFF` (Headings, primary logo, menu label)
* **Muted Gray**: `#8C929A` (Body typography)
* **Watermark Gray**: `#2A2E35` (Large rotated vertical text)
* **Footer Surface**: `#1A1C20` (Bottom bar background)

---

## 3. Typography
* **Primary Family**: `Inter`, `Helvetica Neue`, sans-serif.
* **Fallbacks**: `Arial`, system-ui.

### Text Styles
* **Index Number (`01`)**: `700` Bold, ~48px, `#F05A28`.
* **Main Heading (`Be The Light.`)**: `300` Light, ~36px, `#FFFFFF`, tracking tight.
* **Body Copy**: `400` Regular, 12px, line-height 1.6, `#8C929A`, max-width ~380px.
* **Watermark (`Light Bulb.`)**: `800` ExtraBold, ~64px, `#2A2E35`, rotated -90deg.
* **Nav & Footer Links**: `500` Medium, 11px, lowercase, tracking normal.

---

## 4. Imagery & Graphic Assets

### Hero Image (Light Bulb)
* **Description**: Macro shot of a clear vintage Edison filament bulb with intricate glowing orange filaments. The socket hangs vertically from the top edge. 
* **Placement**: Left hemisphere (`left: 5%`, `top: 0`), spanning ~60% of viewport height.
* **Treatment**: Transparent PNG or seamlessly composited into the dark studio gradient with soft shadows; no rotation.

### Icons
* **Logo (Top-Left)**: Geometric pill outline containing a vertical split/double-bracket monogram (White).
* **Menu Icon (Top-Right)**: 6-dot matrix (2 rows of 3 dots) in `#F05A28`.
* **Social Play Indicators**: Tiny solid triangles (`▶`) in `#F05A28`.
* **Mail Icon (Footer Left)**: Minimalist envelope outline/solid `#F05A28`.
* **Down CTA (Footer Right)**: White downward arrow (`↓`) centered inside an orange square.

---

## 5. UI Layout & Component Structure

```
+-------------------------------------------------------------+
| [Logo]                                         [:::] Menu   |
|                                                             |
|   +-------+        | L |   01                               |
|   |       |        | i |                                    |
|   | Bulb  |        | g |   Be The Light.                    |
|   | Image |        | h |                                    |
|   +-------+        | t |   The filament is protected...     |
|                    | . |                                    |
+-------------------------------------------------------------+
| [✉]          ▶ facebook    ▶ instagram    ▶ pinterest   [ ↓ ]|
+-------------------------------------------------------------+
```

### 1. Header (Fixed top, padded 32px 48px)
* **Left**: Brand logo mark (~24px height).
* **Right**: Flex row containing the orange dot matrix icon and "Menu" text.

### 2. Main Content (Two-Column Grid)
* **Left Column**: Contains the hanging bulb asset extending from the top frame.
* **Center Divider**: Vertical watermark text "Light Bulb." oriented bottom-to-top (`transform: rotate(-90deg)`), positioned right of the bulb.
* **Right Column**: Left-aligned stack:
  1. `01` (Margin-bottom: 8px)
  2. `Be The Light.` (Margin-bottom: 24px)
  3. Body description paragraph.

### 3. Footer Bar (Fixed bottom, height 56px, background `#1A1C20`)
* **Left Anchor**: Mail envelope icon centered over 64px width.
* **Center Group**: Inline flex links (`facebook`, `instagram`, `pinterest`) preceded by orange `▶` bullets, spaced ~40px apart.
* **Right Anchor**: Square CTA container (`56px × 56px`), background `#F05A28`, containing a white down arrow (`↓`).
