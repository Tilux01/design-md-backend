# UI/UX Specification & Design System: Crystal Jellyfish Website

## 1. Overview & General Principles
- **Layout Type:** Full-screen immersive web application/landing page.
- **Theme:** Dark, deep-sea aesthetic dominated by glowing bioluminescent blues and stark white typography.
- **Core Philosophy:** Minimalist, content-forward layout utilizing asymmetrical grid placement, heavy negative space, and floating 3D/rendered visual elements.

---

## 2. Color Palette

| Role | Color Name | Hex Code / Description | Usage |
| :--- | :--- | :--- | :--- |
| **Primary Background** | Abyss Blue | `#04091A` (Deep dark blue/black) | Full viewport background |
| **Surface/Accents** | Bioluminescent Cyan | `#22B2FE` to `#0A42B6` (Gradient) | Jellyfish models, glow effects |
| **Text Primary** | Pure White | `#FFFFFF` | Headings, primary titles |
| **Text Secondary** | Muted Ice Blue | `#A5B4D4` | Body text paragraphs, secondary navigation |
| **Navigation Active** | Active White | `#FFFFFF` with underline/border | Current selected state in nav |

---

## 3. Typography & Font Stack

### Font Families
- **Primary Heading Font:** *Clash Display* / *Cabinet Grotesk* (Geometric, bold, heavy sans-serif with distinct unique cuts).
  - *Fallback Stack:* `'SF Pro Display', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif`
- **Body & Navigation Font:** *Inter* / *Plus Jakarta Sans* (Clean, highly legible geometric sans-serif).
  - *Fallback Stack:* `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`

### Typography Scale & Hierarchy

| Element | Font Size | Line Height | Weight | Color |
| :--- | :--- | :--- | :--- | :--- |
| **Main Heading** (`<h1>`) | `64px` (Fluid up to `80px`) | `1.05` | `700` (Bold) | `#FFFFFF` |
| **Navigation Items** | `14px` | `1.2` | `500` (Medium) | `#FFFFFF` / `#A5B4D4` |
| **Body Copy** | `15px` | `1.6` | `400` (Regular) | `#A5B4D4` |

---

## 4. Layout & Component Breakdown

### A. Top Navigation Bar
- **Position:** Fixed / Absolute at the top (`z-index: 100`).
- **Structure:**
  - **Left Group:** Breadcrumbs / Context indicators (`Project > Page`).
  - **Right Group:** Search icon (`🔍`) and Window Controls (macOS style window utility buttons).

### B. Secondary Sub-Navigation (Header Menu)
- **Items:** `Species` (Active), `Care`, `Facts`, `Art`, `Community`, `Shop`.
- **Styling:**
  - Centered or left-aligned horizontal flex container below the primary bar.
  - Generous spacing (`32px` gap between items).
  - Hover state: Slight brightness shift to `#FFFFFF`.

### C. Hero Section (Main Content Area)
- **Layout Grid:** 2-Column asymmetric layout (60% text content left, 40% visual composition right).
- **Left Column (Text Content):**
  - Title: **"Crystal Jellyfish"** (Stacked into two lines, tight letter-spacing, slight drop-shadow or text-glow for depth).
  - Body Text Box: Constrained max-width (`~400px`), placed directly below the header.
    *Content:* *"The Crystal Jellyfish, scientifically known as Aequorea victoria, is a captivating and translucent jellyfish species that inhabits the coastal waters of the Pacific Ocean. Its ethereal appearance and gentle pulsating movements make it a mesmerizing sight to behold..."*
- **Right Column (Visual / 3D Composition):**
  - Features multiple high-resolution 3D renders or photography assets of glowing blue jellyfish floating at varying depths (creates parallax/depth of field).
  - Main jellyfish positioned prominently toward the top right, with smaller specimens drifting downwards.

---

## 5. Micro-Interactions & Animations

1. **Floating Animation (Jellyfish Assets):**
   - Continuous, slow vertical translation (sine-wave motion) combined with subtle scaling to simulate water currents.
   - CSS Example: `animation: float 6s ease-in-out infinite;`
2. **Cursor Interaction:**
   - Custom custom cursor or subtle light diffusion that follows the cursor across the dark background to mimic bioluminescence.
3. **Hover States on Nav:**
   - Smooth color transition (`0.2s ease`) from `#A5B4D4` to `#FFFFFF`.
