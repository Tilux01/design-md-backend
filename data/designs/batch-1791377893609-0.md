# Design Specification: NEONIX Landing Page (Full Screen Clone)

## 1. Global Layout & Structure
*   **Viewport:** Fullscreen responsive layout (`width: 100vw; height: 100vh;` or `min-height: 100vh;`).
*   **Container Width:** Max-width restricted content with generous horizontal padding (approx. `64px` desktop) to maintain proportional whitespace.
*   **Grid Structure:** Asymmetrical two-column hero setup:
    *   **Left Column (approx. 55% width):** Typography, branding, CTAs, and secondary text blocks.
    *   **Right Column (approx. 45% width):** Immersive hero visual (cyberpunk character portrait) bleeding to the right edge and bottom baseline.

---

## 2. Color Palette
| Color Role | Hex Code / Description | Usage |
| :--- | :--- | :--- |
| **Primary Background** | `#11221c` (Deep Emerald/Pine Green) | Main page background canvas. |
| **Secondary Background** | `#0b1712` (Darker Shade / Bottom Bar) | Footer strip and interactive containers. |
| **Glassmorphism Base** | `rgba(255, 255, 255, 0.05)` to `0.08` | Navigation pill, buttons, icon containers. |
| **Primary Accent (Text/UI)** | `#ffffff` (Pure White) | Headings, active states, key UI icons. |
| **Secondary Accent (Text)** | `#a3b8b1` (Muted Sage Green/Gray) | Paragraphs, inactive nav links, metadata. |
| **Vibrant Neon (Brand/Glow)** | `#ff4d12` (Neon Orange-Red) | Visor highlights, interactive highlights. |
| **Glow Effect** | `rgba(255, 77, 18, 0.4)` | Soft ambient lighting behind neon elements. |

---

## 3. Typography & Font Stack
*   **Primary Font Family (Headings & UI):** `Montserrat`, `Space Grotesk`, or fallback to `sans-serif`.
*   **Body Font Family:** `Inter`, `Roboto`, or fallback to `sans-serif`.

### Hierarchy Rules:
1.  **Logo / Main Heading ("NEONIX"):**
    *   Font Size: `clamp(48px, 6vw, 76px)`
    *   Font Weight: `700` (Bold)
    *   Letter Spacing: Wide tracking (`0.1em` to `0.15em`)
    *   Color: `#ffffff`
2.  **Navigation Links:**
    *   Font Size: `14px`
    *   Font Weight: `400` / `500`
    *   Color: `#a3b8b1` (Active: `#ffffff` inside a rounded pill)
3.  **Hero Paragraph:**
    *   Font Size: `15px`
    *   Line Height: `1.6`
    *   Color: `#a3b8b1`
4.  **Footer Text / Carousel Points:**
    *   Font Size: `12px` / `13px`
    *   Color: `#a3b8b1`

---

## 4. Component Breakdown & Styling

### A. Top Navigation Bar
*   **Position:** Fixed or absolute, top margin `24px` to `32px`.
*   **Left Nav Pill:** 
    *   Container: Rounded pill shape (`border-radius: 50px`), semi-transparent dark backdrop (`rgba(25, 45, 38, 0.6)`), subtle border (`1px solid rgba(255, 255, 255, 0.08)`).
    *   Links: `Home` (wrapped in a solid white pill with dark text `#11221c`), `About`, `Services`, `Clients`. Spacing gap: `24px`.
*   **Right Action Group:**
    *   **Menu Button:** Pill shaped containing "Menu" text and a double-dot icon (`..` or custom icon) on the far right.

### B. Hero Section (Left Content)
*   **Brand Title:** `NEONIX` with crisp tracking.
*   **Subtitle Paragraph:** 
    *   *Text:* "We Innovate. We Secure. We Transform. Step into the future with our cutting-edge solutions."
    *   Max-width constraint: approx. `380px`.
*   **CTA Buttons:**
    *   **Primary Button ("Discover"):** Solid or high-contrast glass pill, dark text or white text with a dual-dot suffix. Hover: Slight lift and brightness increase.
    *   **Secondary Icon Button ("Connect With Us"):** Circular icon button featuring the Discord logo inside a translucent dark circle, paired with label text.

### C. Hero Section (Right Visual)
*   **Imagery:** High-resolution futuristic character rendering (cyberpunk woman with glowing orange visor/glasses and dark bob haircut).
*   **Composition:** Positioned absolutely to the right edge. The vibrant neon orange visor cuts horizontally across the face, casting a realistic warm light gradient onto the skin and dark background.
*   **Subtle Background Details:** Concentric vector/line circles faintly etched into the dark green background behind the portrait to add depth.

### D. Bottom Control / Footer Bar
*   **Layout:** Fixed to the bottom edge (`height: 80px`), divided into distinct functional zones with thin vertical separators (`1px solid rgba(255, 255, 255, 0.1)`).
*   **Zone 1: Play Trailer**
    *   Circular play button icon with white fill/background and a dark arrow.
    *   Label: `PLAY TRAILER` (Uppercase, tracked, small font).
*   **Zone 2 & 3: Carousel / Feature Points (1 & 2)**
    *   **Item 1:** Circular badge with number `1`, followed by short descriptive text: *"To deliver innovative and secure digital solution, empowering businesses to excel and adapt in a rapidly evolving technological world."*
    *   **Item 2:** Circular badge with number `2`, followed by short descriptive text: *"To be a global leader in digital innovation, transforming technology into seamless, secure experiences that enhance human potential worldwide."*
    *   Includes a navigational right arrow icon (`->`) to indicate scrolling/paging.
*   **Zone 4: Social Media Icons**
    *   Circular outlined icon buttons for **Facebook (f)**, **LinkedIn (in)**, **Instagram (camera icon)**, and **X (Twitter - X)**.
    *   Hover state: Border and icon color shift to bright white or neon orange.

---

## 5. Animations & Interactive States (CSS / JS Guidelines)

1.  **Page Load Entrance:**
    *   *Fade-In Up:* Hero text elements slide up from `y: 20px` to `0` with an opacity transition from `0` to `1` over `0.8s` with an `ease-out` cubic-bezier curve.
    *   *Image Reveal:* The right-side portrait scales up subtly from `0.98` to `1` with a smooth fade.
2.  **Hover Transitions:**
    *   All buttons and interactive pills transition smoothly (`transition: all 0.3s ease`).
    *   Social icons scale up slightly (`transform: scale(1.08)`) on hover.
3.  **Neon Glow Pulse (Optional Subtlety):**
    *   The orange visor on the character can feature a soft box-shadow pulse animation to emulate a glowing light source.
