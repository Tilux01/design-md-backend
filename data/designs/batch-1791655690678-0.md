# Design Specification: Mobile App UI Clone

## 1. Global Layout & Canvas Specifications
*   **Target:** Full-screen responsive viewport (no device bezels or decorative background blobs from the original display mockups; clean flat surface).
*   **Color Palette:**
    *   **Primary Dark Blue:** `#0B2545` (Headers, active states, user banner)
    *   **Secondary Dark Blue / Accent:** `#133863` (Icons, primary buttons)
    *   **Background Light:** `#F5F7FA` (Main screen background)
    *   **Card Background White:** `#FFFFFF` (Content containers)
    *   **Subtle Card Surface:** `#EBF0F7` / `#EDF2F7` (Secondary interactive elements/cards)
    *   **Text Dark Primary:** `#1A202C`
    *   **Text Muted Secondary:** `#718096`
    *   **Progress Fill Blue:** `#1A365D`
    *   **Progress Track Gray:** `#E2E8F0`
*   **Typography (Font Family):**
    *   **Primary Font:** *Inter* (Google Fonts)
    *   **Fallback Stack:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
*   **Layout Structure:** Two distinct mobile screens presented side-by-side (Left: **Home Screen**, Right: **Profile Screen**). Both share identical width, border radii (`36px`), and elevation drop shadows (`0px 12px 32px rgba(11, 37, 69, 0.12)`).
