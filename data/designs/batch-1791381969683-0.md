# Part 1: Design Specification (`design.md`)

## 1. Overview
* **Page Type:** Product Landing Page / Hero Section
* **Theme/Vibe:** Vibrant, fresh, modern, fruity, playful.
* **Layout:** Fullscreen (100vw × 100vh), centered focal product, asymmetric decorative elements (floating strawberries), typography split by the product can.

## 2. Color Palette
| Color Name | Hex Code | Usage |
| :--- | :--- | :--- |
| **Primary Pink/Red (Background)** | `#E62752` to `#D11942` | Linear gradient background |
| **Pure White** | `#FFFFFF` | Main typography ("STRAWBERRY"), navigation links, buttons |
| **Can Accent Pink** | `#FF4B72` | Can highlights |
| **Strawberry Natural Tones** | `#D43838`, `#2ECC71` | Strawberries (red bodies, green leaves) |

## 3. Typography & Fonts
* **Brand Logo ("Fruite"):** 
  * *Font Family:* `Pacifico`, `Brush Script MT`, or cursive fallback.
  * *Style:* Italicized script, white.
* **Navigation Links ("Home", "Shop", "Contact", "Choose Your Favorite Beer"):**
  * *Font Family:* `Inter`, `Helvetica Neue`, sans-serif.
  * *Weight:* Regular / Medium.
* **Main Heading ("STRAWBERRY"):**
  * *Font Family:* `Montserrat`, `Arial Black`, sans-serif.
  * *Weight:* Extra-Bold / 900.
  * *Tracking/Letter-spacing:* Wide (approx. `0.05em`).
  * *Effect:* Split down the middle by the centered soda can.

> **Fallback Stack:** `font-family: 'Montserrat', 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;`

## 4. Layout & Positioning
* **Background:** Fullscreen immersive block with a subtle radial or vertical gradient.
* **Header:** Flexbox row with Space-Between layout.
  * Left: Brand logo ("Fruite").
  * Center: Nav links (`Home`, `Shop`, `Contact`).
  * Right: Call-to-action button/link (`Choose Your Favorite Beer 🥤`).
* **Hero Centerpiece:** 
  * Absolute or Flex centered soda can (`width: ~220px`).
  * Large white text `STRA` positioned to the left of the can.
  * Large white text `ERRY` positioned to the right of the can.
* **Floating Elements (Strawberries):**
  * Scattered across the screen with randomized rotation angles (`transform: rotate()`) to create depth and a playful organic feel.

## 5. Micro-Interactions & Animations
* **Float Animation:** Gentle up-and-down floating keyframe animation applied to the central can and scattered strawberries (using CSS `@keyframes float`).
* **Hover States:** Nav items scale up slightly (`scale(1.05)`) and brighten on hover.
