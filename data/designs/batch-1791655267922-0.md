# UI Design Specification: Fitness & Wellness Mobile App ("Hadi")

This document provides a comprehensive design specification to create an exact, pixel-perfect clone of the provided mobile application interface.

---

## 1. Global Layout & Canvas

*   **Platform:** iOS (iPhone with Dynamic Island / Face ID notch layout).
*   **Screen Type:** Full-Screen mobile view (Frame/device mockup background removed).
*   **Orientation:** Portrait.
*   **Background Color:** `#F3F4F6` (Light off-white/gray canvas).
*   **Border Radius (Outer App Container):** `40px` (if rendered inside a device frame, otherwise edges flow full-bleed to screen bounds).
*   **Padding / Margins:** 
    *   Horizontal Screen Padding: `24px`.
    *   Vertical Top Padding: Status bar area (~`44px`), content starts at ~`60px`.

## 4. Summary Checklist for Implementation

1. **Canvas:** Set background to `#F3F4F6`.
2. **Typography:** Implement SF Pro font family with exact font sizes and weights specified.
3. **Card Radius:** Apply generous rounding (`20px` to `24px`) across all content cards to match modern iOS card-stack design patterns.
4. **Icons & Images:** 
   * Avatar: Circular cropped image of the user.
   * Dumbbell: 3D-styled grayscale metallic dumbbell illustration without background.
   * Navigation: Floating glassmorphism tab bar with active black pill indicator on the Home tab.
