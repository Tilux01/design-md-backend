# UI/UX Specification: E-Commerce Product Showcase Landing Page

## 1. Global Layout & Structure

*   **View Type:** Full-screen responsive web application landing page.
*   **Canvas/Background:** Solid crisp white (`#FFFFFF`) occupying 100% width and 100% height. No outer decorative device mockups or backdrop padding—full viewport implementation.
*   **Layout Architecture:** 
    *   Fixed Header at the top (Navigation, Brand, Utilities).
    *   Asymmetrical Multi-Column Body:
        *   Left Column: Vertical navigation list and category filter (`SEARCH`, `ACCESSORIES`, `BAG`, `CLOTHING`, `SHOES`, `Sneakers`).
        *   Center Column: Primary interactive 3D/rendered product showcase with blurred carousel items flanking left and right, brand typography, and call-to-action button.
        *   Top-Right Column: Layout grid/view toggles and localization.

---

## 2. Typography & Fonts

### Primary Font Stack
*   **Primary Typeface:** **Helvetica Neue**, **Arial**, or a geometric sans-serif heavy grotesque style (e.g., *Akzidenz-Grotesk*, *Inter*, or *Roboto* with heavy weights).
*   **Fallback Stack:** `sans-serif`

### Hierarchy & Specifications

*   **Header Navigation Links (MEN, WOMAN, SSENSE, WISHLIST, BLOG):**
    *   Font Family: Geometric Sans-Serif
    *   Font Weight: Medium / Semi-Bold (`500` or `600`)
    *   Font Size: `12px` - `14px`
    *   Letter Spacing: Wide / Expanded (`1.5px` to `2px`)
    *   Text Transform: Uppercase
    *   Color: Charcoal/Black (`#111111`)
    *   Brand Centerpiece ("SSENSE"): Bold, extra-spaced, slightly larger (`16px`).

*   **Left Vertical Menu (ACCESSORIES, BAG, CLOTHING):**
    *   Font Family: Sans-Serif
    *   Font Weight: Regular / Light (`300` or `400`)
    *   Font Size: `18px` - `20px`
    *   Letter Spacing: Normal to Wide
    *   Text Transform: Uppercase
    *   Color: Muted Gray (`#999999`)

*   **Active Left Menu Item (SHOES):**
    *   Font Family: Sans-Serif
    *   Font Weight: Bold / Heavy (`800`)
    *   Font Size: `22px` - `24px`
    *   Text Transform: Uppercase
    *   Color: Pitch Black (`#000000`)

*   **Sub-Menu Item (Sneakers):**
    *   Font Family: Sans-Serif
    *   Font Weight: Regular (`400`)
    *   Font Size: `11px` - `12px`
    *   Color: Dark Gray (`#666666`)
    *   Text Underline: Subtle single pixel border baseline.

*   **Product Brand Title (GUCCI):**
    *   Font Family: Condensed Heavy Sans-Serif (e.g., *Impact*, *Oswald*, or compressed *Helvetica Neue Bold*)
    *   Font Weight: Ultra-Bold / Black (`900`)
    *   Font Size: `36px` - `42px`
    *   Text Transform: Uppercase
    *   Letter Spacing: Moderate tracking (`1px`)
    *   Color: Pitch Black (`#000000`)

*   **Product Details (Crystals Flashtrek Sneakers | 1590$):**
    *   Font Family: Sans-Serif
    *   Font Weight: Regular (`400`)
    *   Font Size: `12px` - `13px`
    *   Color: Mid-Gray (`#666666`)

---

## 3. Component Breakdown

### A. Header Section
*   **Position:** Fixed top, spanning full width with generous horizontal padding (`40px` to `60px`).
*   **Left Elements:** `MEN`, `WOMAN` (spaced evenly).
*   **Center Element:** `SSENSE` (Wordmark, heavily tracked uppercase).
*   **Right Elements:** `WISHLIST`, `BLOG`, Search icon, Profile/User icon, Language selector (`En`).

### B. Left Sidebar (Navigation & Search)
*   **Top Component:** Search indicator with magnifying glass icon and text label `RECHERCHER`.
*   **Vertical Menu List:** Stacked vertically with tight line height. Non-active items are styled in lighter gray tones; active item (`SHOES`) is weighted heavily in black, followed by an indented sub-category (`Sneakers`).

### C. Main Visual Display (Center Stage)
*   **Primary Image (Gucci Crystals Flashtrek Sneakers):**
    *   *Visual Description:* A floating, high-end 3D product render of a chunky designer sneaker. The shoe features a rich color palette containing burgundy/red leather panels, mustard-yellow accents, a thick multi-layered grey and cream lugged sole, and an ornate removable elastic strap encrusted with multi-colored reflective crystals/jewels across the laces. The shoe is angled dynamically in mid-air.
*   **Secondary/Carousel Flanking Images:**
    *   *Visual Description:* Two blurred, out-of-focus background variations of sneakers (one on the lower-left, one on the right) displayed at dynamic diagonal angles to simulate a 3D carousel depth-of-field effect.

### D. Product Information & Call-To-Action (Bottom Center)
*   **Typography Block:** Centered directly below the main 3D product showcase. Features the brand name `GUCCI` in bold condensed lettering, followed by the specific model and price (`Crystals Flashtrek Sneakers | 1590$`).
*   **Button Component ("SEE MORE"):**
    *   Shape: Pill-shaped capsule (fully rounded corners).
    *   Background Color: Semi-translucent light gray (`#E5E5E5`).
    *   Text: `SEE MORE` (Uppercase, medium weight, dark gray text).
    *   Shadow: Soft, diffused drop-shadow underneath (`rgba(0, 0, 0, 0.08)`).

### E. Top-Right Utilities
*   **View Toggle Icons:** Two small square icon buttons (grid view / list view indicators) positioned neatly above the main viewport area.

---

## 4. Color Palette

*   `#FFFFFF` (Pure White) - Background
*   `#000000` (Pitch Black) - Primary text, active states, brand highlights
*   `#666666` (Dark Gray) - Subtitles, secondary text, search labels
*   `#999999` (Muted Gray) - Inactive menu categories
*   `#E5E5E5` (Light Gray) - CTA button background
*   *Product Specific:* Burgundy Red, Mustard Yellow, Cream, Multi-colored crystal jewel tones (as rendered within the central product photography).

---

## 5. Responsive Behavior & Interactions
*   **Hover States:** 
    *   Navigation links transition smoothly to full black text color.
    *   The "SEE MORE" button darkens slightly on hover (`#D0D0D0`) with a subtle elevation shift.
*   **Layout Scaling:** 
    *   On smaller viewports, the side navigation collapses into a hamburger menu, and the flanking blurred carousel items hide to prioritize the central product view.
