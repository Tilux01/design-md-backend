# UI/UX Specification: HR & Team Management Dashboard ("MILKISS")

## 1. Global Layout & Canvas

*   **Canvas Type:** Full-screen responsive web dashboard layout (no wrapper/device frame shadows in production output).
*   **Dimensions & Prototyping:** Designed for a wide screen view (approx. 1440px desktop standard).
*   **Border Radius:** The main container utilizes a smooth `24px` to `32px` rounded corner profile with a subtle inner border highlight.
*   **Grid System:** 12-column flexible structural grid with generous spacing (`20px` to `24px` gutter gaps).

---

## 2. Color Palette

*   **Backgrounds:**
    *   *App Canvas Base:* Soft gradient blend from ice-blue/cyan `rgba(215, 235, 245, 0.9)` at the top-left to crisp white/light gray `#F0F4F8` and pale cyan `#DCEFF5` at the bottom-right.
    *   *Card Backgrounds:* Semi-translucent white with backdrop blur (`background: rgba(255, 255, 255, 0.7); backdrop-filter: blur(12px);`).
    *   *Dark Interactive Elements:* Deep charcoal/slate black `#1C1E22`.
*   **Brand / Accent Colors:**
    *   *Cyan / Sky Blue:* `#5CE1E6` (Used for progress fills, highlights, and active badges).
    *   *Soft Neutral Gray (Text/Borders):* `#8C93A0` (Secondary text), `#E2E6EC` (Dividers).
*   **Status & Feedback Colors:**
    *   *Success (Checked items):* `#5CE1E6` checkmarks inside dark card interfaces.

---

## 3. Typography & Fonts

*   **Primary Font Family:** `Inter`, `SF Pro Display`, `-apple-system`, BlinkMacSystemFont, `Segoe UI`, Roboto, sans-serif.
*   **Fallback Stack:** System sans-serif fonts.
*   **Typography Hierarchy:**
    *   *Main Header ("Welcome in, Olga"):* `32px`, Semibold (Weight: 600), Line height: `1.2`, Color: `#1C1E22`.
    *   *Card Titles ("Progress", "Time tracker", "Onboarding"):* `16px`, Medium (Weight: 500), Color: `#1C1E22`.
    *   *Metric Numbers (e.g., "78", "56", "203"):* `36px` to `48px`, Bold (Weight: 700), Color: `#1C1E22`.
    *   *Body / Metadata Text:* `13px` to `14px`, Regular (Weight: 400), Color: `#68707C`.
    *   *Small Caps / Labels ("Employe", "Hirings", "Projects"):* `11px`, Medium (Weight: 500), Uppercase/Capitalized tracking, Color: `#68707C`.

---

## 4. Header & Navigation

*   **Logo Area:**
    *   Pill-shaped badge containing the text "MILKISS" inside a crisp white border container. Rounded pill radius: `20px`. Font: Bold sans-serif `13px`.
*   **Navigation Menu:**
    *   Pill-shaped segmented control navbar (`background: rgba(255, 255, 255, 0.5)`).
    *   *Tabs:* **Dashboard** (Active state styled with dark pill fill `#1C1E22` and white text), People, Hiring, Devices, Apps, Salary, Calendar, Reviews.
*   **Top Right Utilities:**
    *   **Setting Button:** Circular white button with gear icon (`#1C1E22`).
    *   **Notification Icon:** Circular white button with bell outline.
    *   **User Avatar Profile:** Circular user profile thumbnail placeholder.
