# UI/UX Design Specification: Mobile App Clone

## Global Design Tokens

*   **Background (Canvas):** Pure White (`#FFFFFF` or `#F9F9F9` depending on the device frame context, but standard canvas is `#FFFFFF`).
*   **Neutral Dark (Primary Text/Headings):** Deep Charcoal / Off-Black (`#1A1A1A` or `#222222`).

> *Note: Given the minimalist, editorial aesthetic typical of modern reading/social apps (like Medium or Substack), the typeface family should be a clean, modern **Sans-Serif** (e.g., Inter, SF Pro, or Roboto) for UI elements, paired with a clean **Serif** (e.g., Merriweather, Georgia, or Playfair Display) for article bodies if applicable.*

*   **Primary Font Family (Sans):** `Inter`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, sans-serif.
*   **Fallback Font:** System default sans-serif.

## Screen-by-Screen Breakdown

---

### Screen 1: Onboarding / Welcome Screen (Left)

#### Layout Structure
*   **Alignment:** Left-aligned text content with generous whitespace.
*   **Vertical Flow:**
    1.  Top spacing (generous padding for status bar).
    2.  Main Value Proposition / Hero text block.
    3.  Flexible vertical space.
    4.  Action buttons pinned toward the lower third.

#### Components & Content
1.  **Hero Text Block:**
    *   *Content:* Multi-line welcoming message or app introduction statement (e.g., *"Discover stories, thinking, and expertise from writers on any topic."*).
    *   *Styling:* Large typography, bold emphasis on key phrases.
2.  **Secondary Action (Text Button):**
    *   *Content:* "Skip" or secondary action link.
    *   *Styling:* Centered or left-aligned beneath the primary button, subtle color.
3.  **Primary Action (CTA Button):**
    *   *Content:* "Get Started" or "Continue".
    *   *Styling:* 
        *   Full-width (with horizontal padding around 24px).
        *   Background: Warm Sand (`#EED3B0`).
        *   Border Radius: Fully rounded or slightly curved (approx. 8px - 12px).
        *   Text Color: Dark Charcoal, centered, medium weight.

---

### Screen 2: Feed / Content List View (Middle)

#### Layout Structure
*   **Container:** Vertical scrolling list with separating dividers or card-like separation.
*   **Padding:** Standard mobile horizontal padding (16px to 20px).

#### Components & Content
1.  **List Item 1 (Card Structure):**
    *   **Category/Metadata Tag:** Small uppercase tag at the top (e.g., "TECHNOLOGY" or "DESIGN").
    *   **Article Title:** Bold, 2-line title preview (e.g., *"Understanding the Shift in Modern Architecture and Design"*).
    *   **Snippet/Body:** 2-3 lines of muted body text preview.
    *   **Author Row:** 
        *   *Avatar:* Small circular profile image (backgroundless placeholder or author photo).
        *   *Author Name & Date:* e.g., "Jane Doe • 3 min read".
        *   *Action Icons:* Bookmark / Save icon aligned to the far right.
2.  **List Item 2:**
    *   Similar structure to Item 1, separated by a subtle 1px horizontal divider line (`#EAEAEA`).

---

### Screen 3: Featured Article / Rich Media View (Right)

#### Layout Structure
*   **Container:** Standard detail or rich-media feed item view.
*   **Top Media Banner:** A prominent image container positioned above the text block.

#### Components & Content
1.  **Featured Image (Media Placement):**
    *   *Description:* An editorial-style photograph or illustration depicting abstract objects, machinery, or architectural sketches (rendered in muted monochrome or sepia tones).
    *   *Background:* The image itself is cleanly cropped with rounded corners (approx. 8px radius) and sits on a soft warm-tinted backing card (`#F3EFEA`).
    *   *Rotation/Placement:* Centered horizontally within the card container, maintaining a 16:9 or 4:3 aspect ratio.
2.  **Article Title:**
    *   Bold, prominent headline directly beneath the image.
3.  **Snippet / Body Text:**
    *   Truncated preview text explaining the article content.
4.  **Author Footer:**
    *   Circular avatar on the left.
    *   Author name and publication date.
    *   Interaction buttons (Like/Heart counter, Bookmark icon) aligned horizontally at the bottom right.

## Implementation Checklist for Developers

1. **Remove Frames:** Ensure no device mockups, shadows, or outer background container colors from the screenshot are coded into the final implementation—render purely edge-to-edge UI components.
2. **Spacing Consistency:** Use an 8px grid system for all margins and paddings (`8px`, `16px`, `24px`, `32px`).
3. **Typography Scaling:** Ensure scalable font units (`rem` or `sp`) are used to support accessibility scaling.
4. **Image Assets:** Replace placeholder illustrations with optimized vector graphics or responsive raster images matching the described editorial aesthetics.
