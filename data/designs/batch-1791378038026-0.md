# Design System Specification: "Collection Artic 01" (High-Fashion Winter Apparel E-Commerce)

## 1. Global Foundations

### Color Palette
- **Deep Arctic Blue (Primary Background):** `#1F2C39`
- **Ice Cyan (Accent/UI Borders):** `#8FA8BA`
- **Pure White (Primary Text & Indicators):** `#FFFFFF`
- **Muted Steel Grey (Secondary Text):** `#A3B1BE`
- **Soft Blue Gradient Surface (Product Card Backdrops):** `#4A6075` to `#2C3E50`

### Typography
- **Primary Display Font (Branding, Headings):** `Helvetica Neue`, `Arial`, sans-serif (Geometric, bold, uppercase tracking).
- **Secondary UI / Metadata Font:** `Monaco`, `Courier New`, monospace (Used for brackets `[ CATALOG ]`, prices, sizes, and technical specifications).
- *Fallback Stack:* `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`

### Grid & Layout
- **Container Type:** Fluid full-width (`100vw`) with desktop padding max bounds at `1440px`.
- **Vertical Rhythm:** Modular spacing based on `8px` increments (`8, 16, 24, 32, 48, 64px`).

---

## 2. Header & Navigation Component

### Layout & Structure
- **Positioning:** Fixed / Sticky top bar with a translucent backdrop blur effect (`backdrop-filter: blur(12px)`).
- **Left Region:** Brand Logo (`FRN` typography in stylized gothic-futuristic lettering).
- **Center Region:** Navigation Links enclosed in monospace square brackets (`[ CATALOG ]`, `[ PUFFERS ]`, `[ BOOTS ]`, `[ CATALOG ]`, `[ PUFFERS ]`).
- **Right Region:** Search icon button and Cart icon button (`914px, 57px` grid alignment).

### States
- **Default:** White text at `70%` opacity.
- **Hover:** `100%` opacity with smooth color transition (`0.2s ease`).

---

## 3. Hero Section (Collection Artic 01™)

### Composition
- **Background:** High-altitude mountain snowy backdrop overlaid with heavy atmospheric blue gradients and large subtle background typography (`[ SERIES: STASIS MK.I ]`).
- **Hero Model:** Large centered portrait of a model wearing an oversized reflective silver puffer jacket with goggles and hood up.
- **Left Column Data:**
  - Subtitle: `[ SERIES: STASIS MK.I ] [ SERIES ]`
  - Main Title: **COLLECTION ARTIC 01™** (Extra bold, uppercase, tight leading).
  - Size Selector: Horizontal row of text items (`S`, `M`, `L`, `XL`) with active state underline.
  - Color Selector: `WHITE`, `SILVER`.
  - Action Block: Circular interactive arrow button (`↗`) paired with an **"ADD TO CART / $899.99"** action block.
- **Right Column Carousel Previews:** Two smaller image frames (`01 / 07`) showing alternate angles/products with active thumbnail indicators.
- **Footer Socials:** Absolute positioned small icon links at bottom right (`Instagram`, `Facebook`, `Twitter`).

---

## 4. "New Collection" Section

### Header Bar
- **Title:** `NEW COLLECTION` (Bold serif/sans display).
- **Metadata Sub-tags (Right Aligned):** 
  `[ NEW COLLECTION ]`
  `[ SERIES_01 ]`
  `[ PUFFERS ]`
  `[ PUFFER JACKETS / METAL EDITION / GLOSS SERIES / EXTREME COLD LINE ]`
- **Filters Button:** Outlined pill-shaped button labeled `[ FILTERS ]`.

---

## 5. Product Grid Component

### Grid Layout
- **Top Featured Split Grid (Aurora Puffer):** 
  - Left card: Large atmospheric editorial lifestyle shot with "AURORA™" watermark, price `$1,999`, and explore arrow.
  - Right 3 Columns: Individual full-length model looks (Aurora Silver, Orbit Silver, Stealth Black) set against soft grey-blue cards with dark borders.
- **Bottom Standard Grid (5-Column Row):** 
  - Items: Glacier White, Polar Gloss, Stealth Black, Icefield Blue, Polar White.
  - Card Structure:
    - **Image Container:** Soft grey-blue rounded card with centered full-body studio photography.
    - **Product Information:** 
      - Product Title (e.g., `GLACIER WHITE`, `INSULATED PUFFER JACKET`)
      - Color Option Radio Bullets (e.g., `● GREY`, `○ BLUE`)
      - Price (e.g., `$1,299.99`)

---

## 6. Micro-Interactions & Animations

### Hover Effects
- **Product Cards:** Image scales up by `3%` with a smooth cubic-bezier transition (`transform 0.4s cubic-bezier(0.16, 1, 0.3, 1)`).
- **Buttons / CTA:** Background color shifts subtly; cursor changes to pointer.
- **Carousel Controls:** Active numbers (`01 — 07`) animate line width dynamically as items cycle.

---

## 7. Responsive Breakpoints Strategy
- **Desktop (`> 1200px`):** Full multi-column grid layout as displayed in the master wireframe.
- **Tablet (`768px - 1199px`):** Grid collapses from 5 columns to 3 columns; hero switches to stacked view.
- **Mobile (`< 767px`):** Single-column vertical stack; horizontal navigation collapses into a hamburger drawer menu; monospace category brackets remain centered.
