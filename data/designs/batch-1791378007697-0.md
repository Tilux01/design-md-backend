# UI/UX Specification & Design System: "Daylog" E-Commerce Application

This document provides a comprehensive, production-ready specification for a high-end, dark-themed e-commerce interface ("Daylog"). It is optimized for tablet/desktop displays and translates the provided visual artifact into a scalable design system and layout specification.

---

## 1. Global Design Tokens & Theme Configuration

### Color Palette
The interface utilizes a sophisticated "Neumorphic Dark" aesthetic characterized by deep charcoal/obsidian surfaces, subtle gradient overlays, and warm champagne/gold accents.

| Token Name | Hex Value | Usage / Description |
| :--- | :--- | :--- |
| **`bg-primary`** | `#121214` | Main application background (deep charcoal/black) |
| **`surface-sidebar`** | `#18181b` | Left-hand navigation panel background |
| **`surface-card`** | `#1e1e24` | Elevated card surfaces (product containers, banners) |
| **`surface-card-active`** | `#26262e` | Active state for selected cards/categories |
| **`accent-gold`** | `#c5a059` | Primary brand accent, CTA backgrounds, active indicators |
| **`accent-gold-hover`**| `#d4af37` | Hover state for gold buttons |
| **`text-main`** | `#ffffff` | Primary headings, active text, prices |
| **`text-secondary`** | `#8e8e93` | Body copy, descriptions, inactive navigation labels |
| **`border-subtle`** | `rgba(255, 255, 255, 0.08)`| Subtle structural dividers and borders |
| **`shadow-depth`** | `0 16px 32px rgba(0,0,0,0.6)`| Deep drop shadows for layered glassmorphic/neumorphic look |

### Typography System
*Note: If the primary luxury serif/sans-serif fonts are unavailable, fallback websafe stacks are provided.*

* **Primary Heading Font (Serif):** 
  * *Stack:* `Playfair Display`, `Cormorant Garamond`, `Georgia`, `serif`
  * *Usage:* Product titles, major section headings ("Beige Trench Coat", "Spring Collection 2024").
* **Secondary Font (Sans-Serif):** 
  * *Stack:* `Inter`, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `sans-serif`
  * *Usage:* Navigation, metadata, prices, buttons, descriptions.

#### Typographic Scale
* **App Title ("Daylog"):** Serif, `22px`, Medium (Weight 500), tracking: `0.02em`.
* **Category Header ("Women"):** Serif, `28px`, Semi-Bold (Weight 600).
* **Product Hero Title:** Serif, `36px`, Light/Regular (Weight 400), Line Height: `1.1`.
* **Section Header ("You May Also Like"):** Serif, `18px`, Medium (Weight 500).
* **Body / Description:** Sans-Serif, `13px`, Regular (Weight 400), Line Height: `1.5`, Color: `text-secondary`.
* **Price / Callouts:** Sans-Serif, `16px`, Semi-Bold (Weight 600), Color: `text-main`.
* **UI Labels (Sizes, Nav):** Sans-Serif, `12px`, Medium (Weight 500).

## 2. Layout Structure & Grid System

The viewport is structured into a fluid, multi-column flex/grid application layout spanning **100% width and height** (omitting any outer device bezels).

```
+---------------------------------------------------------------------------------+
| [Sidebar (260px)]  | [Header: Search Bar, Wishlist, Cart]                       |
|                    +------------------------------------------------------------+
|                    | [Hero Product Card (Split View: Details + 3D Render/Image)] |

|                    +------------------------------------------------------------+

+---------------------------------------------------------------------------------+
```

## 3. Component Specifications

### 3.1. Left Sidebar Navigation (`surface-sidebar`)
* **Width:** Fixed `260px`, full height.
* **Top Section:** 
  * Hamburger menu icon (left) paired with Brand Logo *"Daylog"* (Serif).
* **Category Switcher ("Women"):**
  * Active indicator: A small horizontal gold line (`accent-gold`) beneath the active category.
* **Navigation List Items:**
  * Each item features a rounded icon container (circular avatar) + label.
  * **Active State:** `"Outerwear"` features an active pill background (`surface-card-active`), glowing border, and right chevron (`>`).
  * **Items:** New In, Dresses, Tops, Outerwear (Active), Pants, Shoes, Bags, Accessories.
* **Bottom Promotional Card ("Spring Collection 2024"):**
  * Embedded dark card with a background thumbnail of a model.
  * Overlay text: "Spring Collection 2024".
  * Action: "EXPLORE NOW >" text link with underline animation capability.

### 3.2. Top Navigation Bar
* **Search Bar:**
  * Pill-shaped container (`surface-card`), border `border-subtle`.
  * Placeholder text: "Search for products..." with a magnifying glass search icon on the right.
* **Utility Icons:**
  * Wishlist Icon (Outline heart).
  * Cart Icon (Shopping bag outline) with a badge count indicator `2` in a gold circle.

### 3.3. Hero Product Showcase Card
* **Container:** Large elevated card (`surface-card`), rounded corners (`16px`), featuring a radial dark-gold ambient background gradient to highlight the product.
* **Left Column (Text Content):**
  * *Badge:* "New Arrival" (Small uppercase sans-serif, muted gold text).
  * *Title:* "Beige Trench Coat" (Large Serif).
  * *Description:* "Timeless and elegant trench coat with a flattering fit. Perfect for any season and occasion." (`text-secondary`).
  * *Price:* `$129.99` (Prominent, bold).
  * *Color Swatches:* Three interactive circular color selectors (Beige selected with outer ring, Charcoal, Dark Navy).
  * *Size Selector:* Horizontal pills for `S`, `M` (Selected - Gold background), `L`, `XL`.
* **Right Column (Visual Asset):**
  * High-res cutout product image of the beige belted trench coat.
  * Floating action buttons overlaid on the image:
    * Top Right: 360-degree view icon.
    * Bottom Right: Quick-save / Favorite heart icon (circular gold container).

### 3.4. Carousel / "You May Also Like" Section
* **Header:** "You May Also Like" with a right pagination chevron (`>`).
* **Product Cards (4 visible items):**
  1. Wool Blend Coat (`$159.99`)
  2. Oversized Blazer (`$89.99` - Active/Selected border state)
  3. Knit Sweater (`$49.99`)
  4. Pleated Skirt (`$59.99`)
* **Card Anatomy:**
  * Dark rounded surface (`surface-card`).
  * Product thumbnail image filling the top 75% of the card.
  * Title and Price left-aligned at the bottom.
  * Favorite heart toggle icon in the bottom-right corner of each card.

### 3.5. Trust Badges / Value Proposition Bar
* Horizontal layout displaying three icons with descriptive text:
  1. **Free Shipping** (Truck icon) — *On orders over $100*
  2. **Easy Returns** (Refresh/Exchange icon) — *30-day return policy*
  3. **Secure Payment** (Shield/Check icon) — *100% protected*

### 3.6. Action Bar (Bottom Floating CTAs)
* **Primary Add to Bag Button:**
  * Wide pill button filled with `accent-gold`.
  * Text: "ADD TO BAG" with a shopping bag icon. Hover state brightens to `accent-gold-hover`.
* **Secondary Buy Now Button:**
  * Wide pill button filled with `surface-card-active` and subtle border.
  * Text: "BUY NOW" in bold white typography.

## 4. Animation & Interaction Specifications

1. **Micro-Interactions (Hover States):**
   * **Cards:** Scale up slightly (`transform: scale(1.01)`) with an intensified drop shadow on hover.
   * **Buttons & Swatches:** Smooth color transition (`transition: all 0.25s ease-in-out`). Selected size pills instantly swap to gold backgrounds with dark text.
2. **Horizontal Scrolling:**
   * The "You May Also Like" section supports smooth momentum-based horizontal touch/wheel scrolling with hidden scrollbars.
3. **Page Transitions:**
   * Selecting items from the sidebar triggers a fade-and-slide transition on the main content area (`opacity: 0 -> 1`, `translateY: 8px -> 0`).
