# UI/UX Specification: "Noir Essence" E-Commerce Landing Page (Exact Clone)

## 1. Global Layout & Viewport Strategy
* **Target Viewport:** Full-screen browser window (1440px+ desktop optimized, fluid down to 768px). 
* **Frame Removal:** Exclude all operating system browser frames, window tabs, and physical desktop surfaces seen in the reference image. The output must represent the pure viewport content.
* **Layout Structure:** Single-page absolute/flex container, fixed-position header navigation, centered hero showcase, and off-canvas/horizontal product carousel overflow below the fold.

---

## 2. Color Palette & Theming (CSS Variables)
Derived directly from the dark, high-end luxury aesthetic of the reference:

| Role | Color Name | Hex Code / RGBA | Usage |
| :--- | :--- | :--- | :--- |
| **Primary Background** | `Void Black` | `#0b0b0d` | Base page background gradient endpoint |
| **Surface Gradient** | `Dark Slate` | `linear-gradient(135deg, #161619 0%, #08080a 100%)` | Main section backgrounds |
| **Primary Accent** | `Rosewood Red` | `#6b1d2f` | Liquid content in perfume bottle, petal tint |
| **Secondary Accent** | `Champagne Gold` | `#d4af37` to `#b38f27` | Brand logotype, CTAs, highlight text |
| **Neutral Text** | `Pure White` | `#ffffff` | Primary headings |
| **Subtext/Muted** | `Muted Smoke` | `#a1a1aa` | Secondary body text, nav links |
| **Interactive Glow** | `Gold Glow` | `rgba(212, 175, 55, 0.25)` | CTA hover states and focus rings |

---

## 3. Typography & Font Stack
The design relies on a pairing of an elegant high-contrast serif for headings and a clean modern sans-serif for UI elements.

### Primary Heading Font (Serif)
* **Target Font:** *Cinzel* or *Playfair Display* (Fallback: `Georgia`, `Times New Roman`, `serif`)
* **Usage:** "Noir Essence", main product titles, section headers.

### Secondary/UI Font (Sans-Serif)
* **Target Font:** *Montserrat* or *Inter* (Fallback: `Helvetica Neue`, `Arial`, `sans-serif`)
* **Usage:** Navigation links, body copy, button labels, sub-branding tags ("LUXURY PERFUMERY").

```css
:root {
  --font-serif: 'Playfair Display', Georgia, serif;
  --font-sans: 'Montserrat', -apple-system, BlinkMacSystemFont, sans-serif;
}
```

---

## 4. Detailed Component Breakdown

### A. Header / Navigation Bar (`<header>`)
* **Position:** Fixed to the top, sticky with a subtle backdrop blur (`backdrop-filter: blur(10px)`).
* **Left:** Brand Logo
  * Text/Mark: **BIURENCE**
  * Font: *Montserrat*, 700 weight, tracked out (`letter-spacing: 2px`), Color: White with a subtle gold accent dot/icon to the left.
* **Center:** Navigation Links
  * Items: `Home`, `Shop/App`, `About`, `Products`, `Contact`
  * Font: *Montserrat*, 400 weight, 14px, Color: `#a1a1aa`.
  * Hover State: Smooth color transition to `#ffffff` with a subtle bottom underline indicator.
* **Right:** Utility Icons
  * Icons (SVG stroked in white, 20px size): 
    1. Search (Magnifying glass)
    2. User/Profile
    3. Shopping Bag / Cart (with dynamic counter badge set to `0` or `1`).

---

### B. Hero Section (`<section class="hero">`)
* **Background:** Deep radial gradient centered behind the perfume bottle, transitioning from `#1f171c` (deep plum-black) at the core to `#0b0b0d` at the edges.
* **Decorative Elements (Floating Petals & Dust):**
  * **Dark Rose Petals:** Approximately 15–20 distinct SVG or high-res PNG dark maroon/black rose petals scattered across the screen in varying sizes (20px to 80px) and rotations.
  * **Particle Dust:** Subtle golden dust specs scattered across the z-index layer behind the bottle to mimic ambient lighting.

#### Typography & Copy Hierarchy:
1. **Sub-heading:** `"LUXURY PERFUMERY"`
   * Font: *Montserrat*, 600 weight, 11px, `letter-spacing: 4px`, Color: `#d4af37` (Champagne Gold).
2. **Main Heading:** `"Noir Essence"`
   * Font: *Playfair Display*, 700 weight, 48px to 64px (fluid clamp), Color: `#ffffff`, centered alignment.

---

### C. Central Product Showcase (`.product-stage`)
* **Centerpiece Image:** 3D rendered bottle of "Midnight Rose" perfume.
  * **Bottle Design:** Heavy glass flacon, geometric cut edges, translucent dark red/rosewood liquid visible inside. Black cubic stopper cap. Label reads `"Midnight Rose"` in gold/white serif typography.
* **Carousel Navigation Controls:**
  * Left Arrow (`<`) and Right Arrow (`>`) positioned mid-screen vertically, flanking the perfume bottle. Circular dark backdrop with white chevron icons (`rgba(255,255,255,0.1)` background, scaling on hover).

---

### D. Primary Call-to-Action (CTA)
* **Button:** `"Discover Collection"`
  * **Shape:** Pill/Capsule shape (`border-radius: 50px`).
  * **Background:** Linear gradient of champagne gold (`#e6ca65` to `#b38f27`) with a soft drop shadow/glow.
  * **Text:** *Montserrat*, 600 weight, 13px, uppercase, Color: `#0b0b0d` (Dark contrast).
  * **Hover Effect:** Scale up 1.03x, increased box-shadow blur radius.

---

### E. Secondary Content / Below the Fold (`.product-preview-bar`)
* **Layout:** Horizontal scroll or grid preview cards peeking from the bottom edge of the viewport.
* **Card Style:** Dark translucent cards (`background: rgba(255,255,255,0.03)`, `border: 1px solid rgba(255,255,255,0.08)`, `border-radius: 12px`) showing thumbnail previews of alternative perfume bottles in the collection.

## 5. Animations & Micro-Interactions

### 1. Ambient Floating Animation (CSS Keyframes)
The rose petals and the central perfume bottle should exhibit continuous, subtle floating physics to mimic a suspended 3D environment.
```css
@keyframes float {
  0% { transform: translateY(0px) rotate(0deg); }
  50% { transform: translateY(-12px) rotate(2deg); }
  100% { transform: translateY(0px) rotate(0deg); }
}

.hero-bottle {
  animation: float 6s ease-in-out infinite;
}

.petal {
  animation: floatSlow 9s ease-in-out infinite alternate;
}
```

### 2. Page Load Entrance Sequence (Framer Motion / CSS Triggers)
* **0ms - 300ms:** Background dark gradient fades in.
* **300ms - 700ms:** Header navigation slides down from `y: -20px` with `opacity: 0 -> 1`.
* **600ms - 1100ms:** Central perfume bottle scales up from `0.9` with a smooth blur-to-focus filter transition (`filter: blur(10px) -> blur(0px)`).
* **800ms - 1200ms:** Typography ("Noir Essence" and CTA button) fade up with staggered delays.
