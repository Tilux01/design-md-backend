# UI-Kit Design Specification & Clone Blueprint

This specification details a complete, pixel-accurate design system and layout blueprint based on the provided UI-Kit. The implementation targets a modern, responsive full-screen web application.

---

## 1. Global Styles & Typography

### Layout & Siting
- **Canvas / Root Background:** Soft neutral grey-white (`#F4F5F7` or `#F7F8FA`).
- **Container / Card Surface:** Crisp white (`#FFFFFF`) with ultra-subtle borders where applicable, curved using rounded corners.
- **Corner Radius Scale:** 
  - Buttons / Inputs / Small badges: `8px` to `12px`
  - Cards / Containers: `16px` to `24px`
  - Pill badges / Small elements: Fully rounded (`9999px`)

### Typography & Fonts
- **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif.
- **Fallback Stack:** `sans-serif`
- **Type Scale:**
  - **Screen Title ("UI-Kit"):** `28px` - `32px`, Bold (`700`)
  - **Section Headings ("Buttons", "Icons", "Inputs", etc.):** `16px` - `18px`, Semi-Bold (`600`)
  - **Labels / Row Titles ("Default", "Hover", "Focus", etc.):** `12px` - `14px`, Medium (`500`), Muted Grey (`#6B7280`)
  - **Body / Content Text:** `12px` - `14px`, Regular (`400`), Dark Neutral (`#111827`)
  - **Microcopy / Helper Text:** `10px` - `12px`

---

## 2. Color Palette

| Role | Color Name / Hex | Usage |
| :--- | :--- | :--- |
| **Primary Dark** | `#111827` (Near Black) | Primary buttons, active states, key text elements |
| **Primary Accent / Interactive** | `#A78BFA` / `#C4B5FD` (Soft Purple) | Hover/Active highlights, interactive cards, accent fills |
| **Success / Valid** | `#10B981` (Emerald Green) | Success input states, positive indicators |

| **Neutral Border** | `#E5E7EB` | Dividers, default input borders |
| **Disabled Surface** | `#F3F4F6` | Disabled states, placeholders |

---

## 3. Component Specifications

### A. Buttons Component Matrix
The button group features two primary styles (Solid Dark and Outlined Light) across multiple interactive states and variants (Standard text, text with arrow, icon-only circle).

* **States:**
  1. **Default:** Solid dark (`#111827`) with white text, or clean white with dark outline (`#E5E7EB`).
  2. **Hover:** Shift to soft purple background (`#C4B5FD`) or lighter hover tint.
  3. **Focus:** Clear crisp outline ring (`box-shadow: 0 0 0 3px rgba(167, 139, 250, 0.4)`).
  4. **Disabled:** Desaturated grey background (`#F3F4F6`) with muted grey text (`#9CA3AF`), cursor not-allowed.
* **Variants:**
  - Standard Pill Button with Text ("Button Title")
  - Button with trailing diagonal arrow icon (`↗` inside a circular wrapper)
  - Circular Icon Button (`↗`)

---

### B. Icons Set
A collection of monochrome vector glyphs displayed inline:
- Grid layout icons: Arrow, gear/settings, eye/visibility, sliders, layout boxes, search, lock, cross/close, drop/droplet, plus, minus, right-arrow.
- Color: `#111827` (Dark neutral).

---

### C. Decorative Elements
Hand-drawn style vector strokes and abstract vector bursts:
- Slanted tick mark, loose curly underline, swooping arrow, wavy underline.
- Starburst / geometric asterisk patterns in black and soft yellow (`#FDE047`).

---

### D. Inputs Component Matrix
Form text fields designed with a clear label column on the left and input field on the right.

* **States:**
  1. **Default:** Border `#D1D5DB`, background white, placeholder text "First and last name" in `#9CA3AF`.
  2. **Hover:** Border darkens slightly to `#9CA3AF`.
  3. **Active / Typing:** Text input shows typed value ("John").
  4. **Disabled:** Light grey fill `#F3F4F6`, border `#E5E7EB`.
  5. **Focus:** Purple border ring `#A78BFA` with subtle glow.
  6. **Success:** Green border and text `#10B981` with value ("John Doe").
  7. **Error:** Red border and text `#EF4444` with value ("#Vla5").

---

### E. Cards & Other Components

#### 1. Success Notification Card
- **Background:** Warm bright yellow (`#FEF08A`).
- **Content:** Small close icon (`x`) at top-right, bold heading "Thank you for your application", and body text. Includes a centered dark CTA button "Thank you".

#### 2. Media / Profile Card
- **Layout:** Vertical card containing an image preview at the top, followed by a user handle pill badge (`#tagname`), date, secondary text ("Who is a full-stack developer?"), and a bottom-right diagonal arrow action button.
- **Image Description:** *A high-contrast abstract architectural or robotic hands rendering in grayscale monochrome.*

#### 3. Address Card
- **Background:** Soft Purple (`#C4B5FD`).
- **Content:** Header text "Address", location details ("411 Rosewood Lane, New York, NY 10019"), and a dark circular action button with a diagonal arrow at the bottom right.

#### 4. Accordion Component (FAQ style)
- **State 1 (Collapsed):** Yellow background card (`#FEF08A`) with question text ("How does the learning process work?") and a plus (`+`) icon button on the right.
- **State 2 (Expanded):** Yellow background card with question text, a minus (`-`) icon button, and expanded descriptive body text below.

#### 5. Pricing / Upfront Payment Card
- **Background:** Soft lavender-purple gradient or solid fill (`#C4B5FD`).
- **Content:** 
  - Title: "Upfront"
  - Subtitle: "Get the best deal by paying up front."
  - Pricing: `$4,200` (Strikethrough old price `$5,500`, label "save $700 over Monthly").
  - CTA: Full-width dark button ("Submit an Application") featuring a trailing arrow icon.

---

## 4. Layout Grid Structure

The full-screen layout is structured into a multi-column dashboard grid:
- **Top Bar:** Header title `"UI-Kit"` on the left, pill-shaped outline button `"Guidelines"` on the top right.
- **Row 1:** Full-width **Buttons** section.
- **Row 2 (Split Columns):** 
  - **Left Column:** Icons, Decorative Elements, and Inputs.
  - **Right Column:** Cards & Other UI Modules (Notifications, Media cards, Address card, Accordions, Pricing cards).
