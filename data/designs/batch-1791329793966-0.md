# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Clean Minimalist / Liquid 3D Web Experience with Glassmorphism navigation.
- **Visual Density & Whitespace Ratio**: High whitespace, centralized focal point (metallic liquid sphere), uncluttered navigation, serene horizontal layout.
- **Surface Elevation Model**: Floating translucent glass navigation pill with backdrop blur (`blur-md`), subtle specular borders, and clean depth separation against a fluid 3D ripple background.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Liquid metallic 3D sphere, glassmorphic pill navigation, expansive tracked typography.
- **Pill Badge Specification**: Padding: 8px 16px, font-size: 14px, font-weight: 500, tracking: 0em, border-radius: 9999px, background translucency: rgba(255,255,255,0.75), border width: 1px.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;` or SVG icon component.
  - Status Dot (●) -> Use `&#9679;` or `<span class="w-2 h-2 rounded-full bg-emerald-500 inline-block"></span>`.
