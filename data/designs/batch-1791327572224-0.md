# 1. Design Philosophy & Aesthetic Blueprint
- **Primary Mood & Archetype**: Naturalist Impressionist Art Digital Canvas / Neo-Pointillism Digital Gallery.
- **Visual Density & Whitespace Ratio**: High visual density built via discrete pointillist dots creating continuous tone imagery; zero UI chrome, zero traditional whitespace margins, displaying a 100vw/100vh edge-to-edge digital artwork canvas.
- **Surface Elevation Model**: Single flat pixel grid canvas layer with simulated atmospheric lighting depth gradient ranging from bright horizon sunset golds down to deep shadowy forest greens and midnight canvas blacks.

# 5. AI Design Traits, Micro-Badges & Symbol Safety
- **AI Visual Traits**: Pointillist matrix rendering, high-contrast twilight gradient mapping, ambient backlit horizon glow.
- **Pill Badge Specification**: Padding `4px 12px`, font-size `12px`, font-weight `600`, tracking `0.05em`, border-radius `9999px`, background `rgba(250, 204, 21, 0.1)`, border `1px solid rgba(250, 204, 21, 0.3)`.
- **Symbol & Glyph Safety Mapping**:
  - Em-dash (—) -> Use `&mdash;` or CSS `::before` content.
  - Sparkle / Star (✦) -> Use `&#10022;`.
  - Status Dot (●) -> Use `<span class="w-2 h-2 rounded-full bg-yellow-400 inline-block"></span>`.
