# Mobile App UI/UX Design Specification

## 1. Global Styles & Typography

### Color Palette
*   **Primary Accent (Brand Blue):** `#2563EB` (Used for active buttons, main CTAs, and interactive states)
*   **Secondary Accent (Purple/Gradient):** Linear gradient from `#7C3AED` to `#C084FC` (Used for banner backgrounds and special sections)
*   **Backgrounds:**
    *   App Background / Canvas: `#F8FAFC` (Very light cool gray)
    *   Card Background: `#FFFFFF` (Pure white with subtle shadows)
*   **Text Colors:**
    *   Primary Headings: `#0F172A` (Slate 900)
    *   Body Text / Subtitles: `#64748B` (Slate 500)
    *   Muted / Captions: `#94A3B8` (Slate 400)
*   **Status/Badge Colors:**
    *   Success Green: `#10B981`
    *   Warning Yellow: `#F59E0B`

### Typography System
*   **Primary Font Family:** `Inter`, `SF Pro Display`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, sans-serif
*   **Fallback Stack:** `sans-serif`
*   **Type Scale:**
    *   **Screen Header / Page Title:** 20px / Bold (`700`) / Line-height: 28px
    *   **Card Title / Section Heading:** 16px / Semi-bold (`600`) / Line-height: 24px
    *   **Body Text:** 14px / Regular (`400`) / Line-height: 20px
    *   **Captions / Tags:** 12px / Medium (`500`) / Line-height: 16px

## 2. Screen 1: Dashboard / Home (Left View)

### Layout Structure
*   **Container:** Vertical stack (`flex-direction: column`), 16px padding on left/right.
*   **Top Bar:**
    *   Left: User greeting/avatar thumbnail (circular, ~36px diameter).
    *   Right: Notification bell icon with an active red dot indicator.
*   **Hero Banner / Carousel Section:**
    *   Dimensions: Full width of container, height ~140px, border-radius: 16px.
    *   Left Banner: Deep purple/violet background with bold promotional white text ("SPECIAL OFFER") and an illustration placeholder.
    *   Right Banner: Light pastel-green background with a circular badge/icon.
*   **Quick Actions / Navigation Grid:**
    *   2 rows of circular or rounded square icon buttons with labels underneath.
*   **Main Feed / "Recommended Services" Section:**
    *   Section Header: "Recommended Services" (16px Bold, left-aligned) with a "See All" link on the right.
    *   List Items: Horizontal cards with a thumbnail image on the left, title and description in the middle, and an action button/price on the right.
*   **Bottom Navigation Bar:**
    *   Fixed to the bottom. 4 primary icons representing Home, Search/Explore, Notifications, and Profile, with active state highlighted in Primary Blue (`#2563EB`).

## 3. Screen 2: Recommended Games / Catalog (Middle View)

### Layout Structure
*   **Top Header:**
    *   Center-aligned title: "Recommended Games" (or application equivalent).
    *   Top right: Filter/Sort icon button.
*   **Filter Pill Row:**
    *   Horizontal scrollable row of filter chips (e.g., "All", "Action", "RPG", "Strategy").
    *   Active chip: Solid Primary Blue background with white text.
    *   Inactive chips: White background, 1px solid border (`#E2E8F0`), dark text.
*   **Grid Layout:**
    *   2-column CSS Grid (`grid-template-columns: repeat(2, 1fr)`), with 12px gap.
*   **Card Specifications (Each Grid Item):**
    *   Background: White (`#FFFFFF`).
    *   Border Radius: 12px.
    *   Box Shadow: `0 4px 6px -1px rgba(0, 0, 0, 0.05)`.
    *   Content Layout:
        *   Top: Square thumbnail image (aspect ratio 1:1, rounded corners inside the card).
        *   Middle: Game/Item title (14px Semi-bold, centered or left-aligned).
        *   Bottom: Small pill-shaped CTA button ("Install" or "Play") spanning most of the card width, styled in Primary Blue.

## 4. Screen 3: User Profile (Right View)

### Layout Structure
*   **Header / Cover Photo Area:**
    *   Top banner with a vibrant pink-to-orange sunset gradient background.
    *   Overlapping Avatar: Centered circular profile picture overlapping the bottom edge of the cover banner (diameter: ~80px, white border of 3px).
*   **Profile Details:**
    *   Username/Name: Centered, 18px Bold (`#0F172A`).
    *   Action Buttons Row: Two buttons side-by-side underneath the username ("Follow" / Primary Blue, and "Message" / Light Gray outline).
*   **Stats / Metrics Bar:**
    *   Horizontal layout distributing 3 core stats evenly (e.g., Followers, Following, Posts/Likes).
    *   Number: 16px Bold. Label: 12px Muted (`#94A3B8`).
*   **Bio / Details Section:**
    *   Short descriptive text block centered or left-aligned with light padding.
*   **Media Gallery / Tabbed Content:**
    *   Tab switcher (Grid icon vs. List/Bookmark icon).
    *   2-column or 3-column thumbnail grid displaying user posts or achievements.

## 5. Asset & Image Specifications

*Note: All images should be implemented using standard `<img>` tags or CSS background properties with appropriate scaling (`object-fit: cover`).*

1.  **Avatars & Thumbnails:**
    *   *Type:* Backgroundless/Transparent PNGs or high-res circular crops where applicable.
    *   *Placement:* Centered inside respective avatar containers with `border-radius: 50%`. No rotation.
2.  **Hero Banners (Screen 1):**
    *   *Type:* Rectangular raster illustrations with transparent or matching gradient backgrounds.
    *   *Placement:* Aligned to the right side of the banner containers. No rotation.
3.  **Grid Icons / Game Logos (Screen 2):**
    *   *Type:* High-definition app/game icons with rounded rectangular masks (`border-radius: 12px`).
    *   *Placement:* Top-centered within each grid card. No rotation.
